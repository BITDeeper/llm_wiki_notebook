AI自主提交35%代码！Cursor CEO重磅宣言：第三AI编程时代已至 §

摘要 §

本文报道了 Cursor CEO Michael Truell 提出的“AI 编程第三时代”理论。该理论认为，AI 编程已从 Tab 补全（第一时代）和本地智能体（第二时代），演进至以 云端智能体 为核心的自主交付时代。数据显示，Cursor 内部 35% 的代码已由云端智能体自主创建，智能体用户数量已是 Tab 用户的 2 倍。

核心观点 §

三个时代的划分 §

  1. 第一时代（2024）：以 GitHub Copilot 为代表的 Tab 自动补全。AI 作为“超级输入法”，主要处理低熵、重复性代码片段，核心价值是“效率杠杆”。
  2. 第二时代（2025 下半年）：本地智能体崛起。通过“提示-响应”循环，开发者可指挥 AI 编写特定模块，但每一步仍需人类实时审阅。
  3. 第三时代（当前）：云端智能体自主交付。Agent 具备长时序规划能力，以 可评审工件（如视频、日志）形式交付成果，人机关系转变为“指挥官与车队”。

关键数据与趋势 §

  • 行为迁移：2025 年 3 月，Tab 用户约为 Agent 用户的 2.5 倍；现在 Agent 用户数量是 Tab 用户的 2 倍。
  • 代码贡献：Cursor 内部代码提交中，35% 由云端虚拟机中自主运行的智能体创建。
  • 并行性：云端 Agent 解决了本地资源竞争问题，允许开发者同时启动多个 Agent 并行工作。

实战场景 §

文章展示了云端 Agent 在四个复杂场景中的应用：

  1. 构建新功能：自主解析文件、构造链接并录制验证视频。
  2. 复现安全漏洞：构建 HTML 演示页面，执行攻击流程并输出分析报告。
  3. UI 自动化测试：进行 45 分钟全流程走查，生成测试总结与截图。
  4. 快速修复与验证：实现逻辑代码并录制视频验证修复效果。

角色重塑 §

程序员转型为 ai车队指挥官。核心技能从“手写优雅代码”转向：

  • 精准定义问题边界。
  • 设计鲁棒的验收标准。
  • 高效协调多智能体协作。

潜在挑战 §

  • 稳定性：大规模工业化场景下，不稳定测试或环境损坏可能导致 Agent 频繁中断。
  • 信任与安全：在涉及生命的关键场景（如飞机控制）中，如何防止 Agent 因幻觉跳过测试。
