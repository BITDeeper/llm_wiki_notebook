GitHub Star明码标价5毛/颗，AI项目刷假星最猛

概述

本文报道了卡内基梅隆大学（CMU）关于 GitHub 平台虚假 Star 行为的研究（ICSE 2026）。研究揭示了 GitHub 上存在约 600 万颗假星，涉及 1.8 万个仓库和 30 万个造假账号。文章指出，AI/LLM 项目是刷假星的重灾区，其背后的主要驱动力是风险投资（VC）将 Star 数量作为融资的隐形门槛，导致创业者通过低成本刷星来换取高额融资。

核心发现

造假规模与工具

  • 规模：GitHub 上存在约 600 万颗假星，分布在 18,617 个仓库，涉及超过 30 万个造假账号。
  • 检测工具：CMU 团队研发了 starscout 工具，通过识别僵尸账号、同步批量点星等异常行为进行检测，准确率达 81%。
  • 案例：某拥有 111 Star 的仓库，经核验至少 109 颗为假星。

假星产业链

  • 分层定价：
    • 廉价版：$0.03-0.10/颗（约 0.2-0.7 元人民币），使用批量注册的空白小号。
    • 高端版：$0.80-0.90/颗，使用养号多年的优质老账号，模拟真人行为。
  • 账号农场：拥有 5 年 commit 记录和 Arctic Code Vault 徽章的账号售价高达 $5000。
  • 渠道：至少 12 个公开网站和 Fiverr 上的 24 个活跃卖家提供此类服务，甚至支持 API 批量购买。

AI 项目重灾区

  • 在非恶意项目中，AI/LLM 类项目的刷星现象最为严重。
  • 78 个重度刷星项目曾成功挤进 GitHub Trending 榜单。
  • 短期效应：假星仅在不到 2 个月内有效，长期会拖累真实活跃度。

经济动机：Star = 融资入场券

  • VC 隐形门槛：Redpoint 合伙人指出，开源项目种子轮融资的中位数 Star 数为 2850，A 轮需达到 4980。
  • ROI 计算：
    • 成本：达到种子轮门槛需 2850 颗星，按廉价版计算成本约 85−285。
    • 收益：种子轮融资中位数通常在 100 万–1000 万美元。
    • 结论：刷星的 ROI 极高，驱使创业者通过造假来通过 VC 的初筛。
  • 恶性循环：VC 看 Star → 创业者刷星 → VC 更信 Star → 更多造假。

评估指标的失效与替代

  • 失效指标：Star 数量因造假泛滥而失去参考价值。
  • 替代指标：
    • fork-to-star-比率：健康项目通常在 0.1–0.2，过低（如 Union Labs 的 0.052）暗示刷星。
    • Last commit date（最近提交日期）。
    • 项目年龄与更新频率。
    • Issues 和核心代码质量。
