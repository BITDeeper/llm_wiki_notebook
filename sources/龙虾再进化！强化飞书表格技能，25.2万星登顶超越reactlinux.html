龙虾再进化！强化飞书表格技能，25.2万星登顶超越React/Linux §

概述 §

本文报道了开源 AI 智能体工具 openclaw 在 2026 年 3 月发布的 2026.3.1 版本更新。此次更新包含 90 多个 PR 的合并，标志着该项目在功能深度和本土化适配上的重大飞跃。同时，OpenClaw 的 GitHub Star 数达到 25.2 万，超越 Meta 的 React，登顶 GitHub 历史星标榜。

核心更新内容 §

1. 模型能力升级 §

  • Claude 自适应思维：适配了 claude 4.6 的自适应思维功能。模型可根据任务难度（如简单问答 vs 复杂推理）动态调整思考级别，从而优化 Token 消耗和响应速度。
  • OpenAI 接口优化：引入 WebSocket 传输协议和 Warm-up 预热机制，显著降低了响应延迟和连接中断率，提升了对话体验的稳定性。

2. 安卓端自动化扩容 §

新增了大量系统级脚手架，大幅增强了移动端自动化能力：

  • 短信操作：打开、清除、回复信息。
  • 设备管理：列出可用摄像头，查询和管理权限状态。
  • 健康检查：监控电池、电量、存储和温度等设备状态。

3. 深度本土化（飞书生态） §

本次更新特别强调了对国内办公环境的支持，主要得益于大量中文贡献者的参与：

  • 飞书表格技能：支持在飞书文档中创建、修改表格，并自动填充数据。
  • 文件与媒体上传：支持直接将图片和文件上传至飞书。
  • 聊天查询：具备查询聊天信息和成员列表的能力。
  • Web UI 汉化：Cron 定时任务页面支持中英文双语切换。

社区影响力与争议 §

GitHub 排名里程碑 §

OpenClaw 以 25.2 万 Star 超越了老牌劲旅 React（Meta 开源的 JavaScript 库），成为 GitHub 历史上星标最多的软件项目。官方对此进行了高调宣传，甚至对 Meta 进行了“贴脸嘲讽”，引发部分社区争议。

实用性讨论 §

尽管 Star 数量惊人，但有观点指出，React 作为互联网基础设施，其工业级影响力仍不可撼动；而 OpenClaw 目前更多被视为“玩”的工具，实际产出相对较少。

风险提示 §

文章特别提醒用户，在更新版本前务必做好数据备份。已有用户反馈在更新后出现“记忆被清空”的情况，这反映了快速迭代版本可能存在的稳定性风险。
