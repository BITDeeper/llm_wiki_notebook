源：MiniMax 发布 MaxClaw 及专家智能体生态 §

概述 §

本文是量子位对 MiniMax Agent 平台发布的 MaxClaw 模式及 Expert 社区的深度评测。文章详细记录了如何通过 MaxClaw 实现 OpenClaw 的“真·一键部署”，并实测了社区中超过 10000 个垂直领域专家智能体的实际表现。

核心内容 §

MaxClaw：一键部署 OpenClaw §

MiniMax 推出的 MaxClaw 模式旨在降低 OpenClaw 的使用门槛。

  • 部署效率：从点击到 Gateway 启动仅需 20 秒。
  • 预置工具：内置了爆款猎手、多 Agent 投研团队、热点追踪等组合，以及生图、搜图、生成视频、部署应用等实用技能。
  • 平台集成：可直接接入飞书和钉钉，实现工作流无缝衔接。
  • 实测表现：在“城市书房装饰风格分析与邀请函生成”任务中，MaxClaw 准确理解了时间表述（“这周日”转换为具体日期），并成功生成了符合要求的图像。

Expert 社区与智能体生态 §

  • 规模：平台已拥有 10000+ 个公开专家智能体，覆盖技术开发、创意写作、金融分析等领域。
  • 创作模式：用户无需懂代码，通过自然语言描述私有知识和 SOP（标准作业程序），即可创建专属智能体。
  • 激励机制：用户发布的智能体被他人使用可获得积分；未来将推出 Marketplace 交易市场，支持挂牌定价。

实测案例：AI 短剧导演 §

测试了第三方创作的“AI短剧导演+摄影+剪辑师”智能体，任务是为治愈系随笔集制作预热短视频。

  • 工作流逻辑：展现了严谨的递进式创作流程（剧本分析 -> 参考图设计 -> 分镜设计 -> 首帧生成 -> 视频生成 -> 剪辑合成）。
  • 技术能力：智能体在剪辑环节调用了 FFmpeg 和 Python 脚本。尽管 Python 脚本运行中出现多次报错，但智能体自主完成了代码修正并成功运行，展现了强大的代码调试与自我修复能力。
  • 最终效果：生成的视频准确还原了“深夜书店”的暖色调氛围，细节（如中英文手写体、非卖品木牌）处理到位。

实测案例：剧本杀全案策划 §

通过对话创建了一个自定义的“剧本杀全案策划系统”智能体。

  • 流程设计：将策划过程拆解为七个阶段（商业定位 -> 世界观 -> 核心诡计 -> 角色剧本 -> 线索机制 -> DM手册 -> 视觉素材）。
  • 生成质量：生成的《旧校舍の怪奇：七人の影》剧本逻辑严密，包含齿轮共振密室手法和多重不在场证明，人物立绘和主海报也符合日式校园怪谈风格。

观点与趋势 §

  • 贾维斯时刻：文章认为，这种将复杂技术封装、通过自然语言调用的方式，正在将“全员贾维斯”从科幻变为现实。
  • SaaS 替代：Expert 智能体在垂直场景下已展现出对标甚至超越传统 SaaS 的能力，通过逻辑编排和低成本调用打破了软件门槛。
  • 生态重塑：行业正在从单纯的模型竞争转向基于私有知识和 SOP 封装的生态竞争。
