Anthropic封号OpenClaw之父！复刻、改价、拉黑，24天三连杀 §

摘要 §

本文详细记录了 Anthropic 与开源 AI Agent 工具 openclaw 之间的冲突升级过程。核心事件包括：Anthropic 在 2026 年 4 月通过“复刻功能、改价限制、封禁账号”三连手段打击 OpenClaw；OpenClaw 创始人 peter-steinberger 因此转投 openai；以及这一事件背后暴露的 ai-subscription-crisis（AI 订阅制危机）。

核心事件时间线 §

  1. 早期法律施压（2025年）：Anthropic 因 OpenClaw 原名 “Clawdbot” 与 “Claude” 发音相似，向 Steinberger 发送律师函要求更名。Steinberger 在更名过程中遭遇投机者抢注和网络骚扰，最终花费 1 万美元完成更名。
  2. 产品围剿（2026年1月-3月）：Anthropic 推出的 claude-cowork 产品线逐步复刻了 OpenClaw 的核心功能（本地文件读写、跨设备任务派发、桌面控制、Telegram/Discord 集成）。
  3. 商业模式突变（2026年4月3日）：Claude Code 负责人 boris-cherny 宣布订阅服务不再覆盖 OpenClaw 等第三方工具，仅提前一天通知。
  4. 账号封禁风波（2026年4月10日）：Steinberger 的 Claude 账号因“可疑信号”被封禁，引发社区轰动。两小时后解封，但 Anthropic 未给出官方解释。

关键论点与数据 §

算力经济账 §

文章指出，传统的 20 美元包月订阅模式无法适应 Agent 时代的高消耗：

  • 单实例成本：一个重度 OpenClaw 实例 24 小时运行，日消耗 Token 价值 1000-5000 美元。
  • 用户支出：用户仅需支付 200 美元/月的订阅费。
  • 规模：当时全球有 13.5 万个活跃实例。 这解释了 Anthropic 必须切断补贴、转向按量计费或限制第三方访问的经济动因。

生态竞争与人才流失 §

  • Steinberger 的名言“一家欢迎我，一家发来律师函”概括了 OpenAI 与 Anthropic 对开源社区态度的差异。
  • Steinberger 加入 OpenAI 后，负责让 ChatGPT 成为 OpenClaw 用户迁移的下一站，同时仍需购买 Claude API 以维持 OpenClaw 对 Claude 的兼容性。

相关概念 §

  • 逆向代理：OpenClaw 被视为利用官方订阅额度的第三方 Harness，是平台打击的重点。
  • 平台完整性检查：Anthropic 以此为由封禁账号，展示了平台方对生态的绝对控制权。
