# Grok Build上线

2026年5月14日，[[xAI]]正式发布[[grok-build|Grok Build]]终端级AI编程Agent，标志着马斯克编程赛道三连布局的第三步"Agent拿入口"正式落地。

## 产品特点

- 终端级命令行AI编程Agent
- 支持代码生成、文件编辑、依赖管理、shell命令执行
- 最多8个子Agent并行工作
- 原生兼容[[claude-code|Claude Code]]的CLAUDE.md配置文件

## 定价

SuperGrok Heavy订阅每月300美元，前六个月促销价99美元。

## 意义

Grok Build的上线完成了马斯克编程赛道的完整闭环：收购拿分发 → 数据拿能力 → Agent拿入口。其主动兼容Claude Code配置的设计选择，确认了Claude Code在编程Agent领域的事实标准地位。
