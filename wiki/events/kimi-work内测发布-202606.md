# Kimi Work内测发布

2026年6月初，月之暗面推出面向知识工作者的本地通用 Agent [[kimi-work]]，进入内测阶段。

## 背景

紧接2026年5月 [[大模型嵌入办公套件潮-2026年5月]] 之后，AI 办公赛道持续升温。与 OpenAI、Anthropic、商汤等厂商聚焦编程或设计场景不同，月之暗面选择了差异化路径——瞄准非技术职场用户的日常办公需求。

## 核心特征

- 定位为"[[vibe-working]]"而非"[[vibe-coding]]"
- 内置 [[webbridge]] 浏览器操控插件
- 支持自定义 Skill 和本地 Skill 调用
- Agent 集群支持最多 300 个子 Agent

## 意义

标志着 AI Agent 赛道从编程工具向通用办公工具的分化节点。在 [[codex]]、[[claude-code]] 等编程导向产品密集发布的背景下，Kimi Work 代表了一种"不卷 Code、卷 Work"的差异化竞争策略，验证了 [[领域驱动ai办公]] 的市场可行性。
