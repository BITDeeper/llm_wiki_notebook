# Gemini 3.5 Live Translate 发布

2026年6月11日，Google 发布 [[gemini-3-5-live-translate|Gemini 3.5 Live Translate]]，将实时语音翻译从"等你说完再翻"推进到[[实时同声传译|边听边译]]模式。[[jeff-dean|Jeff Dean]] 亲自官宣。

## 发布内容

- **模型**：[[gemini-3-5-live-translate|Gemini 3.5 Live Translate]]，基于 [[gemini-3-pro|Gemini 3 Pro]]
- **语言覆盖**：70+语言，全自动识别
- **核心突破**：边听边译，延迟几秒，保留说话人声音特征

## 三线落地

1. **开发者**：Gemini Live API 和 Google AI Studio 公测，当日可用
2. **企业**：[[google-meet|Google Meet]] 私测启动，从5种语言扩展至70+
3. **消费者**：[[google-translate|Google Translate]] 安卓/iOS全球上线

## 真实场景验证

[[grab|Grab]] 月超1000万通语音电话作为核心落地场景，非Demo级别验证。

## 背景与战略

- Google翻译项目跨度20年，从文本翻译→拍照翻译→实时语音同传
- 发布时间点处于2026年Q2 AI IPO窗口期，与 [[openai|OpenAI]]/[[anthropic|Anthropic]]/[[spacex|SpaceX]] 资本市场焦点同期，有明显的注意力竞争意图
- 谷歌选择"嵌入现有产品矩阵"路线，与OpenAI [[超级应用战略]] 形成差异化对照
