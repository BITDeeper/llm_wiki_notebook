# AI编程工具自治任务竞赛

2026年4月底至5月上旬，三大主流AI编程工具在短短两周内密集推出"AI自拆任务、自派智能体"功能，标志着AI编程范式发生关键跃迁。

## 时间线

- **4月底**：[[openai|OpenAI]] Codex CLI上线/goal功能（[[codex-goal功能上线-202604]]）
- **5月6日**：[[anthropic|Anthropic]]上线多智能体编排功能
- **5月7日**：[[cursor|Cursor]]上线/orchestrate功能

## 路线分歧

| 产品 | 策略 | 智能体限制 |
|------|------|-----------|
| Codex | 放手并行派生 | 无明确限制 |
| Claude Code | 带护栏放权 | 最多20个subagent，仅1层深度 |
| Cursor | /orchestrate编排 | 待确认 |

## 核心意义

三家产品方向出奇一致，说明"让AI自己拆任务、自己派智能体"已成为跨产品的行业共性方向。当代码、任务、意图一层层交还给模型后，开发者角色面临根本性重新定义——从写代码到写任务，再到如今仅提供一句话意图。
