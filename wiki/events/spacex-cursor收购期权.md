# SpaceX-Cursor收购期权披露

2026年4月，[[spacex]] 与 [[cursor]] 签署算力合作协议时嵌入了一份收购期权，该期权在SpaceX IPO招股书中首次披露。

## 期权条款

- **类型**：收购期权（可买可不买）
- **隐含估值**：约600亿美元
- **支付方式**：SpaceX Class A股票
- **推进计划**：上市后30天内推进收购
- **违约成本**：15亿美元分手费 + 85亿美元递延服务费

## 背景

Cursor此前已使用SpaceX的 [[colossus-2|Colossus II]] 算力上架新模型。算力合作协议表面是商业合作，实则暗含并购意图。
