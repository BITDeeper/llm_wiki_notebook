# DeepSeek V4-Pro API永久降价

2026年5月23日，DeepSeek宣布V4-Pro API永久降价，从促销价变为正式定价，不再恢复原价。

## 降价细节

- **生效日期**：2026年6月1日
- **输入缓存命中**：0.025元/百万Token
- **输入缓存未命中**：3元/百万Token
- **输出**：6元/百万Token
- **降幅**：均为原定价的四分之一
- **时限**：永久，无恢复原价计划

## 背景

此次降价与[[deepseek-700亿融资轮|700亿融资]]消息同日发布，体现了[[梁文锋]]"一边融资一边让利"的独特逻辑。降价原因包括：

1. 在探索下一代模型结构中成本先降下来
2. 践行[[普惠定价哲学]]——AI应普惠人人可用

这是继2024年[[deepseek-v4|DeepSeek V2]]首次降价后的又一次重大价格调整，且首次将"降价活动"永久化。
