# Anthropic发布递归自我改进报告

## 事件概述

2026年6月5日，[[anthropic|Anthropic]] 发布重磅博客"When AI builds itself"（当AI开始造AI），首次系统性地公开内部 [[递归式自我改进]] 的量化数据，并发出全球暂停前沿AI开发的呼吁。

## 核心数据披露

| 指标 | 数据 |
|------|------|
| AI编写代码占比 | 超80%（2025年2月前为个位数） |
| 工程师人均产能提升 | 8倍（相对2024年） |
| 研究人员自评产出 | 4倍（中位数） |
| 最开放任务成功率 | 26%→76%（6个月） |
| 实验优化加速 | 52倍（[[claude-mythos-preview|Mythos Preview]]） |
| 研究判断胜率 | 64%（Mythos Preview） |
| 端到端实验性能追回 | 97%（vs 人类23%） |
| Glasswing漏洞发现 | 超10000个高危漏洞 |

## 三种未来剧本

1. **趋势停滞**（S曲线见顶）—— Anthropic最不相信
2. **复合加速持续**（人类掌舵）—— Anthropic认为最可能
3. **完全递归自我改进** —— Anthropic承认"没有好的直觉"

## 暂停呼吁

Anthropic呼吁多国、多个前沿实验室在同样条件下同时暂停前沿AI开发，且彼此可验证。同时承认单方面减速等于"把领先优势拱手送给最不谨慎的人"。

## 历史意义

本报告标志着 [[递归式自我改进]] 从理论推测进入有量化数据支撑的现实阶段，可能被视为通向 [[asi-超级智能|ASI]] 进程中的关键里程碑。[[jack-clark|Jack Clark]] 给出2028年底前出现递归自我改进60%概率的预测。
