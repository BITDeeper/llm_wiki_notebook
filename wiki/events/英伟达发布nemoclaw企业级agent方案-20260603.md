# 英伟达发布NemoClaw企业级Agent方案

2026年6月3日，[[英伟达]] 官方连发两条帖子，正式推出 [[hermes-agent]] + [[nemoclaw]] 企业级部署方案，标志着芯片厂商正式入局 Agent 部署层竞争。

## 背景

英伟达对 Hermes Agent 的布局经历了三步走：
1. **2026-05-13**：发布博客，将 Hermes 适配到 RTX PC 和 DGX Spark（消费侧，配 Qwen 3.6）
2. **2026-05-31**：GTC Taipei 发布 [[rtx-spark]]，宣布 Hermes 和 [[openclaw]] 将集成 [[openshell]]
3. **2026-06-03**：正式推出企业级方案

## 核心发布内容

- [[nemoclaw]]：Agent 整体部署蓝图
- [[openshell]]：安全沙箱运行时
- [[nemotron-3-super]]（120B-A12B）：默认底层推理引擎
- 55分钟官方演示视频、技术博客、代码仓库一应俱全

## 影响

- 标志着英伟达从芯片供应商向 Agent 生态入口层扩张
- 开启了芯片厂商、模型厂商、应用厂商在 Agent 部署层的多方竞争
- 为 [[hermes-agent]] 提供了企业级安全背书，尽管此前存在抄袭争议
