# Ralph Loop 闭环交付革命

## 概述

2026年4月至5月，澳大利亚开发者 [[geoffrey-huntley]] 发明的三行 bash 脚本 [[ralph-loop]] 在 11 天内被三大 AI 实验室集体收编，标志着 AI 编程从"生成代码"向 [[闭环交付]] 的范式确立。

## 时间线

- **2026年4月19日前后**：Geoffrey Huntley 发布 Ralph Loop
- **2026年4月30日**：[[openai|OpenAI]] Codex 率先上线 /goal 功能，Greg Brockman 在 X 上宣布"内置 Ralph loop++"
- **2026年5月7日左右**：[[hermes-agent|Hermes Agent]]（[[nous-research|Nous Research]]）跟进上线 /goal 及多智能体看板系统
- **2026年5月11日左右**：[[claude-code|Claude Code]]（[[anthropic|Anthropic]]）上线 /goal 功能

## 因果链

[[ralph-loop]] 发明 → Codex 率先产品化（4/30）→ Hermes 跟进（~5/7）→ Claude Code 最后跟进（~5/11），呈现明确的行业扩散路径。

## 三条实现路径

| 实验室 | 产品 | 核心策略 | 设计哲学 |
|--------|------|----------|----------|
| OpenAI | Codex | 持久化工作流对象 + 软着陆 | 不忘事 |
| Nous Research | Hermes Agent | 多智能体看板 + 五层防烂尾 | 不烂尾 |
| Anthropic | Claude Code | 独立裁判模型验收 | 不自欺 |

## 影响

这一事件确立了 [[goal模式]] 作为 AI 编程工具的标配功能，开启了 [[工作流入口]] 的争夺战。核心洞察：通用人工智能的临门一脚可能不是更聪明的模型，而是"把事做完"的模型。
