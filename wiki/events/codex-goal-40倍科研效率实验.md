# Codex Goal Mode 40倍科研效率实验

2026年5月13日，Agentic AI工程师 [[dan-mcateer|Dan McAteer]] 在X上披露了一项使用 [[codex-goal-mode|OpenAI Codex Goal Mode]] 的实验结果，引发学术界广泛关注。

## 实验配置

- **工具**：OpenAI Codex /goal 命令
- **模型**：[[gpt-5.5|GPT-5.5]] high
- **模式**：fast mode
- **任务领域**：[[mechanistic-interpretability|机械可解释性]]（Mechanistic Interpretability）

## 实验结果

- **GPT-5.5自行估算**：博士完成该任务需约80小时
- **AI实际用时**：1小时56分钟
- **效率提升**：约40倍

## 影响与评价

该实验被视为AI自主科研能力的标志性演示事件，与 [[openclaw-130万月度账单事件-202605|OpenClaw 130万月度账单事件]] 共同构成2026年5月AI编程代理领域的两个关键节点。

**局限性**：单一实验，缺乏可重复性验证和同行评审；机械可解释性作为AI内部任务可能天然更适合AI辅助，泛化性有待验证。
