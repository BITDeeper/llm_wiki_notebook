# 字节跳动发布 Lance 轻量级统一多模态模型

2026年6月1日，字节跳动智能创作实验室正式发布原生统一多模态模型 Lance，论文提交于2026年5月（arxiv.org/abs/2605.18678），代码在 GitHub 开源。

## 事件概述

Lance 以 3B 激活参数在视频理解（MVBench 62.0）与视频生成（VBench 85.11）双榜登顶统一模型第一，图像生成 GenEval 综合得分 0.90，媲美 20B 规模模型。仅用 128 张 GPU 完成训练。

## 核心创新

- [[双专家混合架构]]：理解专家与生成专家共享上下文但计算路径解耦。
- [[mape-模态感知位置编码]]：在时间维度为不同功能 Token 组引入特定偏移量。
- [[四阶段进阶训练]]：PT → CT → SFT → RL 渐进式训练策略。

## 行业影响

此次发布发生在商汤开源 SenseNova-U1（2026年5月）之后约一个月，标志着[[原生理解生成统一]]范式从单一团队探索进入多团队竞赛阶段。Lance 与 SenseNova-U1 采用了不同的技术路线（双专家 MoE vs. neo-unify 架构），反映了该领域尚未形成共识性最优解。

Lance 的 3B 参数 + 128 GPU 训练配置，为资源受限团队提供了高参考价值的轻量级方案。
