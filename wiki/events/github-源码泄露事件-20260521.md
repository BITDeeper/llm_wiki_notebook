# GitHub 3800+源码库泄露事件

2026年5月21日，[[github]] 3800多个内部代码仓库遭黑客入侵，核心源代码在黑客论坛[[breachforums]]被公开叫卖，要价5万美元。

## 事件经过

### 攻击路径
1. 攻击者在VS Code扩展市场投放被投毒的恶意插件
2. 一名GitHub内部开发人员在工作设备上安装了该恶意插件
3. 恶意插件截获了开发者的长期有效个人访问凭证
4. 黑客利用凭证入侵3800+内部代码仓库
5. 核心源码在BreachForums被公开叫卖

### 黑客声明

> "主平台的一切都在这里，我很乐意向有兴趣的买家发送样本，验证真实性。这不是敲诈，我们懒得去勒索GitHub。只要有一个人接单，我们就会彻底粉碎数据。如果找不到买家，我们很快就会免费公之于众。"

### 官方回应
GitHub官方证实3800+内部代码仓库确实遭到入侵。

## 背景漏洞

2026年3月，安全机构还发现了GitHub内部Git基础设施的一个0-day级高危漏洞。如果被利用，攻击者可直接无限制访问全网数百万个公共和私有代码库，潜在后果比本次泄露恐怖百倍。

## 影响评估

- 对以"代码安全与托管"为立身之本的GitHub而言，源代码被公开叫卖是致命的信誉打击
- 暴露了VS Code插件生态缺乏高强度审核机制的系统性风险
- 与此前[[source-map-leaks|Claude Code源码泄露]]形成对照，属于同类安全事故的不同案例
