# GTC Taipei 2026 — 英伟达发布 RTX Spark

2026年6月1日，英伟达在台北举办 GTC Taipei 2026 大会，CEO [[黄仁勋]] 发表主题演讲，正式发布 [[rtx-spark|RTX Spark]] 超级芯片，宣布英伟达正式进入消费级 Arm PC 市场。

## 事件经过

黄仁勋在近1小时的主题演讲中，首先回顾了2026年3月 GTC 大会发布的 Vera Rubin 系列 GPU（已全面投入生产）和面向智能体时代的 Vera CPU，随后进入重头戏——发布 RTX Spark。

## 核心发布

- **[[rtx-spark|RTX Spark]]**：集成 Grace CPU + Blackwell RTX GPU 的超级芯片，最高 1 Petaflop AI 算力、128GB 统一内存
- **[[agent-pc|Agent PC]]**：提出 PC 从工具向"队友"的范式转变
- **[[nvidia-open-shell|NVIDIA Open Shell]]**：端侧 Agent 安全运行时环境
- **Windows on ARM 生态**：确认专业创作软件和主流游戏的 Arm 适配进展

## 前置事件

- 2025年：DGX Spark / GB10 芯片发布，RTX Spark 的技术前身
- 2026年3月：Vera Rubin 系列 GPU 和 Vera CPU 在 GTC 发布
- 2026年5月31日：[[微软]] 博客发布 Windows PC 新篇章公告

## 影响与意义

此次发布标志着 PC 行业可能迎来架构格局的重大变化：
- 英伟达作为 GPU 巨头正式挑战 x86 在 PC 市场的主导地位
- Arm 架构首次在高端 Windows PC 领域获得顶级硬件支持
- [[agent-pc|Agent PC]] 概念获得具体产品载体，端侧 AI Agent 的硬件基础快速成熟
- [[openclaw]]、[[hermes-agent]] 等主流 Agent 框架已开始适配新平台
