# Agnes AI全模态免费API发布

2026年6月1日，[[agnes-ai]] 宣布即日起无限期免费开放旗下全模态API，涵盖文本、图片、视频三类生成能力。

## 事件详情

### 开放模型
- **[[agnes-2-0-flash]]**：文本模型，已进入 [[claw-eval]] 榜单
- **[[agnes-image-2-0-flash]]**：图片模型，已进入 [[artificial-analysis]] Image Editing Leaderboard
- **[[agnes-video-2-0]]**：视频模型，已进入 [[artificial-analysis]] Image to Video Leaderboard (With Audio)

### 接入方式
- 官方API平台：https://platform.agnes-ai.com/
- 通过 [[workbuddy]] 打包为Skill
- 通过 [[hermes-agent|Hermes]] 本地Agent配置为默认模型

## 行业背景

此事件发生在2026年5月 [[ai-subscription-crisis|AI订阅制危机]]、[[anthropic反超openai-202604|Anthropic反超OpenAI]]、[[第四届中国aigc产业峰会|AIGC产业深水区讨论]]之后，代表行业从"能力竞赛"进入"可及性竞赛"的新阶段。

## 核心影响

Agnes的 [[全模态免费api策略]] 向行业抛出了一个直接问题：当高质量AI能力越来越像水、电、云服务器一样成为基础设施，它到底应该有多贵？
