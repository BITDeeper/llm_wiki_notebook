# ATLAS视觉推理范式发布

2026年5月22日，[[meta-ai|Meta AI]] 与 [[香港中文大学]] 联合发布 [[atlas-视觉推理|ATLAS]] 视觉推理范式，论文第一作者为 [[ziyu-guo|郭子钰]]。

## 事件概述

ATLAS 提出了一种全新的视觉推理范式：用单一离散 [[functional-token|Functional Token]] 同时充当 Agentic Operation 和 Latent Visual Reasoning Unit，无需外部工具或中间图像生成即可完成复杂视觉推理。

## 核心贡献

1. **范式统一**：首次将 Agentic Visual Reasoning 和 Latent Visual Reasoning 统一在单一离散 Token 框架下。
2. **Functional Token 机制**：将复杂视觉操作压缩为词表中的普通 Token，自然兼容标准自回归训练。
3. **[[la-grpo|LA-GRPO]] 算法**：解决 [[梯度稀释]] 问题，确保模型精准学习关键视觉操作 Token。
4. **ATLAS-178K 数据集**：覆盖 40+ 种视觉推理任务的统一标注数据。

## 影响

ATLAS 为多模态模型提供了一种新的能力接口——让模型学会一套简洁的视觉动作语言，在保证可扩展性、泛化性、可解释性的同时避免冗长推理过程和额外中间监督。这标志着视觉推理从"重工具/重生成"向"轻量离散语义操作"的范式演进。
