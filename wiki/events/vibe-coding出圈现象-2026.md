# Vibe Coding 出圈现象（2026年）

2026年4月至5月期间，[[vibe-coding|Vibe Coding]] 从程序员圈层快速扩散至文学圈、娱乐圈等非技术领域，多位知名非技术人物公开实践并取得实际成果。

## 关键事件

- **2026年4月**：[[milla-jovovich|Milla Jovovich]] 发布 [[mempalace|MemPalace]]，GitHub 52.6k stars，[[longmemeval|LongMemEval]] 96.6%
- **2026年5月**：[[余华]] 在《影视飓风》节目中展示对 AI 和"本地部署"概念的认知
- **2026年5月**：[[胡彦斌]] 在《歌手》节目透露通过 Vibe Coding 开发粉丝社区 App [[彦火]]

## 背景与成因

[[andrej-karpathy|卡帕西]] 于2025年提出 Vibe Coding 概念后，随着 AI 编程工具（Claude、Cursor 等）的成熟，非技术人员首次具备了独立完成软件开发的现实条件。

## 影响与意义

- 标志着 Vibe Coding 从"技术圈术语"演变为"大众文化现象"的关键转折
- 为"[[人人都是开发者叙事|人人都是开发者]]"叙事提供了前所未有的实证案例
- 暗示 AI 编程工具的用户群体正在从专业开发者向泛创作者扩展
