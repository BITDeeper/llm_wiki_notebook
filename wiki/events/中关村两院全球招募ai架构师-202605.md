# 中关村两院全球招募AI时代架构师

## 事件概述

2026年5月27日，[[北京中关村学院]] 与 [[中关村人工智能研究院]] 通过 [[机器之心]] 等渠道发布全球人才招募计划，以"AI时代架构师"为号召，面向全球招募三个层级的AI人才。

## 招募层级

1. **领军人才**：博士学位，海外副教授及以上职务或国际企业高级职务
2. **青年科学家**：博士学位，40周岁以下（1986年1月1日后出生），海外36个月以上工作经验
3. **[[z-star|Z-Star]]**：应届博士/博后，具备独立科研能力与卓越潜质

## 四大招聘方向

| 学部 | 方向 |
|------|------|
| 人工智能核心学部 | AI系统、AI模型、理论与算法、具身智能、AI安全 |
| 智能科学技术学部 | 科学计算、生命科学、物质科学、能源科学、量子科学、科学智能体、脑科学 |
| AI+人文社会学部 | 教育、经济金融、治理+法律 |
| 未来实验室 | 5-10年超前方向（科研特区） |

## 关键时间节点

- **2026年5月27日**：招募信息正式发布
- **2026年6月下旬**：拟定召开人才闭门交流会

## 资源承诺

- GPU集群充足供应、科研经费自主支配
- 国家级人工智能学院平台支撑
- 博士生及博士后优先配置
- 具有国际竞争力的优厚薪酬
- 北京户口、人才公寓、配偶子女随迁等生活保障

## 意义

此次招募反映了2026年中国AI人才争夺战的最新态势，[[教育科技人才一体化]]的体制创新和[[极基础极应用极交叉]]的研究理念代表了新型研发机构对传统学术体制的突破尝试。四大招聘方向的设置也映射了当前AI前沿的热点分布：从核心模型到具身智能、从[[ai-for-science]]到AI治理。
