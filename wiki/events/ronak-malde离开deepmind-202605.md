# Ronak Malde 离开 DeepMind

2026年5月，AI Coding 赛道核心工程师 [[ronak-malde]] 宣布离开 [[google-deepmind]]。值得注意的是，他不仅离开 DeepMind，还放弃了随 [[windsurf-google技术许可交易-202507|Windsurf-Google 交易]] 而来的并购激励金（acquisition money），以"More soon"暗示即将启动新创业项目。

## 背景
Ronak Malde 随 Windsurf 团队于 2025年7月加入 DeepMind，在期间参与了 [[antigravity]] 的发布并为 Gemini 3 作出贡献。

## 信号意义
- **人才回流创业**：核心 AI Coding 工程师放弃大厂确定性收益选择创业，预示赛道创新活力仍在创业侧
- **大厂吸引力有限**：即使 DeepMind 拥有顶级研究品味、巨大算力和 Google 级基础设施，仍无法留住最具创业冲动的核心人才
- **行业风向标**：Ronak Malde 的职业轨迹（Codeium → Windsurf → SWE-1 → DeepMind → 创业）几乎完美踩中 AI Coding 赛道主线，其下一步选择具有行业风向标意义
