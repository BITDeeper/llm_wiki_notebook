# Anthropic与SpaceX算力服务合同

2026年5月起，[[anthropic]]开始执行与[[spacex]]的大规模算力服务合同，是AI行业最大的基础设施交易之一。

## 合同细节

| 条款 | 内容 |
|------|------|
| 月付金额 | 12.5亿美元 |
| 合同期限 | 2026年5月至2029年5月 |
| 前两个月 | 因产能爬坡有折扣 |
| 合同期总收入 | 预计超400亿美元 |
| 终止条款 | 任何一方提前90天通知即可终止 |

## 算力规模

- 基础设施：[[colossus-2]]超算集群
- GPU数量：超22万块（NVIDIA GB200）
- 扩容计划：[[tom-brown]]确认6月将"疯狂扩容GB200算力"

## 战略影响

### 对SpaceX
- 仅此一单即可为SpaceX年增收近80%（对比2025年总收入186.7亿）
- 标志着[[ai-算力军火商模式]]的正式确立
- SpaceX明确表示"预计将签订更多类似的服务合同"

### 对Anthropic
- 获得大规模算力资源，缓解"算力饥渴"
- 但月付12.5亿的固定成本可能影响自身盈利能力和IPO估值
- 对SpaceX基础设施形成高度依赖
- 合同可90天通知终止，稳定性存疑
