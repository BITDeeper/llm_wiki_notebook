# Peekaboo v3 正式发布并一日三更

## 概述

2026年5月11日，[[peter-steinberger]] 正式发布 [[peekaboo]] v3，并在发布当日连续推出 v3.1.0、v3.1.1、v3.1.2 三个版本，被称为"一日三更"。这标志着 [[openclaw]] 从"会聊天"到"会干活"的关键跃迁。

## 背景

Peekaboo 早在2025年6月就已上线初版，但因当时模型视觉能力和 [[computer-use]] 能力尚未到位，v3.0.0-beta 3 后于年末停更。Peter 随后将精力转向 OpenClaw 本体的渠道、网关和调度开发。

2026年上半年，模型能力越过临界点，Peekaboo 的价值被重新激活。

## 时间线

| 日期 | 事件 |
|------|------|
| 2025年6月 | Peekaboo 初版上线 |
| 2025年末 | v3.0.0-beta 3 后停更 |
| ~2026年5月9日 | v3.0.0-beta 4 试水，v3.0.0 正式版发布 |
| 2026年5月11日 | 一日三更：v3.1.0→v3.1.1→v3.1.2 |

## 影响

- **补齐关键缺失**：OpenClaw 从多渠道消息网关进化为能在本机环境真正办事的系统
- **社区验证**：已有用户用 Peekaboo 驱动远程 iOS 模拟器，展示完整操作链
- **架构意义**：连接层（OpenClaw）+ 执行层（Peekaboo）合一，接近完整的 AI 助手形态
