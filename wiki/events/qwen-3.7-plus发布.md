# Qwen-3.7 Plus多模态旗舰模型发布

2026年6月3日，阿里发布Qwen-3.7 Plus（Qwen3.7-Plus），一款多模态交互式混合Agent模型。该模型将视觉感知、语言理解、代码生成、工具使用、GUI操作统一放入同一推理循环，标志着Qwen系列从纯语言模型→代码模型→多模态模型→多模态混合Agent的技术演进进入成熟阶段。

## 发布亮点

- **Hybrid-Agent系统** — 连续稳定运行11小时，自动完成英语词汇学习App全周期研发（10000+行代码，1000+次Agent调用）
- **macOS Stocks App复刻** — 智能体与原生应用交互理解UI后生成SwiftUI源码，10项功能验证全部通过
- **跨框架兼容** — 在 [[claude-code]]、[[openclaw]]、Qwen Code等不同Agent框架中均可稳定运行
- **preserve_thinking功能** — 多轮对话中保留每轮思考内容，优化Agent任务表现

## 行业背景

此次发布紧随2026年5月Agent工具密集发布期（Claude Code Agent View、商汤Skills等），属于AI行业从模型能力竞争转向Agent工程化落地的延续和深化。Qwen-3.7 Plus定位为通用Agent底座模型，而非绑定特定框架。

## 开放问题

截至发布时，Qwen-3.7 Plus的开放权重状态未明确，大量开发者呼吁继续像Qwen之前的模型一样开放权重、支持本地部署。
