# SpaceX 发布 C 语言大模型训练堆栈

2026 年 5 月，[[spacex]] 旗下 xAI 团队宣布使用 C 语言编写的全新大模型训练堆栈，抛弃了此前使用的 [[jax|JAX]] 框架。

## 事件经过

[[elon-musk|马斯克]] 本人在社交媒体上确认，[[grok-5]] 已经使用该新堆栈进行训练，并声称训练速度提升了一个数量级。他还表示下一步将用 C 语言重写推理部分的堆栈。

## 技术意义

- 标志着大模型训练从高级框架（JAX）回归底层语言（C）的趋势
- 体现了 AI 公司为追求极致性能而放弃框架便利性的工程取舍
- 与 [[colossus-2|Colossus]] 系列超算集群上的 GB300 硬件深度协同

## 招聘意图

马斯克明确表示发布此消息的目的是鼓励追求硬件卓越性能的人才加入 SpaceX。
