# Claude 双模记忆系统灰度测试

2026年5月，[[testingcatalog|TestingCatalog]] 爆料并经多方验证，[[anthropic|Anthropic]] 正在为 Claude 测试一套全新的「双模记忆系统」，标志着 Claude 记忆架构自上线以来最大规模的重构。

## 事件经过

- **2026年3月底**：Claude Code 51.2万行源码泄露，首次暴露 Conway 智能体平台的存在
- **2026年5月初**：Code with Claude 旧金山开发者大会上，Anthropic 公布 Dreams 功能
- **2026年5月25日**：TestingCatalog 爆料双模记忆系统，侧边栏灰度测试截图流出

## 核心内容

### 双模记忆

- **经典记忆**：沿用至今的滚动摘要模式
- **[[claude-memory-files|文件记忆]]**：全新的结构化文档记忆，按需检索而非全量灌入

用户可在两种模式间自由切换。

### Dreams 梦境机制

异步后台记忆整合，模拟 REM 睡眠，已在 Claude Code 以 Auto Dream 形式落地。

### Conway 智能体

7x24小时永不下线的 AI 智能体平台，以文件记忆和 Dreams 为底层基座。

## 战略意义

此次记忆系统重构是 Anthropic 在 AI 记忆竞争中的关键落子，与 OpenAI 的 Memory Sources 和 Gemini 的生态记忆形成三足鼎立格局。记忆被视为通往 ASI 的必要条件，是 AI 巨头竞争从模型能力转向记忆与持续运行的标志性事件。
