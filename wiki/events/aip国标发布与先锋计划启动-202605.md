# AIP国标发布与先锋计划启动（2026年5月）

## 概述

2026年5月，中国首个AI智能体互联国家标准——《人工智能 智能体互联》7项系列国家标准（[[智能体互联协议-aip|AIP]]）进入报批阶段，标志着AI治理从模型层延伸至智能体层。

## 关键时间线

- **2026年5月8日**：国家网信办、国家发展改革委、工业和信息化部联合发布《智能体规范应用与创新发展实施意见》，明确在19个典型应用场景推动智能体应用
- **2026年5月**：AIP 7项系列国家标准进入报批阶段，近日将正式公布
- **2026年5月12日**：[[aip应用验证先锋计划|AIP应用验证先锋计划]]正式启动

## 因果关系

```
标准编制（全国信标委）→ 标准报批 → 政策发布（三部委《实施意见》）→ 验证计划启动（先锋计划）
```

## 核心创新

1. **智能体身份码（AIC）**：基于国家OID体系的智能体"数字身份证"，实现身份确权与上链注册
2. **多中心化通信协议**：面向海量AI Agent互联的多自治域架构
3. **能力工具化接入**：兼容Skill/MCP的工具化接入套件，降低落地门槛

## 产业影响

- 若AIP成为强制国标，现有基于MCP/A2A的智能体生态可能面临协议迁移压力
- AIC身份码可能成为智能体接入国内市场的准入门槛
- 开源生态（AtomGit）能否吸引足够开发者参与，决定AIP的实际影响力

## 历史意义

这是中国AI治理从"模型监管"走向"智能体监管"的关键信号，也是"AI身份证"从概念到制度落地的第一步。体现了"先标准、后规模"的国家治理思路。
