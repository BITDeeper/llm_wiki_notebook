# xAI发布Grok Build

2026年5月15日，[[xai]] 发布首款 Coding Agent [[grok-build]]，标志着马斯克正式进入 AI 编程智能体赛道，AI 编程竞争从双寡头扩展为三强格局。

## 事件背景

- [[elon-musk|马斯克]] 此前以600亿美元收购 [[cursor]]，Cursor 团队融入 xAI
- xAI 正经历剧烈组织动荡：联创出走、持续离职潮、并入 [[spacex]]
- [[anthropic]] 的 [[claude-code]] 和 [[openai]] 的 Codex 已在 AI 编程赛道占据先发优势
- 新 Grok 模型正在 [[colossus-2]] 集群上训练中

## 发布细节

- **时间**：2026年5月15日凌晨/深夜发布，马斯克人在北京
- **产品**：[[grok-build]]，早期测试版
- **访问门槛**：SuperGrok Heavy 订阅（300美元/月，折扣期99美元/月）
- **核心特性**：并行子智能体、计划模式、工作流兼容、终端原生体验

## 影响与意义

- **竞争格局**：AI 编程赛道从 [[anthropic]]/[[openai]] 双寡头扩展为三强角逐
- **定价趋势**：300美元/月进一步推高 AI 编程工具定价，印证 [[ai-subscription-crisis]]
- **组织韧性**：在团队分崩离析的背景下仍推出重磅产品，展示 Cursor 团队换血后的执行力
- **生态策略**：支持从 Claude Code 无痛迁移，直接争夺现有用户
