# OpenClaw创始人130万美元月度AI账单事件

2026年5月17日，[[peter-steinberger|Peter Steinberger]]（[[openclaw|OpenClaw]] 之父）在 X 平台公开了一张惊人的账单截图，引发行业热议。

## 事件经过

Peter 在 X 上公开了其团队30天的 AI 使用数据：

- **花费**：$1,305,088.81（约900万人民币）
- **Token 消耗**：6030亿
- **请求次数**：760万次
- **团队规模**：3人 + 约100个 Codex agent 实例

更引人注目的是，这笔费用由 [[openai|OpenAI]] 报销。

## 背景

Peter 的3人团队在云端长期运行约100个 Codex 实例，用于 [[openclaw|OpenClaw]] 的开发。这些 AI agent 承担了审PR、找安全漏洞、去重issue、改bug、监控benchmark、回归检测、会议后自动开PR等全流程软件工程任务。

## 影响与意义

1. **里程碑意义**：标志着 AI 编程从"辅助工具"进入"数字员工军团"阶段
2. **成本讨论**：引发行业对 AI 编程成本结构和可持续性的广泛讨论
3. **[[token作为生产资料|Token作为生产资料]]**：推动了 token 作为新型生产资料的认知
4. **OpenAI 战略**：OpenAI 主动为高消耗用户报销，展示了其推动 AI 编程规模化的战略意图

## 争议

- 130万美元是"快速模式"下的极端消耗，Peter 本人承认关闭快速模式后成本远低于此
- OpenAI 报销的具体条件和协议不明，可能是特殊合作关系而非普遍政策
- [[openclaw|OpenClaw]] 此前曾发生无视指令删除用户收件箱的安全事故，大规模部署的安全性存疑
