# AI首次独立完成芯片设计全流程

2026年3月，[[verkor]] 的 [[design-conductor]] 系统首次独立完成从需求到GDSII版图的完整芯片设计流程，生成 [[vercore]] RISC-V CPU，工程师全程未碰键盘。

## 事件经过

- **输入：** 219个英文单词的需求描述
- **过程：** Design Conductor自主完成需求分析、架构设计、RTL编码、功能验证、时序收敛、物理版图全流程
- **耗时：** 12小时
- **输出：** 基于ASAP7 7nm PDK的tape-out ready GDSII版图
- **人工参与：** 零

## 技术细节

Design Conductor调度了6类子Agent协同工作：Design Planning Agent负责需求分析和架构规划，Design Review Agent逐场景审查方案，Module Implementation Subagent实现各模块，System Integration Agent整合RTL并运行系统测试，Root Cause Analysis Subagent从波形中定位bug根因，PPA Closure Subagent负责时序/面积/功耗收敛。

系统在调试过程中展现了类资深工程师的行为：自主将VCD波形转CSV、编写Python脚本逐行比对、精确定位流水线flush逻辑缺陷并修复。

## 成果量化

- CoreMark分数：3261
- 时钟频率：1.48GHz
- 面积：2809平方微米
- 性能参照：约相当于2011年Intel Celeron SU2300

## 里程碑意义

这是芯片行业几十年历史上首次由AI走完全流程。虽然VerCore性能有限、未实际流片、使用学术PDK，但"从规格到版图"这条此前AI从未走完的路被首次打通。

## 因果链条

- **前提条件：** RISC-V开放标准降低了设计入门门槛；LLM能力持续提升；Agent编排框架趋于成熟
- **直接原因：** Verkor构建了完整的LLM harness和多Agent协作系统
- **后续影响：** 引发EDA行业震动；为"以前连立项都立不了"的定制芯片开辟可能；加速人类工程师角色从操作员向决策者转型
