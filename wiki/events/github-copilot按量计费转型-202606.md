# GitHub Copilot 按量计费转型

2026年6月1日，[[github-copilot]]所有套餐全面转向按用量计费，标志着AI编程工具月费制的系统性瓦解。

## 背景

从2026年4月起，[[openai]]率先将Codex计费从按消息估算改为按Token用量对齐，4月23日扩展至所有企业方案。GitHub紧随其后官宣转型。

## 转型细节

旧的高级请求逻辑作废，换成AI额度，按输入Token、输出Token、缓存Token的实际消耗，对照每个模型的API费率结算。基础订阅价格未变，但额外用量、智能体任务、更贵的模型调用从此进入用量计费。

## 官方解释

GitHub表示：智能体崛起后，一次任务能连续跑几小时、改动整个代码库，重度用户和轻度用户的成本差可拉到几个数量级。GitHub一直在替重度任务用户买单，但这套模式已不可持续。

## 用户反应

- 开发者JBusu：月费从28.12美元涨至746.01美元（涨约26倍），决定退订。
- 另一用户：费用从50美元飙至3000美元（涨60倍）。
- 老用户反驳：极端账单是[[vibe-coding|vibe-coder]]的YOLO模式滥用所致。

## 行业意义

这是[[ai-subscription-crisis|订阅制危机]]的关键里程碑。继OpenAI之后，GitHub的转型意味着AI编程工具月费制的系统性终结，行业全面进入按量计费时代。
