# Grok Build发布

2026年5月，[[elon-musk|马斯克]]推出首款编码智能体 [[grok-build|Grok Build]]，标志着 [[xai|xAI]] 正式进入[[终端原生编程智能体]]赛道。

## 发布背景

- [[xai|xAI]] 解散后，外界质疑 Grok 前景
- 马斯克此前公开承认 xAI 在编程能力上落后于 [[anthropic|Anthropic]] 和 [[openai|OpenAI]]
- [[spacex|SpaceX]] 2026年4月获得收购 [[cursor|Cursor]] 的权利，为 Grok 提供真实开发者工作流数据

## 赛道影响

Grok Build 的加入使终端原生编程智能体赛道从三强（[[claude-code|Claude Code]]、[[codex|Codex CLI]]、[[gemini-antigravity|Gemini Antigravity]]）变为四强争霸。

## 当前局限

底层模型 grok-code-fast-1 仅有 256K token 上下文窗口，在竞品面前不足。待 [[grok-v9-medium|Grok V9-Medium]] 发布后有望改善。
