# 微软AI组织大重组

2025年10月至2026年5月，微软在CEO [[萨蒂亚-纳德拉]] 主导下进行了数十年来最大规模的组织重组，核心动作包括废除高级领导团队（SLT）、[[穆斯塔法-苏莱曼]] 转向[[超级智能]]、30年以上工龄老臣集体退场。

## 起因

### 三重压力
1. **投资人压力**：2025年Q1微软股价经历2008年金融危机以来最差季度，投资者要求看到数千亿美元AI投入的回报
2. **规模劣势**：纳德拉公开承认22.8万人体量在AI时代成为"巨大劣势"
3. **业务增速**：AI业务年化收入运行率超370亿美元（同比+123%），组织必须与之对齐

### 因果链
2025年Q1股价危机 → 投资人施压 → 纳德拉2025年10月起逐步推进重组 → 2026年2-4月密集人事调整

## 关键时间线

| 时间 | 事件 |
|------|------|
| 2025年10月 | 纳德拉交出商业业务CEO，开始研究创业公司 |
| 2025年11月 | 引入顾问重新算"AI时代的经济账" |
| 2025年末-2026年初 | 正式废除SLT |
| 2026年2月 | Phil Spencer交棒Asha Sharma；Hayete Gallot回归接管安全业务 |
| 2026年3月12日 | Rajesh Jha官宣7月1日退休 |
| 2026年3月17日 | 苏莱曼发内部信宣布转向超级智能，Copilot重组 |
| 2026年4月 | Arun Ulag升EVP |
| 2026年5月 | 报道公开，重组全貌曝光 |

## 核心变革

### SLT废除
运行数十年的高级领导团队被废除，替换为：
- **5人公司领导层**：纳德拉、Brad Smith、Amy Hood、Amy Coleman、Judson Althoff
- **约35人工程领导组**：扁平协作
- **Copilot三人领导组**：Charles Lamanna（平台）、Jacob Andreou（体验）、Ryan Roslansky（应用）

### 老臣退场
- Rajesh Jha（35年工龄）→ 退休
- Yusuf Mehdi（35年工龄）→ 下一财年离职
- Phil Spencer（38年工龄）→ 交棒Asha Sharma
- Charlie Bell → 从万人安全组织负责人变为零下属工程师

### 新人上位
- Jacob Andreou（入职一年升EVP）
- Hayete Gallot（从Google Cloud回归）
- Asha Sharma（跨业务接管Xbox）

## 同步事件

[[meta]] 同期启动约8000人裁员、7000人转岗AI，硅谷巨头集体进入"组织重设计"阶段。

## 影响

- 微软从应用层AI向前沿模型研究战略加码
- 硅谷巨头开始将[[组织结构即产品]]视为AI时代的核心命题
- 22.8万人巨舰能否以创业公司模式运行，成为行业最大实验
