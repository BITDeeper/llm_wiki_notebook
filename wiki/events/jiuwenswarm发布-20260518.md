# JiuwenSwarm 发布

2026年5月18日，华为支持的开源 AI Agent 平台社区 [[openjiuwen]] 正式发布并开源蜂群智能体框架 [[jiuwenswarm]]，标志着 [[coordination-engineering|协同工程]] 范式的首次完整开源工程交付。

## 背景

AI Agent 领域的工程范式经历了从 Prompt Engineering → Context Engineering → [[harness-engineering|Harness Engineering]] 的持续演进。当行业刚刚把视线从"更强的单 Agent"转向"更强的 Agent 团队"时，openJiuwen 率先将多 Agent 协同从理念做成了一整套可跑、可装、可共建、全栈开源的工程交付。

## 核心发布内容

- **范式主张**：正式提出 Coordination Engineering（协同工程）概念
- **全栈技术体系**：Agent Swarm + [[swarm-skills]] + Swarm Skills Hub + 自演进
- **人机协作模式**：[[hots-hits]]（HOTS 全局调度 / HITS 沉浸式参与）
- **评测成绩**：[[pinchbench]] 94.2%（SOTA），LOCOMO 记忆准确率 85%
- **双平台开源**：GitHub 和 AtomGit

## 影响

- 为多 Agent 协同从理念到工程落地树立了首个标杆
- 在 PinchBench 上超越 [[openclaw]] 近 3 个百分点，token 消耗降低 34.8%
- 通过 Swarm Skills Hub 建立团队技能的开放共享生态
- 明确了"群体智能"路线，与"超级个体"路线形成对照
