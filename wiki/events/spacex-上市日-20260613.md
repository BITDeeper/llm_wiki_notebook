# SpaceX上市日——史上最大IPO与首位万亿富豪诞生

## 事件概述

2026年6月13日，SpaceX（代码：SPCX）正式在纳斯达克挂牌上市，以750亿美元募资额创下全球IPO纪录，打破2019年沙特阿美294亿美元的纪录。54岁的埃隆·马斯克凭借持股对应的1.2万亿美元净资产，成为人类历史上首位万亿富豪。

## 上市数据

| 指标 | 数值 |
|------|------|
| 发行价 | 135美元/股 |
| 发行股数 | 5.556亿股 |
| 开盘价 | 174美元（+29%） |
| 发行市值 | 1.77万亿美元 |
| 开盘市值 | 2.28万亿美元 |
| 募资额 | 750亿美元（史上最大） |
| 认购资金 | 超2500亿美元 |
| 散户配额 | 30%（远超常规5%-10%） |

## 关键人物

- **马斯克**：持股42%，通过A/B股结构掌控85%投票权，净资产按开盘价达1.2万亿美元。母亲梅耶·马斯克现场见证。
- **奥本海默**：给出"跑赢大盘"评级，目标价190美元，剑指2.5万亿估值。
- **New Street Research**：目标价165美元，单独给xAI业务估值5750亿美元。

## 股权结构

- 马斯克持有约8.5亿股A类股（每股1票）和56亿股B类股（每股10票）
- 以42%股权掌控约85%绝对投票权
- B类股中预留10亿股火星殖民地对赌协议——仅当100万人最终居住在火星殖民地时才能兑现

## AI转型数据

SpaceX招股书揭示其本质已从航天公司转型为AI公司：

- **Q1资本支出**：101亿美元，其中77亿美元投向AI基础设施
- **Q1净亏损**：42.8亿美元（AI投资驱动）
- **Q1营收**：4.69亿美元（同比+15%）
- **2025全年营收**：186.7亿美元（+33%）
- **xAI并入**：2026年2月完成，是AI资本支出激增的根源

## 战略意义

1. **史上最大IPO**：打破沙特阿美纪录，标志AI时代资本市场的全新量级
2. **首位万亿富豪**：马斯克以54岁之龄创造历史，体现AI+航天融合的财富效应
3. **散户革命**：30%散户配额打破华尔街传统规则，吸引超2500亿美元认购
4. **绝对控制**：85%投票权+火星对赌协议确保SpaceX不受资本市场干预
5. **AI公司本质**：Q1 77亿美元AI投资揭示SpaceX是"披着航天外衣的超级AI公司"
6. **合并预期**：华尔街深度机构预测2027年SpaceX与特斯拉极大概率完成史诗级合并
