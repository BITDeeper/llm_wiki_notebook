# NSF秘密冻结四大名校科研经费事件

## 事件概述

2026年4月9日，美国国家科学基金会（[[nsf|NSF]]）奖项管理办公室（OAM）在系统后台秘密给哈佛大学、耶鲁大学、普林斯顿大学、杜克大学四所顶尖高校打上"Future Awards to Organization on Hold"（未来资助暂停）标签，全面冻结四校新增科研经费。四校未收到任何公开通知或正式解释。

## 关键时间线

- **2025年：** [[doge|DOGE]] 终止NSF 1752个项目（价值14亿美元），系统性削减开始
- **2026年1月20日：** 耶鲁VERENA项目后续资金被项目官员批准，但卡在OAM审批中
- **2026年4月9日：** OAM在系统后台正式给四校打上"暂停"标签
- **2026年5月28日：** Nature独家曝光此事件

## 核心数据

| 指标 | 数据 |
|------|------|
| 被卡项目数 | 33个 |
| 最长被卡天数 | 91天（截至5月28日） |
| 数理工程占比 | 85% |

| 四校2026财年至今NSF新项目 | 13个 |
| 哈佛/杜克4月9日后新项目 | 0 |

## 受影响项目

- 耶鲁大学量子研究中心支持项目
- 耶鲁VERENA全球大流行病预测项目（200万美元年度经费被卡超5个月，40人团队大量流失）
- 资助青年科学家的五年期经费
- 其他数学、物理、工程领域项目

## 事件性质

NSF内部知情人士指出，这种级别的"封杀令"极其罕见，通常仅用于即将倒闭或有严重审计丑闻的学校。四校被当作"暴雷学校"处置，但NSF不回应、不解释冻结原因。被卡项目均已通过独立科学家评审、NSF项目官员背书和机构领导层批准，属于纯粹的行政层面人为阻断。

## 深层影响

此事件是 [[美国联邦科研资助危机-2026]] 的标志性缩影，揭示了政治/行政干预对学术自由的系统性威胁。被冻结项目85%集中在数理工程领域，直接冲击 [[基础科研与asi竞争|ASI竞赛的地基]]，其长期后果将在2035年前后显现。
