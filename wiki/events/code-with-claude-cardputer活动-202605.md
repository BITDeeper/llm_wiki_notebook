# Code With Claude 活动 — Cardputer 运行 Claude Code

## 概述

2026 年 5 月中旬，[[anthropic]] 在其举办的「Code With Claude」开发者活动上，向参会者发放了 [[m5stack]] 出品的 [[cardputer]] 开发板。开发者在现场成功在该卡片大小的设备上运行完整的 [[claude-code]]，并快速构建了多个趣味应用。

## 活动亮点

- 开发者利用 Cardputer 的陀螺仪、键盘和屏幕，通过 Claude Code 快速开发了「魔法棒」模式切换、Tilt 迷宫游戏、Oregon Trail 文字冒险游戏等应用
- 开源项目 dakshaymehta/cardputer-claude-os 发布，提供完整部署方案
- 活动体现了 [[vibe-coding]] 在硬件创客场景的实践——通过自然语言描述让 AI 生成可运行程序

## 背景与影响

此次活动发生在 [[claude-code]] 订阅制争议和 [[agent-view]] 上线的同一时间段，是 Anthropic 在开发者关系层面的软性布局，通过硬件创意和社区话题制造对冲商业争议。

报道由 [[机器之心]] 发布，标题和叙事有意强调"小电脑跑大模型"的话题感，但技术实质为云端 API 调用的超薄客户端模式。
