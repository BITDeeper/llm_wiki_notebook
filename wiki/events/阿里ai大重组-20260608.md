# 阿里AI大重组

2026年6月8日，阿里巴巴宣布AI架构重大升级，合并通义大模型事业部与未来生活实验室，成立[[token-foundry|Token Foundry]]事业部，标志着阿里AI战略从分散走向统一的Token全栈控制。

## 事件经过

### 组织调整
- **Token Foundry成立**：合并通义大模型事业部（[[周靖人]]从零搭建）与未来生活实验室（[[郑波]]带队），由集团CEO[[吴泳铭]]亲自挂帅
- **周靖人升任首席科学家**：集团技术体系最高学术头衔，牵头成立AI未来研究院
- **郑波并入Token Foundry**：带领未来生活实验室整体并入

### 架构逻辑
- 三个月前成立[[ath事业群|ATH事业群]]（Alibaba Token Hub）搭Token枢纽
- Token Foundry在ATH枢纽内架设"铸造厂"
- 形成"[[平头哥]]造芯片→Token Foundry造模型→[[百炼maas|百炼MaaS]]做分发"的全栈拼图

## 产品版图

重组后Token Foundry手中的牌：
- [[qwen-3-7-max|Qwen 3.7 Max]]：覆盖文本和代码，Agent原生，1M token上下文
- [[happy-horse|Happy Horse]]：覆盖视频生成，全球榜首
- [[happy-oyster|Happy Oyster]]：覆盖世界模型，实时世界引擎
- [[平头哥]]芯片：已规模化量产

## 战略意义

此次重组标志着阿里正式加入[[token供应链控制权之争]]的正赛。通过将分散的AI力量统一到Token全生命周期控制框架下，阿里试图在英伟达（卖铲子）、OpenAI（卡模型层）、Anthropic（卡基础设施）的竞争格局中走出"全栈通吃"的差异化路线。

## 因果链

ATH搭枢纽（约2026年3月）→ Token Foundry在枢纽内架铸造厂（2026年6月8日）→ 芯片+模型+分发全栈拼图完成 → [[token供应链控制权之争]]进入正赛
