# 黄仁勋2026年北京Citywalk

## 概述

2026年5月中旬（约5月16-17日周末），[[英伟达]] CEO [[黄仁勋]] 在北京鼓楼-南锣鼓巷-什刹海区域进行半日 Citywalk，引发全城打卡热潮和商户快速营销响应。

## 路线

鼓楼 → 天泽祥鼓楼馒头 → 黄瓦增福财神庙 → 南锣鼓巷（尹三豆汁、蜜雪冰城、紫光园酸奶站、方砖厂69号炸酱面、三禾稻香村、拓意XCARTOYS） → 什刹海（一品昌后海民谣BAR） → 庆云楼饭庄 → 潮府林苑（深夜二场）

## 关键细节

- **尹三豆汁**：黄仁勋喝完豆汁紧皱眉头说"这是什么东西啊"，大娘亲手递豆汁称其"闻都没闻直接对嘴喝"
- **蜜雪冰城**：喝8元蜜桃四季春，成为最出圈画面，网友制作大量梗图
- **方砖厂炸酱面**：抱着碗在门口嗦面，门店连夜上线"皮衣战神同款"套餐
- **三禾稻香村**：精准识别正品门店，买枣花酥分给路人
- **拓意XCARTOYS**：给孙子买"冬储大白菜"款小汽车，该款网上卖爆
- **一品昌后海民谣BAR**：与老板杨哥连续两年见面（2025年7月首次），约定"以后每年来一次"，赠送写有双方名字的红包
- **庆云楼饭庄**：店员主动吆喝上去，喝了北冰洋

## 传播影响

- 各商户24小时内完成营销响应（更名套餐、贴照片签名、玩梗营销）
- [[量子位]] 记者线下复刻全程，发布 HTML 版和高德地图版 Citywalk 攻略
- 文章发布于 [[第四届中国AIGC产业峰会]]（5月20日）前两天，带有预热引流性质
- 形成"黄仁勋打卡 → 商户营销响应 → 媒体复刻攻略 → 读者跟随打卡"的完整传播链条
