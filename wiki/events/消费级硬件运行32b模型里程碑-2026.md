# 消费级硬件运行32B模型完成Agent任务里程碑

2026年5月，[[triattention]] 论文附录展示了一个标志性部署案例：[[qwen3-32b]]（AWQ INT4 [[量化]]）在单张 RTX 4090（24GB 显存）上完成 [[openclaw]] agent 任务——读取6份 markdown 文档并自动生成完整周报。

## 背景

一年前，"本地跑大模型"还是极客圈的行为艺术，跑个7B都要折腾半天。KV cache 膨胀是长上下文 agent 任务在消费级硬件上的核心瓶颈。

## 突破

- 不压缩 KV cache：显存直接爆掉，模型无法运行
- 开启 TriAttention：agent 顺利读完所有文档，生成完整报告
- 这证明了"一个完整的、有实际生产价值的 agent 任务，可以在消费级硬件上跑通"

## 意义

这一里程碑标志着"本地跑大模型"从极客行为艺术向工程现实的加速转变。结合 [[vllm]] 插件的一键集成和 [[mlx]] 生态的快速发展，KV cache 压缩正在从论文中的消融实验变成每个开发者都能触碰到的工程现实。
