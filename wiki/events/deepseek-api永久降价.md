# DeepSeek API永久降价

2026年5月23日（本周五），DeepSeek发布API降价通知，将限时优惠转为永久定价，价格降至原价1/4，标志着AI模型层价格战进入新阶段。

## 降价细节

- **幅度**：原价砍掉3/4，永久定价为原价的1/4
- **国际对比**：价格数字比[[gpt-5.5]]和Claude Opus 4.7更小，且单位从美元变为人民币
- **实际效果**：国际同级别模型价格的不到1/10

## 技术基础

[[deepseek-v4-pro|DeepSeek V4 Pro]]通过以下技术创新实现极低推理成本：
- 独创的注意力架构
- 并行策略优化
- 显存量化

## 市场反应

- 全球开发者一片欢呼，高频调用API写代码的成本大幅下降
- 部分网友担忧低价策略的长期可持续性
- 博主Yuchen Jin猜测降价背后可能是推理优化突破或华为芯片成本优势

## 战略背景

降价发生在DeepSeek百亿美元融资临近收官的第二天，可能以资金安全感为底气。与[[deepseek-harness|Harness]]团队招募同步推进，构成"降价吸引用户+融资支撑研发+产品化占领场景"的系统性战略。

## 行业影响

- 直接回应[[tokenmaxxing]]和[[ai-subscription-crisis]]的行业痛点
- 对[[ai创业收入双寡头格局]]构成冲击，以极致低价打破双寡头定价权
- 可能引发全球AI模型层价格战新一轮升级
