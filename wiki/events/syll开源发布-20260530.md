# Syll 多模态全交互智能体框架开源发布

2026年5月30日，[[清华大学智能视觉实验室]]（鲁继文教授团队）与 [[极佳视界]] 联合开源了多模态全交互智能体框架 [[syll]]，以 public alpha 形式在 GitHub 发布。

## 事件背景

此发布处于2026年5月桌面智能体赛道活跃期。此前已有 [[马维斯]]（腾讯 OS Agent）、[[qoderwork]]（阿里 AI Native 办公平台）等产品发布，但 Syll 走的是开源桌面智能体研究框架路线，强调[[多模态全交互]]统一与[[示教即技能]]机制。

## 核心发布内容

- 统一 GUI、CLI、MCP/API 的多模态执行回路
- 示教即技能机制，用户手动操作一遍即可生成可复用技能
- 多模态审计体系，全程透明可查
- 本地模块化架构，保障隐私与可扩展性

## 意义

- 为桌面智能体研究提供了开源技术底座
- 提出了区别于纯 API/CLI 和纯 GUI 的第三条路线：统一多模态执行
- 示教即技能机制大幅降低了桌面自动化的使用门槛
- 与 [[第四届中国aigc产业峰会]] 提出的"系统智能"方向相呼应
