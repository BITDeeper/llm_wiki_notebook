# Codex移动端发布

2026年5月14日，OpenAI将[[codex]]集成进ChatGPT手机App，面向iOS和Android全量开放，标志着AI编程从工位延伸到移动场景。

## 事件背景

- [[codex]]周活已超过400万开发者，处理的任务从代码补全升级为长达数小时乃至数天的长时任务
- [[anthropic]]早在2026年2月已发布[[claude-code]] Remote Control功能，在远程控制场景领先约3个月
- 5月13日，[[sam-altman]]宣布切换到Codex的公司可获得两个月免费使用，攻势直指Anthropic

## 核心内容

- Codex进入ChatGPT手机App预览版，覆盖所有套餐（含免费版和Go用户）
- 手机端定位为控制面板：查看活跃线程、审查输出、批准命令、切换模型
- 底层采用[[安全中继层]]，主机可跨设备被访问但不暴露在公网
- 同步发布企业能力：Remote SSH正式GA、Hooks进入GA、程序化访问token、HIPAA合规支持

## 战略意义

- 标志着AI编程进入"异步监督"时代，开发者核心输入从代码变为判断
- 是OpenAI与Claude Code Remote Control的正面对决
- AI编程战场从开发者的工位烧到了口袋
- Codex产品线从桌面App→跨系统→后台运行→Chrome扩展→移动端，完成全场景覆盖

## 风险与争议

- 移动端审批将关键决策搬进碎片化注意力场景
- "5倍产能"等说法缺乏实证支撑
- 开发者不被工位绑住，却被智能体的进度条绑住
