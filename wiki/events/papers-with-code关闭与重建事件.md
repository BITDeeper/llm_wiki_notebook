# Papers with Code 关闭与重建事件

Papers with Code 关闭与重建事件是 2025年7月至 2026年5月期间，机器学习社区关键基础设施从突然断裂到 AI 驱动重建的完整事件链。

## 事件时间线

### 关闭（2025年7月）
- 原 [[papers-with-code]] 毫无预警关闭，网站显示"502 Bad Gateway"。
- GitHub 上的求助帖无人回应，社区一片混乱。
- 平台积累了超 9300 个基准测试、5600 个数据集、5000 多个任务的数据一夜之间无法访问。
- 创始人 [[ross-taylor]] 解释：团队被 [[meta-ai]] 收购后转型大模型研究，维护时间减少，大量成员已离开。

### 过渡（2025年7月后）
- [[hugging-face]] 联合创始人 [[julien-chaumond]] 推出"Trending Papers"页面。
- 原 paperswithcode.com 域名跳转至 Hugging Face 论文页面。
- 社区普遍反馈：缺乏 [[sota排行榜]]，从"研究基础设施"降级为"热榜"，无法接受。

### 重建（2026年5月）
- [[hugging-face]] 开源团队成员 [[niels-rogge]] 在 paperswithcode.co 从零重建。
- 核心变革：采用 [[ai智能体驱动论文解析]] 技术，不再依赖人工维护。
- [[sota排行榜]] 全面回归，新增多项功能。
- 上线正赶上 [[cvpr-2026]] 期间，可一网打尽所有 CVPR 论文。

## 因果链

Meta 团队转型大模型研究 + 人员流失 → 维护能力下降 → 突然关闭 → 社区基础设施真空 → Hugging Face 过渡方案不足（缺乏 SOTA 排行榜）→ 从零重建（AI 智能体驱动）→ 解决实时性与可持续性问题。

## 深层意义

该事件体现了两个重要趋势：
1. **大公司维护开源工具的可持续性问题：** 收购承诺与内部战略转型的矛盾。
2. **科研基础设施的范式转移：** 从人工维护向 AI 智能体驱动的自动化运营转变。
