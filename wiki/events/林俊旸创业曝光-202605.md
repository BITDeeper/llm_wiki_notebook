# 林俊旸创业曝光

2026年5月13日，外媒 The Information 引述两位直接知情人士的消息，曝光前阿里通义千问技术负责人 [[林俊旸]] 正在筹建独立AI实验室，目标估值20亿美元，正在筹集数亿美元融资。

## 事件经过

1. **前兆**：林俊旸在2026年3月初自宣离开阿里Qwen团队后，其小红书账号清空内容并更改昵称、头像和简介
2. **曝光**：The Information 于5月13日发布报道，引述两位直接知情人士消息
3. **投资接洽**：[[高榕创投]] 与 [[sequoia-capital|红杉资本]] 已就投资展开接洽
4. **团队组建**：林俊旸已招募数名字节跳动、腾讯和海外背景的成员

## 背景与因果

- **远因**：2024年8月 [[周畅]] 离职 → 林俊旸晋升至P9 → 独立带队取得成绩 → 行业声望积累
- **近因**：2026年3月林俊旸离开阿里，发表《从推理式思考到智能体式思考》长文暗示方向
- **人才流动链条**：周畅离职 → 林俊旸晋升 → 独立成绩 → 声望积累 → 离职创业获得高估值认可

## 行业意义

此事件可能标志着中国AI开源生态核心人才的首次大规模独立创业，具有行业标志性意义。20亿美元估值在中国AI初创中"几乎闻所未闻"，体现了 [[中国ai初创高估值现象]] 和顶级人才的市场溢价。

## 不确定性

- 融资讨论仍在进行中，最终估值可能变化
- 实验室名称和具体研究方向尚未公开
- 官方尚未正式确认
