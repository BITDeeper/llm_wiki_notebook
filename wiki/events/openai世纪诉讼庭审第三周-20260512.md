# OpenAI世纪诉讼庭审第三周：奥特曼首次出庭作证

2026年5月12日，[[sam-altman]] 在马斯克诉 OpenAI 世纪诉讼案中首次出庭作证，在加州法庭上进行了长达数小时的证词陈述。此次庭审发生在 [[elon-musk]] 跨洋出差期间，奥特曼借此机会对马斯克的核心叙事进行了全面反击。

## 核心证词

### AGI控制权世袭
最具爆炸性的指控：奥特曼称马斯克曾在早期内部讨论中提出，未来 OpenAI 的控制权可以"传给自己的孩子"。这一说法将诉讼叙事从"公司治理纠纷"重构为"权力世袭"问题，直接动摇了马斯克长期塑造的"开放AI、全人类未来"人设。

### 马斯克早年支持营利结构
奥特曼当庭否认"背叛初心"指控，称马斯克在特斯拉总部第二次会面时，两人共同审阅了 OpenAI 创建营利性公司的条款清单，马斯克对此表示赞赏。这一证词直接反驳了马斯克诉讼的核心论点。

### 管理文化冲突
奥特曼将 OpenAI 与马斯克决裂的根本原因归结为文化冲突：马斯克的[[电锯管理学]]（要求对研究人员排名并施加高压）对 OpenAI 的学术研究文化造成了"长期巨大损害"。

### 其他关键细节
- OpenAI 累计募集 1750 亿美元用于模型训练和算力建设
- 马斯克离开后，内部曾担心其采取报复行动
- [[shivon-zilis]] 在私人通信中建议奥特曼如何处理与马斯克的关系
- 奥特曼谈到被罢免后曾考虑转投微软，但最终决定回来："我愿意跑回一栋着火的大楼里抢救它"

## 前后关联

庭审前两天（约5月10日），[[ilya-sutskever]] 出庭时表示"一点也不后悔"参与罢免奥特曼，暗示 OpenAI 内部信任危机至今未完全消解。

本次庭审的证词——特别是马斯克早年支持营利结构的证据——很可能直接影响了6天后（5月18日）陪审团在90分钟内全票驳回马斯克诉讼的结果。详见 [[openai世纪诉讼判决-20260518]]。

## 叙事重构

与会人员观察到，奥特曼在庭审中谈到"技术理想"的部分越来越少，更多从"组织治理"和"现实资源"角度阐述 OpenAI 事务，标志着其角色从"AGI理想主义者"向"大型科技组织CEO"的进一步转变。
