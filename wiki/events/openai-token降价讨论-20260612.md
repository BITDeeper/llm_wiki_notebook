# OpenAI Token降价讨论

2026年6月12日，据《华尔街日报》报道，[[openai|OpenAI]]正在内部讨论大幅削减Token定价，意在抢在[[anthropic|Anthropic]]预期中的类似行动之前占据先机。

## 事件背景

降价讨论发生在多重压力交汇的时刻：

1. **竞争压力**：[[fable-5|Fable 5]]在核心编码基准上对[[gpt-5.5|GPT-5.5]]形成碾压（SWE-bench Pro差距22个百分点，FrontierCode Diamond差距约5倍）
2. **IPO压力**：OpenAI本周刚[[openai-s1秘密提交-20260609|秘密提交IPO申请]]，需要维持增长曲线
3. **客户压力**：[[uber|Uber]]等企业AI预算超支，ROI质疑声四起
4. **亏损压力**：两家公司均因巨额算力投入承受数十亿美元亏损

## 关键表态

CEO [[sam-altman|Sam Altman]]公开承认成本已成为"一个巨大的问题"，并表示"我们会有很多方式帮助用户以更少的支出获得更多价值"。

## 事件影响

- 标志着AI行业从[[tokenmaxxing]]消耗竞赛正式转向[[token价格战|价格战]]
- 在IPO窗口前大幅降价是高风险赌注，将进一步压缩利润率
- 暴露了AI双寡头产品高度可替代的结构性风险
- 价格战的本质是以低价锁定规模→支撑IPO估值→融资反哺模型训练→实现[[递归式自我改进|RSI]]的融资闭环
