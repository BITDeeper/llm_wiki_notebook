# Anthropic x Forum Ventures 黑客松

2025年9月12日，由 [[anthropic|Anthropic]] 和 [[forum-ventures|Forum Ventures]] 在 [[cerebral-valley|Cerebral Valley]] 合办的黑客松，主题为"智能体，助力从0到1创业"。

## 比赛规则

参赛者需在一天内使用多个 AI 智能体，将通常要花几周的创业工作压缩到几小时完成，包括找客户、验证需求、做原型、跑销售等。比赛指定使用 Anthropic 的 [[claude-code|Claude Code]] 现场搭建。

## 冠军

[[affaan-mustafa|Affaan Mustafa]] 和 [[david-rodriguez|David Rodriguez]] 最终夺冠。他们开发了 AI 客户调研平台 [[zenith|Zenith]]（原名 PMF Probe），通过强化学习支持的合成用户测试帮助创业者验证早期创意。

## 奖品

冠军获得价值约1.5万美元的平台使用额度（非现金）。

## 影响

Affaan 赛后决定将打磨了10个月的 Claude Code 工作系统以 MIT 协议开源，取名 [[everything-claude-code-ecc|ECC]]，随后在 GitHub 上爆发式增长至15万星。这次黑客松因此成为 Claude Code 生态系统从工具向平台演进的重要里程碑。
