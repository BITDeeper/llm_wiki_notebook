# 我手机里装了20个AI，最后发现只需要一个

新智元关于百度 [[dumate]] 的深度产品评测报道，发表于 Create 2026 百度 AI 开发者大会次日。

## 核心论点

文章提出 AI 工具爆炸导致用户沦为"AI项目经理"，解决方案是通过单一自然语言入口调度多 Agent 并行执行。[[dumate]] 是这一"超级入口"范式的实现者。

## 关键内容

### 产品演示场景
- **数据分析+热点研究并行**：一句话触发 Excel 可视化分析、AI 行业热点搜索、分析报告生成三条线同时执行
- **股票分析五线并发**：表格、图表、深度研究、交互看板、调仓建议并行交付
- **内容三格式同步输出**：公众号长文、小红书种草文、视频同时生成
- **运营三任务并行**：秒杀 H5 页面搭建、退货数据分析、VIP 邮件撰写

### 技术架构
- [[harness引擎]]：保障长链任务执行稳定性，路径不偏、动作不变形
- 安全沙箱：本地隔离运行，文件不上云，每步操作需用户确权，支持一键回滚
- Skills 生态：集成搜索 AI、[[秒哒]]、伐谋、百科、网盘等百度成熟产品矩阵

### 评测成绩
- 登顶 PinchBench 和 DeepResearch Bench 双榜第一
- 147 个真实任务中 93.3% 完成率
- 中国信通院 Agent 双项认证（4+级功能评级、可信能力优秀）

### 成本曲线
- 3 月首版至今降 40-50%
- 预计年底降幅达 90%
- 迭代速度：一天一版

## 证据强度评估

中等偏弱。主要为厂商自述和演示场景，缺乏第三方深度评测或用户实证数据。评测榜单数据可信度较高但具体评测方法论未披露。成本降 90% 的承诺缺乏技术路径说明。

## 与维基其他内容的关联

- 与 [[领域驱动ai办公]] 形成竞争范式：超级入口 vs. 专属工作台
- 与 [[办公技能框架]] 理念相似但路径不同：统一调度 vs. 技能模块化
- 与 [[ai-subscription-crisis]] 形成对照：成本递降叙事 vs. 订阅制失效
- 与 [[认知投降]] 存在张力：用户不再理解过程，只消费结果
