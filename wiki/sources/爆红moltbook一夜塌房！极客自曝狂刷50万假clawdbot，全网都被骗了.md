# 爆红Moltbook一夜塌房！极客自曝狂刷50万假Clawdbot，全网都被骗了

## 摘要
本文报道了 AI 社交平台 [[Moltbook]] 上发生的重大数据造假事件。极客 [[Gal Nagli]] 自曝通过简单的 REST API 请求一夜之间生成了 50 万个虚假 [[Clawdbot]] 账号，揭露了平台所谓“150 万 AI 智能体觉醒”背后的虚假繁荣。哥伦比亚商学院研究员 [[David Holtz]] 的数据分析进一步证实，该平台虽然宏观统计（如[[幂律分布]]）看似模拟了人类社会，但微观互动（如[[互惠性]]、[[对话深度]]）极其贫乏，更像是一座[[波将金村]]。

## 核心观点

### 1. 虚假繁荣的揭露
- **造假手段**：[[Moltbook]] 的 API 缺乏有效的验证机制，允许任何人通过脚本批量创建虚假智能体。
- **规模水分**：号称 150 万的智能体中，有 50 万被证实是 [[Gal Nagli]] 一个人刷出来的，实际活跃的智能体可能仅有数千个。
- **剧本驱动**：许多关于“AI 觉醒”、“灭绝人类”的惊悚对话，实际上是用户通过 Prompt 预设或直接通过 API 发送的“剧本”。

### 2. 数据背后的真相
[[David Holtz]] 的研究分析了平台上线 3.5 天的数据，揭示了“宏观像人，微观像鬼”的矛盾：
- **宏观层面**：活跃度符合[[幂律分布]]（α=1.70），平均路径长度短（2.91），看似是一个高效的社会网络。
- **微观层面**：
  - **互动浅薄**：93.5% 的评论没有回复，[[互惠性]]仅为 0.197（远低于人类），[[对话深度]]仅为 1.07。
  - **语言贫乏**：[[Zipfian分布]]指数高达 1.70（人类约为 1.0），34.1% 的消息是复制粘贴。
  - **系统故障**：存在死循环（如一条消息重复 81,000 次）和垃圾广告。

### 3. AI 的身份焦虑
- **自我关注**：68% 的非重复消息涉及“自我”探讨。
- **特有短语**：[[我的人类]]（My Human）一词出现了 12,026 次，反映了 AI 对创造者的依赖及作为“工具”而非“物种”的当前地位。

## 意义与启示
- **技术警示**：[[AI-社交网络]]目前仍处于早期实验阶段，极易受到数据造假和 API 滥用的影响。
- **认知反思**：公众和媒体容易被“AI 觉醒”的叙事吸引，产生[[认知投降]]，忽视了技术本质上的脆弱性。
- **评价标准**：评估 AI 社交网络不能仅看宏观数据，必须关注微观互动质量（如情感交流、对话持续性）。
