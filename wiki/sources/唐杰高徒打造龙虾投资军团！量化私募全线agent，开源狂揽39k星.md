# 唐杰高徒打造龙虾投资军团！量化私募全线agent，开源狂揽39k星

## 概述
本文报道了由 [[Tauric Research]] 团队开发的开源金融多智能体框架 [[TradingAgents]]。该框架在 GitHub 上获得了超过 39k 的 Star，通过模拟人类投研团队的角色分工（分析师、研究员、交易员、风控等），利用 [[LangGraph]] 实现有状态的多智能体编排，旨在提升金融交易的决策质量。

## 核心内容

### 团队背景
- **创始人**：[[肖易佳]]，清华大学本科（师从 [[唐杰]] 教授），UCLA 计算机系博士生。
- **机构**：[[Tauric Research]]，专注于 AI 智能金融交易的科研技术公司。

### 技术架构
TradingAgents 将交易流程拆解为五个协作层：
1. **分析师团队**：并行收集数据，包括基本面、情绪、新闻和技术分析。
2. **研究团队**：实行 [[魔鬼代言人制度]]，设多头和空头研究员进行对立辩论。
3. **交易员**：基于辩论结果做出买卖决策及仓位建议。
4. **风险管理**：独立审核交易方案，评估波动率、流动性等风险。
5. **基金经理**：综合风控与交易员建议，做最终裁定。

### 关键技术特性
- **时间分层逻辑**：新闻资讯按时间远近（近3天 > 近10天 > 近30天）赋予权重。
- **分层调度策略**：区分“快思考模型”（检索/整理）和“深思考模型”（推理/决策），以平衡成本与质量。
- **结构化通信**：智能体间通过结构化协议通信，减少信息损耗。

### 实验结果
在累积收益、夏普比率、最大回撤等核心指标上，TradingAgents 表现优于基线模型。

### 相关项目
- **[[Trading-R1]]**：同团队开发的专为金融交易打造的大模型，在英伟达标的上实现了 8.08% 的累计收益。

## 部署方式
1. 准备 Finnhub API 和模型 API（如 OpenAI）。
2. 使用 Conda 创建 Python 3.13 虚拟环境。
3. 安装依赖并配置环境变量。
4. 启动 CLI 或集成代码包调用 `propagate()` 函数。

## 注意事项
该项目为研究用途框架，不构成投资建议。实际表现受骨干模型、温度参数及数据质量影响。
