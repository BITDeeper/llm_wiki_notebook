# Claude Code之父：「品味」不是人类护城河；当工程师不再写代码，招聘看什么？

## 来源信息
- **媒体**：机器之心
- **发布日期**：2026年6月7日
- **原始视频**：https://www.youtube.com/watch?v=RkQQ7WEor7w&t=1s

## 核心内容

本文是对 [[boris-chemy|Boris Cherny]]（Anthropic 技术成员、[[claude-code|Claude Code]] 核心建设者）的深度访谈记录。访谈围绕 Claude Code 的起源、AI 编程对组织形态的重塑、以及人类在 AI 时代的独特性展开。

## 关键论点

### 品味不是人类护城河
Boris 以自身经历论证，编程品味和产品品味正在被模型快速学会。他曾坚持函数式编程风格（禁止使用 class），但模型生成的面向对象代码在业务结果上同样出色。他预测3-6个月后，模型在产品品味上的表现将从20%好想法提升到大部分好想法。详见 [[taste-is-not-a-moat]]。

### 通才黄金时代
AI 降低了跨领域能力的迁移成本，传统分工（工程师/PM/设计师）正在瓦解。Claude Code 团队中工程师每天都在做用户沟通、交互设计、数据分析等非传统工作。详见 [[age-of-the-generalist]]。

### Coding 作为 AI 安全实验场
Anthropic 重视 Coding 的根本原因不是商业价值，而是编程拥有清晰反馈机制和海量训练数据，是观察模型与真实世界交互的理想实验环境。详见 [[coding-as-ai-safety-sandbox]]。

### 少招人多发 Token
Boris 给创业者的核心建议：每个项目故意少放人、多给 Token，迫使团队自动化，产生复利效应。前期成本高但持续成本极低。详见 [[hire-less-spend-more-tokens]]。

### 价值观作为人类最后的独特性
模型最终能学会品味和判断，但"如何做一个好的存在、做对的事情而非仅仅把事情做对"这一价值观层面是人类最后的独特领域。

## 关键数据
- Boris 已半年未亲手写代码，2025年11月卸载 IDE
- 同时运行5-10个 Claude 实例（日常），数百个实例（分析反馈时）
- Anthropic 每位工程师代码产出增长约三倍（Boris 称实际远超此数）
- 新工程师上手时间从数周缩短到两天
- Claude Code 早期仅能完成10-20%的工作
