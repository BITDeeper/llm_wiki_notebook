# 2U服务器碾压超算集群！1000美元电费算出314万亿位圆周率

## 摘要
本文报道了 [[storagereview]] 使用单台 [[dell-poweredge-r7725]] 服务器，耗时 4 个月，仅花费约 1000 美元电费，成功将圆周率计算至 314 万亿位，打破世界纪录的案例。文章指出，此次成功的核心不在于单纯的 CPU 算力堆叠，而在于 [[存储密度与I/O瓶颈]] 的突破性架构设计，为 [[ai-for-science]] 等长周期计算任务提供了新的工程范式。

## 核心事件
- **记录打破**：2025年7月启动，历时4个月，计算至 314 万亿位。
- **能效表现**：总耗电 4,304 kWh，电费约 1000 美元。每万亿位仅耗电 13.70 kWh，是能效最高的超大规模计算之一。
- **稳定性**：实现了“零停机”运行，这在长达数月的超算任务中极为罕见。

## 关键技术因素

### 硬件架构
- **计算平台**：Dell PowerEdge R7725（2U 服务器），搭载双路 AMD Epyc 192 核处理器（共 384 核），1.5TB DDR5 内存。
- **存储核心**：40 块 [[micron-6550-ion-ssd]]（单块 61.44TB），组成 2.5PB 存储阵列。
- **连接优化**：利用第 17 代 Dell 服务器的存储背板，SSD 直接通过 PCIe 通道连接 CPU（无 PCIe 交换机瓶颈），每块 SSD 分配 2-4 条通道，实现高达 280 GB/s 的读写速度。

### 系统优化
- **散热方案**：将标准风冷替换为 [[液冷散热]]（CoolIT AHx10 方案），使 CPU 在 4 个月内维持高频稳定运行，平均系统功耗保持在 1600W。
- **操作系统**：从 Windows Server 切换至 Ubuntu 24.04.2，获得了更好的 I/O 调度性能。
- **资源调度**：为后台系统保留 4 个 CPU 核心，确保主计算业务的 380 线程全力冲刺。

## 对比与启示

### 对比云集群方案
- **Google Cloud (2022)**：计算 100 万亿位，依赖庞大的云集群。
- **Linus Media Group (2025)**：计算 300 万亿位，使用 2PB 闪存和 Weka 共享存储集群。
- **StorageReview (2025)**：计算 314 万亿位，使用单机集成方案。

### 行业启示
文章强调，对于气候建模、基因组学、AI 大模型训练等需要长时间运行、海量 I/O 的任务，[[单机集成方案]]（高 I/O 密度、高能效、高可靠）可能比昂贵的云集群更具优势。这挑战了“超算必须依赖大规模集群”的传统观念，指出了 [[存储密度与I/O瓶颈]] 才是此类任务的关键瓶颈。
