# 龙虾之父参与的首个OpenAI项目：@开源贡献者，ChatGPT token免费送

## 概述
本文报道了 OpenAI 推出的 "Codex for Open Source" 计划，旨在通过向开源项目维护者免费提供 API 积分、ChatGPT Pro 访问权限及安全服务，来笼络开源开发者社区。文章重点提及了新加盟 OpenAI 的 [[Peter Steinberger]]（被称为“龙虾之父”，即 [[openclaw]] 的开发者）在该项目中的积极推动作用。

## 核心内容

### 项目权益
OpenAI 针对开源贡献者提供的具体支持包括：
- **API 积分**：用于调用模型接口。
- **ChatGPT Pro 免费使用权**：为期 6 个月。
- **Codex Security 服务**：用于代码安全审查。

### 申请门槛
申请条件相对灵活，不仅限于高 Star 数的项目：
- 面向开源项目的核心维护者。
- 面向被广泛使用的公开项目的运营者。
- 即使不符合标准，只要在生态中发挥重要作用，OpenAI 也鼓励申请并说明理由。

### 关键人物动态
- [[Peter Steinberger]] 在 X（推特）上积极宣传该项目，并亲自回答开发者疑问。
- 他戏称自己在 OpenAI 的头衔为 "OpenAI Troublemaker"（捣蛋鬼）。
- 关于工作平衡，他表示现在有两份占据 200% 精力的工作（指 OpenAI 工作与 [[openclaw]] 维护），暗示其个人精力已被完全占据。

## 意义与影响
这一举措反映了 AI 巨头在 [[开发者关系]] 和 [[开源生态激励]] 方面的激烈竞争。OpenAI 试图通过资源倾斜来巩固其在开发者社区中的地位，对抗竞争对手（如 [[Anthropic]]）的影响力扩张。
