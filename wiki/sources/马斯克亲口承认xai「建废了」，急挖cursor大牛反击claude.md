# 马斯克亲口承认xAI「建废了」，急挖Cursor大牛反击Claude

## 摘要
本文详细报道了 xAI 在获得特斯拉和 SpaceX 巨额投资后不久，创始人埃隆·马斯克承认公司架构存在根本性错误并宣布“推倒重建”的事件。文章揭示了由此引发的创始团队大规模离职（12位联创中9位离开，包括全部5位华人联创）、大规模裁员以及战略重心的转移。特别记录了马斯克急挖前 Cursor 核心高管 Jason Ginsberg 和 Andrew Milich 以加强编程能力，意图反击 Anthropic Claude 和 OpenAI 的竞争态势。

## 核心要点

### 1. 承认构建错误与重组
- **根本性错误**：马斯克亲口承认 xAI “从一开始构建时，便并不正确”，不得不“从底层开始重建”。
- **时间点争议**：这一表态发生在特斯拉投资 20 亿美元及 SpaceX 以高估值收购 xAI 之后不久，引发了关于投资决策透明度的质疑。
- **四条战线**：重组后的 xAI 划分为四个核心团队：Grok 聊天/语音、编程模型、Imagine 多媒体生成、Macrohard 企业软件。

### 2. 人才大洗牌
- **创始团队离场**：12 位联合创始人中已有 9 位离职，包括 Igor Babuschkin、Yuhuai (Tony) Wu、Greg Yang 等知名研究员，5 位华人联创全部离开。
- **高管动荡**：前 CFO Mike Liberatore 仅任职 102 天便离职加入 OpenAI，透露经历了“每周工作超过 120 小时”的高压环境。
- **引入工程派**：前 Cursor 产品工程负责人 Jason Ginsberg 和 Andrew Milich 入职，直接向马斯克汇报，标志着从研究导向向工程落地的转变。

### 3. 战略转向：死磕编程
- **对标 Claude**：马斯克明确表示要确保在编程方面全面超越竞争对手，承认 Grok 目前落后于 Anthropic 和 OpenAI。
- **挖角 Cursor**：引入年化营收 20 亿美元的 AI 编程工具 Cursor 的核心高管，旨在搭建通往 AI 编程奇点的基础设施。
- **商业压力**：面对 Claude Code 年收入超 25 亿美元的成功案例，xAI 急需在编程这一高变现垂直场景取得突破。

### 4. 管理文化与挑战
- **分身困境**：马斯克同时领导特斯拉、SpaceX、X、xAI 等多家巨头，导致认知负荷过高，被质疑失去专注力。
- **高压文化**：极致的执行力要求（每周 120 小时工作制）被认为是导致人才流失的直接推手。
- **监管压力**：图像生成功能引发的深伪争议及系统提示被篡改等安全事故，加剧了公司的内外部压力。
