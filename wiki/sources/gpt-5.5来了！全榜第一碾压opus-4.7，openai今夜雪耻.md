# GPT-5.5来了！全榜第一碾压Opus 4.7，OpenAI今夜雪耻

## 概述
本文报道了 OpenAI 于 2026 年 4 月 24 日发布的最新一代旗舰模型 [[GPT-5.5]]。文章详细介绍了 GPT-5.5 在编程、推理、数学及智能体任务上对 [[Claude Opus 4.7]] 的全面超越，重点阐述了其作为“Agent 时代的原生大脑”的定位，以及 [[OpenAI]] 内部通过 [[Codex]] 工具实现的“Agent 化办公”新范式。

## 核心要点

### 1. 性能表现：全榜第一
- **编程领域**：在 [[Terminal-Bench 2.0]]（全链路 Agent 工程实力评测）中得分 82.7%，大幅领先 Claude Opus 4.7 的 69.4%。
- **数学与科研**：在 [[FrontierMath Tier 4]]（陶哲轩策划的最难数学题库）中得分 35.4%，显著超越 Opus 4.7 的 22.9%。
- **争议与质疑**：在 [[SWE-Bench Pro]] 上，GPT-5.5 得分 58.6%，略低于 Opus 4.7 的 64.3%。OpenAI 研究员指出 Opus 4.7 可能存在过拟合（记忆）迹象，并质疑该基准已无法衡量顶尖编程能力。

### 2. Agent 化办公：全新的计算机工作方式
- **定位升级**：OpenAI 将 GPT-5.5 定义为“原生大脑”，强调其不仅是语言模型，更是能够自主规划任务、调用工具、在浏览器和本地软件间切换的通用 Agent。
- **内部应用**：OpenAI 内部超过 85% 的员工每周跨部门使用 Codex。案例包括财务部门审查 2.4 万份税表、公关部门建立演讲评分系统等。
- **端到端能力**：Codex 接入 GPT-5.5 后，支持从实现、重构、调试到测试验证的“端到端”编程任务，并能直接操作电脑（点击、打字、跨工具流转）。

### 3. 科研突破
- **数学证明**：GPT-5.5 协助发现了一个关于 [[拉姆齐数]] 的新证明，并在 [[Lean]] 语言中得到了形式化验证。
- **生物信息学**：在 [[BixBench]]（基于真实生物信息学的评测）中得分 80.5%，排名第一。

### 4. 定价策略
- **价格翻倍**：GPT-5.5 API 价格为输入 $5/百万 Token，输出 $30/百万 Token，是 GPT-5.4 的两倍。
- **Token 效率**：OpenAI 解释称涨价基于 Token 效率的提升（完成任务使用更少 Token），但实际账单成本可能仍上涨 40%。
