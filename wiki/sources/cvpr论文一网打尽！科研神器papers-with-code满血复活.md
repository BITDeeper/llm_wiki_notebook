# CVPR论文一网打尽！科研神器Papers with Code满血复活

量子位报道，记录了科研工具 Papers with Code 从 Meta 关闭到 Hugging Face 从零重建的完整历程。

## 核心内容

- **原版关闭：** 2025年7月，由 Meta AI 维护的 Papers with Code 毫无预警关闭，显示"502 Bad Gateway"。平台积累了超 9300 个基准测试、5600 个数据集、5000 多个任务的数据。
- **关闭原因：** 创始人 [[ross-taylor]] 称团队被 Meta 收购后转型大模型研究，维护时间减少，大量成员已离开 Meta。
- **过渡方案不足：** [[hugging-face]] 联合创始人 [[julien-chaumond]] 推出"Trending Papers"页面，但缺乏核心的 [[sota排行榜]] 功能，社区不买账。
- **从零重建：** 2026年5月，[[hugging-face]] 开源团队成员 [[niels-rogge]] 推出 paperswithcode.co，完全独立重建，由 [[ai智能体驱动论文解析]] 技术驱动。
- **功能迭代：** 上线一周内完成多项更新，包括多指标展示、论文继承关系识别、约 3000 个模型评估结果添加。
- **CVPR 契机：** 新平台上线正赶上 [[cvpr-2026]] 期间，可一网打尽所有 CVPR 论文。

## 关键论点

Papers with Code 作为机器学习社区的关键基础设施，在经历 Meta 关闭后，由 Hugging Face 通过 AI 智能体技术成功从零重建并实现功能升级，标志着科研基础设施从人工维护向 AI 驱动的范式转移。
