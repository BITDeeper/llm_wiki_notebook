# AI三巨头72小时狂扫桌面Agent！OpenAI三合一，谷歌秘测Mac版

## 摘要
本文详细记录了 OpenAI、Anthropic 和 Google 在 72 小时内围绕 [[桌面智能体]] 展开的激烈竞争。OpenAI 通过内部重组将 ChatGPT、Codex 和 Atlas 整合为“三合一超级App”，并收购 Python 工具链公司 [[Astral]]；谷歌秘密测试 Gemini Mac 桌面应用，并斥资 24 亿美元引入 [[Antigravity]] 技术攻坚开发者生态；Anthropic 则凭借 [[Claude Cowork]]、[[Claude Dispatch]] 和 [[Claude Code Channels]] 的“三连击”迅速占领桌面。文章指出，AI 战场已从浏览器和聊天框全面转向操作系统底层的系统级接管，[[浏览器智能体]] 赛道（如 [[Project Mariner]]）正面临衰退。

## 核心要点

### OpenAI：战略收缩与聚焦
- **三合一重组**：由应用业务负责人 [[Fidji Simo]] 发起，将 ChatGPT（对话）、Codex（代码）和 [[Atlas]]（AI 浏览器）强制整合为一个桌面超级应用，旨在解决产品碎片化问题。
- **收购 Astral**：闪电收购 Python 工具链公司 Astral（拥有 `uv` 等工具），旨在强化 Codex 接管整个开发工作流的能力。
- **目标**：集中火力对抗 [[Anthropic]]，全面押注 Agent，让 AI 能够自主接手文档、代码和表格处理。

### Google：双管齐下
- **Antigravity 技术**：通过 24 亿美元收购团队获得技术授权，接入 Google AI Studio，支持从自然语言直接生成全栈应用并部署。
- **Gemini Mac 秘密测试**：代号“Janus”的桌面应用首次为 Mac 提供原生 AI 客户端，具备 [[Desktop Intelligence]] 能力，可调用其他 Mac 程序并理解屏幕上下文。
- **生态优势**：利用 Gemini 模型支持 Apple Intelligence 和 Siri 的潜在机会，切入苹果生态。

### Anthropic：高频迭代占领桌面
- **企业市场领先**：在企业首次采购 AI 工具的市场份额中占比超过 73%，超越 OpenAI。
- **三连击产品**：
    1. **Claude Cowork**（1月）：赋予 Claude 读写本地文件夹的能力，使其成为常驻后台的数字员工。
    2. **Claude Dispatch**（3月17日）：允许用户通过移动端远程唤醒桌面端 Claude 执行任务。
    3. **Claude Code Channels**：集成 Discord 和 Telegram，允许开发者直接派发任务和接收通知。

### 行业趋势：从浏览器到桌面
- **浏览器 Agent 衰退**：谷歌的 [[Project Mariner]] 团队被悄然重组，Perplexity Comet 和 ChatGPT Agent 周活数据惨淡，表明仅限于网页操作的 Agent 无法满足用户需求。
- **系统级接管**：巨头们的共识是让 AI 深度介入操作系统底层，读取屏幕、操控文件系统，成为真正的“数字员工”。

## 关键数据
- OpenAI Codex 本月周活突破 200 万，年初以来增长三倍。
- Anthropic 在企业首次采购 AI 工具中占比 73%。
- 谷歌为 Antigravity 技术背后的团队支付了 24 亿美元。
- OpenAI 收购的 Astral 公司仅 23 人，Promptfoo 被 25% 的财富 500 强企业使用。
