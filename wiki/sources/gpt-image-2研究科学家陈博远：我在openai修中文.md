# GPT Image 2研究科学家陈博远：我在OpenAI修中文

## 概述
本文是 [[OpenAI]] 研究科学家 [[陈博远]] 关于 [[GPT Image 2]] 模型发布的幕后技术分享。文章详细介绍了该模型在中文渲染、视觉推理及细节还原方面的突破，并披露了发布会展示案例（如米粒刻字、视觉证明题）的设计思路。

## 核心内容

### 模型代号与测试
- 模型在发布前使用了内部代号 **[[duct-tape]]**（布基胶带）在 [[LMArena]] 进行双盲测试。
- 该代号灵感源自莫瑞吉奥·卡泰兰的著名艺术品《喜剧演员》（用胶带把香蕉贴在墙上）。
- 测试结果显示模型性能“断崖领先”于代号为“小香蕉”的第二名。

### 技术突破与案例
1.  **中文渲染修复**：
    - [[陈博远]] 亲自修复了模型的中文渲染问题。
    - 在生成的海报右下角通过极小的中文字体测试模型的细节极限。
2.  **画中画生成**：
    - 展示了模型一次性生成包含多层嵌套视觉内容（照片中的漫画书中的漫画）的能力，无需后期拼接。
3.  **极致细节**：
    - **米粒刻字**：在 4K 图像的一颗米粒上成功刻字，展示了极高的分辨率控制力。
4.  **视觉推理**：
    - 设计了 **[[视觉证明]]** 测试题：要求模型用几何图形（而非代数计算）证明“从1开始的奇数之和是一个平方数”。
    - 证明了模型具备结合几何图形与逻辑推理的能力。

### 发布会花絮
- [[陈博远]] 与 [[山姆·奥特曼]] 同台主持发布会。
- 官网 Blog 的所有展示图片均为模型生成，无文本排版。
- 直播中展示了 Thinking mode 自动生成二维码并嵌入图片的功能。

## 意义
该分享揭示了 [[GPT Image 2]] 不仅是图像生成工具，更具备了逻辑推理和极高精度的文字还原能力，标志着多模态模型在视觉理解和生成方面的新高度。
