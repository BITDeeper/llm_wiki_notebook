# 封不住！Claude Code爆改Python版加冕最快10万星，且clone且珍惜

## 摘要
本文报道了 [[Claude Code]] 源码泄露事件后的连锁反应。在 [[Anthropic]] 动用 [[DMCA]] 法律武器进行全网封杀的背景下，哥伦比亚大学学生 [[Sigrid Jin]] 通过 [[AI 洗代码]]（将 TypeScript 源码重写为 Python）创建了 [[Claw Code]]。该项目成功规避了版权检测，成为 GitHub 历史上增长最快的开源项目之一（2小时5万星，24小时10万星）。文章还提及 [[马斯克]] 领导的 [[xAI]] 在此次事件中提供算力支持，可能加速了 Grok Code 的开发。

## 核心事件
- **源码泄露**：[[Chaofan Shou]] 发现 Claude Code 51.2 万行源码被意外公开。
- **法律反击**：Anthropic 通过 DMCA 要求 GitHub 下架相关仓库，甚至误伤了自己的 Fork 项目。
- **金蝉脱壳**：[[Sigrid Jin]] 利用 [[oh-my-codex]] 工作流和 OpenAI Codex，在一夜之间将代码逻辑从 TypeScript 转写为 Python，成功规避了版权检测。
- **社区狂欢**：[[Claw Code]] 迅速获得超过 11 万 Stars 和 10 万 Forks，Discord 群组涌入 5000 人。

## 关键观点
- **法律 vs. 技术**：版权法保护的是代码表达而非逻辑思想，跨语言重写成为强有力的规避手段。
- **安全承诺的讽刺**：以“安全”为卖点的 Anthropic 发生了人为失误导致的重大泄露，且后续处理被指“Vibe Coding”（随意自动化）。
- **xAI 的角色**：马斯克团队提供 Grok 积分支持开发，被指可能利用泄露代码加速自身产品迭代。

## 相关实体
- [[Sigrid Jin]]：Claw Code 作者，哥伦比亚大学在读学生。
- [[Claw Code]]：Claude Code 的 Python 重写版，此次事件的幸存者。
- [[Anthropic]]：Claude Code 开发者，采取了激进的法律行动。
- [[Chaofan Shou]]：源码泄露的发现者。
- [[xAI]]：提供算力支持，潜在受益者。
