# 多轮Agent蒸馏终于不翻车！港中文x通义新方法成功率暴涨18点，训练还快32%

## 概述
本文报道了香港中文大学与阿里通义事业群合作的一项研究，该研究针对多轮 Agent 蒸馏中的训练崩溃问题，提出了一种名为 [[tcod]]（Temporal Curriculum On-Policy Distillation，时序课程在线策略蒸馏）的新方法。该方法通过引入课程学习机制，成功解决了 [[轨迹级kl不稳定性]] 导致的模型失效问题，在多个基准测试中实现了显著性能提升，并大幅缩短了训练时间。

## 核心发现

### 问题根源：轨迹级 KL 不稳定性
传统的 [[在线策略蒸馏]]（OPD）在单轮任务（如数学推理）中表现优异，但在 [[alfworld]]、[[webshop]] 等多轮交互任务中往往遭遇灾难性失败。
- **现象**：随着交互轮次增加，学生模型与教师模型之间的 KL 散度持续飙升，导致教师提供的监督信号失效。
- **后果**：小模型（如 [[qwen3-1-7b]]）成功率几乎归零（0.17%），大模型训练也极不稳定。

### 解决方案：TCOD
[[tcod]] 的核心思想是利用 [[课程学习]]，让学生模型从短轨迹开始，逐步扩展到长轨迹，从而规避误差累积。
- **F2B (Front-to-Back)**：前向到后向。学生先负责轨迹的前几步，逐步接管后续步骤。
- **B2F (Back-to-Front)**：后向到前向。教师先引导至接近终点，学生负责最后几步，再逐渐向前延伸。

## 实验结果

### 性能提升
- **起死回生**：[[qwen3-1-7b]] 模型在 Vanilla OPD 下成功率仅为 0.17%，使用 [[tcod]] 后提升至 18% 以上。
- **大幅增益**：[[qwen2-5-3b]] 模型在 ALFWorld 上的成功率从 60.45% 提升至 79.19%（提升 18.74 个百分点）。
- **超越教师**：在教师模型极难完成的 Hard 测试集上，[[qwen2-5-7b]] 学生模型（20.66%）超越了教师模型（6.61%）。

### 效率与鲁棒性
- **训练加速**：总训练时间减少了约 32%，因为早期的短轨迹减少了数据收集和计算开销。
- **超参鲁棒**：课程扩展速率在 {2,4,6} 之间波动时，性能波动不超过 2%，几乎不需要调参。

## 意义
[[tcod]] 展示了“循序渐进”的学习模式在长程 Agent 训练中的重要性，不仅解决了稳定性难题，还提升了模型的泛化能力。未来，这类时序课程机制可能成为训练长程 Agent 的标配组件。
