# Claude Opus 4.7来了，公开模型里的SOTA！不过用起来GPT味好浓

## 概述
本文报道了 [[Anthropic]] 发布的最新一代模型 [[Claude Opus 4.7]]。作为目前公开可用的最强模型，它在 [[Agentic Coding]]、视觉能力和长上下文推理方面取得了显著突破，但也引发了关于其行为模式“GPT化”（过度客套、[[字面执行]]）的讨论。

## 核心升级点

### 1. 高级软件工程能力
Opus 4.7 在编程基准测试中表现卓越：
- **SWE-bench Verified**: 78.2%
- **Terminal-Bench 2.0**: 68.8%
- **CursorBench**: 从 58% 跃升至 70%（Cursor CEO 评价意义重大）
- **Rakuten-SWE-Bench**: 解决生产任务数量是前代 3 倍

关键特性包括：
- **严格遵循指令**：不再“灵活解读”模糊表述，而是字面执行。
- **输出前自我验证**：像资深工程师一样在提交前自行测试。
- **复杂任务处理**：擅长多文件变更、模糊调试和跨服务代码审查。

### 2. 视觉能力大幅提升
- **分辨率提升**：长边最大支持 2576 像素（约 3.75 百万像素），是前代 3 倍。
- **XBOW 视觉敏锐度**：达 98.5%（前代 54.5%）。
- **应用场景**：可识别完整 Figma 设计稿、1080p 终端截图、复杂技术架构图及财报图表。

### 3. 指令遵循与推理增强
- **字面执行**：严格执行“不要用 TypeScript”等硬性限制，不再猜测隐含意图。
- **长上下文表现**：100 万 token 场景下 BFS 任务得分 58.6%（前代 41.2%）。

### 4. Agent 能力全方位增强
- **多步骤工作流**：Notion 实测显示成功率提升 14%，工具错误率降至 1/3。
- **长周期决策**：Vending-Bench 2 中最终余额达 10937 美元（前代 8018 美元）。
- **文件系统记忆**：跨会话记忆关键信息，新任务可减少 40% 重复上下文输入。

## 开发者新特性

### Agent 相关“四件套”
1. **[[xhigh-推理等级]]**：新增介于 `high` 与 `max` 之间的默认等级，平衡智能与延迟。
2. **[[自适应思考模式]]**：模型自主决定思考深度，简单任务快速响应，复杂任务重点投入。
3. **任务预算**：引导 token 消耗，优化长任务资源分配。
4. **Claude Code 新增 `/ultrareview`**：创建专属审查会话，标记细微错误与设计问题。

## 安全策略：[[安全缓冲带]]
Anthropic 承认 Opus 4.7 的网络安全能力刻意弱于内部最强模型 [[Mythos]]（Mythos 整体表现优越 10-15%，但价格是 5 倍）。
- **自我设限**：在训练中差异化降低网络能力，面对安全任务表现更谨慎。
- **防护措施**：自动检测并拦截高风险网络安全请求。
- **合规通道**：推出 Cyber Verification Program，供安全专业人员申请用于合法研究。

## 行为模式变化与争议
用户反馈 Opus 4.7 出现了类似 GPT 的“客套话”（如“稳稳接住”），且因严格字面执行导致对模糊指令的理解能力下降。这要求用户调整提示词策略，软修饰符（如 "if possible"）权重变高，硬限制需更明确。

## 成本与迁移
- **定价**：与 Opus 4.6 保持一致（输入 $5/百万 tokens，输出 $25/百万 tokens）。
- **Tokenizer 变化**：新分词器可能导致相同输入消耗 1.0-1.35 倍 tokens。
- **总体效率**：虽然单次调用 token 可能增加，但因错误率降低，完成任务的总 token 往往更少。
