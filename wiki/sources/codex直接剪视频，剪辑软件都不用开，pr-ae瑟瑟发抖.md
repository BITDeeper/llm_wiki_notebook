# Codex直接剪视频，剪辑软件都不用开，PR AE瑟瑟发抖

量子位发布的实测报道，记录了 OpenAI 旗下 [[codex]] 编程代理接入 [[heygen]] AI视频生成平台插件后的全流程视频制作体验。

## 核心内容

报道展示了用户通过一句自然语言提示词，在 Codex 对话框内完成数字人生成、口播视频制作、字幕添加、自动剪辑、导出等视频制作全流程。整个过程无需在多个软件间切换，体现了 [[vibe-coding]] 理念从编程领域向视频制作领域的延伸。

## 技术要点

- Codex 调用 HeyGen 本质上是用自然语言或代码指挥 AI，生成 HTML+CSS+JS 形式的视频文件
- 具备可编程、可迭代、精确控制局部细节的优势
- Codex 能自主检查、调试、调配素材、解决故障，体现了 [[agentic-engineering]] 的自主性特征
- 与 2026 年 1 月 Remotion+Claude Code 的"视频即代码"方案相比，门槛大幅降低

## 局限性

- 标题暗示"PR AE瑟瑟发抖"存在夸大倾向
- 实测仅覆盖口播讲解类视频，未验证特效、调色、多轨剪辑等复杂场景
- 未涉及实际成本问题
