# Win版Claude Cowork杀疯了！140元雇个全职AI员工，全网首测真香

## 概述
本文是对昆仑天工推出的 [[天工Skywork桌面版]] 的深度评测报告。文章将其定位为 Windows 生态对标 [[Claude Cowork]] 的“神级辅助”，重点测试了其在文件整理、代码编写、办公自动化等方面的能力，并详细解析了其“双核驱动”（Claude + Gemini）的技术架构。

## 核心观点

### 1. Windows 生态的补完与超越
Skywork 不仅是 [[Claude Cowork]] 的 Windows 复刻版，更通过“原生支持+双模型+智能路由”实现了降维打击。
- **实测案例**：
  - **文件分类**：自动识别动物图片类别，创建子文件夹并归档，最后生成统计报告。
  - **批量提取**：现场编写 Python 脚本，将 Word 文档视为压缩包，批量提取 130 张图片并重命名。
  - **报告生成**：根据链接自动搜索并生成关于 OpenAI Codex 桌面版的中文报告。
  - **课件制作**：根据素材自动生成包含时间线、公式推导和练习题的《万有引力定律》网页与 PPT。

### 2. 双核驱动架构的优势
单一模型存在短板（Claude 视觉弱，Gemini 逻辑弱），双模型 [[智能路由]] 能实现 1+1>2。
- **Claude 系列**：负责长文本逻辑推理、代码编写和细腻文本生成。
- **Gemini 系列**：负责原生多模态（视频、图片、音频）理解与生成。
- **Auto Router 模式**：系统根据任务类型自动切换模型，无需用户手动选择。

### 3. 安全与隐私
采用 [[本地虚拟机隔离]] 技术，所有文件操作在安全沙盒中完成，防止误删文件，并保证核心数据不跑路。

### 4. 技能体系
内置 100+ 精选 Skills，覆盖 Office 三件套、网页制作、视觉创作等高频场景。支持 [[技能组合]]，例如自动组合“文档读取+数据分析+PPT生成”来完成复杂汇报任务。

## 商业模式
- **入门版**：$19.99（约 140 元人民币）。
- **Plus 会员**：$49.99，提供“无限”额度。

## 行业意义
文章认为 Skywork 代表了 [[任务执行范式]] 的转移：从“人操作工具”到“人指挥 Agent”。未来的竞争力在于授权、制定任务和验收的能力。
