# 刚刚，中国AI闯入全球编程前二！前面只剩Claude

新智元报道，Code Arena 最新放榜，[[qwen3-7-max]] 以1541分冲进全球第四，成为前五中唯一的非 Claude 模型。这是中国 AI 模型在编程赛道上首次达到这一高度。

## 核心内容

- **榜单成绩：** [[qwen3-7-max]] 在 [[code-arena]] 以1541分排名全球第四，超越 [[gpt-5.5]] 和 Gemini 3.5 Flash，仅次于 Claude Opus 4.7 和 Opus 4.6
- **厂商排名：** 阿里成为全球编程模型竞技场上唯一杀进前列的中国厂商，仅次于 [[anthropic]]，位列第二
- **第三方验证：** Atomic Chat 对比测试中，Qwen3.7-Max 以 $1.32 token 成本超越 Opus 4.7，性能提升56%
- **实测案例：** 3D赛车游戏生成中，Qwen3.7-Max 首轮即基本可玩，是唯一实现开始界面和音效的模型
- **长程能力：** 35小时连续运行、1158次工具调用、10倍几何平均加速、零上下文退化
- **技术核心：** [[环境扩展训练]] 和 [[动态累积生存博弈]] 两大训练方法升级
