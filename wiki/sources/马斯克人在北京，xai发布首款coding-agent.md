# 马斯克人在北京，xAI发布首款Coding Agent

量子位报道，2026年5月15日，马斯克旗下 [[xai]] 发布首款 Coding Agent [[grok-build]]，直接对标 [[claude-code]]。产品定位为专业软件工程和复杂编程任务设计，在终端原生运行。

## 核心内容

- **产品发布**：[[grok-build]] 为早期测试版，面向 SuperGrok Heavy 订阅用户开放
- **核心特性**：并行子智能体（Subagents）、计划模式（Plan Mode）、兼容现有工作流（AGENTS.md/Skills/MCP Servers 一键导入）、diff 可视化变更、终端内图像视频生成
- **战略背景**：马斯克此前600亿美元收购 [[cursor]]，Cursor 团队已融入 xAI 换血
- **组织动荡**：xAI 联创出走、持续离职潮、并入 [[spacex]]、logo 焕新
- **定价**：SuperGrok Heavy 300美元/月，前6个月折扣价99美元/月
- **基础设施**：新 Grok 模型正在 [[colossus-2]] 集群上训练中

## 关联

- 印证 [[ai-subscription-crisis]] 趋势（300美元/月高端定价）
- 关联 [[1-n-agent调度]] 和 [[多agent协作架构]]（Subagents 并行架构）
- AI编程赛道从双寡头（[[anthropic]]/[[openai]]）扩展为三强角逐
