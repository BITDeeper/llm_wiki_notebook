# 准确回答视频细节！11B模型挑战视频理解「证据级」任务，开源可商用

## 概述
本文报道了由复旦大学邱锡鹏教授领衔的 OpenMOSS 团队联合模思智能（MOSI）开源的多模态视觉理解模型 [[moss-vl]]。该模型拥有 11B 参数，专注于解决视频理解中的“证据级”任务，即不仅要求模型概括视频内容，还要求其准确回答可被验证的细节、时间、过程和空间关系。

## 核心主张
当前视频理解模型在概括性任务上表现尚可，但在需要精确证据的细节任务上普遍失效。[[moss-vl]] 通过特定的架构设计（如 [[cross-attention]]、[[绝对时间戳编码]] 和 [[xrope]]），在相对较小的参数规模下实现了精细的时空推理能力。

## 关键能力展示
文章通过六大场景展示了 [[moss-vl]] 的 [[证据级视频理解]] 能力：
1.  **瞬时细节捕捉**：准确读取一闪而过的车牌后四位（4425）。
2.  **跨模态语义对齐**：结合对话内容（而非外观）判断杯子尺寸。
3.  **重复事件计数与时间定位**：统计动作次数（5次）并给出精确时间戳。
4.  **长段滚动文本读取**：完整转写《星球大战》滚动字幕。
5.  **过程理解**：将烹饪视频拆解为步骤并定位时间段。
6.  **运动方向与空间推理**：判断镜头运动方向（向前推进）和物体相对方位（前右）。

## 技术创新
-   **[[cross-attention]]**：按需读取视觉信息，避免长视频处理被视觉 token 数量拖垮。
-   **[[绝对时间戳编码]]**：为视频帧引入真实时间信息，作为定位锚点。
-   **[[xrope]]**：统一位置编码方案，同时建模时间、空间和文本查询维度。

## 对比与评测
在与 [[qwen3-vl]] 的对比中，[[moss-vl]] 在上述证据级任务上表现更优。模型采用 Apache 2.0 协议开源，支持学术研究与商业应用。
