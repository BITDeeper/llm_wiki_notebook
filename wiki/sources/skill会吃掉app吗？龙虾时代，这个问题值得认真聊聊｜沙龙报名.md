# Skill会吃掉APP吗？龙虾时代，这个问题值得认真聊聊｜沙龙报名

## 摘要
本文是量子位于 2026 年 3 月发起的一场 AI 沙龙招募文案。文章提出了在“龙虾”掀起的 Agent 浪潮下，传统 APP 是否会被 [[Skill]]（能力单元）取代的核心议题。沙龙邀请了 [[小卡健康]]、[[WPS AI]]、[[印象笔记]]、[[元空AI]] 及 [[TTC]] 创始人等一线从业者，共同探讨产品形态从“面向人的界面”向“面向 Agent 的调用”转型的机遇与挑战。

## 核心观点

### APP 的多余性
在 Agent 时代，传统 APP 的独立入口和图形界面（GUI）可能变得多余。用户不再需要打开一个个 APP，而是通过 Agent 直接调用所需功能。

### Skill 的崛起
[[Skill]] 被定义为“一段可被调用的能力单元”。它具有以下特征：
- **嵌入性**：嵌在 Agent 的工作流中。
- **按需触发**：无需常驻后台。
- **无界面**：无需 UI，甚至无需下载安装。

### 技术实现：MCP
文中提到 [[MCP]]（Model Context Protocol）调用，暗示这是实现 Skill 连接与解构 APP 的关键技术标准。

## 关键议题
沙龙旨在探讨以下开放问题：
1. **转型机遇**：对于正把自己变成 Skill 的产品，这是新的增长点还是被大模型厂商“降维”收割？
2. **逻辑重构**：如果 Skill 成为新的软件分发单元，产品逻辑将如何重构？
3. **资产报废**：那些花了一两年打磨的精美 APP 界面，是否会被一段后台的 MCP 调用彻底取代？
4. **设计对象转移**：未来的产品是给 Agent 用还是给人用？产品经理该如何重新理解“做产品”？
