# 谷歌全新Gemini Omni首曝，视频版「香蕉」来了！教授黑板推公式全对

新智元2026年5月12日发布的报道，披露谷歌即将发布的原生多模态视频生成模型 [[gemini-omni]] 的泄露信息。

## 核心内容

- **Gemini Omni 泄露**：2026年5月11日左右，Gemini 移动端 App 截图和 API 模型 ID 流出，揭示谷歌即将推出全模态视频生成模型。
- **技术突破**：教授在黑板上推导三角恒等式的 demo 展示了 [[视频文本一致性]] 的重大突破——公式正确、推导连贯、笔迹自然，仅用一句提示词生成。
- **实时编辑能力**：支持一键去水印、物体替换（光影自动适配）、风格化输出（动漫风格达到专业动画师水平）。
- **Sora 对比**：与已停服的 [[sora]] 形成鲜明对比，效果差距"好几个量级"。
- **全线模型泄露**：Gemini 3 Flash、3.1 全系列（Pro、Flash Image、Lite、TTS）及 Lyria 3 Pro 高保真音频模型一同被推送到生产环境 API。

## 关键数据

- Gemini Omni 生成视频：10秒时长，1280×720 分辨率
- Sora 停服数据：日推理成本 100万–1500万美元；峰值约100万活跃用户，停服前跌破50万；30天留存率 < 8%；生命周期应用内收入约210万美元
