# 全球首个自主科研Agent挑战赛！零人工干预冲击CNS成果SOTA，科研变天？

## 摘要
本文报道了由上海科学智能研究院（上智院）和复旦大学主办的第四届世界科学智能大赛之“AI4S智能体CNS挑战赛”。这是全球首个要求参赛智能体在**零人工干预**条件下，独立冲击 CNS（Cell, Nature, Science）级科研成果 SOTA 的赛事。文章详细介绍了赛事背景、四项具体挑战任务（药物筛选、分子设计、蛋白质动态、神经算子）以及评审委员会阵容，探讨了科研范式从“人力主导”向“人机协同”转变的趋势。

## 核心观点
- **范式跃迁**：科研正从传统的“人力主导、AI辅助”转向“人机协同、Agent自主执行”。科学家将回归“品味”和“源头探索”，而繁琐的执行工作由 Agent 承担。
- **零干预闭环**：挑战赛设定了极高门槛，Agent 必须独立完成文献阅读、瓶颈诊断、代码演进、实验验证全流程。
- **拉平起跑线**：复旦大学校长金力指出，AI 作为“超级科研合伙人”可以弥补年轻人在经验和算力上的劣势，使“异想天开”的创新想法得以验证。

## 关键实体
- **主办方**：[[上海科学智能研究院]]、[[复旦大学]]。
- **技术平台**：[[大圣-科研智能体]]（由上智院、复旦、无限光年共建）。
- **评审委员会**：[[金力]]、[[龚新高]]、[[漆远]]、[[雷震]]、[[马剑鹏]]、[[郁金泰]]、[[吴力波]]等院士及专家。

## 四大赛道任务
1.  **DrugCLIP 高通量虚拟筛选优化**：基于 *Science* 发表的 DrugCLIP 技术，要求 Agent 自动化完成数据准备到结果汇报的全流程，解决全基因组药物筛选的算力瓶颈。
2.  **靶向分子设计与逆合成规划闭环**：利用深度生成模型和强化学习，自动化完成“分子生成-性质筛选-逆合成路线规划”，加速新药研发。
3.  **蛋白质构象系综生成**：参考 BioEmu (*Science*, 2025) 和 STARLING (*Nature*, 2026)，要求 Agent 模拟科学家思维完成全科研生命周期闭环，解决蛋白质动态结构模拟难题。
4.  **神经算子 PDE 智能体**：基于 FNO、DeepONet 等基线，要求 Agent 自主完成“理解-改进-验证-复现”闭环，解决复杂物理系统建模中的长时稳定性与效率问题。

## 科研闭环的四个阶段
挑战赛核心在于检验智能体的完整科研闭环能力：
1.  **文献解析与逻辑解构**：深度阅读顶刊论文及代码，理清数学公式与算法逻辑。
2.  **瓶颈诊断与假设提出**：分析日志或数据，识别痛点并提出优化假设。
3.  **自主设计与代码演进**：制定工程方案，编写或修改高质量代码。
4.  **实验验证与科学迭代**：自主运行干实验，管理多分支版本，完成自我进化。

## 评测标准
- **科学性能**：模型在特定科学任务指标上的突破程度。
- **探索效率与计算经济性**：完成闭环的时间、迭代周期及资源消耗。
- **演进逻辑严密性**：决策链条的逻辑透明度与可解释性。
