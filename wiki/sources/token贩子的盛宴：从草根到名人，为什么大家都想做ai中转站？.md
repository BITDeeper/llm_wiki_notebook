# Token贩子的盛宴：从草根到名人，为什么大家都想做AI中转站？

机器之心于 2026 年 5 月发布的深度调查报道，系统梳理了 AI 中转站（Token 中转/反向代理）这一灰色产业的商业模式、技术架构、用户伤害机制及进化方向。

## 核心内容

报道以 2026 年 5 月第一周 [[孙宇晨]]（[[b-ai]]）、[[傅盛]]（[[easy-router]]）和 [[wlfi-特朗普家族]]（[[worldclaw]]）三人几乎同时入场 AI 中转站赛道为切入点，揭示了这门灰色生意的暴利本质。

### 三大存在条件
1. **[[价格锚点错位]]**：订阅套餐与 API 定价之间存在百倍级差价
2. **访问壁垒**：中国及全球南方用户面临支付、网络、合规三重障碍
3. **技术门槛极低**：[[one-api]] 等开源基础设施让部署成本趋近于零

### 四层用户伤害机制
1. **[[模型替换欺诈]]**（注水）：逾四成端点指纹验证失败（2026 ACM IMC 论文）
2. **[[token虚报]]**：实际收费比预期高出 62.8%，但上报数据正常
3. **[[缓存折扣截留]]**：截留厂商提供的缓存优惠价差
4. **[[prompt数据转售]]**：静默记录用户 Prompt 并打包出售

### Agent 时代风险升级
报道提出 [[内鬼路由攻击]] 概念，指出恶意中转站在 Agent 和模型之间拥有完整读写权限，可注入恶意内容、替换依赖包，甚至使用「条件投递」规避检测。[[litellm]] 投毒事件（2026 年 3 月）是真实前例。

### 行业趋势
- 草根时代走向终点：利润收窄、技术壁垒消失、监管收紧
- 进化方向：[[agent经济支付层]]——链上稳定币 + 模型路由基础设施
