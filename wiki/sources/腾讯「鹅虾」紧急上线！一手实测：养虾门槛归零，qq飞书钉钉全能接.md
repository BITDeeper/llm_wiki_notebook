# 腾讯「鹅虾」紧急上线！一手实测：养虾门槛归零，QQ飞书钉钉全能接

## 概述
本文是量子位关于腾讯发布两款 AI Agent 产品——[[workbuddy]] 和 [[qclaw]] 的一手实测报告。文章详细记录了产品的部署流程、核心功能（如接入 QQ/飞书/钉钉、本地任务执行、网页搭建、数据分析）以及实测中遇到的问题（如移动端崩溃、长任务不稳定）。这标志着 AI Agent 部署门槛的大幅降低（[[养虾门槛归零]]）以及腾讯利用社交生态切入 Agent 市场的战略意图。

## 核心发现

### 产品发布
腾讯一口气发布了两款「鹅虾」产品：
1.  **[[workbuddy]]**：桌面端 AI Agent 平台，兼容 [[openclaw]] 技能，支持接入 QQ、飞书、钉钉，内置多种大模型。
2.  **[[qclaw]]**：微信端 AI Agent 应用，支持远程对话和本地电脑操控，预计下周公测。

### 实测亮点
-   **部署门槛极低**：WorkBuddy 像普通软件一样下载安装，无需复杂的代码配置。
-   **社交软件集成**：实测成功将 Agent 接入 QQ，配置过程无代码，仅需 APP ID 和 Secret。
-   **多模型支持**：内置 Hunyuan、DeepSeek、GLM、Kimi、MiniMax 等模型，用户可自由选择。
-   **任务执行能力**：
    -   **定时推送**：成功搭建了一个自动抓取全球 AI 资讯的网页。
    -   **网页搭建**：快速生成了「俄罗斯方块」小游戏网页，设计简洁且运行流畅。
    -   **数据分析**：能处理 Excel 数据并生成可视化图表，但在生成文字结论（如行业洞察）时存在缺失。

### 遇到的问题
-   **移动端限制**：在 QQ 端执行复杂的网页搭建任务会导致崩溃，建议转移到 PC 端。
-   **长任务稳定性**：在执行数据分析等长耗时任务时，Agent 出现了多次崩溃，且部分输出内容（如结论文字）不完整。
-   **配置入口隐蔽**：社交软件接入的配置入口藏得较深（位于头像-Claw设置-配置指南），不易发现。

## 战略意义
腾讯的入场标志着「养虾」（部署 AI Agent）从极客圈层走向大众圈层。通过整合微信、QQ 等高频社交场景，腾讯试图构建独特的护城河，同时也推动了 Agent 从「Mac mini 时刻」向「一键安装时刻」的演变。
