# 谷歌Gemma 4深夜突降，31B爆杀20倍巨头！手机跑全血「龙虾」

## 概述
本文详细报道了谷歌 DeepMind 发布的 Gemma 4 系列开源模型。文章指出，Gemma 4 通过架构创新实现了极高的参数效率，其中 31B 模型在多项基准测试中击败了 20 倍体量的竞争对手。此外，Gemma 4 全系支持多模态（图像、视频、音频），并首次采用 Apache 2.0 开源协议，标志着谷歌在开源生态策略上的重大转变。

## 核心要点

### 模型性能与规格
- **越级性能**：31B Dense 模型在 Arena AI 文本榜单获得 1452 分（开源第三），击败了参数量是其 20 倍的模型。
- **MoE 架构**：26B MoE 模型推理时仅激活 3.8B 参数，Elo 评分 1441，兼顾速度与质量。
- **代际提升**：
    - 数学能力（AIME 2026）：从 21.2% 提升至 89.2%。
    - 编程能力（LiveCodeBench）：从 29.1% 提升至 80%。
    - 智能体能力（t2-bench）：从 6.6% 提升至 86.4%。
- **端侧部署**：E2B 和 E4B 模型针对手机、树莓派等设备优化，支持离线运行。

### 架构创新
Gemma 4 移除了效果不确定的组件（如 Altup），专注于提升参数效率：
1.  **逐层嵌入 (PLE)**：为每一层提供专属的低维信号通道，由 token 身份和上下文共同生成，显著提升小模型性能。
2.  **共享 KV 缓存**：最后 N 层复用前面的 KV 张量，降低推理显存和计算量，有利于长上下文处理。
3.  **交替注意力机制**：交替使用局部滑动窗口和全局全上下文注意力，平衡局部建模效率与长距离依赖。

### 多模态与 Agent 能力
- **全模态支持**：全系支持图像和视频输入，小模型（E2B/E4B）额外支持音频。
- **GUI 元素检测**：具备原生 GUI 元素定位能力，可直接返回界面元素坐标，无需特殊提示词。
- **多模态函数调用**：内置函数调用能力，支持多轮多工具的 Agent 工作流。

### 开源策略
- **Apache 2.0 协议**：首次放弃自定义许可证，采用完全商业友好的 Apache 2.0，消除了企业使用的法律壁垒。
- **双线策略**：Gemini 系列负责 API 变现，Gemma 系列负责生态建设与开发者入口。

## 关键数据
- **Arena AI Elo**：31B (1452), 26B (1441)。
- **Codeforces Elo**：31B (2150), 26B (1718)。
- **显存需求**：31B bfloat16 权重需 80GB 显存（单卡 H100），量化版可在消费级显卡运行。
