# 智谱上市后首份财报：超7.24亿元！国内收入最高大模型公司，MaaS发力了

## 核心数据
- **全年收入**：7.24亿元，同比增长132%，成为国内收入规模最大的大模型公司。
- **MaaS API 平台 ARR**：约17亿元，过去12个月增长60倍。
- **毛利率**：全年综合毛利率41%，远超行业平均水平（行业平均为-30%）。
- **用户规模**：服务400万企业用户及开发者，覆盖全球218个国家及地区。

## 关键论点

### 1. 逆势涨价策略成功
智谱在2026年3月推出 [[glm-5]]-Turbo 模型时，将 API 价格上调 83%。结果 Token 调用量不降反升，吸引了包括字节跳动、阿里巴巴、腾讯、美团等在内的9家中国前十大互联网公司成为付费客户。这验证了 [[张鹏]] 提出的观点：**智能上界决定定价权**。

### 2. MaaS 模式跑通
智谱的商业模式被指与 [[anthropic]] 高度一致，即通过“基座模型 + API 服务”实现规模化盈利。其核心逻辑是：模型效果越好 -> 吸引高价值客户 -> 带来稳定收入和利润 -> 投入技术研发 -> 进一步提升模型效果。

### 3. 技术实力支撑
- **编程能力**：[[glm-5]] 在 SWE-bench-Verified 上取得77.8分，在 Artificial Analysis 榜单排名全球第四、开源第一，体验逼近 Claude Opus 4.5。
- **架构转型**：从知识导向转向任务导向，实现了从 Vibe Coding 到 [[agentic-engineering]] 的跨越。

### 4. 价值重定义：TAC
智谱提出了 [[token架构力]]（TAC）概念，公式为：**TAC = 调用量 × 智能质量 × 经济转化效率**。这标志着行业竞争从“参数/跑分/价格”转向“智能架构竞争”。

## 行业背景
文章指出，2024-2025年中国大模型行业深陷 [[价格战]]，行业平均毛利率为负（-80% 至 -30%）。智谱通过提升技术价值和筛选高价值客户，打破了“增收不增利”的魔咒。
