# 全网玩疯的SBTI，挤爆了服务器！网友用Claude手搓复刻版

## 摘要
本文报道了 SBTI 人格测试在全网爆红的现象，以及开发者“平凡”利用 [[claude-code]] 在 48 小时内完成逆向复刻的案例。文章探讨了 [[vibe-coding]] 和 [[one-man-army]] 趋势如何降低软件开发门槛，并引用了 Shopify CEO 使用 Claude Code 处理医疗影像数据的佐证。

## 核心事件
- **SBTI 爆红**：由 B站 UP 主“蛆肉儿串儿”开发的解构版 MBTI 测试，包含“吗喽”、“僧人”、“尤物”等 27 种荒诞人格标签，因精准击中当代年轻人的自嘲情绪而刷屏热搜，导致服务器崩溃。
- **Claude Code 复刻**：知乎用户“平凡”在 SBTI 爆火后，使用 [[claude-code]] 和 Sonnet 4.6 模型，在一个周末内完成了从算法逆向、产品复刻、功能优化（雷达图、分享卡片）到部署上线的全流程。
- **技术细节**：复刻版使用 Vite + 原生 JS 构建，gzip 后体积仅 26KB。开发者不仅还原了 31 道题的评分逻辑，还通过 AI 分析了原版算法。

## 关键论点
1. **开发门槛坍缩**：过去需要三人小组两周的工作量（逆向、开发、部署），现在单人利用 AI 工具在一个周末即可完成。
2. **Vibe Coding 验证**：文章暗示 SBTI 本身可能源于 AI 生成，且其复刻过程展示了“自然语言描述意图 -> AI 生成代码”的新范式。
3. **商业与市场趋势**：引用了 Cursor (293亿美元估值)、Lovable (66亿美元估值) 的暴涨，以及独立创作者 Mayz 利用 AI 在几天内构建营收破万美元网站的案例。

## 相关背景
- **Shopify CEO 案例**：Tobi Lütke 使用 Claude Code 处理 DICOM 格式脊柱扫描数据，并生成了本地 HTML 查看器，展示了 AI 在非传统编程任务上的潜力。
- **行业数据**：Y Combinator 2024 冬季批次中，25% 的项目代码 95% 由 AI 生成。

## 意义
此事件标志着软件开发从“技术壁垒”转向“想法落地”的竞争。AI 工具使得“一人成军”成为现实，同时也引发了关于原创性与 AI 快速复刻之间伦理张力的讨论。
