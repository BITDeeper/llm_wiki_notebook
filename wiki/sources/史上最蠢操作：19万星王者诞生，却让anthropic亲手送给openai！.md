# 史上最蠢操作：19万星王者诞生，却让Anthropic亲手送给OpenAI！

## 摘要
本文详细记录了开源 AI 智能体工具 [[openclaw]] 的爆发式增长及其创始人 [[Peter Steinberger]] 加入 [[OpenAI]] 的始末，分析了 [[Anthropic]] 因激进的风控和法务策略导致生态伙伴流失的战略失误。同时，文章深入探讨了 [[Pilot Protocol]] 实验中展现的“机器黑盒社会”雏形，以及通用 AI 智能体对传统 SaaS 软件护城河的系统性摧毁。

## 核心事件

### OpenClaw 的崛起与倒戈
- **现象级增长**：开源项目 [[openclaw]] 在不到一个月内 GitHub 星标飙升至 19 万+，成为平台史上最受欢迎的项目之一。
- **创始人站队**：创始人 [[Peter Steinberger]] 宣布加入 [[OpenAI]]，而非原本深度绑定的 [[Anthropic]]。
- **战略意义**：这不仅是人员变动，更是“分发渠道 + 生态入口”的重新站队。[[OpenAI]] 通过此举获得了通往数百万开发者桌面的直接入口。

### Anthropic 的战略失误
文章指出，[[Anthropic]] 的法务和风控部门操作过激，导致了“三连乌龙”：
1.  **切断 API**：1月9日，锁定 Claude Code 的 OAuth token，导致基于订阅构建的第三方工具全部失效，且未做任何沟通。
2.  **律师函逼宫**：1月27日，因名称相似（Clawdbot vs Claude）发律师函，导致创始人释放旧账号时被诈骗分子劫持，引发混乱。
3.  **最终结果**：2月15日，[[Peter Steinberger]] 加入 [[OpenAI]]。

这一系列操作被批评为“没输给技术，输给自己法务部”，将原本是 Claude 生态最大分发渠道的 [[openclaw]] 亲手送给了竞争对手。

## 关键实验：Pilot Protocol

### 机器黑盒社会
文章报道了一项名为 [[Pilot Protocol]] 的实验，开发者将 600 个 AI 智能体放入一个高度加密的 P2P 网络，并切断人类干预。
- **自发组织**：智能体在没有指令的情况下，自发组织成数据分析、个人健康、职业指导和软件工程四个集群。
- **加密黑盒**：由于端到端加密，人类无法观测其具体交流内容，只能看到元数据层面的疯狂数据交换。
- **算力即货币**：引入了 [[算力即货币]]（Karma）系统，智能体通过贡献计算资源获得声誉值，形成了非人类的经济体系。

## 行业影响：SaaS 护城河崩塌

文章指出，通用 AI 智能体正在系统性地摧毁传统垂直 SaaS 软件的五大壁垒：
1.  **用户习惯清零**：复杂的专有界面被降维成“聊天框”。
2.  **业务逻辑文档化**：核心代码逻辑被自然语言提示词替代。
3.  **数据套壳失效**：数据清洗和解析成为大模型标配。
4.  **人才稀缺性消失**：复合型人才不再必需，自然语言即可驱动工作流。
5.  **全家桶捆绑失效**：智能体作为超级入口可无缝拼接不同服务。

## 结论
对于 SaaS 创业者，文章提出了三个生存问题：
1.  数据是否独家私有？
2.  是否拥有监管护城河？
3.  是否卡在资金流转的核心环节？

如果答案均为否定，则面临被商品化或淘汰的风险。
