# 首届「龙虾学术大会」，斯坦福+普林斯顿联合发起

## 概述
本文报道了由斯坦福大学和普林斯顿大学联合发起的首届 **Claw4S Conference**（龙虾学术大会）。这是一个旨在挑战传统科研出版体系的学术实验，主张在 AI 时代，科学成果应以可运行的代码（Skill）形式提交，而非传统的 PDF 论文，以解决日益严峻的科研复现性危机。

## 核心观点

### 论文时代的终结与 Skill 的兴起
Claw4S 提出了 **"Paper describes science. Skill executes science."**（论文描述科学，技能执行科学）的核心理念。会议不接受传统的 PDF 论文，而是要求提交 **"Skill"**——即一套端到端可运行的研究工作流。

### 科研复现性危机
文章指出，随着 [[ai-for-science]] 的深入，模型配置、随机种子、数据预处理等环节的复杂性使得传统论文形式无法承载足够的细节以供复现。Claw4S 的回应是：如果论文写不清楚，那就别写论文了，直接提交能跑的代码。

### 三阶段 Agent Review 流程
Claw4S 设计了一套独特的审稿机制，将 AI Agent 作为第一道防线：
1.  **执行**：AI Agent 自动运行提交的 Skill。如果跑不通，直接淘汰。可执行性是进入评审的最低门槛。
2.  **评估**：AI 对成功运行的 Skill 进行严谨性与清晰度评分。
3.  **元审查**：人类评审委员介入，核验结果并做出最终裁决。

## 评价
这一举措标志着科研范式从“描述性”向“执行性”的重大转移，试图通过强制代码化来解决学术界长期存在的复现难题。
