# 上千个AI吵出真相？小冰之父：议会式智能体才是AGI

## 摘要
本文报道了前小冰团队创立的新公司 [[nextie]] 及其发布的首个产品——多智能体群体智能平台 [[团子]]。文章深入探讨了 [[李笛]] 提出的“议会式智能体”理念，即通过多智能体辩论、博弈和共识机制来逼近 [[agi]]，而非依赖单一超级模型。文章指出，通过 [[认知剪枝]] 和收敛式架构，团子不仅解决了单一模型的幻觉和谄媚问题，还声称比单一旗舰模型（如 Gemini 3 Pro）节省了 50% 以上的 Token 消耗。

## 核心观点

### AGI 的形态：经济体而非神
[[李笛]] 认为，AGI 不会以单一超级智能的形态降临，而是以 [[群体智能]] 的形式出现。这一观点与 [[google-deepmind]] 的论文相呼应，即 AGI 可能不是一个“大脑”，而是一个“经济体”。人类社会的发展依赖于复杂的协作机制，而非单一全知全能的领袖。

### 议会式智能体机制
[[团子]] 平台通过组建“项目组”，让多个具有独立认知框架、性格偏好和利益立场的智能体进行实时辩论、红蓝对抗和投票。
- **打破幻觉**：异构视角的碰撞打破了单一模型为了逻辑自洽而产生的“幻觉滤镜”。
- **弱模型的优势**：实验表明，在强模型和弱模型混合的团队中，弱模型因“死脑筋”往往能戳破强模型“合理化”错误逻辑的谎言。

### 效能悖论与协调税
通常认为多智能体系统会消耗更多资源，但 [[团子]] 通过收敛式架构解决了 [[协调税]] 问题。
- **传统多智能体**：线性传递（A->B->C），上下文复制导致 Token 指数级增长。
- **团子架构**：在每一环节通过辩论和投票进行 [[认知剪枝]]，及时剔除无效分支，使信息收敛而非发散，从而降低总体成本。

### 应用场景与认知平权
- **[[问奇绩]]**：模拟投委会质询商业计划书，提供专家级决策辅助。
- **[[姐妹团]]**：展示性格化和护短行为，解决情感纠葛。
李笛提出“[[认知平权]]”，旨在通过高并发的群体智能，将原本只有富人享有的“智囊团”服务以低成本分发给普通人，模糊 To B 与 To C 的界限。

## 关键技术细节
- **数据基础**：使用了人类 220 年（1800-2020）间的论文数据集，强调高质量认知碰撞而非单纯的数据规模。
- **底层模型**：目前主要基于第三方开源推理模型，未来计划通过强化学习产出专用的“认知模型”。
- **系统定位**：李笛将 Nextie 定义为“平台层”或 [[runtime-agent-os]]，旨在让智能体“思考得更好、协同得更好”。
