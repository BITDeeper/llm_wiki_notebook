# ICML 2026 ｜让大模型边想边说：这篇文章把「何时开口」变成可学习策略

## 概述

本文报道了发表于 ICML 2026 的论文《When to Think, When to Speak: Learning Disclosure Policies for LLM Reasoning》，介绍了 [[并列式交错推理]]（Side-by-Side Interleaved Reasoning）方法。该方法将大模型推理过程中的"何时向用户披露内容"从工程显示问题推进为可学习的模型行为，通过在自回归生成流中交替执行"思考"和"披露"两类动作，实现"边想边说"。

## 核心贡献

1. **识别 [[沉默税]] 问题**：指出单流自回归接口将模型状态更新与面向用户的公开承诺耦合在一起，导致"多想用户多等，早说容易出错"的矛盾。
2. **提出 [[内容延迟]] 概念**：区分系统层面的 TTFT（首 Token 延迟）与用户真正关心的"何时看到有依据的有用内容"。
3. **将 [[披露策略]] 变为可学习行为**：通过蕴含对齐轨迹构造 → SFT → GRPO 的三阶段训练流程，让模型学会在推理过程中有依据地逐步披露答案。

## 关键实验结果

- **Qwen3-4B 在 AIME25 上**：SxS RL Final 准确率 80.0%（vs Standard CoT RL Final 73.8%），AIRW 从 21,316 降至 8,519。
- **Qwen3-4B 在 GPQA-Diamond 上**：SxS RL Final 准确率 49.3%（vs Standard CoT RL Final 19.0%），AIRW 从 16,338 降至 7,738。
- 小模型上的收益尤为显著，准确率和内容延迟同时改善。

## 局限性

- 延迟指标为 Token 级代理指标，不等同于真实时钟延迟。
- SFT-only 阶段会出现准确率下降，需依赖 RL 恢复。
- 披露粒度越高训练效率成本越大，需在准确率与内容延迟间寻找帕累托最优。

## 关联

- 与 [[任务执行范式]] 相关：将流式交互从工程问题推进到模型学习问题。
- 与 [[scaling-law]] 形成补充：不依赖扩大模型规模，通过训练策略优化用户体验。
- 与 [[批次不变性]] 形成对照：分别代表大模型工程化的不同维度（交互体验 vs 工程确定性）。
