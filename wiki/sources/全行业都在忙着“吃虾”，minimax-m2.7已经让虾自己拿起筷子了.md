# 全行业都在忙着“吃虾”，MiniMax M2.7已经让虾自己拿起筷子了

## 概述
本文报道了 [[minimax]] 发布的最新一代大模型 [[minimax-m2-7]]。该模型在 [[agent-harness]]（智能体工具箱）构建、多智能体协作、SRE 级故障排查以及自我进化能力方面取得了显著突破，标志着大模型从“被动使用工具”向“主动构建工具与自我迭代”的范式转变。

## 核心亮点

### 1. 自我进化与工具构建
- **核心突破**：M2.7 具备自主构建和迭代 [[agent-harness]] 的能力，不再局限于使用人类提供的工具。
- **技术实证**：
    - 在强化学习实验中，能自主看日志、排查故障、改代码并提交合并请求。
    - 在优化内部 Harness 代码的测试中，通过自主试错将模型效果提升了 30%。
    - 在 [[mle-lite]]（22道高难度 ML 竞赛题）中，通过自反馈和自优化，拿下了 9 金 5 银 1 铜的成绩。

### 2. SRE 级故障排查
- **能力描述**：具备网站可靠性工程师（SRE）级别的故障诊断与修复能力。
- **实测案例**：
    - 面对生产环境数据库 CPU 飙升，能精准定位漏掉的索引文件。
    - 生成符合生产安全标准的止血代码，例如使用 PostgreSQL 的 `CONCURRENTLY` 语法进行**非阻塞建索引**，严禁锁表。
    - 提供的 SQL 代码规范程度极高，可直接用于提交合并请求。

### 3. 多智能体协作与指令遵循
- **原生支持**：无需外部框架即可组建 Agent Teams，能稳定锚定身份并自主决策。
- **评测成绩**：
    - 在包含 40 个复杂技能的场景下，指令遵循率达 97%。
    - 在 [[mm-claw]]（“龙虾测试”）中正确率达 62.7%，直逼 [[claude-sonnet-4-6]]。

### 4. 代码与办公能力
- **代码能力**：在 [[swe-pro]] 测试中以 56.22% 的正确率追平 [[gpt-5-3-codex]]。
- **办公自动化**：在 [[gdpval-aa]] 评测中超越 GPT-5.3，能自主完成从数据分析、生成 Excel 透视表、撰写 Word 报告到排版 PPT 的全流程。

### 5. 交互系统与角色扮演
- **深度适配**：深度适配 [[openclaw]] 长期记忆框架，强化了人设稳定性与对话情商。
- **开源系统**：官方开源了 [[openroom]] 交互系统，构建了一个赛博朋克风的“龙虾小屋”，支持万物互动的 Web GUI 空间。

## 行业意义
文章指出，当前行业大多在忙着“吃虾”（即适配 [[openclaw]] 等现有框架），而 MiniMax M2.7 已经实现了“让虾自己拿起筷子”（即模型自我进化与工具构建）。这种主动进化的能力被视为决定下一代大模型核心竞争力的分水岭。
