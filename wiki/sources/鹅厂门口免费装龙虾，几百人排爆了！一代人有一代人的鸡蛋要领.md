# 鹅厂门口免费装龙虾，几百人排爆了！一代人有一代人的鸡蛋要领

## 概述
本文报道了 2026 年 3 月发生在腾讯（鹅厂）总部的一场现象级技术普及活动。腾讯云工程师现场为数百名用户免费部署 [[openclaw]]（俗称“龙虾”），参与者涵盖从小学生到退休老人的各个年龄段。这一事件标志着 [[ai-agent]] 技术正从极客圈向大众市场爆发式渗透，同时也引发了云厂商对“Token 消耗”市场的激烈争夺。

## 核心事件

### 腾讯云“免费装龙虾”活动
- **地点**：腾讯总部（深圳）
- **主办方**：腾讯云 Lighthouse 团队
- **规模**：准备了 800 个部署号位，安排 30 位工程师现场服务，现场排队人数爆满。
- **服务内容**：提供从安装部署、模型配置到 IM 渠道打通及技能解锁的“一条龙”服务。
- **参与者画像**：
  - 60 多岁的阿姨（为女儿部署）。
  - 退休航空技术工程师（探索 AI 新技能）。
  - 四年级小学生（用于写作业、查资料）。
  - 各行各业从业者。

### 全球热潮
- **纽约**：同期举办的 OpenClaw 线下活动门票售罄，AI 意见领袖 Allie K. Miller 感叹 AI 发展速度。
- **数据**：OpenClaw 在 GitHub 的 Star 数超过 27 万；腾讯云上的“养虾人”规模突破 10 万。

## 技术背景：OpenClaw (龙虾)

### 定义与功能
[[openclaw]] 是一款由奥地利程序员 Peter Steinberger 开发的开源智能体框架。它允许 AI 直接控制电脑屏幕和键盘，调用本地数据，被视为“24x7 全天候待命的数字员工”。

### 核心特性
- **Docker 沙箱**：通过 [[docker-沙箱]] 技术安全地控制系统，避免直接操作底层风险。
- **本地化与远程控制**：支持本地部署及通过聊天工具远程下发指令。
- **高算力消耗**：被称为“[[token-怪兽]]”，需要持续消耗大量算力/Token 才能维持运行。

## 商业与生态影响

### 云厂商的“Token 战争”
由于 OpenClaw 是高算力消耗工具，各大云厂商和模型厂商纷纷跟进，试图通过其拉动 API 调用和云服务销售：
- **模型厂商**：[[智谱]]、[[MiniMax]]、[[Kimi]]、[[阶跃]] 等优化自家模型以适配 OpenClaw。
- **OpenAI**：将 OpenClaw 纳入生态，优化 GPT 系列的多模态 Agent 能力。
- **互联网大厂**：
  - **字节**：豆包大模型通过火山引擎 API 打通飞书、抖音场景。
  - **阿里**：阿里云 Coding Plan 支持切换 Qwen3.5-Plus 等编程模型。
  - **网易**：有道推出基于 OpenClaw 的 LobsterAI 个人助理。
  - **小米**：将 OpenClaw 集成进手机，支持本地运行。

### 社会现象：养龙虾
- **定义**：指部署、配置和维护 OpenClaw 智能体的过程（喂 Token、配技能）。
- **门槛**：虽然热情高涨，但技术门槛依然存在，催生了“上门安装 500 元一次”的衍生服务市场。

## 关键洞察
1. **技术普及的“鸡蛋模式”**：AI 技术通过类似超市促销（领鸡蛋）的方式下沉到大众，表明 2026 年 AI 已具备极强的社会吸引力。
2. **Agent 的实用性**：用户不再满足于聊天，而是追求能自动操作电脑、处理具体任务的“数字员工”。
3. **安全与便利的博弈**：尽管 [[openclaw]] 曾发生过安全事故（如删除邮件），但大厂的背书和沙箱技术的改进正在推动其大规模普及。
