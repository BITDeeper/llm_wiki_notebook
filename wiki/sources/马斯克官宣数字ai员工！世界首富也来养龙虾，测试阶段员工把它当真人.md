# 马斯克官宣数字AI员工！世界首富也来养龙虾，测试阶段员工把它当真人

## 概述
本文报道了埃隆·马斯克正式官宣的“数字擎天柱”项目，这是一个由 xAI 与特斯拉联合开发的 AI Agent，旨在通过理解屏幕和操作键鼠来模拟人类白领工作。文章详细梳理了该项目从 xAI 内部代号“巨硬”演变至今的过程，涉及管理层变动、技术架构细节以及与竞品（如 Claude Code）的市场竞争。

## 核心要点

### 产品定位：数字员工
- **功能**：能够理解电脑屏幕内容、操作软件界面、使用键盘鼠标，完成日常办公任务。
- **目标**：模拟完整公司的运作，替代重复性白领劳动。
- **分工**：[[digital-optimus]] 负责 System 1（执行），[[grok]] 负责 System 2（思考）。

### 技术与硬件
- **运行载体**：[[tesla-ai4]] 芯片。
- **成本优势**：功耗仅为 H100 的 1/4，价格约 650 美元。
- **架构**：强调边缘侧推理，减少对昂贵数据中心 GPU 的依赖。

### 项目历史与动荡
- **起源**：[[macrohard]] 最早是 xAI 内部旨在对标微软、用 AI 模拟软件公司的项目。
- **挫折**：经历管理层动荡（前负责人 Toby Pohlen 离职）、外包数据项目暂停（600 人录屏）及员工离职潮。
- **整合**：项目部分资源已并入特斯拉自动驾驶团队，现作为 Tesla 与 xAI 的联合项目存在。

### 市场背景
- 文章提到 Anthropic 的 Claude Code 已占据市场优势，OpenAI 收购了 OpenClaw（注：此处指代竞品，可能与 Wiki 中记录的安全事故工具同名），Meta 也有相关动作，迫使马斯克加速入场。

## 关键人物

- [[sulaiman-ghori]]：前 xAI 员工，早期爆料者。
