# 「生化危机」女主用Claude手搓满分AI，一年0.7美元反杀大厂！

## 概述
本文报道了好莱坞女星 [[milla-jovovich]] 与工程师 [[ben-sigman]] 利用 [[claude-code]] 开源了 AI 长期记忆系统 [[mempalace]] 的故事。该系统在 [[longmemeval]] 基准测试中取得满分（500/500），且通过本地化部署将成本控制在每年 0.7 美元，旨在解决大模型缺乏长期记忆和上下文遗忘的问题。

## 核心要点

### 1. 跨界开发与 AI 辅助编程
- **主角**：Milla Jovovich（《生化危机》主演）以“架构师”身份参与，负责逻辑设计；Ben Sigman 负责代码实现。
- **工具**：主要使用 [[claude-code]] 将设计转化为代码，展示了非技术人员借助 AI 构建复杂系统的可能性。
- **动机**：在开发游戏过程中，发现 AI 无法跨会话保留设计思路和决策历史，导致每次对话都从零开始。

### 2. MemPalace 系统架构
- **核心理念**：借鉴古希腊“记忆宫殿”术，将数据结构化存储。
- **空间隐喻**：
  - **翼楼**：代表项目或人物。
  - **房间**：代表特定主题（如认证、数据库）。
  - **走廊**：连接房间的通道，按记忆类型分类（决策、里程碑等）。
  - **隧道**：连接不同翼楼中的同名房间，实现跨视角关联。
- **性能提升**：通过结构化过滤（元数据检索），搜索召回率从 60.9% 提升至 94.8%（+34%）。
- **存储方式**：完全基于本地 [[chromadb]]，不上云，保护隐私。

### 3. AAAK 压缩方言与争议
- **定义**：一种专为 AI 阅读设计的缩写方言，旨在减少 Token 消耗。
- **官方宣称**：最初声称可实现“30倍无损压缩”。
- **社区打假**：
  - 实测显示部分示例压缩后 Token 反而增加（66 -> 73）。
  - 压缩是有损的，导致 LongMemEval 分数下降（96.6% -> 84.2%）。
- **团队回应**：发布公开信承认错误，修正宣传文案，体现了开源社区的诚实精神。

### 4. 成本对比
- **云端方案**：依赖 API 摘要生成，年成本约 507 美元，且丢失推理细节。
- **MemPalace**：本地存储与检索，年成本仅 0.7 美元（主要是存储费用），保留原始对话全文。

### 5. 技术集成
- 支持 [[mcp]] (Model Context Protocol)，可通过一行命令集成到 Claude、ChatGPT 或 Cursor 中，实现 AI 自动调用工具检索记忆。

## 意义与启示
- **开发者门槛降低**：明星跨界开发并取得 SOTA 成绩，验证了 AI 时代“审美法官”角色的价值（人类负责架构，AI 负责实现）。
- **本地化趋势**：提供了一种摆脱高昂订阅费和云端隐私风险的可行路径。
- **开源信任**：面对营销夸大，团队选择公开认错，反而增强了社区信任。
