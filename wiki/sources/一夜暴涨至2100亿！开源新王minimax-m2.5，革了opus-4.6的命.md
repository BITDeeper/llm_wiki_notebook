# 一夜暴涨至2100亿！开源新王MiniMax M2.5，革了Opus 4.6的命

## 摘要
本文详细报道了 MiniMax 发布的开源大模型 [[minimax-m2-5]]。文章声称该模型在编码、办公和长文本理解等核心任务上已逼近甚至超越 [[claude-opus-4-6]]，同时价格仅为后者的 1/20。文章分析了其背后的 [[agent-rl]] 技术体系，包括 [[forge]] 框架和过程奖励机制，并指出这标志着顶级模型能力的去稀缺化和“能力平权”时代的到来。

## 核心评测发现

### 编码能力
- **逻辑陷阱测试**：通过“遛马”变种题（距离仅 5 米），而 Opus 4.6 失败。
- **算法题**：在 LeetCode Hard 题目（寻找两个正序数组的中位数）中，20秒内给出 O(log(m+n)) 时间复杂度的最优解，优于 Opus 4.6 的解法。
- **多轮重构**：在连续的代码审查、重构和架构设计任务中，表现出稳定的上下文理解和工程化思维。
- **3D 生成**：在单个 HTML 文件中生成了完整的 3D 卡丁车竞速体验，表现出优秀的工程落地能力。

### 办公与数据分析
- **脏数据清洗**：成功处理包含日期格式不统一、缺失值、负数等问题的复杂 Excel 表格，并完成了跨表关联与毛利分析。
- **高阶任务**：准确列出 2019-2024 年福布斯亿万富翁前十名，展示了强大的数据检索与整理能力。

### 长文本与研究
- **教材精读**：对《数学分析原理》（Rudin 著）进行了解读，准确提炼核心概念，并使用了“阅兵式”类比一致收敛等通俗易懂的解释方式。
- **深度研究**：对 [[openclaw]] 进行了结构化分析，展现了因果推理和批判性思考能力。

## 技术归因
文章将 M2.5 的成功归因于其围绕 [[agent-rl]] 构建的技术体系：
1. **原生 Agent RL 架构**：通过 [[forge]] 框架解耦底层训推引擎与 Agent 逻辑，支持任意 Agent 接入。
2. **CISPO 算法**：保障 MoE 模型在大规模强化学习中的稳定性。
3. **过程奖励机制**：解决长上下文场景下的信用分配难题。
4. **耗时估计奖励**：直接优化任务在真实环境下的响应速度。

## 市场与行业影响
- **性价比**：1 美金/小时（100 TPS），价格仅为 Opus 4.6 的 1/20。
- **市值反应**：发布后 MiniMax 市值暴涨至 2108 亿港元。
- **行业观点**：文章认为“开放权重模型和专有模型之间的差距已经彻底消失”，行业进入“能力平权”时代，竞争焦点转向系统整合与场景落地。
