# 科研AI出了个狠角色：开源30B小模型，硬刚Gemini和Claude

**摘要**：本文报道了 [[UniPat AI]] 团队发布的开源科研大模型 [[UniScientist]]。该模型仅用 30B 参数（3B 激活），通过 [[形式化科学研究]] 框架和 [[进化式多学科合成]] 数据引擎，在 FrontierScience-Research 等榜单上超越了 [[Claude Opus 4.5]] 和 [[Gemini 3 Pro]] 等顶尖闭源模型。文章详细解析了其如何通过“主动证据整合”和“模型溯因”实现科研闭环，以及利用“成果聚合目标”提升推理能力的技术路径。

## 核心观点

1.  **科研闭环的实现**：真正的科研智能不是生成漂亮的报告，而是跑通“假设-证据-验证”的闭环。[[UniScientist]] 能够在开放问题中不断提出假设、证伪推论、修正路径，直到证据状态稳定。
2.  **数据瓶颈的突破**：利用“模型生成 + 专家验证”的不对称性，构建了包含 4700+ 实例、覆盖 50+ 学科的高质量科研数据集。
3.  **小模型的大能力**：通过特定的训练目标（如 [[成果聚合目标]]），30B 参数的模型在无工具条件下仍能超越参数量大一个数量级的闭源系统，表明模型内化了研究推理能力。

## 关键技术细节

-   **动态系统建模**：将科研过程建模为基于“主动证据整合”和“模型溯因”的动态系统，核心是不断演化的“证据状态”。
-   **Rubric 驱动评测**：将开放式科研成果分解为 N 个封闭的、可独立验证的 Rubric 检查项，强调原子性、客观性和可复现性。
-   **成果聚合**：给定同一问题的 N 份候选成果，模型学会融合优点，产出更稳健的最终成果，模拟了科研中的“集体智能”。

## 局限与未来

-   目前能力主要集中在可复现推理与仿真计算范围内。
-   尚未实现对真实世界研究资源的编排（如大规模 GPU 任务调度、湿实验流程协调）。
-   下一步目标是将框架扩展到对真实实验与计算基础设施的受控编排与执行。
