# 从Token到词元：全模态时代的基模与交互入口

## 概述
本文报道了 [[模思智能]]（MOSI）完成数亿元天使轮融资的消息，并深入剖析了其以“统一 [[词元]] 结构”为核心的全模态技术路线。文章指出，随着国家数据局确立“词元”为 Token 的标准译名，AI 行业正从文本主导时代迈向全模态时代，而 [[情境智能]] 和 [[统一token结构]] 将成为下一代智能系统的关键壁垒。

## 核心要点

### 行业背景
- **术语规范化**：2026年3月24日，国家数据局确立“词元”为 Token 的标准译名，国内日均 Token 调用量突破 140 万亿。
- **范式转移**：AI 交互正从离散文本、低频批量输入转向连续感知、高频流式输入。这不仅是术语的变化，更是底层组织方式的变革。

### 模思智能的技术路径
模思智能选择了一条“非共识路径”：从语音切入，构建全模态统一架构。
- **语音作为入口**：音频包含语调、节奏、情绪等高密度信息，且易于与环境形成连续流，是通向“情境理解”的天然起点。
- **统一 Token 结构**：将语音、视频、文本等不同模态的信息，全部离散化并映射到同一个 Token 空间进行计算，打破模态隔阂。

### 技术演进历程
团队（源自复旦大学 [[邱锡鹏]] 教授体系）的技术演进路径清晰：
1. **[[moss]] (2023.02)**：国内首个类 ChatGPT 对话式大模型。
2. **[[speechgpt]] (2023.05)**：验证了“离散化端到端语音大模型”路径，将语音信号映射为离散 Token。
3. **[[speechtokenizer]] (2023.08)**：融合语义与声学的音频离散化编码器。
4. **[[anygpt]] (2024.02)**：首个将语音、文本、图像、视频统一映射至离散 Token 体系的全模态基座模型。
5. **[[nex]] (2025.11)**：下一代能动性模型体系，强调 Agent 能力与工具使用。

### 团队与商业化
- **核心团队**：首席科学家 [[邱锡鹏]]（复旦大学教授），CEO [[李世民]]（邱锡鹏学生）。团队博士占比近 50%，由 [[上海创智学院]] 与复旦大学联合孵化。
- **融资情况**：完成数亿元天使轮融资，由 [[IDG资本]] 领投。
- **落地场景**：消费电子、智能汽车、具身智能、AI 陪伴。

## 关键概念
- **[[情境智能]]**：以持续感知、动态记忆与环境理解为基础，使 AI 能够在真实世界中进行自适应交互。
- **[[离散化全模态]]**：将连续模拟信号转化为离散 Token 序列，提高压缩效率与可组合性。

## 摘录
> “词元”既避免被简单理解为自然语言中的“词”，又保留了其作为语言处理基本单位的本质内涵。

> 从“理解一句话”转向“理解一个情境”。

> 离散化带来的，不只是更高的压缩效率，更重要的是赋予不同模态以可组合性与可计算性——而这正是全模态智能与 Agent 系统真正落地的底层架构前提。
