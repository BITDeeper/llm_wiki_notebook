# 源内容摘要

本文报道了 AI Agent 在企业端和个人端同时重塑信息处理方式的两个典型案例。

## 核心案例

### 1. 扎克伯格的 CEO Agent
- **背景**：Meta 全公司强推 AI 化，绩效考核纳入 AI 使用情况。
- **功能**：扎克伯格开发个人 Agent，绕过公司层层汇报链，直接向 AI 索取数据。
- **内部文化**：出现“军备竞赛”氛围，员工自建工具如 [[my-claw]]（代替沟通）和 [[second-brain]]（AI 参谋）。
- **代价**：Meta 考虑裁员 20% 以抵消 AI 资本支出，员工面临焦虑与倦怠。

### 2. AI 博士生的“人生托管系统”
- **起因**：AI 博士生 [[gnekt]] 因认知过载（论文、邮件、健康等多线程任务），导致大脑“内存溢出”。
- **解决方案**：开发开源系统 [[my-brain-is-full-crew]]，基于 [[claude-code]] 和 [[obsidian]]，使用 8 个 Agent 协作管理生活。
- **架构**：
  - **Scribe**：语音/文字转结构化笔记。
  - **Sorter**：收件箱分类归档。
  - **Seeker**：跨笔记检索综合作答。
  - **Connector**：发现笔记间隐藏关联。
  - **Librarian**：仓库体检（去重、断链）。
  - **Transcriber**：会议录音转结构化记录。
  - **Postman**：同步 Gmail 和日历信息。
  - **Architect**：系统总控与结构设计。
- **机制**：通过共享消息板异步协调，采用 PARA 和卡片盒笔记法混合架构。

## 关键洞察

- **认知带宽极限**：人类处理信息能力有限，AI 时代信息过载迫使我们必须依赖 Agent 进行“认知外包”。
- **系统设计挑战**：社区反馈指出系统存在级联错误、竞争条件等风险，并提出了引入“精力感知层”的设想。
- **范式转移**：从“使用工具”转向“外包管理”，Agent 成为个人生活的底层操作系统。
