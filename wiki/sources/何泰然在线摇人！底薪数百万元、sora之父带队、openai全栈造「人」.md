# 何泰然在线摇人！底薪数百万元、Sora之父带队、OpenAI全栈造「人」

## 摘要

本文报道了 OpenAI 正式组建机器人部门 [[openai-robotics]]，从"大脑供应商"转型为全栈机器人公司的战略转折。核心要点：

1. **战略转型**：OpenAI 不再满足于向 [[figure-ai]]、[[1x-technologies]] 等公司提供模型 API，而是亲自下场造机器人，实现软硬件闭环。
2. **关键人物**：[[aditya-ramesh]]（DALL·E 发明人、Sora 团队领导者）从零搭建机器人团队，其技术路线（DALL·E → Sora → 机器人）是一条自然延伸。
3. **Sora 重新定位**：[[sora]] 的终极目标不是视频生成，而是作为 [[worldsim|世界模拟器]] 为机器人提供虚拟训练沙盒。
4. **全栈招聘**：OpenAI 官网开放十几个机器人相关职位，覆盖执行器设计、3D打印实验室、仿真逼真度、分布式数据系统等方向，以大模型公司薪酬体系（底薪最高44.5万美元/年+PPU）挖硬件人才。
5. **竞争背景**：在 coding 场景被 [[anthropic]] 领先后，OpenAI 试图通过"世界模型+机器人本体"的软硬件闭环夺回领先地位。

## 关键信息

- [[sam-altman|奥特曼]] 亲自在社交平台发布招聘信息
- 《华尔街日报》曾报道奥特曼考虑拆分硬件部门，最终选择保留
- 团队成员 [[何泰然]] 在社交媒体积极转发招聘，强调看重动手能力而非学历背景
- 短期目标：工业基础设施建设辅助机器人；长期目标：人手一台的通用个人机器人
