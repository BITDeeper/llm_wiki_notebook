# 概述

本文报道了法国研究人员开发的两项低成本、高灵敏度的云端模型变动检测技术：[[对数概率追踪]]（针对灰盒环境）和 [[黑盒边界输入追踪]]（针对黑盒环境）。这些技术能够以极低的成本（仅需1个Token）检测出API供应商是否在未通知用户的情况下私自降级或替换后台模型。

# 核心内容

## 1. 灰盒环境：对数概率追踪

在 [[灰盒环境]] 中，用户无法获取模型权重，但可以获取输出的对数概率。该技术利用对数概率作为“模型指纹”，通过以下方式进行监测：
- **极简输入**：仅需发送极短提示词（如“x”）并请求单个Token输出。
- **统计基准**：重复采样N次建立基准，利用均值绝对距离和排列检验区分硬件噪声与模型变更。
- **高灵敏度**：能捕捉到单步微调的差异，敏感度是主流方案的512倍。
- **低成本**：监测成本仅为传统方案的千分之一。

## 2. 黑盒环境：黑盒边界输入追踪 (B3IT)

在限制更严苛的 [[黑盒环境]] 中，审计者只能看到最终文本。B3IT 技术利用模型决策边界的不稳定性：
- **边界输入**：寻找能让模型在多个Token之间产生剧烈犹豫（逻辑得分持平）的特定提示词。
- **费希尔信息量**：在低Temperature下，边界输入处的检测信噪比会急剧发散，使得微小的权重扰动也能被检测到。
- **两阶段检测**：
    1. **初始化**：通过少量采样筛选出合格的边界输入。
    2. **监测**：观察输出Token是否坍缩或出现新Token，以此判定模型是否变更。
- **高效性**：成本仅为现有SOTA方案的1/30，准确率达87%。

## 3. 行业现状与猫鼠游戏

- **实证数据**：对189个API端点的监测捕捉到了37次显著偏移，证实了私自替换模型的现象普遍存在。
- **供应商反制**：部分头部平台开始强制要求生成至少16个Token，以人为抬高检测成本，侧面印证了监测手段的有效性。

# 意义

这两项技术为维护AI服务消费者的权益提供了强有力的工具，迫使API供应商提高服务透明度，防止因成本优化而牺牲模型质量。
