# Token 新译名：「智元」

## 摘要
本文报道了 AI 行业对 **Token** 中文译名的重新审视与定名过程。鉴于 AI 已从单纯的文本处理（NLP）进入多模态和 Agent 时代，旧译名“词元”已无法涵盖其现在的含义。文章主张并背书将 Token 统一翻译为 **「智元」**，这一译名获得了学术界（尤洋、胡翌霖）、产业界（王小川）和媒体的广泛认可。

## 核心观点

### 1. 译名主张：智元
- **定义**：将 Token 翻译为“智元”。
- **理由**：
  - **智**：对应智能计算领域属性，区别于通用计算。
  - **元**：对应其作为不可再分的基础构件（原子性），如元素、单元。
- **优势**：符合“信达雅”标准，且适应多模态（图像、视频等）和 Agent 时代的需求。

### 2. 时代背景：Agent 时代与 Token 经济学
- **英伟达 GTC 2026**：黄仁勋强调数据中心已成为“Token 中心”，并将 AI 发展划分为生成式、推理和 Agent 三个阶段。
- **OpenClaw 的影响**：作为 Agent 时代的标志性产品，OpenClaw 让用户直观感受到了 [[Token 经济学]]——即惊人的 Token 消耗速度和与之对应的高昂成本。
- **成本现状**：虽然未来架构（如 Rubin）有望降低推理成本，但目前 Agent 的“工资”（Token 消耗成本）仍高于人类，限制了大规模普及。

### 3. 行业共识
- **支持者**：
  - 尤洋（新加坡国立大学教授、潞晨科技创始人）
  - 胡翌霖（原清华大学科学史系副教授）
  - 王小川（百川智能创始人）
  - 胡延平（上海财经大学教授，最早于 2024 年提出此译法）
- **对比**：相比腾讯研究院提出的“模元”，“智元”更强调智能属性，获得了更多共鸣。
