# 国产Claude Cowork来了！阿里祭出首个桌面Agent，打工人彻底解放

**摘要**：本文报道了阿里推出的首个桌面 Agent 工具 [[QoderWork]]，被视为 Anthropic [[Claude Cowork]] 的国产竞品。文章详细介绍了 QoderWork 的核心功能（本地执行、自主规划、MCP 协议支持）及实测场景（文件整理、数据分析、PPT 生成），并提出了 2026 年从“聊天时代”进入“桌面智能体时代”的行业观点。

## 核心观点

- **行业转折**：2026 年被视为 AI 从“聊天时代”迈向“桌面智能体时代”的元年，AI 正式接管鼠标与键盘。
- **产品定位**：[[QoderWork]] 是阿里推出的本地化桌面 Agent，旨在通过 [[本地执行]] 解决隐私焦虑，并通过 [[MCP]] 协议和自定义 [[Skills]] 实现深度工具集成。
- **用户体验**：实测显示，QoderWork 在文件整理、万级数据处理、PPT 生成及行程规划等场景下表现高效，实现了“动动嘴就干活”的 [[工具自由]]。

## 关键信息

- **发布时间**：2026 年 1 月 31 日左右。
- **平台支持**：Mac 用户抢先体验，Windows 版本即将上线。
- **核心架构**：基于 [[MCP]]（模型上下文协议）构建，支持连接本地数据库和自定义 Python 脚本。
- **差异化策略**：与云端 Agent 不同，QoderWork 强调 [[本地执行]]，确保财务报表、代码等敏感数据不上云。

## 实测场景

1.  **文件整理**：自动将杂乱的下载文件夹分类归档为“个人知识库”。
2.  **数据处理**：快速处理上万条旅游行为数据，计算比例并生成 Excel 表格。
3.  **调研报告**：联网查询全球十大 AI 公司信息，整合生成深度调研报告。
4.  **文献引用**：自动提取科研文献信息并按规范生成参考文献列表。
5.  **PPT 生成**：根据主题（如光的折射）生成包含交互式 HTML 的完整 PPT。
6.  **行程规划**：抓取飞猪、携程信息，生成三亚旅行攻略并植入日历。
