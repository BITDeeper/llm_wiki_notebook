# 摘要
本文报道了面壁智能联合清华大学与 OpenBMB 社区发布的「端云两栖」智能体框架 EdgeClaw 及其硬件产品 EdgeClaw Box。文章指出，当前的 AI Agent（「龙虾」）市场陷入了「云端 API 派」（能力强但数据裸奔、成本高）与「本地模型派」（安全但能力弱）的二元对立。EdgeClaw 通过引入「隐私路由」机制和内置 MiniCPM 系列端侧模型，试图融合云端大模型的强推理能力与本地模型的数据安全特性，为 OPC（一人公司）群体提供一种既能断网干活又能保障核心数据安全的解决方案。

## 核心观点
- **市场痛点**：用户在云端 API（数据裸奔、高成本）和本地模型（能力受限）之间面临两难选择。
- **解决方案**：提出「端云两栖」架构，通过智能路由实现任务分级处理。
- **技术实现**：
  - **隐私路由**：根据数据敏感度（S1 公开 / S2 敏感 / S3 绝密）自动分配计算资源。
  - **本地引擎**：集成 MiniCPM 模型，处理绝密任务及高频低难度任务，降低 98% 的云端调用成本。
- **商业价值**：在投研、冷库盘点、数据质检、财务审计等场景中，显著提升了安全性与 ROI。

## 关键实体
- [[面壁智能]]：发布方，致力于端侧模型与 Agent 基础设施。
- [[edgeclaw]]：开源框架，核心为隐私路由与端云协同。
- [[edgeclaw-box]]：软硬一体机，预装 EdgeClaw 系统。
- [[mini-cpm]]：面壁自研的端侧模型系列，作为本地推理引擎。
- [[openbmb]]：清华大学与面壁智能共建的开源社区。

## 关键概念
- [[端云两栖]]：混合架构模式，结合云端与端侧优势。
- [[隐私路由]]：中间件机制，自动判断数据敏感度并分发任务。
- [[opc]]：一人公司，目标用户群体，对成本和安全极度敏感。
- [[断网干活]]：指在无网络环境下通过本地模型执行任务的能力。
