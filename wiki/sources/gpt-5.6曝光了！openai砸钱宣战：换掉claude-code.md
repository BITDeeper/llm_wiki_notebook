# GPT-5.6曝光了！OpenAI砸钱宣战：换掉Claude Code

新智元2026年5月14日报道，核心内容涵盖三大主题：

## GPT-5.6内部测试曝光
知名爆料人Leo（@kimmonismus）披露GPT-5.6开发进入全速阶段，首批检查点已启动内部测试，预计2026年6月正式亮相。Codex内部日志中发现GPT-5.6路由记录（ember-alpha、beacon-alpha等代号），表明Codex环境可能已在用GPT-5.6跑测试。GPT-5.5发布仅三周即被5.6曝光，迭代速度空前。

## Codex ultrafast模式即将上线
OpenAI将于本周四（2026年5月15日）上线ultrafast模式，在旗舰模型上实现2-3倍提速（非阉割版）。这是继/fast模式（1.5倍）和Cerebras芯片加速（15倍）后的第三次速度升级。同步推进的还有[[gpt-image-2]]的A/B测试更新，该模型在Image Arena排行榜以+242分断档领先。

## Codex vs Claude Code全面开战
Anthropic率先出招：推出Opus 4.7 Fast模式，6月15日起为付费用户提升50%编程额度。OpenAI迅速反击：30天内从其他平台迁移的企业可获得2个月免费Codex使用权（价值400美元）。3小时内2000名开发者联系OpenAI。[[sam-altman|奥特曼]]亲自下场宣称"Codex是最强AI编程产品"。

## AI自我加速飞轮
文章提出AI自我加速正反馈循环：GPT-5.3是首个"参与自身训练"的模型→GPT-5.5被85%员工使用→GPT-5.6由5.5深度参与开发。300万Codex周活用户的代码反哺训练，形成产品-模型闭环。奥特曼宣称OpenAI目标直指ASI。
