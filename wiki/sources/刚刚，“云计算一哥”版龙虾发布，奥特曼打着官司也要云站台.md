# 源：AWS 发布 Amazon Quick 与 OpenAI 战略合作

## 概述
本文报道了亚马逊云科技在 What’s Next with AWS 发布会上的重大举措，重点推出了桌面级 AI Agent [[Amazon Quick]]，并宣布与 [[OpenAI]] 达成战略合作，将其前沿模型接入 [[Amazon Bedrock]] 平台。

## 核心内容

### Amazon Quick：桌面级 AI Agent
- **定位**：被称为“龙虾”，运行在本地电脑的 AI Agent。
- **核心能力**：
  - **本地连接**：直接连接本地文件、日历、邮件和应用（无需上传）。
  - **跨生态整合**：打通 Slack、Teams、Outlook、Gmail、Salesforce、Asana 等工作流。
  - **知识图谱**：背后构建连接人、项目、决策和行动的图谱，实现上下文理解。
  - **主动执行**：具备主动提醒和准备材料的能力（如自动生成会议 PPT）。
- **应用层级**：
  - **个人**：安排会议、生成文档。
  - **团队**：创建共享工作空间。
  - **企业**：成为组织运转方式的一部分。

### AWS 与 OpenAI 的战略合作
- **背景**：Sam Altman 因官司未到场，通过视频站台；OpenAI 刚调整完与微软的合作即投奔 AWS。
- **合作内容**：
  1. **OpenAI 模型登陆 Bedrock**：客户可在 Bedrock 上调用 GPT-5.4 等模型，并享受 AWS 企业级安全控制（IAM、加密、日志）。
  2. **Codex 接入**：OpenAI 的编程工具登陆 Bedrock，支持企业团队使用。
  3. **Bedrock Managed Agents**：结合 OpenAI 模型与 AWS 基础设施（安全、审计、治理）的企业级 Agent 服务。

### Amazon Connect 的扩展
从单一产品扩展为四个垂直领域的 Agentic AI 解决方案：
- **Decisions**：供应链决策，利用 SCOT 基础模型压缩告警。
- **Talent**：大规模招聘，自动化面试安排与评估。
- **Customer**：客服系统升级，支持业务团队直接配置复杂流程。
- **Health**：医疗健康，自动化行政任务。

### 产品哲学：Humorphism
- **定义**：一种新的交互设计哲学，主张 Agent 应像人类队友一样互动（卡住时帮忙，专注时等待），而非传统的拟物化。

## 关键观点
- **Agent 是新的企业操作系统**：AWS 认为 Agent 正在深刻改变工作方式，不仅是效率工具，更是组织架构的一部分。
- **重设计而非简单迁移**：Matt Garman 强调，企业必须重新设计工作流才能获得 5-10 倍的效率提升，类比早期云计算的“Lift and Shift”失败经验。
- **基础设施的重要性**：最强 Agent 不仅需要聪明模型，还需要生产级基础设施（记忆、权限、审计）的支持。
