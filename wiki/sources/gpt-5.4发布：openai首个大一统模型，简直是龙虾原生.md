# GPT-5.4发布：OpenAI首个大一统模型，简直是龙虾原生

**摘要**：OpenAI 发布了 GPT-5.4，这是其首个原生支持“计算机使用”能力的通用模型。该模型集成了推理、编程、计算机交互、网页搜索等多种能力，并在多项基准测试中保持领先。文章详细介绍了 GPT-5.4 在深度知识工作、原生计算机操作和高阶编程三个方面的能力提升，以及其通过“工具搜索机制”实现的效率优化。

## 核心要点

- **大一统模型**：GPT-5.4 首次在单一模型中集成了推理、编程、计算机交互、网页搜索和百万级 Token 上下文，且未牺牲单项性能。
- **原生计算机使用**：模型可通过截图理解界面并执行鼠标/键盘操作，在 WebArena、OSWorld-Verified 等基准测试中表现优异。
- **效率优化**：引入“工具搜索机制”，在保持准确率的同时将 Token 使用量降低了 47%，旨在抵消 API 单价上涨带来的成本压力。
- **AI 数字员工定位**：OpenAI 将其定位为能独立负责整块业务的 Agent 系统，标志着从“辅助工具”向“生产力实体”的转变。
- **事实准确性提升**：事实错误概率比前代降低了 33%。

## 关键数据

- **GDPval**：83.0%（衡量 44 种职业知识工作能力）。
- **OSWorld-Verified**：75.0%（桌面操作任务，超过人类平均水平 72.4%）。
- **SWE-Bench Pro**：57.7%（略高于 GPT-5.3-Codex 的 56.8%）。
- **BrowseComp**：82.7%（Pro 版本达到 89.3%）。
- **Toolathlon**：54.6%（多工具调用能力）。
- **API 定价**：输入价格从 1.75美元涨至 2.5美元，Pro 版本输入价格高达 30美元。

## 行业影响

- GPT-5.4 的发布直接对标 Anthropic 的 Computer Use 和 Claude Code，加剧了 AI 编程和自动化领域的竞争。
- UI 交互正在取代繁琐的 API 对接，成为 AI 操作世界的主流路径。
- 高昂的 Pro 版本定价（如单次对话 560 元）引发了关于 AI 订阅制危机和分层定价的讨论。
