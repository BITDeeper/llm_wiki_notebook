# Claude强到不敢发的Mythos，被质疑用了字节Seed技术

## 概述

本文报道了 Anthropic 发布的神秘模型 [[Mythos]] 在特定任务上的异常表现，并分析其可能采用了 [[字节-seed-团队]] 提出的 [[循环语言模型]]（LoopLM）架构。文章指出，Mythos 在图搜索任务上的巨大优势、极低的 Token 消耗与较慢的速度，以及网络安全领域的突破，均符合循环架构的特征。

## 核心论点

### 架构猜测
社区猜测 Mythos 采用了字节 Seed 团队与高校（包括图灵奖得主 [[Yoshua Bengio]]）合作提出的循环语言模型架构。该架构允许模型在潜空间中进行多次迭代计算，而非像标准 Transformer 那样一次性生成结果。

### 关键证据

1.  **图搜索尖峰**：在 GraphWalks BFS（广度优先搜索）测试中，Mythos 得分 80%，远超 [[GPT5.4]] 的 21.4%。这种特定领域的巨大提升符合架构创新（[[归纳偏置]]）而非通用 [[scaling-law]] 的特征。
2.  **Token 与速度的矛盾**：Mythos 使用的 Token 数量仅为 Opus 4.6 的 1/5，但速度更慢且价格贵 5 倍。这符合循环模型在潜空间进行大量计算但不输出中间 Token 的特征。
3.  **网络安全表现**：Mythos 在 CyberGym 上发现大量零日漏洞。漏洞发现本质上是控制流图的遍历，再次指向图遍历能力。

## 技术背景：循环语言模型

字节 Seed 团队的论文指出，循环模型通过在潜空间“多转几圈”，实现了小模型（如 1.4B）碾压大模型（如 4B）的效果。

### 知识存储 vs 知识操作
-   **知识存储**：容量有限，约每个参数 2 bits，循环架构不会增加存储容量。
-   **知识操作**：包括多跳推理、程序执行、图搜索等。这类能力随循环步数和训练 tokens 指数级增长。

## 结论

虽然 Anthropic 未公开承认，但测试数据与循环架构的理论特征高度吻合。这表明下一代 AI 的进步可能不仅来自算力堆叠，更来自架构创新。
