# 300亿美金为AI新王加冕！Anthropic估值狂飙至3800亿，马斯克急了

## 摘要
报道了 [[Anthropic]] 完成 G 轮融资 300 亿美元，估值飙升至 3800 亿美元的消息。文章指出，Anthropic 的年化营收已达 140 亿美元，过去三年增长 10 倍，主要得益于其“企业优先”的战略布局。[[Claude Code]] 被确认为核心增长引擎，年化营收突破 25 亿美元。此外，文章还提到了新产品 [[Cowork]] 的发布及其对 SaaS 行业的潜在冲击，以及马斯克对 Anthropic 的嘲讽。

## 关键数据
- **融资规模**：300 亿美元（G 轮）。
- **估值**：3800 亿美元。
- **年化营收**：140 亿美元（过去三年增长 10 倍）。
- **Claude Code 营收**：25 亿美元（年初以来翻倍）。
- **GitHub 渗透率**：全球 4% 的公开提交代码来自 Claude Code。
- **企业客户**：《财富》十大公司中有 8 家正在使用 Claude。
- **用户重叠度**：79% 的 OpenAI 企业付费用户也在使用 Claude。

## 核心观点
1.  **企业级 AI 的胜利**：华尔街投资风向转向偏好具备企业落地能力的公司（如 Anthropic 和谷歌），而非单纯的“消费型 AI”。
2.  **Claude Code 的统治力**：不仅服务于程序员，还扩展到金融分析、销售、法务等领域，成为 Anthropic 商业化的基石。
3.  **SaaS 模式的颠覆**：[[Cowork]] 等产品的出现引发了关于“SaaS 末日”的讨论，AI 智能体正在取代传统软件的工作流。
4.  **竞争与争议**：马斯克嘲讽 Anthropic 的立场，称其为“Misthropic”（厌世/伪君子），反映了科技巨头之间的文化与政治冲突。
