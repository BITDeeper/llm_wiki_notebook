# 20亿美金落袋？这位90后华人把公司卖给Meta，成了汪滔的同事

## 概述
本文报道了 Meta 以 20-30 亿美元收购 AI 智能体初创公司 [[Manus]] 的交易细节。这是 Meta 历史上价值排名第三的收购。文章深入探讨了 [[Manus]] 创始人 [[肖弘]] 关于 AI 从 Chatbot（聊天机器人）向 Agent（智能体）转型的观点，以及 Manus 采用的“大模型 + [[云端虚拟机]]”技术架构。

## 核心观点

### 从 Chatbot 到 Agent 的范式转移
- **痛点**：传统的 Chatbot 只能提供信息，用户仍需手动执行操作。
- **解决方案**：[[AI Agent]] 能够直接操作软件、规划任务并处理错误，实现从“信息交付”到“结果交付”的转变。
- **案例**：Manus 在测试中曾尝试自主注册邮箱以发送询问邮件，展示了 Agent 的自主性。

### 技术路径：云端虚拟机
- **探索过程**：团队曾尝试基于浏览器内核开发 AI 浏览器，但发现浏览器是受限容器，无法处理复杂的长尾任务。
- **最终方案**：采用“大模型 + 云端虚拟机”架构，赋予 AI 一个完整的电脑环境（操作系统、文件系统、网络），使其能像人类工程师一样使用工具（如执行 git clone）。

### 行业影响：There is No Software
- **开发模式变革**：80% 的代码由 AI 生成，工程师转型为架构师和审查者。
- **SaaS 行业危机**：存量 SaaS 若不进行 AI 化改造，一半可能消失，因为 Agent 可以实时满足非标需求。

## 关键实体
- [[Meta]]：收购方，正在构建 AI 帝国。
- [[肖弘]]：Manus 联合创始人兼 CEO，将出任 Meta 副总裁。
- [[Javier Olivan]]：Meta 首席运营官，肖弘的汇报对象。
