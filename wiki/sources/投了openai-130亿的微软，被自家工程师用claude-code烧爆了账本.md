# 投了OpenAI 130亿的微软，被自家工程师用Claude Code烧爆了账本

新智元2026年5月22日发布的深度报道，揭示AI编程工具按Token计费模式正在制造企业级财务危机。

## 核心内容

报道聚焦两大标志性事件：

1. **微软强制断供Claude Code**：微软"体验+设备"部门（近10万工程师）被要求在6月底前停用[[claude-code]]，强制转向自家的[[github-copilot-cli]]。决策由财务部门主导，尽管工程线一致反馈生产力提升巨大。

2. **Uber AI预算崩溃**：Uber CTO Praveen Neppalli Naga内部备忘录披露，2026年全年AI预算仅4个月即耗尽。95%工程师月活使用AI工具，84%进入智能体编码模式，重度用户月成本达2000美元/人。

## 关键论点

- AI行业正从"订阅经济"不可逆地转向[[效用经济]]，按使用量计费成为新常态
- 过去半年全球AI软件有效价格上涨20%-37%
- GitHub已取消固定价格计划，全面转向按使用量计费
- 微软投了[[openai]]130亿美元，却要按Token向[[anthropic]]付费，形成讽刺性的竞品输血局面
- CFO正在从CTO手中接管AI采购决策权

## 叙事张力

报道揭示了AI生产力收益与成本之间的未解矛盾：工程师一致认可Claude Code的效率提升，但管理层因账单压力选择强制下线。文章将微软决策主要归因于成本，但"战略对齐"可能也包含对OpenAI投资保护和数据安全等考量。
