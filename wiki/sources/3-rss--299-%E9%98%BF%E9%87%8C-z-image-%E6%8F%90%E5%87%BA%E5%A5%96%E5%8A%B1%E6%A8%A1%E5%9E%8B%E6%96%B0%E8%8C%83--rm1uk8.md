# 阿里 Z-Image 提出奖励模型新范式：超越 OPD，将大模型推理能力蒸馏进单 token 分数分布

本来源记录了阿里巴巴 [[阿里巴巴-z-image团队|Z-Image 团队]]与 [[南开大学]]联合发布的一项视觉生成奖励模型技术突破。研究提出了 [[z-reward|Z-Reward]] 范式，旨在解决传统奖励模型在“判断能力”与“部署效率”之间难以兼顾的困境。

## 核心摘要

Z-Reward 提出了一种将大模型推理能力“内化”为单 token 分数分布的新方法。它指出，视觉生成的奖励模型不需要在部署时复现冗长的推理过程，而应将大模型的推理判断能力压缩为高效的分数分布输出。

该研究包含两个核心技术创新：
1. **教师模型训练 ([[gdso|GDSO]])**：提出分组直接分数优化方法，直接优化“分数分布”和“同 prompt 下的分数差距”，使大模型学会带推理的分布式打分。
2. **学生模型蒸馏 ([[risd|RISD]])**：提出推理内化分数蒸馏，学生模型不模仿教师的长推理链，而是用 KL loss 直接对齐教师的推理条件分数分布，推理时仅需输出 1 个 token。

## 关键发现与证据

- **性能逼近教师**：9B 学生模型（RISD）在 HPA 指标上达到 0.8864，非常接近 27B 教师（GDSO）的 0.8956。
- **效率碾压轨迹蒸馏**：相比需要输出约 750 个 token 的在线策略蒸馏（OPD），RISD 仅需 1 个 token 就取得了更高的 HPA 和 Margin HPA 得分。
- **实战优化效果**：作为强化学习优化信号应用于文生图模型后，在盲测中实现了 41.3% 的净人类偏好提升。

## 标注体系与维度

研究构建了面向文生图生产场景的细粒度标注体系，将评价拆分为四个关键维度：文本-图像对齐、真实感、美学和物理合理性。采用九档半分制（1.0 至 5.0）以捕捉细粒度差异，并设计了同 prompt 下的分数校准流程。
