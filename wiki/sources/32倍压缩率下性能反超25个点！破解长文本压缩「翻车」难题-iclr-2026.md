# 摘要

本文报道了阿里巴巴未来生活实验室入选 ICLR 2026 的研究成果——COMI 框架。该研究针对长文本压缩在高压缩率下性能断崖式下跌的问题，提出了基于 [[边际信息增益]]（MIG）的 [[粗到细压缩]] 策略。实验证明，在 32 倍压缩率下，COMI 在 NaturalQuestions 数据集上比次优基线高出近 25 个点，且通过去除噪声实现了“压缩即提纯”的效果，使压缩后的小模型性能反超直接输入全量上下文的大模型。

# 核心观点

## 现有方法的困境：信息内卷
现有的上下文压缩方法在处理长文本时，往往只关注 Token 与查询的“相关性”，忽略了 Token 之间的“多样性”。这导致在高压缩率下，模型保留了大量高度相似却重复的内容，陷入 [[信息内卷]]。这种冗余堆砌不仅浪费了宝贵的上下文窗口预算，还可能因为语义重复误导模型生成错误答案。

## 解决方案：COMI 框架
COMI 框架的核心在于引入了 [[边际信息增益]]（MIG）指标，将压缩决策从单维度的“相关性”升级为“相关性-冗余性”双维度权衡。

### 1. 边际信息增益 (MIG)
MIG 的计算公式为：`本单元与查询的相关性 - 与其他单元的最大相似度`。
这一指标既奖励与问题高度相关的片段，又惩罚与已选内容高度重复的片段，从而有效避免了信息冗余。

### 2. 粗到细压缩策略
- **粗粒度组重分配**：将长文本划分为等长片段，基于组间 MIG 动态调整各段的压缩率。高价值信息区获得更宽松的预算，而稀疏或重复区域则被大幅压缩。
- **细粒度 Token 融合**：在片段内部，根据 Token 级 MIG 进行加权融合。高 MIG Token 占主导权重，低 MIG Token 被稀释，避免了平均池化导致的关键细节丢失。

# 关键数据

- **性能反超**：在 32 倍压缩下，COMI（基于 Qwen2-7B）在 NaturalQuestions 上达到 49.15 的 EM 分数，比次优基线高出近 25 个点。
- **提纯效应**：在 NaturalQuestions 上，经过 32 倍压缩的 Qwen3-4B（F1 28.89）远超直接输入完整上下文的性能（16.90）。
- **效率提升**：端到端推理速度提升 2 倍以上，压缩阶段开销极小（NarrativeQA 任务中压缩耗时 2.76 秒）。

# 意义与影响

这项研究挑战了“保留越多信息越好”的传统直觉，证明了高质量的压缩本质上是“信息提纯”。它为大模型在有限显存和算力下的高效推理提供了新的技术路径，特别是在 RAG（检索增强生成）和长文档处理场景中具有重要应用价值。
