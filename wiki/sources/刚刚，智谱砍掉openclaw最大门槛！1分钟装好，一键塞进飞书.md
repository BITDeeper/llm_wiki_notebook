# 刚刚，智谱砍掉OpenClaw最大门槛！1分钟装好，一键塞进飞书

## 概述
本文报道了 [[智谱]] 发布 [[autoclaw]]（澳龙）的消息。作为 [[openclaw]] 的官方桌面封装版，AutoClaw 通过一键安装和 [[一键自动化配置]] 彻底解决了原版工具高昂的安装门槛，并内置了专为 Agent 场景设计的 [[pony-alpha-2]] 模型。

## 核心要点

### 降低门槛
- **原版痛点**：[[openclaw]] 原版安装流程极其复杂（Node.js 环境、命令行操作、API Key 配置等），催生了暴利的 [[代装产业链]]（湾区报价 $6000）。
- **AutoClaw 方案**：将其打包为桌面应用，实现“下载、双击、登录”即可使用，将上手时间从数天缩短至 1 分钟。

### 核心功能
- **飞书集成**：通过自动化脚本将复杂的 Webhook 配置简化为“一键配置”，实测 2 分半钟完成，使 Agent 能在移动端（手机/iPad）通过 [[飞书]] 随时待命。
- **模型热插拔**：支持在 [[glm-4-7-flash]]（免费）、GLM-5 及外部模型（DeepSeek, Kimi 等）间动态切换，解决了单次任务成本过高的问题。
- **技能扩展**：内置 50+ 技能，特别是 [[autoglm-browser-agent]]，相比原版浏览器自动化能力有显著提升。

### 技术亮点
- **Pony-Alpha-2**：智谱专为 [[agent场景化模型]] 打造的模型，解决了通用 LLM 在长链路任务规划和工具调用中“掉链子”的问题。

## 社会影响
- 智谱启动“小龙虾敲门计划”，志愿者进入社区免费帮普通人安装，标志着 AI Agent 工具从极客圈向大众普及的转折点。
