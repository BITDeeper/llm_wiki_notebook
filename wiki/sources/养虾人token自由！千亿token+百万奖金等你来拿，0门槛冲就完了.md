# 养虾人Token自由！千亿Token+百万奖金等你来拿，0门槛冲就完了

## 概述
本文报道了首届“中关村北纬龙虾大赛”的正式启动。该比赛旨在通过巨额奖金和算力（Token）激励，推动 [[openclaw]] 生态下的 AI 智能体（昵称“龙虾”）应用落地。文章强调了比赛的低门槛（0代码）、实际价值导向以及严格的安全规范。

## 核心内容

### 赛道设置
比赛分为三大赛道，覆盖不同应用场景：
- **学术龙虾**：关注“搞懂一件事”，如文献管理、实验报告生成。
- **生产力龙虾**：关注“把事情做成”，如自媒体运营、数字员工。
- **生活龙虾**：关注“把日子过好”，如日程管理、旅行规划。

### 评价标准
不比拼技术复杂度，核心评判标准是**实际价值**（解决问题、帮助他人、创造实效）。鼓励 [[龙虾+]] 形态（接入机器人、智能家居等硬件）。

### 资源与奖励
- **Token自由**：提供百亿/千亿级 Token 奖励，解决 API 调用成本痛点。
- **匿名模型**：引入 [[hunter-alpha]] 和 [[healer-alpha]] 两款未发布的匿名高性能模型，通过 [[openrouter]] 免费开放调用。
- **奖金池**：总奖金百万级，全场最佳可获得 20 万元 + 100 亿 Token。

### 安全规范
文章详细阐述了 [[openclaw]] 的安全理念，强调“安全是核心 Feature”而非事后修补。提出了“实时免疫系统”概念，包括：
1.  **实时行为监测**与**异常自动熔断**。
2.  **最小权限动态授予**。
3.  **数据安全**：严禁公网暴露，需做好权限隔离。
4.  **合规使用**：严格管理插件来源。

## 关键信息
- **比赛时间**：作品征集 3月11日-19日，评审 20日-21日，颁奖 22日。
- **主办方**：北京中关村学院、中关村人工智能研究院、AI商学院。
- **支持方**：北京中关村学院教育基金会。

## 意义
此次比赛标志着 AI 智能体开发从“技术炫技”向“价值落地”的转型，同时也展示了 [[openclaw]] 在经历此前安全事故后，对安全机制的重新定义和强化。
