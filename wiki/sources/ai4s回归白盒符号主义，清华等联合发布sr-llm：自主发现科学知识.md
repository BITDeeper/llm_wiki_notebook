# AI4S回归白盒符号主义，清华等联合发布SR-LLM：自主发现科学知识

## 概述
本文报道了清华大学、中国科学院自动化研究所等机构联合发布的 [[sr-llm]] 框架。这是一个融合大语言模型（LLM）与深度强化学习（DRL）的新型 [[符号回归]] 框架，旨在从数据中自主发现简洁、可解释的数学公式，代表了 [[ai-for-science]] 领域向 [[白盒符号主义]] 的回归。

## 核心内容

### 背景与挑战
- **黑箱困境**：传统神经网络虽然拟合能力强，但生成的模型难以解析，无法像牛顿发现万有引力定律那样提炼出简洁、普适的解析表达式。
- **符号回归的目标**：从数据中自动归纳出准确、简洁、可解释、具有泛化能力的数学表达式。
- **现有瓶颈**：数学表达式搜索空间巨大，真实数据充满噪声，传统方法（如遗传编程）容易陷入局部最优，难以兼顾精度与可解释性。

### SR-LLM 的技术架构
SR-LLM 将符号回归转化为“增量式生成”任务，利用 LLM 的推理能力引导强化学习搜索。其四大关键技术包括：

1.  **Radix 树存储**：将历史探索的公式压缩存储在前缀树中，节省内存并快速检索相似结构，避免重复探索。
2.  **双阶段强化学习搜索**：
    -   **第一阶段**：采用“风险寻求”策略，只奖励表现最好的公式，快速聚焦高潜力区域。
    -   **第二阶段**：切换到 Soft Actor-Critic (SAC)，利用经验回放跳出局部最优，稳健逼近全局解。
3.  **LLM 驱动的检索增强生成**：设计“反思模块”，将 DRL 探索到的优秀结果聚类到外部知识库中，指导后续搜索。
4.  **LLM 驱动的知识提取和利用**：利用 LLM 的语义理解能力，结合外部知识库（专家模型、历史优秀表达式），动态构造提示词，引导模型生成更合理的符号组合。

### 实验结果与验证
- **基准测试**：在 Fundamental-Benchmarks 和 Feyman-Benchmarks 上显著优于 PSRN、PhySO 等主流方法。
- **鲁棒性**：在含噪数据下保持高鲁棒性，不易过拟合。
- **可解释性**：生成的公式结构简洁、物理意义明确，支持多目标权衡（精度、专家相似度、复杂度）。
- **跟驰模型发现**：在真实 NGSIM 轨迹数据上，SR-LLM 不仅复现了经典 [[跟驰模型]]（如 IDM），还发现了拟合性能更优、物理意义更清晰的新模型，特别是在处理突发速度变更等边缘情况时表现优于经典模型。

### 未来展望：自举范式
研究团队致力于发展类似 [[AlphaZero]] 的自举范式：在完全无先验知识的条件下，通过随机探索与自我优化，让系统自主构建初始知识库，并逐步演化出可解释的科学规律。

## 关键意义
- **AI 角色转变**：LLM 不仅是解释知识的教师，更是科学发现的智能协作者和独立探索者。
- **白盒优势**：解决了深度学习的“黑箱”问题，输出人类可读、可验证、可推广的数学表达式。
- **跨学科潜力**：在交通流领域的成功验证了其在物理、化学等广泛学科领域的应用潜力。
