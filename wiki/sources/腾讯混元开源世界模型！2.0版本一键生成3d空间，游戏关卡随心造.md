# 腾讯混元开源世界模型！2.0版本一键生成3D空间，游戏关卡随心造

## 概述
本文报道了腾讯混元团队发布的开源多模态3D世界模型 [[HY-World 2.0]]。该模型标志着AI能力从“对话”、“画图”进化至“造世界”，能够直接生成可编辑、可交互的3D资产（Mesh/3DGS），并支持导入Unity/UE等主流游戏引擎。

## 核心功能
1.  **世界生成**：支持文、图、视频多种模态输入，一键生成风格多样的可漫游3D世界（如日式RPG地牢、绘本小木屋）。
2.  **世界重建**：基于 [[WorldMirror 2.0]] 架构，支持任意尺寸图像与视频输入，构建高精度 [[数字孪生]] 空间，可应用于装修预览、城市规划等。
3.  **全景图生成**：通过 [[HY-Pano-2.0]] 模型，无需相机元数据即可从普通图片生成360度全景图。

## 技术亮点
-   **混合表征**：与 WorldLabs 的 [[Marble]] 模型不同，HY-World 2.0 输出 3DGS 与 Mesh 的混合表征，支持物理碰撞，允许角色在场景中真实行走。
-   **空间智能体**：结合 VLM 与 NavMesh 技术，智能规划漫游轨迹，理解空间语义，避免穿墙。
-   **空间一致性**：通过记忆机制和后训练算法，确保多视角生成（NVS）在几何和视觉上的完美衔接，解决画面衰减问题。

## 行业意义
HY-World 2.0 填补了生成内容与游戏/仿真工作流之间的鸿沟，为 [[具身智能数据困境]] 提供了潜在的解决方案，通过快速生成3D场景缓解仿真数据匮乏问题。
