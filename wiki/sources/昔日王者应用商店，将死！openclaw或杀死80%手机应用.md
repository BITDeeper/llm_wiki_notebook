# 昔日王者应用商店，将死！OpenClaw或杀死80%手机应用

## 摘要
本文是对 [[openclaw]]（原 Clawdbot）创始人 [[peter-steinberger]] 的深度访谈报道。文章探讨了 OpenClaw 作为一种高度自主的 AI 智能体，如何通过直接操控操作系统（文件、终端、浏览器）来执行复杂任务。Peter 提出了“[[氛围编程]]”的概念，并预言随着通用 AI 智能体的普及，手机中 80% 的单一功能 App 将面临消亡。

## 核心观点

### 1. AI 作为“怪异朋友”
Peter 将 OpenClaw 定义为不仅仅是工具，而是一个“住在电脑里的怪异朋友”。它具有极高的自主性（“极度足智多谋”），能够在未经硬编码的情况下自主解决问题（例如自动寻找 FFmpeg 和 API Key 进行语音转码）。

### 2. 应用商店的消亡
文章核心论点认为，传统的单一功能 App（如记账、健身、值机）将被通用 AI 智能体取代。理由包括：
- **交互优势**：对话界面（CUI）比点击图形界面（GUI）更自然。
- **上下文记忆**：AI 拥有跨 App 的记忆和偏好设置，无需重复配置。
- **功能整合**：一个 Agent 即可完成原本需要多个 App 完成的任务。

### 3. 极简主义工程哲学
Peter 痛批当前的 Agent 架构（如 MCP、编排器、子代理）为“电子垃圾”。他主张：
- 无需复杂的计划模式，直接与模型对话。
- 无需 MCP 协议，直接使用 CLI（命令行界面）。
- 强调“[[尖刺状聪明]]”，即 AI 能力分布不均，需要人类的直觉和审美（“品位”）介入循环。

### 4. 编程门槛的消解
OpenClaw 使得非技术人员（如前律师）也能通过自然语言提交 Pull Request。编程从“技能”转变为“想法”和“脑洞”的竞争。

## 安全性风险
文章提到了 OpenClaw 在 ZeroLeaks 测试中的糟糕表现：
- 安全评分：2/100。
- 信息提取成功率：84%。
- [[提示注入]] 攻击成功率：91%。
- 系统提示词在第一轮对话中即泄露。

这反映了赋予 AI 极高权限（“极度足智多谋”）与系统安全性之间的尖锐矛盾。

## 关键案例
- **摩洛哥修 Bug**：Peter 在度假时仅通过转发推特截图，OpenClaw 便自动读取、理解、修复代码并回复推特。
- **自主语音处理**：OpenClaw 在未预设代码的情况下，自主识别音频格式并调用工具完成转码。
- **生活助理**：用户利用 OpenClaw 进行家庭记账、健身监控、甚至管理家族企业的库存和发票。
