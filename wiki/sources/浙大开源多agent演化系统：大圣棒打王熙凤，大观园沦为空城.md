# 浙大开源多Agent演化系统：大圣棒打王熙凤，大观园沦为空城

## 概述
本文报道了浙江大学高云君、毛玉仁团队开源的 [[openstory]] 多智能体演化叙事系统。该系统通过构建《红楼梦》数字孪生沙盒，展示了 [[异质智能体]]（如孙悟空）介入后引发的 [[逻辑涌现]] 与系统性崩溃，揭示了 [[多智能体演化]] 中记忆与共识的脆弱性。

## 核心发现
- **系统脆弱性**：单一强力变量的暴力介入（即便初衷是正义的）会导致精密社会系统的生态彻底坍塌。
- **共识崩溃机制**：共享记忆的更新（如“孙悟空滥杀无辜”）能瞬间打破群体共识，导致所有 Agent 安全阈值跌破，触发集体逃离。
- **逻辑涌现**：复杂结局（大观园变为空城）并非预设脚本，而是由底层智能体交互自然产生。

## 关键实验：逻辑冲击
1. **变量引入**：将具备高武力值与正义感的 [[齐天大圣]] Agent 置入大观园。
2. **触发点**：当 [[王熙凤]] 的“贪戾”触发孙悟空的判定阈值时，物理攻击动作被触发。
3. **连锁反应**：王熙凤被物理移除 -> 系统广播“滥杀无辜”记忆 -> 所有 Agent 恐惧权重覆盖日常逻辑 -> 触发“逃离”动作 -> [[大观园]] 沦为空城。

## 技术架构
- **数字孪生**：1:1 还原大观园地理拓扑关系，支持上帝视角观察与实时交互。
- **记忆模块**：支持全园广播与连锁更新，是系统共识形成与崩溃的核心。
- **行为规划**：Agent 根据 Profile 与环境输入实时规划行动，支持物理攻击与逃离等复杂行为。

## 未来方向
团队计划构建“西部世界”剧场，探索智械觉醒与系统失控的终极实验，进一步测试多智能体协作的边界。
