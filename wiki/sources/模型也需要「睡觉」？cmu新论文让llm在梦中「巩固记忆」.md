# 模型也需要「睡觉」？CMU新论文让LLM在梦中「巩固记忆」

## 摘要

本文报道了[[卡内基梅隆大学]]联合[[马里兰大学]]发表的一篇论文《Language Models Need Sleep》，提出了一种受动物睡眠中[[记忆巩固机制]]启发的全新方法。该方法通过在上下文窗口填满时让模型进入"睡眠"状态，执行多次[[离线递归前向传播]]，将短期上下文转化为[[快速权重]]中的持久记忆，从而在不增加推理延迟的前提下显著提升长上下文推理能力。

## 核心内容

- **问题背景**：业界长期追求扩大上下文窗口（128K→1M），但单纯增加窗口大小导致 KV Cache 臃肿、显存消耗剧增、推理变慢，且无法真正转化为长期记忆。
- **仿生学灵感**：借鉴神经科学中海马体 replay 机制——动物在睡眠期间将短期记忆巩固到皮层突触权重中。
- **技术方案**：模型分为"醒着"阶段（正常推理）和"睡眠"阶段（离线递归计算），通过迭代更新 SSM 模块中的快速权重来内化记忆。
- **实验结果**：在[[gsm-infinite]]数学推理基准上，增加睡眠循环次数 N 对复杂题目（6步、8步运算）的准确率提升最为显著。
- **局限性**：训练成本随 N 线性增长，可能导致训练不稳定；目前仅在受控合成任务和中等规模模型上验证。

## 关键数据
