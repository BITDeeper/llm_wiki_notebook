# 机器人为什么需要世界模型？世界顶尖机构联合综述震撼发布

## 核心内容

本文是对世界模型在机器人学习领域应用的系统性综述，由 [[南洋理工大学MARS-Lab]] 牵头，联合全球八所顶尖高校及 Microsoft 完成。

### 核心论点

1. **[[机器人世界模型]] ≠ 视频生成模型**：机器人世界模型的核心问题不是"能不能想象未来"，而是"想象出的未来能否用于控制"。必须具备[[动作一致性]]下的因果一致性。
2. **[[vla-视觉-语言-动作]] 的局限性催生世界模型需求**：VLA 模型虽在跨任务泛化上有潜力，但缺少对未来状态变化的显式预判，无法应对接触、遮挡、长时序依赖等真实物理挑战。
3. **架构路线尚未收敛**：解耦式、单骨干、MoE/MoT、统一 VLA、Latent-space 五大路线各有优劣。
4. **评测标准需要根本转变**：从开环视觉保真度转向[[closed-loop-task-utility|闭环任务效用]]。

### 五大架构路线

| 路线 | 代表工作 | 特点 |
|------|----------|------|
| 解耦式（预测未来再恢复动作） | UniPi、VidMan、Vidar、Gen2Act | 模块清晰但存在接口误差 |
| 单骨干紧耦合 | UVA、UWA、VideoVLA、Cosmos Policy | 预测和控制在同一模型内共同发生 |
| MoE/MoT 专家混合 | Motus、LingBot-VA、BagelVLA | 保留模态专门能力，通过交互实现融合 |
| 统一 VLA | GR-1、WorldVLA、DreamVLA、UniVLA、CoWVLA | 将预测目标内化到 VLA 训练中 |
| Latent-space 建模 | — | 在隐空间进行预测，提升推理效率 |

### 三大核心能力

- **Foresight（前瞻预测）**：在执行前预测动作后果
- **Imagination-driven Planning（想象驱动规划）**：通过想象 rollout 比较候选行为
- **Data Amplification（数据扩增）**：通过合成轨迹改善策略学习

### 未来挑战

- [[动作一致性]]：模型必须准确反映动作带来的状态变化
- 推理效率：视频扩散模型计算成本高，需探索 latent-space prediction 等方案
- [[物理grounding]]：需融合本体感觉、力觉、触觉和结构化几何表示
- 神经世界模型与传统规划控制方法的结合
