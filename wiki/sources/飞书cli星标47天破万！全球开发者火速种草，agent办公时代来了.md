# 飞书CLI星标47天破万！全球开发者火速种草，Agent办公时代来了

新智元2026年5月15日发布的报道，记录了[[飞书cli|飞书CLI]]在GitHub上47天星标破万的现象，分析了CLI作为[[cli作为agent操作界面|Agent操作界面]]翻红的技术原因，以及飞书作为[[agent工作空间|Agent工作空间]]的战略定位。

## 核心内容

- **数据亮点**：飞书CLI于2026年3月28日开源，当天Star 1000+，47天后破万；668个fork，50+外部贡献者，32个版本迭代，新增100+项能力。
- **技术架构**：三层命令架构（Shortcut / API Commands / Raw API），覆盖17个业务域、200+命令、2500+端点。
- **开发者案例**：Intent公司CEO陈春宇的决策复盘、张昊的[[noteloom]]知识工作流工具、Daniel的[[pokoclaw]] Agent工作系统。
- **行业背景**：2026年3月底国内多家头部办公平台同期开源CLI，飞书凭借开放广度和深度拉开差距。
- **社区生态**：[[openclaw]]热潮推动大量开发者自发涌入飞书生态，OpenClaw中文社区创始人杨明锋证实这一趋势。
