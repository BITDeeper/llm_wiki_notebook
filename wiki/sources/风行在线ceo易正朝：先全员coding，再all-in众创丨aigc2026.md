# 风行在线CEO易正朝：先全员Coding，再All in众创丨AIGC2026

## 来源概述

本文为风行在线CEO [[易正朝]]在2026中国AIGC产业峰会（由[[量子位]]主办）上的演讲实录。易正朝以风行三年AI转型的实践为基础，提出了五个核心战略选择，核心论点是：**AI编程是比AI视频更基础的企业转型基础设施**，而**众创是比Agent更强的核心杠杆**。

## 核心论点

1. **AI编程是公共基础设施**：风行作为视频公司，三年AI编程改造先于一年多的AI视频渗透，利润增长超10倍主要归功于前者。
2. **非工程师赋能优先**：非工程师离业务最近，在确定性高的业务升级中能产生更直接的效率提升。
3. **面向任务而非面向岗位**：个人提效若无组织适配则是灾难，需从岗位分工转向任务切片。
4. **众创是核心杠杆**：80% Token补贴+50%以上分账，撬动50万创作者生态。
5. **AI放大自嗨的警示**：AI降低执行门槛后容易沉迷，解药是"交付结果"。

## 五大战略选择

1. 坚信AI，不碰模型——卡位中间层
2. AI漫剧不是AI视频的全部（占比不到10%）
3. 成于AI编程——全员Coding
4. 放大组织能力——面向任务设计
5. 众创是核心杠杆——撬动群体智慧
