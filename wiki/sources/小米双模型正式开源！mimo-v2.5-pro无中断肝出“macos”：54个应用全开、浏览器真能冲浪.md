# 小米双模型正式开源！MiMo-V2.5-Pro无中断肝出“macOS”：54个应用全开、浏览器真能冲浪

## 概述
本文报道了小米 AI 团队发布的 MiMo-V2.5 系列模型，重点介绍了旗舰 Agent 模型 [[mimo-v2.5-pro]] 的开源及其在长程任务处理、模糊指令遵循和 Token 效率方面的突破性表现。

## 核心要点

### 模型性能与开源
- **国际顶尖水平**：[[mimo-v2.5-pro]] 在 Coding Agent、SWE-Bench Pro 等基准测试中成绩逼近 [[claude-code]] (Opus 4.6) 和 GPT-5.4，超越 Gemini 3.1 Pro。
- **全家桶开源**：包含 Pro 旗舰 Agent、全模态基座、TTS 语音合成、ASR 语音识别四大模型，权重全量开放。
- **标配 1M 上下文**：全系模型标配 1M 上下文窗口。

### 关键技术突破
1.  **长程任务稳定性**：
    -   能够稳定支撑超千次工具调用的长周期任务。
    -   实测案例：4.3 小时内无中断、无人类接管完成北大 [[北大-sysy-项目]]（完整编译器编写），词法分析、语法分析、中间代码生成、RISC-V 后端、性能优化全包，获得满分。
    -   实测案例：4 小时内复刻类 macOS 桌面系统，包含 68 个组件、54 个原生应用、完整窗口状态机及浏览器内核。

2.  **极高的 [[token-效率]]**：
    -   在 [[claweval]] 标准 Agent 任务中，仅用约 7 万 Token 达到 64% 的 Pass³ 通过率。
    -   相比竞品（普遍 12-18 万 Token），节省了 40%-60% 的成本。

3.  **[[模糊指令遵循]]**：
    -   能够理解非结构化、非精确的自然语言指令。
    -   案例：仅凭“山野风格、治愈系、逃离城市”等大白话描述，自主完成配色、字体、动效设计，生成高完成度的数字手账本。

### 语音能力
-   **TTS**：支持文本描述造音色、零样本克隆，无需参考音频即可生成指定声线。
-   **ASR**：达到中英 SOTA 水平，支持粤语、川语、吴语、闽南语识别及带伴奏歌词转写。

### 商业策略与生态
-   **降价普惠**：Pro 版倍率从 4x 降至 2x，标准版从 2x 降至 1x；1M 和 256K 采取同等 Credit 倍率。
-   **夜间折扣**：北京时间 00:00~08:00 计费打 8 折。
-   **[[mimo-orbit]] 计划**：
    -   百万亿 Token 创造者激励计划（免费发放）。
    -   面向全球新兴 Agent 框架提供限免接入及技术支持。

## 实测案例细节
-   **类 macOS 系统**：基于 React 18+TypeScript+Zustand+Tailwind CSS 构建，实现了 Dock 栏缩放、Spotlight 搜索、窗口管理（拖拽、缩放、焦点切换、z-index 管理）及 Traffic Lights 逻辑。
-   **3D 像素风农场游戏**：自主完成 3D 场景搭建、作物生长系统、天气循环、玩家交互逻辑及商店闭环。
-   **语音辩论**：TTS 模块一人分饰三角（理性女生、夜市老板、吃货少年），音色不串戏。

## 意义
小米在 4 个月内从入场到跻身开源第一梯队，通过“速度+实力+诚意”（快速迭代、顶尖能力、真金白银补贴）的组合拳，试图在由国际巨头主导的 AI 生态中站稳脚跟。
