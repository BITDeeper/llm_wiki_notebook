# 源文件摘要

本文报道了 2026 年初 [[Anthropic]] 与 [[OpenAI]] 之间激烈的市场与政治博弈。[[Anthropic]] 在商业上取得巨大成功，年化收入（ARR）飙升至 **200亿美元**，全美市场份额接近 **70%**，其编程工具 [[Claude Code]] 贡献了 25 亿美元收入，并占据了全球 GitHub 公开代码提交的 4%。然而，由于坚持 AI 安全准则，[[Anthropic]] 被美国国防部长 [[Pete Hegseth]] 定性为“供应链风险”，遭到五角大楼封杀，导致其合作伙伴 [[Palantir]] 被迫终止与其合作。

与此同时，[[OpenAI]] 虽然填补了政府合同的空缺，但因与军方的合作引发了严重的用户信任危机。报道指出，已有约 **250万** 用户参与了 [[QuitGPT]]（抵制 ChatGPT）运动，通过退订表达不满。文章揭示了 AI 行业在商业利益、政治立场与安全准则之间的复杂博弈。

## 关键数据点

- **Anthropic ARR**: 接近 200 亿美元（2周内暴涨 50 亿）。
- **市场份额**: Claude 在美国市场份额接近 70%（OpenAI 约 30%）。
- **Claude Code**: 运行年收入 25 亿美元，占 GitHub 公开代码提交的 4%。
- **用户流失**: 约 250 万人参与 QuitGPT 抵制运动。
- **企业渗透**: 财富 10 强企业中有 8 家使用 Claude。
