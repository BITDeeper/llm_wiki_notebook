# 16亿Windows用户，一夜冲进Agent时代！

新智元关于微软Build 2026大会的深度报道。报道覆盖了纳德拉主题演讲的全部核心发布：Windows正式转型为Agent操作系统，[[openclaw]] 原生入驻Windows生态，[[copilot]] 升级为四合一超级应用，[[scout]] 成为首个企业级Autopilot Agent，[[苏莱曼]] 发布七款自研[[mai系列模型|MAI模型]]，以及[[黄仁勋]]连线定义"PC进化为个人AI"。

核心叙事：微软不再是OpenAI模型的分销商，已具备从芯片到模型到操作系统到应用的AI全栈能力。16亿Windows用户的桌面正在从文件夹和应用图标，变为一支随时待命的Agent团队。

关键产品发布：
- [[mxc]]（Microsoft执行容器）：操作系统级Agent沙盒，四档隔离机制
- [[copilot]] 四合一：Chat+Cowork+Code+Autopilots，今夏上线
- [[scout]]：首个企业级Autopilot Agent，拥有独立身份和许可证
- [[mai系列模型]]：七款全模态自研模型，零蒸馏训练
- [[mai-thinking-1]]：推理模型，SWE-bench Pro 53%追平Opus 4.6
- [[mai-code-1-flash]]：5B编码模型，已在VS Code中运行
- Surface RTX Spark+：128GB统一内存，本地三模型并跑
