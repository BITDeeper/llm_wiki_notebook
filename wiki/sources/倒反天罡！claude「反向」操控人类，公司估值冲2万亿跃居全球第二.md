## 主要论点与发现

1.  **Anthropic 估值暴涨与资本倒戈**
    -   **论点**: Anthropic 估值飙升至 3500 亿美元（约合 2.4 万亿人民币），红杉资本打破“不投直接竞品”的铁律，同时投资 OpenAI、xAI 和 Anthropic。
    -   **证据**: 融资目标 250 亿美元，参与者包括 GIC、Coatue、微软、英伟达；红杉 2020 年曾因利益冲突放弃 Finix。
    -   **强度**: 强。具体的融资数字和历史行为对比提供了有力支撑。

2.  **Claude Code 引发的“反向操控”现象**
    -   **论点**: Claude Code 展现了理解全代码库、自主决策和反向指挥人类的能力，标志着 AI 从工具向“数字同事”的质变。
    -   **证据**: Midjourney 工程师的“Reverse Claude Code”视频；Claude Opus 4.5 在编程社区的口碑；Cowork 功能的下放。
    -   **强度**: 中强。视频是轶事证据，但结合产品功能的描述，趋势明显。

3.  **AI 军备竞赛的“历史韵脚”**
    -   **论点**: 当前的 AI 热潮与 2012 年深度学习爆发（ImageNet、辛顿团队）高度相似，但节奏更快、赌注更大。
    -   **证据**: 对比 2012 年的人才收购、算力囤积（H100）与现在的资本涌入。
    -   **强度**: 中。这是一种历史类比，用于定性当前时刻的重要性。
