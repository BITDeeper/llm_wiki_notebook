# 百度GenFlow 4.0发布：Office三件套全包了，还能养「牛马虾」

## 概述
本文报道了百度于2026年4月27日发布的 [[genflow-4-0]] 通用智能体系统。该版本全面升级了 [[office-agent]] 能力，并融合了 [[openclaw]] 框架，推出了面向个人和团队的「[[niu-ma-xia]]」体系，旨在通过 AI 重构办公流程与团队协作模式。

## 核心更新

### Office Agent 全面升级
GenFlow 4.0 将传统需要数天的办公流程压缩至分钟级，具体能力包括：
- **PPT Agent**：提供“专业模式”（基于 HTML，结构清晰）和“创意模式”（基于图片，高颜值），并支持一键美化。
- **Excel Agent**：支持自然语言处理海量数据，自动解析提取表格，一句话完成从计算到可视化的全过程。
- **Word Agent**：依托百度文库数据，支持自动抓取行业数据、生成图表及万字级报告的自动排版与润色。

### 「牛马虾」体系
百度网盘全面兼容 [[openclaw]] 能力，推出了针对不同场景的 Agent 体系：
- **个人虾**：主打“零门槛”和“云端部署”。不占本地内存，7×24小时待命，支持一键整理网盘文件及迁移其他平台的 Agent。
- **团队虾**：定位为“[[数字员工]]”。支持多 Agent 并行协作（如修图、分发、财务处理），并引入 [[团队记忆]] 功能，将历史经验沉淀为企业知识库。

### 安全与基础设施
- 针对 [[openclaw]] 的部署，百度网盘建立了单独的同步盘目录隔离，确保数据在安全可控环境内流转。
- 百度文库（9700万+ AI 月活）与百度网盘（10亿+ 用户）在 AI 基础设施上实现深度融合。

## 意义
GenFlow 4.0 标志着百度从单一工具辅助向“超级个体”和“超级组织”的演进。通过将网盘转化为 Agent 的托管平台，百度正在探索云存储与 AI 服务捆绑的新生态模式。
