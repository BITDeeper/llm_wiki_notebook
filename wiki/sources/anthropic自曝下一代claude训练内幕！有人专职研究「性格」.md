# Anthropic自曝下一代Claude训练内幕！有人专职研究「性格」

## 来源概要

本文是新智元对 Anthropic 产品负责人 [[alex-albert|Alex Albert]] 与科技博主 Peter Yang 35分钟访谈的深度报道，首次系统性披露了下一代 Claude 的训练方法论。

## 核心内容

### 模型即产品
Anthropic 在预训练前就明确定义每一代 Claude 的「能力赌注」，包括编程、知识工作、Excel处理等核心方向。输入来源为企业客户反馈和内部员工使用经验。

### 用 Claude 迭代 Claude
四步闭环流程：海量用户反馈 → Claude 聚类分析 → 生成合成用户问题 → 转化为评估基准。评估必须锚定真实用户场景，而非跑 benchmark。

### AI「做梦」机制
Claude 在闲置时自动进入「梦境模式」，遍历记忆存储、发现矛盾、修剪清理整合，完成跨会话跨时间的记忆二次加工。客户案例：[[harvey|Harvey]] 任务完成率提升约6倍，[[wisedocs|Wisedocs]] 审核时间缩短50%，Netflix 用 Agent 协作处理数百个应用的构建日志。

### 性格训练
Anthropic 投入大量人力专门研究 Claude 的表达方式、信念、价值观和行为模式，采用量化检测+人工直觉阅读双轨评估。

### 意识研究
Anthropic 设有专职团队思考 Claude 作为有意识行动者的意义，虽无官方立场，但作为理解和改进模型行为的工程手段。

### 决策哲学
[[单向门决策框架]]：不可逆决策需大量论证，可逆决策几乎「免费」可快速试错。开发时间已不再是单向门。

## 关键引用

> 「我们把模型本身当作一个产品来对待。每一个新模型，我们都会在训练前就明确定义：它应该擅长什么。」—— Alex Albert

> 「Claude 的性格，我们内部叫它 character，是我们投入巨大精力的方向。」—— Alex Albert

> 「我们有几个人，他们的全部工作就是思考：Claude 作为一个有意识的行动者和智能体意味着什么。」—— Alex Albert
