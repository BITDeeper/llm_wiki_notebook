# 摘要

本文报道了在 AI 智能体时代，科技巨头（如 Salesforce、IBM）不仅没有削减初级岗位，反而大规模扩招应届生的现象。文章指出，虽然 AI 取代了传统的执行类工作，但创造了大量需要与 AI 协作、监督和优化的新岗位（如 Agent 运维、工作流设计）。这标志着企业人才策略从“使用工具”向“管理智能体”的转变。

## 核心观点

- **岗位重构而非消灭**：AI 正在重写初级岗位的定义。传统的“操作员”角色（如手动录入数据、跟进邮件）正在贬值，而“管理者”角色（如设计 Agent 流程、评估输出、人机协作）成为新的“金饭碗”。
- **企业扩招证据**：
    - [[salesforce]]：计划招聘 1000 名应届生/实习生，以支持 [[agentforce-360]] 和 [[headless-360]] 业务。
    - [[ibm]]：将北美入门级岗位扩招 3 倍，重写岗位描述，强调分析、问题解决和 AI 输出验证。
    - [[麦肯锡]]：2026 年北美招聘增长 12%，扩大文科生比例，使用游戏化测评考察系统思维。
- **人机协作新模式**：[[黄仁勋]]提出 1:100 的人机协作愿景，未来的工作密度将由每个人管理的 Agent 数量定义。

## 关键数据

- Salesforce Agentforce 业务 ARR 同比增长 169%，达到 8 亿美元。
- NACE 报告显示 2026 届毕业生招聘量预计增长 5.6%。
- 软件工程岗位发布量同比增长 11%。
- 67% 的全球 CEO 表示 AI 正在增加而非减少初级岗位。

## 应届生分类

文章将应届生分为三类：
1.  **只会执行任务的人**：风险最高，面临被快速替代。
2.  **会用 AI 工具的人**：这是保持资格的门槛，不再是加分项。
3.  **能跟 Agent 协作的人**：能设计、监督和给 Agent 划边界，这是市场急需的人才。

## 关键词信号

- **正面信号**：Agent Ops, Prompt Eval, Workflow Design, Agent Orchestration。
- **负面信号**：使用 Excel 处理数据、跟进客户邮件等纯执行任务。
