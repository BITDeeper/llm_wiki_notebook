# 并购激励金都不要了？全程踩中AI Coding，Windsurf核心工程师离开DeepMind

## 摘要

本文报道了 AI Coding 赛道核心工程师 [[ronak-malde]] 离开 [[google-deepmind]] 的消息。Ronak Malde 过去两年几乎踩中了 AI Coding 最热的一条主线：从 [[codeium]] 起步，参与推出 [[windsurf]] IDE，训练前沿 [[agentic-coding|智能体编程]] 模型 [[swe-1]]；随后随团队进入 DeepMind，参与发布 [[antigravity]] 并为 Gemini 3 作出贡献。值得注意的是，他不仅离开 DeepMind，还放弃了随 Google 收购 Windsurf 而来的并购激励金（acquisition money），暗示即将启动新的创业项目。

## 核心内容

### 职业轨迹
- **Codeium/Windsurf 时期**：参与从 Codeium Extension → Windsurf IDE → SWE-1 的完整演进
- **DeepMind 时期**：随 Windsurf 团队加入，参与发布 Antigravity（含 CLI 版本），为 Gemini 3 作贡献
- **离职**：放弃并购激励金，以"More soon"暗示新项目

### 关键交易背景
2025年7月，Google 以 24 亿美元许可费获得 Windsurf 部分技术的非独家使用权。Windsurf CEO Varun Mohan、联合创始人 Douglas Chen 及部分 R&D 团队加入 DeepMind，方向为 Agentic Coding 与 Gemini 项目。这属于[[技术许可式收购]]，而非传统全资收购。

### Ronak Malde 的三条心得
1. **找到真正值得攀登的山**：定期退后判断是否在爬正确的山，避免被错误 benchmark 牵引
2. **快不只是拼命工作**：对未来6个月做出具体判断→形成共识→砍掉不重要的事
3. **硅谷很小**：AI Coding 赛道人员流动形成高密度网络

### 人才流动网络
Windsurf 团队拆分后成员去向：DeepMind、Cognition、Thinking Machines、OpenAI、xAI、[[cursor]]、各类高速创业公司。

## 信号意义
核心工程师放弃大厂并购激励金选择离开，预示 AI Coding 赛道人才正从大厂回流至创业生态，下一轮创新可能来自新公司而非巨头。
