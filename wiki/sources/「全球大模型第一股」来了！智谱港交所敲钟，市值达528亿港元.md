# 「全球大模型第一股」来了！智谱港交所敲钟，市值达528亿港元

## 摘要
2026年1月8日，[[智谱华章]]（02513.HK）正式在香港联合交易所挂牌上市，成为全球首家以通用人工智能（AGI）基座模型为核心业务的上市公司。首日市值达528亿港元，公开发售获1159倍超额认购。本文详细记录了智谱的上市历程、核心技术 [[GLM]]、商业化模式 [[MaaS]] 及其市场地位。

## 核心数据
- **上市表现**：发行价116.2港元，首日开盘120港元，市值528.28亿港元。
- **认购热度**：香港公开发售获1159.46倍认购，国际发售获15.28倍认购。
- **研发投入**：累计投入约44亿元，研发人员占比74%。
- **财务增长**：2025年上半年收入1.91亿元，同比增长325%。
- **生态规模**：MaaS平台汇聚300万开发者，赋能12000家企业客户。

## 关键论点
1. **技术领先性**：[[GLM-4.7]] 在 Artificial Analysis 和 Code Arena 榜单上位列开源与国产模型双料榜首。
2. **商业模式验证**：通过 [[MaaS]] 模式实现规模化收入，编程订阅产品 ARR 过亿。
3. **国产化适配**：GLM 架构已适配40余款国产芯片，构建了硬件护城河。
4. **行业地位**：按2024年收入计算，在中国独立通用大模型开发商中排名第一。
