# 最长连续工作40天！硅谷Agent又进化了：给个指令，剩下它全搞定

## 摘要
本文报道了硅谷初创公司 [[factory-ai]] 发布的新产品 [[missions]]，这是一个搭载在 [[droids]] 智能体上的任务调度系统。该系统实现了智能体自主规划并连续执行长达 40 天的复杂任务，标志着 AI 在软件工程领域的自主化程度达到了新的里程碑。

## 核心要点

### 产品特性
- **自主闭环**：用户只需提供一个指令（如“构建 CRM 系统”），系统即可自动完成规划、编码、测试和验证的全过程。
- **超长运行**：普通 Droid 对话平均持续 8 分钟，而搭载 Missions 后普遍达到 2 小时，最长记录达 40 天。
- **里程碑验证**：通过内置调度器将任务分解为里程碑，每个阶段完成后必须通过自动验证（审查、测试、修复）才能进入下一阶段。
- **多模型支持**：支持调用不同厂商的模型，调度器会根据任务自动选择最合适的执行模型。

### 技术架构
- **调度器**：负责管理多个智能体并行工作，将大型项目分解为里程碑和功能。
- **上下文管理**：为每个功能启动全新上下文对话窗口，避免单一长对话导致的信息遗失。
- **Skill-based Learning**：基于技能的学习系统，将可复用操作提炼为技能库，随使用不断优化，赋予系统泛化能力（如写论文、训练模型）。

### 性能与成本
- **Token 消耗**：Missions 消耗的 Token 数量平均是普通对话的 12 倍。
- **速率持平**：尽管总消耗增加，但消耗速率（每分钟约 4.5 万 Token）与普通对话持平，因为大量时间用于执行工程任务而非生成文本。
- **推理深度**：消息发送速率降至每分钟 3 条，但每条的 Token 权重翻倍，表明系统进行了更深度的推理。

### 团队背景
- **[[matan-grinberg]]**：联合创始人，理论物理背景（师从弦理论专家胡安·马尔达塞纳），曾因关于弦理论和 AI 的思考获得红杉资本关注。
- **[[eno-reyes]]**：联合创始人，前 Hugging Face 机器学习工程师，普林斯顿认知科学背景，负责 Droids 的自主循环机制。
- **投资方**：红杉资本合伙人 Shaun Maguire 领投。

## 行业意义
Missions 的出现被视为 [[任务执行范式]] 的典型案例，即从单纯的模型开发转向工程化的智能体系统。它直接超越了此前记录的 [[openclaw]]（曾发生安全事故），展示了在保证验证机制的前提下实现高度自动化的可能性。同时，其高昂的 Token 消耗也佐证了 [[ai-subscription-crisis]] 中关于 Agent 时代成本激增的观点。
