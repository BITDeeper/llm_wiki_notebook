# 同事群里催催催，龙虾自动回回回！刚发布的「飞书龙虾」把我解脱了

## 概述
本文是一篇关于飞书春季发布会产品的深度实测报道。文章详细介绍了飞书升级后的 [[飞书-aily]]、[[飞书妙搭-agent]] 和 [[飞书多维表格-agent]] 三大 Agent 产品，展示了其从“对话”转向“行动”的能力，以及“无需部署”的 [[人人可养-agent]] 理念。

## 核心内容

### 1. 飞书 Aily：人人可养的智能伙伴
- **零门槛体验**：无需部署，直接作为联系人出现在通讯录中。
- **个性化设置**：支持自定义人设（如“皮皮虾”），可设置自动回复规则。
- **跨群/跨文档协作**：能够读取消息、撰写快讯并直接发送文件。
- **Skills 机制**：通过安装 [[skills-技能]]（如 feishu-bitable, feishu-docs）赋予 Agent 调用工具的能力。
- **记忆能力**：能够记住用户习惯，越用越懂用户。

### 2. AI 编辑部：多 Agent 协作案例
文章展示了一个名为“AI 编辑部”的 [[ai-编辑部]] 案例，通过 6 个不同角色的 Agent（总编虾、记者虾、编辑虾等）协同工作，完成从选题、提纲、搜集资料到撰写、排版、发布的全流程。这展示了 [[企业级长任务]] 的拆解与执行能力。

### 3. Aily 专业版：企业级长任务处理
针对复杂业务场景，Aily 专业版展示了处理海量数据（如 7 个 Sheet 的业务数据）的能力，能够：
- 自动生成月度经营汇报 PPT。
- 制作配套的数据可视化图表。
- 搭建多项目进度跟踪看板。

### 4. 飞书妙搭 Agent：Prompt-to-App
- **开发范式**：实现了 [[prompt-to-app]]，即通过自然语言描述直接生成完整应用程序。
- **实测案例**：文章演示了通过一段 Prompt 自动生成一个“狼人杀”游戏应用的过程，包括概要设计、开发计划和自动执行。
- **自主决策**：Agent 能够自主决策调用何种工具，全程无需人工干预。

### 5. 多维表格 Agent：自动化系统搭建
- **自然语言搭建**：通过描述需求（如“小团队周度工作任务跟踪管理系统”），Agent 自动进行系统设计、视图配置、仪表盘生成和自动化流程配置。
- **搭建模式**：提供“轻量”、“标准”、“专业”三种模式，适应不同复杂度的需求。
- **AI 驱动 AI**：支持在飞书 Aily 中通过语音指令调用多维表格 Agent 搭建系统。

## 核心观点

### Agent 落地的关键要素
1. **全流程的安全可控**：[[权限体系对齐]]，操作权限与用户本人一致，全链路留痕可追溯。
2. **深度业务上下文**：依托飞书沉淀的消息、文档、表格等数据，告别盲猜式对话。
3. **闭环执行能力**：不仅能输出方案，更能直接动手执行（如修改文档、发送消息）。

### 生态集成
文章提到飞书支持一键部署 [[openclaw]]，并结合官方插件为 Agent 解放手脚，展示了其开放的 API 生态。
