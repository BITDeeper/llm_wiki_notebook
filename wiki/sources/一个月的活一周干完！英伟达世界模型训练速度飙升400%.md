# 一个月的活一周干完！英伟达世界模型训练速度飙升400%

新智元发布的关于 [[rlinf|RLinf]] 框架对英伟达 [[dreamzero|DreamZero]] 世界动作模型训练管线进行系统级重构的深度技术报道。

## 核心内容

文章详细介绍了 RLinf 框架（由 [[无问芯穹]] 与 [[清华大学]] 联合推出）如何通过三大优化维度将 DreamZero 训练吞吐提升近 4 倍，将原本 25 天的训练周期缩短至约 1 周。

### 三大优化维度

1. **算子/计算图优化**：通过 Torch Compile + CUDA Graph 实现 Kernel Fusion，消除 Python 层调度开销。5B 模型单步耗时从 1.8s 降至 1.2s（50% 加速），14B 模型从 9s 降至 6.7s（34% 加速）。

2. **FSDP2 并行优化与全局参数调优**：用 PyTorch 官方 FSDP2 替代 DeepSpeed，解决 ZeRO3 与 VAE causal conv 的兼容性冲突；支持任意 Microbatch Size 配置；实现 Recompute 与 CUDA Graph、FSDP2 的深度协同。

3. **视频数据处理管线优化**：用 Torchcodec 替代 PyAV，单视频解码时间缩短近 400ms，三视角累计节省 1.2s。

### 性能数据

- **DreamZero-5B**：吞吐从 1.1 samples/sec/gpu 飙升至 4.44 samples/sec/gpu（约 4 倍加速）
- **DreamZero-14B**：相比原生 DeepSpeed 方案实现 2.7 倍加速
- **收敛验证**：在 LIBERO Spatial Benchmark 上达到 96.68% 成功率，与官方基线一致

### 关键技术创新

- **Step 粒度随机采样**：相比官方 Episode 粒度读取，实现更平滑的 Loss 曲线和更稳定的梯度更新
- 测试环境：8×H100 GPU
