# 智谱GLM-5技术全公开！完全适配华为等国产芯片，美国网友酸了

## 概述
本文详细解读了智谱 AI 发布的 GLM-5 模型技术论文。GLM-5 被视为首个将开源 AI 拽入“长任务时代”的模型，具备连续运行代码超过 24 小时、进行 700 次工具调用和 800 次上下文切换的能力。文章重点介绍了其三大核心技术：引入 DeepSeek 同款稀疏注意力（DSA）、异步强化学习基础设施以及全栈适配国产芯片。

## 核心技术亮点

### 1. 架构优化：DSA 稀疏注意力机制
- **背景**：传统 Transformer 密集注意力计算复杂度随上下文长度呈平方级增长，成本高昂。
- **方案**：引入 [[DSA-稀疏注意力机制]]，动态选择与当前 Token 最相关的 Top-K 个 Token 进行计算。
- **效果**：
  - KV Cache 开销降低 75%。
  - 推理速度提升 3 倍。
  - 在 RULER 等长文本评测中性能损失小于 0.5%。
- **训练策略**：采用“稠密预热 + 平滑过渡”策略，避免模型崩塌。

### 2. 训练革新：异步强化学习基础设施
- **痛点**：传统 PPO 算法高度同步，GPU 利用率仅 20%-30%。
- **方案**：解耦训练引擎和推理引擎。
  - 推理引擎持续生成轨迹。
  - 训练引擎异步更新模型。
  - 权重定期同步以保持策略一致性。
- **关键技术**：
  - **TITO (Token-in-Token-out)**：直接消费推理引擎生成的精确 token 流，消除重新 tokenization 带来的边界不匹配。
  - **双侧重要性采样**：解决离策略偏差，通过信任域限制屏蔽梯度计算。
  - **DP 感知路由**：通过一致性哈希避免长上下文中的冗余预填充计算。

### 3. 数据与评测：真实世界环境
- **SFT 阶段**：最大上下文扩展至 202,752 个 token，支持交错思考、保留思考和轮级思考。
- **RL 环境**：构建了软件工程、终端、搜索和 PPT 生成等可验证环境。
- **评测基准**：推出 [[CC-Bench-V2]]，解决传统 SWE-bench 的记忆效应问题，涵盖前端、后端和长程任务。

### 4. 生态适配：国产芯片全栈支持
GLM-5 完成了对华为昇腾、摩尔线程、海光、寒武纪、昆仑芯、沐曦及燧原等 7 家国产芯片的全栈适配，标志着国产 AI 软硬件生态闭环的形成。

## 关键数据
- **SWE-bench Verified**：得分 77.8%（开源 SOTA，优于 Gemini 3 Pro，与 Claude Opus 4.5 相当）。
- **HLE (含工具)**：得分 50.4（优于 Claude Opus 4.5）。
- **Artificial Analysis Intelligence Index v4.0**：得分 50 分（首个达到 50 分的开放权重模型）。

## 轶事：Pony Alpha 实验
在论文公开前，GLM-5 曾以“Pony Alpha”为代号在 OpenRouter 匿名测试。25% 的用户猜测是 Claude，20% 猜测是 Grok，仅有少数猜中是 GLM-5。这打破了地缘偏见，证明了其纯粹的技术实力。
