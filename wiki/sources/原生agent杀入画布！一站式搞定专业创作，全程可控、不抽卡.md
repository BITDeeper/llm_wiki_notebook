# 原生Agent杀入画布！一站式搞定专业创作，全程可控、不抽卡

## 概述
本文介绍了国内最大的 ComfyUI 平台 [[RunningHub]] 推出的原生 AI 智能体全能内容创作平台 [[RHTV]]。文章通过实测案例（抽象短剧、电商主图），展示了 RHTV 如何通过 [[原生智能体]] 和 [[画布原生]] 技术，实现从脚本策划到成片输出的全流程自动化与可视化控制。

## 核心观点
- **范式转变**：AI 内容创作正从单纯的“模型竞争”转向“生态与调度竞争”。RHTV 结合了“极简交互”与“极深底层”，降低了专业创作门槛。
- **技术优势**：[[原生智能体]] 深度集成于画布中，无需外挂；支持 [[不抽卡]] 式的可视化节点操作，用户可随时暂停、干预和局部修改。
- **生态壁垒**：背靠 RunningHub 庞大的开源生态（10万+应用、1.3万+节点），[[RHTV]] 的能力边界随社区进化而扩展。

## 关键案例
1. **抽象短剧创作**：输入“猫毛与柳絮”的抽象概念，Agent 自动拆解任务、策划剧情（霸总风）、生成角色资产、搭建分镜工作流，并最终输出带 BGM 的成片。
2. **电商主图生成**：上传凤梨干实拍图，Agent 自动规划卖点逻辑与视觉方向，批量生成 8 张商用主图，并支持分层抠图和二次编辑。

## 技术细节
- **工作流可视化**：Agent 自动搭建节点工作流，全程透明可见。
- **专业工具集成**：内置分镜大师、导演台、剪辑编辑器、打光控制等影视级功能。
- **模型优化**：集成 [[Seedance 2.0]] 等热门模型，并通过 Agent 调度优化生成逻辑和速度。

## 结论
RHTV 通过将庞大的 ComfyUI 生态封装进具备专家级逻辑的原生 Agent 中，解决了传统 AI 创作工具“有 Agent 没生态”或“有生态没 Agent”的痛点，实现了专业级能力的平民化。
