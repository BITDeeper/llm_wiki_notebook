# 完爆ChatGPT！谷歌这招太狠：连你的「阴阳怪气」都能神还原

## 摘要
本文详细报道了谷歌发布的 [[gemini-2-5-flash]] 原生音频模型及其在实时语音交互领域的突破。文章指出，该模型通过端到端的音频处理技术，实现了从“文本转语音”到真正的“拟人化交互”的跨越，能够保留说话者的语调、节奏和情感（即 [[风格迁移]]）。此外，文章还介绍了 [[google-deepmind]] 实验室开发的实验性工具 [[disco]] 及其内置的 [[gentabs]] 功能，展示了谷歌在“浏览即创造”方向的探索。

## 核心要点

### 原生音频技术
- **技术原理**：不同于传统的“音频转文本 -> 处理 -> 文本转音频”流程，[[原生音频]] 模型直接处理音频流（听、想、说），避免了中间转换带来的信息（如情感、停顿）丢失。
- **应用场景**：实时语音翻译、双向对话代理、客服系统。

### 风格迁移
- **功能描述**：在翻译或生成语音时，AI 能够捕捉并保留原说话者的情绪状态（如焦急、欢快、犹豫）。
- **意义**：解决了机器翻译“莫得感情”的痛点，使跨语言沟通能够传达“态度”和“弦外之音”。

### 实时语音代理
- **持续监听**：AI 自动监听并翻译周围环境中的多种语言，无需用户手动触发，实现“无感”翻译。
- **双向对话**：自动识别说话者，在耳机内播放翻译给用户，通过手机外放翻译给对方，全自动切换。
- **噪声鲁棒性**：针对嘈杂环境（如户外市场）优化，过滤背景音。

### 性能与评测
- **ComplexFuncBench Audio**：在复杂多步骤函数调用评测中得分 71.5%。
- **指令遵循**：指令遵循率从 84% 提升至 90%。
- **多语言支持**：覆盖 70 多种语言和 2000 多个语言对，支持多语言混输。

### 实验性产品：Disco 与 GenTabs
- [[disco]]：Google Labs 发布的新发现工具，集成 [[gemini-3]]。
- [[gentabs]]：基于 Gemini 3 的功能，能通过理解用户的标签页和聊天记录，自动生成交互式 Web 应用程序，无需编写代码。

## 行业影响
- **语音交互入口**：谷歌正通过 [[gemini-live]] 和 Search Live 等产品，将 AI 从屏幕解放出来，抢占语音交互入口。
- **企业应用**：降低了构建具备情感理解能力、能处理复杂任务的下一代 AI 客服的门槛。
- **语言障碍消除**：预计 2026 年该功能将通过 Gemini API 扩展到更多产品，可能改变人类学习语言的方式。
