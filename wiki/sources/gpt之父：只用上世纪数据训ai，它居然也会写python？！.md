# GPT之父：只用上世纪数据训AI，它居然也会写Python？！
**来源**：量子位 | **日期**：2026-04-30 | **作者**：梦瑶

## 概述
本文报道了由前 OpenAI 核心成员、被称为“GPT之父”的 [[Alec Radford]] 参与的一项独特研究。该团队训练了一个名为 [[talkie-1930]] 的“复古语言模型”，该模型仅在 1931 年之前的文本数据上进行训练。研究旨在探究大语言模型（LLM）的核心能力是否依赖于现代互联网数据，以及模型如何应对“未来”知识。

## 核心发现

### 1. 基础能力独立于现代数据
研究团队对比了 [[talkie-1930]] 与使用现代数据训练的孪生模型 [[talkie-web]]。结果显示：
- 在剔除涉及现代知识（如互联网、DNA）的题目后，两者的性能差距缩小了一半。
- 在核心语言理解和数学计算任务上，两个模型的表现几乎一样好。
- 这表明语言理解和逻辑推理能力并不依赖于现代互联网数据，更多源于基础架构和规模。

### 2. 零样本编程能力
最令人惊讶的发现是 [[talkie-1930]] 具备一定的 Python 编程能力：
- 模型在训练数据中从未见过计算机或代码。
- 在 [[HumanEval]] 测试中，模型通过上下文学习，成功解决了一些简单的编程问题（如修改加密函数中的参数）。
- 研究发现，随着模型规模增大，这种“凭空学代码”的能力遵循 [[scaling-law]] 逐步提升。
- 这证明了 LLM 学会的是逻辑推理，而非单纯的记忆，能够实现跨时代的逻辑泛化（即 [[零样本泛化]]）。

### 3. 时代惊讶曲线
团队向模型输入了 1930 年后的近 5000 个历史事件，绘制了模型的困惑度变化曲线：
- **1930 年前**：模型对事件预测准确，惊讶值低。
- **1950-60 年代**：随着晶体管和电视机的普及，技术爆炸导致模型的困惑度急剧上升（“震惊到眩晕”）。
- **后期**：模型对持续的技术进步逐渐“麻木”，困惑度趋于平稳。
- 这一曲线直观反映了技术加速对基于旧知识训练的智能体的冲击。

### 4. 对齐数据的时代污染
为了将模型调教为聊天助手，团队使用了 1930 年代的礼仪手册和书信指南进行 [[历史指令微调]]，并使用 [[Claude]] Sonnet 4.6 作为教师模型进行强化学习（RLHF）。
- 结果发现，模型学会了 1930 年语料中不存在的现代“列表体”说话方式（1. 2. 3.）。
- 这种 [[rlhf-风格污染]] 揭示了使用现代 AI 作为教师时，会将现代语言习惯不可避免地注入复古模型。

## 关键人物与背景
- **[[Alec Radford]]**：GPT-1/2 论文一作，前 OpenAI 技术大神，现 Thinking Machines Lab 顾问。他于 2024 年底离开 OpenAI 转向独立研究，致力于探究 LLM 的本质。
- **[[Thinking Machines Lab]]**：由前 OpenAI CTO Mira Murati 创立，Alec Radford 现任职的实验室。

## 研究意义
该研究挑战了“模型需要海量现代数据才能具备智能”的行业共识，证明了逻辑推理能力的独立性。团队计划在今年夏天发布 GPT-3 级别的复古模型，并进一步扩展语料规模和语言范围。
