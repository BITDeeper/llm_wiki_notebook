## 关键概念

- **Vibe Coding（氛围编程）** — 通过自然语言描述而非手动编码来生成可运行程序的开发方式
  - 重要性：BARKOD 工具的开发方式，体现了该范式的实际应用
  - 维基存在可能性：**已存在**（`vibe-coding`）

- **SVG 矢量图形** — 可缩放矢量图形格式，无限放大不失真
  - 重要性：BARKOD 的输出格式，保证设计质量
  - 维基存在可能性：低

- **条形码扫描兼容设计** — 在保持条形码底部扫描区不变的前提下，在上半部分进行艺术化改造的设计约束
  - 重要性：工具的核心技术理念，平衡美学与功能性
  - 维基存在可能性：低

- **EAN-13 / EAN-8 / Code 128** — 三种主流条形码编码标准
  - 重要性：BARKOD 支持的格式，覆盖零售和物流场景
  - 维基存在可能性：低
