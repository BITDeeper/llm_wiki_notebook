# 后OpenClaw时代！国产Agent模型凭「高配低价」叫板Opus 4.6

机器之心发布的深度报道，聚焦昆仑万维旗下天工AI（Skywork）发布的 SkyClaw-v1.0 智能体模型。文章从产品能力、使用门槛、性价比三个维度分析了该模型的市场定位，并通过实测验证了其在游戏开发、桌面应用打包、复合办公任务等场景中的表现。

## 核心内容

- **产品发布**：SkyClaw-v1.0 及其轻量版 SkyClaw-v1.0-lite 同步上线，专为 OpenClaw、Claude Code、Hermes、Nanobot 等主流智能体框架深度优化。
- **性能表现**：在 PinchBench、Claw-Eval Pass³、Skywork-Claw-Bench 等基准上优于 Minimax 2.7、DeepSeek V4 Flash、Qwen 3.6 35B 等模型，逼近 DeepSeek V4 Pro、Claude Opus 4.6、Qwen 3.6 Plus。
- **定价策略**：定价仅为 Minimax 2.7 和 Qwen 3.6 系列的一半甚至更低，限时免费开放。
- **技术路径**：三阶段训练——环境构建、中期训练与监督微调、强化学习。
- **行业背景**：Agent 赛道从狂欢期进入冷静期，谷歌 I/O 大会 Gemini Spark 直接对标 OpenClaw，巨头加速 Agent 消费级落地。
