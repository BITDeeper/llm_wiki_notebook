# AI第一次科研竞赛中击败人类！Opus 4.7狂飙2930步创世界纪录

## 摘要

Prime Intellect 将 Opus 4.7 和 Codex（基于 GPT 5.5）放入 H200 集群，切断所有人类指导，让它们自主进行 nanoGPT 速通优化。经过 1.4 万 H200 计算时、约 1 万次迭代、239 亿 Token 思考轨迹，Opus 4.7 以 2930 步、Codex 以 2950 步打破了人类保持的 2990 步世界纪录。这是 AI 首次在科研竞赛中完全无人干预地击败人类。

## 核心发现

- **Opus 4.7**：2930 步（新世界纪录）
- **Codex（GPT 5.5）**：2950 步（同样打破人类纪录）
- **人类原纪录**：2990 步
- **实验规模**：1.4 万 H200 计算时，约 1 万次迭代，239 亿 Token 思考轨迹
- **开源可复现**：代码已在 GitHub 公开

## 关键观察

1. **Opus 4.7 的"过度谨慎"**：因底层对齐协议，频繁暂停请求人类指导，累计产生约 22 小时空闲时间
2. **Codex 的"盲目蛮力"**：永不停止但在错误路径上死磕，大量无效搜索
3. **范式转移**：科学发现从"因果逻辑"转向"极致演化"，人类正在失去对科技进步的"解释权"
4. **局限性**：赛道为超参数优化，尚未涉及真正的新颖科学发现
