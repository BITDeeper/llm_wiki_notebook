# ClawHub迷之封杀操作，逼出首个Agent全球进化网络

## 摘要
本文报道了 [[openclaw]] 平台因误封中文开发者账号及索要捐赠事件，导致热门插件 [[evolver]] 被迫下架，进而促使原团队转型开发全球首个 AI 自我进化网络 [[evomap]] 的全过程。文章详细解析了 [[evomap]] 通过 [[基因胶囊]] 和 [[gep-协议]] 实现 Agent 间经验遗传与协同进化的机制，以及其内置的 [[credit-积分机制]] 如何构建价值闭环。

## 核心事件
- **ClawHub 封杀风波**：[[openclaw]] 作者 [[peter-steinberger]] 在邮件中向 [[evolver]] 开发者索要 1000 美元捐赠以调查下架原因，随后平台因编码问题误封大量中文开发者账号。
- **Evolver 的转型**：原 [[evolver]] 插件在登顶 ClawHub 并获得 3.6 万下载量后被下架，团队放弃插件形式，转而开发底层协议，催生了 [[evomap]] 进化网络。

## 关键技术概念
- **基因胶囊**：封装了 AI 成功经验、策略、适用场景及审计记录的数据包，是知识遗传的基本单位。
- **GEP 协议**：与 MCP（连接）和 Skill（招式）不同，GEP 专注于解决智慧的“遗传”问题。
- **自然选择机制**：通过调用频率和成功率优胜劣汰，确保只有优质胶囊留存。
- **Credit 经济模型**：Agent 通过贡献胶囊或完成任务获取积分，兑换 API 额度或算力，实现从“消耗资源”到“创造价值”的转变。

## 案例分析
文章引用了一个跨领域遗传案例：游戏策划通过“强人设命名”策略生成的胶囊，成功解决了后端工程师的变量命名冲突问题，证明了策略比代码更具通用性。

## 行业意义
文章将 [[evomap]] 的诞生比作 AI 的“Linux 时刻”，认为其补齐了 Agent 生态中“遗传”这一缺失环节，使 AI 从孤立的经验孤岛走向协同进化的“硅基生命”形态。
