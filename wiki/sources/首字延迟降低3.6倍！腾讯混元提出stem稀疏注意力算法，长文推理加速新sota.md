# 首字延迟降低3.6倍！腾讯混元提出Stem稀疏注意力算法，长文推理加速新SOTA

## 摘要

本文报道了[[腾讯混元]] AI Infra 团队提出的 [[stem-稀疏注意力|Stem 稀疏注意力算法]]，该成果已被机器学习顶会 ICML-26 收录。Stem 从"因果信息流"视角重新审视块级稀疏注意力，通过 Token 位置衰减（TPD）和输出感知度量（OAM）两大创新，仅用 25% 算力即可逼近稠密注意力精度。配套的 [[hpc-stem-hpc-bsa算子|HPC 算子]]将理论加速比转化为端到端实测性能，在 128K 上下文下实现 3.6 倍首字延迟降低。

## 核心内容

### 问题背景
大模型处理长文本时，[[预填充瓶颈|预填充阶段]]因 Transformer 自注意力二次方复杂度导致首字输出延迟严重。[[稀疏注意力]]是主流破局方向，但现有方案在算法和算子层面均存在短板。

### 算法创新
1. **Token 位置衰减（TPD）**：在因果架构中为初始 token 分配更大稀疏预算，向末尾线性衰减，保护递归依赖链
2. **输出感知度量（OAM）**：结合注意力分数与 Value 向量幅值评估 token 真实信息贡献，通过对数变换实现近零开销

### 工程实现
- 在腾讯混元 Hy3 preview（W8A8-FP8）的 vLLM 框架中完成端到端验证
- HPC-BSA 算子针对 Hopper 架构优化，原生支持 FP8 和 Paged KV Cache
- 跳块开销控制在 2.5% 以内，相比 MIT-BSA 实现约 3.1 倍加速
