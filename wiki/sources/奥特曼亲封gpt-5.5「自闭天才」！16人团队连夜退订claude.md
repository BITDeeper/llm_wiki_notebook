# 奥特曼亲封GPT-5.5「自闭天才」！16人团队连夜退订Claude

## 摘要
本文报道了 OpenAI 发布 GPT-5.5 后引发的市场震动。CEO [[Sam Altman]] 称其为「自闭天才」，强调其原始智能和极高的 Token 效率。数据显示，集成 GPT-5.5的 [[Codex]] 工具单周下载量突破 9000 万，远超 [[Claude Code]]。初创公司 Bold Metrics 的案例表明，迁移至 GPT-5.5 可使 16 人团队每月节省 3.2 万美元成本。文章也指出了 GPT-5.5 在「人味儿」和交互体验上的缺失。

## 核心数据
- **下载量对比**：Codex 单周 9000 万次 vs Claude Code 720 万次（约 12 倍差距）。
- **成本节省**：Bold Metrics 团队每月节省 3.2 万美元（Token 消耗减少 40%）。
- **版本更新**：Codex v0.128.0 引入持久化 `/goal` 工作流。

## 关键论点
1.  **性能与成本的双重优势**：GPT-5.5 在跑分上碾压对手，且 Token 效率极高，成为企业迁移的主要动力。
2.  **开发者大迁徙**：从 Claude 到 Codex 的迁移趋势明显，受成本和性能双重驱动。
3.  **体验的缺失**：尽管性能强大，GPT-5.5 被批评缺乏「人味儿」，在教学和解释能力上不如 Claude。
