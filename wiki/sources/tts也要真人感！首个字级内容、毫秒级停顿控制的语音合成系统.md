# TTS也要真人感！首个字级内容、毫秒级停顿控制的语音合成系统

新智元于2026年5月12日发布的报道，介绍[[华南理工大学]]开发的[[magic-tts|MAGIC-TTS]]语音合成系统。该系统首次实现[[字级节奏控制|字级内容时长]]与[[边界停顿控制|毫秒级边界停顿]]的同步精细控制，将TTS从"把话念自然"推进到"精细安排句内节奏"的新阶段。

## 核心内容

报道重点阐述了三个层面：

1. **问题定义**：现有TTS系统只能做到整句全局变速，无法对句内局部节奏进行精细安排。产品场景（验证码、导航、教学纠音、剧情表达）真正需要的恰恰是局部控制。

2. **技术方案**：MAGIC-TTS 将节奏拆解为内容时长和边界停顿两个独立维度，通过 Stable-ts + MFA 交叉验证构建高置信度训练数据，并引入[[零值校正]]解决停顿信号污染内容控制的问题。

3. **关键指标**：内容时长 MAE 从 36.88ms 降至 10.56ms（相关性 0.588→0.918），停顿 MAE 从 18.92ms 降至 8.32ms（相关性 0.283→0.793）。报道特别指出内容时长指标的提升比停顿更有意义，因为前者难度更高。

## 应用方向

报道提及三类应用场景：[[高辨识播报]]（验证码、订单号、地址）、教学纠音（外语学习、儿童跟读）、表达型语音（数字人、剧情化配音）。
