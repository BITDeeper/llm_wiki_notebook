# Source: 突发！anthropic呼吁全员停止ai研究.md

## 关键实体

- **Anthropic** — AI平台公司（核心）。发布关于递归自我提升（RSI）的长文博客，公开内部数据呼吁行业暂停AI研究。已存在于Wiki。
- **Claude** — Anthropic的旗舰AI模型系列（核心）。涵盖Opus 3/4、Sonnet 3.7、Mythos等版本，在代码编写、代码审查、研究实验中表现突出。已存在于Wiki（作为Anthropic旗下产品）。
- **Claude Code** — Anthropic的AI编程代理工具（核心）。是代码量飙升的关键驱动力，80%以上Anthropic代码由此生成。已存在于Wiki。
- **OpenAI** — AI公司（外围）。在Anthropic博客发布前几天也发表了类似RSI声明的博客。已存在于Wiki。
- **Mythos / Claude Opus 4.6** — Anthropic最新/即将发布的模型（核心）。内测中可连续工作16小时，Mythos Preview发现超1万个高危漏洞。**Wiki中未明确存在，需新建。**
- **Project Glasswing** — Anthropic内部项目（外围）。Mythos Preview用于发现全球软件漏洞的项目。**Wiki中不存在，需新建。**
- **METR** — AI测试框架（外围）。用于衡量AI独立完成任务时长的基准。**Wiki中不存在，需新建。**
- **量子位 (QbitAI)** — 报道媒体。已存在于Wiki。

## 关键概念

- **递归自我提升 (RSI)** — AI系统能够自主设计和构建下一代自身的能力，形成自我加速循环。本文核心主题。已存在于Wiki（[[递归式自我改进]]），本文提供了大量实证数据，应大幅扩展该页面。
- **AI能独立完成的任务时长** — Anthropic创建的新衡量维度，从4分钟（2024.3）→1.5小时（2025.3）→12小时（2026.3）→16小时+（Mythos），翻倍速度从每7个月加速到每4个月。**Wiki中不存在，建议新建。**
- **AI摩尔定律** — 上述任务时长指数增长趋势的通俗表述，本文首次明确提出。**Wiki中不存在。**
- **阿姆达尔定律在组织中的体现** — AI加速某一环节后，瓶颈转移至下一环节（如代码写完→review成瓶颈）。**Wiki中不存在。**
- **研究品味与判断力** — 人类在AI开发流程中最后的比较优势，Anthropic不确定该优势能维持多久。与Wiki中[[审美法官]]概念高度相关。

## 主要论点与发现

**核心声明：** AI的自进化已经开始，Anthropic内部数据证实Claude正在加速AI发展，可能已踏上RSI路径。

**关键证据：**
1. **代码量：** 80%以上Anthropic代码由Claude编写（发布前仅个位数）；工程师日均merge代码量为2024年的8倍。
2. **质量提升：** 开放性编程任务成功率从26%（半年前）→76%（现在）；Claude自动审查可拦截约1/3导致线上事故的bug。
3. **研究能力：** 模型优化任务从3倍加速（Opus 4）→52倍加速（Mythos Preview），远超人类的4倍；AI安全研究中Claude将gap缩小97%，人类研究员仅缩小23%。
4. **任务时长指数增长：** 每4个月翻一倍，预计2027年达数周级别。

**证据强度：** 强。来自Anthropic内部生产数据，涵盖代码量、benchmark、实际研究任务对比，具有高度可信度。但部分数据（如Mythos表现）仍处于内测阶段。

**RSI三种未来场景：**
1. 停滞（S曲线、物理瓶颈）——但即便停滞在当前水平也已影响巨大
2. AI持续加速但人类掌舵（最可能场景）——组织效率指数级提升，瓶颈转移
3. 完全RSI（AI自造下一代）——发展速度完全取决于算力，可能带来科学全线起飞或对齐失败

## 矛盾与张力

1. **自利动机质疑：** 文章自身承认Anthropic即将IPO，此次发布可能被视为"Anthropic式公关"——通过展示技术实力推高估值，同时以"呼吁暂停"占据道德高地。但OpenAI同步发布类似声明增加了可信度。
2. **呼吁暂停 vs. 实际加速：** Anthropic呼吁行业暂停，但其内部数据恰恰展示了前所未有的加速。条件性暂停（"可验证机制确保没人偷卷"）在实际中几乎不可能实现，这使得呼吁更像是一种立场宣示。
3. **安全公司造风险：** Anthropic以AI安全为使命，但其自身正在成为RSI的最大推动者之一，存在深刻的使命矛盾。
4. **与Wiki现有内容的张力：** Wiki中[[anthropic]]页面记录了其年化收入超300亿美元、反超OpenAI等商业成功。本文揭示其技术成功可能带来的存在性风险，形成"商业胜利vs文明风险"的张力。
