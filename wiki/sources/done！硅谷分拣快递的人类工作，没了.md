# Done！硅谷分拣快递的人类工作，没了

量子位发布的关于美国人形机器人公司 [[figure]] 进行8小时不间断自主直播的报道。三台 [[figure-03]] 机器人（Gary、Bob、Frank）在零人工干预下完成快递分拣任务，搭载 [[helix-02]] 统一视觉运动神经网络和 System 0 全身控制系统。

## 核心内容

- **直播起因**：机器人领域布道专家 Scott Walter 公开质疑人形机器人无法在无人干预下完成8小时工作班次，[[brett-adcock]] 次日即开启直播回应
- **技术亮点**：[[helix-02]] 将视觉、触觉、本体感知统一接入执行器，实现"感觉、思考、行动"一体化；System 0 用单个神经网络替换109504行C++代码
- **争议点**：机器人频繁触碰头部被疑远程遥操作，Brett Adcock 回应"都是策略"但未充分解释；偶发错误暴露长程稳定性不足
- **行业背景**：同期 [[宇树]] 推出世界首款量产人形机甲 [[gd01]]，推特热度第一，马斯克点赞

## 关键数据

- 直播吸引超200万网友围观
- 操作速度约每包裹3秒，接近人类水平
- Figure 03 载重20kg，续航5小时，最高速度1.2m/s
- System 0 拥有超1000小时人类运动数据
