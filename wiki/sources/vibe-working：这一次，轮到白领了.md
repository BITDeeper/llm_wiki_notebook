## 关键概念

- **Vibe Working** — 继 Vibe Coding 之后的新概念，指不懂技术的人通过自然语言让 AI 完成知识工作，核心逻辑是"把执行权交给 AI，把判断权留给人"。
  - 重要性：本文核心主题，标志 AI Agent 主战场从写代码迁移到白领日常工作。
  - 维基状态：未收录，建议新建。与已有 [[vibe-coding]] 形成系列。

- **本地通用 Agent (Local Agent)** — Agent 住在用户本地电脑上，直接操作用户的文件、应用和浏览器（含登录状态），区别于云端沙盒 Agent。
  - 重要性：代表 Agent 从云端迁移到本地的行业趋势。
  - 维基状态：未收录，建议新建。

- **Agent 集群能力** — 单个 Agent 可自主创建多个子 Agent（Kimi Work 最多300个）并行处理多线程任务，自动完成项目管理与任务拆解。
  - 重要性：使并行成为默认工作方式，而非需手动触发。
  - 维基状态：与已有 [[1-n-agent调度]] 相关但更具体，建议扩展。

- **WebBridge（浏览器桥接）** — 直接操作用户当前浏览器（含登录状态和 Cookie），而非新建空白 AI 专用浏览器，大幅降低自动化摩擦。
  - 重要性：解决 AI 自动化中"带着你的账号去干活"的关键痛点。
  - 维基状态：未收录，建议新建。

- **Harness** — Agent 的运行环境/工具框架，负责对接真实工作流（调用工具、访问数据、适时介入）。文章认为 AI 长任务的真正挑战不在上下文窗口长度，而在 Harness 搭建质量。
  - 重要性：核心工程判断。
  - 维基状态：未收录，建议新建。

- **云端 Agent vs 本地 Agent 路线分歧** — 第一代 Agent（Kimi 网页版、OpenAI cloud sandbox、谷歌 Project Mariner）在云端独立环境运行；第二代（Kimi Work、Claude Cowork）在本地运行，边界等于用户桌面工作的全部边界。
  - 重要性：行业路线判断。
  - 维基状态：未收录。

## 主要论点与发现

1. **核心论点：AI Agent 主战场正从编程迁移到白领知识工作。**
   - 证据：Codex 知识工作者用户增速是开发者3倍以上，已占全部用户约20%；OpenAI 将 Codex 并入 ChatGPT；Anthropic 推出企业/金融 Agent。
   - 强度：强，有多方数据交叉验证。

2. **核心论点：通用 Agent 战场正从云端迁移到本地。**
   - 证据：Kimi Work、Claude Cowork 均走本地路线；云端 Agent（cloud sandbox、Project Mariner）存在与用户真实环境割裂的固有缺陷。
   - 强度：中等偏强，逻辑清晰但尚处早期。

3. **核心论点：模型+Harness 深度协同是模型公司的天然优势。**
   - 证据：只有同时掌握模型和运行环境才能实现深度协同，外部集成商难以复制。
   - 强度：中等，为竞争格局判断。

4. **实测发现：Kimi Work Beta 版在5个场景（调研、本地文件、浏览器操控、长任务、金融分析）表现可用。**
   - 亮点：Agent 集群自动拆解任务；WebBridge 带登录状态操作浏览器；50分钟长任务断点续跑；内置金融数据源执行20条工具调用完成真实数据分析。
   - 强度：中等，为单一媒体评测，非基准测试。
