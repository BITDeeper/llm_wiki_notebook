# 源文档：凌晨3点，硅谷炸锅！Anthropic源码意外泄露，51万行代码揭露Claude惊天野心

## 概述
本文报道了 Anthropic 因 npm 包配置错误导致 51.2 万行源码意外泄露的事件。泄露的代码揭示了代号为 [[Conway]] 的秘密项目，展示了 Claude 从“聊天机器人”向“全天候常驻智能体平台”转型的宏大野心。

## 核心发现

### 1. 代码泄露事件
- **起因**：Anthropic 在发布 npm 包时，因 `.npmignore` 配置错误，意外包含了 59.8 MB 的 source map 文件。
- **规模**：涉及 51.2 万行未混淆的 TypeScript 源码，涵盖 1900 个文件。
- **暴露内容**：几乎整套内部实现逻辑，包括此前未公开的 [[Conway]] 项目。

### 2. Conway：下一代智能体形态
泄露代码显示，[[Conway]] 是一个独立运行的 Claude 实例环境，具备以下特征：
- **独立 UI**：拥有包含 Search、Chat、System 三个区域的侧边栏界面。
- **后台常驻**：支持独立进程守护、持久化会话状态和后台任务队列。
- **事件驱动**：支持 Webhook 唤醒，能在外部事件触发时自动执行任务。
- **跨设备同步**：代码暗示未来支持跨设备状态同步，任务不绑定单一窗口。

### 3. 战略野心：争夺 OS 入口
文章指出，Anthropic 的目标不仅是做一个更好的助手，而是构建**下一代操作系统入口**。其路线图清晰可见：
1. **对话框**（基础问答）
2. **后台进程**（Claude Code，本地持续运行）
3. **常驻平台**（Claude Dispatch，持久线程）
4. **操作系统入口**（Conway，生态与扩展系统）

### 4. 扩展生态
[[Conway]] 预埋了扩展系统，支持安装自定义工具、UI 标签页和上下文处理器，甚至引入了 `.cnw.zip` 这一新的扩展包格式。这表明 Anthropic 试图建立一个以 Claude 为核心的完整生态。

## 行业洞察

### 范式转移
文章强调，AI 行业正在从“对话式交互”向“任务执行范式”转移。用户对“聊天”感到疲劳，真正渴望的是设定目标后，AI 能在后台自主完成工作。

### 安全与讽刺
尽管 Anthropic 极度强调 AI 安全，但此次重大泄露源于最基础的工程疏忽（一行配置代码）。这暴露了**安全承诺与工程实践之间的巨大鸿沟**，同时也警示：随着智能体获得更高权限，其攻击面将急剧膨胀。

## 数字主权问题
文章提出了一个深刻的伦理问题：当 AI 比你更了解你的电脑并 24 小时在线时，用户是否准备好交出“键盘”（控制权）？这标志着从“认知投降”到“数字主权”让渡的深层挑战。
