# DeepSeek急招Agent方向！一口气放17个岗位，重度Vibe Coding用户优先

## 概述
本文报道了 DeepSeek 在 2026 年 3 月的大规模招聘动作，一口气开放了 17 个与 Agent 方向相关的岗位。这标志着 DeepSeek 的战略重心从“基础模型研究”正式转向“Agent 产品化与全栈能力建设”。

## 核心发现

### 战略转向
对比 2026 年 1 月的招聘需求（当时主要集中在“深度学习研究员-AGI”等通用研究方向），此次招聘明显向 Agent 产品化倾斜。岗位覆盖算法研究、数据评测、基础设施全链条，显示出构建完整 Agent 生态系统的意图。

### 人才画像变化
DeepSeek 对候选人的要求反映了 AI 原生开发时代的到来：
- **Vibe Coding 重度用户**：在全栈开发工程师岗位中，明确要求作为“Vibe Coding 重度用户”，持续探索模型能力在产品中的创新应用。
- **AI 编程工具熟练度**：多个岗位将“重度使用 [[claude-code]]、Cursor、Copilot”列为加分项或硬性要求。
- **竞品对标意识**：要求熟悉并深度使用过 Claude Code、[[openclaw]]、Manus 等知名 Agent，显示出强烈的追赶与对标意图。

### 技术布局细节
1.  **数据闭环**：算法研究员岗位要求与数据标注团队紧密协作，形成“数据-训练-评测”的能力提升闭环，意在摆脱对第三方数据的依赖。
2.  **基础设施**：全栈开发岗位负责支撑海量 AI Agent 运行的下一代容器调度与隔离平台，需攻克容器生命周期管理、资源精细调度等难题。
3.  **交互协议**：基础设施岗位要求熟悉 [[mcp-协议]]、Tool Use、Function Calling 等规范，表明 DeepSeek 正在构建标准化的 Agent 接口。

## 行业影响
DeepSeek 此前凭借 R-1 推理模型以低成本颠覆行业格局。此次大规模招聘 Agent 人才，引发了业界关于其能否在 Agent 领域复现“低成本奇迹”的猜想。文章指出，DeepSeek 计划在 2025 年第四季度发布具备高级 Agent 功能的 AI 模型，对标 OpenAI 等海外竞争对手。
