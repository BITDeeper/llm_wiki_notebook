# 今天，OpenAI Codex大更新！锁屏也能隔空打工，奥特曼强推

新智元 2026年5月22日报道。OpenAI 凌晨发布 [[codex]] 重大更新，包含五大核心能力：Appshots、/goal 模式毕业、锁屏远程操控（Locked Use）、高级标注模式、插件共享。同日，[[chatgpt-powerpoint-plugin|ChatGPT for PowerPoint 插件]] 开启全球 Beta 测试。

## 核心内容

### Codex 五大更新
1. **Appshots**：双击 Command 键即可截取当前窗口全部内容（含未滚动隐藏文本），自动关联活跃线程。详见 [[codex-appshots]]。
2. **/goal 模式毕业**：从实验阶段正式毕业，支持长周期自主编码，用户可随时查看进度、调整方向。详见 [[codex-goal-模式]]。
3. **Locked Use（锁屏远程操控）**：Mac 休眠/锁屏状态下，Codex 可通过手机端远程调度执行任务，实现 7×24 小时无人值守编程。详见 [[codex-locked-use]]。
4. **高级标注模式**：直接在网页/UI 上修改元素并实时预览，Codex 自动生成对应代码。
5. **插件共享**：Business 用户可在团队内部分发自定义插件，统一管理工作区可用插件。

### ChatGPT for PowerPoint
- 以插件形式嵌入 PowerPoint，支持从零生成可编辑演示文稿
- 具备数据连接能力，可直接从 Gmail、Outlook、SharePoint 拉取实时数据
- 全球所有 ChatGPT 用户层级开放 Beta 测试

### 关键数据
- Codex 周活跃开发者突破 **400 万**（两周前为 300 万）
- 1-4 月 Business/Enterprise 用户暴增 **6 倍**
- **50%** 的 Codex 用户已不再仅用于写代码
- [[sam-altman|奥特曼]] 承诺每新增 100 万周活即重置全体用户限额，直至 1000 万
