# 摘要

本文报道了 [[andrej-karpathy]] 提出的一种基于大模型的个人知识库新范式。该方法利用 AI 将分散的原始资料编译成结构化的维基百科，并通过“Lint+Heal”机制实现自动维护，使知识库成为一个能够自我进化的“第二大脑”。

# 核心内容

## 构建流程

1.  **数据导入**：将原始资料（网页、论文、代码）存入 `raw/` 文件夹，无需人工整理。
2.  **AI 编译**：利用大模型将原始资料编译成包含摘要、反向链接和概念分类的 Markdown 维基文件。
3.  **前端查看**：使用 [[obsidian]] 等工具浏览原始数据、编译好的维基及可视化图表。
4.  **循环增强**：将查询结果归档回知识库，通过 [[lint-heal-机制]] 定期扫描并补全信息。

## 关键发现

-   **无需复杂 RAG**：在 40 万字规模下，只要维护好索引和摘要，简单的检索即可达到高质量回答。
-   **记忆范式转移**：从依赖上下文窗口（让模型记住）转向依赖外部知识库（让系统可查找）。
-   **智能体应用**：这种架构为智能体提供了持续存在的知识层，比无限上下文更廉价且可扩展。

# 意义

该范式将知识库从需要人工维护的“静态存储”转变为自动维护的“动态系统”，展示了 AI 在个人知识管理和认知辅助层面的巨大潜力。
