# 一张奥特曼合照，骗过全网！OpenAI深夜偷跑AI图像新王，PS真要凉了

## 概述
本文报道了 OpenAI 新一代图像生成模型 [[GPT-Image-2]]（内部代号 GPT-5o/Spud）的泄露事件。文章指出，该模型在 [[文本渲染]] 和 [[世界知识]] 方面取得了突破性进展，能够生成像素级逼真的图像（如“奥特曼合照”），并在复杂 UI 设计和中文书法处理上超越了竞品 [[Nano Banana Pro]]。此外，文章还披露了关于 [[GPT-6]] 的内部消息，包括其性能提升、发布时间表以及 OpenAI 内部为了 GPT-6 而进行的战略调整（如关停 [[Sora]]）。

## 核心要点

### GPT-Image-2 的技术突破
- **像素级真实感**：生成的图像（如人像、宜家外景）消除了“塑料感”，跨越了 [[恐怖谷效应]]。
- **文本渲染能力**：解决了 AI 生图中文字乱码和排版错误的历史难题，能够完美处理复杂的中文草书和 YouTube 截图。
- **世界知识理解**：生成的图像符合现实物理逻辑和光影透视。

### 对设计行业的影响
- **PS 危机**：[[GPT-Image-2]] 能够“一步直出”复杂的 Web UI 和 OS 界面，大幅缩短了从创意到原型的链路，可能降低传统设计工具（如 Photoshop）的使用门槛。

### GPT-6 传闻与战略调整
- **性能飞跃**：[[GPT-6]]（代号 Spud）在编程、推理和智能体任务上比前代提升 40%。
- **技术规格**：支持 200 万 Token 上下文窗口，定价亲民（2.5/12 美元）。
- **战略重心转移**：为了集中资源，奥特曼关停了 [[Sora]]；产品部门更名为“[[AGI部署部]]”；奥特曼本人退出安全监督，转而专注于数据中心建设。
- **内部状态**：OpenAI 内部处于“红色警报”状态，AGI 据称已实现 70%-80%。
