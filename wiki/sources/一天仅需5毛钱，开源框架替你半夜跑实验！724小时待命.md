# 一天仅需5毛钱，开源框架替你半夜跑实验！7*24小时待命

## 摘要
本文介绍了开源框架 [[Deep Researcher Agent]]，这是一个旨在 7x24 小时代替研究者执行重复性深度学习实验的自动化工具。文章详细阐述了其核心循环（THINK → EXECUTE → MONITOR → REFLECT）、独特的零成本监控策略以及恒定记忆系统，并强调了作者关于科研伦理的立场。

## 核心内容

### 工作原理
框架基于一个自主循环运行：
1.  **THINK（想方案）**：分析历史记录，决定下一步实验方案（包括改代码、换 loss 函数等）。
2.  **EXECUTE（执行）**：自动修改代码或配置，先进行强制 dry-run 以检测 Bug，再提交 GPU 任务。
3.  **MONITOR（监控）**：训练期间完全不调用 LLM API，仅使用系统命令（`kill -0`, `nvidia-smi`, `tail`）检查状态，实现零成本监控。
4.  **REFLECT（反思）**：训练结束后解析日志，提取指标并决定下一轮操作。

### 关键技术特性
-   **低成本运行**：利用训练期间零 API 调用的策略，将每日运行成本控制在约 0.5 元人民币。
-   **恒定记忆系统**：通过冻结项目说明（3000字符）和压缩滚动日志（1200字符），将上下文长度恒定在约 5000 字符，避免长期运行导致的上下文膨胀。
-   **多模型支持**：兼容 Claude (Sonnet/Opus 4.6) 和 OpenAI (Codex 5.3/GPT 5.4) 系列模型。
-   **移动端集成**：配合 [[Happy Coder App]] 实现实时监控和远程指令下达。

### 实测数据与案例
-   已在真实项目中连续运行 30 多天。
-   自主完成 500+ 轮实验循环。
-   单个项目指标比 baseline 提升 52%。
-   期间人类仅介入 5-6 次。

### 差异化定位
与 [[Claude Scholar]]、[[AI Scientist]] 等专注于“写论文”或“写代码”的工具不同，[[Deep Researcher Agent]] 是首个专门为“跑”深度学习实验设计的开源框架。

### 科研伦理
作者明确声明严禁将工具用于学术造假，强调工具只能替代机械劳动，Idea 和责任必须由人承担，倡导“Human-in-the-loop”的研究方式。
