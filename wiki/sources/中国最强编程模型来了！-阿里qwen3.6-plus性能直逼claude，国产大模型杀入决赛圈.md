# 中国最强编程模型来了！ 阿里Qwen3.6-Plus性能直逼Claude，国产大模型杀入决赛圈

## 摘要
阿里发布新一代基座大模型 [[Qwen3.6-Plus]]，主打编程和智能体能力。该模型拥有 1M 上下文窗口，在 SWE-bench、Terminal-Bench2 等权威评测中表现直逼 [[Claude Opus 4.5]]，并超越了 2-3 倍参数量的主流模型。实测显示，其具备强大的 [[Vibe Coding]] 能力，可通过简单自然语言生成复杂的 3D 网页、游戏和工具，并支持多模态理解（如视频脚本拆解、看图写网页）。

## 核心观点
- **性能对标**：Qwen3.6-Plus 是目前最接近全球最强 Claude 系列的国产模型，在部分评测中表现更优。
- **以小胜大**：通过架构优化，较小参数规模的模型实现了超越更大参数模型的性能。
- **门槛降低**：基于自然语言的 [[Vibe Coding]] 不再是概念，普通用户通过“大白话”指令即可生成可运行的复杂应用。
- **生态支持**：针对 [[OpenClaw]]、[[Cline]]、Claude Code 等主流 Agent 框架进行了优化支持。

## 关键证据
- **基准测试**：在 SWE-bench、Terminal-Bench2、NL2Repo、Claw-Eval 等评测中表现优异。
- **实测案例**：
    - 一句话生成可交互的 3D 雪山场景（含动态雪花）。
    - 生成 AI 资讯日历、虚拟宠物养成页、消消乐游戏。
    - 解析长视频并生成小红书爆款文案。
    - 根据截图复刻并优化网页。
    - 基于开源项目生成 Landing Page。
    - 对老旧代码进行问题分析与重构。

## 行业意义
该模型是阿里 [[ATH]]（Alibaba Token Hub）思路的代表性落地，旨在创造高效 Token、输送低成本 Token、应用普惠化 Token。这标志着国产大模型在编程领域已进入全球“决赛圈”，与 Anthropic、谷歌形成激烈竞争。
