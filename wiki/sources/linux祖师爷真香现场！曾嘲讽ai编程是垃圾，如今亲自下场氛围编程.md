# Linux祖师爷真香现场！曾嘲讽AI编程是垃圾，如今亲自下场氛围编程

## 摘要
本文报道了 Linux 之父 [[linus-torvalds]] 在其个人 GitHub 项目 [[audionoise]] 中使用 [[google-antigravity]] 进行 [[vibe-coding]]（氛围编程）的事件。这一举动标志着这位曾激烈批评 AI 编程的行业领袖立场的重大转变。文章结合 [[andrej-karpathy]]、[[dhh]] 和 [[陶哲轩]] 等人的近期动态，论证了 2026 年初 AI 编程范式的普及临界点已至。

## 核心事件
Linus Torvalds 在其业余项目（基于 RP2354 和 TAC5112 芯片的数字吉他效果器）中，需要编写 Python 可视化工具。由于不熟悉 Python，他放弃了传统的“搜索-模仿”模式，转而使用 Google Antigravity 直接生成代码，并在 README 中承认“基本上是靠氛围编程完成的”。

## 关键论点
- **范式转移**：编程从“精通语法、记忆 API”转向“描述需求、验证代码”。
- **行业信号**：多位顶级技术专家（Linus, DHH, 陶哲轩）在 2026 年初集体转向 AI 编程，表明技术已跨越“玩具”阶段，进入实用期。
- **角色转变**：未来的程序员将更像“代码架构师”和“AI 驯养员”。

## 相关背景
- Linus 曾嘲讽 AI 代码是“垃圾”，并拒绝将其引入 Linux 内核。
- 此次使用仅限于非内核、玩具级项目，但他承认效果优于手动编写。
