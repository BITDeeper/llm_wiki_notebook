# 刚刚，Claude Opus 4.8来了！两个史上首次改写历史

新智元关于 Anthropic 发布 Claude Opus 4.8 的深度报道。文章覆盖三大核心主题：

## 核心内容

### 模型发布与基准成绩
- Opus 4.8 在 SWE-Bench Pro（69.2%）、GDPval-AA（1890 Elo）、FrontierSWE（83%）等多项基准上全面霸榜
- 编程、智能体、知识工作等多维度超越 [[gpt-5.5]] 和前代 Opus 4.7
- 价格与上一代完全一致，完成同样任务比 4.7 少用 15% 步骤、少输出 35% token

### 诚实度突破
- 谎报率 0%、偷懒率 0%，历史首次有模型在此评估中满分
- 文章引用 Anthropic 官方视频案例：Claude 拒绝用户"强制覆盖"指令，自主选择正确方案保护同事代码

### Dynamic Workflows 与生产案例
- [[claude-code]] 内置的大规模并行 Agent 调度机制 [[dynamic-workflows]] 首次亮相
- Bun 项目作者 [[jarred-sumner]] 使用该功能在 11 天内将约 75 万行 Zig 代码重写为 Rust，99.8% 测试通过
- 新增 Effort Control 五档思考和 Ultracode 超级编码模式

### 资本动态
- [[anthropic]] 完成 650 亿美元 H 轮融资，估值 9650 亿美元，首次超越 [[openai]]（8520 亿美元）
- 预告 [[claude-mythos]] 将在未来几周上线

## 关键引用
- 博主 Mark Kretschmann 推测 Opus 4.8 可能是 Mythos 的蒸馏版本
- 沃顿商学院教授 Ethan Mollick 评价"令人印象深刻"
- Every 团队报告编码实力比上一代高 30 分
