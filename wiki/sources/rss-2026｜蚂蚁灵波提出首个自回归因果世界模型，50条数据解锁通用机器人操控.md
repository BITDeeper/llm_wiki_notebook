# RSS 2026｜蚂蚁灵波提出首个自回归因果世界模型，50条数据解锁通用机器人操控

本文报道了 [[蚂蚁灵波]] 与 [[香港科技大学]] 联合提出的 [[lingbot-va]]——首个自回归因果视频-动作世界模型。该模型通过统一视频动态预测与动作推理，将物理世界的因果结构融入机器人控制中，每个任务仅需 50 条真实演示数据即可完成微调。

## 核心内容

- **问题定位**：传统 [[vla-视觉-语言-动作]] 模型直接将视觉映射到动作，缺乏显式物理因果建模，在长程、高精度和柔性物体操作任务中表现不佳。
- **架构创新**：采用 [[混合transformer架构]]（MoT），将视频流和动作流解耦但交错处理，配合 [[噪声潜在增强]] 策略实现约 0.5 秒/步的推理延迟。
- **关键技术**：[[视频-动作交错生成]]、[[kv缓存历史整合]]、[[两阶段预测机制]]。
- **实验结果**：在真实世界六类任务上全面超越 π 0.5 和 Genie-Envisioner；在 RoboTwin 2.0 达到 92.0%/91.1% 成功率；在 LIBERO 达到 98.5% 成功率。

## 关键数据

| 指标 | 数值 |
|------|------|
| 微调所需演示数据 | 50 条/任务 |
| RoboTwin 2.0 Easy 成功率 | 92.0% |
| RoboTwin 2.0 Hard 成功率 | 91.1% |
| LIBERO 平均成功率 | 98.5% |
| 推理延迟（RTX 5880 Ada） | ~0.5 秒/步 |
| 控制频率 | ~2Hz |

## 意义

该工作标志着蚂蚁灵波从传统 VLA 模型（[[lingbot-vla]]）向世界模型架构的重要技术跃迁，为解决 [[具身智能数据困境]] 中的数据效率问题提供了有力方案。
