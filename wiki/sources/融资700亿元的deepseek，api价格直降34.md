# 融资700亿元的DeepSeek，API价格直降3/4

机器之心2026年5月23日发布的深度报道，覆盖DeepSeek同一周内的三大战略动作：API永久降价、百亿美元融资临近收官、组建Harness团队进军桌面端Agent产品。

## 核心内容

1. **API永久降价**：DeepSeek将限时优惠转为永久定价，价格降至原价1/4，国际同级别模型的不到1/10，以人民币计价。
2. **百亿美元融资**：彭博社报道DeepSeek正推进约700亿元人民币（100亿美元）融资，投前估值约450亿美元，将创下中国科技初创企业首轮融资历史纪录。
3. **Harness团队组建**：DeepSeek密集招募桌面端Agent产品团队，内部直接对标[[claude-code]]，提出"Model+Harness=Agent"公式。

## 关键信息

- 创始人[[梁文锋]]在与投资者洽谈中明确表态：突破性AI研究置于短期商业化之前，以实现AGI为最终目标
- 投资方阵容包括[[国家人工智能产业投资基金]]（拟出资约100亿元）、[[腾讯]]、IDG资本、Monolith资本，[[宁德时代]]、京东、网易也在谈判中
- 梁文锋本人据报可能个人注资约200亿元
- 降价背后可能的原因：推理优化重大突破或华为芯片成本优势（Yuchen Jin猜测）
