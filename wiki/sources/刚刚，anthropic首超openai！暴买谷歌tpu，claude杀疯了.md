# 刚刚，Anthropic首超OpenAI！暴买谷歌TPU，Claude杀疯了

## 摘要
报道指出 Anthropic 年化收入（ARR）首次超越 OpenAI，达到 300 亿美元，主要得益于 [[Claude Code]] 的爆发式增长和企业客户的激增。为应对指数级增长的需求，Anthropic 宣布与 [[谷歌]]、[[博通]] 签署重磅协议，将于 2027 年上线 3.5 GW 的下一代 TPU 算力集群。与此同时，报道揭示了 AI 行业面临的“烧钱飞轮”困境：尽管营收翻倍，但 [[研究计算成本]] 和 [[推理成本]] 的飙升导致巨额亏损（OpenAI 预计 2028 年亏损 850 亿美元）。

## 核心数据
- **Anthropic ARR**: 300 亿美元（2025 年底为 90 亿美元）。
- **大客户增长**: 2 个月从 500 家增至 1000 家（年支出超百万美元）。
- **算力规划**: 2027 年上线 3.5 GW TPU 集群（与谷歌、博通合作）。
- **OpenAI 预测**: 2028 年算力投入 1210 亿美元，亏损 850 亿美元。
- **全球算力分布**: 谷歌拥有 500 万块 H100 等量算力（TPU 为主），领跑全球。

## 关键论点
1.  **Claude Code 改变战局**: [[Claude Code]] 的成功迫使 OpenAI 重新调整战略，加码 Codex 助手并提升企业销售优先级。
2.  **算力是核心瓶颈**: [[AI算力军备竞赛]] 升级至“吉瓦时代”，Anthropic 通过 [[多平台硬件策略]]（AWS Trainium、谷歌 TPU、英伟达 GPU）平衡性能与风险。
3.  **统计口径差异**: Anthropic 将云合作伙伴（AWS/GCP）销售计入营收，而 OpenAI 不计入，这是其“首超”的部分原因。
4.  **B 端 vs C 端**: Anthropic 80% 营收来自企业，避免了像 OpenAI 那样为海量免费用户承担高昂推理成本。
