# 黄仁勋：龙虾就是新操作系统！英伟达7种芯片拼出算力怪兽，放话2027营收万亿美元

## 摘要
本文详细报道了英伟达 GTC 2026 大会，黄仁勋发布了包含 7 种芯片的超级计算系统 [[vera-rubin]]，并提出了 [[token-工厂经济学]]。文章重点介绍了 [[cpo-共封装光学]] 技术在打破物理限制中的作用，以及通过 [[分离式推理]] 实现 GPU 与 Groq LPU 协同工作的架构。此外，黄仁勋将 [[openclaw]] 定义为 AI 时代的操作系统，并预测每家 SaaS 公司都将转型为 Agent-as-a-Service。

## 核心观点

### 1. Token 工厂经济学
黄仁勋提出了一套新的商业模型，纵轴为 Token 吞吐量（产能/成本），横轴为 Token 速率（智能程度/延迟）。
- **免费层**：高吞吐、低速率，用于获客。
- **中间层**：$3-$6/百万 Token。
- **高级层**：$45/百万 Token，深度推理。
- **顶级层**：$150/百万 Token，关键任务实时响应。
核心论点：在数据中心功率受限（1GW）的物理约束下，**每瓦性能决定了一切**。

### 2. Vera Rubin：十年千万倍加速
英伟达下一代计算平台，由 7 种芯片垂直集成而成：
- **Rubin GPU**：3.6 exaflops 算力，NVLink 72 全互联。
- **Vera CPU**：采用 LPDDR5 的数据中心 CPU。
- **Groq LP30**：500MB 片上 SRAM，确定性数据流处理器。
- **BlueField 4 DPU + CX9 网卡**：AI 原生存储基础设施。
- **NVLink Switch**：第六代交换芯片。
- **Spectrum X CPO 交换机**：全球首款量产共封装光学交换机。

**性能飞跃**：从 Grace Blackwell 到 Vera Rubin + Groq，Token 生成速率从 200万/秒 跃升至 7亿/秒。两年时间提升 350 倍（摩尔定律同期仅 1.5 倍）。

### 3. 散热与互联的革命
- **100% 液冷方案**：不仅 GPU 浸没，连 NVLink 交换机也完全浸泡，互联在液冷模块内部完成。安装时间从 2 天缩至 2 小时。
- **CPO (共封装光学)**：光学器件直接封装到芯片上，电子在硅片表面直接转换为光子。消除了光模块和铜线中转，打破了机架尺寸的物理限制，实现了 72 GPU 全互联和 260TB/s 带宽。

### 4. 分离式推理
针对不同计算需求优化：
- **高吞吐**：Pre-fill 和 Attention 计算交给 [[vera-rubin]]（大显存）。
- **低延迟**：Decode 阶段卸载给 Groq LP30（极快 SRAM）。
两者通过以太网耦合，解锁了 **千 token/秒** 级别的极速生成。

### 5. OpenClaw：AI 时代的 Linux
黄仁勋用操作系统的语言重新定义了 [[openclaw]]：
- **资源管理**：调用模型、文件系统、工具。
- **调度系统**：Cron jobs、分步执行。
- **I/O 系统**：多模态交互。
类比 Windows（PC）、Linux（服务器）、Kubernetes（云），OpenClaw 被定义为 **Agent 计算机的操作系统**。

### 6. 商业预测
- **2027 年营收**：预计至少达到 **1 万亿美元**（覆盖 Blackwell 和 Rubin 订单）。
- **SaaS 转型**：每家 SaaS 公司都将变成 **Agent-as-a-Service** 公司。
- **招聘新标准**：Offer 里包含多少 Token 预算。

### 7. 未来预告
- **Feynman 架构**：下一代 GPU、LPU (LP 40) 和 CPU Rosa，支持铜线与光学双扩展。
- **Space One**：部署在太空的数据中心计算机，探索辐射散热方案。

## 关键数据
- **350 倍**：两年内 Token 生成速率的提升倍数。
- **50 倍**：Grace Blackwell 相比上一代 Hopper 的每瓦性能提升（Semi Analysis 数据，老黄谦虚说是 35 倍）。
- **72**：Rubin 系统支持的 GPU 全互联数量。
- **260TB/s**：全对全带宽。
- **25%**：建议分配给 Groq 的数据中心功率比例（针对高负载场景）。
