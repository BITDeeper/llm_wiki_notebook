# "什么Excel这函数那公式，我千问永远一步搞定"

本文详细报道了 [[千问]] 发布的全新 [[千问表格-agent]] 功能，该功能旨在通过 AI 技术解决用户在处理 Excel 表格时面临的“函数难记、操作繁琐”等痛点。

## 核心功能

文章通过实测案例展示了千问表格 Agent 的四大核心能力：

1.  **格式调整与美化**：用户只需通过自然语言描述（如“删掉空行”、“单价超过5元标黄”），AI 即可自动完成复杂的格式调整，无需手动操作快捷键或菜单。
2.  **边查边写（在线 RAG）**：AI 能够自动联网检索实时数据（如 2026 年新款手机参数）并整理成对比表格，解决了传统制作表格时需要跨网页复制粘贴的繁琐流程。
3.  **多轮对话整理**：支持通过多轮对话不断调整需求（如修改旅游攻略目的地），AI 会实时更新表格内容，最终生成包含多 Sheet 页的完整文件。
4.  **图片与文件转换**：利用多模态能力，将健身计划图片、名片、纸质文档等非结构化信息直接转换为结构化的 Excel 表格。

## 技术实现

文章揭示了该功能背后的技术架构：

-   **Planner（规划器）**：作为“大脑”，负责理解用户的自然语言需求，并将其拆解为具体的执行步骤（如是否需要联网、是否需要写代码）。
-   **沙箱执行**：在独立的隔离环境中生成并运行 Python 代码（使用 Pandas/OpenPyXL 等库），确保了处理复杂公式、图表及数据清洗时的安全性和准确性。
-   **端到端交付**：整个流程从需求输入到文件下载完全自动化，用户无需具备任何编程或 Excel 高级技能。

## 商业策略

值得注意的是，千问宣布该功能在 App、网页版及 PC 端**全渠道免费**。这一策略旨在降低 AI 使用门槛，实现技术普惠，与当前行业因 Agent 高算力成本而普遍转向付费的趋势形成对比。

## 实测结论

文章认为，千问表格 Agent 成功将制作表格从“当代酷刑”转变为“聊着天就能搞定”的零门槛体验，特别适合市场调研、项目策划、数据汇总等需要频繁处理信息的场景。
