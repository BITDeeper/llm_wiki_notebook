# 摘要

本文报道了 Anthropic 因拒绝五角大楼关于“大规模监控”和“全自动武器”的使用要求，导致价值 2 亿美元合同破裂，并随后遭到特朗普政府行政封杀的事件。文章详细记录了美国政府将 Anthropic 列为“供应链风险”的决策过程，以及 OpenAI、谷歌等竞争对手罕见地联合声援 Anthropic 的行业反应。

# 核心事件

1.  **谈判破裂**：五角大楼向 Anthropic 发出最后通牒，要求其开放“所有合法用途”，包括大规模监控和全自动武器。Anthropic CEO Dario Amodei 拒绝妥协，导致谈判破裂。
2.  **政府封杀**：特朗普下令“拉黑” Anthropic，痛斥其为“极左、觉醒派公司”。国防部长 Pete Hegseth 指示将 Anthropic 列为“供应链风险”，禁止所有联邦机构使用 Claude。
3.  **行业声援**：OpenAI 和谷歌的 600 多名员工签署联名信，反对将 AI 用于大规模监控或自主杀人。Sam Altman 和 Jeff Dean 等高层公开表态支持 Anthropic 的立场。

# 关键立场

-   **Anthropic 的红线**：坚持禁止大规模监控美国公民，禁止将模型用于全自动武器。
-   **OpenAI 的立场**：Sam Altman 明确表示 OpenAI 将守住与 Anthropic 相同的红线，强调 AI 不应被用于大规模监视或自主杀伤性武器。
-   **政府的立场**：指责 Anthropic 利用“服务条款”强迫军方服从其规则，认为这构成了供应链风险。

# 后续影响

-   **商业损失**：Anthropic 失去了价值 2 亿美元的政府合同。
-   **替代方案**：马斯克的 xAI 顺势补位，与军方签署协议允许 Grok 用于机密系统。
-   **法律威胁**：Anthropic 表示如果政府实施封杀，将诉诸法律。
