# 黄仁勋预言的100万亿市场，被易鑫金融Agent撞开一道口子

## 摘要
本文详细报道了中国领先的 AI 驱动金融科技平台 [[易鑫]] 如何通过 [[Model+Harness-范式]] 在汽车金融领域落地 Agentic AI。文章指出，通用大模型因缺乏持久记忆、稳定性不足及缺乏业务约束机制，难以直接满足金融行业对复杂业务链路（60+种材料、15+决策节点）的处理需求。易鑫通过发布专为汽车金融打造的 300 亿参数大模型 [[XinMM-AM1]]，并构建包含人类驾驭层、Agentic 驾驭层和数据驾驭层的 [[三层-Harness-体系]]，实现了全链路风险管控与“一次对话即办理”的效率革命。

## 核心观点
- **Model + Harness 公式**：Agentic AI 的落地不仅需要提供智能潜力的 Model（大模型），更需要提供执行标准、上下文管理和合规约束的 Harness（中间层框架）。
- **垂直行业壁垒**：金融业务具有极高的复杂性与专业性，通用模型或简单套壳应用无法触及核心风控与资金链路。
- **人机协同**：在关键合规节点实现 Agent 与真人的实时无缝切换，人类作为风险兜底者，确保业务安全。

## 关键技术细节
- **XinMM-AM1 模型**：参数量约 300 亿，单卡吞吐 370 tokens/s，响应延迟低于 200ms，拥有超过 15T tokens 的金融场景训练语料。
- **情绪洞察**：模型能通过语调、语速等非结构化数据识别客户真实意图（如不耐烦），并动态调整话术。
- **熔断机制**：当模型出现幻觉或违规承诺时，系统在毫秒级触发熔断并切换至人工干预。

## 行业意义
该案例验证了从大模型到 Agent 是 AI 向生产力落地的必然路径，特别是在金融等高合规要求的行业，[[Harness-AI-Infra]] 的建设往往比模型本身更为关键。
