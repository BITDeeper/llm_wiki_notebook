# 一周3.3k star，微软开启Skills自我进化！像训练神经网络一样训练技能

本文报道了微软开源的 [[skillopt]] 框架，该框架将 Agent 技能文档视为「可训练参数」，通过类似训练神经网络的循环机制（Rollout-Reflect-Edit-Gate）实现技能文档的自动化迭代优化。

## 核心内容

- **核心类比**：技能文档 = 外部权重，文本优化 = 梯度下降。不修改模型内部权重，仅在自然语言文本空间内优化 Agent 行为。
- **训练循环**：Rollout（前向传播）→ Reflect（反向传播）→ Edit（参数更新）→ Gate（验证门控），与深度学习训练循环一一对应。
- **关键设计**：[[文本学习率]]（默认 lr=4，防止灾难性遗忘）、[[验证门控]]（仅接受严格提升的候选）、[[被拒绝编辑缓冲区]]（负梯度信息）、[[元技能]]（优化器自身经验文档）。
- **评测结果**：7 个模型 × 6 个基准 × 3 种环境，全部 52 个评测组合中达到最优或并列最优。
- **迁移能力**：跨模型迁移（GPT-5.4 → nano 提升 15.2 分）、跨环境迁移（Codex → Claude Code 提升 31.8 分）。
- **部署零开销**：最终仅需一个 `best_skill.md` 文件，无需额外模型调用。

## 关键发现

1. 小模型受益更大（GPT-5.4-nano 平均提升 +24.9 分 vs GPT-5.5 +23.5 分）。
2. 自优化可行（同一小模型同时作为目标模型和优化器仍获显著提升）。
3. 系统化训练循环设计优于松散自我修正方法（全面超越 TextGrad、GEPA 等基线）。
