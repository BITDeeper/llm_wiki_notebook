# 消费级具身智能跨越式新品：算力提升1000倍，对标英伟达Jetson Thor芯片，成本仅1/10

机器之心发布的蔚蓝科技 BabyAlpha A3 新品发布报道。本文为产品宣传性质，关键性能参数（如"算力提升1000倍"、"成本仅1/10"、TPS数据等）缺乏独立第三方验证，录入维基时需注意标注。

## 核心内容

文章报道了[[蔚蓝科技]]发布新一代消费级四足机器人 [[BabyAlpha A3]]，核心亮点包括：

1. **异构计算集群**：6颗芯片（2×5nm + 2×8nm + 2×3D堆叠）分布式协同，实现[[具身智能边缘端异构计算]]架构，宣称算力对标英伟达 Jetson AGX Thor T5000（2070 TFLOPS），成本仅约300美金。
2. **超人类感知系统**：6600万像素视觉、223.2万点/秒空间感知、12麦立体阵列听觉，全面超越人类感知水平。
3. **端侧大模型可用性**：15B参数617 TPS、70B参数280 TPS，宣称消费级产品首次真正可用。
4. **全自主智能**：无需外部标签或基站，通过360°环视面阵和端侧Physical AI算法独立完成建图、定位与路径规划。
