# Grok最新模型吃上Cursor「加餐」，马斯克：Coding实现巨大改进

量子位报道，马斯克在X上透露 xAI 新基础模型 [[grok-v9-medium]]（1.5T参数）已完成训练，预计2-3周内发布。该模型补充训练中加入大量 [[cursor]] 数据，旨在赋予模型"真实工程手感"。同时，xAI 编程代理工具 [[grok-build]] 进入早期Beta测试阶段。

## 核心内容

- **V9-Medium 参数规模**：1.5T，是前代 v8-small（0.5T）的三倍
- **Cursor 数据训练**：数百万开发者的真实工作流数据被用于补充训练
- **Grok Build 功能**：计划模式、多子代理并行工作、Skills/Marketplace/MCPs 集成
- **Cursor 收购**：马斯克以 600 亿美元收购 Cursor，比去年11月估值翻倍
- **人才引入**：Cursor 核心工程负责人 [[andrew-milich]] 和 [[jason-ginsberg]] 加入 xAI
- **开源计划**：马斯克承诺年底开源 0.5T 模型
