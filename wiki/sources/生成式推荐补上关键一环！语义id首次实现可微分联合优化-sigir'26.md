# 源：生成式推荐补上关键一环！语义ID首次实现可微分联合优化

本文报道了被 SIGIR 2026 接收的论文《DIGER》，该研究由格拉斯哥大学、山东大学和莱顿大学合作完成。DIGER 首次在生成式推荐系统中实现了语义ID的可微分联合优化，解决了传统两阶段流程中语义ID学习目标（内容重建）与推荐目标（预测准确性）不一致的问题。

## 核心发现

- **两阶段流程的局限性**：现有方法通常先用 RQ-VAE 学习语义ID并冻结，再训练推荐模型。这导致语义ID无法直接服务于推荐任务。
- **联合优化的挑战**：直接使用直通估计器（STE）进行联合优化会导致训练不稳定和码本塌缩。
- **DIGER 的解决方案**：
  - 提出 **DRIL**（带探索的可微分语义ID），引入 Gumbel Noise 替代硬选择。
  - 设计 **SDUD**（基于标准差的不确定性衰减）和 **FrqUD**（基于频率的不确定性衰减）两种策略，平衡训练前期的探索与后期的收敛。
- **实验结果**：在 Amazon Beauty、Amazon Instrument 和 Yelp 数据集上，DIGER 在 Recall@10 和 NDCG@10 指标上均优于传统两阶段方法。

## 技术细节

DIGER 通过可视化 Code Usage Distribution 证明，其方法能更均衡、充分地利用码本，避免了 STE 方法中常见的塌缩现象。这表明离散语义表示完全可以进入最终目标的优化闭环。
