# 刚刚，英伟达重新定义PC！史上最高效CPU来了

机器之心报道，2026年6月1日英伟达 GTC Taipei 大会上，[[黄仁勋]]正式发布 [[rtx-spark]] 超级芯片，与[[微软]]联合打造基于 Arm 架构的新一代 Windows PC，提出 [[agent-pc|Agent PC]] 概念。

## 核心内容

- **产品发布**：[[rtx-spark|RTX Spark]] 超级芯片，集成 Grace CPU + Blackwell RTX GPU，最高 1 Petaflop AI 算力、128GB 统一内存
- **架构转型**：英伟达正式进入消费级 Arm PC 市场，挑战传统 x86 架构主导地位
- **生态适配**：Adobe Premiere、DaVinci Resolve、Blender 等专业软件已原生适配 Arm；主流电竞和 3A 游戏确认兼容
- **安全框架**：[[nvidia-open-shell|NVIDIA Open Shell]] 运行时 + Windows 安全原语，为端侧 Agent 提供沙箱隔离
- **Agent 生态**：[[openclaw]]、[[hermes-agent]] 等已适配新 Windows 安全平台

## 关键引用

> 「就像十年前我们重新定义了手机，从今天起，PC 的意义彻底变了。」——[[黄仁勋]]

> 「你只需要提出需求，PC 就会完成工作。RTX Spark 把 NVIDIA 已经打造的一切——CUDA、RTX、我们的 AI 平台——整合进一颗超级芯片。」

## 与现有维基的关联

本文为 [[本地推理]]、[[量化]]、[[任务执行范式]]、[[操作系统agent]] 等已有概念提供了硬件层面的支撑证据。[[openclaw]] 和 [[hermes-agent]] 的端侧适配进展进一步强化了其作为主流 Agent 框架的地位。
