# Claude Opus 4.8问世，Anthropic估值暴涨至9650亿美元

机器之心发布的关于 Anthropic 发布 Claude Opus 4.8 及其 H 轮融资的综合报道。

## 核心内容

### 模型发布
- [[claude-opus-4-8]] 正式发布，构建于 Opus 4.7 基础之上，主打诚实性提升、判断力增强和更长时间的独立工作能力。
- 多项基准测试超越 [[gpt-5.5]]，但用户反馈认为作为小版本更新提升"适中"。
- API 价格不变：输入 $5/M Token，输出 $25/M Token。极速模式价格为快速模式的 1/3。

### 新功能
- [[动态工作流]]：Claude Code 研究预览功能，支持数百个子智能体并行运行数天，适用于代码库级迁移。
- [[投入度控制]]：用户可调节模型推理深度（Low / High / Extra High / Max），Opus 4.8 默认"高投入"。
- 系统条目（System Entries）：Messages API 新增能力，支持运行期间动态更新指令。
- 极速模式：运行速度提升至常规模式 2.5 倍。

### 融资与估值
- [[anthropic]] H 轮融资 650 亿美元，投后估值 9650 亿美元（较 2 月 G 轮 3800 亿暴涨 154%）。
- 年化收入突破 470 亿美元（较 4 月超 300 亿大幅增长）。
- 领投方：Altimeter Capital、Dragoneer、Greenoaks、[[sequoia-capital|红杉资本]]。
- 内存厂商美光、三星、SK 海力士首次加入投资阵营。

### 下一代模型
- [[claude-mythos]] 预览版已向少数机构开放网络安全试用，作为"Glasswing 项目"一部分。
- 预计未来数周内正式发布。
