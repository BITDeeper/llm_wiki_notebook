# 浏览器原地变龙虾！Chrome上线Skills，技能一键复用，Agent帮你干活

## 摘要
本文报道了 Google Chrome 浏览器推出的 Gemini Skills 功能，标志着浏览器从信息展示工具向任务执行助手的转型。该功能允许用户将 Prompt 固化为可复用的技能，支持跨设备同步和多标签页上下文读取，且完全免费内置。

## 核心内容

### Chrome Skills 功能特性
- **一键复用**：用户可将复杂的 Prompt 保存为“技能”，通过斜杠指令（/）一键调用。
- **预置技能库**：Google 提供了 50 多个现成技能，涵盖食谱营养计算、护肤品成分分析、YouTube 视频总结等场景。
- **跨设备同步**：登录 Google 账号即可在不同设备间同步保存的技能。
- **多标签页上下文**：支持 AI 同时读取多个标签页内容以执行任务（如并排对比产品参数）。
- **安全确认**：涉及日历、邮件等实际操作时，系统会先请求用户确认。

### 行业背景与对比
- **历史类比**：文章将当前局势比作 90 年代的浏览器大战，认为这将决定人机交互的新入口。
- **竞品动态**：
  - **Opera (Neon版)**：推出了类似的 Cards 功能，同样支持 Prompt 复用。
  - **Microsoft Edge**：被指其 Copilot App 本质上是 Edge 浏览器的套壳，显示了浏览器 Agent 化的激进趋势。
  - **AI 原生浏览器**：Perplexity 的 Comet、ChatGPT Atlas 以及美团（光年之外）的 Tabbit 均在探索这一领域。

### 商业模式影响
文章强调 Chrome Skills “免费，默认内置在 Chrome 里，不需要买任何订阅”，这反映了 AI 商业模式从单一 SaaS 订阅向依托超级入口的免费/捆绑服务的转变。

## 关键观点
- **门槛降低**：相比于在专门的 Agent 平台（如“龙虾”或 Claude Code）中使用，浏览器内置的技能复用将使用门槛降至最低。
- **交互范式转变**：浏览器核心功能从“展示网页”变为“替你完成任务”。
