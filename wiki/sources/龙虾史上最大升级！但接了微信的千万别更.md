# 龙虾史上最大升级！但接了微信的千万别更

## 概述
本文详细报道了 [[openclaw]]（龙虾）框架在 2026 年 3 月 22 日发布的 `2026.3.22-beta.1` 版本更新。此次更新被称为“史上最大升级”，引入了 [[自更新]]、[[ssh-sandbox]]、[[clawhub]] 插件市场等核心功能，并对模型支持（[[GPT-5.4]]、[[MiniMax M2.7]]）进行了全面同步。然而，更新也导致了 [[clawbot]] 在 [[微信]] 等平台的兼容性崩溃。

## 核心更新内容

### 1. 生态与插件系统
- **ClawHub 上线**：官方插件市场 [[ClawHub]] 成为插件安装的首选源，npm 降级为备选。
- **API 清理**：彻底移除旧的 `openclaw/extension-api`，且不提供兼容垫片，强制迁移至 `openclaw/plugin-sdk/*`。
- **安全策略**：拒绝安装来自官方克隆仓库之外的远程插件清单（如外部 Git 或 HTTP）。

### 2. 安全与架构
- **SSH 沙盒**：引入原生 [[ssh-sandbox]] 支持，允许使用密钥、证书和 `known_hosts` 进行身份验证。
- **OpenShell**：专注于沙盒生命周期管理，支持 Mirror（镜像）模式。
- **漏洞修复**：修复了可能导致 Windows 密码泄露、命令伪造、iOS 配对码滥用及 macOS 审批界面 Unicode 隐藏漏洞。

### 3. 模型同步
- **OpenAI**：默认模型切换至 [[GPT-5.4]]，支持 mini 和 nano 版本。
- **MiniMax**：全员升级至 [[MiniMax M2.7]]，新增高速版。
- **智谱与 Grok**：同步 GLM 4.5/4.6 及 Grok 最新目录。

### 4. 性能与交互
- **冷启动优化**：启动时间从分钟级降至秒级。
- **紧凑目录回退**：当提示词过长时，自动压缩技能目录以保留核心信息。
- **UI 优化**：新增圆角调节、聊天气泡展开至画布等功能。

## 已知问题与争议
尽管更新幅度巨大，但引发了严重的兼容性问题：
- **微信崩溃**：用户反馈更新后 [[clawbot]] 插件在微信端直接失效，并收到 `WARNING: Dangerous Code Patterns` 警告。
- **WhatsApp 故障**：部分用户报告 WhatsApp 无法正常使用。
- **生态阵痛**：激进的架构升级（移除旧 API）虽然净化了生态，但也导致了短期内的连接性断裂。

## 评价
文章指出，OpenClaw 正在从一个单纯的脚本工具演变为一个**高度平台化、安全且生态闭环**的 AI 操作系统。其难点不在于更新量，而在于如何平衡“激进升级”与“向后兼容性”。
