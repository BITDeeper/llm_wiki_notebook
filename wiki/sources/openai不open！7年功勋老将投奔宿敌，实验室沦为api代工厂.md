# OpenAI不Open！7年功勋老将投奔宿敌，实验室沦为API代工厂

## 摘要
本文详细报道了 OpenAI 研究副总裁 [[jerry-tworek]] 于 2026 年 1 月 7 日离职的事件，分析其离职背后的深层原因：OpenAI 从 AGI 实验室向 API 供应商转型，导致核心人才流失和技术创新受阻。文章指出，[[scaling-law]] 面临边际递减，旗舰项目 [[orion]] 被降级为 GPT-4.5，而 [[system2]] 推理技术虽是未来方向，却因高成本与季度 KPI 压力在公司内部难以推进。

## 核心观点

### 1. 核心人才流失
- **[[jerry-tworek]] 离职**：被称为“推理之父”，入职近 7 年，主导了 Codex、o1 及 o3 模型的研发。
- **离职原因**：直言“必须离开才能做那些在 OpenAI 难以开展的研究”，反映了科研自由度受商业利益限制。
- **行业趋势**：包括 Shengjia Zhao 和 Jason Wei 在内的多位核心人才流向 [[meta-superintelligence-lab]]。

### 2. 技术路径转折：Scaling Law 撞墙
- **预训练瓶颈**：单纯依靠增加算力和数据量的扩展路径失效。
- **Orion 项目失败**：未达到预期的指数级跃升，被 Sam Altman 降级为 GPT-4.5。
- **新范式确立**：后训练和推理（[[system2]] 思维链）成为提升智能的主要路径，即“用时间换智能”。

### 3. 商业与科学的冲突
- **季度 KPI 压力**：管理层要求降低延迟、压缩成本，以适配 Copilot 等商业场景，这与深度推理的高成本特性相悖。
- **制度摩擦**：公关、法务和商业利益限制了科学探索的边界（如可解释性研究、非 RLHF 路径探索）。
- **组织转型**：OpenAI 从“探索型”组织转向“利用型”组织，被指沦为“API 代工厂”。

## 关键引述
> “我得离开这里，才能做那些在 OpenAI 难以开展的研究。” — [[jerry-tworek]]

> “Scaling Laws 不中用了。” — 行业共识

> “当科学探索的边界由公关、法务决定，而非科学规律时，像 Tworek 这样的研究者只能出走。”

## 相关背景
- **竞争对手动态**：Meta 提供大量 H100 集群，支持开放权重路线，与 OpenAI 的封闭形成对比。
- **历史参照**：文章将 OpenAI 比作当年的诺基亚，拥有市场份额和现金流，却失去了定义未来的能力。
