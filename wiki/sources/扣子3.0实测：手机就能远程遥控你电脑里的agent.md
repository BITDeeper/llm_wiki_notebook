# 扣子3.0实测：手机就能远程遥控你电脑里的Agent

量子位作者金磊对字节跳动旗下AI智能体平台[[扣子]]3.0版本的全面评测文章。文章通过四组实测（AI热点仪表盘、本地工程化项目、AI桌宠应用、文章→视频生成+手机远程读取电脑文件），展示了扣子3.0的核心升级。

## 核心内容

文章提出扣子3.0的三层升级架构：

1. **项目化**：将AI交互从临时对话升级为围绕同一目标持续推进的项目空间，资料、角色、任务、产物统一沉淀
2. **Agent编排**：多Agent按角色分工协作（选题、资料、产品、代码等），而非单模型"全能"路线
3. **工具链打通**：覆盖编程项目、视频项目、本地Agent接入、行业技能包、多端同步、桌面端本地文件处理

## 关键论点

- AI产品竞争焦点从"谁更聪明"（单模型能力）转向"谁更会打配合"（协作系统）
- 扣子3.0支持导入[[claude-code]]、[[codex]]、[[openclaw]]等本地Agent
- 手机端可远程调度电脑端Agent处理本地文件，实现[[跨端联动]]
- 行业技能包将金融、法律、医疗、自媒体等垂直领域的数据库、专业方法和高频工作流封装为可调用能力
- 视频项目默认使用 Seedance 2.0 模型

## 局限性

文章属于媒体产品评测，存在宣传色彩，未讨论Agent协作的实际出错率、跨端延迟等局限性。
