# 杨植麟当主持人的大模型圆桌：张鹏罗福莉夏立雪都放开说了

## 概述
本文记录了 2026 年中关村论坛期间的一场高密度圆桌讨论，由月之暗面创始人 [[杨植麟]] 主持，嘉宾包括小米 [[罗福莉]]、智谱 AI [[张鹏]]、无问芯穹 [[夏立雪]] 及港大 [[黄超]]。讨论核心围绕 [[openclaw]]（龙虾）引发的 Agent 范式变革、算力受限下的技术路径、以及推理时代的商业与基础设施挑战。

## 核心观点

### Agent 时代的成本与价值
- **[[张鹏]]**：解释了 [[glm-5-turbo]] 涨价背后的逻辑。从“对话”到“干活”，Token 消耗是 **10 倍甚至 100 倍** 的增长。涨价是对 Agent 任务高推理成本（规划、Debug、多模态处理）的合理回归，也是为了维持商业可持续性。
- **[[夏立雪]]**：指出自 OpenClaw 流行以来，Token 调用量 **每两周翻一番**，目前已增长 10 倍。这种增速类似于 3G 时代的流量爆发，标志着行业正式进入 **“推理时代”**。

### 中国团队的独特路径
- **[[罗福莉]]**：提出了 **[[算力受限下的最优解]]** 概念。她认为中国团队的优势不在于算力堆叠，而在于在 NVLink 互联带宽受限等约束下，倒逼出的模型结构创新（如 DeepSeek 的 MoE、MLA）。
- **长上下文与自进化**：她强调超长上下文（100万-1000万 token）不仅是技术指标，更是模型 **“越用越好用”** 和实现 **[[自进化架构]]** 的物理基础。只有低成本的长上下文推理，高生产力任务才能落地。

### 基础设施与软件形态演进
- **[[夏立雪]]**：提出了 **Agentic Infra** 的愿景。现有云基础设施是为人类工程师设计的（分钟级响应），而 Agent 时代需要毫秒级响应的基础设施，甚至基础设施本身也应是一个智能体。
- **[[黄超]]**：提出了 **[[agent-native]]** 概念。未来软件可能不再以人类 GUI 为中心设计，而是原生面向 Agent 使用（如 API、CLI）。人类将只保留愉悦性交互，执行性工作交给 Agent。

### 技术痛点与展望
- **[[黄超]]**：分析了 Agent 技术的三大模块——Planning（长程任务规划）、Memory（信息压缩与分层）、Tool Use（高质量 Skill 生态）。指出当前高质量 Skill 仍然稀缺，且多 Agent 协同带来的上下文管理是巨大挑战。
- **自进化时间窗口**：[[罗福莉]] 预测，随着 Agent 框架和模型能力的结合，具备强自进化能力的 Agent 将在 **1-2 年内** 出现，科研效率将提升十倍。

## 关键词
- **生态**（[[黄超]]）：开源生态是 Agent 从“玩具”变为“生产工具”的关键。
- **自进化**（[[罗福莉]]）：Agent 时代最关键的方向，模型能在长上下文中自我迭代。
- **可持续**（[[夏立雪]]）：关注能源、算力到 Token 再到 GDP 的完整经济链路，打造“AI Made in China”的全球 Token 工厂。
- **算力**（[[张鹏]]）：推理需求爆发（百倍增长）与算力供给之间的矛盾是当前最大瓶颈。
