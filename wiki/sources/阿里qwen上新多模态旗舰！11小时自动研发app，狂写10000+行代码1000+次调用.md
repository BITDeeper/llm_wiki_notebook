# 阿里Qwen上新多模态旗舰！11小时自动研发App，狂写10000+行代码1000+次调用

量子位（QbitAI）作者梦晨于2026年6月3日发布的报道，详细介绍阿里推出的 [[qwen-3.7-plus]] 多模态交互式混合Agent模型。

## 核心内容

报道重点展示了 [[qwen-3.7-plus]] 的三大核心能力：

1. **长程App自动研发** — 基于 [[多模态混合agent|Hybrid-Agent系统]] 连续稳定运行超过11小时，自动完成英语词汇学习App的完整研发周期（需求文档→编码→部署→测试→版本演进），产出10000+行代码，执行1000+次Agent调用。
2. **macOS Stocks App复刻** — 智能体先与原生应用交互理解UI布局，再生成SwiftUI源码并接入真实行情API，10项功能验证全部通过。
3. **基准测试** — Terminal Bench 2.0和Kernel Bench L3详细配置披露，代码任务各模型接近但长程任务拉开差距，多模态任务为Qwen强项。

## 关键技术细节

- Hybrid模式将视觉感知、语言理解、代码生成、工具使用、GUI操作统一放入同一推理循环
- 支持 `preserve_thinking` 功能，在多轮对话中保留每轮思考内容
- 兼容OpenAI规范的chat completions和responses API
- 在 [[claude-code]]、[[openclaw]]、Qwen Code等不同Agent框架中均可稳定运行

## 开放问题

文末提到大量开发者希望Qwen-3.7 Plus能像Qwen之前的模型一样开放权重、支持本地部署，暗示该模型可能暂未开放权重。
