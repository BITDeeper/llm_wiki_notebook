# 顶流里最快！智谱，你是在「喷」代码吧

量子位发布的关于 [[智谱]] 旗舰模型高速版 API [[glm-5-1-highspeed]] 的深度评测文章。该 API 达到 400 tokens/s 的推理速度，是目前顶流模型中最快的。

## 核心内容

文章通过四项实测验证了 GLM-5.1-highspeed 的能力：
1. **复杂 Canvas 动画网页生成**：包含星云粒子效果、音频节奏模拟、可调参数面板
2. **模糊指令迭代修改**：在已有代码基础上通过模糊自然语言指令（如"波纹再快一点""光晕偏暖"）进行实时调参
3. **2D 游戏实时场景修改**：通过"导演指令"（下雪、下雨、爆炸）实时改变游戏世界状态
4. **万字长文 10 秒处理**：一次性完成海报标题、短视频文案、宣传语、公众号文案、JSON 汇总等多任务

## 技术解读

[[智谱]] GLM 团队与 [[tile-rt]] 团队联合打造，在三个层面进行系统工程优化：
- **推理引擎**：针对 GLM-5.1 架构重写核心推理路径
- **调度系统**：动态批处理、请求合并、KV 缓存调度降低尾延迟
- **基础设施**：推理集群部署、网络链路和负载均衡协同优化

TileRT 的核心创新是将调度单元从传统 operator/kernel 下沉到 tile 级别，通过编译期静态编排和常驻 GPU 的 persistent Engine Kernel 压缩调度开销。

## 关键判断

文章指出国产大模型 API 竞争正从"能不能答得好"走向"能不能又快又稳地干活"，高速推理使 [[ai-agent快时代|AI Agent]] 体验出现质变：等待变少、反馈变密、任务推进更连续。同时文章也客观指出速度不能被神化，生产环境还需验证稳定性、成本、并发能力等。
