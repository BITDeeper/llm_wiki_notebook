# 微软：Claude Code的token，我也烧不起了

## 摘要

机器之心2026年5月22日发布的报道，揭示微软本周取消内部 Claude Code 授权的决策内幕。表面原因是基于 token 的计费方式导致成本过高，深层原因是 Claude Code 在微软内部严重蚕食了 GitHub Copilot CLI 的使用率。

## 核心内容

### 成本危机
- 微软取消内部 Claude Code 授权，因按 token 计费成本过高
- Uber CTO 4月发布内部备忘录，称四个月烧光2026全年AI预算
- 美国AI软件价格过去一年上涨20%-37%
- GitHub 正在所有产品中取消固定费率，转向按用量计费

### 产品蚕食
- 2025年12月微软向数千名内部开发者开放 Claude Code
- 开放前91%工程团队使用 GitHub Copilot，开放后被严重蚕食
- 微软要求 GitHub 团队在6月底前疯狂迭代 Copilot CLI
- 微软曾考虑收购 [[cursor]] 以补足短板，后因监管顾虑转向其他标的

### 行业拐点
- AI补贴时代正在终结，企业面临真实成本暴露
- 两大实验室（Anthropic、OpenAI）过去半年悄悄提价
- 企业面临二选一困境：削减使用或实验室继续补贴

### Claude Code 新功能
- Claude Code 团队成员 Boris Cherny 宣布新增 /usage 命令
- 支持查看 Skills、Agents、MCPs 和插件的 token 使用明细
- CLI 版已支持，桌面版即将推出
