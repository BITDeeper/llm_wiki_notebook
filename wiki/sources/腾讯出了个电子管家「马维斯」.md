# 腾讯出了个电子管家「马维斯」

量子位发布的关于腾讯应用宝团队推出操作系统级AI智能体"马维斯（Marvis）"的一手体验报道。文章详细展示了马维斯的多Agent协作架构（"牛马六人组"）、系统级操作能力、跨设备协同功能以及隐私/效率双模式设计。

## 核心内容

- **产品定位**：跳过应用层，直接在操作系统底层运行的AI智能体，定位为"电子管家"
- **技术架构**：PM + File Agent + Computer Agent + APP Agent + Search Agent + Browser Agent 六角色并行协作
- **核心能力**：文件管理、系统运维、应用联动、网络搜索、网页交互、跨设备协同
- **隐私设计**：隐私模式（全本地运算）与效率模式（云端思考+本地执行）双轨可选
- **开发团队**：腾讯应用宝团队
- **支持平台**：目前支持Windows电脑和安卓手机，Mac版本开发中
- **发布状态**：邀请码制体验阶段

## 关联概念

本文是 [[任务执行范式]] 从对话助手向系统管家演进的典型案例，其多Agent架构直接体现了 [[1-n-agent调度]] 范式，任务侧边栏的可视化设计呼应了 [[场景白盒化推理]] 理念。
