# 3个人带100个AI程序员，一个月烧掉130万美元！OpenAI：钱我出

新智元2026年5月17日报道，编辑：所罗门。

## 核心内容

报道了 [[peter-steinberger|Peter Steinberger]]（[[openclaw|OpenClaw]] 之父）在 X 平台公开的惊人账单：其3人团队使用约100个 Codex AI agent 实例，30天花费 $1,305,088.81，消耗6030亿 token，发起760万次请求。[[openai|OpenAI]] 为这笔费用报销。

## 关键信息

- **团队规模**：3人 + 约100个 Codex 实例
- **月度成本**：$1,305,088.81
- **Token 消耗**：6030亿
- **请求数量**：760万次
- **AI 任务范围**：审PR、找安全漏洞、去重issue、改bug、监控benchmark、回归检测、会议后自动开PR
- **工具**：Peter 自研的 [[codexbar|CodexBar]] 用于追踪多种 AI 编程工具的成本和用量

## 重要观点

- Peter 本人表示"关闭快速模式后，花费低于一个工程师的成本"
- 大部分 token 消耗用于 [[openclaw|OpenClaw]] 的开发
- 文章提出 [[token作为生产资料]] 的概念：token 正在成为新的核心生产要素
- 成本递降推演：130万→13万→1.3万，AI 编程成本将快速下降至普及水平
