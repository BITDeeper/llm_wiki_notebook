# 100万亿Token看懵硅谷！全球一半算力写代码，另一半在「搞颜色」

## 概述
本文基于 [[OpenRouter]] 和 a16z 联合发布的《基于OpenRouter的100万亿Token实证研究》，揭示了2025年AI发展的真实图景。报告分析了超过100万亿个Token的元数据，覆盖300多个模型和60多个提供方，提供了基于真实算力消耗的行业洞察。

## 核心发现

### 1. 开源模型逆袭与中国力量崛起
- **市场份额**：开源模型流量占比已稳定在 **30%**，不再是闭源模型的“平替”，而是特定场景的首选。
- **中国力量**：中国开源模型（如 [[DeepSeek V4]]、Qwen、Kimi、GLM）的使用份额从2024年末的1.2%飙升至近 **30%**。
- **竞争格局**：从“一个DeepSeek打遍OSS”转变为“五六个开源模型各有稳定流量”。

### 2. 推理模型成为新常态
- **流量占比**：推理优化模型（如 o1, Grok Code Fast）流量占比飙升至 **50%以上**。
- **行为转变**：AI从“生成文本”转向“思考问题”，平均Prompt长度增长4倍（至6k+），工具调用常态化。

### 3. 两大主导场景：编程与角色扮演
- **编程**：占总流量 **50%以上**，是统治一切的生产力工具。[[Anthropic]] 在此领域占据60%以上份额。
- **角色扮演**：占开源流量的 **52%**，是统治创造力的引擎。[[DeepSeek V4]] 在此领域表现突出（2/3流量）。

### 4. 地缘格局变化
- **亚洲崛起**：亚洲付费使用量翻倍至 **31%**。
- **语言分布**：英语占82%，简体中文以近 **5%** 的份额成为第二大AI交互语言。

## 关键概念

### [[水晶鞋效应]]
用户留存取决于“首发即匹配”。若新模型能完美解决特定高难度痛点（穿上水晶鞋），用户将形成极高粘性的“基石群组”，不易因价格或竞品而流失。

### [[杰文斯悖论]]
当模型效率提高、价格降低时，用户不仅不减少总支出，反而因为使用场景大幅增加（更长上下文、更频繁调用）导致总Token消耗飙升。

### [[中杯模型]]
参数规模在15B-70B之间的模型正在成为市场主流，在能力与效率之间达到最佳平衡（PMF）。

## 商业启示
- **价格弹性弱**：整体降价10%仅带来<1%增量。
- **多模型生态**：闭源负责高价值/高风险任务，开源负责低成本/大容量任务。
- **留存本质**：模型厂商的护城河在于率先解决关键工作负载，而非单纯追求排行榜第一名。
