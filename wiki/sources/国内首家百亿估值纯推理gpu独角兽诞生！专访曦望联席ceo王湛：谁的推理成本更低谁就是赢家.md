# 国内首家百亿估值纯推理GPU独角兽诞生！专访曦望联席CEO王湛：谁的推理成本更低谁就是赢家

## 核心摘要
本文是对国内纯推理 GPU 独角兽公司 [[曦望]] 联席 CEO [[王湛]] 的深度专访。文章指出，随着 Agent 时代的到来，AI 算力需求发生了 [[结构性反转]]，推理算力需求首次全面超越训练算力（预计 2026 年达 4-5 倍）。王湛提出“谁掌握最低的推理成本，谁就是赢家”，并发布了新一代推理 GPU 芯片 [[启望-s3]]，目标将百万 [[token-成本]] 压至一分钱。

## 关键观点

### 1. 算力需求的结构性反转
- **现象**：推理算力需求呈现指数级增长，2026 年预计达到训练算力的 4-5 倍。
- **原因**：Agent 时代的高频、多轮调用导致 Token 消耗增长数十倍甚至上百倍。
- **结论**：单位 Token 的成本成为决定 AI 普及的关键，企业关注点从“能不能用”转向“用不用得起”。

### 2. 技术路线：专用优于通用
- **策略**：All in 推理，放弃训练能力，通过裁剪训练模块将晶体管和功耗集中用于推理。
- **目标**：将百万 Token 成本降低 90%，实现“一分钱”目标。
- **对比**：通用 GPU（训推一体）在大规模推理场景下性价比不足。

### 3. 启望 S3 的技术突破
- **计算层**：AI Core 原生深度定制，GEMM 和 Flash Attention 利用率分别达到 99% 和 98%；原生支持 FP4 全链路低精度运算。
- **系统层**：
  - 国内首个使用 [[lpddr6]] 的推理 GPU，显存最大接近 600GB（解决长上下文记忆瓶颈）。
  - 首个支持 PCIe Gen6 的国产 GPU，系统通信带宽翻倍。
- **生态**：全栈自研（硬件 AI Core 和软件全栈 100% 自研），同时实现对 CUDA 生态 99%+ 的兼容。

### 4. 团队与组织
- **“三位一体”架构**：
  - [[徐冰]]（董事长，商汤联合创始人）：战略与融资。
  - [[王勇]]（联席CEO，前 AMD/昆仑芯）：芯片研发。
  - [[王湛]]（联席CEO，前百度）：商业化与运营。
- **人才机制**：提供中国 GPU 公司中最大的 ESOP 池，打造“六边形战士”团队。

### 5. 市场判断
- **泡沫论**：承认当前估值乐观，但认为 AI 价值填补速度远超互联网时代。
- **供需**：市场处于“供不应求”状态，瓶颈在于生产工具（光模块、内存）而非需求。
- **目标客户**：瞄准要求最苛刻的互联网大厂。
