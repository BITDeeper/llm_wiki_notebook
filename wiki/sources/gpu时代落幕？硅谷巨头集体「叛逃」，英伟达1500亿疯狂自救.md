# GPU时代落幕？硅谷巨头集体「叛逃」，英伟达1500亿疯狂自救

## 摘要
本文详细报道了 AI 算力行业正在发生的结构性转变：从单一依赖 [[英伟达]] GPU 架构转向 [[谷歌tpu]]、[[Groq]] LPU 及 [[Cerebras]] 晶圆级芯片等多样化架构。文章指出，[[去gpu化]] 的核心驱动力在于对能效比（每美元 Token 数）和低延迟的极致追求，而 [[数据搬运瓶颈]] 是传统 GPU 架构的致命短板。

## 核心论点

1.  **GPU 统治力瓦解**：高盛预测非 GPU 芯片占比将从 36% 升至 45%（2027）。[[Anthropic]] 投入 210 亿美元采购 [[谷歌tpu]]，[[OpenAI]] 首次在主力产品（GPT-5.3-Codex-Spark）中使用 [[Cerebras]] 芯片以实现实时代码生成。
2.  **竞争焦点转移**：行业关注点从“峰值算力”转向“每美元 Token 数”。GPU 因数据在显存和计算单元间频繁搬运导致的高能耗、高延迟问题日益凸显。
3.  **英伟达的自救**：英伟达斥资 200 亿美元（溢价三倍）收购 [[Groq]]，获取其 [[软件定义硬件]]（LPU）技术，试图通过架构创新解决数据搬运问题。
4.  **未来架构方向**：[[近内存处理]]、[[3d堆叠]]、[[低延迟互连]]、[[晶圆级芯片]] 及 [[算力网格]] 技术成为演进主流。

## 关键数据

-   **TPU v7**：同等算力下功耗仅为英伟达 B200 的 40%-50%。
-   **Cerebras CS 3**：推理性能比英伟达 DGX B200 快 21 倍，成本与功耗均降低 1/3；支持 OpenAI 实现每秒超 1000 token 的生成速度。
-   **Groq LPU**：首 token 延迟比 TPU v7 降低 20%-50%，每 token 成本降低 10%-30%。

## 行业影响
文章认为，算力世界的单极格局正在松动，定义下一代 AI 上限的不再是单纯的算力规模，而是能耗、延迟与确定性共同构成的新标尺。对于国产芯片而言，这是在底层架构上实现创新超越的窗口期。
