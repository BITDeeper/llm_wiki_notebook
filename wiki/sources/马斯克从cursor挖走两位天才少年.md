# 摘要

本文报道了 [[xAI]] 从 AI 编程工具公司 [[Cursor]] 挖走两位核心高管 [[Andrew Milich]] 和 [[Jason Ginsberg]] 的新闻。文章分析了此次人事变动背后的战略意图——即 [[Elon Musk]] 正在加速构建“数字擎天柱”（Grok 版本的 OpenClaw），旨在模拟完整公司的运作。同时，文章也揭示了 [[Cursor]] 面临的市场竞争压力（来自 [[Claude Code]] 等）以及 [[xAI]] 内部严重的联合创始人离职潮。

## 核心要点

-   **高管变动**：[[Andrew Milich]]（原 Cursor 产品与工程负责人）加入 [[SpaceX]]，[[Jason Ginsberg]]（原 Cursor 工程负责人）加入 [[xAI]]，两人均直接向 [[Elon Musk]] 汇报。
-   **战略意图**：[[xAI]] 正在研发“数字擎天柱”项目，旨在将依赖键盘鼠标的决策型工作数字化，模拟完整公司运作。这与 [[OpenClaw]] 的理念高度相似。
-   **人才背景**：Milich 和 Ginsberg 是长期搭档，曾共同创立加密通讯软件 [[Skiff]]（后被 [[Notion]] 收购），并在 [[Cursor]] 负责 Agent 相关工作（如移动端编程、Slack 汇报）。
-   **行业竞争**：[[Cursor]] 的市场份额正受到 [[Claude Code]] 和 [[Codex]] 的挤压，面临“大模型套壳”护城河薄弱的质疑。
-   **内部动荡**：[[xAI]] 陷入“围城”困境，11 位联合创始人中仅剩 2 人留守，近期 [[Zihang Dai]] 和 [[Guodong Zhang]] 等华人联创相继离职。

## 关键细节

-   **Agent 产品化经验**：两人在 [[Cursor]] 期间主导了网页版 Agent 的开发，强调“随时随地访问”（移动端 [[Vibe Coding]]）和“打通通讯软件”（Agent 主动汇报），这些经验将被带入 [[xAI]]。
-   **文化冲突**：[[xAI]] 内部推崇“闪电文化”（扁平、高强度），虽然吸引了渴望挑战的人才，但也导致了极高的离职率。
-   **资源优势**：相比 [[Cursor]] 面临的底层模型商竞争，[[xAI]] 拥有基础模型、算力和资金优势，为构建超级 Agent 提供了保障。
