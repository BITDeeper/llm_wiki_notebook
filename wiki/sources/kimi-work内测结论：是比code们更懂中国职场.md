# Kimi Work内测结论：是比Code们更懂中国职场

量子位编辑梦瑶撰写的 Kimi Work 内测体验报告，发表于2026年6月4日。

## 核心内容

文章对月之暗面推出的 [[kimi-work]] 进行了深度体验式评测，将其定位为"[[vibe-working]]"范式的代表产品——区别于 [[vibe-coding]] 的编程场景，Kimi Work 瞄准的是非技术职场用户的日常办公需求。

## 评测场景

1. **周报生成**：将上周稿件批量输入，自动生成包含概览、图表、深度复盘、内容矩阵分析、策略复盘等模块的结构化周报
2. **PPT制作**：调用PPT Skill将周报转化为彩色交互式幻灯片
3. **信息收集**：通过 [[webbridge]] 浏览器插件自动抓取小红书具身智能相关笔记，整理为结构化表格
4. **Skill化写作**：尝试让Agent学习作者文风并生成文章，效果有限（AI感重、存在二创现象）

## 关键发现

- [[webbridge]] 浏览器操控能力是核心差异化特性，体感优于竞品
- Skill能力支持自定义DIY、内置Skill和本地Skill调用
- Agent集群支持最多300个子Agent并行，但需付费
- 资源消耗控制优于竞品，未出现电脑发烫卡死问题
- 输出格式稳定性有待优化（Markdown/表格切换不稳定）

## 局限性

- 基于单一作者的体验式评测，非系统性基准测试
- Skill化写作效果有限，作者坦言"写作确实很难完全skill化"
- Agent集群功能未实际付费测试
