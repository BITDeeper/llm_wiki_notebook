# ICML 2026｜让 Agent 真正协同作战：GoS 为多智能体推理构建共享信念状态

本文报道了[[南开大学]]与联想合作提出的 **Graph of States（GoS）** 框架，该工作已被 [[icml-2026]] 正式接收。

## 核心内容

GoS 是一个面向通用[[溯因推理]]任务的[[神经符号架构]]框架，通过为多智能体协作构建[[共享信念状态]]，解决现有推理框架在真实世界溯因任务中的结构性缺陷。

### 解决的问题
现有 CoT、ToT、GoT、FoT 等推理框架在医疗诊断、分布式系统故障排查等场景中暴露出四类失败模式：证据伪造、上下文漂移、回溯失败和过早停止。这些失败的根源在于缺乏显式状态表示和状态控制机制。

### 核心架构
- **认知层**：中心智能体与专家智能体协作，对应现实世界专业角色分工
- **符号层**：由因果图和状态机组成，显式维护推理状态并导航约束推理过程
- **推理焦点**：聚焦当前层级中置信度最高的假设，将发散探索转化为有导航的调查
- **回溯与下钻**：基于明确转移规则的状态转换机制

### 实验结果
- **医疗诊断**：在改造后的 DiagnosisArena 基准上取得 39.86% Match 和 78.99% Relevant
- **分布式系统故障诊断**：在 150 个真实生产环境 incident 上取得 70.67% Match 和 88.00% Relevant，Match 比最强基线高出 36.67 个百分点

### 产业化
xCloud 联想智能云正加速将 GoS 技术融入其智能运维产品体系。
