# GPT-5.2提前泄露？今夜，OpenAI要拿Gemini 3祭天！

## 摘要
本文报道了 OpenAI 即将发布的 GPT-5.2（代号“Garlic/大蒜”）模型，该模型被指为专门狙击谷歌 Gemini 3 的“复仇武器”。文章指出，GPT-5.2 首次亮相于 [[Cursor]] IDE 而非 ChatGPT 网页端，强调了编程能力已成为 AI 竞争的核心战场。同时，文章揭示了 OpenAI 内部的战略焦虑，CEO Sam Altman 发出“红色警报”，承认领先优势缩小，并暂停 [[Sora]] 等项目以集中算力应对竞争。此外，谷歌因部署 [[Nano-Banana-Pro]] 导致 API 免费额度大幅削减，反映了行业面临的 [[算力零和博弈]]。

## 核心要点

### GPT-5.2 (Garlic) 的关键特性
- **定位**：针对编程和逻辑推理彻底重构的专用模型，非 GPT-5 的简单微调。
- **性能**：据 OpenAI 首席研究官 Mark Chen 称，在编程和逻辑上超越 [[Gemini-3]] 和 Anthropic Opus 4.5。
- **代理能力**：能执行比以往任何模型都更长的任务，理解整个代码仓库，并在修改一个文件时同步调整引用的其他文件，极少出现幻觉。
- **首发平台**：选择 [[Cursor]] 作为首发战场，而非 ChatGPT 网页端，标志着编程能力是衡量模型智能的硬指标。

### OpenAI 的战略转向
- **生存压力**：奥特曼在内部备忘录中警告，谷歌的进展可能带来“经济逆风”，OpenAI 的领先优势正在缩小。
- **重心转移**：从追求 AGI 转向商业生存。暂停 [[Sora]] 视频生成项目，推迟广告和个人助理功能，集中资源提升模型质量。
- **预训练回归**：承认预训练阶段的重要性。此前认为“预训练已死”，但 [[Gemini-3]] 的成功证明预训练在规模化下仍能带来有效优势。

### Shallotpeat 项目
- **代号含义**：Shallot（红葱头）+ Peat（泥炭土），隐喻“现有预训练的土壤不理想，需要重做地基”。
- **技术目标**：旨在修复预训练阶段的错误，重做模型预训练的“地基”。
- **整合**：该项目的错误修复方案已被整合进 GPT-5.2 (Garlic) 中。

### 算力零和博弈
- **OpenAI 的取舍**：在算力有限的情况下，被迫牺牲高算力消耗、变现难的 [[Sora]]，将资源集中在能产生直接收入的文本/推理模型（GPT-5.2）上。
- **谷歌的配额休克**：2025年12月，谷歌大幅削减 Gemini API 免费额度（Flash 降至 20次/天），以释放算力支持 [[Nano-Banana-Pro]]（Gemini 3 Pro Image）的部署。
