# 源文件摘要

本文报道了 OpenAI 发布的新一代图像生成模型 [[ChatGPT Images 2.0]]。OpenAI CEO [[Sam Altman]] 亲自主持直播，称其为从 GPT-3 到 GPT-5 级别的飞跃。

## 核心亮点

- **思考模式**：首个具备推理能力的图像模型，能联网搜索、二次自检，并一次性生成最多 8 张风格连贯的图片。
- **像素级精度**：实现了极高的细节控制，Demo 中展示了在米粒上刻字的能力。
- **多语言质变**：解决了中日韩（CJK）文本渲染难题，OpenAI 研究科学家 [[陈博远]] 演示了全中文漫画生成。
- **照片级逼真**：通过模拟胶片颗粒、过曝等“不完美”消除了“AI 感”，支持 3:1 到 1:3 的全尺寸输出。
- **Arena 榜首**：在 Arena 盲测的全部 7 个类别中排名第一，证实此前神秘模型 [[DuckTape]] 即为 Images 2.0。

## 技术细节

底层模型 [[gpt-image-2]] 已通过 API 开放。该模型结合了 [[视觉智能]]（理解与生成），支持基于上传照片的复杂任务（如生成穿搭建议）。
