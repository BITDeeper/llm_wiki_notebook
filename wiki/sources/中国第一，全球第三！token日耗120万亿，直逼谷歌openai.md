# 中国第一，全球第三！Token日耗120万亿，直逼谷歌OpenAI

## 摘要
本文报道了 [[火山引擎]] 旗下的 [[豆包大模型]] 日均 Token 使用量突破 120 万亿，成为全球第三家（仅次于 OpenAI 和 Google）达到此规模的厂商。文章分析了 Token 消耗激增的两大驱动力：[[AI 视频]]（如 [[Seedance]] 2.0）和 [[AI Agent]]（文中称为“养虾”）。同时，文章探讨了企业落地 AI 面临的模型、Skills 和安全三大难点，并指出 [[MaaS]]（模型即服务）正成为 AI 时代的核心商业模式，Token 调用量是衡量 AI 落地最诚实的指标。

## 核心数据
- **Token 消耗**：日均 120 万亿（2026年4月），较三个月前（63万亿）翻倍，较两年前（1200亿）增长 1000 倍。
- **行业地位**：全球第三家日耗超 100 万亿 Token 的厂商。
- **个人用户增长**：过去一个多月，个人用户 Token 消耗增长约 16 倍。

## 关键事件
1.  **OpenClaw 镜像站上线**：[[OpenClaw]] 官宣 ClawHub 中国镜像站上线，由 [[BytePlus]]（火山引擎海外业务）赞助基础设施。这解决了国内开发者下载 Skill 的网络难题，推动了 Agent 生态的发展。
2.  **Seedance 2.0 开放公测**：火山引擎宣布 [[Seedance]] 2.0 面向企业开放公测。该模型在 Artificial Analysis 盲测中获文生视频和图生视频双榜第一，支持多模态输入（文字、图片、音频、视频）且物理准确度大幅提升。
3.  **豆包 2.0 Pro 评测**：在 SuperCLUE“养虾”场景专项测评中，[[豆包大模型]] 2.0 Pro 综合能力排名国内第一，仅次于 Claude Opus 4.6 和 GPT-5.4。

## 行业洞察
-   **Token 经济**：英伟达 CEO 黄仁勋称 Token 将是未来最值钱的大宗商品。Anthropic 和 OpenAI 的营收预计将指数级增长，但算力支出（OpenAI 预计 2030 年达 6650 亿美元）同样巨大。
-   **MaaS 趋势**：企业倾向于通过公有云调用模型而非自建 GPU，以应对模型快速迭代和运维复杂性。AWS 认为 MaaS 收入未来将与 EC2 不相上下。
-   **企业落地难点**：[[火山引擎]] 总裁 [[谭待]] 指出，企业“养虾”卡在模型（大脑）、Skills（手脚）和安全（底线）三方面。

## 相关概念
-   [[养虾]]：指代部署和维护 AI Agent 的俗称。
-   [[多模态输入]]：[[Seedance]] 2.0 支持最多 12 个参考文件组合输入。
-   [[安全认证]]：火山引擎通过了信通院“智能助理智能体产品可信能力认证”和“安全防护产品有效性认证”。
