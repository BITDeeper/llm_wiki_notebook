# AI能自己打红警了！经济拉满零交战惨遭打脸，玩家笑疯

## 概述
本文报道了 Hugging Face 发布的开源项目 [[openra-rl]]，该项目将经典 RTS 游戏《红色警戒》改造为大模型 Agent 的训练场。文章详细介绍了其架构设计（C# 引擎 + gRPC + Python）、异步交互机制、并发优化成果以及基于 [[qwen3-32b]] 模型的实战测试结果。

## 核心发现
- **实战表现**：使用 Qwen3 32B 模型在简单难度下进行 5 局测试，结果全部平局，且零次战斗交锋。Agent 能够建立经济体系（得分 0.58-0.80），但完全缺乏进攻意愿（战斗维度得分为 0）。
- **架构优势**：通过 [[异步交互架构]]，成功将秒级推理的 LLM 与毫秒级（25Hz）的游戏引擎解耦，使得 `advance`（快进）指令占据了 57% 的工具调用。
- **工程突破**：v2 版本通过共享 ModData，将 64 局并发的内存占用从 40GB 降至 6GB，重置延迟降低 40 倍（至 256ms）。
- **评价体系**：引入 8 维 [[奖励向量]]（经济、基建、战斗等），提供了比单纯胜负更精确的失败模式诊断。

## 关键技术细节
- **工具集**：暴露了 50 个 [[mcp-model-context-protocol]] 游戏工具，支持任何兼容 MCP 的 LLM 客户端驱动游戏。
- **学习机制**：实验发现，[[提示注入式学习]]（Prompt Injection，即将经验注入下一局提示）能有效修复建造顺序错误，但无法解决战斗意愿缺失的问题，后者需要依靠强化学习（如 GRPO）进行权重更新。
- **生态接入**：原生接入 [[openenv]] 生态，支持 TRL、torchforge 等训练框架即插即用。

## 意义
该项目将 RTS Agent 研究的门槛从“几千块 TPU + 定制架构”降低到“消费级显卡 + pip install”，为研究大模型在复杂实时环境中的规划与执行能力提供了公开、可复现的基准。
