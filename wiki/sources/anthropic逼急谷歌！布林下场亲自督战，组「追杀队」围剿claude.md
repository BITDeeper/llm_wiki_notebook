# 源：Anthropic逼急谷歌！布林下场亲自督战，组「追杀队」围剿Claude

## 概述
本文报道了谷歌因 [[anthropic]] 在编程领域的巨大成功而再次拉响“红色警报”，联合创始人 [[sergey-brin]] 亲自挂帅组建攻坚队，试图挽回在 [[claude-code]] 面前的劣势。文章揭示了编程能力已成为通往 [[ai-takeoff]] 的关键路径，以及 [[gemini]] 在企业市场的落后现状。

## 核心数据
- **Claude Code 收入**：9个月内从零增长至25亿美元年化收入。
- **市场份额**：在企业编程市场占据54%份额，OpenAI 为21%。
- **内部渗透率**：Anthropic 内部100%代码由AI编写，谷歌约为50%。
- **Anthropic 估值**：3800亿美元（G轮融资后）。

## 关键事件
1. **谷歌组建攻坚队**：由 [[sergey-brin]] 亲自督战，DeepMind CTO 参与，目标是填补智能体执行力差距。
2. **策略转向**：优先训练能理解谷歌内部私有代码库的模型，而非仅关注外部客户。
3. **强制执行**：布林下达强制指令，要求工程师在复杂任务中必须使用内部AI工具。
4. **OpenAI 战略调整**：关停 Sora 项目，将资源重新分配给编程和企业产品。

## 战略意义
文章指出，编程能力被视为通向“AI起飞”（即AI自我进化）的必经之路。一个足够强的代码智能体结合数学和实验能力，可能实现AI研究的自动化。这解释了为何三大巨头（谷歌、OpenAI、Anthropic）在此领域寸土必争。
