# 源：突发，马斯克xAI解散了！22万张GPU忍痛全给Claude

## 核心摘要
2026年5月，[[Elon Musk]] 宣布解散其创立的 AI 公司 [[xAI]]，并将其并入 [[SpaceX]]。几乎同时，SpaceX 将 xAI 建造的全球最强超算集群 [[Colossus 1]]（22万张 GPU，300+兆瓦）全部租给 [[Anthropic]]，用于支持 [[Claude]] 模型的推理。这一举动标志着 AI 竞争从“模型战”正式转向“基建战”，马斯克通过 [[AI基础设施对冲策略]]，在法律和商业两个层面对 [[OpenAI]] 形成了围剿之势。

## 关键事件

### 1. xAI 解散与并入
- **时间**：2026年5月。
- **背景**：xAI 虽然拥有强大的算力设施（Colossus 1），但其 Grok 模型在开发者生态中无法与 Claude (SWE-bench 80.8%) 和 GPT-5.5 抗衡。
- **财务状况**：2025年预计亏损约130亿美元，月烧约10亿美元。
- **结果**：xAI 品牌消失，成为 SpaceX 旗下一款产品，承认了 [[模型战争失败]]。

### 2. Colossus 1 租给 Claude
- **资产**：22万张 GPU，300+兆瓦计算能力。
- **交易**：SpaceX 将 Colossus 1 全部算力租给 Anthropic。
- **影响**：Claude 当天即宣布 Claude Code 用量上限翻倍，高峰时段限速取消，Opus API 限制上调。SpaceX 成为唯一能“立刻解渴”的算力合作伙伴（相比谷歌/亚马逊的 2026-2027 年上线计划）。

### 3. 双重围剿 OpenAI
- **法律层面**：马斯克在联邦法庭起诉 OpenAI，核心诉求是罢免 [[Sam Altman]] 和 Brockman 的董事席位，指控其违背非营利初心。
- **商业层面**：通过给 OpenAI 的最大对手 Claude 提供核心算力，直接削弱 OpenAI 的竞争优势，增强 Anthropic 的火力。

## 深度分析

### 竞争范式转移
文章指出，谷歌和马斯克都选择了通过控制算力来对冲风险，而非死磕单一模型。这被称为 [[AI基础设施对冲策略]]：如果不能确保自己的模型是唯一赢家，那就确保最大竞争对手的对手也是自己投的。

### Anthropic 算力联盟
随着 SpaceX 的加入，Anthropic 背后的算力联盟空前强大：
- 亚马逊：5GW 容量协议 + 250亿美元投资
- 谷歌+博通：5GW TPU 容量 + 400亿美元投资
- 微软+英伟达：300亿美元 Azure 容量
- Fluidstack：500亿美元基础设施
- **SpaceX**：22万块 GPU，300兆瓦，**现在就能用**
