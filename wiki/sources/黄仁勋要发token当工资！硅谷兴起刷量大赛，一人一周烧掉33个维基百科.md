# 黄仁勋要发Token当工资！硅谷兴起刷量大赛，一人一周烧掉33个维基百科

## 摘要
本文报道了硅谷兴起的“[[tokenmaxxing]]”现象，即工程师和公司竞相消耗大量 AI Token 以追求生产力或排名。文章指出，[[coding-agent]] 的普及使得 Token 消耗呈指数级增长，[[黄仁勋]]甚至提出将 Token 预算作为继工资、奖金、期权之后的“第四种薪酬”。同时，文章也揭示了这种刷量大赛背后的不可持续性及“[[token焦虑]]”。

## 核心数据与案例
- **OpenAI 内部竞赛**：一位匿名员工单周处理 2100 亿 Token，相当于填满 33 个维基百科。
- **高额账单**：一位 [[claude-code]] 用户单月账单超过 15 万美元。
- **个人支出激增**：风投人 Tomasz Tunguz 半年内年化 AI 支出从 7200 美元涨至 10 万美元。
- **商业增长**：[[anthropic]] 收入预期翻倍，Claude Code 年化收入达 25 亿美元；OpenAI Codex 周活超 200 万。

## 关键观点
1. **Coding Agent 改变工作流**：工具（如 [[claude-code]]、[[codex]]）能 24/7 无人监督工作，自动派生子任务，导致 Token 消耗从手动变为自动喷射。
2. **Token 货币化**：[[黄仁勋]]在 GTC 2026 提议给工程师提供相当于一半年薪的 Token 预算，使其能力放大 10 倍。
3. **补贴驱动**：当前的繁荣部分源于 [[推理补贴]]（如 200 美元订阅提供 1000 美元额度），类比早期的打车/外卖补贴战。
4. **质量与数量的博弈**：OpenAI 内部排行榜只衡量消耗量，不衡量产出质量，引发了关于“空转”和“看起来很忙”的质疑。
