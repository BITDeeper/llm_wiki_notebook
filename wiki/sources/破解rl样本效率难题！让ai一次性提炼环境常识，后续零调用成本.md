# 破解RL样本效率难题！让AI一次性提炼环境常识，后续零调用成本

## 概述
本文报道了南京大学章宗长、俞扬团队与腾讯叶德珩团队的一项联合研究。该研究提出了一种利用大语言模型（LLM）一次性提炼“环境背景知识”的新范式，旨在解决强化学习（RL）中样本效率低、训练成本高及任务泛化难的问题。

## 核心方法
研究团队提出利用 GPT-4 等大模型从无标签的随机探索轨迹中提炼出对整个环境通用的“背景知识”，并将其转化为数学形式的势函数（Potential Function），通过 [[奖励塑形]] 技术融入下游任务的训练流程。

### 三种技术路线
论文提出了三种将 LLM 知识转化为奖励信号的具体方法：
1.  **BK-CODE**：让 LLM 编写 Python 代码作为奖励函数，通过迭代反馈优化代码质量。
2.  **BK-PREF**：让 LLM 对不同轨迹进行偏好比较（二选一），利用 Bradley–Terry 模型将偏好转化为奖励。
3.  **BK-GOAL**：让 LLM 识别轨迹中的关键子目标，通过计算当前状态与目标的相似度来给予奖励。

## 关键发现
- **零调用成本**：仅需在知识提炼阶段调用一次 LLM，后续所有下游任务的训练过程均无需再调用 LLM，显著降低了工程成本。
- **任务无关性与泛化**：在 Minigrid 环境中，基于简单“Goto”任务提炼的知识，成功迁移到了更复杂的“Goto-seq”和“Pickup”任务上，且未见过的目标物体类型也能被有效识别。
- **稀疏奖励问题的解决**：在 Crafter 这类长链任务环境中，背景知识提供了中间过程的反馈信号，有效引导智能体达成有用子目标，大幅提升了样本效率。
- **规模扩展性**：当地图规模从 20x20 扩大到 30x30 时，传统基线方法性能崩溃，而引入背景知识的方法依然保持了高效的学习能力。

## 实验环境
- **Minigrid**：用于测试基础任务泛化和新目标识别。
- **Crafter**：用于测试复杂生存游戏中的稀疏奖励和长链规划能力。

## 意义
该研究为解决 [[具身智能数据困境]] 提供了新思路，证明了通过引入先验知识（LLM 常识）而非单纯依赖算力堆砌，可以有效对抗 [[scaling-law]] 带来的资源压力，实现更高效的智能体训练。
