## 关键概念

- **测试时扩展**
  - 定义：在推理阶段而非训练阶段投入更多计算资源，通过候选探索、质量评估和动态筛选来提升生成质量
  - 重要性：Stream-T1 的核心理念，提供了一条不重新训练模型即可提升视频质量的新路径
  - 维基状态：不存在，需新建。与已有概念 `scaling-law` 相关但不同——后者关注训练阶段，此处关注推理阶段

- **流式视频生成**
  - 定义：逐段（chunk）自回归地生成视频，每一段依赖前序段的输出，区别于一次性生成整段视频
  - 重要性：Stream-T1 的应用场景，将测试时扩展与流式生成结合是本文首创
  - 维基状态：不存在，需新建

- **Stream-Scaled Noise Propagation（流式缩放噪声传播）**
  - 定义：将当前 chunk 的噪声与历史 chunk 的噪声主动关联，使生成探索空间锚定在已验证的高质量轨迹上
  - 重要性：三个核心模块之一，确保时序平滑过渡，几乎不增加推理时间

- **Stream-Scaled Reward Pruning（流式缩放奖励剪枝）**
  - 定义：结合即时短期评估与滑动窗口长期评估，对多个候选结果进行综合筛选
  - 重要性：三个核心模块之一，在局部画面美感与全局时序一致性间取得平衡

- **Stream-Scaled Memory Sinking（流式缩放记忆沉淀）**
  - 定义：根据语义边界检测，将重要历史信息沉淀为长期记忆，重复内容融合，不重要内容丢弃
  - 重要性：三个核心模块之一，解决长视频生成中历史信息管理的核心难题

- **主体漂移 / 画面退化**
  - 定义：长视频生成中常见的质量问题，表现为生成内容中主体外观或背景随时间推移发生不可控变化
  - 重要性：Stream-T1 重点解决的核心痛点

## 主要论点与发现

- **核心主张**：将测试时扩展引入流式视频生成，可在不重新训练模型的前提下，显著提升长视频的时序稳定性、语义一致性和画面质量。
- **证据支撑**：
  - 在 5 秒和 30 秒视频生成任务上与 CausVid、Self-forcing、LongLive 等方法进行定量对比，多项指标领先
  - 30 秒长视频场景中展现出更强的长期稳定性
  - 消融实验证明三个模块各有不可替代的作用（去 Memory Sinking → 背景稳定性退化；去 Noise Propagation → 结构伪影；去 Reward Pruning → 语义偏离/动作僵硬）
- **证据强度**：中等偏强。有定量对比和消融实验，但本文为媒体转载的论文解读而非原始论文，缺少具体数值细节；需查阅原始论文（arXiv: 2605.04461）获取完整数据。

## 矛盾与张力

- **内部张力**：论文声称 Stream-Scaled Noise Propagation 和 Reward Pruning "几乎不增加额外的推理时间成本"，但测试时扩展的本质就是在推理阶段投入更多计算。这一表述可能仅指模块本身的额外开销较小，而非整体推理成本不变——生成多个候选结果并筛选必然增加计算量。
- **与现有知识的张力**：无直接冲突。测试时扩展是已知研究方向，但将其系统性地应用于流式视频生成属于新探索。
