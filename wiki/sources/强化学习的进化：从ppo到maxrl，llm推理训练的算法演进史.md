# 强化学习的进化：从PPO到MaxRL，LLM推理训练的算法演进史

本文由 Alexander Weers 撰写，机器之心编译，系统性地回顾了 2024 至 2026 年间大语言模型（LLM）推理训练中强化学习算法的演进历程。文章从基础的 REINFORCE 和 PPO 讲起，详细剖析了以 [[DeepSeek]] 的 [[GRPO]] 为代表的第二代算法，以及后续的 [[RLOO]]、[[Dr. GRPO]]、[[DAPO]]、[[CISPO]]、[[MaxRL]]、[[DPPO]] 和 [[ScaleRL]] 等变体。

## 核心论点

文章指出，算法演进的核心驱动力在于**效率与稳定性**。第一代 [[PPO]] 算法虽然成功，但需要维护四个大模型（策略、旧策略、参考策略、价值模型），显存占用巨大。第二代算法（如 [[GRPO]]）通过移除 Critic 模型并引入组内基线，节省了约 50% 的显存，使得大规模强化学习成为可能。

此外，文章强调了**归一化细节**和**信任域机制**对模型行为的深远影响。例如，[[Dr. GRPO]] 发现样本级平均归一化会导致模型生成冗长的错误回复；而 [[CISPO]] 则指出 PPO 的对称裁剪机制会抑制低概率但关键的推理词（如 "Wait"）的学习。

## 关键技术演进

1.  **移除 Critic 模型**：[[GRPO]] 和 [[RLOO]] 均证明了在 LLM 微调中，简单的统计基线（如组均值）可以替代学习到的价值函数，大幅降低内存消耗。
2.  **信任域优化**：[[DAPO]] 提出了非对称裁剪，[[CISPO]] 解耦了裁剪与梯度流，[[DPPO]] 则尝试用策略散度替代概率比来定义信任域。
3.  **目标函数重构**：[[MaxRL]] 将优化目标从 Pass@1 转向 Pass@k，证明了最大似然估计实际上是 Pass@k 梯度的无限调和混合。
4.  **大规模实证**：[[ScaleRL]] 通过 40 万 GPU 小时的消融实验，确立了异步训练、FP32 Logits 和零方差过滤等最佳实践。

## 开放挑战

文章最后总结了当前领域面临的四大挑战：**信用分配**（如何将结果归因于具体的推理步骤）、**样本效率**（强化学习的信息增益极低）、**极难样本**（模型无法生成任何正确轨迹时的优化停滞）以及**泛化能力**（从数学/代码向通用领域的迁移）。
