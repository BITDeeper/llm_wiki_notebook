# 刚刚，小扎砸143亿的「牛油果」来了！硬刚GPT-5.4，硅谷最贵华人首作

## 概述
本文详细报道了 Meta 超级智能实验室（MSL）成立 9 个月后发布的首个作品——[[Muse Spark]]（代号「牛油果」）。文章指出，该模型在 Artificial Analysis 测试中得分 52，远超去年的 [[Llama 4 Maverick]]（18分），标志着 Meta 重返 AGI 第一梯队。

## 核心亮点

### 性能表现
- **综合得分**：Artificial Analysis 得分 52，仅次于 [[Gemini 3.1 Pro]]、[[GPT-5.4]] 和 Opus 4.6。
- **多模态优势**：在 CharXiv（86.4）和 ScreenSpot Pro（84.1）上表现出色，视觉理解能力仅次于 Gemini。
- **医疗健康**：HealthBench Hard 得分 42.8，显著领先竞争对手，得益于 1000 多名临床医生参与的数据清洗。
- **短板**：代码生成（LiveCodeBench Pro 80.0）和抽象推理（ARC AGI 42.5）仍落后于 GPT-5.4 和 Opus。

### 技术创新
- **[[沉思模式]]**：利用 [[多 Agent 并行思考]] 技术，在不增加延迟的情况下提升准确率（从 54% 提升至 58%）。
- **[[思维压缩]]**：通过在强化学习中引入「思考时间惩罚」，模型学会了用更少的 Token 解出同样的问题，Token 消耗仅为 Opus 的 1/3。
- **算力效率**：预训练算力需求降至 Llama 4 的 1/10，展示了新架构的高效性。

### 战略与团队
- **团队背景**：由 Meta 首席 AI 官 [[Alexandr Wang]] 领导，核心成员包括从 OpenAI、DeepMind 跳槽的华人研究员（如 [[Shengjia Zhao]]）。
- **产品定位**：[[个人超级智能]]，强调多模态感知（如拍照识物、健康建议）和社交数据整合（购物模式）。
- **商业模式**：免费但闭源，通过 Meta 社交生态（Instagram、Facebook）进行商业化整合。

## 关键数据
- **Token 效率**：跑完 Intelligence Index 仅消耗 5800 万输出 Token，远低于 Opus 4.6（1.57 亿）。
- **HLE 得分**：在 Humanity's Last Exam（无工具）中得 50.2 分，超过 Gemini 和 GPT-5.4。
- **Scaling 曲线**：强化学习呈现平滑的对数线性增长，证明模型具备泛化能力而非死记硬背。

## 行业影响
Muse Spark 的发布被视为 Meta 对 OpenAI 和 Anthropic 的强力回应。其「免费+闭源」的策略与 [[Anthropic]] 的订阅制形成对比，试图通过社交生态优势构建护城河。同时，多 Agent 并行思考的架构为解决推理延迟和成本问题提供了新思路。
