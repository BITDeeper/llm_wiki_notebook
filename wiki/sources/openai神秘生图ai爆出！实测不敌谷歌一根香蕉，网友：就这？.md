# OpenAI神秘生图AI爆出！实测不敌谷歌一根香蕉，网友：就这？

## 摘要
本文报道了 OpenAI 即将发布的图像生成模型 [[GPT Image 2]]（内部代号 [[Chestnut]]/[[Hazelnut]]）与谷歌 [[Nano Banana Pro]] 的对比测试结果。实测显示，OpenAI 的新模型在物理色彩理论理解和人物面部真实度上不及谷歌模型，但在代码嵌入和世界知识方面表现出色。

## 核心发现

### 模型表现对比
- **物理色彩理论测试**：OpenAI 的 Chestnut 和 Hazelnut 模型均未能正确生成符合物理光学规律的“黄红混合橙色表皮”，而 [[Nano Banana Pro]] 成功通过了该测试。
- **人物面部真实度**：开发者反馈 OpenAI 模型生成的人脸看起来比较假，缺乏真实感。
- **细节稳定性**：[[Hazelnut]] 模型在生成骰子时出现了点数错误的[[图像幻觉]]，而 [[Chestnut]] 表现较好，被推测为 Nano Banana Pro 的最强竞争对手。

### 技术特性
- **代码嵌入能力**：[[GPT Image 2]] 被发现特别擅长在图像中嵌入代码，甚至能生成手写风格的白板字。
- **基础架构推测**：有开发者认为 GPT Image 2 可能仍基于 GP-4o 完成，虽有提升但未达市场预期的激进迭代。

### 行业动态
- **发布节点**：[[GPT Image 2]] 预计随 [[GPT-5.2]] 一同上线，而谷歌也准备推出 Nano Banana Flash 和 [[Gemini 3 Flash]]。
- **竞争态势**：谷歌与 OpenAI 在图像生成领域的竞争进入白热化，双方均在近期推出新一代模型。
