# 太抓马了！马斯克OpenAI开庭，硅谷巨富互揭老底像极了村口吵架

## 概述
本文详细记录了埃隆·马斯克起诉 [[openai]] 及其高管 [[山姆·奥特曼]] 和 [[格雷格·布罗克曼]] 的庭审过程。这场诉讼的核心在于指控 OpenAI 违背了创始时的非营利使命，转变为由微软控制的营利实体。庭审中，双方互揭老底，马斯克在证人席上表现失态，而 OpenAI 方面也被曝光了早期创始人的私利算计。

## 核心指控与叙事

### 马斯克的指控：诱饵调包
马斯克试图证明 OpenAI 实施了 [[诱饵调包]]（Bait and Switch）：
- **初始承诺**：2015年以“非营利、造福全人类”吸引捐赠和人才。
- **现状**：转变为估值8500亿美元的营利公司，受微软控制。
- **核心比喻**：[[尾巴摇狗]]（The tail is wagging the dog），指营利子公司反客为主，控制了非营利使命。
- **诉求**：索赔1500亿美元，阻止 IPO，并要求解除奥特曼和布罗克曼的职务。

### OpenAI 的辩护：控制权之争
OpenAI 律师 [[威廉·萨维特]] 展示了马斯克早期的邮件和短信，试图证明：
- 马斯克早在 2015-2017 年就主张 OpenAI 应该营利化。
- 马斯克离开的真正原因是因为未获得绝对控制权（51%股权），而非所谓的利益冲突或专注于特斯拉。
- 马斯克曾试图将 OpenAI 并入特斯拉，被拒后切断资金并挖走核心研究员 [[安德烈·卡帕西]]。

## 庭审关键证据与事件

### 1. 马斯克的六次失态
马斯克在证人席上多次情绪失控，削弱了其作为“AI 安全救世主”的形象：
1.  **承认真实动机**：被迫承认离开是因为没拿到控制权，而非为了避免利益冲突。
2.  **安全人设碰壁**：被质疑 xAI 的 [[grok]] 模型生成了大量有害内容，与其标榜的安全理念不符。
3.  **证词前后矛盾**：关于是否阅读了 2018 年术语表的证词与庭前录像不一致，当庭大喊“我读了标题！”。
4.  **管理风格争议**：承认骂 OpenAI 安全团队是“蠢货”是他的“管理风格”。
5.  **无知于安全标准**：声称不知道行业通用的“Safety Card”是什么，尽管 xAI 正在发布该文件。
6.  **情绪失控**：上午刚承诺不会大喊，下午就因术语表问题当庭咆哮。

### 2. 承认使用 [[蒸馏]] 技术
在盘问中，马斯克公开承认 [[xAI]] 使用了 OpenAI 的模型进行 [[蒸馏]] 训练。这一承认极大地削弱了他关于 OpenAI “知识产权被盗”的道德指控，显示行业内部存在普遍的技术借鉴和竞争。

### 3. 布罗克曼的日记
庭审曝光了联合创始人 [[格雷格·布罗克曼]] 的私人日记，成为对 OpenAI 不利的核心证据：
- **摆脱马斯克**：2017年，日记写道这是“摆脱马斯克的唯一机会”。
- **财务算计**：日记中记录了“在财务上，什么能让我身家达到10亿？”，并指出接受马斯克的条件会摧毁经济回报。
- **两面派行为**：一边当面保证坚守非营利，一边私下考虑转型为 B-Corp（共益公司）。

### 4. 奥特曼的短信
- 2022年，马斯克发短信指责 OpenAI 转向营利化感觉像“诱饵调包”，奥特曼回复“我同意，感觉确实不好”。
- 2023年公开决裂后，奥特曼私下发短信称马斯克是“英雄”，承认没有马斯克 OpenAI 无法成立，试图软化关系。

### 5. 扎克伯格的介入
庭审曝光了马斯克与 [[扎克伯格]] 的短信记录，显示 Meta 曾致函加州总检察长支持马斯克起诉，并探讨过联合竞标 OpenAI 资产的可能性。

## 法律概念：慈善信托
马斯克律师主张，OpenAI 的捐款构成了法律上的 [[慈善信托]]（Charitable Trust）。根据加州法律，一旦接受捐赠，资金必须用于声明的慈善目的。OpenAI 后期的营利化转型被视为违反了这一法律义务。

## 庭审后续
- 证人席上的攻守即将易位，[[山姆·奥特曼]]、[[格雷格·布罗克曼]]、[[萨蒂亚·纳德拉]] 及 [[希冯·齐利斯]] 等关键证人即将出庭。
- 此案不仅关乎巨额赔偿，更将决定 AI 行业非营利组织与商业资本结合的法律边界。
