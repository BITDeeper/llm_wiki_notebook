# 摘要

报道了硬件创业公司 [[吾云创新]] 正在研发的 [[agent-computer]]，一种没有键盘、鼠标、屏幕的“三无”个人计算设备。该设备旨在解决本地部署 AI Agent 时面临的硬件资源短缺、配置复杂及隐私安全问题，试图融合 PC、NAS 和存储功能，提供比 [[mac-mini]] 更具性价比的专属运行环境。

# 核心内容

## 产品定义与形态
- **三无设计**：设备没有键盘、鼠标和屏幕，因为其主要使用者是 Agent 而非人类。
- **交互方式**：通过 IM 或软件接口下达指令，Agent 在后台自主运行任务并推送结果。
- **角色转变**：人类从设备操作者转变为指令决策者，Agent 成为 7x24 小时的实际使用者。

## 核心理念：Context 是新的操作系统
创始人 [[郭亚楠]] 提出，在 AI 开发成本趋近于零的时代，Agent 将代替人成为设备的主要使用者。
- 传统 OS 的核心是“人机交互”，连接用户与开发者。
- 新 OS（Context）的核心是“人与 Agent 对齐”，Context 是个人数据的结构化、语义化集合，像管理内存一样管理数字痕迹。

## 解决的痛点
1. **资源竞争**：避免人类与 Agent（如 [[openclaw]]）抢夺 [[mac-mini]] 等硬件资源。
2. **配置门槛**：消除本地部署 Agent 的复杂配置需求，开箱即用。
3. **隐私与效率**：支持本地数据深度处理，兼顾隐私安全与实时响应。

## 技术优势与商业验证
- **多模态检索**：宣称支持千万级视频秒级检索，精准定位到具体帧。
- **数据安全**：采用硬件级数据隔离技术，即使 Agent 误删数据也能在存储层复原。
- **前代产品**：前代产品 [[zettlab-ai-nas]] 在 Kickstarter 筹资超 140 万美金，验证了市场需求。

## 团队背景
- 创始人 [[郭亚楠]]：硕士毕业于北京理工大学，曾任职于 [[大疆]]（端侧 AI 与芯片定义）和 [[云鲸]]（全球第一款智能扫地机研发）。
- 核心团队：来自大疆、云鲸、华为、理想等公司。

# 关键观点
> “Context 是个人数据的结构化、语义化集合，它就像 OS 管理内存和 CPU 一样管理每个人的数字痕迹。” —— [[郭亚楠]]

# 评价与展望
- **机遇**：切中了 Agent 时代本地化算力与数据管理的痛点，特别是针对白领等数据密集型用户。
- **挑战**：作为初创公司，如何在供应链成本上战胜 [[mac-mini]] 的规模效应，以及“三无”形态如何建立用户信任。
- **发售计划**：预计 2026 年 Q3 在国内正式发售。
