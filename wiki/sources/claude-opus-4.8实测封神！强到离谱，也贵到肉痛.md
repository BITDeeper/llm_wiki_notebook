# Claude Opus 4.8实测封神！强到离谱，也贵到肉痛

新智元发布的关于 [[claude-opus-4-8|Claude Opus 4.8]] 实测表现的深度报道。文章全面呈现了 Opus 4.8 发布后科技界的两极分化反应。

## 核心内容

### 正方观点（以评测媒体 Every 为代表）
- 高级工程师基准 63 分，比 Opus 4.7 暴涨 30 分，险胜 [[gpt-5.5|GPT-5.5]] 的 62 分
- 写作基准 79.6 分，远超 GPT-5.5 的 73 分
- Box 企业测试：报告起草 87%-90%，法律审查近乎完美
- 沃顿商学院教授 Ethan Mollick 实测自主完成学术论文

### 反方观点（以 DHH、antirez 为代表）
- Terminal Coding 项 GPT-5.5 以 78.2% 胜过 Opus 4.8 的 74.6%
- Vending Bench 测试表现不如 Opus 4.7 和 GPT-5.5
- 多位开发者反馈前端和工程任务表现不佳
- 桌面端 UI（Chat/Code/Cowork 三标签割裂）严重拖累体验

### 关键发现
- Opus 4.8 距 4.7 仅 6 周迭代，为 [[anthropic|Anthropic]] 历史最快
- 真正旗舰 [[mythos|Mythos]] 几周内面世，Opus 4.8 或为过渡产品
- Anthropic 以 9650 亿美元估值完成 650 亿美元融资，超越 OpenAI
- 模型表现病态依赖 Extra-High 推理档位，降档后性能暴跌
