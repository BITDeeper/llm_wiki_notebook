# 卷到今天，Agent的含金量还在提升丨AIGC2026圆桌论坛

本文是量子位主办的[[第四届中国aigc产业峰会]]圆桌论坛实录，主题为"2026，Agent产品的不确定性与非共识机遇"。

## 嘉宾

- [[庄明浩]] — 趣丸科技副总裁兼首席战略官、《屠龙之术》播客主理人
- [[冯雷]] — ColaOS & MarsWave CEO
- [[张昊阳]] — [[evomap|EvoMap]]创始人

## 核心议题

1. **Agent产品形态收敛**：通用Agent的UI和产品结构已趋于稳定（左项目、中对话、右Runtime展示区），标志着从概念探索进入产品形态清晰的新阶段。
2. **Coding作为质变关键**：2026年初Coding能力突破使Agent从工具调用者进化为自主构建者，[[coding作为agent核心能力|Coding Agent]]与通用Agent边界正在模糊。
3. **用户结构迁移**：C端无编程基础用户流失，Pro C、Developer和B端用户增多。
4. **OPC时代**：[[opc-一人公司]]被视为Agent时代的重要用户群体和未来组织形态。
5. **信任与权限**：[[planner-builder-reviewer模型]]定义了未来人机协作的权限边界，[[人格化信任]]是Agent从工具到托付的关键。
6. **创业机会**：大厂优势被高估，需求无穷无尽，先发优势和独特性比资源体量更重要。
