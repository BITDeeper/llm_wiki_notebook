# 华为盘古大模型负责人王云鹤离职，被曝Agent创业

**来源**：量子位
**日期**：2026年3月28日
**作者**：鱼羊

## 核心摘要

华为盘古大模型负责人、诺亚方舟实验室主任（90后）[[王云鹤]]已离职。据量子位获悉，王云鹤此次离职将投身 [[Agent]] 创业，目前正在进行水下融资。

## 关键信息

### 职业轨迹
- **背景**：1991年出生，本科毕业于西安电子科技大学数学与应用数学专业，博士毕业于北京大学。
- **学术成就**：师从许超教授和陶大程教授。Google Scholar 被引数 33109，h-index 为 68。
- **华为履历**：
  - 2017年进入 [[华为诺亚方舟实验室]] 实习。
  - 2018年博士毕业后正式入职。
  - 8年间历任高级工程师、主任工程师、技术专家。
  - 2021年底升任算法应用部部长。
  - 2025年接棒姚骏，成为诺亚方舟实验室主任，负责 [[盘古大模型]] 研发。

### 技术贡献
- **GhostNet**：被引数最高的论文，解决了在内存和计算资源有限的嵌入式设备上部署 CNN 的难题。
- **Image Processing GNN**：获 CVPR 2024 最佳学生论文奖提名，提出了一种嵌入图神经网络的超分成像算法。
- **工程落地**：曾获华为“十大发明”奖，其获奖成果应用于中国天眼 FAST，协助发现数百个快速射电暴样本。

## 行业意义

王云鹤作为华为内部培养的顶尖技术人才，在担任核心大模型负责人期间选择离职投身 Agent 创业，这一动向具有标志性意义。它暗示了 AI 行业风向的可能转变：顶尖人才正从单纯的基础大模型研发，转向探索 [[Agent]] 的落地应用和商业闭环。这印证了 [[任务执行范式]] 中提到的行业趋势，即从“卷”模型规模转向工程化系统落地。
