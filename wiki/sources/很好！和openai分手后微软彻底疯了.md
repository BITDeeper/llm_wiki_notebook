# 很好！和OpenAI分手后微软彻底疯了

量子位于2026年6月3日发布的报道，全面记录了微软 Build 2026 大会的核心发布内容。文章以"微软AI自立门户"为主线，报道了微软在解绑OpenAI后首次系统性发布全套自研AI产品线的重大战略转型。

## 核心内容

### 7款MAI自研模型
微软首次发布覆盖推理、代码、图像、语音转写、语音生成的完整自研模型家族，包括 [[mai模型系列|MAI-Thinking-1]]、MAI-Code-1-Flash、MAI-Image-2.5/Flash、MAI-Transcribe-1.5、MAI-Voice-2/Flash。其中MAI-Thinking-1直接叫板 [[claude-code|Claude]]，微软强调"没有蒸馏任何第三方模型"。

### 企业级AI Agent与OpenClaw登陆Windows
[[scout|Scout]] 作为嵌入Microsoft 365的企业级AI Agent亮相。[[openclaw|OpenClaw]] 正式登陆Windows，通过 [[mxc|MXC]] 操作系统级安全沙箱实现安全运行，[[peter-steinberger|Peter Steinberger]] 亲自站台演示。

### GitHub Copilot独立与Windows开发者生态
[[github-copilot桌面客户端]] 脱离IDE成为独立桌面应用。Coreutils for Windows用Rust重写75+Linux命令行工具，WSL Containers即将公开。

### AI开发者硬件
[[surface-rtx-spark-dev-box]] 搭载NVIDIA RTX Spark超芯片，128GB统一内存，1 PFLOP算力，支持本地运行1200亿参数模型。
