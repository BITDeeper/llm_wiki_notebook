# Skill vs App：一场入口范式的争夺

本文记录了量子位举办的「龙虾时代，Skill会吃掉App吗？」主题沙龙的精华内容。多位来自AI健康、智能办公、效率笔记及智能体操作系统领域的创业者与产品负责人，围绕 [[skill-vs-app]]、[[mcp-模型上下文协议]]、[[记忆底座]] 及 [[to-agent-营销]] 等话题展开了深入讨论。

## 核心观点摘要

- **Skill 不会完全取代 App**：App 会以 Skill 形式存在或自身 Agent 化，两者是进化关系而非替代关系。
- **交互范式迁移**：从 GUI（图形界面）向 LUI（对话式交互）迁移，自然语言成为统一入口。
- **App 的生存关键**：必须能被 Agent 调用（支持 [[mcp-模型上下文协议]]），否则在 AI 世界中“不可见”。
- **笔记工具的进化**：从“存储工具”进化为 AI 的 [[记忆底座]]，解决人脑带宽限制，提供结构化记忆管理。
- **商业逻辑重构**：从 To C 转向 [[to-agent-营销]]，Agent 不看广告，只执行最优指令。

## 关键人物与论点

### 包炬强（小卡健康）
- **观点**：受 AI 冲击最大的是搜索类产品。Skill 更像 AI 时代的“小程序”，App 会持续作为服务载体存在。
- **论据**：App 服务人类（GUI、通用流程），Skill 服务 Agent（自然语言、个性化流程）。

### 徐奕成（金山办公 WPS AI）
- **观点**：App 必须能被 Agent 调用，否则“AI 看不见它”。笔记应成为“记忆底座”。
- **论据**：竞争从“抢用户打开”转向“抢 Agent 调用”。WPS 笔记定位为帮用户整理，核心在于全生态整合和记忆能力。

### 焦文超（印象笔记）
- **观点**：AI 时代笔记需解决“带宽”问题，做结构化记忆管理，让 AI 更“懂我”。
- **论据**：人脑处理带宽有限，需要第二大脑做过滤与聚焦。简单文件式记忆太粗糙，需结构化分层级管理。

### 逄大嵬（元空 AI）
- **观点**：Skill 与 App 是进化关系，非替代关系。核心是技术驱动和解决需求。
- **论据**：历史证明新形态未杀死旧形态（如 PC 未杀死大型机）。ChatExcel 从 GUI 到 LUI 的演进体现了用户心智的进化。

### 宁辽原（TTC & ClawOS）
- **观点**：Skill 只是过渡态，未来是 Agent Team 和 Agent Economy。超级 App（如微信）难被替代。
- **论据**：高阶 Skill（Deep Skill）虽能调用 API，但存在兼容性、冲突和权限问题。Agent 是承载 Skill 的最佳容器。

## 行业趋势与商业机会

- **To Agent 营销**：传统基于流量和注意力的广告模式失效，新的竞争在于谁能被 Agent 优先调用。
- **去中心化 vs 新中心化**：关于未来生态是平权开放还是诞生新的“超级商店”存在争议。
- **记忆即壁垒**：企业级私有数据记忆将成为小厂与大厂抗衡的关键。

## 活动背景
- **地点**：中关村科学城国际创新服务集聚区。
- **背景**：[[openclaw]] 引发的连锁反应，让行业开始重新思考应用形态与入口范式。
