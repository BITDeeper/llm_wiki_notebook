# 源：GPT-5.4 核心内幕

本文报道了 [[OpenAI]] 即将发布的模型 [[GPT-5.4]] 的核心内幕，重点涵盖了其通过 [[Codex]] 错误日志和 GitHub PR 泄露的证据，以及关于“极限推理模式”和“永久记忆”的传闻。

## 关键发现

### 1. 泄露证据
- **Codex 错误日志**：开发者触发安全限制时，日志中出现了 `gpt-5.4-ab-arm1-1020-1p-codexswic-ev3` 的模型名称。
- **GitHub PR**：OpenAI 官方 Codex 仓库出现了提及 `minimum model version = (5, 4)` 和 `toggle Fast mode for GPT-5.4` 的 PR，随后被删除。
- **员工截图**：OpenAI Codex 团队员工 Tibo 误发了一张显示模型选择器中有 GPT-5.4 的截图，随后删除。

### 2. 性能提升
- **代码生成**：测试者报告一次提示可生成 6000+ 行代码。
- **推理速度**：模型推理速度明显更快。
- **Fast Mode**：新模型似乎引入了“快速模式”开关，暗示可能存在多级延迟管道或不同速度档位的模型架构。

### 3. 核心特性传闻
- **极限推理模式**：允许模型在遇到困难问题时花费更多时间、调用更多计算资源进行深层推理。虽然普通用户和商业客户更看重速度，但这对于科研和构建复杂 AI Agent 具有重大意义。
- **长上下文窗口**：上下文窗口从 40万 tokens 提升至 100万 tokens（甚至传闻 200万），追平了谷歌 [[Gemini]] 和 Anthropic [[Claude]]。
- **长任务处理**：在持续数小时的任务中表现更好，能记住细节和权限限制，这对 Codex 和 AI Agent 开发至关重要。

### 4. 永久记忆
- **传闻**：GPT-5.4 可能拥有“永久记忆”或“持久状态”。
- **技术猜测**：业界猜测 OpenAI 可能找到了大规模结合 [[状态空间模型]] (SSM) 和 Transformer 的方法。SSM 的计算复杂度随上下文长度线性增长，适合处理超长上下文和持久状态。
- **意义**：这将使 AI 从《记忆碎片》式的短期记忆转变为《雨人》式的长期记忆，是 AI 形态的根本性变革。

### 5. 战略背景
- **高频更新**：OpenAI 在 GPT-5 后开启了“月更”模式（5.1, 5.2, 5.4），反映出在谷歌和 Anthropic 竞争压力下的焦虑。
- **用户目标**：尽管 ChatGPT 周活达 9.1 亿，但仍未达到 OpenAI 10 亿 WAU 的内部目标。
