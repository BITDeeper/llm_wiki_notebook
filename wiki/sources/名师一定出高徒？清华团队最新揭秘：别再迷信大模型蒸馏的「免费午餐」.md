# 名师一定出高徒？清华团队最新揭秘：别再迷信大模型蒸馏的「免费午餐」

## 摘要

本文报道了清华大学 THUNLP 实验室联合多家机构对 [[on-policy-distillation|On-Policy Distillation (OPD)]] 的系统性研究。研究揭示了 OPD 并非"免费午餐"，其效果受限于两大先决条件：[[思维模式一致性]] 和 Teacher 是否提供真正的新知识。论文还发现了 [[熵崩塌]] 现象，揭示了 OPD 在长思维链场景中的根本性局限。

## 核心发现

1. **更强 Teacher ≠ 更好蒸馏**：同家族更大模型仅提供参数规模红利，不提供新可学习信息
2. **蒸馏成败取决于两大先决条件**：思维模式一致性和 Teacher 提供新知识的能力
3. **优化核心引擎是重叠区域的高概率 Token**：仅对 Overlap Token 计算损失，性能几乎不打折扣
4. **OPD 存在根本性扩展限制**：在 15K token 响应中观察到"从后向前的熵崩塌"
