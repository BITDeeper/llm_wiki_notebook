# 源文件摘要

本文介绍了由 Liu Fayao、Ye Deheng 和 Chen Tianrun 团队开发的 [[claw-ai-lab]] 系统。该系统旨在通过 [[金字塔式分层架构]] 和 [[lab讨论模式]]，将单人科研转变为模拟真实实验室协作的“带实验室”模式。

核心组件 [[claude-code-harness]] 被提出，它不仅生成代码，还通过 [[experiment-harness]] 注入时间预算控制和指标校验，确保实验的可复现性。文章强调 [[群体智能]] 在科研中的价值，通过多智能体并行调研与讨论收敛共识，而非单一的线性输出。

文中展示了具身智能方向的讨论案例，以及幻觉量化和 PhyCustom 复现的项目结果，证明了系统在处理复杂科研任务时的有效性。
