# 概述

本文报道了 Cursor CEO Michael Truell 进行的一项极限压力测试：让 [[GPT-5.2]] 连续运行 7 天（168 小时），从零构建了一个 Chrome 级别的浏览器。该项目生成了超过 300 万行代码和数千个文件，涵盖了 HTML 解析、CSS 布局、文本渲染以及自研的 JavaScript 虚拟机。

# 核心发现

### 1. 无限耐力的验证
实验证明了 AI 模型在物理上具备无限运行的能力。只要基础设施稳定，[[GPT-5.2]] 能够 7×24 小时不间断工作，表现出极高的专注度和执行力，被描述为“老练的高级工程师”。相比之下，[[Claude Opus 4.5]] 在测试中表现出“急躁”特征，倾向于过早结束任务或移交控制权。

### 2. 多智能体分层架构
为了解决大规模协作中的冲突（如锁竞争、沟通成本高），[[Cursor]] 团队采用了“规划者-执行者-评审者”的分层架构。这种架构模拟了人类软件公司的组织结构，实现了上百个 Agent 在同一代码库上数周的无冲突协作。

### 3. 工程难点的突破
AI 成功攻克了浏览器开发的三大难点：
- **复杂的 CSS 布局**：处理了层叠规则和复杂的继承逻辑。
- **JavaScript 虚拟机**：实现了内存管理、垃圾回收（GC）和安全沙箱。
- **Rust 语言特性**：在数百万行代码规模下满足了 Rust 编译器严格的借用检查和生命周期要求。

### 4. 软件经济学的颠覆
[[Emad Mostaque]] 估算该项目消耗了约 30 亿个 token。随着算力转化为工程实施能力，软件开发的边际成本趋近于零，传统的按授权付费模式面临失效。

# 意义

这次实验标志着 AI 从“聊天伴侣”向“数字劳工”的质变，展示了 [[长时任务]] 的巨大潜力。它不仅验证了 AI 在复杂系统架构掌控力上的突破，也预示着软件开发范式从“任务”向“项目”的根本性转移。
