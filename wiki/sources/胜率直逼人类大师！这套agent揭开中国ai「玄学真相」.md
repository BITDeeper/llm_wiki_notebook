# 胜率直逼人类大师！这套Agent揭开中国AI「玄学真相」

## 摘要

本文报道了 [[destinylinker]] 研究团队在传统术数领域的大模型推理能力研究。研究发现，主流通用大模型（Claude、GPT等）在无信息泄漏的专业术数四选一选择题上准确率仅23%-40%，略高于25%随机线。团队随后开发了 [[tianfu-agent]] 系统，通过200+原子工具、3大流派规则函数库、多Sub-Agent协作和置信度量化机制，将准确率提升至50%，逼近本届术数大赛人类Top 20选手的53.5%平均水平。

## 核心内容

### 评测基准 [[mingli-bench]]
- 基于 [[hkjfma]] 主办的术数大赛官方题库（3069名选手参与）
- 测试主流大模型在专业术数推理上的表现
- 所有基线模型Prompt中提供预计算盘面数据，排除计算幻觉干扰

### Tianfu Agent 架构创新
- **[[多Sub-Agent协作]]**：多个子智能体各自维护独立工具集和上下文，渐进式发现策略
- **[[四级可见性控制]]**：按LLM可理解性和可穷举性将工具分四级管理，解决200+工具的选择退化问题
- **[[规则函数化封装]]**：将复杂领域规则封装为带元数据的可调用函数，"知识即接口"替代"知识即提示词"
- **[[三层不确定性量化]]**：在工具输出层、Sub-Agent层、多流派合参层分别进行置信度评估

### 工程启示
1. 工具化范式在"规则密集+语料稀缺"领域收益最大
2. 工具数量膨胀后管理本身成为独立工程问题
3. 缺乏自动验证时不确定性量化是务实次优方案
4. "知识即接口"比"知识即提示词"更可靠
