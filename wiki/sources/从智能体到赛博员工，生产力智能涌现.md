# 从智能体到赛博员工，生产力智能涌现

本文由 [[机器之心]] 发布，基于 Workspace-Bench 1.0 评测基准的深度解读，提出从"Agent"到"赛博员工"再到"生产力智能"的范式跃迁框架。

## 核心论点

AI行业正从"模型能力"和"Agent工具调用"的竞争，转向"生产力智能"的竞争——即AI能否像真实员工一样，在复杂工作空间中理解文件依赖关系、承担岗位职责并稳定交付结果。

## 关键发现

1. **Workspace-Bench 1.0 评测数据**：27种Agent配置的平均Rubrics通过率约43.3%，最佳约60%，远低于人类专家的80.7%。
2. **难度梯度衰减**：Easy→Medium→Hard任务通过率从51.4%→46.0%→35.7%，复杂依赖网络是Agent的核心瓶颈。
3. **Node F1 > Edge F1**：Agent能找到相关文件，但难以判断文件间关系（谁是源数据、谁是派生报告、谁是历史版本）。
4. **高交互≠高质量**：某些配置40-60轮交互、大量token消耗，准确率仍停留在30%-45%。

## 四阶段演进框架

| 阶段 | 关注点 | 核心局限 |
|------|--------|----------|
| 大模型助手 | 生成与问答 | 依赖用户把上下文喂干净 |
| Agent Harness | 工具与执行 | 会干活但未必理解角色 |
| [[赛博员工]] | 工作站与职责 | 需要长期适应组织语境 |
| [[生产力智能]] | 角色与规模化 | 工作站、角色和任务的规模化扩展 |

## 三大Scaling挑战

- **工作站规模**：真实企业有成千上万个不断变化的workspace
- **角色规模**：需要从泛化Agent转向承担具体职责的角色
- **任务规模**：需要稳定覆盖高频生产力任务
