# 源：除夕夜袭！千问3.5硬刚Gemini 3 Pro

本文报道了阿里在2026年除夕发布的全新一代大模型 [[千问3.5-Plus]]。该模型通过创新的混合架构（397B总参数，仅激活17B），实现了性能与成本的双重突破，在多项基准测试中超越 [[Gemini 3 Pro]]、[[GPT-5.2]] 和 [[Claude 4.5]]，同时 API 价格仅为竞品的 1/18。

## 核心要点

-   **架构效率**：采用 [[门控技术]]（融合线性注意力与稀疏MoE），以不到5%的激活参数调动全局知识，推理吞吐量在256K上下文下最高提升19倍。
-   **原生多模态**：从预训练阶段即进行文本与视觉混合Token联合学习，支持长达2小时的视频理解输入及 [[视觉编程]]（草图转代码）。
-   **Agent能力**：具备GUI操作能力，千问App的AI购物Agent在春节期间6天内完成1.2亿笔订单，实现大规模商业验证。
-   **极致性价比**：API价格低至0.8元/百万Token，显存占用降低60%，大幅降低部署门槛。

## 关键数据

-   **MMLU-Pro**: 87.8分 (超越 GPT-5.2)
-   **GPQA**: 88.4分 (超越 Claude 4.5)
-   **IFBench**: 76.5分 (刷新历史纪录)
-   **吞吐量提升**: 32K上下文提升8.6倍，256K上下文提升19倍
-   **生态规模**: 累计开源超400个模型，全球下载量破10亿次
