# GitHub帝国崩塌前夜：源码泄露、18年老粉决裂！微软失去1.5亿开发者

新智元2026年5月22日发布的深度报道，全面梳理了GitHub面临的安全、技术、管理和竞争四重危机。

## 核心内容

### 安全危机
- 2026年5月21日，3800+内部源码库在黑客论坛[[breachforums]]被公开叫卖，要价5万美元
- 攻击路径：投毒VS Code扩展插件→截获开发者凭证→入侵代码仓库
- 2026年3月还发现Git基础设施0-day高危漏洞

### 技术危机
- 持续宕机频发，最严重事故导致大量仓库回滚、用户代码消失
- CTO [[vladimir-fedorov]]激进推进Azure迁移加剧不稳定

### 管理危机
- 前CEO [[thomas-dohmke]]辞职，CEO职位被取消
- GitHub被并入CoreAI团队，由[[jay-parikh]]掌管
- 顶级人才大规模流失

### 竞争危机
- [[cursor]]和[[claude-code]]形成降维打击
- 微软内部数万工程师自发采用Claude Code
- 高管下令6月底收回所有CC许可证

### 财务危机
- [[github-copilot]]卖得越多亏得越惨，被迫从包月制转向按量计费
- 微软CFO承认Copilot拉低云业务毛利率

## 分析备注

文章标题和基调带有强烈的"崩塌叙事"色彩，但GitHub仍拥有1.5亿开发者、10亿仓库、Copilot 470万付费用户和30亿美元年收入。崩塌程度可能被一定程度的夸大，更准确的描述是"战略困境"。部分内部爆料为单源信息，无法独立验证。
