# 逮虾户注意！神秘模型点名OpenClaw，疑似是OpenAI

## 概述
本文报道了 2026 年 3 月 11 日深夜在 OpenRouter 平台上突然出现的两个匿名前沿模型——[[hunter-alpha]] 和 [[healer-alpha]]。文章通过术语指纹（如 "omni-modal"）、历史行为模式以及 OpenAI 员工的社交媒体活动，推测这两个模型极有可能是 [[openai]] 的 [[stealth-model]]（幌子模型），用于在正式发布前进行测试或市场预热。

## 核心发现

### 1. 两个方向迥异的模型
- **[[hunter-alpha]]**：定位为深度 Agent 能力模型。拥有 1 万亿参数和 100 万 token 上下文。其描述中明确提到“专为像 [[openclaw]] 这样的生产级 Agent 流水线而设计”，强调长程规划、复杂推理和持续多步任务执行。
- **[[healer-alpha]]**：定位为全模态感知模型。具备视觉、听觉、推理和行动能力，强调原生感知和跨模态推理，填补了 GPT-5.4 在原生音频和跨模态感知上的空白。

### 2. OpenAI 的“指纹”
- **术语证据**：Healer Alpha 的描述中使用了 "omni-modal" 一词，这是 [[openai]] 的内部惯用语（源自 GPT-4o），其他主流实验室很少使用。
- **时间巧合**：OpenAI 语音团队成员 Atty Eleti 在 3 月 9 日于 X 上公开询问对新 omni 模型的期望，随后模型即出现。
- **历史模式**：OpenAI 此前已有三次通过 OpenRouter 发布匿名模型的前科（[[quasar-alpha]]、[[horizon-alpha]]、[[polaris-alpha]]），且遵循“幌子出现→社区破案→正式发布→退场”的规律。

### 3. 关键疑点
文章末尾提到，有单一信源称这两个模型的系统提示中包含“严格遵守中国法律法规”。这是中国模型（如 DeepSeek、阿里、字节）的标配，从未出现在 OpenAI 模型中。如果属实，这将推翻“OpenAI 幌子”的结论，或者暗示这是某种极其特殊的定制/合作版本。

## 对 [[openclaw]] 的启示
此事件表明 [[openclaw]] 可能不仅仅是一个独立的工具，而是 [[openai]] 生态战略中的一环。Hunter Alpha 的出现暗示 OpenAI 可能正在专门为 [[openclaw]] 准备更强的“大脑”，以支持其生产级 Agent 流水线。
