# Claude「永久大脑」，真的来了！

新智元2026年5月25日发布的报道，首次系统披露 Anthropic 正在为 Claude 测试的「双模记忆系统」——经典记忆与文件记忆并存，以及配套的 Dreams 异步记忆整合机制和 Conway 永不下线智能体平台。

## 核心内容

- **双模记忆系统**：Claude 同时运行经典记忆（滚动摘要）和文件记忆（结构化文档），用户可自由切换
- **Dreams 梦境机制**：模拟人类 REM 睡眠的异步后台记忆整合，已在 Claude Code 以 Auto Dream 形式落地
- **Conway 智能体平台**：7x24小时永不下线的 AI 智能体，包含 Search/Chat/System 三功能区
- **AI 记忆竞争格局**：ChatGPT（个人助理路线）、Gemini（谷歌生态路线）、Claude（文件系统+自主进化路线）三足鼎立

## 关键引用

- Dario Amodei 判断：ASI 不会是某一次突破的产物，而是一系列能力模块逐渐拼合的结果，记忆可能是其中最被低估的一块
- 企业客户数据：Netflix、Rakuten、Wisedocs 等首批接入 Dreams 的企业，首次处理错误率暴降 97%，文档验证提速 30%
