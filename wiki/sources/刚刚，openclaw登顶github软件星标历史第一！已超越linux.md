# 刚刚，OpenClaw登顶GitHub软件星标历史第一！已超越Linux

**摘要**：本文报道了 [[openclaw]] 在 2026 年 3 月登顶 GitHub 软件星标历史第一的事件，分析了其超越 [[Linux]] 和 [[React]] 的原因，探讨了开源社区中 [[注意力经济]] 的兴起，以及 [[本地推理]] 技术带来的破圈效应与安全挑战。

## 核心事件

[[openclaw]] 仅用两个月（约 100 天）时间，星标数超越 [[React]]（13 年积累）和 [[Linux]] 等老牌基建项目，成为 GitHub 历史上星标最多的基础软件项目。

## 关键论点

### 1. 注意力的通货膨胀
文章指出，GitHub Star 的含义已发生改变：
- **过去**：代表技术背书和实际使用需求。
- **现在**：成为一种低成本的社交货币和身份表态。
- **现象**：排行榜前列常是资源汇总类（如 `build-your-own-x`），而非基建软件。[[openclaw]] 的爆发标志着 [[注意力经济]] 在开源社区的彻底胜利。

### 2. 破圈与失控的魅力
[[openclaw]] 的流行不仅源于技术，更源于其赋予 AI 的极高权限带来的破坏力与亚文化吸引力：
- **受众下沉**：从极客扩展到设计师、家庭主妇等普通用户。
- **失控边缘**：[[ClawHavoc]] 安全危机（恶意软件感染、账号封禁）反而坐实了其“破坏性力量”，满足了人们对“活在未来”的猎奇心理。
- **亚文化**：吉祥物龙虾 Molty 和口号“EXFOLIATE！”使其成为数字图腾。

### 3. 时代的分水岭
- **Web/云原生时代 (2013-2016)**：工程师为了构建稳定的商业系统（如 [[React]]）。
- **AI 时代 (2022-至今)**：驱动力变为好奇心、兴奋感与对未知的隐忧。[[openclaw]] 是当下技术情绪的“最大公约数”。

## 相关实体

- **[[Peter Steinberger]]**：奥地利独立开发者，[[openclaw]] 作者。
- **[[Molty]]**：项目吉祥物（龙虾）。
- **[[ClawHavoc]]**：2026 年 1 月底爆发的安全危机。

## 引用数据

- [[openclaw]]：100 天达到同等高度。
- [[Linux]]：22 万星标，仍是互联网的基石。

## 结论

虽然 [[openclaw]] 在技术重要性上远不及 [[Linux]]，但它证明了在 AI 时代，**病毒式传播 > 技术积淀**，**情绪价值 > 实用工具**。
