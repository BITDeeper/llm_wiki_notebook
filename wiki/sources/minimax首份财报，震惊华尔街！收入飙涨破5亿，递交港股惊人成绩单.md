# MiniMax首份财报：收入飙涨破5亿，递交港股惊人成绩单

## 概述

本文详细报道了 MiniMax 上市后首份年度财报的惊人表现，并深入分析了其背后的技术驱动力与战略转型。财报显示，MiniMax 2026 年总收入达 7903.8 万美元（同比增长 158.9%），其中 73% 来自海外市场。创始人 [[闫俊杰]] 提出“AI 平台价值 = 智能密度 × Token 吞吐量”的公式，标志着公司从大模型公司向 AI 平台型公司的迈进。

## 核心数据

- **营收**：7903.8 万美元（+158.9% YoY）。
- **毛利**：2007.9 万美元（+437.2% YoY），毛利率提升至 25.4%。
- **用户**：累计 2.36 亿用户，覆盖 200+ 国家，21.4 万企业客户。
- **成本优化**：销售费用下降 40.3%，研发增速（33.8%）低于收入增速。

## 技术亮点

### M2.5 模型与 Forge 系统
- **架构**：MoE 架构，总参数 2290 亿，激活 100 亿。
- **性能**：推理速度 100 token/秒，上下文窗口 20 万-100 万。
- **成本**：同等模型（GPT-5.2, Claude Opus 4.6）的 5%-10%。
- **训练**：通过 [[forge]]（异步原生 Agent RL 系统）将训练速度提升 40 倍。

### MaxClaw 与 Agent 革命
- **产品**：[[maxclaw]]（云端 AI 爪子），基于 [[openclaw]] 框架，实现“人人可用的智能体”。
- **趋势**：AI 竞争进入第二阶段，从 Coding 到 Agent，预测 Token 消耗量将增长 10-100 倍。

## 战略分析

### 产模一体
MiniMax 坚持 [[产模一体]] 策略，既做底层模型研发，又在产品侧（如 [[星野]]、[[talkie]]）形成规模化应用。这解决了单纯做模型缺乏变现、单纯做应用缺乏壁垒的矛盾，形成了独特的商业护城河。

### 全球化布局
- **收入结构**：73% 来自海外。
- **生态合作**：已部署在 Google Vertex AI、Microsoft Azure AI Foundry 等国际平台。
- **开发者生态**：在 OpenCode、Notion 等平台成为首选模型。

## 行业预测

MiniMax 预测，随着 Agent 时代的到来，编程（L4-L5 级别）、办公和多模态创作三大赛道将迎来爆发。公司已开始研发 M3 和 Hailuo3 系列模型以应对未来的大规模智能供给。
