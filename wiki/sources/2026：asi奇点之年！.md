# 2026：ASI奇点之年！

## 摘要
本文记录了马斯克断言 2026 年为奇点之年的背景及依据，结合新智元杨静与 CSDN 李建忠的对谈，深入分析了 ASI（通用超级人工智能）降临的时间表争议、技术实证（如 Claude Code 的自我编程能力）以及通往奇点的逻辑路径。

## 核心观点

### 1. 奇点时间表：2026 vs 2035
- **激进派（马斯克/杨静）**：认为 2026-2027 年是临界点。马斯克预测 2026 年实现 AGI，2030 年 AI 智力超越全人类总和。
- **审慎派（李建忠）**：预测 2035 年。强调 ASI 的定义应包含人的「获得感」，并指出当前 AI 存在「锯齿状智能」和缺乏持续学习机制的问题。

### 2. 技术实证：从补全到进化
- **Claude Code**：谷歌工程师 Jaana Dogan 证实，Claude Code 在 1 小时内完成了谷歌团队 1 年未果的分布式系统任务。Claude Code 负责人 Boris Cherny 称其正在 100% 自动编写自己的代码。
- **METR 数据**：AI 独立任务时长的翻倍周期从 7 个月缩短至 4 个月，且模型已能独立完成 5 小时任务。
- **范式转移**：AI 编程已越过「智能补全」临界点，进入「自主改进」阶段。

### 3. 关键概念
- **品味奇点**：指 AI 在判断价值、架构优雅度上的能力提升速度快于编码能力。这意味着 AI 将从执行者转向架构师。
- **锯齿状智能**：指 AI 在特定领域（如编程、奥数）超越人类，但在通用、连贯、可迁移能力上仍不如人类的非均衡状态。
- **记忆与遗忘**：人类通过遗忘和抽象形成智慧，而大模型目前存在「灾难性遗忘」，缺乏将经历转化为长期自我的机制。

### 4. 通往 ASI 的路径
- **三步逻辑**：等价前提（GPT-5） -> 扩展前提（算力/算法） -> 放大前提（AI++ 自我设计）。
- **双爆炸合流**：智能爆炸（自我进化） + 速度爆炸（硅基载体速度优势）。
