# 死脑筋的达里奥，这次把OpenAI干翻了

**来源：** 机器之心
**发布日期：** 2026-06-01

## 摘要

本文分析了 Anthropic 凭借对 coding 的极致专注，在估值和营收上全面超越 OpenAI 的战略逻辑。Anthropic 完成 H 轮融资 650 亿美元，估值达 9650 亿美元，超越 OpenAI 的 8520 亿美元。年化收入从 2025 年初的 10 亿美元飙升至 2026 年 5 月的 470 亿美元，核心驱动力是 [[claude-code]]。

## 核心数据

- Anthropic 估值 9650 亿美元 vs OpenAI 8520 亿美元
- Anthropic 年化收入 470 亿美元 vs OpenAI 300 亿美元（高出约 35%）
- 企业 AI 编程市场份额：Anthropic 54% vs OpenAI 21%
- 企业大模型采购份额：Anthropic 40%（上升） vs OpenAI 27%（下降）
- Claude Code 上线 9 个月年化收入从 0 增至 25 亿美元
- Anthropic 有望在本季度实现盈利

## 关键论点

1. **专注 vs 分心：** [[anthropic]] 全力押注 coding 单一赛道，而 [[openai]] 和 Google 摊子铺得很大（Sora、浏览器、硬件、咨询等）。
2. **代码加速 AI 自进化：** 代码 Agent 可以写工具、搭评测、改基础设施，直接帮助下一代模型变得更强。
3. **编程作为 Agent 治理测试场：** 编码场景涉及文件访问、API 调用、线上部署等高风险环节，解决代码场景的权限问题等于解决所有垂直行业的 Agent 治理问题。

## 反面观点

- Anthropic 护城河脆弱，优势几乎全部集中在 Claude Code 和编程智能体上
- 编程能力不等于通用智能，过度专注可能制约模型在其他维度的发展
- 幸存者偏差：专注被奉为圭臬只是因为 Claude Code 跑出来了
