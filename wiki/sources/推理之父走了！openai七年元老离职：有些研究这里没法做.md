# 摘要
本文报道了 OpenAI 研发副总裁 [[jerry-tworek]] 于 2026 年 1 月离职的消息。Tworek 是 OpenAI 的七年元老，被称为“推理模型之父”（主导 o1/o3 系列）和“编程代码之父”（主导 Codex）。他在离职备忘录中表示，希望探索“在 OpenAI 内部难以开展的研究类型”。

文章将此次离职置于 OpenAI 核心人才持续流失的背景下进行解读，列举了 [[dario-amodei]]（创立 [[anthropic]]）、[[ilya-sutskever]]、[[jan-leike]] 和 [[john-schulman]] 等关键人物的离开。分析指出，这种“大脑流失”现象的根本原因在于 OpenAI 从理想主义研究机构向商业化实体的转型，导致研究自由度受限和安全问题被边缘化。

# 核心观点
- **研究自由受限**：Tworek 的离职理由暗示 OpenAI 内部的研究方向正受到商业 Deadline 和产品化需求的过度干预。
- **商业化与理想的冲突**：OpenAI 已从非营利研究圣地转变为追求商业回报的机器，这种文化转变导致追求技术突破的研究员感到不适。
- **安全优先级倒置**：继 Jan Leike 之后，Tworek 的离开再次暗示 OpenAI 可能为了产品发布速度而牺牲 AI 安全研究。
- **Sam Altman 的孤独**：尽管 [[sam-altman]] 在 2023 年宫斗中获胜，但随着元老级骨干的离去，他的权力基础正面临“空心化”风险。

# 关键事实
- **Jerry Tworek 的身份**：OpenAI o1 项目负责人、Codex 核心研究员、GPT-4 编程能力贡献者。
- **离职时间**：2026 年 1 月（新年第一周）。
- **历史对比**：Tworek 是继 Dario Amodei、Ilya Sutskever 等人之后又一位离职的核心元老。
- **竞争对手动态**：Anthropic（由前 OpenAI 人员创立）在编程领域对 OpenAI 构成巨大压力。
