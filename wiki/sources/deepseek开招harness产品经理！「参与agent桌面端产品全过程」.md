# DeepSeek开招Harness产品经理！「参与Agent桌面端产品全过程」

量子位报道DeepSeek发布Agent Harness产品经理招聘，标志着DeepSeek从纯模型实验室向模型+产品双轮驱动的AI公司转型。

## 核心内容

- DeepSeek正式组建Harness团队，招聘Agent桌面端产品经理
- 核心公式：Model + Harness = Agent，Harness负责约束、验证、纠错和收敛
- 岗位要求深度使用Claude Code、Codex、Cursor、Manus、OpenClaw、Hermes等Agent产品
- 明确提出Prompt Engineering、Context Engineering、Harness Engineering三大工程课题
- 可使用[[vibe-coding]]写代码，不一定需要技术背景

## 商业化背景

- DeepSeek估值3500亿元，[[梁文锋]]个人出资200亿元（占40%）
- 融资被解读为理想主义对现实的妥协，核心驱动力是人才争夺
- 明星研究员郭达雅、王炳宣、魏浩然因薪酬问题流失
- DeepSeek承诺加快模型发布节奏，V4.1计划6月推出

## 关联

- 印证[[任务执行范式]]——AI行业从模型开发转向智能体工程化系统
- 与[[claude-code]]、[[openclaw]]、[[hermes-agent]]、[[cursor]]形成竞品关系
- 延续[[deepseek-v4]]的技术路线，向产品化延伸
