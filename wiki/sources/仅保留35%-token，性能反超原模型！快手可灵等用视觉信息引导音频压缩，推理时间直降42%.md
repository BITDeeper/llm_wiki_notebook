# 仅保留35% Token，性能反超原模型！快手可灵等用视觉信息引导音频压缩，推理时间直降42%

## 概述
本文报道了由 [[快手可灵]]、[[中科院自动化所]] 和 [[南京大学]] 联合提出的 [[OmniSIFT]] 技术。这是一种针对全模态大模型的 [[模态非对称压缩]] 框架，旨在解决音视频理解中计算资源浪费严重的问题。

## 核心发现
- **高冗余性**：全模态模型（如 [[Qwen2.5-Omni]]）在处理音视频时，超过 65% 的 Token 是冗余的。
- **性能反超**：在仅保留 35% Token 的情况下，模型在 WorldSense 等基准上的性能（50.0）反超了全量 Token 输入（49.7）。
- **效率提升**：推理时间减少了 42%（从 15097秒 降至 8756秒），GPU 显存占用同步下降。

## 技术原理
OmniSIFT 的核心在于利用视频与音频之间的非对称依赖关系（视频信息密集，音频跟随视频），通过两个核心模块实现协同压缩：
1. **STVP (时空视频剪枝)**：从空间（帧内背景）和时间（相邻帧重复）两个维度压缩视频 Token。
2. **VGAS (视觉引导音频选择)**：利用筛选后的视觉特征，通过跨模态注意力机制决定保留哪些音频 Token，解决了音频对时间连续性敏感的问题。

## 实验验证
- **消融实验**：移除 VGAS 模块后，DailyOmni 得分从 73.2 降至 69.3，证明了“视觉引导”的有效性。
- **对比基准**：在 25% Token 保留率下，整体表现优于 OmniZip 和 DyCoke 等现有压缩方法。

## 意义
该研究揭示了真正决定模型理解能力的是信息的密度而非数量，为全模态模型在实时交互和端侧部署的应用提供了新的技术路径。
