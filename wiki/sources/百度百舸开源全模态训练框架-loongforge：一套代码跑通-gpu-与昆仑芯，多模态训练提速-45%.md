# 百度百舸开源全模态训练框架 LoongForge：一套代码跑通 GPU 与昆仑芯，多模态训练提速 45%

## 摘要

本文报道了 [[百度百舸]] 开源发布全模态训练框架 [[loongforge|LoongForge]] 的消息。LoongForge 以 Megatron 为核心引擎，针对多模态训练场景进行了原生重构，覆盖 LLM、VLM、VLA、Diffusion 等多种模型形态，支持 NVIDIA GPU 与 [[昆仑芯]] XPU 双平台运行。

## 核心内容

### 行业背景
- 多模态正在成为大模型的新底座，从"外挂视觉编码器"演进为"预训练原生多模态"
- 算力从单一 GPU 供给走向多元异构，[[昆仑芯]] P800 已进入千卡级规模化落地

### 核心技术
- [[cct-通算传并行|CCT 通算传并行]]：解决 MoE 长序列训练中显存与通信的二选一困局
- [[chunkpipe-流水线并行|ChunkPipe 流水线并行]]：将超长序列显存开销从线性增长转为固定开销
- [[dp-负载均衡|DP 负载均衡]]：动态重排样本分配，消除多模态数据异构带来的隐性算力损耗
- [[模型异构并行]]：允许 ViT 与 LLM 各自独立配置最优并行策略
- [[自适应-fp8|自适应 FP8]]：按层、按组件动态选择 FP8 或 BF16 精度策略
- [[dsa-算子融合|DSA 算子融合]]：针对 DeepSeek V3.2 稀疏注意力架构的端到端算子融合

### 性能数据
- 主流模型 15%~45% 端到端训练加速
- DeepSeek V3.2 上约 5 倍性能提升
- 昆仑芯 5000+ 卡集群 90%+ 线性扩展效率

### 生产案例
- [[llava-onevision|LLaVA-OneVision]] 1.5/2.0
- [[千帆-vl|千帆 VL 系列]]（3B/8B/70B）在昆仑芯 5000+ 卡集群上训练

### 路线图
- 持续适配 Kimi K2.6、[[DeepSeek V4]] 等新模型
- 完善百万级超长序列训练支持
- 训推一体协同优化
