# 「Claude Code之父」其实是野路子来的

## 摘要
本文详细介绍了 [[claude-code]] 之父 [[boris-cherny]] 的非典型职业路径。Boris 并非计算机科班出身，而是经济学专业辍学后自学编程，曾任 Meta 首席软件工程师近 7 年。他在 Anthropic 期间从一个简单的 CLI 工具起家，开发了年化收入达 25 亿美元的 Claude Code。文章还提及了他离职又回归（"C妃回宫"）的戏剧性经历，以及他主导的新产品 [[claude-cowork]] 和极致的 [[dogfooding]] 实践。

## 核心要点

### Boris Cherny 的背景
- **非科班出身**：加州大学圣地亚哥分校经济学专业，辍学后补位。
- **自学成才**：中学时自学编程，为 eBay 编写网页代码。
- **Meta 生涯**：任职近 7 年，负责 Instagram 服务器架构和开发基础设施。
- **技术著作**：著有 TypeScript 界"圣经"《Programming TypeScript》。

### Claude Code 的诞生与爆发
- **偶然起源**：最初只是为了学习公司 API 而写的极简 CLI 工具。
- **关键转折**：2025 年 5 月，利用 Opus 4 和 Sonnet 4 模型打磨，代码生成比例从 10% 提升至 30%。
- **商业成功**：年化收入从 2025 年 12 月的 10 亿美元暴涨至 2026 年 2 月的 25 亿美元，带动 Anthropic 总收入突破 300 亿美元。

### "C妃回宫"戏剧性
- **离职风波**：Boris 和产品负责人 Catherine Wu 曾跳槽至 [[cursor]]。
- **火速回归**：半个月后被 Anthropic 请回，回归后营收暴涨 5.5 倍。
- **核心地位**：证明了核心产品负责人在 Agent 时代的决定性作用。

### Claude Cowork 与极致 Dogfooding
- **新产品**：面向普通用户的自动化工具，能直接操作桌面和办公软件。
- **开发速度**：团队用 Claude Code 仅 10 天生成。
- **极致实践**：Boris 宣称不再手写代码，并让 AI 接管生活琐事（预定航班、支付罚单、催办同事）。

### 代码质量争议
- **源码泄露**：[[chaofan-shou]] 发现 Claude Code 源码泄露。
- **"屎山"评价**：代码质量被吐槽为"没意思"，与其强大功能形成反差。
- **公关危机**：Boris 亲自处理 [[openclaw]] 封杀事件，工作到晚上 11 点。

## 重要引述
> "模型就是想用工具，这是它的本能。" — Boris Cherny

> "从去年年底开始，他就再也没手写过一行代码。"
