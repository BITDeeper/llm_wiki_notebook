## 关键概念

**Think-at-Hard (TaH)**（方法）
- 定义：一种面向小模型的选择性潜空间迭代方法，通过轻量级 decider 动态决定哪些 token 需要额外计算，跳过约 93% 的无效迭代。
- 重要性：本文核心贡献，入选 ICLR LIT Workshop Best Paper Shortlist 并被 ICML 2026 接收。
- 维基状态：未收录。

**潜空间过度思考 (Latent Overthinking)**（现象）
- 定义：在 Looped Transformer 中，对已经预测正确的 token 进行额外潜空间迭代，反而将正确预测改为错误预测的现象。
- 重要性：本文的核心发现与动机，揭示了统一深度迭代的根本缺陷。
- 维基状态：未收录。

**Looped Transformer**（架构）
- 定义：在生成每个 token 前，将最后一层隐藏状态送回模型进行额外潜空间迭代的架构，在不增加参数的情况下增加计算深度。
- 重要性：TaH 的基础架构。
- 维基状态：未收录。

**Duo-causal Attention**（技术）
- 定义：将因果注意力扩展到"token 位置 × 迭代深度"二维平面的注意力机制，允许跨迭代深度的信息流动。
- 重要性：TaH 的核心架构创新之一。
- 维基状态：未收录。

**Depth-aware LoRA**（技术）
- 定义：仅在深层迭代（d>1）中启用 LoRA adapter，让 LoRA 专注于学习困难 token 的修正方向。
- 重要性：使不同迭代层承担不同优化目标。
- 维基状态：未收录。

**Oracle 策略**（方法）
- 定义：仅当模型第一次预测出错时才进行潜空间迭代的理想策略，用于量化选择性迭代的上限潜力。
- 重要性：证明了 token 级动态计算分配的巨大价值（最高可带来 25% 以上提升）。
- 维基状态：未收录。

**测试时计算扩展 (Test-time Scaling)**（范式）
- 定义：通过增加推理时的计算量来提升模型性能的方法。
- 重要性：TaH 将其推向更细的 token 粒度。
- 维基状态：未收录。

## 主要论点与发现

**核心主张：**
1. 统一深度的潜空间迭代存在"潜空间过度思考"问题，对简单 token 的额外迭代不仅浪费算力，还会损害准确率。
2. TaH 通过 token 级动态算力分配，在跳过 93% 额外迭代的同时，准确率反而提升 3.0%–6.8%。

**关键证据：**
- Oracle 策略实验：仅让 11–19% 的 token 二次迭代即可带来最高 7.3% 提升；配合 TaH 架构提升超 25%。
- 9 个基准测试（GSM8K、MATH500、AMC23 等）：TaH 相比标准模型提升 3.0%–3.8%，TaH+ 提升 5.3%–6.2%。
- 效率指标：平均每 token 仅 1.07 次迭代，FLOPs 仅增加 4–5%，相比始终迭代策略显存低 1.48 倍、解码快 2.48 倍。
- 语义解释：But（34%）和 So（18%）是最常触发额外迭代的 token，对应推理中的转折和因果关键点。
- 消融实验：系统性验证了 decider、duo-causal attention、depth-aware LoRA 和两阶段训练各自的必要性。

**证据强度：** 强。多规模模型验证（0.6B/1.7B/4B）、9 个基准测试、完整消融实验、已被 ICML 2026 接收。

## 矛盾与张力

- **与"更多计算=更好性能"的直觉矛盾**：本文核心发现是"更多迭代反而有害"，这对当前行业普遍追求更长 CoT、更多 test-time compute 的趋势提出了重要修正。
- **内部张力**：TaH 的两阶段训练虽然有效，但 decider 与 backbone 的紧耦合问题尚未完全解决，端到端训练仍不稳定。
- **适用范围限制**：实验仅在较小参数模型（0.6B–4B）上验证，是否能扩展到大模型尚不明确。
