# 刚刚，Meta Skill来了

量子位发布的关于 [[opensquilla]] 发布 [[meta-skill|Meta Skill]] 功能的深度评测文章。文章详细实测了9个封装好的Meta Skill，重点展示了 kid-project-planner 的运行效果（20分钟自动交付3000字项目规划包），并深入分析了 [[智能模型路由]] 的Token节省机制、Meta Skill的创建流程以及 [[skill-2-0|Skill 2.0]] 范式迭代的行业意义。

## 核心内容

- **Meta Skill 实测**：kid-project-planner 由5个原子Skill拼接而成，包含立项、可行性分类、执行（分步计划→材料清单→安全提醒→家长学习目标→最终组装交付），全程无需人介入
- **智能路由**：根据子任务复杂度自动分配模型，弱智问题用DeepSeek仅花三分钱，复杂任务才调用大模型，号称节省60-80% Token成本
- **meta-skill-creator**：用于创建Meta Skill的Meta Skill，降低Skill编排门槛
- **「个人×社区」索引协议**：基于用户使用信号自动匹配和推荐社区Skill的推荐引擎
- **团队揭秘**：幕后创始人为 [[王云鹤]]，公司名为 [[基元律动]]

## 关键论点

1. Agent发展正从单Skill时代进入Meta Skill（Skill 2.0）时代
2. 智能路由是Agent大规模运行的必要基础设施
3. 多Agent潜能释放需要Skill层的架构升级
4. 三条线交汇（模型理解力提升 + Skill生态爆发 + 成本约束）倒逼范式迭代
