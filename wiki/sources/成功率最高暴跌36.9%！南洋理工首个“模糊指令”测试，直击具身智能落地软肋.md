# 概述

本文报道了南洋理工大学 [[MARS Lab]] 发布的 [[REI-Bench]] 评测基准，该研究首次系统性地评估了具身智能体在处理“模糊指令”时的表现。研究发现，在真实人机交互场景中，现有的主流任务规划框架（如 [[SayCan]]）在处理包含隐含指代或代词的指令时，成功率最高暴跌 **36.9%**。这一发现直击了当前具身智能落地的一大软肋：模型普遍建立在“指令永远是清晰”的理想化假设之上，缺乏处理真实人类语言模糊性的能力。

# 核心发现

- **性能断崖下跌**：在 [[REI-Bench]] 测试下，基线模型（LLaMA3.1-8B + SayCan）在处理模糊指令时，成功率下降幅度在 7.4% 至 36.9% 之间。
- **多轮对话敏感性**：即便在标准上下文中，仅增加对话轮次（不引入模糊词），LLaMA3.1-8B 的成功率也从 57.7% 降至 46.9%。这暴露了现有模型在上下文管理上的脆弱性。
- **错误归因**：主要错误原因是目标物体混淆。研究表明，模型并非缺乏知识，而是过于“急切”地执行任务，忽视了深层语义理解。通过引入“反思性提示”，模型可以重新识别正确目标。

# 关键技术细节

## REI-Bench 评测体系

研究团队融合语言学语用学理论，构建了覆盖 **9 个层级** 的模糊性测试矩阵：
1.  **指代难度 3 级**：显式指代（清晰） -> 混合指代 -> 隐式指代（极度依赖上下文）。
2.  **上下文干扰 3 级**：标准上下文 -> 噪声上下文（含同名干扰项） -> 短上下文（信息缺失）。

## 解决方案：TOCC

针对这一问题，团队提出了 [[TOCC]]（一种轻量级即插即用解法），通过前置指令重写，将指代解析与任务规划解耦，从而有效提高成功率。

# 意义与影响

该研究挑战了“只要集成 LLM，机器人就能自然理解人类意图”的现有假设。它揭示了 [[具身智能数据困境]] 中的“认知对齐”难题，即仅靠增加数据量无法解决语用学层面的理解鸿沟。研究呼吁学术界关注 [[桥接推理]] 在具身智能中的应用，以提升机器人在真实场景（如服务老人、儿童）中的可用性。
