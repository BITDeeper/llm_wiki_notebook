# 什么！你说胡彦斌也在苦修Vibe Coding

量子位发布的轻量化科普文章，记录了 [[vibe-coding|Vibe Coding]] 从程序员圈层向文学圈、娱乐圈等非技术领域快速扩散的现象。

## 核心内容

文章以三个代表性案例展示 Vibe Coding 的"出圈"趋势：

1. **[[余华]]**（作家）—— 在《影视飓风》节目中展示对 AI 的开放态度，称"连本地部署都学会了"，体现文学界对 AI 技术的初步接纳。
2. **[[胡彦斌]]**（歌手）—— 2024年起自学编程，2026年通过 Vibe Coding 独立开发粉丝社区 App [[彦火]]，在社交媒体发帖"修bug在路上"。
3. **[[milla-jovovich|Milla Jovovich]]**（演员）—— 与 Claude 合作开发 AI 记忆系统 [[mempalace|MemPalace]]，GitHub 52.6k stars，[[longmemeval|LongMemEval]] 基准测试史上最高分 96.6%。

## 关键论点

- Vibe Coding 正在从技术圈术语演变为大众文化现象
- "人人都是开发者"的愿景在过去三十年被多次提出（Dreamweaver → Wix → low-code/no-code → GPT → Vibe Coding），但 Vibe Coding 首次让非技术人员真正完成完整产品开发
- [[andrej-karpathy|卡帕西]] 于2025年提出 Vibe Coding 概念，但非技术人员用 AI 辅助编程的实践可能早于概念命名

## 分析备注

- 文章为轻量化科普风格，缺乏深度技术分析
- MemPalace 的具体技术架构和 LongMemEval 基准细节未展开
- 胡彦斌2024年学编程早于 Karpathy 2025年提出概念，存在时序张力
