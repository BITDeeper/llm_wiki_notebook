# 马斯克破大防了：私信求和遭拒，怒喷奥特曼Brockman「全美最恶人」

## 概述
本文详细报道了 [[埃隆·马斯克]] 与 [[OpenAI]] 诉讼案庭审第二周的激烈交锋。核心事件包括马斯克因和解被拒而发出的威胁短信，以及 [[格雷格·布罗克曼]] 在证人席上承认“追求报酬”是其动机之一。文章还梳理了双方在庭审中展示的关键证据，包括布罗克曼 2017 年的私人日记和马斯克试图收购 OpenAI 的历史记录。

## 关键事件

### 威胁短信事件
在庭审前（4月25日），马斯克向布罗克曼发送短信提议和解。在遭到拒绝后，马斯克回复威胁称：“这周结束之前，你和 [[萨姆·奥特曼]] 会成为美国最令人憎恶的两个人。”
- **法律后果**：法官 Yvonne Gonzalez Rogers 裁定该短信因程序问题（提交时机过晚）不予采纳为证据，但未禁止媒体报道。
- **舆论影响**：短信曝光后，主流媒体（如金融时报、彭博社）普遍将其解读为马斯克试图“毁掉对方名声”的胁迫行为。预测市场（Kalshi, Polymarket）上马斯克的胜诉率大幅下跌至 36% 左右。

### 布罗克曼的证词
OpenAI 总裁布罗克曼出庭作证，面对马斯克律师 Steven Molo 的盘问，承认了以下关键事实：
1.  **财务动机**：首次公开承认，除了实现 AGI 使命外，“报酬当然也是次要动机之一”。这与 OpenAI 官方长期宣称的“纯粹为了使命”的叙事存在偏差。
2.  **巨额股权**：确认其个人持有的 OpenAI 股权市值接近 300 亿美元，但他并未向 OpenAI 非营利基金会捐赠任何资金。
3.  **历史日记**：2017 年的私人日记被公开，其中记录了关于“财务上达到 10 亿美元”、“没对马斯克诚实”、“偷走非营利会是道德破产”以及“直接翻成营利赚钱听起来挺好”的想法。法官认为这些日记暗示了欺诈意图。
4.  **未兑现的捐款**：2015 年布罗克曼曾承诺个人捐赠 10 万美元给 OpenAI 非营利组织，但至今未兑现。

## 双方论点与策略

### 马斯克方的核心主张
- **“偷窃慈善机构”**：指控奥特曼和布罗克曼利用马斯克的资金和名声，将原本承诺为全人类服务的非营利组织，变成了一个估值 8520 亿美元的营利帝国。
- **“尾巴摇狗”**：马斯克用此比喻形容 OpenAI 现状，即原本为了辅助非营利使命的营利子公司（尾巴）反过来控制了整个组织的方向（狗）。
- **索赔诉求**：索赔 1500 亿美元，要求 OpenAI 恢复非营利状态，并撤销奥特曼和布罗克曼的职务。

### OpenAI 方的反击策略
- **揭露虚伪性**：通过证据展示马斯克自己也曾在 2017 年试图将 OpenAI 营利化并要求绝对控制权，且在 2025 年试图收购 OpenAI。
- **指控不正当竞争**：指出马斯克的 xAI 使用 OpenAI 代码训练 [[Grok]] 模型，违反了服务条款。
- **人格攻击**：利用威胁短信和马斯克的历史行为，试图将案件定性为马斯克出于嫉妒和竞争意图对竞争对手的攻击，而非真正关心 AI 安全。

## 案件背景与后续
- **证人名单**：萨姆·奥特曼和微软 CEO [[萨蒂亚·纳德拉]] 计划在本月稍晚出庭作证。希冯·齐利斯（前 OpenAI 董事、马斯克孩子的母亲）也被卷入其中。
- **公众舆论**：YouGov 民调显示 56% 的美国公众对马斯克持负面看法。
- **预测市场**：目前市场预测马斯克胜诉概率约为 35%-36%，且双方达成和解的概率较低。
