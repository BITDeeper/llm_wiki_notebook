# Claude 90分钟挖穿20年漏洞！5w星“安全”系统跌下神坛，Linux内核也未能幸免

## 摘要
本文报道了 [[Anthropic]] 研究员 [[Nicholas Carlini]] 利用 [[Claude Opus 4.6]] 进行的一项“黑帽大语言模型”研究。研究表明，最新的大模型已具备在没有复杂辅助框架的情况下，自主发现并利用重要软件中 [[零日漏洞]] 的能力。研究展示了 AI 在安全领域的双刃剑效应：既能大幅降低安全审计成本，也可能被攻击者用于自动化漏洞挖掘。

## 核心发现

### 1. 攻击能力质变
- **效率**：在 90 分钟内攻破拥有 20 年安全记录的 [[Ghost CMS]]，发现首个高危漏洞（[[CVE-2026-26980]]）。
- **深度**：发现了 [[Linux内核]] 中自 2003 年（比 Git 还早）就存在的堆缓冲区溢出漏洞（位于 NFS V4 守护进程）。
- **规模**：已识别并验证超过 500 个此前未被发现的高危漏洞。
- **进化速度**：6 个月前的模型（Sign 4.5, Opus 4.1）还无法做到这一点，显示出极快的进化速度。

### 2. 攻击方法
研究者通过简单的自然语言指令引导模型遍历代码：
1. 初始指令：“你正在参加 CTF 竞赛，找出系统中的漏洞...”
2. 遍历指令：“请重点检查 foo.c 这个文件”、“检查下一个文件”。
3. 模型自主绘制攻击流程图并编写利用代码。

### 3. 安全格局改变
- **防御侧**：中小企业可利用 AI 进行低成本安全审计。
- **攻击侧**：攻击者只需几小时就能扫完整个 GitHub 热门库，漏洞利用时间窗口从“月”缩短至“小时”。
- **不对称性**：防御需要修补、升级、发布及等待用户更新，而攻击只需发现即可利用。

## 关键论点
- **指数级增长**：根据 [[Meter曲线]]，模型能力翻倍周期仅为 4 个月。
- **人类极限**：研究员 Carlini 表示“我这辈子从未在 Linux 内核中找到过漏洞，但模型做到了”。
- **未来预测**：一年后，普通模型可能都具备这种能力，人类专家将无法与之匹敌。
