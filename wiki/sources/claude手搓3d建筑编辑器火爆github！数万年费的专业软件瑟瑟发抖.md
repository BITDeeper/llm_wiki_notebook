# Claude手搓3D建筑编辑器火爆GitHub！数万年费的专业软件瑟瑟发抖

## 摘要
本文报道了由 Claude 编写的开源 3D 建筑编辑器 [[pascal-editor]]，该项目上线数天即在 GitHub 获得 5.4k Stars。文章探讨了 AI 生成软件对传统昂贵 SaaS（如 AutoCAD, Revit）的潜在冲击，并介绍了另一个基于 Claude 的多 Agent 游戏开发项目 [[claude-code-game-studios]]。

## 核心内容

### Pascal Editor：浏览器端的 3D 建筑设计
- **技术栈**：基于 [[webgpu]] 的高性能渲染，无需安装，直接在浏览器运行。
- **功能**：支持墙体绘制、区域选择、家具布置、2D/3D 联动编辑、参数实时调整。
- **优势**：免费开源，降低了建筑设计的门槛，适合非专业用户或基础设计需求。
- **局限**：在专业深度上相比 Revit 等顶级软件仍有差距。

### Claude-Code-Game-Studios：一人工作室
- **概念**：包含 48 个专业 AI Agent（如创意总监、技术总监、关卡设计师）的虚拟游戏开发工作室。
- **架构**：展示了 [[agent-workflow]] 在复杂任务协作中的应用，所有 Agent 分工明确但最终决策权归用户。
- **意义**：验证了“一人公司”模式的可行性，大幅降低了团队协作成本。

## 关键观点
- **AI 编程能力的质变**：Claude 已具备生成完整、可用且架构复杂的应用软件的能力。
- **软件行业成本结构颠覆**：免费开源的 AI 生成软件正在挑战动辄数万年费的传统专业软件。
- **设计平民化**：技术门槛的降低使得室内设计师、房产中介甚至个人用户都能轻松进行 3D 设计。
