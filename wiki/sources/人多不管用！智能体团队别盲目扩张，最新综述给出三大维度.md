# 源：人多不管用！智能体团队别盲目扩张，最新综述给出三大维度

## 概述
本文报道了埃默里大学、牛津大学和格里菲斯大学联合发布的一篇关于大规模智能体系统的综述。该研究指出，单纯增加智能体数量（“堆人头”）并不能保证系统性能的提升，反而可能导致系统失稳。文章提出了一个包含架构拓扑、记忆范围和更新行为的[[三维分类框架]]，用于分析系统的扩展性和稳定性。

## 核心观点

### 三维分类框架
研究者提出用以下三个维度来统一描述大规模智能体网络：
1.  **架构拓扑**：系统是中心化还是去中心化的。
2.  **记忆范围**：信息存储在全局记忆（共享上下文）还是局部记忆（分布式环境）中。
3.  **更新行为**：系统在运行中是静态（结构固定）还是动态（自适应变化）的。

### 真正的瓶颈：世界模型不一致
文章强调，通信协议并非最深层的瓶颈。更根本的问题是[[世界模型不一致]]。即使消息传输无误，不同智能体因内部知识、偏好和记忆不同，也可能对同一信息产生不同解释。这种不一致会导致：
-   **信念漂移**：认知层面的理解分歧。
-   **目标偏移**：任务层面的方向偏离。
-   **非平稳动态**：系统层面难以收敛。

### 扩展性难题
-   **中心化系统**：易统一调度，但规模扩大后易出现中心瓶颈。
-   **去中心化系统**：更灵活，适合研究群体涌现，但易出现局部失调和信息漂移。

## 行业趋势
数据显示，无论是 Marketplace 中的 Agent 数量，还是 System 中每个任务链涉及的 Agent 数，都在明显增长。现有的评估体系多针对小规模系统，无法评估未来可能包含上百万智能体的真实环境。

## 启示
未来系统要真正扩展，关键不在于增加智能体数量，而要解决拓扑、记忆、更新机制和世界模型对齐之间的系统性问题。
