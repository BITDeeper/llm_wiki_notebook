# 让机器真正理解世界需要一张「认知地图」，中科院发布空间智能综述

## 概述

中国科学院自动化研究所田雨萱（第一作者）与郑晓龙（通讯作者）联合多所高校发布综述论文《Spatial Intelligence from a Cognitive Map Perspective: A Survey》，以**认知地图（Cognitive Map）**为核心视角，重新梳理空间智能研究。

## 核心论点

论文将传统生物导航中的认知地图概念扩展为现代空间智能系统中的**内部表征蓝图**，连接空间感知、空间推理与空间生成三大方向，使原本分散的研究方向能够在统一机制框架下被理解与讨论。

## 关键贡献

1. **认知地图三性质框架**：提出抽象性（Abstraction）、全局性（Globality）、持久性（Persistency）作为评价认知地图能否支撑空间智能的充分必要条件。
2. **统一流程模型**：建立"感知（构建）→推理（读取）→生成（外化）"的连续过程模型。
3. **系统分类**：
   - 表征范式：度量表征、关系表征、混合表征
   - 推理范式：Map as Embedding、Map as Prompt、Map as API
   - 生成范式：静态场景合成、动态世界模拟
4. **应用分类**：开环空间认知（观察理解）vs 闭环空间交互（感知-行动循环）

## 未来方向

- 更深层的语义抽象（对象身份、物理属性、因果机制）
- 扩展全局空间理解（大规模3D场景空间基础模型）
- 动态环境长期持久性（4D时空表征）
- 认知地图作为生成式模拟器
- 弥合感知与行动之间的鸿沟
