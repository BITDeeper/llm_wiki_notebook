# 奥特曼趁马斯克出差爆猛料：他曾想让子女继承OpenAI

量子位（QbitAI）关于 OpenAI 世纪诉讼庭审第三周的现场报道。本文记录了 [[sam-altman]] 首次出庭作证的核心内容，包括多项爆炸性指控。

## 核心内容

### AGI控制权世袭指控
奥特曼当庭作证称，[[elon-musk]] 曾在 OpenAI 早期内部讨论中提出，未来 OpenAI 的控制权可以"传给自己的孩子"。奥特曼表示当时对此十分反感。

### 马斯克早年支持营利结构
奥特曼证词称，马斯克并非后来才知道 OpenAI 会走向营利结构。两人在特斯拉总部第二次会面时，共同审阅了创建营利性公司的条款清单，马斯克对此表示赞赏，认为实验室需要大量资金。

### 管理文化冲突
奥特曼评价马斯克"不懂如何运营一个好的研究实验室"，称其[[电锯管理学]]对 OpenAI 组织文化造成了长期巨大损害。

### 其他细节
- OpenAI 累计从投资人手中募集 1750 亿美元用于模型训练和算力建设
- 马斯克离开董事会后，内部曾担心其采取报复行动
- [[shivon-zilis]]（齐利斯）曾在私人通信中建议奥特曼如何不"惹恼"马斯克
- 奥特曼谈到被罢免后曾考虑转投微软，最终决定回来："我愿意跑回一栋着火的大楼里抢救它"
