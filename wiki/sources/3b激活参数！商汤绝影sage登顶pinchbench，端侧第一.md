# 3B激活参数！商汤绝影Sage登顶PinchBench，端侧第一

## 摘要
商汤绝影发布了端侧多模态智能体基座大模型 [[sage-模型]]。该模型采用 MoE 架构（总参数 32B，激活参数 3B），在 [[pinchbench]] 全球 Agent 权威评测中以 94% 的任务完成率超越 Claude-Opus-4.6 (93.3%) 和 GPT-5.4 (90.5%) 等主流云侧大模型。文章详细介绍了其背后的 [[scout]]（分级协同学习）和 [[erl]]（可擦除强化学习）技术，以及其在智能座舱场景中的应用优势。

## 核心观点
- **打破迷思**：证明了“只有大模型才能做好 Agent 任务”是错误的。通过架构优化和后训练技术，3B 激活参数的端侧模型可以在 Agent 任务上超越云端大模型。
- **效率优势**：相比小米 MiMo-v2-Pro，Sage 所需激活算力仅为其 1/14，显存占用约为其 1/31，但任务完成率高出 6.6%。
- **技术护城河**：
  - [[scout]]：通过“探路与吸收解耦”，利用小模型探索高价值路径喂给大模型，节省约 60% 算力。
  - [[erl]]：允许模型在推理过程中自动识别并“擦除”错误步骤，阻断偏差扩散，提升任务完成率 20%。
- **场景落地**：Sage 不仅能处理语音指令，还能主动感知（如儿童模式）、实时路况判断及多系统联动（空调、导航、音乐），在 OrinX 平台上首字响应仅 0.5s。

## 关键数据
- **PinchBench 评测**：任务完成率 94%（Claude-Opus-4.6 为 93.3%）。
- **τ2-bench（工具调用）**：得分 80，较同级端侧旗舰 Gemma4 提升 38%。
- **座舱语义理解**：得分 91，较 Gemma4 提升 32%。
- **部署性能**：在 OrinX 上实现 0.5s 首字响应，80tk/s 生成吞吐。

## 行业意义
Sage 的发布标志着智能座舱从“语音助手”向“端侧智能体”的转型。它解决了云端方案的高延迟、高成本（单任务数十万 Token）和隐私风险问题，为车企提供了一套经过验证的量产端侧 Agent 方案。
