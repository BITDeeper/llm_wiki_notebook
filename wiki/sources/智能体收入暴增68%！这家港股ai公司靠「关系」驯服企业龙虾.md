# 智能体收入暴增68%！这家港股AI公司靠「关系」驯服企业龙虾

## 摘要
本文报道了港股 AI 公司 [[海致科技]]（2706.HK）的上市首份财报。公司通过专注于企业级 [[图模融合]] 架构，实现了 [[Atlas智能体业务]] 收入同比增长 68.4% 的亮眼成绩。文章深入探讨了为何单纯的大模型参数竞赛无法解决 B 端落地难题，并指出 [[AtlasGraph]] 作为“Agent OS”在管理企业复杂关系、技能依赖和执行边界方面的核心价值。

## 核心数据
- **全年营收**：6.21 亿元（同比增长 23.4%）。
- **净利润**：2414.7 万元（同比增长 42.6%）。
- **Atlas 智能体业务收入**：1.457 亿元（同比增长 68.4%）。
- **智能体业务毛利率**：53.2%。
- **图谱解决方案客户数**：172 家（客单价 280 万元）。
- **智能体业务客户数**：从 19 家增长至 40 家（其中 50% 为原有图谱客户转化）。

## 关键论点

### 1. 企业级 AI 落地的痛点
尽管 Coding Agent（如 [[claude-code]]）和 C 端生态（如 [[openclaw]]）发展迅速，但 B 端应用仍停留在 Demo 阶段。核心原因在于**不敢给 AI 执行权**。
- **不可控性**：底层概率模型的随机性导致不可预测的行为。
- **上下文瓶颈**：暴力扩充上下文不仅成本高，且受限于模型注意力机制（中间内容易被遗忘）。
- **资产分散**：知识、规则、Skill 和状态散落在不同系统中，难以协同。

### 2. 解决方案：图模融合
[[海致科技]] 提出了 [[图模融合]] 的架构，利用图数据库的结构化优势弥补 LLM 的不确定性。
- **图数据库逻辑**：通过节点和边管理数据间的复杂关系（如反走私案例中的资金、物流、人员关联）。
- **协同工作**：图技术负责高效索引和约束，LLM 负责推理和生成。

### 3. AtlasGraph：面向 Agent 的操作系统
[[AtlasGraph]] 被定位为管理 Agent 的操作系统，包含五大核心模块：
1.  **Ontology 图管理**：语义对齐，定义业务世界的统一坐标系。
2.  **Skill 管理**：解决技能间的依赖关系（如销售报价中定价规则对历史订单的依赖），提供标准化执行接口。
3.  **三张图架构**：
    -   **任务图**：拆解目标，管理子任务依赖与并行。
    -   **记忆图**：存储历史交互与经验（如客户之前的询价记录）。
    -   **状态图**：保存任务快照，支持断点续传（如报价生成中断后的恢复）。
4.  **规则引擎**：内置审批链、权限控制等，确保执行合规。
5.  **端到端闭环**：从数据治理到知识建模，再到自动执行。

## 行业洞察
- **中间层价值**：在模型能力同质化竞争中，中间层基础设施（如 [[AtlasGraph]]）构成了更深的护城河。
- **深水区需求**：金融、政务等核心场景需要的不是“更聪明的大脑”，而是“严守纪律的数字员工”。
- **未来趋势**：随着 Agent 自主性增强，失控风险上升，对治理架构（Agent OS、多智能体编排）的需求将愈发迫切。
