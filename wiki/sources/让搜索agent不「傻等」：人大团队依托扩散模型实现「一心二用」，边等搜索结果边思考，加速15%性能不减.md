# 让搜索Agent不「傻等」：人大团队依托扩散模型实现「一心二用」

本文报道了 [[中国人民大学]] 团队（GSAI IIR & GSAI-ML）发表的论文工作，提出了基于 [[扩散大语言模型]] 的搜索 Agent 系统 [[DLLM-Searcher]]。该系统通过 [[p-react]] 策略实现了“一心二用”的 [[并行推理]] 模式，即在等待搜索引擎返回结果的同时继续进行思考，从而在不损失性能的前提下实现了 14.77% 到 22.08% 的端到端加速。

## 核心痛点
传统的 [[ReAct]] 框架搜索 Agent（如 [[Search-R1]]）采用串行执行模式（想 -> 调工具 -> 等 -> 再想）。在等待外部工具返回时，模型处于空闲状态，导致严重的延迟累积。自回归模型因因果注意力机制限制，无法通过调整生成顺序（先调用工具再思考）来解决这个问题，否则会导致性能大幅下降。

## 解决方案
[[DLLM-Searcher]] 利用扩散模型 [[块内双向注意力]] 的特性，允许模型在生成过程中利用上下文信息，从而支持“先行动后思考”的并行模式。

### 技术路径
1.  **Agentic SFT（监督微调）**：使用强模型（[[豆包]] Seed-1.8）生成的高质量轨迹进行训练。
2.  **Agentic Noising**：针对扩散模型双向注意力可能导致的信息泄露问题，仅对“思考”和“工具调用”部分加噪，保留或遮蔽搜索结果，确保训练与推理的一致性。
3.  **Agentic VRPO**：通过方差缩减的偏好优化，进一步提升推理准确性。
4.  **P-ReAct 策略**：无需额外训练的推理加速方案。通过预填充边界标记和给工具调用区域置信度加偏置，强制模型优先解码工具调用，利用等待时间并行生成思考内容。

## 实验结果
-   **性能持平**：在 HotpotQA 等四个数据集上，准确率达到 57.0 (ACC_R)，与自回归基线 [[R1Searcher]] 持平。
-   **显著加速**：P-ReAct 带来了 14.77% - 22.08% 的端到端加速。
-   **架构优势**：对比实验显示，自回归模型（Qwen3）尝试“先行动后思考”会导致准确率显著下降，证明了扩散模型在并行推理上的结构性优势。
-   **数据效率**：仅使用不到 8000 条训练数据即达到 SOTA 水平。

## 意义
该工作首次证明了扩散大语言模型在 Agent 任务中不仅能追平自回归模型，还能利用其并行生成特性突破效率瓶颈，为搜索 Agent 的优化提供了新思路。
