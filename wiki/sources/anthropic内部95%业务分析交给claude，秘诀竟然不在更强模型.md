# Anthropic内部95%业务分析交给Claude，秘诀竟然不在更强模型

## 摘要

本文报道了 Anthropic 官方博客披露的内部 AI 数据分析方法论。Anthropic 数据科学与数据工程团队搭建了四层 [[智能体分析栈]]，将 Claude 的数据分析准确率从 21% 提升至 95% 以上。核心发现是：准确率的瓶颈不在模型写 SQL 的能力，而在写 SQL 之前的上下文组织、知识固化与持续验证。

## 核心发现

1. **Skills 是最大跃迁因子**：没有 Skills 准确率 ≤21%，加上后稳定 95%+，部分领域接近 99%。
2. **负面实验**：喂入数千条历史 SQL 进行检索，准确率提升不到 1 个百分点；80% 的错误答案其实已存在于模型刚读过的语料中。
3. **系统会"腐烂"**：未维护的系统准确率一个月内从 95% 降至 65%。
4. **最后几个百分点的代价**：对抗式审查提升 6% 准确率，但 token 消耗增加 32%、延迟增加 72%。

## 关键概念

- [[虚假的精确感]]：AI 输出格式漂亮、语气笃定，却用错了数据源的现象。
- [[智能体分析栈]]：四层架构（数据基础层、事实来源、技能、验证）。
- [[分析准确率衰减]]：系统准确率随数据模型变化而自然下降的现象。
