# 不止会写代码：清华和极佳联合开源多模态全交互智能体框架Syll！

## 摘要

本文报道了清华大学智能视觉实验室（鲁继文教授团队）与极佳视界联合开源的多模态全交互智能体框架 [[syll]]。该框架针对当前个人 AI 智能体面临的界面割裂、教学门槛高、执行不透明、隐私与定制困难四大痛点，提出了统一多模态执行、示教即技能、全程可审计追踪与本地模块化架构四大设计理念。

## 核心内容

- **统一多模态执行**：Syll 将 GUI、CLI、MCP/API 三种操作方式纳入同一执行回路，使智能体能在不同工作表面间自然流转。
- **示教即技能**：用户无需编写代码，只需手动操作一遍任务流程，Syll 自动录制、提取关键步骤并沉淀为可复用技能。
- **多模态审计体系**：每一步操作均被记录、可回放、可审计，形成机器执行到人审核的验证闭环。
- **本地模块化架构**：记忆、技能、规则、偏好以本地可编辑文件存储，支持模型 provider 替换和技能插件扩展。

## 项目状态

项目处于 public alpha 阶段，已在 GitHub 开源（THU-SAGE/syll）。

## 关键关联

- 与 [[任务执行范式]] 呼应：Syll 是智能体工程化系统的具体实践。
- 与 [[场景白盒化推理]] 呼应：多模态审计体系是白盒化理念的桌面端实践。
- 与 [[操作系统agent]] 互补：Syll 侧重桌面级多模态交互统一，区别于 OS 级智能体。
