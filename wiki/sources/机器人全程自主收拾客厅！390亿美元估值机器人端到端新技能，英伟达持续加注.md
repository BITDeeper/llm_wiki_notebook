# 机器人全程自主收拾客厅！390亿美元估值机器人端到端新技能，英伟达持续加注

## 摘要
本文报道了 [[Figure]] 公司发布的最新进展，其 [[Figure 02]] 机器人在 [[Helix 02]] 系统的驱动下，实现了完全自主、端到端的客厅整理任务。文章详细解析了 Helix 02 的三层架构（System 0/1/2），强调了其“数据驱动”而非“算法重写”的泛化能力，并披露了 Figure 与 OpenAI 分道扬镳的细节及英伟达持续加注的融资背景。

## 核心内容

### 技术演示：自主整理客厅
Figure 02 机器人在家庭环境中完成了一系列复杂任务，包括：
- **清洁表面**：喷洒消毒液并用毛巾擦拭茶几。
- **物品收纳**：将杂物拾起并归置到收纳桶中。
- **整理环境**：摆正抱枕，精准使用遥控器关机并摆放好遥控器。
- **全身协作**：将毛巾搭在肩上腾出双手，侧身穿过狭窄空间。

整个演示过程持续近 4 分钟，全程无人为干预、无遥操作、无重置，展示了高度的自主性和鲁棒性。

### Helix 02 系统：统一的全身 VLA
[[Helix 02]] 被定义为一个统一的全身行走-操作 [[vla-视觉-语言-动作]] 模型。它将机载的全部传感器（视觉、触觉、本体感知）直接连接到所有执行器，实现了“感觉、思考、行动”的一体化。

其核心创新在于引入了 [[System 0/1/2]] 三层架构：
1.  **System 2（慢系统）**：负责高层语义推理，理解场景和语言，将任务拆解为行为目标。
2.  **System 1（快系统）**：以 200Hz 运行，将感知转化为全身关节目标，实现 [[pixels-to-whole-body]]（像素到全身）的控制。
3.  **System 0（极快系统）**：以 1kHz 运行，负责平衡、接触处理和全身协调。

### System 0：数据驱动的运动先验
System 0 是基于 1000 多小时人类运动数据训练得到的全身控制器，结合了 [[sim2real]] 技术。
- **替代手工代码**：用一个神经网络先验替代了 109,504 行手工编写的 C++ 控制代码。
- **通用性**：它不针对特定动作（如走路或伸手），而是学习人类在保持平衡与稳定前提下的底层运动先验。
- **作用**：当上层规划“做什么”时，System 0 保证身体能“稳定地做出来”。

### 泛化能力：数据即技能
团队强调，此次解锁客厅整理任务，**并未新增算法**，也未进行特殊场景的工程适配，仅通过补充最新场景数据，便让系统掌握了新技能。这证明了其架构在处理融合移动、操作与环境感知任务时的强大泛化能力。

### 公司背景与融资
- **创始人**：[[Brett Adcock]]，连续创业者。
- **合作破裂**：2025 年 2 月，Figure 宣布与 [[OpenAI]] 解约。据 TechCrunch 报道，原因在于 AI 模型与机器人硬件的集成环节出现分歧。
- **融资情况**：2025 年 9 月，Figure 完成 C 轮融资，斩获超 10 亿美元，投后估值达 **390 亿美元**，创下具身智能赛道最高估值纪录。[[英伟达]]（NVIDIA）在此轮融资中持续加注。

## 结论
Figure 的 Helix 02 系统通过端到端的神经网络架构和数据驱动的学习方式，展示了人形机器人在非结构化环境中的巨大潜力。其自研路径（特别是 System 0 的引入）与依赖外部通用大模型的路径形成了鲜明对比，为具身智能的落地提供了重要的技术参考。
