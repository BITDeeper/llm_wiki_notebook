# 震撼全网！3位00后夺200万大奖，卷走鹅厂顶级Offer

## 摘要
本文详细报道了 2025 年腾讯广告算法大赛的盛况。该赛事以“全模态生成式推荐”为题，吸引了全球 30 国、8400 多名技术精英参与。最终，由华中科技大学、北京大学、中国科学技术大学学生组成的“Echoch”战队夺得 200 万大奖。文章指出，高校学生在处理大规模工业级数据和设计复杂模型架构方面的能力已与工业界持平，推荐系统正从传统的“检索-排序”判别式模式，向端到端全模态生成式模式发生根本性转变。

## 核心观点
- **范式转移**：推荐系统正告别“检索-排序”的旧时代，大步迈入“端到端生成”的新纪元。全模态生成式推荐要求 AI 整合文本、图像、视频等多模态信息，直接生成推荐结果。
- **学界业界零代差**：腾讯公司副总裁蒋杰指出，现在的学生与工业界几乎没有代差，甚至更有创意。1-3 人组队即可完成过去大团队才能完成的工业级任务。
- **技术挑战与解法**：面对多模态噪声、超大规模稀疏 ID 和冷启动等挑战，冠军团队通过“逐位置行为条件化”、语义 ID 生成及 Muon 优化器实现了工程与算法的双重突破。

## 关键技术细节
- **冠军方案**：重构 PinRec 思想，提出逐位置行为条件化，利用 FiLM 层和 ATTMatch 解决点击与转化目标冲突；采用 LLM 风格 Dense Model + RoPE；使用 SVD 降维+层次化聚类生成语义 ID。
- **亚军方案**：设计了 Encoder-Decoder 架构，Encoder 端使用 G-MLP，Decoder 端使用改进版 SASRec Transformer，侧重隐私安全。
- **季军方案**：验证了推荐系统领域的 Scaling Law，单纯增加 Embedding 维度和模型层数可显著提升性能。

## 行业背景
文章提到 Meta 发布的生成式广告基础模型 GEM，以及谷歌、亚马逊、Shopify 等巨头在生成式推荐领域的布局，表明这一范式已成为全球行业风向标。
