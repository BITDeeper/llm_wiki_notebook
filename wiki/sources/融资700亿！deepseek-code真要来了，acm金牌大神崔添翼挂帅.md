# 融资700亿！DeepSeek Code真要来了，ACM金牌大神崔添翼挂帅

## 摘要

量子位2026年5月22日报道，DeepSeek融资额已飙升至700亿元，管理层表示优先考虑突破性AI研究而非短期商业化。与此同时，DeepSeek Code产品线通过多个官方信号确认存在：资深研究员Deli Chen公开发帖招聘"从零开始构建Code Harness"，官网密集释放Agent Harness相关岗位（5月15日产品经理、5月18日研发工程师）。前TSY Capital联合创始人、ACM六金得主[[崔添翼]]于3月加入DeepSeek，或将出任Agent Harness团队负责人。

## 核心信息

- **融资动态**：DeepSeek融资额达700亿元，管理层优先突破性研究
- **产品线确认**：DeepSeek Code通过招聘信号、Deli Chen公开帖确认存在
- **团队负责人**：[[崔添翼]]或将挂帅Agent Harness团队
- **核心公式**：Model + Harness = Agent（官方招聘信息）
- **竞品对标**：招聘要求深度使用过[[claude-code]]、[[codex]]、[[cursor]]、Manus、[[openclaw]]、[[hermes-agent]]等
- **社区生态**：[[deepseek-tui]]（GitHub 32.9k Stars）等社区平替工具已涌现

## 关键时间线

- 2026年3月：[[崔添翼]]加入DeepSeek
- 2026年5月15日：官网发布Agent Harness产品经理岗位
- 2026年5月18日：发布Agent Harness研发工程师岗位
- 2026年5月22日：Deli Chen公开发帖，本文发布
