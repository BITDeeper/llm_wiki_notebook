# 6.4k Stars！用Claude Code写论文的全套流水线，有人打包开源了

量子位关于开源项目 [[academic-research-skills]]（ARS）的深度报道。ARS 是一套基于 [[claude-code]] 的学术论文写作技能包，涵盖研究、写作、审稿、定稿四个环节，由 [[edward-cheng-i-wu]]（吴政宜）开发。

## 核心内容

- **四技能架构**：Deep Research（13个Agent）、Academic Paper（12个Agent）、Academic Paper Reviewer（7个Agent）、Academic Pipeline（流程编排器），组成10阶段流水线
- **引用核验机制**：使用 Semantic Scholar API + Levenshtein 相似度算法（阈值0.70）进行模糊匹配，防止 [[高阶幻觉]] 引用
- **完整性闸门**：在 Stage 2.5 和 4.5 设置不可跳过检查点，基于2026年 Nature 论文总结的7种AI失败模式
- **反谄媚协议**：魔鬼代言人评分机制（1-5分，低于4分不允许让步），对抗 [[认知投降]] 风险
- **三层数据隔离**：灵感来自 [[anthropic]] 的 w2s-researcher 研究，防止AI偷看评分标准
- **repro_lock 文件**：诚实记录运行配置但声明不保证复现

## 关键数据

- GitHub 6.4k Stars，300+ commits
- 实测抓到15个伪造引用和3个统计错误
- 1.5万字论文全程费用约4-6美元
- 推荐 Claude Opus 4.7 + Max 订阅（100-200美元/月）
- 项目支持繁体中文和英文

## 设计哲学

> "AI是你的副驾驶，不是飞行员。"

核心不在于"让AI写论文"，而在于"系统性防止AI搞砸学术研究"。
