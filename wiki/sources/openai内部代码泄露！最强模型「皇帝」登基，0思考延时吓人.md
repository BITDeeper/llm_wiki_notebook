# OpenAI内部代码泄露！最强模型「皇帝」登基，0思考延时吓人

## 概述
本文报道了 OpenAI 在 2025 年底的一系列代码泄露和产品测试动态，揭示了代号为「企鹅家族」的分级推理模型、新的「记忆搜索」功能以及应对市场竞争（特别是 [[gemini]] 3）的紧迫感。

## 核心发现

### 「企鹅家族」模型
泄露的代码显示 OpenAI 正在测试四个不同推理预算的模型变体，内部以企鹅命名：
- **Emperor (帝企鹅)**：推理预算 512，最强旗舰。
- **Rockhopper (跳岩企鹅)**：推理预算 64，中端。
- **Macaroni (马可罗尼企鹅)**：推理预算 16，高效快速。
- **Mumble**：推理预算 0，极速响应（无推理）。

代码中变量名为 `juice`，指模型在一次对话中可用的推理资源。

### 新功能：记忆搜索
OpenAI 正在测试「记忆搜索」功能，允许用户通过提示词直接检索 ChatGPT 中存储的历史记忆信息。这旨在解决当前记忆管理 UI 难用的问题，提升工作流效率。其设计思路与 Atlas 浏览器的「Browser Memory」功能相似。

### 竞争与发布计划
- **Shallotpeat**：传闻中即将推出的推理模型，据称在内部评估中性能超越 [[gemini]] 3。
- **Garlic**：已完成预训练的模型，预计明年初以 [[gpt-5.2]] 或 [[gpt-5.5]] 名义发布。
- **市场压力**：受 [[gemini]] 3 冲击，OpenAI 日活用户下降 6%，可能加速 GPT-5.2 的发布。

### 争议：广告植入
有付费用户报告在对话中看到广告。此前代码也曾泄露广告功能，引发用户威胁退订。这反映了 OpenAI 在变现与用户体验之间的冲突。
