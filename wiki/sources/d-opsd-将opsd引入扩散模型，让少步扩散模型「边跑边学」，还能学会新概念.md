# D-OPSD：将OPSD引入扩散模型，让少步扩散模型「边跑边学」，还能学会新概念

本文由[[机器之心]]发布，报道了阿里巴巴 Z-Image 团队联合[[香港科技大学]]、加州大学圣地亚哥分校、[[香港中文大学]]等机构提出的 [[d-opsd]]（On-Policy Self-Distillation）框架。

## 核心内容

文章介绍了首个针对[[少步扩散模型]]的[[在线策略自蒸馏]]框架 D-OPSD，解决了少步扩散模型在持续微调时面临的[[训练-推理分布偏移]]和[[灾难性遗忘]]问题。

### 关键发现

1. 现代配备 LLM/VLM 编码器的扩散模型继承了[[上下文学习]]能力，当目标图像作为条件输入时，无需额外训练即可生成保留目标概念/风格的变体。
2. D-OPSD 利用这一涌现行为，将目标图像作为教师分支的上下文监督信号，而非直接的降噪目标。
3. 在 LoRA 定制和全量微调实验中，D-OPSD 实现了"学新不忘旧"。

### 方法要点

- 学生分支仅基于文本条件采样（on-policy 轨迹）
- 教师分支基于文本+图像的多模态条件提供更强预测
- 采用[[速度预测对齐]]（均方误差）替代 LLM 中的 KL 散度进行分布对齐
- 无需奖励模型、无需成对偏好数据
