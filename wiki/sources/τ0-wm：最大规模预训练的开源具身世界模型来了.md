# τ0-WM：最大规模预训练的开源具身世界模型来了

量子位发布的关于 [[τ0-WM]] 具身世界模型的深度报道。文章详细介绍了由 [[罗剑岚]] 团队发布的全球最大规模开源预训练具身世界模型 τ0-WM，其参数量达 5B，预训练数据约 3 万小时（含 1.78 万小时真机遥操作数据）。

## 核心内容

- **模型架构**：基于 Wan2.2-5B 视频生成模型，包含视频动作模型（VAM）和动作条件视频模拟器两个共享 backbone 组件。
- **三步推理 Pipeline**：提议（采样候选动作）→ 推演（多视角未来画面生成）→ 评估与修正（RCS 打分 + LAR 修正）。
- **训练策略**：通过模态特定监督掩码统一处理三类异构数据（真机遥操作、UMI、EgoCentric）。
- **实验结果**：在长程精细操作任务上超越 π0.5 和 Fast-WAM；[[测试时计算]] 将新任务成功率从 43% 提升至 60%。

## 行业意义

文章指出 τ0-WM 打破了具身智能数据金字塔的固有认知，首次将真机数据作为预训练主力，标志着"真机数据飞轮"（预训练→真机部署→数据回流→再预训练）的闭环建立。
