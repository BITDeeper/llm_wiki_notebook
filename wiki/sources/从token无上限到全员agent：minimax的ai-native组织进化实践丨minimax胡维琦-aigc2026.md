# 从Token无上限到全员Agent：MiniMax的AI Native组织进化实践

本文为 MiniMax ToB 中国区商业化负责人 [[胡维琦]] 在 [[第四届中国aigc产业峰会]] 上的演讲实录，由 [[量子位]] 整理发布。

## 核心内容

演讲围绕 [[ai-native组织]] 的建设实践展开，分享了 [[minimax]] 从2024年到2026年的组织进化路径：

1. **公司定位**：专注文本、视频、语音、音乐多模态模型的AI公司，2026年1月港股上市，核心理念为"Intelligence With Everyone"。
2. **产品矩阵**：涵盖 [[星野]]（C端情感陪伴）、[[海螺ai]]（视频生成）、[[maxclaw]]（Agent工具）、[[maxhermes]] 等产品。
3. **内部实践**：2024年9月起全员不限Token使用Cursor；2025年8月启动Agent项目；10月推广Agent实习生计划。
4. **效率数据**：研发效率提升30%，30%-50%代码由模型自动生成。
5. **关键经验**：从"人类最不愿意干"的高价值场景切入；AI使组织更扁平；Token消耗量成为衡量效率的新指标。

## 关键观点

- AI已从"玩具"变为生产力工具，正在重塑组织形态。
- AI Native组织的建设路径是"先内部闭环，再外部输出"（[[dogfooding闭环]]）。
- 模型不仅能思考，还能反向驱动工具框架迭代（[[模型帮助harness迭代]]）。
- 未来2-3年AI将与各行业深度融合，改变商业模式和组织构成。
