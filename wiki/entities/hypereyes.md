# HyperEyes

HyperEyes 是 [[小红书]] 研究团队提出的并行多模态搜索智能体模型，实现了从「搜得更深」（串行加深）到「搜得更宽」（多目标并发）的范式跃迁。

## 核心架构

HyperEyes 在三个维度进行了全栈式底层重构：

### 1. 动作空间重构 — UGS
通过 [[统一定位即搜索-ugs|UGS（统一定位即搜索）]]，将视觉定位框直接作为检索动作的内嵌参数，使一次函数调用能并发携带多个目标框，从物理层面打通多目标并发通路。

### 2. 数据合成 — PRS
通过 [[渐进式拒绝采样-prs|PRS（渐进式拒绝采样）]]，在严格递增轮次预算下提纯出 3 万条「零冗余」的并行行为种子数据，解决 SFT 冷启动问题。

### 3. 强化学习 — 双粒度效率感知 RL
[[双粒度效率感知强化学习]] 框架包含：
- **宏观层面**：[[trace-动态参考成本效率奖励|TRACE]] — 自我超越的动态标尺机制，每个 Epoch 用最优表现收紧基准
- **微观层面**：[[opd-策略内蒸馏|OPD（策略内蒸馏）]] — 仅在轨迹失败时引入 235B 教师模型提供稠密 Token 级监督

## 关键实验结果

| 指标 | HyperEyes-30B | 对比 |
|------|---------------|------|
| 准确率 | 64.0% | 超越 VDR 9.9% |
| 平均工具调用轮次 | 2.2 | VDR 的不到 1/5（VDR 为 11.6） |
| CAS 成本效率评分 | — | 次优开源模型的 7.6 倍 |

235B 版本以仅 1.1% 的微弱差距逼近闭源旗舰 Gemini-3.1-Pro。

## 核心理念

**「效率即智能」** — 敢于少搜、一次看全的并行策略，反而能规避过度检索带来的幻觉陷阱。准确率与效率可以协同进化（Pareto 占优）。
