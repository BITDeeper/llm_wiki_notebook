# skill-cleaner

[[peter-steinberger]]（龙虾之父）开源的 Skill 体检与精简自动化工具，用于给 AI Agent 的 Skill 做全面审计和优化。GitHub 仓库位于 `steipete/agent-scripts/skills/skill-cleaner`。

## 设计理念

skill-cleaner 践行 Peter 的核心主张：**Skill 要像路标，不该把整本说明挂在路标上**。工具本身即为此理念的示范——Skill.md 仅 56 行提示词，调用的脚本足足近千行代码。Skill.md 是路标，代码才是说明书。

## 五大核心功能

1. **技能提示词预算审计计算**：分析技能占用的上下文令牌空间，计算预算占用比例，给出预算优化方案
2. **重复技能检测**：跨 Codex 内置库、插件缓存、代码库、个人技能根目录扫描同名或高度相似的重复技能
3. **未使用技能筛查**：基于历史日志识别长期未被调用的闲置技能，提供清理候选清单
4. **技能根目录审计**：统计所有技能来源根目录，标注启用/禁用状态，梳理技能加载链路
5. **描述精简优化**：找出冗长描述，推荐通过标准化短动作词组替换来压缩长度

## 技术细节

- **运行环境**：Node.js 脚本，支持自定义参数（时间范围、日志深度、预算阈值、自定义根目录等）
- **计费逻辑**：采用 [[codex]] 官方源码同款提示词预算核算逻辑（UTF8 字节数/4 向上取整）
- **上下文参考**：优先读取本地模型缓存配置获取 [[gpt-5.5]] 上下文窗口参数（默认 272k token）
- **预算基数**：以模型上下文窗口的 2% 为默认技能预算基数
- **优先级排序**：系统技能 > 内置技能 > 插件技能 > 仓库自定义技能
- **模拟功能**：可模拟预算不足时的技能描述截断字符数、被省略技能数量，输出预算使用率、剩余预算、上下文占用比例等指标

## 描述精简流程

1. 文本预处理：统一格式、全部小写、剔除标点符号
2. 场景识别：内置预设场景关键词词库，识别技能所属业务领域
3. 标准化替换：匹配场景后调用预设短动作词组替换冗长描述
   - 调试类 → debug, inspect, fix
   - 部署发布类 → deploy, release, verify
   - 检索归档类 → search, sync, summarize

## 工作流程

1. 在技能目录/仓库根目录运行分析脚本
2. 按顺序阅读审计报告：技能预算 → 描述优化项 → 重复技能 → 未使用技能 → 根目录汇总
3. 安全清理/编辑：优先保留 Codex 内置技能，删除本地/重复副本，修改前验证保留文件有效性

## 生态定位

skill-cleaner 深度绑定 [[codex]] 生态，是 [[token作为生产资料]] 概念的具体工程实践工具。与 [[tokenmaxxing]] 的"吞吐量最大化"形成对照，代表了 token 经济学中"精简节约"的策略方向。
