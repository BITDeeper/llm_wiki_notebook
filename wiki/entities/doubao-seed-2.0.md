# Doubao-Seed-2.0

[[Doubao-Seed-2.0]] 是字节跳动开发的大语言模型系列。在 [[arkclaw]] 的实测中，该模型被证明在处理复杂智能体任务时表现最为稳定。

## 特点
- **推理规划能力强**：擅长拆解复杂任务并制定执行计划。
- **长程任务处理**：在多步骤、长链路的任务中不易迷失目标，中途跑偏率低。
- **工具调用精准**：在需要调用多个 API 或技能的场景下，指令遵循能力出色，零失误率较高。

## 应用
它是 [[arkclaw]] 平台默认推荐的主力模型之一，特别适合用于构建需要高可靠性的 [[多智能体协作]] 系统，如 [[AI 编辑部]] 中的“总编虾”或“全自动总控”角色。
