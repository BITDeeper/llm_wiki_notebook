# 杨泽乾

杨泽乾是清昴智能的产品负责人，在 AI Agent 领域专注于解决记忆持久化问题。

## 观点与贡献
在量子位主办的“养虾沙龙”上，杨泽乾发表了题为《Session会断，但记忆不能断：OpenClaw记忆管理实战》的演讲。他深入剖析了当前 AI Agent 面临的会话记忆挑战，并实战演示了如何构建持续稳定、永不“失忆”的 AI Agent 工作流。

他认为，虽然对话 Session 可能会中断，但 AI 的记忆能力必须保持连续性，这是 AI Agent 从“玩具”走向实用工具的关键瓶颈。
