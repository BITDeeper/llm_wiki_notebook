# 蚂蚁·安诊儿医疗大模型

蚂蚁·安诊儿医疗大模型（AntAngelMed）是蚂蚁集团联合浙江省卫生健康委开源的大规模医疗语言模型。它是目前参数规模最大的开源医疗模型（100B 总参数），基于 [[混合专家模型]] 架构，在多项权威医疗评测中取得领先成绩。

## 核心特性

### 高效 MoE 架构
AntAngelMed 继承了 [[ling-flash-2.0]] 的高效架构，通过精细设计实现了极致的推理效率：
- **1/32 激活比例**：在 100B 总参数中，每次推理仅激活 6.1B 参数。
- **性能对标**：激活 6.1B 参数即可媲美约 40B 稠密模型的性能。
- **推理速度**：在 H20 硬件上实现超过 200 tokens/s 的推理速度。

### 权威评测登顶
模型在多个权威基准测试中展现了“高效、专业、安全”的能力：
- **[[HealthBench]]**：在 OpenAI 主导的评测中位列开源模型第一，超越 DeepSeek-R1 和 Qwen3。
- **[[MedAIBench]]**：在国家人工智能应用中试基地（医疗）等共建的评测中表现突出。
- **[[MedBench]]**：在中文医疗场景评测中排名第一。

### 训练方法论
模型采用三阶段训练流程，确保了专业性与人文关怀的统一：
1. **持续预训练**：注入大规模、高质量医学语料。
2. **监督微调**：强化通用思维链并适配真实医疗场景。
3. **双阶段强化学习**：利用 [[GRPO]] 算法，先锻造逻辑推理核心，再打磨同理心与安全边界。

### 推理加速优化
技术团队采用 [[FP8 量化]] + [[EAGLE3]] 优化技术，显著提升了推理吞吐量：
- HumanEval 提升 71%
- GSM8K 提升 45%
- Math-500 提升 94%

## 应用场景
AntAngelMed 能够处理复杂的医疗逻辑推理和日常健康科普，例如：
- 解释肝硬化手术中排查肝癌的必要性。
- 科学分析早起喝水对缓解便秘的作用及局限性。

## 开源生态
模型已在 HuggingFace、ModelScope 和 GitHub 平台开源，旨在降低医疗 AI 技术的应用门槛。
