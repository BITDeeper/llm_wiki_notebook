# Tauri

Tauri 是一个用于构建轻量级、安全桌面应用程序的框架。它使用 Rust 作为后端核心，并允许使用 Web 技术（如 HTML、CSS、JavaScript）作为前端界面。

## 在 AIRI 中的应用

[[AIRI]] 使用 Tauri 构建其桌面客户端，利用 Rust 的高性能特性调用 NVIDIA CUDA 和 Apple Metal 等硬件加速接口，从而支持高强度的 AI 推理和图形渲染任务。
