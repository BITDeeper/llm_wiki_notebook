# Rajesh Jhu

微软 Experiences + Devices 集团执行副总裁。2026年5月发布内部备忘录，解释取消内部 [[claude-code]] 授权的决策。

在备忘录中，Jha 表示最初同时提供 Copilot CLI 和 Claude Code 的目标是"快速学习、在真实工程工作流中对这些工具进行基准测试"，而 Claude Code 是学习过程中的重要组成部分。但他强调 Copilot CLI 给了微软"一款可以直接与 GitHub 一起塑造的产品"，能更好适配微软的代码仓库、工作流、安全预期和工程需求。
