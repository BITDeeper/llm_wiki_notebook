# Noah Zweben

Noah Zweben 是 [[anthropic]] 的 [[claude-code]] 产品经理。

## 内部实践
Zweben 是 [[定时任务自动化]]（`/schedule`）功能的积极推广者和实践者。他透露，Anthropic 团队内部已将该功能作为**基础设施**使用。

### 应用案例
- **自动化维护**：利用 `/schedule` 自动修复 CI 报错、推送文档更新。
- **跨语言同步**：配置定时任务，全权负责维护一个活跃 Python 库的 Go 语言孪生版本。

他的实践展示了 Claude 如何从辅助工具转变为 7×24 小时不间断工作的自动化员工，实现了“你睡觉的时候，它在干活”的愿景。
