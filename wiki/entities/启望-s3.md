# 启望 S3

启望 S3 是 [[曦望]] 发布的新一代纯推理 GPU 芯片，旨在通过深度定制架构大幅降低 AI 推理成本。

## 核心目标
- **成本指标**：将百万 [[token-成本]] 压至一分钱（降低 90%）。
- **设计理念**：放弃训练能力，专为大模型推理做原生深度定制，将节省的晶体管与功耗集中用于推理。

## 技术特性

### 计算层深度定制
- **AI Core 架构**：专为推理而生，大幅提升核心算子利用率。
  - GEMM 利用率：约 99%
  - Flash Attention 利用率：约 98%
- **低精度支持**：原生支持从 FP16 到 [[FP4]] 的全链路低精度运算，在模型效果接近无损的情况下，吞吐量翻倍。

### 系统层创新
- **[[LPDDR6]]**：国内首个使用 LPDDR6 的推理 GPU，兼容 LPDDR5X。
  - 显存容量：最大接近 600GB（国内最大）。
  - 作用：解决 Agent 时代 KV Cache 暴增和长上下文记忆的瓶颈。
- **PCIe Gen6**：目前已发布的国产 GPU 中首个支持 PCIe Gen6。
  - 作用：系统通信带宽翻倍，提升数据吞吐速度。

### 软件与生态
- **全栈自研**：硬件 AI Core 和软件全栈 100% 自研，确保底层自主可控。
- **CUDA 兼容**：通过自写底层代码，实现对 CUDA 生态 99%+ 的兼容，降低客户迁移成本。
- **验证体系**：拥有庞大的验证团队和自主开发的仿真验证工具，保证每一代芯片一次性流片成功。
