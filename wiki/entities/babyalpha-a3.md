# BabyAlpha A3

[[蔚蓝科技]]于2026年5月17日发布的最新一代消费级四足机器人，预计2026年Q3正式上市。定位万元级家庭陪伴产品，核心突破在于[[具身智能边缘端异构计算]]架构和[[超人类感知系统]]，标志着消费级四足从"能动"走向"能想"、从"执行工具"走向"智能体"、从"半智能"向"真智能"的代际跃迁。

> ⚠️ 本文参数来源于产品发布宣传稿，缺乏独立第三方验证，以下数据仅供参考。

## 核心规格概览

| 参数 | 规格 |
|------|------|
| 算力提升 | 相比前代1000倍跃迁 |
| 端侧大模型 | 70亿参数，本地运行 |
| 推理速度 | 280 tokens/s（7B模型） |
| 芯片架构 | 六芯片混合异构架构 |
| 感知能力 | 对标甚至部分超越人类 |

## 算力架构

采用自研[[异构计算集群]]"具身智能边缘端混合异构计算集群"：

- 6颗国产芯片组成[[混合异构计算]]集群，总计22核CPU，通过高速总线互联，任务切换延迟毫秒级
  - 2颗5nm芯片：大模型推理 / 感知智能
  - 2颗8nm芯片：感知数据处理 / 机器人系统与自主智能
  - 2颗3D堆叠芯片：运动控制 / 认知智能
- 宣称算力对标英伟达 Jetson AGX Thor T5000（2070 TFLOPS）
- 物料成本约300美元（英伟达Jetson AGX Thor T5000约2999–3000美元）

## 感知系统

### 超能视觉感知系统

- 5000万像素主摄（8K）+ f/2.8超广角（4K）+ 4K全景摄像头，总像素6600万
- 1/1.3英寸大底，360度环视
- HDR 140dB视网膜级感光（超人眼动态范围100–120dB；行业主流HDR 90dB以下）
- 最高帧率480fps（行业主流30fps）

### 空间感知

- 5组3D ToF + 3D结构光构成360°环视面阵
- [[点云密度]]达223.2万点/秒（行业主流3–16线激光雷达仅3–8万点/秒，约50倍差距）
- 厘米级精度3D环境地图

### 听觉系统

- 全球首发12-Mic 3D Mesh仿生立体听觉
- 12个麦克风组成三维声场阵列（3D Mesh拓扑立体阵列），判断方向、距离、空间位置
- 360度声源精确定位（方位角、俯仰角、距离），定位精度±3°（行业主流±15°，精度超5倍）
- 波束成形定向拾音
- 配合超声波雷达环形阵列（宣称全球首次消费级量产应用）

## 运动能力

- 最高速度：3.5 m/s
- 爬坡能力：45°
- 最大越障：28cm

## 自主能力

A3实现了"全自主智能"，无需外部标签或基站：

- 通过360°环视面阵 + 超声波近场避障
- 端侧[[physical-ai|Physical AI]]算法独立完成建图、定位与路径规划
- 主动跟随、障碍躲避、环境适应

区别于行业"伪自主"（依赖UWB标签或指令执行的半自主模式）。

## 安全设计

### 物理安全

- 隐藏式关节、隐藏式线束、防夹手设计
- 悬崖检测、碰撞缓冲
- 独立安全制动系统，故障状态下毫秒级紧急制动

### 系统安全

- 芯片级信任根、安全启动链、SELinux强制访问控制
- 端云双重安全架构：
  - 端侧：360安全大脑（恶意攻击、木马病毒、远程攻击拦截）
  - 云端：等保三级 + 阿里云安全体系 + Azure DDoS防护

### 隐私保护

- 本地可信计算架构，端侧AI驻留
- 全分区加密、全链路通信加密（TLS/SSL）
- 算力在本地，数据不外传

在物理安全、数据隐私和系统安全方面，蔚蓝已将家庭机器人最重要的"安全"环节做到极致——家庭机器人每天看到、听到、反应和存储的内容，决定用户是否愿意长期接受它。

## 行业意义

A3标志着国产[[混合异构计算]]架构对英伟达单芯片路线的正面挑战。70亿参数大模型的端侧推理是[[vla-视觉-语言-动作|VLA]]类模型在消费级设备上运行的关键里程碑。

其核心突破在于：**消费级价格带已经能够承载企业级智能**。A3的发布标志着消费级具身智能的[[消费级飞轮|飞轮]]开始在蔚蓝科技身上转动，是四足机器人从"玩具"走向"智能体"的关键节点。
