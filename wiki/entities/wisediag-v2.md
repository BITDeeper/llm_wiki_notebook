# WiseDiag V2

[[WiseDiag V2]] 是 [[智诊科技]] 发布的全学科医学基座多模态大模型。

## 技术特性
WiseDiag V2 支持千亿级参数，实现了端到端的多模态理解。它摒弃了传统的“先识图转文字、再理解文字”的管道模式，转而采用底层图文同构架构，将视觉特征直接对齐医学知识向量。

## 训练数据
- 训练数据量从 450亿 Token 跃升至 800亿 Token。
- 联合 50 余位三甲医院专家，对 3 万余例真实病历进行了深度拆解，标注了完整的循证推理路径。

## 性能基准
- **MedBench**（中文医疗大模型评测）：得分 69.8，排名第一。
- **MedQA**：得分 93.6，逼近人类执业医师水平。
- **OpenAI HealthBench**：得分 67.2，领先于前沿模型（约 60%）。

## 临床应用
WiseDiag V2 具备 [[多模态医学推理]] 能力，能够同时分析胸部 X 光片、外观照片和血常规化验单。例如，它成功诊断了罕见的 VACTERL 联合征，综合识别了食管闭锁、半椎体发育异常、足部马蹄内翻和吸入性肺炎风险。
