# OpenAI 智能体手机

**OpenAI 智能体手机**（OpenAI Agent Phone）是 OpenAI 正在研发的一款从底层逻辑重新设计的智能手机。该项目旨在将 AI 智能体从应用层下沉至操作系统核心，使其能够直接控制硬件和底层系统，而非仅仅作为 App 运行。

## 核心特征

### 操作系统重构
与在现有 Android 生态上叠加 GUI Agent（如字节跳动豆包手机的方案）不同，OpenAI 主张只有同时控制硬件和操作系统，才能完整交付 Agent 体验，打破现有平台规则（如苹果 App Store 或谷歌 Play 政策）对 AI 能力的限制。

### 硬件规格
- **处理器**：搭载联发科基于 [[天玑9600]] 深度定制的芯片，采用台积电 N2P 工艺。
- **双 NPU 异构架构**：配备两个独立的神经网络处理单元，分别支持视觉理解和语言推理并行运行。
- **端云协同**：日常轻量任务在本地完成，复杂推理任务推送至云端。
- **存储组合**：采用 [[LPDDR6]] 内存与 [[UFS 5.0]] 存储，以缓解 Agent 持续推理带来的数据吞吐瓶颈。
- **安全机制**：集成 pKVM (Protected Kernel Virtualization) 与 inline hashing 技术。

## 项目进展与预测

- **量产时间**：分析师郭明錤预测，量产时间可能从 2028 年提前至 **2027 年上半年**。
- **出货量目标**：预计 2027-2028 年合计出货量约为 **3000 万部**。
- **制造合作**：由 [[立讯精密]] 独家代工。

## 战略意义

OpenAI 认为，手机是唯一能实时捕捉用户全状态的设备，是 Agent 推理最重要的输入来源。通过自研硬件，OpenAI 试图定义下一代移动计算的交互方式，并利用 ChatGPT 的数亿日活用户作为独特的市场切入点。

## 关键人物

- **Jony Ive**：苹果前首席设计官，其被 OpenAI 收购的硬件初创公司 LoveFrom (原文作 io) 参与了该项目的开发。
