# DiffSynth Studio

DiffSynth Studio 是一个开源的扩散模型工具项目，托管于 GitHub（modelscope/DiffSynth-Studio）。该项目承载了 [[diffusion-templates]] 插件框架的完整代码，包括框架运行时和模型训练代码。

## 项目信息

- GitHub 仓库：https://github.com/modelscope/DiffSynth-Studio
- 项目主页：https://modelscope.github.io/diffusion-templates-web/
- 由 [[魔搭社区]] 团队维护

## 功能范围

- [[diffusion-templates]] 框架的完整实现
- Template 模型的训练代码
- 多种可控生成能力的集成与调度
