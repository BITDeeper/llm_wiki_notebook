# DeepSeek Code

DeepSeek Code 是 [[DeepSeek V4|DeepSeek]] 计划推出的 AI 编程产品，目前处于方向成型阶段，尚未面向普通用户开放。

## 产品定位

DeepSeek Code 的核心架构遵循公式 **Model + [[harness|Harness]] = Agent**，即通过给大模型装配可执行、可反馈、可纠错的工作系统（Harness），使其成为能稳定干活的智能体。这一理念与 [[任务执行范式]] 和 [[agentic-engineering]] 形成呼应。

## 确认信号

- **2026年5月15日**：DeepSeek 官网发布 Agent Harness 产品经理岗位
- **2026年5月18日**：发布 Agent Harness 研发工程师岗位
- **2026年5月22日**：资深研究员 Deli Chen 公开发帖招聘"从零开始构建 Code Harness"
- 同期密集释放 Agent 深度学习算法研究员、Agent 数据策略工程师等 10+ 岗位

## 团队

- **Deli Chen**：DeepSeek 资深研究员，公开发帖确认 Code Harness 团队存在
- **[[崔添翼]]**：前 TSY Capital 联合创始人，2026年3月加入 DeepSeek，或将出任 Agent Harness 团队负责人

## 竞品格局

招聘要求中明确列出对标产品：[[claude-code]]、Codex（Cowork）、[[cursor]]、GitHub Copilot、Manus、[[openclaw]]、[[hermes-agent]] 等。文章承认 DeepSeek Code 入局"不算早了"，Claude Code、Codex、Cursor 已先行。

## 社区生态

在官方产品发布前，社区已涌现多个平替工具：
- [[deepseek-tui]]：GitHub 32.9k Stars，定位为"DeepSeek版Claude Code"
- AIMatrices：Rust 编写的 AI 应用构建框架
- 无思微程序：DeepSeek 移动端编程助手
- WindSurf 等主流编辑器已支持集成 DeepSeek 模型

## 融资背景

DeepSeek 融资额已飙升至 700 亿元，管理层向投资者表示优先考虑突破性 AI 研究而非短期商业化。这一表态与密集推出 Code 产品线之间存在叙事张力。
