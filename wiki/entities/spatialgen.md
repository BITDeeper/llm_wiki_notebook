# SpatialGen

[[SpatialGen]] 是 [[群核科技]] 发布的空间生成模型，专注于 3D 世界的生成与重建。

## 核心功能
- **多模态输入**：支持根据文字描述、参考图像和 3D 空间布局生成内容。
- **时空一致性**：能够生成具有时空一致性的多视角图像，构建可漫游的高保真 3D 场景。
- **应用接口**：开发者可通过 API 和 SDK 调用其能力，应用于具身智能训练、影视制作、电商棚拍等场景。

## 技术对比
与 [[李飞飞]] 团队 [[world-labs]] 开发的 [[marble]] 模型类似，SpatialGen 也能从单张照片重建 3D 场景。但两者侧重点有所不同：
- **Marble**：侧重于可视化的虚拟环境生成，深受游戏开发者青睐。
- **SpatialGen**：更侧重于现实世界的重建与模拟，强调结构参数等物理信息的精准与正确，而非单纯的视觉表象。

## 战略定位
SpatialGen 是 [[群核科技]] 四大空间能力（空间重建、空间生成、空间编辑、空间理解）的关键组成部分，旨在将物理世界转化为可计算、可编辑的对象。
