# Token Foundry

Token Foundry是阿里巴巴于2026年6月8日成立的核心AI事业部，由集团CEO[[吴泳铭]]亲自挂帅。该部门由通义大模型事业部与未来生活实验室两大队伍合并而成，架设在三个月前成立的[[ath事业群|ATH事业群]]（Alibaba Token Hub）枢纽内。

## 组织构成

- **通义大模型事业部**：由[[周靖人]]从零搭建，核心产品为[[qwen-3-7-max|Qwen 3.7 Max]]大模型
- **未来生活实验室**：由[[郑波]]带队并入，核心产品为[[happy-horse|Happy Horse]]视频生成模型和[[happy-oyster|Happy Oyster]]实时世界引擎

## 战略定位

Token Foundry的命名体现了阿里的核心战略——将自身定位为AI时代Token的"铸造厂"。在阿里的全栈Token战略中，Token Foundry承担模型层的铸造职能：

- **[[平头哥]]**：造芯片（算力底座）
- **Token Foundry**：造模型（Token铸造）
- **[[百炼MaaS]]**：做分发（Token分发）

## 产品矩阵

- [[qwen-3-7-max|Qwen 3.7 Max]]：覆盖文本和代码，天生为Agent设计，支持1M token超长上下文
- [[happy-horse|Happy Horse]]：覆盖视频生成，2026年4月登顶全球视频生成榜
- [[happy-oyster|Happy Oyster]]：覆盖[[世界模型]]，定位"实时世界引擎"

## 与阿里AI体系的关系

Token Foundry与Wiki中已收录的[[阿里rtp团队]]（搜索推荐广告技术）、[[rtp-llm]]（推理引擎）、[[qoderwork]]（AI Native办公平台）共同构成阿里AI版图。其中RTP团队和QoderWork更偏向应用层，Token Foundry则定位为模型层的核心铸造组织。
