# Dojo 3

Dojo 3 是 [[特斯拉]] 重启的新一代超级计算机项目，旨在通过自研芯片打破对 [[英伟达]] GPU 的依赖。该项目曾一度被搁置，后随 [[tesla-ai5]] 研发的完成而重启。

## 项目历程
- **暂停**：2024 年 8 月，因资源需集中于 AI5 研发，Dojo 项目被无限期搁置，团队解散。
- **重启**：2026 年 1 月，马斯克宣布 AI5 状态良好，将重启 Dojo 3 的工作。

## 战略转型与架构统一
Dojo 3 的诞生源于对 Dojo 2 路线的否定。原本的 Dojo 2 计划采用独立的 D 系训练芯片架构，但这导致了车端（推理）与云端（训练）架构的分裂，分散了研发精力。

Dojo 3 彻底放弃了独立架构，转而直接使用下一代车载推理芯片 [[ai5]] 及后续芯片（如 [[tesla-ai6]]）来搭建计算集群，实现了 [[统一架构]]。其技术愿景包括：
- **统一指令集**：训练和推理使用同一套指令。
- **统一软件栈**：简化开发流程，提升效率。
- **晶圆级架构**：继承 Dojo 独特的晶圆级设计，以减少通信延迟。

## 目标与挑战
- **目标**：成为特斯拉摆脱 GPU 依赖的“大杀器”，支撑 FSD 和 Optimimus 的大规模训练。通过 Dojo 3 和 AI6 的融合，特斯拉旨在实现从芯片设计、整车制造、机器人开发到云端训练的完全垂直整合，构建独特的硬件护城河。
- **挑战**：统一架构带来了节奏冲突。[[ai5]] 首先是一颗车规级芯片，必须满足 ISO 26262 等严苛的安全标准，这与数据中心芯片追求的快速迭代存在矛盾。特斯拉计划通过“基于平台的增量演进”来解决这一问题。

## 关联设施
目前，特斯拉已上线 [[colossus-2]]（1GW 超算），该设施仍大量使用英伟达 GB200/GB300，作为向 Dojo 3 过渡的算力桥梁。
