# M-Flow

**M-Flow** 是由 [[心流元素]] 团队开发的开源 AI Agent 记忆引擎。它被定义为一种基于“联想”而非“搜索”的新型记忆系统（即第三代记忆模式），旨在解决现有 Graph RAG 方案中信息颗粒度隔离、检索效率低下以及多跳推理困难的问题。

## 核心特性

M-Flow 通过自研的 [[图路由bundle-search]] 架构，摒弃了传统的平坦向量检索，利用知识图谱的拓扑结构进行路径代价评估。其主要特性包括：

- **联想优先**：不同于传统的向量检索或浅层图谱，M-Flow 试图模拟人类的联想记忆过程，通过线索激活上下文，重建情景并获得新理解。
- **倒锥结构**：采用 Entity -> FacetPoint -> Dimension -> Episode 的四层有向图设计（即 [[cone-graph]] 分层结构），实现多粒度信息的精准匹配。
- **边携带语义**：图中的边不仅表示连接，还附带可被向量化的语义描述，作为主动过滤器参与检索评分。
- **指代消解**：业内首个支持此功能的记忆引擎，能区分文本中代词（如“他”、“它”）的具体指代，提升理解深度。
- **毫秒级响应**：检索过程不依赖 LLM，保证了极低的延迟。

## 性能表现

M-Flow 在多项行业通用 Benchmark 中表现卓越，显著领先于现有主流方案（如 [[mem0]]、[[zep]]、[[graphiti]]、[[cognee]]）：

- **[[lcomo]]**：排名第一，领先 mem0 36%。
- **[[longmemeval]]**：排名第一，领先 graphiti 16%。
- **[[evolvingevents]]**：排名第一，领先 cognee 7%，领先 Graphiti 20%。

## 技术理念

M-Flow 认为，真正的 Agent 记忆不应只是更准的“搜索引擎”，而应具备人类般的“联想”能力。现有的 RAG 方案本质上仍是“形态匹配”的搜索引擎，而非具备理解能力的“记忆系统”。M-Flow 通过重构底层知识组织结构，试图让 AI 实现从“找相似文本”到“联想与推理”的跨越。这种能力使得 Agent 不仅能回答“你问的那句话出现在哪条历史记录里”，还能从随口的一句话中拼出整个上下文，甚至揭示用户尚未察觉的潜在关联。

## 开源与部署

M-Flow 保持开源，支持 Docker 一键部署，降低了使用门槛。项目在 GitHub 上开源后迅速获得关注，在 X (Twitter)、Reddit 和 HackerNews 等海外开发者社区引发了热烈讨论。
