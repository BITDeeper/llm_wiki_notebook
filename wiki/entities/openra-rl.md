# OpenRA-RL

OpenRA-RL 是一个基于经典 RTS 游戏《红色警戒》改造的开源 AI Agent 训练框架，由 Hugging Face 社区发布。它旨在为大语言模型（LLM）和强化学习算法提供一个具有真实策略深度、实时交互复杂度和可复现性的测试环境。

## 核心特性

### 异步交互架构
为了解决 LLM 推理延迟（秒级）与游戏引擎实时性（25Hz，毫秒级）的冲突，OpenRA-RL 采用了“三明治”分层架构：
1.  **底层**：魔改的 OpenRA 游戏引擎（C#），负责维持游戏心跳。
2.  **中间层**：gRPC 桥接层，负责推送观测数据、接收指令。
3.  **上层**：Python 封装，提供 Gymnasium 风格接口及 MCP 服务器。

这种架构允许 Agent 的“计算”与游戏的“执行”完全解耦。Agent 可以通过 `advance` 指令让游戏快进，从而在思考时不影响游戏进程。实测中，`advance` 指令占用了约 57% 的工具调用。

### 高并发优化
通过在 v2 版本中引入 ModData 共享机制（单位属性、地图规则等初始化后不可变数据），实现了单进程承载 64 个游戏会话。
-   **内存优化**：64 局并发内存占用从 ~40GB 降至 ~6GB。
-   **速度优化**：重置延迟从 5-15 秒降至 256ms（提升约 40 倍）。
-   **编译优化**：JIT 编译次数从 64 次降为 1 次。

### 8 维奖励向量
不同于传统的胜负二元评价，OpenRA-RL 提供了细粒度的反馈机制，涵盖经济、基建、战斗、骚扰等 8 个维度。这使得研究者可以精确定位 Agent 的短板（例如：经济满分但战斗零分），从而设计针对性的课程学习策略。

## 实战测试结果
在基于 [[qwen3-32b]] 模型的测试中，Agent 展现了典型的“言语巨人，行动矮子”特征：
-   **规划能力**：能在第 2 回合写出“attack AI base”的策略。
-   **执行能力**：在整个游戏过程中从未生产进攻部队，战斗得分为 0。
-   **学习能力**：通过 [[提示注入式学习]]，成功修正了建造顺序错误（如先造发电厂），但无法习得进攻行为。

## 生态兼容性
-   **OpenEnv**：原生接入，支持 TRL、torchforge、Unsloth 等训练框架。
-   **MCP 协议**：暴露 50 个游戏工具，任何兼容 MCP 的客户端均可接入。
