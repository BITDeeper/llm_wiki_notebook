# Google Chrome

Google Chrome 是由谷歌开发的网页浏览器。在 AI Agent 时代，Chrome 正在从单纯的浏览工具演变为智能体的运行环境。

## 与 Agent 的集成
在 Chrome 146 的早期预览版中，Chrome 引入了 [[webmcp]]（Web 模型上下文协议）。通过 `navigator.modelContext` API，Chrome 允许 AI 智能体绕过传统的图形界面，直接与网页内核进行结构化交互。

这一举措标志着浏览器正在成为 AI 的“一等公民”运行环境，使得 Agent 能够更高效、稳定地操作 Web 服务，而无需依赖脆弱的屏幕抓取技术。
