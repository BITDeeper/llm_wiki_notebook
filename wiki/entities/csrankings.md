# CSRankings

**CSRankings** (Computer Science Rankings) 是目前全球最受认可的计算机科学院校排名体系之一，由[[麻省州立大学阿姆赫斯特分校]]的[[Emery Berger]]教授创建和维护。

## 核心特点
- **极度透明**：完全基于客观研究产出，无问卷调查或声誉打分。
- **硬核指标**：仅统计全球各大高校在计算机领域顶级会议上的论文发表数量。
- **可验证性**：所有数据公开，可在 GitHub 上查源码。

## 排名机制
### 人员收录标准
- 必须是全职且终身教职。
- 必须能独立指导计算机科学专业的博士生。
- 兼职/附属教授若满足带博士条件也会被统计。

### 1/N 归一化计分
为了防止大团队通过增加作者数量刷分，CSRankings 采用独特的分数分配规则：
- 每篇论文给每位作者 **1/N** 分（N为总作者数）。
- 分数永久固定，不随作者身份变化（如学生变教授）而调整。
- 限制：若一篇论文所有作者都是教职员，该论文最多只能为机构贡献 1.0 分。

## 学科分类
CSRankings 将计算机科学分为四大板块：
1. **人工智能 (AI)**：包括 CV、ML、NLP 等。
2. **系统类**：包括操作系统、网络、数据库等。
3. **理论类**：包括算法、复杂性、密码学等。
4. **跨学科领域**：包括生物信息学、计算机经济学等。

## 争议与局限
- **唯论文论**：仅看数量，不评估论文质量、影响力或引用率。
- **会议偏好**：侧重会议论文，可能对重视期刊的传统强校（如部分欧洲高校）不利。
- **学科偏差**：AI 领域因顶会多、产出大，在排名中权重较高。

## 2026年排名亮点
在2026年的排名中，中国高校表现极其强势，[[上海交通大学]]与[[清华大学]]并列全球综合第一，[[北京大学]]在AI领域排名第一。
