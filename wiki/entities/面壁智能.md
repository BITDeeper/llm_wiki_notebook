# 面壁智能

[[面壁智能]]（ModelBest）是中国领先的人工智能大模型初创公司，专注于大模型研发与开源生态建设。公司是 [[OpenBMB]] 生态的构建者，与 [[清华大学]] 及 [[OpenBMB]] 开源社区保持着紧密的产学研合作关系。面壁智能以提出[[密度定律]]（Densing Law）并坚持“[[高知识密度]]”的研发路线而闻名，致力于推动大模型的高效落地与开源生态建设。

## 核心理念：高知识密度与密度定律

面壁智能主张在AI发展的后Scaling Law时代，单纯堆砌参数和算力的边际效益递减，真正的竞争力来自于提升模型的“智能密度”（即单位参数的智能水平）。这一理念强调通过优化模型架构和训练效率，在资源受限的端侧设备上实现媲美大模型的性能。

这一理念的核心理论支撑是**密度定律**。2024年底，面壁智能与清华大学孙茂松、刘知远教授团队合作，发表了关于大模型“密度定律”的论文，并被 *Nature Machine Intelligence* 接收。该理论预言了达到特定智能水平所需的参数量每3.5个月下降一半。这一预言在2026年4月被[[Meta]]和[[METR]]独立验证，标志着中国AI研究者在理论范式上的领先。

## 战略方向：端云两栖

除了基础模型研发，面壁智能在 Agent 基础设施与端云协同架构方面亦有深入布局。公司主张「端云两栖」的第三条道路，试图打破纯云端 API 派（数据泄露风险）与纯本地模型派（能力瓶颈）的二元对立。

-   **[[EdgeClaw]] 框架**：一种支持「端云两栖」的智能体框架，通过 [[隐私路由]] 技术实现数据分级处理。在该框架中，[[MiniCPM]] 充当「本地引擎」，负责处理绝密数据和高频基础任务，而云端则处理复杂推理。
-   **[[ClawXRouter]]**：作为联合研发方，面壁智能推出了智能调度员技术，进一步优化端云协同的效率与成本。
-   **EdgeClaw Box**：基于 EdgeClaw 框架的软硬一体机，面向 OPC（一人公司）群体，提供开箱即用的数字员工解决方案。

## 主要产品与开源贡献

### MiniCPM 系列
面壁智能通过[[MiniCPM]]系列模型实践其“密度优先”的方法论。该系列模型被称为“小钢炮”，主打端侧高性能推理，以小参数量实现高性能著称，被广泛应用于手机、电脑及智能硬件中。
-   **MiniCPM-1.2B**：2024年2月发布，以2.4B参数打平或超越Mistral-7B（7B参数），成为密度定律的首个实证案例。
-   **开源生态**：覆盖了10B以下参数的文本、多模态、语音、全模态四大方向，全球开源下载量已突破2400万次。

### VoxCPM 系列
-   **[[VoxCPM 2]]**：2026年4月开源的2B语音多模态模型，基于 MiniCPM 基座构建。该模型仅用2B参数就实现了超越百亿级参数模型的语音合成效果，支持多语言、多方言及高保真音色克隆。该模型以其卓越的情感控制、方言支持和[[音色设计]]能力引发广泛关注，支持端侧部署。
-   **技术路线**：采用[[扩散自回归连续表征]]，保留了完整的声学细节。

### OpenBMB 社区
面壁智能联合开源社区 [[OpenBMB]]，推动模型权重的开源与工具链的完善。通过提供 ComfyUI、WebUI 等全套工具，降低开发者使用门槛，构建活跃的开源生态。

## 合作伙伴
-   [[清华大学]]：包括孙茂松、刘知远教授团队（[[清华大学-THUNLP]]）及[[清华大学人机语音交互实验室]]，在基础理论研究（如密度定律）和具体项目（如 VoxCPM 2）中提供学术支持。

## 行业地位与影响
面壁智能是国内少数在基础模型理论层面做出全球级贡献的AI公司之一。其提出的密度定律不仅被Nature子刊收录，更获得了硅谷顶级机构（如Meta）的实测验证。同时，其开源策略（如免费提供商用级模型）直接冲击了闭源 SaaS 订阅市场，为内容创作和跨境电商领域提供了低成本的生产力工具。
