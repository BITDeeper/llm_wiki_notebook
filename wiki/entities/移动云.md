# 移动云

**移动云**（Mobile Cloud）是中国移动旗下的云服务平台，也是其 AI 战略的重要承载底座。它不仅提供传统的云计算资源，更是 [[中国移动]] 构建 [[token-运营体系]] 和实施“通算智融合”战略的核心基础设施。

## 核心功能
移动云承载了 [[中国移动]] 的算力网络和智能网络，支持从百卡到超万卡的全规格算力覆盖。它通过遍布全国的边缘节点和毫秒级全光高速直连网络，为 AI 服务的低延迟调度提供物理保障。

## 关键组件：MoMA 模型服务平台
移动云已升级其模型服务平台 **MoMA**（Model as an Assistant），该平台是 [[token-运营体系]] 的“能力底座层”。
- **模型接入**：接入了 MiniMax、豆包、GLM 等 200 多款主流模型。
- **统一调度**：通过统一 API 调用实现多模型协同调度。
- **服务分级**：提供“普惠、精品、机密”三档 Token 服务，以满足不同场景的需求。

## 战略角色
在 [[中国移动]] 的“汇聚、筑基、激活、共赢”四大行动中，移动云负责“Token 汇聚”，即打造“AI 算力超市”。它通过“自建+合作+联营”的模式，构建了一个多元异构的算力生态，确保 Token 的高质量供给。
