# MOSS

MOSS 具有双重含义：一方面是由[[复旦大学]][[邱锡鹏]]教授团队主持研发的系列开源大模型，另一方面是 2026 年 5 月发布的实现 Agent [[源码级自我改写]]能力的研究项目（arxiv 2605.22794）。两者均与复旦大学自然语言处理实验室相关。

## 开源大模型系列

MOSS 是由复旦大学和[[模思智能]]联合推动的系列开源大模型，覆盖语言和多模态能力，是中国学术界最具影响力的开源大模型项目之一，也是国内最早发布的开源大模型之一。其首个类 ChatGPT 对话式大模型于 2023 年 2 月发布，是国内最早发布的对话式大模型之一。[[模思智能]]负责 MOSS 的商业化推进。

### 历史意义

MOSS 的发布打响了中国"百模大战"的第一枪，标志着国内学术界在大模型对话系统领域的突破。MOSS 系列模型是中国学术界推动大模型开源的代表性成果，为国内大模型生态的发展提供了重要的技术基础设施。

### 技术特点

MOSS 系列模型定位为高影响力开源大模型，支持多轮对话、工具调用等能力，是国内开源大模型生态的重要组成部分。

### 模型体系

MOSS 不仅是单一模型，更演化为一个系列体系，包括：

- **[[speechgpt]]**：端到端语音大模型。
- **MOSS-TTSD**：基于百万小时音频训练的开源中英双语对话语音模型。
- **MOSS-Audio**：被评价为"突破语音交互恐怖谷效应"的语音模型。

MOSS 系列模型的技术积累直接催生了[[模思智能]]及其后续的[[anygpt]]和[[nex]]体系。

## Agent 自进化研究（2026）

2026 年 5 月，以 MOSS 为名发布的研究项目（论文地址：https://arxiv.org/abs/2605.22794）实现了 Agent 的[[源码级自我改写]]能力。

### 核心成果

- Agent 不只改 prompt 或 workflow 配置，而是直接改写自身源代码
- 在[[openclaw]]平台上运行
- 无人干预的进化周期内，四个任务的平均评分从 0.25 升至 0.61

### 意义

MOSS 将 Agent 自我改进推到了更极端的位置。与 TAX-AI 的 eval 驱动改进不同，MOSS 展示的是 Agent 对自身代码库的直接修改能力，是[[递归式自我改进]]的学术前沿验证。

## 研发团队

MOSS 由复旦大学自然语言处理实验室主导研发，邱锡鹏教授担任主持。邱锡鹏同时担任中国人工智能学会自然语言理解专委会副主任、中国中文信息学会大模型与生成专委会副主任。

## 最新进展
