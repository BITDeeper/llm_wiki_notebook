# GLM-5-Turbo

**GLM-5-Turbo** 是由 [[智谱AI]] 发布的大语言模型版本，前身为内测代号 Pony-Alpha-2。该模型常被称为“龙虾特供”模型，专门针对 [[Agentic Engineering]] 场景进行了深度优化，强调在长路径任务、工具调用和多智能体协同中的稳定性。

## 核心特性

### 长路径任务稳定性
GLM-5-Turbo 的主要卖点是解决智能体在执行复杂任务时容易“中途掉链子”或产生累积误差的问题。实测表明，该模型在包含多个步骤、耗时较长或需要多次工具调用的任务中，能保持逻辑连贯和执行成功率。

### 环境感知与自适应
模型具备检测运行环境并据此调整策略的能力。例如，在全栈开发任务中，当检测到本地未安装 Node.js 时，它能自主切换到 Python 技术栈完成开发，而非报错终止。

### 多智能体协同
模型深度优化了工具调用与多智能体协同能力，能够将复杂需求拆解为详细步骤，并指挥多个子任务（Agent）分工合作。

## 性能表现

在智谱AI组织的“龙虾测试” [[ZClawBench]] 评测基准中，GLM-5-Turbo 获得了国产模型综合成绩第一，并展现出了优于 GLM-5 的实战能力。

其优势场景主要集中在：
- **办公场景任务处理**
- **信息搜索与筛选**
- **自动化检测与操作**

这一数据表明，在 Agent 应用落地时，并非参数规模越大越好，针对特定任务优化的模型（如 Turbo 版本）往往能提供更高效的推理和执行能力。

## 应用场景

- **全栈开发**：一人包揽前后端代码编写、数据库对接及测试。
- **内容策划**：生成长周期的系列文案及配套素材。
- **本地数据操作**：接管本地文件系统，进行数据清洗与分析。

## 获取方式

- 通过 [[AutoClaw]]（澳龙）应用直接调用。
- 通过智谱开放平台 BigModel.cn 调用 API。
- 包含在 GLM Coding Plan 的 Max 版本中。
