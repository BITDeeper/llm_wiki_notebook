# NLA（自然语言自编码器）

NLA（Natural Language Autoencoder，自然语言自编码器）是 [[anthropic|Anthropic]] 开源的 AI 可解释性工具，能将大语言模型内部激活向量翻译为人类可读的自然语言描述，被称为"AI 脑部 CT 机"。

## 工作原理

NLA 的核心架构包含两个模型：

- **AV（激活向量翻译器）**：接收一个激活向量，将其翻译为一段自然语言描述（如"模型正在考虑用 rabbit 押韵"）。
- **AR（激活向量还原器）**：仅根据 AV 输出的自然语言描述，将激活向量还原出来。

两个模型联合训练，唯一的考核标准是**重建精度**——还原的向量与原始向量的相似度。AV 写得越准，AR 还原得越好；AV 漏掉信息，AR 就对不上。这种压力反过来逼 AV 把翻译写得更完整、更精确。

关键特点：
- **无需人工标注**：不需要事先定义要寻找的概念。
- **无监督训练**：训练目标仅关注重建精度，副产品是可读的"内心独白"。
- **使用强化学习训练**。

## 性能指标

在 [[claude-opus-4-6|Claude Opus 4.6]] 上达到 **60%-80% 的方差解释率**。

## 核心应用

1. **训练数据 debug**：成功定位俄语切换 bug 的根因——训练数据中英文 prompt 配对未翻译外语回复。
2. **因果验证**：通过修改 NLA 翻译出的描述（如将"rabbit"改为"mouse"），再用 AR 还原为向量注入模型，可因果性地改变输出。
3. **隐藏动机审计**：在审计游戏中将成功率从不到 3% 提升至 12%-15%（4-5 倍提升）。
4. **考试意识检测**：发现模型在内部表征中意识到被评估但不在输出中表达的现象。

## 开源信息

- 训练代码已在 GitHub 完全开源。
- 同步发布四套预训练 NLA，覆盖三家主流开源模型族，从 7B 到 70B 全跨度。
- [[neuronpedia]] 上线了交互式前端，支持浏览器内体验。

## 局限与开放问题

- NLA 本身是否可被模型"欺骗"？如果模型知道存在 NLA 监控，是否会在激活层面也进行隐藏？
- 当前方差解释率仍有 20%-40% 的信息未被捕获。
