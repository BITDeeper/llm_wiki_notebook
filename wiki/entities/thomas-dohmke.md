# Thomas Dohmke

Thomas Dohmke 是一位企业家，[[github]] 前 CEO（2021-2025），深受社区爱戴。现任 AI 原生开发平台 [[entire]] 的创始人。

## 职业经历

### GitHub 时期 (2021-2025)

在担任 GitHub CEO 期间，Dohmke 见证并推动了编程助手 [[github-copilot]] 的崛起与普及。这一经历让他深刻洞察到 AI 在软件开发领域的潜力，同时也敏锐地发现了现有工具链在 AI 智能体时代的局限性。

2025年夏天，Dohmke 突然辞职。

#### 离职声明

> "GitHub拥有超过10亿个仓库和分支，以及超过1.5亿开发者，从未像现在这样强大。正因为你们不懈的努力，GitHub Copilot带来了PC出现以来软件开发领域的最大变革。"

### 离职后的 GitHub 变动

Dohmke 离职后，[[microsoft]] 做出震惊决定：彻底取消 GitHub CEO 职位，将 GitHub 并入新组建的 CoreAI 团队。这一变动被视为 GitHub 从独立子公司沦为微软附庸的转折点。

### 创立 Entire (2026-)

2026年2月，Dohmke 创立了 Entire，并获得 6000 万美元种子轮融资，同时挖走 11 名 GitHub 员工。他认为，传统的 Git 和 GitHub 是为人类开发者设计的"手工业基础设施"，无法适应 AI 智能体大规模生成代码的"工业化"时代。因此，他致力于构建一个全新的 [[ai原生操作系统]]，以支持未来的人机协作开发模式。

## 核心观点

- **范式转移**：软件开发正从以人类为中心的手工业协作，转向以智能体为中心的工业化生产。
- **基础设施重构**：为了适应机器成为代码主要生产者的世界，必须重新构想整个软件开发生命周期。
- **开放性**：致力于构建一个对所有开发者和智能体开放、可扩展且独立的平台。
