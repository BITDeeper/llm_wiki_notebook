# Vibe Coding

[[vibe-coding]] 是 [[coze]] 平台的底层技术基石，也是其“元能力”的核心来源。它支撑了 Coze 从代码生成到智能体构建的全过程。

## 功能与演进
Vibe Coding 最初是 Coze 用于代码生成的技术，使得用户可以通过自然语言描述需求，机器就能生成可用的代码。随着平台的发展，它演变为支撑 [[vibe-agent]] 和 [[coze-skills]] 的基础架构。

## 关联技术
- **[[vibe-agent]]**：基于 Vibe Coding 积累发展出的智能体能力，负责理解复杂任务并生成相应的技能。
- **[[vibe-infra]]**：与 Vibe Coding 配套的基础设施服务，覆盖了从开发到部署的完整软件生命周期。

## 意义
Vibe Coding 代表了 AI 编程的一种演进方向：不仅关注代码的生成，更关注代码背后的逻辑封装与实际交付能力。
