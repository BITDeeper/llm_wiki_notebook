# 百度秒哒

百度旗下无代码应用搭建平台，核心理念为"人人都是创造者"。定位为"一句话做应用"的产品——用户只需通过自然语言描述想法，即可直接生成网页、小程序、APP、小游戏、PPT等多种形态的应用。当门槛被AI抹平，想象力就是新的生产力。

## 产品定位

秒哒是 [[vibe-coding|Vibe Coding]] 在国内的重要实践者，朱广翔称其为"国内最早做 Vibe Coding 的团队"。产品于2024年下半年首次发布（早于 DeepSeek 2025年春节发布），2026年5月推出企业版，成为国内无代码应用搭建产品中首个支持多人协作的平台。

在[[第四届中国aigc产业峰会]]上，朱广翔分享了秒哒的产品理念与实践。

## 核心人物

- **朱广翔** — 产品总经理，博士毕业于清华大学交叉信息研究院，曾获中国智能体与多智能体系统最佳论文、北京市优秀博士学位论文等荣誉，在NeurIPS、ICLR、ICML等国际顶会发表论文14篇

## 技术架构

秒哒的底层逻辑是 [[多agent协作架构|多智能体协作开发]]：将传统软件开发中的产品经理、设计师、工程师、测试、运维、运营等角色全部替换为 AI Agent，用户扮演"老板"角色发起命令，多 Agent 合作完成需求分析、UI设计、技术选型、编码、测试、部署、分发等全流程。

## 关键数据

- **用户构成**：87% 完全不懂代码；16% 为 [[opc-一人公司|OPC（一人公司）]]（第一大群体）；9.7% 为产品经理
- **服务规模**：生成应用累计服务超过2000万用户
- **等价价值**：按人力开发成本换算，价值"几十个亿"
- **评测成绩**：IDC 测评中文环境排名第一，全球环境位于第一梯队；获沙利文、环球时报等奖项

## 企业版

2026年5月首发企业版，核心特性包括：
- 多人协作（类似 GitHub 的版本管理与 Merge）
- 企业级 SLA（高稳定性、高可用）

## 典型案例

- **8岁儿童**：小学二年级学生用秒哒做出专属儿童操作系统，含模拟安装过程和AI宠物
- **OPC创业者"黄啊码"**：开发AI漫剧平台赚12万、企业站点赚3万，培训3000学员
- **上海企业**：4位项目经理替代12人研发团队，交付周期从"年"缩短至"月"，盈利50万并拿下1000万订单
- **[[软通动力]]**：用秒哒重构交付范式，支撑20个项目，交付成本降低70%
- **[[自如]]**：设计师搭建房屋设计工具，让业主实时看到"想象中的家"
- **石油工程师**：做出油井设计平台，替代140万采购系统，在大庆、青海、长庆油田投产
- **文科生用户**：两句话10分钟做出DAU 200万的测评应用

## 竞品对标

全球对标对象为 Lovable（全球Top1无代码开发平台），秒哒用户常称其为"中国的 Lovable"。Lovable 一家公司生成的AI应用占全球新增应用的10%。
