# CrowdStrike

**CrowdStrike** 是一家美国的网络安全技术公司，也是该行业的龙头企业之一。在 [[Anthropic]] 发布 [[claude-code-security]] 后，CrowdStrike 成为受冲击最大的典型代表。

## 市场事件
2026年2月21日，受 Claude Code Security 发布的影响，CrowdStrike 股价暴跌 **6.5%**。这一暴跌反映了市场对 AI 技术颠覆传统网络安全服务的恐慌。投资者担心 AI 能够以更低的成本完成大部分漏洞扫描和修复工作，从而削弱 CrowdStrike 等传统厂商的定价权和市场份额。

## 行业地位
作为网络安全领域的领军企业，CrowdStrike 的股价波动往往被视为行业风向标。此次暴跌带动了 [[Cloudflare]]、[[Okta]]、[[Zscaler]] 等其他安全股的集体下挫，导致整个板块单日市值蒸发超过 100 亿美元。
