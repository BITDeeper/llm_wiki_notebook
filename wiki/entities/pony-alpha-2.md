# Pony-Alpha-2

[[Pony-Alpha-2]] 是 [[智谱]] 发布的专为 [[agent场景化模型]]（特别是 [[openclaw]] 场景）打造的大语言模型。它是此前在 OpenRouter 上引起关注的匿名模型“Pony Alpha”的进化版，其命名渊源延续了 GLM-5 发布前测试版本的名字。

## 核心特点

与擅长对话的通用大模型不同，Pony-Alpha-2 针对智能体的核心需求进行了深度优化，重点解决了通用模型在执行复杂 Agent 任务时容易“掉链子”（中途崩溃或产生幻觉）的问题。

### 长链路任务执行
- **连续规划**：能够处理包含多个步骤的复杂任务。
- **多步执行**：在需要反复调用工具的场景下保持稳定性，确保多步骤任务中的连贯性和可靠性。
- **一次通过率**：在论文综述、日程管理、文档生成等演示场景中，表现出极高的一次执行成功率。

## 应用与发布

### 独家首发
Pony-Alpha-2 目前处于内测阶段，[[autoclaw]]（澳龙）是其唯一的体验入口。该模型被预置在 [[autoclaw]] 应用中，作为其默认的核心推理引擎。这一策略旨在通过具体的 Agent 应用场景收集反馈，进一步优化模型在工具调用和任务规划方面的表现。
