# 王云鹤

王云鹤（1991年出生）是人工智能领域的青年技术领袖，被称为"90后少帅"。他是 [[基元律动]] 创始人兼CEO，同时也是 [[opensquilla|OpenSquilla]] 幕后创始人。前 [[华为诺亚方舟实验室]] 主任（2025-2026）及 [[盘古大模型]] 核心负责人。他于 2026 年 3 月离职，投身 [[Agent]] 领域创业。

## 教育背景

- **本科**：毕业于西安电子科技大学数学与应用数学专业。
- **博士**：毕业于北京大学智能科学系，2018年获博士学位，师从许超、陶大程教授，主攻深度学习、模型压缩与计算机视觉。

## 职业生涯

### 华为时期 (2017-2026)

王云鹤在北大攻读博士期间即进入 [[华为诺亚方舟实验室]] 实习，为华为北京部门首位实习生。2018 年正式入职后，他在华为内部晋升迅速，8 年内从实习生升至实验室主任：

- **2017年**：以实习生身份加入华为。
- **2018 年**：正式入职，任高级工程师。
- **2020 年**：任技术专家。
- **2021 年底**：升任算法应用部部长。
- **2025 年 3 月**：接替 [[姚骏]]，出任诺亚方舟实验室主任，年仅 33 岁便执掌华为 AI 研究重镇，正式接棒盘古大模型，成为万亿参数模型的掌舵人，全面负责 [[盘古大模型]] 的研发工作。
- **2026 年 3 月 28 日**：在朋友圈发布告别词，官宣离职，结束仅一年的主任任期。

### 创业时期 (2026-)

2026 年，王云鹤创立 [[基元律动]]，投身 AI Agent 赛道，新公司估值据媒体报道达1亿美元。团队身份最初保密，其 [[opensquilla|OpenSquilla]] 项目在 GitHub 上迅速走红后被 [[量子位]] 通过多方打听曝光其创业动态。截至2026年6月，团队正处于大力招兵买马阶段，希望专注打磨产品。

这一举动被视为行业顶尖人才对 [[任务执行范式]] 转向的实质性投票，也被广泛解读为 AI 行业从"大模型军备竞赛"向"智能体应用落地"转移的风向标。

## 核心技术贡献

王云鹤的研究主线聚焦于**高效 AI**，即在有限算力下提升模型性能。其 Google Scholar h-index 高达 68，发表 CCF-A 类学术论文 70 余篇，涵盖 NeurIPS、ICML、CVPR、ICCV 等顶级会议，并曾担任 NeurIPS 和 ICML 的领域主席。

### 1. 模型压缩与端侧 AI

- **[[GhostNet]]**（2019/2020年）：与 [[韩凯]]、田奇等人合著的论文《GhostNet: More features from cheap operations》是其被引数最高的工作（CVPR 2020）。该研究通过"廉价操作"生成"幽灵"特征图，有效解决了在资源受限的嵌入式设备上部署卷积神经网络的难题，在同等精度下速度和计算量均优于当时的 SOTA 算法，谷歌学术引用量极高。
- **[[AdderNet]]**：加法神经网络（CVPR 2020）。创新性地在深度学习中以加法运算替代高能耗的乘法运算，理论上可显著降低 AI 芯片的运算功耗。该成果获选华为第四届"十大发明"。

### 2. 基础科学应用

- **中国天眼（FAST）项目**：带领团队开发高效 AI 算法，应用于 FAST 射电望远镜的观测数据中，协助中科院国家天文台专家发现了数百个新的快速射电暴（FRB）样本。这是 AI 算法在天文基础科学领域的成功跨界应用。

### 3. 大模型架构

- **[[盘古-π-架构]]**：2023 年底作为第一作者提出的新型网络架构。旨在解决 Transformer 架构在深层网络中出现的 [[特征塌陷]] 问题，通过新的激活机制与结构设计提升大模型的非线性能力。
- **[[盘古-5.5]]**：任内主导发布的华为大模型系列，包含 718B 参数的 [[Pangu Ultra]]（MoE 架构）。该系列强调长序列处理、低幻觉生成及 Agent 能力，重点面向企业级实用性。

### 4. 图像处理与 GNN

- **Image Processing GNN**：与许超教授团队合作，该论文获得了 CVPR 2024 最佳学生论文奖提名。论文提出了一种嵌入图神经网络的超分成像算法，在实验中达到了当时的 SOTA（State-of-the-Art）水平。

### 5. AI Agent

- **[[dllm-agent]]**（2026年初）：团队发表《DLLM Agent: See Farther, Run Faster》论文，提出基于扩散模型的智能体，声称比传统自回归模型"看得更远，跑得更快"。

## 技术基因

王云鹤的技术路线具有鲜明的"模型效率"特征。当行业普遍追求模型规模扩张时，他始终关注如何在算力受限条件下实现高性能。这种对算力和模型效率的极致把控，既体现在 GhostNet 的轻量化设计中，也成为他掌舵盘古万亿参数大模型的关键能力。

## 创业逻辑

王云鹤选择 AI Agent 赛道而非继续卷大模型，源于其技术判断：大模型不仅是"脑"，更要是"手"和"脚"。单纯的文本生成和问答价值壁垒正在变薄，真正的金矿在于让大模型像人一样操作手机和电脑。这一判断与其 [[dllm-agent]] 论文中的技术洞察一脉相承。

## 行业评价

王云鹤的轨迹被视为"学术根基+产业实战"新生代技术领袖的典型代表。他的离职投身 Agent 创业，被广泛解读为 AI 行业从"大模型军备竞赛"向"智能体应用落地"转移的风向标。
