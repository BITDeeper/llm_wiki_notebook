# Gemini Skills

**Gemini Skills** 是 Google 为其 Gemini AI 助手（集成于 Chrome 浏览器中）推出的功能模块，旨在实现 Prompt 的固化与复用。它是 [[chrome-skills]] 的底层技术支撑和功能总称。

## 功能描述
Gemini Skills 允许用户将针对特定任务的复杂提示词保存为独立的“技能”。用户无需重复输入指令，只需通过斜杠（`/`）即可激活技能。Google 提供了包含 50 多个场景的预置技能库，并支持跨设备同步。

## 关联条目
该功能在浏览器端的直接体现即为 [[chrome-skills]]。
