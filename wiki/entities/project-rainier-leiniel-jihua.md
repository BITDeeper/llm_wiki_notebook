# Project Rainier (雷尼尔计划)

Anthropic 与亚马逊正在紧密推进的深度训练合作项目。

## 概述
- **合作方**: [[Anthropic]] 与 [[亚马逊]]。
- **目的**: 旨在构建大规模的训练基础设施，以支持 Claude 系列模型的持续迭代。
- **地位**: 尽管 Anthropic 宣布了与 [[谷歌]] 的 3.5 GW TPU 合作，但亚马逊依然是其主要云服务提供商和训练合作伙伴，雷尼尔计划是双方合作的重要体现。
