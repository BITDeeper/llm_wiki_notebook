# CREAO

CREAO 是一款由 [[creao团队]] 开发的 AI Agent 产品，被定义为“全球第一个真正面向普通用户的 AI Agent Harness”。

## 核心特性

### 零门槛部署
CREAO 旨在解决普通用户使用 AI Agent 时的环境部署和逻辑构建门槛。用户无需配置服务器、API Key 或具备编程思维，只需打开官网并使用自然语言下达指令即可。

### 固化机制
CREAO 的核心创新在于其“固化”流程：
1.  **理解与构建**：系统理解自然语言指令，实时编写代码并连接 Gmail、Slack 等 300+ 软件。
2.  **驯化与固化**：用户验证效果后，可点击“创建智能体”将动态流程“固化”为永久 Agent。
3.  **确定性执行**：固化后的 Agent 不再依赖 LLM 实时推理，从而消除了 [[幻觉]]问题，实现 100% 的准确率。

### 持久化运行
CREAO 在云端服务器为 Agent 创建“影分身”，支持用户在关闭网页或电脑后，任务仍按既定时间表执行。这解决了传统 Agent（如 [[openclaw]]）必须保持在线的痛点。

## 技术架构
CREAO 采用全栈自研架构，包括底层架构、执行引擎和集成协议。这种设计使其摆脱了对 LangChain、CrewAI 等第三方框架的依赖，保障了任务执行的稳定性与安全性。

## 市场定位
CREAO 定位于 [[消费级-ai-agent]] 市场，强调从“对话”到“行动”的跨越。与 [[claude-code]]（仅文本输出）和传统自动化工具（如 n8n，需专业知识）相比，CREAO 实现了“思考、构建、运行、连接、持久化”的全维度覆盖。

## 融资情况
据报道，CREAO 在正式发布前的一年内已完成连续多轮数千万级美金融资。
