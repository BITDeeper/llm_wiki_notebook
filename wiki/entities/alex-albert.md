# Alex Albert

Alex Albert 是 [[anthropic]] 的产品负责人，也是公司对外的重要技术布道者，直接负责打造下一代 [[claude]] 模型的核心人物。

## 角色与影响

Albert 是 Anthropic 内部推动 Claude 产品化的关键人物。在2026年5月与科技博主 Peter Yang 的35分钟访谈中，他首次系统性披露了 Anthropic 的下一代 Claude 训练方法论，涵盖：

- [[模型即产品]] 的研发哲学
- 用 Claude 迭代 Claude 的反馈闭环流程
- [[ai梦境记忆再巩固|AI「做梦」]] 机制
- [[性格训练]] 方法论
- [[意识研究-anthropic|意识研究]] 团队的存在

## 观点与愿景

### Agent 化与产品进化

Albert 积极推动 Claude 从单纯的对话模型向具备实际操作能力的 Agent 进化。在 [[claude-code]] 推出全平台电脑控制功能时，他直言**"不用再打开电脑完成工作的未来，正加速兑现"**。

他致力于将 Claude 打造为一个完全自动化的"数字人类"，重新定义人机交互的未来形态。在他的推动下，Anthropic 密集发布了包括 [[电脑使用]]、[[orbit]]（[[手机使用]]）和 [[定时任务自动化]] 在内的多项新功能。

### 训练方法论与产品哲学

- 主张将模型本身视为产品，在预训练前就定义能力蓝图
- 强调评估必须锚定真实用户场景，反对「评估戏剧」
- 认为 AI Agent 时代，模型的性格和价值观变得「生死攸关」
- 推崇 [[单向门决策框架]]，在 AI 加速开发环境下快速试错
