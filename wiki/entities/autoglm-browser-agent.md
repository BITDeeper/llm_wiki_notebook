# AutoGLM-Browser-Agent

[[autoglm-browser-agent]] 是 [[智谱]] 自研的浏览器自动化引擎，作为核心技能集成在 [[autoclaw]] 中。

## 功能特性

- **多步骤操作**：能够稳定完成跨越多个页面的复杂任务流程。
- **自动串联**：相比 [[openclaw]] 原生的 Browser use 能力，AutoGLM-Browser-Agent 在处理复杂网页操作时表现更强，能自动串联一系列操作。

## 与原版对比

原版 [[openclaw]] 自带的浏览器工具（browser use）功能较为基础，在处理稍微复杂的多步骤、跨页面任务时容易出错。AutoGLM-Browser-Agent 针对这些痛点进行了优化，能够稳定地完成整个操作链路的自动化。

## 应用场景

该技术使得 AutoClaw 能够胜任更复杂的 Web 操作任务，是 Agent 具备“实操能力”的关键组件。具体应用包括：

- 自动填表
- 跨站数据抓取
- 页面交互
- 资讯抓取
- 跨平台同步
