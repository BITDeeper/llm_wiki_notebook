# UALink

[[UALink]] (Ultra Accelerator Link) 是一个开放的加速器互联标准，旨在对标英伟达的专有 NVLink 技术。它是「反英伟达联盟」在技术层面的核心支柱，由 AMD、英特尔、博通、谷歌、Meta、微软等巨头联合制定。

## 技术特性

### Scale Up (节点内扩展)
- **规模**：UALink 1.0 规范支持多达 1024 个加速器在一个 POD（节点）内互联。这在规模上甚至超越了英伟达当前的 NVSwitch 能力。
- **内存一致性**：最关键的特性是支持显存池化。这意味着集群内的 GPU 可以像访问本地显存一样访问其他 GPU 的内存，这对于训练万亿参数级别的模型至关重要。

### 战略价值
- **打破垄断**：NVLink 是英伟达最深的护城河，它构建了一个封闭的高速物理层协议。UALink 的出现打破了这种封锁，允许不同厂商的 GPU 通过统一标准高效互联。
- **降低成本**：通过开放标准，客户可以混合使用不同厂商的硬件，利用通用组件降低总拥有成本，避免被单一供应商锁定。

## 背景与联盟
UALink 的推出反映了行业巨头对供应链安全和议价权的深切担忧。通过支持 UALink，OpenAI、微软等公司希望迫使英伟达开放生态或至少提供更具竞争力的价格。
