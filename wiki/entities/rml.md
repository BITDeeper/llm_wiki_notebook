# RML

火星车标记语言（Rover Markup Language），一种基于 XML 的指令集。

## 作用
它是 [[毅力号]] 火星车能够直接理解和执行的“方言”。在 [[Claude]] 辅助驾驶的任务中，Claude Code 负责生成符合 RML 规范的代码，这些代码随后被上传至火星车并转化为具体的物理动作（如移动、转向、避障）。

## 技术意义
对于 AI 模型而言，掌握 RML 意味着不仅要理解自然语言，还要精确控制底层硬件接口，这是实现 [[外星自动驾驶]] 的关键一环。
