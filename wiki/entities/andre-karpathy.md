# Andre Karpathy

Andre Karpathy 是一位知名的计算机科学家，曾任特斯拉 AI 主管，也是 [[Vibe Coding]]（氛围编码）概念的布道者。

## 观点与贡献

### Vibe Coding
Karpathy 创造了“Vibe Coding”一词，描述一种新的编程范式：开发者通过自然语言向 AI 描述直觉和感觉，由 AI 生成代码，开发者仅负责结果验收（如 UI 美观度）。

### 工程实践
尽管是 Vibe Coding 的旗手，Karpathy 本人的操作极其严谨。他强调：
- Vibe Coding 适合本地 Demo，但部署时需要大量手动干预。
- 必须花费时间审查 AI 写的代码，仔细盯着 Diff 看。
- 如果完全不看逻辑而点击 Accept，那是“自寻死路”。

## 评价
Karpathy 的言行揭示了 Vibe Coding 作为一种**营销概念**与**工程实践**之间的鸿沟。新手可能只学到了“爽”，而忽略了“险”。
