# Context System

**Context System**（上下文系统）是 [[Generative Enterprise Agent (GEA)]] 架构的底层支撑系统，也是 [[System of Context]] 概念的具体实现。由 [[特赞]] 提出。

## 定义与组成
Context System 不仅仅是数据的集合，而是一个由企业认知结构构成的网络。它组织了以下关键信息：
- 历史决策路径
- 品牌资产结构
- 用户研究结果
- 产品演化逻辑
- 业务反馈循环

## 核心功能
Context System 的核心作用是回答“为什么如此”，而传统的数据库（System of Record）只能回答“发生了什么”。

## 价值
在 Agent 时代，Context System 成为企业新的引力中心。当这些结构被系统化之后，智能体才真正具备持续推理能力，能够基于企业的长期判断经验进行运作，而不仅仅是处理单次查询。

## 与相关概念的关系
- 是 [[System of Context]] 概念的技术实体化。
- 区别于 [[Palantir]] 等代表的以数据为中心的操作系统。
