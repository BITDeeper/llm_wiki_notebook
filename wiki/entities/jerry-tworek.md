# Jerry Tworek

**Jerry Tworek** (也称 Jarosław Tworek) 是前 [[openai]] 研发副总裁，被誉为 OpenAI 的“推理之父”及“编程代码之父”。作为“[[波兰军团]]”的重要成员，他在 OpenAI 任职约七年（2019-2026），是公司核心技术路线的关键奠基人。

## 职业生涯与教育背景
- **教育背景**：在华沙大学获得应用数学硕士学位。
- **任职经历**：2019 年加入 OpenAI，任职约七年（至 2026 年），是公司的 7 年元老。
- **学术影响力**：在 Google Scholar 上拥有极高的论文引用数，特别是在“代码生成”和“强化学习（RLHF）”领域。

## 核心贡献
Tworek 在 OpenAI 期间领导了多个具有里程碑意义的项目，主要集中在编程生成和复杂推理两个领域：

### 代码生成与 Codex
- **Codex 开发**：作为 [[codex]] 模型的核心研究员，他于 2021 年主导了 Codex 的开发，奠定了 GPT 系列模型的代码能力基础。这是 GitHub Copilot 等产品的基础。
- **GPT-4/5**：专门负责 GPT-4 的编程能力模块，并在 2025 年主导了 [[gpt-5]] 的部署工作。

### 推理模型与 System 2
- **推理模型突破**：担任 [[openai-o1]] 项目的团队负责人，领导了 [[o1]]、[[o3]] 及 [[gpt-4]] 的早期研发工作。
- **技术范式确立**：在 [[scaling-law]] 出现边际递减时，他确立了 [[system2]]（思维链）技术范式，将逻辑能力注入 GPT 神经网络，使模型从统计学的“下一个词预测”转向强化学习的“Reasoning Search”（即“慢思考”模式）。
- **Agent 研发**：参与了 ChatGPT Agent（智能体）的研发工作，并负责 [[chatgpt]] 的“推理”研究。

## 离职与去向
- **时间**：2026 年 1 月 7 日宣布离职。
- **去向**：创办新公司 **Core Automation**，致力于开发需要更少数据和计算的新型 AI 模型。
- **声明**：他在离职声明及内部备忘录中表示：“我得离开这里，才能做那些在 OpenAI 难以开展的研究。”这一表态被广泛解读为对 OpenAI 当前商业化导向和研究环境限制的无声抗议。

## 离职原因
Tworek 的离职源于多重因素的综合作用，包括与现任首席科学家 [[jakub-pachocki]] 的理念冲突、商业化压力以及资源分配问题。

### 理念与战略冲突
- **研究方向分歧**：
  - Tworek 致力于“[[持续学习]]”（Continuous Learning）研究，旨在让模型在吸收新数据的同时保留既有知识，并坚持认为需要新的基础突破。
  - 相比之下，Pachocki 更看好能快速落地的大语言模型架构。
- **研究 vs. 产品**：
  - Tworek 认为 AI 已进入“[[研究时代]]”，但 OpenAI 的资源过度倾斜给 ChatGPT 等产品部门，导致基础研究被边缘化。
  - 管理层强调季度盈利，要求降低延迟、压缩成本，这与深度推理（o1/o3）所需的高成本、慢思考模式存在根本冲突。

### 资源与制度限制
- **资源匮乏**：他多次向管理层申请更多的算力和人员支持，但均未获批准。
- **制度摩擦**：尽管 OpenAI 拥有全球最丰富的算力和资金，但公关、法务和商业利益限制了科学探索的边界，涉及可解释性研究、非 RLHF 路径探索等方向的项目在公司内部难以推进。

## 行业影响与象征意义
Tworek 的出走被视为 [[openai-人才流失]] 现象中的标志性事件，反映了 OpenAI 内部“基础研究”与“工程化变现”之间的剧烈冲突（即 [[商业化-vs-理想主义]]）。

他的离职不仅是 OpenAI 从“AGI 实验室”转型为“API 供应商”的标志性事件，也削弱了 OpenAI 在推理技术上的核心竞争力，引发了外界对 OpenAI 是否能维持基础研究领先地位的担忧。
