# 福州大学

福州大学是 [[vifit|ViFIT]] 虚拟纤维染色框架的第一完成单位。该校联合福建师范大学、福建医科大学附属第一医院、协和医院及美国伊利诺伊大学厄巴纳-香槟分校，在医学影像顶刊《Medical Image Analysis》上发表了关于无监督虚拟纤维图像转换的研究。

该研究团队（AI-XPM-group）专注于病理图像分析与计算医学方向，代码已通过 GitHub 开源。
