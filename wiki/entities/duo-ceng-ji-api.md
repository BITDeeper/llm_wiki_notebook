# 多层级 API

**多层级 API** 是 [[apex]] 框架中设计的一套预定义操作接口，用于替代不稳定的代码生成，实现对文档的增量式、确定性编辑。

## 设计背景
在使用 AI Agent 进行文档编辑时，直接生成代码（如 Python 脚本）往往存在以下问题：
-   **执行不稳定**：生成的代码可能包含语法错误或逻辑漏洞。
-   **安全性风险**：直接执行代码可能带来安全隐患。
-   **难以控制**：代码逻辑的复杂性使得精确控制修改范围变得困难。

## 功能层级
APEX 的多层级 API 涵盖了不同粒度的操作能力，主要包括：
-   **单元素操作**：针对单个文本框、图片或形状的属性修改（如字体、颜色、大小）。
-   **组操作**：针对逻辑上相关的一组元素进行批量处理（如 `move_group` 移动整个章节，`text_format_brush` 格式刷）。
-   **全局操作**：涉及整体布局或样式的调整。

## 优势
-   **确定性**：预定义的 API 保证了输入与输出之间的稳定映射，避免了模型幻觉导致的随机错误。
-   **可组合性**：简单的 API 原子操作可以组合成复杂的编辑任务。
-   **易于审查**：API 调用序列比生成的代码更易于人类或模型进行审查和调试。

## 与审查—调整机制的配合
多层级 API 提供了稳定的操作原语，使得 [[审查—调整机制]] 能够在检测到错误时，精确地生成反向或修正操作，从而实现闭环的纠错流程。
