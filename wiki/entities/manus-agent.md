# Manus Agent

## 概述
Manus Agent 是 Meta 在收购 Manus 后推出的进阶版 AI Agent 产品。它是 Meta 在“龙虾化”浪潮中的核心答卷，旨在通过 AI Agent 替代人类完成繁琐的数字任务。

## 核心特性
- **长期记忆**: Manus Agent 的核心差异化卖点。它能够记住用户的风格、语气和细碎偏好，并在历史交互中积累上下文。
- **社交场域集成**: Meta 将 Manus Agent 直接接入了 [[Telegram]] 聊天室，使其成为首个大规模进入社交场域的 Agent 之一。
- **跨应用操作**: 能够配合 Gmail 和 Notion，完成从脚本生成、视频制作到发送的全流程任务。

## 应用场景
用户只需在 Telegram 上发送一句指令（如“按老规矩帮我做个视频”），Manus Agent 就能自动调用历史素材和相关工具，自动完成整个工作流。

## 战略意义
Meta 通过 Manus Agent 试图构建一个基于社交关系的 Agent 生态，利用其在社交领域的优势，将 AI Agent 从工具属性转变为社交属性。
