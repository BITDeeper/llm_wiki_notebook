# 郑炳南

郑炳南是 AI Agent 框架 [[minion]] 的创建者，毕业于复旦大学物理系。他拥有 20 多年的软件开发经验，是开源社区的活跃贡献者。

## 背景与贡献
-   **学术成就**：他是 ICLR 2025 Oral Paper《AFlow: Automating Agentic Workflow Generation》的作者之一。
-   **开源贡献**：参与贡献了 MetaGPT、Hugging Face 项目的 smolagents、mem0、crystal 等知名开源项目。
-   **Minion 框架**：开发了基于“LLM 规划 + Python 代码执行”架构的 Agent 框架，并在 Anthropic 推出 PTC 之前一年多就在生产环境中验证了这一理念。

## 观点与理念
郑炳南强调 LLM 应专注于理解和规划，而代码应负责执行和转换。这种职责分离是构建高效、可靠 AI Agent 的关键。
