# 1.x-Distill

**1.x-Distill** 是由[[清华大学]]和[[华为中央媒体技术院]]联合提出的少步扩散模型蒸馏框架，核心突破在于将扩散模型推理步数从整数步推进至"分数步"（如1.67 NFE），在保持高画质和高多样性的同时实现极致加速。

## 核心技术

1. **[[时间步感知指导控制]]**：针对[[模式崩溃]]根因，在高噪声阶段关闭/减弱[[无分类器指导]]（CFG），低噪声阶段恢复强CFG，阈值0.94分段处理。
2. **[[阶段性聚焦蒸馏]]**（SFD）：第一阶段"结构聚焦分布匹配"引入重要性时间步采样关注宏观结构；第二阶段"细节聚焦对抗精炼"使用合成图作为对抗损失的真图，消除域差。
3. **[[蒸馏-缓存协同训练]]**（DCT）：通过块级缓存与轻量级MLP补偿模块，将2步推理压缩为"1步完整计算 + 0.x步残余计算"，实现1.67/1.74 NFE。

## 性能表现

| 指标 | 数值 |
|------|------|
| 最低 NFE | 1.67 |
| 加速比（vs 28步） | 33倍 |
| DPG-Bench 得分 | 86.13（超过56步教师模型的85.46） |
| LPIPS 多样性 | 0.6432 |
| 验证模型 | SD3-Medium（2B）、SD3.5-Large（8B） |
