# GLM-4.7

**GLM-4.7** 是 [[智谱华章]] 发布的最新一代基座大模型，代表了国产开源模型的顶尖水平。

## 性能表现
- **综合能力**：在模型综合能力榜单 Artificial Analysis 中荣登开源模型与国产模型榜首。
- **编码能力**：在权威编码榜单 Code Arena 中位列开源模型与国产模型双料第一。
- **Agent能力**：在真实场景下的 Agent 表现优秀，支持设备操控。

## 商业应用
GLM-4.7 发布后迅速获得市场认可：
- **付费用户**：发布两个月内，来自184个国家的15万开发者为其编程订阅产品付费。
- **生态接入**：Cerebras、Windsurf 等超过50家海内外开发平台工具选择接入。

## 技术背景
该模型基于智谱原创的 [[GLM]] 架构，延续了 [[自回归填空]] 的技术范式，并保持了智谱模型每2-3个月完成一次基座迭代的节奏。
