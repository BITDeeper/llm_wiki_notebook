# Claude-Code-Game-Studios

Claude-Code-Game-Studios 是一个基于 [[claude]] 构建的开源虚拟游戏开发工作室项目。它展示了如何利用多 Agent 协作系统，将原本需要数十人团队的游戏开发流程压缩为个人可操作的自动化工作流。

## 系统架构

### 48 个专业 AI Agent
该项目内置了 48 个具有特定角色的 AI Agent，涵盖了游戏开发的各个环节，包括但不限于：
- **管理层**：创意总监、技术总监、制作人、QA 主管。
- **设计层**：叙事总监、关卡设计师、经济系统设计师。
- **技术层**：Godot 4 专家（GDScript/Shader）、Unity 专家（DOTS/ECS/Addressables）。

### 工作流特点
- **层级分工**：Agent 之间按照真实工作室的层级进行清晰分工，从高层决策到具体代码实现均有专人负责。
- **人类最终决策权**：系统设计强调“人机协作”，所有 Agent 不具备最终拍板权，决策权始终保留在用户手中。

## 意义与影响

### “一人公司”的可行性
Claude-Code-Game-Studios 是 [[agent-workflow]] 概念的生动实践。它证明了借助 AI，个人可以拥有以前需要整个团队才能完成的生产力，极大地降低了创业和开发的边际成本。

### 开发范式转变
该项目标志着软件开发从“手动编写”向“指挥 Agent 生成”的转变。开发者的核心技能从具体的语法掌握转变为系统架构设计和 Prompt 编排。
