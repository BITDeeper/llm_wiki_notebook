# Project Extract

[[Project Extract]] 是 [[google-deepmind]] 与英国政府 AI 孵化器（i.AI）合作开发的地理空间智能系统，旨在解决英国城市规划系统中的「数据孤岛」问题，提高规划申请处理效率。

## 核心能力

### 1. 非结构化信息理解
利用 [[Gemini]] 的视觉语言能力读取低质量的扫描文档和手绘地图。
-   **语义理解**：能识别手写注释的语义（如区分「批准日期」与「申请日期」）。
-   **准确率**：日期识别准确率达到 **94%**。

### 2. 视觉推理与多边形提取
-   **符号理解**：理解地图上的视觉符号语言（如红色实线代表产权边界）。
-   **精确提取**：结合 OpenCV 和 SAM 等计算机视觉工具，精确提取地理多边形。
-   **匹配度**：形状匹配度（IoU）达到 **90%**。

### 3. 时空特征匹配
利用 LoFTR 算法，在历史地图和现代卫星地图之间找到共同特征点，计算出精确的变换矩阵，将几十年前的手绘红线映射到现代数字地图坐标系中。

## 实际成效
-   **效率提升**：将复杂规划文档的处理时间从平均 **2 小时**压缩至 **40 秒到 3 分钟**。
-   **试点范围**：已在威斯敏斯特、希灵登等四个地区试点。
-   **推广计划**：英国政府计划于 2026 年春季推广至全国所有地方议会。

## 战略意义
Project Extract 是 [[深度研究]] 技术在垂直领域应用的最佳范例，它将通用的多模态推理能力转化为具体的行政生产力，为英国政府承诺的「建设150万套新住房」计划提供了数据底座。
