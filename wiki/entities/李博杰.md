# 人物简介
李博杰是 AI 研究人员，因提出“[[不可压缩知识探针]]”框架而受到关注。该研究试图通过黑盒 API 测试来逆向估算大语言模型的参数规模。

# 主要贡献
- **不可压缩知识探针 (IKP)**：提出了一种新的评测框架，利用模型对冷门事实性知识的记忆能力来推断其参数量。该研究在 arXiv 发布的论文显示，开源模型的事实准确率与参数量之间存在高度的对数线性关系（R² = 0.917）。
- **数据集构建**：利用 AI Agent 历时四天构建了包含 1400 个冷门问题的 IKP 数据集，并在 188 个模型上进行了测试。
- **反驳 Densing Law**：其研究发现模型的事实记忆容量在过去三年中并未随时间显著提升，挑战了关于模型效率随时间快速提升的既有认知。

# 相关研究
李博杰的研究灵感源于对 [[中科大 Hackergame]] 等冷门知识的长期观察。他指出，模型更倾向于记住产生领域性影响的工作，而非高产但影响分散的学者。
