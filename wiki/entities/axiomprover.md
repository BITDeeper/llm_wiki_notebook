# AxiomProver

AxiomProver 是 [[axiom|Axiom]]（即 [[axiom-math|Axiom Math]]）开发的 AI 数学证明工具，结合大语言模型与 [[lean-形式化证明语言|Lean]] 形式化验证语言，能够将自然语言数学问题翻译为 Lean 形式化证明，并生成机器可逐步验证的证明。

## 技术路线

与大型语言模型生成自然语言"证明文本"不同，AxiomProver 的核心区别在于：

1. **大语言模型驱动**：使用大语言模型生成证明草稿
2. **形式化输出**：所有证明以 Lean 形式化语言编写，而非自然语言描述
3. **机器验证**：Lean 检查器充当"铁面无私的机器裁判"，由独立检测器逐步验证每一步逻辑，证明正确性由机器当场背书，不依赖人类专家逐行验算
4. **消除风险**：规避 [[高阶幻觉]] 和 [[潜意识剽窃]] 风险——即 AI 从冷门文献中提取逻辑并重新包装的问题
5. **人机协作**：AI 负责生成/形式化可检查证明，人类数学家负责问题表达、论文解释和审稿沟通

## 工作流程

```
自然语言问题陈述 → 大语言模型生成证明草稿 → Lean 形式化翻译 → 独立检测器逐步验证 → 人类数学家配学术解释
```

## 产出成果

自2026年2月以来：

- **8篇论文**现身 arXiv，覆盖代数几何、表示论、数论、组合数学
- **5篇**已通过同行评审被权威数学期刊接收
- **6篇**正在筹备中
- 历史上首次以"论文+形式化证明证书"方式引入期刊文献
- **普特南数学竞赛**：满分成绩
- **Erdős 猜想**：解决两个困扰学界数十年的猜想
- **具体案例**：论文 *Reciprocals of Partition Polynomials* 处理 Ballantine、Beck、Feigon 和 Maurischat 提出的10个猜想，证明6个，发现1个反例

## 速度表现

- 实际案例：上午10点提出开放研究问题，下午4点返回完整机器验证证明
- 将数学证明周期从数月/数年压缩至数小时
- 创始数学家 [[ken-ono|Ken Ono]] 表示，在某些情况下，系统被给定开放研究问题后，可在约24小时内生成完整、机器验证的证明

## 行业意义

AxiomProver 代表了 AI 数学从"不可验证的声称"向"机器背书的形式化证明"的范式转移。

- **与 [[aletheia]]（Google DeepMind）对比**：Aletheia 专注于大规模自动化猜想验证/解决数学猜想，AxiomProver 专注于生成可验证的形式化证明，两者形成互补。AxiomProver 的形式化路线声称能规避 [[潜意识剽窃]] 问题
- **与 [[openai|OpenAI]] 对比**：2025年10月 OpenAI 声称 GPT-5 解决埃尔德什难题但被质疑造假，AxiomProver 通过 Lean 验证避免了类似的信任危机
