# TPU 8i

TPU 8i 是谷歌第 8 代 TPU 中专门面向**AI 推理**的芯片。与其姊妹芯片 [[tpu-8t]] 相比，8i 采用了完全不同的物理设计，核心目标是优化延迟、提高吞吐量并降低推理成本。

## 核心特性

### 性价比与吞吐
- **性价比提升**：每美元性能提升约 80%。
- **服务能力翻倍**：在相同成本下，服务能力接近翻倍。
- **低延迟优化**：针对 Agent 时代对实时响应的要求，进行了底层栈的重构。

### 内存与带宽
- **大容量内存**：配备了 288GB 高带宽内存（HBM）和 384MB 片上 SRAM，容量是上一代的 3 倍。这使得模型的活跃数据能尽量留在芯片上，减少内存搬运带来的延迟。
- **MoE 优化**：针对混合专家模型，将互连带宽提升至 19.2 Tb/s，并采用新的 Boardfly 架构将网络“路径长度”砍掉一半以上，解决多专家协作的瓶颈。

### 系统级优化
- **片上集体加速引擎（CAE）**：将原本需要跨芯片完成的全局操作搬回芯片内部，整体延迟最高可降低到原来的 1/5。
- **CPU 协同**：引入 [[axion-cpu]] 架构，通过 NUMA 隔离优化，提升服务器整体协同效率。

## 设计理念
TPU 8i 体现了谷歌“训推分离”的战略思想。推理任务不仅需要算力，更需要“稳”和“快”。通过专用化设计，8i 在能效和响应速度上取得了突破，为大规模 Agent 部署提供了硬件基础。
