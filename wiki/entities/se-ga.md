# SE-GA

SE-GA（Memory-Augmented Self-Evolution for GUI Agents）是天津大学与上海交通大学联合提出的记忆增强型自进化 GUI 智能体框架，发表于 ICML 2026。该框架通过分层记忆结构和迭代自我改进机制，让 GUI 智能体从"静态执行器"进化为"动态学习者"。

## 核心架构

SE-GA 由两大互补模块组成：

### TTME（测试时记忆扩展）
解决"记不住"问题。借鉴人类认知架构构建分层记忆库：
- **情景记忆**（Episodic Memory）：短期工作记忆，跟踪"刚才做了什么"，记录前一步观察、动作和新观察。
- **语义记忆**（Semantic Memory）：通用规则库，存储"怎么做才对"，如"需要先登录才能访问受限页面"。
- **经验记忆**（Experiential Memory）：过往经历库，复用"成功的经验"，采用文本-图像混合检索机制（语义一致性+视觉相似性）。

### MASE（记忆增强自进化训练）
解决"学不会"问题。两阶段训练框架：
1. **基础能力训练**（Grounding Training）：通过监督微调对专家轨迹进行行为克隆，强化视觉定位和动作推理能力。
2. **自我进化训练**（Self-Evolution Training）：基于 [[grpo]] 算法，引入分层奖励设计（点定位奖励+包围框奖励），将非参数化经验编码为参数化策略。

### Hindsight Goal-Shifting
核心数据精炼方法：将失败轨迹的前缀子序列重新标注为子目标的成功实例，"变废为宝"提升训练数据利用率。

## 实验表现

以 [[qwen2-5-vl-7b]] 为基座模型，仅使用 4K 条交互轨迹训练：

- **ScreenSpot**：89.0%（超越 [[ui-tars-72b]] 的 88.4%）
- **GUIOdyssey**：步骤成功率 83.9%，动作类型准确率 96.5%（超越 72B 模型）
- **AndroidWorld**：39.0%（显著领先 UI-TARS-7B 的 33.0% 和 GPT-4o 的 23.7%）

## 理论基础

将 GUI 导航任务形式化为[[部分可观察马尔可夫决策过程]]（POMDP），智能体无法完全观察环境状态，只能通过局部观察做决策。

## 局限性与未来方向

1. 经验记忆库规模增长后检索计算开销显著，影响实时推理速度
2. 训练数据集覆盖任务类型有限
3. 超长工作流的分层任务分解尚未探索
4. 跨平台迁移学习（iOS、Web、桌面）尚未验证

## 关联

- 与 [[自进化架构]]：SE-GA 是自进化理念在 GUI 智能体领域的学术路线实现，与 EvoMap 团队的 Evolver 工程路线形成互补。
- 与 [[runtime-agent-os]]：两者都关注智能体的系统级架构设计，Pi 团队的三层架构与 SE-GA 的分层记忆结构有理念共鸣。
- 与 [[递归式自我改进]]：MASE 的自我进化训练是该概念在 GUI 领域的具体落地。
