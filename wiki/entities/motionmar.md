# MotionMAR

MotionMAR 是由 [[厦门大学asc实验室|厦门大学]] 与 [[上海科技大学]] 联合提出的稀疏观测人体运动重建模型，论文被 ICML'26 接收。该模型通过 [[coarse-to-fine多尺度生成|分层生成]] 方式，仅依赖3个追踪点（头部+双手）即可还原22个关节的完整人体姿态。

## 核心思想

MotionMAR 的核心创新在于将人体运动视为多尺度信号，而非平铺的时间帧。借鉴视觉自回归生成中"先生成粗略图像、再补充细节"的逻辑，采用 **next-scale 预测**范式替代传统逐帧 next-token 预测：先预测粗尺度 token（整体运动趋势），再预测细尺度 token（局部动作细节），同层内可并行预测。

## 架构组成

模型由四个核心组件构成：

1. **[[时间多尺度词元量化变分自编码器]]（TMT VQ-VAE）**：将连续运动序列映射到多尺度离散潜在空间。使用共享码本在 K=3 个时间尺度（T/4、T/2、T）上逐次量化，为自回归生成提供层次先验。
2. **尺度感知控制模块（SAC）**：将稀疏跟踪信号投影到高维潜在空间，通过线性插值实现条件信号与各尺度 token 序列长度的时间对齐，生成控制特征金字塔。
3. **运动自回归网络（MAN）**：执行 next-scale 预测的核心网络，层间保持自回归依赖，层内可并行。
4. **运动精炼网络（MRN）**：在连续姿态空间中进行残差修正，减少量化误差和局部抖动。

## 实验结果

在 [[amass数据集|AMASS]] 数据集上进行评估：

- **S1（三点追踪）**：绝大多数重建指标（MPJRE、MPJPE、MPJVE、部位级误差）达到最优，仅 Jitter 略逊于 RPM。
- **S2（四追踪器）** 和 **S3（大规模数据组合）**：持续保持领先，证明泛化能力。
- **消融实验**：TMT（时间多尺度建模）是最关键模块，SAC 负责尺度对齐，MRN 负责最终平滑。

| 指标 | 数值 |

| 参数量 | 42.36M |
| FLOPs | 1.47G |

满足 VR/AR 实时应用需求。

## 局限性

- Jitter 指标略逊于 RPM，时序平滑性仍有改进空间。
- 仅在 AMASS 数据集上评估，真实 VR/AR 环境中的噪声、遮挡、长时间连续使用等挑战未被讨论。
