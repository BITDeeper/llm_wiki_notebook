# 通义千问团队

**通义千问团队**（隶属于阿里巴巴通义实验室）是阿里巴巴旗下负责大语言模型及多模态智能体研发的核心团队。

## 主要贡献

### GUI Agent 领域
团队在 GUI Agent（图形用户界面智能体）领域进行了深入探索，致力于解决高可用、跨平台智能体的工程与算法挑战。
*   **Mobile-Agent 系列**：开发了 Mobile-Agent-v3.5 框架，实现了跨桌面、手机、浏览器的统一控制。
*   **GUI-Owl 模型家族**：发布了 GUI-Owl-1.5 系列原生基座模型，通过引入世界模型和统一思维链，显著提升了模型在长程任务和复杂环境中的表现。

### 技术创新
*   **MRPO 算法**：提出了多平台强化学习策略优化算法，解决了混合训练中的梯度冲突和 GRPO 结果坍塌问题。
*   **数据工程**：构建了包含合成数据、不可行查询负样本及虚拟环境轨迹的混合数据管线。
*   **工程落地**：通过 [[Token-ID 对齐]] 等机制，保证了大规模分布式 RL 训练的数学一致性。

## 开源理念
团队坚持开源策略，将模型权重、Agent 框架源码及在线 Demo 对外开放，旨在为技术社区提供系统性的技术参考，推动 GUI Agent 从演示 Demo 走向工程级应用。
