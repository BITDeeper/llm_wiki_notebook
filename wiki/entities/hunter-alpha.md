# Hunter Alpha

Hunter Alpha 是 [[小米]] [[mimo-v2-pro]] 大模型在正式发布前使用的测试代号。该模型于 2026 年 3 月 11 日深夜以匿名形式出现在 [[openrouter]] 平台上，凭借卓越的性能连续多日霸榜调用量榜首，并在 [[中关村北纬龙虾大赛]] 期间作为核心资源引发全球 AI 社区的广泛猜测与关注。

## 模型规格
- **参数量**：1 万亿（1T）
- **上下文窗口**：100 万 token
- **核心定位**：专为 Agent 使用而构建，强调生产级可靠性和指令执行精度。
- **架构**：在揭晓前以匿名高性能模型形式提供，具体架构未公开。

## 核心特性
根据 OpenRouter 的描述及比赛期间的实测表现，Hunter Alpha 具备以下特征：
- **长程规划**：能够处理跨越长时间或大量步骤的任务。
- **复杂推理**：具备高阶逻辑推理能力。
- **持续多步任务执行**：能够稳定地执行包含多个步骤的复杂任务流。
- **免费试用**：在比赛期间（2026年3月11日-19日）向参赛者免费开放 API 调用，为实现 [[token自由]] 提供算力支持。

## 历史背景与行业反响

### 身份猜测
在 [[小米]] 官方认领之前，业界对其来源有多种推测：
- **OpenAI**：因其命名习惯、使用了 OpenAI 惯用的术语风格，且出现时间紧随 OpenAI 员工关于“新 omni 模型”的讨论之后。社区普遍推测其为 [[openai]] 发布的 [[stealth-model]]（幌子模型）。
- **DeepSeek/国产模型**：测试中发现模型自称主要使用中文训练，且有传闻称其系统提示包含“严格遵守中国法律法规”。
- **小米**：部分网友在 3 月 14 日于小红书上准确预言了其身份。

### 实战验证
在盲测期间，Hunter Alpha 展现了极强的工程落地能力：
- **硬核工具支持**：[[openclaw]]、Kilo Code 和 Roo Code 等开发工具贡献了超过 700B Token 的调用量，验证了其在生产环境中的可靠性。
- **官方描述关联**：Hunter Alpha 的官方描述中明确提到：“专为像 [[openclaw]] 这样的生产级 Agent 流水线而设计”。这表明其并非旨在取代 [[openclaw]]，而是为其提供更强大的底层模型支持。
- **行业关注**：被称为“龙虾之父”的 [[peter-steinberger]] 曾在 X (Twitter) 上发帖询问 Hunter Alpha 的具体细节，侧面印证了该模型在行业内的受关注程度。

## 揭晓
2026 年 3 月 19 日，小米团队正式官宣 Hunter Alpha 即为 [[mimo-v2-pro]]，结束了这一代号的历史使命。
