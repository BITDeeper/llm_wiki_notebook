# Visa

全球支付网络巨头，在Agent时代推出智能体支付基础设施。

## Agent时代布局

推出 **Intelligent Commerce**，为AI合作伙伴提供API、标准和全球网络，让Agent可以在用户和企业授权下安全交易。将信任、可见性和安全作为核心能力，面向Agentic Commerce提供支付基础设施。

与 [[mastercard]] 的 Agent Pay、[[stripe]] 的商家侧闭环、[[支付宝]] 的 [[act协议]] 形成全球AI支付基建的并行布局。
