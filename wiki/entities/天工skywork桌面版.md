# 天工Skywork桌面版

## 概述
[[天工Skywork桌面版]] 是由 [[昆仑天工]] 推出的 Windows 原生高阶桌面 Agent。它旨在填补 Windows 生态在 AI Agent 领域的空白，对标 Mac 平台的 [[Claude Cowork]]。

## 核心特性

### 双核驱动架构
Skywork 最大的技术护城河在于同时集成了两大顶尖模型阵营，并通过 [[智能路由]]（Auto Router）自动切换：
- **Claude 系列**（Opus 4.5, Sonnet 4.5）：擅长长文本逻辑推理、代码编写和细腻文本生成。
- **Gemini 系列**（3 Pro）：擅长原生多模态处理，对视频、图片、音频的理解与生成能力极强。

### Windows 原生与安全
- 深度集成 Windows 文件系统，能直接读取、理解复杂的文件夹结构和命名习惯。
- 采用 [[本地虚拟机隔离]] 技术，在安全沙盒中执行文件操作，防止误删文件并保护隐私。

### 技能体系
内置 100+ 针对办公场景精选的 Skills，支持 [[技能组合]]：
- **Office**：一键生成 PPT、构建 Excel 公式、批量生成 Word。
- **开发**：现场编写 Python 脚本处理文件（如将 Word 视为压缩包提取图片）。
- **创作**：生成网页、图片、视频等多模态内容。

## 工作流
Skywork 展示了典型的 [[任务执行范式]]：**感知 -> 规划 -> 行动**。
1. **感知**：扫描文件列表，建立全局索引。
2. **规划**：列出待办清单，分解任务步骤。
3. **行动**：调用工具（如终端、Python 脚本）执行，并实时汇报进度。

## 定价

- **Plus 会员**：$49.99 / 月，提供“无限”额度。

## 竞争优势
相比 [[Claude Cowork]]，Skywork 强调其多模态能力（通过 Gemini）和对 Windows 生态的原生支持，试图通过“双核”实现降维打击。
