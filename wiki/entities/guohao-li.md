# Guohao Li

**Guohao Li** 是一位拥有 KAUST 和牛津大学背景的华人学者与创业者，[[camel-ai]] 框架的创始人，以及全栈本地 Agent 系统 [[eigent]] 的开发者。

## 职业背景
- 曾在 Intel 和 Kumo AI 等知名机构深耕。
- 长期致力于 [[分布式多智能体]] 系统的研究与工程化落地。

## 主要贡献
- **Camel AI**：开发了知名的 AI 智能体框架。
- **Eigent**：基于 Camel AI 构建了分布式多智能体系统，并集成了 [[seta-scaling-environments-for-terminal-agents]] 项目，实现了 Agent 对终端的直接控制。
- **开源运动**：在 [[anthropic]] 发布 [[claude-cowork]] 导致其商业化计划受挫后，决定将 Eigent 以 Apache 2.0 协议彻底开源，喊出 "I don't care" 的口号。

## 行业影响
- 其开源行为引发了 AI 社区（包括 [[thomas-wolf]] 和 [[andrej-karpathy]]）的热烈反响。
- 被视为 [[代码朋克]] 精神的代表人物，强调从第一性原理出发构建底层基础设施，而非简单的 API 封装。
