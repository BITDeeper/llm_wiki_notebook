# OpenHands

**OpenHands** 是一个用于承载代码 Agent 实验的基础框架。在 [[beyondswe]] 和 [[searchswe]] 的评测研究中，OpenHands 被用作运行环境，支持 Gemini 3 Pro、GPT-5.2、DeepSeek-V3.2 等多种前沿模型的接入与测试。

## 特点
- 提供标准化的 Agent 执行环境。
- 支持工具扩展（如 SearchSWE 中的 SearchTool 和 BrowserTool）。
- 能够处理复杂的软件工程任务，包括代码修改、依赖管理和系统构建。
