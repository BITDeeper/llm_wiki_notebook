# 豆包手机

豆包手机是字节跳动推出的 AI 原生手机（或操作系统级助手），具备跨应用自动化操作能力。它被海外创业大佬 Taylor Ogan 评价为「世界上第一款真正的智能手机」，被视为 GUI Agent 落地的标杆产品。

## 核心特性

### 影子系统
豆包手机并非仅仅是一个 App，而是在 Android Framework 层构建的一套 OS 级虚拟化环境。它允许 Agent 在后台的「逻辑屏」上运行，与用户前台的「物理屏」并行。这种架构解决了 Agent 抢占前台导致手机卡死的问题，实现了真正的多任务并行（例如一边打电话一边让 Agent 比价）。

### 双栈模式
为了平衡速度与准确性，豆包手机采用了两套处理模式：
- **System 1（标准模式）**：依赖直觉和浅层 VLM，追求速度（体感延迟小于 500ms）。
- **System 2（Pro 模式）**：依赖深度推理和工具调用，追求鲁棒性和复杂任务处理。

### 混合感知路由
系统能够动态选择数据获取路径：
- 对于标准 UI（如安卓原生控件），通过 XML 无障碍树获取信息。
- 对于非标 UI（如游戏、OpenGL 渲染的地图），通过视觉路线（截图+VLM）进行像素级识别。

### 隐私保护：任务层级过滤
针对用户对隐私的担忧，豆包手机采用了基于安卓 Activity 层级的视觉隔离机制。Agent 仅抓取当前任务相关的应用界面，物理隔离了画中画、安全键盘等隐私区域。测试表明，Agent 无法截取到悬浮窗内容，证明了其并非简单的「全天候录屏」。

### 韧性
Agent 具备面对错误时的动态调整能力。例如，当邮件 App 闪退时，Agent 不会直接报错，而是降级读取列表页的预览信息以完成任务。这体现了其规划器关注的是「任务目标」而非死板的操作序列。

## 技术基础
豆包手机的核心能力来源于字节跳动开源的 [[UI-TARS]] 模型。据分析，其可能使用了 Doubao-1.5-UI-TARS 的蒸馏版（标准模式）和完整版（Pro 模式）。

## 行业评价
- **Taylor Ogan**：称其为「DeepSeek 时刻」，是第一款真正的智能手机。
- **六分超超 / 电丸科技AK**：实测后赞叹其速度与能力，称其为「今年印象最深的产品」。
- **Tiezhen Wang (Hugging Face)**：认为它证明了手机使用可以成为 OS 级原生能力，将定义下一代 AI 手机。
