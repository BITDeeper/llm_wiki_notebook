# Command A+

Command A+ 是 [[cohere]] 于 2026 年 5 月 20 日发布的旗舰大模型，也是 Command A 家族的最后一个模型。它是 Cohere 的第一个 [[moe-混合专家架构]] 模型，也是首个采用 [[apache-2-0-开源许可]] 的完全开源旗舰。

## 架构规格

| 指标 | 数值 |
|------|------|
| 总参数 | 2180 亿（218B） |
| 激活参数 | 250 亿（25B） |
| 架构 | MoE（混合专家） |
| 上下文长度 | 128K |
| 支持语言 | 48 种 |
| 多模态 | 原生支持文本和图像 |
| 最低部署配置 | 1 张 NVIDIA B200 或 2 张 H100 |

## 量化方案

提供三种版本：
- **BF16**：全精度基线
- **FP8**：中等压缩
- **W4A4**：权重 4-bit、激活 4-bit 的极端压缩方案，仅对 MoE 专家做 4-bit 压缩，注意力通路保留全精度

W4A4 版本通过 [[量化感知蒸馏]] 技术实现"接近无损"压缩，低并发下达 375 tok/s，首 token 延迟 113ms。较前代 Command A Reasoning 速度提升 63%，延迟降低 17%。

## 核心功能

### 原生引用
[[原生引用]] 是 Command A+ 的标志性能力。模型在生成答案时自动嵌入溯源标记（grounding spans），将每条事实声明链接到具体文档或数据库记录，直接服务于金融、医疗、法律等强监管行业。

### 智能体工具调用
支持标准 chat template 下的对话式工具调用，可无缝对接内部 API、搜索引擎或 SQL 数据库。

### 多语言优化
新分词器降低非欧洲语言 token 消耗：阿拉伯语少 20%，日语少 18%，韩语少 16%。

## 第三方评价

据 VentureBeat 报道，Command A+ 以 250 亿激活参数的体量，在纯推理和数学上可媲美体量大出许多的模型；但在深度智能体编码和综合智能的广度上，仍落后于 [[DeepSeek V4]] 等中国头部开源模型。

## 许可证演进

Command A+ 标志着 Cohere 许可证从限制性走向完全开放的关键转折：
- Command R / R+：CC-BY-NC 4.0（禁止商用）
- Command A+：Apache 2.0（完全开放商用）
