# Brian Roemmele

**Brian Roemmele** 是一名开发者和创业者，因创建首个“[[零员工公司]]”而受到关注。

## 零员工公司实验

Roemmele 利用 [[clawdbot]] 和 [[claude-code]] 组建了一家完全由 AI 运营的公司：
- **CEO**：由 Clawdbot 调用的 [[Grok]] 模型担任。
- **CTO/首席工程师**：由 Claude Code 担任。

他认为 [[clawdbot]] 是零员工公司的基石，因为它具备持久的自主性、支持多智能体系统克隆，并保证了本地控制与隐私。这一实验被视为 AI 从辅助工具转向独立执行者的重要里程碑。
