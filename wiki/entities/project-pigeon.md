# Project Pigeon

## 概述
[[project-pigeon]]（鸽子计划）是二战期间美国心理学家 B.F. Skinner 提出的一项秘密军事项目，旨在利用鸽子来引导导弹击中目标。

## 技术原理
该计划在导弹的鼻锥内放置经过训练的鸽子，通过光学系统让鸽子看到目标画面。鸽子会啄击屏幕上的目标图像，这种啄击动作被转化为信号用于调整导弹的飞行轨迹。

## 历史意义
虽然该项目最终未被实战部署，但它是早期尝试将生物体与武器系统结合的典型案例。这种利用生物本能进行制导的思路，与后来的 [[darpa]] [[hi-mems]] 项目及现代 [[swarm-biotactics]] 的 [[赛博格昆虫]] 技术一脉相承。
