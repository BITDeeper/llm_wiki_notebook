# MMDesign

MMDesign是[[分子之心]]开发的AI生物药从头设计平台，于2026年6月4日正式对外发布。该平台标志着[[蛋白质从头设计]]从概念验证走向产业化应用的关键转折。

## 技术架构

MMDesign采用[[生成-过滤策略]]：

1. **生成阶段**：用户输入目标蛋白和指定的表位残基，平台通过自研蛋白质基础大模型和[[mmfold|MMFold]]结构预测模型协同优化，一次性生成数万个候选分子
2. **过滤阶段**：经结构可靠性、序列自然性、基于物理的界面评估等多层智能评估体系，将候选池极限压缩至每个靶点仅数十个分子进入湿实验验证

## 核心性能数据

| 指标 | 数据 |
|------|------|
| 靶点结合成功率 | 超90%（12个靶点中11个确认特异性结合） |
| 每靶点湿实验分子数 | 14-50个 |
| PD-L1命中率 | 86.7% |
| PD-L1最优亲和力 | 7.2nM |
| TNFα命中率 | 50%（仅14个分子） |
| TNFα最高亲和力 | 51pM |
| GPCR特异性结合率 | 22/29（76%） |

## 技术亮点

- **攻克高难度靶点**：成功突破TNFα（浅层三聚体）和[[gpcr|GPCR]]（高难度跨膜蛋白）等业界公认难靶点
- **[[成药性前置优化]]**：在设计极早期即将可溶性、不易聚沉等成药性特征作为内在优化目标
- **源头新颖性**：输出的高活性分子展现出全新结合构象空间，构筑专利护城河
