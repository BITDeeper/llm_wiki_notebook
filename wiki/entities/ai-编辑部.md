# AI 编辑部

[[AI 编辑部]] 是一个基于 [[arkclaw]] 和 [[飞书]] 搭建的 [[多智能体协作]] 系统案例。它模拟了传统媒体编辑部的运作流程，通过 6 个具有特定角色和技能边界的 AI 智能体，实现了从选题策划到内容发布的全自动化生产。

## 角色架构
该系统包含以下 6 个核心角色，每个角色都有严格的 [[角色隔离]] 规则：

1.  **总编虾**
    *   **职责**：分析选题需求，设计文章提纲。
    *   **技能**：`feishu-bitable`（读写看板）。
    *   **产出**：包含核心立意、受众画像、章节结构的提纲。

2.  **记者虾**
    *   **职责**：根据提纲搜集权威资料。
    *   **技能**：`web-search`, `feishu-bitable`。
    *   **产出**：标注来源的素材包。

3.  **编辑虾**
    *   **职责**：基于提纲和资料撰写初稿。
    *   **技能**：`feishu-docs`, `feishu-bitable`。
    *   **产出**：飞书文档形式的初稿。

4.  **校对虾**
    *   **职责**：校对错别字、语法及事实准确性。
    *   **技能**：`feishu-docs`, `grammar-check`, `fact-check`。
    *   **产出**：修改后的终稿。

5.  **排版虾**
    *   **职责**：进行文档美化、配图和格式优化。
    *   **技能**：`feishu-docs`, `image-search`, `feishu-bitable`。
    *   **产出**：排版精美的文档。

6.  **运营虾**
    *   **职责**：生成标题、导出 Markdown、准备发布。
    *   **技能**：`feishu-docs`, `markdown-export`, `feishu-bitable`。
    *   **产出**：发布指引和最终内容包。

## 工作流机制
- **进度看板**：利用 [[飞书]] 多维表格建立实时进度追踪系统，每个 Agent 完成任务后自动更新状态，实现了 [[场景白盒化推理]]。
- **可视化界面**：开发了模拟办公室场景的网页 UI，Agent 被拟人化为在工位工作的“虾”，直观展示工作状态。
- **全自动总控**：通过一个总控 Prompt 串联所有角色，无需人工干预即可自动流转。

## 技术亮点
- **Prompt 工程**：每个角色的 Prompt 都包含了明确的“硬性规则”和“技能限制”，有效防止了幻觉和越权行为。
- **工具编排**：展示了如何组合调用搜索、文档读写、图片搜索等 API 来完成复杂任务。
