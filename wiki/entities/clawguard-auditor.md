# ClawGuard Auditor

[[ClawGuard Auditor]] 是由 [[北京航空航天大学]] 复杂关键软件环境全国重点实验室智能安全创新团队开发的开源安全防御工具，专门用于保障 [[OpenClaw]] 智能体的运行安全。

## 核心特性

该工具锚定于系统最高特权层运行，作为一个底层安全守护进程，对所有外部指令、提示词及技能插件拥有最高否决权。其设计旨在解决 AI 智能体因拥有过高系统权限（如文件管理、邮件操作）而带来的安全风险。

## 技术架构

ClawGuard Auditor 采用了 [[动静结合-三位一体防御]] 架构：

1.  **静态应用安全测试（SAST）审查器**：
    *   **阶段**：运行前。
    *   **机制**：在技能加载前介入，利用词法分析和行为建模技术，精准识别并拦截包含恶意逻辑的代码包。

2.  **主动安全内核**：
    *   **阶段**：运行时。
    *   **机制**：实现透明监管，一旦检测到智能体行为触及敏感操作（如修改系统配置），立即接管执行流并阻断未经授权的调用。

3.  **主动数据防泄漏引擎**：
    *   **阶段**：全程。
    *   **机制**：持续监控内存状态与网络出口数据，严格防止 API Keys 等敏感资产外泄。

## 防御公理

系统的运行基于四大不可被篡改的防御公理：

1.  **绝对覆盖与零信任原则**：默认将所有外部代码（Skill/插件）视为具有敌意，任何机制都无法绕过或修改 Auditor 的规则。
2.  **语义意图匹配机制**：不仅分析代码本身，还深入评估代码的实际行为与其声明意图是否一致，防止“披着合法外衣执行非法行为”。
3.  **能力令牌模型与限制特权机制**：严格强制执行最小权限原则。采用 [[能力令牌模型]]，令牌随用随发，任务结束后自动撤销。
4.  **数据主权与数字资产隔离原则**：将守护本地资产不受侵犯作为最高准则。

## 开源与获取

该工具已开源，托管于 GitHub，用户可快速部署以增强 OpenClaw 智能体的本地安全性。
