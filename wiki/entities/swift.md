# SWIFT

**SWIFT** (Simple Weighted Intrinsic Feedback Technique) 是一种由上海交通大学、新加坡国立大学等高校联合提出的轻量级奖励模型框架。它代表了从“外部评判”向“内省评判”的范式转移。

## 核心特性
- **极低参数量**：参数规模仅为传统文本级奖励模型的不到 0.005%（约 $10^5$ 量级）。
- **高效推理**：在 [[Best-of-N]] 场景下，端到端推理速度提升 1.7×–6.7×。
- **内部信号利用**：直接利用底座模型的[[隐藏状态]]进行打分，无需对输出文本进行重编码。

## 技术架构
SWIFT 的架构设计极其简洁，主要包含以下组件：
1. **状态收集**：收集生成序列中每个 Token 在模型选定层处的[[隐藏状态]]。
2. **线性映射**：通过线性层同时预测每个 Token 的“奖励分数”和“重要性门控权重”。
3. **加权汇总**：使用[[门控加权汇总]]机制计算最终序列分数，自动聚焦于关键推理步骤。

## 性能表现
在多个基准测试中，SWIFT 在 Best-of-N 设置下的表现优于主流开源奖励模型：
- **数学推理**：MATH, GSM8K, AQuA-RAT
- **代码理解**：Imbue Code Comprehension
- **常识推理**：HellaSwag, CoinFlip
- **安全对齐**：PKU-SafeRLHF（有用性与安全性评估）

## 工程优势
- **部分层训练**：实验表明，仅使用靠近输出的后层隐藏状态即可获得接近全层训练的性能，进一步降低了计算开销。
- **Logits 降级方案**：在无法访问隐藏状态的闭源模型场景下，可仅基于输出分布进行训练，尽管效果可能略有折扣。
- **即插即用**：由于参数量极小，可作为现有奖励模型的补充模块，通过加权融合进一步提升系统性能。

## 应用场景
SWIFT 特别适用于计算资源受限或对推理延迟敏感的场景，例如：
- 大规模 [[Best-of-N]] 推理系统
- 实时 [[Agent]] 决策循环
- 本地部署的 AI 应用
