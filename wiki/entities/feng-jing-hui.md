# 冯景辉

冯景辉现任百度安全副总经理。

## 观点与贡献
在 2026 年百度 AIDay 上，他分享了百度关于 [[openclaw]]（龙虾）安全机制的见解，提出了构建安全生态的四个关键要素：
1. **环境隔离**：确保运行环境的安全边界。
2. **技能管控**：对智能体调用的工具进行管理。
3. **权限控制**：限制 Agent 仅访问最小必要数据。
4. **记忆管理**：保障用户数据主权。

他强调，只有让用户永远是数据的主人，让能力可审计、权限可控制，才能形成繁荣安全的龙虾生态。
