# MiniMax

MiniMax 是一家中国人工智能独角兽公司，由 [[闫俊杰]]（[[yan-junjie]]）创立，专注于大语言模型、多模态内容及 Agent 应用生态的开发。公司成立于 2022 年左右，以"全模态"技术战略和极致的工程效率著称，并于 2026 年 1 月在港交所上市（股票代码：0100），首日股价大涨 80%。公司核心理念为"Intelligence With Everyone"——追求所有人都能用得起的 AGI。

作为中国大模型赛道的重要玩家和全球首家披露详细年报的大模型企业，MiniMax 正从大模型研发向 AI 时代的平台型公司（[[ai-platform-company]]）转型。公司创立之初即构想"下一代 AI"——通过图灵测试的智能体，能在多场景创造极致客户体验。上市之初 C 端业务占比较高，目前已发展为 B 端和 C 端并重。

## 核心战略：Model + Harness（产模一体）

MiniMax 坚持"大模型和应用并重、ToC 和 ToB 双轮驱动"的战略，认为 AI 行业的竞争维度已从单纯的模型参数比拼转向"智能密度"与工程落地能力的结合。创始人 [[闫俊杰]] 提出了价值公式：

`AI平台价值 = 智能密度 × Token吞吐量`

这一战略体现为"产模一体"的闭环：
1. **模型为 Harness 而生**：优化工具调用、长上下文一致性和 Skills 遵循率。
2. **Harness 反哺模型**：通过产品层收集的真实场景数据反馈训练模型。
3. **降本增效**：通过同时运营底层模型和规模化应用，实现了研发效率的提升（研发增速 33.8% < 收入增速 158.9%）和获客成本的降低（销售费用下降 40.3%）。

### 2026 战略愿景
MiniMax 预判 2026 年将出现三大 [[super-pmf]]（编程、办公、多模态），并据此提出从"大模型公司"向"AI 平台型公司"转型的战略。

## 全模态技术布局

MiniMax 坚持文本、语音、视频、音乐四线并进的 [[全模态]] 战略，实现了底层架构 80% 的资源复用。

### 文本与代码模型
- **M2.5**：2026 年 2 月发布的开源大模型，以高性价比和强大的 Agent 能力引发行业关注。
    - **市场表现**：发布后公司市值一度暴涨至 2108 亿港元。在 [[openclaw]] 平台上深受"养虾人"喜爱，调用量稳居前三，并在 2026 年 2 月第三周一度超越谷歌登顶全球榜首。
    - **技术特性**：在 10K-100K 和 100K-1M tokens 的长文本任务中成为更多用户的首选；在编程任务（代码生成、调试）中排名全球前三；在英文语境下的调用量也包揽全球前三。
    - **评测数据**：在 [[pinchbench]] 榜单中，M2.1 得分超过 79%（成功率位居前列），但 M2.1 和 M2.5 在响应速度上排名较后（第 23 和 26 名）。
    - 详见 [[minimax-m2-5]]。
- **M2.7**：2026 年 3 月发布的编程与 Agent 专用模型，也是首个在训练过程中深度参与自我迭代的商用大模型，当前主力大语言模型。
    - **技术特性**：具备原生多智能体协作能力，被称为"最佳 Cowork Agent 模型"。在复杂 Skills 遵循测试中达到 97% 的准确率，并在 PinchBench 榜单上位列全球第四。
    - **研发范式**：通过 [[Agent Harness]] 系统，M2.7 直接参与到研发流程中，承担了 30%-50% 的工作流，并实现了超过 100 轮的自主迭代优化。
    - 详见 [[m2-7]]。
- **M2-5**：最新 MoE 架构模型，以 100 token/秒 的速度和极低的推理成本（同级模型的 5%-10%）著称。该模型已部署在 Google Vertex AI、Microsoft Azure AI Foundry 等国际头部云平台。
- **M2-her**：专为长程对话优化的模型，支撑 [[星野]] 和 [[talkie]] 等全球化互动产品。
- **M3**：下一代模型，预计与 Agent Team 一起开源。

> 以上文本模型统称 [[m2系列]]（MiniMax2.5/2.7），特点是 Agent 任务闭环率高、响应速度快、性价比高。

### 多模态模型
- **[[hailuo-02]] (海螺)**：视频模型，在 AA 视频竞技场排名全球第二。光影效果达到影视级，支持中国风漫剧、真人纪录片等多种风格。
- **Speech 02**：语音模型，综合性能位列全球第一。拟人化、情绪化、多语言、低延时，最大特色为真人声音拟人化。
- **MiniMax Music 2.5**：2026 年 1 月发布的 AI 音乐生成模型，标志着公司在多模态领域的重大突破。音色和真实感大幅增强。
    - **技术特性**：以"格莱美级"音质和强大的中文演唱能力著称，支持 14 种以上的结构标签控制。
    - **市场地位**：被视为补齐 MiniMax 多模态生态的关键拼图，在中文处理能力上展现出显著优势，被拿来与 [[Suno]] 和 [[Udio]] 等国际领先产品进行对比。
    - 详见 [[minimax-music-2-5]]。

## 应用与基础设施

### Mavis（MiniMax as a Jarvis）
[[mavis-minimax]] 是 MiniMax 推出的多 Agent 协作产品，采用 Leader/Worker/Verifier 三角色架构，底层由 [[team-engine]] 状态机驱动。其设计理念包括：
- **实用优先**：正视多 Agent 成本更高的事实，通过 [[team-engine]] 工程框架把控 ROI。
- **Agent 与人类同权**：用户和 Agent 使用同一套操作协议（prompt/spawn/abort/kill），操作可审计追溯。
- **按需调度**：判断何时需要 Agent Team、何时单 Agent 足够，避免无意义的 token 浪费。

### MaxHermes
基于开源项目 [[hermes-agent]] 构建的云端 AI 智能体产品。其核心特性是"学习闭环"，能够自动从任务中提炼可复用的 Skills 并持续迭代。详见 [[maxhermes]]。

### MaxClaw
基于 [[openclaw]] 架构的云端 AI 助手，旨在解决本地部署门槛高和稳定性问题。它打通了"实践-总结Skills-激励分享"的链路，预置了专家级 Skills（拥有超过一万个社区"专家"技能），并支持多子代理并行运行。详见 [[maxclaw]]。

#### MaxClaw 平台特性
- **低代码/无代码创建**：用户无需编写代码，仅通过自然语言描述工作流和知识库（SOP），即可封装成专属智能体。
- **真·一键配置**：平台推出的 OpenClaw 部署模式，号称"真·一键配置"，预置了多种工具和技能，支持快速接入飞书、钉钉等办公软件。
- **Expert 社区**：托管了超过 10,000 个垂直领域的专家智能体（[[expert-智能体]]），涵盖技术、创意、金融等多个方向。
- **代码执行与调试**：实测显示，其平台上的智能体具备编写 Python 代码、调用 FFmpeg 等工具，并在报错时进行自我修正的能力。
- **商业模式**：用户分享的智能体被他人使用可获得积分；平台规划推出 Marketplace，允许用户对高质量的智能体进行挂牌定价。

### Forge
内部设计的异步原生 Agent RL 系统，将模型训练速度提升了 40 倍。该框架是团队提出的原生 Agent RL 框架，用于优化模型在智能体场景下的表现。

### 云厂商合作
为了支撑云端 Agent 的大规模运行，MiniMax 与云厂商深度合作：
- **腾讯云**：在训练侧合作，利用其 Agent Runtime 沙箱搭建 Forge 强化学习框架。
- **阿里云**：在部署侧合作，基于 ACK/ACS 构建云端架构，提供高并发沙箱能力。

## 商业模式

MiniMax 采用 **C端 + B端** 双轮驱动模式，并将 TokenPlan 和 Agent Plan 合并为一份订阅，CLI、API、Agent 全打通，M2.7、音乐、视频、语音所有模型均包含在内。Credits 额度在 Agent 和 API 之间共享。

- **C端**：通过 [[海螺AI]]、星野等 AI 原生应用获取订阅收入，占比 67.2%，覆盖全球 2.36 亿用户。
- **B端**：通过开放平台提供 API 和 Token 计费服务，占比 32.8%，但增速高达 197.8%，显示企业需求爆发。

## 内部 AI 实践（Dogfooding）

MiniMax 作为 AI 公司自身的 [[ai-native组织]] 实践具有标杆意义：

- **2024年9月**：全员不限 Token 使用 Cursor。
- **2025年8月**：启动 Agent 项目，10 月推广 Agent 实习生计划。
- **研发效率提升 30%**：30%-50% 代码由模型自动生成。
- **[[dogfooding闭环]]**：通过内部使用形成场景发现与效果优化的反馈循环。
- **[[模型帮助harness迭代]]**：内部实践发现模型能够反过来帮助工具框架迭代，挑战了模型与工具的简单分工假设。

## 组织架构：AI-Native 组织

MiniMax 是典型的 [[ai-native-组织]]，以极高的资本效率和工程效率著称。
- **资本效率**：累计花费约 5 亿美元（仅为 OpenAI 同期开销的 1%）便实现了全模态技术的全球领先。
- **极度扁平**：CEO 之下不超过 3 层职级。
- **高人效**：全员 385 人（平均年龄 29 岁），支撑数亿用户；内部 80% 代码由 AI 生成。
- **年轻化**：董事平均年龄 32 岁，由创始人 [[闫俊杰]]（36 岁）带领。

## 行业地位与生态合作

MiniMax 是 [[OpenClaw]] 生态的核心玩家之一，为该开源项目提供底层大模型算力支持。其模型能力获得了全球开源社区的广泛认可：
- [[hermes-agent]] 和 [[openclaw]] 等头部开源项目将其作为默认模型。
- Notion Custom Agents 和 Kilo Code 等知名应用也集成了 MiniMax 模型。
- Hermes Agent 业务负责人 Tommy Eastman 公开表示"中国在开源模型方面已经领先了"。
- 在英伟达 GTC 大会期间，英伟达联合 OpenClaw 核心作者推出了 [[nemo-claw]]，进一步巩固了这一生态的合作关系。
- 在 OpenRouter 上日 Token 消耗量超过 500 亿，是首个达到此里程碑的中国模型。
