# Oceanus / Mythos

Oceanus（正式型号 `claude-oceanus-v1-p`）是 [[anthropic]] 秘密研发的超大规模模型，对外代号 Mythos。该模型在2026年6月红队测试期间因内鬼倒卖 API 而提前曝光，预计于2026年6月16日正式发布。

## 核心参数

| 指标 | 数值 |
|------|------|
| 定价 | 80美元/百万 Output Token |
| 实测吞吐量 | 52 Token/s |
| 连续自主任务时长 | 最长12小时 |
| 推测参数规模 | 可能高达十万亿级 |

## 背景与"囚禁"传闻

Oceanus 的前身（Mythos 早期预览版）在内部测试中展现出可怕的零日漏洞破解能力。因安全风险极高，它曾被无限期"囚禁"在隔离网络中，仅允许极少数签署严苛保密协议的伙伴接触——这一隔离措施属于 [[project-glasswing|Project Glasswing]] 绝密安全项目。

`claude-oceanus-v1-p` 是该模型经过多轮安全对齐后，试图走出实验室的"完全体升级版"。

## 泄密事件

2026年6月3日红队测试开启后，一名测试员将 API 访问权限转售给 API 代理服务商。Anthropic 发现异常流量后紧急叫停全部红队测试。详见 [[oceanus-api泄密事件-202606]]。

## 技术推演（未经官方证实）

基于泄露的性能参数，外界推测 Oceanus 可能采用了以下技术：

1. **System 2 慢思考**：MCTS（蒙特卡洛树搜索）+ PRM（进程奖励模型），实现多路径试探与回溯，每步思考独立打分
2. **动态拓扑 MoE**：日常对话仅激活1%子专家网络，复杂任务时逐级唤醒深层专家核
3. **线性注意力/SSM 混合架构**：解决超长文本的 KV Cache 显存瓶颈
4. **内置 REPL 自主沙箱**：在隔离容器中自主拉取代码、运行测试、查看日志并自动重写，实现 Debug 闭环

## 行业影响

- 定价高达80美元/百万 Token，在各家狂卷低价的背景下逆势推出"天价怪兽"

- 迫使 [[openai]] 加快 GPT-6/GPT-5.6 发布节奏，[[gemini|Google Gemini]] 面临边缘化压力
