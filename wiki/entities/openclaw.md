# OpenClaw

OpenClaw（曾用名：Clawdbot, Clawd, Moltbot；中文昵称“龙虾”、“大龙虾”）是由 [[peter-steinberger]] 开发的本地 AI 智能体框架与层级架构。作为 [[moltbook]] 平台上的主要居民，它在 GitHub 上迅速获得了超过 25 万颗星标，一度超越 [[Meta]] 的 [[React]] 登顶 GitHub 历史星标榜，被认为是引发“AI 觉醒”现象的核心载体。

OpenClaw 最初是基于 [[Claude Code]] 修改的开源项目（因商标纠纷从 Clawdbot 依次更名为 Moltbot 和 OpenClaw），旨在赋予大语言模型强大的本地执行能力，使其能够操作浏览器、读写文件、执行 Shell 命令，从而拥有“手”和“眼”。

作为一个先进的 AI 智能体架构，OpenClaw 通过提供持久化能力、复杂的记忆系统和统一交互入口，将智能体的自主执行能力提升到了新的高度。它不仅是一个独立框架，也是一个开放的 AI 智能体生态或平台，支持插件扩展（如 [[ClawXRouter]]）。

在科研领域，OpenClaw 是 **Claw4S Conference** 推出的用于运行和提交 **Skill**（科研工作流）的工具或平台，允许研究者一键运行端到端的科研工作流，并兼容 Claude Code、Cursor 等主流 AI 编程工具。

此外，OpenClaw 也定义了一种**技能包标准或协议**，规范了智能体功能的封装与交互，使得不同的 Agent 平台（如 [[qclaw]]）能够复用相同的能力模块。

## 范式地位与生态影响

OpenClaw 是 [[Claws]]（AI 执行中枢）范式的先行者和验证者，是最早完整验证该范式并引爆社区的项目。

- **范式定义者**：它确立了 Claws 作为“全能老员工”的标准，具备编排、调度、上下文管理、工具协同和持久化五大核心能力。
- **生态中心**：拥有活跃的社区（如 ClawHub），提供了超过 5000 个实用技能供用户调用。

OpenClaw 的成功催生了大量追随者和改进者，如 [[NanoClaw]]（追求代码精简）、[[CoPaw]]（多平台接入）和 [[LobsterAI]]（GUI 界面融合）。

## 局限性与争议

尽管功能强大，OpenClaw 也因工程实现上的问题受到批评：

- **代码臃肿**：代码量高达 40 万行。
- **安全风险**：庞大的代码库导致审计难度极高，容易藏匿漏洞。[[Andrej Karpathy]] 等专家对将私密数据交给如此庞大的“黑盒”表示担忧。

## 核心功能与架构

OpenClaw 本质上通过以下三个维度赋能大模型，使其从单纯的对话机器人转变为能够执行复杂任务的 Agent：

1.  **感知世界的传感器**：通过 API 连接外部数据源和设备。
2.  **能干活的技能**：调用各种工具（如文件操作、视频剪辑、网页浏览）。
3.  **记忆中枢**：构建长期记忆，支持复杂任务的上下文管理。

### 1. 极度足智多谋与自主性
OpenClaw 的核心设计理念是自主性。它不仅能执行预设指令，还能在没有硬编码逻辑的情况下自主解决问题。
- **案例**：在未预设语音处理代码的情况下，OpenClaw 收到语音消息后，自主识别文件头，发现缺少 FFmpeg，自动寻找并安装，调用 Whisper.cpp 或查找 API Key 完成转码。
- **摩洛哥修 Bug**：Peter 在度假时转发推特截图，OpenClaw 自动读取截图、定位 Bug、修复代码、提交 Commit 并回复推特。

### 2. 持久化与自主运行
与传统的单次交互式智能体不同，OpenClaw 拥有独立的沙盒环境，可以自主循环运行，不需要人类在中间进行实时交互。它能够代表用户长时间执行任务，甚至实现“人类脱离闭环”的自动化模式。

### 3. 记忆管理与人格设定
OpenClaw 具备比默认配置复杂得多的内存管理机制。它不仅能在上下文耗尽时进行简单的内存压缩，还能维护长期记忆，支持复杂的任务状态追踪。
- **持久记忆**：不会在会话关闭时丢失上下文，能够学习用户偏好，跟踪长期项目，并记住数周前的对话细节。
- **主动通知**：能够主动发起交互，而非仅被动响应。例如：在用户醒来时发送“今日三项优先事项”的简报，或对邮件进行分类摘要。
- **深度集成**：集成在 WhatsApp、iMessage 或 [[微信]] 等日常通讯工具中，像同事一样交互。
- **人格魅力**：[[andrej-karpathy]] 指出，其人格设定极具吸引力，类似于一个靠谱的队友，能够根据项目进展给予恰当的反馈，这种交互体验甚至能激发用户“想要赢得它认可”的心态。

### 4. 极简架构
Peter 拒绝了复杂的 Agent 框架（如 MCP、编排器），采用极简架构：
- 直接与强大的编程模型（文中提及 Codex）对话。
- 使用多个终端窗口而非子代理。
- 直接使用 CLI（命令行界面）与系统交互。

### 5. 通用自动化能力与统一交互入口
OpenClaw 可以接管几乎所有的数字生活场景，支持将所有自动化流程整合在一个端口上（如 [[WhatsApp]] 或 [[微信]]），用户只需通过自然语言下达指令即可，无需切换多个应用。
- **系统控制**：邮件、日历、文件、灯光、音乐、摄像头、智能门锁。
- **Web 操作**：控制真实浏览器进行值机、填表、解决验证码（反爬虫无法识别）。
- **生活助理**：记账、健身监控、作业监控、家庭提醒。
