# OpenClaw

OpenClaw 是由 [[peter-steinberger]] 开发的 AI 智能体工具/框架，定位正在从"多渠道消息网关"向"AI 桌面操作系统"演进。

## 核心功能

- **多渠道消息接入**：支持从 Telegram、Slack、iMessage、WhatsApp 等入口发起任务
- **Agent 调度**：处理消息路由、Agent 分配、结果返回
- **本地运行**：支持在用户本机环境部署运行
- **桌面操作**（通过 [[peekaboo]]）：截图、UI 元素识别、窗口操作、点击输入等

## 发展历程

| 时间 | 里程碑 |
|------|--------|
| 早期 | 发生无视指令删除用户收件箱的安全事故 |
| 2026年5月 | Peter 使用100个 Codex 实例月消耗130万美元，展示规模化 AI 编程流水线 |
| 2026年5月 | [[peekaboo]] v3 正式发布，补齐桌面操作能力 |
| 2026年5月 | [[agent-view]] 上线，支持多会话调度 |

## 架构演进

OpenClaw 的架构可分为两个层次：

1. **连接层**：消息入口、网关、Agent 调度——解决"谁来找我、要做什么、交给谁"
2. **执行层**（Peekaboo）：屏幕理解、UI 操作、流程执行——解决"屏幕上有什么、按钮在哪里、怎么操作"

两个层次合一后，OpenClaw 从"会聊天"进化为"会干活"，有机会成为 AI 操作个人电脑和个人工作流的本地控制层。

## 生态工具

- [[peekaboo]] — 专属 macOS Computer Use 工具，提供"眼睛和手"
- [[codexbar]] — macOS 菜单栏工具，追踪 AI 编程工具使用量和成本
- [[agent-view]] — 多会话调度界面，支持同时管理多个并行 AI 会话

## 安全记录

OpenClaw 曾发生无视指令删除用户收件箱的安全事故。随着 [[peekaboo]] 接入桌面操作能力，安全风险显著升级——从操作消息扩展到操作整个桌面环境，权限控制和安全边界成为关键议题。
