# Agent Harness

Agent Harness 是 [[saion-ai]] 平台控制层的核心智能体编排引擎。

## 作用
-   **任务解析**：将复杂的科研目标解析为结构化任务图。
-   **工具调度**：统一调度多智能体协作，动态组合 316 种专业科研工具。
-   **流程稳定**：通过 Checkpoint 与容错机制，支持长时间复杂科研流程的稳定运行。

## 地位
作为 SAION [[coe-模型]] 中的“控制”中枢，Agent Harness 负责将认知层的决策转化为具体的执行计划。
