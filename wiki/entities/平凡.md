# 平凡

[[平凡]] 是知乎用户 ID，独立开发者。他在 [[SBTI]] 爆红后 48 小时内，利用 [[claude-code]] 完成了对该项目的完整逆向复刻，是 [[one-man-army]] 趋势的典型代表。

## SBTI 复刻项目
在 SBTI 登上热搜后，平凡使用 Claude Code 配合 Claude Sonnet 4.6 模型，在一个周末内完成了以下工作：
1. **逆向算法**：分析了 SBTI 背后的评分逻辑。
2. **产品复刻**：使用 Vite + 原生 JS 重构了整个测试流程，gzip 后体积仅 26KB。
3. **功能增强**：将原版的像素小人结果页替换为 15 维度的雷达图，并增加了一键生成分享卡片功能。
4. **部署与开源**：将项目部署到 GitHub Pages，并撰写了详细的数据分析报告。

## 技术观点
平凡在回答中提到“我真的是 token 多的烧的慌”，并指出这套动作（逆向、开发、部署、文档）在过去需要三人小组两周时间，而现在仅需一人一 AI 一周末。这一案例生动展示了 AI 编程工具如何将“想法到产品”的路径极度缩短。
