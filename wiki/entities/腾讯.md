# 腾讯

[[腾讯]]（Tencent）是中国领先的互联网增值服务提供商之一，在人工智能领域拥有深厚的研发实力。腾讯不仅推出了 [[混元]] 大模型，还在多模态、计算机视觉、强化学习等细分领域持续创新，并积极布局 AI Agent 生态。

## AI Agent 战略与产品

在 AI Agent 领域，腾讯通过发布「鹅虾」系列产品（[[WorkBuddy]]、[[QClaw]]）积极布局，试图利用其强大的社交生态（微信、QQ）抢占市场。

### 战略特点
腾讯的切入点并非单纯追求模型能力的突破，而是侧重于**生态整合**与**降低门槛**：
- **社交壁垒**：将 AI Agent 接入 QQ、微信、飞书、钉钉等高频软件，利用社交关系链构建护城河。
- **兼容开源**：虽然构建封闭生态，但选择兼容 [[openclaw]] 技能标准，以吸引开发者和现有用户。

### 产品矩阵
1. **[[WorkBuddy]]**：桌面端平台，主打办公场景和多模型支持。
2. **[[QClaw]]**：微信端应用，主打远程操控和社交集成。
3. **[[腾讯云轻量应用服务器]]**：提供云主机一键部署 OpenClaw，面向开发者。

### 行业影响
腾讯的入场标志着 AI Agent 行业从极客圈层向大众圈层的加速渗透。通过「一键安装」和「社交软件集成」，腾讯正在推动 Agent 的普及化，使得竞争焦点从「会不会用」转向「用得好不好」。

## 前沿技术研究

腾讯团队（如叶德珩团队）积极参与前沿学术研究，与高校合作推动技术落地。

### 强化学习与 LLM 结合
- 与 [[南京大学]]团队合作，共同发表了关于利用 LLM 提炼环境常识以提升强化学习样本效率的研究。该研究旨在解决 RL 样本效率难题，让 AI 一次性提炼环境常识，实现后续零调用成本。

### 多模态与视觉技术
腾讯在多模态大模型领域亦有重要贡献，特别是在视觉编码器的训练方法上进行了创新：
- 开源了 [[penguin-vl]] 多模态大语言模型，提出了 [[penguin-encoder]]，探索了从纯文本 LLM 初始化视觉编码器的新路径。
- 在文档理解、图表解析和长视频理解等复杂任务上推动了开源小模型 SOTA 的发展。
