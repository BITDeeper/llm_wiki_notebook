# DiNA 架构

**DiNA** (Discrete Native Autoregressive，离散原生自回归) 是 [[美团-longcat]] 团队提出的一种多模态大模型架构，旨在实现真正的 [[原生理解生成统一]]。

## 核心思想
DiNA 的核心在于将文本、图像、语音等所有模态的数据，统一转化为离散 [[token]] 序列，然后利用标准的自回归语言模型进行建模。这种设计消除了传统多模态模型中“语言模型底座 + 视觉/语音外挂”的拼接式结构，使得所有模态共享同一套参数、注意力机制和损失函数。

## 工作流程
1.  **输入侧**：原始信号（文本、图像、语音）通过各自的 Tokenizer（如 [[dnavit]]）被转化为离散 Token ID。
2.  **中间层**：所有模态的 Token 汇入一个模态无关的学习器。模型不区分 Token 的来源模态，统一进行“预测下一个 Token”的计算。
3.  **输出侧**：生成的 Token 序列通过 De-Tokenizer 还原为图像、音频或文本。

## 技术优势
- **理解与生成协同**：在 DiNA 架构下，理解（看图生文）和生成（看文生图）在数学形式上完全一致，仅仅是输入输出的互换。实验表明，这种统一性使得两者能够互相促进，而非此消彼长。
- **训练稳定与部署轻量**：多模态数据的混合使得梯度信号更稳定；部署时一个模型即可处理多种模态，节省显存并提高速度。
- **模态融合自然**：t-SNE 可视化显示，不同模态的 Token 在空间中自然交融，而非各自孤立，证明模型内部长出了统一的多模态世界。

## 理论支撑
DiNA 架构挑战了“离散视觉建模存在性能天花板”的传统观点。[[美团-longcat]] 团队通过实验证明，只要具备足够的[[语义完备性]]和数据规模，离散建模可以达到与连续建模相当的性能。
