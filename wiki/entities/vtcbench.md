# VTCBench

VTCBench 是由 [[中科院自动化所]] 与中国科学院香港创新研究院等机构推出的首个专门针对 [[视觉文本压缩]]（VTC）范式的基准测试。其核心使命是评估视觉语言模型（VLM）在将文本压缩为图像后，是否依然具备理解高密度信息的能力。

## 测试任务
VTCBench 通过三大维度系统性地评估模型在视觉空间中的认知极限：

1.  **VTC-Retrieval (信息检索)**：
    -   类似于“大海捞针”，测试模型在长图像中精准定位特定事实的能力。
    -   旨在评估模型对空间分布信息的捕捉精度。

2.  **VTC-Reasoning (关联推理)**：
    -   挑战模型在几乎没有文本重叠的情况下，通过跨区域关联寻找事实。
    -   测试模型超越单纯词汇检索的逻辑推理能力。

3.  **VTC-Memory (长期记忆)**：
    -   模拟超长对话场景，评估模型在视觉压缩框架下，抵御时间与结构性信息衰减的能力。

## 衍生版本
- **VTCBench-Wild**：引入了 99 种不同的渲染配置（涵盖多种字体、字号、行高及背景），用于全方位检测模型在复杂现实场景下的鲁棒性。

## 关键发现
VTCBench 的测试结果揭示了 VLM 处理长图像时的核心瓶颈——**[[空间注意力偏见]]**（U 型曲线）：
-   模型能精准捕捉开头和结尾的信息。
-   对中间部分的事实理解能力随文档长度增加而剧烈衰退。

## 行业影响
VTCBench 已在 GitHub 和 Huggingface 开源，并集成至 VLMEvalKit 评估工具中。它证明了虽然 [[Gemini-3-Pro]] 等顶尖模型已展现出接近纯文本基准的视觉理解能力，但整体而言，VLM 在复杂推理和记忆任务上仍弱于纯文本 LLM。
