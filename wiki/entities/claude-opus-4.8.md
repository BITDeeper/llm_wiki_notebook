# Claude Opus 4.8

Claude Opus 4.8 是 [[anthropic]] 旗舰大模型的新版本，于2026年5月23日左右在 Google Vertex AI 后台被开发者发现模型标识 `claude-opus-4.8`。

## 发现经过

开发者 can 最先爆料，在 Google Vertex AI 平台的模型列表中发现了 `claude-opus-4.8` 标识。这一发现延续了 Anthropic 此前的发布规律——Opus 4.6 和 Opus 4.7 都是先在 Vertex AI 后端被提前发现，然后才正式公布。

## 版本演进

- Opus 4.7 于2026年4月发布，击败了 Gemini 3.1 Pro 和 GPT-5.4
- Opus 4.8 距离上一版本仅一个多月，显示 Anthropic 模型迭代速度显著加快
- 预计2026年6月正式发布

## 竞争定位

Opus 4.8 的快速迭代是 Anthropic 三线并进战略的一部分，与 [[claude-sonnet-4.8]] 和 [[mythos-1]] 同步推进，应对 OpenAI GPP-5.6 和谷歌 Gemini 3.5 Pro 的竞争压力。
