# Claude Opus 4.8

Claude Opus 4.8 是 [[anthropic]] 下一代前沿旗舰大模型，于2026年5月23日左右在 Google Vertex AI 后台被开发者发现模型标识 `claude-opus-4.8`。预计2026年6月正式发布。

## 发现经过

开发者 can 最先爆料，在 Google Vertex AI 平台的模型列表中发现了 `claude-opus-4.8` 标识。这一发现延续了 Anthropic 此前的发布规律——Opus 4.6 和 Opus 4.7 都是先在 Vertex AI 后端被提前发现，然后才正式公布。

此外，曾被称为"太危险不公开"的 [[mythos-1|Mythos 1]] 也在 Claude 界面短暂露脸。

## 版本演进

- Opus 4.6 在 [[swe-bench-verified|SWE-bench Verified]] 上得分 80.8%
- Opus 4.7 于2026年4月发布，击败了 Gemini 3.1 Pro 和 GPT-5.4
- Opus 4.8 距离上一版本仅一个多月，显示 Anthropic 模型迭代速度显著加快
- Sonnet 系列跳过 4.7 直接到 [[claude-sonnet-4.8|4.8]]

## 竞争定位

Opus 4.8 是 [[6月前沿模型混战-2026|2026年6月前沿模型混战]] 的四大参战模型之一，也是 Anthropic 三线并进战略的一部分，与 [[claude-sonnet-4.8]] 和 [[mythos-1]] 同步推进，应对 OpenAI GPP-5.6 和谷歌 Gemini 3.5 Pro 的竞争压力。

## 事实标准地位

[[claude-code|Claude Code]] 在开发者社区已成为编程 Agent 的事实标准，竞品 [[grok-build|Grok Build]] 甚至原生兼容其 CLAUDE.md 配置文件。
