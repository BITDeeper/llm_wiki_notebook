# Sebastian Markbage

[[Sebastian Markbage]] 是 React 核心团队成员，资深前端架构师。

## 主要贡献
- **React 核心开发**：作为 React 团队的早期核心成员，对 React 的设计理念有重要影响。
- **Pretext 架构源头**：十年前，他编写了一个名为 `text-layout` 的实验项目，探索了使用 Canvas `measureText` 进行文字塑形、利用 pdf.js 的 bidi 算法处理双向文本等技术。
- **技术传承**：[[Cheng Lou]] 开发的 [[Pretext]] 引擎，其架构骨架直接源自 Sebastian 十年前的这个实验项目。这体现了前端技术社区中核心思想的长尾效应和传承。
