# MAGIC-TTS

**MAGIC-TTS** 是[[华南理工大学]]开发的语音合成系统，首次实现[[字级节奏控制|字级内容时长]]与[[边界停顿控制|毫秒级边界停顿]]的同步精细控制。论文于2026年4月发布于arXiv（编号 2604.21164）。

## 核心创新

MAGIC-TTS 的核心价值在于将语音合成从"把话念自然"推进到"能精细安排句内节奏"。系统不再将节奏视为模糊的整体感觉，而是明确区分每个 token 的展开长度（内容时长）和 token 之间的边界停顿，实现局部可控的语音生成。

## 技术架构

### 训练流程

1. **大规模预训练**：在3万小时语音数据上，使用 Stable-ts 构造 token 级时序标签进行持续预训练
2. **交叉验证筛选**：使用 Stable-ts 和 MFA（Montreal Forced Aligner）做交叉验证，筛掉不可靠样本
3. **精细指令微调**：在230.72小时高置信度子集上进行精细指令微调

### 关键技术

- **双维度拆分**：将节奏控制拆分为内容时长和边界停顿两个独立可控维度
- **[[零值校正]]**：校正 MLP 编码的停顿残差，防止无意义信号积累污染内容时长控制
- **缺失控制鲁棒性训练**：使用户未提供完整精细时序指令时仍能保持默认合成质量

## 性能指标

| 指标 | 无控制 | 有控制 | 提升 |
|------|--------|--------|------|
| 内容时长 MAE | 36.88ms | 10.56ms | 71.4% |
| 内容时长相关性 | 0.588 | 0.918 | +56.1% |
| 停顿 MAE | 18.92ms | 8.32ms | 56.0% |
| 停顿相关性 | 0.283 | 0.793 | +180.2% |

内容时长指标的大幅提升比停顿更有意义——让某个 token 说得更长而不破坏整句，难度远高于在边界处插入停顿。

## 应用场景

- [[高辨识播报]]：验证码、订单号、地址、药品名等"听错一个字都麻烦"的场景
- 教学纠音：外语学习、儿童跟读、口语训练中的差异示范
- 表达型语音：数字人、剧情化配音、故事讲述中的情绪张力控制

## 开放问题

- 与主流 TTS 系统（VITS、NaturalSpeech 等）的基线对比细节
- 230.72小时微调数据的泛化性
- 推理延迟是否满足实时场景需求
