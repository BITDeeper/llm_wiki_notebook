# Cooper

Cooper 是云基础设施提供商 [[railway]] 的 CEO。在 [[cursor-9秒删库搞崩公司，然后…写了份检讨.md]] 报道的事故中，他在关键时刻介入并挽救了 [[pocketos]] 的数据。

## 事故中的角色

在 [[cursor]] Agent 删除 [[pocketos]] 生产数据库后的最初30小时内，Railway 的官方支持渠道未能给出有效回应。

直到周日深夜，Cooper 主动联系了 [[jer-crane]]。他利用 Railway 从未在文档中公开承诺过的“灾难级快照”，在一小时内成功恢复了被删除的数据。

## 后续行动
在事故引发广泛关注后，Railway 在 Cooper 的主导下为相关 API 端点打上了补丁，增加了延迟删除逻辑，以防止类似事故再次发生。
