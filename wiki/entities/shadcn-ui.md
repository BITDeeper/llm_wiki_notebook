# shadcn/ui

shadcn/ui 是一个基于 Radix UI 和 Tailwind CSS 的可复用组件库，采用“复制粘贴”而非传统 npm 安装的方式集成到项目中。

## 在 AI 隐形技术栈中的地位

根据 Amplifying.ai 的研究，shadcn/ui 在 UI 组件类别中占据主导地位：

### 数据表现
- **首选率**：90.1%
- **类别**：UI 组件库

### 含义
当 [[Claude Code]] 需要构建用户界面时，它几乎默认会选择 shadcn/ui，而非 Material-UI、Ant Design 或 Chakra UI 等其他流行组件库。这反映了 AI 对现代、可定制性强且与 React 生态深度集成的工具的偏好。

## 技术特征

shadcn/ui 的独特之处在于它不是传统的组件库分发，而是一组可以直接复制到项目中的组件代码。这种模式与 Claude Code 倾向于 [[自定义/DIY偏好]] 的特征高度契合——AI 可以根据项目需求灵活修改组件代码，而非受限于封装好的 API。
