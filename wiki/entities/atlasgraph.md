# AtlasGraph

**AtlasGraph** 是 [[海致科技]] 开发的自研图数据库产品，也是其企业级 AI 解决方案的核心底座。它不仅仅是一个数据库，更被定位为一个面向 [[Agent OS]] 的“操作系统”，旨在解决企业级智能体落地过程中的知识管理、技能编排和安全合规问题。

## 核心功能模块

### 1. Ontology 图管理
作为系统的语义基础，负责将企业的设备、流程、概念和关系统一编码成机器可理解的语义框架，实现 AI 与人类认知的“对齐”。

### 2. Skill 管理
提供标准化的执行接口，管理 Agent 可调用的工具和技能。它解决了技能间的依赖关系问题（例如：定价规则依赖历史订单），将最优流程以图的形式固定下来，避免每次重新规划。

### 3. 三张图架构
为了解决超长上下文管理和任务恢复问题，AtlasGraph 引入了 [[三张图架构]]：
- **任务图**：拆解目标，管理子任务间的依赖与并行关系。
- **记忆图**：存储历史交互和关键信息（如客户过往询价），实现精准回忆。
- **状态图**：保存任务执行的快照，支持断点续传和任务恢复。

### 4. 规则引擎
内置企业的审批链、权限控制、风险要求等规则，确保 Agent 的每一次操作都在合规的边界内运行，防止不可控的执行风险。

## 技术价值
AtlasGraph 通过 [[图模融合]] 技术，利用图数据库的结构化优势弥补大语言模型（LLM）在长上下文记忆和逻辑约束上的短板，使得 AI 能够在复杂的业务场景中实现精准、可控的执行。
