# Catherine Wu

Catherine Wu 是 [[anthropic]] 的产品负责人，曾与 [[boris-cherny]] 一同负责 [[claude-code]] 的产品工作。她在 2025 年底的"C妃回宫"事件中扮演了关键角色。

## 职业经历

### Anthropic 时期
- **职位**：Claude Code 原产品负责人
- **合作**：与 Boris Cherny 紧密合作，推动 Claude Code 从内部工具发展为商业化产品

### 短暂离职
- **时间**：2025 年底
- **去向**：与 Boris Cherny 一同跳槽至竞争对手 [[cursor]]
- **回归**：约半个月后被 Anthropic 请回

## 产品贡献

Catherine Wu 在 Claude Code 的发展过程中发挥了重要作用：
- **产品定位**：帮助将 Claude Code 从内部工具转化为面向开发者的商业化产品
- **市场策略**：参与制定 Claude Code 的市场推广和商业化策略
- **用户体验**：负责优化 Claude Code 的用户体验和功能设计

## "C妃回宫"事件

Catherine Wu 与 Boris Cherny 的短暂离职和回归，成为 AI 领域人才争夺的经典案例：
- 反映了顶尖 AI 产品人才的稀缺性
- 证明了核心产品团队对产品成败的决定性影响
- 展示了 Anthropic 对关键人才的重视程度

两人回归后，Claude Code 实现了商业化爆发，年化收入从 10 亿美元增长至 25 亿美元，带动 Anthropic 总收入突破 300 亿美元。
