# QoderWork

**QoderWork** 是阿里巴巴推出的桌面级 AI Agent 办公自动化软件，被媒体称为"国产版 [[Claude Cowork]]"。它运行在本地操作系统层面，拥有系统级权限，能够通过自然语言指令直接操控文件、应用及浏览器，旨在将 AI 从"对话"推向"行动"，成为用户的"全能数字打工人"。

2026年5月20日，QoderWork 正式发布全球首个"AI Native 自定义工作台"，首发上线设计、PPT、写作三大领域模式。目前该工具支持 Windows 和 Mac 生态，并已开启邀测。

## 核心架构

### 本地化与自主执行

QoderWork 具备"本地读写+自主执行"的核心能力。与大多数云端 Agent 不同，它强调 [[本地执行]]，任务处理在用户终端设备上完成，无需上传至云端。这一特性主要解决了企业级数据隐私痛点（如财务报表、核心代码不上云）和网络延迟问题。

其自主规划能力允许它将复杂指令拆解为步骤、执行并反馈。遇到模糊指令时，它会主动询问用户，而非盲目执行，从而确保任务完成的可控性。

### 解耦式工作台架构

QoderWork 通过解耦 UI 组件、业务逻辑和工作区区块实现场景独立化：

- **底层**：统一的 Agent 底座与任务系统（所有工作台共享）
- **上层**：每个工作台拥有独立的视图、工具、状态和产物标准
- **扩展机制**：开放平台，未来开发者和企业可基于底座搭建专属领域工作台

### MCP 与 Skills 体系

- **MCP (模型上下文协议)**：作为骨架，支持连接本地数据库、Notion 文档及自定义 Python 脚本。
- **技能广场**：集成官方和社区自定义 Skills（包含 Prompt、工具集与执行策略），支持一键安装和热更新。用户可以将特定工作流（如"周报 Skill"、"竞品监控 Skill"）封装成一键触发的功能，像"乐高底座"一样扩展能力。

## 三大领域模式

### 设计工作台（5月18日率先上线）

核心理念为 [[code-as-design]]——设计产物即代码产物，消除从设计稿到代码的"翻译链"。采用三步协作机制：

1. **Questions**：输入不足时 AI 先追问对齐意图，而非"猜着做"
2. **Design Plan**：AI 先输出结构化设计计划，用户确认后才执行
3. **Nudge**：生成后通过参数化面板微调配色、间距、圆角等设计决策

支持画笔功能圈选区域修改，产物可一键交付至 [[qoder-ide]] 等开发工具。支持 [[vibe-coding|零代码氛围编程]]，用户无需理解代码原理。

### PPT 工作台

将演示稿制作拆解为 11 个可介入阶段，用户在大纲、主题、图像、内页四个层级均可介入。核心技术特点：

- **HTML 即源文件**：每页以独立 HTML 文件落盘，Theme JSON 为视觉真值
- 内容可读、可 diff、可手改、可离线分发
- 支持 PDF / HTML / PPTX 三种格式导出
- 内置 30+ 官方预制模板，成稿可一键抽取为团队模板

实测中，QoderWork 能够从杂乱的素材中自动整理信息，生成包含复杂排版、数据更新和结构重组的专业级 PPT。它成功生成了一份包含 12 位 AI 领军人物介绍的 19 页大作，并具备"五幕剧"结构的高级叙事能力。

### 写作工作台

核心能力为"选中即批注"——用户圈选文本直接批注修改指令，AI 围绕选中内容定向修改。提供润色、重写、扩写、缩短、修复语法、中英互译等快捷动作。支持人机接力，每次重要修改有历史版本可回看。

## 其他应用场景

- **数据分析**：能够读取 Excel 数据（处理上万条数据），自动生成 HTML5 格式的可视化分析报告，涵盖画像归档、趋势预测及商业洞察。
- **文件管理**：自动分类归档杂乱的文件夹。
- **自我修复**：具备极强的环境感知能力。在遇到系统缺少 Python 环境或中文文件名导致编码错误（UTF-8 BOM 缺失）时，能自主编写诊断脚本并修复问题。
- **私人助理**：联网抓取信息生成旅行攻略并同步至日历。

## 安全机制

为了解决类似 [[OpenClaw]] 的安全隐患（如 [[Summer Yue]] 的邮箱误删事故），QoderWork 构建了 [[三层安全防护]]：

1. **逻辑删除**：文件删除改为可恢复的逻辑删除。
2. **高危拦截**：遇到高风险命令自动弹窗，需用户确认。
3. **沙箱隔离**：在设备端构建全隔离的 [[本地沙盒]]，任务在独立环境中运行，不污染宿主系统。

## 商业化特性

- **模型分级选择器**：允许用户在"标准模式"（省流量/快）和"旗舰模式"（高算力/强推理）之间切换，以适应不同任务的成本需求。

## 竞争与定位

- **vs [[OpenClaw]]**：QoderWork 强调商业化和安全性，提供了沙箱隔离机制，避免了 OpenClaw 直接调用系统权限带来的风险。
- **vs [[Claude Cowork]]**：同为桌面 Agent 竞品，QoderWork 在本地化执行和办公场景（特别是 PPT 和 Excel）的深度优化上表现出色。媒体将其定位为中国用户 AI 办公的新选择，暗示可替代 [[anthropic|Claude]] 等海外产品（需注意部分对比性标题在正文中缺乏直接功能对比支撑）。

阿里 Qoder 负责人 [[丁宇]] 表示，其目标是推动 AI 从"聊天时代"进入"[[桌面智能体]]时代"。

## 已知局限

- 设计工作台产物一键交付后默认打开新 workspace，融入已有项目上下文仍是挑战
- "全球首个 AI Native 自定义工作台"的宣称缺乏独立验证
- 扩展机制尚未开放，无实际开发者/企业案例
