# Cortical Labs

Cortical Labs 是一家专注于生物计算的初创公司，致力于将体外培养的生物神经元与硅基芯片结合，构建新型的智能计算系统。

## 核心产品与技术

### DishBrain
Cortical Labs 开发的核心系统，将体外培养的神经网络与 [[高密度多电极阵列]]（HD-MEA）结合。该系统曾于 5 年前让脑细胞学会玩 Pong 游戏，现已进化至能玩 3D 游戏《毁灭战士》。

### CL1
被称为“世界首台可编程生物计算机”。其核心是一块多电极阵列芯片，上面生长着约 20 万个活体人类神经元。Cortical Labs 为 CL1 开发了配套的 API 接口，允许开发者通过 Python 代码直接与活体神经元进行交互、训练和行为塑造。

## 技术理念
公司主张利用生物神经元天然的 [[样本效率]] 和信息处理能力，解决传统硅基芯片在能效和适应性上的瓶颈。其研究表明，生物系统在 [[前向传播学习]] 和处理稀疏信息方面具有独特优势。

## 开发生态
Cortical Labs 采取了开放策略，向开发者和研究人员开放云平台 API。独立开发者 [[Sean Cole]] 利用该平台在不到一周内实现了 Doom 游戏的神经元适配，证明了该平台的易用性和可扩展性。

## 未来方向
团队计划进一步优化神经元的训练效果，使其不仅能玩游戏，还能出色地完成更复杂的任务，如控制机械臂，从而探索 [[具身智能]] 的生物硬件实现路径。
