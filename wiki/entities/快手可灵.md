# 快手可灵

快手旗下的 AI 团队，专注于多模态大模型与视频生成技术的研发。

## 主要贡献
- 与 [[中科院自动化所]] 和 [[南京大学]] 合作研发了 [[OmniSIFT]]，一种高效的模态非对称 Token 压缩框架。
- 在 [[Qwen2.5-Omni]] 等全模态模型上验证了其技术方案，实现了在保留 35% Token 的情况下性能反超原模型的效果。

## 技术方向
团队致力于解决全模态大模型在处理音视频信息时面临的计算瓶颈问题，通过利用模态间的非对称依赖关系（如视觉引导听觉）来优化推理效率。
