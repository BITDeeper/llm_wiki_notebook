# Dianne Penn

Dianne Penn 是 [[anthropic]] 的产品研发主管。

## 核心贡献
在 Code with Claude 开幕演讲中，她系统阐述了 Anthropic 下一代模型的三大核心升级方向：**更高判断力**、**无限上下文窗口**和**多智能体协调**。

## 关键观点
- **[[task-horizon]]（任务视界）**：她提出了这一概念，用于衡量 AI 能独立工作且保持质量提升的时间长度，指出模型能力正从“分钟级”向“小时级”乃至“天级”跨越。
- **指数级进步**：她强调模型能力呈指数增长，而大多数组织仍在线性路径上采用 AI，两者之间的缺口是开发者的机会所在。
- **脚手架角色的转变**：她指出，过去脚手架是为了弥补模型的不足，现在则是为了放大模型本身的智能。
