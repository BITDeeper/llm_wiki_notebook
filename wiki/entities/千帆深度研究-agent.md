# 千帆深度研究 Agent

千帆深度研究 Agent 是百度推出的基于 [[agentic-架构]] 的深度研究工具，旨在解决复杂、长程的研究任务。它在 DeepResearch Bench 榜单中超越了 OpenAI、Google 和 Anthropic 等竞争对手，位列第一。

## 核心特性

### 1. 澄清式交互
在研究开始前，Agent 会通过多轮对话确认用户的具体关注点（如技术细节 vs 商业影响，技术人员 vs 投资人），以确保研究方向准确，避免一开始就跑偏。

### 2. 由粗到细的研究路径
- **宏观扫描**：通过初步信息检索形成对研究任务的全局理解，建立初步研究框架。
- **精细深入**：基于框架设计，逐步收集和整合信息，通过全局唯一的任务调度器保证任务的一致性和连贯性。

### 3. 深度执行路径图规划与反思
在每个研究节点上进行三步操作：
1. **反思**：评估当前节点的成果是否符合预期。
2. **调整**：根据反思结果，动态调整后续研究路径。
3. **细化**：基于完整路径图，细化每个节点的具体执行方案。

### 4. 结构化交付
最终交付不仅包括文本，还支持生成结构化的精美网页、Markdown 文档甚至 CSV 数据表。提供可视化的研究路径图、交互式的推理链条追溯和关键信源的置信度标注。

## 技术架构
千帆深度研究 Agent 基于 Qianfan Agent Foundry 构建，采用 Agentic 设计架构，通过“任务理解分析-任务思考规划-任务调度执行”的循环式设计，实现复杂研究任务的端到端交付。

## 市场表现
在 DeepResearch Bench 榜单中，千帆深度研究 Pro 和千帆深度研究分别拿下第一和第二，在全面性、洞察力、指令遵循度、可读性四个核心维度上全面领跑。

## 商业定位
百度将这一能力以开发平台能力的形式开放，旨在服务金融、科研、咨询等高价值场景，帮助企业实现知识管理的新范式。
