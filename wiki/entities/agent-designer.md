# Agent Designer

[[Agent Designer]] 是谷歌推出的一款交互式无代码/低代码平台，旨在让非程序员用户也能在 [[Gemini Enterprise]] 环境中创建、管理和发布 AI Agent。

## 核心功能

根据谷歌官方更新日志及媒体报道，Agent Designer 具备以下关键能力：

1.  **多步骤任务编排**：
    -   支持创建复杂的单步及多步 Agent。
    -   支持 Agent 嵌套（子 Agent），允许用户串联成完整的工作流。
    -   区别于简单的“帮我写封邮件”指令，它能处理长链路任务。

2.  **连接真实工具**：
    -   内置连接器支持 Gmail、Google Drive、Jira、GitHub、Notion、SharePoint 等主流企业应用。
    -   Shopify 等更多连接器处于公开预览阶段。
    -   使得 Agent 能够真正操作企业数据，而非仅生成文本。

3.  **定时执行**：
    -   支持 Agent 在设定时间自动运行，无需用户实时监控。
    -   适用于自动化报告生成、数据监控等场景。

## 产品定位

-   **面向用户**：主要面向企业 IT 部门和普通业务用户，而非专业开发者。
-   **互补关系**：与 [[Vertex AI Agent Builder]] 形成互补。后者更偏底层和开发者场景，而 Agent Designer 提供了门槛更低、更易用的可视化界面。
-   **战略意义**：它是谷歌实现“平台化”路线的关键拼图，将原本复杂的 Agent 构建能力封装成大众可用的工具，直接嵌入到 Google Workspace 等现有产品矩阵中。

## 发展历程

-   **2025年底**：正式上线于 Gemini Enterprise。
-   **2026年4月**：随着 Gemini 界面新增“Agents”入口，Agent Designer 成为连接用户与 Agent 运行平台的核心桥梁。
