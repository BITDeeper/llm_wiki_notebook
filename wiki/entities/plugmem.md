# PlugMem

**PlugMem** 是由 UIUC（伊利诺伊大学厄巴纳-香槟分校）和清华大学联合提出的任务无关 AI 智能体记忆架构。它旨在解决 Agent 在长程任务中面临的记忆过载与低效复用问题，通过将原始经验转化为结构化的知识，实现了即插即用的通用记忆能力。

## 核心特性

### 任务无关
PlugMem 被设计为一个通用的记忆骨架，无需针对特定任务（如对话、网页导航）进行专门修改即可接入不同的 AI Agent。实验表明，同一个 PlugMem 模块在长程对话、多跳检索和交互式网页决策等异构基准上均表现优异。

### 以知识为中心
区别于传统的“日志式”记忆，PlugMem 借鉴认知科学，将记忆组织为两类核心知识单元：
*   **命题式知识**：关于世界的事实（例如“用户喜欢科幻电影”）。
*   **处方式知识**：可复用的技能或策略（例如“如何在电商网站上筛选商品”）。

## 技术架构

PlugMem 包含三个协同工作的组件：

1.  **Structuring（结构化）**
    将原始的情景经验（对话、文档、网页轨迹）标准化，提取为命题和处方，并将其组织成**记忆图**。

2.  **Retrieval（检索）**
    摒弃了检索文本块的做法，转而检索与当前任务语义对齐的知识单元。高层概念与意图作为“路由信号”帮助快速定位相关内容。

3.  **Reasoning（推理/压缩）**
    将检索到的知识进一步压缩为简洁、可直接用于当前任务的指引，从而高效利用宝贵的上下文窗口。

## 评估与指标

PlugMem 引入了**决策效用**（Decision Utility）这一基于信息论的指标，用于衡量记忆系统每消耗一个 Token 能带来多少“决策相关的信息增益”。

在效用-成本空间中，PlugMem 被证明在更低的 Token 成本下提供了更高的决策效用，优于传统的检索方法和针对特定基准定制的记忆系统。

## 应用与影响

PlugMem 证明了“把经验转化为知识”比直接检索原始日志更紧凑、更有信息量。它被视为构建智能体“可复用知识基础设施”的重要一步，有助于缓解 Agent 的冷启动问题并支持跨任务的泛化能力。
