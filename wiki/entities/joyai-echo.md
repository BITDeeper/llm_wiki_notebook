# JoyAI-Echo

[[京东]] 开源的长音视频生成框架，旨在解决AI长视频生成中角色一致性、音色稳定性、生成速度和画面质量等核心痛点。支持最长5分钟的跨镜头音视频双重一致生成，代码和权重文件均已公开。2026年6月发布，标志着京东在长视频生成领域进入全球第一梯队。

## 核心技术

JoyAI-Echo 通过两层互补的技术矩阵攻克长视频生成难题：

### 数据层

- **百万级[[身份向心型视频语料库]]**：从源头解决"变脸"问题。

### 模型层——跨模态音视频记忆库

详见 [[跨模态音视频记忆库]]（亦称[[渐进演化记忆库]]）。在框架中嵌入记忆系统，同步记录角色视觉特征和声音特征并绑定，保留故事开头关键镜头和最近生成镜头，实现5分钟长视频高一致性生成。"槽位配对"机制绑定面部与声音。

### 后训练层——记忆驱动后训练

详见 [[记忆驱动后训练]]。包含三步：

1. **SFT监督微调**：长上下文损失重定向、多分辨率渐进式SFT。
2. **RLHF人类反馈强化学习**：[[omninft-跨模态对齐强化]]。
3. **DMD（Distribution Matching Distillation）**：即[[分布匹配蒸馏]]，将大模型能力压缩到轻量推理模型，带来约 **7.5倍推理速度提升**。

### 应用层

#### Director Agent（导演智能体）

详见 [[director-agent|Director Agent]]（[[导演智能体]]）。自然语言驱动的AI视频导演，自动完成三阶段工作流：

1. **策划**：剧本拆解。
2. **生成**：上下文检索与条件组装。
3. **点评修改**：局部重生成，告别"改一个镜头要重跑整条视频"的盲盒式生成，通过自然语言指挥AI进行局部修改。

#### 轻量化实时超分

详见 [[轻量化实时超分]]（[[联合单步超分架构]]）。将超分能力直接嵌入生成链路，先生成720P视频再通过一次前向推理完成1K/2K高清输出，避免传统两阶段架构的额外延迟。支持流式延迟约束下的两档实时超分，最高输出1472×2560分辨率。

## 评测表现

在100个剧本、3000个镜头的超长生成基准评测集上，视听一致性各项指标均位列前茅。

| 指标 | 数值 |
|------|------|
| 长视频画面偏好 | 63.6% |
| 音频质量偏好 | 81.7% |
| 提示词遵循偏好 | 80.6% |
| IP一致性偏好 | 59.4% |
| 人像短视频视觉美学偏好 | 58.8% vs 竞品26.5% |
| 语音准确率（台词准确率） | 0.8646 |

提供了皮克斯3D、哥谭黑暗写实、Vlog写实、细腻情感等多种风格的完整案例视频。

## 应用场景

虚拟IP故事、数字人内容、品牌营销视频、教育课件、知识讲解、游戏动画、互动剧情等。

## 局限性与注意事项

- 快速切镜时背景细节偶有轻微不一致。
- 开源范围是否包含完整训练数据（百万级身份向心型语料）未明确说明。
- 评测数据为官方用户盲测，缺乏第三方独立验证。
- "全球第一梯队"表述未与Sora、Kling等具体竞品进行命名对比。
