# UMM-World

**UMM-World** (Unified Multimodal World Model) 是 [[VLA-MBPO]] 框架中的核心组件，一个统一的多模态世界模型。它基于 [[Bagel]] 模型构建，旨在为具身智能体提供一个能够同时预测未来观测和奖励的“脑内模拟器”。

## 核心功能
与传统的视频世界模型（如 Ctrl-World）不同，UMM-World 并不单纯追求生成“画得像”的视频，而是强调“画得对”（物理上合理且对控制有用）。它统一处理以下任务：
1.  **动力学预测**：根据当前的多视角观测和动作，预测未来的画面（头视角和腕视角）。
2.  **奖励判断**：直接预测当前动作序列是否会导致任务成功。

## 技术优势
- **统一建模**：将视觉、文本和动作 token 统一输入模型，利用预训练多模态模型的先验知识，在少量数据下实现更好的泛化。
- **高效推理**：可以跳过中间帧，直接预测动作切块之后的未来状态。相比传统视频世界模型，推理时间从 21ms 降至 10ms。
- **高精度奖励判断**：在 LIBERO Object 套件上的奖励判断准确率达到 98.4%，F1 分数为 0.861，优于专用的视觉语言模型 Qwen3-VL-8B。

## 在 VLA-MBPO 中的作用
UMM-World 为 [[VLA-MBPO]] 提供了高质量的合成数据。通过 [[交错式视角解码]] 保证多视角一致性，并结合 [[短分支推演]] 策略，它能够在控制误差累积的前提下，为策略优化提供丰富的训练信号。
