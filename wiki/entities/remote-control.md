# Remote Control

Remote Control 是 [[Anthropic]] 于 2026 年 2 月底为 [[Claude Code]] 发布的远程控制功能。

## 功能定位
- **目标用户**：程序员和开发者。
- **控制对象**：Mac 上运行的 Claude Code 终端会话（CLI）。
- **核心能力**：允许用户通过手机远程编写代码、运行脚本和管理终端任务。

## 与 Dispatch 的关系
Remote Control 与 [[Dispatch]] 构成了 Anthropic 的“双线作战”策略：
- **Remote Control**：针对程序员，控制命令行环境（Terminal）。
- **Dispatch**：针对普通用户，控制图形用户界面（GUI）。

两者共享相同的底层架构逻辑：以手机为入口，Mac 为执行端，强调 [[本地优先]] 的数据处理方式。
