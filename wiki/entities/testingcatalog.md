# TestingCatalog

TestingCatalog 是一个著名的 AI 追踪平台，专注于监控和爆料各大 AI 公司未发布的产品信息、AI 模型的测试与发布动态。

## 已知爆料记录

- **2026年5月**：爆料有用户在 Claude 界面中短暂看到了 [[mythos-1]] 模型选项，虽然很快消失，但源代码中新增的字符串泄露了 Claude Code 和 [[claude-security]] 的关键信息。
- 首次爆出 Anthropic 正在为 Claude 测试「双模记忆系统」（经典记忆 + 文件记忆）。
- 证实了 [[claude-conway|Conway]] 永不下线智能体平台的存在。
- 披露了 Claude 侧边栏灰度测试中 Memory Files 和 Dreams 功能的截图。

## 可信度评估

TestingCatalog 的爆料在多个独立信源中得到交叉验证（Claude Code 源码泄露、侧边栏灰度测试截图），但部分功能仍处于测试阶段，最终产品形态可能有所变化。
