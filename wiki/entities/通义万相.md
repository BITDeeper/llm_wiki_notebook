# 通义万相

通义万相是阿里巴巴集团旗下的AI视觉生成产品与研究团队，专注于图像和视频生成模型的研发。其研究实验室（ali-vilab）在扩散模型、多模态生成等领域持续产出学术成果并开源代码。

## 研究贡献

- **[[diffusionopd|DiffusionOPD]]**：与[[复旦大学]]联合提出扩散模型在线策略蒸馏新范式，代码通过 ali-vilab 在 GitHub 开源。该方法在构图、文字生成（OCR）和美学等多个任务上实现了统一模型的多能力整合。

## 技术定位

通义万相的研究方向聚焦于扩散模型的后训练优化，特别是强化学习在图像生成质量提升中的应用，涵盖文字渲染、构图控制和美学优化等核心能力。
