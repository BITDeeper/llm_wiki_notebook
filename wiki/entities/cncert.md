# 国家互联网应急中心

**国家互联网应急中心**（CNCERT，全称国家计算机网络应急技术处理协调中心）是中国国家级的网络安全应急机构。

## 关于 OpenClaw 的风险提示
针对 [[openclaw]] 的流行，CNCERT 发布了《关于OpenClaw安全应用的风险提示》。

### 核心关注点
- **高权限风险**：指出该类智能体运行时通常需要较高系统权限（访问文件系统、读取环境变量、调用 API 等）。
- **默认配置缺陷**：如果默认配置缺乏必要的安全限制，攻击者一旦突破防护，可能获得系统完全控制权。
- **后果严重性**：可能导致数据泄露或业务系统失控。

CNCERT 的介入标志着 AI 智能体安全已被纳入国家网络安全监管视野。
