# Ultron

**Ultron** 是由 [[modelscope]] 团队开源的自进化群体智能框架。它定位为 Agent 体系的“群体协作基础设施”，旨在解决智能体在规模化落地中面临的**状态易失**、**重复试错**和**迁移困难**三大痛点。

## 核心架构

Ultron 围绕三个核心 Hub 构建其能力体系：

### 1. Memory Hub (群体记忆)
负责将智能体在真实任务中的经验沉淀为可复用的资产。
-   **分层管理**：将记忆按 HOT（高频）、WARM（中频）、COLD（低频）进行分层管理。
-   **语义检索**：支持基于语义的相似场景召回，而非简单的关键词匹配。
-   **自动去重**：对重复或相似的记忆进行合并与压缩。
-   **数据规模**：已从真实轨迹中提炼出 1746 条结构化记忆，覆盖 pattern、error、security、life、correction 五类知识。

### 2. Skill Hub (技能结晶)
将高频验证的记忆自动转化为可复用的技能工作流。
-   **自动结晶**：通过语义聚类，将反复验证的高频记忆自动转化为技能。
-   **持续进化**：新证据积累后会触发“再结晶”，通过溯源验证与结构分数门控确保技能质量只升不降。
-   **生态打通**：打通 ModelScope Skill Hub，可统一检索并调用 80,000+ 外部技能。
-   **内部技能**：已形成 182 个内部技能，归入 9 大类、39 个分类体系。

### 3. Harness Hub (蓝图分发)
实现智能体画像的跨框架标准化分发。
-   **蓝图打包**：将角色设定（201 个预置角色）、记忆背景、技能组合和工具配置打包成标准化蓝图。
-   **一键导入**：支持其他框架（如 [[openclaw]]、[[nanobot]]、[[hermes-agent]]）一键导入成熟的专家智能体。
-   **案例**：[[financebot]] 是一个典型的蓝图分发案例，集成了金融数据工程师角色、ISTJ 决策风格及 Finnhub Pro 技能。

## 解决的问题

1.  **状态易失**：通过 Memory Hub 保存长期记忆，避免会话结束后经验清空。
2.  **重复试错**：通过语义检索共享避坑经验，避免不同智能体重复排查同一问题（如 MySQL 8.0 字符集问题）。
3.  **迁移困难**：通过标准化蓝图实现专家画像在不同框架和环境间的无缝流转。

## 接入方式

Ultron 提供了技能包机制，无需修改源码即可接入现有 Agent 框架。以 Nanobot 为例，只需下载技能包、设置 API 地址并运行配置脚本即可完成接入。
