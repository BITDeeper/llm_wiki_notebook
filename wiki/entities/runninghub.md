# RunningHub

RunningHub 是国内最大的 [[ComfyUI]] 平台，也是一个内容创作者共创的图像音视频内容平台。它致力于聚合全球最活跃的 ComfyUI 开发者资源，发布工作流、节点和模型方案。

## 核心数据与生态规模
根据官方公开信息，RunningHub 拥有庞大的技术生态：
- **170+** 标准模型 API
- **10万+** 社区 AI 应用 API
- **13,681** 个可用节点
- 覆盖图像、视频、音频、3D、文本五大模态

## 产品演进路径
RunningHub 的发展路径体现了降低 AI 创作门槛的持续努力：
1. **ComfyUI 工作流聚合**：整合分散的节点和工作流。
2. **开放式模型社区**：建立标准化的模型接入与分享机制。
3. **原生 AI 智能体平台 ([[RHTV]])**：通过 Agent 封装复杂生态，实现自然语言交互。

## 战略意义
RunningHub 的核心价值在于构建了一个“活的、持续进化的知识库”。其推出的 [[RHTV]] 平台并非凭空诞生，而是这一生态自然生长的产物，完整继承了其全部资产与技术积累，使得普通创作者可以通过自然语言调度整个 AI 创作生态的能力。
