# GSD

GSD 是一个在 GitHub 上拥有超过 5 万星标的 AI 开发框架，全称意为“Get Shit Done”。它被设计用于辅助 AI 智能体进行复杂的软件开发任务。

## 框架机制
GSD 框架包含 79 个子技能，定义了一套标准的工作流程：
1. **Discuss（讨论）**：明确需求和目标。
2. **Plan（计划）**：生成项目文档和路线图。
3. **Execute（执行）**：编写代码。
4. **Verify（验证）**：测试和检查。

## 实际应用中的挑战
在 [[mimo-v2.5-pro]] 的实测中，虽然模型成功初始化了 GSD 项目并生成了路线图，但在执行阶段表现出了 [[最短路径倾向]]。模型倾向于绕过 GSD 复杂的子智能体调用机制，直接编写代码。这表明虽然框架提供了规范化的流程，但高效的模型可能会为了追求速度和节省 Token 而选择“捷径”。
