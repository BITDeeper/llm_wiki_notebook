# 微软

微软（Microsoft）是美国跨国科技巨头，全球市值约 3.5 万亿美元，拥有 22.8 万员工，以 Windows 操作系统、Microsoft 365 办公套件、Azure 云服务和 GitHub 开发者平台闻名。作为 [[OpenAI]] 最大的投资方（130 亿美元），微软在 AI 领域同时扮演模型开发者（通过 OpenAI 合作及自研）和应用平台提供者的双重角色。2026 年初，微软因激进的 AI 投资策略、复杂的合作关系以及财务表现，成为 [[ai-资本支出恐慌]] 的风暴中心。

与此同时，微软内部正经历数十年来最大规模的组织重组——由 AI 驱动的深层结构变革，通过激进的裁员、层级压缩和薪酬改革，试图从传统的科技公司转型为 AI 时代的效率机器。在 AI 研究方面，微软持续投入大语言模型、多模态模型、文生图模型、Agent 工程化等多个方向，保持独立技术布局，并通过大量开源项目深度参与 AI 产业生态。

## AI 战略定位

微软虽然自身长期未训练出进入第一梯队的前沿大模型，但通过战略投资和系统层创新，走出了一条独特的 AI 路径。2026 年 6 月的 [[微软build-2026|Build 2026]] 大会成为关键转折点，标志着从依赖 OpenAI 模型分销到全栈自研的战略跃迁——从"OpenAI 分销商"转变为全栈 AI 厂商。

- **路径二实践者**：不追求造出最强单一模型，转而构建能最大化现有模型能力的系统。
- **模型无关理念**：[[MDASH]] 多 Agent 安全系统全部使用公开可用模型，强调"the model is one input"。
- **平台转型战略**：CEO [[萨蒂亚-纳德拉]]（[[satya-nadella]]）在 2025 年 10 月致股东信中明确提出"AI 平台转型"战略，并披露微软内部 30% 的代码已由 AI 生成。
- **AI CEO 预言**：微软 AI CEO [[穆斯塔法-苏莱曼]] 预测白领工作将在 12-18 个月内被 AI 全面自动化。
- **多模型策略**：作为 OpenAI 最大投资方，微软同时在使用竞争对手 [[Anthropic]] 的模型构建系统，并在 Azure 上为 Anthropic 搭建了大部分算力底座。
- **自建前沿模型**：苏莱曼从 Copilot 日常管理转向[[超级智能]]，推动自建前沿模型。Build 2026 上，苏莱曼一口气发布七款自研 [[mai系列模型|MAI 模型]]（亦称 [[mai模型系列]]），覆盖推理、编程、图像、语音、转录全模态，并强调"零蒸馏训练"——不从任何第三方前沿模型蒸馏知识。MAI Thinking 1 直接对标 Anthropic Opus 4.6，MAI Transcribe 1.5 声称超越 OpenAI 旗舰转录模型。

## 核心 AI 产品矩阵

微软构建了完整的 AI 产品与技术栈，覆盖自研模型、操作系统沙盒、超级应用、自主 Agent、企业管理平台和开发者工具：

- **MAI 模型家族**：7 款自研模型，包括推理模型 MAI-Thinking-1、代码模型 MAI-Code-1-Flash、图像模型 MAI-Image-2.5/Flash 等。
- **[[mxc]]**（Microsoft 执行容器）：操作系统级 Agent 沙盒，四档隔离机制，Windows 内核强制执行，解决 Agent 本地部署的安全顾虑。
- **[[copilot]]**：四合一超级应用（Chat + Cowork + Code + Autopilots），统一入口、统一身份、统一上下文。
- **[[scout|Scout]]**：首个企业级 Autopilot Agent，嵌入 Microsoft 365，定位为"永不下班的 AI 同事"，拥有独立身份和生产力许可证，7×24 小时自主运行。
- **Agent 365**：企业级 Agent 管理平台，IT 管理员可像管员工一样管 Agent。
- **[[github-copilot桌面客户端]]**：从 IDE 插件升级为独立开发者工作台。
- **[[surface-rtx-spark-dev-box]]**：面向 AI 开发者的本地工作站。

## AI 研究亮点

### MAI 系列自研模型

Build 2026 大会上发布的七款 [[mai系列模型|MAI 模型]]是微软从"模型分销商"向"模型制造商"转型的里程碑。覆盖推理、编程、图像、语音、转录全模态，强调"零蒸馏训练"原则。微软特意强调 MAI-Thinking-1"没有蒸馏任何第三方模型"，暗示与 OpenAI 的技术切割。

### Lens 文生图模型

微软团队于 2026 年 5 月开源了 [[lens-t2i]]，一款仅 3.8B 参数的文本生成图像基础模型。该模型通过 [[高密度数据训练]] 和精巧的架构设计，在多个权威基准测试中超越了参数量大其数倍的竞争对手，训练效率提升约 5 倍。

- **论文地址**：arxiv.org/abs/2605.21573
- **代码仓库**：github.com/microsoft/Lens（已开源）
- **模型权重**：huggingface.co/microsoft/Lens

Lens 的开源体现了微软在高效训练范式上的技术积累，为开发者和研究者提供了可复现的高性能文生图工具。

### SkillOpt Agent 技能优化框架

微软于 2026 年 5 月开源了 [[skillopt]] 框架——一个将 Agent 技能文档作为「可训练参数」进行文本空间优化的研究框架。该项目一周内获得 3.3k GitHub star，显示出极高的社区关注度。

SkillOpt 的开源标志着微软在 Agent 工程化领域的重要布局，与 [[openai]] 的 Codex 和 [[anthropic]] 的 [[claude-code]] 形成互补——SkillOpt 不绑定特定模型或执行环境，而是一个通用的技能优化层。

## Windows 平台与端侧 AI

微软通过与 [[英伟达]] 的深度合作，推动 Windows 平台向 [[agent-pc|Agent PC]] 方向演进，标志着 Windows 正式拥抱 Arm 架构，挑战 Intel/AMD 长期主导的 x86 生态。2026 年 6 月 Build 大会上，微软宣布 Windows 正式转型为 Agent 操作系统，标志着从应用运行平台向 Agent 运行时的战略转型——16 亿 Windows 用户一夜冲进 Agent 时代。

微软拥有十几亿 Windows 用户、Teams、Office、VS Code 等分发渠道，每一个都是 AI 产品落地的天然入口。微软从来不缺地盘，缺的只是一颗自己的 AI 心脏——Build 2026 表明它正在打造这颗心脏。

### 2026 GTC 大会：Agent 原生 PC 产品线

在 2026 年 GTC 大会上，微软与英伟达联合推出基于 [[rtx-spark]] 的三件套 Windows PC 产品线（笔记本、桌面、工作站），全部 100% Windows 兼容。

- **黄仁勋类比**：将此次合作类比为 Windows 95 时刻，宣称"LLM 是新时代的 DirectX，Agent 是新时代的应用"。
- **DGX Station for Windows**：768GB 内存、20 PFLOPS 算力。
- **桌面版特性**：支持 Agent 7×24 小时本地免计费运行。

### 硬件生态

与 NVIDIA 合作推出搭载 RTX Spark 的 Surface 设备，支持本地三模型并跑（含 1200 亿参数模型），推动 PC 从"个人电脑"向"个人 AI"进化。

### 在 RTX Spark 项目中的角色

- **Windows on ARM**：为 Arm 架构处理器提供完整的 Windows 操作系统支持。
- **Prism 模拟器**：开发 x86 应用兼容层，解决 Arm 架构运行传统应用的兼容性问题。
- **安全原语**：新增 Windows 安全机制，为本地运行的 AI Agent 提供沙箱隔离和用户控制保障。
- **反作弊适配**：与 Epic Easy Anti-Cheat、BattlEye 等厂商进行底层深度合作，确保主流多人在线游戏在 Arm 架构下正常运行。

通过 [[nvidia-open-shell|NVIDIA Open Shell]] 和 Windows 安全原语的结合，微软试图建立端侧 Agent 的安全运行标准。

## 安全领域成就

- [[MDASH]] 在 [[CyberGym]] 基准上登顶，验证了"系统层竞争"的可行性。
- [[MDASH]] 发现 16 个 Windows 11 高危漏洞（4 个 Critical 级）。
- 核心团队来自 [[Team Atlanta]]（DARPA AI 网络挑战赛冠军）。
- 预测"以后的 Patch Tuesday 会越来越大"。

## 与 OpenAI 的关系演变

微软对 OpenAI 的投资和合作关系在 2026 年的世纪诉讼庭审中被深度审视，呈现出"稳固但稀释"且充满控制权张力的复杂局面。Build 2026 的自研模型发布和高调强调"零蒸馏"进一步暗示战略独立性增强——微软已不再只是 OpenAI 模型的分销商。随着 OpenAI 加速推进 IPO 并寻求多合作伙伴关系，微软感知到供应链风险，开始加速自研 AI 能力——"花钱养出白眼狼，不如自己开荒种粮"。

### 合作现状

- **官方声明**：双方发布联合声明，称合作伙伴关系依然"稳固且核心"。
- **地位变化**：尽管关系稳固，[[亚马逊]] 的巨额入局（500 亿）及其获得的 [[Frontier]] 平台独家第三方云分发权，客观上稀释了微软作为"首选"云合作伙伴的独特性。
- **战略调整**：OpenAI 引入亚马逊被视为寻求独立性、避免过度依赖单一云厂商的举措。
- **融资参与**：在 2026 年 2 月 OpenAI 的巨额融资中，微软虽未直接领投，但保留了参与期权。

### 控制权野心与争议

庭审披露的内部通讯揭示了微软对 OpenAI 的深层控制意图：

- **控制权诉求**：CEO [[satya-nadella]] 2022 年邮件明确表示"投入这么多钱却没有控制权完全没意义"。
- **事实否决权**：对 OpenAI 新董事会成员行使事实上的否决权。
- **接管准备**：2023 年 11 月政变期间已准备好 14 人接管董事会名单。
- **商业化推动**：2023 年初催促 Altman 尽快推出付费订阅版 ChatGPT。
- **"IT 部门"指控**：马斯克的核心指控之一是 OpenAI 已沦为微软的"IT 部门"和变现工具。庭审文件中纳德拉的邮件和短信直接佐证了这一指控。
- **营利性重组**：微软被视为 OpenAI [[营利性重组]] 的关键推动方。

## AI 业务数据

- AI 业务年化收入运行率超 370 亿美元（2026 财年 Q3），同比增长 123%。
- 2025 年 Q1 股价经历 2008 年金融危机以来最差季度。

## 财务表现与 AI 基建

### 整体财务数据

- 2025 年全年营收 2817 亿美元，同比增长 15%。
- 2026 年初财报显示云业务营收增长 26% 至 515 亿美元。
- Azure 收入首次突破 750 亿美元，同比增长 34%。

### 资本支出与基础设施

- 数据中心支出激增 66%。
- 全球数据中心扩张至 70 个区域、超过 400 个，新增超过 2 吉瓦容量。
- 2026 年预计资本支出接近 1000 亿美元，全部投向 AI 基础设施。

### 市场反应

尽管营收增长，股价暴跌 18%。市场不再满足于单纯的营收增长，而是开始要求看到真实的投资回报率（ROI）。

## 关键争议：左手倒右手的资金循环

财报披露了一个令市场不安的数据：在微软 6250 亿美元的未来云合同中，有 **45% 来自 [[OpenAI]]**。这揭示了 [[左手倒右手-ai-资金循环]] 的现象：

1.  微软向 OpenAI 注资。
2.  OpenAI 利用这笔资金租用微软的 Azure 算力。
3.  虽然账面营收增加，但缺乏外部利润验证。

这种对单一客户的过度依赖以及资金循环的封闭性，加剧了投资者的恐慌情绪。

## Claude Code 断供事件与 Token 成本反思

2026 年 5 月，微软发布内部通知，要求"体验+设备"部门（负责 Windows、Microsoft 365、Outlook、Teams 和 Surface）近 10 万工程师在 6 月底前停用 [[claude-code]]，强制转向自家的 [[github-copilot-cli]]。

值得注意的是，Claude Code 进入微软内部距离此次收回授权不过 6 个月。微软给出的官方理由是"回归自研产品"（Eat Your Own Dog Food），但 Token 账单被认为是绕不开的核心因素。这次断供被内部定义为"紧急刹车"而非有序迁移，由财务部门主导。工程线一致反馈 Claude Code 生产力提升巨大，但管理层因账单压力选择强制下线。官方辞令为"战略对齐"。

微软也因此成为 [[企业token-roi反思潮-2026q2]] 的代表性企业之一——整个行业开始重新审视 AI 工具的 Token 成本与实际 ROI 之间的关系。

### 财务逻辑

对微软而言，GitHub Copilot 属于"内部核算成本"，资源在 Azure 内部流动，边际成本极低；Claude Code 则是实打实的"外部账单"。即便两者产出完全相同，财务性质也天差地别。

这形成了一个讽刺性的局面：当自家工程师大规模调用 Claude Code 时，微软需要按 Token 向 Anthropic 付费——等于在给自己最直接的竞品输血。

## AI 时代的组织变革

在对外激进投资 AI 的同时，微软内部也在进行残酷的组织结构优化。根据 2021-2025 财年的数据，微软在 AI 扩张期虽然用工规模曾一度高涨，但在 2023 年后进入深度重组阶段。2026 年，CEO [[萨蒂亚-纳德拉]] 主导了数十年来最大规模的架构重组（详见 [[微软ai重组-2026]]）。

### 废除高级领导团队（SLT）

微软废除了运行数十年的高级领导团队（SLT），替换为三层新架构：

1. **公司领导层**（5人）：纳德拉、总裁 Brad Smith、CFO Amy Hood、首席人力官 Amy Coleman、商业 CEO Judson Althoff
2. **工程领导组**（约 35 人）：扁平协作运作
3. **Copilot 领导组**（3人）：Charles Lamanna（平台）、[[jacob-andreou]]（体验）、Ryan Roslansky（应用）

这一变革体现了 [[组织结构即产品]] 的理念，旨在应对 [[规模劣势]]——22.8 万人体量带来的协调挑战。

### 结构性调整：哑铃化趋势

微软的员工结构发生了显著变化，反映了从传统的"金字塔结构"向"[[组织结构哑铃化]]"结构的转变：

- **增长部门**：运营与研发人数暴涨。
- **停滞/缩减部门**：行政、市场及中层管理岗位几乎停滞或被裁
