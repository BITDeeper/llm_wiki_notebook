# 三万

“三万”是猎豹移动 CEO [[傅盛]] 在 2026 年春节期间，利用 [[openclaw]] 框架训练出的 AI Agent 团队。它是 AI Agent 从“对话工具”向“自主智能体”进化的典型案例。

## 团队构成

三万并非单一的 Agent，而是一个由 8 个不同职能的 Agent 组成的协作团队，包括：
- 参谋
- 运营官
- 进化官
- 健康管家
- 交易官
- 社区官
- 笔杆子

这种架构模拟了真实公司的组织结构，每个 Agent 负责特定的任务领域。

## 核心能力

### 1. 技能积累与进化
三万的强大之处在于其具备 [[技能积累]] 能力。在 14 天的训练中，它通过不断的试错（如查不了通讯录、发错消息）将经验转化为永久性的 Skill。
- **案例**：第一天无法查询通讯录，第二天便学会编写脚本抓取 674 人通讯录。
- **特性**：技能一旦形成永不遗忘，且可瞬间在 Agent 间复制。

### 2. 长期记忆与上下文理解
三万拥有文件持久化的长期记忆系统。
- **案例**：在傅盛五天前随口提过一次助理 Abby 的名字后，五天后傅盛受伤时，三万主动提出联系 Abby。

### 3. 主动任务执行
三万具备 7×24 小时自动运转的能力，无需人类精确指令即可完成复杂任务。
- **建站任务**：在 24 小时内完成了包含 59 个 HTML 页面、7070 行代码的完整网站，成本仅为 115 美元。
- **运维救场**：在直播中网站崩溃时，主动分析问题、定位负责人并修复故障。

## 技术基础

三万底层基于 [[openclaw]] 框架，并使用了 [[easyclaw]] 技术栈进行简化部署。它拥有一台完整的电脑环境，通过 Cron 定时任务实现自动化，区别于活在沙箱中的普通 Agent。

## 意义

三万的存在验证了 [[工具类agi]] 的可行性，展示了 AI Agent 在企业级应用中通过积累私有数据和经验，最终实现“越养越强”的进化路径。
