# AutoGEO

**AutoGEO** 是由 [[卡内基梅隆大学]]（CMU）在 ICLR 2026 上提出的首个“合作式”[[生成式引擎优化]]（GEO）框架。它旨在通过系统化地理解 AI 搜索引擎的偏好，帮助内容创作者提升可见度，同时维护甚至提升搜索结果的质量。

## 核心特性

### 合作式优化
与通过劫持或投毒进行攻击的 [[对抗式GEO]] 不同，AutoGEO 试图找到一种“正和博弈”的路径。它不通过欺骗手段强行提升排名，而是通过优化内容本身以符合 AI 引擎的偏好逻辑。

### 性能表现
根据 ICLR 2026 论文数据：
-   **可见度提升**：相比此前最强的 Fluency Optimization 方法，AutoGEO API 的可见度提升最高达 **50.99%**。
-   **质量保持**：在 [[Gemini]]、[[GPT]]、Claude 三大引擎上，AutoGEO 在提升排名的同时，[[GEU]]（生成式引擎效用）指标（精确度、召回率、清晰度、洞察力）全部维持在基线水平甚至略有提升。

### 部署模式
AutoGEO 提供了两种使用方式：
1.  **AutoGEO API**：直接将提取的规则作为提示词注入 GPT、Gemini 等大模型 API，即插即用。
2.  **AutoGEO Mini**：使用规则作为奖励信号，通过强化学习训练 [[Qwen-3-1.7B]] 小模型。其推理成本仅为 API 版本的 0.71%，可在 CPU 上离线运行。

## 工作原理
AutoGEO 的核心在于从大量真实的引擎行为数据中自动提取偏好规则。其流程分为四步：
1.  **解释**：对比高可见度和低可见度文档的差异。
2.  **提取**：提炼影响排名的核心因素。
3.  **合并**：跨查询汇总规则。
4.  **过滤**：去噪留精，形成可解释的规则集。

## 发现的规则
-   **通用性**：不同 AI 引擎（Gemini, GPT, Claude）的偏好规则重叠率在 79%-84% 之间，表明“好内容”标准具有跨引擎一致性。
-   **领域差异**：研究领域偏好“深度解释”和“因果分析”，而电商领域偏好“可操作的步骤指引”和“模块化信息结构”。
