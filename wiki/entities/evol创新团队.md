# EVOL 创新团队

EVOL 创新团队是与 [[北京邮电大学]] 合作的研究团队，联合研发了 [[drawmotion|DrawMotion]] 框架。该框架提出了一种面向手绘条件的3D人体运动生成方法，发表于 TPAMI 2026。代码以 InvertedForest 名义在 GitHub 开源。
