# PICO 感知图像编解码器

PICO（Perceptual Image Codec）是 [[苹果]] 工程师团队开发的感知图像编解码器，首次系统性地将[[感知压缩]]从学术概念转化为可在手机上实时运行的工程现实。

## 核心理念

PICO 的设计目标不是优化传统数学指标（如 [[峰值信噪比-psnr|PSNR]]），而是直接针对人眼视觉体验进行优化。这代表了图像压缩领域的一次根本性范式转移：从"让数字更好看"转向"让人眼更满意"。

## 三项核心技术创新

### 1. 一次性上下文模型（One-shot Context Model）
将熵编码中最关键的"尺度参数"单独拆出，在一次前向传播中全部计算完毕，不再需要像自回归编码那样逐像素等待。其余参数可并行计算，保留了自回归的精度，却绕开了速度瓶颈。消融实验显示，去掉该模块模型性能下降 10.28%。

### 2. TextFidelityLoss（文字保真损失）
针对 [[gan-幻觉|GAN 幻觉]] 在文字区域的问题，利用现成的文字检测器自动找出图中文字区域，在这些区域强制施加严格的像素保真约束，同时压制 GAN 在文字区域的"发挥空间"。实验显示文字区域绝对误差降低 50%。

### 3. TilingArtifactLoss（分块伪影损失）
为解决图像分块处理（504×504 像素瓦片）导致的色块边界问题，引入多分辨率 L1 损失函数，强制模型在多个空间频率上保持瓦片间色彩一致性。瓦片边界误差下降 50% 以上。

## 性能数据

| 指标 | 数据 |
|------|------|
| 比特率（相对传统标准） | 30%-43% |
| 比特率（相对最强学习型感知编解码器） | 节省 20%-40% |
| iPhone 17 Pro Max 编码 12MP | 230ms |
| iPhone 17 Pro Max 解码 12MP | 150ms |
| 人类主观评测规模 | 610 人，74,925 次配对比较 |

## 评测方法论

苹果委托第三方平台 Mabyduck 组织大规模人类主观评测。610 位通过筛选的评测者（需通过色盲检测和压缩伪影辨别测试）进行盲测两两对比，最终汇总为 Bayesian ELO 分数。PICO 在评分中全面领先。

## 局限性

- PSNR 指标表现平平，甚至不如 DCVC-RT 和 VVC（这是设计取舍，非缺陷）
- 对卡通、示意图等高度规则化的合成图像压缩效率不如传统编解码器
- 这类内容天然适合规则驱动的自回归建模，而非感知生成
