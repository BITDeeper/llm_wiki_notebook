# Peekaboo

Peekaboo 是 [[openclaw]] 的专属 macOS 桌面自动化工具，名字取自"躲猫猫"之意——因为电脑界面天天跟自动化躲猫猫，按钮躲在弹窗里，菜单躲在系统栏里，窗口一动坐标全变。

## 核心能力

- **截图与视觉理解**：截取屏幕内容并识别 UI 元素
- **窗口管理**：识别、切换、操作窗口
- **UI 元素识别**：读取控件、文本、按钮及其层级关系
- **交互操作**：点击、输入、滚动、切换应用、操作菜单
- **结构化桌面地图**：将桌面转化为 Agent 可理解的结构化信息，而非单纯的像素截图

## 架构定位

在 [[openclaw]] 生态中，Peekaboo 负责执行层：

- **OpenClaw** 管"连接"——消息入口、网关、Agent 调度
- **Peekaboo** 管"执行"——屏幕上有什么、按钮在哪里、操作怎么落地

两者合一，OpenClaw 才从"多渠道消息网关"进化为"能在本机环境真正办事的系统"。

## 设计理念

Peekaboo 的核心价值在于将桌面操作变为**可观察、可复盘、可继续**的操作链：

- 每一步操作都可记录和回溯
- 与 [[断点续跑]] 理念高度契合
- AI 看到的不再只是一片像素，而是一张"带结构的桌面地图"

## 社区验证

已有用户用 Peekaboo 在浏览器中驱动远程 iOS 模拟器，展示完整的操作链：分析截图→识别 UI 元素→注册屏幕状态→点击目标→等待界面变化→继续探索。

## 工程现状

连续更新主要解决 CLI、MCP、桌面应用、远程 Agent、不同模型之间的摩擦问题。文章坦言"没有神迹，只有大量脏活"——目标是让一次截图、一次点击、一次窗口选择都更接近可预期。
