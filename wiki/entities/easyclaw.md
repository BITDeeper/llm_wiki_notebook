# EasyClaw

EasyClaw 是猎豹移动基于开源框架 [[openclaw]] 开发的极简 AI Agent 工具，旨在降低 AI Agent 的部署和使用门槛，实现“开箱即用”。

## 背景与动机

虽然 [[openclaw]] 在 GitHub 上爆火，但其部署过程对普通用户极其不友好，需要掌握命令行、Docker 和 API Key 配置等复杂技术。猎豹移动利用其 16 年的工具软件基因（如 Clean Master），推出了 EasyClaw，将这种极客技术转化为大众可用的产品。

## 核心特性

- **一键安装**：无需配置 API Key，无需折腾 Docker，双击运行即可连接大模型。
- **本地运行**：提供 Mac 和 Windows 原生应用，数据不上传，保护隐私。
- **多模型支持**：支持 Claude Opus、GPT 等多种主流大模型。
- **极简交互**：用户只需通过自然语言下达指令，Agent 即可自动完成文件整理、信息搜集、全网调研、方案生成等全流程工作。

## 产品形态

EasyClaw 分为国际版和国内版：
- **国际版**：分为企业版（easyclaw.work）和个人版（easyclaw.com）。
- **国内版**：名为“元气AIBot”（yuanqiaibot.net），采用自主研发框架。

## 实战验证

[[傅盛]] 春节期间“养”出的 AI 团队 [[三万]]，正是基于 EasyClaw 技术栈运行。这次 14 天的硬核实验被视为 EasyClaw 最成功的内测案例，证明了其在真实高强度业务场景下的可行性。

## 愿景

EasyClaw 的终极形态是让每个人都能拥有自己的 AI 团队。它试图将 AI Agent 从“被动工具”转变为“主动智能体”，让用户像指挥员工一样指挥 AI，无需编写代码。
