# ChatGPT Pulse

**ChatGPT Pulse** 是 [[OpenAI]] 于 2025 年 9 月发布的首个主动式异步助手，被视为 AI 产品形态从“被动响应”转向“主动服务”的早期标志。

## 核心功能

- 基于用户与 ChatGPT 的最近对话内容
- 配合 Gmail 和 Calendar 连接器
- 每天早上推送一份个性化简报

## 行业意义

Pulse 被定位为 OpenAI 首次让 ChatGPT 主动找用户说话的产品，标志着 AI 竞争从“回答能力”转向“服务能力”的开端。

## 与 Orbit 的对比

与 [[Orbit]] 相比，ChatGPT Pulse 的连接器主要集中在 Gmail + Calendar + Memory 这种邮件日历型组合，目标用户更偏向处理邮件和日程的高管。而 Orbit 通过集成 GitHub 和 Figma，将目标用户扩展至产品研发团队（开发者、设计师、产品经理）。
