# Teknium

Teknium 是 [[nous-research]] 的联合创始人兼首席科学家，[[hermes-agent]] 项目的核心领导者。

## 核心观点

Teknium 在 Hermes 击败 [[codex]] 的讨论中明确阐述了 Python vs Rust 的架构决策理念：

> "那样就无法编辑代码，以及实时改进和迭代。"

他认为 Python 的优势不在于"快"，而在于"活"——对于一个需要持续进化、从每次交互中学习的 Agent 来说，开发者友好性和迭代速度就是最大的性能优势。这一观点直接回应了"为何不将 Hermes 迁移到 Rust"的质疑。
