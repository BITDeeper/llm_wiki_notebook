# Gemini API File Search

Google [[gemini]] API 中的文件搜索功能，于2026年5月5日更新引入多模态检索能力，是推动[[多模态-rag]]进入产业可用阶段的标志性产品更新。

## 核心能力

- 将RAG的处理对象从文本片段扩展到PDF页面、图表、截图、图片和表格区域等多模态证据单元
- 支持对图像进行原生向量化与检索
- 覆盖文件导入、切片、向量化、索引和检索全流程
- 结合元数据过滤和页级引用，支持按客户、版本、权限、时间、文件类型等业务边界控制召回范围
- 将回答定位至具体页面和来源位置，提升生成结果的可核验性

## 工程意义

该功能将文件导入、切片、向量化、索引和检索下沉到平台层，减少企业自行拼接RAG管线的工程成本。对企业部署LLM与RAG的成本、门槛和知识库利用率产生直接影响。

## 在AI社区的影响

在AI社区引发了关于企业部署LLM与RAG的成本、门槛和知识库利用率的热烈讨论。过去企业内部沉淀的大量PDF、表格、截图、图表和业务文档往往难以稳定转化为模型可用上下文，Gemini API File Search的多模态能力为这一问题提供了平台级解决方案。
