# Zoë Hitzig

Zoë Hitzig 是 [[openai]] 的研究员。她在 OpenAI 决定在产品中引入广告测试的当天选择辞职，成为公司内部商业化压力与理想主义冲突的标志性人物。

## 辞职事件
Hitzig 强烈反对 OpenAI 引入广告模式，认为这损害了用户隐私和用户体验，违背了公司早期的非盈利初衷。她撰文警告 OpenAI 不要重蹈 Facebook 的覆辙，即为了追求利润最大化而牺牲平台生态健康和用户信任。她的辞职引发了外界对 OpenAI 商业化转向的广泛讨论。
