# Claude Code Agent Teams

Anthropic 旗下 [[claude-code]] 的多智能体编程模式，被视为 AI 编程领域的重要基准之一。

## 竞争对比

在 [[阿里-Qoder]] 公布的内部复杂任务基准测试中，Qoder 的 [[专家团模式]] 在代码质量得分上领先 Claude Code Agent Teams **16%**。

这一数据反映了多智能体协同编程领域激烈的竞争现状，不同厂商在智能体分工、上下文管理及协同效率上采取了不同的技术路径。
