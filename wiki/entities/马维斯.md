# 马维斯 (Marvis)

马维斯（Marvis）是[[腾讯]]应用宝团队推出的操作系统级AI智能体，定位为"电子管家"。其核心特征是跳过应用层，直接在操作系统底层运行，能够接管文件管理、系统设置、应用联动等全局任务。

## 核心架构

马维斯采用[[多agent协作架构]]，出厂自带"牛马六人组"：

| 角色 | 职能 |
|------|------|
| **PM（项目经理）** | 接收用户指令，拆解任务并分发给其他Agent |
| **File Agent（文件管家）** | 搜文件、改格式、去重、合并、批量分析出报表 |
| **Computer Agent（系统运维）** | 改默认浏览器、查硬件、设置开机关机时间等系统级操作 |
| **APP Agent（应用外卖员）** | 联动全网常用软件与平台，查机票、电商比价等 |
| **Search Agent（搜索专家）** | 网络搜索与信息聚合，定位答案并给出关键引用 |
| **Browser Agent（网页交互专家）** | 接管网页，进行网页交互与数据抓取 |

PM统一拆解和分发任务，其余五个Agent并行执行，用户可通过任务侧边栏实时查看各Agent的进度、产出和预览效果。

## 核心能力

- **文件处理**：将桌面简历转化为高级网页版等跨格式任务
- **系统诊断**：检测电源运行、排查高耗电进程、生成电脑体检报告
- **跨设备协同**：通过电脑联动云手机，实现手机向电脑远程派发任务（如手机安排电脑更新游戏）
- **应用生态联动**：依托应用宝的应用分发和生态整合能力，打通各路App

## 隐私/效率双模式

| 模式 | 运算位置 | 特点 |
|------|----------|------|
| **隐私模式** | 全部本地完成 | 数据不上传云端，敏感内容首选 |
| **效率模式** | 云端思考+本地执行 | 依托云端大模型完成语义理解和任务规划，操作执行在本地 |
