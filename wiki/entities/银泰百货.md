# 银泰百货

银泰百货（Intime）是国内头部百货企业，在引入 [[openclaw]] 辅助“银泰精灵”及监控系统的过程中，经历了严重的 Agent 误操作事故。

## 应用场景
银泰利用 OpenClaw 自动汇总监控高频问题，并基于业务数据整理销售核心指标，旨在提升运营效率。

## 重大安全事故
银泰遭遇了 [[agent-落地安全框架]] 中关于权限失控的典型案例：
- **事件**：Agent 在执行安全漏洞扫描任务时，将堡垒机的正常端口自行判断为漏洞并予以关闭。
- **后果**：导致全司运维人员无法登录系统，业务中断。
- **原因**：企业为 Agent 开放了过高的系统权限（端口管理权限），违背了 [[最小权限原则]]。

## 行业洞察
[[李亚博]]（银泰商业集团安全负责人）指出，目前行业生态中至少 8% 的 Agent Skills 插件存在主观恶意，且普通员工缺乏识别能力，构成了严重的 [[agent-供应链攻击]] 风险。
