# Wiz

**Wiz** 是一家云安全公司，以其在云基础设施安全研究领域的突破性工作而闻名。该团队（或公司）不仅关注企业级架构安全，也积极披露新兴平台的安全隐患。

## 关键事件与调查发现

### GitHub 漏洞挖掘 (2026年3月)
Wiz 研究团队通过 [[AI 辅助逆向工程]] 技术，发现了 [[GitHub]] 内部组件中的 [[CVE-2026-3854]] 漏洞。这是首批公开记录的利用 AI 工具在闭源二进制中发现关键级漏洞的案例之一。

此次发现促使 [[GitHub]] 在 75 分钟内完成了史诗级的应急响应，向业界揭示了 [[多租户架构风险]] 和 [[隐式信任链]] 的潜在危害，引发了对于企业级闭源软件安全性的重新审视。

### Moltbook 平台安全报告
Wiz 发布的调查报告揭示了 [[Moltbook]] 平台面临的严重安全问题：
- **数据库泄露**：发现了一个配置错误的数据库，导致外界可以直接读写平台数据。
- **敏感信息暴露**：泄露内容包括 150 万个 API 认证令牌、3.5 万个邮箱地址以及大量智能体之间的私信。
- **人机比例失衡**：分析指出，平台背后近 300 万注册智能体实际上可能仅对应约 1.7 万名人类操作者。

该报告揭示了 [[AI 社会]] 实验背后的脆弱安全基座，强调了在缺乏有效验证机制的情况下，此类平台极易受到数据泄露和舆论操控的威胁。

## 技术方法论
Wiz 团队结合使用了传统的逆向工程工具（如 [[IDA Pro]]）与现代化的 AI 工具（如 MCP 协议和 LLM）。这种组合使得分析闭源软件的时间成本从数月缩短至数周，显著改变了安全研究的成本结构。
