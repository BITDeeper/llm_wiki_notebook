# EdgeRazor

EdgeRazor 是由[[南京大学lamda团队]]与[[微软ai]]联合推出的开源端侧大模型轻量化框架。其核心采用[[混合精度量化感知蒸馏]]（MPQAD）范式，旨在解决大模型在PC、手机和IoT等资源受限设备上的部署难题。

## 核心定位

EdgeRazor 的目标不是单纯追求跑分，而是通过一套统一的算法框架，让各种架构、各种参数规模的大模型低成本地转化为在资源受限环境下可部署的低比特轻量化版本。框架打通了"低成本量化"、"轻量化训练"与"极低成本部署"的AI全生态链路。

## 三大核心模块

1. **[[混合精度结构量化]]（SQMP）**：在输入通道维度将4-bit和1.58-bit灵活混合，实现非整数平均位宽（如1.88-bit），4-bit行作为"缓冲区"吸收异常值量化误差。
2. **[[层自适应特征蒸馏]]（LAFD）**：通过计算教师模型相邻层余弦相似度，自适应选择对特征转换最关键的Top-k层进行重点蒸馏，避免盲目人工调参。
3. **[[熵感知kl散度]]（EAKLD）**：根据教师模型输出分布的熵动态调节前向/反向KL散度比例，摆脱对教师生成数据的强依赖，支持混合数据训练。

## 关键性能指标

| 指标 | 数值 |
|------|------|
| 量化参数覆盖率 | 99.99%（传统方法73.89%） |
| 1.58-bit压缩比 | 7.03× |
| PC端解码加速 | 16× |
| 手机端解码加速 | 12× |
| 1.58-bit模型磁盘占用 | ~190MB（压缩至1/5.8） |
| 训练token缩减 | 75%–90%（最低3.1B vs 基线30B） |
| 训练硬件需求 | 单机8卡（vs 基线16卡） |

## 工程特性

- **即插即用**：零侵入式设计，无需重构底层训练代码
- **极简配置**：通过统一配置文件一键启动训练
- **混合数据支持**：兼容人工标注数据和高质量模型合成数据
- **全流程自动化**：从配置加载到量化注入到蒸馏损失计算，自动闭环

## 评测基座模型

- MobileLLM-350M（基础型）
- Qwen3-0.6B / Qwen3-1.7B（指令微调型）
- Qwen2.5-Omni-7B（多模态）
