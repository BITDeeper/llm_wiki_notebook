# Brian Chesky

**Brian Chesky** 是 Airbnb 的联合创始人兼 CEO。

## 观点与行动
Chesky 是 [[qwen]] 模型在硅谷企业级应用中的核心背书者之一。他公开表示：
- Airbnb 在很大程度上依赖阿里巴巴的 Qwen 模型。
- Qwen 非常好，速度很快，而且很便宜。
- 虽然也会使用 OpenAI 的最新模型，但在实际生产中通常不会大量使用，因为有更快、更经济的模型可供选择。

尽管 Chesky 与 Sam Altman 是挚友，但在产品整合上坚持“亲兄弟，明算账”，选择了性价比更高的中国开源模型。
