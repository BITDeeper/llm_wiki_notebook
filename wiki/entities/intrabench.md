# IntraBench

**IntraBench** 是由 [[佐治亚大学]] 团队联合五个STEM学科专家构建的专家级基准测试集，用于评估AI智能体在 [[intraview]]（文献内部信息检索）任务上的表现。

## 核心特征

- **规模**：包含 **315个专家级测试实例**
- **领域覆盖**：物理、地球科学、公共卫生、工程、材料科学五个代表性STEM领域
- **设计理念**：关注文献解析的「深度」而非文献数量的「覆盖度」

## 领域代表性

| 领域 | 挑战特征 |
|------|----------|
| 物理学 | 复杂公式推导和严苛的边界约束 |
| 工程学 | 复杂公式推导和严苛的边界约束 |
| 地球科学 | 庞大而精确的模拟参数 |
| 公共卫生学 | 精确的统计元数据 |
| 材料科学 | 多步骤、高灵敏度的实验配方与工艺条件 |

## 设计特色

- 所有测试实例均由各学科专家依据实际科研场景痛点亲自设计
- 问题构建要求模型具备多步骤逻辑推理能力，需跨越不同章节进行信息比对
- 经过严格的可用性筛选，过滤掉可通过模糊语义检索直接获取答案的浅层问题
- 每个问题都必须依赖对文献上下文逻辑链条的完整掌握才能准确作答
- 被定位为检验AI智能体是否具备真正专家级精读能力的「试金石」

## 关联

IntraBench 是 [[intragent]] 框架评估的核心基准，该框架在此基准上较当前最优基线实现了13.2%的准确率提升。
