# M2.7

M2.7 是 MiniMax 于 2026年3月18日发布的最新一代大语言模型，专注于编程和 Agent 应用场景。它是业界首个在训练过程中深度参与自我迭代的商用大模型。

## 核心特性

### 自我进化能力
M2.7 在一套内部 Agent Harness 中运行，包含短时记忆、自反馈和自优化模块。其自我进化体现在三个层次：
1.  **任务执行**：在 MiniMax 的强化学习团队中承担了 30%-50% 的日常工作流。
2.  **框架优化**：自主运行优化循环超过 100 轮，使评测效果提升 30%。
3.  **模型迭代**：在 MLE Lite 的 22 道高难度竞赛中获得 9 金 5 银 1 铜，得牌率 66.6%。

### Agent 场景优化
M2.7 针对智能体运行框架进行了专门优化：
- **工具调用准确度**：针对复杂工具链进行了专项训练。
- **复杂 Skills 遵循**：在 40 个复杂 Skills（每个超过 2000 Token）的测试中，保持了 97% 的遵循率。
- **长上下文一致性**：确保在长对话和复杂任务中的逻辑连贯性。

## 应用与生态
M2.7 已被多个全球头部开源项目和应用采用：
- [[hermes-agent]]：M2.7 是其中使用量最高的模型之一，日均 Token 消耗超过 250 亿。
- [[openclaw]]：创始人 Peter 公开称赞 M2.1（前代）能以 5% 的成本达到顶尖闭源模型的效果。
- Notion Custom Agents 和 Kilo Code 也将其作为默认或首选模型。

## 技术意义
M2.7 的发布标志着模型开发从“通用能力比拼”转向“特定场景深度优化”。它验证了“Model + Harness”双向飞轮的可行性，即模型通过在 Harness 中运行产生的数据来反哺自身进化。
