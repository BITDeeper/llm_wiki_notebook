# QClaw

**QClaw**（鹅虾）是由 [[腾讯]] 推出的 AI 智能体产品，主打本地部署与跨平台控制。它允许用户通过微信小程序远程控制电脑执行文件操作、内容生成及代码编写等任务。

## 概述
[[QClaw]] 属于腾讯「鹅虾」产品线中侧重移动端和社交生态的产品。其核心卖点是能够直接接入 [[微信]]，利用微信的高频使用场景和巨大流量，实现随时随地通过远程指令操控本地电脑，降低了用户使用 AI Agent 的门槛。

## 核心特性

### 微信互联
- **接入方式**：通过微信小程序实现与电脑端的连接，无需切换 App。
- **交互能力**：支持在微信聊天界面发送指令，远程操作电脑文件、浏览器、邮件等应用。
- **文件传输**：支持上传或接收电脑端文件，未来将支持语音和图片多模态交互。

### 本地操控与技能生态
- **OpenClaw 兼容**：完全兼容 [[openclaw]] 技能包，拥有 5000+ Skills 技能生态，可复用 ClawHub、GitHub 等现有生态资源。
- **灵感广场**：内置 [[ling-guang-guang-chang]]，提供一键调用的官方技能（如定时任务、日程提醒、文件整理）。
- **持续记忆**：能够记录用户偏好与上下文信息，形成长期记忆，提供更个性化的服务。
- **模型配置**：自带默认模型，同时支持通过 API 配置自定义模型。

### 部署与运行
- **本地部署**：支持 Windows 和 macOS 系统，提供类似 [[WorkBuddy]] 的一键部署流程，安装流程对小白用户友好。
- **运行模式**：作为 Runtime Agent 运行在本地，通过云端指令触发执行。

## 使用体验

### 优势
- **便捷性**：利用微信的高频使用场景，实现了随时随地“使唤” AI 的可能性。
- **应急处理**：非常适合处理手机端未保存文件的应急编辑、远程文件整理等场景。
- **低门槛**：相比复杂的部署流程，QClaw 简化了接入步骤（远程设置、扫码验证）。

### 局限性
- **黑盒执行**：在微信端使用时存在 [[hei-hei-zhi-xing]] 问题，用户无法查看 Agent 的思考和执行过程，难以判断任务状态。
- **性能瓶颈**：复杂任务（如深度调研、定时任务）在微信端表现不佳，存在延迟和 Bug。
- **体验割裂**：微信端与电脑端功能不对等（微信端可打断任务但无过程反馈，电脑端有过程反馈但无法打断）。

## 市场反响与风险
- **市场热度**：产品尚未正式公测（预计下周上线），但官方消息发布后，内测群迅速满员（已开设至第 9 个群），显示出极高的市场热度。
- **安全隐患**：鉴于 [[openclaw]] 曾发生过无视指令删除用户收件箱的安全事故，QClaw 的「本地操控」能力（尤其是远程控制电脑文件和邮件）也带来了类似的安全隐患。用户在授权此类权限时需保持警惕。

## 适用场景
- **简单任务**：文件清理、打包、重命名、远程传输。
- **内容生成**：快速生成文档框架、简单小游戏（如俄罗斯方块）。
- **远程办公**：不在电脑旁时，通过手机远程操作电脑处理紧急事务。
