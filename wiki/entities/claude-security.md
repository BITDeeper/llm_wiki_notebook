# Claude Security

**Claude Security** 是 [[anthropic]] 推出的企业级自动化安全修复工具，专为 Claude 企业版客户打造。其核心逻辑是：不仅帮助发现代码库中的漏洞，还直接自动生成修复补丁。它与 [[mythos-1]] 深度配套，构成 Anthropic "代码+安全"双螺旋结构的安全侧。

## 关键信息

- **底层引擎**：使用 Opus 4.7 模型
- **上线时间**：约2026年5月初
- **上线三周成果**：企业客户已修复超过**2,100个**漏洞
- **定位**：[[project-glasswing]] 的配套防御产品，代表"AI发现漏洞、AI修复漏洞、人类审核"的终极安全范式

## 产品形态

一个全新的安全仪表盘正在搭建中，功能包括：

- 展示已发现的漏洞
- 7天和30天历史图表
- 更深层的分类分析结果

目前仅面向企业客户开放。

## 与 Mythos 的关系

[[claude-mythos-preview]] 负责发现漏洞和构建攻击链，Claude Security 负责自动生成修复补丁。两者共同构成了 Anthropic "用魔法打败魔法"的安全产品矩阵。

## 战略定位

Claude Security 与 [[claude-code]] + Mythos 形成互补的产品矩阵：

- **Claude Code + Mythos**：面向开发者的安全编程助手
- **Claude Security + Mythos**：面向企业的自动化漏洞发现与修复平台

两者共同构成 Anthropic 在代码生成与代码安全领域的双线布局。
