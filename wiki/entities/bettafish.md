# BettaFish (微舆)

BettaFish（微舆）是一个多 Agent 舆情分析助手，由大四学生 [[bai-fu]] 开发。该项目是其大学毕业设计，也是 [[vibe-coding]] 开发范式的早期成功案例。作为 [[mirofish]] 的前作，BettaFish 曾登顶 GitHub 全球趋势榜第一。

## 核心功能
BettaFish 旨在帮助用户破除信息茧房，还原舆情原貌，预测未来走向，辅助决策。其标语强调“人人可用”，致力于将专业的舆情分析工具大众化。

- **全网搜索**：根据输入的热点话题，自动从国内外 30+ 主流社交媒体平台获取相关信息及数百万条大众评论。
- **多 Agent 协作**：组建 AI 团队对信息进行总结、碰撞和分析。
- **交互方式**：用户通过聊天对话提出分析需求。
- **报告生成**：智能体全自动分析，并生成一份数十页的结构化舆情分析报告。

## 技术实现
结合了自动化数据抓取、大模型分析、自动报告生成等技术。它尝试用 AI 将过去需要一整个团队完成的舆情分析工作自动化。

## 发展历程
- **开发**：利用 [[claude-code]] 等 AI 工具，仅用 10 天完成。
- **初期反馈**：最初被博士学长批评为“不是一个合格的毕设”。
- **爆发**：在 GitHub 开源一周内获得了 20k Stars。在达到 1,000 Star 后，通过社交媒体传播引发流量爆发，几天内新增 Star 超 2 万，迅速登顶 GitHub Trending 榜。
- **成果**：项目的成功直接促成了 BaiFu 与盛大集团创始人 [[陈天桥]] 的接触，并孵化出后续项目 [[mirofish]]，为后续获得 3000 万投资奠定了基础。

## 投资人评价
盛大集团创始人 [[陈天桥]] 认为，虽然 BettaFish 的技术水平并非特别出色，但其展现了从数据收集、分析到预测的全流程规划能力，以及“定义并解决有价值问题”的行动力。

## 意义
BettaFish 验证了“从垂直领域切入”的产品策略。它是 [[vibecoding]] 开发范式下的首个成功案例，展示了个人开发者利用 AI 快速构建复杂应用的能力。
