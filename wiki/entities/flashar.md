# FlashAR

FlashAR 是由 [[浙江大学]] 与 [[阿德莱德大学]] 联合提出的 [[后训练加速|后训练]] 加速框架，用于将预训练好的 [[自回归图像生成]] 模型改造为高度并行的生成器。

## 核心思路

FlashAR 的关键洞察在于：图像天然具有 2D 结构，为模型新增垂直方向的预测能力后，解码步数可从 H×W 骤降至 H+W-1。以 512×512 分辨率（16×16 下采样）为例，解码步数从 1024 步降至 63 步。

## 三大关键组件

### 1. [[中间层分支]]
从预训练模型中间层（而非最终层）引出垂直预测头（Vertical Head）。核心洞察：最终层特征已充分适配水平方向光栅预测任务，而中间层保留更丰富的 2D 空间信息，更适合适配新的垂直预测方向。消融实验通过 linear probing 系统验证了这一设计。

### 2. [[可学习融合门]]
轻量级 MLP，在逐位置粒度上自适应融合水平与垂直方向的预测结果，避免简单平均导致的预测模糊。两个方向的预测分别建模了互补的空间依赖，其贡献在不同空间位置上并不一致。

### 3. [[两阶段适配训练]]
- **第一阶段**：冻结骨干网络，仅优化垂直预测头，快速学习有意义的预测能力
- **第二阶段**：联合微调垂直预测头和骨干网络，适配新的解码范式

渐进式策略提升训练稳定性和数据利用效率。

## 推理优化

部署阶段利用 FlexAttention 动态编译稀疏 2D 近邻注意力掩码，配合批量化 KV 缓存更新，将理论并行性转化为真实加速效果。

## 实验结果

### Emu3.5-Image-34B
- **加速**：130.10秒 → 5.68秒（**22.9 倍**端到端加速）
- **数据效率**：仅用 0.05% 原始训练数据（约 8 万张图片）
- **质量保持**：GenEval 总分仅下降 0.19（80.48→80.29）
- **部分指标提升**：颜色 +1.59，位置 +7.00

### ImageNet 类别条件生成（LlamaGen 系列）
- FlashAR-L 的 IS（289.0）超过从头训练的 NAR-L（263.9）
- FlashAR-B 吞吐量 447.2 img/s，超过 NAR-B（419.7 img/s）
- 仅需 25 个 epoch 后训练，为 BlockDiffusion 训练量的三分之一

### 对比优势
BlockDiffusion 在相同设置下 GenEval 大幅下降至 73.83，而 FlashAR 几乎无损。

## 核心价值主张

FlashAR 证明：通过精心设计的后训练适配，可以在几乎不改变原始模型训练目标的前提下，将自回归模型改造成高度并行的生成器，完整继承预训练模型的强大能力。
