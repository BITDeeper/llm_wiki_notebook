# Peter (龙虾之父)

Peter，网名“龙虾之父”，是 AI 工具 [[openclaw]] 的开发者。他目前任职于 [[openai]]，负责协助制定未来的产品战略。

## 职业背景

尽管在 OpenAI 工作，Peter 通过 OpenClaw Foundation 致力于支持多模型生态，主张工具应兼容包括 [[anthropic]] Claude 在内的各种主流模型提供商。

## 封号事件

2026 年 4 月，Peter 的 Claude 账号（包括订阅和 API 权限）被 Anthropic 以“违反使用政策”为由封禁。他在社交媒体上表示，这将使 OpenClaw 继续支持 Anthropic 模型变得困难。

随后，Anthropic 员工介入，解释称是触发了过于敏感的滥用检测分类器（Bug），并恢复了他的权限。

## 争议

*   **利益冲突**：作为 OpenAI 员工频繁使用竞品模型进行测试，引发了社区关于边界模糊的讨论。
*   **测试目的**：Peter 解释称使用 Claude 是为了进行端到端（e2e）测试，确保 OpenClaw 的改动不会在主流模型上出问题。
