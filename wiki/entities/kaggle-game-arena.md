# Kaggle Game Arena

**Kaggle Game Arena** 是2026年2月举办的一场特殊AI博弈竞技场，旨在测试大语言模型在社交直觉、欺诈策略和非完美信息处理方面的能力。

## 核心赛制

### 狼人杀
- **配置**：8位顶级模型参赛（2狼 vs 6好人）。
- **目的**：测试AI的伪装、结盟与煽动能力。
- **结果**：在平民极度有利的情况下，狼人（少数派）通过信息差和逻辑陷阱拿下了近40%的胜率。

### 复式德州扑克
- **机制**：采用 Duplicate Poker 赛制，给不同选手发同样的牌，剥离运气因素。
- **目的**：测试AI在纯逻辑与心理博弈中的诈唬能力。
- **规模**：经历了90万手牌的暴力洗礼。
