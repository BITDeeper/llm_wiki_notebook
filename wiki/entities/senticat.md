# SentiCat

**SentiCat** 是由 [[SentiPulse思维光谱]] 开发的桌面 AI Agent 产品，于 2026 年 4 月开启公测。该产品以“AI 小猫”和虚拟形象“SUSU”为核心，旨在结合生产力工具与情感陪伴，提供兼具效率与情绪价值的 AI 体验。

## 核心功能
SentiCat 定位为全能型桌面助手，具备以下三大核心能力：
1.  **办公自动化**：支持一键生成 PPT、Excel 表格及文档处理。
2.  **深度研究**：能够自动执行网页搜索、内容抓取与数据分析，生成结构化的行业研究报告。
3.  **代码开发**：提供代码编写与调试辅助功能（基于 MCP/Skill 扩展）。

## 产品特色

### 双重角色设计
-   **SUSU**：负责情感交互的虚拟形象，拥有动态表情、随机动作和拟人化性格，提供 [[情绪价值]]。
-   **AI 小猫**：负责具体任务执行的 Agent，通过调用工具链完成用户指令。

### 隐私与安全
SentiCat 采取“本地优先”的数据策略：
-   所有聊天记录、个人偏好和文件资料存储于 [[本地SQLite数据库]]，不上传云端。
-   API 密钥本地加密，不经手第三方服务器。
-   代码执行与插件运行在隔离沙盒环境中。

### 技术架构
-   **自研框架**：底层架构由 SentiPulse 自主研发，宣称非套壳产品。
-   **多模型支持**：接入 MiniMax、通义千问、DeepSeek、豆包、Kimi 等 7 款国内主流基座模型，用户可根据需求自由切换。

## 实测表现
根据量子位评测，SentiCat 在以下场景表现突出：
-   **报告生成**：成功生成 17 页、7000 字的行业深度研究报告，结构完整，数据详实。
-   **任务可视化**：执行过程（搜索、抓取、写入）清晰可见，符合 [[场景白盒化推理]] 理念。
-   **局限性**：在复杂旅游规划中出现了行程安排过载和时间逻辑错误，显示其在常识推理和长逻辑规划上仍有提升空间。

## 扩展性
支持通过 MCP (Model Context Protocol) 和 Skill 接入第三方工具（如 12306 查询、麦当劳插件），允许技术背景用户扩展其能力。
