# GaussianDWM

GaussianDWM 是一个基于 [[3dgs-3d高斯溅射|3D高斯场景表示]] 的 [[自动驾驶世界模型]]，由 [[上海交通大学]]、[[清华大学]]、旷视科技和 Mach Drive 联合提出，被 CVPR 2026 收录。

其核心目标是解决传统驾驶世界模型仅关注视觉生成而缺乏显式 3D 环境建模能力的问题。GaussianDWM 将 3D 高斯表示作为连接器，统一承载几何、外观和语言语义，使同一组表示既能输入 LLM 进行场景理解与查询，也能作为条件指导多模态生成。

## 核心架构设计

GaussianDWM 的框架包含三个关键设计：

1. **[[语言增强的3d高斯分词器]]**：将 CLIP 和 SAM 提取的语言语义特征注入 3D 高斯基元，并通过自编码器将 512 维特征压缩至 3 维，使高斯基元转化为携带语义的 3D token。
2. **[[任务感知采样]]**：由于密集的 3D 高斯场无法直接输入 LLM，模型根据任务需求进行动态采样（全局理解使用均匀/Top-K采样，视觉定位使用基于文本相似度的采样），提取 4096 个紧凑 Token 输入 LLM。
3. **[[双条件生成]]**：在生成阶段，同时利用低层视觉条件（稀疏 RGB/深度）维持纹理细节，并利用 LLM 提取的高层世界知识（语义和空间先验）维持空间几何一致性。

## 性能与表现

在 NuInteract 数据集上，GaussianDWM 在场景理解任务上的综合指标达到 59.23，显著超越基线 DriveMonkey（52.12），3D 视觉定位 mAP 达到 52.78。

在 nuScenes 数据集上的多模态生成任务中，消融实验证明，在大视角变化（如 ±4m）下，高层世界知识的引入能显著降低 FID（从 21.79 降至 18.91），有效维持了场景的空间几何一致性。
