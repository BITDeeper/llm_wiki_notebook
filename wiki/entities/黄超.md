# 黄超

**黄超**是香港大学助理教授、博士生导师，知名AI开源项目开发者，Agent 技术领域的资深研究者。

## 职业背景
- **现任职位**：香港大学助理教授、博士生导师。
- **研究方向**：大型AI智能体、语言模型及图机器学习。
- **学术影响力**：研究成果在Google Scholar上被引用超过17,000次。

## 开源贡献
黄超团队推出了多个具有影响力的开源项目：
- **[[LightRAG]]**：开源检索增强生成（RAG）框架。
- **nanobot**：AI智能体相关项目。
- **CLI-Anything**：命令行工具项目。
- **HKUDS**：团队打造的GitHub开源平台累计获得超过240,000 Stars，位列全球Top50，并超过100次登上GitHub Trending榜单。

## 核心观点与技术洞察

### Agent 技术的三大模块
黄超将 Agent 技术抽象为三个核心模块：
1.  **Planning（规划）**：当前痛点在于长程任务（如 500 步）的规划能力不足，本质是模型缺乏隐性知识。需要通过 Skills 机制来缓解规划错误。
2.  **Memory（记忆）**：面临信息压缩失真和检索效率问题。未来需要走向分层设计，并解决多模态场景下的通用记忆管理。
3.  **Tool Use（工具使用）**：当前高质量的 Skill 仍然稀缺，且存在安全风险。需要依靠社区建设更好的生态。

### Agent-Native 范式
他提出了 **[[agent-native]]** 的激进观点。他认为未来很多软件可能 **不再以人类为中心** 设计。因为人类需要 GUI，但 Agent 更倾向于使用 CLI 或 API。未来的软件架构将原生面向 Agent 使用，人类只保留那些让自己感到愉悦的交互，而大量执行性工作将转移给 Agent。

### 对 OpenClaw 的评价
他认为 [[openclaw]] 的爆火在于给了大家“活人感”和“贾维斯”的感觉，其简单的 Agent Loop 架构再次被证明是高效的。它撬动了整个开源生态，让更多人参与到 AGI 的变革中。
