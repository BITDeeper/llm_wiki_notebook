# 镝数科技

**镝数科技**是[[王琼]]教授团队背后的商业化实体，专注于数据表达与数据可视化领域。该公司是[[爱图表]]（Aitubiao.com）的开发者。

## 发展历程与成就
- **战略合作**：与[[金山办公-WPS]]达成战略合作，共同推进数据可视化在办公场景的应用。
- **国际认可**：作为中国唯一入选联合国「创韧项目」的企业。
- **行业标准**：作为行业首个起草单位，发布了《数据新闻制作流程》团体标准。

## 业务定位
镝数科技致力于成为“AI 工作流的数据表达基础设施”。除了开发面向 C 端的爱图表产品外，还通过 API 和 Skill 集成（如[[飞书-Aily]]、[[网易-Lobster]]等）向 B 端和开发者提供服务。

## 核心价值
依托[[武汉大学数据新闻研究中心]]的学术背景，镝数科技在数据语义理解、复杂图表渲染及数据叙事逻辑方面积累了深厚的技术壁垒，强调[[白盒-ai]]和可控性。
