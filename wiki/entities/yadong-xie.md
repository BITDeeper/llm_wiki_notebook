# Yadong Xie

Yadong Xie 是英伟达（NVIDIA）的开发者，因发现并制作 [[claude-code]] 隐藏功能“[[Buddy System]]”的交互界面而受到关注。

## 发现与贡献
在分析 Claude Code 源码时，Xie 发现了代码中内置的一个完整的电子宠物系统。他为此开发了一个交互界面，使用户能够与这些电子宠物进行实时互动。这一发现揭示了 Claude Code 功能的丰富性，被 [[Andrej Karpathy]] 戏称为“龙虾化”。
