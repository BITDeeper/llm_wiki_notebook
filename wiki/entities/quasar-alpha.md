# Quasar Alpha

Quasar Alpha 是一个历史 [[stealth-model]]，于 2025 年 4 月出现在 OpenRouter 上。它是社区成功“破案”的第一个典型案例。

## 识别证据
- **Tokenizer 指纹**：处理中文时出现了 OpenAI 特定的 tokenizer 错误（此前只在 OpenAI 模型上出现过）。
- **API 行为**：支持 `name` 字段，且行为限制与 OpenAI API 完全一致。
- **官方确认**：OpenRouter 后来确认其为 GPT-4.1 的早期测试版本。

## 意义
Quasar Alpha 的出现确立了社区识别 Stealth 模型的标准方法论，即通过技术指纹而非仅凭性能表现来判断模型归属。
