# Project Genie

**Project Genie** 是由 [[google-deepmind]] 推出的网页应用项目，旨在将 [[世界模型]] 的能力带给大众用户。它被视为谷歌在游戏和模拟领域的一次重大尝试，试图通过自然语言提示词或图片实时生成可玩的 2D 游戏环境。

该项目集成了 [[genie-3]]、[[Nano Banana Pro]] 和 [[gemini]] 三个核心模型，其宏大目标是“模拟一切”，应用场景涵盖机器人训练、动画制作以及探索历史场景，试图解决现实世界中“无剧本”的预测问题。

## 核心功能与体验

Project Genie 的体验主要围绕以下三个核心环节展开：

### 1. 世界速写
用户无需懂代码或 3D 建模，仅需输入文本提示词或上传图片，即可利用 [[Nano Banana Pro]] 生成并调整世界的视觉预览。这极大地降低了内容创作的门槛，允许用户快速构建一个可交互的虚拟环境。

### 2. 世界探索
这是对传统游戏引擎最具颠覆性的功能。与传统游戏读取预制静态地图数据不同，Project Genie 利用 [[Genie 3]] 在玩家移动时**实时生成**前方的路径。它通过预测玩家下一步会看到什么并瞬间渲染出来，实现了“路是因为你迈出了脚才存在”的动态体验。

### 3. 世界重混
允许用户在画廊中混搭现有世界，或通过自然语言修改角色和环境。这种“混音”式的逻辑旨在催生一种全新的 UGC（用户生成内容）生态，创造无限数量的新世界。

## 技术局限性与争议

尽管概念惊艳，但 Project Genie 目前仍处于早期阶段，面临诸多批评：

- **体验碎片化**：单次生成视频时长上限仅为 60 秒，且无法保存状态供后续继续游玩。
- **功能缺失**：缺乏声音、计分系统和持久化存储机制。
- **逻辑不稳定**：物理规律经常失灵，例如道路可能突然变成草地，角色可能穿模。
- **黑盒属性**：生成的内容本质上是互动视频流，而非可编辑的游戏代码，无法导出到 Unity 或 Unreal Engine 进行二次开发。

## 市场影响

Project Genie 的发布引发了资本市场的恐慌反应，反映了投资者对 AI 颠覆传统游戏开发和分发模式的高度预期，但也暴露了技术愿景与当前现实之间的巨大落差：

- [[unity]] 股价暴跌 24.22%。
- [[roblox]] 股价下跌 13.17%。
- Take-Two 股价下跌 7.93%。
