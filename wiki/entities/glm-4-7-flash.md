# GLM-4.7-Flash

GLM-4.7-Flash 是 [[智谱]] 推出的大语言模型版本，主要特点是**完全免费**。

## 应用场景

### 降低 Agent 使用成本
在 [[autoclaw]] 等客户端中，GLM-4.7-Flash 被作为默认选项之一，旨在解决 Agent 任务（尤其是长上下文、多步骤任务）消耗 Token 量巨大导致的成本问题。用户可以使用该免费模型处理日常轻量任务，仅在需要更高推理能力时切换至付费模型（如 GLM-5 或 Pony-Alpha-2）。

### 模型热插拔
它是 AutoClaw 支持 [[模型热插拔]] 特性的关键组成部分，为用户提供了一条零成本入门 AI Agent 的路径。
