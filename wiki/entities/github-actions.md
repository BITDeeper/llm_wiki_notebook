# GitHub Actions

GitHub Actions 是 GitHub 提供的持续集成和持续交付（CI/CD）平台。

## 在 AI 隐形技术栈中的地位

根据 Amplifying.ai 的研究，GitHub Actions 在 CI/CD 类别中展现出近乎垄断的地位：

### 数据表现
- **首选率**：93.8%
- **类别**：CI/CD

### 含义
当 [[Claude Code]] 需要配置自动化工作流时，超过 9 成的情况下会推荐 GitHub Actions，而非 GitLab CI、CircleCI 或 Jenkins。这使得 GitHub Actions 成为 AI 辅助开发模式下的事实标准。

## 稳定性特征

GitHub Actions 类别在“措辞变化测试”中表现出极高的稳定性——即使使用 5 种不同的方式提问，Claude Code 仍然会推荐 GitHub Actions。这表明该工具在 AI 的“认知”中已与 CI/CD 概念深度绑定。
