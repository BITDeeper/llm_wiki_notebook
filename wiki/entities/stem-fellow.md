# STEM Fellow

[[STEM Fellow]] 是 [[Anthropic]] 推出的一个研究员驻场项目，旨在通过引入各领域（STEM）专家的深度参与，提升 Claude 模型在科学推理和专业领域任务中的表现。

## 项目机制

- **驻场要求**：入选者需在 Anthropic 办公室（如旧金山）全职驻场 3 个月。
- **薪酬待遇**：每周津贴 3800 美元（约合人民币 2.7 万元）。
- **工作内容**：
  - 与 Anthropic 研究员一对一合作。
  - 设计严格的、不容易被投机取巧绕过的评估方法。
  - 系统性地找出模型“自信但错误”的地方。
  - 识别能力短板，创建有针对性的数据和技术来弥补。
- **技能要求**：机器学习经验有帮助，但**不是必需**。更看重科学判断力和快速学习的意愿。

## 战略定位

这是 Anthropic 第三代 Fellowship 计划，标志着其与科学界合作模式的深化：
1. **第一代**：关注安全对齐。
2. **第二代**：提供 API 额度，支持外部应用。
3. **第三代（本项目）**：深度共建，让科学家直接参与模型能力的打磨。

## 核心目标

该项目的本质是利用人类专家的[[专家级判断力]]来校准模型。Anthropic 意识到，AI 科研的瓶颈已从算力转移到了判断力。通过让材料学家、气候学家、生物学家等专家“调教”模型，解决其在专业领域的“一本正经胡说八道”问题。

## 相关案例

- [[Matthew Schwartz]]（哈佛物理教授）作为典型案例，展示了专家如何发现并修正 Claude 在高能物理计算中的“高置信度错误”。
