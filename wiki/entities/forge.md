# Forge

[[Forge]] 是 [[MiniMax]] 团队设计的异步原生 [[agent-rl]]（强化学习）框架与系统，用于加速模型训练并优化 Agent 能力。

## 核心功能

- **训练加速**：实现了约 40 倍的训练加速，显著提升了 [[m2-5]] 等模型的迭代效率。
- **解耦架构**：通过引入中间层，完全解耦底层训推引擎与 Agent 逻辑。
- **泛化支持**：支持任意 Agent 的接入，优化模型在 Agent 脚手架和工具上的泛化能力。
- **打破不可能三角**：在保证模型性能的同时，大幅提升了训练效率，解决了传统训练中速度、成本和质量难以兼得的问题。

## 技术意义与应用

- **快速迭代支撑**：Forge 系统是 MiniMax 能够在 108 天内迭代 M2、M2.1、M2-her 三款模型的关键技术支撑。
- **基础设施**：该框架是 [[minimax-m2-5]] 实现高推理效率和强大泛化能力的基础设施之一。
- **核心竞争力**：体现了 MiniMax 在工程优化层面的深厚积累，是其维持高迭代速度和低成本优势的核心竞争力之一。
