# MiniMax M2.5

[[MiniMax M2.5]] 是由 [[MiniMax]] 公司发布的开源大语言模型，拥有 10B 参数。该模型定位为 [[原生Agent生产级]]，以其在编码、办公和长文本理解任务上对标 [[claude-opus-4-6]] 的性能表现，以及极具竞争力的性价比（1 美金/小时）而受到广泛关注。

## 核心特性
- **参数规模**：10B（MoE 架构）。
- **推理速度**：100 TPS（Tokens Per Second），据称是 Claude Opus 4.6 的三倍。
- **原生 Agent 能力**：架构设计之初即为了驱动智能体，能够同时调度多个子 Agent 并行处理任务，减少对话轮次。
- **原生 Spec 能力**：在编写代码前，能像人类架构师一样主动拆解架构、规划功能模块。
- **性能指标**：在 BrowseComp 测试中评分达到 76.3%，显示出强大的浏览和任务执行能力。

## 技术架构
M2.5 的强大性能源于其围绕 [[agent-rl]] 构建的技术体系：
- **[[forge]] 框架**：原生 Agent RL 框架，解耦底层训推引擎与 Agent 逻辑。
- **CISPO 算法**：保障大规模强化训练的稳定性。
- **过程奖励机制**：解决长上下文训练中的信用分配难题。

## 性能表现
根据媒体报道，M2.5 在多项测试中表现出色：

### 逻辑推理与代码
- **逻辑推理**：通过了“遛马”逻辑陷阱变种题测试。
- **代码生成**：在 LeetCode Hard 算法题中给出了最优时间复杂度解法；在单文件中生成了完整的 3D 网页游戏。

### 办公与长文本
- **办公能力**：能够清洗包含脏数据的复杂 Excel 表格并进行业务分析；深度学习了专业场景知识，支持生成带公式和图表的 Excel 财务模型、专业排版的 PPT 以及高质量的 Word 文档和研报。
- **长文本**：能够精读《数学分析原理》等高难度教材并进行通俗化改写。

## 应用场景
MiniMax M2.5 特别适合需要生成结构化文档（如财务报告、演示文稿）以及复杂工作流自动化的场景，目前已接入阿里云 [[Coding Plan]]。

## 市场影响
发布后，[[MiniMax]] 公司市值一度暴涨至 2108 亿港元。该模型被视为“能力平权”的标志，即顶级模型能力不再被闭源巨头垄断。
