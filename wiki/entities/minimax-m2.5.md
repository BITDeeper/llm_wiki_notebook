# MiniMax M2.5

**MiniMax M2.5** 是中国 AI 公司 MiniMax 推出的大语言模型，于 2026 年春节期间上线。该模型主打“让无限运行复杂 Agent 在经济上可行”。

## 性能表现

### 速度优势
在 [[PinchBench]] 评测中，MiniMax M2.5 在速度榜单上超越了 [[Gemini 3 Flash]] 和 Llama 等模型，登顶榜首。
*   相比上一代 [[MiniMax M2.1]]，其在 SWE-Bench Verified 测试中的任务完成速度提升了 37%。
*   端到端运行时间缩短至 22.8 分钟，与 Claude Opus 4.6 持平。

### Agent 适配性
作为针对 Agent 场景优化的模型，M2.5 在 [[OpenClaw]] 等框架中表现出极高的执行效率，体现了国产模型在 [[Agent能力测试]] 中的竞争力。
