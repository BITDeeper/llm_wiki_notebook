# AlphaProof Nexus

**AlphaProof Nexus** 是 [[google-deepmind]] 于 2026 年 5 月推出的由 Gemini 驱动的数学证明智能体框架，结合大语言模型的创造力与 [[lean-形式化证明语言|Lean]] 编译器的严谨性，自主解决开放性数学研究问题，标志着 AI 首次批量解决顶级数学开放问题。该系统一夜攻克 9 道 [[erdős开放问题|埃尔德什问题]]，其中最古老的 Erdős #12 悬置 56 年。

AlphaProof Nexus 是 [[aletheia]]（DeepMind 此前解决数学猜想的大规模自动化系统）的技术进化 successor，专注于形式化证明的智能体框架。

## 核心设计

框架的核心逻辑是将大模型天马行空的"创造力"与 Lean 编译器绝对严谨的"判别力"结合。人类数学家只需输入带有占位符（`sorry`）的代码草图，用特殊标记（如 `EVOLVE-BLOCK` 或 `EVOLVE-VALUE`）圈出可修改范围，智能体即可自主完成宏观战略规划、微观逻辑推导、引理创建和参数微调。

核心循环（[[形式化证明循环]]）：AI 提出证明草稿 → Lean 编译器逐行检查验证 → 失败则反馈错误 → AI 修正 → 再验证 → 循环往复，直至通过。

## 四层架构

系统设计了四类 Agent，复杂度递增：

### Agent A（基础智能体 / 最简配置）
- 简约架构，启动多个无共享状态的子智能体独立运行
- 每个子智能体内部是多轮交互循环：[[gemini-3-1-pro]] 通过思考链推理，调用搜索和替换工具修改代码草图
- 每次修改后 Lean 编译器立即验证，报错则自我反思修正
- 无进化算法、无 AlphaProof，纯靠写代码 + 查错循环
- **关键发现**：极简架构同样成功解出所有 9 个 [[erdős问题]]

### Agent B
- 在 Agent A 基础上加入 [[alphaproof-初代]]（即 [[alphaproof-rl]]，DeepMind 此前为奥数级别题目训练的强化学习证明工具），用于攻克局部难点

### Agent C（演化智能体）
- 引入受 AlphaEvolve 启发的多智能体演化算法
- 共享种群数据库，所有子 Agent 共享证明草图种群
- 从合理性、清晰度、新颖性三维打分，用 Elo 评分系统驱动草稿优胜劣汰
- [[gemini-3-0-flash]] 充当"裁判"，对证明草图进行 Elo 排名和进化筛选

### Agent D（全功能智能体 / 全功能完全体）
- 进化筛选 + 专项工具攻克难点 + 大模型逻辑推理，三股力量协同
- 进化算法 + AlphaProof + Gemini 3.1 Pro 协同作战
- 可调用经奥数级强化学习训练的 [[alphaproof]] 作为辅助求解工具
- 是大规模扫荡 Erdős 问题的主力武器

## 架构悖论与关键发现

研究团队投入大量精力设计复杂的全功能智能体，但最终发现极简的 Agent A 同样解决了所有问题。Agent D 的优势主要体现在最困难问题上，有 2-5 倍成本优势。论文最反直觉的结论：**最简单的 Agent A 同样能解出全部 9 道题**，无需进化算法或强化学习。

研究团队归因于：
1. Gemini 3.1 Pro 本身能力足够强
2. Lean 编译器的纠错反馈对 AI 的引导作用远超预期

这暗示随着底层模型能力跃升，复杂特化系统的边际收益可能正在递减，行业可能转向直接利用通用大模型的原生推理能力。

**基础模型是关键前提**：单独运行 AlphaProof 或使用较小模型（Gemini 3.0 Flash），9 道题一道都解不出。

## 主要成果

### Erdős 开放问题
- 自主解决 353 个 Erdős 开放问题中的 9 个（含 Erdős #12、#125、#138、#846 等）
- 所有解法通过 Lean 编译器自动验证并经人工审查

### OEIS 猜想
- 自动形式化 492 个开放猜想，证明其中 44 个

### 其他领域突破
- **代数几何**：解决悬置约 15 年的余维数 3、类型 2 纯 O-序列对数凹性问题（希尔伯特函数对数凹性）
- **凸优化**：解决锚定梯度下降-上升算法精确收敛速率问题，自主发现新学习率调度参数，改进理论边界
- **图论**：证明 Graffiti 系统 1996 年提出的生成树猜想
- **加法组合学**：解决 Ben Green 开放问题列表第 57 题
- **量子光学**：与 Mario Krenn 合作解决单色量子图猜想

## 成本效益

每道题算力成本 5-400 美元（单题仅需几百美元量级）。最便宜的 #741(ii) 中位成本仅 5-7 美元，最贵的 #152 约 200-400 美元。
