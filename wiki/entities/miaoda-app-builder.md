# Miaoda App Builder

**Miaoda App Builder** 是百度 [[秒哒]] 平台在 [[OpenClaw]] 的公共技能市场 [[ClawHub]] 上发布的插件（Skill）。它是全球首个将完整应用开发能力封装为 Skill 的工具。

## 功能与作用
- **能力封装**：将前端、后端、数据库和部署等全栈开发流程封装为一个独立的、可被 AI 智能体调用的功能包。
- **一键安装**：用户只需在 [[秒哒]] 官网获取 API Key，并通过命令或搜索即可在 OpenClaw 中完成安装和配置。
- **全栈开发团队**：安装后，OpenClaw 不再仅仅是聊天助手，而转变为具备构建商业级应用能力的“全栈开发团队”。

## 应用案例
- **宣传网站**：快速生成带有交互功能的科技公司官网。
- **多人联机游戏**：生成了包含国潮风 UI、房间匹配、实时动作同步的麻将游戏，并展示了处理登录报错和上下文超限等复杂问题的能力。
- **多任务管理**：能够并行处理多个应用开发任务（如官网、问卷、抽奖系统），并提供项目进度看板。

## 生态意义
Miaoda App Builder 填补了 OpenClaw 生态中“信息处理”类 Skill 过剩，但“产品交付”类 Skill 空白的短板，使得 AI Agent 能够直接产出可商业化的成果。
