# The Path Not Taken

## 概述
《The Path Not Taken》是 [[田渊栋]] 团队在 2025 年末发表的一篇研究论文。该论文深入探讨了强化学习（RL）与监督微调（SFT）在模型权重层面上的行为差异，并解释了为何 RL 在某些情况下能避免 SFT 常见的 [[灾难性遗忘]] 问题。

## 核心发现

### SFT 的局限性
- **现象**：SFT 往往导致过拟合和灾难性遗忘。
- **表层原因**：训练数据不够 on-policy。
- **深层原因**：外来数据大幅修改了模型权重的**主分量**（Principal Components），导致模型的“根基”不稳，性能大幅下降。

### RL 的优势
- **机制**：RL 使用 [[on-policy]] 数据进行训练。
- **权重动力学**：RL 训练过程中，权重的**主分量保持不变**，改变的只是次要分量。
- **结果**：这种机制使得 RL 能够避免灾难性遗忘，并且改变权重的分布通常较为稀疏（特别是在 bf16 量化下）。

## 意义
这篇论文为理解 RL 和 SFT 的本质区别提供了理论依据，强调了数据分布和权重动力学变化对模型稳定性的影响。
