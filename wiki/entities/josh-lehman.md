# Josh Lehman

## 概述
[[Josh Lehman]] 是一名开发者，[[openclaw]] 项目的贡献者。

## 贡献
他是 [[openclaw]] v2026.3.7 版本中核心功能“[[可插拔上下文引擎]]”的 PR 作者。

## 观点
他提出了关于 Agent 记忆的著名观点：
> “你其实不需要一个 Agent 记忆系统，你需要的是不会被重置的上下文。”

这一观点强调了在 AI Agent 架构中，状态的连续性和上下文的不重置比单纯的外部记忆检索更为关键。基于此理念，他参与推动了 [[lossless-claw]] 插件的开发与集成。
