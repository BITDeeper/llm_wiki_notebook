# HY-Embodied-0.5

HY-Embodied-0.5 是由 [[腾讯混元团队]] 联合 [[腾讯Robotics X实验室]] 开发的专为具身智能（Embodied AI）从底层重构的基础模型系列。该系列旨在解决通用视觉语言模型（VLM）在物理环境中缺乏精细三维空间感知和物理交互预测能力的问题。

## 模型版本

### MoT-2B
- **参数规模**：总参数 4B，激活参数 2B。
- **架构特点**：采用创新的 [[MoT-架构]]（混合 Transformer），主打端侧部署和实时响应。
- **性能表现**：在涵盖感知、推理、规划的 22 项权威评测中获得 16 项最佳，超越了参数量更大的通用底座 [[Qwen3-VL-4B]] 和专用具身模型 [[RoboBrain2.5]]。

### MoE-32B
- **参数规模**：总参数 407B，激活参数 32B。
- **架构特点**：采用混合专家（MoE）架构，追求复杂推理与极致性能。
- **性能表现**：在具身测评标准下的综合成绩与行业标杆 [[Gemini]] 3.0 Pro 等抗衡。

## 核心技术

### 架构重构
为了解决小模型在多模态训练中的“灾难性遗忘”问题（即视觉能力增强挤占语言参数空间），HY-Embodied-0.5 进行了深度重构：
1.  **HY-ViT 2.0**：原生支持任意分辨率输入，针对端侧打造了 400M 参数的高效版本。
2.  **MoT 机制**：为视觉分支赋予非共享参数（复制 LLM 的 FFN 和 QKV），并允许视觉 Token 使用双向注意力机制。
3.  **Visual Latent Tokens**：在视觉输入序列末尾追加专属 Token，接受超大 ViT 全局特征监督，作为连接视觉与文本的桥梁。

### 数据与训练
- **数据构建**：整合了视觉感知、空间感知和具身感知三个层级的数据，系统性地注入物理直觉。
- **后训练范式**：引入 [[拒绝采样微调]]（RFT）和 [[在线蒸馏]]（Online Distillation），通过迭代式自我演化，将大模型能力高保真地“压缩”传授给轻量级变体。

## 实机验证
在打包、堆叠、悬挂等实机任务中，使用 HY-Embodied-0.5 作为基座初始化的 VLA 模型，相比于 pi0 和 pi0.5 初始化的模型取得了更好的效果，证明了其从仿真到现实的迁移能力。
