# Bug Nemo

Bug Nemo 是 [[英伟达]] 内部开发的另一款大语言模型工具，与 [[Chip Nemo]] 同属内部辅助系统。

## 功能
- **任务分配**：负责汇总芯片设计过程中的错误报告。
- **自动化流程**：自动将 Bug 分配给最合适的工程师或负责相应模块的专家。

## 意义
通过自动化处理繁琐的错误分类和分配工作，Bug Nemo 极大地缩短了芯片验证这一“长跑阶段”的时间，提高了整体研发效率。
