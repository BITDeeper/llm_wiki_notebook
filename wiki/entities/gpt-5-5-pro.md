# GPT-5.5 Pro

[[GPT-5.5 Pro]] 是 [[OpenAI]] 发布的最新一代多模态大语言模型。根据 [[LisanBench]] 和 [[TrackingAI]] 的评测数据，该模型在智力测试中取得了突破性进展，成为首个正式跨过 [[门萨]] 俱乐部（IQ 130）门槛的非人类实体。

## 核心性能指标

- **文本智商**：133（门萨门槛为 130）。
- **视觉智商**：145（进入天才区，位于人类前 0.1%）。
- **Token 效率**：相比前代模型，Token 使用量减少 45.6%，智能分数提升 1.77 倍。

## 技术突破

### 视觉推理质变
与过去一年中顶级模型（如 [[Claude 4.7]]）在视觉推理题上表现不佳（IQ < 125）不同，[[GPT-5.5 Pro]] 实现了视觉能力对文本能力的反超（145 vs 130）。这表明模型解决了传统 LLM 在将图片 Token 化过程中丢失空间结构和拓扑关系的问题，从“模拟思考”转向了“重构智能”。

### 语义重组能力
模型具备强大的 [[语义重组]] 能力，能够将长文本（如书籍）转化为高密度的“视觉认知流”（信息图）。[[Greg Brockman]] 展示了利用 [[GPT Image 2]] 将《物种起源》瞬间转换为详细信息图的案例，标志着知识摄入媒介从线性文字向高带宽视觉的变革。

## 市场地位与影响

根据 SemiAnalysis 的评估：
- **数学**：表现最佳。
- **编程**：与 [[Opus 4.7]] 持平。
- **智能体**：远胜其他所有模型。

[[GPT-5.5 Pro]] 的发布被视为 [[OpenAI]] 对竞争对手的一次 [[降维打击]]，其更高的智力水平和更低的延迟使得市场规则面临失效。
