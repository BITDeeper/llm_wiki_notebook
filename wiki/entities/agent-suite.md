# Agent Suite

Agent Suite是[[workbuddy企业版]]背后的内容知识底座智能体套件，整合了腾讯三大办公产品，构成Agent原生办公底座。

## 三大组件

| 产品 | 角色 | 功能 |
|------|------|------|
| 腾讯文档 | 协作 | 处理团队协作中的内容生产 |
| 腾讯网盘 | 存储 | AI时代的统一存储底座和Agent外部记忆体 |
| 腾讯乐享 | 知识 | 企业知识空间，连接办公文件、会议记录、业务数据，支持整库导入和增量同步 |

## 腾讯乐享的知识能力

- 知识去重、打标、纠错和进化
- 权限隔离、密级管理和合规审查
- 保障企业知识的安全使用

## 架构定位

三者组合构成Agent原生办公底座。WorkBuddy企业版作为统一中枢，通过OneID一次登录、Credit统一度量，将这些能力连接起来。
