# Cheng Lou

[[Cheng Lou]] 是一位知名的前端工程师，目前就职于 [[Midjourney]]。他是 [[Pretext]] 引擎的作者，在前端架构、编程语言设计及动画系统方面有深厚造诣。他的工作主要集中在探索前端渲染和排版的新范式，试图通过数学计算突破传统 DOM 的限制。

## 职业履历

### 核心贡献
- **React Motion**：创造了 React 生态中早期的动画库 React Motion。
- **ReasonML/ReScript**：ReasonML 和 ReScript 语言的缔造者之一，致力于为 JavaScript 带来类型安全和函数式编程特性。
- **Facebook Messenger**：曾担任 Facebook Messenger 的前端核心架构师。
- **Midjourney**：目前在 Midjourney 负责 UI 体系，使用 Bun 等技术栈。

## 技术哲学

Cheng Lou 在 2016 年 ReactEurope 的演讲中曾说过一句名言：
> “减少表达力，反而能获得更大的力量。”

十年后，他通过开发 [[Pretext]] 验证了这一理念——通过砍掉对 DOM 的依赖，反而获得了排版性能和自由度的巨大提升。

## Pretext 与 AI

在开发 Pretext 时，Cheng Lou 积极使用了 [[Claude Code]] 等 AI 工具。他利用 AI 进行了长达数周的跨浏览器像素级精度测试，被视为 AI 辅助进行高质量软件工程验证的典型案例。
