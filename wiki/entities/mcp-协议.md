# MCP 协议 (Model Context Protocol)

由 [[anthropic-labs]] 团队开发的开源协议，旨在成为 AI 连接数据与工具的标准。

## 核心数据

发布后月下载量迅速突破 **1 亿次**，显示出开发者社区对其作为连接标准的高度认可。

## 功能定位

MCP 解决了 AI 模型如何与外部数据源和工具进行标准化交互的问题。它是 [[anthropic]] 构建生态系统的关键基础设施，使得 Claude 能够更深入地集成到用户的工作流中。

## 战略意义

作为 Labs 孵化的核心成果之一，MCP 协议的普及是 Anthropic 在 [[产品巷战期]] 建立护城河的重要手段，试图在应用层定义连接标准。
