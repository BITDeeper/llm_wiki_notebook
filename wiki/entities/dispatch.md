# Dispatch

Dispatch 是 [[Anthropic]] 于 2026 年 3 月 17 日在 [[Claude]] 应用中发布的“研究预览”功能，属于 [[Cowork]] 功能集的一部分。它允许用户通过手机远程指挥 Mac 上的 Claude 执行图形界面（GUI）操作。

## 核心特性
- **跨设备协同**：实现了从移动设备（手机）到固定设备（Mac）的控制流。
- **自然语言指令**：用户只需输入自然语言（如“整理会议纪要”），Claude 即可自动完成点击、打字等操作。
- **本地执行**：所有屏幕读取、文件操作和指令执行均在 Mac 本地完成，数据不经过云端，确保隐私安全。

## 使用流程
1. 更新 Mac 端 Claude 应用。
2. 在 Cowork 界面选择 Dispatch 并生成二维码。
3. 使用手机端 Claude App 扫码配对。
4. 通过手机侧边栏的 Dispatch 入口发送指令。

## 当前限制
- **订阅门槛**：目前仅对 Max 订阅用户开放。
- **设备状态**：Mac 必须保持唤醒且 Claude 应用必须处于打开状态。
- **成功率**：根据早期评测，成功率约为 50%，在跨应用操作和特定系统功能（如 Safari、Shortcuts）上存在局限。

## 战略意义
Dispatch 的发布标志着 AI Agent 的 [[操作半径]] 从单机桌面扩展到了跨设备协同，是 Anthropic 构建“远程员工”生态面向普通用户的关键一环。
