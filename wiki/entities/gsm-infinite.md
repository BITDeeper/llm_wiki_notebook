# GSM-Infinite

GSM-Infinite 是一个长上下文数学推理评测基准。它通过在数学题目中添加干扰 token 来拉长题目长度，同时用所需算术操作数来控制题目难度。题目越复杂，需要的推理步骤越多。

## 特点

- **可变难度**：通过算术操作步数（如4步、6步、8步运算）控制推理复杂度
- **长上下文测试**：通过干扰 token 拉长输入，测试模型在冗长上下文中的推理能力
- **区分度高**：能有效区分模型在不同推理深度上的表现差异

## 在记忆巩固研究中的应用

在《Language Models Need Sleep》论文中，GSM-Infinite 被用于验证[[记忆巩固机制]]的效果。实验表明，题目越难（推理步骤越多），"睡眠"机制带来的准确率提升越明显，证明额外计算对深度推理任务的价值。
