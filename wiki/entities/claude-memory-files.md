# Claude Memory Files

Claude Memory Files是[[anthropic|Anthropic]]开发的一种文件化记忆系统，类似于个人Wiki，为长期运行的AI Agent提供持久化记忆能力。

## 技术特点

- **文件化存储**：将AI的记忆以文件形式持久化，而非依赖上下文窗口。
- **长期运行支持**：为需要跨会话、跨天甚至跨周执行的Agent任务提供记忆连续性。
- **个人Wiki模式**：用户可以查看、编辑和管理AI的记忆文件，保持对AI认知状态的掌控。

## 战略意义

Claude Memory Files是Anthropic构建"企业操作系统"愿景的基础设施层。它解决了当前AI Agent的核心痛点——记忆持久性，使得[[1-n-agent调度|1:N Agent调度]]范式下的长期自主任务成为可能。
