# Yuntian Deng

哈佛博士、滑铁卢大学助理教授，AI 研究人员。在 [[claude-opus-4-8|Claude Opus 4.8]] 发布后公开表达对 Opus 4.8 智能体表现的强烈不满，称"第一次被智能体如此愤怒"（"First time an agent made me this angry"）。

其公开批评成为 Opus 4.8 质量危机的重要佐证，代表了学术界对商业化压力下模型质量退化的担忧。
