# 鲲鹏

**鲲鹏** 是华为推出的 ARM 架构 CPU 处理器系列，主打企业级计算。

在具身智能[[端云协同架构|端云协同]]场景中，鲲鹏 CPU 负责工具调度、任务编排、状态管理以及机器人控制逻辑。在 [[jiuwen-symbiosis|Jiuwen Symbiosis]] 架构中，Agent Runtime、Memory、Workspace、Tool Calling 等逻辑均运行在鲲鹏 CPU 上，从而避免了传统纯 GPU 方案中所有任务争抢同一计算资源的瓶颈，实现低延迟、高可靠的执行链路。
