# CodeTracer

**CodeTracer** 是由南京大学 NJU-LINK 实验室与快手科技联合开发的代码 Agent 可追溯性框架。它是一个无需重新训练、即插即用的诊断工具，旨在解决 AI 编程智能体在执行复杂任务时面临的“黑箱调试”难题。

## 核心功能
CodeTracer 能够将 Agent 运行产生的杂乱日志转化为结构化的**执行状态历史**，自动定位任务失败的起始节点，并将生成的诊断信息反馈给 Agent，从而实现错误恢复与执行恢复。

## 工作原理
CodeTracer 的核心流程分为三个模块：

1.  **运行日志解析（进化式提取）**
    采用“探索-适配-复用”策略，自动扫描运行目录并识别日志结构。若注册表中无匹配解析器，系统会自动生成新解析器并注册入库。这种机制解决了异构日志格式兼容性难题，使框架能即插即用于 SWE-Agent、OpenHands 等不同框架。

2.  **构建执行视图（层级轨迹树）**
    将扁平的执行序列转化为层级轨迹状态树。其关键在于区分两类步骤：
    - **探索步骤**：只读取、搜索环境，不修改代码状态。
    - **状态变更步骤**：对代码库或环境产生实际修改，触发状态跳转。
    这种结构化使得诊断无需从头阅读原始日志，即可快速定位偏差点。

3.  **精准定位与反思回放**
    - **Trace Agent**：沿轨迹树遍历检索，输出失败责任阶段、错误相关步骤集合及精简证据集。
    - **反思回放**：将诊断信号作为前置提示注入原 Agent，驱动其在相同资源约束下重新执行任务。

## 实验效果
- **定位精度**：在各类基本模型上，F1 分数从直接 LLM 提示的 16%-19% 提升至 46%-48%。
- **资源效率**：通过树形结构实现证据聚焦检索，显著降低了 Token 消耗。
- **恢复能力**：通过反思回放机制，所有骨干模型的 Pass@1 均有显著提升。
