# Vibe Coding Agent

Vibe Coding Agent 是 [[Yoroll]] 平台集成的自动化 AI Agent 工具，专门用于 3D 游戏场景和逻辑的生成。

## 功能
- **自然语言生成**：用户只需输入一句自然语言描述（如“做一个第三人称射击游戏...”），Agent 即可自动生成完整的可运行 3D 游戏空间。
- **全流程自动化**：自动完成扫描项目结构、搭建场景、创建角色、编写交互脚本和连接行为逻辑等原本需要多工种协作的任务。
- **无缝嵌入**：生成的 3D 场景可以直接嵌入到互动视频游戏中，实现从视频叙事到 3D 玩法的平滑过渡。

## 技术意义
Vibe Coding Agent 不仅是代码生成工具，更是 [[Vibe Coding]] 范式在复杂 3D 逻辑领域的应用实例。它极大地降低了 3D 游戏开发的门槛，将策划、美术、程序、关卡设计的工作压缩为单一的自然语言指令。
