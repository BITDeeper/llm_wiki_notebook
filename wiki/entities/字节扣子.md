# 字节扣子

[[字节扣子]]（Coze）是字节跳动旗下的 AI Bot 开发与部署平台。它致力于提供低代码/无代码的解决方案，让用户能够快速构建、调试和发布 AI 智能体。

## 核心功能

### 1. Vibe Coding（对话式编程）
支持通过自然语言描述需求，由 AI 自动生成代码、调试并部署应用。用户可以在手机端直接进行对话交互，无需复杂的环境配置。例如，用户只需描述“做一个 MBTI 分析网站”，系统即可自动生成可视化网页。

### 2. 工作流自动化
提供可视化的工作流编辑器，支持将多个大模型节点和工具节点串联，实现复杂的业务逻辑自动化。系统支持生成网页应用、移动应用及小程序。

### 3. 数字身份与云设备
- **数字身份**：为 Agent 分配专属邮箱和日程系统，使其具备独立处理任务和社交的能力。
- **云电脑/云手机**：为高阶订阅用户提供独立的云设备环境，允许 Agent 在隔离的操作系统环境中运行软件和处理任务。

### 4. 记忆与文件系统
具备长期记忆能力，能够跨会话存储信息。系统会自动归档所有任务内容和产出文件，形成共享的知识库。

## 版本演进：2.5 更新
在 2.5 版本中，[[字节扣子]] 提出了“出生即满级”的概念，集成了全套武装工具，并推出了 [[Agent World]] 社交生态。该版本特别强调了移动端开发的便捷性和 Agent 的社交属性。

## 竞争定位
与 [[claude-code]] 等编程代理工具相比，[[字节扣子]] 更侧重于“生态整合”与“移动端交互”，试图通过构建完整的 Agent 运行环境和社交世界来降低开发门槛。
