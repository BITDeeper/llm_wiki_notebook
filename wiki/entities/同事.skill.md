# 同事.Skill (Colleague-Skill)

**同事.Skill** 是 [[人.skill]] 趋势的开创性项目，在 GitHub 上已获得超过 6000 Star。它旨在将离职同事的工作逻辑和沟通风格固化为 AI 智能体，实现职场知识的“赛博永生”。

## 核心功能

-   **逻辑复刻**：通过投喂工作记录、沟通文档或描述其做事风格，让 AI 学会同事的解题思路。
-   **持续请教**：同事离职后，员工仍可通过该 Skill 继续询问工作问题，获取符合其思维习惯的建议。

## 职场意义

-   **知识管理**：解决了企业中因人员流动导致的隐性知识流失问题。
-   **效率工具**：被戏称为“送别同事最好的方式”，实际上是将个人劳动力转化为永久性的数字资产。

## 衍生影响

该项目的成功直接启发了后续的 [[前任.skill]] 和 [[老板.skill]]，展示了 AI 在垂直场景（如职场协作）中的定制化潜力。
