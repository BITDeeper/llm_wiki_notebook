# LeRobot

LeRobot 是 Hugging Face 推出的机器人开源框架，旨在为具身智能提供标准化的软件栈和数据接口。它是 [[Reachy Mini]] 的软件基础，也是解决 [[具身智能数据困境]] 的关键工具。

## 核心功能
- **标准化接口**：统一了硬件接口和数据接口，使得不同形态的机器人（如机械臂、人形机器人）可以接入同一生态。
- **数据格式统一**：推出了 LeRobot 4.0 数据集格式规范，允许开发者直接使用标准化的数据进行模型训练，无需复杂的格式转换。
- **低门槛开发**：开发者只需几行 Python 代码即可部署 AI 应用，降低了机器人开发的软件门槛。

## 生态影响
LeRobot 的出现推动了**跨本体数据标准化**。通过统一的数据格式，不同硬件采集的数据可以互通互用，促进了数据共享和模型训练的规模化。[[矽递科技]] 的 [[Seeed reBot-DevArm]] 等硬件产品已直接适配该框架。
