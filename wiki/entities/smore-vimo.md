# SMore ViMo

## 概述
[[SMore ViMo]] 是 [[思谋科技]] 基于 [[IndustryGPT]] 打造的“行业模型+Agent”落地形态。它依托 [[IndustryGPT]] 的原生 Agent 能力，旨在解决工业场景中从模型开发到实际生产应用的“最后一公里”问题。

## 核心功能
[[SMore ViMo]] 实现了 [[任务执行范式]] 在工业领域的具体应用，具备以下能力：
-   **自动缺陷识别**：在工业质检环节中自动识别并归类缺陷属性。
-   **闭环校验**：通过反馈机制自动修正精度，确保持续优化。
-   **流程自动化**：将抽象的工程理解转化为可执行的工程流程。

## 落地成效
-   **周期压缩**：将客户从项目启动到可运行模型的落地周期，从行业平均的14天压缩至3天以内。
-   **效率提升**：在工业质检环节中，效率飙升200%。
-   **知识沉淀**：在复杂产线管理中，将个人经验转化为组织资产，实现90%常见异常的自主解决。

## 意义
[[SMore ViMo]] 的成功证明了 [[原生工业垂类大模型]] 结合 Agent 技术的有效性，展示了AI如何从“能说”的聊天工具转变为“能做”且“能负责”的生产力工具。
