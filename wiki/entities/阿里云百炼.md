# 阿里云百炼

[[阿里云百炼]] 是阿里云提供的模型服务平台，作为 [[qwen3-6-27b]] 等模型的官方 API 调用渠道。

## 特性

- **兼容性**：平台兼容 OpenAI 和 Anthropic 两大主流 API 格式，允许开发者无需大幅修改现有程序即可对接 Qwen 系列模型。
- **分发渠道**：除了提供开源模型权重的本地下载外，阿里云百炼为不想本地部署的开发者提供了云端调用选项。
