# Z Code

[[Z Code]] 是 [[智谱AI]] 基于 [[GLM-5]] 模型构建的新一代 AI 编程开发工具。它代表了 [[Agentic Engineering]] 范式下的具体落地产品，旨在将 AI 从单纯的代码补全工具转变为能够独立完成软件交付的智能体系统。

## 核心功能
- **多 Agent 并发开发**：模型能够自动拆解复杂任务，并拉起多个 Agent 并发处理代码编写、命令运行、Debug 和预览等不同环节。
- **全流程自动化**：不仅负责编码，还能自动处理 Git 提交等工程流程。
- **远程控制**：支持用户通过手机远程指挥桌面端的 Agent 进行开发工作。

## 技术背景
Z Code 本身也是 GLM 模型全程参与开发出来的产物，类似于 OpenAI 用 Codex 开发新版本 Codex 的“用 AI 造 AI”模式。它充分利用了 GLM-5 在长程任务规划、复杂系统架构设计以及自我修复方面的能力。
