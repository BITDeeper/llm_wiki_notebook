# Codex for Open Source

## 概述
[[Codex for Open Source]] 是 [[OpenAI]] 推出的一项针对开源项目维护者和运营者的支持计划。该计划旨在通过免费提供 AI 资源和服务，来加强与开源社区的联系，并促进 OpenAI 技术在开源项目中的应用。[[Peter Steinberger]] 是该项目的核心推动者之一。

## 核心权益
该计划为符合条件的申请者提供以下资源：
1.  **API 积分**：用于调用 OpenAI 模型接口。
2.  **ChatGPT Pro 访问权**：为期 6 个月的免费使用权。
3.  **Codex Security 服务**：用于辅助代码审查和安全检测。

## 申请条件
OpenAI 对申请者的门槛设定相对灵活，不仅限于高知名度的项目：
- **核心维护者**：开源项目的核心贡献者。
- **运营者**：被广泛使用的公开项目的运营人员。
- **生态贡献者**：即使项目不符合常规标准（如 Star 数较低），但若在生态系统中发挥重要作用，OpenAI 也鼓励申请并说明理由。

## 战略意图
该计划是 [[OpenAI]] 在 [[开发者关系]] 领域的重要布局，属于典型的 [[开源生态激励]] 策略。通过降低开源开发者使用顶级 AI 服务的成本，OpenAI 旨在：
- 培养开发者对 OpenAI 生态的依赖。
- 对抗竞争对手（如 [[Anthropic]]）在开发者社区中的影响力。
- 收集更多来自真实高难度开发场景的反馈数据。
