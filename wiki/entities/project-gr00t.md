# Project GR00T

[[Project GR00T]] 是 [[英伟达]] 发布的具身智能项目，旨在打造人形机器人的通用大模型。

## 与 3D-GENERALIST 的关系
[[3d-generalist]] 生成的可交互 3D 物理世界，主要服务于 [[Project GR00T]] 的训练需求。通过在 [[Isaac Lab]] 仿真环境中进行大规模训练，Project GR00T 试图赋予机器人理解复杂物理场景并执行通用任务的能力。

## 战略地位
作为 [[英伟达]] 「具身智能」版图的核心，Project GR00T 承载着 [[黄仁勋]] 关于「所有移动之物终将自主」的愿景。
