# Papers with Code

Papers with Code 是机器学习社区的核心科研基础设施，将论文、代码、数据集和排行榜整合在统一站点中，使研究人员找参考实现的时间从几天压缩到几分钟。

## 历史沿革

### 创建与早期（2018-2019）
- **2018年7月：** 平台上线，迅速成为机器学习社区绕不开的基础设施。
- **2019年12月：** 被 [[meta-ai]] 收购，当时承诺保持中立、开放和免费。

### 关闭（2025年7月）
- 毫无预警关闭，网站显示"502 Bad Gateway"，GitHub 求助帖无人回应。
- 关闭时平台积累了超过 **9300 个基准测试**、**5600 个数据集**、**5000 多个任务**的性能对比数据。
- 创始人 [[ross-taylor]] 解释：团队被收购后转型大模型研究，维护时间越来越少，大量成员已离开 Meta。

### 重建（2026年5月至今）
- [[hugging-face]] 开源团队成员 [[niels-rogge]] 在 paperswithcode.co 从零重建。
- 核心变革：部署 [[ai智能体驱动论文解析]]，自动解析论文、提取标签和性能数据、链接代码仓库。
- [[sota排行榜]] 全面回归，新增散点图可视化、Methods 标签页、多指标展示等功能。
- 上线一周内完成多项功能迭代，已为约 3000 个模型添加评估结果。

## 技术特征

- **原版：** 依赖人工维护，更新速度受限于人力。
- **新版：** 由 AI 智能体驱动数据处理，覆盖范围和更新速度不再受人工瓶颈限制。
- **数据来源：** 不限于 arXiv，博客、GitHub 报告均可提交，由 AI 自动索引。
