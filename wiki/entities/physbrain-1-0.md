# PhysBrain 1.0

PhysBrain 1.0 是 [[深度机智]] 于2026年3月在中关村论坛发布的具身通用智能基座模型体系，代表"[[人类学习路线]]"的核心模型成果矩阵。

## 核心特点

- **学习效率**：用千小时人类数据超越万小时真机数据训练的性能，数据效率实现数量级突破
- **涌现能力**：模型涌现出"灵活应变"能力，不再局限于刻板模仿
- **全栈覆盖**：涵盖 VLM（视觉语言模型）、VLA（视觉语言动作）、世界模型与空间智能

## 五大国际榜单成绩

1. **WorldArena**：[[z-wm-v1]] 以64.96分超越榜首（64.24分），全榜唯一在机器人落地核心维度无致命短板
2. **SimplerEnv**：WidowX Robot 测试 80.2% 平均成功率，远超国际标杆 π0.5 的 57.1%
3. **RoboTwin 2.0**：[[starr框架]] 在 Clean 和 Random 设置下分别取得 93.82%、93.30%
4. **RoboCasa**：仅千小时人类数据做 VLM 增强，即达 64.5% 平均成功率
5. **LIBERO**：融合体系达 98.8% 平均成功率，刷新行业最好成绩
