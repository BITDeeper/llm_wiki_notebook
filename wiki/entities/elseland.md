# Elseland

**Elseland** 是由 [[Elser.AI]] 开发的全球首个 [[AI 开放世界]] 平台。该项目由 [[刘耕]] 主导，利用 17 个 [[AI Agent]] 在 49 天内以约 5000 元的成本构建完成。

## 核心特性

Elseland 被定义为“AI 开放世界”而非单纯的“AI Roblox”或“游戏版 TikTok”，其核心围绕“给每个灵魂一个世界”的愿景，强调“角色”与“共存”的体验。它包含三个层次的开放性：

1.  **玩法的开放**：集成了社交、刷剧、互动小说、剧本杀以及多种类型的小游戏（卡牌、割草、三消、MOBA 等）。
2.  **世界的开放**：构建了一个横跨 5 个纪元、10 大种族的宏大世界观。首期推出的“第三纪元”故事包含魔法、炼金与偃甲并存的设定。
3.  **创造的开放**：提供了低门槛的编辑器（如角色编辑器、世界模拟器、互动剧场编辑器、3D Studio 等），支持“一句话创作”和拖拽式操作，赋予用户创造世界的能力。

## 开发模式与技术

Elsand 的开发是 [[Vibe Coding]] 和 [[超级个体]] 概念的典型案例。刘耕作为文科博士，通过管理 17 个 Agent 完成了传统模式下需要 50 人团队工作 4-6 个月的工程量（约 30 万行代码）。

### Agent 分工
开发团队中的 17 个 Agent 分工明确：
*   **程序开发（9个）**：包括 6 个 [[Claude Code]]（分别担任主架构师、游戏引擎工程师、智脑工程师等）、1 个 Codex（顾问）、1 个 Gemini CLI（UI 优化）、1 个 Kimi Code（机动）。
*   **内容生成（8个）**：包括负责 3D 资产的“皮格马利翁”、负责剧本的“莎士比亚”、负责调度的“调度师”等。

## 效率与成本

*   **成本**：约 5000 元人民币。
*   **周期**：49 天（实际开发时间）。
*   **效率对比**：相比传统管线提升百倍（例如重构一个小说 Agent 产品从 50 天缩短至半天）。
