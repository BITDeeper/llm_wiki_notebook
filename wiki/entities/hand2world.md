# Hand2World

[[hand2world]] 是由 [[南洋理工大学-mmlab]] 团队开发的一种基于手势交互的自回归第一人称世界模型。它旨在解决 AI 世界模型从被动观察环境转向能够主动生成与物理世界（如手势）交互内容的能力，即实现从“看见世界”到“触碰世界”的跨越。

## 核心特性

### 遮挡不变性
传统的基于 2D mask 的方法（如 [[coshand]]）在处理手部交互时存在严重缺陷：训练数据中手部常被物体遮挡（残缺），而在推理时（如空中手势）输入的是完整的手，这种分布错配导致模型生成伪影。

[[hand2world]] 彻底抛弃了 2D mask，采用 [[mano-模型]] 从单目视频中恢复完整的 3D 手部网格，并将其投影渲染为“填充轮廓 + 线框叠层”的复合信号。无论手是否被物体遮挡，控制信号的格式始终一致，将遮挡关系的推断交给了生成模型本身。

### 运动解耦
在第一人称视频中，手部运动和佩戴者的头部转动在画面上高度纠缠。[[hand2world]] 使用 [[plucker-射线嵌入]] 逐像素显式编码相机运动，通过一个轻量级 adapter 注入扩散模型。这一技术将手部关节运动和头部自运动彻底解耦，避免了背景随手势漂移的问题。

### 闭环交互
[[hand2world]] 将双向扩散教师模型蒸馏为因果自回归生成器，利用 KV cache 维持时序连贯，支持流式输出（单卡 A100 达 8.9 FPS）。这实现了真正的 [[闭环交互]]：用户可以边看生成结果边调整手势，模型实时响应并持续生成。

## 性能指标
在 ARCTIC 数据集上，[[hand2world]] 相比现有方法取得了显著提升：
- **FVD (Fréchet Video Distance)**: 从 908 降至 218（降幅 76%）。
- **相机轨迹误差**: 从 0.13 降至 0.07（降幅 42%）。
- **DINO 语义相似度**: 从 0.80 提升至 0.88。

## 数据方案
与依赖多目同步采集的 [[playerone]] 不同，[[hand2world]] 提出了一套 [[单目全自动标注]] 流水线。它可以直接从普通的第一人称视频中自动提取手部 mesh、相机轨迹和训练数据对，极大地降低了数据采集门槛，为具身智能提供了可扩展的数据飞轮。

## 应用场景
- AR/MR 眼镜的实时手势交互。
- 机器人手-物交互数据的合成。
- 从单张照片构建可交互的虚拟环境。
