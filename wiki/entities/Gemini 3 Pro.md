# Gemini 3 Pro

[[Gemini 3 Pro]] 是谷歌发布的主力大语言模型，在 [[千问3.5-Plus]] 发布时被视为主要的性能对标对象。

## 性能对比

根据报道，[[千问3.5-Plus]] 在多项评测中达到了与 Gemini 3 Pro 媲美甚至超越的水平，特别是在通用Agent评测（BFCL-V4, Browsecomp）中表现优异。

## 成本对比

-   **Gemini 3 Pro**: API 价格较高。
-   **[[千问3.5-Plus]]**: API 价格仅为 Gemini 3 Pro 的 1/18（0.8元/百万Token）。

这一巨大的价格差异标志着AI行业在追求高性能的同时，正通过架构优化（如 [[门控技术]]）急剧降低推理成本，挑战传统闭源巨头的定价模式。
