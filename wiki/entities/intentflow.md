# IntentFlow

IntentFlow 是 [[pask]] 系统中的核心**流式意图检测模型**。它受语音/视频端到端流式模型启发，专门设计用于在文本流上实时运行，以解决传统 AI Agent 机制中意图推理耗时过长的问题。

## 核心功能
IntentFlow 只关注“人类需要什么”，而不负责生成具体的执行结果。它接收文本化的多模态信息流和用户记忆，自主判断人类当下的潜在需求。

## 技术特点
*   **实时性**：能在 1.5 秒内结合个人、工作和全局记忆完成一次完整的意图检测。相比之下，传统 Agent 机制（包含 API 调用和意图推理）通常需要 3-10 秒。
*   **流式处理**：无需等待完整输入即可开始推理，类似于实时语音对话模型的处理方式。
*   **桥接作用**：IntentFlow 被比喻为一座桥，连接用户面对的信息流和强大的后端 AI 模型，负责在正确的时机触发 AI 介入。

## 设计背景
Pask 团队发现，传统的“纯 Agents 机制”无法满足主动 AI 的实时性要求。人类能忍受的时延极限（约 2 秒）甚至不够完成一次完整的模型 API 调用。因此，团队借鉴实时对话模型的经验，开发了 IntentFlow 这一专用的小模型来处理意图检测，将复杂的执行任务交给上层 Agents。
