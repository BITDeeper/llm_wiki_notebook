# Chronicle

**Chronicle** 是 [[OpenAI]] 在 [[Codex]] 平台上推出的实验性屏幕记忆功能，内部代号为“Telepathy”（心灵感应）。该功能旨在通过实时读取用户的屏幕内容来构建长期记忆，从而减少用户在使用 AI 时重复陈述背景信息的需要，实现 [[屏幕感知上下文]]。

## 核心功能
- **实时感知**：在后台持续运行，通过周期性截屏读取屏幕内容、打开的文件、浏览的网页及未完成的文档。
- **记忆图谱**：将屏幕碎片信息压缩并关联索引，形成个人知识结构，使 AI 能理解上下文中的指代（如“这个”、“那个”）。
- **工作流理解**：随着时间推移，帮助 Codex 理解用户使用的工具、参与的项目及依赖的工作流程。
- **自动摘要**：将截图转化为 Markdown 文本摘要，作为上下文索引，允许 Codex 理解用户屏幕上的内容（如报错信息、文档、代码），无需用户手动粘贴。

## 技术实现
1.  **截屏**：后台 Agent 周期性抓取屏幕截图。
2.  **云端处理**：截图上传至 OpenAI 服务器进行 OCR 和视觉分析。
3.  **本地存储**：生成的 Markdown 摘要回传并存储在本地设备。
4.  **数据清理**：原始截图在本地保留 6 小时后删除，摘要永久保留（明文、未加密）。

## 技术限制
- **系统限制**：目前仅支持 macOS 系统。
- **订阅限制**：仅对 Pro 订阅用户开放。
- **算力消耗**：被称为“Token 燃烧机器”，后台持续处理会快速消耗 API 配额，算力消耗极高。

## 隐私与安全
- **数据存储**：官方文档称数据“主要在本地处理”，但部分场景需云端辅助。本地保存的记忆摘要**未加密**。
- **使用建议**：OpenAI 建议在“开会前”或“看敏感内容前”手动关闭，承认了其在隐私保护上的不完善。
- **提示词攻击**：面临严重安全漏洞，恶意网页可通过在屏幕上显示指令来劫持 AI 助手（[[提示词注入]]）。
- **监管规避**：发布范围刻意避开了欧盟、英国和瑞士等隐私法规严格的地区。

## 竞品对比
- 相比 [[Microsoft Recall]]，Chronicle 采取了更保守的策略（如原图短期保留），但仍面临未加密存储的质疑。
- 与 [[Rewind AI]] 和 [[Screenpipe]] 同属桌面感知 AI 赛道。

## 商业逻辑
OpenAI 缺乏谷歌或微软的天然数据生态，因此采用最暴力的“直接读屏”方式建立用户理解。通过高补贴（消耗远超订阅费的算力）换取用户习惯，旨在实现 [[生态锁定]]。

## 评价
- [[Sam Altman]] 称其为“Telepathy”，旨在消除解释背景信息的需要。
- [[Greg Brockman]] 评价体验为“surprisingly magical”（意外地奇妙）。
- 媒体将其比作“寄生在你电脑里的第二个大脑”和“数字影子”。
