# Elephant (大象模型)

## 概述
**Elephant (大象)** 是由 [[inclusion-ai]]（蚂蚁 Inclusion AI 团队）开发的 100B 参数规模的大语言模型。该模型主打“快、准、省”的特性，被定位为“干活圣体”，旨在解决企业级应用中 Token 浪费和响应延迟的问题。

## 核心参数
- **参数规模**：100B
- **上下文窗口**：256K
- **最大输出**：32K

## 核心特性
### 1. 极高的 Token 效率
Elephant 在生成内容时以“简洁”著称，避免了常见大模型的冗余输出。在代码修复和文档整理任务中，它能精准给出答案，没有多余废话，从而显著降低 API 调用成本。

### 2. 低延迟
根据 [[ai-benchy]] 的评测数据，Elephant 的平均响应时延约为 1 秒，远低于同类竞品 10-30 秒的水平。这使得它非常适合对实时性要求较高的 [[任务执行范式]] 场景。

### 3. 高一致性
在 AI BENCHY 评测中，Elephant 的一致性得分达到 9.6 分（满分 10 分），表明其在指令遵循方面的稳定性极高。

## 实测表现
- **代码生成与修复**：能够快速生成 HTML/JS 代码，并在“投毒”测试（删除关键变量）中精准定位 Bug 并给出极简修复方案。
- **文档处理**：在处理包含大量口语、重复和跑题内容的会议纪要时，能精准提取关键信息并按指定格式（如 JSON）输出，表现优于 Gemini-2.5-Flash-Lite。
- **Agent 任务**：能在 10 秒内完成读取 CSV 数据、计算同比、分析结论及自检的闭环。

## 局限性
- **复杂长链规划**：不具备数据采集、策略生成等工具能力，无法独立执行如“出海战略规划”等复杂任务，需配合大模型使用。
- **新知识幻觉**：对非常新的知识（如 React 18 新特性）可能基于旧数据产生幻觉，需要在 Prompt 中注入最新文档。
- **Prompt 敏感性**：对 Prompt 的明确性要求较高，模糊指令可能导致输出质量下降。

## 行业定位
Elephant 是 AI 行业从追求“大而全”转向“小而美”和工程落地的代表产品之一。它与 OpenAI 的 GPT-5.4 mini/nano 和谷歌的 Gemma 4 类似，都是为了应对 [[ai-subscription-crisis]] 和 Token 浪费问题而生的高效能模型。

## 与蚂蚁集团的关系
虽然同属蚂蚁集团，但 Elephant 与 [[蚂蚁灵波]]（专注于具身智能的 VLA 模型）处于不同的技术分支。Elephant 更侧重于通用文本和代码处理的高效执行。
