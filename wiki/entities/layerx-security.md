# LayerX Security

**LayerX Security** 是一家网络安全公司。2026年3月，该公司与剑桥大学的研究人员共同发现了 [[Anthropic]] 内容管理系统（CMS）的配置错误，这一发现导致了 [[Claude Mythos]] 模型细节的意外泄露。

## 主要贡献
LayerX Security 在此次事件中识别出 Anthropic 使用的第三方工具存在配置失误，致使约 3000 份原本保密的内部文件暴露在公开可访问的数据库中。
