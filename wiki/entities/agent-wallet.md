# Agent Wallet

Agent Wallet 是由 [[FluxA]] 推出的专为 AI 智能体设计的数字钱包产品。它旨在解决 AI 在执行任务时无法自主处理付费环节的 [[最后一公里痛点]]，赋予 AI 真正的经济自主权。

## 核心特性

### 1. 原生 AI 支持
不同于传统人类钱包，Agent Wallet 专为机器调用设计。它支持 [[OpenClaw]]、[[Claude Code]] 等主流智能体，通过简单的自然语言指令（如 `Read and install...`）即可完成安装和配置。

### 2. 授权契约
为了解决 AI 持有资金的安全风险，Agent Wallet 引入了 [[授权契约]] 机制：
- **细颗粒度控制**：用户可以设定具体的支付限额（如每日 5 美元）和用途（如仅限购买 GitHub 资源）。
- **自动熔断**：一旦支出超出预设规则，钱包会自动锁死，防止资金失控。

### 3. 意图转化
Agent Wallet 不仅仅是一个支付工具，它是 AI 将“意图”转化为“价值交换”的接口。通过支付，AI 可以自主购买 API 调用、算力资源或服务，从而实现任务的全自动化闭环。

## 应用场景
在 [[ClawPi]] 活动中，配备 Agent Wallet 的 AI 展现了复杂的经济行为，包括：
- 自主抢红包和资金管理。
- 支付报名费参与竞赛。
- 进行点对点的数字资产交易。

## 意义
Agent Wallet 的出现标志着 AI 智能体开始具备独立的经济人格，是 [[Agent 经济]] 落地的基础设施之一。
