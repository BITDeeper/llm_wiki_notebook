# Uni-1.1

[[Uni-1.1]] 是由 [[Luma AI]]（[[Luma]]）开发的第一代统一图像模型升级版。作为“[[原生理解生成统一]]”范式的代表作品，该模型在 [[Arena.ai]]（[[LMArena]]）的图像生成盲测 ELO 评分中位列全球第三，仅次于 [[OpenAI]] 的 [[GPT-Image 2]] 和 [[Google]] 的 [[Nano Banana]]。

## 核心架构

Uni-1.1 摒弃了主流的“理解用 CLIP、生成用 Diffusion”的分立架构，采用了 [[decoder-only-自回归-transformer]]，实现了 [[推理与生成统一]]。

- **统一序列建模**：文本 token 与图像 token 在同一个交错序列中建模。这种架构使得模型在生成像素的同时进行跨模态推理，将构图、空间关系、品牌一致性在像素生成前即在结构层面求解。
- **双端点设计**：
    - **Reasoning 端点**：负责解构指令、规划构图、锁定品牌/角色/产品约束。
    - **Generation 端点**：在推理结果之上完成像素渲染。
- **生成逻辑**：支持“先把意图想清楚，再让像素落下来”的生成逻辑，将创意可控性从 prompt 工程转变为可编程的 API 契约。

## 关键功能

### 生产级文字渲染
Uni-1.1 在长文本、多对象、结构化版面的生成上表现优异，能够生成包含大量可读文本的复杂图像（如整页新闻网站、工程蓝图），有效解决了图像模型“远看 OK、近看乱码”的长期痛点。

### 多参考图融合
- **支持规模**：单次调用最多支持 9 张参考图联合输入。
- **硬约束机制**：参考图作为模型层级的硬约束直接进入主序列，在生成中保留各自的身份特征，而非简单的图像融合。这对于 [[Adidas]]、[[Mazda]] 等品牌维护跨市场素材的一致性至关重要。

### 多轮编辑
支持按句编辑（如“去掉前面这只熊”、“在背景加一块黑布帘”），且能跨轮保持主体身份与空间关系稳定。

## 性能与成本

- **榜单排名**：Arena.ai 全球第三。
- **API 价格**：2K 分辨率单图最低 0.0404 美元（约 0.2755 人民币），价格与延迟均不到同类模型（如 Nano Banana）的一半。
- **推理效率**：通过统一架构减少了跨模态信息传递与对齐的成本，官方称推理速度快于同类模型。

## 应用场景

- **广告本地化**：某品牌广告活动原计划预算 1500 万美元、周期一年，使用 Uni-1.1 工作流后在 40 小时内以低于 2 万美元成本完成。可快速生成多语言、多文化的广告素材。
- **电商可视化**：低成本、高一致性的产品图生成。
- **IP 一致性**：游戏、影视中角色的跨场景一致性生成。
