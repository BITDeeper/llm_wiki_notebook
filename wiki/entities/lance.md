# Lance

Lance 是字节跳动智能创作实验室发布的原生统一多模态模型，仅凭 3B 激活参数在视频理解与生成双榜登顶，是轻量级统一多模态模型的新标杆。

## 核心架构

Lance 采用[[双专家混合架构]]（Dual-expert MoE），核心设计理念为"统一上下文建模与解耦能力路径"：

- **理解专家**：处理文本和来自 ViT 的语义视觉 Token，负责语义推理和文本生成，采用自回归预测。
- **生成专家**：处理来自 VAE 的连续潜变量 Token，负责视觉合成和编辑，采用[[流匹配]]（Flow Matching）技术。

两个专家共享同一个交错的多模态上下文序列，但在执行具体任务时通过不同路径计算，有效解决了[[表征冲突]]问题。

## 关键技术创新

- **[[mape-模态感知位置编码]]**：在时间维度为不同功能 Token 组引入特定偏移量，使模型能区分语义 Token、干净 VAE 条件 Token 和加噪 VAE 目标 Token，显著提升跨任务对齐效果。
- **[[四阶段进阶训练]]**：预训练（PT）→ 持续训练（CT）→ 有监督微调（SFT）→ 强化学习（RL），RL 阶段使用 GRPO 算法专门优化文本渲染准确度。

## 评测表现

| 评测基准 | 得分 | 备注 |
|----------|------|------|
| VBench（视频生成） | 85.11 | 统一模型排名第一 |
| MVBench（视频理解） | 62.0 | 较前纪录 Show-o2 提升 11.3% |
| GenEval（图像生成） | 0.90 | 媲美 20B 规模的 Qwen-Image |

## 资源效率

- 仅 3B 激活参数
- 128 张 GPU 完成全部训练
- 代码已在 GitHub 开源：https://github.com/bytedance/Lance

## 多任务协同效应

消融实验验证了[[多任务协同效应]]：引入理解数据能反哺生成任务的语义对齐，多任务生成训练也能提升模型对视频的理解深度。这证明统一模型不是简单的能力叠加，而是相互促进的机制。

## 与同类模型的对比

Lance 与[[sensenova-u1]]同属[[原生理解生成统一]]范式，但技术路线不同：商汤采用 neo-unify 架构，字节采用双专家 MoE + MaPE。这反映了该领域尚未形成共识性最优解。Lance 侧重视频理解+生成，商汤 U1 侧重信息图生成。
