# UI-TARS-72B

UI-TARS-72B 是一个 720 亿参数的 GUI 智能体模型，在 [[se-ga|SE-GA 框架]]的实验中作为主要对比基线之一。SE-GA（7B）在多个基准上超越了该 72B 模型：

- ScreenSpot：UI-TARS-72B 得分 88.4%，被 SE-GA（89.0%）超越
- GUIOdyssey：动作类型准确率被 SE-GA（96.5%）超越
- AndroidWorld：UI-TARS-7B（33.0%）显著落后于 SE-GA（39.0%）
