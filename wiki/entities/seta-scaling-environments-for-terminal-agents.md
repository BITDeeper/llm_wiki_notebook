# SETA (Scaling Environments for Terminal Agents)

**SETA** (Scaling Environments for Terminal Agents) 是 [[eigent]] 项目的一个核心组件，旨在实现 Agent 对计算机终端的直接控制。

## 功能特点
- **直接接管**：允许 Agent 直接在命令行中执行操作（如 `git clone`, `npm install`），而非仅输出文本代码块。
- **自我修正**：Agent 能够读取报错日志并自动进行调试和环境修复。
- **闭环环境**：打造了闭环的运行环境，使 Developer Agent 能够真正独立完成任务。

## 行业评价
- 获得了 AI 研究者 [[andrej-karpathy]] 的点赞。
- 被谷歌开发者博客誉为“Next Generation Agents”（下一代智能体），标志着 AI 从“文本生成”进入“环境交互”的深水区。
