# Adam Wathan

Adam Wathan 是 [[Tailwind CSS]] 的创始人兼 CEO。他是全栈工程师出身，因创造 Tailwind CSS 框架而闻名于前端开发社区。

## 关键事件

### 2026 年财务危机公开信

在 2026 年 1 月，Adam Wathan 公开透露 Tailwind CSS 公司面临严重的财务危机。他在播客和社交媒体上表达了极度的情绪化反应，称自己“像个白痴”，因为虽然他打造了一个“统治级的 CSS 框架”，却找不到办法养活仅 8 人的团队。

-   **裁员决策**：他不得不裁掉 75% 的工程团队（3 名同事），这让他感到极度沮丧和挫败。
-   **危机预警**：他计算出如果情况不改变，公司将在 6 个月内无法支付工资。
-   **公开求救**：他甚至一度将 GitHub 仓库设为私有，以逃避社区的关注，随后录制视频向社区求助。

## 观点与反思

Adam Wathan 的经历揭示了 [[AI 时代的开源困境]]：开源项目虽然获得了巨大的生态影响力，但在 AI 工具阻断了传统变现路径（文档流量）后，变得极其脆弱。他的公开求助最终引发了 [[Google AI Studio]] 和 [[Vercel]] 的 [[生态反哺]] 行动。
