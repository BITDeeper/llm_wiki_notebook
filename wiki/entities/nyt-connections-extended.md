# NYT Connections Extended

NYT Connections Extended 是 GitHub 上维护的一个逻辑推理基准测试，使用 940 道《纽约时报》Connections 谜题来评估大语言模型的逻辑推理和抗干扰能力。

## 测试特点
该测试通过额外加入干扰词来提升难度，被认为是社区公认的高难度 Benchmark 之一。

## 关键数据
在 [[Claude Opus 4.7]] 的争议中，该基准测试提供了关键的客观数据支持：
- **Claude Opus 4.6 (High Reasoning)**: 94.7%
- **Claude Opus 4.7 (High Reasoning)**: 41.0%

这一断崖式下跌（从年级第一到不及格）被用户引用作为 4.7 在逻辑推理能力上退化的铁证，与官方强调的“全球第一”评测（主要基于工作任务）形成了鲜明对比。
