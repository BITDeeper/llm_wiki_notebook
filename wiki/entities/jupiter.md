# Jupiter

Jupiter 是 [[Anthropic]] 内部正在开发的新型大语言模型代号，于 2026 年 5 月初在 Claude Code 相关源码泄露中被曝光。

## 基本信息

- **开发者**：Anthropic
- **代号性质**：内部使用代号（V1），预计不会出现在公开 API 字符串或用户界面中。
- **定位推测**：可能是 [[Sonnet]] 级别的后续型号，或者是 Anthropic 产品线中的全新分支。

## 曝光细节

Jupiter 与 [[Sonnet 4.8]]、Opus 4.7、Mythos 和 Capybara 等型号一同出现在源码泄露信息中。考虑到 Sonnet 4.8 已经现身，Jupiter 被视为产品线演进中的下一个重要节点。

## 预期发布

据传，Anthropic 计划在 2026 年 5 月 6 日于旧金山举办的“Code with Claude”开发者大会上正式展示相关进展，Jupiter 可能是其中的核心内容。
