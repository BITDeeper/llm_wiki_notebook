# Qwen-3-1.7B

**Qwen-3-1.7B** 是通义千问系列的小参数语言模型。

在 [[AutoGEO]] 框架中，Qwen-3-1.7B 被用作 **AutoGEO Mini** 的基础模型。通过使用提取的偏好规则作为奖励信号进行强化学习微调，该模型能够以极低的成本（推理成本仅为 API 版本的 0.71%）实现离线的内容优化，且可在 CPU 上运行。
