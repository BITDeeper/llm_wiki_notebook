# MiMo-V2.5-Pro

[[小米]] 开发的旗舰级 AI Agent 模型，于 2026 年 4 月正式开源。该模型前身为匿名测试代号 [[hunter-alpha]]，作为 MiMo-V2.5 系列中的 Pro 版本，它在通用智能体能力、复杂软件工程与长程任务处理上实现了显著跃升，跻身国产开源第一梯队，性能逼近国际顶尖闭源模型（如 Claude Opus 4.6、GPT-5.4）。

## 核心特性

### 1. 极高的长程任务稳定性
MiMo-V2.5-Pro 被设计用于处理需要大量步骤和长时间跨度的复杂任务。其核心优势在于能够在长时间运行中保持逻辑连贯性，无需人类干预。

-   **北大 SysY 编译器项目**：在 4.3 小时内，通过 672 次工具调用，自主完成了从零编写一个完整编译器的任务。涵盖了词法分析、语法分析、中间代码生成、RISC-V 后端及性能优化，最终获得 233/233 的满分。
-   **类 macOS 系统复刻**：在 4 小时内，无中断地构建了一个包含 68 个组件和 54 个原生应用的桌面操作系统环境。该系统具备完整的窗口状态机（拖拽、缩放、焦点管理、z-index）和可浏览网页的 Safari 浏览器。

### 2. 卓越的 Token 效率
在 [[claweval]] 评测基准中，MiMo-V2.5-Pro 展现了极高的资源利用率。

-   仅消耗约 7 万 Token 即达到 64% 的 Pass³ 通过率。
-   相比同类竞品（通常消耗 12-18 万 Token），成本降低了 40%-60%。

### 3. 强大的模糊指令遵循能力
该模型能够理解并执行非结构化、依赖语境的自然语言指令，降低了用户的使用门槛。

-   **案例**：在仅输入“山野风格、治愈系、逃离城市”等模糊描述的情况下，模型自主完成了配色方案（大地色系）、字体选择（手写感）、动效设计（视差滚动、粒子效果）及交互逻辑，生成了一个高完成度的数字手账本。

### 4. 全模态与长上下文
-   **1M 上下文窗口**：全系标配，支持 100 万 token 的长上下文输入，使得在处理复杂任务（如大型项目开发）时无需频繁清理会话历史。
-   **语音能力**：集成了先进的 TTS（支持文本描述造音色）和 ASR（支持多方言及歌词转写）能力。

## 实测表现

### SBTI 测试仿写
在“10 分钟仿写 SBTI 测试”的实测中，MiMo-V2.5-Pro 展现了极高的开发效率：
1.  **快速规划**：在 3 分钟内完成了项目拆解和路线图生成。
2.  **高效执行**：在 7 分钟内完成了算法理解、代码编写和调试，成功复刻了包含 30 道题目和 25 种类型的测试系统。
3.  **行为特征**：表现出明显的 [[最短路径倾向]]，倾向于绕过复杂的子智能体调用，直接编写代码以最快解决问题。

### Agent 框架兼容性
在 [[gsd]] 等 Agent 框架下表现出色，能够自动拆解任务、生成路线图并执行代码，具备处理复杂、多步骤任务并维持上下文连贯的能力。

## 竞争格局
MiMo-V2.5-Pro 的发布被视为对 [[claude-code]] 和 GPT-4.1/GPT-5.4 等国际顶尖模型的直接挑战。特别是在编程 Agent 领域，其通过“无中断生成”和“高 Token 效率”解决了当前 AI 编程中常见的成本高昂和上下文丢失问题。

## 开源与生态
-   **权重开放**：模型权重已全量开源。
-   **MiMo Orbit**：作为底层引擎支持该计划，向开发者提供百万亿 Token 激励及框架接入支持。
