# Project Eden

Project Eden 是 [[vast|VAST]] 发布的全球首个允许对世界状态进行自主维护与确定性控制的世界模型。它采用 [[状态推演与视觉呈现原生解耦]] 的三层架构，从根本上区别于主流的动作条件视频生成和静态 3D 场景生成方案。

## 核心架构：三层解耦

### 第一层：结构化状态层
- 跨时间持续存在、可进行动作更新、可被任意相机位置查询的全局结构化表征
- 并非庞大的 4D 点云，而是一种紧凑的、兼顾效率与语义丰富性的隐式表征
- 负责回答"世界里有什么、发生了什么"，独立于任何观察者的视角而存在

### 第二层：条件接口层
- 状态与渲染之间的转换枢纽
- 将底层全局世界状态按特定相机位置和观察视角转化为局部条件约束
- 包括语义信息、几何线索、局部事件变化等中间表征
- 从物理机制上保证多视角之间的一致性

### 第三层：生成式渲染层
- 在底层状态与中间约束的双重指引下生成精细化视觉画面
- 不再承担猜测画面结构的责任，专注于补全纹理、光照、材质和高频局部动态细节

## 三大系统级能力

### 1. 环境长程持久化
物体离开相机视野后仍在底层状态中存在并继续演化，用户返回时查询的是同一个底层世界状态。世界拥有真正意义上的长程记忆。详见 [[环境长程持久化]]。

### 2. 场景自由复用与确定性控制
底层状态可被读写和干预，用户的改变被真实写入底层状态，后续进入同一场景的其他用户看到完全一致的世界状态。生成内容从一次性视频变为可复用、可编辑、可持续运营的互动空间。

### 3. 原生多智能体并发交互
底层状态只有一份被所有智能体共享，渲染层根据各自位置和视角独立生成画面。计算成本从指数级变为线性级，是商业大规模落地的先决条件。详见 [[原生多智能体并发交互]]。

## 数据策略

采用 [[双态对齐数据]] 策略，结合 L1（互联网视频自标注）和 L2（引擎合成数据）两层方法。

## Demo 展示

- 暴雨、巨浪与直升机交互的复杂物理场景
- 第一人称视角实时赛车体验
- 人物动画、刚体（木船）与流体（水面）的多模态物理融合

## 更大想象空间

Project Eden 不仅面向内容消费，更天然适合作为通用人工智能的世界底座：
- 世界规则学习
- 仿真模拟
- [[具身智能数据困境|具身智能]]训练环境
- 多智能体协同研究
- 可持续运行的环境供智能体长期训练和探索

## 当前局限

文章承认"通往真正通用的世界模拟器还很长"，Project Eden 目前更像是确立了一条重要的技术路径，距离成熟的通用基础设施仍有距离。目前证据主要基于受控 Demo 演示和理论推演，缺乏大规模公开测试或第三方基准评测的验证。
