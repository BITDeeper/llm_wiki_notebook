# Devin

Devin 是由 [[Cognition]] 公司开发的“世界第一位 AI 软件工程师”。

## 核心特性
不同于传统的代码补全工具（如 GitHub Copilot），Devin 是一个具备自主规划能力的 AI 智能体：
- **全栈操作**：能够独立完成代码编写、调试 bug、部署等全流程工程任务。
- **自主规划**：针对复杂的工程目标，能够自主拆解步骤并执行。
- **性能领先**：在 SWE-bench 基准测试中，Devin 能够独立解决 13.86% 的 GitHub 真实问题，表现远超当时的顶尖模型（如 GPT-4）。

## 技术背景
Devin 的开发团队 [[Cognition]] 被称为“IOI 金牌梦之队”，其强大的算法规划能力被认为是 Devin 能够实现复杂任务自主执行的关键。
