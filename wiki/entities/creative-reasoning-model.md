# Creative Reasoning Model

**Creative Reasoning Model**（创意推理模型）是 [[特赞]] 自研的模型，作为 [[Generative Enterprise Agent (GEA)]] 架构中 **Orchestration Layer（编排层）** 的核心组件。

## 功能
该模型负责在意图被识别之后进行发散推理与路径编排。它不生成单一答案，而是执行以下流程：
1. 拆解多个可能执行路径
2. 评估路径价值与风险
3. 选择最优策略组合

## 意义
Creative Reasoning Model 的存在决定了智能体是否具备真正的业务推理能力。它将 AI 的能力从简单的“内容生成”提升到了复杂的“策略编排”层面，是企业级 Agent 区别于普通生成式模型的关键技术之一。
