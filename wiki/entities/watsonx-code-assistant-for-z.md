# watsonx-code-assistant-for-z

watsonx Code Assistant for Z 是 IBM 于 2023 年推出的一款 AI 工具，旨在利用生成式 AI 帮助客户将 COBOL 代码转换为 Java 等现代语言，作为应用程序现代化工作的一部分。

## 功能与定位
- **代码转换**：辅助开发人员评估和确定最需要现代化改造的代码块。
- **生态锁定**：与 [[Claude Code]] 等通用工具不同，watsonx 的核心目标是**将客户保留在 IBM 的软硬件生态体系内**。它旨在增强大型机的吸引力，而非帮助客户迁移出大型机。

## 市场反应
尽管 IBM 强调该工具是其 GenAI 业务（2025 年规模超 125 亿美元）的重要组成部分，并声称大型机销售额因此增长，但市场对其护城河效应仍持怀疑态度。

当 Anthropic 展示了更通用的 AI 能力（能够处理遗留系统分析而不限于特定平台）后，IBM 股价依然暴跌，表明投资者认为单纯的“修补”策略可能无法抵御“迁移”趋势的冲击。
