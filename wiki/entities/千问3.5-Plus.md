# 千问3.5-Plus

[[千问3.5-Plus]] (Qwen3.5-Plus) 是阿里云于2026年除夕发布的全新一代开源大语言模型。该模型以其“以小博大”的架构设计和极致的性价比著称，在多项基准测试中超越了当时的闭源旗舰模型（如 [[Gemini 3 Pro]]、[[GPT-5.2]] 和 [[Claude 4.5]]），同时保持了极低的推理成本。

## 核心规格

-   **总参数量**: 3970亿 (397B)
-   **激活参数**: 170亿 (17B)
-   **架构**: 混合架构（[[门控技术]] + 线性注意力 + 稀疏MoE）
-   **上下文长度**: 支持1M Token原生上下文
-   **多模态**: [[原生多模态]]，支持2小时超长视频输入

## 性能表现

千问3.5-Plus 在推理、编程和Agent任务上展现了强大的能力：
-   **MMLU-Pro**: 87.8分，超越 [[GPT-5.2]]。
-   **GPQA**: 88.4分，超越以逻辑严谨著称的 [[Claude 4.5]]。
-   **IFBench**: 76.5分，刷新所有模型的历史纪录。
-   **Agent评测**: 在 BFCL-V4 和 Browsecomp 等基准中表现优于 [[Gemini 3 Pro]]。

## 工程效率

通过 [[门控技术]]，该模型在保持高性能的同时大幅降低了资源消耗：
-   **显存占用**: 相比前代万亿参数模型降低60%。
-   **吞吐量**: 在32K上下文下提升8.6倍，在256K超长上下文下最高提升19倍。
-   **推理成本**: API 价格低至 0.8元/百万Token，仅为同级竞品的 1/18。

## Agent能力

得益于 [[原生多模态]] 能力，千问3.5-Plus 具备强大的GUI操作和任务执行能力：
-   **视觉编程**: 能够直接将手绘界面草图或UI截图转化为高质量前端代码。
-   **GUI操作**: 能够自主操作手机与电脑界面，识别按钮、表单并执行多步骤任务。
-   **商业落地**: 千问App的AI购物Agent在春节期间6天内完成了1.2亿笔订单。

## 生态与开源

千问3.5-Plus 是阿里开源生态的一部分。截至发布，阿里已累计开源超过400个千问模型，全球下载量突破10亿次。开发者可通过 [[魔搭社区]] 或 HuggingFace 下载模型，或通过阿里云百炼平台获取API服务。
