# 腾讯混元

腾讯混元是 [[腾讯]] 旗下的人工智能研究团队与大模型系列。在 Mobile Agent 领域，腾讯混元牵头主导了 [[phoneworld|PhoneWorld]] 项目，联合港中深、人大高瓴、武汉大学等学术机构，致力于解决手机智能体训练中面临的环境规模化构建难题。
