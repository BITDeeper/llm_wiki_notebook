# DataElem

DataElem（数据项素）是一家专注于大模型应用落地的前沿科技公司，主要业务涵盖开源平台与企业级 Agent 服务。

## 核心产品

- **BISHENG（必省）**：开源企业级 LLM 应用开发与编排平台。该项目在 GitHub 拥有 1.2 万+ Stars，拥有中国规模最大的企业开发者社区之一。
- **Clawith**：团队版 [[openclaw]]。它将开源的 Agent 能力升级为企业级服务，强调可观测性、可治理性与可扩展性。

## 业务方向

DataElem 聚焦于企业级场景，正在从 0 到 1 将 BISHENG 和 Clawith 等产品推向海外市场，探索 AI 原生全球化的商业化路径。其工作涉及 [[AgentOps]]（AI 智能体运维）领域，旨在解决企业在部署和管理 AI 智能体时面临的治理与监控挑战。
