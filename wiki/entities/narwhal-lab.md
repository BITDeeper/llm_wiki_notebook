# Narwhal-Lab

[[Narwhal-Lab]] 是 [[北京大学]] 旗下的一个研究实验室（或团队）。

该团队因发布开源项目 [[MagicSkills]] 而受到关注。MagicSkills 是一个旨在解决 AI Agent 技能管理问题的工具，被类比为“AI Agent 世界的 npm”。

Narwhal-Lab 的工作聚焦于 AI Agent 的工程化基础设施，致力于推动 Agent 开发从碎片化、重复建设向标准化、可复用的生态方向发展。
