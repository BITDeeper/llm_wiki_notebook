# Aholo 空间智能平台

Aholo 是[[群核科技]]推出的[[空间智能]]全链路平台，提供从 3D 重建到浏览交互的完整能力。

## 核心 API 能力

### 空间重建
拍一段视频，即可将物理世界 1:1 复刻到数字世界。

### 云端渲染
- 无需本地 GPU
- 支持光线追踪与全局光照渲染
- 支持 3DGS + Mesh 混合渲染
- 支持以视频流方式传输至不同客户端

### 3D AI 模型生成
- 支持图生 3D 和文生 3D 模型
- 具备更强的材质细节表现
- 可接入 3D 内容生产工作流

## 数据资产
持续开放 3D 高斯数据集，包括 [[interiorgs]]——曾登顶 HuggingFace 趋势榜的 3D 高斯语义数据集，专门用于机器人和智能体仿真训练。

## 全链路闭环
1. **重建/生成 3D 世界**：通过 Aholo 完成真实世界的 3D 重建，或根据文字、草图直接生成 3D 场景
2. **编辑 3D 资产**：通过平台多种 API，让 3D 世界像网页一样可编程
3. **浏览交互**：通过 [[aholo-viewer]]，让用户在任何设备的浏览器里实时漫游超大 3D 场景

## 应用场景
- **数字文旅**：文物古迹通过 3DGS 重建"活"在数字世界
- **短剧制作**：手机拍摄后快速重建三维"虚拟片场"，通过 API 编辑场景元素
- **工业孪生**：物理世界的数字化复刻
- **机器人训练**：提供仿真训练数据集
