# MuleRun

**MuleRun**（骡子快跑）是一个全球首个自进化个人 AI 平台，于 2026 年 3 月 16 日正式发布。它被定位为“赛博骡子”，旨在通过 [[免部署]] 和 [[云端虚拟机]] 技术，为用户提供 7×24 小时在线的 AI Agent 服务。

## 核心特性

### 1. 零部署与易用性
- **免部署**：用户无需配置本地环境或安装依赖，打开网页即可使用。
- **自然语言交互**：支持使用大白话指令生成复杂的 Agent 应用（如网站、游戏）。
- **模块化设计**：界面分为 Super Agent（主对话框）、Knowledge（技能模板）、Computer（持续运行任务）和 Drive（历史记录）。

### 2. 自进化与主动性
- **个性化学习**：系统能够持续学习用户的数据、习惯与决策方式，随时间推移越来越贴合用户需求（参见 [[自进化个人 AI]]）。
- **主动触达**：具备主动推荐待办事项、智能预判解决方案和定时推送信息的能力。

### 3. 云端执行与安全
- **云端虚拟机**：为每位用户分配独立的云端运行环境，确保任务在本地电脑离线时仍能持续运行。
- **沙箱隔离**：通过物理隔离保护用户本地数据，防止 AI Agent 读取本地密码或破坏系统（对比 [[OpenClaw]] 的安全隐患）。

### 4. 群体智慧共享
- **Agent 网络**：用户可以将自己创建的优质 Agent 模板分享到生态中，其他用户可以直接复用经过群体验证的最佳实践。

## 应用场景
- **资讯监控**：自动生成并维护 24 小时更新的行业资讯追踪网站。
- **内容创作**：辅助进行短剧/漫剧的拉片、叙事提炼和分镜设计。
- **游戏开发**：快速生成网页小游戏（如贪吃蛇），且运行流畅度优于部分国内 AI 工具。

## 与 OpenClaw 的对比
| 特性 | MuleRun | OpenClaw |
| :--- | :--- | :--- |
| **部署方式** | 免部署（SaaS） | 本地部署（高门槛） |
| **运行环境** | 云端虚拟机 | 本机环境 |
| **安全性** | 沙箱隔离，不碰本地数据 | 存在系统风险（如删除邮件） |
| **售后支持** | 提供专业团队支持 | 主要靠社区自助 |
