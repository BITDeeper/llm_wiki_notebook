# 智谱华章

**智谱华章**（北京智谱华章科技股份有限公司，02513.HK）是中国领先的人工智能公司，被誉为“中国的OpenAI”。公司由清华大学技术成果转化而来，专注于通用人工智能（AGI）的研发，致力于“让机器像人一样思考”。

## 发展历程
- **2019年**：公司成立，源自清华大学 KEG 实验室。
- **2021年**：推出原创算法架构 [[GLM]]。
- **2026年1月8日**：在香港联交所挂牌上市，成为“全球大模型第一股”。

## 核心技术
智谱坚持原创技术路线，提出了基于 [[自回归填空]] 的通用预训练范式 [[GLM]]。该架构具有高度的通用性和国产化适配能力，已适配40余款国产芯片。公司研发投入巨大，累计投入约44亿元，研发人员占比高达74%。

## 商业模式
公司采用 [[MaaS]]（Model as a Service）模式，通过 API 调用、模型订阅及本地化部署向企业和开发者输出通用智能能力。
- **开发者生态**：MaaS 平台汇聚超过300万开发者。
- **企业客户**：赋能全球12000家企业客户及逾8000万台终端设备。
- **收入增长**：2025年上半年收入同比增长325%，编程订阅产品 ARR 过亿。

## 市场地位
根据弗若斯特沙利文报告，按2024年收入计算，智谱在中国独立通用大模型开发商中排名第一。其最新模型 [[GLM-4.7]] 在多项国际权威榜单中位列开源模型与国产模型榜首。
