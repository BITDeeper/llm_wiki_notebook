# AI Insights

AI Insights 是 Meta 内部的一个官方仪表盘。在 [[claudeonomics]] 排行榜因舆论压力被撤下后，该仪表盘仍然保留并对所有员工开放。

## 功能

AI Insights 允许员工查看自己和团队的 AI Token 消耗情况。Meta 发言人表示，该仪表盘的目的是帮助公司了解各组织如何向 [[ai-native]] 的工作方式转型，提供的洞察不仅包括 Token 用量，还涵盖代码相关指标和其他维度。

## 争议

尽管 Meta 声称排行榜的撤下意味着公司不再以 Token 论英雄，但 AI Insights 的持续存在表明，监控 Token 消耗的逻辑并未消失。这种可视化的数据展示，配合 [[checkpoint]] 系统的记录，依然在无形中引导着员工的行为，使得 [[tokenmaxxing]] 的诱因依然存在。
