# COMI

**COMI** (Coarse-to-fine context compression via Marginal Information Gain) 是由 [[阿里巴巴未来生活实验室]] 提出的一种长文本压缩框架。该框架旨在解决大语言模型在处理超长上下文时面临的计算成本高和显存占用大的问题，特别是在高压缩率（如 32 倍）场景下保持甚至提升模型性能。

## 核心机制

COMI 的核心创新在于引入了 [[边际信息增益]]（MIG）作为 Token 价值的评估指标，并采用 [[粗到细压缩]] 的两阶段策略来执行压缩。

### 边际信息增益 (MIG)
传统的压缩方法往往只保留与查询相关性最高的 Token，这容易导致保留大量语义重复的冗余信息。COMI 定义的 MIG 指标计算公式为：
$$ \text{MIG} = \text{相关性} - \text{最大相似度} $$
通过减去该 Token 与其他已选 Token 的最大相似度，MIG 有效地惩罚了冗余信息，鼓励保留既相关又多样化的内容。

### 粗到细压缩
1.  **粗粒度组重分配**：系统首先将长文本切分为多个片段，然后根据每个片段的 MIG 分数动态分配压缩预算。包含关键证据的高价值片段会被分配更多的 Token 保留额度，而信息稀疏的片段则被大幅压缩。
2.  **细粒度 Token 融合**：在片段内部，COMI 不采用简单的截断或平均池化，而是基于 MIG 分数对 Token 进行加权融合。这确保了关键信息在压缩过程中不会被平滑掉，实现了“既紧凑又富含信息”的表示。

## 性能表现

根据 ICLR 2026 的论文数据，COMI 在多个基准测试中表现出色：
- **高压缩率优势**：在 32 倍压缩率下，COMI 在 NaturalQuestions 数据集上的 Exact Match (EM) 分数达到了 49.15，比当时的次优基线高出近 25 个百分点。
- **提纯效应**：实验发现，使用 COMI 压缩后的 Qwen3-4B 模型（F1 28.89），其性能显著优于直接输入完整上下文的原生模型（F1 16.90）。这证明了 COMI 通过去除噪声和冗余，实现了“压缩即提纯”的效果。
- **推理加速**：由于输入上下文长度的显著减少，端到端推理速度提升了 2 倍以上。

## 应用场景

COMI 特别适用于以下场景：
- **RAG 系统**：在检索增强生成中，检索到的文档往往包含大量无关段落，COMI 可以精准提取关键证据。
- **长文档问答**：处理书籍、财报或长篇报告时，COMI 能将上下文压缩至模型可处理的范围，同时保留回答问题所需的关键信息链。
