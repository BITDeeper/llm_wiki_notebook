# New API

基于 [[one-api]] 二次开发的商业化框架，提供更完善的商业化功能，成为众多 AI 中转站事实上的底层框架。

## 行业地位

作为 One API 的商业化增强版，New API 降低了中转站的运营门槛，使非技术背景的从业者也能快速搭建和运营中转站服务。
