# DeepSeek-TUI

DeepSeek-TUI 是由美国独立开发者 Hunter Bown 发起的开源终端编程工具，定位为"DeepSeek版[[claude-code|Claude Code]]"。截至2026年5月已在 GitHub 获得 32.9k Stars。

## 技术特征

- 使用 Rust 语言编写
- 在终端中运行，针对 [[DeepSeek V4]] 做了专门优化适配
- 功能覆盖：读写文件、执行 Shell、搜网页、管 Git、调度子 Agent、接 MCP 服务器
- 支持安装 Skills，底层由 DeepSeek V4 驱动
- 提供中文版 README 文档和 TUNA Cargo 镜像，适配国内用户

## 生态意义

DeepSeek-TUI 是 [[deepseek-code|DeepSeek Code]] 官方产品发布前最重要的社区平替，反映了开发者对 DeepSeek 编程工具的强烈需求。其快速增长的 Star 数（32.9k）也印证了 DeepSeek 在开发者社区的影响力。
