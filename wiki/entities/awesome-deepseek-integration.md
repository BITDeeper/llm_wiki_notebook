# awesome-deepseek-integration

**awesome-deepseek-integration** 是 [[DeepSeek]] 官方维护的 GitHub 仓库，旨在收录和整理所有与 DeepSeek API 相关的第三方集成项目。

## 功能与内容
该仓库集中展示了 DeepSeek 的生态系统繁荣度，收录的项目包括：
- **客户端应用**：如 [[LobeChat]]、BibiGPT 等。
- **开发运维工具**：如 SkyPilot、DeepSeek Alfred WorkFlow 等。
- **企业级解决方案**：如 Bytedesk、微信 RPA 智能客服等。

## 市场信号
2026 年 2 月，维护者 [[mowentian]] 对该仓库进行了大规模更新（合并 PR #121 至 #536），这一常规维护动作因市场对 [[DeepSeek V4]] 的敏感神经，被外界解读为可能的新模型发布前兆，间接触发了金融市场的“[[deepseek第二时刻]]”预警。
