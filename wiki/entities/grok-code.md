# Grok Code

Grok Code 是 [[xAI]] 开发的代码智能体产品，直接对标 [[Anthropic]] 的 [[Claude Code]] 和 [[Google]] 的 [[Gemini]] 编程能力。

## 项目背景
该项目由 [[xAI]] 联合创始人 [[张国栋]] 直接负责并向 [[Elon Musk]] 汇报，是公司的两大战略产品之一（另一个是 [[Grok Imagine]]）。

## 现状与风险
随着张国栋及多位核心技术负责人的离职，Grok Code 的未来发展面临巨大的不确定性。核心领导层的变动可能导致项目延期或技术方向发生重大改变。
