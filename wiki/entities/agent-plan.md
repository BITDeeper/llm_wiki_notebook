# Agent Plan (长期计划)

[[agent-plan]] 是 [[coze]] 平台推出的“长期任务”功能，旨在解决 AI 智能体在长周期、复杂任务中的落地难题。

## 工作原理
Coze 将其称为“[[目标导向协作]]”。其工作流程如下：

1. **目标拆解**：用户给出一个模糊的目标（如“开副业”、“练口语”），AI 将其拆解为清晰、可执行的步骤。
2. **自动执行**：AI 按步骤调用相应的 [[coze-skills]] 和工具去执行任务。
3. **人工确认**：在关键节点，AI 会请求用户进行确认，确保方向正确。

## 角色转变
Agent Plan 将 AI 的角色从被动的“工具”转变为主动的“同事”或“职场搭子”。它不仅能生成内容，还能催促进度、补全缺口并交付结果。

## 应用价值
该功能特别适合那些“想做但没落地”的长周期任务，如学习新技能、健身、自动化汇总等。通过 AI 的主动推进，帮助用户克服拖延，实现目标的持续达成。
