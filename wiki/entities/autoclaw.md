# AutoClaw

[[autoclaw]]（中文昵称：澳龙）是由 [[zhipu-ai]]（智谱AI）发布的 [[openclaw]] 官方桌面封装版本及智能体应用框架。它旨在通过产品化手段解决原版 OpenClaw 极高的安装门槛，并集成最新的多模态模型能力，使普通用户也能轻松使用本地 AI Agent。

## 核心特性

### 一键安装与部署
AutoClaw 将原本复杂的命令行配置流程（环境搭建、API Key 填写、端口调试）封装为标准的桌面应用程序。用户只需下载、双击并登录智谱账号即可使用，号称“1分钟”完成部署。这一改进极大地降低了技术门槛，终结了围绕 OpenClaw 形成的 [[代装产业链]]，体现了 [[agent-部署平民化]] 的趋势。

### 飞书深度集成
AutoClaw 提供了一键配置 [[飞书]] 机器人的功能。通过自动化脚本处理原本繁琐的开放平台应用创建、权限开通和 Webhook 配置，实测可在 2 分半钟内完成。这使得 Agent 不再局限于桌面端，而是可以通过手机或 iPad 上的飞书随时调用，作为群助手处理任务或推送信息。

### 模型热插拔与多模态支持
作为一个开放的 Agent 容器，AutoClaw 支持动态切换底层大模型，并集成了最新的多模态能力：
- **内置选项**：包括 [[glm-5v-turbo]]、GLM-4.7、GLM-5 以及完全免费的 [[glm-4-7-flash]] 系列。
- **外部接入**：支持用户添加 DeepSeek、MiniMax、Kimi 等第三方 API Key。
- **多模态交互**：支持用户通过截图、链接、文档等多种形式输入指令，利用 GLM-5V-Turbo 的视觉能力分析图表或界面。

### 技术内核
- **核心模型**：内置 [[pony-alpha-2]]，这是智谱专为 Agent 场景优化的模型，擅长长链路任务规划和工具调用。
- **技能体系**：完整继承 OpenClaw 的 Skill 体系，预装 50+ 技能（涵盖资讯搜集、舆情监控、跨平台同步等）。框架内置了多种 Skills，允许模型直接调用智谱家的图像、视频生成等模型（使用澳龙积分，无需额外配置）。
- **浏览器工具**：特别集成了 [[autoglm-browser-agent]]，相比原版自带的浏览器工具，在处理多步骤、跨页面复杂任务时稳定性大幅提升。
- **本地环境交互**：允许模型接管本地桌面环境，例如读取文件夹内容、执行 Python 脚本进行数据清洗等，实现了 Agent 与本地操作系统的深度集成。
- **训练机制**：利用合成环境生成的数据进行训练，以确保在真实 GUI 环境（如 AndroidWorld, WebVoyager）中的操控能力。

## 应用场景

AutoClaw 能够浏览网页、解读文档、制作报告和 PPT，并执行 GUI 操作，典型应用场景包括：

- **全栈开发与原型开发**：辅助开发人员根据草图快速生成前端代码（视觉编程），或直接在本地运行和测试 AI 生成的代码（如基于 GitHub 仓库自动生成 UI 界面）。
- **金融分析**：利用“股票分析师”等 Skill，自动读取股票 K 线图和研报，生成分析报告。
- **资讯监控**：定时抓取 B站、抖音、GitHub 等平台资讯并总结。
- **文档处理**：快速解析长篇论文或技术文档，提取关键信息。
- **本地数据处理**：通过脚本自动化处理本地文件。
- **多模态内容生成**：利用内置 Skills 生成图文结合的内容。

## 市场定位

AutoClaw 的发布标志着 AI Agent 工具从“极客玩具”向“大众工具”的转变。它是 [[openclaw]] 的商业化、易用化封装版本，配合智谱发起的“小龙虾敲门计划”（社区免费安装活动），意在加速 Agent 技术的普及。
