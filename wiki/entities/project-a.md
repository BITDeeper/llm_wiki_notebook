# Project A

Project A 是 OpenAI 与著名设计师乔纳森·艾维合作开发的硬件设备项目。

## 战略动机
OpenAI 在 iOS 生态中面临双重困境：
1. **苹果税**：每笔收入需向苹果分成 30%。
2. **后台限制**：受制于操作系统的后台运行限制，无法实现全时在线的 AI 体验。

## 目标
通过打造自有硬件入口，绕过苹果和谷歌的操作系统壁垒，实现真正的全时在线 AI 服务。该项目被视为 OpenAI 构建“软硬一体”护城河的关键尝试。
