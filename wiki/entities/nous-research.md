# Nous Research

Nous Research 是一家成立于 2023 年的 AI 实验室，总部位于硅谷，团队规模约 20 人。该机构以推出 Hermes 系列开源大模型和 Agent 框架而闻名，在 LLM 圈具有显著影响力。公司累计融资 6500 万美元（其中包括由 Paradigm 领投的 5000 万美元 A 轮）。

## 核心产品与项目

- **Hermes Agent**：该公司的主打开源自主 Agent 框架，强调私有部署和内置学习闭环。旨在构建从 Agent 使用到模型训练的数据飞轮。
- **Hermes/Nomos/Psyche 模型家族**：团队此前开发了多个开源模型家族，累计下载量超 5000 万次。这些模型在 Agent 场景（如工具调用、长程规划）中被广泛使用。

## 战略定位

Nous Research 的独特之处在于“**训模型的人亲自做 Agent**”。

- **数据反哺训练**：通过 Hermes Agent 收集用户在真实场景中的工具调用轨迹数据，用于训练和优化下一代 Hermes 模型。
- **生态构建**：推出了 [[agentskills-io]] 开放技能标准，试图构建一个技能可跨项目共享的 Agent 生态系统。

## 创始团队

主要创始人包括 Jeffrey Quesnelle、Karan Malhotra、Teknium 和 Shivani Mitra，均具有研究与工程背景。
- **Jeffrey Quesnelle**（联合创始人）：曾演示使用 Hermes Agent 自主完成一部 7.9 万字的小说。

## 发展历程

- **2023 年**：公司成立。
- **2026 年 2 月**：推出 Hermes Agent，迅速在 GitHub 上获得 4 万星。
- **2026 年 4 月**：Hermes Agent 迭代至 v0.8.0，确立了“安全 → 稳定 → 智能”的演进路线。

## 争议

2026 年，其旗下的 [[hermes-agent]] 项目被指控抄袭中国团队 [[evomap]] 的 [[evolver]] 架构。在证据确凿的情况下，该机构被指态度傲慢，仅以“Delete your account”回应，引发了关于开源伦理和 AI 抄袭的广泛批评。
