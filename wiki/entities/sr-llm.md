# SR-LLM

[[SR-LLM]] 是由 [[清华大学]]、中国科学院自动化研究所等机构联合发布的一种融合大语言模型（LLM）与深度强化学习（DRL）的新型 [[符号回归]] 框架。它旨在从数据中自主发现简洁、可解释的数学公式，被视为 [[ai-for-science]] 领域向 [[白盒符号主义]] 回归的重要代表。

## 核心特性
- **可解释性**：不同于传统的“黑箱”神经网络，SR-LLM 输出人类可读、可验证的数学解析表达式。
- **融合架构**：结合了 LLM 的语义推理能力与强化学习的搜索优化能力。
- **增量生成**：将符号回归转化为增量式任务，通过检索增强机制动态利用先验知识。

## 技术架构
SR-LLM 的运行机制包含四个核心组件：
1.  **Radix 树存储**：用于高效存储和检索历史探索的公式结构。
2.  **双阶段强化学习**：结合“风险寻求”策略与 SAC 算法，平衡探索与利用。
3.  **检索增强生成 (RAG)**：利用外部知识库（专家模型、历史经验）辅助生成。
4.  **知识提取与利用**：通过 LLM 的推理模块，将语义知识转化为符号组合。

## 应用与成果
- **基准测试**：在标准符号回归基准（Feynman, Fundamental）上表现优异。
- **科学发现**：在 [[跟驰模型]] 发现任务中，不仅复现了经典模型，还发现了在边缘情况下（如突发速度变更）性能更优的新模型。
- **鲁棒性**：在含噪真实数据（如 NGSIM 轨迹数据）中表现出色。

## 未来方向
研究团队计划将其发展为类似 [[AlphaZero]] 的自举范式，实现在无先验知识条件下的完全自主科学发现。
