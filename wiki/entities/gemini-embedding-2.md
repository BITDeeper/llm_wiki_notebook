# Gemini Embedding 2

**Gemini Embedding 2** 是谷歌发布的首个原生全模态嵌入模型。它能够将文本、图像、音频、视频和 PDF 文档映射到同一个统一的向量空间中，实现了真正的跨模态语义检索。

## 核心特性

### 原生全模态支持
不同于传统的“转录+文本嵌入”或“拼接式”多模态方案，[[gemini-embedding-2]] 直接处理原始数据，将所有模态数据整合进同一个语义坐标系：

- **文本**：支持 100+ 语言，上下文窗口 8192 tokens。
- **图像**：支持 PNG 和 JPEG 格式，单次请求最多 6 张。
- **音频**：支持 MP3 和 WAV 格式，原生处理（无需转录），最长 80 秒。
- **视频**：最长 120~128 秒的动态影像（支持 MP4, MOV）。
- **文档**：支持原生读取 PDF，最多 6 页。
- **混合输入**：支持如“图像+文本”的混合查询。

### 俄罗斯套娃表示学习 (MRL)
该模型采用了 [[俄罗斯套娃表示学习]] 技术，允许开发者根据存储和计算预算灵活调整向量维度，而性能损失极小：
- **3072 维**：默认满血状态，提供最佳检索性能。
- **1536 维**：MTEB 多语言得分 68.17。
- **768 维**：维度降低 75%，得分仅微跌 0.18 分（67.99 分）。

## 技术优势

1. **消除信息损耗**：通过直接处理音频波形和图像像素，保留了语调、背景音等在转录过程中丢失的“感官细节”。
2. **架构简化**：将过去需要多个独立模型、多个向量数据库和复杂重排序算法的流程简化为一次 API 调用。
3. **跨模态检索**：支持使用一种模态（如发动机异响录音）检索另一种模态（如 PDF 维修手册）。
4. **统一感官总线**：提供统一的 [[感官总线]]，大幅简化了 RAG 检索、语义搜索和情感分析等应用的开发流程。

## 应用场景

### 赋能 AI Agent
对于 [[openclaw]] 等 AI Agent，Gemini Embedding 2 提供了关键的视觉理解能力。它不再局限于识别屏幕上的文本标签，而是能理解像素区域、UI 布局和控件位置，从而实现真正的图形界面自动化操作。

### 市场定位
根据报道，[[gemini-embedding-2]] 被称为实现“全模态 SOTA”的模型，填补了 [[OpenAI]] (text-embedding-3 缺视觉)、[[Cohere]] (Embed v4 缺音视频) 和 [[Jina]] (v4 缺音视频) 的市场空白。

## 局限性与注意事项

- **时长限制**：音频限制在 80 秒，视频限制在 120~128 秒，长内容需外部切片。
- **迁移成本**：与旧版模型（如 `gemini-embedding-001`）的向量空间不兼容，迁移需重新编码历史数据。
- **手动归一化**：若使用非默认的低维度输出，开发者需手动进行 L2 归一化处理。

## 可用性
该模型已通过 Gemini API 和 Vertex AI 展开公测，并支持 LangChain、LlamaIndex 等主流工具链调用。
