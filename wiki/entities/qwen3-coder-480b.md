# Qwen3-Coder-480B

Qwen3-Coder-480B 是阿里巴巴开发的开源编程大语言模型，参数规模为 480B。

## 在 Token 消耗研究中的表现

在 2026 年 5 月发表的 agentic coding token 消耗研究中，Qwen3-Coder-480B 作为开源模型代表参与测试，与闭源 API 模型（GPT 系列、Claude 系列、Gemini 系列）和另一开源模型 [[kimi-k2]] 共同构成 8 模型评测矩阵。该研究覆盖了五家不同公司的模型，同时包含闭源和开源，为 [[agentic-coding-token消耗分析]] 提供了全面的跨模型对比数据。
