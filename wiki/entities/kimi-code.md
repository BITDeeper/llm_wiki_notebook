# Kimi Code

**Kimi Code** 是推测由月之暗面推出的 AI 编程或代码助手产品（类似于 [[claude-code]]）。

## 特点与应用
-   **运行环境**：支持安装和运行 [[nuwa-skill]] 等基于 AI 的技能包。
-   **资源消耗**：在运行复杂的蒸馏任务（如蒸馏 [[lu-xun]]）时，可能会因极高的 Token 消耗而导致用户额度耗尽。

## 背景
该产品体现了国内 AI 厂商在 Agent 和编程辅助领域的布局，与 Anthropic 的 Claude Code 形成竞争关系。
