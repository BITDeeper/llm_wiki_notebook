# 智谱AI

[[智谱AI]]（北京智谱华章科技有限公司，Zhipu AI）是中国领先的人工智能公司，也是国产大模型“四小龙”之一。该公司专注于开发新一代认知智能大模型，是 [[GLM]]（General Language Model）系列模型的开发者，致力于通过开源生态推动 AI 技术的普及与工程化落地。

## 核心产品与模型

智谱 AI 构建了围绕 GLM 系列模型的完整技术生态：

- **GLM 系列**：包括新一代开源模型 [[GLM-5]] 及多模态变体 [[glm-5v-turbo]]。
    - [[GLM-5]]：最新旗舰模型，引入了 DSA 稀疏注意力和异步强化学习（RL）基础设施。凭借其在 [[Agentic Engineering]] 领域的突破性表现（如强大的长任务处理能力），GLM-5 被视为缩小国产模型与顶尖闭源模型（如 Anthropic Claude）差距的重要里程碑，并曾助力智谱股价在发布后暴涨 32%。
    - [[glm-5v-turbo]]：在视觉编程领域取得突破，支持“一张草图搞定前端”，被视为 [[claude-code]] 等国际顶尖编程工具的有力竞争者。
- **ChatGLM**：针对对话场景优化的模型系列。
- **[[Z Code]]**：新一代 AI 编程工具，支持多 Agent 协作与远程控制。
- **AutoClaw（澳龙）**：智谱推出的电脑端 Agent 应用，旨在简化 [[OpenClaw]] 的部署流程。该平台集成了多种 Skill（如“股票分析师”），旨在实现复杂任务的自动化执行。
- **Pony-Alpha-2**：专为 OpenClaw 场景设计的模型，强调多步任务处理的稳定性。
- **AutoGLM-Browser-Agent**：自研的浏览器自动化工具，支持多步骤、跨页面操作。

## 技术方向与贡献

智谱AI 的技术路径强调以下核心领域：

- **智能体工程**：推动 AI 从“对话”向“行动”范式转移。通过强化学习和合成数据解决智能体数据稀缺问题，提升模型在 GUI 操控和工具调用上的表现。
- **训练基础设施**：开发了异步强化学习基础设施，解决了传统 PPO 算法 GPU 利用率低的问题。
- **多模态融合**：从预训练阶段即整合文本与视觉信息，而非简单的模块拼接。
- **工程化落地**：提供 API 接口和平台服务，降低大模型应用门槛。

## 战略与市场

- **开源与平权**：通过提供高性能的开源模型（如 GLM-5），挑战闭源巨头的壁垒。
- **国产算力适配**：积极推动 AI 软硬件国产化，GLM-5 完成了对华为昇腾、摩尔线程等 7 家国产芯片的全栈适配与底层算子级深度优化，确保供应链安全与自主可控。
- **商业化探索**：在维持开源优势的同时，通过 Max 用户套餐和调整 Token 价格（如 GLM-5 发布后的涨价）来平衡高昂的推理成本。其产品策略注重性价比和实际工程落地能力。
- **生态布局**：智谱正积极布局 Agent 生态，通过推出 [[autoclaw]] 等产品，试图将 AI 智能体技术从极客圈推向大众市场。
