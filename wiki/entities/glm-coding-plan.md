# GLM Coding Plan

**GLM Coding Plan** 是[[智谱]]面向开发者的订阅服务，于2026年6月13日随[[glm-5-2|GLM-5.2]]发布全量开放。该服务包含四个层级：

- **Lite**：基础版
- **Pro**：专业版
- **Max**：最高权限版
- **团队版**：团队协作版

全量开放意味着所有层级的用户在发布当晚即可使用GLM-5.2的最高权限。这与[[ai-subscription-crisis|AI订阅制危机]]和[[token末日|Token末日]]背景下其他AI平台收紧使用限额或转向按量计费的趋势形成对比。
