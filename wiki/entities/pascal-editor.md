# Pascal Editor

Pascal Editor 是一个基于浏览器的开源 3D 建筑编辑器，由 [[claude]] 生成代码编写而成。该项目上线 GitHub 数天内便获得了 5.4k Stars，被视为 AI 生成软件挑战传统专业 SaaS 的典型案例。

## 核心特性

### 技术架构
- **WebGPU 渲染**：采用目前浏览器中最先进的图形 API，能够直接调用高性能显卡，使得复杂 3D 场景在浏览器中也能流畅运行，体验接近原生软件。
- **纯 Web 应用**：无需安装客户端，打开浏览器即可使用，极大地降低了使用门槛。

### 编辑功能
- **专业工具集成**：整合了选择、墙体、区域、视角、装置等常用设计工具。
- **参数化调整**：支持通过拖拽数值条实时改变建筑部件的长宽高，无需手动输入数值。
- **视图控制**：支持俯视、左右视角 360 度切换，以及堆叠、爆炸视图等视觉效果。
- **2D/3D 联动**：在 v0.3.0 版本中加入了 2D 编辑功能，实现了平面图与 3D 视图的无缝同步。

## 行业影响

### 挑战传统软件
Pascal Editor 的出现对 AutoCAD、Revit 等动辄数万年费的传统建筑软件构成了潜在威胁。虽然在专业深度上尚不及顶级软件，但其“免费、开源、零安装”的特性足以满足大量中低端及非专业用户的需求。

### 设计平民化
它体现了 [[democratization-of-design]]（设计平民化）的趋势，使得室内设计师、房产中介甚至个人用户都能轻松进行 3D 空间规划。

## 局限性
尽管功能丰富，但在处理极度复杂的建筑项目或特定行业标准方面，与 Revit 等成熟商业软件相比仍显稚嫩。
