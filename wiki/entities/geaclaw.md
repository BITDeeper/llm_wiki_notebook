# GEAClaw

**GEAClaw** 是 [[Generative Enterprise Agent (GEA)]] 架构中 **Execution Layer（执行层）** 的核心子系统，由 [[特赞]] 开发。

## 功能
GEAClaw 负责具体的业务执行阶段，主要任务包括：
- 跨系统调用能力资源
- 根据环境变化动态调整执行策略
- 通过 Proactive Agent 体系调度模型能力、Agent Skills 与企业内部系统接口

## 特点
与一次性响应的 Copilot 型工具不同，GEAClaw 旨在使任务能够持续推进，让智能体持续参与企业工作流运行。它是实现“围绕业务目标持续运行”的关键执行引擎。
