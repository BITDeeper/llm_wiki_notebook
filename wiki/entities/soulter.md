# Soulter

Soulter（B 站 ID：SoulterL）是一位中国“00后”全栈独立开发者、B站 UP 主，开源项目 [[astrbot]] 的创始人。目前就读于北京邮电大学。

## 个人背景
- **教育**：北京邮电大学（BUPT）学生。
- **技术经历**：初中开始接触编程，初期因缺乏电脑而在手机上进行安卓开发。曾开发过即时通讯工具、记账应用、校园自动化项目等。
- **兴趣**：动漫、吉他、天文爱好者。

## 主要成就
- **AstrBot**：于 2023 年 1 月发起的开源 Agent 编排平台，在 GitHub 上获得 2.6 万 Star。
- **开源赞助**：曾收到 OpenAI 的开源项目赞助。

## 角色定位
Soulter 是典型的 [[混合型创作者]]。他兼具深厚的技术能力（全栈开发、架构设计）和内容创作能力（视频制作、社区运营）。他利用 [[bilibili]] 平台不仅进行内容分发，更构建了一个活跃的技术反馈回路，将观众转化为项目的共同参与者和贡献者。

## 观点与见解
- **关于技术传播**：他认为 [[openclaw]] 的成功在于其完整的产品叙事和大众吸引力，而 [[astrbot]] 则更侧重于底层能力和开发者体验。他承认“把东西做出来不等于把它讲明白”是技术圈的常见遗憾。
- **关于社区**：他高度评价 B 站的社区氛围，认为这里不仅有高密度的知识分享，还有少见的“松弛感”，适合 AI 时代的混合型技术讨论。
