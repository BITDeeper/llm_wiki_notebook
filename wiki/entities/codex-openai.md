# Codex（OpenAI）

[[openai|OpenAI]] 推出的**基于云端的软件工程智能体**，是 [[claude-code|Claude Code]] 的直接竞争对手。[[Codex]] 目前正演变为一个集成了代码生成、UI 设计和浏览器功能的综合性开发环境，被视为 OpenAI 构建"超级 APP"战略的核心雏形。

## 核心能力

[[Codex]] 能够接收自然语言任务指令，在后台并行处理多项编程任务，每条任务对应一个代码改动或 PR。具体能力包括：

- **读取和编辑文件**
- **运行测试框架、代码检查工具和类型校验器**
- **提交代码改动并开启 GitHub 拉取请求**供审查
- **与维护者在 PR 评论线程中沟通**
- **自然语言代码生成**：用户通过自然语言指令直接生成代码，实现"言出法随"的 Vibe-coding 体验
- **内置浏览器预览**：OpenAI 将浏览器内置其中，用户无需单独开启窗口即可预览和调试代码

### 异步并行与沙箱执行

- **异步并行**：可同时处理多个任务，每条任务独立运行
- **沙箱执行**：在隔离环境中运行代码，不直接影响用户系统

### 多模态垂直整合

[[Codex]] 的最新重大变化是接入了 [[gpt-image-2]] 的前身技术（文中称为 GPT-image-1.5）。这一整合实现了**设计与代码的闭环**：

1. **UI 生成**：用户可以直接在 [[Codex]] 中生成高质量的 UI 素材，解决了以往 GPT UI 设计能力差（如生成丑陋的黄色滤镜卡片）的问题。
2. **逻辑适配**：生成的图像素材会自动适配交互逻辑，无需用户手动导出参考图或编写繁琐的布局代码。

这种模式被类比为 **"Google Stitch + Claude Code"**，即在一个工具中完成从视觉设计到逻辑实现的全过程。

## 产品定位与架构

- **底层模型**：[[gpt-5-5]]
- **集成平台**：已接入 [[github-agent-hq|Agent HQ]]，可在 GitHub 原生工作流中运行
- **订阅配额**：基于 ChatGPT Pro、Team、Enterprise 等订阅计划的任务额度运行

## 关键约束

- **默认关闭互联网访问**：智能体执行阶段阻断网络，仅安装脚本阶段有网络权限；用户可按需手动开启，但面临提示词注入、代码外泄等风险
- **需人工审查**：OpenAI 官方明确要求用户手动审查和验证所有智能体生成的代码

## 安全功能

OpenAI 推出了 Codex Security 功能，专门面向工程和安全团队，可逐次扫描 GitHub 仓库，在隔离环境中验证高可信度安全漏洞。

## 竞争格局

### 对标 Claude Code

[[Codex]] 与 [[anthropic|Anthropic]] 的 [[claude-code]] 形成直接竞争。虽然 [[claude-code]] 在纯编程领域具有优势，但 [[Codex]] 通过整合图像生成能力，试图在前端开发和 UI 设计领域建立差异化优势。其核心差异化在于异步并行处理和沙箱隔离执行。

### 竞争优势（相对于 Claude Code 新政）

在 [[anthropic|Anthropic]] 宣布 Agent SDK 额度分离政策同一周，OpenAI 迅速推出 Codex 企业免费迁移方案，精准抓住竞争对手制造的痛点：

- **不区分调用方式**：订阅用户无论是交互式还是程序化调用，统一计费，无额度分离
- **零座位费**：降低企业采用门槛
- **按 Token 计费**：透明的按量付费模式
- **内置一键迁移工具**：可直接搬运 Claude Code 的系统提示词、Skills、MCP 配置
- **两个月免费期**：30天内申请，足够企业将自动化流水线跑起来形成使用习惯

### 战略定位

OpenAI 似乎放弃了在"创造力"路线上的竞争，转而将"模仿"能力发挥到极致。[[Codex]] 能够精确复刻现有的设计风格（如 Windows、LinkedIn），这种策略虽然实用，但也引发了关于 AI 仅仅是模仿者还是创造者的讨论。

Codex 的迁移策略被分析为 [[asi竞赛|ASI竞赛]] 决赛圈的第一场定价战。两个月免费期结束后，企业迁移成本已高到不愿意再搬回去，形成用户锁定效应。

## 对工作流的影响

[[Codex]] 的多模态整合能力预示着前端开发工作流的变革：

- **降低门槛**：设计师或产品经理可以直接通过自然语言生成可交互的原型，无需依赖专业前端开发人员。
- **效率提升**：消除了设计工具与代码环境之间的割裂，减少了资产导出和手动转换的步骤。
