# 网易有道

**网易有道**（NetEase Youdao）是中国一家领先的 AI 科技企业，正从传统的教育/工具提供商转型为以 [[ai 原生矩阵]] 为核心的 Agent 公司。

## 战略转型
有道正在经历一场深度的“脱胎换骨”，其内核已从单一的工具集演变为以 Agent 为灵魂的执行层。这一转型由 CEO [[周枫]] 推动，核心逻辑是拥抱“行动的 AI”。

## AI 原生矩阵
有道构建了覆盖知识工作者全天候场景的 Agent 产品矩阵：
- **[[LobsterAI]]**：桌面级 Agent，负责操作系统级的执行流，定位为“数字员工”。
- **[[有道同传]]**：会议 Agent，不仅能实时翻译，还能提炼观点、生成思维导图和待办事项。
- **[[有道宝库]]**：知识库 Agent，对标 NotebookLM，擅长处理异构文档并生成深度内容（PPT、长图、播客）。

## 商业模式
有道采用“高频 Agent 矩阵 + 垂直闭环交付”的路径，深耕 [[场景切片]]。
- **订阅收入**：2025 年 AI 订阅销售额近 4 亿元，证明了用户愿意为能“交付结果”的 Agent 付费。
- **业务赋能**：在广告营销等业务线，利用 Agent 实现策略自动化探索与经验迁移。

## 技术积淀
从 2023 年国内首个教育大模型“子曰”问世，到翻译大模型和端侧算力的优化，有道的技术积累为其 Agent 矩阵爆发提供了基础。
