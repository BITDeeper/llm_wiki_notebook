# Chrome Skills

**Chrome Skills** 是 Google Chrome 浏览器内置的一项 AI 功能，旨在将浏览器转变为免费的智能体平台。它允许用户将提示词固化为可重复调用的“技能”，从而实现任务自动化。

## 核心功能

### 技能复用
用户可以将复杂的 Prompt（如“分析这篇文章的营养价值并生成表格”）保存为技能。在后续浏览中，只需在 Gemini 侧边栏输入斜杠（`/`）或点击加号按钮，即可一键调用该技能。

### 多标签页上下文读取
这是 Chrome Skills 区别于普通聊天机器人的关键特性。AI 可以同时读取多个浏览器标签页的内容。例如，打开两个电商产品页面，运行一个技能即可生成并排对比表。

### 预置与同步
- **预置库**：Google 提供了包含 50 多个技能的官方库，覆盖食谱分析、视频总结等常见场景。
- **跨设备同步**：技能通过 Google 账号云端同步，确保用户在不同设备上的一致体验。

### 安全机制
对于涉及日历写入、邮件发送等具有实际后果的操作，系统会强制弹出确认框，请求用户授权后再执行。

## 行业意义

Chrome Skills 的推出被视为 [[浏览器-agent化]] 趋势的重要里程碑。它将 AI 能力直接集成到互联网流量最大的入口中，极大地降低了用户使用 AI Agent 的门槛。与 [[claude-code]] 等专业编程 Agent 不同，Chrome Skills 面向通用用户场景，强调“一键调用”和“无缝集成”。

## 竞品对比
- **Opera Cards**：Opera 浏览器 Neon 版提供的类似功能，同样支持保存和复用 Prompt。
- **Microsoft Edge Copilot**：微软在 Edge 浏览器中深度集成的 AI 助手，被指有过度 Agent 化的倾向。
