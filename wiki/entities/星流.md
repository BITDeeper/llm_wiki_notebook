# 星流

星流是 [[liblibai]] 早期在设计领域推出的垂直 Agent 产品。

## 技术意义
虽然星流主要针对设计领域，但它在 Agent 交互方式、能力编排和用户协作逻辑上进行了大量的技术验证与实践。它是 [[libtv]] 能够实现“人+Agent 双入口”和复杂技能编排的前置技术探索。
