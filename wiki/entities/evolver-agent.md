# EvolveR

EvolveR 是由上海人工智能实验室 [[knowledgexlab|KnowledgeXLab]] 团队开发的 Agent 经验自蒸馏框架，论文被 ICML 2026 接收。其核心目标是让 Agent 从自身的成功与失败轨迹中自动蒸馏出可复用的"认知Skill"，而非依赖人类编写的外部 Skill。

> ⚠️ 注意：EvolveR 与 Wiki 中已有的 [[evolver]]（EvoMap 团队的自进化引擎）是完全不同的项目。EvolveR 来自上海人工智能实验室，关注经验级自进化；Evolver 来自 EvoMap 团队，关注代码级自进化。

## 闭环生命周期

EvolveR 的运行包含四个阶段：

1. **在线交互：** Agent 面对任务，调用外部知识库和内部经验库，生成完整执行轨迹。
2. **离线自蒸馏：** Agent 冻结参数，回看自身成功与失败轨迹，总结出简洁的经验策略。
3. **经验库维护：** 系统对新经验做语义去重、合并、动态评分，保留真正有用的经验，低分经验被剪枝。
4. **策略进化：** 使用 GRPO 强化学习训练模型，让 Agent 学会在合适时机检索和应用经验。

## 核心技术特点

- **[[复合奖励函数]]：** 包含结果奖励、思考步数奖励和搜索多样性奖励，区分"做事"和"会做事"。
- **[[经验库动态维护]]：** 每条经验记录使用次数和成功次数，动态计算分数，低于阈值则剪枝，语义重复则合并。
- **[[认知对齐]]：** Agent 自己蒸馏的经验比外部强教师（GPT-4o-mini）总结的经验更有效。

## 实验结果

- 在 7 个复杂问答基准上，Qwen2.5-3B 和 7B 模型均取得最优平均表现。
- 超越 CoT、RAG、SFT、Rejection Sampling 和 Search-R1 等基线方法。
- 在多跳推理和域外泛化任务上表现尤其稳定。

## 局限性

- 实验仅限于问答基准，尚未在真实工具调用场景（编程、办公、具身操作）中验证。
- "认知对齐"效应在更大模型（70B+）上是否成立尚不明确。
- 经验库在超大规模任务下的计算成本未深入讨论。
