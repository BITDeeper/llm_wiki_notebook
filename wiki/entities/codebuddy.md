# CodeBuddy

CodeBuddy是腾讯推出的面向开发团队的AI编程智能体，是[[workbuddy企业版]]三大核心能力之一。由腾讯云副总裁[[刘毅]]负责。

## 产品形态

提供三种形态，均接入Admin后台统一治理：

| 形态 | 说明 |
|------|------|
| Plugin | 插件形态，嵌入现有开发环境 |
| IDE | 集成开发环境形态 |
| CLI | 命令行形态 |

## 能力覆盖

覆盖编码、任务拆解、代码生成、验证和交付等研发全流程环节。Admin后台统一治理覆盖知识、权限、模型、研发效率和安全五个维度。

## 行业定位

定位为企业级编程智能体，可以进入研发流程而非仅作为辅助工具。与[[codex]]和[[claude-code]]处于同一赛道，但强调企业级治理和与[[workbuddy企业版]]的统一入口整合。
