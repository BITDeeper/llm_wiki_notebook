# Comni

[[Comni]] 是由 [[OpenBMB]] 社区发布的桌面软件，旨在简化 [[MiniCPM-o 4.5]] 的本地部署流程。该软件集成了模型下载、环境安装和 Demo 运行能力，提供 Windows 和 macOS 版本的一键安装包。

## 功能
- 自动下载并配置 [[MiniCPM-o 4.5]] 模型。
- 提供全双工语音对话、实时视觉理解等功能的图形化演示界面。
- 支持本地推理，无需联网即可使用。

## 硬件要求
- **Windows**：12GB+ 显存 GPU（如 RTX 4080/4090/5070）。
- **macOS**：M1-M5 Max/Pro 芯片，建议 16GB 以上内存。
