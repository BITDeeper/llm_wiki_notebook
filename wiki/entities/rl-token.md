# RL Token

[[RL Token]] 是 [[智平方]] 提出的一种将强化学习（RL）与视觉-语言-动作（VLA）模型结合的优化方案。它旨在解决 VLA 模型在结合强化学习微调时面临的算力门槛高和 [[灾难性遗忘]] 两大难题。

## 核心机制

### 1. 信息瓶颈编码与参数冻结
*   在 RL 微调阶段，庞大的 VLA 主体参数被完全冻结。
*   引入信息瓶颈编码器，仅对极少量参数进行训练。
*   **效果**：守住了模型原有的通用能力底线，避免了在学习新任务时忘记旧知识。

### 2. 极低的算力需求
*   通过架构优化，系统所需训练的参数量从原本的 3.9B 骤降至约 137M（仅占总参数的 3.5%）。
*   在实际梯度更新环节，仅涉及 1.3M 参数。
*   **硬件门槛**：开发者仅需单张消费级 RTX 4090 显卡即可完成 VLA 的强化学习后训练（Post-training）。

### 3. 稳定进化
*   允许模型在不破坏原有能力的前提下，对特定任务进行低成本优化。
*   实现了类似人类的经验积累模式，而非每次遇到新场景都推翻重来。

## 应用价值
RL Token 使得每个行业和场景都能低成本定制专属的“能干活的 AI”，极大地降低了 VLA 模型落地的技术门槛和资金成本。
