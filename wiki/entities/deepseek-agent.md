# DeepSeek Agent 战略

DeepSeek Agent 战略是指 DeepSeek 公司在 2026 年初全面启动的、旨在从基础模型研究转向 Agent 产品化落地的一系列技术布局与人才招聘计划。

## 战略背景
在 [[DeepSeek V4]] 和 R-1 推理模型取得成功后，DeepSeek 开始将目光投向更具应用前景的 Agent 领域。2026 年 3 月，DeepSeek 一次性开放了 17 个 Agent 相关岗位，覆盖算法、数据、评测、基建和产品全链条，标志着其战略重心的实质性转移。

## 核心布局

### 1. 全栈能力建设
DeepSeek 试图构建从底层基础设施到上层应用的全栈能力：
- **算法层**：探索 RLHF/RLAIF、过程奖励、偏好学习等对齐技术，提升 Agent 的规划与工具调用能力。
- **数据层**：构建“数据-训练-评测”闭环，自建评测数据集，精准区分模型能力边界。
- **基建层**：搭建支撑海量 Agent 运行的容器调度平台，集成 [[mcp-协议]] 等标准接口。

### 2. 人才标准革新
DeepSeek 在招聘中提出了极具时代特征的人才要求，特别是对 [[vibe-coding]] 的强调。这表明 DeepSeek 的 Agent 团队将是一支“AI 原生”队伍，极度依赖 AI 编程工具（如 [[claude-code]]）进行开发。

### 3. 竞品对标
岗位描述中频繁提及 Claude Code、[[openclaw]]、Manus 等竞品，显示出 DeepSeek 在 Agent 产品形态和应用场景（如个人助理、Deep Research）上对标国际顶尖水平的决心。

## 预期目标
据行业传闻，DeepSeek 计划在 2025 年第四季度发布具备高级 Agent 功能的模型，目标是能够在最小用户指引下执行多步任务，并基于历史行动自主学习进化。DeepSeek 旨在复现 R-1 时代的“低成本奇迹”，用高性价比方案颠覆 Agent 赛道。
