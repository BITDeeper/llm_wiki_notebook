# 阿岛

[[阿岛]] 是 [[MiniMax]] 的 Agent 首席架构师。

## 核心观点
在探讨企业 Agent 落地困境时，[[阿岛]] 提出了著名的“F1 赛车与乡镇公路”比喻，强调 [[Agent Native]] 思维的重要性。他认为，试图在不改变原有工作流的前提下强行嵌入 Agent，就像在乡镇公路上开 F1 赛车，无法发挥其效能。

## 主要贡献
- 推动了 [[Agentic RL]] 在 [[MiniMax]] 的大规模应用。
- 与 [[腾讯云]] 深度合作，通过底层基础设施重构解决了海量沙盒并发难题。
- 预测未来 Token 成本将呈指数级下降，全模态 Agent 将在便携设备中实时互动。
