# ATLAS

ATLAS（Autoformalized Textbook Library At Scale）是 [[meta]] 联合 [[纽约大学]] 发布的迄今最大规模自动化数学形式化代码库，基于 Lean 4 构建。

## 核心数据

| 指标 | 数值 |
|------|------|
| 覆盖教科书 | 26 本 |
| 总代码行数 | 630,999 行 |
| Lean 核心代码 | 483,917 行 |
| 数学声明 | 46,203 条 |
| 已完成证明 | 42,837 条（通过率 92.7%） |
| 教科书定理形式化覆盖率 | 71.3%（4,007 条中 2,855 条） |
| Token 消耗 | 1,831.57 亿 |

## 规模对比

Lean 社区多年协作维护的标准库 Mathlib 约有 210 万行代码、308,129 条声明。ATLAS 在数周内机器生成的体量已达到 Mathlib 总量的约四分之一。

## 覆盖领域

横跨分析学、代数学、几何、拓扑、组合数学、概率、统计、偏微分方程、数论及理论计算机科学。代表性成果包括：

- **实分析**：177 条目标定理中形式化 175 条，覆盖率 98.9%
- **复变函数**：覆盖率 97.4%
- **数论 I**：576 条目标定理中形式化 460 条（79.9%）
- **代数几何 I**：覆盖率 60.2%，仍生成超 4 万行代码
- **李群**：消耗 token 最多（45,384M），覆盖率仅 40%，反映极端技术难度

## 技术架构

ATLAS 完全由 [[autoformbot]] 流水线自动生成，零人工证明工程介入。项目提供可视化浏览器，支持非正式原文与 Lean 形式化版本对比、逻辑依赖关系图浏览、最小代码集提取等功能。

## 局限性

团队定位为持续进行中的机器生成扩展努力，而非完成品。约 28.7% 目标定理尚未形式化，代码风格与 Mathlib 标准尚存差距。

## 意义

ATLAS 的发布呼应了 [[陶哲轩]] 提出的数学从"证明匮乏"转向[[证明泛滥]]的历史性判断，是对"数学基础设施"的大规模投资实验。
