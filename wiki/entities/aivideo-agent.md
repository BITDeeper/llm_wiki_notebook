# AIVideo Agent

AIVideo Agent 是由 [[AIVideo.com]] 开发的全自动视频制作智能体，被社区昵称为“Open Claw”（龙虾）。它旨在通过 AI 技术实现视频创作流程的完全自动化，使用户能够像管理“数字员工”一样管理视频生产。

## 核心特性

### 全流程自动化
AIVideo Agent 能够自主完成视频制作的全生命周期，包括但不限于：
- 选题策划与脚本撰写
- 素材搜索与生成（支持文字/图片转视频）
- 智能剪辑（粗剪、精剪、特效、转场）
- 配音与字幕生成
- 自动发布至邮箱、YouTube、Instagram、X 等平台

### 生态深度集成
该智能体与主流生产力工具深度打通，支持构建复杂的自动化工作流：
- **Google Drive/Docs**：读取和存储素材与文档。
- **Notion**：读取任务列表，确定项目优先级。
- **Discord**：上传编辑链接或发布成品。
- **Gmail**：发送任务完成通知。
- **Web Search**：获取实时新闻或资讯。

### 白盒化交互
与许多“黑盒”视频生成工具不同，AIVideo Agent 提供了类似传统剪辑软件的时间轴界面。
- **思考过程可视化**：界面右侧会实时显示 AI 的决策过程，例如如何进行音乐节拍分析、如何选择卡点位置。
- **人工可干预**：用户可以在时间轴上直接进行分割、吸附、打点等操作，修正 AI 的输出结果。

## 使用模式
用户无需具备编程技能或配置 API Key，仅需使用自然语言描述需求（例如：“制作一个关于马斯克在火星跳舞的电子音乐 MV”），Agent 即可自动调用相应工具完成任务。

## 定价与可用性
- **状态**：测试阶段。
- **费用**：约 74 美元/月。
- **额度**：约 1100 个视频片段和 22000 张图片。

## 行业定位
官方强调其垂直定位：“我们不是通用型的，我们只做视频”。这表明其策略在于深耕视频制作领域的专业逻辑（如分镜、空镜、B Copy 等），而非追求通用大模型的广泛能力。
