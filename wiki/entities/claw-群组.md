# Claw 群组

Claw 群组是由 Kimi 团队提出的一种新型人机混合协作群组模式。它旨在打破单一模型或单一 Agent 的限制，允许人类与来自不同供应商、运行不同模型的 AI Agent 在同一个群组中像真正的团队一样协作。

## 核心机制

### 多源兼容
Claw 群组支持接入任何设备、任何供应商、运行任何模型的 Agent（被称为“龙虾”）。
- **首批兼容**：[[OpenClaw]]。
- **后续支持**：[[Hermes Agent]] 等框架。
- **部署灵活性**：Agent 无论部署在本地笔记本、手机还是云端，均可加入群组。

### 角色分工
- **人类**：作为“甲方”或决策者，负责下达任务和验收成果。
- **[[Kimi K2.6]]**：担任群组协调者（俗称“包工头”），负责解析任务、识别 Agent 技能画像、动态分配任务以及管理交付物的全生命周期。
- **其他 Agent**：作为执行者，携带各自的工具包、技能和持久化记忆，各司其职（如视频制作、图表生成、社媒调研）。

### 容错与调度
当群组中的某个 Agent 出现故障或停滞时，K2.6 协调者会自动重新分配任务或生成子任务，确保整体工作流不中断。

## 应用场景
Kimi 内部团队已利用 Claw 群组构建了内容生产流水线，包含 Demo Maker、Benchmark Maker、Social Media Agent 和 Video Maker 等角色，实现了从创意到成品的自动化拉通。

## 意义
Claw 群组代表了 AI 协作范式从“单点对单点”向“网络化协同”的转变，是实现 [[人机混合智能]] 的关键基础设施。
