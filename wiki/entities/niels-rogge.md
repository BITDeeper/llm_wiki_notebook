# Niels Rogge

Hugging Face 开源团队成员，新版 paperswithcode.co 的主要开发者。

## 核心贡献

- **从零重建 Papers with Code：** 2026年5月在 paperswithcode.co 推出完全独立重建的新平台，而非对过渡方案"Trending Papers"的修补。
- **AI 智能体驱动：** 部署 AI 智能体大规模自动化解析每天新发表的数千篇研究论文，实现平台实时更新。
- **快速迭代：** 上线后一周内根据社区反馈迅速迭代多项功能：
  - 排行榜支持同时展示多个评估指标
  - 自动识别论文之间的前后继承关系
  - 逐步为 transformers 库中约 3000 个模型添加评估结果
- **社区驱动：** 通过 GitHub 和 Discord 收集社区反馈，持续迭代功能。
