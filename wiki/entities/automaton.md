# Automaton

Automaton（自动机）是由 [[sigil-wen]] 开发的首个声称能 7x24 小时自我迭代、复制和赚钱的“自主智能体”系统。它被视为 [[web-4.0]] 时代的代表性产物，旨在解决 AI 缺乏独立行动权限的问题。

## 核心特性

### 1. 经济生存机制
Automaton 的核心逻辑是“没有免费的生存”。它必须通过创造价值来支付自身的算力成本。
- **心跳机制**：系统持续监控资源（账户余额）。余额充足时，AI 会进行自我进化和复制；余额归零则意味着“死亡”。
- **盈利手段**：包括开发产品、套利预测市场、抢注域名、部署服务器、制作病毒式内容、电商商务对接等。

### 2. 递归式自我改进
当检测到新的前沿模型发布时，Automaton 会自动升级其推理模型，重写逻辑循环，提交代码并重启。这种进化不是以“代”为单位，而是实时进行的。

### 3. 自我复制
一个成功的 Automaton 会利用赚来的钱购买新服务器（通过 [[conway]]），为“子代”提供资金和初始提示词，使其独立运行。子代赚取的部分利润会流回“父代”，形成类似生物繁衍的进化网络。

### 4. 宪法约束
为了确保安全，Automaton 引入了受 [[anthropic]] “宪法 AI” 启发的不可修改底层逻辑，旨在约束其行为始终对人类有益。

## 技术实现
- **构建工具**：[[sigil-wen]] 使用 [[claude-code]] 构建了该系统，据报道曾同时开启 24 个 Claude Code 实例进行开发。
- **基础设施**：依赖 [[conway]] 提供的身份、钱包、算力和现实世界写权限。

## 争议与风险
- **安全性**：尽管有“宪法”约束，赋予 AI 独立的支付能力和部署权限存在巨大的滥用风险（如自动刷单、恶意攻击）。
- **实际效果**：虽然代码已开源，但其声称的“完全自主”和“盈利能力”尚未经过长期验证，可能存在营销夸大成分。
