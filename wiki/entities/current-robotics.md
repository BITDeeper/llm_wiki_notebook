# Current Robotics

Current Robotics 是一家致力于构建具身智能全栈基础设施的公司/组织。其核心主张是：数据不是训练模型的副产品，而是具身智能系统的核心基础设施。

## 核心产品与技术

- **[[curr-0|Curr-0]]**：全身灵巧操作模型，实现单一策略同时控制移动、姿态协调与手部精细操作。
- **[[humanex|HumanEx]]**：自研的全身外骨骼数据采集系统，用于在真实场景中记录人类自然完成任务的全身运动数据。
- **[[human-in-the-world-model|Human-in-the-World-Model]]**：人类直接在多物理模态交互世界中介入并修正机器人策略的闭环框架。

## 全栈路线

Current Robotics 构建了从数据采集到模型部署的完整闭环：
1. **数据采集**：通过 HumanEx 积累真实人类行为数据
2. **模型训练**：Curr-0 端到端训练
3. **评测验证**：多物理模态交互世界模型
4. **后训练与部署**：Human-in-the-World-Model 框架

该路线强调模型能力的提升依赖于人类行为数据的持续积累，而非机器人 Fleet 规模的扩张。
