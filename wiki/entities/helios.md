# Helios (机架系统)

[[Helios]] 是 AMD 发布的新一代 AI 机架系统，以希腊神话中的太阳神命名，象征着 AMD 试图照亮黑暗、打破英伟达垄断的愿景。它是 AMD 开放架构战略的集大成者，直接对标英伟达的 NVL72/NVL144 封闭机架系统。

## 核心特性

### 硬件规格
- **CPU 配置**：集成 4,600 颗 [[Zen 6]] CPU 核心。这一配置不仅提供了强大的通用计算能力，也标志着 AMD 在面对英伟达推行 Arm 架构（Vera CPU）时，对 x86 架构的坚守。
- **内存容量**：配备高达 31TB 的 [[HBM4]] 内存。这种「暴力美学」策略旨在通过海量的显存容量来容纳更大的混合专家模型，从而减少跨卡通信的频率，弥补互联带宽可能存在的劣势。

### 战略意义
- **开放图腾**：与英伟达全栈自研的封闭方尖碑不同，Helios 强调开放标准和兼容性，允许客户保留原有的服务器机箱和基础设施，仅升级计算模组。
- **反锁定策略**：通过模组化设计，降低客户的迁移成本和总拥有成本（TCO），吸引那些寻求供应链多元化的云服务商。

## 对比分析

| 特性 | AMD Helios | 英伟达 NVL72/NVL144 |
| :--- | :--- | :--- |
| **架构理念** | 开放、模组化、x86 兼容 | 封闭、垂直整合、Arm 倾向 |
| **互联标准** | [[UALink]] (开放) | NVLink (私有) |
| **网络** | Ultra Ethernet (以太网) | InfiniBand (私有) |
| **内存策略** | 极致堆料 (31TB HBM4) | 高带宽 + NVLink 显存池化 |

Helios 机架不仅是硬件产品，更是 AMD 联合行业巨头组成的「反英伟达联盟」在物理层面的具体体现。
