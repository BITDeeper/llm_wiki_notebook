# Codex (OpenAI Enterprise)

Codex 是 [[OpenAI]] 旗下的代码生成与 Agent 产品，目前被视为其在企业级市场的杀手锏和核心现金牛。该产品在 [[NVIDIA]] 的成功部署极大地提升了其市场地位。

## 市场表现
- **用户增长**：在 [[NVIDIA]] 全员部署后的两周内，周活跃用户从 300 万增长至 400 万。
- **企业合作**：已有七家全球顶级系统集成商签约落地，包括 Cisco、Ramp、Notion、Rakuten 等。企业用户规模较年初增长了 6 倍。

## NVIDIA 部署案例
[[NVIDIA]] 创始人黄仁勋向全公司 10000 多名员工（涵盖工程师、法务、市场、财务、HR）发布了内部信，强制推广 Codex。
- **部署方式**：为每个员工配备一台云虚拟机，Agent 拥有自己的电脑，出错时可冻结并抓取堆栈。
- **内部反馈**：被称为“炸裂”和“改变人生”。调试周期从“天级”压缩到“小时级”，实验迭代从“周级”压缩到“隔夜”。

## 战略地位
Codex 是 [[OpenAI]] 构建“企业级 AI 操作系统”战略的基石。[[OpenAI]] 计划将 ChatGPT、Codex 和 Atlas 浏览器合并为一个桌面端“超级应用”，不再分散兵力做多个产品，而是通过 Codex 深度整合企业工作流。
