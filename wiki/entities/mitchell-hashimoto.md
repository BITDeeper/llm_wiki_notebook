# Mitchell Hashimoto

Mitchell Hashimoto 是美国著名的软件开发者和开源先驱，以创造多款基础设施工具而闻名。他是 GitHub 第 1299 号用户（注册于 2008 年 2 月），曾是该平台最忠诚的支持者之一，但在 2026 年 4 月因平台频繁宕机宣布将其项目 [[Ghostty]] 迁离 GitHub。

## 主要贡献

### 核心工具创造
Hashimoto 创造了多个在现代 DevOps 和基础设施即代码 领域具有里程碑意义的工具：
- **[[Vagrant]]**：用于构建和配置虚拟化开发环境的工具。
- **[[Terraform]]**：由 HashiCorp 开发的基础设施即代码 工具，用于安全高效地构建、更改和版本控制基础设施。
- **[[Packer]]**：用于自动化创建机器镜像 的工具。
- **[[Ghostty]]**：一款高性能、跨平台的终端模拟器，使用 Zig 和 Swift 编写，发布一年内即在 GitHub 上获得超过 5 万颗星。

## 与 GitHub 的关系

### 早期经历
Hashimoto 与 GitHub 的关系极其深厚。他曾表示，开发 Vagrant 的初衷之一是希望能获得 GitHub 的工作。在过去的 18 年里，GitHub 承载了他几乎所有的开源活动、工作热情甚至个人情感（如在分手后通过开源社区疗伤，蜜月期间提交代码）。

### 决裂与出走
2026 年 4 月，Hashimoto 发表了一篇充满情感的告别文章，宣布将 [[Ghostty]] 迁离 GitHub。这一决定的直接原因是 GitHub 持续且频繁的服务宕机，特别是 GitHub Actions 的不稳定。他通过记录日记的方式，证实了过去一个月几乎每天都有宕机发生。

这一事件被视为 [[去github化]] 趋势中的一个标志性时刻，因为 Hashimoto 代表了最核心、最资深的开源开发者群体。

## 技术风格
Hashimoto 的项目通常关注开发者体验和底层系统效率。例如，[[Ghostty]] 强调性能和 GPU 加速渲染，而 [[Terraform]] 则定义了多云管理的标准。
