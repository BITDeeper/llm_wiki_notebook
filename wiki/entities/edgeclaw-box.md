# EdgeClaw Box

EdgeClaw Box 是 [[面壁智能]] 发布的一款软硬一体机，被视为 [[EdgeClaw]] 框架的「产品化身」。它预装了支持「端云两栖」的 EdgeClaw 系统，旨在为 OPC（一人公司）及数据敏感型企业提供开箱即用的 AI Agent 解决方案。

## 产品定位
-   **目标用户**：[[OPC]]（一人公司）、中小企业及对数据安全有极高要求的商业用户。
-   **核心价值**：解决用户在「云端 API 派」（数据裸奔、成本高）与「本地模型派」（能力弱）之间的两难选择，提供既安全又强大的生产力工具。

## 功能特性
-   **开箱即用**：无需复杂的部署和配置，插电即可使用。
-   **端云协同**：内置 [[隐私路由]] 机制，自动判断任务是在本地还是云端执行。
-   **断网运行**：内置 [[MiniCPM]] 系列模型，支持在无网络环境下处理任务（如冷库盘点）。
-   **成本优化**：通过本地模型承担大量基础任务，显著降低云端 Token 消耗。

## 竞争优势
相比于纯软件方案，EdgeClaw Box 通过硬件预集成的形式，降低了用户的使用门槛，并确保了本地算力的稳定性，是面壁智能抢占 Agent 市场的重要硬件载体。
