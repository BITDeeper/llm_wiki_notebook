# N1X

N1X 是英伟达自研的笔记本级超级芯片，被视为"英伟达版 M 系列芯片"。该产品传闻在圈内流传至少大半年，2026年5月28日由英伟达、微软、ARM 三方同日发布暗示帖基本确认。

## 规格

| 参数 | 规格 |
|------|------|
| 合作方 | 联发科 |
| 制程 | 台积电 N3B |
| CPU | 20核 ARM |
| GPU | Blackwell 架构，6144 CUDA 核心 |
| 内存 | 128GB LPDDR5X 统一内存 |
| 系统平台 | Windows on Arm |

## 技术前身

N1X 大概率是 [[dgx-spark|DGX Spark]] 搭载的 GB10 芯片的笔记本版本。GB10 同样是"一块 NVIDIA GPU + 一颗 20核 ARM CPU + 一大坨内存"的超级芯片设计。

## 优势

- **6144 CUDA 核心**：与桌面端 RTX 5070 相当的算力
- **128GB 统一内存**：CPU 和 GPU 共享访问，适合大模型本地推理
- **ARM 架构高能效**：类似苹果 M 系列的能效优势

## 局限

- **带宽瓶颈**：[[统一内存架构]]下 GPU 可用带宽约 273 GB/s，远低于传统独显的 GDDR 显存带宽，不适合高性能游戏
- **x86 兼容性**：ARM 架构需通过 [[x86模拟转译]] 层运行传统 PC 应用，数十年积累的 x86 PC 游戏无法原生运行
- **定价预期**：英伟达品牌溢价可能削弱"AI 民主化"叙事
