# MiniCPM

MiniCPM 是 [[面壁智能]] 自研的一系列端侧大模型。该系列模型以小参数量和高性能著称，被称为「端侧最强基础模型之一」。

## 技术特点
-   **紧凑架构**：相比大型云端模型，MiniCPM 规模更小，适合部署在手机、电脑及专用硬件（如 [[EdgeClaw Box]]）上。
-   **优化训练**：通过架构优化和训练策略调整，在有限的算力下提供具有竞争力的推理能力。

## 在 EdgeClaw 中的角色
在 [[EdgeClaw]] 框架中，MiniCPM 充当「本地引擎」：
1.  **处理绝密任务**：负责 S3 级别数据的本地推理，确保数据物理隔离。
2.  **承担高频琐事**：处理文本清洗、格式转换、信息抽取等不需要复杂推理的任务。
3.  **降低成本**：通过本地化处理，减少对云端 API 的依赖，从而大幅降低运营成本（据称可减少 98% 的云端调用）。

## 应用场景
由于其轻量化和高性能的特性，MiniCPM 特别适合对隐私和延迟敏感的场景，如移动办公、离线工业检测及个人知识库管理。
