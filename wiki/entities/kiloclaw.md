# KiloClaw

**KiloClaw** 是由 [[Kilo AI]] 推出的全托管智能体平台。该平台基于 [[OpenClaw]] 构建，旨在降低用户使用 Agent 的技术门槛。

## 关联产品
KiloClaw 与 [[PinchBench]] 评测基准一同发布，PinchBench 被用于验证和推荐在 KiloClaw 平台上运行效果最佳的大模型。
