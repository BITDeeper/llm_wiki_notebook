# Qwen Code

[[Qwen Code]] 是 Qwen 团队官方推出的 AI 编程助手工具。

作为 [[qwen3-6-27B]] 生态的一部分，它支持直接接入该模型。用户可以通过操作界面内的 `/auth` 命令完成账号授权登录来使用该服务。它与 [[openclaw]] 和 [[claude-code]] 一样，是支持 Qwen3.6-27B 的热门第三方编程助手之一。
