# CC-Bench-V2

CC-Bench-V2 是由 [[智谱AI]] 推出的一个完全自动化的评测基准，旨在模拟真实的软件开发环境，以评估大模型在复杂工程任务中的表现。

## 设计动机
传统的 SWE-bench 评测集存在“记忆效应”问题，因为它是静态、公开且发布超过 2 年的数据集。模型可能仅凭记忆而非真实推理能力得分。CC-Bench-V2 旨在解决这一问题，提供更贴近真实开发场景的测试。

## 评测维度

### 1. 前端评估
- **Agent-as-a-Judge**：引入 GUI Agent 模拟用户交互，验证生成项目的功能正确性。
- **结果**：[[GLM-5]] 的构建成功率（BSR）达到 98.0%。

### 2. 后端评估
- **环境**：基于真实开源项目。
- **指标**：Pass@1。
- **结果**：GLM-5 得分 25.8%，与 Claude Opus 4.5 相当。

### 3. 长程任务评估
- **方法**：通过挖掘已合并的 Pull Request 构建多步链式任务，评估模型在增量开发中的上下文跟踪与规划能力。
- **现状**：虽然 GLM-5 较前代有显著提升，但与 Claude Opus 4.5 仍有差距。这反映了链式任务中错误累积放大的难题，是行业当前的技术瓶颈。
