# 吾云创新 (Zettlab)

吾云创新（Zettlab）是一家专注于 AI 硬件与数据管理的创业公司，致力于打造 Agent 时代的个人计算设备。公司由 [[郭亚楠]] 创立，主张“Context 是新的操作系统”，旨在通过软硬结合的方式解决个人数据的存储、检索与 Agent 运行问题。

## 核心产品

### Zettlab AI NAS
公司的初代产品形态，定位为 AI NAS（网络附属存储）。
- **功能**：不仅解决存储问题，还强调数据的高效使用与多模态检索。
- **市场表现**：在海外众筹平台 Kickstarter 上获得了超过 140 万美金的支持，证明了市场对 AI 辅助数据管理的需求。
- **技术积累**：为后续 [[agent-computer]] 的研发奠定了核心技术栈（如多模态数据处理）基础。

### Agent Computer
公司目前的旗舰研发方向，定义为“三无”个人计算设备（无键盘、无鼠标、无屏幕）。
- **定位**：融合了个人计算终端（PC）、家庭数据中枢（NAS）、海量存储基座和 Agent 运行环境。
- **目标**：提供比 [[mac-mini]] + NAS 更具性价比的专属 Agent 运行环境，主打零门槛、免配置的使用体验。

## 技术特点
- **多模态检索**：宣称实现了千万级视频的秒级检索，并能精准定位到视频的具体帧。
- **硬件级数据隔离**：在存储层实现数据保护，防止 Agent 误操作导致的数据丢失。

## 团队背景
- **创始人**：[[郭亚楠]]，拥有 [[大疆]] 和 [[云鲸]] 等明星硬件公司的工作经历。
- **核心成员**：团队主要成员来自大疆、云鲸、华为、理想等硬件与 AI 领域的知名企业。

## 发展历程
- **2023年**：郭亚楠从 [[云鲸]] 离职创业，确立 AI NAS 为初代产品方向。
- **2025年11月**：随着 AI 技术演进和 Agent 需求显现，将产品方向升级为 Agent Computer。
- **2026年**：Agent Computer 历经 7 个月研发，预计 Q3 正式发售。
