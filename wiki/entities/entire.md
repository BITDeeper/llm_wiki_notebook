# Entire

Entire 是一家由 [[github]] 前 CEO [[thomas-dohmke]] 辞职后创办的下一代开发者平台和初创公司，致力于构建适应 AI 智能体的新一代操作系统和开发基础设施。Dohmke 从 GitHub 挖走 11 名员工加入 Entire，被视为 GitHub 顶级人才流失潮的重要组成部分。

## 核心愿景
Entire 旨在解决现有开发工具（如 Git）无法适应 AI 智能体大规模协作的问题。其目标是实现从"以人类为中心的手工业协作"向"以智能体为中心的工业化生产"的范式转移。

## 融资情况
- **时间**：2026年2月
- **轮次**：种子轮
- **金额**：6000万美元
- **估值**：3亿美元
- **领投方**：Felicis
- **跟投方**：Madrona、M12（微软风投）、Basis Set 等。
- **意义**：被称为"开发工具史上最大种子轮"。

## 核心产品与技术

### 1. Git 兼容数据库
建立一个统一的版本控制系统，不仅存储代码，还存储代码的意图、约束条件和推理过程，形成代码的"数字基因库"。

### 2. 通用语义推理层
利用 [[上下文图谱]] 技术，使不同的 AI 编码助手能够共享工作记忆，避免重复推理和 Token 浪费。

### 3. AI 原生用户界面
重新设计从问题提出到代码部署的整个开发生命周期，优化机器与人的交互体验。

## 主要产品：Entire CLI
Entire 发布的首个开源产品，核心功能是 [[checkpoints]]。
- **功能**：将 AI 编程时的上下文（对话、提示词、推理过程、工具调用）自动捕获并存入 Git。
- **支持工具**：[[claude-code]], [[gemini]]。
- **承诺**：保持平台开放、可扩展且独立，反对被单一巨头锁定。

## 行业影响
Entire 的出现标志着 AI 编程领域正在从单纯的"辅助工具"竞争转向"底层基础设施"的重构。它试图解决 [[代码工业化]] 带来的代码可维护性、安全性和追溯性挑战。
