# WICG

## 概述
[[WICG]] (Web Platform Incubator Community Group) 是 Web 平台孵化器社区组，隶属于 W3C 体系。其职责是孵化新的 Web API 和技术提案，待其成熟后再推动进入正式的 Web 标准。

## 与 HTML-in-Canvas 的关系
[[html-in-canvas]] 目前正处于 WICG 的提案阶段。这意味着该技术已经获得了社区和部分浏览器厂商（如 Google）的关注，未来有机会成为浏览器原生支持的标准功能。
