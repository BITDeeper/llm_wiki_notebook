# TMLR

**TMLR**（*Transactions on Machine Learning Research*）是机器学习领域的重要学术期刊，专注于发表高质量的机器学习研究成果。2026年，关于[[时序点过程]]三大范式演进的重磅综述《Advances in Temporal Point Processes: Bayesian, Neural, and LLM Approaches》在此平台发表。
