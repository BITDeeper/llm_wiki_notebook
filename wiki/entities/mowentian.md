# mowentian

**mowentian**（GitHub ID），真名 Huang Panpan（黄盼盼），是 [[DeepSeek]] 的核心工程师之一，也是 DeepSeekMoE 等重要论文的署名作者。

## 角色与影响
作为 DeepSeek 在 GitHub 上的主要维护者之一，mowentian 的活跃度常被外界视为 DeepSeek 动向的风向标。2026 年春节后，他对 `awesome-deepseek-integration` 仓库进行的大规模 PR 合并（#121 至 #536），虽然属于常规的“节后大扫除”，但因市场对 [[DeepSeek V4]] 的极度期待，这一动作被华尔街误读为新模型发布的信号，进而引发了关于“[[deepseek第二时刻]]”的市场恐慌。

## 相关贡献
- 参与撰写 DeepSeekMoE 论文。
- 维护 DeepSeek 开源生态，整合第三方 API 集成工具。
