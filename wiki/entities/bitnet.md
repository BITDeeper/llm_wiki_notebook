# BitNet

BitNet 是 Microsoft 开发的 [[原生低比特模型]] 项目，其代表性版本 BitNet b1.58 采用 1.58-bit 权重设计，从训练阶段就严格约束权重的数值表征与底层计算方式。

## 核心特征

- **原生 1.58-bit 设计**：非事后压缩，而是训练阶段即内建低位宽约束
- **端到端一致**：模型结构、训练过程和推理执行之间形成一致的低位宽设计
- **配套推理框架**：专门开发了 [[bitnet-cpp]] 推理框架，通过底层针对性代码实现保障 1-bit LLM 在 CPU 和 GPU 上顺畅运行

## 在低比特格局中的定位

BitNet b1.58 与 NVIDIA [[nvfp4]] 分别代表低比特推理的两条路径：BitNet 从模型设计端约束数值表征，NVFP4 从硬件端原生支持低精度计算。两者形成"模型路线"与"硬件路线"的二元格局。
