# Nicholas Joseph (Nick Joseph)

Anthropic 预训练团队负责人，[[andrej-karpathy]] 加入 Anthropic 后的直接汇报对象。

## 背景

- OpenAI 前核心成员
- 现任 Anthropic 预训练团队负责人
- 与 [[dario-amodei]]（前OpenAI研究副总裁）同属从 OpenAI 流向 Anthropic 的核心人才

## 与 Karpathy 的关系

2026年5月，Karpathy 官宣加入 Anthropic 后，将在 Nick Joseph 的指导下工作。这一汇报关系令外界有些意外——作为 OpenAI 联合创始人、前特斯拉AI总监，Karpathy 并非直接向 Anthropic CEO 汇报，暗示其职级可能低于外界预期。

## 行业意义

Nick Joseph 的存在进一步印证了 Anthropic 内部"OpenAI系"人才的系统性聚集现象。从 [[dario-amodei]] 到 Nick Joseph 再到 [[boris-cherny]]，Anthropic 汇聚了大量 OpenAI 前核心成员，形成了被外界称为"复仇者联盟"的人才阵容。
