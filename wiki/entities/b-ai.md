# B.AI

[[孙宇晨]] 于 2026 年 5 月 1 日推出的 AI 中转站产品。

## 核心特性

- 一个 API Key 调用 Claude + GPT + Gemini + 国产大模型全系列
- [[tron]] 链钱包登录，USDT 结算
- 零注册、零信用卡、零 [[kyc]]
- 纯匿名支付，零篡改

## 产品定位

B.AI 的核心卖点不是折扣，而是「无身份」支付。报道分析其本质是为 AI Agent 时代搭建的支付基础设施：

- 直接打通全球南方用户的支付需求（无 Visa 卡、无美区账号）
- 为 AI Agent 的链上自主任务执行和微支付提供结算层
- 依托 TRON 网络 3.76 亿账户、860 亿美元 USDT 流通量的成熟基础设施

## 发布背景

发布同期，孙宇晨正与 [[wlfi-特朗普家族]] 互诉法律纠纷，但双方几乎同时以相同产品形态入场 AI 中转站赛道。
