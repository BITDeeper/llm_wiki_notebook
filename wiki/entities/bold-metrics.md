# Bold Metrics

Bold Metrics 是一家初创公司，其创始人 Morgan Linton 公开宣布团队已完全弃用 [[Claude Code]]，转而使用 [[Codex]] + [[Cursor]] 的组合。这一案例成为 [[开发者大迁徙]] 中的典型代表。

## 迁移原因
- **成本过高**：使用 Claude Code 时，16 人团队每月的 Token 消耗超过 3.2 万美元。
- **性能与效率**：[[GPT-5.5]] 提供了更高的 Token 效率（节省约 40%），且在代码审查和生成任务中表现优异。

## 影响
该案例的公开披露被视为对 [[Anthropic]] 的「深水炸弹」，直观地展示了高昂的 Token 成本如何迫使企业做出技术栈迁移的决定。
