# Project Maven

**Project Maven**（算法战争跨职能团队）是美国国防部的一项标志性计划，旨在将人工智能技术应用于实战场景，以提升军事决策和行动效率。

## 概述
该项目始于 2017 年，最初的目标是利用计算机视觉算法自动分析无人机侦察画面，以减轻人类分析师的认知负担。随着发展，它已演变为整合多源情报、加速杀伤链闭环的核心系统。

## 发展历程
- **2016 年**：时任美国国防部长 [[Ashton Carter]] 提出 [[第三抵消战略]]，强调“决策优势”是 21 世纪战争的关键，为 Project Maven 奠定了战略基础。
- **2017 年**：项目正式启动，[[Palantir]] 成为主要承包商。
- **初期挑战**：最初仅提供单点 AI 能力（如目标识别），但由于指挥流程碎片化，AI 反而成为信息孤岛，增加了认知负担。
- **系统整合**：[[Palantir]] 开发了 [[Maven Smart System]]，将 8-9 个独立系统整合至单一可视化界面，成功将杀伤链从“小时级”压缩至“分钟级”。

## 核心能力
1. **全流程整合**：连接情报、后勤和决策环节，实现从目标发现到打击指令的无缝流转。
2. **多模态交互**：结合聊天式交互（通过 [[AIP]] 平台）与战场地图可视化，支持自然语言指令生成行动方案。
3. **全域部署**：目前已部署至美军所有军种，包括负责特定战区（如伊朗）的中央司令部。

## 关联实体
- **承包商**：[[Palantir]]（负责系统开发与维护）。
- **负责人**：[[Cameron Stanley]]（现任美国国防部首席数字与人工智能官，前 Project Maven 负责人）。
- **技术支持**：集成 [[Anthropic]] ([[Claude]])、OpenAI 等大模型厂商的 API。

## 争议与影响
Project Maven 展示了 AI 在战争中的实际效能，但也引发了关于“自动化杀人”和人类决策权丧失的伦理争议。它是 [[AI军事化]] 趋势中最具代表性的案例。
