# DLLM-Searcher

[[DLLM-Searcher]] 是由 [[中国人民大学]] GSAI IIR & GSAI-ML 团队提出的一种基于 [[扩散大语言模型]]（dLLM）的搜索 Agent 系统。该系统旨在解决传统基于 [[ReAct]] 框架的搜索 Agent 在多跳问答任务中存在的串行等待延迟问题。

## 核心特性
DLLM-Searcher 的核心创新在于利用扩散模型的 [[块内双向注意力]] 机制，实现了 [[并行推理]]。这使得模型可以在等待外部工具（如搜索引擎）返回结果的同时，继续生成下一步的思考内容，从而实现“一心二用”。

## 技术架构
该系统通过两阶段后训练流程将原始的扩散语言模型调教为合格的搜索 Agent：

1.  **Agentic SFT（监督微调）**：
    使用强模型（如 [[豆包]] Seed-1.8）生成的轨迹进行训练。为了解决扩散模型双向注意力导致的“偷看答案”问题，团队设计了 [[Agentic Noising]] 策略，仅对“思考”和“工具调用”部分加噪，防止信息泄露。

2.  **Agentic VRPO（方差缩减的偏好优化）**：
    通过成对数据（正确 vs 错误轨迹）进行偏好学习，进一步拉开正负样本的差距，提升推理鲁棒性。

3.  **P-ReAct（并行推理与行动）**：
    这是一个无需额外训练的推理加速方案。通过预填充边界标记和调整置信度偏置，强制模型优先解码工具调用部分，从而在等待搜索结果期间并行完成思考部分的生成。

## 性能表现
-   **准确率**：在 HotpotQA、2WikiMultiHopQA、Bamboogle、Musique 等数据集上，准确率达到 57.0 (ACC_R)，与自回归基线 [[R1Searcher]] 持平或略有超越。
-   **速度**：通过 [[p-react]] 策略，实现了 14.77% 到 22.08% 的端到端推理加速。
-   **数据效率**：仅使用不到 8000 条训练数据即达到 SOTA 水平，展现了强大的泛化能力。

## 对比优势
与自回归模型（如 Qwen3）不同，DLLM-Searcher 能够在“先输出工具调用再输出思考”的顺序下保持高性能，而自回归模型尝试这种顺序会导致准确率显著下降。这证明了扩散模型架构在并行 Agent 任务中的独特优势。
