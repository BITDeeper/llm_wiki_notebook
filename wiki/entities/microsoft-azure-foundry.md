# Microsoft Azure Foundry

Microsoft Azure Foundry 是微软 Azure 云平台上的企业级 AI 服务（注：通常指 Azure AI Studio 或相关企业级 Foundry 服务）。

## 角色
它是 [[Anthropic]] 实现全云覆盖的关键一环。尽管微软是 [[OpenAI]] 的主要投资者和合作伙伴，但 Azure 平台依然托管了 Claude 模型，体现了 Anthropic [[多云分发策略]] 的渗透力。
