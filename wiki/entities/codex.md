# Codex

[[Codex]] 是 [[OpenAI]] 旗下的核心 AI 编程与生产力工具，也是 [[coding-agent]] 的代表性产品之一。它最初是基于 [[GPT-3]] 的代码生成模型（也是 [[GitHub Copilot]] 的早期技术引擎），后深度集成至 [[GPT-5.5]] 生态系统中，演变为一个具备环境感知能力的 Agentic IDE。

作为 OpenAI [[战略收缩]]后的核心重点方向，公司已砍掉 [[sora]] 和 [[ai-for-science]] 等项目，将资源集中投入到 Codex 的开发中。[[Sam Altman]] 曾表示，Codex 正在经历 [[ChatGPT Moment]]，即从专业工具跨越到大众普及的临界点。

## 产品定位

Codex 被定位为"[[智能体指挥中心|agent-指挥中心]]"（Agent Command Center），核心能力包括：
- 管理多个智能体并行运行
- 处理长达数小时乃至数天的长时任务
- 支持 diff 审查和工作树隔离（worktree isolation）
- 不同智能体可在同一代码库的不同副本上工作而互不干扰
- 支持在云端以大规模并行实例运行，执行代码审查、Issue 管理、安全扫描等自动化开发任务

在产品哲学上，Codex 走的是"瑞士军刀"路线（广度优先、快速出活），这与 [[Claude Code]] 的"手术刀"路线（深度优先、处理复杂任务）形成鲜明对比。

## 核心特征

- **编程能力第一梯队**：Codex 生成 HTML、CSS、JS 的水平在所有 AI 编程 Agent 中处于第一梯队
- **插件生态**：支持一键安装插件扩展能力，如 [[HeyGen]] 视频生成插件
- **自主调试**：能自主检查环境、调试设备、调配素材、解决故障，具备工程化自主性
- **全流程编排**：从纯代码编程工具扩展为多媒体内容生产平台，可通过自然语言完成视频制作全流程
- **大规模并行**：支持在云端同时运行约 100 个实例，覆盖 PR 审查、Issue 去重、安全扫描、性能基准验证等 10 余种自动化用例

## 核心功能

### 编程与开发

- **基础编程能力**：提供代码补全、生成和重构功能，擅长将自然语言翻译成代码。
- **Memories（记忆）**：允许 AI 从对话历史中学习用户偏好和项目背景。
- **[[Chronicle]]（视觉记忆）**：2026 年 4 月推出的重大更新，通过截屏赋予 AI 视觉感知能力，使其能理解屏幕上的上下文（如报错、文档）。
- **自动化与控制**：支持独立鼠标操作、自动排班及任务执行，甚至能通过语音指令编写 SQL。
- **电脑操控**：支持在模拟器中直接运行应用并进行自动化 UI 测试。
- **[[持久化-goal-工作流]]**：v0.128.0 引入，支持跨会话的多步任务规划，被视为引爆 2026 年 5 月增长的关键功能。
- **Composer 2**：内置在 [[Cursor]] 等兼容 IDE 中的功能，能处理绝大多数开发场景。

### 多媒体与视频制作

2026 年 5 月，Codex 接入 [[HeyGen]] 插件，将能力从纯代码编程扩展至多媒体内容生产：

1. **数字人生成**：生成具有自然皮肤纹理、瞳孔细节的数字人形象
2. **口播视频制作**：声画同步的数字人口播，口型匹配度高
3. **字幕与配音**：替换口条后自动重新生成匹配口型
4. **自动剪辑**：支持裁剪、去帧、字幕排版等精细剪辑指令
5. **自动导出**：成品自动下载到本地文件夹

**技术原理**：Codex 调用 HeyGen 时，将视频制作流程转化为 HTML+CSS+JS 代码工作流，使视频具备可编程、可迭代、可精确控制局部细节的特性。用户无需掌握 HTML、React、FFmpeg 等技术，仅需用自然语言描述需求。

## 速度优化历程

Codex 在推理速度上经历了三次重大升级：

1. **2026 年 3 月**（GPT-5.4）：/fast 模式，1.5 倍加速
2. **GPT-5.3-Codex-Spark**：借助 [[Cerebras]] 芯片，推理速度超过 1000 token/秒，是普通模式的 15 倍
3. **2026 年 5 月 15 日（预计）**：ultrafast 模式，在旗舰模型上实现 2-3 倍提速（非阉割版）

ultrafast 模式专为延迟敏感型任务设计，对 Agent 循环、长任务流水线、浏览器自动化等场景体验提升显著。

## 平台与生态

### macOS 桌面版
Codex 最初以 CLI（命令行界面）形式发布，随后迅速演变为完整的 Agentic IDE。桌面版主要面向 ChatGPT Pro 订阅用户（每月 100 美元），仅支持 macOS 平台。其功能设计（特别是 Chronicle）标志着 AI Agent 从单纯的"文本交互"向"环境感知"进化。

### 移动端（iOS / Android）
2026 年 5 月 14 日，Codex 进入 ChatGPT 手机 App，支持[[异步审批]]。移动端并非在手机上运行编码环境，而是作为远程控制面板：
- 查看所有活跃线程、审查智能体输出
- 批准命令执行、切换模型、开启新任务
- 实时推送智能体状态（截图、终端输出、diff、测试结果）
- 底层采用[[安全中继层]]，主机可跨设备被访问但不暴露在公网

### Chrome 扩展
2026 年 5 月初发布，智能体可在真实浏览器会话中工作，进一步扩展了 Codex 的环境感知范围。

### Xcode 集成
在 2026 年发布的 [[Xcode]] 26.3 中，Codex 与 [[Anthropic]] 的 Claude 一起被原生集成到苹果的 IDE 中，作为 IDEIntelligence 框架的两大支柱之一：
- **快速诊断**：当开发者遇到报错时，可以直接将 Log 甩给 Codex，它能迅速定位问题（例如识别空指针错误）。
- **通用代码生成**：处理广泛的编程任务，提供代码补全和片段生成。
- **辅助理解**：帮助开发者理解复杂的代码逻辑或第三方库的用法。

在 Xcode 环境中，相比专注于精细重构和长上下文的 Claude，Codex 更多扮演"通用型选手"的角色，处理日常开发中高频、基础的需求。

### 第三方工具

- **[[codexbar]]**：第三方监控工具，用于追踪 Codex 的使用量和成本。

## 企业能力

- **Remote SSH**：正式 GA，可直连公司受管远程环境。
- **Hooks**：进入 GA，支持敏感信息扫描、命令验证、会话日志。
- **程序化访问 token**：用于 CI 流水线和内部自动化。
- **HIPAA 合规**：本地环境支持。

## 市场表现

Codex 在 2026 年 5 月经历了爆发式增长，成为开发者大迁徙的核心载体，并在关键指标上反超了竞争对手 [[Claude Code]]：

- **周活跃用户**：突破 400 万（年初以来用户量增长两倍）。
- **下载量**：
    - npm 日下载量约为 Claude Code 的 100 倍。
    - 单周下载量达到 9000 万次，是 Claude Code 的 12 倍以上。
- **Token 使用量**：年初以来增长了五倍。
- **用户偏好**：在开发者调研中，65.3% 的用户倾向使用 Codex。
- **行业背书**：微软副总 Omar Shahine 等行业大佬公开称赞其在 Swift iOS 应用开发中的表现。

## 规模化使用案例

[[Peter Steinberger]] 的实践是 Codex 规模化使用的典型案例：
- 长期在云端运行约 100 个 Codex 实例
- 覆盖 PR 审查、Issue 去重、安全扫描、性能基准验证等 10 余种自动化用例
- 部分较乱的 PR 由 [[Anthropic|Claude]] 编写，经人工整理后提交
- 30 天消耗 6030 亿 Token，费用由 OpenAI 全额承担

## 补贴战

2026 年 5 月 14 日，OpenAI 宣布在 30 天内为从其他平台迁移的企业提供 2 个月免费 Codex 使用权（按 Pro 计划 200 美元/月计算，价值 400 美元）。[[Sam Altman|奥特曼]]亲自宣称"Codex 是最强 AI 编程产品"。3 小时内即有 2000 名开发者联系 OpenAI。此举被视为 [[ai编程工具补贴战-202605]] 的标志性事件。

## 核心优势

- **Token 效率**：得益于 [[GPT-5.5]] 的高效 Token 利用率，在同等任务下，Codex 的 Token 消耗仅为 Claude Code 的约 1/4，处理复杂任务时成本显著低于竞争对手。
- **稳定性**：Session 稳定性极高，极少出现因配额计算错误导致的服务中断，且未触发大多数团队的额度限制。
- **价格策略**：坚持保留 $20 的 Plus 套餐，维持了开发者对"平价高性能"的信任；同时打出价格补贴牌与竞争对手争夺开发者日常工作流入口。

## 战略地位与资源整合

为了应对激烈的竞争（特别是来自 [[anthropic]] [[claude-code]] 和 [[google-deepmind]] [[gemini]] 的挑战），OpenAI 进行了内部资源的深度整合：

- **团队合并**：原属于 AI for Science 团队的 [[Prism]] 工具被并入 Codex。
- **人员分流**：原科学计算团队的人员被分流至 Codex 相关项目。
- **收购整合**：通过收购 [[Astral]]，Codex 进一步强化了 Python 开发者工具链的整合能力。

### 工程师视角

OpenAI Codex 工程负责人 Thibault Sottiaux 指出，AI 算力正变得越来越稀缺和值钱。在招聘面试中，候选人越来越关心"能有多少专属推理算力"，这反映了算力预算已成为吸引顶尖工程师的重要筹码。

## 模型迭代与泄露事件

作为 OpenAI 模型更新的前沿阵地，Codex 经常成为测试下一代模型能力的窗口。

### GPT-5.4 泄露
在
