# MiMo Orbit

[[小米]] AI 团队推出的全球开发者扶持计划，旨在通过资源补贴和技术支持，构建基于 MiMo 模型的 Agent 生态。

## 核心内容

### 1. 百万亿 Token 创造者激励计划
-   面向全球个人开发者、团队和企业。
-   免费发放共计 100 万亿 Token 的算力资源。
-   申请需经过评估，按需发放，以确保资源给到有实际需求的用户。

### 2. Agent 框架专项支持
-   面向全球新兴 Agent 框架提供起步阶段支持。
-   **限免接入**：免除接入费用。
-   **技术支持**：提供底层适配技术支持，降低用户体验门槛。

## 目的
在由国际巨头主导的 AI 市场中，通过“真金白银”的补贴和低门槛接入策略，吸引开发者尝试并基于 MiMo 模型构建应用，从而快速扩大生态影响力。
