# Project Atlas

Project Atlas 是 OpenAI 秘密开发的浏览器项目，旨在应对 Google Chrome 的入口垄断威胁。

## 战略背景
Chrome 占据全球 65% 的浏览器市场份额。Google 不仅可以通过调整搜索框算法切断 ChatGPT 的流量，还向 OpenAI 收取每年 15-20 亿美元的“过路费”（默认搜索引擎费用）。

## 项目目标
- **数据自主**：通过将 AI 植入地址栏，将用户数据掌握在自己手中。
- **降低成本**：避免向 Google 支付巨额流量获取费用。
- **防御封锁**：防止竞争对手通过浏览器层面的限制扼杀 OpenAI 的服务。

## 现状
截至 2026 年初，该项目属于 OpenAI 的最高机密之一，是其摆脱平台寄生状态的关键尝试。
