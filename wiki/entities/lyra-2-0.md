# Lyra 2.0

[[Lyra 2.0]] 是 NVIDIA 开发的开源 3D 世界生成系统，能够将单张 2D 图片瞬间转换为可漫游、可交互的 3D 场景。它是 [[Lyra 1.0]] 的继任者，首次解决了长时程 3D 生成中的 [[空间遗忘]] 和 [[时间漂移]] 问题。

## 核心特性
- **单图生成**：仅需一张 2D 图片即可生成完整的 3D 环境。
- **持久世界**：支持自由漫游和回访已探索区域，保持高度一致性。
- **实时渲染**：输出 [[3D高斯泼溅]] 和表面网格，支持实时路径规划。
- **仿真就绪**：生成的 3D 资产可直接导入 [[Isaac Sim]] 用于具身智能训练。

## 技术架构
1. **视频生成底座**：基于 [[Wan 2.1-14B]]（140亿参数扩散 Transformer），将图片和相机轨迹转化为漫游视频。
2. **前馈 3D 重建**：无需优化迭代，直接从视频帧预测 3D 结构。
3. **一致性机制**：
   - **几何路由**：利用 3D 几何检索历史帧以对抗 [[空间遗忘]]。
   - **自增强训练**：通过训练时引入模型自身的退化输出来对抗 [[时间漂移]]。

## 应用场景
- 老照片/历史场景的 3D 复原与漫游。
- 生成式 AI 游戏世界构建。
- 为机器人训练提供大规模合成数据（解决 [[具身智能数据困境]]）。

## 局限性
目前主要侧重于视觉保真度，缺乏对物理因果的深层理解，生成的场景在物理交互层面仍属于“死”环境。
