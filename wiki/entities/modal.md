# Modal

Modal 是一家提供服务器计算和沙盒环境的云基础设施公司。它是 OpenAI [[Agents SDK]] 首批原生支持的七大沙盒厂商之一。

## 合作案例
Modal 技术团队成员透露，金融科技公司 [[Ramp]] 已利用 Modal 和 OpenAI 的技术构建了后台编码 Agent 大军，公司超过 50% 的 PR 由这些 Agent 生成。

## 生态角色
通过 [[Manifest]] 抽象层，Modal 成为了 OpenAI 生态中的关键计算组件。然而，这也引发了关于沙盒供应商可能沦为平台“组件供应商”的生态位担忧。
