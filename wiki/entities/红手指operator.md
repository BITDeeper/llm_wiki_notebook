# 红手指Operator

**红手指Operator** 是百度发布的全球首款手机端 AI Agent 应用。它旨在让用户在移动端通过自然语言指令操控手机完成跨 App 操作（如查资料、订车票、点外卖）。

## 核心技术：云端物理隔离
为了解决用户对高权限 Agent 触碰隐私数据（如微信钱包、相册）的担忧，红手指 Operator 采用了 [[云端物理隔离]] 技术：
- **运行环境**：Agent 实际运行在百度的云端虚拟手机中，而非用户的真实手机。
- **敏感操作**：一旦 Agent 触碰支付密码、隐私结算等敏感红线，系统会瞬间触发“人类接管模式”，将控制权交还给用户。

## 意义
这一方案在保持 Agent 强大操作能力的同时，确立了安全边界，消除了用户对移动端 Agent 的隐私焦虑。
