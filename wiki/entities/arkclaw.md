# ArkClaw

**ArkClaw** 是由 [[火山引擎]] 推出的云端 AI 智能体托管平台，在营销中常被形象化为“龙虾”或“熟虾”。它是开源框架 [[OpenClaw]]（俗称“生虾”）的云端 SaaS 化变体，定位为“云上的 OpenClaw”。ArkClaw 旨在解决本地部署 AI 智能体过程中面临的高门槛、运维成本高、安全风险和场景落地难等问题，代表了 AI 从单纯的聊天机器人向能够执行复杂任务的“数字分身”的进化。

## 核心特性

### 零门槛云端部署
-   **开箱即用**：用户无需购买服务器、配置命令行环境或处理复杂的依赖关系，仅需通过浏览器访问控制台即可启动智能体。
-   **订阅制计费**：采用包月订阅模式（Lite 版本约 9.9 元/月起），避免了传统 Token 计费带来的成本焦虑，同时提供 7x24 小时不间断运行能力。
-   **运维托管**：平台负责底层运维和算力保障，用户无需自备服务器或保持电脑不关机。

### 模型与多模态支持
-   **主力模型**：默认搭载字节系 [[豆包大模型]] / [[Seed 2.0]] 系列大模型（包括 Pro 和 Lite 版本），支持 Auto 模式智能调度。实测中 [[Doubao-Seed-2.0]] 表现稳定，擅长推理规划和长程任务。
-   **多模态能力**：通过方舟平台接入 Seedream（生图）和 Seedance 2.0（视频理解与生成）模型，使智能体具备图像和视频生成能力。
-   **语音能力**：集成语音与播客模型，支持声音克隆和播客制作。
-   **生态兼容**：兼容 DeepSeek、Kimi 2.5、MiniMax 2.5、GLM 等主流大模型，用户可根据任务场景自由切换，无需单独申请 API。

### 深度平台集成与多端打通
ArkClaw 最大的特点是能够跨越不同的应用和硬件平台执行任务，实现真正的多端打通：
-   **办公软件**：与 [[飞书]] 实现深度集成，支持一键扫码授权。智能体可以直接操作用户的文档、多维表格、日历、任务列表，并在群聊中回复消息，将飞书变为 AI 的“记忆”和“执行”中心。
-   **社交媒体**：支持直接在社交媒体（如微博）上发布内容。
-   **硬件控制**：通过 IoT 端口直接操控硬件（如 [[何同学]] 演示的 3D 打印机）。
-   **文件交互**：通过 TOS 网盘挂载对象存储桶，实现本地与云端的双向文件传输。

### ClawHub 技能市场
类似于手机的应用商店，ArkClaw 拥有官方的技能仓库 [[ClawHub]]：
-   **低门槛使用**：用户无需编写代码，仅需通过自然语言对话即可一键安装技能（如 `web-search`, `feishu-docs`），或安装特定的“Skill”（如“财报分析”、“视频剪辑”）赋予 AI 相应的专业能力。
-   **自定义扩展**：支持通过网关上传自定义 `.md` 格式的技能文件。
-   **官方 Hub**：建立官方 Skills Hub 替代野生市场，所有上架技能需经过安全扫描和代码审计。

### 结构化数据搜索
-   内置火山引擎联网搜索 Skill，区别于传统搜索 API（如 Tavily），它直接返回结构化数据（如 JSON、Markdown 表格），大幅降低了智能体解析信息的成本。
-   整合了字节系独家资源（如今日头条、抖音百科），在中文语境和本地生活信息查询上具有优势。

## 安全架构

针对本地部署（如 OpenClaw）中频发的安全漏洞（如 CVE-2026-25253）和恶意技能注入问题，ArkClaw 构建了四层纵深防御体系：

1.  **平台安全层**：控制面默认不暴露公网，强制认证，用户环境隔离（独立沙箱），消除了配置错误导致的公网裸奔风险。
2.  **供应链安全层**：所有上架的 Skill 都经过严格的安全扫描和代码审计，并持续进行运行时巡检。
3.  **运行时安全层**：实施“事前预防、事中拦截、事后审计”机制。对于不可逆的高危操作（如删除文件、群发消息、获取敏感信息），系统会提前预警并强制要求二次确认，防止智能体失控。
4.  **身份与权限管理层**：提供凭证安全托管服务，智能体仅能获取临时、低权限的访问令牌。遵循 [[最小权限原则]]，用户可随时撤销授权。

## 应用场景与案例

根据实测案例，ArkClaw 已在以下场景中展现出全流程自动化能力：

### 内容创作与分发
-   **全自动化流程**：从选题、会议安排、文章撰写到配图生成的全自动化。
-   **视频与播客**：利用 ArkClaw 进行视频切片、播客制作和跨平台内容分发。
-   **案例**：[[李诞]] 利用该平台进行视频切片、播客制作和跨平台内容分发；亦有用户利用 10 元/月的“熟虾”搭建 [[ai-编辑部]]，实现从选题到发布的自动化。

### 金融与数据分析
-   **市场监控**：自动抓取 A 股行情，生成包含涨跌停分析和预测的定时简报。
-   **深度调研**：通过 [[多智能体协作]]，指挥多个具有不同角色的 Agent（如调研员、文档专家）协同完成复杂调研任务。
-   **案例**：[[小Lin说]] 利用 ArkClaw 分析财报、监控市场数据并自动生成公众号文章。

### 硬件控制与创意实现
-   **IoT 操控**：通过 IoT 端口直接操控硬件设备。
-   **案例**：[[何同学]] 利用 ArkClaw 操控 3D 打印机打印“龙虾眼中的自己”。

### 办公与群聊管理
-   **群聊管理**：在 [[飞书]] 群中设置“群管虾”，自动整理聊天记录。
-   **资料搜集**：设置“搜索虾”，自动检索并整理特定主题的网络信息。

## 与 OpenClaw 的对比

虽然 [[openclaw]] 曾因安全事故引发关注，但 ArkClaw 是其商业化的迭代版本或云服务版本。它重点解决了安全性和易用性问题，并引入了“养成系”的交互模式。

| 特性 | OpenClaw (生虾) | ArkClaw (熟虾) |
| :--- | :--- | :--- |
| **部署方式** | 本地部署 | 云端 SaaS |
| **门槛** | 高（需代码、环境配置） | 低（网页对话、一键授权） |
| **运维成本** | 高（需自备服务器或电脑不关机） | 低（平台托管，约 9.9 元/月） |
| **安全性** | 风险较高（全盘文件权限） | 权限可控，云端安全加固 |
| **集成性** | 需自行配置 API | 深度集成 [[飞书]] 等生态 |
