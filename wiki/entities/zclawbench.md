# ZClawBench

**ZClawBench** 是由 [[智谱AI]]（Zhipu AI）推出的针对 AI Agent（特别是 [[OpenClaw]]）实战能力的评测基准，也被称为“龙虾测试”题库。

## 概述
该基准旨在解决传统评测（如单纯的代码分数）无法全面反映 Agent 在实际办公场景中表现的问题。它包含 **116 道实战题**，覆盖了信息搜索、自动化检测、邮件处理、会议安排等“鸡毛蒜皮”的办公任务。

其评测内容侧重于长路径、多步骤的复杂任务，用于测试模型的工具调用、多智能体协同及长上下文稳定性。

## 核心发现与结果
根据智谱专家 [[李子玄]] 在沙龙上的分享，ZClawBench 的测试结果显示：
- [[glm-5-turbo]] 在办公场景、信息搜索和自动化检测上的表现，实战能力显著超越了 GLM-5。
- 在 ZClawBench 评测中，[[GLM-5-Turbo]] 获得了国产模型综合成绩第一。
- 估算约 **60%** 的用户仍在用 Agent 进行“问答和闲聊”，仅有 **40%** 的用户进入了真正的任务操作阶段。

## 开放性
智谱AI已全面公开了 ZClawBench 的题库与测试轨迹，供开发者参考和验证。

## 意义
ZClawBench 强调了评价一个 Agent 模型好坏的标准，不应仅看其代码生成能力，更要看其处理复杂、琐碎现实任务的综合能力。这为用户选择合适的底层模型提供了科学依据。
