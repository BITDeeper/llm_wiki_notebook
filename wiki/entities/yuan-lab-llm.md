# Yuan-lab-LLM

[[Yuan-lab-LLM]] 是一个在 GitHub 上活跃的开发团队/实验室，因开发 [[ClawManager]] 而知名。该团队针对 [[OpenClaw]] 在企业级落地中的管理难题，开发了业内首个企业级 OpenClaw 服务器部署管理方案。

## 技术栈与目标
该团队的技术选型包括 Go 1.21+、React 19 和 Kubernetes，致力于解决 AI 智能体在大规模应用中的运维、安全和治理问题。

## 相关项目
- [[ClawManager]]：基于 Kubernetes 的 OpenClaw 企业级部署管理工具。
