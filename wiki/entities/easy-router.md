# Easy Router

[[傅盛]] 领导的 [[猎豹移动]] 于 2026 年 5 月 1 日推出的 AI 中转站产品。

## 核心特性

- 一个 Key 调用 40 余个主流大模型
- 全场 8.5 折
- 零平台费、零加价

## 商业逻辑

作为 Google Cloud 和 AWS 认证合作伙伴，猎豹移动在云端采购上具备渠道折扣优势。8.5 折并非噱头，而是渠道差价的部分回馈给用户。

报道将其模式概括为「傅盛卖便利」——面向需要简单、合规 API 调用的企业用户，走正规渠道差价路线，而非灰色套利。
