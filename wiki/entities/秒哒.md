# 秒哒

**秒哒**（Miaoda）是百度旗下的对话式应用开发平台与智能体产品。它旨在降低 AI 应用开发门槛，允许用户通过自然语言描述（“一句话”）直接生成可上线、可交付的商业级应用，同时也支持构建复杂的多智能体工作流。

## 核心功能
- **全栈自动生成**：自动处理前端页面、后端逻辑、数据库配置及部署上线流程。
- **多端支持**：支持生成 Web 应用，配置微信授权后可直接发布微信小程序。
- **迭代维护**：支持通过对话对已生成的应用进行修改（如添加动画、搜索功能），并保留项目历史和修改轨迹。
- **自我修复**：在演示案例中，秒哒展现了识别报错（如邮箱验证冲突、上下文超限）并自主修改代码或调整配置参数的能力。
- **多智能体协作**：支持多个 Agent 协同完成复杂任务，体现了从单一模型调用向多智能体协作的转变。

## 技术特点
- **低代码/无代码**：结合自然语言处理技术，使非技术用户也能创建 AI 应用。
- **知识管理**：结合百度知识库与数据中台能力。
- **底层算力**：依托 [[百度智能云]] 的底层算力和数据基础设施。

## 生态集成
- **OpenClaw Skill**：通过 [[Miaoda App Builder]] 插件，秒哒的能力被集成到 [[OpenClaw]] 智能体框架中，使得 OpenClaw 具备了构建完整应用的能力。
- **独立平台**：除了作为 Skill 使用，用户也可以直接访问 miaoda.cn 使用其独立服务。

## 负责人
- **朱广翔**：百度秒哒产品总经理，清华大学交叉信息研究院博士。他在智能体与多智能体系统领域有深厚的研究背景，曾在 NeurIPS、ICML 等顶级会议发表论文。

## 商业模式
- **免费额度**：注册并获取 API Key 后，通常会赠送一定的免费额度（如 300 点）。

## 行业活动
[[朱广翔]]将在[[中国aigc产业峰会]]上分享关于 Agent 工具开发与应用的实践。

## 意义
秒哒的出现标志着 AI 从“内容生成”向“产品交付”的跨越，解决了 AI 产出无法直接商业化的痛点，使用户能够利用 AI 快速构建赚钱工具。
