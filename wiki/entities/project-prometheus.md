# Project Prometheus

[[Project Prometheus]] 是一家专注于机器人技术的 AI Neolab，由亚马逊创始人 [[杰夫·贝佐斯]] 亲自下场运营。

## 核心信息
- **估值**：380 亿美元（5个月内从 0 飙升至该量级）。
- **关键人物**：[[杰夫·贝佐斯]]（联合创始人/运营者）、Vik Bajaj（前 Google X 科学家）。
- **核心方向**：[[物理经济]]。

## 业务模式
Project Prometheus 致力于机器人的规模化部署，旨在解决制造、物流和劳动力等真实世界的物理痛点。贝佐斯卸任亚马逊 CEO 后首次以正式运营角色回归一线，显示了其对“AI 落地物理世界”这一赛道的极度重视。
