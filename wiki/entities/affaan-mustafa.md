# Affaan Mustafa

旧金山开发者，[[everything-claude-code-ecc|ECC（Everything Claude Code）]] 项目的创建者。

## 背景

自2025年2月 [[claude-code|Claude Code]] 发布以来，Affaan 每天都在使用它，并持续打磨自己的智能体优化系统。

## 黑客松夺冠

2025年9月12日，Affaan 与 [[david-rodriguez|David Rodriguez]] 在 Cerebral Valley 举办的 Anthropic x Forum Ventures 黑客松上夺冠。比赛主题为"智能体，助力从0到1创业"。他们开发了 AI 客户调研平台 [[zenith|Zenith]]（原名 PMF Probe），通过合成用户测试帮助创业者验证早期创意。整个产品几乎全程由 Claude Code 完成。

## 开源贡献

2026年1月，Affaan 以最宽松的 MIT 协议将整套系统开源，取名 Everything Claude Code。项目迅速成为 GitHub 上星标最高的 Claude Code 配置项目，达15万星。

## 核心理念

Affaan 开源的不是"高深的代码逻辑"，而是他作为资深开发者的"直觉与框架约束"（Harness & Constraints）。他认为代码本身正变得廉价，而定义问题的能力、搭建约束边界的逻辑、以及克制的系统审美则变得前所未有地昂贵。
