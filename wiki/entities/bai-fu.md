# BaiFu

BaiFu（白富/白复）是中国科学技术大学的学生，[[超级个体]] 的代表性人物。他以 [[vibecoding]]（氛围编程）的开发范式闻名，能够在极短时间内（10天）构建出高质量的开源 AI 项目。

## 主要成就

### BettaFish (微舆)
- **类型**：多 Agent 舆情分析助手。
- **起源**：最初是 BaiFu 的毕业设计项目。
- **成绩**：开源一周内在 GitHub 获得 20k Stars，并迅速登顶 GitHub Trending 榜。

### MiroFish
- **类型**：AI 预测引擎。
- **成绩**：获盛大集团 3000 万人民币投资。
- **技术**：基于 [[时序-graphrag]] 和多智能体模拟，用于预测社会事件、公司战略及文学结局。

## 投资与合作
在 BettaFish 爆火后，BaiFu 收到了盛大集团创始人 [[chen-tianqiao]] 的邀请。陈天桥对他在 AI 领域的潜力表示高度认可，并告诉他“继续做你想做的事”。随后，BaiFu 加入盛大，并在 10 天内完成了 MiroFish 的开发。在看到演示视频后 24 小时内，陈天桥当场拍板决定注资 3000 万人民币全力支持 MiroFish 的深度孵化。

## 开发哲学
BaiFu 是 [[vibecoding]] 的积极实践者和推广者。他认为：
1.  **深度人机协作**：开发者必须作为“审美法官”和“架构师”，深度审计 AI 生成的代码，理解其逻辑而非盲目接受。
2.  **工具边界认知**：通过多 Agent 并行工作，直观地摸清每个模型的能力边界（擅长什么、容易在哪里跑偏）。
3.  **市场敏锐度**：技术变化极快，但市场对 AI 变革的焦虑是确定的。开发者应关注如何解决实际问题，而非单纯堆砌技术。

## 评价
BaiFu 的成功案例被视为“超级个体”时代的有力证据。他展示了年轻开发者如何利用 AI 工具极大放大个人能力，从而获得传统资本和市场的认可。
