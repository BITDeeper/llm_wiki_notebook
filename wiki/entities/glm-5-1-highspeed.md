# GLM-5.1-highspeed

[[智谱]] 推出的旗舰模型高速版 API，基于 [[glm-5-1]] 模型，通过系统工程优化实现 400 tokens/s 的推理速度，是目前顶流模型中最快的 API。

## 核心指标

- **推理速度**：400 tokens/s
- **模型基础**：旗舰模型 GLM-5.1（非缩小模型）
- **定位**：顶流模型中最快的 API

## 技术实现

与 [[tile-rt]] 团队联合打造，三层系统工程优化：

1. **推理引擎层**：针对 GLM-5.1 架构特点重写核心推理路径
2. **调度系统层**：动态批处理、请求合并、KV 缓存调度，降低高并发场景尾延迟
3. **基础设施层**：推理集群部署、网络链路和负载均衡协同优化

TileRT 的核心创新是将调度单元从传统 operator/kernel 下沉到 tile 级别，通过编译期静态编排和常驻 GPU 的 persistent Engine Kernel 压缩调度、搬运与同步开销。

## 实测表现

量子位四项实测验证：
- 复杂 Canvas 动画网页：十几秒思考后一口气生成完整代码
- 模糊指令迭代修改：体感接近与设计师坐在同一画布前实时调参
- 2D 游戏实时场景修改：通过"导演指令"实时改变游戏世界
- 万字长文处理：10 秒内完成多任务内容生成

## 局限与待验证项

文章指出 400 tokens/s 的速度需要在更多任务、更多时段、更多并发条件下持续验证。生产环境还需考察模型质量、稳定性、成本、上下文能力、工具调用可靠性及复杂任务错误率。
