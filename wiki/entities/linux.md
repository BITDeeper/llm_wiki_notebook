# Linux

**Linux** 是世界上应用最广泛的开源操作系统内核。在 [[openclaw]] 于 2026 年 3 月爆发之前，Linux 长期被视为 GitHub 上最重要的基础软件项目之一。

## 历史地位与对比

尽管 [[openclaw]] 在星标数量上超越了 Linux（文章发布时 Linux 约有 22 万星标），但分析指出，两者在**技术重要性**上存在本质区别：
- **Linux**：是互联网跳动的稳定脉搏，默默支撑着全球绝大多数的服务器和智能设备。
- **[[openclaw]]**：代表了当下的技术情绪和注意力经济现象，虽然星标数增长极快，但在基础设施的渗透率和不可替代性上无法与 Linux 同日而语。

这一对比常被用来说明 GitHub Star 指标在衡量项目实际价值时的局限性。
