# Agentic Harness

Firefox 团队构建的漏洞发现流水线系统，是 [[任务执行范式]] 在安全领域的典型案例，也是 AI 漏洞挖掘从实验走向规模化的关键工程突破。

## 核心流程

1. **发现漏洞：** 给模型一段代码，让它找 Bug
2. **动态验证：** 模型编写测试用例去动态验证假设，能复现的才算数，不能复现的自动排除
3. **去重和分诊：** 自动和已知漏洞比对，避免重复
4. **跟踪和修复：** 进入正式的安全 Bug 生命周期

## 工程特点

- **换模型只需一行代码：** 从 Claude Opus 4.6 切到 [[claude-mythos|Mythos Preview]] 几乎无缝衔接
- **并行化执行：** 在多台临时虚拟机上同时运行，每台 VM 负责扫描特定文件或函数
- **模型升级自动放大效果：** 每次模型升级，发现能力更强，验证更精准，报告质量更高

## 方法论演进

早期尝试用 GPT-4 或 Claude Sonnet 3.5 做"静态代码分析"，误报率极高，无法规模化。转向 [[动态验证]] 后实现质变——从"看着像那么回事，实际全是幻觉"到可规模化验证的真实发现。

## 关键洞察

> "真正的杠杆可能不只在模型本身，而在 Harness 的工程能力。"
