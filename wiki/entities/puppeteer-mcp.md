# Puppeteer MCP

Puppeteer MCP 是一种浏览器自动化工具/服务器，常被集成到 AI 智能体工作流中（如 [[Claude Agent SDK]]），用于实现端到端（E2E）测试。

## 功能与作用
- **模拟用户操作**：允许 AI 智能体像真实用户一样点击按钮、输入文本并验证页面响应。
- **发现隐藏 Bug**：相比静态代码分析或单元测试，它能发现仅在真实交互流程中暴露的问题（如布局错乱、流程阻断）。
- **视觉验证**：通过截图功能，智能体可以“看到”页面渲染结果，从而判断功能是否正常。

## 局限性
- **原生元素盲区**：由于模型视觉能力的限制，Puppeteer MCP 可能无法识别或处理浏览器原生的非 HTML 元素，例如 `alert()` 弹窗。这导致依赖此类原生交互的功能测试存在盲区。

## 应用场景
主要用于 Web 应用开发中的自动化回归测试，确保 [[渐进式推进]] 过程中不破坏现有功能。
