# 模思智能 (MOSI)

[[模思智能]]（MOSI）是一家专注于"全模态"与"情境智能"的人工智能初创公司，由复旦大学特聘教授 [[邱锡鹏]] 创立，是 [[moss|MOSS]] 系列开源大模型的商业化实体，致力于推动其产业化落地。公司致力于通过 [[统一token结构]]，将语音、文本、图像、视频等不同模态的信息映射到同一计算空间，以实现下一代 AI 的情境理解与 Agent 能力。

## 核心技术路线

模思智能的技术路径以"离散化"和"统一 Token"为核心特征：

- **从语音切入**：认为音频是包含情绪、语调的高密度信息载体，是通向 [[情境智能]] 的最佳入口。
- **全模态统一**：通过 [[anygpt]] 等模型，验证了将多模态信息统一映射为离散 Token 序列的可行性。

## 关键产品与模型

模思智能与 [[复旦大学]] 和 [[上海创智学院]] 合作，参与了包括 [[moss-vl]] 在内的多个模型联合开发，致力于多模态视觉理解技术的研究与落地。

- **[[moss|MOSS]]**：国内首个类 ChatGPT 对话式大模型（2023年2月发布），系列开源大模型。
- **[[speechgpt]]**：离散化端到端语音大模型。
- **[[anygpt]]**：全模态基座模型，支持语音、文本、图像、视频的统一理解与生成。
- **[[nex]]**：下一代能动性模型体系，侧重于 Agent 编程与工具使用。
- **[[mova]]**：高性能音视频生成开源模型。

## 团队背景

### 创始人 / 首席科学家

[[邱锡鹏]]，CAAI Fellow，国家杰青获得者，复旦大学特聘教授、[[上海创智学院]]院长助理。主要研究方向为大模型、智能体以及科学工程等领域中的应用，发表学术论文被引用4万余次，5次获得AI领域高水平会议的最佳/杰出等论文奖。主持研发了 [[moss|MOSS]] 等系列高影响力开源大模型。

### CEO

[[李世民]]（邱锡鹏学生，复旦大学博士）。

### 孵化方

[[上海创智学院]]（提供算力与资源支持）。

### 人才构成

团队近百人，博士占比接近 50%，主要来自复旦大学 NLP 体系。

## 商业化与融资

- **融资**：2026年完成数亿元天使轮融资，由 [[IDG资本]] 领投，元禾控股、上海国投等跟投。
- **落地场景**：消费电子、智能汽车、具身智能、AI 陪伴。
- **平台**：多模态大模型开放平台已进入公测，提供 API 服务。

## 行业地位

模思智能是国内少数完成"全模态基座模型能力闭环"的初创公司之一，其技术路线强调 [[离散化全模态]] 带来的可组合性与可计算性，被视为 Agent 时代底层架构的重要探索者。

## 荣誉与成就

邱锡鹏作为创始人与核心研究者所获主要荣誉：

- 2022年度钱伟长中文信息处理科学技术奖一等奖（第一完成人）
- 2024年度CCF-ACM青年科技奖（每年仅1人）
- 2025年度吴文俊人工智能科学技术奖自然科学一等奖（第一完成人）
- 连续多年入选中国高被引学者、全球前2%顶尖科学家榜单

## 行业参与
