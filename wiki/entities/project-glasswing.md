# Project Glasswing

[[anthropic|Anthropic]] 为负责任发布 [[claude-mythos]] 而启动的防御性安全部署计划，官方定位为"为AI时代守住全世界最关键的软件"。2026年4月7日上线。

## 背景

这是AI历史上首次因"攻防失衡"而主动搁置模型发布的案例。Anthropic发现Mythos能力过强后，选择不单独发布，而是联合行业主要参与者共同评估安全边界和部署方案。

## 运作模式

将预览阶段的 [[claude-mythos-preview|Claude Mythos]] 限定交付给约50家合作伙伴，仅用于防御性安全工作。合作伙伴横跨云服务、芯片、金融、网络安全等领域。

## 合作伙伴

初始合作伙伴名单包括：
- Apple
- AWS
- Google
- Microsoft
- CrowdStrike

[[cloudflare]] 最初不在发布合作伙伴名单中，后来才受邀加入。

## 一个月成绩单（2026年5月22日公布）

- 与约50家合作伙伴使用 Mythos Preview，在全球最关键软件中找出超1万个高危或严重级别漏洞
- 开源领域：扫描1000+项目，标记6202个高危/严重漏洞候选
- 经六家独立安全公司复核，真阳性率90.6%，确认1094个高危/严重级别
- 估算开源代码将浮现约3900个高危/严重漏洞

## 合作伙伴案例

- **Cloudflare**：关键路径系统被挖出2000个漏洞，400个高危/严重
- **Mozilla**：Firefox 150 单版本修复271个漏洞，为此前12倍
- **wolfSSL**：发现完整攻击链（CVE-2026-5194，CVSS 9.1）
- **合作银行**：实时拦截150万美元诈骗电汇

## 战略意义

Project Glasswing 体现了 Anthropic 在 AI 网络安全领域的"窄门"策略——不将攻击性能力面向公众开放，而是限定交付给经过筛选的防御者。这是 [[ai网络安全受限部署|受限部署]] 共识的典型案例。

该计划标志着AI安全治理从"发布后修补"转向"发布前协同评估"的新范式，体现了 [[anthropic]] 一贯强调的安全优先理念。
