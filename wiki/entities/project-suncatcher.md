# Project Suncatcher

Project Suncatcher 是谷歌提出的 GPU 太阳卫星项目，旨在构建分布式太空计算集群。

## 核心技术
- 利用高吞吐量的 [[自由空间光通信]] 技术连接卫星。
- 利用近日点不间断的太阳能供电。

## 发展计划
- **2027 年**：计划利用卫星上的小型服务器机柜进行早期测试。
- **未来十年**：有望实现主流应用，成为谷歌基础设施的一部分。

谷歌 CEO 将该项目称为“登月计划”，显示了其在谷歌战略中的重要地位。
