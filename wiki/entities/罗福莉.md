# 罗福莉

罗福莉是 [[小米]] [[小米mimo团队]] 负责人及 [[token-plan]]（Token 计费订阅计划）负责人。她曾在阿里达摩院从事大模型研发工作，也是前 [[DeepSeek]] 早期成员。作为北京大学硕士毕业生，她在连接小米大模型团队与北大科研资源方面起到了关键的桥梁作用，并因在 AI 行业价格战背景下的独特商业观点及对技术架构的深刻洞察而受到关注。

## 教育背景

硕士毕业于 [[北京大学]]，师从穗志方教授。在校期间从事自然语言处理相关研究。

## 职业经历

- **DeepSeek**：早期成员之一，积累了深厚的大模型研发经验。
- **阿里达摩院**：曾从事大模型研发工作。
- **小米**：现任 MiMo 团队负责人，带领团队推出了 [[mimov2-pro]] 等具有全球竞争力的推理模型。

## 技术观点与行业洞察

### 算力受限下的最优解能力
罗福莉认为，中国大模型团队的核心优势不在于拥有无限的算力，而在于 **[[算力受限下的最优解]]** 能力。在 NVLink 互联带宽受限、算力不足的背景下，中国团队被迫并成功走出了 **结构创新** 的道路。她以 [[DeepSeek V4]]（V2/V3）系列中的细粒度 MoE 和 MLA 为例，指出这种创新为行业带来了勇气和信心，推动了 Hybrid Sparse、Linear Attention 等新架构方向的探索。

### 长上下文与自进化
她强调，超长上下文（100万-1000万 token）是模型实现 **“越用越好用”** 和 **[[自进化架构]]** 的前提。只有将长上下文的推理成本打下来，用户才会将高生产力任务交给模型，模型也才有可能在复杂环境中完成对自身的持续优化（包括框架层和参数层）。

### 对 Agent 框架的评价
罗福莉高度评价 [[OpenClaw]] 的开源生态，认为其设计在某些方面领先于 Claude-code。她指出，Agent 框架的价值在于“保证了基座大模型的下限，拉升了上限”，让次闭源模型也能在绝大部分场景中接近顶尖模型的任务完成度。

### 未来预测
她预测，随着 Agent 框架和模型能力的结合，具备强自进化能力的 Agent 将在 **1-2 年内** 出现，这将使科研效率提升接近十倍。

## 商业策略与定价主张

### 反对盲目降价
罗福莉曾发表长文回应关于 [[小米]] 模型定价的争议，建议行业**不要盲目降价**。她认为，过度的价格竞争会引发用户体验和服务质量的恶性循环，导致厂商难以维持高质量的算力服务。这一观点与小米按 Token 实际消耗量计费（而非调用次数）的策略一脉相承。

### 行业影响
她的言论及小米的定价策略调整（如降低旗舰模型的倍率消耗、推出非高峰折扣）在一定程度上重塑了行业标准，促使其他模型公司也开始下架按调用次数计费的套餐，转向更精细化的按量计费模式。

## 关联人物与资源

罗福莉及其团队的成功被视为“学术-工业界人才循环”的典型案例。她利用自己在北大的师承关系，将高校科研力量与工业界算力资源高效结合。

- **[[林俊旸]]**：前阿里通义实验室Qwen负责人，罗福莉的北大师兄。
- **[[穗志方]]**：北大导师，也是团队成员 [[马文晗]] 的导师。
- **[[马文晗]]**：罗福莉的同门师弟，团队成员。
