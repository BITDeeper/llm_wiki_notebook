# AgentSkills.io

AgentSkills.io 是由 [[nous-research]] 推出的开放技能标准。其核心目标是解决 AI Agent 领域的“孤岛问题”，实现 Agent 技能的跨项目、跨社区共享。

## 背景与目的
在传统的 Agent 开发中，技能（如“如何抓取特定网站”、“如何部署特定服务”）通常被硬编码在特定项目中，难以复用。AgentSkills.io 试图定义一种通用格式，使得：
1. Agent 创建的技能可以被其他 Agent 导入和使用。
2. 社区可以围绕技能标准构建市场（如 HermesHub）和工具（如 mission-control）。

## 生态组件
- **Skills Hub**：由官方运营的技能发现与安装中心。
- **HermesHub**：第三方社区开发的带安全扫描的技能市场。
- **hermes-workspace**：基于该标准的网页端 GUI 界面。

## 意义
AgentSkills.io 是构建 Agent 生态的关键基础设施。它标志着 Agent 开发从“单点工具开发”向“生态化协作”的转变，类似于移动应用商店对于智能手机生态的意义。
