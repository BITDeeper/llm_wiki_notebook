# Project Mariner

Project Mariner 是 [[Google]] 曾备受关注的浏览器智能体项目，曾在去年的 I/O 大会上作为宠儿亮相。然而，随着 [[桌面智能体]] 的兴起，该项目近期已被悄然重组或拆散。

## 衰退原因
Project Mariner 的困境反映了整个 [[浏览器智能体]] 赛道的遇冷：
1. **功能局限**：仅能在浏览器环境中替用户执行操作（如填表、下单），无法跳出浏览器处理跨应用任务。
2. **用户需求不匹配**：用户真正需要的是能替他们“干真活”的 AI，即能够读写本地文件、操控系统级应用的 Agent，而不仅仅是一个“上网替身”。
3. **数据表现**：类似的浏览器智能体产品（如 Perplexity Comet、ChatGPT Agent）周活数据惨淡，验证了该技术路线的市场疲软。

## 行业信号
Mariner 团队的重组标志着 AI 战场已从网页聊天框和浏览器插件，全面转向操作系统底层的系统级接管。
