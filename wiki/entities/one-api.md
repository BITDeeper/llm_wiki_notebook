# One API

AI 中转站行业的事实基础设施，GitHub 超 3.3 万星的开源反向代理框架。

## 技术特征

- Go 语言编写
- 支持 OpenAI、Claude、Gemini、DeepSeek 等几乎所有主流模型
- 全量兼容 OpenAI 标准 API 格式
- 一行 Docker 命令即可部署，带上数据库和缓存也不过十几行配置

## 行业影响

One API 的成熟使 AI 中转站的技术门槛趋近于零，任何人都能在一天内搭起一个中转站。这既是行业快速扩张的基础，也导致了价格战和信任危机——当技术不再是壁垒，差价空间收窄，纯差价模式的中转站越来越难以生存。

[[new-api]] 是基于 One API 二次开发的商业化框架，提供更完善的商业化功能，成为众多中转站事实上的底层框架。
