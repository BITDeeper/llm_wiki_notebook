# Mureka Agent

[[昆仑万维]] 自研的音乐大模型产品，由 [[方汉]] 在2026中国AIGC产业峰会上公开介绍。

## 核心数据

- **成本降幅**：将单首歌曲制作成本从约10万元降至约1元（对外售价），成本降幅约10万倍。
- **原流程**：传统歌曲制作需找人作曲、作词、录音室演奏、演唱、混音，最便宜的方式也需约10万元。
- **新流程**：通过Mureka Agent一键生成，成本极低。

## 意义

Mureka Agent是方汉论证"AI成本已可量化、创作门槛急剧下降"的核心例证之一，展示了AI在创意内容生产领域的颠覆性降本能力。
