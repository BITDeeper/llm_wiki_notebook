# 爱诗科技

爱诗科技是国内 AI 视频赛道的头部玩家，致力于开发顶级 AI 视频生成技术并将其转化为大众和团队可用的基础设施。

## 核心产品
- **[[PixVerse V6]]**：主打电影级视听质感和物理级真实还原的视频生成模型。
- **[[PixVerse R1]]**：全球首个通用实时世界模型，支持实时交互和数字分身功能。
- **拍我AI**：落地平台，涵盖 Web 端、App 端及 API 平台。

## 商业化进展
- **Team Plan**：针对 2-15 人小型内容工作室推出的团队协作方案，解决资产管理和权限分配问题。
- **Mini Apps**：一键成片功能，降低商业广告制作门槛。

## 市场表现
- **融资情况**：已完成 3 亿美元 C 轮融资。
- **用户规模**：全球累计用户突破 1 亿，月活跃用户超 1600 万。
- **行业认可**：PixVerse R1 入选 2026 中关村论坛“面向经济主战场”七大“重大科技成果”之一。

## 战略方向
爱诗科技的战略打法分为三个层面：
1. **“真”**：通过 V6 模型消除“AI 味”，让物理规律被理解。
2. **“用”**：通过 Team Plan 和 Mini Apps 将工具嵌入真实工作流。
3. **“玩”**：通过 R1 的实时生成和互动直播吸引 C 端用户持续参与。

## 行业地位
在 Sora 被叫停的背景下，爱诗科技凭借 PixVerse 系列产品迅速填补市场空白，与字节跳动（Seedance 2.0）、快手（可灵）共同构成了国内 AI 视频赛道的第一梯队。
