# GitHub Copilot CLI

GitHub Copilot CLI 是微软旗下 GitHub 推出的 AI 命令行编程辅助工具，可以在 Visual Studio Code 等开发应用之外运行，是微软在 AI 编程工具赛道的核心产品，同时被视为 [[claude-code]] 的直接竞品与内部替代方案。

## 竞争态势与内部偏好转移

在微软内部基准测试中，[[claude-code]] 展现出显著的产品力优势。2025年12月微软向数千名内部开发者开放 Claude Code 使用权限后，此前91%工程团队使用 Copilot 的高频使用率遭到"严重蚕食"，大量工程师转向偏好 Claude Code。

## 微软强制迁移事件

2026年5月至6月，微软因 Claude Code 按 Token 计费成本过高，决定取消内部 Claude Code 授权，强制近10万名工程师从 Claude Code 迁移至 GitHub Copilot CLI。迁移范围覆盖"Experiences + Devices"（体验+设备）部门，要求6月底前完成。官方理由是"回归自研产品"（Eat Your Own Dog Food）。

这一决策被视为企业控制 Token 成本、减少对外部 AI 供应商依赖的标志性事件。同时微软加大对 GitHub 团队的督促，要求根据内部员工的 Bug 报告和反馈"疯狂"迭代升级 Copilot CLI。

## 财务优势

对微软而言，GitHub Copilot 属于"内部核算成本"——资源在 Azure 内部流动，边际成本极低。相比之下，Claude Code 是一笔实打实的外部账单，需要按 Token 向 [[anthropic]] 付费。即便两者产出完全相同，财务性质也天差地别。

## 收购考量

微软还曾考虑收购 [[cursor]] 以补足 GitHub Copilot 的短板，但后来为避免潜在监管审查，转而关注其他小型 AI 初创公司。

## 定价转型

GitHub 已取消"一口价"固定计划，正在所有产品中全面转向按使用量计费，反映行业从补贴获客向真实成本定价的转型趋势，标志着整个 AI 工具行业向 [[效用经济]] 的转型。过去半年全球 AI 软件有效价格上涨20%-37%。
