# 傅盛

傅盛是猎豹移动（Cheetah Mobile）的 CEO，也是 AI Agent 时代的早期深度实践者和验证者。

## 职业背景

傅盛拥有 16 年的工具软件基因。猎豹移动曾是中国互联网清除流氓软件的代表。PC 红利消退后，傅盛带领猎豹转型过机器人、出海工具，均未打出真正的第二曲线。从 PC 时代的金山毒霸到移动时代的 Clean Master，再到 AI 时代的 [[easyclaw]]，他始终致力于通过工具提升效率。作为上市公司，猎豹移动需要一个新故事，AI 转型是其最新尝试。

## AI 实践：养虾实验

2026 年春节期间，傅盛因滑雪导致髋关节脱臼卧床。在此期间，他没有选择静养，而是利用 [[openclaw]] 框架，通过语音和截图与 AI Agent 进行了为期 14 天的高强度交互，成功"养"出了一支名为 [[三万]] 的 AI 团队。

### 实验过程
- **交互规模**：14 天内发送 1157 条消息，累计 22 万字。
- **进化路径**：从最初连公司通讯录都查不了，到后来能够自主编写脚本抓取数据、发送个性化拜年消息、判断伤情并主动联系助理。
- **团队形态**：最终进化为包含参谋、运营官、进化官等 8 个 Agent 的协作团队，实现了 7×24 小时自动运转。

### 核心观点

傅盛基于其实践，提出了关于 AI Agent 的几个关键判断：

1.  **[[技能积累]] 是核心壁垒**：他认为 Agent 的强大不在于模型参数，而在于通过试错积累的永久性技能。这些技能不会遗忘，且可在 Agent 间瞬间无损复制。
2.  **[[工具类agi]]**：他提出在工具使用领域（如编程、业务流程自动化），AGI 已经实现。
3.  **[[老板思维]]**：他认为未来职场中，个人必须具备像老板一样定义目标、拆解任务和调度资源（包括 AI）的能力，否则将被淘汰。
4.  **SaaS 与 Agent 的本质区别**：SaaS 卖的是能力，Agent 卖的是结果。

## 产品化

### EasyClaw

为了解决 [[openclaw]] 部署复杂（需命令行、Docker 配置）的问题，傅盛带领猎豹移动团队推出了 [[easyclaw]]。这是一款极简的 AI Agent 工具，主打"一键安装、无需配置、开箱即用"，旨在降低技术门槛，让普通人也能拥有自己的 AI 团队。

### Easy Router

2026 年 5 月 1 日，傅盛推出 AI 中转站 [[easy-router]]，定位为面向需要简单、合规 API 调用的企业用户。

- 口号「全场 8.5 折」，声称一个 Key 调用 40 余个主流大模型
- 零平台费、零加价
- 作为 Google Cloud 和 AWS 认证合作伙伴，[[猎豹移动]] 在云端采购上具备渠道折扣优势，8.5 折是渠道差价的部分回馈
- 定位为「卖便利」

报道将其模式概括为「傅盛卖便利」，与孙宇晨的「卖管道」和特朗普家族的「卖门票」形成鲜明对比。
