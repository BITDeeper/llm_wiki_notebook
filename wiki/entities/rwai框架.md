# RWAI框架

**RWAI（Real World AI）** 是由[[清华长三角研究院人工智能创新研究中心]]发布的面向产业AI落地的开源框架。其核心理念是将开源的范围从代码、工具扩大到包括角色定义、流程设计、人-机交互、人-人交互的整体实践，搭建"智能工厂"的控制论和工程管理框架。

## 设计理念

RWAI框架的口号是"Talk is cheap, code is not enough, PRACTICE is all we need"，主张AI产业的核心矛盾已从"提升模型智力"转向"跨越[[落地鸿沟]]"。框架试图解决的问题是：在[[能力过剩]]的背景下，如何将模型能力转化为可验证、可复制的工程实践。

## 三大核心要素

1. **[[任务集机制]]（Task Set Mechanism）**：超越传统静态数据集，明确定义目标、约束条件、团队角色和评估标准
2. **[[人类反馈分类法]]（Taxonomy for Human Feedback）**：对人在AI应用各环节的作用进行精确量化的交互分类体系
3. **[[人机交互标准化]]（Standardized Interaction Guidelines）**：建立"一致性API"，让人人/人机沟通可预测、可管理

## 与现有范式的关系

RWAI框架可视为[[任务执行范式]]在产业落地维度的延伸——从"AI员工"到"人与AI高度协作的智能工厂"。与[[办公技能框架]]和[[模型-技能分离架构]]形成互补：后者关注技能拆解与模型解耦，RWAI关注整体工程实践与人机协作流程。
