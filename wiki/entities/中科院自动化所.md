# 中国科学院自动化研究所

中国科学院自动化研究所（CASIA，简称中科院自动化所）是中国在人工智能、自动化与机器人领域的顶尖科研机构。其模式识别实验室（Pattern Recognition Lab, Institute of Automation, CAS）在多模态大模型评估、Mobile Agent 基础设施以及具身智能等领域均有重要贡献。

## 代表工作

### 多模态大模型评估

该所与香港创新研究院等机构合作，推出了 [[VTCBench]] 基准测试。这一工作针对 [[视觉文本压缩]]（VTC）范式下的模型能力进行了系统性评估，揭示了视觉语言模型在处理长图像时存在的 [[空间注意力偏见]] 问题，为行业提供了重要的评估标准。

### Mobile Agent 基础设施

该团队开发了 [[MobileGym]] 和 [[MobileGym-Bench]]：

- [[MobileGym]]：浏览器端安卓仿真平台，用于 Mobile Agent 训练与评测
- [[MobileGym-Bench]]：配套的手机 Agent 评测基准

通过"[[交互保真]]"理念和[[结构化状态仿真]]方法，该团队首次将可验证的训练与评测能力延伸到日常高频 App。

### 具身智能与灵巧操作

在具身智能领域，该机构提出了面向 [[任务导向灵巧操作]] 的基准与工具链 [[dexjoco|DexJoCo]]，致力于推动机器人操作能力从简单的抓取放置向复杂的功能性交互演进。
