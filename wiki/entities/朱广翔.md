# 朱广翔

**朱广翔**博士是百度“秒哒”产品总经理，负责无代码应用搭建平台 [[百度秒哒]] 的产品方向与战略，专注于智能体与多智能体系统的产品研发。

## 个人背景

- **教育背景**：博士毕业于清华大学交叉信息研究院。
- **编程经历**：从初中开始写代码，到博士毕业已写了20年代码。
- **情感驱动力**：小学时曾在纸上画游戏设计图，与8岁秒哒用户的经历高度相似，这种个人经历成为他投身 [[vibe-coding|Vibe Coding]] 赛道的情感驱动力。

## 职业经历

- **现任职位**：百度“秒哒”产品总经理。
- **加入时间**：2021年加入百度。
- **过往经历**：
    - 负责百度信息流双列首页产品。
    - 负责百度智能云数据中台、知识管理产品及办公产品。
    - 负责百度智能云千帆Appbuilder等业务。

## 学术成就

- **荣誉**：曾获中国智能体与多智能体系统最佳论文、北京市优秀博士学位论文、清华优秀博士学位论文。
- **发表**：在NeurIPS、ICLR、ICML、AAAI、NAR、Nature Communications等国际顶会和期刊发表论文14篇。

## 核心观点

在 [[第四届中国aigc产业峰会]]（即 [[2026中国AIGC产业峰会]]）演讲中，朱广翔作为 [[秒哒]] 产品负责人，展示了百度在 [[Agent工具]] 及多智能体系统领域的最新产品布局，并提出了以下核心论点：

1. **[[第四次编程革命]]**：编程门槛从机器语言一路降低到自然语言，Vibe Coding 是这一趋势的极限。
2. **[[需求方变供给方]]**：Vibe Coding 让不懂代码的业务人员直接成为软件供给者。
3. **[[opc-一人公司|OPC]] 成为AI时代主流商业组织**：秒哒数据验证了这一趋势。
4. **[[创业3.0浪潮]]**：创业从零工时代→内容时代→软件交付时代演进。
5. **AI正在杀死传统软件**：以 [[saas末日事件|SaaS末日]] 为宏观证据。
