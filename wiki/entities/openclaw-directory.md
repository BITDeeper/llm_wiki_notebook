# OpenClaw Directory

OpenClaw Directory 是一个由第三方搭建的 [[openclaw]] 生态工具目录网站，旨在帮助开发者和用户在日益繁杂的工具生态中筛选合适的解决方案。

## 功能与分类

该网站对收录的工具进行了精细化的分类梳理，主要类别包括：
-   **[[ai-agent-teams]]**：Agent 团队协同工作方案。
-   **AI Agent Trigger**：触发 Agent 执行任务的机制/工具。
-   **[[boilerplate]]**：代码模板或预置配置。
-   **Command Centre**：控制面板。
-   **Deployer**：部署工具。
-   **Hosting**：托管服务。
-   **Token Optimizer**：Token 优化工具。
-   **Skills**：扩展特定功能的技能模块。
-   **Plugins**：增强 OpenClaw 能力的插件。

## 筛选与排序

支持按“必备”、“可定制”、“开源”等标签筛选，也可按“流行”、“最新”、“评分最高”、“A-Z字母序”等方式排序。

## 生态意义

该目录的出现标志着 [[openclaw]] 已从单一工具发展为拥有完整第三方生态的平台化系统。它不仅提供工具列表，还通过 Blog 板块提供从入门科普到进阶优化的教程，降低了新用户的准入门槛。
