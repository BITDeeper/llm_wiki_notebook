# dNaViT

**dNaViT** 是 [[美团-longcat]] 团队为 [[longcat-next]] 模型开发的自研视觉分词器。它的主要功能是将连续的图像信号转化为离散的 [[token]]，以支持 [[dina-架构]] 的统一建模。

## 核心功能
dNaViT 实现了从图像到离散 ID 的映射，并支持从离散 ID 还原回图像。它强调“原生学习”，即 Token 的含义是由模型自己学出来的，而非硬编码的规则。

## 技术细节
- **特征提取**：首先使用 [[sae]]（Semantic-and-Aligned Encoder）从图像中提炼高信息密度、多属性的特征，既包含语义信息也包含细节。
- **量化压缩**：采用 8 层残差向量量化（RVQ，Residual Vector Quantization）技术。每一层只负责打包上一层遗漏的“剩余信息”（如轮廓、颜色、纹理等），最终实现高达 28 倍的像素空间压缩。
- **图像还原**：使用双轨解码器保障还原质量。
    - **结构像素解码器**：生成低分辨率锚点图，保证布局正确。
    - **扩散像素细化器**：注入高频纹理细节，提升画面清晰度。

## 原生分辨率
dNaViT 支持 [[原生分辨率]] 处理，即无需对输入图像进行缩放、裁剪或填充，即可直接进行编码与解码，且输出尺寸与输入完全一致，细节不丢失。
