# Think Token

[[think-token]]（思维令牌）是 [[deepgen-1-0]] 模型中引入的一种特殊机制，充当隐式思维链的角色。

## 功能与作用
在 VLM-DiT 架构中，Think Token 作为可学习的参数，被用于连接视觉语言模型（VLM）的理解分支和扩散模型（DiT）的生成分支。其主要作用包括：
- **缓解信息丢失**：在跨层特征传递过程中，减少语义信息的损耗。
- **减少表示偏移**：对齐理解与生成模态之间的特征空间。
- **提升推理能力**：赋予模型面对复杂指令时的隐式推理能力，使其能更好地处理基于推理的生成与编辑任务。

## 优势
与显式的思维链不同，Think Token 不需要在推理时生成大量的中间文本 token，因此不会显著增加模型的参数量和推理计算开销，非常适合轻量化模型。
