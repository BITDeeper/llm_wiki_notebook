# GPT-5.3-Codex

[[GPT-5.3-Codex]] 是 [[OpenAI]] 发布的新一代编程与网络安全智能体模型。它不仅是 OpenAI 迄今为止最具网络安全能力的模型，标志着 OpenAI 开始将特定的“危险能力”剥离为独立产品并实施严格访问控制；同时，它也是对 [[Claude Opus 4.6]] 的直接回应，旨在巩固 OpenAI 在编程 AI 领域的领导地位，推动 Codex 系列从单纯的代码生成工具进化为全能的“通用协作者”。

## 核心特性

### 架构与能力融合
- **双重融合**：完美融合了 GPT-5.2-Codex 的顶尖编程能力与 GPT-5.2 的卓越推理及专业知识能力。
- **性能提升**：运行速度较前代提升了 25%，能够驾驭涉及深度研究、工具调用及复杂执行的长程任务。
- **高等级攻防能力**：具备强大的代码枚举和缺陷挖掘能力，能够辅助发现和修补复杂的安全漏洞。

### 意图理解与生成质量
相比 GPT-5.2-Codex，[[GPT-5.3-Codex]] 对模糊指令的理解更为精准。例如在构建落地页时，它能自动优化价格展示逻辑（如将年付折算为月付），并生成更丰富的组件（如自动切换的证言轮播），使产出更接近可直接上线的成品。

## 基准测试表现

### 标准基准
- **SWE-Bench Pro**：创下了行业新高。该基准涵盖四种编程语言，比仅测试 Python 的 SWE-bench Verified 更具挑战性和行业相关性，且更能抵御数据污染。
- **Terminal-Bench 2.0**：在衡量编程智能体终端技能的评测中表现远超此前的 SOTA。
- **OSWorld**：在计算机使用基准测试中展现出远超之前 GPT 模型的操作能力，能够利用视觉在可视化桌面环境中完成任务。
- **Token 效率**：实现上述性能所消耗的 Token 比以往任何模型都要少，显著降低了使用成本。

### EvoClaw 评测
在 [[EvoClaw]] 的持续软件演进评测中，该模型展现了极高的性价比：
- **综合得分**：**28.88%**，位居第二，仅次于 Claude Opus 4.6。
- **推理开销**：不到 Claude Opus 4.6 的三分之一。
- **长尾表现**：凭借最佳的“留存率”后来居上，展现出更佳的长尾表现。
- **稳定性**：其在项目演进中的 effort 分配最为稳定。

#### 局限性
分仓库来看，GPT-5.3-Codex 在 Rust 项目（如 Nushell、ripgrep）上表现较弱，拖了整体后腿；但在其余仓库上能接近甚至超过 Opus 4.6。

## 产品定位与交互

### 双重产品定位
- **单一通用智能体**：OpenAI 将其定位为向 [[单一通用智能体]] 迈出的跨越性一步。它不仅能处理软件生命周期的所有环节（调试、部署、监控、写 PRD 等），还能处理数据分析、幻灯片制作等案头工作。
- **独立安全产品**：与 OpenAI 的通用旗舰模型（如 Spud）不同，GPT-5.3-Codex 在网络安全维度被定位为专门的独立产品，官方强调其主要用于防御性研究，旨在帮助安全团队加固系统。

### 实时交互引导
针对长程任务中的“黑盒”问题，[[GPT-5.3-Codex]] 引入了实时交互机制。用户可以在智能体工作过程中随时掌握关键决策和进度，进行提问、讨论方法并引导方向，无需干等最终结果。

## Trusted Access for Cyber 计划

为了管控该模型带来的风险，OpenAI 推出了 [[Trusted Access for Cyber]] 计划：

- **邀请制**：不向公众开放，仅限受邀合作伙伴访问。
- **资源支持**：承诺提供 1000 万美元的 API 额度，专门用于支持正当的防御性研究。
- **安全栈**：这是 OpenAI 首次在网络安全维度上按高能力等级部署安全栈。

## 研发影响：自我加速迭代

[[GPT-5.3-Codex]] 是首个在自身创造过程中发挥关键作用的模型。OpenAI 内部使用其早期版本去训练、部署和优化正式版，形成了“套娃”式的进化：
- **研究团队**：利用其监控训练运行、挖掘交互模式、开发分析工具。
- **工程团队**：利用其优化测试框架、定位缓存失效根源、动态调度 GPU 集群。
- **数据分析**：能在三分钟内从数千个数据点中提炼关键洞察，大幅提升研发效率。

## 战略意义与竞争背景

GPT-5.3-Codex 的发布反映了 OpenAI 对 [[AI 网络攻防能力]] 质变的应对。通过将高危能力封装在独立产品中并限制访问，OpenAI 试图在推动技术进步与防止社会风险之间寻找平衡，同时也开启了 [[能力分层与分级访问]] 的商业化尝试。

该模型的发布被广泛视为对 [[Claude Opus 4.6]] 的紧急反击。[[Sam Altman]] 在 [[Claude Opus 4.6]] 发布后不久即在社交媒体预告，随后正式推出，显示出 AI 编程与安全领域竞争的白热化。
