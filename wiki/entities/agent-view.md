# Agent View

Agent View 是 [[anthropic|Anthropic]] 为 [[claude-code]] 推出的多会话调度界面，以"研究预览版"形式于2026年5月上线。它允许开发者在单一终端界面中管理多个并行 AI 会话，无需开启多个终端窗口。

## 功能设计

- **表格式会话管理**：底部输入框输入 prompt 后自动新增一行，每个任务在后台独立运行。
- **状态颜色编码**：动画图标表示 Claude 正在工作，黄色表示等待用户反馈，绿色表示任务完成，红色表示崩溃。
- **Peek Panel**：按 Space 弹出预览面板，查看会话最新状态。
- **全屏切换**：按 Enter 或 → 进入完整对话视图，按 ← 返回调度表。
- **后台挂起**：使用 `/bg` 将当前会话扔到后台，处理完紧急事项后可无缝恢复。

## 适用场景

1. **互不依赖的并行任务**：修 bug、加 endpoint、写测试、查 log、跑数据迁移等可独立执行的任务。
2. **长跑等待型任务**：PR 审查、CI 等结果、自动 merge 等耗时但无需频繁介入的任务。
3. **临时插队**：紧急任务插入时不丢失当前会话进度。

## 不适用场景

需要深度参与的协作场景，如架构设计、棘手 bug 调试——这类工作应保持 attach 状态，一来一回慢慢打磨。

## 产品定位

Agent View 标志着 [[claude-code]] 从"一对一对话工具"向"一对多任务调度平台"的跃迁。它不是提前设计的产品功能，而是 Claude Code 任务完成度突破独立性临界点后才"长出来"的工具——当模型能够独立完成读代码、定位问题、修改、跑测试、提 PR 的全流程时，并行调度才有意义。
