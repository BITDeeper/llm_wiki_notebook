# OmniSIFT

OmniSIFT 是一种由 [[快手可灵]]、[[中科院自动化所]] 和 [[南京大学]] 联合提出的模态非对称 Token 压缩框架，旨在提升全模态大模型的推理效率。

## 核心架构
OmniSIFT 由两个主要模块组成，协同工作以去除冗余信息：
1. **STVP (Spatio-Temporal Video Pruning)**：负责视频端的压缩。
   - **帧内剪枝**：去除单帧内的背景区域或重复纹理。
   - **帧间剪枝**：分析连续帧相似度，丢弃变化较小的重复帧。
2. **VGAS (Vision-Guided Audio Selection)**：负责音频端的压缩。
   - 利用筛选后的视觉特征，通过跨模态注意力机制评估音频 Token 的重要性。
   - 保留与视觉内容高度相关的声音（如说话声、关键环境音），过滤无关背景音。

## 性能表现
- **压缩率**：在仅保留 35% Token 的情况下，模型性能保持稳定甚至反超全量输入。
- **推理速度**：在 [[Qwen2.5-Omni]]-7B 上，总推理时间减少约 42%（从 15097秒 降至 8756秒）。
- **显存占用**：随着 Token 数量减少，GPU 显存占用同步下降。

## 技术创新
- **非对称依赖**：利用“视频信息密集，音频跟随视频”的特性，打破了传统统一压缩策略的局限。
- **可微优化**：引入 [[Straight-Through Estimator]] (STE)，使得离散的 Token 选择过程能够参与端到端训练。

## 应用场景
该技术为全模态模型在实时交互、端侧部署等算力受限场景的应用提供了新的可能。
