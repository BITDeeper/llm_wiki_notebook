# Karel

Karel 是一位重度 AI 用户和极客，以其对 [[gpt-5.3-codex]] 的极限用法著称。据 OpenAI 研究科学家 Aidan 称，Karel 单人的 Codex 使用量是其他人的十倍之多。

## 科研自动化实践
Karel 将 Codex 作为科研加速器，单月 API 费用高达 $10,000。他构建了一套“非人知识循环”：
- **多智能体管理**：使用 Codex 管理多个子智能体，分别负责 Slack 调研、代码研究、编写和数据科学。
- **假设生成**：让 AI 扫描公司内部积年累月的 Slack 记录和杂乱文档，在几小时内挖掘出 700 个具有科研价值的假设。
- **HelperCommits**：通过 [[helper-commits]] 机制，让 AI 记录并优化自身的工作流程，将中间态上下文提交到 Git，供后续迭代检索。

Karel 的案例展示了 AI 作为“搜索智能体”和“尽职调查员”在科研领域的巨大潜力。
