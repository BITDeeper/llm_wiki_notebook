# 悟界·RoboBrain Orca

[[智源研究院]]正在研发的具身大脑，以"下一个物理状态预测"为核心，构建「统一表征—建模—预测—交互」完整闭环。

## 核心架构："想、看、动"三位一体

从 Next Token / Frame / Action Prediction 升级为 **Next Physical State Prediction**，彻底打破传统AI仅能理解文本的局限。RoboBrain Orca可同时生成：

- **想** — 语言思考
- **看** — 视觉预测
- **动** — 动作决策

赋予具身智能机器人打通「认知—预测—行动」完整链路的能力。

## 三大核心能力

1. **统一表征** — 将多模态信息统一编码为物理状态表征；融合大量Ego-centric（第一人称视角）交互数据，强化世界模型的具身表征
2. **因果推演** — 基于物理状态进行因果推理，有效提升下游少样本与跨场景的泛化能力
3. **模态解码** — 将推理结果解码为语言、视觉、动作等多模态输出

## 与VLA的关系

智源将传统[[vla-视觉-语言-动作|VLA]]归类为"以语言为中心的世界模型"，认为其"学到的是语言描述的世界，并不能理解背后的物理后果"。RoboBrain Orca通过物理隐空间表征突破这一局限，实现从理解文本到感知、预测与交互物理世界的跃迁。

## 与其他具身大脑的对比

RoboBrain Orca与[[lingbot-vla|LingBot-VLA]]（蚂蚁灵波，真机数据预训练路线）、[[dm0|DM0]]（原力灵机，Picking原子任务路线）形成具身大脑赛道的不同技术路线。RoboBrain Orca的独特之处在于以"下一个物理状态预测"为核心范式，而非传统的VLA架构。

## 与Physis-v0.1的关系

与[[悟界-physis|Physis-v0.1]]形成"物理基座 + 通用交互"双引擎架构，共同为物理AGI提供从底层物理可信性到顶层类人认知交互的全栈支撑。

## 应用场景

支撑具身智能机器人在物流场景、酒店服务场景等真实环境中的长期自主作业。
