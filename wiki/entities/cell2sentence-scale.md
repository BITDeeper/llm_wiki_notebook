# Cell2Sentence-Scale

[[Cell2Sentence-Scale]] 是耶鲁大学研究团队基于 [[Gemma]] 模型开发的开源项目，旨在利用大语言模型处理单细胞基因表达数据。

## 工作原理

该项目将复杂的单细胞基因表达数据转化为语言模型可以理解的“句子”序列。通过这种方式，AI 可以像阅读文本一样“阅读”细胞的状态，从而识别出传统方法难以察觉的模式。

## 应用成果

在癌症治疗靶点发现的研究中，Cell2Sentence-Scale 成功找到了几条此前被传统方法忽略的新路径。这展示了开源小模型在科学研究中的巨大潜力。

## 意义

-   **降低科研门槛**：如果没有开源的 Gemma 模型，类似的项目可能需要花费数百万美元购买商业 API 调用。
-   **AI for Science 实证**：作为 [[ai-for-science]] 的典型案例，证明了数十亿参数的开源模型足以推动真正的科学发现，而不仅仅是千亿参数模型的专利。
