# AXLearn

AXLearn 是一个开源的深度学习训练框架，专门用于高效训练大规模 AI 模型。

## 背景
该工具是 [[庞若鸣]] 在苹果期间参与开发的项目之一。其 GitHub 仓库曾获得 2.1k 星，反映了社区对其技术价值的认可。
