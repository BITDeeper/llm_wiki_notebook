# 刘星光

刘星光是古茗科技集团网络安全总监。作为 [[openclaw]] 在企业端落地的早期实践者，他分享了 Agent 技术带来的提效价值及具体的安全风险。

## 核心观点
- **提效价值**：OpenClaw 最吸引人的地方在于其自动化执行能力，能够自主拆解任务并反馈问题节点，而非仅生成内容。
- **风险警示**：
    - **端口暴露**：OpenClaw 默认开启的 18789 端口及明文 Token 极易导致内网横向渗透。
    - **成本失控**：曾遭遇 Agent 持续调用 API 超过 20 分钟无法自动终止的情况。
- **应对策略**：强调独立隔离运行环境（如 [[landing-zone]]）是安全落地 Agent 的核心基础。
