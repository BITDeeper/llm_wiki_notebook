# GitHub Copilot

GitHub Copilot是微软旗下GitHub推出的AI编程助手，基于大语言模型为开发者提供代码补全和生成服务。作为AI编程工具月费制的代表性产品，Copilot于2026年6月1日从固定订阅制全面转向基于Token的按量计费模式，成为"[[token末日|Token末日]]"事件的直接触发者。

## 按量计费转型

2026年6月1日起，所有Copilot套餐全面转向按用量计费。旧的高级请求逻辑作废，换成AI额度，按输入Token、输出Token、缓存Token的实际消耗，对照每个模型的API费率结算。

### 转型原因

GitHub官方解释：智能体崛起后，一次任务能连续跑几小时、改动整个代码库，重度用户和轻度用户的成本差可拉到几个数量级，月费制已不可持续。

### 核心变化

- 从固定月费转向按Token消耗量计费
- 不同模型间Token成本乘数差异巨大，最高达60倍
- 高级模型（用户公认最好用的）涨幅最凶
- 缺少"员工级别Token限额"功能，企业成本管控困难

## 用户反应

转型引发Reddit和X上大量用户抗议：

- 开发者JBusu晒出账单：原本28.12美元/月的开销按新制需付746.01美元，涨幅约26倍
- 另一用户费用从50美元飙至3000美元，涨幅60倍
- 也有老用户反驳，认为极端账单是[[vibe-coding|vibe-coder]]群体YOLO模式滥用的结果

基础订阅价格未变，被冲击最大的是靠Copilot跑长链任务的重度智能体用户。

## 与其他AI编程工具的关系

- [[codex]]：OpenAI推出的AI编程代理，周活超500万
- [[claude-code]]：Anthropic推出的AI编程代理，因高算力消耗引发订阅制争议

Copilot的按量计费转型可能预示着整个AI编程工具市场的定价方向。
