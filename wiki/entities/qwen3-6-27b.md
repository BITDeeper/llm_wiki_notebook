# Qwen3.6-27B

[[Qwen3.6-27B]] 是由阿里 Qwen 团队开源的大语言模型，参数量为 27B。与前代旗舰 [[qwen3-5-397b]]（397B MoE 架构）相比，该模型在智能体编程任务上表现出了显著的效率提升，在多项基准测试中以更小的参数量实现了超越。

## 核心特性

### 架构设计
Qwen3.6-27B 放弃了复杂的混合专家（MoE）架构，转而采用 [[密集架构]]。这一选择旨在简化部署流程并提升推理的稳定性，使得普通开发者能够更便捷地在本地运行模型。

### 智能体编程优化
该模型针对智能体编程场景进行了深度优化，特别是在代码库理解、跨文件编辑、前端生成和终端命令执行等真实开发场景中。其引入的 [[思维保留机制]] 允许模型在多轮调试中保持上下文连贯性，避免因对话轮次过多而丢失之前的思路。

### 技术组件
- **[[gated-deltanet]]**：采用混合注意力架构，以平衡显存占用与模型性能。
- **原生多模态**：原生支持文本、图像和视频的理解与处理。
- **双模式**：支持思考模式（深度推理）和非思考模式（快速响应）。

## 性能表现

- **编程能力**：在四大智能体编程基准上全面超越前代 397B 模型。在 SkillsBench 测试中，得分从 30.0 提升至 48.2。
- **逻辑推理**：在 GPQA Diamond 测试中得分 87.8，表现对标 Claude 4.5 Opus。
- **数学能力**：在 AIME26 竞赛中得分 94.1。

## 部署与生态

- **开源**：模型权重可在 Hugging Face 和 ModelScope 上免费获取。
- **云服务**：通过 [[阿里云百炼]] 提供 API 调用服务，兼容 OpenAI 和 Anthropic 接口格式。
- **工具集成**：已支持 [[openclaw]]、[[claude-code]] 和 [[qwen-code]] 等主流编程工具。
