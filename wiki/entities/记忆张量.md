# 记忆张量

记忆张量（MemTensor）是一家 AI 研究团队，专注于 Agent 记忆基础设施的研发。该团队推出了 [[memos|MemOS]] 记忆操作系统和 [[memprivacy|MemPrivacy]] 隐私保护框架。

## 核心产品

### MemOS
记忆操作系统，将 Agent 记忆从向量库或 RAG 插件提升为可管理、可调度、可演化的系统资源。涵盖记什么、怎么检索、如何更新、如何治理等完整生命周期管理。

### MemPrivacy
面向端云协同 Agent 的隐私保护框架，是 MemOS 往端云协同场景自然延伸的隐私层。与 [[荣耀]] 联合研发，[[同济大学]] 参与其中。

## 技术理念

记忆张量的技术路线强调从 Agent 长期记忆的真实使用场景出发，而非从通用 PII 打码出发。MemPrivacy 的开发逻辑是：当 Agent 开始长期记住用户偏好、健康状态、账号凭证和工作上下文时，核心问题不只是"能不能记住"，而是"能不能安全地记住"。

## 合作生态

- 与 [[荣耀]] 深度合作，MemPrivacy 已在荣耀终端设备（MagicOS、YOYO 助手）上落地
- 与 [[同济大学]] 学术合作
- 模型仓库以 IAAR-Shanghai 名义发布于 Hugging Face
