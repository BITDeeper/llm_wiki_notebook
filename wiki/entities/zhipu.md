# 智谱

智谱（Zhipu AI）是中国领先的人工智能公司，专注于大模型研发与 Agent 应用落地。

## Agent 领域布局

### 产品化工具
智谱积极推动 AI Agent 的普及与易用性：
- **[[autoclaw]]**：针对 [[openclaw]] 安装门槛高的问题，推出了官方桌面封装版，通过一键安装和 [[飞书]] 集成，大幅降低了用户使用门槛。
- **[[autoglm-browser-agent]]**：自研的浏览器自动化引擎，相比开源基础方案，在处理复杂多步骤任务时表现出更强的稳定性。

### 模型研发
智谱针对不同场景推出了差异化模型：
- **[[pony-alpha-2]]**：专为 [[agent场景化模型]] 打造的模型，旨在解决通用大模型在长链路任务规划和工具调用中容易“掉链子”的问题。
- **GLM 系列**：包括 GLM-4.7、GLM-5 以及免费的 [[glm-4-7-flash]]，支持在 AutoClaw 等客户端中进行热插拔，兼顾性能与成本。

## 社区推广
智谱发起了“小龙虾敲门计划”，组织志愿者进入社区免费帮助普通人安装和配置 Agent 工具，体现了其推动 AI 技术大众化的战略意图。
