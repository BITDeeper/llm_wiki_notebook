# 彦火

歌手 [[胡彦斌]] 通过 [[vibe-coding|Vibe Coding]] 独立开发的粉丝社区 App。

## 开发背景

- **开发者**：胡彦斌（非专业程序员）
- **开发方式**：Vibe Coding，使用 Claude 连接 Mac 编程环境
- **开发周期**：约一个月
- **发布时间**：2026年5月前后

## 意义

彦火是 [[vibe-coding|Vibe Coding]] 赋能非技术人员完成完整产品开发的典型案例。胡彦斌从2024年开始自学编程，到2026年独立交付一款粉丝社区应用，展示了 Vibe Coding 降低软件开发门槛的实际效果。
