# Matrix-Game 3.0

Matrix-Game 3.0 是 [[天工AI]] 发布的AI游戏世界模型，旨在通过实时交互环境训练和验证世界模型能力。

## 核心特性
Matrix-Game 3.0 主要解决了世界模型从“视频生成”转向“可交互系统”过程中的两大难题：

### 1. 长时序一致性
- **问题**：传统模型在生成长视频时会“失忆”，导致场景变形或物体消失。
- **方案**：引入“记忆”机制。生成当前帧时，不仅参考最近几秒，还会根据视角从长视频中检索相关关键帧，并结合几何信息理解不同角度的对应关系。
- **效果**：实现了**分钟级**的长期记忆能力，确保长时间跨度下的场景一致性。

### 2. 高分辨率实时生成
- **性能指标**：在720P分辨率下，5B参数模型实现最高 **40FPS** 的实时生成。
- **技术手段**：
    - **减少步数**：大幅压缩推理步数。
    - **提前适应**：训练时模拟真实运行，让模型适应长时间运行的误差累积。
    - **边生成边纠偏**：在高速生成过程中进行自我校正。

## 技术意义
Matrix-Game 3.0 标志着世界模型从离线内容生成工具转变为在线交互系统。它不再仅仅是一个“视频生成器”，而是一个可以像游戏引擎一样运行的“可交互系统”。

## 开源与落地
- **开源**：模型代码已在 GitHub 和 Hugging Face 开源。
- **应用**：支撑新一代AI开放世界模拟游戏平台“[[猫森学园]]”。
