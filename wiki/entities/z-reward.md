# Z-Reward

Z-Reward 是由 [[阿里巴巴-z-image团队|阿里巴巴 Z-Image 团队]]与 [[南开大学]]联合提出的一种新型视觉奖励建模范式。

## 核心理念

Z-Reward 的核心论点是：**奖励模型不需要复现教师的推理过程，而要内化教师的判断能力。** 它将大模型级别的深度判断能力与高效、稳定的单 token 分布输出相结合。

## 技术架构

Z-Reward 分为两个关键阶段：
1. **教师阶段**：使用 [[qwen3-5|Qwen3.5-27B]] 作为教师模型，通过 [[gdso|GDSO（分组直接分数优化）]]训练，使其学会基于视觉证据和评分标准输出高质量的推理条件分数分布。
2. **学生阶段**：使用 [[qwen3-5|Qwen3.5-9B]] 作为学生模型，通过 [[risd|RISD（推理内化分数蒸馏）]]，直接对齐教师的分数分布，实现推理时仅需输出 1 个 token。

## 实验成果

- 9B 学生模型在 HPA 指标上达到 0.8864，逼近 27B 教师的 0.8956。
- 相比需要约 750 个 token 的 OPD（在线策略蒸馏），Z-Reward 仅需 1 个 token 即可实现更优性能。
- 作为 RL 优化信号应用于文生图模型后，在盲测中实现了 41.3% 的净人类偏好提升。
