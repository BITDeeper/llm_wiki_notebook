# Michael Arnaldi

**Michael Arnaldi** 是 Effectful Technologies 的创始人兼 CEO。他从 11 岁起开始编程，拥有从内核级开发到 TypeScript 高抽象层的广泛经验。他是 [[ralph-wiggum]] 现象的重要评论者，提出了“软件开发已死，工程重生”的著名论断。

## 核心观点

### 流程优于模型
Michael Arnaldi 指出，大多数开发者沉迷于模型之争（Claude vs GPT vs Gemini），但这完全搞错了重点。
- **关键在于流程**：一个中等模型配合优秀的流程，远远强于一个顶级模型配合混乱的流程。
- **Ralph 只是起点**：虽然 Ralph Wiggum 很强，但它只是更复杂的“智能编程基础设施”的入门。

### 软件开发已死，工程重生
他认为传统的“手写代码”行为将消失，取而代之的是“构建能写代码的系统”。
- **角色转变**：工程师不再是“写代码的人”，而是“构建能写代码的系统”的人（系统架构师）。
- **个体崛起**：一个人 = 过去一整个团队。个体正在变得前所未有地强大。
- **行业重构**：过去 40 年积累的最佳实践（团队结构、开发流程、技术栈选型）很多已经过时，需要重构。

## 实践案例
- 用 2 小时利用 Ralph 搞定了一个现代版 Bloomberg 终端简化版。
- 他的法律专业朋友（几乎 0 编程经验）靠和 Claude Code 聊天完成了 GDPR 合规检测工具。
- 计划开源一个符合美国 GAAP 标准的会计系统，仅用闲暇时间“Ralph 出来”。
