# Veo 3.1

[[谷歌]] 开发的视频生成模型，以其强大的 [[角色一致性]] 和 [[原生竖屏输出]] 能力著称。

## 核心功能

### 素材生视频
Veo 3.1 引入了“素材生视频”功能，允许用户上传静态图片（素材图片）作为基础，通过文本提示词生成动态视频。这一范式相比纯文本生成，提供了更高的可控性和叙事连贯性。

### 角色一致性
该模型在保持角色外观特征（如脸型、服饰）在不同场景和动作下的稳定性方面表现优异，被宣传为实现了“0变形”。这使得创作者可以轻松让同一角色穿梭于多个场景中讲述完整故事。

### 画质与格式
- **分辨率**：支持业界领先的 1080p 和 4K 超分辨率输出。
- **竖屏优化**：原生支持 9:16 竖屏视频生成，专为 [[youtube-shorts]] 等移动端短视频平台设计，避免了后期裁剪带来的画质损失。

## 生态整合
- **消费级应用**：集成于 YouTube Shorts 和 YouTube Create。
- **企业级 API**：通过 [[flow]]、[[gemini]] API 和 Vertex AI 向专业用户开放。

## 竞争地位
在 [[sora]] 等竞争对手面前，Veo 3.1 通过在移动端适配和角色一致性上的技术突破，确立了新的行业标杆。
