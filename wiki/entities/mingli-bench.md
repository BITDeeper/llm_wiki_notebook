# MingLi-Bench

[[destinylinker]] 研究团队基于术数大赛官方题库构建的术数推理评测基准，用于测试大模型在训练语料稀缺的垂直领域的推理能力。

## 数据来源

- 基于 [[hkjfma]] 主办的术数大赛官方题库
- 大赛共有 **3069名选手** 参与
- 题目形式为四选一专业术数选择题
- 几乎不存在信息泄漏风险（使用最新比赛题目）

## 评测设计

为公平考察推理能力而非计算能力：
- 所有基线模型的Prompt中提供 **预计算的盘面数据**
- 排除计算幻觉对评测结果的干扰
- 直接考察模型的专业术数推理能力

## 基线结果

| 模型类型 | 准确率范围 |
|---------|-----------|
| 主流通用大模型（Claude、GPT等） | 23%-40% |
| 随机猜测线（四选一） | 25% |
| [[tianfu-agent]] | 50% |
| 人类Top 20选手平均 | 53.5% |

通用模型准确率仅略高于随机线，表明在训练语料稀缺的垂直领域，单纯依赖模型推理能力远远不够。
