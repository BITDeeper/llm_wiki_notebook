# Claude Mythos 5.0

Claude Mythos 5.0 是 [[Anthropic]] 即将发布的下一代旗舰大语言模型，内部代号为 **Capybara**。它被定位为比 [[Opus 4.6]] 规模更大、更智能，但也更昂贵的“顶配级别”AI。

## 核心特性
- **代际提升**：在编程、逻辑推理以及 [[进攻性安全]]（Offensive Security）方面实现了跨代级提升。
- **内测状态**：已于 2026 年 3 月底开始灰度测试，出现在 Claude 和 Claude Code 的界面中。
- **市场预测**：Polymarket 预测其于 2026 年 6 月正式上线的概率高达 73%。

## 安全争议与推迟发布
Anthropic 迟迟未正式发布 Mythos 5.0，主要原因是出于安全考量。鉴于其在 [[零日漏洞]] 发现方面的强大能力（如 90 分钟内攻破 Linux 内核），官方担心该模型会被恶意行为者用于发起大规模、破坏力极强的网络攻击，而目前的防御手段难以跟上。

## 与前代对比
虽然 [[Opus 4.6]] 已展现出惊人的代码审计能力（如发现 Ghost CMS 和 Linux 内核漏洞），但 Mythos 5.0 被内部视为“最高层级”的 AI，其能力边界可能已触及现有安全防御的极限。
