# Pelican-Unify 1.0

Pelican-Unify 1.0 是[[北京人形机器人创新中心]]发布的全球首个在理解、推理、想象、行动维度同时达到顶尖水平的统一具身智能模型（UEI），作为[[慧思开物]]平台的认知内核。

## 架构设计

### 核心理念
Pelican-Unify 1.0 的统一不是"把几个模块输出拼在一起"，而是结构上共享表征、相互约束条件、以同一个训练过程共同演化。实现理解、推理和生成三类统一。

### 两大紧耦合组件

1. **视觉-语言模型（VLM）**：基于 Qwen3-VL 4B 初始化，承担统一理解与统一推理。
   - 接收多模态上下文 c_t（过去观测序列、历史动作序列、当前语言指令），统一编码进共享语义空间。
   - 自回归生成思维链推理迹 τ_t，编码任务意图、物理约束、未来后果与动作选择。
   - 取最后一层隐状态通过投影层压缩为稠密潜变量 z。

2. **统一未来生成器（UFG）**：基于 Wan2.2-5B 初始化的扩散 Transformer（DiT），承担统一生成。
   - 以 z 为条件，在同一个去噪过程中联合生成未来视频帧和低层动作序列。
   - 视频 token 和动作 token 在去噪过程的每一步都在同一空间中相互感知、相互约束。
   - DiT 主干共享，只有输入嵌入和输出头是模态专属的。

### 共享稠密潜变量 z
z 是整个架构的关键耦合点，不只针对语言建模优化，还被下游的视频和动作生成损失持续施压，被迫同时编码"物理世界将如何演化"和"应当执行什么动作"所需的信息。

### 三路损失
- 语言推理损失 𝓛_text（自回归负对数似然）
- 视频流匹配损失 𝓛_video（连续时间 flow matching）
- 动作预测损失 𝓛_action（SmoothL1 鲁棒回归）

三路损失共同作用于同一表征 z，推理、想象、行动的一致性通过梯度博弈自然涌现。
