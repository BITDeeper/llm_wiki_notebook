# Spider-Sense

**Spider-Sense** 是一个由 [[上海财经大学]]、[[新加坡国立大学]] 和 [[卡耐基梅隆大学]] 联合研发的智能体安全防御框架。其核心设计理念是赋予 AI 智能体类似“蜘蛛感应”的原生风险直觉，从而在几乎不增加延时的前提下实现全链路安全防护。

## 核心特性

Spider-Sense 旨在解决传统 Agent 防御机制（如 [[guardagent]]、[[agrail]]）中存在的“安全与效率”二元对立问题。传统方法通常采用强制外部检查，导致延时高达 200% 以上。Spider-Sense 通过以下机制将防御延时降至 **8.3%**：

### 1. 内源性风险感知 (IRS)
*   **原理**：通过指令微调将安全意识直接植入 Agent 的推理逻辑中，使其具备类似直觉的“原生”风险探测能力。
*   **覆盖范围**：全生命周期监控，包括 Query（指令）、Plan（规划）、Action（行动）、Observation（观察）四个阶段。
*   **触发机制**：Agent 只有在感知到特定风险时，才会生成特殊的 [[感知信号]]（如 `<audit_action_parameters>` 或 `<sanitize_observation>`）来触发防御，从而在绝大多数安全交互中保持零延时。

### 2. 分层自适应筛选 (HAS)
*   **粗粒度筛选**：利用向量检索技术，将可疑内容与 [[攻击向量数据库]] 中的已知模式进行快速比对。
*   **细粒度分析**：对于难以判断的模糊案例，调用 LLM 进行深度推理和对比分析，确保高精度的威胁识别。

## 性能表现

在 [[s2bench]] 基准测试及主流数据集（如 [[Mind2Web]]、[[EICU]]）上，Spider-Sense 展现了卓越的性能：
*   **效率**：相比基线模型 197%-381% 的延时，Spider-Sense 的额外延时仅为 **8.3%**。
*   **安全性**：实现了最低的攻击成功率（ASR）。
*   **可用性**：实现了最低的误报率（FPR），避免误伤合法操作。

## 应用场景

Spider-Sense 特别适用于需要高安全性且对响应速度敏感的复杂 Agent 系统，例如：
*   **医疗分析 Agent**：能够有效拦截 [[工具返回注入]] 攻击，防止恶意代码执行。
*   **自动化运维**：在执行高风险操作时提供实时的参数审计和结果清洗。
