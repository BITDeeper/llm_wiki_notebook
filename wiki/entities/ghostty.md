# Ghostty

[[Ghostty]] 是一款现代、高性能的开源终端模拟器，由 [[Mitchell Hashimoto]] 开发。它支持 macOS 和 Linux 平台，使用 Zig 和 Swift 编写。因其出色的性能和设计，Ghostty 在发布一年内就在 [[GitHub]] 上获得了超过 5 万颗星，是近年来最受关注的开源终端项目之一。

## 技术特点

- **高性能**：利用 GPU 加速渲染，提供流畅的滚动和显示体验。
- **跨平台**：原生支持 macOS 和 Linux。
- **现代技术栈**：使用 Zig 语言（系统级编程）和 Swift（macOS 原生开发）构建。

## 迁移事件

2026 年 4 月至 5 月间，因 [[GitHub]] 频繁宕机（特别是 GitHub Actions 服务中断）导致开发工作严重受阻，Mitchell Hashimoto 公开发表"绝交信"，宣布将 Ghostty 的主仓库迁离 GitHub。Hashimoto 直言平台"每天都把你锁在外面几个小时"，使得严肃的开发工作无法进行。

原仓库保留为只读镜像，Ghostty 打包所有资产整体迁移至其他平台。这一迁移是 [[GitHub 宕机事件 (2026)]] 的一部分，也是 [[去github化]] 运动中的标志性事件——Ghostty 作为拥有极高人气和活跃度的明星项目，其出走引发了社区对 GitHub 可靠性和信任危机的广泛讨论。
