# Matrix-Game 3.0

Matrix-Game 3.0 是 [[天工AI]] 发布的开源游戏世界模型，旨在解决现有世界模型在长时序生成中的「失忆症」问题。

## 核心突破
该模型主要解决了世界模型在生成长序列或视角大幅度移动后，无法保持场景一致性（如物体消失、地形改变）的痛点。

## 技术架构
1.  **记忆注入**：
    模型在生成当前画面时，不仅依赖最近几帧，还会根据相机位姿检索更早期的「记忆帧」，将其放入同一个注意力空间进行联合建模。这使得模型能够「记住」走过的路和看过的场景。

2.  **Error Buffer 抗漂移**：
    针对长时序生成中状态逐渐偏离真实的问题，模型在训练时显式建模生成结果与真实帧之间的误差，并将误差作为条件重新注入，迫使模型学会自我纠正。

3.  **蒸馏加速**：
    采用多段自回归蒸馏框架，配合模型量化和 VAE 解码器蒸馏，使得 5B 参数的模型能够在 720P 分辨率下达到 40FPS 的实时生成速度。

## 行业影响
- 其上一代 Matrix-Game 2.0 是该技术范式首个开源实现，被 Yann LeCun 创办的 AMI 公司选为 Solaris 模型的技术底座。
- Matrix-Game 3.0 在记忆、分辨率和实时性上全面超越 2.0，是目前与 Google DeepMind Genie 3 齐头并进的方案。
