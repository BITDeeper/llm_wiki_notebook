# MiniMax M2.1

**MiniMax M2.1** 是 MiniMax 系列大语言模型的一员，在 [[PinchBench]] 的成功率榜单中排名第二（93.6%），仅次于 [[Gemini 3 Flash]]。

## 性能特点
*   **高成功率**：在 PinchBench 的 23 个真实任务测试中表现出色，展现了强大的任务执行能力。
*   **价格劣势**：虽然性能优异，但在价格方面，其输入价格约为 2.1 元/百万 tokens（约 0.3 美元），输出价格约为 8.4 元/百万 tokens（约 1.2 美元），是 [[GPT-5-nano]] 价格的三倍左右。

## 评价
M2.1 的表现证明了国产模型在 Agent 任务执行能力上已达到国际领先水平，但在成本控制方面仍面临挑战。
