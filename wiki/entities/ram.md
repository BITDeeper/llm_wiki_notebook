# RAM (Read As HuMan)

**RAM** (Read As HuMan) 是一个由[[清华大学]]、[[鹏城实验室]]与[[阿里巴巴未来生活实验室]]联合提出的长上下文压缩框架。它通过模仿人类“精读”与“略读”的混合阅读策略，实现了在保留关键信息的同时大幅提升推理效率。

## 核心特性
- **认知启发式设计**：首次将人类阅读中的“精读+略读”策略算法化，对高相关内容保留原文，对低相关内容进行语义压缩。
- **极致效率**：通过并行编码规避了[[二次计算复杂度]]，在平均 1.6 万 token 输入下实现 12 倍端到端加速。
- **去噪效应**：实验表明，适当的压缩（如 4x）反而能提升模型在问答任务上的表现（EM 分数从 32.77 提升至 66.59），证明压缩过程起到了去除噪声的作用。
- **长度外推能力**：训练长度仅 2 万 token，但在 3.2 万 token 的测试集上表现优异，显示出强大的泛化能力。

## 技术架构
RAM 的处理流程包含三个核心部分：
1.  **精读区**：保留与查询高度相关的原始文本片段，维持自然语言的可解释性。
2.  **略读区**：利用[[查询引导压缩]]技术，将低相关片段转化为单个语义向量。
3.  **混合表示**：将精读文本与略读向量按原顺序拼接，输入给大模型进行推理。

## 应用场景
RAM 特别适合需要处理长文档但算力或延迟敏感的场景，例如：
- [[本地推理]]设备上的长文档分析。
- 需要实时响应的 RAG（检索增强生成）系统。
- 高吞吐量的企业级知识库问答。
