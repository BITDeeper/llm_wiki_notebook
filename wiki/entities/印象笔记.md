# 印象笔记

印象笔记是一款知名的知识管理工具（SaaS 产品）。在 Agent 时代的讨论中，它被视为可能被 [[Skill]] 化和 [[APP]] 解构浪潮影响的典型代表。

## 面临的挑战
- **功能解构**：其核心的笔记捕捉、整理和检索功能可能被拆解为独立的 Skill，直接嵌入用户的个人 Agent 工作流中，不再需要打开 APP。
- **交互变革**：从“面向人的笔记界面”转向“面向 Agent 的数据存储与检索接口”。
