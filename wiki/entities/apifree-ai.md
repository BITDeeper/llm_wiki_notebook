# ApiFree.ai

ApiFree.ai 是一个 AI 模型聚合服务平台，提供 OpenAI 兼容 API 接口的调用服务。用户注册账号并创建 API Key 后即可免费调用 [[skyclaw-v1|SkyClaw-v1.0]] 和 [[skyclaw-v1-lite|SkyClaw-v1.0-lite]]（限时免费试用）。

## 功能特性

- 提供 OpenAI 兼容 API 接口
- 支持流式输出、工具调用、多轮对话等核心功能
- 免费注册获取 API Key 即可调用
