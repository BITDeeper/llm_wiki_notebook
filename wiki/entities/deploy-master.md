# Deploy-Master

[[Deploy-Master]] 是由 [[深势科技]] 开发的以执行为中心的一站式自动化工作流系统，旨在解决科学计算领域长期存在的软件部署难题。

## 核心功能
该系统主要解决科学软件因依赖冲突、环境不兼容、文档缺失等原因导致的“无法开箱即用”问题，从而提升科学研究的可复现性和效率。

## 系统架构
Deploy-Master 包含两个核心 Agent 组件：

### 1. Search Agent
负责从海量代码仓库中发现和筛选科学工具。
-   **学科空间构建**：基于 91 个科学与工程领域扩展关键词。
-   **迭代扩展**：利用依赖关系、引用关系等信号进行扩展，避免关键词搜索盲区。
-   **规模**：从约 50 万个仓库中筛选出 52,550 个候选工具。

### 2. Build Agent
负责处理复杂的构建环境，生成并验证可执行规格。
-   **信息处理**：系统遍历仓库中的构建线索，处理零散、过时或矛盾的文档。
-   **[[双模型辩论]]**：引入两个 AI 模型，一个提出构建方案，另一个进行审查和找茬。通过多轮交互修正方案，显著提升了构建规格的准确性。
-   **验证**：通过“最小可执行命令”进行最终验证。

## 成果数据
-   **部署数量**：成功部署 **50,112** 个工具。
-   **成功率**：通过双模型辩论机制，构建成功率从 50%-60% 提升至 **95%** 以上。
-   **语言覆盖**：覆盖 170 多种编程语言。
-   **效率**：大多数工具构建时间约 7 分钟。

## 设计哲学
系统遵循 [[以执行为中心]] 的原则，认为工具是否“真的能跑”是 [[Agentic Science]] 的第一性问题。它为 AI Agent 提供了稳定的 **Action Space**（动作空间），使得 Agent 的规划、执行与学习闭环得以成立。

## 局限与挑战
尽管解决了单机软件的部署问题，但异构硬件、分布式计算、语义级 I/O 及物理实验闭环集成仍是未解难题。
