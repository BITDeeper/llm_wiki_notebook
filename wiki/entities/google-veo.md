# Google Veo

**Google Veo** 是 [[google-deepmind]] 开发的高清视频生成模型。在 2026 年 2 月的 [[image-to-video-arena]] 排行榜中，其版本 Veo-3.1-audio-1080p 以 1402 ELO 评分位居第二，仅次于 [[grok-imagine]]。

## 竞争态势
尽管 Veo 模型在视频生成质量上表现强劲，但在用户偏好盲测中被 xAI 的 Grok Imagine 超越。此外，第三方评测指出 Grok 在 API 成本和生成延迟上相比 Veo 具有一定优势。

## 版本
- **Veo 3.1 Fast**：侧重于生成速度的版本。
- **Veo-3.1-audio-1080p**：支持原生音频和 1080p 分辨率的旗舰版本。
