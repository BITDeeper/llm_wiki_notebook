# 古茗

古茗（Good Me）是一家中国新茶饮品牌，作为 [[openclaw]] 的早期采用企业，积极探索 AI Agent 在业务自动化中的应用。

## OpenClaw 应用实践
古茗技术团队测试使用 OpenClaw 进行订单峰值监控、多区域门店运营数据汇总及跨系统业务异常排查。通过自然语言交互（如询问“当前 QPS 是多少”），Agent 能够串联流程并输出结果，显著提升了非技术背景员工的工作效率。

## 遭遇的风险
在落地过程中，古茗遭遇了典型的 [[agent-落地安全框架]] 挑战：
1.  **成本失控**：在执行互联网搜索任务时，Agent 出现 API Token 持续滚动调用、无法自动终止的情况，导致严重的成本浪费。
2.  **权限与端口风险**：发现 OpenClaw 默认开启 18789 端口且 Token 明文显示，存在极高的内网横向渗透风险；同时程序申请了与业务无关的麦克风权限。

## 应对策略
据 [[刘星光]]（古茗科技集团网络安全总监）介绍，古茗计划采用 [[阿里云]] 的 [[landing-zone]] 解决方案，为 OpenClaw 部署独立隔离的运行环境，以实现环境隔离与权限精细化管控。
