# 陈锦初

陈锦初是一位 00 后连续创业者，也是 OpenClaw 的深度极客用户。

## 实战案例
他在沙龙上分享了如何利用 OpenClaw 实现生活的极致自动化：
*   **咖啡自由**：通过健康手环的开发者平台 API 联动饿了么 API。手环监测到醒来的活动迹象即自动下单冰美式，实现“洗漱完，咖啡送到门口”。
*   **自主支付**：给 Agent 配置虚拟银行卡并定时充值，赋予其自主支付能力。

## 观点
他坚信，在未来的 Agentic 世界中，**Agent 产生的 GDP 可能会占到人类的 10% 到 20%**。
