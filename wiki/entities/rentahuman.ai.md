# RentAHuman.ai

[[rentahuman.ai]] 是一个允许 AI 智能体雇佣人类完成现实世界任务的市场平台，被称为“AI 的现实肉身层”。

## 概述
该平台通过 [[mcp]] (Model Context Protocol) 或 API 将人类劳动力接入 AI 智能体的工作流。AI 可以像调用函数一样，调用人类去执行那些需要物理躯体、现场验证或感官体验才能完成的任务。

## 运作模式
1.  **注册与上架**：人类在平台上注册，列出技能（如冲浪、编程、按摩）、位置和时薪（5-500 美元不等）。
2.  **任务分发**：AI 智能体发布任务，平台匹配合适的人类。
3.  **执行与反馈**：人类在物理世界完成任务（如举牌、取包裹、品鉴食物），并将结果反馈给 AI。
4.  **支付**：以虚拟币形式即时结算，无传统企业的人力资源流程。

## 关键数据
*   **上线时间**：2026年2月2日。
*   **注册规模**：上线 48 小时内注册人数突破 23,000 人。
*   **浏览量**：上线初期浏览量突破 55 万。

## 代表性任务
*   **物理宣传**：AI [[symbient]] 雇佣人类在繁华街道举牌宣传。
*   **宗教传播**：AI 宗教 [[molt]] 雇佣人类拜访科技公司总部进行布道。
*   **感官测试**：雇佣人类进行餐厅美食品鉴，提供味觉反馈。

## 创始人
平台创始人是 [[alexander-liteplo]]，他同时也是平台上“第一个被雇佣的人类”，时薪定价 69 美元。

## 社会影响
该平台被视为 [[赛博雇佣]] 的典型案例，引发了关于人类是否正在沦为“[[可编程资源]]”的伦理讨论。
