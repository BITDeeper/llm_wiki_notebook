# F.03

F.03 是 [[figure]] 公司旗下的人形机器人产品，在2026年5月的直播事件中首次在真实工业任务中实现了超100小时连续自主运行。

## 性能参数

| 指标 | 数值 |
|------|------|
| 单次分拣速度 | 约2.83秒/个 |
| 连续运行时长 | 超100小时（截至报道时仍在继续） |
| 累计分拣包裹 | 超13万个 |
| 驱动系统 | [[helix-02]] 端到端神经网络 |
| 遥操作 | 全程零遥操作 |

## 核心能力

- **自主分拣**：通过头部摄像头识别条码，抓取包裹，将条码面朝下翻转放上传送带
- **自主容错**：出现软件或硬件问题时，自主离开工位前往维修区，另一台自动顶上
- **自动复位**：遇到超出训练分布的情况时，Helix 触发自动复位，回到初始状态重新执行

## 人机对决表现

在10小时人机对决中：

| 选手 | 分拣数量 | 平均速度 |
|------|----------|----------|
| 人类（Aime） | 12,924个 | 2.79秒/个 |
| F.03 | 12,732个 | 2.83秒/个 |

差距仅192个包裹、0.04秒/个。人类付出了左前臂接近"报废"的代价，而 F.03 状态无衰减。

## 已知局限

直播中也暴露了一些问题：
- 偶尔出现原地发呆的情况
- 存在丢包裹的现象
- 某些动作看起来不够自然（如抬手避让被误认为遥操作）

## 轮班机制

直播中使用了四台 F.03 轮班，网友分别命名为 Bob、Frank、Rose、Gary。容错机制允许单台故障时自主前往维修区，另一台自动顶上，最大化整体在线时间。
