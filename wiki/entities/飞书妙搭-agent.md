# 飞书妙搭 Agent

[[飞书]] 旗下的低代码/无代码开发 Agent，能够通过自然语言描述自动生成完整的应用程序。

## 核心能力

### Prompt-to-App
飞书妙搭 Agent 实现了 [[prompt-to-app]] 的开发范式。用户只需用自然语言描述需求，Agent 即可自动完成从概要设计、开发计划到代码执行的全过程。

### 工作流程
1. **概要设计**：根据用户的 Prompt，Agent 首先生成应用的概要设计方案。
2. **开发计划**：制定详细的开发步骤和工具调用计划。
3. **自动执行**：Agent 按照计划自主决策并调用相应工具进行开发，全程无需人工干预（仅需偶尔确认）。

## 实测案例
在相关报道中，通过一段 Prompt 描述“狼人杀”游戏规则，飞书妙搭 Agent 自动生成了一个包含完整 UI 和逻辑的游戏应用，并支持一键发布到应用广场。

## 产品定位
飞书妙搭 Agent 极大地降低了软件开发的门槛，使得不懂代码的业务人员也能快速搭建业务系统，是飞书 Agent 生态中实现“行动”能力的关键一环。
