# Trusted Access for Cyber

[[Trusted Access for Cyber]] 是 [[OpenAI]] 围绕其网络安全模型 [[GPT-5.3-Codex]] 推出的访问控制计划。该计划采用邀请制，旨在将强大的网络攻防能力限制在可信的防御性研究机构手中。

## 计划详情

- **邀请制准入**：仅对经过筛选的合作伙伴和安全研究机构开放。
- **资金支持**：OpenAI 承诺投入 1000 万美元的 API 额度，以支持正当的防御性研究。
- **防御导向**：明确强调该计划仅用于防御目的，禁止用于攻击性研发。

## 战略意图

该计划是 OpenAI 应对 [[AI 网络攻防能力]] 不可逆扩散的一种风险管理策略。通过建立“可信通道”，OpenAI 试图确保最前沿的攻防技术优先服务于防守方（如电网、银行等关键基础设施的防护），从而延缓恶意攻击者获取同等能力的时间窗口。

## 与 Project Glasswing 的对比

与 [[Anthropic]] 的 [[Project Glasswing]] 类似，两者都代表了 AI 巨头对高危模型能力的管控尝试。不同之处在于，OpenAI 的计划更侧重于通过资金和资源引导防御生态的建设，而 Anthropic 更侧重于封闭环境下的技术验证。
