# Ross Taylor

Papers with Code 创始人。

## 关键信息

- 创建了 Papers with Code 平台（2018年7月上线）。
- 2019年12月随平台被 [[meta-ai]] 收购。
- 在平台关闭后解释了关闭原因：团队被收购后转型从事大模型研究，能花在 Papers with Code 的时间越来越少，且大量成员已经离开 Meta，最终无法继续维护。
