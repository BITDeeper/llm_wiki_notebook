# AdaSEKA

**AdaSEKA** (Adaptive SEKA) 是 [[SEKA]] 算法的自适应变体，旨在解决标准 SEKA 投影矩阵固定、面对不同任务可能需要手动调参的问题。

## 核心机制：多专家路由

AdaSEKA 引入了 [[多专家路由]] 机制，使得模型能够根据当前的 Query 向量动态组合不同的引导算子。

### 工作流程
1. **专家学习**：针对不同类型的任务（如事实校正、指令遵循等），分别学习多组“专家投影”子空间。
2. **动态权重**：在推理时，计算 Query 向量与各专家子空间的对齐程度，自动生成动态权重。
3. **实时组合**：根据权重实时组合出最适合当前提示的引导算子。

## 优势

- **零训练推理**：路由机制无需额外训练，计算代价极低。
- **模块化扩展**：新的专家可以随时加入，无需重新计算已有专家。
- **降低调优负担**：显著减少了针对特定任务调整超参数的需求。

## 应用场景

AdaSEKA 特别适合需要处理多种异构任务的复杂系统，能够自动适应不同的注意力引导需求。
