# Kilo AI

**Kilo AI**（亦称 Kilo.ai）是一家专注于 Agent 基础设施开发的创业团队，由 GitLab 前联合创始人兼 CEO [[Sid Sijbrandij]] 投资并参与创立。团队同时承担 AI 评测机构的角色，发布了具有行业影响力的评测基准。

## 主要产品

### Kilo Code
一款主打"[[氛围编程]]"的开发工具，曾一度爆火。

### KiloClaw
基于 [[OpenClaw]] 构建的全托管智能体平台。在 [[OpenClaw]] 爆火后，Kilo AI 推出了该平台以降低用户使用 Agent 的门槛。

### PinchBench
伴随 KiloClaw 发布的 Agent 综合能力评测基准，用于评估不同大模型在 OpenClaw 上的适配程度。任务覆盖代码开发、创意写作、文档处理、会议管理、内容转换、文件操作等多个领域。因任务设计贴近真实业务场景、评估维度全面，已成为衡量 Agent 执行能力的重要参考。

#### PinchBench 已知成绩

| 模型/系统 | 得分 | 备注 |
|---|---|---|
| [[jiuwenswarm]] | 94.2% | SOTA |
| [[openclaw]] | 91.6% | 对比基准 |

## 行业定位

Kilo AI 致力于解决 Agent 时代的工程化问题，通过提供评测基准和托管平台，帮助开发者在模型性能、速度和成本之间找到最佳平衡点。
