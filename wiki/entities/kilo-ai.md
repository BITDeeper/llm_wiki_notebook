# Kilo AI

**Kilo AI** 是一家专注于 Agent 基础设施开发的创业团队，由 GitLab 前联合创始人兼 CEO [[Sid Sijbrandij]] 投资并参与创立。

## 主要产品

### Kilo Code
一款主打“[[氛围编程]]”的开发工具，曾一度爆火。

### KiloClaw
基于 [[OpenClaw]] 构建的全托管智能体平台。在 [[OpenClaw]] 爆火后，Kilo AI 推出了该平台以降低用户使用 Agent 的门槛。

### PinchBench
伴随 KiloClaw 发布的智能体框架评测工具，用于评估不同大模型在 OpenClaw 上的适配程度。

## 行业定位
Kilo AI 致力于解决 Agent 时代的工程化问题，通过提供评测基准和托管平台，帮助开发者在模型性能、速度和成本之间找到最佳平衡点。
