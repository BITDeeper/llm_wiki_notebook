# TuriX

TuriX 是一家成立于 2025 年 2 月的 AI 初创公司，以其“全球最年轻 00 后团队”的标签和推出的工业级 Agent 产品 [[TuriX Superpower]] 而受到关注。公司致力于解决 AI 领域“云端智力溢出，物理执行贫血”的痛点，通过技术手段打通决策与执行的“最后一公里”。

## 核心团队
- **[[Kevin]]**：联合创始人兼 CEO，拥有多年管理经验，负责确保 Agent 能切实解决日常运营难题。
- **[[Tony Yan]]**：联合创始人兼 CTO，剑桥大学工程硕士，负责带领团队攻克 AI 架构的核心技术难题。

## 产品与技术
TuriX 的核心产品是 [[TuriX Superpower]]，这是一个集成了 Chat、Work、Code、CUA 四大能力的工业级 Agent。其技术基石是开源的 [[TuriX-CUA]] 框架，该框架基于 Python 开发，采用了 [[Planner+Executor 架构]]。

## 理念
TuriX 提出了“[[万物 CLI 化]]”的产品理念，旨在将复杂的图形界面操作转化为类似命令行（CLI）的确定性指令执行逻辑。公司强调 Agent 的终极使命不是成为“健谈的同伴”，而是成为执行人类意志的精密仪器，即从“Chatty Companion”转向“Silent, Capable Tool”。

## 市场定位
TuriX 将自身定位为工业级生产力工具，强调安全性、易用性和高成功率。文章指出其产品在桌面自动化基准测试中表现出远超行业平均水平的成功率，且相比 [[OpenClaw]] 等竞品，在安装门槛和隐私保护方面具有优势。
