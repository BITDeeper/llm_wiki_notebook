# VirBench

首个系统量化生物学Agent数据检索瓶颈的评测基准，由[[laura-luebbert|Laura Luebbert]]及研究团队构建，用于评估生物医学智能体的检索准确率。

## 基本构成

- **任务数量：** 120个真实风格病毒序列查询任务
- **覆盖范围：** 40种病原体
- **答案标准：** 配有人工验证的标准答案
- **任务来源：** 病毒监测、诊断试剂设计、蛋白模型训练数据构建等实际场景

## 典型任务示例

从NCBI检索TaxID 3052462对应的Zaire ebolavirus序列，需满足：宿主是人类、采样地点在非洲、采样时间在2014年1月1日至6月20日之间、序列长度至少15200个碱基、模糊字符N不超过1900个、排除实验室传代样本。

## 评测结果

无专用检索层时，各系统准确率在16.9%–91.3%间散布：

| 模型 | 平均准确率 |
|------|-----------|
| Claude Sonnet 4 | 较低 |
| Claude Opus 4.7 | 中等 |
| GPT-5.2-pro | 中等 |
| GPT-5.5 | 91.3%（最高） |
| Biomni | 较低 |
| Edison Analysis | 较低 |

无一稳定达到科学所需的近100%标准。

接入[[gget-virus]]确定性工具后，所有模型准确率提升至90%以上，GPT-5.5达99.7%。

## 关键发现

- **结果不稳定：** 同一模型在相同提示词下重复运行三次，结果差异极大（Claude Sonnet 4三次分别返回106、15、5条序列，标准答案266条）
- **下游分析偏差：** 不完整数据集导致严重错误——埃博拉病毒TMRCA从2014年错误推至1922年，偏差达90年
- **确定性工具的必要性：** 加入[[gget-virus]]后，所有模型准确率均突破90%，表明瓶颈不在模型能力，而在数据基础设施
