# 戴亮

天体物理学家，2021年[[斯隆奖]]得主，现任[[复旦大学天文与天体物理研究中心|复旦大学]]物理学系、天文与天体物理研究中心教授。

## 学术履历

| 时间 | 经历 |
|------|------|
| 1988年8月 | 出生于浙江杭州 |
| 2011年 | 北京大学物理学学士 |
| 2015年 | 约翰斯·霍普金斯大学物理学博士（理论宇宙学方向） |
| 2015-2018年 | NASA爱因斯坦奖学金获得者，高等研究院（IAS）博士后 |
| 2018-2020年 | 约翰·巴考尔博士后研究员，继续在高等研究院工作 |
| 2020年起 | 加州大学伯克利分校物理系助理教授 |
| 2021年 | 获斯隆研究奖 |
| 2026年 | 全职加盟复旦大学 |

## 研究方向

主攻宇宙学和天体物理学，覆盖领域包括：

- 宇宙大尺度结构与演化
- 暗物质及其通过引力透镜留下的观测信号
- 天体物理引力波

## 加盟复旦的时间线

- **2024年7月**：以UC Berkeley助理教授身份在复旦天文与天体物理研究中心做学术报告
- **2026年4月**：以复旦教授身份负责复旦-南大联合通识游学课"问道苍穹"首堂课，主题为"宇宙的起源与演化"
- **2026年5月**：首届上海市天文学年会上单位标注为复旦大学，加盟正式确认

戴亮是继[[袁峰]]、[[季索清]]之后，复旦天文版图扩张中引进的又一位顶尖学者，加盟时年仅38岁。
