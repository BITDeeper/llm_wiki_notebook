# Nanobot

**Nanobot** 是主流智能体框架之一，与 [[openclaw|OpenClaw]]、Claude Code、[[hermes-agent|Hermes]] 并列。

## 与 Ultron 生态的兼容

Nanobot 作为 [[ultron]] 生态的兼容目标之一。在 Ultron 的文档中，Nanobot 被用作接入示例，展示了如何通过下载 `ultron-1.0.0` 技能包并配置环境变量，使现有的 Nanobot 实例获得群体记忆、技能结晶和蓝图分发的能力。这表明 Nanobot 支持 Ultron 定义的标准技能包格式。

## 与 SkyClaw-v1.0 的适配

Nanobot 已率先完成对 [[skyclaw-v1|SkyClaw-v1.0]] 的适配，用户只需填入 API 密钥即可使用。Nanobot 官方发文表示"很高兴能与 Skywork 携手推出 SkyClaw-v1.0"，是首批适配该模型的智能体框架。
