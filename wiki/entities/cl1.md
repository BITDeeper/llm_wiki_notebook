# CL1

CL1 是由 [[Cortical Labs]] 发布的“世界首台可编程生物计算机”。

## 硬件构成
CL1 的核心是一块 [[高密度多电极阵列]]（HD-MEA）芯片，上面生长着约 20 万个活体人类神经元（来源于人类诱导多能干细胞）。

## 可编程性
与传统生物实验设备不同，CL1 被设计为一台通用的“计算机”。Cortical Labs 为其开发了标准的 API 接口，允许用户通过简单的 Python 命令与芯片上的活细胞进行实时交互。这意味着开发者无需具备深厚的神经生物学背景，即可编写代码来训练和塑造神经元的行为。

## 应用验证
CL1 已被用于运行复杂的电子游戏（如《毁灭战士》），证明了其作为通用计算平台的潜力。独立开发者利用其开放的 API，在不到一周的时间内就完成了游戏适配，展示了该平台在开发效率和可复现性上的优势。

## 目标
CL1 旨在探索生物神经元在处理复杂任务时的独特能力，特别是在 [[样本效率]] 和能耗控制方面，为未来 [[具身智能]] 和新型计算架构提供硬件基础。
