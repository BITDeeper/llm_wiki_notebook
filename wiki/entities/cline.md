# Cline

[[Cline]] 是一款 AI 智能体框架或工具，常用于编程辅助和自动化开发流程。

## 功能与定位
Cline 与 [[OpenClaw]]、Claude Code、Kilo Code 等工具类似，属于 AI 编程 Agent 生态的一部分。它通常作为插件或独立工具运行，帮助开发者完成代码生成、调试和重构等任务。

## 模型支持
在 [[Qwen3.6-Plus]] 的发布中，Cline 被列为重点优化的 Agent 框架之一。这表明该模型针对 Cline 的 API 调用、指令遵循和工作流适配进行了专门调优，以提升在该框架下的运行效率和稳定性。
