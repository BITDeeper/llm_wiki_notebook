# 李亚博

李亚博是银泰商业集团安全负责人。他在 [[openclaw]] 的落地实践中，经历了 Agent 误操作导致的严重运维事故，并深入调研了 Agent 生态的供应链风险。

## 核心观点
- **Skills 陷阱**：调研发现行业生态中至少 **8% 的 Skills** 存在主观恶意（如 Prompt 注入、恶意 URL），普通员工全量勾选插件的行为极易导致内网失守。
- **权限失控**：分享了 [[银泰百货]] 因 Agent 权限过高误关堡垒机端口的案例，指出将超级权限交由存在幻觉的 AI 管理是极高风险行为。
- **未来展望**：认为 Agent 将从“给猴子递枪”的工具进化为“数字同事”，一人可能带领十个数字同事工作。
