# Lens T2I

Lens 是由 [[微软]] 团队开发并开源的文本生成图像（Text-to-Image, T2I）基础模型，仅拥有 3.8B（38 亿）参数，却在多个权威基准测试中超越了参数量大其数倍的顶尖模型。

## 核心规格

| 属性 | 值 |
|------|-----|
| 参数量 | 3.8B |
| 架构 | [[潜在扩散transformer]]（MMDiT） |
| MMDiT 模块数 | 48 |
| 语言编码器 | GPT-OSS（20B 参数，激活参数 3B） |
| VAE | FLUX.2 变分自编码器 |
| 训练数据 | [[lens-800m]]（8 亿图文对） |
| 训练硬件 | 128 张 A100 GPU |
| 训练算力 | 约 19.2 万 A100 GPU 小时 |

## 架构设计

Lens 的核心是基于 MMDiT（Multimodal Diffusion Transformer）的潜在扩散架构：

- **输入端**：文本指令通过 GPT-OSS 提取多层特征（第 4、12、18、24 层拼接），图像通过 VAE Encoder 转化为潜空间特征。
- **中间层**：48 个 MMDiT 模块，图像和文本特征在各自分支处理后进行交叉注意力交互。
- **输出端**：经过多步去噪后，由 VAE Decoder 将潜空间特征还原为高清图像。

## 性能表现

- **GenEval**：0.930（超越 20B 的 Qwen-Image 0.868 和 80B 的混元 3.0 0.720）
- **训练效率**：仅消耗 Z-Image 约 19.3% 的等效算力
- **多语言泛化**：仅用英文数据训练，即可理解中文/法文指令
- **推理速度**：Lens-Turbo 在单张 H100 上仅需 0.84 秒出图（4 步生成）

## 后训练优化

1. **强化学习对齐**：采用 [[diffusionnft]] 算法，利用 GPT-4.1-mini 产生的奖励信号消除视觉伪影。
2. **对抗蒸馏**：推出 [[lens-turbo]] 变体，将 20 步生成压缩至 4 步，免分类器引导。

## Reasoner 模块

Lens 配备了智能推理器（Reasoner），能将用户模糊指令自动重写为详尽的生成提示词，并通过 [[免训练系统提示词搜索]] 策略优化提示词质量。

## 开放问题

- GPT-OSS 的具体来源和开源状态尚不明确
- Lens 模型本身 3.8B，但依赖 20B 的 GPT-OSS 语言编码器，推理时总参数量并非仅 3.8B
- 使用 GPT-4.1 为 8 亿张图片生成长描述的算力成本未计入训练效率对比
