# Linear

面向软件开发团队的项目管理工具公司。

## 与 Symphony / Codex 的集成

与[[symphony]]集成。Symphony作为[[codex]]与Linear之间的编排层，监控issue tracker并给每个ticket分配独立的Agent工作空间，实现"管工作不管Agent"的工程理念。

## 与 Tokenmaxxing 的关联

COO Cristina Cordova在𝕏上公开质疑按Token花费给工程师排名的做法，称其"跟按谁花钱最多给市场团队排名有啥区别"，主张"别把高烧钱率当成高成功率"。这一质疑代表了[[tokenmaxxing]]文化中的反对声音。
