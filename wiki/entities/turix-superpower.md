# TuriX Superpower

[[TuriX Superpower]] 是由 [[TuriX]] 团队发布的新一代工业级 Agent 产品。它旨在解决传统 AI 智能体“只能聊不能干”的问题，通过融合通用 Agent 与 [[CUA (Computer Use Agent)]]，实现了从语义交互到物理执行的跨越。

## 核心能力
TuriX Superpower 整合了以下四大能力：
1.  **Chat（聊天）**：不仅理解用户指令，更懂用户意图，支持深度逻辑推理和知识检索增强。
2.  **Work（办公）**：像专家一样进行计划、决策和优化，支持端到端任务闭环。
3.  **Code（编码）**：提供开发者级别的执行精度，能感知本地代码仓库结构，辅助调试和编写脚本。
4.  **CUA（自动操作）**：安全可控地跨应用执行任务指令，能够像人类一样操作 GUI 界面。

## 技术特点
- **视觉模型驱动**：不依赖底层 API 或坐标定位，而是通过视觉模型识别屏幕上的按钮、输入框等元素，从而操作没有 API 接口的旧软件（如 ERP、微信）。
- **[[万物 CLI 化]]**：将复杂的 GUI 操作转化为确定性指令执行逻辑。
- **[[人类在环]]**：在执行过程中展示思考过程，允许用户随时介入，确保在关键决策点上的控制权。

## 安全性与易用性
- 相比 [[OpenClaw]]，TuriX Superpower 强调不会擅动和泄漏用户隐私。
- 降低了使用门槛，用户仅需注册 API Key 即可体验，无需复杂的安装流程。
- 目前支持 macOS 版本，Windows 版本即将上线。
