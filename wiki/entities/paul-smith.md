# Paul Smith

[[Paul Smith]] 是 [[Anthropic]] 的首席商务官（CBDO）。

## 观点与言论

Paul Smith 强调了 [[Anthropic]] 在产品策略上的普惠野心。他指出，虽然 [[claude-code]] 在程序员群体中获得了巨大成功，但大型科技公司中工程师仅占 2%-5%。

他断言，通用智能体 [[Cowork]] 的影响力将超越 Claude Code，因为它服务于占据职场绝大多数的非技术人员（白领、财务、HR 等）。他将 Cowork 比作给普通人安装的「动力装甲」，而 Claude Code 只是给特种兵的「狙击镜」。
