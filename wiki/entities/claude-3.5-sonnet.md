# Claude 3.5 Sonnet

Claude 3.5 Sonnet 是 [[Anthropic]] 发布的大语言模型，在 [[Vibe Coding]] 社区中被昵称为“Sonnet Coder”。

## 技术特点
- **UI 生成能力**：在处理 UI 布局、交互细节和理解模糊指令方面表现出惊人的“灵性”。
- **低沟通成本**：不需要精准的坐标或严格的语法，就能给出几乎完美的 CSS 和界面代码。
- **对比优势**：与逻辑严密但有时显得死板的 GPT-4o 不同，Sonnet 更擅长捕捉开发者的“直觉”和“氛围”。

## 应用场景
它是 [[Cursor]] 等 AI 编程工具的核心引擎，使得开发者只需投喂截图和简短提示词即可生成完整的应用界面。
