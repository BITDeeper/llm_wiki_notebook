# Kimi K2.5

**Kimi K2.5** 是由月之暗面（Moonshot AI）开发的大语言模型。在 [[PinchBench]] 的成功率榜单中，Kimi K2.5 以 93.4% 的成功率排名第三，仅次于 [[Gemini 3 Flash]] 和 [[MiniMax M2.1]]。

## 行业地位
Kimi K2.5 的上榜进一步印证了中国模型在 [[OpenClaw]] 和 Agent 任务执行领域的整体竞争力。在 PinchBench 的前五名中，国产模型占据了重要席位。
