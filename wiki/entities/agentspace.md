# Agentspace

[[Agentspace]] 是谷歌原有的企业级知识搜索与 Agent 执行平台。

## 产品演变

-   **初始形态**：作为一个独立平台存在，致力于将企业知识搜索与 Agent 执行能力整合。员工无需关心后台运行的是哪个 Agent 或调用了哪个数据源，即可在一个界面内完成搜索、提问和任务执行。
-   **战略整合**：已被整体并入 [[Gemini Enterprise]]，成为其核心引擎。
-   **现状**：Agentspace 的能力现已融入 Gemini Enterprise 的 Agent 体系中，支撑起“发现、创建、分享和运行 AI Agent”的官方定义。

## 功能价值

Agentspace 的并入标志着谷歌将分散的 AI 能力（搜索、对话、执行）收拢至统一的 Gemini 平台下，强化了 Gemini 作为企业级 Agent 运行底座的地位。
