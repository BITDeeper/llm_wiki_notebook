# 胡彦斌

华语乐坛唱作人，代表作《红颜》《你要的全拿走》。2024年起自学编程，2026年通过 [[vibe-coding|Vibe Coding]] 独立开发粉丝社区 App [[彦火]]。

## Vibe Coding 实践

- **2024年**：开始观看软件教学类视频，学习写代码（早于 [[andrej-karpathy|卡帕西]] 2025年提出 Vibe Coding 概念）
- **2026年**：在社交媒体发帖"Vibe Coding的都懂这个姿势，修bug在路上"，截图显示使用 Claude 连接 Mac 的编程环境
- **2026年**：在《歌手》节目中透露，花了一个月时间通过 Vibe Coding 开发出粉丝社区 App [[彦火]]

## 意义

胡彦斌是 [[vibe-coding|Vibe Coding]] 从技术圈向娱乐圈扩散的标志性案例。他的经历表明，非技术人员在 AI 辅助下可以独立完成从编码到产品交付的全流程，且其编程学习实践甚至早于 Vibe Coding 概念的正式命名。
