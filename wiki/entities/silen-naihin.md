# Silen Naihin

Silen Naihin 是一位资深的 AI 编程探索者和开发者，以 [[AutoGPT]] 的早期构建者身份和 [[Cursor]] 全球前 0.01% 顶级用户的身份而闻名。他是 AI 编程范式从“辅助工具”向“自主智能体”转变的早期实践者和布道者。

## 主要经历
- **早期探索**：自 2021 年开始探索 AI 编程，见证了 GPT-4 带来的范式转移。
- **AutoGPT 时期**：参与构建了第一个真正走红的 AI 智能体项目 AutoGPT，该项目曾迅速在 GitHub 上获得 10 万星标。
- **Cursor 时期**：曾是 Cursor 的忠实用户，深入探索了其上下文管理和光标控制技巧，并被评为全球前 0.01% 用户。
- **Claude Code 时期**：在 Claude Code 2.0 发布后，果断全面迁移，成为其核心推广者之一。

## 核心贡献与观点
- **抽象极大主义**：主张开发者应追求最高层级的抽象，关注“行为”和“架构”，而非具体的代码实现细节。
- **异步优先工作流**：提倡打破 IDE 的“紧密反馈循环”，采用终端原生的异步交互模式，让 AI 自主完成任务。
- **行为级编程**：提出从验证“代码写得对不对”转变为验证“功能是否正常工作”，标志着对 AI 生成代码信任度的提升。

## 实战技巧
他总结了一套完整的 Claude Code 使用体系，包括上下文管理（`/compact`, `/transfer-context`）、规划面试（`/interview-me-planmd`）和系统化调试（`/debug`）等自定义命令，极大地提升了 AI 编程的效率。
