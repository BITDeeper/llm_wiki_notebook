# AWS Bedrock

AWS Bedrock 是亚马逊云服务（AWS）提供的全托管 AI 服务平台。

## 角色
它是 [[Anthropic]] Claude 模型的关键分发渠道之一。作为 [[多云分发策略]] 的一部分，Anthropic 在 Bedrock 上托管其模型，使 AWS 的企业客户能够直接在熟悉的云环境中使用 Claude。

## 竞争格局
它是三大云平台（AWS Bedrock, Google Cloud Vertex AI, Microsoft Azure Foundry）中最早且最重要的 AI 模型市场之一。
