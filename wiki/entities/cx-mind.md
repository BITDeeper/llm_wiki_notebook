# CX-Mind

CX-Mind 是由[[上海交通大学]]、[[上海创智学院]]与[[瑞金医院]]联合发布的医学多模态大模型，是首个将胸片诊断推进为[[可验证推理链]]的模型。该模型已开源，代码和权重分别在 GitHub 和 HuggingFace 上公开。

## 核心架构

CX-Mind 的核心设计是**交错式推理（Interleaved Reasoning）**，将医学推理拆解为可解析的think-answer交错单元：

- **封闭式问题**：逐项评估候选答案，给出保留或排除的证据
- **开放式问题**：先提出可能疾病，再围绕每种疾病进行证据核验，最后形成诊断结论

这种输出方式模拟真实阅片流程：先观察征象→形成假设→进行鉴别→写出结论。

## 训练管线

CX-Mind 采用四阶段训练管线：

1. **医学文本warm-up**：建立基础医学语言能力
2. **大规模胸片指令微调**：基于[[cx-set]]数据集进行多任务学习
3. **交错式推理cold-start**：引入42,828条高质量交错式推理样本
4. **基于GRPO的课程强化学习**：使用[[curl-vpr]]算法进行过程约束优化

## 三大能力域

| 能力域 | 任务类型 | 关键提升 |
|--------|---------|---------|
| 视觉理解 | 疾病识别、多病共存诊断 | 多病共存提升63.5%（vs CheXagent） |
| 文本生成 | Findings/Impression/Summary | BLEU高7.6%、ROUGE高11.1%（vs GPT-4o） |
| 时空对齐 | 影像-文本匹配、病程判断 | 分别提升25.8%和30.2% |

## 真实世界验证

在[[rui-cxr]]真实世界测试集（4,031张胸片，14种疾病）上，CX-Mind 保持领先。多中心医生主观评估五个维度（临床相关性、逻辑连贯性、证据支撑、鉴别诊断覆盖度、解释清晰度）全部排名第一。

## 行业意义

CX-Mind 推动了医学AI的关键转向：从"医学视觉模型"→"医学推理模型"→"可被医生协作审查的医学智能体"。这一思路有望迁移到胸部CT多癌种筛查、MRI跨序列整合、病理高分辨率分析等更多医学场景。

## 局限与挑战

临床部署仍面临前瞻性研究、跨医院泛化验证、医生工作流集成和监管审查等现实挑战。
