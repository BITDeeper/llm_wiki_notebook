# 千问表格 Agent

[[千问表格-agent]] 是由 [[千问]]（通义千问）推出的专门用于处理 Excel 文件的 AI 智能体工具。它旨在通过自然语言交互，帮助用户零门槛地完成从数据收集、整理到格式美化的全流程表格制作工作。

## 核心特性

### 1. 零门槛操作
用户无需掌握 Excel 的快捷键、函数公式（如 VLOOKUP）或透视表操作，仅需使用大白话描述需求，Agent 即可自动执行。例如：“删掉空行”、“把单价超过5元的标黄”。

### 2. 端到端交付
与以往仅能提供表格思路的 AI 不同，[[千问表格-agent]] 能够直接生成可编辑、可下载的 .xlsx 文件，支持多 Sheet 页、复杂公式及图表插入。

### 3. 实时信息整合
具备 [[在线rag]] 能力，能够根据用户需求自动联网检索最新数据（如新款手机参数、旅游攻略信息），并将其整理成结构化表格，解决了信息差问题。

### 4. 多模态输入
支持图片转表格功能。用户上传随手拍的健身计划、名片或纸质文档图片，Agent 能通过 OCR 和语义理解将其转化为规范的 Excel 表格。

### 5. 多轮对话迭代
支持在对话过程中随时修改需求（如“第2天换成去千岛湖”），Agent 会基于上下文实时更新表格内容，直至用户满意。

## 技术架构

[[千问表格-agent]] 的运行依赖于以下核心技术组件：

-   **Planner（规划器）**：负责解析用户意图，判断任务类型（如格式调整、数据检索、代码生成），并规划最优执行路径。
-   **沙箱执行环境**：在隔离的 Python 环境中运行代码（主要使用 Pandas/OpenPyXL），确保了处理复杂数据逻辑时的安全性，避免影响用户本地环境。
-   **专项优化**：针对 Excel 场景进行了大量边缘情况处理，确保公式兼容性和格式稳定性。

## 商业模式

目前，[[千问表格-agent]] 在千问 App、网页版及 PC 端**全渠道免费**开放使用。这一策略旨在降低 AI 使用门槛，吸引广泛的办公人群和学生群体。

## 应用场景

-   **市场调研**：自动搜索并对比竞品参数。
-   **行政办公**：美化报表、清洗数据、制作周报月报。
-   **个人生活**：制定旅游攻略、健身计划、记账单。
