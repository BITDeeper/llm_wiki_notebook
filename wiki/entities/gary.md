# Gary

[[Gary]] 是腾讯云 Agent Runtime 产品副总经理、专家工程师。

## 核心观点
[[Gary]] 指出业界普遍存在 [[技术惯性认知误区]]，即用微服务架构硬套 Agent。他主张云不仅是给人用的，更是给 Agent 用的，必须通过原生基础设施（如 [[Agent Runtime]]）来消灭 [[偶然复杂度]]。

## 实践案例
分享了腾讯内部从 TAPD 接入失败到以 Git 为中心转型的亲身经历，证明了 [[Agent Native]] 工作流重构的有效性。

## 愿景
认为未来智能体可能会拥有类似“企业法人”的地位和权限，企业应构建适应 Agent 时代的安全沙箱和授权体系，而非因噎废食。
