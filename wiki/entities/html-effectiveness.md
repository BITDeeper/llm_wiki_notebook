# HTML Effectiveness

[[HTML Effectiveness]] 是由 Anthropic 工程师 [[Thariq Shihipar]] 开源的一组 HTML 文件集合，托管在 GitHub Pages 上。该项目旨在展示 [[Claude Code]] 生成 HTML 的各种实用场景，证明 HTML 在 AI 工作流中优于 [[Markdown]] 的潜力。

## 项目内容
包含 20 个单独的 HTML 文件，按用途分为九大类：
1.  **代码审查**：带风险地图和颜色编码注释的 Diff 视图。
2.  **交互式教程**：如一致性哈希可视化。
3.  **用完即弃编辑器**：工单排序、Prompt 微调工具。
4.  **周报**：带图表和时间线的可视化报告。
5.  **实施计划**：包含里程碑、数据流图和风险表的仪表盘。
6.  **设计系统可视化**：色板和组件状态表。
7.  **动画原型**：带缓动曲线滑块的交互式动画。
8.  **幻灯片**：基于 HTML 的演示文稿。

## 核心价值
- **演示 [[双向交互]]**：用户可在页面中操作（拖拽、点击），并将结果导出回文本。
- **展示 [[用完即弃编辑器]]**：为特定任务定制的临时工具，而非通用产品。
- **[[空间信息还原]]**：利用 HTML 布局能力还原代码 Diff 或设计系统的空间关系。
