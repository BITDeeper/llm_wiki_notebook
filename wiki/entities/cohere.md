# Cohere

Cohere 是一家专注于企业级 AI 的公司，由 [[aidan-gomez]]、[[nick-frosst]] 和 Ivan Zhang 于 2019 年在加拿大多伦多创立。

## 创立背景

三位创始人选择了与 [[openai]] 不同的路线：不做面向大众的聊天机器人，只为企业做模型。这一战略定位使 Cohere 在企业私有化部署领域建立了差异化优势。

Gomez 是 Transformer 论文《Attention Is All You Need》的八位共同作者中最年轻者（当时20岁，为 Google Brain 实习生）。Frosst 则是 AI 教父 Geoffrey Hinton 在谷歌大脑多伦多实验室的早期雇员，被视为 Hinton 的得意门生。一个写出 Transformer，一个师承 Hinton——Cohere 从第一天起就具备了"把前沿研究做成企业能用的产品"的基因。

## 核心产品

- **Command R / Command R+**：早期旗舰模型，采用 CC-BY-NC 4.0 许可证（禁止商用）
- **Command A Reasoning / Command A Vision**：中期迭代产品
- **[[command-a-plus]]**：2026年5月发布的首个 MoE 架构旗舰模型，采用 [[apache-2-0-开源许可]]，标志着 Cohere 全面倒向真开源

## 战略方向

Cohere 的核心叙事是帮助企业摆脱供应商锁定：企业可以下载模型权重，用机密数据微调，部署在私有服务器甚至气隙网络中，不再受制于基础设施、定价变动或 API 稳定性。

## 与 Aleph Alpha 合并

近期，Cohere 宣布与德国 AI 公司 [[aleph-alpha]] 合并。两家公司方向一致：不押注聊天机器人，而是为政府和大企业做能装进自家机房的 AI。
