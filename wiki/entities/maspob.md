# MASPOB

**MASPOB**（Multi-Agent System Prompt Optimization via Bandits）是由香港中文大学（深圳）、香港科技大学（广州）、华南理工大学和立命馆大学联合提出的基于Bandit的多智能体Prompt优化框架，已被 **ICML 2026** 接收为 Spotlight 论文（arXiv: 2603.02630）。

## 核心定位

MASPOB回答的核心问题是：在固定工作流拓扑约束下（如医疗SOP、金融审计流程），如何高效地优化各Agent的Prompt配置以提升多智能体系统整体性能？这区别于主流的"改工作流"优化路线，开辟了约束条件下的新优化维度。

## 三大核心组件

### 1. 拓扑感知性能代理模型
- 将MAS工作流建模为有向无环图（DAG）
- 以各Agent的Prompt嵌入为节点特征
- 采用图注意力网络（GAT）进行消息传递
- 显式建模上游Prompt变化对下游Agent的影响

### 2. Bandit式探索-利用权衡
- 将Prompt组合优化建模为Bandit问题
- 采用线性置信上界（LinUCB）构造采集函数
- 在有限评估预算下实现样本高效搜索

### 3. 坐标上升搜索
- 将联合优化分解为对各Agent的逐一单变量优化
- 避免组合搜索空间的指数爆炸
- 运行时间减少98-99.8%，性能损失仅0.29-0.48%

## 实验表现

| 基准 | MASPOB得分 | 任务类型 |
|------|-----------|---------|
| HotpotQA | 75.43% | 问答 |
| DROP | 82.28% | 问答 |
| HumanEval | 94.15% | 代码生成 |
| MBPP | 80.65% | 代码生成 |
| GSM8K | 93.90% | 数学推理 |
| MATH | 57.05% | 数学推理 |

- 平均得分80.58%，较IO基线提升12.02%，较AFlow提升2.06%，较MIPRO提升1.71%
- GNN消融：去除GNN平均性能下降2.31%
- 复杂拓扑（7-8个Agent）下仍保持最优排名
- 约35轮后收敛，验证集与测试集走势一致

## 与其他方法的关系

- **与 [[mango-多智能体流网络优化|MANGO]]**：互补关系。MANGO联合优化路径选择与节点提示词（改工作流），MASPOB在固定拓扑下优化提示词（不改工作流）。两者分别从结构优化和参数优化切入
- **与 [[多智能体错误传播]]**：MASPOB的拓扑感知代理模型本质上在建模和缓解错误传播
- **与 [[文本梯度]]**：MASPOB提供了基于Bandit的替代路线，区别于文本梯度的自然语言优化方式

## 局限性

- 假设工作流为DAG，未讨论循环工作流的适用性
- 在复杂拓扑（7-8个Agent）下部分任务性能略有下降（如HumanEval 94.15%→90.08%）
- 50次评估预算下的结论，在更紧或更松的预算约束下是否成立未验证
- 未讨论不同LLM backbone下的泛化性
