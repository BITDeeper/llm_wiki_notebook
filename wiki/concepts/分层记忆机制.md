# 分层记忆机制

分层记忆机制是指 AI Agent 区别于传统 Chatbot 的短期上下文，具备能够沉淀和调用历史数据的长期记忆能力。

## 记忆分层

- **短期记忆**：处理当下的指令和对话，类似于人类的工作记忆。
- **长期记忆**：通过向量数据库或知识库对接，沉淀过往的项目背景、用户偏好、历史修改记录和专属档案。

## 应用价值

在真实的工作场景中（如“电子班主任”案例），项目周期可能长达数月，涉及数百条记录。具备分层记忆机制的 Agent 能够：
- 读懂昨天的数据，从而做出今天正确的决策。
- 记住每个用户的历史交互，实现真正的个性化服务。
- 在多轮任务中保持连贯性，避免重复沟通。

## 技术实现

通常通过 [[OpenClaw]] 等框架连接外部向量数据库（如 RAG 技术）来实现，使 Agent 能够跨越会话窗口访问历史信息。
