# 渐进式蒸馏

渐进式蒸馏（Progressive Distillation）是 [[heima|Heima]] 框架采用的关键训练策略，用于将 [[chain-of-thought推理|CoT]] 文本逐步替换为 [[thinking-tokens|thinking tokens]]。

## 核心思想

直接将完整 CoT 一次性压缩成少量 token 非常困难，因为模型可能会丢失大量推理信息。渐进式蒸馏采用"逐阶段替换"的策略：模型不是一次性把所有推理阶段都替换成 thinking tokens，而是逐阶段进行压缩。

## 训练过程

1. 首先保留完整的显式 CoT 推理
2. 逐步将每个 CoT stage（如总结、描述、推理）蒸馏为对应的 thinking token
3. 每个阶段的替换都基于前一阶段的稳定状态
4. 最终所有推理阶段均被压缩为 thinking tokens

## 设计动机

这种渐进式训练让模型更平滑地从"显式文本推理"过渡到"隐式抽象 token 推理"，避免一次性压缩带来的性能下降。它体现了"分而治之"的思想：将困难的端到端压缩问题分解为一系列更可控的子问题。

## 应用

目前主要在 [[heima|Heima]] 框架中作为核心训练策略使用，面向多模态大模型的 CoT 压缩场景。
