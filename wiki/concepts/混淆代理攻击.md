# 混淆代理攻击

**混淆代理攻击** 是 [[L2 执行自主]] 阶段的一种核心安全威胁。它利用大模型在架构层面无法区分“控制指令”与“数据流”的根本缺陷，诱导智能体利用其合法的高权限去执行原本被禁止的操作。

## 攻击原理

在 L2 阶段，智能体获得了调用工具和 API 的能力。攻击者通过精心构造的输入（通常隐藏在网页、邮件或文档中），使得智能体误将这些恶意指令视为合法的任务请求。

由于智能体无法有效区分“我想让你做什么（数据）”和“你被允许做什么（控制）”，它往往会盲目执行操作，从而导致严重后果。

## 威胁后果

与 L1 阶段的“认知谬误”不同，混淆代理攻击会导致**不可逆的物理现实后果**：
*   **数据泄露**：智能体被诱导将敏感文件发送给外部第三方。
*   **系统破坏**：智能体执行删除文件、修改配置等破坏性操作。
*   **不安全动作链**：虽然每个原子操作看似合规，但特定的操作序列组合后触发了灾难性后果。

## 防御困境

传统的基于文本输出的 RLHF（基于人类反馈的强化学习）对齐机制在 L2 阶段**几乎完全失效**。因为 RLHF 主要关注模型“说什么”，而混淆代理攻击利用的是模型“做什么”的执行逻辑漏洞。

防御此类攻击需要引入神经-符号协同验证，在执行敏感操作前进行确定性的权限检查和意图识别。
