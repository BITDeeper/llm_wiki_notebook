# Mantis

在统一模型上训练具身动作策略的方法，属于 World Action Model 范畴，由 [[邓志杰]]团队提出。

## 核心思想

Mantis 基于 [[latentum]] 隐空间统一模型，在其上训练具身动作策略，实现从多模态理解到具身行动的端到端能力。

## 与现有方法的关系

与现有 World Action Model 相比，Mantis 在性能与效率上具有优势（具体数据待活动后获取）。

## 技术定位

Mantis 代表了统一模型向具身智能延伸的一条重要路径：
- 统一模型提供跨模态理解基座
- 世界建模提供环境模拟能力
- Mantis 在此基础上训练具身动作策略
