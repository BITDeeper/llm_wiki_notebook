# 对数空间对称性

**对数空间对称性（Log-space Symmetry）** 是 [[gipo]] 算法的核心数学创新，指在对数空间中对重要性比率及其倒数赋予相同信任权重的特性。

## 数学表述

对于重要性比率 $r$，GIPO 满足：

$$w(r) = w(1/r)$$

这是因为高斯核函数中的平方项 $(\log r)^2 = (\log(1/r))^2$，使得概率高出 $k$ 倍与低 $k$ 倍的情况获得完全相同的信任权重。

## 与 PPO 的对比

PPO 在线性空间进行截断（如阈值 1.2 与 0.8），其算术距离相等但逻辑比例并不对称。例如：
- 概率高 1.2 倍：距离阈值 0.2
- 概率低 1.2 倍（即 0.833）：距离阈值仅 0.033

这种不对称在处理重尾分布时导致更新方向性偏差。

## 意义

对数空间对称性确保无论策略偏离方向如何，更新幅度在逻辑比例上都是对称且平衡的，这是 GIPO 在高滞后场景下优于 PPO 的数学基础。
