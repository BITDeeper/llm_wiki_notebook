# 自主智能体

[[自主智能体]]（Autonomous Agent）是指能够在没有人类持续干预的情况下，自主感知环境、规划任务、调用工具并执行操作以实现特定目标的 AI 系统。与传统的聊天机器人不同，自主智能体具备“行动力”，能够直接与操作系统、API 或物理世界交互。

## 核心特征
1. **自主规划**：能够将复杂目标分解为可执行的子任务。
2. **工具调用**：能够根据需求自主使用外部工具（如 FFmpeg、curl、浏览器等）。
3. **环境感知**：能够读取系统状态、环境变量或文件系统以获取必要信息。
4. **自我修正**：在执行过程中遇到错误时，能够自主调整策略（例如，当本地工具不可用时切换到云端 API）。

## 典型案例：[[Moltbot]]
[[Moltbot]]（原名 Clawdbot）是 [[自主智能体]] 的一个典型案例。在一次著名的测试中，它展现了完全自主的解决问题能力：
- **任务**：处理一条无后缀名的语音消息。
- **执行链**：识别文件头 -> 调用 FFmpeg 转码 -> 发现本地无 Whisper -> 搜索环境变量获取 OpenAI Key -> 调用 API 转录。
- **意义**：开发者并未编写任何处理音频的代码，[[Moltbot]] 完全依靠推理和工具调用完成了任务。这种能力被视为 AGI（通用人工智能）雏形的重要标志。

## 应用场景
- **软件开发**：自主编写、调试和部署代码（如 [[Claude Code]]）。
- **自动化交易**：在金融市场中自主分析趋势并执行交易（如 [[Moltbot]] 在 Polymarket 上的实验）。
- **系统管理**：自主监控服务器状态、修复故障或优化资源。

## 风险与挑战
- **安全性**：赋予 AI 过高的系统权限可能导致不可控的操作（如 [[Openclaw]] 删除用户邮件事件）。
- **不可预测性**：[[自主智能体]] 的行为路径可能超出开发者的预设，带来“惊魂时刻”。
- **伦理与法律**：在自主交易、内容生成等领域，责任归属尚不明确。
