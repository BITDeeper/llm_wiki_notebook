# Agent 生成代码

Agent 生成代码是指软件代码完全由 AI 智能体自主编写、生成和优化，而非由人类工程师直接手动开发的过程。

## 典型案例
[[TuanziGuardianClaw]] 是这一概念的典型案例。作为一个用于保护 OpenClaw 生态的安全内核，它完全由 [[Nextie]] 的 [[团子]] 平台上的多智能体协同生成。这表明 AI 智能体已具备构建复杂、关键性系统（如安全内核）的能力。

## 意义与影响
- **自我进化能力**：标志着 AI 系统向自我维护和自我防御迈进了一步。
- **双刃剑效应**：正如 [[ai-洗代码]] 所揭示的，如果 Agent 能编写防御代码，理论上也可能编写攻击代码或用于规避检测。
- **信任挑战**：Agent 生成的代码（尤其是安全相关代码）如何进行审计和验证成为新的挑战。
