# API价格战

[[API价格战]]（API Price War）是指 AI 模型提供商通过大幅降低 API 调用价格来争夺开发者市场份额和生态主导权的行业现象。这通常伴随着模型性能的同步提升，即“更强、更便宜”。

## 现象案例
- **[[Nano Banana 2]]**：发布时 API 价格为 0.067 美元/1K图，比前代 Pro 版本降低了 **50%**。
- **行业趋势**：随着模型训练效率的提高和基础设施成本的摊薄，主流模型提供商纷纷降价，使得 AI 生图、生文成本呈指数级下降。

## 驱动因素
1. **技术优化**：模型架构（如 [[Nano Banana 2]] 引入 Flash 技术）和推理效率的提升降低了边际成本。
2. **生态竞争**：各大厂商（如 Google、OpenAI、Anthropic）为了吸引开发者构建基于其模型的 App，必须通过低价策略锁定生态。
3. **规模效应**：用户量的增加使得厂商可以通过薄利多销的方式维持盈利。

## 影响
- **开发者红利**：降低了创业公司和独立开发者的试错成本。
- **应用爆发**：使得原本因成本过高而不可行的应用场景（如实时生图游戏、个性化广告生成）成为可能。
- **行业洗牌**：无法跟上降价节奏的小型模型提供商可能被淘汰。

## 与订阅制危机的关系
API 价格战主要影响 B 端（开发者）市场，而 [[ai-subscription-crisis]] 主要讨论 C 端（个人用户）的订阅模式失效。两者共同反映了 AI 算力成本下降与商业化探索之间的张力。
