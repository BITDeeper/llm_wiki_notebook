# 管道化危机

**管道化危机** (Commoditization of Platform) 是指平台型公司担心自己沦为单纯的“管道”或基础设施提供商的风险。在这种情境下，虽然底层的算力或服务依然被使用，但高价值的用户入口、交互界面和附加值被前端应用（Agent 或 Wrapper）截断。

## 表现形式
- 用户通过第三方应用（如 [[openwork]]）调用底层 API，而非直接使用平台官方应用。
- 平台失去了与用户的直接触点，无法通过品牌溢价或订阅服务获取超额利润。
- 平台退化为可被随时替换的“水电煤”式基础设施。

## 应对策略
为了应对管道化危机，巨头公司通常采取以下措施：
1.  **功能下放与降价**：如 [[anthropic]] 将 [[claude-cowork]] 从高价订阅下放至低价订阅，通过牺牲利润来保住官方入口的吸引力。
2.  **限制与封锁**：通过技术手段限制第三方应用访问，或收紧 API 政策。
3.  **构建生态壁垒**：通过官方独有的数据或功能闭环，增加第三方应用的复现难度。

## 案例
2026 年初，Anthropic 面对开源项目 Openwork 的竞争，迅速下调 Cowork 功能的价格，就是为了防止用户习惯于使用开源界面，从而导致 Anthropic 仅作为模型 API 供应商被“管道化”。
