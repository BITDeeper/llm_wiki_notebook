# AI+终端

AI+终端 指人工智能技术与硬件设备（如手机、汽车、机器人）的深度融合，旨在打造软硬结合的超级助理。

## 核心特征
- **感知能力**：需要具备视觉、听觉等多模态感知能力（即“原生多模态”）。
- **行动能力**：不仅能理解指令，还能直接操作设备的 GUI 或物理接口。
- **跨端协同**：由跨端 OS 驱动，在不同设备间提供连续的服务体验。

## 落地场景
- **智能手机**：如 [[阶跃星辰]] 的 [[Step-GUI]] 模型，装机量超 4200 万台。
- **智能座舱**：如吉利银河 M9 搭载的 [[AgentOS]]，预计年上车规模超百万辆。

## 行业趋势
随着大模型竞争进入“[[季后赛]]”，单纯依赖云端 API 或订阅制的模式面临挑战。AI+终端被视为实现规模化用户入口和真实商业落地的重要路径。
