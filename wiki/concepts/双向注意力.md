# 双向注意力

[[双向注意力]]（Bidirectional Attention）是一种注意力机制，允许序列中的每个元素关注其前后所有的其他元素。这与 [[因果注意力]]（Causal Attention）形成对比，后者限制元素只能关注其之前的元素（即生成第 N+1 个 token 时只能看到第 1 到第 N 个 token）。

## 核心机制

在 [[diffusiongemma|DiffusionGemma]] 中，每次前向计算并行生成 256 个 token，每个 token 都能看到其他所有 token（包括后续 token）。这使得模型在生成时具备全局视野。

## 核心能力：实时自我纠错

模型边生成边评估整段文字的一致性，发现不对立刻修正，不用等全写完再回头改。这是自回归模型很难做到的能力。

## 与因果注意力的对比

- **因果注意力**：自回归模型采用因果注意力，每个 token 只能关注自身及之前的 token。这在逐 token 生成中是必要的（否则会「看到未来」），但也限制了模型处理非线性依赖的能力。适用于自回归文本生成，确保预测不依赖于未来信息。
- **双向注意力**：适用于理解任务（如 BERT、视觉编码）和需要全局协调的生成任务（如 [[扩散文本生成]]），能够聚合全序列信息。文本扩散模型通过整块并行生成 + 双向注意力绕过了因果注意力的限制。

## 在视觉编码中的应用

在 [[penguin-vl]] 和 [[penguin-encoder]] 的上下文中，双向注意力是关键的架构改造之一。由于图像和视频帧中的像素或 Patch 之间不存在固有的时间顺序或因果依赖，使用 LLM 原生的因果注意力会限制模型捕捉全局空间关系的能力。

通过将 LLM 的因果注意力替换为双向注意力，模型能够：

- 同时利用上下文信息来理解当前视觉单元。
- 更好地捕捉图像中的全局结构和空间关系。
- 适应非因果的视觉建模需求。

## 在扩散文本生成中的应用

[[扩散文本生成]]模型中，所有 token 同时生成，每个 token 都能看到画布上所有其他 token，前后文同时可见——这正是双向注意力赋予的技术特性。

### 验证实验

[[diffusiongemma|DiffusionGemma]] 的数独微调实验：数独本质是"后面的数影响前面的数"，自回归模型由于只能往前看，做起来极痛苦。DiffusionGemma 微调后数独成功率从 0% 飙到 80%。

## 优势场景

以下"需要前后文同时协调"的非线性任务，双向注意力具有结构性优势：

- **行内编辑**：修改某处时可见上下文全局
- **数独**：每个数字依赖其他所有数字的约束
- **代码补全**：函数体生成可见函数签名和后续上下文
- **氨基酸序列**：序列中每个位置受全局约束
- **数学图结构**：节点间存在双向依赖关系
- **复杂 Markdown 格式化**
- **结构化数据生成**（如 SVG、JSON）
