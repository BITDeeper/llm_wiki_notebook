# Agent 永续记忆

**Agent 永续记忆**（Agent Persistent Memory）是指 AI Agent 具备的、不依赖本地文件系统或有限的上下文窗口，能够持久化存储、跨设备同步并在长期交互中保持连贯性的记忆能力。

## 核心需求

### 1. 持久化
记忆不应仅存在于当前的 Session 或本地的 `MEMORY.md` 文件中，而应存储在可靠的云端或数据库中，以防数据丢失。

### 2. 跨设备同步
用户在不同设备上与 Agent 交互时，Agent 应能调用完整的记忆历史，提供连贯的服务体验。

### 3. 语义与精确检索
记忆系统需要支持基于语义（向量）和关键词（全文）的混合检索，以便在生成回复时准确召回相关信息。

### 4. 可审计性
记忆不应是“黑盒”。用户应能通过 Dashboard 或日志查看 Agent 到底记住了什么，并能进行修正或删除。

## 实现挑战

### 上下文压缩
许多 Agent 框架（如早期的 [[openclaw]]）使用上下文压缩来控制 Token 消耗。这往往导致非关键信息被永久丢弃，造成“失忆”。永续记忆系统需要与上下文生命周期（如 [[contextengine]]）深度集成，以决定哪些信息应被转入长期存储。

### 多租户隔离
在服务大量 Agent 时，如何低成本地实现数据隔离（如 [[mem9]] 提出的“一虾一库”）是一个工程挑战。

### 成本与性能
随着记忆数据的无限增长，如何在保证检索速度（低延迟）和控制成本（存储与计算）之间取得平衡，是云端记忆方案的核心问题。

## 技术路径
- **本地优先**：数据存储在用户设备，隐私性好，但难以同步和备份。
- **云端记忆**：利用云数据库（如 [[tidb]]）实现弹性伸缩和多端同步，体验更佳，但引入了隐私和依赖网络的考量。
