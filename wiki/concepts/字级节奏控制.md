# 字级节奏控制

**字级节奏控制**是指对语音合成中每个 token（字/词）的声学展开长度进行毫秒级精确调节的能力，区别于传统的整句全局变速。这是[[magic-tts|MAGIC-TTS]]系统的核心创新之一。

## 背景

传统TTS系统的节奏控制停留在全局层面——整段话变快或变慢，或给整段话套一个风格标签。但产品场景中，用户真正需要的往往是对关键位置的局部精细调节：验证码中数字之间的刻意拉开、导航中站名的单独强调、教学中近音词的差异示范。

## 两个维度

字级节奏控制包含两个独立维度：

1. **内容时长控制**：调节每个 token 内部的声学展开长度。这是更难的维度——让某个词说得更长，同时不把整句节奏带坏，直接涉及 token 内部的声学生成过程。
2. **[[边界停顿控制]]**：在 token 之间的边界处插入精确时长的停顿，模拟真人说话中的节奏留白。相对容易，更接近"在内容之间插空"。

## 范式意义

字级节奏控制代表了TTS领域从"自然度竞赛"向"精细可控性"的范式转变。这与[[场景白盒化推理]]的理念形成呼应——都强调从"黑盒整体输出"转向"可精细控制的局部过程"。也类似于[[办公技能框架]]中将能力拆解为可编排模块的思路，字级节奏控制将节奏拆解为内容时长和停顿两个独立可控维度。

## 关键挑战

- **监督边界精度**：如果训练数据中 token 的起止位置不稳，推理时的精细调节将失去基础
- **维度间干扰**：停顿控制信号可能污染内容时长控制，需要[[零值校正]]等技术手段解决
- **鲁棒性**：用户不可能每次都提供精细指令，系统必须在缺失控制条件下仍保持合成质量
