# 语义冗余

[[语义冗余]] 指的是在模型的 KV 缓存中存在大量语义相似或重复的 Token 表示。

## 特征

- **多模态输入中更显著**：研究表明，视觉-语言输入下的 KV 相似度分布整体右移，意味着其语义冗余度显著高于纯文本输入。
- **分布不均**：冗余并非均匀分布，而是呈现出 [[异构头部冗余性]]，即不同的注意力头具有不同的冗余水平。

## 对压缩的影响

在 [[KV缓存压缩]] 中，如果仅基于“重要性”进行筛选，往往会保留大量语义冗余的 Token。这些 Token 虽然重要，但它们在表示空间中“扎堆”，不会线性叠加信息量，反而挤占有限的缓存预算，导致模型对其他信息的覆盖面变窄。

## 解决方案

为了打破这种冗余带来的负面影响，[[MixKV]] 引入了“多样性”评分机制，鼓励在保留重要 Token 的同时，尽可能选择语义上互不相似的 Token，从而扩大上下文的信息覆盖范围。
