# 具身智能飞轮

具身智能飞轮是指机器人通过连续运行形成的数据正反馈循环，是具身智能从线性进步转向指数进步的核心机制。

## 飞轮机制

```
机器人连续运行 → 采集真实场景数据 → 模型迭代优化
       ↑                                    ↓
  运行时间进一步拉长 ← 处理更多边界情况 ← 模型更强
```

## 与 LLM Scaling 的类比

这一循环与大语言模型靠互联网文本做 Scaling 的逻辑如出一辙，区别在于：

| 维度 | LLM | 具身智能 |
|------|-----|----------|
| 语料来源 | 互联网文本 | 物理世界本身 |
| 数据生成 | 已有文本语料 | 每一秒真实运行都在生成训练数据 |
| Scaling 驱动 | 更多数据 → 更大模型 | 更长运行 → 更多数据 → 更强模型 |

## 与现有概念的关系

- **[[ai-infrastructure-flywheel]]** — 两者逻辑同构，都是正反馈循环驱动指数增长
- **[[具身智能数据困境]]** — 飞轮一旦启动，可通过持续运行自动生成训练数据，部分解决数据获取难题
- **[[sim2real]]** — Figure 选择直接在真实场景中运行采集数据，绕过仿真鸿沟
- **[[ai-takeoff]]** — 飞轮的指数进步曲线与 AI 起飞临界点概念直接相关

## 实际验证

[[figure]] 的 [[f-03]] 机器人在2026年5月的 [[figure-100小时直播事件]] 中，连续运行超100小时、分拣超13万包裹，被视为飞轮启动的初步证据。CEO [[brett-adcock]] 将此事件类比为2016年 AlphaGo，暗示这是具身智能的拐点。

## 开放问题

- 飞轮在简单重复任务（分拣包裹）上已启动，但在开放环境复杂任务上是否同样有效？
- 真实场景数据的多样性和质量是否足以支撑通用能力的涌现？
- 从单一任务飞轮到通用操作能力的跨越有多大？
