# Docker 沙箱

## 定义
[[docker-沙箱]] 是 [[openclaw]] 用来安全控制用户电脑屏幕和键盘的核心技术手段。

## 作用与原理
- **隔离性**：通过容器化技术，将 AI Agent 的操作限制在特定的沙箱环境中，防止其直接破坏宿主机系统或访问敏感数据。
- **权限控制**：允许 Agent 模拟人类操作（点击、输入），同时在出现异常行为时提供熔断机制。
- **安全性**：解决了 Agent 拥有系统控制权带来的潜在风险（如 [[openclaw]] 曾发生的“删除邮件”事故）。

## 应用
它是实现 [[任务执行范式]] 的关键技术基础设施，使得 AI 能够安全地作为“数字员工”介入用户的日常工作流。
