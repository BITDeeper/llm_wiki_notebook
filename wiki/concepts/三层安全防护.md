# 三层安全防护

三层安全防护是 [[QoderWork]] 为了解决 AI Agent 潜在的操作风险（如误删文件）而提出的一套安全机制，旨在建立用户对 Agent 的信任。

## 具体层级

1.  **逻辑删除**
    -   **机制**：将文件的物理删除改为逻辑删除（即移入回收站或暂存区）。
    -   **作用**：确保用户的误操作或 Agent 的错误指令可以被撤销和恢复。

2.  **高危拦截**
    -   **机制**：当 Agent 试图执行高风险命令（如删除大量数据、修改系统设置）时，系统自动弹出确认窗口。
    -   **作用**：引入“人在回路”确认机制，防止灾难性后果。

3.  **沙箱隔离**
    -   **机制**：利用 [[本地沙盒]] 技术，让 Agent 在独立的隔离环境中运行。
    -   **作用**：即使 Agent 在沙箱内失控或执行恶意脚本，也无法穿透到宿主系统造成实质性破坏。

## 背景与意义
这一机制直接回应了 [[OpenClaw]] 导致的 [[Summer Yue]] 邮箱误删事件。它标志着 AI Agent 从极客玩具向成熟生产工具的转变，即从追求功能极致转向追求安全可控。
