# P-ReAct

[[P-ReAct]]（Parallel-Reasoning and Acting）是一种专为 [[扩散大语言模型]] 设计的推理加速策略，由 [[中国人民大学]] 团队在 [[DLLM-Searcher]] 项目中提出。其核心目标是实现 Agent 的“一心二用”，即在等待外部工具（如搜索引擎）返回结果的同时，模型继续进行下一步思考。

## 背景与动机
传统的 [[ReAct]] 框架采用串行模式：思考 -> 调用工具 -> 等待 -> 思考。这种模式导致大量时间浪费在等待工具响应上。虽然理论上可以调整生成顺序（先调用工具再思考），但自回归模型受限于因果注意力机制，强行改变顺序会导致性能大幅下降。

## 工作原理
P-ReAct 利用扩散模型 [[块内双向注意力]] 的特性，通过以下两个步骤实现并行推理：

1.  **预填充边界标记**：
    在每轮生成开始时，不是给模型一整块空白，而是提前在特定位置放置 `<action_start>` 和 `<action_end>` 两个锚点。这相当于告诉模型：“这两个标记之间是你要填工具调用的地方”。

2.  **置信度偏置**：
    扩散模型每一步会给所有位置的候选 token 打一个置信分。P-ReAct 在工具调用区域的置信分上统一加一个正偏置（α=0.5），人为拉高这些位置的解码优先级。

## 效果
-   **优先行动**：模型几乎 100% 会先把工具调用解码完毕，立刻发送请求。
-   **并行思考**：在等待搜索结果返回的“空窗期”，模型继续填充思考部分。
-   **性能无损**：实验数据显示，P-ReAct 带来了 14.77% 到 22.08% 的端到端推理加速，且准确率没有下降（甚至在部分数据集上略有提升）。

## 局限性
P-ReAct 依赖于扩散模型的架构特性（双向注意力），无法直接应用于自回归模型。
