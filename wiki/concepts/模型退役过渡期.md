# 模型退役过渡期

[[模型退役过渡期]] 是指 AI 服务提供商在正式下线旧模型之前，为开发者和用户留出的适应和迁移时间窗口。

## 背景与目的
在 AI 领域，模型迭代速度极快。频繁的模型更迭可能导致依赖 API 的生产环境应用出现行为异常或崩溃。设立过渡期旨在：
- 避免生产环境事故。
- 给开发者留出时间进行回归测试和代码调整。
- 减少因强制切换带来的用户体验摩擦。

## 历史教训
[[OpenAI]] 在退役 [[GPT-4o]] 时曾因缺乏过渡期而遭遇强烈反弹，导致许多应用服务中断。这一教训促使 [[GPT-5.3 Instant]] 在被 [[GPT-5.5 Instant]] 取代时，设定了三个月的过渡期。

## 实施细节
- **手动切换**：在过渡期内，付费用户通常可以手动切换回旧模型。
- **API 兼容**：旧模型 ID 通常仍可调用，但会被标记为“即将弃用”。
- **开发者建议**：建议开发者尽早开始在新模型上进行测试，以确保平稳迁移。
