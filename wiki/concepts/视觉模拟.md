# 视觉模拟

视觉模拟是传统 AI Agent 操作网页的主要方式，指通过截屏、识别按钮位置、模拟点击（DOM 抓取）来完成任务。

## 痛点
虽然视觉模拟让 Agent 能够像人一样操作网页，但它存在明显的缺陷：
- **成本高昂**：一次简单的操作可能需要消耗数千 Token 来处理和解析截图。
- **稳定性低**：高度依赖 DOM 结构，一旦网站改版，Agent 容易失效。
- **效率低下**：Agent 必须反复“看”屏幕来确认操作结果。

## 替代方案
随着 [[webmcp]] 等协议的出现，行业正逐渐从“视觉模拟”转向“逻辑直连”，即通过 API 直接调用网页功能，从而规避上述问题。[[openclaw]] 等工具是视觉模拟范式的典型代表。
