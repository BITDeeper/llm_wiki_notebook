# 纯文本LLM初始化视觉编码器

[[纯文本llm初始化视觉编码器]] 是一种训练视觉编码器的新范式，旨在打破“对比学习视觉 Backbone + LLM”的传统多模态拼接套路。

## 核心逻辑

该范式认为，传统的对比学习（如 CLIP）擅长判别和检索，会将图像压入适合分类的语义空间，从而过早丢失细粒度的局部结构、空间关系和时序细节。相比之下，纯文本 LLM 已经具备了强大的序列建模、上下文组织和因果逻辑能力。

通过直接从 LLM 初始化视觉编码器，模型可以：
- 继承 LLM 成熟的架构模块（Attention, FFN, GQA 等）。
- 缩小视觉与语言特征空间之间的鸿沟。
- 利用 LLM 的推理能力作为视觉理解的起点。

## 必要的架构调整

由于 LLM 原生架构是为文本序列设计的，直接用于视觉编码通常需要进行以下调整：
- 将因果注意力改为 [[双向注意力]]，以捕捉图像的全局空间依赖。
- 引入 [[2D-RoPE]]（二维旋转位置编码），以处理图像和视频的二维空间位置信息。

## 实证结果

[[penguin-vl]] 的实验表明，使用 LLM 初始化的视觉编码器在文档理解、图表解析等任务上表现优于传统对比学习模型，且训练效率更高（仅需少量样本即可超越大规模对比学习方案）。
