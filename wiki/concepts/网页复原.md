# 网页复原

**网页复原**是指 AI 模型通过分析网页的静态截图，自动生成对应的 HTML/CSS 代码，从而重建出可交互的网页界面的技术能力。

## 技术要求
这不仅仅是简单的 OCR（光学字符识别），而是要求模型具备深层的 **UI 理解能力**：
1. **布局识别**：理解导航栏、按钮、文本框、图片等元素的空间排列。
2. **样式推断**：根据视觉特征推断字体、颜色、间距等 CSS 属性。
3. **逻辑还原**：识别可交互元素（如链接、按钮）并赋予其正确的功能逻辑。

## 实测案例
在 [[DeepSeek Vision]] 的测试中，模型能够将网页截图直接转换为可用的 HTML 代码。生成的页面不仅排版还原度高，甚至保留了按钮的跳转功能（如自动配置 API 文档链接），展示了从“看图”到“工程实现”的跨越。

## 应用价值
- **快速原型开发**：设计师可截图直接生成前端代码。
- **爬虫与数据迁移**：将无法直接抓取的图形化界面转化为可操作的数据结构。
