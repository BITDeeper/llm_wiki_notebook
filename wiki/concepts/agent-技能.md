# Agent 技能

Agent 技能是指赋予 AI 智能体特定领域能力或执行特定任务功能的插件或模块。

## 定义
类似于人类技能的习得，AI 智能体通过加载不同的“Skills”来扩展其原生能力边界。例如，一个基础的大语言模型可能擅长对话，但无法联网搜索或生成图片，通过加载“搜索技能”或“绘图技能”，智能体便具备了相应的能力。

## 技术实现
- **工具调用**：技能通常封装为 API 接口或本地函数，智能体根据任务需求自主决定调用哪个技能。
- **插件生态**：通过类似于 [[clawhub]] 的仓库进行分发和管理。
- **配置化**：在配置文件中声明所需的技能列表，系统在启动时自动加载。

## 典型案例
在 [[openclaw]] 生态中，[[百度千帆]] 提供了七大核心 Skills：
- **信息获取**：搜索、百科、学术检索。
- **内容生成**：绘本、PPT 生成。
- **复杂任务**：深度研究 Agent。

这些技能使得 OpenClaw 从一个简单的聊天机器人转变为能够处理实际业务（如制作演示文稿、查阅文献）的生产力工具。
