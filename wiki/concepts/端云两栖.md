# 端云两栖

「端云两栖」是一种混合计算架构模式，旨在同时利用云端大模型的强推理能力和端侧小模型的数据安全与低延迟特性。这一概念由 [[面壁智能]] 在发布 [[EdgeClaw]] 时提出，作为对「云端 API 派」和「本地模型派」二元对立的第三条道路。

## 核心理念
-   **拒绝二选一**：认为用户不应在「数据裸奔/高成本」（云端派）与「能力受限」（本地派）之间做单选题。
-   **优势融合**：通过智能调度，让云端负责复杂推理，端侧负责隐私保护和高频任务。

## 技术实现
端云两栖的实现通常依赖于以下机制：
1.  **隐私路由**：根据数据敏感度（如 S1/S2/S3 分级）自动分配计算节点。
2.  **模型协同**：云端使用超大参数模型（如 GPT-4 级别），端侧部署轻量级高性能模型（如 [[MiniCPM]]）。

## 优势
-   **安全性**：核心数据（S3 级）物理隔离，不上传云端。
-   **成本效益**：大量基础任务由本地零成本完成，仅少量复杂任务调用昂贵的云端 API。
-   **鲁棒性**：支持 [[断网干活]]，在弱网或无网环境下仍能维持基础服务能力。

## 适用场景
-   **OPC（一人公司）**：需要处理敏感商业数据，同时受限于成本。
-   **金融与审计**：对数据合规性有极高要求。
-   **工业现场**：网络环境不稳定或完全离线的生产环境。

## 行业意义
这一架构试图解决 [[ai-subscription-crisis]]（AI 订阅制危机）中关于成本失控的问题，同时也回应了市场对数据隐私的日益增长的需求。
