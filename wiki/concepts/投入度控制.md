# 投入度控制

投入度控制（Effort Control）是 [[claude-opus-4-8]] 引入的用户可调节机制，允许用户设定模型在生成回复时应投入的精力与资源量，直接影响 Token 消耗量和响应质量。

## 四档设置

| 档位 | 说明 |
|------|------|
| Low（低投入） | 响应速度更快，消耗速率限制更慢 |
| High（高投入） | 更频繁深入的思考，质量与体验的最佳平衡（Opus 4.8 默认） |
| Extra High（额外投入） | 消耗更多 Token 以产出更优质结果，适合高难度任务 |
| Max（最大投入） | 最高投入级别，适合耗时长的异步工作流 |

## 设计理念

投入度控制赋予用户在"速度 vs. 质量"之间的选择权。在 [[claude-code]] 中，"额外投入"对应"xhigh"选项。Anthropic 已上调速率限制以适应高投入度下的 Token 消耗增加。

## 关联

- 与 [[tokenmaxxing]] 相关：高投入模式将 Token 消耗推向新量级。
- 与 [[ai-subscription-crisis]] 相关：用户对 Token 消耗的控制权是订阅制危机的一种缓解机制。
- 编程类任务中，高投入级别的 Token 消耗量与 Opus 4.7 默认设置相近，但性能更优。
