# BOLA漏洞

**BOLA**（Broken Object Level Authorization，对象级授权失效）是 OWASP API 安全列表中排名第一的漏洞类型。它发生在系统未能正确验证用户是否有权访问特定对象（如数据库中的特定记录或文件）时。

### 原理
在正常的软件工程逻辑中，访问控制应确保：
1. 用户已通过身份验证（我是谁？）。
2. 用户已获得授权（我能做什么？）。
3. **对象级授权**（我有权访问*这个*特定的对象吗？）。

BOLA 漏洞通常发生在第三步的缺失。例如，用户 A 登录后，系统可能只检查了「用户 A 是否登录」，却未检查「用户 A 是否拥有访问 ID 为 123 的资源的权限」。

### ICLR 2026 泄露门案例
在 [[ICLR 2026泄露门]] 中，[[OpenReview]] 平台的 `profiles/search` API 存在 BOLA 漏洞。攻击者只需将 URL 中的参数（如 `Submission{paper_id}/Authors`）中的 ID 进行替换，即可访问任意论文的作者、审稿人等敏感信息，无需任何黑客技术或复杂工具。

### 影响
BOLA 漏洞往往被认为是「低级错误」，但其后果可能是灾难性的，特别是在涉及敏感数据（如学术评审隐私、个人身份信息）的系统中。
