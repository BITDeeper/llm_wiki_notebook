# 上下文外编排

上下文外编排（Out-of-Context Orchestration）是 [[动态工作流]] 的核心技术设计理念，指将 AI 智能体的编排逻辑从对话上下文移入独立的代码脚本中执行。

## 问题背景

此前 Claude Code 的子智能体机制中，Claude 本身逐轮决定下一步做什么，每个中间结果都要回到对话上下文中。这导致：

- 大量 token 被中间过程占用
- 任务规模增大时计划容易偏离
- 主会话被长时间占用无法响应

## 解决方案

在动态工作流中，Claude 动态生成 JavaScript 编排脚本，所有中间结果存储在脚本变量中而非对话上下文里：

- Claude 的上下文中只保留最终结果
- 主会话始终保持响应状态
- 任务规模不受上下文窗口限制
- 编排逻辑可持久化、可断点续跑

## 意义

这一设计解决了大规模多智能体编排中 token 占用和计划偏离的根本性问题，是 [[1-n-agent调度]] 从理论走向工程实践的关键技术突破。
