# 低延迟图传

低延迟图传是将端侧多路视觉以GPU直编直解方式传入云端显存的技术，是 [[端云协同]] 架构的核心数据通路。与传统面向人类观看的通用视频流不同，低延迟图传围绕"画面直接进入云端模型"设计。

## 技术原理

- **GPU直编直解**：通过GPU编码、GPU解码和GPU侧色彩转换，减少CPU-GPU往返搬运
- **视觉输入直达推理链路**：使视觉输入更快进入模型推理链路
- **近网中继**：靠近云端推理服务的中继方案，适配实验室内网、企业网络和云厂商VPC等复杂环境
- **多路并发**：支持多路相机并发上云

## 性能指标（LiOS实现）

| 方案 | 延迟 |
|------|------|
| LiOS GPU图传 | 约30ms（网络部分24ms） |
| Livekit TCP隧道 | 77ms |
| 跨区公网Cloud部署 | 165ms |
| 加速比 | 2.1-6.9倍 |

- 单路GPU图传解码吞吐：每秒数千帧量级
- 传输协议：WebRTC/GStreamer

## 关键差异

与面向人类观看的通用视频流相比，低延迟图传的核心差异在于：

- 终端消费者是模型而非人眼，无需主观画质优化
- 数据流终点是GPU显存而非显示器
- 追求的是端到端（相机传感器到模型输入张量）的最短路径
