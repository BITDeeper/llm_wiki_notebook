# 有状态智能体交互

[[有状态智能体交互]]（Stateful Agent Interaction）是一种新的 API 交互模式，与传统的无状态「请求-响应」模式相对。在这种模式下，服务器负责维护会话状态、上下文历史和工具调用结果，而非每次请求都由客户端发送全部历史数据。

## 核心优势

### 降低客户端复杂度
开发者无需在客户端编写复杂的代码来管理对话历史和上下文窗口，只需通过简单的会话 ID 与服务器交互。

### 提升性能与降低成本
-   **缓存命中**：服务器端可以更有效地缓存和处理重复的上下文信息。
-   **减少带宽**：避免了每次请求都传输数万 token 的历史记录，显著降低带宽成本和延迟。

### 支持长时程任务
对于需要运行数分钟甚至数小时的复杂任务（如 [[深度研究]]），有状态交互允许任务在后台执行，客户端无需维持长连接，只需轮询或等待回调。

## 实现案例
谷歌的 [[Interactions API]] 是这一概念的具体实现，它提供了 `/interactions` 端点来创建和管理有状态的会话。

## 行业意义
从无状态向有状态的转变，标志着 AI 应用开发从简单的「对话模型」调用，转向构建复杂的、具备记忆和规划能力的「智能体系统」。
