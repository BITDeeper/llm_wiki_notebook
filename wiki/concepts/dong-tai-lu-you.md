# 动态路由

**动态路由** (Dynamic Routing) 是一种根据输入数据的特性，动态决定调用哪些模型、模块或计算资源的技术。在 AI 系统中，它旨在打破“全量计算”的范式，通过智能调度实现资源的高效利用。

## 核心思想

传统系统往往对所有输入执行相同的计算流程（例如调用所有模型）。动态路由则引入了一个“决策者”（通常是轻量级模型或规则），在计算发生前或计算过程中进行判断：
-   **谁需要参与**：识别出对当前输入最有效的模型子集。
-   **谁可以跳过**：过滤掉无效或冗余的计算单元。

## 在多智能体系统中的应用

在 [[Mixture-of-Agents]] (MoA) 系统中，[[RouteMoA]] 是应用动态路由的典型案例。它利用 Query 的特征进行**先验筛选**，避免了让所有模型都进行推理（即 [[预推理]]），从而将计算成本降低了近 90%。

## 理论基础：稀疏性

动态路由的有效性通常基于**稀疏性**假设：对于特定的任务或输入，只有少数模型是真正有效的。只要路由机制能准确识别这些关键模型，系统就能在保持性能的同时大幅降低开销。

## 优势

-   **降低成本**：减少无效的 Token 生成和 API 调用。
-   **降低延迟**：并行调用的模型数量减少，系统响应速度加快。
-   **提升可扩展性**：使得系统能够轻松接入大规模模型池，而不会导致计算量爆炸。
