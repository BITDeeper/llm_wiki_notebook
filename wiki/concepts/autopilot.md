# Autopilot（企业级自主Agent）

拥有独立身份、许可证和记忆，7x24小时在企业租户中自主运行的长效Agent。[[萨蒂亚·纳德拉]]将其定义为"企业级的龙虾"。[[scout]]是首个实例。

## 核心特征

- **独立身份**：有自己的名字、人格、自定义连接器
- **持久记忆**：拥有独立的上下文和记忆，跨会话保持
- **自主运行**：7x24小时在企业租户中工作，无需人工触发
- **企业合规**：从第一天起内置企业级管控
- **生产力许可证**：作为独立的数字员工存在

## 与其他Agent形态的区别

| Agent形态 | 触发方式 | 运行时长 | 身份 | 典型代表 |
|-----------|---------|---------|------|---------|
| Chat | 用户主动提问 | 单次对话 | 无 | Copilot Chat |
| Cowork | 用户委派任务 | 多步骤 | 无 | Copilot Cowork |
| [[openclaw]] | 用户指令 | 任务周期 | 无 | OpenClaw |
| Autopilot | 自主触发 | 7x24 | 独立 | [[scout]] |

## 与[[1-n-agent调度]]的关系

Autopilot代表了从1:1对话到长效自主Agent的范式升级，是[[1-n-agent调度]]概念在企业场景的具体实现。未来Copilot将构建一整支Autopilot"数字团队"。
