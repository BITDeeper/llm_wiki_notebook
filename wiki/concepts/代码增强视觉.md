# 代码增强视觉

[[代码增强视觉]] 是一种利用大模型的编程能力，通过编写和执行代码（如 Python）来弥补视觉感知中精度短板的技术范式。

## 核心思想
传统的多模态模型（VLM）通常依赖“语言化视觉”或直觉式“瞪眼观察”来处理图像。虽然它们具备强大的代码生成能力，但在基础视觉任务（如精确计数、测量距离、读取图表数值、几何推理）上往往表现不佳。这是因为端到端的感知机制缺乏精确计算能力，容易产生幻觉。

代码增强视觉通过允许模型调用 Python 代码解释器，将视觉问题转化为计算问题。模型可以“掏出 Python 尺子”，通过编写代码来加载图像、绘制辅助线、计算数值，从而获得比直觉感知更精确的结果。

其核心逻辑遵循以下步骤：
1.  **观察**：模型先对图像进行初步感知。
2.  **计算**：编写代码调用图像处理库（如 PIL, OpenCV, NumPy）进行精确计算。
3.  **验证**：将计算结果回传给模型，进行逻辑校验和最终判断。

## 实现机制
这一范式通常依赖于以下机制：
1.  **工具调用**：模型能够发起代码执行请求。
2.  **环境支持**：提供一个支持图像处理库（如 PIL, NumPy, Matplotlib）的执行环境。
3.  **结果回传**：代码执行产生的数值、文本或生成的可视化图像被反馈给模型，供其进行下一步决策。

## 优势
*   **精度提升**：通过程序化计算消除视觉直觉的模糊性。
*   **可解释性**：生成的代码提供了清晰的推理路径，便于人类审计。
*   **通用性**：无需为特定任务设计专用 API，通用的 Python 环境即可覆盖广泛的视觉任务。

## 典型案例
[[SWE-Vision]] 是这一范式的典型实现。它证明了仅靠通用的 Python 接口（极简设计），就能系统性地提升模型在多个视觉基准上的表现，甚至超越 [[GPT-5.2-xhigh]] 等顶尖模型的原生输出。

这与 [[claude-code]] 在软件工程领域的逻辑一致，即利用代码作为“外脑”来扩展核心模型的认知边界。

## 认知框架关联
在 [[三系统认知框架]] 中，代码增强视觉是典型的“系统3”（外接认知系统）应用。它利用系统3强大的逻辑和计算能力，来校准和增强系统1（视觉直觉）的输出，解决了单一系统容易产生幻觉和精度不足的问题。
