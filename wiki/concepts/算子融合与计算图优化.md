# 算子融合与计算图优化

算子融合与计算图优化是大模型训练加速的核心技术手段，通过消除 Python 层调度开销和 GPU launch 瓶颈来榨干 GPU 峰值性能。

## 核心技术

### Torch Compile
- 通过底层编译优化，对算子进行深度融合（Kernel Fusion）
- 针对 Diffusion 架构中的低效算子（如 WanRMSNorm、adaLN-zero）进行专门优化
- 减少算子间的内存读写开销

### CUDA Graph
- 将计算图固化，消除 GPU launch 的 CPU 调度瓶颈
- 对 kernel launch 密集的部分（如 CausalWanSelfAttention）效果显著
- 将多次 GPU 调用合并为单次图执行

## 在 DreamZero 中的应用

[[rlinf|RLinf]] 框架通过 Torch Compile + CUDA Graph 的深度融合：

- **DreamZero-5B**：单步耗时从 1.8s 降至 1.2s，实现 50% 加速
- **DreamZero-14B**：单步耗时从 9s 降至 6.7s，实现 34% 加速

## 与其他优化主题的关联

- 与 [[批次不变性]] 同属底层系统优化范畴，但侧重点不同：算子融合追求极致性能，批次不变性追求数值确定性
- 需要与 Recompute（激活重计算）、FSDP2 等并行策略深度协同
