# 跨设备 Agent

跨设备 Agent 是指人工智能智能体不再局限于单一设备（如仅在工作站上通过浏览器或终端交互），而是能够跨越移动设备（如手机）和固定设备（如 PC、Mac）进行协同工作的技术范式。

## 范式演进
跨设备 Agent 代表了 AI [[操作半径]] 的进一步扩展：
1. **对话框时代**：AI 仅存在于聊天窗口内。
2. **浏览器时代**：AI 能够生成和操作网页内容。
3. **桌面时代**：AI 能够通过 [[Cowork]] 等技术直接操作本地操作系统。
4. **跨设备时代**：用户可以在移动端发起指令，AI 在其他设备上执行任务。

## 关键特征
- **入口与执行分离**：指令输入端（手机）与任务执行端（Mac/PC）物理分离。
- **情境连续性**：允许用户在非办公场景（如通勤、家中）利用闲置的计算资源（如办公室电脑）处理任务。
- **本地化处理**：为了解决隐私和延迟问题，现代跨设备 Agent（如 [[Dispatch]]）倾向于在执行端进行本地数据处理，而非将所有数据上传至云端。

## 潜在影响
- **工作边界模糊**：随着设备间协作的增强，工作与生活的物理界限可能进一步消解。
- **24小时待命**：计算设备可能演变为“永远在线”的数字劳动力，改变人类对工具的掌控关系。
