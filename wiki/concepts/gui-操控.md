# GUI 操控

[[GUI 操控]]（Graphical User Interface Control）是指 AI 智能体不依赖软件 API 或命令行接口，而是通过模拟人类感知与操作来控制计算机的技术范式。

## 技术原理
1. **视觉感知**：AI 通过实时截取屏幕画面，利用视觉大模型（VLM）识别界面元素（按钮、菜单、文本）。
2. **动作模拟**：根据任务目标，计算并执行鼠标移动、点击和键盘输入操作。
3. **反馈循环**：再次截图确认操作结果，形成闭环控制。

## 优势与局限

### 优势
- **通用性**：打破了软件生态壁垒，可操控任何有图形界面的软件，包括老旧系统、专业软件（如 Photoshop、CAD）或未开放 API 的应用。
- **拟人化**：能够完成需要复杂视觉判断的任务，操作逻辑与人类无异。

### 局限
- **高成本**：依赖视觉模型进行实时分析，导致 [[Token 消耗]] 极大，远高于纯文本 API 调用。
- **低效率**：相比 API 调用，GUI 操作速度较慢，且受界面渲染和响应时间影响。
- **安全风险**：赋予 AI 直接控制桌面的权限增加了误操作或恶意操作的风险，通常需要配合 [[Docker 隔离环境]] 使用。

## 应用场景
- [[RPA]]（机器人流程自动化）的智能化升级。
- 复杂软件的自动化测试与操作。
- 个人助理层面的无人值守任务执行（如定时整理文件）。
