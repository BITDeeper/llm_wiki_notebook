# 黄金上下文

**黄金上下文**（Gold Contexts）是指在解决特定软件工程问题（如 Bug 修复）时，由人类专家标注的、不可或缺的最小代码依赖集。它作为评测基准中的“标准答案”，用于衡量 AI 智能体检索相关代码的精准度。

## 构建方法
黄金上下文的构建并非简单的关键词匹配，而是基于严谨的逆向工程分析：
1. **真实任务溯源**：基于真实开源仓库的 Issue 与补丁。
2. **依赖回溯**：专家分析实际补丁，沿函数调用、类引用与变量依赖关系逐步回溯。
3. **最小化集**：确定解决问题必须阅读的代码片段（文件/代码块/行），排除无关代码。

## 作用
在 [[contextbench]] 等评测基准中，黄金上下文用于计算：
- **精确率**（Precision）：Agent 检索到的代码中有多少是黄金上下文？
- **召回率**（Recall）：黄金上下文中有多少被 Agent 检索到？
- **F1 分数**：综合评估检索质量。

## 价值
黄金上下文将评测从“模糊的相关性”转变为“精确的必要性”。它不仅判断 Agent 是否“读了代码”，更判断 Agent 是否“读对了代码”，从而揭示了 [[信息整合瓶颈]] 等深层问题（即 Agent 读到了黄金上下文却未在补丁中使用）。
