# Agent模型训练范式

Agent 模型训练范式是指专为智能体场景设计的系统化训练流程，区别于传统大语言模型的通用训练方法。[[skyclaw-v1|SkyClaw-v1.0]] 的训练流程是这一范式的代表性实践。

## 三阶段训练流程

### 第一阶段：环境构建

- 搭建高复杂度的模拟智能体环境（如模拟 OpenClaw 环境）
- 内置丰富的高质量工具和技能供模型探索调用
- 深入分析真实用户的实际任务行为
- 结合线上高频技能的使用数据和反馈，梳理工具之间的关系图谱
- 基于图谱合成贴近真实用户需求的复杂任务

**核心目标**：解决"用什么数据来练"的问题。

### 第二阶段：中期训练与监督微调（SFT）

- 基于验证过的训练环境合成海量高质量训练数据
- 建立严格的过滤和评估机制
- 不仅考核最终答案正确性，还回溯评估任务完成的完整轨迹
- 进行大量数据配比实验，找到智能体任务训练数据的最优组合

**核心目标**：解决"如何练出基础能力"的问题。

### 第三阶段：强化学习（RL）

- 利用自建环境的端到端探索与反馈能力
- 确保模型在特定任务上表现出色的同时，在不同智能体框架和陌生任务场景下保持稳定的泛化能力

**核心目标**：解决"如何进一步提升性能上限和泛化性"的问题。

## 核心理念

这一训练范式不依赖单点突破，而是围绕"真实智能体场景下的可用性"这一目标，实现数据、训练与优化的贯通。关键在于从训练阶段就让模型接触到足够真实与复杂的场景，而非通用实验室数据。
