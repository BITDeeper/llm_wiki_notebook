# 云端虚拟机

**云端虚拟机**（Cloud VM）是指为 [[AI Agent]] 提供的一个完整的、隔离的电脑运行环境。这个环境包含完整的操作系统、文件系统、网络栈等，使得 AI 能够像人类一样操作工具和执行任务。

## 技术背景
在 [[AI Agent]] 的发展过程中，早期的尝试（如基于浏览器内核的 AI 浏览器）往往受限于容器的权限和功能。浏览器无法处理某些需要系统级权限或复杂环境配置的长尾任务。

## 核心优势
- **完整操作能力**：AI 可以执行命令（如 `git clone`）、安装特定软件、运行自己编写的代码。
- **隔离性与安全性**：在独立的虚拟环境中运行，避免影响宿主系统。
- **处理长尾任务**：能够应对各种非标准和复杂的任务场景，这是单纯的 API 调用或浏览器操作难以实现的。

## 应用场景
[[Manus]] 采用了“大模型 + 云端虚拟机”的架构，让 AI 拥有了“手”和“脚”，从而实现了从提供信息到直接交付结果的转变。这与 [[runtime-agent-os]] 的理念相呼应，为 Agent 提供了必要的底层支撑。
