# Agent 工作流优化

**Agent 工作流优化**（Agent Workflow Optimization）是指针对大语言模型在智能体场景下的特定需求，对模型进行的训练或微调优化。其目标是提高模型在自主规划、调用工具和执行复杂任务链时的准确性和稳定性。

## 核心目标
- **高准确率工具调用**：确保模型能正确选择和生成 API 调用参数，减少格式错误或调用失败。
- **任务规划能力**：模型能够将模糊的指令拆解为可执行的步骤。
- **上下文管理**：在长对话或多轮交互中保持对任务状态的记忆和追踪。

## 应用场景
在 [[pony-alpha]] 的描述中，特别强调了其针对 Agent 工作流做了优化。这意味着该模型不仅适合单轮对话，更被设计用于：
- 编写并执行代码。
- 操作外部软件或 API。
- 自动化处理复杂的办公或开发流程。

## 技术意义
随着 AI 从“聊天机器人”向“智能体”演进，单纯的对话能力已不足以满足需求。Agent 工作流优化成为了区分通用模型和工程化模型的重要分水岭。具备这一特性的模型通常在编程、逻辑推理和指令遵循方面表现更为出色。
