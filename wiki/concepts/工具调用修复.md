# 工具调用修复（Tool-Call Repair）

工具调用修复是 [[reasonix]] 针 [[DeepSeek V4]] 模型常见的工具调用异常而设计的自动修复机制，最多进行 4 轮处理，确保草稿区内容在归入历史日志前被提炼为稳定格式，从而维护前缀一致性。

## 修复的四类异常

1. **JSON 消失**：工具调用 JSON 在模型内部已生成，但在最终输出消息中却消失不见。
2. **参数畸形**：模型意图调用工具，但 JSON 参数格式错误，无法正确解析。
3. **重复调用风暴**：同一工具被反复调用且参数完全相同，造成无意义的 token 消耗。
4. **JSON 截断**：输出因长度限制被截断，导致 JSON 不完整。

## 设计意义

工具调用修复不仅提升了 Agent 的鲁棒性，更重要的是服务于 [[前缀缓存优化]] 的整体架构：通过在草稿区将不稳定的模型输出提炼为确定性格式，确保归入历史日志的内容字节级稳定，从而维持高缓存命中率。
