# 全栈应用构建系统

[[全栈应用构建系统]] 是一种超越传统“AI 辅助编程”的下一代开发范式。它不仅帮助开发者编写代码片段，而是直接处理软件开发的完整生命周期，包括身份验证、数据库构建、前端界面生成和部署上线。

## 核心特征
与 [[Cursor]]（优化编码速度）、[[Replit]]（降低入门门槛）和 [[Vercel]]（解决部署问题）等现有工具不同，全栈应用构建系统旨在让“写代码”这一行为本身变得多余。用户只需通过自然语言描述需求，系统即可自动生成完整的应用程序。

## 战略意义
对于 [[Anthropic]] 等公司，构建此类系统是应对 [[模型商品化]] 和 [[ai-subscription-crisis]] 的关键战略。通过控制用户的工作流、数据和部署环境，平台可以建立深层的 [[平台锁定]]，从而避免在 API 价格战中失去客户。

## 相关概念
- [[任务执行范式]]：从模型开发转向智能体工程化系统。
- [[审美法官]]：在该系统下，人类角色从执行者转向决策者。
