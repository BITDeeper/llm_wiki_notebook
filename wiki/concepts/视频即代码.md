# 视频即代码

将视频制作流程（生图、剪辑、字幕、配音、导出）转化为代码工作流的技术范式。视频不再是非结构化的媒体文件，而是由 HTML+CSS+JS 代码定义的可编程对象。

## 核心理念

传统视频制作需要在多个专业软件（如 Photoshop、Premiere、After Effects）之间切换，每个软件有独立的工作流和操作逻辑。"视频即代码"将整个流程统一到代码层面，使视频制作具备以下特性：

- **可编程**：视频的每一帧、每个元素都可通过代码精确控制
- **可迭代**：修改某个细节只需修改对应代码，无需重新制作整个视频
- **可版本管理**：视频文件可以像代码一样进行版本控制和差异比较
- **可自动化**：通过自然语言或代码指令驱动 AI 自动完成制作流程

## 发展历程

- **2026年1月**：Remotion + [[claude-code]] 推出首个"视频即代码"方案，但门槛较高，用户需要懂 React 才能理解和修改生成的代码
- **2026年5月**：[[codex]] 接入 [[heygen]] 插件，将门槛降至零——用户无需懂 HTML、React、FFmpeg，仅需用自然语言描述需求

## 与 Vibe Coding 的关系

[[vibe-coding]] 是"零代码氛围编程"的通用理念，用户通过自然语言描述即可生成可运行的工程文件。"视频即代码"是 Vibe Coding 在视频制作领域的具体应用和延伸，表明这一范式正在从编程领域向多媒体内容生产领域渗透。

## 意义与局限

**意义**：将专业视频制作从"手艺活"转变为"对话式"工作流，大幅降低门槛，使非专业用户也能完成口播视频、字幕添加、自动剪辑等操作。

**局限**：目前主要适用于口播讲解类视频，对于特效制作、调色、多轨剪辑等复杂场景的能力尚未验证。
