# 元生成器

**[[元生成器]]**（Meta-Generator）是 [[MetaCompress]] 框架中的核心组件，是一个轻量级神经网络。

## 功能
元生成器的作用是**仅根据输入图像本身**，自适应地生成最优的 [[Token压缩]] 映射（压缩矩阵）。它不依赖于具体的文本 Prompt，从而避免了因 Prompt 变化导致的压缩策略偏差。

## 核心特性
1.  **多尺度适配**：通过自适应下采样层，元生成器可以处理不同分辨率和不同数量的输入 Token，兼容 LLaVA-NeXT 等主流多尺度 LVLM 架构。
2.  **数据驱动**：摒弃了人工设计的剪枝规则（如基于注意力分数的阈值），通过学习数据分布来决定哪些 Token 应该被保留。
3.  **轻量化**：通常由少量线性投影层构成，引入的计算开销极低，不会显著增加模型的推理负担。

## 意义
元生成器的引入使得 Token 压缩从“基于规则的静态处理”转变为“基于内容的动态学习”，是实现高效 [[多轮视觉问答]] 的关键技术突破。
