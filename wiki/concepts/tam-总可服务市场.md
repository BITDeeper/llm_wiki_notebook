# TAM（总可服务市场）

TAM（Total Addressable Market）是企业估算其产品/服务可触及的全部市场总规模的指标，常用于IPO招股书中支撑估值叙事。

## SpaceX的TAM案例

[[spacex]]在2026年S-1招股书中声称锁定28.5万亿美元TAM，被称为"人类史上最大的可服务市场"：

| 领域 | 规模 |
|------|------|
| AI（合计） | 26.5万亿美元 |
| — 企业级AI应用 | 22.7万亿美元 |
| — 太空数据中心 | 2.4万亿美元 |
| — 消费者订阅 | 7600亿美元 |
| — 数字广告 | 6000亿美元 |
| 网络连接 | 1.6万亿美元 |
| 传统太空 | 3700亿美元 |

AI占整个TAM的93%以上。

## 审慎看待

28.5万亿美元相当于全球GDP的四分之一，其中企业级AI应用22.7万亿的数字极度激进，带有明显的招股书营销色彩。这一TAM叙事需结合SpaceX实际业务进展和盈利能力综合判断。
