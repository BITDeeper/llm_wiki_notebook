# 超级 Agent

超级 Agent 指的是能够接管用户所有数字化生存空间（如通用桌面任务、文件管理、跨应用操作）的 AI 智能体，其能力范围远超传统的单一对话框或专用工具。

## 定义与特征

与仅限于聊天或特定任务（如写代码）的 AI 不同，超级 Agent 具备以下特征：
- **通用性**：能够处理电脑上的各种任务，而不仅仅是编程或问答。
- **控制权**：拥有对操作系统的深度访问权限，可以管理文件、调用应用程序、执行复杂的工作流。
- **自主性**：在较少的人工干预下完成多步骤的目标。

## 行业动态

[[OpenAI]] 正在积极布局这一领域。2026 年 5 月初，[[Codex]] 完成了从编码工具到通用桌面 Agent 的升级，Sam Altman 亲自推广其“非编码电脑工作”能力。这被视为 OpenAI 从模型提供商向“超级 Agent”构建者转型的明确信号。

## 技术支撑

[[GPT-5.6]] 的后台测试被认为是为了支撑这种超级 Agent 体验而进行的底层能力升级。为了实现可靠的桌面级操作，模型需要具备更强的推理能力、上下文理解能力和工具调用稳定性，这推动了模型从“对话式”向“任务执行式”的进化。
