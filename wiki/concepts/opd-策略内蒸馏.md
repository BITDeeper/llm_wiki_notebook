# OPD（策略内蒸馏）

OPD（On-Policy Distillation）是 [[双粒度效率感知强化学习]] 框架中微观 Token 层面的核心机制，用于精准抢救失败轨迹中的「正确中间过程」。

## 工作机制

1. **触发条件**：仅在轨迹最终答错时启动
2. **教师介入**：引入 235B 满血版教师模型
3. **稠密监督**：为失败轨迹中的每一步提供 Token 级别的监督信号
4. **精准打捞**：保留原本正确的中间规划和推理过程

## 非对称设计哲学

「仅在失败时蒸馏」的设计是关键创新：
- 避免了对学生模型「高效并发」本能的覆盖
- 成功轨迹由 [[trace-动态参考成本效率奖励|TRACE]] 宏观奖励主导效率优化
- 失败轨迹由 OPD 微观蒸馏托底纠偏

## 隐性成本

OPD 依赖 235B 教师模型进行失败轨迹蒸馏，这意味着小模型（30B）的推理效率优势实际上建立在更大模型的训练时算力投入之上，存在「训练时低效、推理时高效」的隐性成本。
