# 对角线并行解码

对角线并行解码是 [[flashar]] 框架的核心创新，通过为预训练自回归模型新增垂直方向预测能力，将解码过程从逐个串行转变为沿对角线并行执行。

## 核心原理

传统自回归图像生成遵循光栅扫描顺序，每步仅预测水平方向的下一个 token，H×W 个 token 需要 H×W 步。

对角线并行解码的关键洞察：图像天然具有 2D 结构。如果模型同时具备水平方向和垂直方向的预测能力，则在每个步骤中，沿对角线的所有 token 可以并行生成。

**步数缩减**：从 H×W 降至 H+W-1。

**实例**：512×512 分辨率（16×16 下采样），解码步数从 1024 步降至 63 步。

## 实现要素

对角线并行解码的有效实现依赖三个关键设计：

1. **[[中间层分支]]**：从模型中间层引出垂直预测头，利用中间层保留的丰富 2D 空间信息
2. **[[可学习融合门]]**：逐位置自适应融合水平与垂直方向的预测结果
3. **[[两阶段适配训练]]**：渐进式训练策略确保稳定性和数据效率

## 与其他并行解码方案的区别

- **vs. NAR（近邻预测）**：NAR 需从头训练，对角线并行解码通过后训练适配复用已有模型
- **vs. PAR（分组并行）**：PAR 同样需从头预训练，对角线并行解码仅需 0.05% 原始训练数据
- **vs. 离散扩散**：不改变原始预测目标，避免预训练-推理不一致性
