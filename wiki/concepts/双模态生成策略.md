# 双模态生成策略

[[双模态生成策略]] (Dual-Mode Generation Strategy) 是 [[PaperBanana]] 为解决不同类型图表绘制难题而采用的架构设计。

## 核心逻辑
根据图表类型自动切换生成模式：
1.  **逻辑图（架构图、流程图）**：使用 **图像生成模式**。利用扩散模型（如 [[Nano Banana Pro]]）的构图能力，生成具有设计感的图形。
2.  **统计图（柱状图、雷达图、热力图）**：使用 **代码生成模式**。利用 LLM 编写 Python Matplotlib 代码，通过运行代码来渲染图表。

## 优势
-   **解决幻觉**：绕过了扩散模型“不识数”的缺陷，确保统计图数据点精确无误。
-   **可复现性**：代码生成的图表易于修改和调试，符合科研严谨性要求。
-   **审美与精度兼得**：逻辑图追求视觉冲击力，数据图追求绝对准确。
