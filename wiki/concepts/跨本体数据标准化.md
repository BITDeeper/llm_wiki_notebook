# 跨本体数据标准化

跨本体数据标准化是指通过统一的数据格式和接口标准，使得不同形态（本体）的机器人采集的数据可以互通互用。这是解决具身智能领域“数据孤岛”问题的关键路径。

## 实现方式
- **统一格式**：如 [[LeRobot]] 4.0 定义的标准数据集格式，规范了姿态、轨迹和元数据的存储方式。
- **标准接口**：硬件厂商遵循统一的 API 规范，使得不同机械臂或机器人的数据能被同一套代码读取。

## 价值
- **规模化**：允许汇集来自不同硬件的数据，扩大训练集规模。
- **泛化性**：混合不同形态的数据有助于训练出更具泛化能力的模型。
- **降低成本**：开发者无需为特定硬件专门编写数据采集代码，降低了开发门槛。
