# 信息景观鸿沟

**信息景观鸿沟** 是指搜索引擎索引的内容与代码任务实际所需信息之间的错位。

## 具体表现
- **搜索引擎的偏好**：经过几十年优化，搜索引擎擅长检索和展示人类可读的高层文档（如 API 参考手册、教程）。
- **代码任务的需求**：解决复杂的 Bug 或进行依赖迁移时，关键知识往往深埋在源文件、commit diff 或 issue 评论的只言片语中。
- **结果**：Agent 通过搜索拿到的是“概念上正确”的文档摘要，但它真正需要的是“逻辑上精确”的源码细节。这种错位导致搜索往往无法提供决定性的帮助。

## 影响
信息景观鸿沟是阻碍 [[deep-research-for-coding]] 实现的主要障碍之一，解释了为什么单纯的联网搜索能力并不总能转化为编程性能的提升。
