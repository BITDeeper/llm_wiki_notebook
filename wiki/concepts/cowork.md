# Cowork

Cowork 是 [[Anthropic]] 为 [[Claude]] 桌面应用推出的功能集，前身为“Computer Use”。它赋予了 Claude 查看屏幕内容、移动鼠标光标以及点击按钮等图形界面（GUI）操作能力。

## 核心功能
- **屏幕感知**：Claude 能够理解屏幕上的视觉信息。
- **模拟操作**：能够执行人类常见的交互动作（点击、输入、滚动）。
- **任务执行**：基于上述能力完成复杂的桌面任务。

## 功能演进
Cowork 能力是 [[Dispatch]] 功能的基础。Dispatch 将 Cowork 的本地操作能力延伸到了远程控制场景，使得用户无需坐在电脑前，即可利用 Claude 的桌面操作能力。

## 意义
Cowork 标志着 AI 从“对话式工具”向“协作式智能体”的转变，试图通过模拟人类操作来直接解决软件交互问题，而非依赖 API 集成。
