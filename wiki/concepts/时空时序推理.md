# 时空时序推理

时空时序推理是一种结合了**时间序列分析**、**空间图结构**和**自然语言理解**的高级认知能力。它旨在解决现实世界复杂系统（如交通网络、电力系统、疾病传播）中“为什么发生”和“如何传播”的问题，而不仅仅是“未来会发生什么”。

## 核心要素
1. **时间动态**：系统状态随时间的变化趋势（如周期性、趋势性、突发性）。
2. **空间依赖**：节点之间的拓扑连接关系和相互影响。
3. **时空耦合**：不同节点间事件发生的传播延迟和对齐问题。
4. **语义查询**：用自然语言提出的复杂问题，通常涉及因果解释。

## 与传统时序预测的区别
| 维度 | 传统时序预测 | 时空时序推理 |
| :--- | :--- | :--- |
| **核心目标** | 预测未来数值 | 理解因果机制与传播路径 |
| **输出形式** | 数值/曲线 | 自然语言解释 + 路径 + 预测 |
| **关注点** | 拟合精度 | 结构化逻辑与可解释性 |
| **典型问题** | “下个时刻的值是多少？” | “拥堵是从哪里传过来的？” |

## 关键挑战
- **数据对齐**：很难获取同时包含高质量时序数据、准确图结构和语义标注的数据集。
- **模态融合**：如何让模型同时处理数值（时序）、结构（图）和文本（语言）三种异构信息。
- **训练机制**：防止模型在推理时“偷懒”，即仅依赖明显的时间模式而忽略隐式的空间结构。

## 解决方案
以 [[streasoner]] 为代表的最新研究通过以下方式应对这些挑战：
- 使用 **Network SDE + Multi-Agent** 生成严格对齐的合成数据。
- 采用 **三阶段训练**（对齐 -> SFT -> 强化学习）逐步建立推理能力。
- 引入 **空间感知奖励机制**（如 S-GRPO）强制模型利用图结构。

## 应用场景
- **智能交通**：分析拥堵源头，优化信号灯控制。
- **电力系统**：定位故障源，预测级联失效路径。
- **流行病学**：追踪疾病传播路径，识别超级传播事件。
- **金融风控**：分析风险在市场网络中的传导机制。
