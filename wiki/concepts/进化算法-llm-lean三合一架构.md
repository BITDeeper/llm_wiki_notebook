# 进化算法+LLM+Lean 三合一架构

[[alphaproof-nexus]] 的核心架构设计，将三种技术融合为统一的数学证明系统。

## 三大组件

1. **LLM（Gemini 3.1 Pro）**：生成证明草稿，进行思维链推理，分析问题结构
2. **Lean 编译器**：对证明草稿进行形式化验证，提供精确错误反馈（参见 [[编译器反馈锚定]]）
3. **进化算法**：通过 Elo 评分系统和种群数据库驱动草稿优胜劣汰，高分草稿被优先采样、变异、进化

## 四层实现

- **Agent A**：LLM + Lean 反馈循环（最简版）
- **Agent B**：+ AlphaProof 强化学习树搜索
- **Agent C**：+ 进化算法（Elo 评分 + 种群数据库）
- **Agent D**：完整版，三组件协同作战

## 核心洞察

Agent A（最简版）也能解全部 9 题，但 Agent D 在最困难问题上有 2-5 倍成本优势。这表明三合一架构的价值主要体现在成本效率上，而非能力门槛上。
