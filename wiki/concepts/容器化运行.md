# 容器化运行

容器化运行是指将应用程序及其依赖项打包到一个独立的、隔离的运行环境中（如 Docker 容器）进行执行的技术。

## 在 AI Agent 中的重要性
随着 AI Agent（如 [[OpenClaw]]、[[NanoClaw]]）获得执行代码、操作文件系统的权限，安全性成为巨大隐患。如果 Agent 直接运行在用户的主操作系统上，恶意的 Prompt 注入可能导致 Agent 删除用户文件或窃取密钥。

容器化运行解决了这一问题：
- **隔离性**：Agent 的所有操作都被限制在容器内部，无法触及宿主机的核心文件。
- **可审计性**：容器的网络请求和文件修改可以被严格监控和记录。
- **可恢复性**：一旦出现异常或崩溃，可以直接销毁容器并重建，不影响宿主机稳定性。

## 应用案例
[[NanoClaw]] 将容器化运行作为其默认特性，这是其获得 [[Andrej Karpathy]] 推荐的关键原因之一。
