# 反蒸馏

**反蒸馏**（Anti-Distillation）是指 AI 提供商为了防止竞争对手或第三方通过 API 抓取模型输出数据，用于训练自家模型（即“模型蒸馏”或“知识蒸馏”），而采取的一系列技术防御手段。

## 背景
在大模型行业，高质量的合成数据或模型输出是宝贵的资产。竞争对手可能通过“爬虫”大量调用领先模型的 API，收集输入输出对来训练自己的模型，从而以较低成本缩小与领先者的差距。

## 技术手段
根据 [[claude-code]] 源码泄露的分析，Anthropic 采用了激进的反蒸馏措施：

### 1. 流式投毒
- **原理**：在模型返回的输出流中，随机注入虚假的工具调用指令或无意义的噪声。
- **效果**：对于正常用户，这些内容可能只是一闪而过的杂讯或被前端过滤；但对于后台抓取数据的爬虫，这些“毒药”数据会污染训练集，导致被训练的模型产生幻觉或逻辑混乱。

### 2. 打码大法
- **原理**：对模型内部的复杂推理步骤和工具调用细节进行模糊化处理。
- **效果**：输出端不再展示详细的逻辑链条，而是返回像“马赛克”一样的简短摘要。这使得竞争对手无法通过 API 复刻出强大的 Agent 执行逻辑。

## 行业意义
反蒸馏技术的出现，标志着 AI 竞争从单纯的模型性能比拼，延伸到了数据保护和供应链安全层面。它反映了领先厂商在面对“开源”或“低成本”竞争时的防御姿态。
