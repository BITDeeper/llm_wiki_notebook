# Prompt 数据转售

AI 中转站静默记录用户 Prompt 和上下文数据，匿名化处理后打包出售给下游买家的数据变现行为。

## 数据链条

1. 用户发送 Prompt 和上下文 → 经过中转服务器时被静默记录存档
2. 匿名化处理后打包成数据集
3. 出售给下游买家

## 买家类型

- 需要 SFT/RLHF 训练素材的国内大模型公司
- 数据经纪商
- 学术研究机构

## 双重剥削

用户不仅付费使用了服务，还在无偿贡献训练数据——既是客户，也是 AI 生态的「免费燃料」。

## 法律风险

在中国法律框架下，未经用户同意私自收集、存储并转售 Prompt 数据，面临「侵犯公民个人信息罪」的指控。
