# 龙虾税

“龙虾税”（Lobster Tax）是开发者社区对 AI 基础设施提供商（如 Anthropic）禁止用户通过第三方工具（如 [[openclaw]]）使用每月固定订阅额度，迫使其转向按量计费（API）这一政策的戏称。

## 起源与背景

该术语在 2026 年 4 月 Anthropic 针对 [[openclaw]] 的政策调整后广为流传。Anthropic 宣布，Claude 的订阅用户不再允许通过 OpenClaw 等第三方工具使用订阅额度，必须走 API 通道按量计费。

## 官方理由

Anthropic Claude Code 负责人 Boris Cherny 解释称，这是出于工程成本的考虑：
- **[[Agent 用量模式]]**：AI 智能体在运行时会进行持续推理循环、自动重试任务并调用大量第三方工具。
- **成本差异**：这种模式的算力消耗远超普通对话，原有的订阅价格无法覆盖成本。

## 影响

对于重度用户而言，这一政策导致成本急剧上升。例如，有用户计算，原来每月 200 美元的 Claude 订阅费用，在转向 API 后，每天可能就需要消耗 200 美元。

## 商业与伦理争议

- **利益冲突**：这被视为 AI 平台方与应用层工具之间的直接利益冲突。平台方在推出自家竞品（如 Anthropic 的 Cowork）后，通过价格手段限制第三方工具的发展。
- **开源依赖风险**：揭示了建立在第三方 API 之上的开源项目的脆弱性。一旦平台方改变政策，开源项目的生存空间可能被瞬间挤压。
