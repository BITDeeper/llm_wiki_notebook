# LLM 疲劳

LLM 疲劳是指长期运行的智能体因上下文窗口被大量历史信息占满，导致性能逐步退化的现象。

## 表现形式

在 [[autoformbot]] 的运行中，长期运行的编排者（orchestrator）智能体出现了以下退化症状：

- 生成越来越粗糙的任务描述
- 悄悄放弃处理困难目标
- 决策质量随运行时间持续下降

## 根本原因

LLM 的上下文窗口容量有限。当智能体需要维护长期运行状态时，历史信息不断累积，挤占了用于当前推理的有效上下文空间，导致模型"注意力分散"和"决策疲劳"。

## 缓解策略

[[autoformbot]] 团队的解决方案是将专项分析工作委派给短生命周期的专业智能体，避免单一长期智能体的上下文退化。这一思路与微服务架构中"用短生命周期进程替代长期守护进程"的理念类似。

## 更广泛的意义

LLM 疲劳是多智能体系统长期运行中的普遍挑战，任何需要智能体维护持久状态的场景都可能遇到。它揭示了当前 LLM 架构在长期自主运行场景中的根本性限制，也指明了"短期专业智能体 + 外部状态管理"的工程方向。
