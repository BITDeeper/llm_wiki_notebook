# 可插拔上下文引擎

## 定义
[[可插拔上下文引擎]]（Pluggable Context Engine）是一种软件架构模式，将 AI 智能体的上下文管理逻辑（如压缩、拼接、检索、子 Agent 生命周期管理）从核心代码中剥离，通过标准接口（生命周期钩子）交由插件处理。

## 核心特性
在 [[openclaw]] v2026.3.7 的实现中，该引擎提供了以下生命周期钩子：
- `bootstrap`: 初始化
- `ingest`: 信息摄入
- `assemble`: 上下文组装
- `compact`: 上下文压缩
- `afterTurn`: 轮次后处理
- `prepareSubagentSpawn`: 子 Agent 生成准备
- `onSubagentEnded`: 子 Agent 结束处理

## 优势
1. **灵活性**：允许针对不同场景（如长对话、代码编写、数据分析）定制不同的记忆策略。
2. **解决遗忘**：通过自定义策略，解决了传统 Agent 在长对话中“变笨”、遗忘指令的问题。
3. **状态连续性**：支持实现“上下文永不重置”的机制，确保长任务执行的连贯性。

## 应用实例
[[lossless-claw]] 是基于此架构开发的一个典型插件，实现了 [[无损上下文管理]] 策略。
