# 记忆与共识的脆弱性

[[记忆与共识的脆弱性]] 是 [[openstory]] 团队在多智能体实验中发现的核心现象。它揭示了在高度互联的智能体社会中，共享记忆的污染或错误更新能够瞬间瓦解群体共识，导致系统性行为逆转。

## 机制解析
1. **共享记忆**：系统中的 Agent 依赖共享记忆模块来认知环境状态。
2. **共识打破**：当系统广播“孙悟空滥杀无辜”这一记忆时，所有 Agent 的安全阈值瞬间跌破。
3. **集体崩溃**：基于这一新记忆，所有 Agent 独立判定环境不再安全，并触发“逃离”动作，导致社会结构瞬间解体。

## 启示
这一发现表明，在未来的 AGI 系统或多智能体协作网络中，防止恶意信息污染共享记忆、建立共识修复机制是维持系统稳定性的关键。
