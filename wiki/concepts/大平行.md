# 大平行

大平行（The Great Parallel）是 NVIDIA GEAR 实验室主任 Jim Fan 提出的概念，认为机器人领域正在逐步复制 LLM 的发展剧本。

## 核心类比

| LLM 发展阶段 | 机器人对应阶段 |
|--------------|---------------|
| 预训练（GPT 学习预测下一个 token） | 世界模型（学习仿真下一个物理状态） |
| 微调 | 动作微调（将仿真折叠到对真实机器人重要的部分） |
| 强化学习走完最后一英里 | 强化学习优化机器人行为 |

这套三步配方用了六年时间将 LLM 从 GPT-3 带向了 o1。如果这个平行成立，当前的世界模型系统就是物理 AI 的 GPT-2 阶段。

## 战略含义

如果大平行假说成立，那么当前投入世界模型的资本和研发努力将沿着与 LLM 相似的轨迹产生回报。但这一假说本身尚未被验证——物理世界的复杂性可能远超语言空间的复杂性。
