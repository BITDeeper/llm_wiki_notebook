# Director Agent（导演智能体）

[[joyai-echo|JoyAI-Echo]] 框架中的AI视频导演智能体，用自然语言驱动视频创作全流程。使框架从一次性出片工具升级为可迭代的长视频创作系统。

## 核心定位

现实影视制作从来不是一次完成的——从剧本、分镜到拍摄、审片，每个环节都需要反复打磨。传统AI视频生成停留在一次性出片阶段，某个镜头出问题只能重新生成整条视频。Director Agent 解决了这一痛点。

## 三阶段技术链路

### 策划阶段（编剧兼导演）
- 理解用户自然语言意图
- 将需求扩展为完整故事框架
- 补充角色设定、场景信息和叙事逻辑
- 拆解为镜头级规划
- 生成符合模型训练格式的结构化条件

### 生成阶段（现场导演）
- 根据当前镜头内容，从已生成历史镜头中检索最相关信息
- 将参考内容与当前剧本状态整理成模型输入条件
- 让生成模型准确调用角色、场景和剧情上下文

### 点评修改阶段（审片环节）
- 接收用户反馈或自动评价模型发现问题
- 快速定位到具体镜头
- **只对受影响部分进行重生成，不需要推倒重来**
- 修改后结果同步更新到后续剧情，确保故事连贯一致

## 与现有Agent概念的关系

Director Agent 是 [[多agent协作架构]] 和 [[任务执行范式]] 在视频创作垂直场景的具体落地，体现了 [[场景白盒化推理]] 的理念——将AI生成过程从不可见"黑盒"转变为可见、可干预的"白盒"。
