# 内部产品蚕食

指企业引入竞争对手产品进行内部基准测试，结果内部用户偏好转向竞品，反噬自家产品市场份额的现象。

## 典型案例：微软与 Claude Code

2025年12月，[[microsoft]] 向数千名内部开发者开放 [[claude-code]] 使用权限，本意是基准测试和鼓励非技术人员尝试编程。但 Claude Code 在内部极受欢迎，此前91%工程团队使用 [[github-copilot-cli]] 的高频使用率遭到"严重蚕食"。

微软最终不得不以 token 成本过高为由强制取消 Claude Code 授权，要求工程师迁移回 Copilot CLI，并督促 GitHub 团队加速迭代以弥补产品差距。

## 教训

内部引入竞品进行基准测试存在风险：如果竞品产品力显著优于自家产品，测试本身可能成为竞品的内部推广渠道，加速用户流失。
