# Dropshipping

## 定义
[[Dropshipping]]（代发货模式）是一种零售供应链管理模式，其中零售商不持有商品库存，而是将客户订单和运输详情直接转交给供应商或制造商，由供应商直接发货给最终客户。

## 核心特点
- **零库存风险**：零售商无需提前购买和存储商品，降低了资金压力和库存风险。
- **低门槛创业**：无需仓储和物流管理，适合个人和小微企业快速启动电商业务。
- **自动化集成**：现代 Dropshipping 平台（如 [[CJ Dropshipping]]）支持 API 集成，实现订单和物流信息的自动同步。

## 在 AI 时代的进化
- **全流程自动化**：通过 [[企业级 Agent]]（如 [[Accio Work]]），Dropshipping 的选品、上架、营销等环节可实现全自动。
- **一人公司**：个人借助 AI 和 Dropshipping 可快速搭建跨境电商网店，实现“一人跨国公司”模式。
- **Agent-Agent 交互**：未来贸易交互可能由 AI 代表买卖双方进行自动化比价和交易。

## 相关平台
- [[CJ Dropshipping]]：代发货供应商平台，被 Accio Work 集成。
- [[Shopify]]：支持 Dropshipping 模式的电商平台，Accio Work 通过其 API 进行店铺搭建。
