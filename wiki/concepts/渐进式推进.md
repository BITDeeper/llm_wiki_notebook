# 渐进式推进

渐进式推进是一种强制 AI 智能体以小幅度、高频率迭代方式执行任务的策略，旨在防止上下文耗尽和代码烂尾，确保长时任务的连续性和稳定性。

## 核心原则
1. **单步改动**：每次会话只进行一小步功能改动，避免一次性重写大量代码。
2. **干净状态**：每次修改后，环境必须保持可随时合并到主分支的状态（无 Bug、代码整洁）。
3. **可回滚性**：通过描述性的 Git 提交信息，确保任何错误改动都能被快速回滚。

## 实施机制
- **Git 原子提交**：每个功能点或修复都对应独立的提交，便于追踪和回退。
- **进度文件同步**：在 `claude-progress.txt` 等文件中总结当前进展，指导下一轮智能体的行动。
- **测试驱动**：在实现新功能前，先运行现有测试套件，确保基线稳定。

## 优势
- **降低认知负载**：减少了智能体在每次会话中需要处理的上下文量。
- **提高容错率**：即使某一步出错，也能迅速定位并恢复，不会影响整体项目结构。
- **模拟人类习惯**：符合人类工程师“小步提交、频繁集成”的最佳实践。

## 适用场景
特别适合 [[Claude Agent SDK]] 等需要跨越多个上下文窗口的长时运行任务，如全栈 Web 应用开发。
