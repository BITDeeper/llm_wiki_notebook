# Token Plan

Token Plan 是 [[小米]] 推出的一种 AI 服务订阅计费模式，其核心特点是**按 Token 消耗量计费**，而非按 API 调用次数计费。

## 设计理念
该模式旨在更真实地反映 AI 模型的计算成本。在传统的按次计费模式下，复杂的长文本生成任务与简单的问答任务成本差异巨大，但收费相同，导致定价机制扭曲。Token Plan 通过计量实际消耗的计算资源（Token），试图解决这一问题。

## 行业背景与争议
- **争议**：Token Plan 初期推出时，因用户反馈额度消耗过快（1天用完）而引发争议。
- **回应**：[[小米]] 负责人 [[罗福莉]] 发文回应，强调不应盲目降价，以免引发服务质量和用户体验的恶性循环。
- **调整**：随着 [[mimo-v2.5-pro]] 效率的提升，小米调整了计费倍率（从 4 倍降至最高 2 倍）并引入了非高峰时段折扣。

## 影响
这一模式正在影响行业定价标准，促使其他厂商从简单的按次订阅转向更精细化的按量计费或分层定价体系，这与 [[ai-subscription-crisis]] 中提到的行业趋势相呼应。
