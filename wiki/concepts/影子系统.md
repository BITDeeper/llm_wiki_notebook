# 影子系统

影子系统是指在操作系统（OS）层面构建的虚拟化环境，允许 AI Agent 在后台的「逻辑屏」上运行，与用户前台的「物理屏」并行工作。

## 核心功能
影子系统实现了「输入隔离」和「并行运行时」：
- **输入隔离**：用户的物理操作（如打电话、刷视频）与 Agent 的逻辑操作（如比价、订票）互不干扰。
- **并行处理**：Agent 可以在后台执行长任务，即使手机切换到其他应用或锁屏，任务也不会中断。

## 技术意义
影子系统是 [[豆包手机]] 被称为「AI 原生手机」的关键基础设施。它彻底解决了传统 Agent 抢占前台导致手机卡死或无法同时进行其他操作的问题。这种架构类似于在系统中运行了两个并行的宇宙：一个是用户的物理交互空间，另一个是 Agent 的逻辑执行空间。

## 实现推测
虽然字节跳动未公开源码，但基于黑盒测试推测，豆包手机在 Android Framework 层实现了这一机制，使得 Agent 能够在锁屏状态下依然丝滑操作。
