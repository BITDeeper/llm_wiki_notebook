# Apache 2.0

[[Apache 2.0]] 全称 Apache License Version 2.0，是开源软件界广泛使用的一种宽松式许可证。在 AI 和大模型领域，它被视为对商业应用最友好的开源协议之一。

## 核心条款与权利

-   **商业使用**：允许将受保护的代码或模型用于商业目的，包括销售、再许可或将其集成到商业产品中。
-   **修改与分发**：允许自由修改源代码（或模型权重），并在原始协议下分发修改后的版本。
-   **无专利诉讼**：包含专利授权条款，防止贡献者对使用者提起专利侵权诉讼。
-   **免责声明**：声明软件按“原样”提供，不提供任何形式的担保。

## 在 AI 领域的意义

对于 AI 模型而言，采用 Apache 2.0 协议意味着：
1.  **无使用费**：企业和个人可以在不支付任何 API 费用或授权费的情况下使用模型。
2.  **无部署限制**：模型可以部署在任何环境，包括公有云、私有服务器或边缘设备。
3.  **法律确定性**：相比自定义许可证，Apache 2.0 条款清晰，法务审核成本低，降低了企业采用开源模型的风险。

## 行业影响

谷歌在 [[Gemma 4]] 中全面采用 Apache 2.0，取代了此前 Gemma 1/2 时代的自定义协议，被视为对开发者社区呼声的回应。这一举措消除了商用壁垒，被 Hugging Face CEO 称为“开源 AI 社区的分水岭”。
