# AI造AI五级分类（L1-L5）

[[面壁智能]]定义的AI参与研发的成熟度模型，为"AI制造AI"提供了清晰的阶段定义。

## 五级定义

| 级别 | 描述 | 代表产品 |
|------|------|---------|
| **L1** | AI只给建议，人类执行所有操作 | GitHub Copilot |
| **L2** | AI辅助研发，完成具体环节 | [[cursor]]、[[claude-code]] |
| **L3** | AI端到端产出下一代模型 | [[ForgeTrain]] |
| **L4** | AI递归自改进，改造训练管线和自身 | — |
| **L5** | AI自主设定研究议程，开放式探索 | — |

## ForgeTrain的定位

[[ForgeTrain]]处于L3-L4阶段。它还没有到AI自己发明下一代Transformer的程度，但已进入大模型研发最核心的基础设施层——预训练框架。

## 与相关概念的关系

- **[[递归式自我改进]]**：L4阶段直接对应递归自改进概念，本文提供了该概念从理论走向工程实践的具体案例
- **[[ai-takeoff]]**：五级分类本质上是AI Takeoff的阶段性路线图，L5阶段即对应Takeoff的完全实现
- **[[scaling-law]]**：当Scaling Law的"堆料"走到尽头，AI造AI的层级推进成为能力继续提升的替代路径
