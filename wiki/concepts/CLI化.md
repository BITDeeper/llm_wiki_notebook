# CLI化

**CLI化**（Command Line Interface）是指将软件的图形用户界面（GUI）能力重写为命令行界面（CLI）指令的过程。在 AI Agent 时代，这一技术趋势被认为是实现从“副驾驶”到“自主智能体”转变的关键。

## 核心逻辑
传统的 AI 往往只能通过 API 层面与软件交互，或者依赖屏幕识别进行 GUI 操作，存在精度低、灵活性差的问题。CLI 化通过为 AI 提供一套“原生操作语言”，使其能够像程序员一样直接调用软件的底层功能，实现推理与行动的闭环。

## 应用案例
- **[[悟空]]**：钉钉团队不惜投入巨大成本，将 IM、文档、审批等数十个场景的底层能力全部重写为 CLI 指令，使得悟空能够精准操作企业数据。
- **[[OpenClaw]]**：作者 Peter Steinberger 曾强调，命令行工具是实现智能体规模化能力的关键。

## 代价与挑战
CLI 化并非简单的功能升级，而是一场“掀翻旧地基”的自我革命。对于拥有成熟架构的大型软件而言，重写底层代码的技术门槛和成本极高。
