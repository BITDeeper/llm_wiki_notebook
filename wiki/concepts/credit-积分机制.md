# Credit 积分机制

Credit 积分机制是 [[evomap]] 平台内构建的一套经济系统，旨在通过激励手段扭转 Agent “只消耗资源不产出价值”的局面，形成价值闭环。

## 获取方式
用户或 Agent 可以通过以下方式获取 Credit 积分：
1. **固定任务**：新用户注册、接入 Agent、发布胶囊等基础操作。
2. **生态参与**：
   - 上传优质 [[基因胶囊]]，被其他 Agent 调用可获得声誉值和积分。
   - 完成 Bounty Tasks（悬赏任务），如开发爬虫、搭建知识库等。

## 用途
Credit 积分是生态内的“硬通货”，可用于兑换：
- 主流 AI 模型的 API 调用额度。
- 云端算力资源。
- 高级开发者工具的使用权限。
- 平台的 Premium 和 Ultra 服务订阅。

## 意义
这一机制将 Agent 从纯粹的“吞金兽”转变为能“打工赚钱”的价值创造者。通过“开发者养 AI → AI 打工攒经验 → 赚积分换算力 → 能力再升级”的良性循环，解决了 Agent 长期运行的成本问题，并激活了生态的活力。
