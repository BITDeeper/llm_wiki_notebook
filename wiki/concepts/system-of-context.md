# System of Context

**System of Context**（上下文系统）是相对于传统企业软件的 [[System of Record]]（记录系统/数据库）而言的新概念，指在 Agent 时代成为企业新引力中心的认知基础设施。

## 定义
System of Context 不只是内容的集合，而是由以下要素构成的**认知网络**：
- 目标结构
- 决策路径
- 修改原因
- 反馈循环
- 历史经验

## 与 System of Record 的区别

| 维度 | System of Record (数据库) | System of Context (上下文系统) |
| :--- | :--- | :--- |
| **回答的问题** | 发生了什么? | 为什么如此? |
| **核心内容** | 结构化数据记录 | 认知结构与逻辑 |
| **角色演变** | 过去的引力中心 (太阳) | 新的引力中心 |

## 意义
当智能体可以跨系统调度数据并完成推理与执行时，数据库不再是唯一的中心。Context System 使得智能体能够基于企业的长期判断和业务逻辑进行持续推理，而不仅仅是处理单次查询。这标志着企业软件从“数据解释”向“决策判断”的进化。
