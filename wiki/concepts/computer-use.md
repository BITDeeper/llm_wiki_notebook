# Computer Use（计算机操控）

**Computer Use**（电脑操作/计算机操控）是指 AI 模型直接操作计算机图形界面（GUI）的能力范式，涵盖屏幕感知（截图、UI 元素读取）、坐标定位、操作执行（点击、输入、拖拽等）等完整链路。它标志着 AI 交互从单纯的文本/代码生成跨越到了对物理操作系统环境的直接操作，是 AI Agent 从"只会说话"到"能动手干活"、从"聊天工具"向"自主助手"、从"指手画脚的甲方"变为"下场干活的乙方"进化的关键能力跃迁。

## 工作原理

Computer Use 的运作遵循"感知-推理-执行"的循环模式：

1.  **感知（视觉理解）**：AI 模型获取当前屏幕的截图，理解屏幕上的 UI 元素、布局和状态。
2.  **推理（坐标定位）**：分析屏幕内容，识别可操作对象（按钮、输入框、菜单）的精确位置，理解当前状态并确定下一步操作。
3.  **执行（动作执行）**：向操作系统发送模拟的鼠标移动、点击、键盘输入、快捷键、滚动、拖拽、窗口切换等指令。
4.  **状态追踪**：将每一步操作结果记录为可追踪的状态变化。
5.  **循环**：重复上述过程，直到任务完成。

## 核心组成

-   **屏幕感知**：通过像素级截图和 UI 元素结构化读取，让 AI 理解当前屏幕状态。
-   **操作执行**：模拟人类的鼠标点击、键盘输入、快捷键、滚动、拖拽、窗口切换等操作。
-   **任务闭环**：AI 自主完成"看→判断→操作→验证"的完整循环，无需人类介入。

## 能力层级

AI 在桌面端的交互能力通常分为三个层级，Computer Use 特指第三层能力：

1.  **入口层**：能够通过快捷键或侧边栏快速唤起。
2.  **感知层（屏幕上下文）**：能够读取并理解当前屏幕上的内容（如 [[屏幕上下文]]）。
3.  **执行层**：能够基于理解，自主执行点击、输入、滚动、切换窗口等操作。

## 核心特征

-   **跨应用协作**：AI 能够在不同软件之间传递信息（例如：从邮件中提取数据填入 Excel）。
-   **UI 交互**：能够识别并操作按钮、菜单、输入框等用户界面元素。
-   **任务链执行**：能够将一个模糊的目标（如"预定一张机票"）拆解为一系列具体的计算机操作并自动完成。
-   **动态适应**：Agent 需要**边看边想边操作**，能适应弹窗、窗口遮挡、界面变化等动态场景。

## 与传统自动化的区别

传统脚本（如 AppleScript、Selenium）依赖固定的元素路径和坐标，环境一变就崩溃。Computer Use 则通过视觉理解实时感知界面状态，具备对动态场景的适应能力，而非依赖预定义的固定路径。

## 在 Agent 架构中的位置

Computer Use 属于 Agent 的**执行层**能力，与**连接层**（消息入口、网关、调度）互补：

-   **连接层**解决"谁来找我、要做什么"
-   **执行层**解决"屏幕上有什么、按钮在哪里、这一刀该往哪儿落"

两者合一才构成普通人想象中的完整 AI 助手。Computer Use 代表了 [[任务执行范式]] 的成熟阶段——AI 不再仅限于生成文本或调用 API，而是能够像人类一样直接操作图形界面。这与 [[runtime-agent-os]] 的理念形成呼应。

## 应用场景

在软件开发与日常办公领域，Computer Use 能够解决许多传统工具无法处理的痛点：

-   **GUI 自动化测试**：自动操作原生应用、Electron 应用或网页进行端到端测试。
-   **视觉调试**：根据自然语言指令（如"修复这个布局错位"）自动复现并修复界面问题。
-   **工具桥接**：驱动那些没有命令行接口的软件（如 iOS 模拟器、设计工具）。
-   **办公自动化**：自动处理跨应用的重复性数据录入与整理工作。

## 临界点判断

2026 年上半年，模型视觉能力和 Computer-Use 能力被认为越过了一个质变临界点：

-   单项进步（多识别一点、多点准一点）叠加后产生体验质变
-   Agent 从"偶尔能演示"接近"可持续跑流程"的状态
-   底层自动化工具（如 [[peekaboo]]、[[peekaboo-v3]]）的价值因此被显著放大

## 安全风险与防护

赋予 AI 完整桌面操控权限意味着极高的安全风险。一旦 AI 产生幻觉或执行错误操作（如 [[openclaw]] 此前删除用户收件箱的事故），后果将远超文本生成场景。因此，实施 Computer Use 必须配套严格的安全机制：

-   **权限分级**：对高风险应用（如浏览器、交易平台）实施只读限制，对代码编辑器限制输入权限。
-   **人工确认**：在操作新应用或执行高风险操作前请求用户授权。
-   **隔离与排除**：排除终端窗口截图，防止 AI 窃取敏感信息或被屏幕上的恶意文本注入攻击。
-   **操作审计**：记录 AI 的每一步操作，便于事后追溯和问题排查。
-   **紧急停止**：提供全局快捷键（如 `Esc`）以便用户随时中断 AI 操作。

## 技术挑战

实现可靠的 Computer Use 面临诸多挑战：

-   **上下文长度**：频繁的截图会消耗大量 Token，导致成本高昂。
-   **UI 理解准确性**：不同应用的 UI 设计差异巨大，AI 需要极高的泛化能力以准确识别细微的 UI 元素变化。
-   **操作确定性**：确保 AI 的点击和输入操作精确无误，避免误操作。
-   **错误恢复**：当操作失败（如点击无效）时，AI 需要具备自我纠错机制。

## 未来展望

随着模型推理能力和多模态理解能力的提升，Computer Use 被视为 AI Agent 的终极形态之一。结合 [[无人值守模式]]，AI 将能够像人类实习生一样操作电脑，彻底解放用户的双手，实现全自动工作流。
