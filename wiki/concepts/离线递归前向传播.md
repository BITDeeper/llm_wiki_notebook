# 离线递归前向传播

离线递归前向传播是[[记忆巩固机制]]中的核心计算过程。在模型进入"睡眠"状态后，系统在不接收外部输入 token 的情况下，对累积的上下文执行 N 次循环往复的前向计算。

## 工作流程

1. 上下文窗口被填满，模型即将淘汰 KV Cache 中的旧 token
2. 模型进入"巩固阶段"，停止接收外部输入
3. 对累积上下文执行 N 次递归传递（N 即"睡眠循环次数"）
4. 每次传递中，通过学习得到的局部规则迭代更新 SSM 模块中的[[快速权重]]
5. N 次传递完成后，KV Cache 被淘汰，模型带着更新后的快速权重继续处理后续 token

## 关键特性

- **计算与推理解耦**：额外计算集中在离线阶段，不影响预测阶段的单次前向传播延迟
- **深度与循环次数成正比**：N 越大，记忆提炼越充分，但训练成本也线性增长
- **端到端可优化**：整个计算图通过反向传播进行端到端优化，以最大化睡眠之后的任务表现

## 代价

训练过程中需要执行 N 次更深的前向和反向传播，导致训练变慢，也可能引发训练不稳定。
