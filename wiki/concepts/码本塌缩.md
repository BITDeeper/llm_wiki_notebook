# 码本塌缩

**码本塌缩** (Code Collapse) 是指在使用量化表示（如 VQ-VAE、RQ-VAE）的模型训练过程中，模型倾向于只使用码本中极少数几个 Code（码字），而忽略大部分 Code 的现象。

## 后果

- **表示能力退化**：由于大量 Code 未被使用，模型的潜在表示空间被压缩，无法有效编码数据的多样性。
- **训练停滞**：在生成式推荐等任务中，塌缩会导致模型过早停止优化，因为梯度无法通过未被激活的 Code 有效回传。

## 成因

- **探索不足**：在训练初期，如果模型过早收敛到某些容易输出的 Code，其他 Code 就很难被激活。
- **梯度估计问题**：直接使用直通估计器（STE）进行硬更新可能导致模型缺乏探索随机性，从而陷入局部最优。

## 解决方案

[[diger]] 框架通过引入 **Gumbel Noise** 和 **不确定性衰减** 策略来缓解码本塌缩：
- **Gumbel Noise**：在采样过程中引入随机性，增加探索机会。
- **Uncertainty Decay**：在训练前期保持高噪声（鼓励探索），后期降低噪声（保证收敛），从而实现 Code 的均衡利用。
