# 基于 Fisher-Rao 距离的 Token 角色分配

基于 Fisher-Rao 距离的 Token 角色分配是 [[dyco-rl|DyCo-RL]] 框架的核心机制之一。它利用信息几何中的测地距离来自动判定模型在生成每一个 Token 时，究竟是在“看图”还是在“思考”。

## 核心原理

该机制的核心假设是：当模型真正从某一模态中获取新信息时，该模态内部的注意力分布会发生明显的结构重构；反之，如果只是沿着已有思路继续推导，注意力结构变化较小。

具体操作如下：
1. 对视觉模态和文本模态内部的注意力分布进行归一化。
2. 利用 **Fisher-Rao 测地距离** 衡量相邻生成步骤之间注意力结构的变化程度。
3. 比较视觉模态与文本模态对应的结构变化强度：视觉模态变化更显著则判定为“视觉型 Token”，反之则为“文本型 Token”。

## 不可替代性

消融实验表明，如果将 Fisher-Rao 距离替换为 Random、Reverse、Entropy 或 KL 散度等替代方案，模型性能会出现明显下降，证明了该测度在捕捉注意力动态重构方面的精确性和不可替代性。
