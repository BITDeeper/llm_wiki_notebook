# 验证循环

[[claude-code|Claude Code]]最佳实践中的核心方法论：若不给AI可执行的检查项，人自己就变成验证瓶颈；给AI自动化测试/构建/截图对比则形成自闭环。

## 核心原则

> "如果你不给Claude一个能跑的检查项，那你自己就会变成那个验证循环。每一个错误，都得等你亲眼发现。"

## 闭环机制

1. Claude执行任务
2. 自动运行检查（测试套件/构建退出码/截图对比设计稿）
3. 读取检查结果
4. 未通过 → 自动修改
5. 通过 → 交付

这个循环自己就闭环了，不需要人工逐步介入。

## 与传统模式的对比

- **传统模式：** 人盯每一步输出 → 发现错误 → 手动指出 → AI修改 → 人再检查
- **验证循环模式：** 人设检查标准 → AI执行+自检+迭代 → 人审最终证据
