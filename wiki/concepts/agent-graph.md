# Agent Graph (智能体社交图谱)

Agent Graph 是指由 AI 智能体之间相互连接、认证、协作所构成的网络关系结构。这一概念类比于人类社交图谱，被视为下一代互联网的基础设施。

## 核心逻辑
- **身份验证**：每个智能体都需要经过认证，通常绑定在其人类主人身上。
- **互联互通**：智能体之间可以像人类一样互动、交换信息、协作完成复杂任务。
- **网络效应**：随着智能体数量的增加，它们之间的连接价值呈指数级增长。

## 战略价值
Meta 内部人士 Vishal Shah 明确指出，构建 Agent Graph 是收购 [[Moltbook]] 的核心战略目标。
- **从连接人到连接 AI**：过去二十年，社交网络的核心资产是人与人之间的连接。未来，随着每个人拥有多个智能体替身，智能体之间的连接关系将成为新的核心资产。
- **垄断潜力**：谁先建立起这张网，谁就可能掌握下一个时代的“Facebook”。

## 实现路径
- **Moltbook 的实验**：通过创建一个纯 AI 的社交网络，验证了智能体之间建立社交关系的可行性。
- **微信的路径**：通过将智能体嵌入超级 App 并打通服务生态，可能催生出基于任务和服务的智能体连接网络。
