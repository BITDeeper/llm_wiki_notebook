# 全模态 Agentic 协同设计

[[全模态-agentic-协同设计]] 是一种系统设计理念，旨在同时解决全模态数据异构、Agentic 工作流复杂性和大规模异步训练的稳定性问题。这一理念是 [[Relax]] 引擎的核心设计哲学。

## 核心洞察
该设计理念认为，随着 RL 后训练逐步延伸至全模态（图文音视频）与 Agentic（多轮推理、工具调用）场景，现有的 RL 训练框架面临着三个环环相扣的困境，必须协同解决：

1.  **数据异构**：多模态原始数据传输体积大、CPU 预处理开销高、编码后 Token 数量爆炸，导致传统并行策略失效。
2.  **系统脆弱**：多模态训练增加了 OOM 风险，叠加千卡长时训练，硬件故障频发，传统方案缺乏分钟级故障恢复能力。
3.  **角色耦合**：Colocate 方案下各角色共享 GPU 只能串行执行，资源利用率低；现有全异步方案则缺少细粒度的流水线调度。

## 协同解决方案
[[全模态-agentic-协同设计]] 主张通过以下三个层面的协同设计来打破困境：

-   **全模态原生 Pipeline**：针对多模态数据特点优化数据传输和预处理流程（如 CPU 预处理与 GPU 推理流水线重叠）。
-   **服务化容错**：通过 [[服务化隔离]] 将各角色拆分为独立微服务，配合 [[分布式checkpoint服务-dcs]] 实现快速故障恢复。
-   **全异步流水线**：利用 [[transferqueue]] 数据总线解耦 Rollout 和 Train，通过 [[micro-batch-流水线]] 实现细粒度的并行执行。

这三者形成了一条因果链：多模态导致系统低效且脆弱，进而催生服务化隔离和全异步架构，进而催生数据总线，而总线的字段存储天然兼容多模态，最终完成闭环。
