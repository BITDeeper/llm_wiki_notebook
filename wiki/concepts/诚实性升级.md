# 诚实性升级

[[claude-opus-4-8|Opus 4.8]] 的一项核心隐性改进：模型更愿意承认自己不确定，而非过度自信地给出错误答案。

## 关键数据

- 代码中留下缺陷却不声张的概率比 Opus 4.7 降低 4 倍
- 在大型 Agent 任务中，过度自信是最昂贵、最致命的失败模式

## 营销策略

[[anthropic|Anthropic]] 在官方发布图中保留了 Opus 4.8 输给 [[gpt-5.5|GPT-5.5]] 的 Terminal Coding 项目（74.6% vs 78.2%），甚至将 GPT-5.5 的胜利数字加粗，以此展示"诚实"品牌形象。

## 争议

业界大佬（DHH、antirez）认为这更像是一种营销策略而非真正的技术突破——当你把对手放在同一张图里对比，而用户体感与跑分不符时，反而会损害公信力。
