# 多智能体系统

多智能体系统研究多个智能体之间如何协调、协作或竞争以实现个体或集体目标。

## 研究范畴
-   **协调机制**：如何设计协议让多个 Agent 高效配合。
-   **计算博弈论**：分析 Agent 在策略环境下的交互行为。
-   **多智能体强化学习**：训练 Agent 在复杂环境中通过交互学习最优策略。

## 应用场景
-   **机器人集群**：如物流机器人协作。
-   **自动驾驶**：车辆间的协同决策。
-   **资源调度**：如计算资源或电网的分布式管理。
