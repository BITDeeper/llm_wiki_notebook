# 多智能体架构

[[多智能体架构]]（Multi-Agent Architecture）是一种系统设计模式，通过使用多个具有特定功能和角色的 Agent（智能体）协同工作，以模拟真人团队的工作流来解决复杂问题。

## 在 Hilight 中的应用
[[Hilight]] 采用了三层多智能体架构，将视频生成过程分解为策略、创意和执行三个阶段：

### 1. 策略总监层（理解与洞察）
负责将“需求+素材”转化为“可执行的营销指令”。包含素材理解、信息总结和趋势洞察等 Agent。

### 2. 执行导演层（创意与结构）
负责将“好想法”转化为“可执行的视频结构”。包含创意生成、剧本策划和素材匹配等 Agent。

### 3. 后期生成层（执行与成片）
负责将结构化方案转化为视频资产。包含编辑执行和成片生成等 Agent。

## 相比单体 AI 的优势
1. **独立判断力（Say No）**：每个 Agent 都有否决权。例如，素材 Agent 发现图片模糊可以拒绝使用，从源头减少废片。
2. **协商能力**：Agent 之间可以像真人一样“讨价还价”。例如剪辑 Agent 觉得素材不够长，素材 Agent 会去寻找或生成替代品。
3. **自我进化**：系统能够沉淀爆款数据和创意范式，随着使用次数增加，越来越懂品牌调性和用户喜好。
