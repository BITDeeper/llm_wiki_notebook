# 截断重要性采样（TIS）

截断重要性采样（Truncated Importance Sampling，TIS）旨在解决高效 RL 训练框架中推理引擎和训练引擎之间 token 概率不一致的问题。

## 问题背景

现代 RL 训练采用**生成器-训练器分离架构**：

- **推理引擎**（如 vLLM、SGLang）：使用低精度推理（int8/fp8）生成轨迹
- **训练框架**（如 FSDP、DeepSpeed）：计算策略更新

由于两个引擎的精度和实现差异，产生的 token 概率存在不可忽视的差异。这种差异难以通过统一代码实现消除，需针对每种引擎组合重复调试。

## 核心方法

TIS 在策略梯度表达式中引入重要性采样项，自动纠正引擎间不匹配：

- 重要性比率 = learner 引擎概率 / sampler 引擎概率
- 用最大值 ρ 进行单侧截断（仅防止极端上调权重）
- 将截断后的比率乘以策略梯度表达式

## 两种实现形式

1. **序列级 TIS**：类似 [[gspo]] 的梯度表达式，理论上偏差更小
2. **Token 级 TIS**：与 PPO/GRPO 目标对齐良好，实践中更常用

目前哪种方式更优尚无定论，最佳实现可能取决于具体应用场景。

## 与批次不变性的关联

TIS 解决的训练-推理引擎概率不一致问题，与 [[批次不变性]] 关注的训练确定性问题本质相通——都涉及在不同计算路径下保持数值一致性的挑战。

TIS 已被主流训练框架（如 verl 和 OpenInstruct）迅速采用。
