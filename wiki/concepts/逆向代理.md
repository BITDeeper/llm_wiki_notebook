# 逆向代理

**逆向代理**（Reverse Proxy）在 AI 订阅服务的语境下，指通过技术手段将个人订阅（如 Claude Pro/Max）的额度转化为 API 接口，供第三方应用、开源项目或多用户使用的行为。

## 常见形式
- **Sub2API**：将订阅服务的 Web 接口转换为标准的 API 接口。
- **额度代跑**：利用个人账号为他人或客户运行任务。
- **第三方工具接入**：将订阅账号接入 [[OpenClaw]] 或 [[Hermes Agent]] 等高风险智能体工具。

## 风险
Anthropic 明确将此类行为列为禁止范围：
1.  **违反服务条款**：个人订阅仅限原生应用和正常使用场景，不得作为分发接口。
2.  **封号风险**：随着 [[平台完整性检查]] 和 [[KYC]] 的引入，此类行为极易被精准识别并导致封号。
3.  **法律风险**：官方公告提到违规行为“可能被执法处理”。

## 应对建议
对于需要 API 接口的商业或团队用途，应使用官方提供的 Claude Console、API Key 或支持的云平台，而非依赖个人订阅的逆向代理方案。
