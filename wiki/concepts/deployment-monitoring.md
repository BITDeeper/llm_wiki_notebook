# 部署后监控

部署后监控是指在 AI 模型发布后，持续收集和分析其在真实世界中的行为数据。[[anthropic]] 强调，这是理解 AI 智能体风险和能力的唯一可靠途径，因为部署前的受控环境测试无法覆盖所有现实场景。

## 核心重要性
- **现实复杂性**：真实世界中的用例和边缘情况远超实验室环境。
- **用户行为演变**：用户与 AI 的交互方式（如信任度、监督策略）会随时间快速演变，这只能在部署后观察到。
- **高风险识别**：某些高风险操作（如金融交易、生产部署）只有在真实流量中才能被捕捉和评估。

## 当前技术局限
Anthropic 在研究中披露了当前监控基础设施的盲区：
- **会话重组困难**：缺乏可靠的方法将独立的 API 请求串联成连贯的智能体会话。这导致难以判断某些操作（如金融交易）是真实执行还是模拟测试。
- **可见性有限**：对于第三方通过 API 构建的智能体，平台方的理解能力非常有限。

## 未来方向
- **跨行业协作**：需要以保护隐私的方式开发新的监控技术。
- **不确定性识别**：监控不仅关注结果，还需关注模型是否在不确定时主动暂停。
- **监管建议**：监管重点应放在“人类是否处于能有效监控的位置”，而非强制规定具体的交互流程（如强制每步批准）。
