# 原生 Computer Use

指大语言模型（LLM）直接具备控制计算机、操作桌面软件（如浏览器、Excel、IDE）的能力，而无需依赖外部 API 封装或中间插件。

## 技术意义
与传统的“函数调用”或“工具使用”不同，原生 Computer Use 意味着模型可以直接理解屏幕像素、生成鼠标/键盘指令，并像人类一样操作界面。

## 应用场景
- **数据分析**：在 Excel 中直接通过自然语言修正公式、生成图表或进行财务建模。
- **网页操作**：自动浏览网页、抓取数据（如 Zillow 房价）并填入表格。
- **软件开发**：直接操作 IDE 进行代码编写、调试和运行。

## 影响
这一能力使得 AI 从“对话者”转变为“操作者”，直接威胁到大量基于桌面软件的白领工作，如数据录入、初级分析师和文员。
