# Code Red

Code Red 是 [[sam-altman]] 在 OpenAI 内部发出的紧急警报，要求全员回归 [[chatgpt]] 主线，暂停其他分散的项目。

## 背景

2025 年，随着 Google Gemini 3 在任务自动化、代码生成等关键维度上加速逼近，OpenAI 意识到其领先地位面临动摇。同时，ChatGPT 的周活跃用户增长出现波动，甚至一度下滑。这种内忧外患的局面促使公司进入极度紧绷状态。

## 内容与影响

- **战略收缩**：Altman 要求所有团队必须将精力集中在 ChatGPT 的核心体验提升上，其他边缘项目一律后排。
- **权力集中**：在危机时刻，为了快速拍板和统一节奏，决策权实际上集中到了 [[nick-turley]] 手中。他成为了协调研究线与产品线的唯一核心人物。
- **组织重塑**：这一事件标志着 OpenAI 从「研究驱动」的宽松模式向「产品生存」的战时模式转型。

## 意义

Code Red 不仅是应对竞争的战术动作，更是 OpenAI 发展史上的转折点。它暴露了公司内部项目各自为战的弊端，并确立了产品经理在 AI 实验室中前所未有的核心地位。
