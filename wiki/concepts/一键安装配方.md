# 一键安装配方

一键安装配方（Install Recipes）是一种软件安装与依赖管理的交互机制，旨在降低用户配置复杂工具的门槛。它通过系统自动检测缺失的依赖项（如库文件、API Key、环境变量），并提供明确的下一步操作指引，替代了以往用户需自行查阅文档、排查报错信息的繁琐过程。

## 核心特征
- **自动检测**：系统在安装或运行时主动扫描当前环境，对比所需依赖清单。
- **主动提示**：一旦发现缺失，立即通过控制台或 CLI 提示用户，而非等待运行时报错。
- **上下文指引**：不仅告知“缺什么”，还提供“怎么配”（如 API Key 获取链接、配置文件路径）。

## 应用案例
在 [[openclaw]] 3.24 版本中，该功能被应用于其 Skills 系统。对于内置的 Skills（如 `coding-agent` 或 `openai-whisper-api`），系统会自动识别用户是否配置了必要的密钥或运行时环境。如果未配置，界面会显示“需配置”状态，并引导用户完成设置，从而解决了“装了跑不起来”的核心痛点。

## 价值
- **降低认知负荷**：用户无需成为专家即可完成复杂配置。
- **减少挫败感**：将“报错排查”转变为“引导式设置”，改善了用户体验（UX）。
