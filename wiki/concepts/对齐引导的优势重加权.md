# 对齐引导的优势重加权

对齐引导的优势重加权（Alignment-Guided Advantage Reweighting）是 [[dyco-rl|DyCo-RL]] 框架的核心机制之二。它负责在强化学习过程中，根据 Token 的行为是否符合其功能角色，动态调整学习信号（优势值）的强度。

## 机制详解

在确定了 Token 的角色（视觉型或文本型）后，该机制会计算 Token 当前的实际注意力分配与其理想功能角色的匹配程度（即对齐得分）：
- **匹配（对齐）**：如果视觉型 Token 确实关注了图像，或文本型 Token 关注了上下文，其对应的优势值将被**放大**，强化正确的跨模态行为。
- **失配（错配）**：如果出现“该看图时不看图”等情况，其学习信号会被**抑制**。

## 工程意义

这种重加权后的优势被无缝集成到标准策略梯度目标中，仅替换了传统 [[可验证奖励的强化学习|RLVR]] 中的优势项计算，不增加额外参数，实现了对主流算法的即插即用增强。
