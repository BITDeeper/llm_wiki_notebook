# 并行优化 (扩散模型生成范式)

在[[扩散模型]]（如 [[Mercury 2]]）的语境下，**并行优化**指的是一种与[[自回归]]串行生成截然不同的内容生成机制。

## 工作原理
- **自回归模式**：像“打字机”一样，必须按照从左到右的顺序，逐个生成 token。第 N 个 token 的生成必须依赖于第 N-1 个 token 的结果，导致延迟随输出长度线性增加。
- **并行优化模式**：像“编辑”一样，先生成一份粗糙的草稿，然后拿着“红笔”在整页纸上同时进行圈改和细化。模型不需要等待前一个字的结果就能生成下一个字。

## 优势
这种机制使得模型的响应速度极快，延迟不再与输出长度成正比。[[Mercury 2]] 正是利用这一特性实现了 1009 tokens/s 的生成速度，比传统模型快 5 倍。

## 与 Test-time Compute 的关系
并行优化使得在实时延迟预算内进行大规模 [[test-time-computation]]（测试时计算）成为可能。由于生成过程是并行的，增加计算量（如更多的迭代步骤）不会像自回归模型那样造成不可接受的延迟堆积。
