# Agent 扩展定律

Agent 扩展定律是 [[黄仁勋]] 提出的算力扩展第四条定律。它指出：**通过扩充“数字员工”（Agent）的数量来提升整体智能产出，比提升单体模型的智能更容易、更有效。**

## 四条扩展定律

黄仁勋总结了智能规模化的四条定律，形成了一个闭环：
1.  **预训练扩展**：数据越多，模型越聪明。
2.  **后训练扩展**：通过合成数据持续规模化。
3.  **测试时扩展**：推理即思考，通过增加运行时计算量提升能力。
4.  **Agent 扩展**：扩充员工比提升我自己容易得多。

## 商业逻辑

- **边际效益**：提升单体模型（如 GPT-5）的智能面临物理和数据的极限，而复制一个 Agent 的边际成本极低。
- **闭环效应**：Agent 产生的数据流回预训练，经后训练精调，再经推理增强，再释放到产业。
- **算力需求**：这一定律解释了为什么英伟达要押注 Agent 基础设施（如 [[Vera Rubin]]），以及算力需求的未来增长点在于“数字员工”的普及。
