# 认知对齐

**认知对齐** 是指在人工智能系统中，不仅对齐模型的最终输出（答案），更对齐模型背后的多维认知评估过程（包括思维链、权衡过程、不确定性处理等），以及使经验、知识与模型自身能力边界相匹配。

## 核心思想

### 多维认知评估对齐

传统的对齐方法（如标准的 [[rlhf|RLHF]]）通常将人类反馈视为对结果的"单点决策"或"偏好排序"，往往忽略了人类在做出判断时的思维过程。认知对齐认为，人类偏好实际上是"多维认知评估的投影"，包含了对中间步骤的探索、对不确定性的权衡以及对最终结论的收敛。

### 自我蒸馏与认知匹配

认知对齐也在 [[evolver-agent|EvolveR]] 论文（ICML 2026）中表现为一种关键现象：Agent 自己从执行轨迹中蒸馏出的经验原则，比外部强教师（如 GPT-4o-mini）总结的原则更有效。自我蒸馏的经验更符合 Agent 自身的能力边界和推理习惯，在实际任务中更容易被有效使用。

## 理论基础

### 神经决策中熵的双相性

认知对齐的一个关键理论支撑是**[[神经决策中熵的双相性]]**：

- **高熵阶段**：在关键决策节点，人类思维表现出高熵（探索性、不确定性）。
- **低熵阶段**：在结论形成阶段，人类思维趋向低熵（确定性、收敛）。

通过模仿这种"发散-收敛"的认知模式，AI 模型可以更深入地理解人类意图，而不仅仅是表面地模仿答案。

### 认知匹配优于能力最大化

[[evolver-agent|EvolveR]] 的发现挑战了"强教师蒸馏"的常规假设，表明对 Agent 而言，最强的经验不一定来自最强教师，而可能来自与自身策略最匹配的"自我经验"。这与 [[具身智能数据困境]] 中的"仿真鸿沟"问题有深层共鸣——最匹配自身策略的数据才是最好的数据，而非最"高质量"的外部数据。

## 优势与应用

- **数据效率**：通过从少量数据中提取深层认知信号，认知对齐方法（如 [[gem-框架|GEM 框架]]）能在数据稀缺场景下实现优于传统方法的效果。
- **可解释性**：对齐思维过程有助于提高 AI 决策的透明度和可解释性。
- **专业领域**：在医疗、法律等需要复杂推理和专业知识的领域，认知对齐能帮助模型更好地捕捉专家的决策逻辑。

## 实现路径

实现认知对齐通常涉及：

1. **推理链生成**：让模型生成详细的思维链。
2. **认知评分**：利用熵等指标评估推理过程的质量。
3. **策略优化**：基于认知评估反馈调整模型策略。
4. **经验自蒸馏**：从模型自身的执行轨迹中提取经验原则，形成与自身能力匹配的认知策略。

## 规模效应

认知对齐中存在显著的规模效应：

- 当模型较小时，外部教师模型帮助总结经验效果更好。
- 但当模型扩展到 3B 规模时，Agent 自我蒸馏的原则反超外部教师蒸馏的原则。
- 这表明随着模型规模增长，认知对齐策略应从"外部引导"逐步转向"自主生成"。

## 对行业的启示

- 未来 Agent Skill 不一定都来自人类编写，可能有一部分来自 Agent 自身的长期执行轨迹。
- Skill 生态应从"人类编写+外部安装"向"人类编写+自主生成"的混合模式演进。
- 在设计蒸馏策略时，应考虑教师与学生模型之间的"认知匹配度"，而非单纯追求教师模型的最大能力。
