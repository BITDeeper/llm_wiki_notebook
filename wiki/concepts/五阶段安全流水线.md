# 五阶段安全流水线

[[mdash]] 采用的安全审计流程，将复杂的漏洞发现任务拆解为五个阶段，每个阶段使用不同的 Agent 和模型。

## 五个阶段

1. **准备（Prepare）**：代码分析和上下文理解
2. **扫描（Scan）**：潜在漏洞识别
3. **验证（Verify）**：漏洞可利用性验证
4. **去重（Deduplicate）**：消除重复发现
5. **证明（Prove）**：生成完整的漏洞利用证明

## 设计理念

- 审计 Agent 和辩论 Agent 分开
- 发现漏洞和证明漏洞分开
- 重度推理用大模型、高频验证用蒸馏小模型
- 通过任务分解实现单次推理无法完成的复杂目标
