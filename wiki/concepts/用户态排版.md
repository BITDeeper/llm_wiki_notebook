# 用户态排版

[[用户态排版]] 是一种将文本排版和布局计算逻辑从浏览器内核（内核态）剥离，移至应用层代码（用户态）执行的软件架构范式。

## 背景与动机

### 传统模式的困境
传统的 Web 排版严重依赖浏览器内置的 DOM 和 CSS 引擎。开发者受限于标准实现的缓慢迭代（如 CSS 委员会的讨论周期），且无法解决底层性能瓶颈（如 [[DOM Reflow]]）。

### 范式转移
随着 Web 应用对 UI 交互和性能要求的提高，单纯依赖浏览器内核已无法满足需求。用户态排版主张：
- **掌控权回归**：开发者应拥有对排版逻辑的完全控制权。
- **打破黑盒**：不再将浏览器视为不可更改的黑盒，而是将其视为底层的图形绘制接口（如 Canvas/WebGL）。

## 优势

### 性能
通过在用户态进行计算，可以避免内核态与用户态之间的频繁通信和同步开销。[[Pretext]] 的实践证明，这种方式可实现数百倍的性能提升。

### 灵活性
开发者可以实现浏览器尚未支持的复杂布局算法，例如：
- 动态流体排版。
- 复杂的形状内文字流动。
- 与物理引擎结合的文本动画。

## 与 AI 智能体的关系
用户态排版是 [[Runtime Agent OS]] 理念在图形渲染领域的延伸。通过将排版逻辑“白盒化”，AI 智能体能够更精确地理解和控制 UI 的生成过程，而不仅仅是生成 HTML/CSS 字符串。
