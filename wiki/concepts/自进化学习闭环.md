# 自进化学习闭环

自进化学习闭环是 [[hermes-agent]] 的核心设计理念，指 Agent 在完成复杂任务后自动总结为技能文件（SKILL.md），下次遇到类似任务直接调用，实现"越用越聪明"。

## 工作机制

1. 用户给 Agent 一个复杂任务（如每天拉 GitHub issue 日报）
2. Agent 完成任务后，根据用户反馈（如格式纠正、夸奖）自动生成 SKILL.md 文件
3. 下次遇到类似任务，Agent 直接调用已有技能，无需重新摸索
4. 技能存储在文件中而非对话记忆里，重装系统也不会丢失

## 与 Curator 的配合

[[curator-技能库自维护]] 是自进化学习闭环的维护机制。Curator 按周期给技能库打分、合并重复技能、归档过时技能，相当于 Agent 自己给自己做性能调优。

## 与 Evolver 的区别

Wiki 中已记录的 [[evolver]]（EvoMap 团队开发）是引擎级自进化，而 Hermes 的自进化学习闭环是技能文件级自进化。两者代表了 [[自进化架构]] 的不同实现路径。

## 用户模型

Hermes 还会随着时间建立一个"你是谁、你习惯怎么工作"的用户模型，使 Agent 从一次性问答工具变成常驻的、越来越了解用户工作习惯的"同事"。
