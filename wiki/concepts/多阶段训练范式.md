# 多阶段训练范式

多阶段训练范式是将LLM训练方法论系统迁移至3D视觉领域的训练策略，从合成预训练到真实数据后期训练的渐进式对齐。

## 阶段划分（以SAM 3D为例）
1. **预训练（Pre-training）**：在大规模合成数据（Iso-3DO，270万个3D物体）上学习基础表征
2. **中期训练（Mid-training）**：使用半合成数据（RP-3DO）应对真实世界复杂性
3. **后期训练（Post-training）**：使用真实世界数据（MITL标注）进行对齐
4. **SFT**：监督微调
5. **DPO**：基于人类偏好的[[直接偏好优化]]
6. **蒸馏**：[[模型蒸馏]]压缩推理开销

## 与LLM训练的类比
| LLM阶段 | SAM 3D对应 |
|---------|-----------|
| 大规模预训练 | Iso-3DO合成预训练 |
| 继续预训练 | RP-3DO半合成中期训练 |
| SFT | MITL真实数据微调 |
| RLHF/DPO | 基于标注员偏好的DPO |
| 模型压缩 | NFE蒸馏（25→4） |

## 方法论意义
这一范式代表了2025-2026年的重要趋势：将LLM领域已验证的训练方法论系统迁移至3D视觉领域，证明其通用性。
