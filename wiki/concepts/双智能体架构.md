# 双智能体架构

双智能体架构是 [[Anthropic]] 提出的一种用于解决长时运行 AI 智能体任务中断和记忆缺失问题的设计模式。它通过将任务明确划分为“初始化”和“执行”两个阶段，模拟人类工程团队的分工协作。

## 核心组件

### 1. 初始化智能体
- **职责**：负责项目启动阶段的环境搭建。
- **产出**：
    - `init.sh` 脚本：用于启动开发服务器和基础环境。
    - `claude-progress.txt`：记录项目状态和进度的日志文件。
    - 初始 Git 提交：确立代码基线。
    - 功能列表：将用户需求细化为具体的、可勾选的任务清单（通常为 JSON 格式）。

### 2. 编码智能体
- **职责**：在后续会话中接手工作，负责具体的功能实现。
- **行为准则**：
    - **小步迭代**：每次只推进一小步功能改动。
    - **状态保持**：确保环境随时处于“干净状态”（无 Bug、可合并、有文档）。
    - **信息留痕**：通过 Git 提交信息和更新进度文件，为下一轮“接班”的智能体留下清晰线索。

## 解决的问题
- **贪多嚼不烂**：通过强制的小步迭代和功能列表，防止智能体试图在单一上下文窗口内完成过多工作。
- **过早胜利**：通过显式的 `failing` 状态标记，防止后续智能体误判项目已完成。
- **上下文失忆**：利用外部文件（Git 历史、进度文件）作为“记忆体”，使无记忆模型能够跨越会话延续工作。

## 设计理念
该架构的核心在于将“思考如何规划项目”与“执行具体代码”解耦，类似于人类团队中“架构师/项目经理”与“核心开发者”的分工。
