# 环境状态持久化

环境状态持久化是指将 AI 智能体的项目状态、进度和上下文信息保存在模型上下文窗口之外的外部存储系统中，以解决 AI 缺乏长期记忆的问题。

## 核心组件
1. **版本控制系统**：
    - 记录代码的每一次变更历史。
    - 提供描述性提交信息，帮助智能体理解“为什么做这个改动”。
2. **进度文件**：
    - 通常为文本或 JSON 格式。
    - 记录已完成的功能、待办事项以及当前项目状态。
3. **初始化脚本**：
    - 自动化环境搭建步骤，确保新启动的智能体能快速进入工作状态。

## 工作原理
当一个新的智能体会话开始时（即“接班”），它首先读取这些持久化数据：
- 运行 `pwd` 确认工作目录。
- 阅读 Git 日志了解历史变更。
- 阅读进度文件确认当前任务。

这样，即使模型本身没有记忆，也能通过读取外部状态快速“恢复”上下文，继续未完成的工作。

## 优势
- **突破上下文限制**：不受模型 Token 窗口大小的限制，可保存海量历史信息。
- **容错性强**：即使主进程崩溃，状态依然保留在磁盘上，不会丢失。
- **人类可读**：生成的日志和文档人类工程师也可直接审查，实现人机协作。

## 与上下文压缩的区别
[[上下文压缩]] 是在模型内部通过算法压缩历史信息以节省 Token，而环境状态持久化是完全外部的存储方案。两者通常结合使用：压缩用于短期记忆，持久化用于长期记忆和状态恢复。
