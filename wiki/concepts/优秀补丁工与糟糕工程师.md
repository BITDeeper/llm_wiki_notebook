# 优秀补丁工与糟糕工程师

**"优秀补丁工与糟糕工程师"** 是 [[swe-atlas|SWE Atlas]] 论文对当前最强AI编程智能体能力的精炼概括：能修bug能加功能，但写不出可维护的代码、留不住一个仓库的长期健康。

## 核心论点

传统AI编程评测基准（如 SWE-Bench）几乎都在做同一件事——修bug和加feature。过度专注于功能解决，会让 Agent 被训练成 **excellent patchers（优秀的补丁工）**，却是 **poor engineers（糟糕的工程师）**。

## 具体表现

| 能力维度 | 补丁工（当前AI） | 工程师（期望目标） |
|---------|----------------|-----------------|
| 修bug | ✅ 一骑绝尘 | ✅ |
| 加功能 | ✅ 能完成 | ✅ |
| 代码理解 | ⚠️ 部分覆盖 | ✅ 深度理解 |
| 测试编写 | ⚠️ 堆数量缺质量 | ✅ 精准覆盖边界 |
| 代码重构 | ⚠️ 行为不变但结构未改 | ✅ 结构性改进 |
| 跨文件协调 | ❌ 漏掉调用点 | ✅ 一致传播 |
| 旧代码清理 | ❌ 常遗漏 | ✅ 完整清理 |

## 与相关概念的关系

这一概念与 [[agentic-engineering|智能体工程]] 形成互补——界定了当前智能体工程的能力边界。同时也对 [[vibe-coding|氛围编程]] 的乐观叙事提供了理性校准：AI能快速生成代码，但距离真正的工程素养仍有相当距离。
