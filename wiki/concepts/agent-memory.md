# Agent Memory

Agent Memory（智能体记忆）是指在智能体系统中用于存储、检索和利用历史信息的机制。在 [[gems]] 框架中，它特指一种分层压缩策略，旨在解决长上下文迭代中的 Token 开销和效率问题。

## 分层压缩策略

GEMS 中的 Agent Memory 并非简单堆叠历史对话，而是采用了智能压缩策略：
*   **保留事实**：保留生成过程中的关键事实性要素（如物体位置、颜色参数），确保信息的准确性。
*   **压缩思维链**：将冗长的推理过程（思维链，CoT）压缩为精炼的“经验”或“结论”。

## 价值

这种机制有效减少了长时迭代中的 Token 消耗，同时保留了指引后续生成所需的高质量信息。实验表明，良好的记忆管理不仅能降低成本，还能提升迭代优化的指引效率，从而减少达到高质量结果所需的平均轮次。
