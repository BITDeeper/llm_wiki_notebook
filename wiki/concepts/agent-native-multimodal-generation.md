# 原生智能体多模态生成

原生智能体多模态生成（Agent-Native Multimodal Generation）是一种将智能体机制（如循环、记忆、技能）原生整合到多模态生成流程中的技术范式。它不同于简单的“模型调用”，而是强调通过系统化的架构设计来弥补单一模型在处理复杂指令时的不足。

## 核心理念

该范式认为，多模态生成的未来不仅仅在于构建更大的基础模型，还在于构建更聪明的生成系统。通过引入 [[agent-loop]]（闭环优化）、[[agent-memory]]（经验压缩）和 [[agent-skill]]（按需扩展能力），系统可以在不增加基础模型参数规模的前提下，显著提升生成质量、对齐度和艺术性。

## 代表性工作

[[gems]] 框架是该范式的代表性实现。它证明了受 [[openclaw]] 等 Agent 系统启发的设计理念，可以成功移植到多模态生成领域，使 6B 小模型超越更强的闭源模型。

## 与传统生成的区别

| 特性 | 传统多模态生成 | 原生智能体多模态生成 |
| :--- | :--- | :--- |
| **架构** | 单次前向传播 | 多轮循环与迭代 |
| **上下文** | 静态输入 | 动态记忆与经验积累 |
| **能力** | 固定模型能力 | 可通过技能库动态扩展 |
| **目标** | 像素级对齐 | 语义与审美双重对齐 |
