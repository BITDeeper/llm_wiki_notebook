# Context Rot

Context Rot 是指大模型中上下文越长、模型性能反而下降的现象。这是扩展上下文窗口方案的固有缺陷。

## 表现

即使将上下文窗口扩展到百万token，模型也会出现性能退化。许多产品宣称支持百万token窗口，但实际并未从根本上解决记忆问题。

## 成因

Context Rot的成因与注意力机制的本质有关：
- 随着上下文增长，注意力权重被分散到更多token上
- 关键信息的信号被噪声稀释
- 模型难以在超长上下文中准确定位和利用相关信息

## 对行业的影响

Context Rot的存在意味着单纯扩展上下文窗口无法解决大模型的长期记忆问题。这直接推动了对替代方案的研究，包括：
- **[[参数化记忆]]**路线：将记忆编码到参数中而非依赖显式上下文
- **外部检索**方案：通过RAG等机制按需检索相关信息
- **[[delta-mem|δ-mem]]**的紧凑动态状态方案：不依赖上下文长度，用固定大小的矩阵承载记忆

## 与Scaling Law的张力

Context Rot现象对"扩展上下文窗口就能解决记忆问题"的叙事构成直接挑战，表明单纯的规模扩展存在根本性限制，需要架构层面的创新来突破。
