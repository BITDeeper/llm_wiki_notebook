# 轨迹级KL不稳定性

**轨迹级KL不稳定性** (Trajectory-level KL Instability) 是指在多轮 Agent 的 [[在线策略蒸馏]]（OPD）过程中，随着交互轮次（轨迹长度）的增加，学生模型生成的回复分布与教师模型分布之间的 KL 散度持续攀升的现象。

## 机制与后果

在单轮任务中，学生模型通常能较好地模仿教师模型。但在多轮交互任务（如 [[alfworld]]、[[webshop]]）中：
1.  **误差累积**：每一轮的微小误差会随着轨迹的延伸被不断放大。
2.  **分布偏离**：学生模型逐渐被推入教师模型从未见过的状态区域。
3.  **监督失效**：由于分布差异过大，教师模型提供的监督信号（Logits 或梯度）不再有效，导致训练崩溃。

## 影响

这种现象是导致传统 OPD 在多轮 Agent 场景下“翻车”的根本原因：
- 对于小参数模型（如 1.7B），往往导致成功率直接崩塌至接近 0%。
- 即使是较大的模型，也会面临初始 KL 极高、训练过程剧烈震荡的问题。

## 解决方案

[[tcod]]（时序课程在线策略蒸馏）方法被提出专门用于解决这一问题。通过从短轨迹到长轨迹的 [[课程学习]]，TCOD 避免了学生在能力不足时接触长轨迹中的高误差区域，从而维持了 KL 散度的稳定性。
