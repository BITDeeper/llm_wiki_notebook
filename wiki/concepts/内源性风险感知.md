# 内源性风险感知

**内源性风险感知** (Intrinsic Risk Sensing, 简称 IRS) 是一种将安全意识直接植入 AI 智能体推理逻辑的技术范式。它改变了传统依赖外部插件或强制中断进行安全检查的模式，使 Agent 具备类似生物直觉的“原生”风险探测能力。

## 核心原理

IRS 通过 **指令微调** (Instruction Tuning) 的方式，将安全规则和风险识别模式整合到模型的参数记忆中。这使得 Agent 在执行任务时，能够像人类直觉一样，在推理过程中自然地“感知”到潜在风险，而无需等待外部系统的指令。

## 技术特点

1.  **全链路感知**：
    IRS 不仅关注用户的输入（Query 阶段），还覆盖 Agent 执行的完整生命周期：
    *   **Plan 阶段**：监控记忆检索和规划生成，防止 [[记忆中毒]] 或恶意规划。
    *   **Action 阶段**：审计传递给工具的参数，识别注入攻击。
    *   **Observation 阶段**：检查工具返回的内容（如网页、API 响应），防止 [[工具返回注入]]。

2.  **按需触发**：
    这是 IRS 实现低延时的关键。Agent 并不是每一步都进行繁琐的安全检查，而是只有在感知到异常时，才生成特殊的 [[感知信号]]（例如 `<audit_action_parameters>` 或 `<sanitize_observation>`）。这意味着在 99% 的安全交互中，防御机制是“隐形”的，几乎不带来性能损耗。

## 与传统防御的对比

| 特性 | 传统外挂防御 | 内源性风险感知 (IRS) |
| :--- | :--- | :--- |
| **工作方式** | 强制中断，外部检查 | 内嵌推理，按需触发 |
| **延时影响** | 高 (197% - 381%) | 极低 (约 8.3%) |
| **思维流** | 切断思维流 | 保持思维连贯性 |
| **防御范围** | 通常仅限输入输出 | 全生命周期覆盖 |

## 应用实例

在 [[spider-sense]] 框架中，IRS 是其核心组件之一。它使得 Agent 能够在面对复杂的 [[工具返回注入]] 攻击时，自主识别出工具返回值中的恶意代码片段（如 `import fake_module`），并主动触发清洗机制，从而避免执行有害操作。
