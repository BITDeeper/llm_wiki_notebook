# There is No Software

**There is No Software** 是一种关于软件开发和软件行业未来的预测趋势。该观点认为，随着 [[AI Agent]] 的普及和能力的增强，传统的、静态的、定制化的软件将被 Agent 动态生成的代码和实时操作所取代。

## 核心论点

### 对开发者
- **开发模式重塑**：软件研发将更多由 AI 系统主导。据 [[Manus]] 创始人 [[肖弘]] 透露，其公司内部已有 80% 的代码由 AI 生成。
- **角色转型**：传统的软件工程师正在消失，取而代之的是“架构师”和“审查者”。工程师不再手写代码，而是通过指挥多个 Coding Agent 进行协作。

### 对 SaaS 行业
- **行业重构**：存量 SaaS 产品如果不进行 AI 化改造，可能有一半会消失。
- **原因**：未来的非标需求，用户可以直接告诉 Agent，Agent 能够立刻通过生成代码或操作工具来实现需求，无需依赖固定的软件功能。

## 意义
这一概念标志着软件行业从“制造工具”向“制造数字劳动力”的范式转移，与 [[审美法官]] 的概念相辅相成——人类从繁琐的执行中解放出来，转向负责判断问题价值和方向。
