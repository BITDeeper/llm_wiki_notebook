# 采样算力最优分配

采样算力最优分配是文献 [3]（IsoCompute Playbook，2026）提出的 RL 训练算力优化方法，研究如何在固定算力预算下最优分配采样资源。

## 算力模型

RL 训练的总算力建模为 C = B_p × n × M：

- **B_p**：每批次的独特提示数
- **n**：每个提示生成的滚出（rollout）数
- **M**：RL 训练的步数

## 核心发现

### 增大 n 优于延长训练

随着算力预算增加，**最优滚出数 n 随之增大**并最终趋于饱和。将增加的算力用于为每个提示采样更多滚出，比单纯延长训练时间效果更好。

### 难度依赖性

- **简单问题**：更多滚出提升已可解问题的性能（改善 Avg@K），降低错误滚出概率
- **困难问题**：更多滚出增强探索能力，有助于发现罕见解法（提升 Pass@K）
- 困难数据集上的最优 n 值较小

### B_p 的影响

B_p 在保持在合理范围内时对性能影响适中，主要影响训练稳定性。

### 正则化策略随难度调整

- 简单问题：熵奖励 + KL 散度
- 困难问题：不使用正则化

### 学习率缩放

学习率需随批次大小增大而提高，采用平方根缩放规则。

## 实践流程

1. 在低算力预算下变化 B_p 和 n 运行 RL 训练
2. 对结果拟合 Scaling Law
3. 从 Scaling Law 推断 n 的最优值
4. 选择保证训练稳定的最小 B_p
5. 将剩余算力投入额外训练步数 M
