# 2维注意力头

**2维注意力头**（2D Attention Head）是一种创新的注意力机制设计，它将高维向量映射到二维空间，从而将注意力计算转化为几何问题。

## 设计原理
在 2D 注意力头中，每个历史 Token 的 Key 向量被表示为二维平面上的一个点。当前步骤的 Query 向量则被视为二维平面上的一个方向。

此时，核心的注意力计算问题——找到与 Query 最匹配的 Key——就转化为了**凸包极值查询**问题：即在二维平面的凸包上，找到沿 Query 方向最远的点。

## 优势
*   **复杂度降低**：利用凸包数据结构，查询复杂度从 O(n) 降至 O(log n)。
*   **极速推理**：是 [[HullKVCache]] 实现每秒 3 万 Token 吞吐量的数学基础。
*   **无需定制硬件**：这种几何优化使得在普通 CPU 上进行高效长上下文推理成为可能。
