# 多意图理解

多意图理解（Multi-Intent Understanding）是指 AI 系统能够一次性解析并处理用户自然语言中包含的多个、甚至相互关联的复杂需求的能力。

## 技术内涵

这不仅仅是简单的语音识别（ASR），而是深度的语义理解（NLU）与逻辑规划。它要求 AI 模型在瞬间完成以下维度的分析：
- **空间维度**：理解地理位置、路径关系和实时路况。
- **时间维度**：处理时间窗口、先后顺序和截止时间约束。
- **偏好维度**：解析抽象形容词（如“方便”、“好吃”）并转化为具体的筛选条件。

## 应用场景

多意图理解在 [[场景智能]] 中至关重要，特别是在驾驶等双手和注意力受限的场景下。例如，用户说：“先去北京大学，中午找一家沿途方便又好吃的烤鸭店，下午5点前我要到T3航站楼。”

具备多意图理解的 AI（如 [[千问]]）会将其拆解为：
1. 导航至北京大学。
2. 搜索沿途符合“方便”和“好吃”标准的烤鸭店。
3. 预估用餐及堵车时间，确保下午5点前到达T3航站楼。

## 实现机制

通常依赖于云端多 Agent 协同工作。一个 Agent 负责拆解意图，多个子 Agent 分别负责调用地图、搜索、预订等 API，最终由主 Agent 进行逻辑校验和结果汇总，形成毫秒级的响应闭环。
