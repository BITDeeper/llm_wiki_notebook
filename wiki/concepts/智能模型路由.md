# 智能模型路由

智能模型路由是根据子任务复杂度自动分配不同成本模型的机制，旨在解决 Agent 大规模运行时的 Token 成本问题。[[opensquilla]] 将其作为核心卖点，号称节省 60-80% Token 成本。

## 工作原理

- 每个子步骤经过路由时，系统评估任务复杂度
- 简单任务（如提取年龄和偏好）分配给低成本模型（如 DeepSeek）
- 复杂任务（如生成安全审查方案、长周期规划）才分配给参数更大的模型
- 运行时以"老虎机"动画可视化各环节 Token 消耗和节省量

## 成本效果

- 弱智问题仅花三分钱（使用 DeepSeek）
- 经常出现单次任务节省90%+ Token 的情况
- 支持用户手动关闭路由或锁定到特定模型

## 行业意义

智能路由是 [[模型-技能分离架构]] 的工程实践案例，将模型选择从用户决策变为系统自动优化。在 [[tokenmaxxing]] 竞赛和 [[ai-subscription-crisis]] 的背景下，成本控制成为 Agent 大规模部署的关键基础设施。

## 注意事项

"60-80%节省"为 OpenSquilla 团队自述数据，目前缺乏第三方独立验证。
