# 厂商融资

英文 vendor financing，指硬件厂商向客户提供股权投资或贷款，客户再用这笔钱购买厂商产品，形成资金回流闭环的经典商业模式。

## 经典案例

- **思科**：历史上曾大规模使用厂商融资模式
- **[[英伟达]]**：将这一模式规模放大了一万倍

## 英伟达的运作机制

```
英伟达把钱投给客户 → 客户拿钱买英伟达的卡 → 英伟达收入再创新高 → 股价更高 → 有更多钱投下一个客户
```

最典型的案例是[[coreweave]]：接受英伟达股权投资 → 签下63亿美元算力采购协议 → 转租给[[openai]] → OpenAI又拿了英伟达300亿投资。

## 市场质疑

这种模式被质疑为[[循环交易]]——除了推高本就岌岌可危的AI泡沫，真实意义几何？与思科泡沫的历史类比引发市场担忧。

## 与Token经济的关系

[[黄仁勋]]的投资逻辑不止于厂商融资。更深层的驱动力是[[token经济]]——投资模型公司不只是绑定客户，更是在加固自身整个商业模式的地基。
