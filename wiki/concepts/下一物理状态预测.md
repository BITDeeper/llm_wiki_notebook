# 下一物理状态预测

Next Physical State Prediction——由[[智源研究院]]院长王仲远明确提出的世界模型核心范式。AI正从"预测下一个词元"（Next Token Prediction）演进到"预测下一个物理状态"，这是世界模型的核心本质，也是AI从数字世界迈向物理世界的关键范式变革。

## 范式演进脉络

- **Next Token Prediction** — 大语言模型的核心范式，在文本空间中预测
- **Next Frame Prediction** — 视频生成模型的核心范式，在像素空间中预测
- **Next Action Prediction** — 具身智能的传统范式，在动作空间中预测
- **Next Physical State Prediction** — 世界模型的新范式，在物理隐空间中预测

## 核心差异

传统大语言模型对现实世界的理解本质上来自海量语言数据中的经验归纳，而不是对物理过程的真实模拟。例如，大语言模型可能知道"推一下桌边的杯子，大概率会掉下来"，但并不意味着它明白重力、受力、惯性和空间关系。

下一物理状态预测要求模型真正理解物理规律，能够预测一个动作在真实世界里会产生什么物理后果。
