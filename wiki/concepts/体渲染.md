# 体渲染

体渲染（Volume Rendering）源自 NeRF（Neural Radiance Fields）的技术，在 [[occlusionformer|OcclusionFormer]] 中被创新性地迁移到 2D 图像生成领域，用于解决 [[z-order-遮挡|Z 轴遮挡]] 问题。

## 在图像生成中的应用

OcclusionFormer 通过虚拟正交相机审视图像平面，将物体的组合生成过程概念化为：光线穿过按 [[z-order-遮挡|Z-order]] 显式排列的像素空间。

与传统平面特征混合方式不同，体渲染能够：
- 避免密集交叉区域的严重特征纠缠
- 显式建模物体间的前后遮挡关系
- 保持 2D 平面上的边界精度与结构完整性

## 与 LaRender 的区别

LaRender 同样引入了体积渲染原理，但采用无训练的遮挡模拟方式，依赖启发式潜在特征操作，对超参数极其敏感。OcclusionFormer 则选择端到端训练路线，结合 [[查询对齐损失]] 实现了更稳定、更准确的遮挡建模。

## 跨领域技术借鉴

体渲染从 3D 场景重建（NeRF）迁移到 2D 布局条件图像生成，是一次典型的跨领域技术借鉴，展示了 3D 视觉技术对 2D 生成任务的启发价值。
