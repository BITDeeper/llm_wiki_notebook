# 配分函数

在 [[kl-正则化对齐目标|KL-regularized alignment objective]] 的最优策略 closed-form solution 中出现的归一化项，需要对所有可能输出求和，通常不可计算。

## 在偏好优化中的角色

配分函数是不同偏好优化方法需要以不同方式处理的核心数学障碍：

- **[[dpo-direct-preference-optimization|DPO]]**：在同一个 prompt 下比较两个输出时，partition function 在 reward difference 中自然抵消
- **[[qrpo|QRPO]]**：将原始 reward 转为 quantile reward，使 partition function 具有解析形式
- **[[tgo-threshold-guided-optimization|TGO]]**：用经验阈值近似与 partition function 相关的 oracle baseline

DPO 的简洁很大程度上依赖成对数据让配分函数抵消，这也是为什么一旦脱离成对设定，就需要新的数学工具来处理这一项。
