# AI编程飞轮

AI编程飞轮是指"AI写的代码反哺AI训练"的正反馈循环——掌握编程工具用户即掌握AI自训练循环的加速器。这是 [[ai-infrastructure-flywheel]] 在编程领域的具体变体。

## 核心逻辑

```
编程工具用户 → AI生成代码 → 代码反哺训练 → 模型更强 → 吸引更多用户
```

谁掌握了编程工具的用户，谁就掌握了这个循环的加速器。

## 现实证据

- [[gpt-5.5]] 的开发几乎可以确定是在 GPT-5.5 深度参与下进行的（GPT-5.6 同理）
- 三巨头同时补贴开发者，底层逻辑正是争夺飞轮加速权

## 三巨头补贴战（2026年5月）

- **OpenAI**：给 Codex 追加 ultrafast 模式，速度提升2-3倍；30天内切换的企业2个月免费；3小时内2000名开发者响应
- **Anthropic**：放出 Opus 4.7 Fast 模式，[[claude-code]] 额度提升50%
- **谷歌**：[[antigravity]] 多次调整定价，但采用率仍仅6%

## 战略意义

AI编程飞轮解释了为什么三巨头愿意在编程工具上大举补贴——这不是慈善，而是对未来训练数据来源的投资。这一概念与 [[递归式自我改进]] 和 [[ai-takeoff]] 密切相关。
