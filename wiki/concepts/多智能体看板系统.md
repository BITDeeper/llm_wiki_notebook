# 多智能体看板系统

多智能体看板系统是 [[hermes-agent|Hermes Agent]] 的任务调度架构，将单 Agent 问题升级为团队协作问题。

## 架构设计

- **底层存储**：本地 SQLite，持久化存储，跨重启不丢
- **任务拆分**：创建任务卡片后，Hermes 自动拆分为多个子任务
- **Worker 分配**：每个子任务分配给不同的 Agent worker
- **独立进程**：每个 worker 是独立的 OS 进程，拥有独立的身份、模型配置和工作目录

## 与 /goal 的关系

看板和 [[goal模式]] 是两套互补的系统：
- /goal 管单个 Agent 的目标锁定（[[ralph-loop]]）
- 看板管多个 Agent 之间的任务调度
- 一个纵向深入，一个横向铺开

## 配套机制

看板系统配合 [[五层防烂尾机制]] 运作，确保每个 worker 都在有效推进任务，不会出现"摸鱼型 Agent"反复领任务又不做的情况。
