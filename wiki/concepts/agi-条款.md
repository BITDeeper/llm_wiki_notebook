# AGI 条款

AGI 条款是指 [[OpenAI]] 与 [[微软]] 原合作协议中一项极具争议的特殊规定。该条款规定，一旦 OpenAI 达成通用人工智能（AGI），[[微软]] 对 OpenAI 技术的独家权利将自动终止，微软将失去对其技术的访问权。

## 背景与目的
设立此条款的初衷是为了确保 AGI 技术的安全性，防止单一商业实体过早垄断可能对人类构成威胁的超级智能。这也反映了 OpenAI 初期作为非营利组织的使命遗留。

## 核心争议
-   **既当运动员又当裁判**：原协议中判定 AGI 是否达成的权力掌握在微软手中。这意味着微软既是利益相关方（独家分销商），又是技术里程碑的判定者。
-   **商业不确定性**：对于 OpenAI 而言，这一条款虽然提供了摆脱微软控制的理论路径，但也引入了巨大的法律和商业不确定性。

## 战略影响
这一条款的存在深刻影响了 OpenAI 的商业战略与合作伙伴选择：
-   **排他性丧失风险**：一旦 AGI 实现，微软的“独家”地位自动失效，业务面临断供风险。
-   **基础设施多元化**：为了对冲这一风险，OpenAI 有动力引入其他合作伙伴（如 [[亚马逊]]）并建立独立于 [[微软]] 之外的基础设施能力。在 2026 年的融资中，OpenAI 与亚马逊的深度合作（如在 AWS 上部署非 API 工作负载）即被视为对此条款风险的对冲。
-   **避险需求**：OpenAI 不再将所有算力鸡蛋放在 Azure 一个篮子里，寻求更广泛的算力支持。

## 废除与影响
在 2026 年的协议重写中，双方彻底废除了 AGI 条款：
-   **删除定义权**：微软不再拥有判定 AGI 的权力。
-   **固定日期**：所有协议条款改为与固定日期挂钩，不再受技术里程碑影响。
-   **商业自由**：这一变更消除了 OpenAI 实现技术突破时可能面临的合同束缚，换取了确定性的商业自由。

该条款的废除也被视为对 [[Elon Musk]] 诉讼案的回应，旨在削弱“微软过度控制 OpenAI”的法律指控。
