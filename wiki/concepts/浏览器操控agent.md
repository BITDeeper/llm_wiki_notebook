# 浏览器操控Agent

指 AI Agent 通过浏览器插件直接操控网页元素（点击、填写、提取等），实现信息收集和网页操作自动化的能力。

## 核心特征

- **自动化浏览**：Agent 自主打开网页、导航、搜索
- **元素交互**：点击按钮、填写表单、勾选选项
- **信息提取**：从网页中抓取结构化数据并整理
- **任务编排**：将多步骤网页操作串联为完整工作流

## 代表实现

[[webbridge]] 是 [[kimi-work]] 内置的浏览器操控插件，目前评测反馈其交互体感优于竞品。

## 应用场景

- 竞品信息收集与整理
- 社交媒体内容监测
- 数据看板自动登录与数据抓取
- 表单自动填写与提交

## 与相关概念的区别

- 区别于传统爬虫：浏览器操控 Agent 模拟真实用户操作，可处理动态渲染页面
- 区别于 RPA：基于大模型理解页面语义，无需预编程操作路径
- 是 [[操作系统agent]] 理念在浏览器层面的具体实现
