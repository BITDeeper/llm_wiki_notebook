# C 语言训练堆栈

C 语言训练堆栈是指 [[spacex]] 旗下 xAI 团队用 C 语言从零编写的全新大模型训练软件栈，用以替代此前广泛使用的 [[jax|JAX]] 框架。

## 核心特征

- **抛弃 JAX**：不再使用 Google 开发的 JAX 高性能数值计算框架，转而使用更底层的 C 语言直接控制硬件
- **性能提升**：马斯克声称新堆栈使大模型训练速度提升了一个数量级
- **推理重写**：训练堆栈完成后，推理部分的堆栈也将用 C 语言重写
- **硬件协同**：与 [[colossus-2|Colossus]] 系列超算集群上的 GB300 等硬件深度协同优化

## 技术背景

JAX 作为高级框架提供了便捷的自动微分和 XLA 编译能力，但在极端性能场景下，框架层的抽象可能成为瓶颈。直接使用 C 语言编写训练堆栈意味着放弃框架便利性，换取对 GPU 硬件的极致控制和更高的计算效率。

## 应用

[[grok-5]] 已确认使用该 C 语言训练堆栈进行训练。
