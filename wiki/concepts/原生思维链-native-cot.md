# 原生思维链（Native CoT）

**原生思维链（Native CoT）** 是 [[星海图]] [[g0-5]] 模型中的关键技术组件，指模型在生成物理动作之前，先在同一条自回归序列中输出四类推理 token：

1. **原子子任务文本** — 将复杂任务分解为可执行的子步骤
2. **目标对象边界框** — 定位当前子任务涉及的目标物体
3. **二维末端执行器轨迹** — 规划机械臂的运动路径
4. **动作提示** — 提供动作执行的上下文信息

## 核心特点

- 推理 token 与动作 token 受同一个交叉熵损失函数约束，端到端联合优化。
- 推理和动作共享同一条自回归序列，动作生成时可直接回看 CoT 内容（而非通过压缩的条件向量传递）。

## 实验效果

- 在"面包放入空气炸锅"任务上，开启 Native CoT 后成功率提升 **30 个百分点**。
- 在"培根煎制"任务上，提升 **35 个百分点**。
- 思维链的价值随任务阶段数增加而急剧放大：单阶段任务仅提升 3.1pp，五阶段任务提升 30-35pp。
- 对比之下，CoT 对流匹配模式的提升仅约 10pp，不足自回归模式的三分之一。
