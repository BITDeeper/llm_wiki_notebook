# 统一内存架构

统一内存架构是指 CPU 和 GPU 共享同一池物理内存的芯片设计，区别于传统架构中 CPU 内存（系统 RAM）和 GPU 内存（显存）分离的模式。

## 技术特征

- CPU 和 GPU 共享同一池内存（如 LPDDR5X）
- 无需在 CPU 内存和 GPU 显存之间拷贝数据
- 内存容量可做到较大（如 [[n1x|N1X]] / [[rtx-spark|RTX Spark]] 的 128GB）
- CPU 和 GPU 通过高速互联（如 NVLink-C2C）共享同一内存池

## 优势

- **大容量**：统一内存可提供远超传统独显显存的容量，适合大模型本地推理
- **零拷贝**：CPU 和 GPU 之间无需数据传输，减少延迟
- **高能效**：减少内存芯片数量，降低功耗
- **灵活调度**：GPU 可直接调用系统内存，缓解传统独立显存容量受限的问题

## 权衡

- **带宽受限**：统一内存带宽远低于 GDDR 显存。[[n1x|N1X]] 的 GPU 可用带宽估计仅约 273 GB/s，而传统独显可达 500-1000 GB/s
- **不适合高性能图形**：带宽瓶颈导致游戏性能受限
- **CPU/GPU 争用**：两者共享带宽，高负载时互相影响

## 对本地推理的意义

统一内存架构对 [[本地推理]] 至关重要：

- 大语言模型需要大量内存加载参数，传统独立显卡的显存容量（通常 8-24GB）严重制约了可运行模型的规模
- 128GB 统一内存使消费级 PC 能够在本地运行较大参数的 AI 模型
- 消除 CPU-GPU 之间的数据拷贝开销，提升推理效率

## 代表产品

- 苹果 M 系列芯片（统一内存架构的先驱）
- [[n1x|N1X]]（英伟达版统一内存超级芯片）
- [[rtx-spark|RTX Spark]]（最高支持 128GB 统一内存，通过 NVLink-C2C 互联；在处理高分辨率视频合成或复杂 3D 几何图形时，GPU 可直接调用系统内存）
