# 里程碑任务依赖图

[[里程碑任务依赖图]]（Milestone DAG）是一种将零散的 Git 提交聚合为语义完整的功能单元，并严格保留代码时序依赖关系的图结构。

## 设计目的

在评估 AI 持续编程能力时，传统的 Commit 粒度太碎（包含大量琐碎修改），而 Release 粒度太粗（压缩了中间依赖）。Milestone DAG 旨在两者之间取得平衡：
-   **语义完整性**：每个 Milestone 代表一个功能内聚的开发目标。
-   **依赖保留**：严格保留任务间的代码时序依赖，确保演进路径的真实性。

## 构建方法

通常由 [[deepcommit]] 这样的自动化流水线生成，通过 Agent 驱动的静态分析和动态修复，将 Git 历史重构为可验证的 DAG 结构。

## 应用价值

Milestone DAG 是 [[evoclaw]] 基准的核心数据结构，使得评测能够要求 AI 在同一个代码库中连续执行多个相互依赖的任务，从而真实反映其在持续软件演进中的能力。
