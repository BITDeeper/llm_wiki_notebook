# Agent 协作能力

Agent 协作能力是指人类能够设计、监督、评估并与 AI Agent 共同工作的综合能力。在智能体时代，这取代了传统的“执行力”，成为初级岗位的核心技能要求。

## 能力构成

1.  **设计与拆解**：能将一段业务流程拆解到 Agent 可以执行的颗粒度，设计 Prompt 流程和触发条件。
2.  **监督与验证**：能判断 Agent 输出的正确性，进行抽查和案例升级，负责对话流调优。
3.  **编排与管理**：能管理多个 Agent 协同工作，设定边界和目标。

## 职业分层

根据这一能力的强弱，应届生被分为三类：
- **高风险层**：只会执行任务的人（如传统 Excel 处理、邮件跟进）。
- **门槛层**：会使用 AI 工具的人（这是保持资格的底线）。
- **稀缺层**：能与 Agent 协作、设计和管理 Agent 的人（这是 IBM、Salesforce 等大厂争抢的对象）。

## 岗位关键词

在招聘中，具备这一能力的岗位通常包含以下关键词：Agent Ops, Prompt Eval, Workflow Design, Agent Orchestration。
