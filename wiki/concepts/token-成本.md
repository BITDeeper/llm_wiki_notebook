# Token 成本

Token 成本指生成或处理单位 Token（文本片段）所需的货币成本，通常以“每百万 Token 价格”为计量单位。

## 重要性
在 [[Agent]] 时代，Token 成本成为衡量 AI 商业可行性的核心指标。
- **消耗激增**：Agent 的高频调用和多轮交互导致 Token 消耗增长数十倍甚至上百倍。
- **案例**：有用户仅向一个 AI 龙虾说了一句“Hi”，就烧掉了 80 美元的 Token 费用。
- **商业瓶颈**：企业关注点从“能不能用”转向“用不用得起”。高昂的成本会阻碍 AI 技术的大规模普及。

## 降低成本的路径
1. **硬件层**：使用专用推理芯片（如 [[启望-s3]]），通过裁剪训练模块、优化架构（如高利用率算子、低精度计算）来降低单位算力成本。
2. **系统层**：采用高带宽内存（[[LPDDR6]]）和高速互联（PCIe Gen6）提升吞吐量。
3. **目标**：[[曦望]] 提出了“百万 Token 一分钱”的激进目标，旨在降低 90% 的成本以实现普惠 AI。

## 相关概念
