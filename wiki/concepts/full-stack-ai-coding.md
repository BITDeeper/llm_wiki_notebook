# 全栈 AI 编码

[[full-stack-ai-coding]] 指的是 AI 系统具备独立开发完整应用程序的能力，涵盖前端界面、后端逻辑、数据库架构以及部署配置的全过程。

## 能力范畴

超越传统的代码补全或辅助编程，全栈 AI 编码要求模型能够：
1. **理解需求**：从自然语言描述中提取功能需求。
2. **技术选型**：自主决定合适的技术栈（如 React, MySQL, tRPC 等）。
3. **系统设计**：设计数据库 Schema 和 API 接口。
4. **实现与验证**：编写可运行代码，并确保数据流（如表单提交到后台存储）通畅。

## 实例验证

[[kimi-k2-6]] 的测试案例展示了这一能力：它构建了一个包含前端 3D 交互页面、后端 API 以及带密码验证的管理后台的报名系统，并成功验证了数据的写入功能。

## 发展趋势

随着模型推理能力和工具调用能力的增强，AI 编程正从“辅助人类写代码”向“替代人类完成简单全栈开发”演进。这对软件开发流程和开发者角色提出了新的挑战和机遇。
