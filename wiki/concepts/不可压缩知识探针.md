# 概念定义
**不可压缩知识探针**（Incompressible Knowledge Probes, IKP）是一种通过黑盒 API 调用来评估大语言模型（LLM）参数规模的评测框架。其核心思想是利用模型对冷门、长尾事实性知识的记忆准确率，来逆向推断其物理参数量。

# 核心原理
该框架基于以下假设：
1. **可压缩性差异**：模型的逻辑推理能力可以通过蒸馏、训练技巧等手段进行有效压缩；然而，对具体事实性知识（如特定年份的赛事题目、冷门文献细节）的记忆容量，主要受限于模型的物理参数规模，难以通过算法手段大幅压缩。
2. **对数线性关系**：在开源模型上，事实准确率与参数量之间存在显著的对数线性关系（拟合优度 R² = 0.917）。

# 方法论
1. **数据集构建**：构建包含大量冷门问题的数据集（如 1400 个问题），并按信息的稀缺程度划分为多个层级（如 7 个层级）。
2. **基准拟合**：在参数量已知的开源模型上进行测试，建立“事实准确率 vs 参数量”的拟合曲线。
3. **黑盒估算**：将闭源模型在相同数据集上的表现代入拟合公式，推算其可能的参数规模。

# 局限性与争议
- **合成数据干扰**：如果模型通过合成数据进行了针对性的微调，可能会显著提升对特定冷门知识的掌握度，从而导致参数量被高估。
- **架构差异**：[[MoE (混合专家) 架构]] 模型与稠密模型在知识存储和压缩效率上可能存在本质差异，混合统计可能导致偏差。
- **置信区间宽**：估算结果的置信区间通常较大（如 0.3 至 3 倍），意味着结果仅能作为量级参考，而非精确测量。
- **反驳 Densing Law**：IKP 的研究发现模型的事实记忆容量在过去三年中并未随时间显著提升（时间系数接近零），这与预测效率随时间提升的 [[Densing Law]] 相悖。

# 应用实例
该框架被用于估算主流闭源模型的参数量，例如推算 [[GPT-5.5]] 约为 9 万亿参数，[[Claude Opus 4.7]] 约为 4 万亿参数。尽管这些数字引发了巨大争议，但 IKP 提供了一种在无法访问内部权重的情况下，窥探模型“黑盒”规模的新思路。
