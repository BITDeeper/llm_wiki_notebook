# 自主规划

**自主规划** 是指 AI Agent 在接收到复杂指令后，能够自主将其拆解为可执行的子任务序列，并按步骤调用工具完成目标的能力。它是 [[桌面智能体]] 区别于传统脚本或宏命令的核心智能特征。

## 工作流程

典型的自主规划流程包括：
1.  **拆解**：将“分析销售表并生成报告”这样的模糊指令，拆解为“读取数据 -> 清洗数据 -> 计算指标 -> 生成图表 -> 撰写摘要”等具体步骤。
2.  **执行**：按顺序调用相应的工具或 API 完成每个子任务。
3.  **反馈**：在执行过程中向用户展示进度，遇到歧义时主动询问（例如：“您希望按月还是按季度汇总？”），而非自作主张。

## 价值

自主规划解决了早期 AI 助手“听懂指令但瞎搞”或“遇到复杂任务直接死机”的问题。它使得 AI 能够像成熟的员工一样处理多步骤任务，是实现 [[工具自由]] 的技术基础。
