# 私域数据CLI化

私域数据 CLI 化是指将微信、Telegram、Discord 等封闭聊天平台的数据通过 CLI 工具统一接管，使其可搜索、可导出、可自动化处理的技术实践。

## 背景

聊天记录散落在各个 App 中，是碎片化的隐性知识。其中包含工作流、关系链、协作历史、长期偏好等 AI 以前根本碰不到的信息。这些数据不是静态文档，而是实时更新的个人信息流。

## 核心价值

1. **可搜索：** 跨平台统一搜索聊天内容
2. **可导出：** 输出 JSON/CSV 格式，直接灌入知识库或数据分析流程
3. **可自动化：** 与 Obsidian 等知识管理工具对接，实现持续更新的个人信息流
4. **Agent 能力扩展：** 让 Agent 真正具备持续读取用户真实数字生活最新信息的能力

## 代表工具

- [[wx-cli]] — 微信聊天记录读取（需 root 权限，从进程内存扫描数据库密钥）
- OpenCLI Telegram 模块 — 基于 MTProto 协议搜索消息
- OpenCLI Discord 模块 — 查询最近消息和频道操作

## 合规与隐私

私域数据访问属于灰色地带。微信聊天记录读取需要 root 权限和内存密钥扫描，存在法律风险。工具提供的是技术能力，实际使用需仔细评估合规风险和隐私边界。
