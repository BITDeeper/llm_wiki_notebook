# 概述

[[黑盒边界输入追踪]]（Black-Box Boundary Input Tracking, 简称 B3IT）是一种专门针对 [[黑盒环境]] 设计的模型变动检测技术。当审计者无法获取模型内部状态或对数概率时，该技术通过利用模型决策边界的不稳定性，以极低的成本检测后台模型是否被 [[模型调包]]。

# 核心机制：边界输入

B3IT 的核心在于寻找特定的“边界输入”。这些输入能让模型在两个或多个候选Token之间产生剧烈的犹豫，即这些Token的逻辑得分几乎完全持平。

根据统计学原理（[[费希尔信息量]]），在低Temperature（如接近0）的采样条件下：
- 如果模型对某个输出非常确定（只有一个顶级Token），微小的参数扰动很难改变输出，检测信噪比极低。
- 但如果模型处于“犹豫”状态（存在多个得分持平的Token），检测信噪比会随着Temperature降低而急剧发散。此时，模型参数的任何微小扰动都会打破原有的概率平衡，导致输出从随机采样坍缩为确定性选择。

# 实施流程

1. **初始化阶段**：
    - 从海量随机提示词中筛选出合格的边界输入。
    - 方法：在Temperature为0的条件下对候选提示词进行少量（如3次）重复采样，观察是否产生不同的输出Token。
    - 通常只需不到1500次请求即可锁定足够的敏感点。

2. **监测阶段**：
    - 定期在极低Temperature下对这些已知的边界输入进行采样。
    - **判定标准**：如果观测到了参考分布中从未出现的Token，或者原本多样化的输出突然坍缩为单一Token，则判定后台模型已发生变更。

# 性能表现

- **成本优势**：在黑盒环境下的监测成本仅为现有最先进（SOTA）方案的1/30。
- **准确率**：识别单步微调模型变动的准确率可达87%。
- **对抗性**：由于检测极其高效，部分API供应商试图通过强制生成长文本（如至少16个Token）来增加探测成本，这也侧面印证了该技术的威慑力。
