# 设计到代码流水线

[[设计到代码流水线]]（Design-to-Code Pipeline）是指从视觉设计稿直接生成可运行代码（如 HTML/CSS/JS 或 React 组件）的自动化工作流程。

## 关键环节

1.  **设计生成**：在 [[claude-design]] 等工具中完成视觉设计。
2.  **打包交接**：一键生成 Handoff Bundle（交接包），包含设计意图、样式规范和布局信息。
3.  **代码实现**：将交接包输入 [[claude-code]] 等 AI 编程工具，自动生成前端代码。

## 影响

这一流程消除了设计与开发之间的“人工翻译”环节（如手动标注、切图），极大缩短了产品从想法到上线的周期，是 [[ai-native-design]] 范式下实现软件生产自动化的关键一环。
