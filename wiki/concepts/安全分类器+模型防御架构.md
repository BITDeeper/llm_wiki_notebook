# 安全分类器+模型防御架构

安全分类器 + 模型防御架构是当前主流的 AI 安全静态防御范式，被新一代超级智能体普遍采用。

## 工作原理

该架构在模型外围部署安全分类器（Safety Classifier），对用户输入进行风险识别与拦截。当检测到高风险请求时，系统会根据风险等级直接拒绝请求，或切换至更加保守的模型处理。例如[[fable-5|Fable 5]]在检测到高风险请求时会切换至[[opus-4-8|Opus 4.8]]模型。

该架构对直接的高风险请求非常敏感，能有效检测和过滤显性的高风险指令，使传统对抗提示、角色扮演、编码绕行等越狱攻击技术几乎全部失效。

## 结构性缺陷

[[内部安全坍塌]]（ISC）揭示了该架构的根本性缺陷：安全分类器仅在输入层拦截显性风险，无法感知智能体在长时运行、多步规划、环境交互以及工具调用过程中逐渐产生的内在风险行为。如果突破口不是从用户 Prompt 进入，而是从 Agent 的目标、工具、校验器和执行轨迹中出现，那么安全检测器就会变得非常脆弱。

外部检测器对 Prompt 边界有效，并不等于它能覆盖 Agent 内部的长程任务风险。
