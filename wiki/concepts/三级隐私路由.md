# 三级隐私路由

[[三级隐私路由]] 是一种数据安全分级处理机制，主要用于 [[端云协同]] 场景下，决定数据是在本地处理还是发送到云端。

## 分级标准

该机制将数据分为三个安全等级：

1.  **S3（私密）**：
    -   **定义**：极度敏感的信息，如 SSH 私钥、硬编码密码、工资单等。
    -   **处理策略**：物理隔离。请求完全由本地模型离线处理，云端毫不知情。

2.  **S2（敏感）**：
    -   **定义**：包含个人身份或内部网络信息的数据，如含内网 IP 的告警日志、含手机号的联系人列表。
    -   **处理策略**：[[智能脱敏]]。自动识别并替换敏感信息（例如将“王小二”替换为 `[REDACTED:NAME]`），然后转发给云端模型。

3.  **S1（安全）**：
    -   **定义**：不涉及隐私的普通问题，如“HTTP 403 和 401 有什么区别？”。
    -   **处理策略**：直接发往云端，利用云端大模型的最强能力。

## 技术实现

在 [[ClawXRouter]] 中，这一机制通过植入 **Hook**（钩子）来实现，像安检一样自动扫描每一条消息、工具调用和 Agent 输出。其背后通常由“规则+模型”双检测引擎驱动，以确保分类的准确性和效率。
