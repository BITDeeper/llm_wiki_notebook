# DOM 渲染

## 概述
[[DOM 渲染]]（DOM Rendering）是指传统浏览器根据 HTML 和 CSS 代码构建文档对象模型（DOM），并计算布局和样式以生成网页视觉呈现的过程。

## 特点
-   **声明式**：开发者描述“结构是什么”，浏览器决定“怎么画”。
-   **限制性**：通常基于矩形盒模型，难以实现非线性布局或像素级特效。
-   **易用性**：对于常规内容展示，提供了开箱即用的组件和布局系统。

## 挑战与变革
随着 [[html-in-canvas]] 和 [[pretext]] 等技术的出现，传统 DOM 渲染在自由度和性能上的局限性受到挑战。新技术试图绕过或接管 DOM 渲染流程，以实现更复杂的视觉效果和更高的性能，特别是在游戏化 UI 和生成式界面场景中。
