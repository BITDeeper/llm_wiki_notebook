# AI 编辑部

一种利用多个 AI 智能体（Agent）模拟传统编辑部工作流程的协作模式。

## 工作原理
通过创建多个具有不同角色定位、人设和技能的 Agent，将复杂的内容生产任务拆解并分配给不同的 Agent 协同完成。

## 典型架构
在 [[飞书-aily]] 的演示案例中，AI 编辑部包含以下角色：
1. **总编虾**：负责分析选题、设计提纲，并调用表格同步任务状态。
2. **记者虾**：负责根据提纲搜集相关资料。
3. **编辑虾**：负责根据资料撰写初稿。
4. **校对虾**：负责校对文章内容。
5. **排版虾**：负责对终稿进行排版。
6. **运营虾**：负责将文章发布到网站。

## 优势
- **专业化分工**：每个 Agent 专注于特定环节，提高了输出的专业性和质量。
- **流程可控**：通过表格看板实时追踪每个环节的进度，便于管理和干预。
- **可扩展性**：可以根据业务需求灵活增减 Agent 角色或调整流程。

## 意义
AI 编辑部是 [[企业级长任务]] 自动化处理的典型案例，展示了多 Agent 协作在复杂业务场景中的应用潜力。
