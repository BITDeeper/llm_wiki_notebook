# 计算与存储解耦

**计算与存储解耦**（Decoupling Compute and Memory Access）是一种计算机架构设计理念，旨在将数据的读取过程（存储访问）与数据的处理过程（计算）从传统的串行模式改为并行模式，以减少等待时间，提高硬件利用率。

## 背景与问题

在传统的 AI 推理架构中，当模型需要处理大规模上下文（如智能体的长对话历史）时，必须先将存储在 CPU 内存或磁盘中的 [[KV-Cache]] 数据通过 PCIe 总线加载到 GPU 显存中。只有当数据完全加载完毕后，GPU 的计算单元才能开始工作。

这种“串行”模式导致了严重的资源浪费：在数据加载期间，昂贵的 GPU 计算单元处于**空转**状态。随着智能体应用对上下文长度需求的爆发式增长，数据加载时间（I/O 延迟）逐渐超过了计算时间，使得 I/O 成为系统的主要瓶颈。

## 工作原理

计算与存储解耦通过引入独立的流水线或通路，打破这种串行依赖：

1.  **并行流水线**：系统同时维护数据加载流水线和计算流水线。
2.  **缓冲机制**：在内存（DRAM）中设置缓冲区，数据预先加载至此，计算单元直接从缓冲区读取数据进行计算，无需等待远端存储的响应。
3.  **流式处理**：结合 [[块式流处理]] 技术，将大数据切分，实现“边下载边计算”。

## 实际应用

[[DeepSeek]] 的 [[DualPath]] 架构是该理念在 AI 推理领域的典型应用。DualPath 引入了 **Storage-to-Decode** 通路，使得 GPU 在进行当前步推理计算的同时，后台可以并行加载下一步所需的 KV Cache 数据。

## 意义

*   **消除 I/O 瓶颈**：有效掩盖了内存访问延迟，使得系统吞吐量不再受限于数据加载速度。
*   **提升资源利用率**：显著减少了 GPU 的空转时间，在相同硬件下实现了近乎 2 倍的性能提升。
*   **降低成本**：通过软件层面的架构优化，在不增加硬件采购成本的前提下，大幅降低了单位推理成本。
