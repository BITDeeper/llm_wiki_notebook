# 多Agent并行推理

**多Agent并行推理**（Multi-Agent Parallel Reasoning）是一种系统架构模式，指使用多个专门的 AI 智能体同时处理同一任务的不同部分，以提高系统的效率、准确性和鲁棒性。

## 架构原理
与单一通用模型处理所有任务不同，多 Agent 并行推理将复杂的任务拆解，分配给多个高度专业化的 Agent 并发执行。每个 Agent 专注于特定的子任务或视角，最终通过编排器汇总结果。

## 典型应用：ASMR 系统
在 [[Supermemory]] 的 [[ASMR]] 系统中，多 Agent 并行推理是其核心架构，主要分为两个阶段：

### 1. 摄取阶段（观察者 Agent）
- **配置**：3 个并行 Agent。
- **分工**：将原始会话数据按顺序分配给不同 Agent（如 Agent 1 处理奇数会话，Agent 2 处理偶数会话）。
- **优势**：显著提升了信息提取的速度与颗粒度，避免了单一模型处理超长上下文时的注意力分散。

### 2. 检索与生成阶段（搜索 Agent 与决策森林）
- **搜索 Agent**：3 个 Agent 并行搜索，分别关注事实、上下文和时间线，确保检索的全面性。
- **决策森林**：8 个或 12 个 Agent 并行推理，通过“多重判断”或“多数投票”机制得出最终答案。

## 优势
- **专业化分工**：专用专家（如时间专家、细节提取器）的表现远超单一的全能提示词。
- **盲区覆盖**：并行的多重推理路径可以互相覆盖盲区，只要有一条路径正确，系统即可得出正确结果。
- **效率提升**：通过并发处理，可以在保证质量的同时缩短总响应时间。

## 与传统方法的对比
传统的向量搜索或单一模型推理往往在面对复杂、矛盾或高密度信息时失效。多 Agent 并行推理通过“分而治之”的策略，利用群体的智慧解决了单一模型的局限性。
