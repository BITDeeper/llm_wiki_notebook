# 渐进式三阶段训练

渐进式三阶段训练是 [[gamma]] 模型采用的系统性训练方法论，使模型能力从「基础对齐」逐步发展到「复杂时序推理」。

## Stage 1：多模态对齐预训练

**目标**：建立音乐与文本之间的基础对齐能力。

- 训练数据：数百万级音乐-文本对，覆盖音乐-描述与音乐-歌词两类监督信号
- 音频限制：60 秒以内，每段最多 1500 token
- 训练策略：仅训练音频到语言空间的 Projector，冻结 LLM 主体参数
- 歌词处理：根据歌词时间戳切分音乐，使用 Qwen 词表语言标记区分歌词语种
- 设计意图：最大程度保留预训练语言模型已有的语义能力

## Stage 2：监督微调（SFT）

**目标**：构建高质量、具备时间结构监督信号的音乐指令数据。

- 使用 SongFormer 进行秒级细粒度音乐结构分割
- 将时间对齐的音乐片段与歌词输入 Gemini 2.5 Pro 生成详细音乐分析报告
- 具备音乐专业背景的人类专家进行严格校验（时间对齐修正、语义一致性筛选、音乐学合理性重写）
- 预定义 11 个音乐维度的问题模板（结构、节奏、旋律、配器等）
- 使用 GPT-5.1 对模板进行改写与个性化重述，避免过拟合
- 音频扩展至 300 秒（7500 token），全参数可训练

## Stage 3：强化学习（GRPO）

**目标**：通过强化学习进一步提升复杂音乐推理能力。

- 沿用 SFT 数据生成流程构建初始种子样本
- Monte Carlo rollout 估计可解性（Pass 率）
- 仅保留中等难度样本（25% ≤ Pass < 1%），避免过易或过难样本退化学习信号
- Gemini 2.5 Pro 合成语义一致但推理路径更复杂的问题变体
- Rollout-based 验证：对合成样本进行可解性筛选与一致性校验
- 采用 [[grpo]] 算法优化，奖励函数由答案正确性与格式一致性共同构成

## 设计理念

三阶段训练体现了「由浅入深、逐步精化」的训练哲学：先建立跨模态对齐基础，再通过高质量监督信号注入领域知识，最后通过强化学习突破能力天花板。这种渐进式策略与 [[MedGRPO]] 在医疗视频理解领域的三阶段方法（预训练→SFT→RL）形成了跨域方法论呼应。
