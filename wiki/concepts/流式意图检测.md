# 流式意图检测

流式意图检测是一种在数据流（如文本流、音频流）上实时运行的意图识别技术。它无需等待用户输入完整，即可在输入过程中开始推理用户的潜在需求。

## 技术背景
传统的 AI Agent 机制通常依赖完整的 Prompt 和 API 调用，这导致推理延迟往往超过 3 秒，无法满足人类实时交互的需求（忍耐极限约 2 秒）。流式意图检测借鉴了端到端语音/视频流式模型的经验，旨在将意图识别的延迟压缩至 1.5 秒以内。

## 工作原理
*   **输入**：连续的文本化多模态信息流 + 用户记忆。
*   **处理**：模型在流上持续运行，实时分析上下文变化。
*   **输出**：判断用户当下的意图（如“需要解释”、“怀疑真实性”），但不直接生成最终结果，而是作为触发器调用上层 AI 能力。

## 应用场景
该技术是构建 [[主动智能体]] 的基石。例如 [[pask]] 系统中的 [[intentflow]] 模型，就是利用流式意图检测来实现“在用户开口前就知道其深层意图”的功能。
