# A2A (Agent-to-Agent)

**A2A**（Agent-to-Agent）是指多个 AI 智能体之间进行通信、协作和协调的协议或机制。它是实现复杂自动化任务的关键技术，允许不同的 Agent 专注于各自的专长，共同完成单一 Agent 无法处理的复杂目标。

## 应用场景

在企业级 AI 应用中，A2A 协议使得高度专业化的分工成为可能。例如：
- 一个 Agent 负责收集数据，另一个负责分析，第三个负责生成报告。
- Microsoft Copilot Agents 支持多 Agent 协同，被视为其核心优势之一。

## 发展趋势

随着 [[workspace-agents]] 等平台的普及，A2A 协作预计将成为企业自动化的标准范式。未来的工作流可能不再是人与 AI 的交互，而是多个 AI 在后台协同工作，人类仅负责最终审核。
