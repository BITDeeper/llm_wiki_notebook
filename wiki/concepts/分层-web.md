# 分层 Web (Layered Web)

分层 Web 是对未来互联网结构的一种预测，指随着 [[webmcp]] 等协议的普及，互联网将分化为两个独立的层级。

## 结构划分
1. **人类视觉层**：专注于视觉美感、品牌叙事和用户体验，服务于人类用户。
2. **Agent 工具层**：专注于结构化数据、极速响应和逻辑契约，服务于 AI 智能体。

## 竞争要素
开发者 [[nikoloz-turazashvili]] 指出，在分层 Web 时代，最终赢家将不再是那些界面最花哨的应用，而是那些拥有最清晰“工具契约”的应用。这意味着 Web 开发的核心竞争力将从“像素设计”转向“Schema 定义”。
