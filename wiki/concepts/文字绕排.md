# 文字绕排

**文字绕排**（Text Wrapping）是指文本内容在遇到障碍物（如图片、插画、几何形状）时，能够自动调整排列路径，沿着障碍物边缘流动的排版技术。

## 传统实现方式

### CSS Float
在传统 Web 开发中，最基础的文字绕排是通过 CSS 的 `float` 属性实现的。例如，让图片左浮动，文本就会自然环绕在图片右侧。

**局限性**：
-   只能实现简单的矩形绕排。
-   无法处理不规则形状（如圆形、多边形或复杂的插画轮廓）。
-   布局控制力弱，难以实现复杂的杂志级排版。

### CSS Shapes
CSS Shapes 模块引入了 `shape-outside` 等属性，允许开发者定义非矩形的浮动区域。

**局限性**：
-   浏览器兼容性曾一度是问题。
-   依然依赖于浏览器的布局引擎，在处理动态变化的形状或大量文本时，性能开销巨大（频繁触发 [[布局回流]]）。

## Pretext 中的文字绕排

[[Pretext]] 通过其高性能的布局引擎，将文字绕排的能力提升到了新的高度：

1.  **动态绕排**：文本可以实时绕过动态移动的物体。例如，在演示中，文本会毫秒级自动避让画面中移动的喷火龙插画。
2.  **高性能**：由于 [[Pretext]] 使用纯数学计算布局，而非查询 DOM，因此即使每一帧都在重新计算绕排路径，也不会导致页面卡顿。
3.  **任意形状**：通过 `layoutNextLine()` 等高级 API，开发者可以逐行指定文本的可用宽度，从而实现任意复杂的绕排逻辑。

## 应用场景
-   **创意营销页面**：制作类似《预言家日报》的动态报纸效果。
-   **游戏 UI**：在游戏界面中，文本需要绕过角色模型或不规则的游戏元素。
-   **电子书/杂志**：提供比传统 PDF 或网页更丰富的阅读体验。
