# 线性注意力

线性注意力是一种旨在降低标准自注意力机制计算复杂度的优化技术。

## 背景与动机

标准的自注意力机制需要计算 Query (Q) 与 Key (K) 的点积矩阵，其计算复杂度与序列长度的平方（$O(N^2)$）成正比。对于高分辨率图像或长序列数据，这种二次复杂度会导致巨大的计算开销和内存消耗，严重阻碍了 Transformer 模型在移动端或长序列任务中的部署。

## 核心机制

线性注意力通过利用核技巧（Kernel Trick）或矩阵结合律，改变计算顺序，将复杂度从 $O(N^2)$ 降低到 $O(N)$。

常见的形式是将 Softmax 的指数运算移除或替换为其他映射函数，使得注意力矩阵的计算可以分解，从而避免显式构建巨大的 $N \times N$ 注意力图。

## 挑战与缺陷

尽管线性注意力极大地提升了效率，但它也存在固有的缺陷：

1.  **表达能力下降**：由于简化了相似度计算（通常去除了 Softmax），模型对特征间关系的刻画能力可能弱于标准注意力。
2.  **高熵特性与 Token 干扰**：线性注意力的特征图往往具有较高的熵值，意味着信息分布更加平滑但也更缺乏聚焦。这可能导致不同位置的 Token 特征相互干扰，使得模型难以关注到关键信息。
3.  **精度损失**：在直接替换标准注意力时，往往会导致模型精度下降。

## 优化方向

为了弥补上述缺陷，研究者提出了多种改进方案：

*   **特征解耦**：如 [[care-transformer]] 中的 [[非对称特征解耦]]，将线性注意力仅应用于部分通道或特征，结合局部卷积来增强细节捕捉。
*   **显式交互**：通过引入额外的交互模块（如 [[双交互模块]]），在线性注意力分支之外补充信息流动，增强特征的表达能力。
*   **动态记忆**：利用记忆单元存储全局信息，辅助线性注意力构建更准确的上下文关系。

## 应用

线性注意力广泛应用于高效 Transformer 变体中，如 Linformer, Performer, 以及移动端视觉模型（如 MobileViT, CARE）。
