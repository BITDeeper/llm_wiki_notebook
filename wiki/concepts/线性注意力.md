# 线性注意力

**线性注意力**（Linear Attention）是一种旨在降低标准自注意力机制计算复杂度的优化技术。它用固定大小状态矩阵 S 压缩存储历史信息，将标准 Transformer 的 $O(N^2)$ 复杂度降至 $O(N)$。代表性工作包括 Linear Attention（ICML 2020）、RWKV、Mamba、[[gdn-gated-deltanet|Gated DeltaNet]] 等。

## 背景与动机

标准的自注意力机制需要计算 Query (Q) 与 Key (K) 的点积矩阵，其计算复杂度与序列长度的平方（$O(N^2)$）成正比。对于高分辨率图像或长序列数据，这种二次复杂度会导致巨大的计算开销和内存消耗，严重阻碍了 Transformer 模型在移动端或长序列任务中的部署。

## 核心机制

### 计算原理

线性注意力通过利用核技巧（Kernel Trick）或矩阵结合律，改变计算顺序，将复杂度从 $O(N^2)$ 降低到 $O(N)$。常见的形式是将 Softmax 的指数运算移除或替换为其他映射函数，使得注意力矩阵的计算可以分解，从而避免显式构建巨大的 $N \times N$ 注意力图。

### 有限背包类比

Transformer 的 Attention 机制是"无限背包"：把每个 token 的 KV 完整保存在 KV Cache 中，推理时逐一比对。线性注意力则是"有限背包"：用固定大小的状态矩阵 S 压缩存储所有历史信息，不管序列多长，S 的大小不变。

背包容量有限，每来一个新 token，模型必须决定往里写什么、同时擦掉什么。这个"写与擦"的规则，决定了有限背包模型的天花板。

### 本质上是 RNN，但可并行

有限背包模型的数学形式本质上就是 RNN：每一步的状态依赖上一步。但当递推关系满足线性结构（参数只依赖当前输入、不依赖历史状态）时，可以被改写为满足结合律的二元运算，从而使用 Parallel Scan（并行前缀扫描）实现并行计算。N 步串行递推可在 $O(\log N)$ 深度内完成。

## 挑战与缺陷

尽管线性注意力极大地提升了效率，但它存在以下固有缺陷：

1.  **表达能力下降**：由于简化了相似度计算（通常去除了 Softmax），模型对特征间关系的刻画能力可能弱于标准注意力。
2.  **高熵特性与 Token 干扰**：线性注意力的特征图往往具有较高的熵值，意味着信息分布更加平滑但也更缺乏聚焦。这可能导致不同位置的 Token 特征相互干扰，使得模型难以关注到关键信息。
3.  **精度损失**：在直接替换标准注意力时，往往会导致模型精度下降。
4.  **Rank-1 写入瓶颈**：以 GDN 为代表的线性注意力模型，每个 token 对 S 做一次 rank-1 更新。如果 token 携带的语义是多维度的，rank-1 写入无法同时在这些维度上做精细调整。这是当前所有线性复杂度模型的共有瓶颈。
5.  **Memory-bound 瓶颈**：GPU 上真正的瓶颈不是计算而是 HBM↔SRAM 数据搬运。Parallel scan + fused kernel 将搬运次数从 $O(N)$ 降到 $O(1)$，这是 10-100 倍实际运行速度差异的根源。能否适配 parallel scan 直接决定了模型的实际部署可行性。

## 优化方向

为了弥补上述缺陷，研究者提出了多种改进方案：

*   **特征解耦**：如 [[care-transformer]] 中的 [[非对称特征解耦]]，将线性注意力仅应用于部分通道或特征，结合局部卷积来增强细节捕捉。
*   **显式交互**：通过引入额外的交互模块（如 [[双交互模块]]），在线性注意力分支之外补充信息流动，增强特征的表达能力。
*   **动态记忆**：利用记忆单元存储全局信息，辅助线性注意力构建更准确的上下文关系。
*   **多步写入突破 Rank-1 瓶颈**：[[prism|PRISM]] 通过多步残差迭代实现 rank-L 写入来缓解此瓶颈，[[ttt-test-time-training|TTT]] 则通过将状态升级为 MLP 权重做多步梯度下降来突破。

## 与相关概念的关系

- **[[参数化记忆]]**：线性注意力的状态矩阵 S 本质上是一种参数化记忆形式。
- **[[context-rot]]**：有限背包长序列信息覆盖是 context-rot 的另一种表现形式。
- **[[混合架构]]**：线性注意力层 + 少量 Transformer 层的混合可能是必然趋势，前者提供 $O(N)$ 高速处理，后者提供精确长程检索。
- **[[rtpturbo-v2]]**：互补方向——RTPurbo 压缩 Full Attention 的计算量，线性注意力从根本上使用固定状态避免 $O(N^2)$。

## 应用

线性注意力广泛应用于高效 Transformer 变体中，如 Linformer, Performer, 以及移动端视觉模型（如 MobileViT, CARE）。
