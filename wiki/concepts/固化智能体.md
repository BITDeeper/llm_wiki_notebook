# 固化智能体

固化智能体是指将 AI 动态生成的执行流程“固化”为永久可用的、确定性的软件基础设施的一种技术机制。

## 工作原理
1.  **动态生成**：AI 根据用户的自然语言指令，实时编写代码并编排工具，完成一次性的任务执行。
2.  **验证与固化**：用户对执行效果满意后，系统将这一动态流程“冻结”或“固化”为一个可重复调用的 Agent。
3.  **确定性执行**：固化后的 Agent 在后续运行中不再依赖 LLM 的实时推理，而是执行预生成的确定性代码。

## 核心优势
*   **消除幻觉**：由于脱离了 LLM 的实时生成环节，固化后的 Agent 能够实现 100% 的执行准确率，解决了 AI 固有的幻觉问题。
*   **持久化与复用**：固化的 Agent 可以被定时调度、重复运行，并作为技能复用于其他场景，形成复利式的能力积累。
*   **离线运行**：固化的流程通常运行在云端，不依赖用户本地设备的在线状态。

## 应用场景
这一机制主要应用于需要长期稳定运行的生产力工具中，例如自动化竞品监控、内容流水线处理等。[[creao]] 是目前采用这一机制的代表性产品。
