# 决策森林

**决策森林**（Decision Forest）是一种集成学习策略在 AI Agent 领域的应用。它通过部署多个高度专业化的 AI Agent 独立处理同一任务，并引入一个“聚合器”来综合这些 Agent 的输出，以生成最终的单一权威答案。

## 工作机制
在 [[ASMR]] 系统中，决策森林的具体实现如下：
1. **独立推理**：12 个高度专业化的 Agent 变体（由 [[GPT-4o-mini]] 驱动）独立阅读上下文并生成答案。
2. **聚合裁决**：一个“聚合大模型”作为裁判，通过以下机制综合这 12 个答案：
   - **多数投票**：选择获得最多支持的答案。
   - **领域信任度**：根据特定 Agent 在该问题领域的可靠性进行加权。
   - **冲突解决**：当答案不一致时，依据逻辑或元数据进行裁决。

## 性能表现
尽管决策森林旨在产出单一、权威答案（而非像“8 变体集群”那样只要有一条对就算对），它在 [[LongMemEval]] 测试中依然取得了高达 **97.2%** 的准确率。这证明了通过多 Agent 协同和冲突解决机制，可以在保持输出简洁性的同时维持极高的准确性。

## 与“8 变体集群”的对比
- **8 变体集群**：侧重于覆盖盲区，只要有一条路径正确即视为成功（准确率 98.6%）。
- **决策森林**：侧重于达成共识，输出单一、可靠的答案（准确率 97.2%）。

## 适用场景
决策森林适用于对答案的确定性和一致性要求较高的场景，例如需要给出明确建议或执行具体操作的 AI 系统。
