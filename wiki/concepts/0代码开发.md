# 0代码开发

0代码开发（Zero-Code Development）指利用 AI 辅助工具，在不手动编写底层代码的情况下构建软件产品的流程。这一趋势极大地降低了软件开发的门槛，使得个人或小团队能够以极低成本快速验证商业创意。

## 典型工具链
- **产品定义**：ChatGPT / Claude / Gemini（生成 PRD、用户流程）。
- **UI/UX 设计**：Figma AI / Uizard / Galileo AI（生成界面原型）。
- **前端开发**：[[claude-code]] / Cursor / GitHub Copilot（根据描述生成代码）。
- **后端服务**：Firebase / Supabase（无服务器数据库和逻辑）。

## 案例分析
[[死了么-app]] 是 0代码开发的典型案例。三位95后开发者利用上述工具，仅用一个月时间、千元成本就完成了从概念到上线的全过程。这证明了在 AI 时代，**执行力**和**产品思维**比单纯的编码能力更为关键。

## 影响
0代码开发使得“微创新”和“模因产品”的爆发成为可能，但也意味着市场竞争将更加激烈，因为创意的复制成本几乎降为零。
