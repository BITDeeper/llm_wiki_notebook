# 并行视频工具调用（Parallel Video Tool Calling）

并行视频工具调用是一种在单一 turn 内同时发出多个 `crop_video` 指令、并发处理多个时间窗的视频推理范式，由 [[paravt]] 框架首次系统化实现。

## 核心思想

将 N 次串行工具调用压缩到 1 个 turn 内并行 dispatch。模型在第一轮思考完成后一次性给出多个时间窗调用，系统并发执行这些 crop，把所有片段的精采样视觉证据一并送回，模型在第二轮统一做跨片段推理并给出答案。

## 解决的痛点

传统串行回看范式的三大根本缺陷：

1. **无同行纠偏**：一次只能 crop 一个时间窗，定位错了只能等下一轮修正，没有 peer signal 提示"看错了"
2. **上下文污染**：每轮 tool-call 输出留在 context 里，多轮后早期错误无法剔除，模型背着累积幻觉继续推理
3. **成本线性增长**：每多一次回看就多一次完整 forward，部署侧延迟与显存被串行拉爆

## 与人类认知的类比

人类回看长视频从来不是串行的——当需要确认多个事件时，会同时打开多个时间窗并行核对、彼此印证。并行视频工具调用正是将这种认知模式编码进模型 policy。

## 在 ParaVT 中的实现

[[paravt]] 通过 weight-sharing 多智能体体系实现并行调用：Main Agent 一次性生成多个 `crop_video(start_time, end_time)` 指令，多个 Sub-Agents 共享权重并行处理各自片段，最后 Main Agent 聚合所有输出做跨片段推理。
