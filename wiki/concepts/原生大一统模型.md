# 原生大一统模型

“原生大一统模型”是指在同一架构中原生集成多种核心能力（如推理、编程、多模态理解、计算机操作等）的 AI 模型，而非通过简单的模型拼接或微调来实现。[[GPT-5.4]] 被称为首个此类模型。

## 核心特征
- **多能力融合**：集成了推理、编程、[[计算机原生交互]]、深度网页搜索及长上下文窗口。
- **无缝协同**：不同能力在同一思维链路中协同工作，无需外部工具桥接。
- **Agent 基础**：具备直接操作计算机界面（截图、点击、输入）的能力，是构建通用 Agent 的技术基础。

## 与传统架构的区别
与 [[neo-unify-架构]] 类似，该概念强调消除模态间的信息断层。但“大一统”更侧重于功能（推理、行动、搜索）的统一，而不仅仅是视觉与语言的统一。

## 应用案例
- GPT-5.4 能够在 [[Microsoft Paint]] 中通过自我修正绘图，或自动化填写 Web 表单，展示了其作为通用 Agent 的潜力。
