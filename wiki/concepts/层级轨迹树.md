# 层级轨迹树

**层级轨迹树**（Hierarchical Trace Tree）是 [[CodeTracer]] 框架中用于构建 Agent 执行视图的核心数据结构。

## 设计目的
将 Agent 运行产生的扁平、冗长的执行日志转化为结构化的树状状态历史，以便快速定位偏差。

## 关键区分
该结构的核心在于区分两类本质不同的步骤：
1.  **探索步骤**：只读取、搜索环境，不修改代码状态。说明 Agent 处于信息探查阶段。
2.  **状态变更步骤**：对代码库或执行环境产生实际修改。这会触发状态跳转并生成新的子状态节点，标志着 Agent 完成了一次关键决策。

## 优势
- **压缩导航**：每个节点附加意图与结果摘要，使整棵树成为一个压缩版的导航索引。
- **证据聚焦**：诊断时无需从头逐行阅读原始日志，可快速定位从哪一次状态变更出现偏差。
- **提升检索效率**：避免了直接对全量原始日志进行低效遍历，显著降低了 Token 消耗。
