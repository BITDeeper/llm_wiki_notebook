# 工具搜索机制

工具搜索机制是一种用于优化 AI Agent 调用外部工具效率的技术。它改变了过去将所有工具定义塞入 Prompt 的做法，允许模型先获取工具列表摘要，仅在需要执行特定操作时才加载该工具的详细定义。

## 工作原理

1. **索引阶段**：系统维护一个包含所有可用工具的简要清单（仅包含名称和简短描述）。
2. **检索阶段**：模型根据任务需求，从清单中筛选出可能需要的工具。
3. **加载阶段**：仅对选中的工具加载完整的参数定义和 API 文档。

## 优势

- **降低 Token 消耗**：避免了无关工具定义占用上下文窗口。
- **提升响应速度**：减少了输入 Token 的处理时间。
- **降低成本**：在按 Token 计费的 API 模式下，直接减少了用户的费用。

## 实测数据

根据 [[GPT-5.4]] 的发布说明，引入工具搜索机制后，在 MCP Atlas 基准测试中，模型在保持同等准确率的情况下，将总 Token 使用量降低了 **47%**。

## 商业意义

这一机制是应对 [[ai-subscription-crisis]] 的重要技术手段。它使得 AI Agent 在处理复杂任务（如调用数十个内部 API）时变得更加经济可行，抵消了模型单价上涨带来的成本压力。
