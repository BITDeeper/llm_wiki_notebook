# 动态污点追踪

**动态污点追踪**（Dynamic Taint Tracking）是一种数据流分析技术，旨在追踪敏感数据在程序执行过程中的流向。在 AI 智能体安全的语境下，它用于解决“局部语义正常但全局上下文违规”的隐蔽风险。

## 工作原理

当智能体在执行过程中读取或生成了敏感数据（如 API 密钥、个人隐私信息、关键配置文件）时，系统会为这些数据打上“污点”标签。这些标签会随着数据的流动和传播（如被复制、被引用、被编码进请求体）自动附加到后续的所有衍生数据上。

## 在智能体安全中的应用

传统的语义过滤往往只能判断单次操作是否可疑，而无法识别多步骤攻击中的隐蔽风险。例如：
- 智能体先读取了一个本地密钥文件（语义上可能是“读取配置”）。
- 随后发起一个普通的 HTTP POST 请求（语义上可能是“发送数据”）。

单独看每一步操作可能都符合语义规范，但结合上下文可知，该请求正在外泄敏感数据。

动态污点追踪通过在运行时检查数据是否携带污点，能够识别出这种跨步骤的违规行为。即使后续操作的语义完全合法，只要其 Payload 中包含来自敏感来源的污点数据，治理引擎（如 [[arbiteros]]）就会触发拦截、脱敏或人工确认。

## 优势

- **全链路感知**：不局限于单点操作，能够覆盖整个工作流中的数据传播路径。
- **高确定性**：基于数据标签的硬性规则，不依赖对自然语言意图的模糊理解。
- **防御隐蔽攻击**：有效对抗利用合法操作进行的“数据走私”或间接泄露。
