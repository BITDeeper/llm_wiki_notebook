# 行业专家体系

**行业专家体系**是指 AI 平台预置的一系列针对特定职业、领域或场景优化的智能体角色。这些角色内置了对应行业的专业术语、决策逻辑、最佳实践和思维框架，旨在解决通用大模型“懂皮毛不懂门道”的问题。

## 背景与痛点
通用大语言模型（LLM）虽然知识面广，但在处理垂直领域的专业任务时，往往缺乏深度：
-   不了解行业特定的“黑话”和术语体系。
-   缺乏该领域的实战经验和决策逻辑。
-   输出内容过于泛泛，无法直接指导专业工作。

## 机制与实现
行业专家体系通过以下方式提升专业度：
1.  **角色预设**：在 System Prompt 中明确设定 Agent 的身份（如“资深增长黑客”、“心血管科主任医师”）。
2.  **知识注入**：将行业知识库、方法论或工作流模板注入到 Agent 的上下文中。
3.  **思维链引导**：强制 Agent 按照该领域的专业思考路径（如诊断步骤、分析框架）进行推理。

## 应用实例
[[workbuddy]] 内置了 **12 大领域、141 位行业专家**，例如：
-   **增长黑客**：提供流量获取、病毒裂变方案。
-   **行业分析师**：输出市场趋势调查报告。
-   **法律顾问**：审查合同合规性。

用户无需编写复杂的提示词，直接选择对应的专家即可获得专业级输出。

## 价值
-   **降低门槛**：普通用户无需学习提示词工程，即可调用专家级能力。
-   **提升质量**：输出内容更符合行业规范，具有可操作性。
-   **标准化**：为企业提供了标准化的 AI 工作流输出。
