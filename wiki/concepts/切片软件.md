# 切片软件

[[切片软件]]（Slicer）是 3D 打印工作流中的中间件，负责将 3D 模型“切”成层层薄片，并生成打印机喷头或激光的移动路径指令（G-code）。常见的切片软件包括 [[拓竹]] 的 Bambu Studio、PrusaSlicer 等。

## 作用
切片软件会根据模型的 [[网格完整性与密封性]] 计算打印路径。如果模型存在破孔，切片软件可能报错或生成错误的路径。

## 与 AI 的集成
传统的 AI 3D 生成流程通常止步于模型导出，用户需手动下载文件并导入切片软件。[[Meshy]] 通过 API 直连 Bambu Studio 等切片软件，实现了“一键发送至打印机”，消除了繁琐的手动导入、格式转换和模型摆放步骤，极大提升了用户体验。
