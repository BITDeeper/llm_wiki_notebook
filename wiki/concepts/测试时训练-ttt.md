# 测试时训练 (Test-Time Training, TTT)

测试时训练（Test-Time Training，TTT）是一种让模型在推理阶段根据输入上下文动态更新自身参数的机器学习范式。作为一种新兴的序列建模范式，TTT 将注意力操作重新定义为一个在线学习过程——在每次推理时用 Key-Value 对构建一个轻量化的内部模型，通过梯度下降将信息压缩到模型权重中，实现线性复杂度的高效序列建模。

TTT 最初在 LLM 领域提出，[[vit3-vittt|ViT³]] 代表其向视觉领域的系统性迁移和重要早期验证。

## 核心思想

传统的模型训练分为预训练和微调阶段，参数在推理阶段是固定的。TTT 打破了这一界限，允许模型在"测试时"（即推理时）根据当前输入的上下文信息，实时调整部分参数（通常称为 [[快速权重]]）。

TTT 的核心洞察来自 [[注意力机制的信息压缩视角]]，将注意力机制统一于在线学习框架：

| 机制 | 等价模型 | 复杂度 | 特点 |
|------|----------|--------|------|
| Softmax 注意力 | 隐层宽度=N 的双层 MLP | O(N²) | 表达能力极强，但计算开销大 |
| 线性注意力 | 压缩的线性层 | O(N) | 信息损失严重，性能受限 |
| TTT | 可训练的任意模块 | O(N) | 线性复杂度 + 强非线性建模能力 |

- **Softmax 注意力**：用完整的 Key 和 Value 构建两层 MLP，不进行压缩，效果好但成本高昂（二次复杂度）
- **线性注意力**：通过矩阵乘法将 Key 和 Value 压缩到 d×d 空间，压缩过于粗糙，导致性能下降
- **TTT**：借鉴深度学习的成功经验，通过梯度下降将 Key-Value 信息高保真地压缩到内部模型权重中

## 工作机制

TTT 将键值对视为"微型数据集"，内部模型泛化为任意可训练模块。具体流程：

1. 将 Key 和 Value 视为一个"小型数据集"
2. 要求内部模型在输入 Key 时重建对应的 Value
3. 通过梯度下降更新内部模型权重（自监督重建损失）
4. 将更新后的内部模型应用于 Query，通过前向传播读取信息

当内部模型采用线性复杂度架构时，TTT 整体保持 O(N) 复杂度。

## 解决的问题

- **长上下文崩溃**：随着上下文长度增加，模型性能可能下降。TTT 允许模型边处理边学习，适应新信息。
- **持续适应**：在智能体场景中，环境不断变化，TTT 使模型能即时适应新任务。
- **复杂度瓶颈**：通过将信息压缩到权重中，TTT 实现线性复杂度的序列建模，突破 Transformer 的二次复杂度限制。

## 与其他线性复杂度方案的对比

- **线性注意力**：通过矩阵乘法压缩 KV 对，信息损失严重
- **Mamba/SSM**：状态空间模型，在视觉任务中表达能力受限
- **TTT**：通过在线训练实现非线性建模，表达能力更强

## 传统方法的局限

在 [[in-place-ttt]] 提出之前，TTT 方法通常面临以下挑战：

1. **架构侵入性强**：需要引入新的专用层（如 RNN 层）来处理快速权重，导致无法直接利用现有的预训练模型（如 Llama、Qwen），必须从头预训练。
2. **计算效率低**：为了维持状态的连续性，往往采用逐 Token 顺序更新的方式，无法利用 GPU 并行计算，导致推理速度慢。
3. **目标不匹配**：优化目标多为重建当前输入，而非预测下一个 Token，这与语言模型的核心任务相悖。

## 设计空间

TTT 的设计空间极为丰富，主要包括：

### 内部训练设置
- **损失函数**：必须避免混合二阶导数趋于零的损失函数（如 MAE/L1），需要二阶混合偏导数非零的损失（如 MSE/L2 和点积损失），否则外部梯度消失
- **训练策略**：视觉任务适合单 Epoch 全 Batch 训练（非因果性决定），语言任务适合小 Batch 渐进式更新
- **学习率**：较大内部学习率（如 1.0）最有效

### 内部模型设计
- **架构**：MLP、SwiGLU、卷积网络等。深度可分离卷积（DWConv）是视觉 TTT 的理想选择——全局信息编码进卷积核权重，通过卷积自然融合全局与局部信息
- **宽度**：扩大容量能持续稳定提升性能
- **深度**：当前实现下较深模型存在优化困难，标准残差连接和权重初始化策略缓解作用有限

## 与元学习的关系

TTT 本质上是一种元学习：内部模型的初始权重是外部训练的可学习参数，端到端训练时需要计算"梯度的梯度"（二阶混合偏导数）。这一元学习属性也解释了为什么较深的内部模型存在优化困难——初始参数的优化和内部训练的梯度传播都面临挑战。

## 跨域验证意义

长期以来，TTT 被认为更适合因果关系强烈的语言任务。[[vit3-vittt|ViT³]] 的系统性实证研究证明，只要设计得当，非因果的视觉任务同样能从 TTT 中获得巨大红利。这为 TTT 范式在其他非因果领域（如音频、表格数据等）的应用提供了理论支撑。

## 关键开放问题与潜在局限

1. **深度优化困境**：较深内部模型存在欠拟合问题（梯度消失/爆炸），远未达到理论表征能力，是 TTT 的核心瓶颈
2. **领域依赖性**：视觉 TTT 的最佳设计（全批量、卷积）与 NLP 任务可能不同
3. **效率权衡**：内部模型的计算量约为同尺寸外部模块的 4 倍，TTT 引入了额外的内部训练步骤，单步推理延迟可能高于纯前馈方案，轻量化设计是重要方向
4. **扩展规律**：内部模型扩展是否构成新的 [[scaling-law|Scaling Law]] 有待验证，在更大规模上的 Scaling 行为尚待研究

## 演进与代表性工作

- [[in-place-ttt]]：TTT 技术的重要演进，通过复用 MLP 模块和引入块级更新，解决了架构兼容性和效率问题（字节 Seed + 北大）
- [[vit-cube|ViT³]]：首个系统性的视觉 TTT 架构（CVPR 2026 Oral，[[清华大学]] + [[阿里巴巴]]）
