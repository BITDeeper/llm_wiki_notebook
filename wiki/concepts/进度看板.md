# 进度看板

[[进度看板]] 是一种可视化的任务状态追踪界面，常用于 [[多智能体协作]] 系统中。它将 AI Agent 的内部执行过程（通常是不可见的“黑盒”）转化为人类可读的实时状态更新。

## 作用
- **消除焦虑**：解决用户在等待 Agent 完成长任务时的不确定性，提供确定性的反馈。
- **流程监控**：允许用户实时查看工作流卡在哪个环节，便于调试或人工干预。
- **状态同步**：在多 Agent 协作中，作为共享记忆源，告知不同 Agent 前置任务的完成情况。

## 实现方式
在 [[AI 编辑部]] 案例中，[[进度看板]] 是通过 [[飞书]] 多维表格实现的。每个 Agent 完成任务后，会调用 API 更新表格中的“任务状态”和“负责人”字段，从而实现自动流转。

## 关联概念
- [[场景白盒化推理]]：进度看板是实现白盒化推理的具体 UI 表现形式之一。
