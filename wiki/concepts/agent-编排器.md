# Agent 编排器

Agent 编排器是一种用于管理和协调多个 AI Agent（智能体）交互、任务分配和资源调度的系统或框架。它位于底层大模型（LLM）与上层应用之间，负责将复杂的任务拆解并分发给合适的 Agent 执行。

## 核心功能
- **多 Agent 管理**：同时调度和管理多个独立的 Agent 实例。
- **任务分发**：根据用户意图，将任务路由到最合适的 Agent 或插件。
- **状态隔离**：确保不同会话或不同 Agent 之间的状态互不干扰（如会话级隔离）。
- **热重载**：在不停止服务的情况下动态更新插件或 Agent 逻辑。

## 与个人助手框架的区别
虽然功能上有重叠，但 Agent 编排器与面向大众的个人助手（如 [[openclaw]]）在设计理念上有所不同：
- **个人助手**：侧重于“开箱即用”的终端用户体验，强调单一入口的便捷性和叙事性。
- **编排器**：侧重于开发者的灵活性和系统的可扩展性，强调多平台接入、插件生态和底层控制。

## 典型案例
- **[[astrbot]]**：一个开源的 Agent 编排平台，支持接入 QQ、微信等多个平台，并拥有丰富的插件生态。
