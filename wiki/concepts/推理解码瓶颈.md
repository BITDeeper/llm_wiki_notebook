# 推理解码瓶颈

大模型推理过程中，自回归生成（解码）阶段的核心性能瓶颈在于内存带宽而非计算能力。

## 原理

模型在解码阶段一个 token 一个 token 往外吐，每生成一个 token 都需要把全部模型权重从内存中读取一遍。因此：

- **内存带宽决定速度**：带宽越高，权重读取越快，token 生成越快
- **计算核心经常闲置**：在单用户场景下，GPU 的计算核心大部分时间在等内存数据
- **GPU 算力利用率极低**：[[semianalysis]] 指出单用户场景 GPU 实际算力利用率只有理论峰值的零头

## 对硬件架构的影响

这一瓶颈解释了为什么 [[cerebras]] [[wse-3]] 的 SRAM 架构（21PB/s 带宽）在小模型推理上碾压 GPU 的 HBM：SRAM 带宽足以把全部 90 万计算核心喂饱，而 GPU 的计算核心只能"饿着等内存"。

## 与批处理的权衡

GPU 的优势在于批处理（同时服务多用户，分摊内存读取开销），类似"公交车"模型。WSE-3 的优势在于单用户极致速度，类似"F1 赛车"模型。
