# 季度KPI杀死AGI

“季度KPI杀死AGI”描述了人工智能领域中短期商业利益与长期科学研究之间不可调和的冲突。

## 冲突表现
- **成本控制 vs. 深度推理**：AGI 级别的深度推理（如 [[system2]] 范式）需要高昂的计算成本和时间，但季度财报要求降低延迟、压缩成本。
- **产品落地 vs. 硬核探索**：管理层倾向于快速将技术集成到 API 或 Copilot 等商业产品中，而高风险、长周期的探索性研究被视为财务负担。

## 案例分析
在 [[openai]]，这种冲突导致了旗舰项目 [[orion]] 的降级以及核心人物 [[jerry-tworek]] 的离职。Tworek 希望追求 AI 的真正思考能力，而投资者和微软更需要高效、低成本的工具。

## 后果
当一家 AGI 实验室系统性排斥硬核研究以迎合季度 KPI 时，其创新活力受损，最终可能蜕变为一家维护现有利益的 API 供应商，失去定义未来的能力。
