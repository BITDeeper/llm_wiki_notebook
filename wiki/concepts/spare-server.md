# 备用服务器轮转

备用服务器轮转（Spare Server）是一种用于保障大规模 [[online-rl]] 训练稳定性的工程化机制。

## 工作机制

在训练过程中，系统维护一个备用环境池。当某个正在运行的环境（如 Docker 容器或物理手机）出现故障（例如截图失败、连接断开、设备不健康）时，系统会自动将该环境标记为不可用，并立即切换至备用服务器继续执行任务。

## 目的

- **保证训练不中断**：避免因单点故障导致整个 Episode 失败或训练流程停止。
- **提高资源利用率**：自动隔离故障节点，减少人工干预成本。

## 应用场景

该机制在 [[clawgui]]-RL 中被用于支持长时间的 GUI 智能体训练，特别是在涉及大量物理手机或云手机并行的场景下。
