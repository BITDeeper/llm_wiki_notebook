# Skill (能力单元)

[[Skill]]（能力单元）是指在 Agent 时代，被定义的一段可被调用的功能模块。它被视为可能取代传统 [[APP]] 的下一代软件分发和交互形态。

## 定义与特征
与传统的 APP 相比，Skill 具有以下显著特征：
- **可调用性**：通过标准协议（如 [[MCP]]）暴露接口，供 Agent 或其他 Skill 调用。
- **无界面（UI-less）**：通常不包含图形用户界面，专注于后台逻辑执行。
- **轻量化**：无需用户下载安装，按需加载。
- **嵌入性**：作为原子能力嵌入到 Agent 的复杂工作流中。

## 与 APP 的区别
| 维度 | APP | Skill |
| :--- | :--- | :--- |
| **交互对象** | 人（通过 GUI） | 机器/Agent（通过 API） |
| **分发方式** | 应用商店下载 | 协议市场/注册中心发现 |
| **用户感知** | 强（图标、品牌） | 弱（后台服务） |
| **设计核心** | 视觉与体验 | 稳定性与接口定义 |

## 行业影响
Skill 的兴起引发了关于 [[APP]] 解构 的讨论：
1. **产品重构**：产品经理需要从“设计界面”转向“设计接口”。
2. **商业逻辑**：流量分发逻辑从“抢占入口”变为“抢占调用权”。
3. **技术标准**：[[MCP]] 等协议成为连接生态的关键。
