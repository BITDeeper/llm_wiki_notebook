# 长上下文推理

长上下文推理是指大模型处理长序列输入（如32K token）时的推理场景。在此场景下，KV cache 随序列长度线性膨胀，成为显存占用的核心瓶颈。

## 核心挑战

- KV cache 膨胀：长系统提示加上多轮文档读取，KV cache 可膨胀到显存无法承受
- 硬件限制：消费级显卡（如 RTX 4090 24GB）难以承载大模型参数 + 长 KV cache
- 精度保持：压缩 KV cache 的同时需保持推理准确率

## 解决方案

[[kv-cache压缩]] 是解决长上下文推理瓶颈的核心技术路径，包括 [[triattention]]（选择性保留）和 [[turboquant]]（量化）两条路线。
