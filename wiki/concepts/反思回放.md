# 反思回放

**反思回放**（Reflective Replay）是 [[CodeTracer]] 框架中提出的一种错误恢复机制。

## 工作机制
该机制将 Trace Agent 诊断出的失败根因（包括失败责任阶段、错误相关步骤及证据集）作为提示注入原 Agent，驱动其在**相同的资源约束**（相同的迭代次数与 Token 配额）下重新执行任务。

## 核心价值
实验证明，反思回放带来的性能提升显著优于单纯增加迭代次数。
- **对比重试**：当 Agent 早期形成错误假设时，额外的迭代次数往往只会导致[[无效循环陷阱]]，消耗资源却无法纠偏。
- **诊断信号的价值**：反思回放证明了“在正确的时机提供正确的诊断信号”远比“给 Agent 更多重试机会”更有价值。

## 实验结果
在 CodeTraceBench 上的测试显示，利用反思回放机制，所有骨干模型的 Pass@1 均有显著提升，且诊断过程本身的额外 Token 消耗仅为 5k-8k，性价比极高。
