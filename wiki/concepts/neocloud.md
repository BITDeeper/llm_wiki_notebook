# NeoCloud

NeoCloud（新型云服务商）是指像 [[coreweave]] 这样，专门为 AI 工作负载（如大模型训练和推理）优化的云服务提供商。它们区别于 AWS、Google Cloud 或 Azure 等提供通用计算服务的传统云巨头。

## 特点
- **专用性**：基础设施针对 GPU 密集型任务进行深度优化，不承载传统 Web 应用或数据库业务。
- **硬件绑定**：通常与特定的硬件厂商（如英伟达）深度绑定，能够最快部署最新的硬件（如 [[vera-cpu]] 和 [[rubin-platform]]）。
- **灵活性**：能够根据客户特定的 AI 工作负载（如特定的模型架构或数据流）定制底层硬件配置，例如独立采购高性能 CPU 而非被迫购买整机架解决方案。

## 市场角色
NeoCloud 厂商是英伟达“[[供给侧革命]]”的关键合作伙伴。它们帮助英伟达消化产能，同时也为那些不想被传统云厂商锁定或需要极致硬件性能的 AI 公司提供了替代选择。
