# 平台锁定

## 定义
平台锁定是指平台方通过技术手段、服务条款或商业策略，排除第三方竞争者，强迫用户和开发者完全依赖自家生态系统的一种商业策略。其目的是消除“不受控的连接器”，将流量、数据和利润牢牢掌握在平台手中。

## 典型操作流程
1.  **开放生态**：初期允许第三方工具通过 API 或订阅接入，利用社区力量做大生态和用户基数。
2.  **寻找借口**：当生态成熟或面临竞争压力时，以“安全性”、“基础设施压力”或“合规性”为由，开始限制第三方工具。
3.  **功能抄袭**：官方推出原生产品，复刻第三方工具的核心功能。
4.  **强制迁移**：切断第三方工具的访问权限或提高其使用成本，迫使用户迁移至官方原生工具。

## 案例分析：Anthropic vs OpenClaw
[[anthropic]] 对 [[openclaw]] 的封杀是平台锁定的典型案例：
- **第一步**：早期默许 [[openclaw]] 使用订阅额度，吸引了大量开发者。
- **第二步**：以 [[CVE-2026-25253]] 漏洞和创始人跳槽 [[OpenAI]] 为由，进行安全施压。
- **第三步**：推出 [[claude-cowork]]，复刻了 OpenClaw 的 Dispatch 和 Channels 功能。
- **第四步**：正式切断订阅额度访问，强推原生工具。

## 行业影响
这种策略虽然有助于平台收回成本和加强控制，但往往导致开发者信任崩塌，被视为“开放生态黄昏”的标志。
