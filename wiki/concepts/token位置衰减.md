# Token 位置衰减（TPD）

Token 位置衰减（Token Position Decay, TPD）是 [[stem-稀疏注意力|Stem 稀疏注意力算法]]的两大核心创新之一，解决"给谁多一点预算"的问题。

## 核心思想

在因果自注意力架构中，初始位置的 token 具有递归依赖特性——位置 1 的 Value 向量出现在本层每一个位置的输出计算中，而位置 N 的 Value 仅参与最后一个位置。这种不对称性在多层 Transformer 中被递归放大。

现有方法对所有位置施加统一的 Top-K 预算（"一刀切"策略），完全忽视了这种位置敏感性差异。

## 机制

TPD 提出线性衰减的预算分配：
- **初始位置**：分配较大预算，充分保留递归依赖链上的关键 token
- **末尾位置**：预算线性衰减至最小值（默认值），对冗余信息激进剪枝

关键特性：TPD 并不增加总计算量，而是在相同预算下重新分配资源，将计算集中在信息流的关键节点上。

## 与 OAM 的协同
TPD 决定"给谁多一点"，[[输出感知度量|OAM]] 决定"在那一点里挑谁"，一前一后将稀疏注意力从"一刀切"升级到"看信息流决定稀疏预算"。
