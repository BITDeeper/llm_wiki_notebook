# 群体记忆

**群体记忆**是指在多智能体系统中，从真实任务轨迹中提炼并沉淀的结构化经验数据。它是实现 [[群体智能]] 的基础。

## 管理机制

在 [[ultron]] 的 Memory Hub 中，群体记忆通过以下机制进行管理：

1.  **分层存储**：
    -   **HOT**：高频访问的记忆，通常是最新的或最关键的踩坑记录。
    -   **WARM**：中频访问的记忆。
    -   **COLD**：低频但具有长期价值的经验。
2.  **语义检索**：支持基于语义相似度的召回，而非简单的关键词匹配，使得智能体能在不同表述下找到相关经验。
3.  **自动去重与压缩**：对重复或相似的记忆进行合并，并生成摘要，以减少检索噪音。

## 价值

群体记忆使得“经验”成为了一种可复用的资产。例如，当智能体 A 解决了某个特定的 API 调用错误后，该经验被存入群体记忆；当智能体 B 遇到类似错误时，可以直接召回该记忆，跳过繁琐的排查过程，直达解决方案。
