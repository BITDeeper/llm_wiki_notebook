# 累积上下文微调

累积上下文微调（Accumulative Context Finetuning）是 [[emformer|EMFormer]] 论文提出的核心创新策略，旨在解决多步长期预测中的 [[误差累积]] 问题。

## 核心思想

在多步自回归预测中，每一步的预测误差会逐步叠加，导致远期精度急剧下降。累积上下文微调通过**缓存前序步骤的 KV 对**，结合 [[kv缓存动态修剪]] 机制，保留关键历史信息，使模型在每一步预测中都能利用低误差的历史状态。

## 实现机制

该策略通过三步实现 KV 缓存的动态更新与修剪：

1. **计算当前注意力得分**：对当前步骤的 Query 与 Key 计算注意力分布
2. **融合历史与当前得分**：将缓存的 KV 对的注意力得分与当前得分融合
3. **修剪冗余 KV 对**：根据融合后的得分移除低重要性 KV 对，避免内存溢出

## 方法论价值

累积上下文微调的核心价值在于其**通用性**——该策略不依赖于特定的模型架构，理论上可迁移至其他基于 Transformer 的多步预测模型。这使其成为解决长期预测误差累积的通用策略，而非仅限于气象领域。

## 实验验证

在 [[emformer|EMFormer]] 的消融实验中：
- 无微调：10 天预测 ACC 较低
- 标准微调：ACC 有所提升
- **累积上下文微调**：10 天预测 ACC 提升至 **0.5389**，显著优于前两者

## 开放问题

- KV 缓存修剪策略在不同规模模型上的内存开销
- 在更长期（>10 天）预测上的效果衰减情况
- 与其他误差缓解策略（如 scheduled sampling、curriculum learning）的对比
