# 沉思模式

[[沉思模式]]（Contemplating Mode）是一种多智能体协作机制，通过让多个 Agent 同时思考同一个问题并汇总结果，以提升 AI 模型的极限推理能力。该功能由 [[Muse Spark]] 引入，旨在通过增加计算量来提升模型在复杂任务上的表现。

## 机制原理

与传统的「延长思考时间」（单个 Agent 花更长时间进行长链推理）不同，沉思模式利用 [[多 Agent 并行思考]] 机制，通过群体智慧解决问题：

1.  **并行思考**：系统同时调度多个模型实例或模块独立处理同一任务。
2.  **结果汇总**：系统收集并评估所有推理路径，选择最优解。
3.  **性能提升**：在不显著增加单次推理延迟（不增加等待时间）的前提下，提高复杂任务的解决率。

## 行业对标

沉思模式被视为 Meta 对标 Google [[Gemini]] Deep Think 和 OpenAI [[GPT-5.4]] Pro 的功能。这些模式均旨在通过 [[测试时计算扩展]]（Test-time Compute）来换取模型在数学、编程等强推理任务上的更高准确率。

## 性能表现

-   **Humanity's Last Exam（无工具）**：得分 50.2，超过 Gemini Deep Think（48.4）和 GPT-5.4 Pro（43.9）。
-   **准确率提升**：在特定任务中，多 Agent 并行将准确率从约 54% 提升至 58%。

## 应用场景

该模式特别适用于需要复杂规划和多步推理的任务，例如：
-   高难度数学问题求解（如“人类最后的考试”）。
-   复杂逻辑推理与代码生成。
-   需要多步规划的长程任务（如规划一个包含多个约束条件，如家庭成员年龄、饮食偏好的旅行行程）。
