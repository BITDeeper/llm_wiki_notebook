# DLLM Agent

基于扩散模型（Diffusion Model）的AI智能体方法，由[[王云鹤]]团队于2026年初在论文《DLLM Agent: See Farther, Run Faster》（arXiv: 2602.07451）中提出。

## 核心主张

DLLM Agent声称基于扩散模型的智能体能够比传统的自回归模型"看得更远，跑得更快"。这一主张挑战了当前主流基于自回归大语言模型构建Agent的技术路线。

## 技术背景

传统AI Agent主要基于自回归（Autoregressive）大语言模型，通过逐步生成token来规划和执行任务。DLLM则探索将扩散模型的生成范式应用于智能体决策，可能具备更好的全局规划能力和多步推理效率。

## 战略意义

这篇论文揭示了[[王云鹤]]选择AI Agent赛道而非继续卷大模型的深层技术判断：大模型不仅是"脑"，更要是"手"和"脚"。单纯的文本生成和问答价值壁垒正在变薄，真正的金矿在于让大模型像人一样操作手机和电脑。

## 开放问题

- 扩散模型做Agent是一个相对非主流的技术选择，其在学术界和工业界的接受度尚待验证
- 与自回归路线相比的具体性能优势和局限性有待更多实验数据支撑
