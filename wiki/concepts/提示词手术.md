# 提示词手术

**提示词手术**（Prompt Surgery）是一种高级的工程化提示词技术，指在不重新训练模型的情况下，通过精细修改系统提示词、调整输入格式或注入特定标记，来修正模型的行为缺陷或优化其性能。

## 起源与案例
该概念在 [[anthropic]] 的 [[capybara-v2-fast]] 模型开发中得到了典型应用。当发现 Capybara 模型在工具调用后会误判 [[Turn Boundary]]（轮次边界）导致过早停止时，Anthropic 并未进行昂贵的模型重训，而是实施了“提示词手术”：

1. **强制边界标记**：在 Prompt 中插入 `Tool loaded.` 等硬性标记，明确告知模型当前状态。
2. **结构重组**：重新定位具有风险的“同级模块”，防止模型混淆。
3. **信息嵌入**：将原本独立的提醒文本压缩并嵌入到工具结果中，确保模型注意力集中。
4. **非空填充**：针对空输出强制添加非空标记，防止模型因空白而中断。

## 优势
- **低成本**：避免了重新训练模型所需的巨大算力和时间成本。
- **即时生效**：修改 Prompt 可以立即部署，无需漫长的训练周期。
- **精细控制**：可以对特定场景下的模型行为进行微调。

## 局限性
- **治标不治本**：并未改变模型内部的权重参数，可能只是掩盖了模型在理解上的缺陷。
- **脆弱性**：过度依赖特定的 Prompt 格式，一旦格式变动可能导致问题复现。
