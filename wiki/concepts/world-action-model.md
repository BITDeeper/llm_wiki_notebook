# World Action Model (世界动作模型)

[[World Action Model]] 是一种将“预测世界”和“驱动行动”统一在同一个模型中的技术范式。它旨在解决传统 [[World Action Model]]（先看后动）和 [[vla-视觉-语言-动作]]（直接行动）的局限性。

## 核心特征
- **边看边动**：推演和行动融合在同一个模型里，没有先后顺序。决策的同时就在推演，推演的结果直接影响决策。
- **统一表征空间**：推演和行动共享同一个表征空间，避免了预测偏差和执行偏差的相互放大。
- **响应速度快**：不需要等待机器人“想象”后再行动，适合实时交互场景。

## 与其他范式的对比
1.  **直接行动派 (VLA)**：直接进行感知理解和执行。优点是快，但缺乏对物理规律的深层理解，容易在复杂场景中失败。
2.  **先看后动派**：先训练视频预测模型想象未来，再据此决策。优点是有规划，但响应慢，且想象与现实的误差会累积。
3.  **World Action Model (边看边动)**：结合了前两者的优点，既有物理世界的理解深度，又能实时响应。

## 技术实现
通常基于 [[U-ViT 架构]] 或类似的统一多模态架构，利用 UniDiffuser 等技术打通视频（视觉）和动作（控制）模态。

## 应用案例
[[生数科技]] 的 [[MotuBrain]] 是该范式的代表性模型，在 [[WorldArena]] 和 [[RoboTwin2.0]] 榜单上均取得了优异成绩。
