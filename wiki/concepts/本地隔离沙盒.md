# 本地隔离沙盒

## 定义
[[本地隔离沙盒]] 是指在用户本地计算设备上构建的一种受限制、安全隔离的运行环境。AI 智能体或应用程序在此环境中执行任务，以确保其操作不会破坏主系统的稳定性，同时防止敏感数据在未经授权的情况下外泄至云端或第三方服务器。

## 核心价值

### 1. 数据隐私与安全
对于企业用户和注重隐私的个人用户，本地沙盒提供了一道物理防线。它确保了敏感文档（如财务报表、代码库、内部报告）的处理过程完全在本地闭环，消除了云端上传带来的泄露风险。

### 2. 系统稳定性
通过限制 AI 智能体的文件访问权限和操作范围，沙盒机制可以防止 AI 因“幻觉”或逻辑错误而误删系统关键文件、修改错误配置，从而保障主系统的正常运行。

## 技术实现
虽然具体实现细节因产品而异，但通常包含以下要素：
-   **资源隔离**：限制 CPU、内存和磁盘 IO 的使用上限。
-   **权限控制**：仅允许访问特定的“工作区”文件夹，禁止访问系统目录。
-   **网络管控**：根据策略决定是否允许沙盒内的进程发起网络请求。

## 应用实例
-   [[DuMate]]：百度智能云推出的 AI 办公助手，明确宣称采用自动构建的本地隔离沙盒来保障任务运行环境安全。
-   [[Claude Code]]：虽然主要运行在本地环境，但其对代码库的操作也涉及类似的权限隔离逻辑，以防止破坏开发环境。

## 与云端 Agent 的对比
| 特性 | 本地隔离沙盒 | 云端 Agent |
| :--- | :--- | :--- |
| **数据隐私** | 高（数据不出本地） | 依赖厂商协议，存在潜在风险 |
| **执行速度** | 受限于本地算力 | 依赖网络延迟和云端排队 |
| **可控性** | 用户完全掌控 | 厂商掌控，用户通过 API 交互 |
