# 零空间协方差约束微调

零空间协方差约束微调是 [[KORE]] 框架中 KORE-CONSTRAINT 组件的核心机制，通过将参数更新方向约束在预训练知识激活协方差矩阵的零空间中，从几何层面切断新旧知识之间的参数干扰。

## 几何直觉

核心思想可以直观理解为：将旧知识保护问题转化为线性代数问题。如果微调的更新方向与代表旧知识的激活模式"正交"，那么更新对旧知识的影响将最小化。

## 技术步骤

### 1. 收集旧知识"指纹"
用一组代表预训练知识的随机样本（如 OneVision 数据集）输入模型，收集线性层的激活值 X。

### 2. 计算协方差矩阵
计算激活值的协方差矩阵 C = XXᵀ，该矩阵捕捉了旧知识在模型内部的分布模式。

### 3. 找到"安全"更新空间
对 C 进行奇异值分解（SVD），对应于极小或零奇异值的子空间即为零空间——对这个空间的扰动对旧知识影响最小。

### 4. 初始化 LoRA 适配器
构建投影矩阵 P = ÛÛᵀ（Û 由最小奇异值对应的奇异向量组成），将原始权重投影到零空间，并用分解结果初始化 LoRA 的矩阵 A 和 B。

### 5. 约束微调
微调过程中只训练矩阵 B，保持矩阵 A 冻结。由于 A 位于零空间中，无论 B 如何变化，最终更新 ΔW = BA 对旧知识协方差 C 的影响都将最小（BAC ≈ 0）。

## 可定制性

KORE 的一个强大特性是支持定制化知识保护：如果用户希望特别保护某一类旧知识（如数学推理能力），可以在构建协方差矩阵 C 时只使用该类任务的数据，从而实现针对性的知识保护。

## 性能优势

- 以极低参数开销（Rank=64，不到 Replay 1/3 的参数量）实现旧知识保留
- 旧知识保留平均分（40.00）仅略低于需要存储大量旧数据的 Replay 方法（43.00）
- 在多个模型架构和尺寸上均有效
