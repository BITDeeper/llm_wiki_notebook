# 养虾

[[养虾]]（Raising Lobsters）是中文 AI 社区及硬件爱好者圈子中的黑话，指代对 [[AI Agent]]（智能体）或特定“龙虾”AI 硬件进行部署、配置、调优及持续维护的过程。

这一术语既是对“Agent”的谐音昵称，也特指基于 [[OpenClaw]] 生态构建智能体，或对“龙虾”硬件进行极客级调试的行为。

## 起源与含义

该词汇包含双重文化语境：
-   **谐音梗**：源自“Agent”的中文发音，被戏称为“虾”。
-   **生态特指**：
    -   在 [[OpenClaw]] 社区中，“虾”指代 [[OpenClaw]]（其标志为龙虾），“养”则暗示了 AI Agent 需要持续的投入、调试和交互，类似于饲养宠物或种植作物，而非简单的“使用”工具。
    -   在 AI 硬件圈，特指对“龙虾”AI 设备进行安装、刷机、配网及优化的行为。

## 行为特征

“养虾”通常涉及高门槛的持续操作，用户常自称为“虾农”或“养虾er”：

-   **高门槛操作**：包括设备安装、刷机、配网及 Agent 配置，往往需要“专业养虾户”指导。
-   **持续优化**：类似于“养宠物”，用户需要不断调整设备设置或 Agent 参数以适应个人习惯，解决“记忆效果”不佳等问题。
-   **拟人化交互**：体现了用户倾向于将 AI 视为具有某种“生命”或“个性”的伙伴，而非冷冰冰的代码。
-   **社群互助**：通过线下沙龙（如“养虾沙龙”）和线上社群交流“养虾”经验。

## 行业应用与趋势

随着 AI Agent 技术的普及，让智能体执行复杂任务（如自动编程、数据分析、流程自动化）成为趋势。由于 Agent 需要拆解任务、调用工具、进行多步推理，其 Token 消耗量远超简单的对话交互。

-   **Token 消耗大户**：[[火山引擎]] 数据显示，过去一个多月，个人用户因“养虾”导致的 Token 消耗增长了约 16 倍。
-   **企业场景**：广泛应用于工业制造中的自动告警、金融投研中的策略回测等。
-   **评测基准**：SuperCLUE 推出了专门的“养虾”场景测评，[[豆包大模型]] 2.0 Pro 在该测评中排名国内第一。

## 落地难点

根据 [[火山引擎]] 总裁 [[谭待]] 的观察，企业“养虾”面临三大核心挑战：
1.  **模型（大脑）**：需要强大的多模态理解和推理能力。
2.  **Skills（手脚）**：需要丰富的工具生态（如 [[OpenClaw]] 的 Skill 插件）。
3.  **安全（底线）**：需要管控 Agent 的权限，防止越权操作。

## 文化意义

“养虾”一词的使用，标志着 AI 硬件从消费电子产品向极客文化符号的转变，同时也反映了中国 AI 开发者社区的高度活跃与本土化特征：
-   **身份认同**：建立了社群内部的认同感。
-   **产品阶段**：暗示了产品（无论是软件 Agent 还是硬件设备）在易用性上尚未完全达到“开箱即用”的消费级标准，仍需用户具备一定的技术背景进行“饲养”。
