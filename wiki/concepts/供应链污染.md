# 供应链污染

供应链污染（Supply Chain Pollution）是指攻击者通过在官方插件或技能市场上传伪装成正常功能的恶意软件，从而入侵用户系统的攻击手段。在 [[openclaw]] 生态中，这被称为“ClawHavoc”攻击行动。

## 攻击方式
攻击者在官方技能市场 ClawHub 上传了数百个伪装精良的恶意技能。这些技能通常拥有专业的文档和无害的名称，但安装后会部署键盘记录器或 Atomic Stealer 等恶意软件。

## 影响规模
据统计，在 2857 个技能中约有 341 个（约 12%）被确认为恶意。这导致了数百万条记录泄露，包括 API 令牌、电子邮件地址、私人消息和第三方服务凭证。

## 应对措施
[[cisco]] 等安全团队发布了开源的 Skill Scanner 工具以应对这一威胁。这也暴露了开源生态在保持开放性与确保安全性之间的核心矛盾。
