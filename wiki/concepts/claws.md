# Claws

Claws（意为“爪子”，取自抓取、执行之意）是指一种新的 AI 软件范式，全称为“AI 执行中枢”。它被视为继 LLM 和 LLM Agent 之后的下一代高度（"Agent 2.0"）。

## 定义与定位
Claws **不是模型**，而是一种能**自主组织工具、跑通完整流程、维持长期运行状态**的系统。

如果说 LLM 是“只会聊天的实习生”，LLM Agent 是“会用工具的新手”，那么 Claws 就是“全能老员工”。它不仅能执行指令，还能负责规划、调度和长期维护。

## 五大核心能力
Claws 相比传统 Agent 的升级主要体现在以下五个方面：

1.  **编排能力**：实现任务拆解、步骤规划和逻辑校验的自动化，无需人工介入。
2.  **调度能力**：支持多工具并行和资源动态分配，解决了传统 Agent 单线程干活效率低的问题。
3.  **上下文管理**：突破会话窗口限制，实现跨场景、长周期的状态留存。
4.  **工具协同**：通过标准化协议（如 MCP 协议）打通本地系统、云端 API 和 IoT 设备，打破工具壁垒。
5.  **持久化能力**：支持定时任务、持续监控等长效场景。任务未完成时会在后台持续运行，断网重启也能断点续传。

## 技术特征
- **本地化优先**：强调在个人设备（如 PC、Mac Mini）上运行，连接本地网络，保护隐私。
- **自然语言编程**：支持通过自然语言指令（如 `/add-telegram`）动态修改自身代码以扩展功能。
- **容器化隔离**：为了安全，通常在容器中运行任务，与主系统隔离。

## 代表性项目
- [[OpenClaw]]：鼻祖，功能全但代码臃肿。
- [[NanoClaw]]：极简主义代表，代码仅 4000 行，强调安全。
- [[CoPaw]]、[[LobsterAI]]、[[Kimi Claw]]：国内大厂推出的各类变体。

- 与 [[runtime-agent-os]]：Claws 是 Runtime Agent-OS 理念的具体实践形态之一。
