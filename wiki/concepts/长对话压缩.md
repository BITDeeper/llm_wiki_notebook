# 长对话压缩

长对话压缩是指 AI 智能体在处理长上下文任务时，为了节省 Token 资源和避免上下文窗口溢出，对历史对话记录进行精简和优化的机制。

## 挑战
在长周期任务（如代码生成、数据分析）中，对话历史可能非常庞大。如果不加处理，会导致：
- **Token 消耗过大**：增加 API 成本和延迟。
- **超时崩溃**：压缩过程本身耗时过长，导致会话被系统杀掉。
- **上下文污染**：历史记录中的孤立数据块可能干扰模型的后续推理。

## OpenClaw 的优化
在 [[OpenClaw]] 3.22 版本中，Agent 引擎对压缩机制进行了多项改进：
1.  **延长截止时间**：在压缩过程中自动延长运行截止时间，防止大型会话在压缩到一半时被超时终止。
2.  **修复孤立块**：自动清理或修复历史记录中孤立的 `tool_result` 块，避免残余数据导致后续 API 请求失败。
3.  **防止死循环**：修复了空会话压缩时可能陷入的死循环问题。

这些优化显著提升了 OpenClaw 在生产环境中处理长任务（如默认超时设为 48 小时的任务）的稳定性。
