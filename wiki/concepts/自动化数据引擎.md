# 自动化数据引擎

在 3D 视觉与具身智能领域，**自动化数据引擎**是指一套能够从无标注或弱标注的原始数据（如互联网视频）出发，自动生成高质量、结构化标注数据（如 3D 网格、实例分割、空间关系问答）的软件管线。

## 核心价值

传统的 3D 数据获取依赖于昂贵的激光扫描或深度相机采集，并需大量人工标注，难以扩展。自动化数据引擎旨在通过算法替代人工，利用海量的互联网视频资源，实现“互联网规模”的数据生成，从而解决 [[具身智能数据困境]] 中的数据稀缺问题。

## 典型流程（以 SceneVerse++ 为例）

一个典型的面向 3D 场景理解的自动化数据引擎包含以下关键模块：

1. **数据筛选与预处理**
   - 使用镜头检测算法（如 TransNetV2）剔除无效片段（如黑屏、人物特写）。
   - 保留适合 3D 重建的静态室内场景片段。

2. **几何重建 ([[sfm]], [[tsdf]])**
   - **SfM (Structure from Motion)**：通过特征匹配与光束法平差（BA），从 2D 图像序列中恢复相机位姿和稀疏 3D 点云。
   - **稠密重建**：结合度量深度估计与 TSDF（截断符号距离函数）体积融合，生成稠密的水密 3D 网格。

3. **语义理解与标注**
   - **2D 分割提升**：利用 2D 实例分割模型（如 SAM）结合多视图一致性，将 2D 掩码聚合为 3D 实例。
   - **自动标注生成**：利用视觉语言模型（VLM）自动生成物体的类别标签、文本描述以及空间关系问答对。

4. **任务特定数据生成**
   - 针对 [[视觉语言导航]] (VLN) 任务，引擎还需包含轨迹优化（移除冗余旋转）和指令增强（生成多样化导航指令）模块。

## 关键挑战

- **鲁棒性**：子模块（如 SfM、分割器）通常在受控环境下训练，直接应用于“野生”互联网视频时容易产生误差累积。
- **质量把控**：需要在自动化流程中设置质量过滤机制（如人工复核或几何一致性检查），以确保生成的 3D 场景符合物理真实性和任务需求。
- **模型协同**：不同的下游模型对数据分布的敏感度不同（例如 [[spatiallm]] 比 [[mask3d]] 更具鲁棒性），引擎设计需考虑目标模型的特性。

## 应用实例

[[sceneverse++]] 是该概念的典型应用案例，其通过自动化引擎从 8,217 段视频中成功生成了 6,687 个高质量的 3D 训练场景，显著提升了 3D 检测、VQA 和 VLN 任务的模型性能。
