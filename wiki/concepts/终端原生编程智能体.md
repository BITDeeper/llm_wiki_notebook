# 终端原生编程智能体

终端原生编程智能体是指直接运行在命令行（终端）中的 AI 编程代理，能够读取代码、制定计划、修改文件、运行测试，区别于 Web 端或 IDE 插件形态的编程辅助工具。

## 四强争霸格局

截至2026年5月，该赛道已形成四强争霸格局：

1. **[[claude-code|Claude Code]]**（[[anthropic|Anthropic]]）——赛道先行者，编程能力领先
2. **[[codex|Codex CLI]]**（[[openai|OpenAI]]）——支持大规模并行实例运行
3. **[[gemini-antigravity|Gemini Antigravity]]**（Google）——基于 Gemini 模型构建
4. **[[grok-build|Grok Build]]**（[[xai|xAI]]/马斯克）——最新入场者，以 Plan Mode 和 Arena Mode 差异化竞争

## 核心特征

- **终端原生**：直接在命令行中运行，无需 IDE 或浏览器
- **全流程能力**：读代码→做计划→改文件→跑测试的完整工作流
- **Agent 化**：具备自主规划和执行能力，而非简单的代码补全
- **上下文窗口关键**：大上下文窗口对大型代码库和长时间会话至关重要
