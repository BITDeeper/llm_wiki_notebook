# OpenAI股权结构与造富效应

OpenAI通过慷慨的股权分配和频繁的[[tender-offer]]，在IPO前已制造大量百万美元富翁，形成硅谷罕见的造富神话。

## 核心数据

| 指标 | 数值 |
|------|------|
| 员工+离职员工持股比例 | 19.35% |
| 员工持股总价值 | 1649亿美元 |
| 员工总数（约） | 5000人 |
| 人均持股（约） | 3300万美元 |
| 员工期权池 | 10%（估值500亿美元） |
| 未来5年新增激励 | 200亿美元 |

## 造富机制

1. **入职即配股**：技术岗位年薪超50万美元+远超同行的股权补偿
2. **定期套现**：通过多次[[tender-offer]]允许员工IPO前变现，单人限额已提至3000万美元
3. **估值飞轮**：早期员工股票价值7年增长超100倍，Ilya持股半年从50亿增至70亿（+40%）
4. **持续加码**：10%期权池+5年200亿美元新增激励

## 关键人物股权

- [[greg-brockman]]：约300亿美元（2018年董事会授予）
- [[ilya-sutskever]]：约70亿美元（离职后仍持有）
- [[sam-altman]]：目前0持股，[[营利性重组]]时曾考虑授予7%（约百亿美元）

## 外溢效应

- 湾区房价过去一年上涨14%，与AI公司员工套现时间线吻合
- 三巨头（SpaceX、OpenAI、Anthropic）集体IPO后预计进一步推高旧金山房地产市场
- 被称为"亿万富翁生产线"

## 与[[营利性重组]]的关系

OpenAI从非营利组织转为营利性PBC的重组过程，是股权大规模分配的关键节点。重组期间董事会曾考虑授予Altman 7%股权，标志着公司治理结构的根本性转变。
