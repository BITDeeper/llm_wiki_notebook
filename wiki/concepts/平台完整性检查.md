# 平台完整性检查

**平台完整性检查**（Platform Integrity Check）是 [[Anthropic]] 在 [[Claude]] 平台中实施的一种风控机制。

## 触发机制
根据官方公告，当用户访问某些特定功能，或系统检测到异常行为模式时，可能会触发此检查。这是平台例行安全和合规措施的一部分。

## 后果
触发完整性检查后，用户可能会被强制要求进行身份验证（即 [[KYC]]）。如果用户无法提供有效的政府证件或完成验证，账户可能会受到限制或被禁用。

## 针对对象
虽然官方公告未明确列出具体目标，但分析指出，此类检查主要针对高风险行为，例如：
- 使用 [[逆向代理]] 将个人订阅额度转化为 API 接口。
- 在不支持的地区创建账户。
- 违反服务条款的滥用行为。

## 不确定性
官方对“部分用例”和“某些功能”的定义较为模糊，导致用户对何时会触发检查缺乏确定性，增加了使用焦虑。
