# Token计费

[[Token计费]] 是 AI 服务按处理的 Token 数量计算费用的模式。在视频生成领域，这种计费方式被进一步细化为区分输入和输出成本。

## 计费实例
[[Seedance 2.0]] 采用了差异化的 Token 计费策略：
- **含视频输入**：28 元/百万 tokens（适用于视频编辑场景，需处理原始视频帧）。
- **不含视频输入**：46 元/百万 tokens（适用于纯文本生成视频场景）。

这种精细化的计费模式反映了不同任务对算力消耗的差异，也是应对 [[ai-subscription-crisis]]（订阅制危机）的一种解决方案，特别是在视频生成这种高算力消耗场景下。
