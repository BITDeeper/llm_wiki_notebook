# 高速推理API

高速推理 API 指旗舰大语言模型通过系统工程优化（而非缩小模型规模）实现极高推理速度的 API 服务形态。代表案例是 [[智谱]] 的 [[glm-5-1-highspeed]]，达到 400 tokens/s。

## 核心特征

- **旗舰能力不缩水**：区别于传统做法中通过缩小模型换取速度，高速推理 API 保持旗舰模型的完整能力
- **系统工程驱动**：速度提升来自推理引擎、调度系统和基础设施的综合优化，而非单纯依赖更强芯片
- **体验质变**：使人与 AI 的协作从"一次性下单"变为"来回打磨"，体感接近实时

## 竞争维度演变

高速推理 API 的出现标志着国产大模型 API 竞争从单一维度走向双维竞争：

1. **第一阶段**：能不能答得好（模型质量竞争）
2. **第二阶段**：能不能又快又稳地干活（质量 + 速度 + 稳定性综合竞争）

## 关键技术支撑

- [[tile级推理调度]]：将调度单元下沉到 tile 级别
- 动态批处理与 KV 缓存调度
- 推理集群部署与负载均衡协同优化

## 对 Agent 体验的影响

高速推理 API 使 [[ai-agent快时代|AI Agent]] 体验出现直观变化：
- 等待变少
- 反馈变密
- 任务推进更连续

这与 [[tokenmaxxing]] 所描述的 Token 吞吐量最大化竞赛形成呼应，也与 [[任务执行范式]] 中从单次对话到持续协作的趋势一致。

## 待验证问题

- 复杂任务、高并发条件下的实际表现
- 生产环境的稳定性、成本和错误率
- 定价模型及其对 [[ai-subscription-crisis]] 的影响
