# 智效比

## 定义
**智效比**（Intelligence-Efficiency Ratio）是指模型的智能水平与其所消耗的资源（如 Token 数量、算力成本、响应时间）之间的比率。

## 背景
随着 AI 应用从简单的对话转向复杂的任务执行（如 Agent），行业对模型的评价标准发生了变化。过去主要关注“大而全”（参数规模、通用能力），现在越来越重视“小而美”和工程落地。全球企业级 AI 应用中约有 50% 的 Token 被浪费，这使得**智效比**成为衡量模型商业价值和实用性的关键指标。

## 核心要素
1.  **智能水平**：模型完成任务的准确度、逻辑推理能力和指令遵循能力。
2.  **资源消耗**：
    - **Token 效率**：输出内容的简洁度，是否包含冗余废话。
    - **响应速度**：生成内容的延迟，直接影响用户体验。
    - **算力成本**：运行模型所需的硬件资源和 API 调用费用。

## 应用案例
- [[elephant-大象模型]] 是高智效比的典型代表。它虽然只有 100B 参数，但在代码修复、文档整理等任务中表现出极高的准确度，同时保持极低的 Token 消耗和约 1 秒的响应延迟。
- OpenAI 的 GPT-5.4 mini/nano 和谷歌的 Gemma 4 也是为了提升智效比而推出的产品，旨在降低部署成本并提高吞吐量。

## 意义
追求高智效比意味着在保持足够智能的前提下，尽可能降低使用成本。这对于预算有限的中小企业、需要处理大量高频任务的 Agent 系统以及边缘计算场景至关重要。它标志着 AI 行业从单纯的“军备竞赛”向精细化运营转变。
