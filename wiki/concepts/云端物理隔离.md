# 云端物理隔离

**云端物理隔离**是一种用于移动端 AI Agent 的安全解决方案，指将 Agent 的运行环境放置在云端虚拟机中，而非用户的本地物理设备上。

## 工作原理
- **云端运行**：用户的指令在云端虚拟手机上执行，Agent 完成跨 App 的数据抓取、操作模拟等任务。
- **结果回传**：仅将操作结果（如截图、文本）回传给用户。
- **敏感触发**：当 Agent 尝试访问支付密码、隐私相册等敏感数据时，系统会强制中断操作并提示用户接管（人类接管模式）。

## 优势
- **隐私保护**：Agent 无法直接触碰用户真实设备上的敏感数据，消除了用户对“AI 乱点手机”的恐惧。
- **权限解耦**：Agent 可以拥有高权限以完成复杂任务，同时通过物理隔离保证安全底线。

## 应用
百度发布的 [[红手指Operator]] 是该技术的典型应用案例。
