# 混合感知路由

混合感知路由是 GUI Agent 中一种动态选择数据获取路径的技术策略。它旨在解决 Agent 落地中环境噪声大、非标界面无法解析的痛点。

## 工作原理
系统根据当前界面的特性，动态在以下两种路径之间切换：
1. **XML 无障碍树路径**：适用于标准 UI（如安卓原生控件）。通过读取系统的结构化数据，快速获取界面元素信息，效率高且准确。
2. **视觉路线**：适用于非标 UI（如游戏界面、OpenGL 渲染的地图）。通过截取屏幕像素，利用视觉语言模型（VLM）进行像素级的「开放词汇定位」。

## 应用案例
在 [[豆包手机]] 的测试中，当用户要求在高德地图上「点击深红色最堵路段旁边的施工图标」时，由于地图界面通常是 OpenGL 渲染的，安卓的无障碍树往往为空或仅包含一个容器。此时，系统自动切换至视觉路线，VLM 理解了「深红色、旁边、施工图标」等复杂语义和空间关系，成功完成了任务。

## 优势与权衡
- **优势**：兼顾了效率与通用性。对于标准应用，利用 XML 树实现快速响应；对于复杂图形界面，利用视觉模型实现理解。
- **代价**：视觉路线通常比解析 XML 树更耗电且耗时。
