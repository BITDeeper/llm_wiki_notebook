# 全局上下文同步机制

**全局上下文同步机制** (Global Context Synchronization，简称 GCS) 是 [[Scal3R]] 模型中用于确保分布式训练和推理一致性的关键机制。

## 工作原理
在处理长序列时，Scal3R 将序列切分为多个重叠的分块，并分配到不同的 GPU 上并行处理。GCS 利用 PyTorch DDP (Distributed Data Parallel) 的 all-reduce 机制，在不同 GPU 处理的不同分块之间同步 [[全局上下文记忆模块]] (GCM) 中自适应存储单元的自监督梯度。

## 重要性
GCS 确保了无论在训练还是推理阶段，整个长序列机制都是一致的。它防止了不同分块各自为政（即“训练时学局部、测试时临时拼一下”的情况），保证了全局上下文信息在整个长序列范围内的同步更新和一致性。
