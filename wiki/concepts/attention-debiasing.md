# 注意力去偏

注意力去偏是一种修正模型注意力权重中结构性偏置的技术。在视觉-语言模型（VLM）中，注意力机制常被用作衡量 token 重要性的指标，但研究发现其包含大量与语义无关的系统性偏差。

## 核心原理
该技术主要针对两类偏置进行修正：
1.  **位置偏置修正**：通过拟合注意力随 token 位置变化的趋势曲线，去除模型倾向于关注序列末尾（如图像下方）的非语义偏好。
2.  **Padding 抑制**：显式抑制填充区域因隐藏状态异常激活而产生的虚假高注意力。

## 优势
- **无需重训练**：作为一种后处理修正手段，不需要更新模型参数，降低了应用门槛。
- **即插即用**：不依赖特定的剪枝算法，可集成到 [[FastV]]、[[PyramidDrop]] 等多种主流方法中。
- **提升可靠性**：在资源受限（如移动端、边缘计算）场景下，能帮助模型在信息更少时做出更准确的判断。

## 应用场景
主要用于 [[visual-token-pruning]] 过程中，确保被保留的视觉 token 真正对应图像中的关键语义信息，而非背景或填充区域。
