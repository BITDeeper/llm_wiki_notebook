# 显式认知地图探测

**显式认知地图探测**（Explicit Cognitive Map Probing）是 [[theory-of-space]] 研究中引入的一种核心评估技术。

## 原理
传统的评估方法通常只关注模型输出的最终答案对错，将模型内部视为“黑盒”。显式探测技术要求模型在每一步决策后，以 JSON 格式外化其内部的空间信念（即当前的认知地图）。

## 评估维度
通过分析这些外化的 JSON 地图，研究人员可以度量以下指标：
*   **准确性**：地图与真实环境的吻合程度。
*   **感知质量**：对物体位置和朝向的感知精度。
*   **稳定性**：记忆随时间的变化情况。
*   **不确定性**：模型对未知信息的处理方式。

## 价值
这种“白盒”方法揭示了模型失败的深层原因，例如 [[信念漂移]] 和 [[信念惯性]]，证明了认知地图准确度与下游任务表现之间存在显著的正相关（Pearson r = 0.42~0.65）。
