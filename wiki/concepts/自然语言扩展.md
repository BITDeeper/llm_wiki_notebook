# 自然语言扩展

自然语言扩展是一种软件交互模式，指用户通过输入自然语言指令，让软件系统自动修改自身的代码或配置以添加新功能。

## 工作原理
传统软件扩展功能通常需要用户下载插件、修改配置文件或编写代码。而在自然语言扩展模式下（如 [[NanoClaw]]）：
1.  用户输入指令：“/add-telegram”。
2.  AI 理解意图，检索相关 API 文档。
3.  AI 自动生成所需的代码片段并插入到系统中。
4.  系统重启或热重载，新功能生效。

## 优势
- **降低门槛**：完全不懂编程的用户也能通过对话定制软件功能。
- **灵活性**：避免了传统软件“设置面板越来越复杂”的问题，保持了核心的简洁。

## 风险
- **不可预测性**：AI 生成的代码可能包含 Bug 或安全漏洞，需要配合 [[代码审计]] 和 [[容器化运行]] 来降低风险。
