# Humorphism (拟人化设计)

## 定义
[[Humorphism]] 是一种针对 AI Agent 时代的交互设计哲学。它主张 Agent 的行为应模仿人类队友的互动模式，而非传统软件的“拟物化”或机械响应。

## 核心原则
根据亚马逊云科技应用 AI 解决方案高级副总裁 Colleen Aubrey 的阐述，Humorphism 的核心在于顺应人类互动的动态学：
- **卡住时帮忙**：当用户遇到困难或停滞时，Agent 应主动提供帮助或建议。
- **专注时等待**：当用户处于心流状态或专注工作时，Agent 应保持静默，不打扰用户。

## 背景与演变
- **拟物化**：早期 GUI 设计试图将现实世界的物体（如文件夹、垃圾桶）模拟到屏幕上。
- **拟人化**：在 Agent 时代，交互的重点从“操作物体”转向“与人协作”。因此，界面设计需要从静态的视觉隐喻转向动态的行为模式。

## 应用实例
[[Amazon Quick]] 是 Humorphism 设计理念的典型应用，它试图在主动服务与尊重用户注意力之间取得平衡，成为用户值得信赖的“数字队友”。
