# Software 2.0

[[andrej-karpathy|Andrej Karpathy]] 于2017年在Medium上提出的概念框架，重塑了整个行业对"什么是编程"的认知。[[software-2.0]] 指软件开发从传统的显式编程（由人类编写逻辑代码）转向基于权重和优化的范式（由训练数据决定行为）。

## 核心主张

| Software 1.0 | Software 2.0 |
|---|---|
| 人类编写明确指令 | 神经网络权重就是新的代码 |
| 源代码 | 数据集就是新的源代码 |
| 编译器 | 梯度下降就是新的编译器 |

## 发展阶段

- **初期**：主要表现为神经网络替代显式规则。
- **深水区**：根据最新观点，Software 2.0 正在进入更深层次。这不仅是权重的优化，更涉及底层架构、通信方式乃至智能形态的根本性变革（如 [[蜂群思维]]）。

## 影响

这一框架将深度学习从"工具"提升为"范式"，改变了行业对编程本质的理解。后续Karpathy在2025年6月进一步提出 [[software-3.0|Software 3.0]] 框架，将提示词（Prompt）定义为新的编程层。

## 未来展望

在 Software 2.0 的终局设想中，传统的代码可能被视为"汇编残骸"，而人类语言（英语等）作为交互界面也可能显得过时。智能将不再通过代码或语言这种低带宽介质表达，而是通过更直接的神经连接或权重融合实现。
