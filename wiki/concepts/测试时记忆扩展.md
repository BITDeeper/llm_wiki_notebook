# 测试时记忆扩展（TTME）

测试时记忆扩展（Test-Time Memory Extension, TTME）是 [[se-ga|SE-GA 框架]]的核心组件之一，旨在解决 GUI 智能体"记不住"的问题。该模块借鉴人类认知架构思想，构建分层记忆库，从不同粒度为智能体决策提供支撑。

## 分层记忆结构

TTME 包含三种互补的记忆类型：

### 情景记忆（Episodic Memory）
- **定位**：短期工作记忆
- **功能**：跟踪"刚才做了什么"
- **机制**：在每个时间步记录前一步的观察、采取的动作以及动作执行后的新观察
- **优势**：避免保留全部历史的计算开销，过滤过时信息

### 语义记忆（Semantic Memory）
- **定位**：通用规则库
- **功能**：存储"怎么做才对"
- **内容**：抽象的、跨任务通用的交互规则（如"需要先登录才能访问受限页面""搜索功能通常在页面顶部"）
- **作用**：帮助智能体理解当前状态背后的行为逻辑

### 经验记忆（Experiential Memory）
- **定位**：过往经历库
- **功能**：复用"成功的经验"
- **内容**：过往成功完成的任务轨迹，包括原始轨迹和智能体自己生成的反思总结
- **检索**：采用文本-图像混合检索机制，同时考虑语义一致性和视觉相似性

## 设计理念

TTME 的核心创新在于将人类认知科学中的多重记忆系统理论引入 GUI 智能体设计，使智能体能够在推理阶段（而非仅训练阶段）利用外部记忆进行决策增强。

## 局限性

随着交互数据不断积累，经验记忆库规模持续增长，基于嵌入相似度和视觉特征的检索操作可能带来显著的计算开销，影响实时推理的响应速度。
