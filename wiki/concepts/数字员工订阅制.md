# 数字员工订阅制

**数字员工订阅制**是一种新型的 AI 商业模式，企业按“雇佣”数字员工的数量或能力付费，而非单纯按 Token 消耗计费。这一模式由 [[智谱AI]] 在其“龙虾套餐”（Claw-plan）中率先提出。

## 核心逻辑
- **传统模式**：按 API 调用次数或 Token 量付费，成本随使用量线性增长。
- **数字员工模式**：将 AI 视为一名具备特定技能（如编程、数据分析）的员工，企业支付固定费用（如月薪）以获得其产出。

## 代表产品
智谱AI推出的 **Claw-plan**（龙虾套餐），定价 39 元/4000 万 Token，旨在降低企业使用高算力 Agent 的成本门槛。

## 行业意义
这一模式反映了 AI 商业化从“售卖资源”向“交付价值”的转变，试图解决 [[ai-subscription-crisis]] 中提到的 Agent 时代高算力消耗带来的成本压力。
