# 输出感知度量（OAM）

输出感知度量（Output-Aware Metric, OAM）是 [[stem-稀疏注意力|Stem 稀疏注意力算法]]的两大核心创新之一，解决"挑哪些 token"的问题。

## 核心洞察

传统方法仅用注意力分数（Query 和 Key 的点积）来挑选 token，但 Stem 指出一个常被忽视的事实：**分数高 ≠ 实际贡献大**。

- 一个 token 可能与 Query 很相关（分数高），但它的 Value 向量幅值接近零，对输出几乎无贡献
- 反过来，分数中等但 Value 幅值很大的 token，才是真正的"信息富矿"

## 机制

注意力的本质是加权求和，一个 token 的真实贡献 = 路由概率 × 信号幅值。OAM 据此设计度量方法：

通过对数变换将"乘法"转化为"加法"，排序结果不变，又能直接套用标准 Top-K 算子，实现几乎零开销。

## 与 TPD 的协同
[[token位置衰减|TPD]] 决定"给谁多一点"，OAM 决定"在那一点里挑谁"，两者协同将稀疏注意力从"一刀切"升级到"看信息流决定稀疏预算"。
