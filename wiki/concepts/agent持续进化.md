# Agent持续进化

[[agent持续进化]] 是指 AI Agent 在部署上线后，仍能从实际执行过程中的失败或成功经验中学习，实现能力自我迭代和优化的特性。

## 背景与痛点
传统的 Agent 开发遵循“[[上线即冻结]]”的模式：模型训练完成后部署，能力在生命周期内基本不变。然而，现实世界的任务需求、工作流程和工具链在不断变化，导致静态 Agent 难以适应长期的实际应用。

## 实现路径
[[metaclaw]] 框架提出了一种可行的解决方案，即通过 [[快慢双循环]] 机制：
1.  利用大模型分析失败轨迹，提炼显性规则（快循环）。
2.  利用碎片时间进行强化学习微调权重（慢循环）。

## 范式转移
这一概念标志着 Agent 的生命周期从“训练完成后交付”向“交付后继续生长”的范式转移。未来的 Agent 竞争力将不仅取决于出厂时的参数规模，更取决于其在真实场景中持续转化经验的能力。
