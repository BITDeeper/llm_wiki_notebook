# 产能转移效应

产能转移效应是指三大DRAM原厂将产能系统性切给 [[hbm高带宽内存]]，导致普通存储芯片供应收缩、价格上涨的传导现象。这是2026年消费级内存涨价的根本原因。

## 核心数据

- HBM目前吃掉**23%**的DRAM晶圆产能
- [[sk海力士]] 和 [[三星电子]] 将最多**40%**的先进晶圆产能重新分配给HBM
- 全球约**70%**的存储芯片产能被数据中心吃掉

## 产能分配优先级

1. 超大规模云厂商（微软、谷歌、亚马逊）
2. 企业级
3. 汽车
4. 智能手机和PC（**消费者排在最末位**）

## 传导机制

```
AI模型规模扩张 → HBM需求激增 → 产能向HBM系统性转移 → 普通DRAM/NAND供应收缩 → 消费端内存涨价
```
