# 视频数据处理管线优化

视频数据处理管线优化是指针对以视频为核心学习材料的世界模型（如 [[dreamzero|DreamZero]]），通过优化视频解码与预处理流程来消除 I/O 吞吐瓶颈的技术手段。

## 问题背景

随着计算密度（算子融合、并行优化）的显著提升，数据加载效率逐渐成为制约整体训练吞吐的新瓶颈：

- 视频数据的解码与预处理极其消耗 CPU 资源
- 传统方案（如 PyAV）在解码性能上难以支撑高频吞吐需求
- 单纯增加 num_workers 会剧烈抢占 CPU 资源，导致训练主线程 Kernel Launch 延迟

## 解决方案

[[rlinf|RLinf]] 团队对主流视频处理库进行了深度性能 Benchmark：

- **Decord**：纯解码速度略胜，但 CPU 占用稳定性不足
- **Torchcodec**：保持同梯队解码性能的同时，表现出更优的 CPU 占用稳定性
- **PyAV**（原生方案）：解码速度最慢

最终选择 Torchcodec，因为更优的 CPU 占用稳定性可以：
- 预留充足计算余量给训练主线程
- 支持开启更多 num_workers 并发处理数据

## 优化效果

- 单视频解码时间缩短近 **400ms**
- 多视角训练场景（左、右、腕部三个视频）累计节省 **1.2s**
- 为后续进一步压榨 GPU 计算潜力提供充足的数据「弹药」
