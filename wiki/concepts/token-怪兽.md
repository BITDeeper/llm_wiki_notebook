# Token 怪兽

## 定义
“Token 怪兽”是对高消耗型 [[ai-agent]]（如 [[openclaw]]）的形象比喻。这类智能体在执行自动化任务（如浏览网页、操作软件、分析数据）时，需要持续调用大模型的 API，产生巨大的 Token 消耗量。

## 商业逻辑
- **云厂商动机**：由于 Agent 是 24x7 运行的“数字员工”，其 Token 消耗量远超传统聊天机器人。这使得云厂商（腾讯云、阿里云、火山引擎等）热衷于推广此类框架，以拉动云服务和 API 销售增长。
- **模型厂商策略**：[[智谱]]、[[MiniMax]]、[[Kimi]] 等厂商纷纷针对 OpenClaw 进行优化，旨在争夺这一高频消耗场景的市场份额。

## 影响
这一现象加剧了 [[ai-subscription-crisis]]（AI 订阅制危机），推动了行业从固定订阅制向按量计费或分层定价模式的转变。
