# SOTA 排行榜

SOTA（State-of-the-Art）排行榜是按任务、数据集和评估指标对模型性能进行结构化对比的排名系统，是机器学习研究中不可或缺的基础设施。

## 核心功能

- **按任务对比：** 用户可按具体任务（如自动语音识别、图像分类等）查找最佳模型。
- **按数据集对比：** 在特定数据集上对比不同模型的表现。
- **按评估指标对比：** 支持多种评估指标（如 WER、RTFx 等）的性能排序。
- **时间演进可视化：** 新版平台加入散点图，展示特定基准上技术水平随时间的演进。

## 在 Papers with Code 中的地位

SOTA 排行榜是 [[papers-with-code]] 最核心、最无可替代的功能。原版关闭时积累了超过 9300 个基准测试的性能对比数据。

Hugging Face 推出的过渡方案"Trending Papers"仅展示热门论文和 GitHub 链接，完全缺乏 SOTA 排行榜，被社区认为从一个功能完备的"研究基础设施"降级为仅仅一个"热榜"，落差巨大。

## 新版升级

新版 paperswithcode.co 的 SOTA 排行榜全面回归，并增加：
- 同时展示多个评估指标
- 散点图可视化技术演进
- 自动从论文中提取评估结果（由 [[ai智能体驱动论文解析]] 实现）
