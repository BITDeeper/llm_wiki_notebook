# 长程任务执行衰减

长程任务执行衰减是 [[computer-use-agent|Computer-Use Agent]] 在真实环境中表现出的四种结构性失败模式之一，指 Agent 在多步骤任务中通过率随任务推进呈不可逆下降的现象。

## 核心特征

- 即使每个检查点通过率高达 95%，12 个检查点的全部通过概率也只有 54%
- 所有模型都呈现同一模式：通过率随任务推进呈下降趋势
- 没有一个模型能在后半段维持住前期表现
- 这是一条不可逆的下降曲线，越往后走越不可能走完

## 数学本质

这是概率论中独立事件联合概率的自然结果——当每步都有微小失败概率时，总通过率随步骤数指数衰减。但 Agent 的问题比纯数学预期更严重，因为后续步骤还受到[[错误级联传播]]和[[意图-状态断层]]的叠加影响。

## 与其他失败模式的关系

长程任务执行衰减是四种结构性失败中最基础的模式，与[[错误级联传播]]、[[意图-状态断层]]和[[路径依赖不稳定性]]共同构成了当前 Agent 范式的"天花板"。
