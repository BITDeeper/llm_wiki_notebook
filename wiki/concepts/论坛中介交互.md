# 论坛中介交互

论坛中介交互是一种利用在线论坛的异步、多智能体和持久化特性，作为人类指令与 AI 智能体/物理机器人之间交互信道的系统设计范式。

## 核心优势
相比于微信群、Slack、REST API 或语音控制，论坛中介交互具有以下独特优势：
*   **异步性**：不需要双方同时在线，机器人可以自主安排执行时间。
*   **多智能体支持**：一个论坛可容纳无数个 Agent，各自监听特定任务（如 `@dog`, `@arm`）。
*   **持久化与可搜索性**：每一条指令和执行结果都永久保存，自然形成交互日志和知识库。
*   **通用基础设施**：无需为每个机器人开发专用 GUI，帖子即指令，回帖即报告。

## 技术实现
该范式通常通过 [[Model Context Protocol]] (MCP) 等标准化协议连接论坛层与智能体层。智能体充当“永不下线的版主”，轮询特定标签或提及（Mention），将自然语言帖子转化为可执行的动作序列。

## 局限性
*   **延迟**：受限于轮询机制（如 30 秒一次），无法满足毫秒级的实时控制需求。
*   **安全风险**：将物理控制权暴露在互联网论坛上，面临 Prompt 注入或权限绕过的潜在风险。
