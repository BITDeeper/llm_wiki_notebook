# 复合奖励函数

复合奖励函数是 [[evolver-agent|EvolveR]] 框架中用于 GRPO 强化学习训练的多维度奖励设计，核心思想是区分"做事"和"会做事"，使 Agent 不仅学会给出正确答案，还学会如何有效地检索和使用经验。

## 组成部分

1. **结果奖励（Outcome Reward）：** 最终答案与标准答案的精确匹配，衡量任务完成质量。
2. **格式奖励（Format Reward）：**
   - **思考步数奖励：** 鼓励 Agent 进行适度推理，但不鼓励无脑堆长度，防止陷入"无限反思"死循环。
   - **搜索多样性奖励：** 激励 Agent 同时调用内部经验和外部知识，而非偏废其一。

## 设计动机

如果仅使用稀疏奖励（只看最终答案是否正确），Agent 很难学会"如何善用经验"这种中间行为。复合奖励函数通过多维度打分，引导模型学到：

- 什么时候该查经验
- 查什么经验
- 如何把经验转化成有效行动

## 与传统方法的区别

传统 RAG 解决的是"缺知识"的问题，EvolveR 的复合奖励函数解决的是"缺经验"的问题——不仅要有信息，还要有运用信息的策略。
