# 元系统

**元系统**（Meta-System）是一种位于基础大模型之上的架构层，旨在通过动态编排和策略生成来优化模型推理，而非直接依赖模型本身的参数规模。

## 核心特征
1. **策略自动生成**：系统能够根据任务特性，自动生成解决特定任务的策略、模型组合甚至代码。
2. **模型无关性**：无需微调底层模型，即可快速适配不同架构的前沿模型（如 Gemini、GPT、Claude）。
3. **递归式自我改进**：通过“生成 -> 执行 -> 反馈 -> 改进”的循环流程，逐步打磨最终解答。
4. **资源感知**：具备自我监控机制，能判断何时信息足够、结果可靠，从而自动结束流程以节省算力。

## 设计理念
元系统强调“提示词只是接口层，并非智能本体”。它认为真正的智能不在于单次提示词的优劣，而在于系统如何动态生成、调整和管理这些接口（提示词）。

## 与传统 Agent 的区别
虽然与 [[runtime-agent-os]] 和 [[任务执行范式]] 有相似之处，元系统更侧重于“生成系统”的特性——即利用 LLM 来构建系统本身，而不仅仅是让 LLM 执行任务。它代表了从“模型为中心”向“系统为中心”的范式转移。

## 应用案例
[[Poetiq]] 公司利用元系统架构，在 [[ARC-AGI-2]] 基准测试中实现了 SOTA 级别的准确率，同时将推理成本降低了一半。
