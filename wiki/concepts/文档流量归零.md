# 文档流量归零

**文档流量归零**（Zero-Doc Traffic）指随着 AI 编程助手（如 [[Claude Code]]、[[Cursor]]、[[Copilot]]）的普及，开发者不再通过查阅官方文档来学习 API 或最佳实践，而是直接向 AI 描述需求获得代码，导致技术文档网站的访问量急剧下降的现象。

## 影响机制

传统开发者工作流：
1.  遇到问题 -> 2. Google/搜索 -> 3. 访问官方文档 -> 4. 学习/转化（购买产品或看广告）

AI 时代开发者工作流：
1.  遇到问题 -> 2. 打开 AI 助手 -> 3. 输入自然语言需求 -> 4. 获取代码（跳过文档）

## 后果

对于依赖“文档流量”作为获客漏斗的开源项目或技术公司（如 [[Tailwind CSS]]），这一现象是致命的。它直接切断了“知名度 -> 付费转化”的商业闭环，导致项目虽然流行（被 AI 大量引用），但收入却断崖式下跌。

## 案例

[[Tailwind CSS]] 创始人 [[Adam Wathan]] 指出，其官方文档流量下降了 40%，直接导致了公司 80% 的收入下滑。
