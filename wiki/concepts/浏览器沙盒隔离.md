# 浏览器沙盒隔离

[[浏览器沙盒隔离]] 是一种安全架构理念，指将 AI Agent 的运行环境严格限制在浏览器提供的沙盒中，使其无法直接访问或修改用户主操作系统的核心文件和设置。

## 目的与优势

- **防止灾难性操作**：避免 AI Agent 因幻觉或错误指令删除用户关键文件（如 [[OpenClaw]] 曾发生的删除邮件事故）。
- **系统稳定性**：即使浏览器环境崩溃或被攻破，也不会影响主操作系统的稳定性。
- **用户信任**：降低用户对 AI Agent 接管电脑的恐惧心理。

## 权衡

虽然安全性更高，但浏览器沙盒隔离也限制了 AI Agent 的能力上限。例如，它可能无法像拥有系统级权限的 Agent 那样高效地管理本地应用或深度修改系统设置。[[Perplexity Computer]] 选择了这种架构，以此作为与直接控制 OS 的竞品区分的核心卖点。
