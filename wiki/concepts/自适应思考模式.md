# 自适应思考模式

[[自适应思考模式]]（Adaptive Thinking Mode）是 [[Claude Opus 4.7]] 引入的一种资源分配机制，用于替代传统的固定预算长思考模式。

## 工作原理
在该模式下，模型不再对所有任务使用固定的思考时间或 token 预算，而是根据**任务复杂度**自主决定思考深度：
- **简单查询**：快速响应，减少不必要的 token 消耗。
- **复杂步骤**：重点投入计算资源，进行深度推理。

## 优势
- **资源优化**：避免了简单任务上的算力浪费，同时确保复杂任务有足够的思考空间。
- **效率提升**：结合 [[xhigh-推理等级]]，能够更灵活地平衡响应速度与输出质量。

## 实际效果
根据 [[Anthropic]] 的内部测试，启用自适应思考模式后，虽然单次调用的 token 数可能增加，但由于模型错误率降低（返工减少），完成任务所需的总 token 往往更少。
