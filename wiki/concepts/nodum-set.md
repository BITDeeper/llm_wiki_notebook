# nodum set

**nodum set** 是 [[陶哲轩]] 在与 [[google-deepmind]] 合作研究中涉及的一个数学对象，主要探讨在特定规则下如何用尽可能少的线构造出“重叠最多”的构型。

## 研究过程
在针对该问题的研究中，[[AlphaEvolve]] 被用于在庞大的参数空间中探索高分构型。AI 提供了许多基于已有文献思想组合的方案，这些方案启发了陶哲轩的思考，使他能够抽象出适用于任意大规模参数的通用构造方法。

## 意义
这一案例被视为 [[ai-for-science]] 的典型范例：AI 负责具体的、繁琐的探索工作，而人类科学家负责高层次的抽象和证明。
