# GUI 元素检测

**GUI 元素检测**（Graphical User Interface Element Detection）是指 AI 模型识别并定位图形用户界面（如网页截图、应用界面）中特定交互元素（如按钮、输入框、菜单）位置的能力。

## 功能描述
具备 GUI 元素检测能力的模型可以接收一张界面截图，并根据自然语言指令（例如“查找‘查看食谱’按钮”）返回目标元素的精确位置（通常以边界框坐标或 JSON 格式表示）。

## 技术特点
- **原生能力**：在 [[Gemma 4]] 中，这是一种原生能力，不需要特殊的提示词工程或微调即可使用。
- **多模态基础**：该能力依赖于模型强大的视觉理解能力，能够解析复杂的视觉布局和文本信息。
- **Agent 基石**：对于 AI Agent 而言，GUI 元素检测是实现自动化操作（如点击、滑动、输入）的基础，是连接“理解”与“行动”的关键环节。

## 应用场景
- **自动化测试**：自动识别界面元素进行软件测试。
- **RPA (机器人流程自动化)**：模拟人类操作软件业务流程。
- **无障碍辅助**：帮助视障用户理解和使用图形界面。
