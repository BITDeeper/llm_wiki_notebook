# 端侧多模态

[[端侧多模态]]（Edge-side Multimodality）是指在边缘计算设备（如智能手机、物联网设备、嵌入式系统）上本地运行能够理解和处理多种模态信息（如文本、图像、音频、视频）的 AI 模型。

## 核心特征

-   **本地化处理**：所有推理计算均在设备本地完成，无需依赖云端 API。
-   **多模态输入**：能够直接通过摄像头、麦克风等传感器获取视觉和听觉信息并进行理解。
-   **低功耗与高效**：针对移动芯片架构（如 ARM、NPU）进行优化，追求极低的能耗（如“耗电养虾”）。

## 优势

1.  **隐私保护**：数据不离设备，敏感信息（如照片、语音、环境视频）无需上传云端，从根本上解决了隐私泄露风险。
2.  **零延迟**：消除了网络传输和云端排队的时间，提供实时的交互体验。
3.  **成本降低**：无需支付昂贵的云端推理费用或 API 调用费用，实现“Token 自由”。
4.  **离线可用**：在无网络环境（如飞行模式、偏远地区）下依然保持完整功能。

## 技术挑战

-   **模型压缩**：需要通过量化、剪枝或 [[MoE-混合专家]] 技术将大模型压缩到端侧可用的体积。
-   **硬件适配**：需要与芯片厂商（如 [[高通]]、[[联发科]]）深度合作，优化 NPU 和 GPU 的计算效率。
-   **散热与续航**：高强度的多模态计算对设备的电池续航和散热控制提出了极高要求。

## 代表性进展

[[Gemma 4]] 系列中的 E2B 和 E4B 模型是端侧多模态的里程碑式产品。它们不仅能在手机上离线运行，还支持复杂的视觉和音频理解任务，标志着端侧 AI 能力从简单的文本处理迈向了全感官交互。
