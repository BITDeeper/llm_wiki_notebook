# 在线策略蒸馏

在线策略蒸馏（On-Policy Distillation, OPD）是一种知识蒸馏范式，其核心特征是：**学生模型基于自身策略生成轨迹，教师模型在学生访问的每个状态上提供监督信号**。

## LLM 领域的 OPD

在大语言模型中，OPD 的实现较为自然：学生模型先按照自己的策略生成 token，随后教师模型在学生访问到的每一个 token 状态上提供监督。由于语言模型是离散 token 分布，可以直接对每一步的 token distribution 做 KL 蒸馏。

## 扩散模型中的 OPD

[[diffusionopd|DiffusionOPD]] 首次将 OPD 系统性地扩展到扩散模型的连续状态空间。关键挑战在于：扩散模型不是离散 token 序列，而是连续状态的去噪过程。

解决方案是将去噪过程重新建模为[[连续状态马尔可夫链]]，在此基础上推导出[[闭式kl散度损失]]，实现无方差的多任务能力蒸馏。

## 核心优势

- **高效探索**：学生无需对所有任务从零探索，直接学习各任务教师的策略与能力
- **低方差**：闭式KL损失天然无 Monte-Carlo 方差，优于PPO-style策略梯度
- **采样器兼容**：同时支持SDE和ODE采样器
