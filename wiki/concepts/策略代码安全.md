# 策略代码安全（非模型自觉）

策略代码安全是 [[英伟达]] [[nemoclaw]] 方案的核心安全理念：安全不依赖模型行为约束，而是通过硬编码的策略代码实现。

## 四层安全设计

1. **[[凭证代理隔离]]**：Agent 看不到 Slack/Outlook 令牌，鉴权在沙箱代理出口完成
2. **网络硬隔离**：接触内部敏感数据的 Agent 被硬性禁止访问公网
3. **策略代码白名单**：网络策略写在 policy.yaml 文件中，白名单以外的目标直接返回403
4. **[[可观测性轨迹]]**：Agent 每步决策以轨迹形式记录，通过 NeMo Relay 和 Arize Phoenix 查看

## 核心理念

安全靠的是策略代码，而非靠模型自觉。Agent 想碰白名单以外的目标，代理直接返回403，Hermes 把它当成普通工具报错处理，连闹幺蛾子的机会都没有。

## 与传统安全模型的区别

传统 Agent 安全依赖模型遵循指令（如系统提示词约束），存在被绕过的风险。策略代码安全将约束下沉到基础设施层，即使模型行为异常也无法突破安全边界。
