# Agent 用量模式

Agent 用量模式是指 AI 智能体在运行过程中表现出的算力消耗特征，其成本结构与传统的“一问一答”式聊天机器人有显著差异。这是 Anthropic 实施 [[龙虾税]] 政策的主要技术依据。

## 特征

与普通对话不同，AI 智能体的典型行为包括：
- **持续推理循环**：Agent 会不断进行自我反思和规划，产生大量的内部推理 Token。
- **自动重试**：遇到错误或不确定性时，Agent 会自动重试任务，成倍增加 API 调用次数。
- **工具调用**：频繁调用搜索引擎、代码解释器、文件系统等外部工具，产生额外的交互成本。

## 经济影响

这种模式意味着单个用户的资源消耗不再是线性的，而是可能呈现指数级增长。对于采用固定订阅制的平台（如 Claude Pro），重度 Agent 用户的成本可能远超订阅费用，导致平台亏损。

## 行业应对

为了应对这一模式带来的成本压力，AI 基础设施提供商开始区分“对话式用量”和“Agent 用量”，并对后者采用按量计费或更高的定价策略。这也促使开发者社区更加关注推理优化和成本控制技术。
