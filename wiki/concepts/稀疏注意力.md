# 稀疏注意力

稀疏注意力（Sparse Attention）是大模型推理加速领域最主流的技术方向之一，是一类通过选择性计算 token 交互来降低长上下文计算复杂度的注意力机制。其核心思想是"让模型学会有选择地看"——仅计算"重要"的 token 交互，从而降低算力消耗。

## 问题背景

标准 Transformer 的全注意力机制要求每个 token 与序列中所有其他 token 做交互计算，计算复杂度为 O(N²)，其中 N 为序列长度。当上下文从 32K 扩展到 1M 时，计算量膨胀近 1000 倍，这就是大多数模型上下文窗口被卡在 128K 以内的根本原因。随着大模型上下文窗口持续扩展至百万级别，[[预填充瓶颈|预填充阶段]]的计算开销急剧增长，成为长文本推理的核心瓶颈。

## 核心挑战

稀疏注意力的核心挑战在于两个决策：

1. **预算分配**：给哪些位置分配更多计算资源？
2. **token 选择**：在预算内选择哪些 token 进行计算？

### 现有方案的不足

- **算法层面**：对所有位置"一刀切"地分配相同稀疏预算，忽视因果架构中初始 token 的递归依赖特性；仅依赖注意力分数选择 token，忽略 Value 向量本身携带的信息量
- **算子层面**：底层算子无法真正高效地跳过被稀疏丢弃的块，导致理论加速比无法转化为实测性能

## 代表性工作

- **Blockwise Sparse Attention** — 将 KV cache 分块后用打分机制选择重要块，[[msa-稀疏注意力]]属于此类
- **[[stem-稀疏注意力|Stem]]** — [[腾讯混元]] AI Infra 团队提出的块级稀疏注意力算法，通过 Token 位置衰减（TPD）和输出感知度量（OAM）两大创新解决上述不足，被 ICML-26 收录
- **DeepSeek DSA** — DeepSeek 提出的稀疏注意力方案
- **Kimi MoBA** — Kimi 提出的稀疏注意力方案

## 意义

稀疏注意力是突破长上下文瓶颈的关键技术，直接支撑长程 Agent、长视频理解等高阶能力的实现。
