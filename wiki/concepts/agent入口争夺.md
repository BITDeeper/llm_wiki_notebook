# Agent 入口争夺

Agent 入口争夺是指 AI 行业中各主要玩家竞相抢占 Agent 部署层的竞争态势。谁掌握了好用又安全的部署层，谁就掌握了 Agent 时代真正的入口。

## 主要玩家

- **[[英伟达]]**：从芯片层向上扩展到模型+蓝图+安全运行时+技能库层，推出 [[nemoclaw]] 方案
- **[[openclaw]]**：开源 Agent 工具，将集成 [[openshell]] 运行时
- **[[hermes-agent]]**：开源 Agent 框架（GitHub 17万星），被英伟达选为企业级方案核心
- **商汤 [[agent-pack]]**：集成 Hermes Agent + OpenClaw + SenseNova-Skills 的一键安装包

## 竞争维度

- **部署便利性**：一键安装 vs 复杂配置
- **安全性**：企业级安全架构（凭证隔离、网络策略、可观测性）
- **自进化能力**：技能学习闭环、Curator 自维护
- **硬件生态**：从消费级 RTX PC 到企业级 DGX Spark 的全栈覆盖

## 产业意义

标志着 AI 竞争从模型能力转向部署能力和生态整合能力。芯片厂商（英伟达）、模型厂商（[[openai]]、[[anthropic]]）、应用厂商（商汤）的边界正在模糊。
