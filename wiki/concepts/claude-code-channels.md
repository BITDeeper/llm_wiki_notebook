# Claude Code Channels

Claude Code Channels 是 [[Anthropic]] 推出的一项集成功能，允许开发者通过 Discord 和 Telegram 等社交平台直接与 [[Claude Code]] 交互。

## 核心功能
- **任务派发**：开发者可以在 Discord 或 Telegram 的频道中直接发送指令，让 Claude Code 执行编程任务。
- **状态通知**：任务完成后，AI 会通过消息通知开发者结果。
- **降低门槛**：开发者无需购买 Mac Mini 24 小时运行开源 Agent，也无需本地配置复杂环境，即可使用强大的 AI 编程能力。

## 意义
Channels 进一步降低了使用 Claude Code 的摩擦力，将其嵌入到开发者日常沟通的工具流中。这是 Anthropic “三连击”中的第三击，旨在让 Claude 无处不在。
