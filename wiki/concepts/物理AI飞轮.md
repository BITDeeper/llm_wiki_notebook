# 物理AI飞轮

物理AI飞轮是 [[jeff-bezos|贝佐斯]] 将亚马逊经典飞轮理论应用于 [[物理AI]] 领域的战略模型，描述的是"模型优化工厂、工厂反哺模型"的闭环正反馈机制。

## 飞轮机制

```
AI模型优化工厂运营
        ↓
工厂产生真实运营数据
        ↓
数据反哺模型训练迭代
        ↓
更强的模型进一步优化工厂
        ↓
（循环加速）
```

## 与亚马逊飞轮的类比

| 亚马逊飞轮 | 物理AI飞轮 |
|------------|------------|
| 更低价格 → 更多客户 | 更好模型 → 更优工厂 |
| 更多客户 → 更多卖家 | 更多工厂 → 更多数据 |
| 更多卖家 → 更多选择 | 更多数据 → 更强模型 |
| 更多选择 → 更低价格 | 更强模型 → 更优工厂 |

## Prometheus的落地路径

[[project-prometheus|Project Prometheus]] 通过关联1000亿美元产业并购基金来实现飞轮启动：

1. 收购航空航天、芯片制造、国防等领域的工业企业
2. 将Prometheus的AI技术植入被收购企业
3. 被收购企业的运营数据接入模型进行持续训练
4. 更强的模型反过来优化更多工厂

## 与算力飞轮的对比

与 [[ai-infrastructure-flywheel|AI算力飞轮]]（算力→更智能模型→更好产品→更多营收→更多算力）不同，物理AI飞轮的核心资源不是算力而是**真实工业场景数据**，竞争壁垒来自对物理资产的掌控而非对GPU的掌控。
