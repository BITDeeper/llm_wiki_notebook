# AI Agent快时代

AI Agent 快时代指高速推理 API 使 AI Agent 体验出现质变的趋势。当推理速度达到 400 tokens/s 级别（如 [[glm-5-1-highspeed]]），Agent 的等待变少、反馈变密、任务推进更连续，人机协作从"一次性下单"变为"来回打磨"。

## 核心特征

- **等待变少**：Agent 响应速度接近实时，用户不再需要长时间等待
- **反馈变密**：高频反馈使迭代周期大幅缩短，类似与设计师坐在同一画布前调参
- **任务推进更连续**：Agent 任务链路不再因推理延迟而中断，执行更加流畅

## 体验质变

高速推理带来的不仅是速度提升，更是协作模式的根本转变：

1. **从"下单"到"打磨"**：用户角色从下达一次性指令变为与 AI 来回迭代
2. **从"异步"到"实时"**：模糊指令的实时修改成为可能（如"波纹再快一点""光晕偏暖"）
3. **新产品形态解锁**：此前因延迟而难以成立的产品形态变得可行（如游戏中实时改变世界状态）

## 与相关概念的关系

- **[[任务执行范式]]**：快时代强化了从单次对话到持续协作的范式转换
- **[[agentic-engineering]]**：高速推理使 Agent 深度参与上游研发工作成为可能
- **[[vibe-coding]]**：实时反馈进一步降低了氛围编程的体验门槛
- **[[产业深水区]]**：速度是应用闭环的关键指标之一

## 待解决的工程问题

文章指出快时代仍面临诸多工程挑战：稳定性、安全边界、状态一致性、成本和并发能力。
