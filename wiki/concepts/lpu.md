# LPU

[[LPU]] (Language Processing Unit，语言处理单元) 是一种专为 AI [[推理]] 场景设计的芯片架构，属于 [[ASIC]]（专用集成电路）。该架构由 [[Groq]] 团队提出并开发，旨在解决大语言模型（LLM）推理过程中的性能瓶颈。随着 [[英伟达]] 收购 [[Groq]] 并将该技术引入其核心产品线，[[LPU]] 已成为补齐推理短板的关键技术。

## 核心设计理念

与通用 [[GPU]] 不同，[[LPU]] 的设计哲学是“为推理而生”，针对大模型推理中串行、流式的 Token 生成过程进行了深度优化。

- **解决数据搬运瓶颈**：[[LPU]] 的核心原理在于解决 [[GPU]] 在推理阶段面临的 [[数据搬运瓶颈]]。它采用片上存储权重的流式架构，通过将数据存储在芯片内部（主要采用 [[SRAM]] 架构），避免了传统方案中计算核心与内存分离导致的频繁数据搬运。
- **确定性性能**：实现了极致的低延迟和确定性性能，保证输出时间的稳定性。这对于金融交易、自动驾驶等对延迟敏感的场景至关重要。
- **高能效**：去除了 GPU 中为图形渲染和通用计算设计的冗余电路，通过软件定义的硬件流水线，降低推理能耗并消除推理过程中的排队和等待时间。

## 与 GPU 的架构对比

| 特性 | [[GPU]] | [[LPU]] |
| :--- | :--- | :--- |
| **核心优势** | 通用性强，适合 [[训练]] 和高吞吐量任务 | 专为 [[推理]] 优化，响应速度极快 |
| **内存类型** | 依赖外部 [[HBM]] (高带宽内存) | 采用高密度片上 [[SRAM]] |
| **数据路径** | 计算核心与内存分离，需频繁搬运 | 数据紧贴算力，路径极短 |
| **性能表现** | 擅长大规模并行计算，但推理 decode 阶段受限于数据移动延迟 | 算力利用率高，延迟极低；理论最高速度可比传统 [[GPU]] 快 100 倍 |
| **适用场景** | 大规模模型训练、批处理任务（吞吐量优先） | [[推理时代]] 的实时交互、[[Agent]] 应用（延迟优先） |

## 代表厂商与行业地位

- **[[Groq]]**：[[LPU]] 概念的主要倡导者，以其极致的推理速度闻名。随着 [[英伟达]] 收购 [[Groq]]，[[LPU]] 技术及相关团队被纳入 [[英伟达]] 的技术版图，成为其补齐推理短板的关键一环。
- **寒序科技**：中国国内的追随者与创新者，通过引入 [[MRAM+SRAM混合架构]] 解决了传统 [[LPU]] 容量不足的问题。

## 行业意义

[[LPU]] 的出现挑战了 GPU 在推理市场的垄断地位。随着 AI 应用从训练转向大规模部署，推理成本和效率成为关键瓶颈。

[[英伟达]] 首次在核心产品线中采用外部 [[LPU]] 架构，标志着 AI 算力市场从“训练优先”向“[[推理优先]]”的范式转移。[[LPU]] 代表了 ASIC（专用集成电路）路线对通用架构的一次有力反击。
