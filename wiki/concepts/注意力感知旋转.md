# 注意力感知旋转

**注意力感知旋转**（Attention-Aware Rotation）是 [[oscar-kv-quantization|oscar]] 提出的核心创新机制，突破了传统 KV Cache 量化中"向量压缩"的局限，将优化目标从"重建原始 K/V 向量"重新定义为**保护注意力机制质量**。

## 核心思想

传统 Hadamard 旋转能把 [[outlier-channel问题]] 中的 outlier 摊平，但它不知道模型在 attention 里真正读取哪些方向。注意力感知旋转不再单纯追求 K/V 向量的重建精度，而是围绕 attention 真正会使用的方向来做旋转、裁剪和分组，让量化误差尽量避开模型最敏感的部分。

## 技术原理

注意力感知旋转利用 attention 的计算结构来指导旋转：

### Key 旋转

量化误差通过 QKᵀ 进入 attention logits，因此使用 **query covariance（QᵀQ）** 来决定 Key 的旋转方向。

### Value 旋转

误差先被 attention score 加权，再进入 attention 输出，因此使用 **score-weighted value covariance（VᵀSᵀSV）** 来决定 Value 的旋转方向。

### 旋转矩阵构造

最终旋转矩阵由三部分组成：

**R = U · Hadamard · bit-reversal**

- **U**：对齐 attention 相关方向（核心创新，通过离线校准从少量样本中估计 attention-aware covariance）
- **Hadamard**：摊平 outlier 能量（继承自传统方法）
- **bit-reversal**：让 INT2 分组更均衡，避免某个 group 被少数通道支配（新增优化）

## 与传统方法的区别

| 维度 | 传统 Hadamard 旋转 | 注意力感知旋转 |
|------|-------------------|---------------|
| 优化目标 | 向量重建误差 | 注意力机制质量 |
| 旋转依据 | 统计分布 | Query/Score 协方差 |
| 校准方式 | 无需校准 | 离线校准（少量样本） |
| 推理开销 | 无额外开销 | 固定参数复用 |

## 工作流程

1. **离线校准**：用少量样本估计每一层、每一个 head 的协方差矩阵
2. **参数生成**：生成固定的旋转矩阵和 clipping 阈值
3. **在线推理**：参数直接复用，无需任务级微调或在线学习

## 效果与意义

注意力感知旋转使 OSCAR 能够将量化误差压到 attention 不敏感的方向上，从而在约 2.28 BPE 的极端压缩下仍保持接近 BF16 的推理质量。这一方法不仅在短评测中有效，也能抵抗超长历史中 KV 误差的累积（128K RULER-NIAH 测试验证）。

注意力感知旋转重新定义了低比特 KV Cache 的优化目标：**压缩不是目的，让模型在压缩后仍然能正确使用注意力机制，才是目的**。这一理念对长上下文 Agent 场景尤其重要，因为 Agent 往往包含很长的系统提示、工具说明和历史对话，对注意力机制的准确性要求极高。
