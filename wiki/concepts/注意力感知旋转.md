# 注意力感知旋转

**注意力感知旋转**（Attention-Aware Rotation）是 [[oscar-kv-quantization]] 的核心创新思想。其关键洞察是：将旋转目标从"重建原始 K/V 向量"改为"保留 attention 消费 KV 的方式"。

## 核心原理

传统 Hadamard 旋转能把 [[outlier-channel问题]] 中的 outlier 摊平，但它不知道模型在 attention 里真正读取哪些方向。注意力感知旋转利用 attention 的计算结构来指导旋转：

- **Key 旋转**：量化误差会进入 attention logits（QKᵀ），因此使用 **query covariance**（QᵀQ）构造 key 的旋转目标。
- **Value 旋转**：误差经过注意力权重进入输出，因此使用 **score-weighted value covariance**（VᵀSᵀSV）构造 value 的旋转目标。

## 旋转矩阵构造

最终旋转矩阵写作 **R = U・Hadamard・bit-reversal**：

- **U**：对准 attention 相关方向（通过离线校准从少量样本中估计 attention-aware covariance）
- **Hadamard**：分散 outlier
- **Bit-reversal**：平衡 INT2 分组，避免某个 group 被少数通道支配

## 离线校准

在离线阶段，OSCAR 从少量校准样本中估计 attention-aware covariance，为每层、每个 head 生成固定旋转矩阵和 clipping 阈值。这一过程只需执行一次，生成的旋转矩阵可在推理时直接使用。

## 效果

注意力感知旋转使 OSCAR 能够将量化误差压到 attention 不敏感的方向上，从而在约 2.28 BPE 的极端压缩下仍保持接近 BF16 的推理质量。这一方法不仅在短评测中有效，也能抵抗超长历史中 KV 误差的累积（128K RULER-NIAH 测试验证）。
