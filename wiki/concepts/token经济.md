# Token 经济

Token 经济是一种由 AI 生成 Token（文本、代码、动作单元）作为核心价值产出的经济形态。这一概念由 [[英伟达]] CEO [[黄仁勋]] 在 2026 财年财报电话会议中重点提出。它标志着 AI 产业链从"卖卡"演化为"卖 token"的趋势——[[英伟达]]作为最上游的"token 工厂"，其整个商业帝国的地基就建立在 token 的持续消耗之上。

## 核心逻辑

黄仁勋认为：

1.  **计算即收入**：在 AI 时代，计算能力直接转化为货币收入。
2.  **Token 是价值载体**：没有计算就无法产生 Token，没有 Token 就无法产生收入。
3.  **推理即消耗**：随着 [[agentic-ai]] 的兴起，AI 系统为了完成任务（如 [[claude-code]] 编程），会消耗海量的推理 Token。

这一逻辑可以用一条正反馈链来概括：

```
头部模型公司跑得越快 → 用户越多、调用量越大 → token消耗越快 → GPU需求越旺 → 英伟达财报和股价越稳
```

[[openai]]、[[anthropic]]、xAI 这些模型公司每生成一个 token，背后烧的都是英伟达的算力。英伟达本质上就是这场 token 革命里最上游的"token 工厂"。

## 行业影响

这一概念解释了为何 [[英伟达]] 数据中心业务（主要提供推理算力）呈现指数级增长。它也揭示了 AI 商业模式从"固定订阅制"向"按量计费/Token 计费"转型的必然性（参见 [[ai-subscription-crisis]]）。

## 驱动因素

-   **Agentic AI**：能够自主执行复杂任务的 AI 智能体，需要持续的推理计算来规划、思考和行动。
-   **成本下降**：新一代架构（如 [[rubin]]）承诺将推理成本降低 10 倍，将进一步刺激 Token 的生产和消费。

## 与厂商融资的关系

如果说 [[厂商融资]] 是英伟达投资的表层逻辑（绑定客户），Token 经济则是更深层的逻辑——投资模型公司不只是绑定客户，更是在加固自己整个商业模式的地基。只要 OpenAI 们持续繁荣，token 的水龙头就会一直开着，而水龙头连接的那根管道，恰恰握在英伟达手里。

## 与相关概念的关联

本概念与 [[token作为生产资料]] 高度互补但角度不同：

-   **[[token作为生产资料]]**：从下游使用视角，关注 Token 作为生产要素和计价单位。
-   **Token 经济**：从上游供应商视角，关注 Token 消耗如何驱动英伟达的商业模式。
