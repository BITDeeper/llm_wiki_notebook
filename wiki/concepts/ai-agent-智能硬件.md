# AI Agent 智能硬件

AI Agent 智能硬件是指将 [[ai-agent|AI Agent]]（具备自主决策、规划能力的智能体）技术集成到物理硬件设备中，以提供更主动、个性化服务的硬件产品。

## 核心特征

- **主动服务**：不同于传统的被动响应式智能硬件，AI Agent 硬件能根据环境或用户状态主动发起交互或任务。
- **场景落地**：强调 AI 技术在具体物理场景（如家庭、车载、个人护理）中的实际应用，而非单纯的云端对话。
- **软硬结合**：依赖硬件传感器收集数据，结合云端或本地大模型进行决策。

## 行业背景

随着大模型技术的发展，市场关注点从单纯的“聊天对话”转向“场景落地”。资本（如 [[红杉中国]]、[[蚂蚁集团]]）开始看好 AI Agent 与硬件结合带来的新入口机会。

## 案例

- [[薇光点亮]]：由 [[宋紫薇]] 创立，专注于将 AI Agent 技术应用于个人护理硬件（如 [[ai化妆镜]]、[[ai护肤]] 设备）。
