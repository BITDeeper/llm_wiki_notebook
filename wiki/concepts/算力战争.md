# 算力战争

算力战争指 AI 领域的竞争演变为对计算资源（硅和电）的争夺，规模直接决定了智能水平的上限。

## 核心逻辑
- **算力即真理**：每一代基础设施的升级，都让 Token 更聪明，成本更低。
- **良性循环**：更多算力 -> 更强智能 -> 更好产品 -> 更多现金流 -> 更多算力重投入。

## 战略举措
- **多供应商策略**：OpenAI 构建了涵盖英伟达、AMD、博通（自研芯片）、AWS、微软、谷歌云等的基础设施组合，以避免单一依赖。
- **自研芯片**：OpenAI 确认与博通合作研发自研芯片，试图掌握底层硬件命运。
- **数据中心竞赛**：[[Anthropic]] 依靠 AWS 位于 Madison 与 New Carlisle 的数据中心获得大规模算力支持，以实现 Opus 4.5 的突破。

## 行业格局
- **从算法到资源**：竞争焦点从单纯的算法创新转向对 GPU、数据中心和能源的掌控。
- **资本门槛**：高昂的算力成本（如 OpenAI 的 1220 亿美元融资）设立了极高的行业壁垒。
