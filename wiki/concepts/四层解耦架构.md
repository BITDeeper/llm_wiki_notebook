# 四层解耦架构

**四层解耦架构**是 [[vantage]] 项目采用的核心系统设计模式。它将复杂的评估流程拆分为四个独立运作的模块，借鉴了软件工程中的微服务思路，实现了系统的高内聚、低耦合和可扩展性。

## 架构层级
1.  **场景生成**
    -   **功能**：根据输入的软技能维度（如“冲突解决”）和评估量表，自动倒推并生成一个能有效区分表现好坏的具体情境。
    -   **作用**：确保测试场景具有针对性和区分度。

2.  **角色扮演**
    -   **功能**：多个 AI Agent 进入场景，与被测试者进行实时对话。
    -   **关键点**：引入专门制造压力的 Agent（如“反派”角色），动态调整施压策略，以激发被测试者的真实反应。

3.  **行为提取**
    -   **功能**：对话结束后，独立的 Agent 逐回合分析对话记录。
    -   **原则**：只提取客观事实（如“用户打断了对方”、“用户提出了折中方案”），不做主观评价。这一步将“事实”与“判断”严格分离。

4.  **评分**
    -   **功能**：评分 Agent 拿着评估量表和上一步提取的行为证据，逐条对照打分。
    -   **要求**：每个分数都必须指向具体的对话片段作为依据，禁止凭印象给分。

## 设计优势
-   **模块化与可扩展性**：场景、角色、评分标准都可以像插拔组件一样替换。例如，今天测“冲突解决”，明天只需更换量表和场景即可测“谈判能力”。
-   **专业化分工**：生成场景的 AI 不需要懂评分，制造压力的 AI 不需要懂分析，各司其职，优化了单一模型的职责范围。
-   **可解释性**：通过行为提取层，评分结果不再是黑盒，而是有据可查的“证据链”。
