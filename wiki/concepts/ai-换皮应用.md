# AI-换皮应用

AI-换皮应用是指利用 AI 工具批量生成仅做表面修改（如 UI 换肤、微调文案）但核心逻辑完全相同的低质应用。这种现象是 [[Vibe Coding]] 降低开发门槛后的负面产物。

## 现象描述
- **批量生产**：开发者利用 AI 模板快速生成大量同质化应用，试图通过数量优势覆盖长尾关键词。
- **缺乏创新**：应用内核往往是通用的 API 套壳，没有独特的技术或价值。

## 平台治理
面对 App Store 提交量的暴涨（60%），苹果已开始严厉打击此类应用：
- **审核指南 4.1(c)**：严禁试图通过 AI 批量生成“换皮应用”的山寨行为。
- **审核指南 5.1.2(i)**：强制要求所有涉及第三方 AI（如 OpenAI API）的数据传输必须获得用户显式授权。

## 后果
凡是未明确披露数据流向，或仅靠 API 套壳的僵尸应用，都将被视为违规并被下架。这标志着 AI 应用“野蛮生长”阶段的结束。
