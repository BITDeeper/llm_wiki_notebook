# Mobile Agent（移动端智能体）

Mobile Agent（移动端智能体）是指能够在智能手机等移动设备上自主执行任务的 AI 系统。其核心能力包括：
- **屏幕理解**：看懂复杂的 GUI 界面。
- **动作执行**：精确点击按钮、滑动、输入文本。
- **长序任务规划**：跨多个 App 完成连贯的复杂指令。

## 发展瓶颈：环境而非模型

当前 Mobile Agent 发展的限制不仅在于模型推理能力，更在于缺乏高质量的训练环境。真实 App 存在状态难以重置、结果难以验证以及充满不稳定噪声（如弹窗、验证码）的问题。这构成了 [[具身智能数据困境]] 在软件操作领域的具体表现。

突破这一瓶颈的关键在于 [[环境-scaling|环境规模化]]，即系统性地构建接近真实分布且可交互、可验证的模拟环境（如 [[phoneworld|PhoneWorld]]）。
