# 工具检索

工具检索是 Tool-Use（工具使用）系统中的关键前置步骤。随着 API 数量扩展至数千甚至上万，智能体必须先在庞大的工具集合中找到合适的工具，随后才能完成调用与执行。

## 核心挑战

工具检索面临的主要挑战是**语义鸿沟**（Semantic Gap）：
- **用户查询**：通常以自然语言表达具体任务需求。
- **工具文档**：多以简略的技术描述或函数说明呈现。
这种表达差异导致即使强大的检索模型也难以稳定匹配到正确工具。

## 解决范式

根据 [[eit-nlp]] 团队的研究（ICLR 2026），解决工具检索瓶颈的有效路径是“先优化文档，再训练模型”：
1. **文档结构化扩展**：通过 LLM 将零散文档补充为包含 `function`、`tags`、`when_to_use` 等字段的标准化结构。
2. **两阶段检索**：
   - **召回**：使用 [[tool-embed]] 等嵌入模型进行快速筛选。
   - **精排**：使用 [[tool-rank]] 等重排序模型进行精准匹配。

## 在 Agent 系统中的地位

工具检索是 [[任务执行范式]] 和 [[runtime-agent-os]] 的基础能力。如果智能体无法精准找到 API，再优秀的架构设计也无法发挥作用。
