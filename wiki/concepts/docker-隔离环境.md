# Docker 隔离环境

[[Docker 隔离环境]] 是指利用 Docker 容器技术创建的独立沙盒运行环境，常用于保障 AI 智能体在进行高风险操作时的系统安全。

## 在 AI Agent 中的应用

随着 [[Claude Code]] 和 [[OpenClaw]] 等工具引入 [[GUI 操控]] 能力，AI 获得了对宿主计算机的直接控制权（如读写文件、执行命令）。这带来了显著的安全隐患：
- **误操作风险**：AI 可能因幻觉误解指令，删除重要文件或发送错误邮件。
- **不可逆破坏**：某些系统级操作可能导致宿主机崩溃或数据丢失。

## 解决方案
官方通常推荐在 Docker 容器内运行这些 Agent 工具。容器提供了以下保护：
- **文件系统隔离**：Agent 只能访问容器内的挂载目录，无法直接触碰宿主机核心文件。
- **网络隔离**：可限制容器的网络访问权限，防止数据外泄或恶意连接。
- **进程隔离**：Agent 的崩溃或异常进程不会影响宿主机其他任务的运行。

## 实践意义
Docker 隔离被视为在享受 AI 强大自动化能力的同时，控制“数字风险”的必要工程手段。
