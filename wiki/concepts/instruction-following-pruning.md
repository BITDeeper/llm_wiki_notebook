# Instruction-Following Pruning

苹果提出的**端侧稀疏模型推理策略**，用于解决手机内存装不下200亿参数大模型的工程难题。应用于[[afm-3|AFM 3 Core Advanced]]（20B参数稀疏模型）。

## 工作原理

1. **完整模型存储**：200亿参数的完整稀疏模型存在手机闪存（NAND）中
2. **路由模块决策**：收到推理请求后，轻量级路由模块先分析任务，选出需要激活的专家
3. **按需加载**：仅将需要激活的专家权重从闪存加载到DRAM
4. **稀疏执行**：每次实际调动的参数量在10亿到40亿之间（5%-20%），取决于任务复杂度

## 关键创新

传统大模型要求所有权重常驻DRAM，这对手机等终端设备是不可承受的内存压力。Instruction-Following Pruning将"全量常驻"改为"按需调度"，利用稀疏模型中专家不全部激活的特性，将存储压力转移到闪存（容量大、便宜），仅将活跃参数放入DRAM（速度快、容量小）。

## 与其他稀疏推理方法的区别

不同于训练后剪枝（Pruning）丢弃参数，该方法保留完整模型，推理时动态选择激活哪些部分，是一种**推理时稀疏调度**策略。
