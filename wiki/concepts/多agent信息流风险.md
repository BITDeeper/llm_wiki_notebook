# 多Agent信息流风险

多 Agent 信息流风险是指在多 agent 系统中，消息路由虽然正确（消息会发给正确的 agent），但消息内容可能携带超量上下文，导致敏感信息在 agent 间泄露的安全隐患。

## 量化数据

[[harnessaudit]] 评测揭示了单 agent 到多 agent 切换时安全性的急剧下降：

| 指标 | 单 Agent | 多 Agent |
|------|---------|---------|
| 工具合规性 | >0.85 | 0.64 |
| 资源合规性 | >0.85 | 0.63 |
| 信息流合规性 | 不适用 | 0.58 |

## 典型故障模式

1. **上下文过度共享** — 子 agent 收到超过其任务所需的上下文
2. **敏感信息残留** — 中间组件在任务结束后继续保留敏感信息
3. **摘要泄露原始数据** — agent 间传递的摘要可能泄露背后的原始数据

## 领域差异

不同领域的信息流风险严重程度不同：日常生活和电子商务任务的失败主要集中在信息流方面。
