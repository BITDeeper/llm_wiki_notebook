# 三无硬件

“三无硬件”是指为了适应 AI Agent 时代而出现的一种新型硬件设计理念，特指**没有键盘、没有鼠标、没有屏幕**的计算设备。这一概念主要由 [[吾云创新]] 在其 [[agent-computer]] 产品中提出。

## 设计逻辑

### 去除 GUI 的必要性
传统个人电脑的设计核心是 GUI（图形用户界面），键盘、鼠标和屏幕是人类与机器交互的桥梁。然而，在 [[agent-as-primary-user]] 的理念下，Agent 成为设备的实际操作者：
- Agent 不需要屏幕来显示图像，它直接处理数据。
- Agent 不需要键盘鼠标来输入指令，它通过 API 或接口接收任务。
- 保留这些外设不仅增加了成本，还占用了物理空间和接口资源。

### 交互方式的转变
“三无硬件”标志着交互范式的转移：
- **旧范式**：人 -> (键盘/鼠标) -> 电脑 -> (屏幕) -> 人。
- **新范式**：人 -> (指令/IM) -> Agent -> (后台运行) -> Agent -> (结果推送) -> 人。

## 优势
1. **成本优化**：去除了昂贵的显示和输入组件，可能降低硬件成本。
2. **形态灵活**：设备可以被放置在隐蔽位置（如柜子里），无需像传统 PC 一样放在桌面上供人操作。
3. **专注后台**：设计重点完全集中在算力、存储和网络连接上，优化 Agent 的运行效率。

## 潜在挑战
1. **调试困难**：对于“最白的小白”用户，如果设备出现网络故障或启动问题，没有屏幕进行故障排查会极大增加维护难度。
2. **信任建立**：完全不可见的运行过程可能增加用户对“设备是否在工作”或“数据是否安全”的焦虑。
3. **配置依赖**：初次配置（如 Wi-Fi 连接）可能仍需依赖手机 App 或临时屏幕辅助。

## 应用场景
“三无硬件”主要适用于以下场景：
- **家庭/办公室数据中心**：作为数据中枢和 Agent 服务器运行。
- **边缘计算节点**：为特定场景（如智能家居、安防）提供本地算力。
- **个人助理基站**：专门运行个人助理 Agent，处理日程、邮件和文档。
