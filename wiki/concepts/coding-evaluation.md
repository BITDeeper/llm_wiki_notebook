# Coding Evaluation

[[Coding Evaluation]] 是指针对大语言模型在代码生成、调试、理解及软件工程任务上的专项评测体系。

## 应用案例
在 [[智谱]] 发布 [[GLM-5.1]] 时，官方引用了 Coding Evaluation 的评测结果，指出该模型相比上一代提升了近 10 分，与 [[Claude Opus 4.6]] 的分差仅为 2.6 分。这一数据被用作证明其编程能力已达到国际顶尖水平的关键论据。

## 局限性
作为单一维度的评测指标，Coding Evaluation 的具体细则（如测试集构成、评分标准）在公开报道中往往不详，其公信力有时依赖于第三方验证或广泛的社区实测。
