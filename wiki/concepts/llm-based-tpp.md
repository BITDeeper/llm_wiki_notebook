# 基于大语言模型的时序点过程

**基于大语言模型的时序点过程**（LLM-based TPP）是将大语言模型引入[[时序点过程]]（TPP）事件流建模的新兴范式。它标志着 TPP 正从单纯处理"时间+类型"的二维数据，演进为处理带有自然语言描述、外部知识和多模态上下文的复杂事件流。

## 两大分类

根据技术路线，LLM-based TPP 可分为两类：

1. **借鉴 LLM 思想（LLM-inspired TPP）**：不直接替换 TPP 主干，而是借鉴 Prompt Learning 等思想增强现有神经 TPP。例如 PromptTPP 使用可学习的时间提示适应数据分布变化；LAMP 引入溯因推理能力生成可能原因。
2. **直接用 LLM 整合**：将 LLM 作为事件序列的核心表示模型。例如 TPP-LLM 将事件转化为文本描述并注入时间信息；Language-TPP 将连续时间间隔编码为 byte-level tokens，让时间和语言进入同一序列由 LLM 统一建模。

## 领域边界争议

LLM 的引入使得事件问答、多模态推理等任务被纳入 TPP 版图，但也引发了"什么是严格意义上的 TPP 问题"的学术争议。此外，尽管 LLM-based TPP 在语义理解任务上表现出色，但在纯时间预测基准上的结构性优势尚不明确。
