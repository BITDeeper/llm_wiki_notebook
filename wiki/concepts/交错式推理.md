# 交错式推理

交错式推理（Interleaved Reasoning）是[[cx-mind]]的核心架构设计，指模型在推理时先围绕影像证据进行观察和推断，输出阶段性答案，再继续鉴别、定位或生成报告，形成"思考-回答"交替的输出范式。

## 设计原理

传统医学视觉模型遵循one-shot judgment路线：输入影像，输出标签或报告。即便引入CoT（思维链），也常常变成一整段难以验证的长文本，无法判断哪些中间步骤真正来自影像，哪些只是语言模型生成的"医学叙事"。

交错式推理将输出拆解为**think-answer交错单元**：

- **封闭式问题**：逐项评估候选答案，给出保留或排除的证据
- **开放式问题**：先提出可能疾病，再围绕每种疾病进行证据核验，最后形成诊断结论

## 与真实阅片的对应

这种输出方式模拟了真实阅片流程：

1. **观察征象** → 影像证据提取
2. **形成假设** → 候选诊断提出
3. **进行鉴别** → 证据核验与排除
4. **写出结论** → 诊断结论输出

## 关键创新

交错式推理的突破性不在于"让模型解释自己"，而在于让解释成为训练和奖励的一部分。可解释性不再是事后附加的说明，而是模型学习诊断能力时必须满足的结构约束。通过[[curl-vpr]]算法，每一步推理都会被真实放射科报告核查。
