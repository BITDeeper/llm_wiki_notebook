# 对抗式审查

**对抗式审查（Adversarial Review）** 是 [[anthropic|Anthropic]] 在 [[智能体分析栈]] 第四层"验证"中采用的机制，通过让模型反复质疑和检验自身假设来提升分析准确率。

## 效果与代价

| 指标 | 变化 |
|------|------|
| 准确率 | +6% |
| Token 消耗 | +32% |
| 延迟 | +72% |

## 核心意义

对抗式审查展示了准确率**最后几个百分点需要"真金白银"去换**的成本权衡。它是 [[token作为生产资料]] 的一个具体案例：token 不再只是计价单位，而是需要理性配置的生产资源。

## 与其他概念的关系

- 是 [[vlm质检闭环]] 在数据分析领域的具体实现形式。
- 体现了 [[智能体分析栈]] 中"验证"层的核心功能。
- 引出一个开放问题：32% 的 token 增量在规模化部署时的经济可行性如何？在哪些业务场景下，6% 的准确率提升值得付出这个代价？
