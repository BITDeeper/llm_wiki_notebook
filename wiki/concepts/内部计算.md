# 内部计算

[[内部计算]]（Internal Computation）是指大语言模型（LLM）不依赖外部工具调用（如 Python 解释器或 API），而是通过模型自身的权重和前向传播过程，直接在神经网络内部执行算法指令的能力。

## 核心特征
- **全内化执行**：计算过程完全发生在模型的推理链路中，不需要中断生成去请求外部服务。
- **确定性**：相比于概率性的文本生成，内部计算旨在提供类似传统计算机的确定性结果（如 100% 准确率的数独求解）。
- **无损嵌入**：将完整的计算机逻辑（如 [[WebAssembly (WASM)]] 解释器）硬编码进模型权重中，而不损失通用性。

## 技术实现
根据 [[Percepta]] 团队的研究，实现内部计算的关键在于：
1. **指令映射**：将高级语言（如 C 代码）转化为模型可理解的 Token 序列（如 WASM 指令）。
2. **状态模拟**：模型通过自回归方式生成代表虚拟机状态的轨迹，包括指令指针、内存、栈操作等。
3. **注意力机制优化**：利用 [[快速解码路径]] 解决长序列计算中的性能瓶颈。

## 与外部工具调用的对比
| 维度 | 内部计算 | 外部工具调用 |
| :--- | :--- | :--- |
| **延迟** | 低（无网络/进程开销） | 高（需启动外部进程） |
| **连贯性** | 不打断推理链 | 可能打断思维链 |
| **安全性** | 内部沙箱，风险可控 | 依赖外部环境，风险较高 |
| **灵活性** | 受限于嵌入的指令集 | 理论上无限（可运行任意代码） |

## 意义
内部计算被视为解决 LLM “终极缺陷”（无法精确算术）的根本性路径。它标志着 LLM 从单纯的“概率预测机”向“混合计算系统”的演进，为 [[ai-for-science]]、物理模拟等领域提供了新的技术可能性。
