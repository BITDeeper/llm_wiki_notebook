# 从"工具扩展"到"经验进化"

"从工具扩展到经验进化"是对 Agent 能力增长范式演变的概括，由 [[evolver-agent|EvolveR]] 论文（ICML 2026）明确提出，定位为"后 OpenClaw/Claude Code 时代"的 Agent 发展方向。

## 范式对比

| 维度 | 工具扩展范式 | 经验进化范式 |
|------|------------|------------|
| Skill 来源 | 人类编写、社区贡献 | Agent 自身轨迹蒸馏 |
| 增长瓶颈 | 依赖人类工程师 | Agent 自主积累 |
| 质量保障 | 人工审核 | 动态评分与剪枝 |
| 策略匹配 | 可能不匹配 Agent | 天然匹配（认知对齐） |
| 代表系统 | [[openclaw]]、[[claude-code]] | [[evolver-agent|EvolveR]] |

## 演进逻辑

1. **2025 年主流：** Agent 学会了使用工具和调用 Skill（工具扩展阶段）。
2. **瓶颈暴露：** Skill 依赖人类编写，增长受限、质量参差、策略不匹配。
3. **2026 年新方向：** Agent 从自身成败中自主积累经验，实现"越干越会干"（经验进化阶段）。

## 与相关概念的关系

- **[[任务执行范式]]：** 经验进化是任务执行范式从"会用 Skill"到"会从经验中长出 Skill"的跃迁。
- **[[自进化架构]]：** 经验进化是自进化架构在 Skill 层面的具体体现。
- **[[递归式自我改进]]：** 经验进化的闭环（学习→改进→生成更好经验）是递归式自我改进的实例。
