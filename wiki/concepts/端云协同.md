# 端云协同

[[端云协同]]（Edge-Cloud Collaboration）是一种结合端侧隐私安全与云端强大算力的混合计算架构。它旨在解决单一依赖本地算力导致模型能力受限，或单一依赖云端算力导致数据隐私泄露及成本高昂的矛盾。在具身智能领域，端云协同更是释放大模型潜力的关键架构范式——将云侧大模型/算力与端侧实时执行通过低延迟链路协同工作。

## 背景与动机

在 AI Agent 和具身智能的实际应用中，开发者常面临"两头堵"的困境：

- **纯云端模式**：存在数据隐私泄露风险（"不敢用"），且频繁调用顶级 API 导致成本高昂（"用不起"）。
- **纯本地模式**：受限于端侧硬件算力和模型参数规模，难以处理复杂推理任务（"用不好"）。端侧机器人本体必须保持轻量、稳定、低功耗和实时安全，很难独立承载大规模基础模型的推理需求；而机器人要获得更强的感知、推理和动作生成能力，又必须调用更大规模的基础模型和更充足的训练推理资源。

端云协同试图打破这种二元对立，通过智能路由机制，让端侧和云侧各尽其能。

## 核心逻辑

在端云协同架构中，计算任务在终端设备（端）与云端服务器（云）之间进行智能分配。其核心原则是：

- **端侧**：负责敏感数据的预处理、感知及行动等隐私敏感任务，确保原始数据不离开本地域。在具身智能场景中，端侧还承担传感器同步、运动控制、安全执行、接管恢复和本地状态管理。
- **云端**：负责复杂的计算推理、理解及规划等需要大规模算力的任务，包括分布式训练与推理优化、数据湖仓管理、高并发仿真评估。
- **端云协同层**：[[低延迟图传]]、控制信令与状态同步、远程接管、数据回流。

这种模式既利用了云端大模型的强大能力，又确保了原始隐私数据的安全。

## 实现方式

### 三段式隐私脱敏

典型的实现方式采用 [[三段式隐私脱敏]] 流程：

1. **本地脱敏**：在本地提取特征并替换敏感信息。
2. **云端处理**：将脱敏数据发送至云端进行推理。
3. **本地回填**：在本地将推理结果中的占位符还原。

### 智能路由

[[ClawXRouter]] 是端云协同理念的典型工程实现。它通过 [[三级隐私路由]] 和 [[性价比感知路由]]，在 [[PinchBench]] 测试中实现了成本降低 58% 且性能提升 6.3% 的效果。

### 关键技术

- **低延迟图传**：将端侧多路视觉以 GPU 直编直解方式传入云端显存。
- **Real-time Chunking**：将大规模模型生成的动作指令转化为可实时执行的动作序列。
- **Real2Sim 遥操作**：将真实机器人操作数据回流至仿真环境的闭环方法。
- **近网中继**：靠近云端推理服务的中继方案，减少公网绕行。

## 优势

- **隐私保护**：原始数据（如视频、语音、财务数据）无需上传至云端。
- **能力无损**：依然可以调用云端最先进的大模型进行复杂任务处理。
- **成本优化**：通过端侧处理部分任务，显著减少云端 API 调用的成本或带宽消耗。

## 挑战

- **同步延迟**：端云之间的数据传输可能增加响应延迟。
- **端侧算力要求**：本地仍需具备运行多模态大模型进行脱敏和回填的算力。
- **一致性保证**：需要确保脱敏和回填过程不会导致语义丢失或上下文错误。
- **网络依赖**：端云协同依赖网络连接，与强调本地运行的 [[本地推理]] 路线形成互补。端云协同适合需要大模型能力的复杂任务，本地推理适合对延迟和断网容错要求极高的场景。

## 实践案例

- **ClawXRouter**：在 AI Agent 场景中通过智能路由实现成本降低 58% 且性能提升 6.3%。
- **[[lios|LiOS]]**：端云协同在具身智能领域的完整实践，通过约 30ms 的图传延迟实现云端推理频率高于端侧 5090 的效果。

## 进化形态

随着 [[AI主机]] 等新硬件品类的引入，端云协同架构正在向 [[端-边-云一体]] 架构演进，以进一步优化成本和效率。
