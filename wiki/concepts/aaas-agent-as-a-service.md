# AaaS (Agent as a Service)

**AaaS (Agent as a Service)**，即**智能体即服务**，是一种新兴的商业模式，指通过云端直接提供具备自主执行能力的 AI 智能体，以替代传统的人力服务或软件操作过程。

## 背景与定义
随着 AI 从“聊天”转向“干活”，传统的 [[SaaS]]（软件即服务）模式开始显露出局限性。SaaS 卖的是**工具**，用户仍需雇佣人力来操作这些工具。而 AaaS 卖的是**结果**或**服务**，AI Agent 可以绕过 GUI（图形用户界面），直接通过 API 操作数据和逻辑来完成特定任务。

## 核心特征
1. **去界面化**：用户不再需要复杂的仪表盘或点击流程，只需通过自然语言下达指令。
2. **全栈自动化**：Agent 负责从理解意图、规划步骤到执行操作的全过程。
3. **按需/按结果计费**：商业模式可能从传统的订阅制转向按任务量或按效果付费。

## 市场影响
红杉资本在其博客《服务即新软件》中指出，价值超过 **1 万亿美元**的服务市场正面临被 AI Agent 颠覆的风险。
- **旧世界**：公司花 1 万美元买财务软件，再花 12 万美元请会计师操作。
- **新世界**：公司直接使用 AaaS，AI 替代了会计师的操作过程，软件成本直接覆盖了人力成本。

## 对 SaaS 的挑战
AaaS 的兴起引发了关于 [[SaaS 终结论]] 的讨论。那些仅靠“用户体验”、“界面设计”或“数据孤岛”作为护城河的中间层 SaaS 软件，面临被 Agent “管道化”的风险。未来的软件可能需要内嵌 Agent 能力，进化为具备自主执行能力的智能系统。

## 典型案例
- **Claude Managed Agents**：允许企业几天内部署一个能干活的数字员工，是 AaaS 模式的早期实践者。
- **Notion/Sentry**：传统 SaaS 通过接入 Claude，将软件升级为能自动执行任务的服务平台。
