# GitHub 假星产业链

GitHub 假星产业链是指围绕 GitHub Star 数量形成的规模化造假服务生态。这一产业链利用 GitHub 的推荐算法和 VC 对开源项目热度的依赖，通过出售虚假 Star 来牟利。

## 产业链结构

### 1. 上游：账号农场
- **养号**：专门注册并维护大量 GitHub 账号。
- **增值服务**：为账号添加 5 年的 commit 记录、Arctic Code Vault 贡献者徽章等，使其看起来像“资深开发者”。
- **售价**：一个高质量的“资深”账号售价可达 $5000。

### 2. 中游：刷星服务商
- **平台**：至少 12 个公开网站及 Fiverr 上的 24 个活跃卖家。
- **定价策略**：
  - **廉价版**（$0.03-0.10/颗）：使用批量注册的小号，速度快但风险高。
  - **高端版**（$0.80-0.90/颗）：使用养号多年的老账号，模拟真人行为，难以被风控识别。
- **技术支持**：提供 API 接口支持程序化批量购买。

### 3. 下游：买家（主要是初创公司）
- **动机**：通过 [[vc-融资隐形门槛]]，获取融资机会。
- **重灾区**：AI/LLM 项目是假星购买的主力军。

## 经济逻辑
- **低成本**：达到种子轮门槛（约 2850 星）仅需 $85-$285。
- **高回报**：种子轮融资中位数可达数百万美元。
- **ROI**：投入产出比极高，导致刷星成为“融资捷径”。

## 负面影响
1. **信号失灵**：Star 数量不再能客观反映项目质量，导致“劣币驱逐良币”。
2. **资源错配**：资金流向了擅长营销而非技术过硬的项目。
3. **生态污染**：GitHub Trending 榜单被注水项目占据，挤压了真实优质项目的曝光空间。

## 检测与防御
- **工具**：如 [[starscout]] 等工具可识别异常行为。
- **指标**：投资者和开发者开始转向 [[fork-to-star-比率]]、Commit 频率、Issue 质量等更难造假的“硬指标”。
