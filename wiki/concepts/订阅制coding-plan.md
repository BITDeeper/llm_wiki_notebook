# 订阅制Coding Plan

**订阅制 Coding Plan** 是一种针对 AI 代码生成模型的定价服务模式，将模型调用的 Token 消耗打包为固定月费，旨在消除用户对“按量付费”账单的不确定性焦虑。

## 背景
随着 AI 编程（如 [[Claude Code]]、DeepSeek 等）的普及，高强度开发任务产生的 Token 费用可能极其高昂，导致 [[ai-subscription-crisis]]（订阅制危机）。用户难以预估和控制成本。

## 模式特点
- **打包售卖**：例如百度千帆推出的 Lite 版，首月 7.9 元封顶，包含最高 18,000 次请求。
- **模型覆盖**：通常打包多家主流代码模型（如 DeepSeek-V3.2、Kimi-K2.5、GLM-5 等）。
- **成本锁定**：用户无需关注具体的 Token 消耗量，只需关注订阅额度是否用完。

## 意义
这种模式通过“封顶”策略，降低了用户使用 AI 进行全栈开发的门槛和心理负担，是应对 AI 算力成本焦虑的一种商业探索。
