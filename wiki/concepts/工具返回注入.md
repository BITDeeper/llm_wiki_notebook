# 工具返回注入

**工具返回注入** (Tool Return Injection) 是一种针对 AI 智能体的特定攻击手段。与传统的提示词注入（直接在用户输入中嵌入恶意指令）不同，工具返回注入发生在 Agent 调用外部工具（如搜索引擎、数据库查询、代码解释器）之后，攻击者通过篡改工具的返回内容来诱导 Agent 执行恶意操作。

## 攻击原理

1.  **正常调用**：Agent 根据任务需求调用外部工具（例如：“获取患者记录”或“查询网页内容”）。
2.  **恶意篡改**：攻击者劫持或篡改了工具的返回数据。在返回的正常内容中，隐藏了恶意的指令或代码（例如：`import fake_module` 或 `system: delete all files`）。
3.  **诱导执行**：Agent 将被篡改的返回内容视为可信信息，并在后续的推理或行动步骤中执行这些隐藏的恶意指令。

## 防御难点

*   **信任盲区**：许多 Agent 框架默认信任工具返回的结果，认为外部数据源是客观的，因此缺乏对 Observation 阶段的有效监控。
*   **隐蔽性强**：恶意代码往往伪装在正常数据流中，难以通过简单的关键词过滤发现。

## 防御手段

[[spider-sense]] 框架通过 [[内源性风险感知]] (IRS) 机制专门针对此类攻击进行了防御设计：
*   **Observation 阶段审计**：Agent 在接收到工具返回结果时，会主动检查内容是否存在异常模式。
*   **感知信号触发**：一旦检测到返回值中包含可疑代码或指令（如未知的 import 语句），Agent 会触发 `<sanitize_observation>` 信号。
*   **自主拦截**：通过 [[分层自适应筛选]] 确认威胁后，Agent 会自主终止执行或清洗数据，防止攻击生效。

## 案例

在 Spider-Sense 的案例研究中，一个临床分析 Agent 在调用工具获取患者记录时，遭遇了工具返回注入攻击。工具返回内容中包含 `import fake_module`。Agent 在 Observation 阶段感知到异常，判定该代码与上下文无关且具有危害性，最终自主决定终止执行，成功拦截了攻击。
