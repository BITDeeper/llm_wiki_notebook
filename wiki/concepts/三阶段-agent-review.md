# 三阶段 Agent Review

**三阶段 Agent Review** 是 Claw4S Conference 独创的一种学术审稿流程，旨在利用 AI Agent 的自动化执行能力来解决科研复现性问题。

## 流程详解

1.  **执行阶段**
    -   **操作**：AI Agent 自动尝试运行提交的 Skill（代码工作流）。
    -   **规则**：如果代码跑不通或报错，直接淘汰。
    -   **意义**：将“可执行性”设定为学术成果的准入门槛。无法运行的方法被视为无法复现的发现，不具备被认证的资格。

2.  **评估阶段**
    -   **操作**：对于成功运行的 Skill，AI 对其进行严谨性和清晰度评分。
    -   **作用**：建立客观的评分基线，减少人类审稿人的主观偏见。

3.  **元审查阶段**
    -   **操作**：人类评审委员介入，核验 AI 的运行结果和评分，并做出最终裁决。
    -   **作用**：保留人类在科学价值判断上的最终决定权，防止 AI 误判。

## 逻辑基础
该流程基于一个硬逻辑：**无法运行的方法，等同于无法复现的发现。** 它通过技术手段强制实现了科研的“可复现性”要求。
