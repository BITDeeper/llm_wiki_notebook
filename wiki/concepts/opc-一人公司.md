# OPC（一人公司）

OPC（One-Person Company，一人公司）是 Token 经济时代兴起的最小创新单元，正在重新定义个人能力与组织边界。它是指借助 AI 工具独立完成产品构建、分发和运营，实现单人运营并产生商业收入的公司形态。这是 [[超级个体]] 概念的商业化延伸，代表了 AI 时代创业和组织形态的根本性变革，被视为 Agent 时代的重要用户群体和未来组织形态。

## 定义演变

- 2025 年底被称为"超级个体"
- 2026 年成为行业热词，统称为 OPC

## 核心特征

1. **单人运营**：公司只有一名人类成员，其余「员工」均为 AI 智能体
2. **AI 驱动**：核心业务流程由 AI 工具完成，人类负责方向判断和决策
3. **商业可行**：能够产生真实商业收入，而非仅仅是技术实验
4. **一人+一台电脑+一群AI Agent**：写代码、做海报、跑投放、做客服、交付产品——办公室里只有一把椅子，但背后好像站着一支隐形团队
5. **一人操纵数百 Agent**：[[张昊阳]]预测未来一个人可能操纵数百个 Agent 大军，Agent 之间大部分协作不需要反复 Permission
6. **Build 变容易，分发变难**：[[冯雷]]指出 OPC 可以借助 AI 快速 Build 出产品，但很快会发现分发反而成为瓶颈，每个 OPC 都要做自媒体、懂内容创作和营销
7. **OPC、一人公司、内容创作者趋同**：这三类人正在逐渐变成同一类人
8. **外部化生产要素**：年轻人要学会成为外部化的生产要素，企业不再需要养那么多内部中台，而是把能力包给一堆 OPC

## 产业数据

根据 [[百度秒哒]]（[[秒哒]]）后台数据：

- OPC 占秒哒用户的 **16%**，是第一大用户群体
- 2025 年底（当时称"超级个体"）已成为第一大群体
- 近百万 [[超级个体]] 和 OPC 正在平台上成长，最高单人收入可达 1000 万
- **市场规模**：预计将突破 8000 亿元

## 典型案例

- **"黄啊码"**：通过秒哒做 AI 漫剧平台卖给工作室赚 12 万，开发企业站点赚 3 万，培训 3000 学员
- **上海企业**：4 位项目经理（非程序员）替代 12 人研发团队，通过秒哒完成软件交付，拿下 1000 万订单

## 与 Token 经济的关系

[[token作为生产资料|Token]] 正在从模型调用的计费单位，逐渐演化为"智能生产"的基础计量单位。在 OPC 模式下，Token 消耗量直接对应个人生产力产出，个人能力边界由可调度的 Token 量和 Agent 能力共同决定。

## 与 Agent 调度范式的关系

OPC 是 [[1-n-agent调度]] 范式的组织形态体现——当用户角色从对话者变为调度者，一人即可指挥"数字员工军团"。随着 [[智能体]] 系统进入真实工作流，个人借助 AI Agent 的能力边界被极大扩展，一个人通过调度多个 AI Agent，即可完成传统上需要整个团队才能完成的工作。

这也与 Peter Steinberger 的 3 人团队使用 100 个 [[codex]] 实例的实践（参见 [[openclaw-130万月度账单事件-202605]]）形成现实印证。

## 与企业 AI 落地的张力

OPC 代表的是"超级个体"的极致形态，但 [[刘毅]] 在 WorkBuddy 企业版发布会上提出了一个关键反转：个人起飞不等于组织起飞。"个人很爽，组织无感"——这正是 [[超级个体到超级团队]] 框架要解决的核心问题。

OPC 的"性感"叙事与企业 AI 落地的"组织协同"现实之间构成有趣的张力：一个人可以借助 [[openclaw]] 等工具撑起全流程，但在公司团队里，AI 协同却卡在资料散落、版本混乱、知识断层等老问题上。

## 行业意义

OPC 的兴起标志着软件生产的组织形态发生根本变化：从"团队协作"转向"个人+AI Agent 协作"。[[vibe-coding|Vibe Coding]] 抹平了从创意到实现 99% 的成本，使单人完成全栈软件开发成为可能。

## 产业影响

- 大厂未来会慢慢缩减甚至部分解体，社会上出现越来越多 OPC 公司
- 人和一个 Agent 交互可能放大一百倍产能；十个人和 Agent 交互可能只能放大几倍产能
- 人多不再一定是加分项，反而可能变成负资产
- 未来可能出现几十人到几百人团队撑起千亿市值的新"大厂"

## 与相关概念的关系

- 与 [[超级个体]]：超级个体描述能力状态，OPC 描述组织形态
- 与 [[超级个体到超级团队]]：从 OPC 的个体极致到组织协同的范式跃迁
- 与 [[vibe-coding]]：Vibe Coding 是 OPC 的核心技术手段，让非技术人员也能生产软件
- 与 [[tokenmaxxing]]：OPC 的运营高度依赖 Token 消耗，Token 成本是 OPC 商业模式的关键变量
- 与 [[企业ai三阶段演进]]：OPC 停留在第二阶段（Agent），尚未进入第三阶段（工作流）
- 与 [[数字员工]]：OPC 依赖的 AI 劳动力形态

## 行业动态

2026 年 [[智源大会]] 新增"Token 经济与 OPC"论坛，将视角从技术延伸至智能时代的生产关系变革。

## 开放问题

- OPC 模式的经济可行性尚无量化验证
- 分发能力是否成为 OPC 的核心瓶颈
- OPC 的法律和合规框架尚未建立
- OPC 的个体极致模式如何向组织协同扩展，仍缺乏成熟路径
