# 恶意 Skills

**恶意 Skills** 指在 AI 智能体生态中，伪装成正常功能插件，实则执行恶意行为的代码。随着 Agent 框架权限的扩大，恶意 Skills 成为主要的网络安全威胁之一。

## 攻击手段
恶意 Skills 通常利用用户对插件功能的信任，通过以下手段造成危害：
*   **伪装**：披着金融分析、自动更新、系统优化等合法功能的外衣。
*   **数据窃取**：在后台偷偷读取用户的私钥、配置文件（如 `MEMORY.md`）或聊天记录，并上传至攻击者控制的服务器。
*   **破坏性操作**：执行删除文件、破坏系统配置等操作。
*   **资源滥用**：利用用户的计算资源进行挖矿或攻击其他目标。

## 真实案例
根据 OpenClaw 官方披露，在其官方插件商店 ClawHub 中，曾发现同一攻击者上传了超过 300 个伪装极好的恶意 Skills。此外，还存在与官方界面一模一样的钓鱼镜像站，诱导用户下载恶意软件。

## 防御策略
应对恶意 Skills 需要多层防御体系：
1.  **静态审计**：使用如 [[Skill Vetter]] 等工具在安装前扫描代码逻辑。
2.  **运行时拦截**：通过 [[requireapproval]] 等机制，在执行高危操作时强制请求用户确认。
3.  **官方审核**：加强插件商店的代码审查机制（尽管 OpenClaw 的案例表明官方审核并非万无一失）。
4.  **用户教育**：提高用户安全意识，只安装可信来源的插件，并仔细检查权限请求。
