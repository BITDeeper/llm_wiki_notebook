# Flash 模型范式重构

Flash 模型从"旗舰平替"转变为"生产级 Agent 地基"的认知升级。

## 旧范式

长期以来，Flash 模型被视为旗舰模型的"青春版"——能力打折，图的是便宜和快。定位是替补和降级选项。

## 新范式

Agent 时代重写了这一定义。当 Agent 钻进企业流程、开发链路、知识工作和自动化系统，模型需要同时满足：够快、够稳、够便宜、够可靠、够容易被集成和部署。此时"又快、又省、又不掉链子"的 Flash 反而成了生产级 Agent 的地基。

## 核心论点

下一阶段的模型竞争，比的不再是峰值智能，而是**可规模化的高效智能**。最强的模型不一定是分数最高的那个，而是能被千万次调用、稳定执行任务、还不让用户心疼钱包的那个。

## 哲学框架

当 [[scaling-law|Scaling Law]] 不可避免地撞上 Economic Law（经济法则），谁能用九分之一的成本输出稳定、不掉链子的生产力，谁就掌握了让 Agent 真正爆发的密码。这开辟了智能竞赛的另一条战线：性价比前沿。
