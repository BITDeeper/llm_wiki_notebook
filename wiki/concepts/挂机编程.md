# 挂机编程

**挂机编程**（AFK Programming, Away From Keyboard Programming）是指人类在离开计算机（如睡觉、休息）期间，AI 智能体自动执行软件开发任务的生产力模式。

## 起源与背景
这一概念随着 [[ralph-loop]] 等自动化智能体工作流的流行而兴起。它标志着软件开发从“同步操作”（人机实时交互）转向“异步操作”（人类设定目标，AI 自主执行）。

## 典型场景
- **睡前部署**：开发者睡前配置好任务和循环逻辑，次日醒来发现代码已写好、测试已通过。
- **夜间构建**：利用夜间低谷时间或闲置算力进行自动化调试和功能迭代。

## 优势与挑战
### 优势
- **时间解放**：将人类的休息时间转化为生产力。
- **效率倍增**：实现了 7x24 小时的连续开发。

### 挑战
- **成本风险**：无人值守的循环可能因 Bug 产生巨额 API 费用（参见 [[ai-subscription-crisis]]）。
- **安全风险**：缺乏人工干预可能导致不可逆的代码破坏或资源泄露。
