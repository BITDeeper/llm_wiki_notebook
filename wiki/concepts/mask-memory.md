# Mask Memory（掩码记忆）

Mask Memory 是 [[x2sam]] 引入的时序记忆模块，用于解决视频分割中目标运动、遮挡、形变导致的分割不一致问题。

## 核心机制

Mask Memory 可以理解为模型的"短期记忆"：

1. **记录**：在处理视频时，记录前面若干帧中与目标相关的信息
2. **参考**：在处理当前帧时，参考历史帧中的目标信息
3. **追踪**：基于历史信息在视频中保持对同一目标的连续追踪

## 解决的问题

视频分割比图像分割更难，核心难点包括：

- **目标移动**：目标在帧间位置变化
- **遮挡**：目标被其他物体部分或完全遮挡
- **形变**：目标外观发生变化
- **短暂消失**：目标暂时离开画面后重新出现

如果模型只逐帧处理，容易出现前后不一致——这一帧分对了，下一帧可能就跟丢了。Mask Memory 通过引入时序参考信息，使模型输出更稳定的分割结果。

## 当前局限

- 记忆机制为**固定长度**，对于很长的视频或目标长时间被遮挡的情况仍有挑战
- 未来研究方向包括更适合长视频的可扩展记忆机制
