# Codex Memory

2026年4月16日随 [[codex|Codex]] 大更新上线的预览功能，可记住用户偏好、修正记录和项目专属知识，并在未来会话中自动调用。

## 功能特点

- 记住用户偏好和修正记录，跨会话保持一致性。
- 存储项目专属知识，减少重复说明。
- 在 [[codex自我蒸馏|自我蒸馏]] v2提示词中作为第二优先级数据源，用于发现跨会话的重复模式。

## 在Codex功能迭代中的位置

作为2026年3-5月Codex功能迭代链条的中间环节：
- 3月：[[codex-subagent|Subagent]] 上线
- 4月16日：Memory 上线
- 4月20日：[[codex-chronicle|Chronicle]] 上线

Memory的上线使得自我蒸馏提示词能够利用跨会话的历史模式，是从单次会话感知到持续记忆的关键一步。
