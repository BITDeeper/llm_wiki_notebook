# Software 3.0

[[andrej-karpathy|Andrej Karpathy]] 于2025年6月在YC AI Startup School演讲中提出的概念框架，与"Agent的十年"并列，成为当年讨论最广的AI演讲之一。

## 核心思想

Software 3.0是 [[software-2.0|Software 2.0]] 的演进，将提示词（Prompt）定义为新的编程层，强调自然语言作为编程接口的崛起，以及Agent作为自主执行实体的十年展望。
