# Apache 2.0 开源许可

Apache 2.0 是由开源促进会（OSI）认可的真开源许可证，允许任意使用、修改、分发和商业化，无授权费和竞业条款。

## 在 AI 行业的意义

### 与"伪开源"的对比

在今天的 AI 圈，"开源"一词已被严重稀释。许多 AI 公司放出权重却套着限制性商用条款：大企业不许拿去做商业用途，也不许用它训练竞品模型。下载可以，研究可以，真要赚钱则需回来买授权。这种做法实质是"开放一半，留一半"。

### Cohere 的许可证演进

[[cohere]] 的许可证变更轨迹清晰展示了从限制性走向完全开放的过程：

1. **Command R / Command R+**：CC-BY-NC 4.0（知识共享-非商业许可）——研究者和开发者能下载、评测，但严禁商用
2. **[[command-a-plus]]**：Apache 2.0——从独立开发者到世界 500 强企业，任何人都可以使用、修改、分发并商业化

### 对企业的影响

Apache 2.0 许可证意味着企业可以：
- 下载模型权重并用机密内部数据微调
- 部署在私有服务器甚至气隙网络中
- 不再被供应商的基础设施、定价变动或 API 稳定性绑住
- 彻底摆脱供应商锁定
