# 不公平基准测试

[[不公平基准测试]] 指在对比实验中，故意给竞品或 Baseline 设置不利条件（如使用未优化的实现、不匹配的硬件环境或错误的配置），以获得虚假的性能优势，从而误导读者的行为。

## 常见手段
- **硬件不对等**：例如，使用对手的 CPU 单核实现对比自己的 GPU 实现。
- **版本选择**：使用对手的旧版本或非官方实现的低效版本，而非官方发布的优化版本。
- **配置限制**：故意关闭对手代码的多线程或加速功能。

## 案例：TurboQuant vs RaBitQ
在 [[turboquant]] 争议中，谷歌团队被指控进行 [[不公平基准测试]]：
- 他们使用自己翻译的 Python 版本 [[rabitq]]（关闭多线程，单核 CPU 运行）与 [[turboquant]] 的 A100 GPU 实现进行对比。
- 实际上，[[rabitq]] 官方提供了高度优化的 C++ 实现，且谷歌作者在邮件中已知晓其速度。
- 这种对比导致论文得出了“TurboQuant 快数个数量级”的误导性结论。

## 后果
[[不公平基准测试]] 严重违背了学术诚信原则，会扭曲技术发展的真实图景，导致劣币驱逐良币。
