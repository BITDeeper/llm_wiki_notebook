# 可插拔 Skill 体系

[[可插拔-skill-体系]] 是一种模块化的 AI 智能体功能扩展机制，旨在解决传统 Agent 上下文臃肿和 Token 消耗过高的问题。该概念在 [[deer-flow2]] 框架中得到了典型应用。

## 核心机制
- **渐进式加载**：系统不会在初始化时加载所有功能，而是根据当前任务的具体需求，动态加载相关的 Skill 模块。
- **独立封装**：每个 Skill（如“深度研究”、“数据分析”）是一个独立的单元，包含特定的 Prompt、工具和逻辑。
- **生命周期管理**：Skill 在任务完成后可以被卸载，释放上下文窗口资源。

## 优势
1.  **资源效率**：显著减少了无效 Token 的消耗，因为不相关的 Skill 逻辑不会被加载到上下文中。
2.  **扩展性**：开发者或用户可以通过官方提供的 `skill-creator` 工具快速封装新能力，无需修改框架核心代码。
3.  **定制化**：允许用户根据特定场景（如金融分析、代码审查）定制专属的 Skill 集合。

## 实现案例
Deer-Flow2 内置了十余种 Skill，并支持通过 MCP 或 Python 接口接入外部工具（如 [[claude-code]]），体现了该体系的高度开放性。
