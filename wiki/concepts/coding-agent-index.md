# Coding Agent Index

**Coding Agent Index** 是由 [[artificial-analysis|Artificial Analysis]] 推出的AI编程智能体综合评测指数，整合了三大评测基准：

1. **SWE-Bench-Pro-Hard-AA** — 传统issue解决能力
2. **Terminal-Bench v2** — 终端任务执行能力
3. **SWE-Atlas-QnA** — 代码理解与工程能力（来自 [[swe-atlas|SWE Atlas]]）

## 当前榜单状态

- **榜首：** [[cursor|Cursor]] CLI + [[opus-4.7|Claude Opus 4.7]]，综合 pass@1 为 **61分**
- **整体格局：** 顶尖系统均聚集在 **40~60分** 区间，无一突破70分
- **意义：** 从外部视角印证了 SWE Atlas 评测的严苛度，表明当前AI编程智能体在综合能力上仍有巨大提升空间
