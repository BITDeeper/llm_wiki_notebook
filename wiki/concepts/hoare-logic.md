# 霍尔逻辑

**霍尔逻辑**，也称为 **Floyd-Hoare 逻辑**，是一种由 [[tony-hoare]] 在 1968 年开发的形式化系统。它用于证明计算机程序的正确性，是 [[形式化验证]] 领域的基石。

## 核心概念：霍尔三元组
霍尔逻辑的核心是 **霍尔三元组**，描述形式为 `{P} C {Q}`：
- **P (前置条件)**：执行代码段 C 之前必须满足的条件。
- **C (命令)**：待执行的程序代码段。
- **Q (后置条件)**：执行代码段 C 之后必须满足的条件。

这个三元组的含义是：如果前置条件 P 成立，且执行命令 C 终止，那么后置条件 Q 必然成立。

## 意义
在霍尔逻辑提出之前，程序的正确性主要通过测试来验证，这只能发现错误而不能证明没有错误。霍尔逻辑引入了数学逻辑的严密性，使得程序员能够像证明数学定理一样证明程序的正确性。这标志着软件工程从“手艺”向“科学”的重要转变。

## 起源
Hoare 在贝尔法斯特女王大学任教时，对当时含糊不清的程序文档感到不满。受 Robert W. Floyd 关于流分析程序工作的启发，他开发了这套逻辑系统。这一贡献是他获得 1980 年图灵奖的主要原因之一。
