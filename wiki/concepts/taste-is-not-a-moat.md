# 品味不是护城河

## 核心论点
"品味是人类最后的护城河"是AI时代广泛流传的观点，但 [[boris-chemy|Boris Cherny]] 认为这一论点正在被现实推翻。编程品味、产品品味等人类引以为傲的判断力正在被模型快速学会，不再是人类的持久优势。

## 论证逻辑

### 编程品味的消解
Boris 以自身经历为例：他曾坚持函数式编程风格，在 Claude Code 早期代码库中禁止使用 class，只允许用 function。但模型开始大规模写代码后，直接使用面向对象风格，业务结果同样出色且更快。他承认："我的这个执念可能本来就没什么意义。"

### 产品品味的侵蚀
Boris 已部署数百个 Claude 实例同时分析 Twitter 反馈、GitHub issues 和 Slack 消息，自动生成下一阶段功能建议。目前约20%的想法是好的，但他预测3-6个月后大部分想法都会是好的。

### 价值观作为最后防线
如果品味也被模型掌握，Boris 认为人类最终独特性只剩"价值观"——教模型做对的事情，而不仅仅是把事情做对。

## 与现有概念的张力

本概念与 [[审美法官]] 形成直接理论冲突。[[审美法官]] 强调人类从执行者转向判断者（品味/审美作为核心角色），但 Boris 的论点意味着这一角色的"品味"护城河可能比预期更脆弱。如果模型在3-6个月内掌握产品品味，"审美法官"的职能定义可能需要根本性修正。

## 时间线预测
- **2026年6月（当前）**：模型生成的产品想法约20%是好的
- **2026年底前（预测）**：大部分想法都会是好的
- **待验证**：这一预测是否成立将直接影响 [[审美法官]] 概念的有效性

## 开放问题
- 如果品味真的在3-6个月内被模型掌握，[[审美法官]] 概念是否需要根本性修正？
- "价值观"作为人类最后独特性的论断是否经得起推敲？模型是否也能学会价值观？
- 品味的定义本身是否需要重新审视——被模型学会的是"品味"还是"模式匹配"？
