# 编程实质性解决

编程实质性解决是指对于大多数软件开发任务而言，AI 模型已经能够完全替代人类手写代码，开发者不再需要关心底层语法、环境配置或具体语言实现。这是 [[boris-cherny]] 在 2026 年提出的核心判断。

## 核心论点

- **一切皆为 Token**：对于模型来说，本地环境、编译器或具体的语言语法都不再重要，所有输入输出都是 Token 序列。
- **从“怎么做”到“做什么”**：开发者的工作重心从编写实现逻辑（How）转变为描述意图（What）。
- **去神圣化**：软件开发将从精英技能变为大众基础技能，就像发短信一样简单。

## 证据

- **Boris Cherny 的实践**：2026 年全年未写一行代码，通过手机管理数百个 Agent，单日提交 150 个 PR。
- **现场投票**：在红杉演讲现场，几乎没有人举手表示“100% 手写代码”，绝大多数人处于“手写与 AI 之间”的状态。
- **Claude Code 自噬**：随着模型能力增强，Claude Code 自身的代码库预计将从复杂系统缩减至 100 行左右。

## 影响

- **领域知识夺回高地**：正如会计软件写得最好的人应该是懂业务的会计而非程序员，未来软件开发的门槛将在于领域知识和系统思维，而非编码技巧。
- **SaaS 护城河重构**：AI 削弱了“转换成本”和“流程权力”两大商业护城河，使得微型公司能构建巨头级价值。
