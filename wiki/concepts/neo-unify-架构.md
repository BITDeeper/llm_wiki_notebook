# NEO-Unify 架构

NEO-Unify 是 [[商汤科技]] 行业首创的原生多模态统一架构，是 [[sensenova-u1]] 模型的设计核心。该架构的核心目标是解决传统多模态模型中"理解"与"生成"模块分离导致的信息断层问题。其出发点是：**语言与视觉并非异质信号，而是对同一现实世界的不同编码**。

## 设计哲学与原理

NEO-Unify 让模型直接从接近原始形态的信息（像素与文字本身）中学习，在学习过程中形成统一的内部表示。理解与生成不再被拆开处理，而在同一体系中统一建模。

传统多模态模型通常采用"视觉编码器（理解）+ 语言模型（推理）+ 图像解码器（生成）"的分离式设计。这种设计存在以下问题：

- **信息损耗**：图像在编码成特征向量时会丢失细节。
- **中间商赚差价**：模块间的数据传递增加了计算开销和对齐成本。
- **表示空间割裂**：两套系统学习目标不同、表示空间各异，信息传递存在结构性损耗。

NEO-Unify 架构通过将视觉和语言信息整合到统一的计算空间，从底层消除了这些中间环节。模型在处理任务时，感知、理解、推理和表达在同一套模型内部完成。

## 三大递进矛盾解法

### 矛盾一（接口层）：近无损视觉接口

- **Encoder-free 设计**：完全消除预训练视觉编码器（VE）和 VAE 解码器。
- 输入端：两层卷积 + GELU 激活将图像转化为 token（每 token 对应 32×32 像素块）。
- 输出端：MLP 直接预测原始像素块。
- 消融验证：MS COCO 2017 重建 PSNR 31.56、SSIM 0.85，接近 Flux VAE（32.65/0.91）。
- 意义：在统一表示空间中同时支持语义理解和像素级精度。

### 矛盾二（训练层）：[[分辨率自适应噪声尺度]]

- 解决 256×256 到 2048×2048 动态分辨率下 SNR 失衡问题。
- 噪声标准差按平方根比例同步上调。
- 自适应尺度编码后作为条件引入去噪器。

### 矛盾三（参数层）：原生 [[mixture-of-transformers-mot|MoT]] 架构

- 理解流与生成流共享自注意力上下文。
- Q/K/V/O 投影、归一化及 MLP 层完全参数解耦。
- 每层根据 token 类型动态路由。
- 消融实验显示两种能力协同演化，冲突极小。

## 辅助设计

- **三维 RoPE 旋转位置编码**：T/H/W 三轴各有独立频率基，对齐语言顺序和空间结构。
- **混合注意力 Mask**：文本 token 走标准因果注意力，同块图像 token 间双向关注并保持对前置上下文的因果条件。

## 技术优势

- **路径更短**：减少了信息在不同模块间的转换次数。
- **计算利用率高**：节省下来的计算资源可用于提升生成质量，而非用于弥补模块割裂带来的损耗。
- **低延迟**：实现了在低延迟条件下的高质量生成（如 SenseNova-U1-8B-MoT 的 15秒/2K图）。
- **数据扩展效率高**：消融实验表明，NEO-Unify 以更少训练 token 实现更高性能，意味着随着数据规模扩大，架构优势将持续放大。

## 实际效果

基于 NEO-Unify 架构的模型能够实现"带图思考"，即在推理过程中实时生成视觉内容，保证了图文在逻辑和风格上的高度一致。
