# Spatial Agent Memory（空间智能体记忆）

[[spatial-agent-memory]] 是一种赋予机器人在物理空间中持久化记忆能力的技术架构。它标志着机器人从单纯的“反应式”设备向具备“世界模型”的智能体演进。

## 核心能力

### 时空感知
不同于传统机器人只能处理当前的感知输入，具备 Spatial Agent Memory 的机器人能够：
- **记忆位置**：知道物体（如钥匙）在物理空间中的具体位置。
- **记忆事件**：记住特定时间点发生的事情（如“上周一谁来过”）。
- **语义关联**：理解行为与空间的统计关系（如“谁在厨房待的时间最长”）。

### 物理上下文
它为 AI 提供了持续的、跨越时空的物理上下文，弥补了大型语言模型（LLM）仅有静态训练数据记忆的缺陷。

## 技术实现
该系统通常依赖于 [[SpatialRAG]] 技术，通过将非结构化的传感器数据（视频、雷达、深度图）转化为结构化的多维向量库（通常基于 [[体素化]] 表示），从而实现对物理世界的多维度检索。

## 意义
Spatial Agent Memory 被视为实现真正 [[具身智能]] 的关键里程碑，它让机器人不再是“会走路的音箱”，而是能够观察、记忆并理解世界的物理代理。
