# 内联脚本哈希

内联脚本哈希（Inline Script Hash）是一种 Web 安全技术，用于防止跨站脚本攻击（XSS）。它通常作为内容安全策略（CSP）的一部分实施。

## 工作原理

系统会对 HTML 页面中需要执行的内联 JavaScript 代码计算 SHA-256 哈希值，并将该哈希值加入白名单。当浏览器加载页面时，只有当内联脚本的实际哈希值与白名单中的值匹配时，才允许执行该脚本。

## 应用场景

在 [[openclaw]] 3.23 版本中，开发团队引入了针对所有内联脚本的 SHA-256 哈希检查。这意味着：
- 任何尝试在控制台页面注入的恶意代码，如果其哈希值不在官方白名单中，将被浏览器直接拒绝执行。
- 这有效地防止了黑客利用潜在的 XSS 漏洞劫持用户会话或窃取敏感信息。

## 安全意义

通过强制校验脚本哈希，系统建立了一道“白名单”防线，确保只有经过官方审核的代码才能在用户浏览器中运行，显著提升了 Web 客户端的安全性。
