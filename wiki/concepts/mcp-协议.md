# MCP 协议

MCP 协议（Model Context Protocol，模型上下文协议）是一种允许 AI 智能体安全、标准化地连接外部数据源和工具的技术标准。它旨在解决 Agent 系统中模型与外部环境（如数据库、API、软件工具）连接的标准化问题。

## 核心功能

### 打通私有数据孤岛
MCP 协议解决了 AI 智能体访问私有或受保护数据的难题。通过该协议，智能体可以连接到：
- **企业内部数据库**：如 CRM、ERP 系统数据。
- **专业数据终端**：如金融行业的 [[factset]]、Bloomberg 终端。
- **云存储服务**：如 Google Drive, Dropbox 等用户文件存储。

### 标准化交互
通过定义统一的交互协议，MCP 使得：
- **模型**能够以标准化的方式调用外部工具。
- **开发者**无需为每个工具定制特定的接口逻辑。
- **系统**更容易扩展和维护。

### 安全与控制
协议设计强调安全性，确保智能体在访问敏感数据时遵循权限控制和审计要求，这对于金融、医疗等低容错率行业至关重要。

## 应用场景

### 金融分析
在 [[deep-research-max]] 的应用中，MCP 协议使得智能体能够直接接入华尔街分析师标配的 [[factset]]、[[s&p-global]] 和 [[pitchbook]] 等数据源。这意味着 AI 可以像人类分析师一样查询实时金融数据、评级信息和私募股权记录，并将其整合进研究报告中。

### 企业工作流集成
MCP 协议将 AI 智能体从单纯的“网页检索器”升级为能在任意专业数据仓库中自主导航的智能系统，使其成为企业级工作流的基础设施。

### Agent 基础设施建设
在 [[deepseek-agent]] 的战略中，MCP 被列为必须熟悉的关键规范之一。Agent 基础设施工程师需要负责“集成外部工具到内部强化学习基础设施”，并熟悉“MCP、[[tool-use]]、[[function-calling]] 等 Agent 交互协议与规范”。这表明 MCP 是构建具备复杂任务执行能力的自主 Agent 系统的底层基石。

## 行业影响
MCP 协议的普及正在打破传统数据供应商的“订阅护城河”。过去，拥有昂贵数据终端访问权限是专业人士的核心竞争力；现在，任何企业都可以通过 API 调用具备 MCP 连接能力的 AI 智能体来获取同等质量的数据分析。
