# 截断重要性采样权重策略优化（CISPO）

截断重要性采样权重策略优化（CISPO）是一种基于 REINFORCE 风格目标的 RL 变体，与 [[tis]] 类似使用了重要性比率，但解决的是不同问题。

## 解决的问题

在 PPO/GRPO 的截断机制下，被截断的 token 对策略梯度贡献为零。模型推理轨迹中重要的"分叉" token（如"啊哈"、"等等"等反思行为 token）在基础模型中概率较低，第一次策略更新后概率急剧增大，导致重要性比率过大而被截断。

对于每批数据进行多次策略更新的场景（如 MiniMax-M1 进行 16 次更新），重要 token 在仅一两次更新后就被屏蔽出损失，显著损害训练效率。

## 核心方法

CISPO 对截断后的重要性比率应用**停止梯度（stop gradient）**：

- 重要性比率被用作权重，控制 token 对策略梯度的贡献量
- 截断为权重设置上限，确保没有 token 因重要性比率过大而被过度放大
- 即使被截断，每个 token 仍能以有限权重参与策略梯度

CISPO 同时采纳了 [[dapo]] 的部分建议，包括 token 级损失公式以纠正长度偏差。

## 与 TIS 的区别

| 维度 | CISPO | TIS |
|------|-------|-----|
| 重要性比率来源 | 当前策略 vs 旧策略（同引擎） | 训练引擎 vs 推理引擎（跨引擎） |
| 解决的问题 | 重要 token 被截断屏蔽 | 引擎间概率不一致 |
| 截断方式 | 停止梯度 + 权重上限 | 单侧截断 |
