# 多智能体辩论

**多智能体辩论**是 [[one-sentence-one-drama]] 框架中用于剧本打磨的核心机制，通过多个 LLM reviewer 从不同角度审查和改进剧本草稿。

## 工作流程

1. 用户输入一句话创意，系统扩展为初步故事骨架
2. 基于 [[短剧节奏先验]] 进行事实检索、逻辑检索和模式检索
3. 多个 LLM reviewer 从不同角度审查剧本草稿：
   - 开头是否足够抓人
   - 冲突是否升级
   - 结尾是否留下悬念
   - 故事逻辑是否顺畅
4. 当 reviewer 给出不同修改意见时，系统进行**综合裁决**
5. 通过**局部 patch** 修改剧本，而非粗暴重写整段

## 设计理念

将故事生成从"一次写完"推进为"写作 → 审稿 → 局部修订 → 再审稿"的迭代过程。这种设计解决短剧"节奏平"、缺乏钩子和反转的核心痛点。

## 与相关概念的区别

- 与 [[多agent协作架构]] 相关但不同：多智能体辩论强调的是同一任务的多角度审查与迭代改进，而非并行任务分发
