# 纵深防御

纵深防御是一种信息安全策略，通过在系统中分层部署多重安全控制措施，以提供冗余保护。即使某一层防御被突破，后续层仍能保护系统免受侵害。在 [[IronClaw]] 项目中，这一理念被具体化为四层防御体系，以应对 AI 智能体面临的安全威胁。

## IronClaw 的四层防御

1.  **语言层安全 (Rust)**：利用 Rust 语言的内存安全特性，从底层杜绝缓冲区溢出等传统漏洞。
2.  **隔离层安全 (WASM)**：通过 [[wasm-沙箱]] 隔离运行第三方工具和代码，限制潜在恶意程序的破坏范围。
3.  **数据层安全 (加密保险库)**：使用 AES-256-GCM 加密存储凭证，并实施 [[凭证隔离]]，确保 LLM 无法直接读取敏感信息。
4.  **硬件层安全 (TEE)**：利用可信执行环境（TEE）进行硬件级隔离，防止云服务商或恶意软件窥探内存中的数据。

## 应用价值
在 AI 智能体领域，纵深防御尤为重要，因为智能体通常需要处理高权限凭证（如 API 密钥）并执行不可预测的代码。单一防御手段（如仅依赖沙箱或仅依赖加密）可能不足以应对复杂的攻击向量（如提示注入结合内存溢出）。
