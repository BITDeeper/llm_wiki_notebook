# Prompt Requests

**Prompt Requests** 是 [[Peter Steinberger]] 提出的一种理念，将传统的 Pull Request (PR) 重新定义为“提示词请求”。

## 核心思想
在 AI 辅助编程的新范式中：
- **代码只是结果**：最终的代码文件实际上是 AI 执行指令后的产物。
- **提示词才是载体**：PR 中的描述、指令和上下文（即提示词）才是开发者思考过程和逻辑的真正载体。

## 实践意义
这一概念改变了代码审查的焦点：
1. **审查逻辑**：审查者应更关注指令是否准确传达了意图，而非纠结于具体的代码实现细节。
2. **可追溯性**：通过保留提示词，可以更好地追溯代码生成的逻辑源头。
3. **迭代优化**：优化提示词比直接修改代码更能从根本上解决问题。

## 背景
这一概念是 [[闭环]] 开发流程的一部分，强调了在 AI 时代，自然语言正在成为新的编程接口。
