# 决策效用

**决策效用**（Decision Utility）是 [[PlugMem]] 提出的一种基于信息论的评估指标，用于衡量记忆系统的经济性和有效性。

## 背景与动机

传统的 AI 记忆系统评估往往侧重于**任务准确率**（Accuracy）或**记忆大小**（Memory Size）。然而，在资源受限的上下文窗口环境下，仅看准确率是不够的。一个记忆系统可能通过注入海量 Token 提高准确率，但这在实际应用中成本过高且不可持续。

决策效用旨在解决这一问题，它关注的是：**记忆系统每消耗一个 Token，能带来多少决策相关的信息增益？**

## 定义

直观地说，决策效用衡量的是记忆模块产生的记忆 Token 能让 AI Agent 对正确行动的把握增加多少。该指标通常会按记忆长度进行归一化处理。

## 数学意义

从信息论的角度看，它衡量的是记忆内容对于当前决策分布的信息贡献度。高决策效用意味着记忆内容不仅相关，而且高度浓缩，去除了对决策无帮助的噪声。

## 应用

在 PlugMem 的实验中，通过绘制**效用-成本曲线**，可以直观地比较不同记忆架构：
*   **低效系统**：需要消耗大量 Token 才能带来微小的信息增益（曲线平缓）。
*   **高效系统（如 PlugMem）**：在较低的 Token 成本下就能获得较高的决策效用（曲线陡峭）。

这一指标为评估 AI 系统的“性价比”提供了新的视角，强调了在 Agent 时代，**信息密度**与**决策相关性**的重要性。
