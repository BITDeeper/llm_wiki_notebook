# 原生计算机使用

原生计算机使用是指 AI 模型无需依赖外部 API 封装或中间件，直接通过理解软件界面截图（视觉感知）并输出鼠标点击、键盘输入等操作指令来与计算机环境进行交互的能力。

## 技术原理

模型通常结合视觉编码器和策略网络，将 GUI 界面视为一种特殊的“视觉语言”，通过观察屏幕状态的变化来规划操作序列。

## 应用场景

- **办公自动化**：自动填写表单、发送邮件、创建日程。
- **网页操作**：基于自然语言指令进行复杂的网页浏览和数据抓取。
- **软件测试**：通过模拟用户操作来发现软件 Bug。

## 行业案例

- **[[GPT-5.4]]**：OpenAI 首个原生支持该能力的通用模型，在 OSWorld-Verified 基准测试中达到 75.0% 的成功率，超过人类平均水平。
- **[[Claude Code]] / [[Anthropic]]**：率先推广 Computer Use 概念，引发了行业对于 AI 自动化操作的关注。

## 风险与挑战

原生计算机使用赋予了 AI 直接操作数字世界的权力，这也带来了潜在的安全风险。例如，模型可能因幻觉而误删文件（如 [[OpenClaw]] 事故），或被利用进行恶意自动化攻击。
