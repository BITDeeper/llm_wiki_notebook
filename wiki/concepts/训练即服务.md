# 训练即服务

[[训练即服务]]（Training as a Service, TaaS）是一种将模型训练过程完全托管、按需调用的云服务模式。它通过 [[算法与基础设施解耦]]，让开发者能够在本地编写代码或通过 API 发送指令，而将繁重的计算任务提交至云端集群执行。

## 核心特征

- **全托管与解耦**：云服务商负责底层基础设施（如 GPU 集群、分布式调度、容错运维和并行策略优化），用户只需专注于算法逻辑和数据。
- **本地开发与控制**：开发者使用熟悉的 IDE（如 Jupyter Notebook）进行控制，或通过 API 发送数据和训练指令。
- **Serverless 部署**：支持按需启动训练任务，无需维护常驻集群。结合 [[按Token计费]]，实现资源的极致弹性。
- **多租户支持**：在共享的基础模型部署上，同时服务多个用户的训练任务（如不同 LoRA），是提升商业可行性的关键技术。

## 实现案例

[[Twinkle]] 框架通过 [[Client-Server 架构]] 和 [[多租户训练]] 支持，是实现 TaaS 的典型技术尝试。它允许在单个基础模型上并发运行多个异构训练任务，极大地提高了算力利用率。

## 意义

[[训练即服务]] 使得算法工程师无需依赖庞大的 Infra 团队即可完成复杂的模型微调和强化学习任务，实现了“1人顶1个 Infra 团队”的人效提升。
