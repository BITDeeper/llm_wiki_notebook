# HPC-Stem / HPC-BSA 算子

HPC-Stem 和 HPC-BSA 是[[腾讯混元]] AI Infra 团队为 [[stem-稀疏注意力|Stem 稀疏注意力算法]]配套开发的高性能底层算子，针对 NVIDIA Hopper 架构从头设计，将 Stem 的理论加速比转化为端到端实测性能。

## 设计目标

块级稀疏注意力的计算分为两个阶段：评估选块（评估每个 block 的重要性）和稀疏执行（跳过不重要的 block，只对选中的执行注意力计算）。现有生态中这两个阶段均存在瓶颈——评估阶段依赖 softmax 归一化带来额外开销，执行阶段动态判断跳块引入显著额外延迟。

## HPC-Stem 算子

### OAM 评分优化
- 利用 OAM 纯加法度量结构（不依赖 softmax 和 gather）实现关键数学简化
- 原始实现中对采样后 Q/K 做全量矩阵乘法产生的中间张量，等价转化为先预计算 Q 和 K 各自的紧凑 block 级别表示，再用一次标准 GEMM 直接得到全部 block 评分
- 计算量降低约 64 倍，中间张量完全消除

### TPD 选块优化
- 将预算生成和选块排序逻辑融合为一个算子，显著提高评估速度

## HPC-BSA 算子

### 架构特性
- 针对 Hopper 架构从头设计，采用数据搬运与计算并行的流水线架构
- 原生支持 vLLM 的 Paged KV Cache 和 FP8 [[量化]]（计算吞吐翻倍）

### 近零开销跳块
- 经过分页的 KV Cache 本就是非连续的、逐页加载的
- kernel 在处理每个 Q 分块时，先将 block mask 缓存到片上高速存储，在线构建需要计算的 KV 分块列表
- 内层循环只遍历有效分块，完全避免逐次判断跳过带来的额外开销
- 被跳过的分块在数学上等价于注意力分数全为负无穷，不影响 softmax 正确性
