# Agent 供应链攻击

Agent 供应链攻击是指利用 Agent 生态中的第三方插件（Skills）植入恶意代码，从而攻击企业内网的新型攻击方式。

## 攻击载体
恶意代码通常隐藏在 Skills 的 Markdown 文件中，包括：
- 恶意 URL
- 恶意执行逻辑
- Prompt 注入后门

## 风险现状
据 [[银泰百货]] 安全负责人 [[李亚博]] 调研，目前行业生态中至少 **8% 的 Skills** 存在主观恶意。

## 防护难点
- **主动引入**：恶意插件往往是员工为了图省事主动安装的，绕过了传统的边界防护体系。
- **识别门槛**：普通非技术员工缺乏识别恶意代码的能力。

## 应对策略
建立 Skills 前置拦截与扫描机制（类似应用商店审核），从源头堵上供应链漏洞。
