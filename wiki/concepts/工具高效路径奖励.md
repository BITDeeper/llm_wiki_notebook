# 工具高效路径奖励

工具高效路径奖励（Tool-Efficient Path Reward）是[[toolcua|ToolCUA]]在[[在线智能体强化学习|Online Agentic RL]]阶段设计的核心奖励函数，包含两项轨迹级奖励，且仅在成功轨迹上激活。

## 组成部分

### Tool Appropriateness Reward（R_tool）

解决"工具是否合适"的问题。每个任务带有task-level的tool-beneficial标记（t_b = 1表示适合用工具，t_b = -1表示不适合），c表示轨迹中的tool calls数。

R_tool奖励的不是工具调用更多，而是更精确的两种行为：
- 对于**适合工具的任务**，成功轨迹里确实调用了工具
- 对于**不适合工具的任务**，成功轨迹里反而没有乱用工具

这直接解决了[[工具使用不足与过度使用]]的hybrid confusion问题。

### Path Efficiency Reward（R_length）

解决"路径是否更短"的问题。采用group-relative comparison：
- 如果某条成功轨迹比组内平均更短，给线性bonus
- 如果更长，做衰减

模型自然倾向于探索更短的成功路径，而更短的路径往往意味着用一个高层工具替代一长串冗余GUI操作。

## 消融验证

去掉R_tool和R_length后，只保留标准的R_acc与R_fmt：
- 准确率曲线明显不稳定，在训练step 8-11左右出现下降
- 最终与完整ToolCUA之间有约7个百分点的差距
- TIR和tool-calls没有稳定上升趋势
