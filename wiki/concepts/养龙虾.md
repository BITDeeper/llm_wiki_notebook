# 养龙虾

## 定义
“养龙虾”是指用户部署、配置和维护 [[openclaw]] 智能体的过程。这一隐喻形象地描述了 AI Agent 时代的用户交互模式：用户需要像养宠物一样，为 AI 提供“食物”（[[token-怪兽]]/算力）、配置“技能包”（Skills），并搭建运行环境（本地或云端）。

## 行为特征
- **喂养**：持续购买或充值 API 额度，确保 Agent 有足够的算力执行任务。
- **训练**：根据需求编写或下载特定的技能脚本（如自动订票、文件整理）。
- **部署**：利用 [[docker-沙箱]] 技术在服务器或本地电脑上搭建安全运行环境。

## 社会现象
- **门槛与商机**：尽管技术门槛较高，引发了“上门安装 500 元一次”的衍生服务，但大众热情极高。
- **代际差异**：从小学生（用于辅助学习）到退休老人（探索新技术），各年龄段人群均参与其中，被称为“一代人有一代人的鸡蛋要领”。
- **全民 AI**：标志着 AI 技术通过极具亲和力的方式（如腾讯云的“免费装龙虾”活动）实现了大规模普及。
