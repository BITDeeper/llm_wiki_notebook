# 环境扩展训练

环境扩展训练是 [[qwen3-7-max]] 采用的核心训练方法之一，通过将任务拆解为多个独立维度并自由组合，迫使模型学习通用的问题解决策略而非特定框架下的取巧方法。

## 方法论

每个编程训练任务被拆为三个独立维度：

1. **任务本身：** 需要解决的具体问题
2. **执行框架：** 在哪个框架中执行（如 [[claude-code]]、[[openclaw]]、Qwen Code 等）
3. **验证方式：** 如何判断任务完成质量

三个维度自由组合，同一道题可能在不同框架中、以不同验证方式反复训练。

## 类比

效果如同"一个实习生被轮岗到所有项目组"——模型被迫学会的是解决问题的通用策略，而非"在某个特定框架里怎么取巧"。

## 效果

解释了一个反直觉的现象：[[qwen3-7-max]] 在 [[claude-code]]、[[openclaw]]、Qwen Code 等不同框架中表现都很稳定，没有出现"在自家框架里很强、换一个就拉胯"的情况。

## 与其他训练方法的关系

环境扩展训练解决的是**跨框架泛化**问题，而 [[动态累积生存博弈]] 解决的是**长程连贯推理**问题，两者共同支撑 [[agent基座模型]] 的核心能力。
