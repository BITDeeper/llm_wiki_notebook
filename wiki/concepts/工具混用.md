# 工具混用

工具混用是指 AI 模型在单次 API 请求中，能够同时调用平台内置工具（如 Google Search、Google Maps）和开发者自定义函数（如后端数据库查询 API）的能力。

## 解决的问题
在早期的 Agent 开发模式（即 [[编排噩梦]]）中，内置工具和自定义函数通常处于隔离状态。开发者必须编写复杂的编排代码，分步骤发起请求，并手动将第一步的输出作为第二步的输入。这不仅增加了延迟，也极大地提高了代码维护成本。

## 工作原理
在支持工具混用的系统中（如更新后的 [[Gemini]] API），开发者只需在配置列表中声明所有可用工具（无论是内置还是自定义）。模型会根据任务逻辑，自主决定：
1. 调用哪些工具。
2. 调用的先后顺序。
3. 如何在不同工具间传递上下文数据。

## 示例场景
**任务**：“搜一下今天最火的降噪耳机，然后查查我们仓库有没有货。”
- **旧模式**：先发请求调用搜索工具 -> 解析结果 -> 发第二个请求调用库存 API。
- **新模式**：发送一个包含搜索工具和库存 API 的请求 -> 模型自动完成搜索并调用库存查询。

## 价值
这一特性是实现 [[声明式Agent]] 的基础，显著降低了 Agent 开发的门槛，使得开发者可以专注于业务逻辑和工具定义，而非繁琐的流程控制。
