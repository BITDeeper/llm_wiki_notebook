# 工作板

工作板（Workboard）是[[openclaw]] 2026.6.1版本引入的多智能体协调看板，提供编排原语和智能体协调工具，将多Agent协作从理论推向工程化落地。

## 核心功能
- **多智能体规划**：主智能体接收大任务后自动拆解
- **运行追踪**：实时追踪每个子任务的进度
- **任务驱动面板流转**：支持任务状态流转和进度可视化
- **编辑弹窗集成**：直接在弹窗中查看任务进度和评论

## 工作流程
1. 给主智能体分配一个大任务
2. 主智能体拆解任务、分发给子智能体
3. 追踪每个子任务的进度
4. 汇总交付
5. 整个过程在工作板上一目了然

## 技术支撑
- Code mode内部命名空间
- 精确的工具分发机制
- Agent组队协作告别"纸上谈兵"

## 与多Agent协作架构的关系
工作板是[[多agent协作架构]]的产品级落地实现，与[[1-n-agent调度]]范式形成呼应——用户角色从对话者变为调度者，通过工作板同时管理多个Agent任务。
