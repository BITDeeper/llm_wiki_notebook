# 几何锚点注意力

几何锚点注意力是 [[UniGeo]] 框架在**架构层**引入的一种机制，旨在维持连续生成过程中的跨视角结构一致性。

## 工作机制
在视频生成过程中，为了防止后续帧偏离初始的几何结构，UniGeo 将序列的**首帧**显式指定为“几何锚点”。
- 后续所有生成的帧不再仅仅依赖于前一帧（这容易导致误差累积），而是通过新增的少量可学习投影矩阵（作为 Query 和 Output 映射），持续与首帧的 Key 和 Value 进行注意力交互。
- 这意味着每一帧的生成都直接参考了初始视角的几何特征。

## 优势
- **全局结构对齐**：在微观特征层面实现了与初始状态的全局对齐，有效抑制了几何漂移。
- **低计算开销**：仅通过增加少量的投影矩阵实现，不需要引入复杂的 3D 卷积或图神经网络，保持了推理效率。
- **保留先验**：不破坏预训练视频生成模型原有的生成能力。
