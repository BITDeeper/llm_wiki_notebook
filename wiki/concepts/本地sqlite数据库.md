# 本地SQLite数据库

**本地 SQLite 数据库**是指在用户本地设备（如个人电脑）上运行的轻量级嵌入式数据库。在 AI 应用（如 [[SentiCat]]）的语境下，它是一种关键的隐私保护技术手段。

## 特点
-   **零云存储**：所有用户数据（包括聊天记录、上传文件、个人偏好设置）均存储在本地数据库文件中，不经过云端服务器。
-   **完全控制**：用户拥有数据的完全所有权，可以随时查看、修改或删除记忆库内容。
-   **轻量高效**：SQLite 无需独立服务器进程，适合桌面应用集成。

## 应用场景
在 AI Agent 产品中，采用本地 SQLite 数据库主要是为了应对用户对隐私泄露的担忧。配合 API 密钥本地加密和沙盒执行环境，可以构建一个相对封闭和安全的个人计算环境，防止敏感信息被第三方采集或滥用。

## 权衡
虽然本地存储极大地提升了隐私安全性，但也可能限制了跨设备同步和云端算力辅助记忆训练的能力。
