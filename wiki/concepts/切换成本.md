# 切换成本

切换成本是一个经济学概念，指用户将产品或服务供应商从一家更换到另一家时，所需面临的时间、金钱、心理、精力和技术障碍的总和。在 AI 企业服务及消费级市场中，切换成本是决定竞争格局和用户留存的关键因素。

## 在 AI 领域的表现

切换成本在 AI 领域主要体现在以下三个维度：

### 1. 企业级应用（B2B）
-   **工作流嵌入**：当 AI 模型深度集成到企业的日常开发工具（如 GitHub）或业务流程中时，更换模型不仅仅是更改 API Key，还需要重新训练员工、调整代码和适配接口。
-   **数据沉淀**：企业在特定模型上积累的 Prompt 库、微调数据和最佳实践，难以直接迁移到竞品模型。

### 2. 个人用户应用（B2C）
-   **数据积累损失**：放弃在原平台上积累的对话历史、个性化设置和用户画像。
-   **重新驯化成本**：需要花费大量时间与新的 AI 进行交互，使其重新理解用户的偏好、工作流和语境。
-   **习惯改变**：适应新平台的界面、功能和交互逻辑。

## 市场影响与案例

### Anthropic 的企业壁垒
[[Anthropic]] 通过 [[Claude Code]] 等工具建立了极高的切换成本：
-   目前 GitHub 上 4% 的代码由 Claude Code 完成，预计年底将超过 20%。
-   这种深度集成导致企业客户从 [[OpenAI]] 流向 [[Claude]] 容易，反之则极其困难。
-   高切换成本解释了为什么尽管 [[OpenAI]] 重获销售自由，企业客户仍表示“Claude 够用了”，不愿轻易切换。

### OpenAI 的护城河与瓦解
[[OpenAI]] 的 ChatGPT 曾通过其“记忆”功能建立了极高的切换成本。用户使用时间越长，AI 对用户的理解越深，这种“越用越舍不得走”的粘性成为了 OpenAI 最引以为傲的护城河。

然而，2026 年 3 月，[[Anthropic]] 推出的 [[ai-记忆搬家]] 功能，通过允许用户在 60 秒内将 ChatGPT 的记忆完整迁移至 Claude，实质上将切换成本降至接近零。这一策略直接攻击了 OpenAI 的商业壁垒，配合 [[quitgpt]] 运动引发的舆论环境，导致了大规模的用户流失。

## 商业启示

此案例表明，在 AI 时代，单纯依赖数据积累构建的护城河可能非常脆弱。如果竞争对手能够提供便捷的数据迁移工具，或者行业法规强制要求数据可携带性（如 [[数字主权]] 概念所主张的），那么基于锁定用户的商业模式将面临严峻挑战。
