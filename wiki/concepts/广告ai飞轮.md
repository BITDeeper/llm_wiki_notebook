# 广告AI飞轮

广告AI飞轮是 [[applovin|AppLovin]] 的核心增长逻辑，描述的是"数据越多→模型越强→转化越高→吸引更多预算→更多数据"的正向闭环。

## 飞轮机制

```
更多广告主预算 → 更多用户行为数据 → Axon模型更强 → 广告转化率更高 → 吸引更多广告主预算 → ……
```

具体而言：
1. 广告主投入预算，通过 [[axon|Axon]] 进行智能投放
2. 投放产生大量用户行为数据（展示、点击、下载、购买、复购）
3. [[adjust|Adjust]] 归因系统将这些反馈信号回传Axon
4. Axon 基于新数据持续优化预测模型
5. 更强的模型带来更高的转化率和ROAS
6. 更好的效果吸引更多广告主投入更多预算
7. 回到步骤1，飞轮加速旋转

## 与算力飞轮的对比

本概念与 [[ai-infrastructure-flywheel]]（算力飞轮）形成有趣的对照：

- **算力飞轮**（OpenAI模式）：算力→更智能模型→更好产品→更多营收→更多算力
- **广告AI飞轮**（AppLovin模式）：数据→更精准预测→更高转化→更多预算→更多数据

两者都是正向闭环，但驱动力不同：前者依赖算力投入和通用模型能力，后者依赖垂直场景的行为数据和预测精度。

## 关键前提

飞轮能够启动并加速的前提是：
- 拥有足够大的流量覆盖（AppLovin月触达14亿独立用户）
- 具备准确的归因和反馈闭环
- 模型架构能够有效利用新增数据（Axon 2的深度学习架构满足此条件）
