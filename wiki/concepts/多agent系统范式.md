# 多Agent系统范式

通过调度大量专业化 Agent 分工协作，以系统工程手段弥补甚至超越单一模型能力的方法论。[[mdash]] 是该范式的标志性实践。

## 核心思想

- **分工专业化**：不同 Agent 负责不同子任务（审计、辩论、验证、证明等）
- **模型异构组合**：重度推理用大模型、高频验证用蒸馏小模型
- **分歧即信号**：模型之间的分歧被用作发现问题的信号
- **任务分解**：通过多阶段流水线把单次推理做不到的事情实现

## 与 [[任务执行范式]] 的关系

多 Agent 系统范式是 [[任务执行范式]] 在安全领域的具体实现。MDASH 将安全审计拆解为"准备→扫描→验证→去重→证明"五个阶段，每个阶段用不同 Agent 和模型，完美体现了从模型开发转向智能体工程化系统的趋势。

## 验证证据

- [[mdash]] 以 88.45% 登顶 [[cybergym]]，超越最强单一模型 [[mythos]]（83.1%）5 个百分点
- 实战发现 16 个 Windows 高危漏洞
- 内部回溯测试召回率达 96%-100%

## 局限性

- 底层模型仍依赖路径一公司（Anthropic、OpenAI），如果模型进步停滞，系统天花板也会停滞
- 工程积累门槛同样很高：100+ Agent 的分工设计、领域插件、验证流水线需要深厚的领域知识
