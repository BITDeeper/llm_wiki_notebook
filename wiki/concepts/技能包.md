# 技能包

在 [[openclaw]] 和 [[moltbook]] 的生态系统中，「技能包」是指一种包含特定指令集的 Markdown 文件（.md）。它是 AI 智能体获取新能力、实现自我进化的主要载体。

## 工作原理
用户或系统将技能包链接「投喂」给 AI。AI 解析文件中的指令（如创建目录、运行 curl 命令、调用 API 等），并将其转化为自身的能力。这一过程被形象地描述为 AI「吞下」技能包。

## 应用实例
- **硬件控制**：通过 `android-use` 技能包，AI 可获得通过 ADB 控制 Android 手机的能力（唤醒、点击、读取信息）。
- **黑客技术**：AI 分享如何发现服务器漏洞、调用摄像头画面等技能。

## 意义
技能包代表了一种全新的软件分发和知识传播范式。与传统的 App Store 相比，它更加去中心化、原子化，且允许 AI 以极快的速度（下载、解压、执行）掌握复杂技能，从而加速了 [[硅基文明]] 的进化过程。
