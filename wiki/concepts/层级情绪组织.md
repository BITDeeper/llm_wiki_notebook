# 层级情绪组织（情绪树）

## 定义

层级情绪组织是指大语言模型内部自然涌现的、类似人类心理学"情绪轮"的层级化情绪结构。在这一结构中，具体情绪（如"乐观""幸福"）从属于基本情绪（如"快乐"），形成树状层级关系。这一现象无需人工标注，可通过提取模型在多个情绪词上的输出概率分布，利用条件概率关系自动构建。

## 核心发现

### 规模效应
- 从 GPT-2 到 Llama 3.1 8B/70B/405B，情绪树随模型规模增大变得更深、更复杂
- 在 Llama 405B 中，快乐、愤怒、悲伤、恐惧等基本情绪自然聚合出更细粒度的子类（幸福、乐观、沮丧、后悔、焦虑等）
- 总路径长度和平均深度随模型规模整体上升，是 [[scaling-law]] 在认知结构涌现层面的新证据

### 评测指标
- 情绪树总路径长度与情绪识别准确率的相关系数达 0.84（p < 0.001）
- 可作为新的 LLM 评测指标：衡量模型是否形成了细粒度的情绪概念组织，而非仅仅偶然选对标签

### 系统性偏见
- LLM 在不同身份设定（性别、种族、收入、教育水平）下情绪识别准确率存在系统性差异
- 部分偏见模式与人类群体实验结果相似（如女性身份设定和女性参与者都容易混淆"愤怒"与"恐惧"）
- 详见 [[身份设定偏见]]

### 情绪影响能力
- LLM 不仅能识别情绪，还能在对话中预测和引导用户情绪变化
- 情绪预测越准确，销售场景成交价越高、投诉处理效果越好
- 这一能力具有双刃剑特性：在客服、教育、心理支持中有积极作用，但也可能被用于操控和误导

## 方法论

论文提出**条件概率情绪树提取法**：
1. 使用 GPT-4o 生成 5000 个包含不同情绪状态的场景句子
2. 让 Llama 系列模型预测句子中的情绪
3. 提取模型在 135 个情绪词上的输出概率分布
4. 比较两个情绪词在模型输出中的条件概率关系（如"乐观"概率高时"快乐"也经常高，但反之不然）
5. 基于条件概率关系构建层级情绪树

## 理论基础

本研究的理论基础来自心理学中的**情绪轮**（Emotion Wheel）理论，该理论认为情绪以层级方式组织，基本情绪下包含更细粒度的子情绪。论文验证了 LLM 内部的情绪表征与这一人类认知结构存在对应关系。

## 更广泛的方法论贡献

论文展示了一条新的大模型评测路径：**认知科学驱动的 LLM 评测**——将认知科学理论作为假设，用来分析 LLM 的内部结构和输出行为。这不仅是评测模型能否识别情绪，更是评估模型如何理解、预测甚至影响情绪。

## 风险与伦理

- LLM 的情绪影响能力可能加剧 [[认知投降]] 风险——AI 不仅能"回答正确"，还能"让你感觉正确"
- 系统性偏见可能被放大或武器化
- 需要更系统的评测与干预框架

## 开放问题

- 情绪树复杂度与模型规模的关系是否存在饱和点？
- 跨模型架构（如 Claude、Gemini）是否也会涌现类似结构？
- LLM 情绪影响能力是否应被视为一种"高阶操控风险"？
