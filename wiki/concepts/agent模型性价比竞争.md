# Agent模型性价比竞争

Agent模型性价比竞争是指在后OpenClaw时代，AI模型厂商围绕"性能强的用不起，用得起的不够强，好用的生态封闭"这一核心矛盾展开的市场竞争。

## 市场矛盾

当前 Agent 模型市场存在三重矛盾：

1. **性能强的用不起**：Claude Opus 4.6 等顶级闭源模型调用成本高昂
2. **用得起的不够强**：轻量模型只能"凑合跑"，无法满足复杂智能体任务需求
3. **好用的生态封闭**：顶级能力被少数闭源模型垄断

## 竞争策略

[[skyclaw-v1|SkyClaw-v1.0]] 的"高配低价"策略是这一竞争的代表性案例：

- 以接近 Claude Opus 4.6 等闭源顶流的 Agent 性能
- 定价仅为 Minimax 2.7 和 Qwen 3.6 系列的一半甚至更低
- 开发者可用同样的成本调用到接近顶级水平的 Agent 能力

## 与订阅制危机的关联

这一竞争趋势与 [[ai-subscription-crisis|AI订阅制危机]] 形成呼应：当 Agent 任务的高算力消耗使订阅制难以为继时，按量计费的性价比成为关键竞争维度。
