# API永久降价策略

指AI模型提供商将限时优惠价格转为永久定价，大幅降低API调用成本的商业策略。2026年5月[[deepseek|DeepSeek]]率先实施这一策略，将价格降至原价1/4。

## 核心特征

- **从限时到永久**：将原本的促销/优惠价格固化为长期定价，消除用户的价格不确定性
- **数量级差距**：不仅低于国内竞品，更将价格拉到国际同级别模型的不到1/10
- **货币优势**：以人民币计价，对海外开发者形成汇率叠加的成本优势

## 战略逻辑

1. **用户生态锁定**：极低价格吸引全球开发者高频调用，形成使用习惯和生态依赖
2. **技术自信**：降价底气来自推理成本的极致优化（注意力架构、并行策略、显存量化）
3. **资本支撑**：百亿美元融资为低价策略提供资金安全垫
4. **竞争壁垒**：价格降至竞争对手难以跟进的水平，重塑全球AI定价体系

## 行业影响

- 直接回应了[[tokenmaxxing]]和[[ai-subscription-crisis]]中"烧不起token"的行业痛点
- 对[[ai创业收入双寡头格局]]构成潜在冲击，以极致低价打破OpenAI和Anthropic的定价权
- 可能引发全球AI模型层价格战的新一轮升级
