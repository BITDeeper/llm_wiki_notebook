# 临时令牌

[[临时令牌]]（Ephemeral Tokens）是一种安全机制，用于在客户端（如浏览器或移动应用）直接连接后端 API 时，避免在客户端代码中暴露长期有效的标准 API Key。

## 工作原理

系统生成一个短期有效、权限受限的临时令牌给客户端。客户端使用该令牌进行 API 认证。一旦令牌过期或会话结束，该令牌即失效。

## 应用场景

在 [[gemini-live-api]] 的部署中，为了降低实时交互的延迟，开发者可能会选择让前端直接建立 WebSocket 连接到谷歌服务器。为了防止 API Key 泄露（类似 [[claude-code]] 曾发生的安全事故），官方文档强烈推荐在生产环境中使用临时令牌机制，而非硬编码标准 Key。

## 重要性

随着 Agent 应用越来越复杂，前端直接调用模型 API 的场景增多，临时令牌成为了平衡“低延迟需求”与“安全风险”的关键工程实践。
