# Hooks（Codex）

[[codex]] 的可扩展机制，2026年5月宣布普遍可用（GA），为 Codex 的企业级定制和安全管理提供关键支持。

## 功能范围

- **安全扫描**：扫描提示中的秘密信息（如 API 密钥、密码）
- **验证器**：运行自定义验证器检查代码质量
- **对话记录**：记录对话用于审计和合规
- **记忆创建**：为特定项目创建持久化记忆
- **行为自定义**：为特定存储库和目录自定义 Codex 行为

## 战略意义

Hooks 的普遍可用标志着 Codex 从"开箱即用"的工具向"可定制平台"的转变。企业可以根据自身需求构建安全策略、质量标准和自动化流程，这是 Codex 进入企业级市场的关键能力。

## 与其他功能的协同

- 与 [[程序化访问令牌]] 配合，实现端到端的自动化工作流
- 与远程 SSH 集成，支持在托管环境中执行自定义 Hooks
- 与 HIPAA 合规模式结合，满足受监管行业的审计需求
