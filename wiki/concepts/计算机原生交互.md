# 计算机原生交互

[[计算机原生交互]]（Computer Use）是指 AI 模型直接理解并操作计算机图形用户界面（GUI）的能力，包括识别屏幕截图、模拟鼠标点击和键盘输入等。

## 技术实现
- **输入**：通过屏幕截图感知软件界面状态。
- **处理**：利用视觉理解能力解析界面元素。
- **输出**：生成坐标点击、拖拽和按键指令。

## 应用场景
- **自动化办公**：批量数据录入、自动填写 Web 表单。
- **自我修正**：例如 [[GPT-5.4]] 在绘图软件中发现自己画得不好，主动打开浏览器搜索参考图并导入。
- **复杂任务流**：发邮件、安排日程等连贯操作。

## 与编程代理的区别
虽然 [[Claude Code]] 专注于代码层面的操作，但计算机原生交互更侧重于通用的 GUI 操作，使得 AI 能够像人类一样操作任何软件，无需 API 接口。这是实现通用 Agent 的关键一步。
