# 多Token预测草稿模型

多 Token 预测草稿模型（Multi-Token Prediction Draft Model，简称 MTP）是一种用于加速自回归模型推理的投机解码技术。[[gemma-4-12b]] 配备了该技术以降低推理延迟。

## 工作原理

传统自回归模型逐个 Token 生成输出，每个 Token 的生成都依赖前序所有 Token。MTP 草稿模型通过同时预测多个后续 Token 来加速这一过程：

1. **草稿生成**：小型草稿模型快速预测多个后续 Token
2. **验证接受**：主模型并行验证草稿 Token 的正确性
3. **接受/拒绝**：正确的 Token 被接受，错误的 Token 被拒绝并重新生成

## 优势

- **降低延迟**：通过并行预测减少总生成时间
- **保持质量**：主模型验证机制确保输出质量不降
- **特别适合本地推理**：在[[本地推理]]场景中，延迟是用户体验的关键瓶颈

## 在 Gemma 4 12B 中的应用

Gemma 4 12B 配备 MTP 草稿模型，作为其在消费级设备上实现流畅推理体验的关键技术之一，配合[[无编码器多模态架构]]进一步降低端侧运行的整体延迟。
