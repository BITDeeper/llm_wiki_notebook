# Hub Token 通信枢纽

**Hub Token 通信枢纽** 是 [[gamma-world|Gamma-World]] 引入的一种注意力机制设计，用于解决多智能体世界模型中算力随玩家数量平方爆炸的问题。

## 核心思想

引入一组共享的 hub token 作为通信中转站。玩家之间不再两两直连，而是通过两跳路径完成信息交互：

1. **第一跳**：所有玩家将信息汇给 hub token
2. **第二跳**：hub token 将整合后的信息广播给所有玩家

信息路径：玩家 → 枢纽 → 玩家

## 复杂度分析

| 方案 | 复杂度 | 8人时相对算力 |
|------|--------|---------------|
| 全连接（如 Solaris） | O(N²) | 基准（1.0） |
| Hub Token 两跳 | O(N) | **1/8** |

- 8个玩家时，Gamma-World 的算力消耗仅为全连接方案的 **1/8**
- 延迟从 17.6ms 降至 **4.5ms**

## 意义

这一设计将多智能体世界模型的计算成本从平方增长压至线性增长，使得实时多智能体模拟成为可能，是从"能做"到"可扩展"的关键技术突破之一。
