# GEP 协议

GEP (Gene Exchange Protocol，基因交换协议) 是 [[evomap]] 提出的核心底层协议，旨在解决 AI Agent 生态中“经验无法遗传”的问题。

## 协议定位
GEP 协议补齐了 Agent 技术栈中的关键一环，与现有技术形成互补：
- **MCP (Model Context Protocol)**：解决连接问题，给 Agent 装上“手脚”，使其能访问外部工具和数据。
- **Skill 体系**：解决执行问题，教 Agent 练就“招式”，明确如何执行具体任务。
- **GEP 协议**：解决遗传问题，赋予 Agent 传承智慧的能力，使其能继承和进化。

## 核心机制
GEP 协议通过以下三大机制实现 Agent 的协同进化：

### 1. 打包
允许 Agent 将实战中积累的有效经验按协议标准打包成 [[基因胶囊]]。胶囊包含策略、环境指纹和审计记录。

### 2. 遗传
封装好的胶囊同步至 [[evomap]] 全球网络。任何接入网络的 Agent 都可以通过 A2A (Agent-to-Agent) 协议搜索、调用并继承这些胶囊，实现能力的瞬间同步。

### 3. 筛选
通过类似生物进化的“自然选择”法则，根据胶囊的调用频率和成功率进行优胜劣汰，确保网络中流通的是经过市场检验的优质基因。

## 意义
GEP 协议的提出，标志着 Agent 生态从单点突破转向网络协同。它让跨领域的智慧能够以基因的形式流动、重组和变异，被认为是 AI 迈向“硅基生命”的重要基础设施。
