# Map as Memory

[[高德]] 提出的跨机器人本体空间记忆系统，旨在将地图升维为智能体的持久化记忆载体，以解决「[[一机一图]]」导致的「知识孤岛」问题。

## 核心机制
以全局空间坐标系为统一参考框架，构建支持多模态感知数据（视觉关键帧、物体 6D 位姿、语义坐标、行为轨迹）持久化存储与联合索引的分布式记忆架构。

## 四层拓扑结构
1.  **Block Layer（区域层）**：定义室内房间和室外街区，支持长程任务分解。
2.  **Road Layer（路网层）**：刻画物理连通性（交叉口、门洞、通道），提供路径规划约束。
3.  **Function Layer（功能层）**：标注语义节点（休息区、厨房），将抽象意图转化为导航目标。
4.  **Object/POI Layer（对象层）**：定位具体实体，作为「最后一米」导航的精确锚点。

## 关键特性
-   **零成本继承**：新机器人接入网络即可订阅全局空间语义图谱，直接复用历史经验。
-   **动态维护**：任务执行结果和海量导航数据实时回写，支持对「变化的世界」的感知。
-   **混合检索**：融合几何约束与语义相似度，支持开放词汇条件下的跨模态召回。
