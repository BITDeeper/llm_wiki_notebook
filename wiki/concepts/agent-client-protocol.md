# Agent Client Protocol

允许外部工具调用编程 Agent 的协议接口。[[grok-build]] 提供的三种使用方式之一，使 Grok Build 可以被第三方应用集成和调用，将编程 Agent 变为可被外部系统编排的基础能力。

## 意义

Agent Client Protocol 代表了 AI 编程工具从独立产品向可集成基础设施的演进方向，与 [[codex]] 的 headless 模式和 [[claude-code]] 的 API 接入思路一脉相承。
