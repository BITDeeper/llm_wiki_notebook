# 多智能体协作工坊

**多智能体协作工坊** 是一种将多个具有特定技能配置的 [[AI Agent]] 组织起来，由人类或“调度 Agent”统一管理以完成复杂任务的开发模式。

## 运作机制

在 [[Elseland]] 的开发过程中，[[刘耕]] 建立了一套包含 17 个 Agent 的协作机制：
*   **技能配置**：为每个 Agent 分配特定的 Skill（技能）、Tool（工具）和 Workflow（工作流）。例如，“皮格马利翁”负责 3D 资产，“莎士比亚”负责剧本。
*   **调度管理**：通过专门的“调度师 Agent”或直接使用 [[Claude Code]] 来协调各 Agent 之间的工作。

## 效率提升

这种模式实现了开发效率的数量级提升。通过将复杂的开发任务拆解并分配给专业的 Agent，个体开发者可以像指挥交响乐团一样管理软件生产过程，实现百倍于传统管线的效率。
