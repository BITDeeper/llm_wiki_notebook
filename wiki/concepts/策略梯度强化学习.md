# 策略梯度强化学习

当前 LLM 依赖的强化学习方法，直接优化策略参数以最大化期望奖励。在长序列场景下面临严重的方差问题。

## 在 LLM 中的应用与困境

LLM 的策略梯度 RL 面临两大核心困难：

1. **[[梯度方差暴增]]**：多步强化学习中，梯度方差随时间步长 T 呈二次方增长，导致训练极不稳定。
2. **[[信用分配难题]]**：奖励仅在序列末尾出现，难以精确归因到序列中的每个 Token。

## T=1 设定

为规避上述问题，当前 LLM RL 将整段序列视为单一动作（T=1），将对数概率视为单个 Token 概率之和。但朴素 REINFORCE 估计器仍保留高梯度方差，需数百万样本才能提取有效监督信号。

## 与 MCTS 的对比

[[mcts-蒙特卡洛树搜索|MCTS]] 采取完全不同的路径——通过"重新标记"为每一步提供更优行动标签，将策略提升转化为强监督学习，从根本上绕开信用分配难题。
