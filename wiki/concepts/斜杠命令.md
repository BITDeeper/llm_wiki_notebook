# 斜杠命令

**斜杠命令**（Slash Commands）是指在 AI 编程工具（如 [[Claude Code]]）中预定义的脚本指令，通常以 `/` 开头（如 `/commit-push-pr`）。它们用于封装重复性的开发工作流，从而减少开发者与 AI 模型之间的交互摩擦，提升自动化程度。

## 作用与优势
- **减少重复劳动**：避免每次执行相同任务时重复编写提示词。
- **加速执行**：命令中可内嵌 Bash 脚本预计算信息（如 `git status`），使 AI 能直接获取上下文，减少来回确认。
- **标准化流程**：将团队的最佳实践固化为命令，确保工作流的一致性。

## 实例
[[Boris Cherny]] 在其 100% AI 编程实践中，每天会使用 `/commit-push-pr` 命令数十次。该命令封装了代码提交、推送和创建 Pull Request 的完整流程，并自动处理了 Git 状态检查等细节。

## 与子代理的区别
虽然 [[子代理]] 也是用于封装任务，但斜杠命令更侧重于**线性的、脚本化的操作流**，而子代理通常具备更复杂的自主性和针对特定任务的逻辑。
