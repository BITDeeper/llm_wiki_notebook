# 生成式 AI UI

## 概述
[[生成式 AI UI]]（Generative AI UI）是指利用大语言模型（LLM）实时生成网页界面，而非由设计师预设、程序员写死的用户界面设计模式。

## 核心特征
-   **实时生成**：UI 在用户交互的瞬间由 AI 动态构建。
-   **千人千面**：每个用户看到的界面可能完全不同，根据其意图和上下文定制。
-   **非静态**：界面不再是固定的 DOM 树，而是流动的、可变的输出。

## 技术支撑
[[vercel]] CEO 等业界人士认为，Web 是实现这一愿景的最佳载体，因为：
1.  大模型擅长编写 Web 代码（HTML/CSS/JS）。
2.  浏览器是免费的、无需应用商店审核的运行时环境。
3.  [[html-in-canvas]]、[[WebGPU]] 等新技术提供了足够的渲染自由度和性能，支持 AI 生成的复杂视觉效果。

## 意义
这一概念标志着 UI 设计从“静态装配”向“动态生成”的范式转移，被视为 AI 时代 UI 的终极形态。
