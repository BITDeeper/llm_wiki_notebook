# AI 优先的内容格式

AI 优先的内容格式是指内容格式选择的逻辑从“人类易于编辑”（如 [[Markdown]]）转向“人类易于阅读/机器易于生成”（如 [[HTML]]）。

## 背景逻辑
- **传统假设**：人类亲手编辑文件，因此格式需优化书写体验（如 Markdown 的 `#`、`**`、`-` 语法）。
- **AI 时代现状**：AI 负责生成和修改文件，人类主要负责阅读和审阅。
- **瓶颈转移**：过去的瓶颈是 Token 数量或生成速度，现在的瓶颈是“人的注意力”。

## 格式对比
| 维度 | Markdown | HTML |
| :--- | :--- | :--- |
| **核心优势** | 易于人类编辑 | 易于人类阅读/机器生成 |
| **表现力** | 弱（依赖 ASCII 字符画） | 强（支持 CSS、SVG、交互组件） |
| **交互性** | 静态 | 支持拖拽、滑块、实时预览 |
| **可读性** | 长文档难以阅读 | 结构化页面易于扫视 |
| **生成成本** | 低 | 稍高（但可接受） |

## 结论
既然人的角色从“写”变成了“看”，输出格式也应随之反转。HTML 恰好符合这一趋势：人写起来痛苦，但 AI 写起来毫不费力；人看起来舒服，因为有颜色、布局和交互。
