# 云端虚拟机

**云端虚拟机**（Cloud Virtual Machine）在 AI Agent 语境下，特指为每个用户分配的、独立运行在云端的隔离计算环境。它使得 AI Agent 能够在云端持续执行任务，而不依赖用户的本地硬件。

## 核心功能

### 1. 持续运行
- **7×24 小时在线**：即使关闭本地电脑或断网，Agent 依然可以在云端虚拟机中持续运行（如定时抓取资讯、监控数据）。
- **后台任务**：适合处理长耗时的任务，不占用本地资源。

### 2. 安全隔离
- **沙箱机制**：Agent 的所有操作（文件读写、网络请求）都被限制在虚拟机内部，无法触碰用户本地电脑的操作系统或敏感数据（如密码、信用卡信息）。
- **自动清理**：任务结束后，环境会被重置或清理，防止残留数据泄露。
- **物理隔离**：通过云端与本地物理隔离的方式，解决了 [[OpenClaw]] 等本地 Agent 可能带来的“乱删文件”或“病毒植入”风险。

### 3. 可视化与监控
用户可以通过网页端实时查看 Agent 在虚拟机中的操作步骤（如点击、输入、跳转），增加了执行过程的透明度。

## 应用场景
- **自动化资讯站**：全天候监控并更新网站内容。
- **定时报告**：每天早上自动生成并发送行业日报到邮箱。
- **安全测试**：在隔离环境中运行不可信的代码或脚本。

## 局限性
- **隐私顾虑**：所有数据必须在云端处理，对于对数据隐私极度敏感的企业或个人可能是一个障碍。
- **网络延迟**：相比本地执行，云端交互可能存在轻微延迟。
