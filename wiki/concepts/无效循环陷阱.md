# 无效循环陷阱

**无效循环陷阱**（Ineffective Loop Trap）是指 AI Agent 在执行任务时，一旦陷入错误的假设或方向，往往会在无意义的操作中反复循环，消耗大量 Token 与计算资源，却无法自主纠偏的现象。

## 表现特征
- Agent 在早期阶段做出错误判断后，该错误会逐级传导，引发后续连锁失败。
- Agent 未能意识到路径错误，继续执行无效的探索或修改操作。
- 导致 Token 资源被大量浪费，且最终任务失败。

## 根源
这一陷阱往往与[[证据-行动鸿沟]]有关。Agent 虽然检索到了信息，但无法正确解读或利用这些信息来纠正自己的假设。

## 解决方案
CodeTracer 的研究指出，单纯增加 `max_iterations`（最大迭代次数）并不能帮助 Agent 跳出这一陷阱，反而会加剧资源浪费。有效的解决方案是引入外部诊断系统（如 Trace Agent），精准定位错误起点并强制中断错误链，通过[[反思回放]]机制引导 Agent 回到正轨。
