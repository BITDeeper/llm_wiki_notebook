# 结构化中间表示

[[结构化中间表示]] (Intermediate Representation, IR) 是指介于高层抽象（如自然语言意图）和底层执行（如可执行代码）之间的一种数据结构或配置形式。

## 在 Vibe Graphing 中的作用

在 [[Vibe Graphing]] 范式中，[[结构化中间表示]] 扮演了核心角色。它通常以 JSON、YAML 或特定的图结构格式存在，用于描述系统的拓扑结构、角色定义和连接关系，而不包含具体的实现语法。

## 优势

1.  **降低 Token 成本**：相比于生成几百行 Python 代码，生成一段描述拓扑的 JSON 配置消耗的 Token 数量呈指数级下降。
2.  **平台无关性**：IR 不依赖于特定的编程语言，便于在不同后端之间迁移。
3.  **易于验证**：结构化数据比自由文本更容易进行语法校验和逻辑检查，减少 AI 幻觉导致的运行时错误。
