# 价格锚点错位

AI 厂商高企的 API 定价与订阅套餐之间的百倍级差价，构成 AI 中转站套利基础的核心经济现象。

## 具体数据

- **OpenAI**：订阅 Pro 套餐 200 美元/月，同等调用量走 API 折算高达数千美元/月，差距百倍级别
- **Claude**：Max 订阅约 200 美元/月，可承载的 API 调用量按官方定价折算价值 400-600 美元

## 形成机制

AI 厂商有意用高企的 API 定价充当「价格锚点」，让订阅套餐显得划算。但大量用户不需要订阅、只想临时调用——这个缝隙就是中转站的存在逻辑。
