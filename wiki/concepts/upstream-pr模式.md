# Upstream PR模式

向开源项目主线（upstream）提交代码并争取合入的协作模式，区别于私有Fork适配。是 [[摩尔线程]] 在国产GPU生态策略中的核心方法论。

## 实践数据

截至2026年5月12日，摩尔线程在 [[sglang|SGLang]] 主线：
- 累计提交47个PR
- 41个已合入主线
- 完成从环境构建到分布式推理的全链路打通

## 与私有Fork的区别

- **私有Fork**：拉分支做适配，不提交上游。主线更新后适配版本成为无人维护的孤品
- **Upstream PR**：代码合入主线，可持续跟随社区迭代，每次更新自动受益

## 工程闭环

Upstream PR模式不仅是提交代码，而是包含一整套工程闭环：环境构建 → PR提交 → CI自动化测试 → Release发布 → 文档维护。这种可持续模式才是真正掌握生态话语权的方式。
