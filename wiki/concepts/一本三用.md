# 一本三用

“一本三用”是指在一台物理笔记本上，通过虚拟化和容器技术同时运行三种操作系统环境，以满足不同场景需求的概念。

## 实现方式
1. **Host OS (宿主系统)**：通常是 Linux（如 [[mtt-aibook]] 上的 [[mt-aios]]），用于核心的 AI 开发和编程工作，提供原生的性能和兼容性。
2. **安卓容器**：在 Linux 桌面上直接运行安卓应用，满足移动端应用（如社交软件、手游）的使用需求。
3. **Windows 虚拟机**：通过 KVM 虚拟化技术运行 Windows 系统，支持 GPU 直通，用于处理必须依赖 Windows 的办公软件、游戏或特定测试环境。

## 解决的问题
该方案主要解决了 Linux 开发机在日常使用中的局限性：
- **办公兼容性**：解决了 Linux 下办公软件生态不足的问题。
- **娱乐需求**：解决了 Linux 下游戏和特定应用无法运行的问题。
- **设备精简**：开发者无需同时携带开发本和办公本，实现“双面特工”式的工作流。
