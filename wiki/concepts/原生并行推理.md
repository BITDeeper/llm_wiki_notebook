# 原生并行推理

原生并行推理是指让 AI 模型在一次思考中**同时衍生并维护多条候选推理路径**，并在关键节点进行分支与聚合，最终合成最优解的推理能力。其核心在于将「并行性」内化为模型的**原生认知能力**，而非外部工程技巧。

## 背景：传统链式思维的局限

[[链式思维]]（Chain-of-Thought）采用顺序生成推理步骤的方式，在复杂推理场景中存在明显瓶颈：

- **发散不足**：只沿单一路径探索，缺乏多角度尝试
- **易被早期错误带偏**：后续推理建立在可能有误的前置判断上
- **自我纠错弱**：缺乏交叉验证机制
- **效率受限**：顺序生成的计算效率天然受限

## 核心特征

原生并行推理区别于「模拟并行」或「脚本化并行」，具备以下特征：

1. **自适应分解**：模型自主决定何时分叉、分叉多少条路径
2. **多样化并行规划**：不同分支独立探索不同解题策略
3. **可靠聚合**：在汇聚点进行交叉验证、比较与合并
4. **KV Cache 共享**：不同分支共享公共前缀的计算状态，避免重复计算

## 典型推理结构

```
<guideline> → 并行产生若干独立 plan
<step>      → 每个 plan 独立并行展开推理
<takeaway>  → 整合与交叉验证，输出最终结论
```

## 意义

原生并行推理是扩展 [[测试时计算扩展]] 能力边界的关键手段，类似 MapReduce 的分而治之思想在认知层面的实现。[[native-parallel-reasoner|NPR]] 是该方向的代表性工作，证明了原生并行推理在准确率和效率上的双重优势——且加速比随任务难度增加而增大。
