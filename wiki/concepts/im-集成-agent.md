# IM 集成 Agent

[[im-集成-agent]] 指将 AI 智能体直接接入即时通讯软件（如飞书、微信、Slack），使其作为群成员或助手存在，用户无需切换应用即可在日常工作流中调用 AI 能力。

## 特点

- **入口融合**：AI 成为聊天列表的一部分，交互方式接近人与人之间的沟通。
- **被动与主动交互**：既支持用户 @ 机器人发起任务，也支持机器人定时推送信息。
- **群协作**：机器人可以参与群聊讨论，执行如舆情监控、会议纪要等协作任务。

## 案例

[[autoclaw]] 支持一键接入飞书，用户可以在飞书群中直接指挥 Agent 执行资讯搜集或监控任务。
