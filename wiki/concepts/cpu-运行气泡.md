# CPU 运行气泡

CPU 运行气泡是指在 CPU 执行指令流水线过程中，由于各种原因（如缓存未命中、分支预测失败、指令依赖阻塞）导致的空转周期。在这些周期内，CPU 无法执行有效的计算任务，类似于俄罗斯方块中堆砌不规则形状产生的空隙。

## 成因

英特尔用“送外卖”的比喻形象地解释了运行气泡的成因：
- **外卖送错（缓存未命中）**：CPU 需要的数据不在缓存中，需要从内存重新获取，导致等待。
- **用“猜”的方式送餐（分支预测失败）**：CPU 猜测下一步执行路径，如果猜错则需要清空流水线重来。
- **等餐超时（前端阻塞）**：指令解码或分发速度跟不上执行单元的速度。
- **爬楼梯送餐（微架构热点）**：多个指令争用同一个执行资源，导致拥堵。

## 影响

运行气泡直接降低了 CPU 的执行效率和 IPC（每时钟周期指令数）。大量的气泡意味着算力资源的浪费，即使 CPU 的主频很高，实际性能也可能大打折扣。

## 消除方法

消除 CPU 运行气泡是 CPU 优化的核心方向之一。方法包括：
- **硬件级优化**：改进分支预测器、增加缓存容量、优化执行端口。
- **软件级优化**：如 [[ibot]] 技术，通过动态替换低效指令来减少气泡，提高指令级并行度（ILP）。
