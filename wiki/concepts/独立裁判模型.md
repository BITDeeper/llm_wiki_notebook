# 独立裁判模型

独立裁判模型是 [[claude-code|Claude Code]] [[goal模式]] 的核心设计：用独立的小模型验收任务完成情况，避免"做事的人和验收的人是同一个"。

## 工作原理

1. 开发者设定完成条件（如"test/auth 目录下所有测试通过且 lint 无报错"）
2. Claude 开始执行任务
3. 每完成一轮，系统将对话记录和完成条件发送给独立小模型（默认为 [[haiku|Haiku]]）
4. 裁判模型判断是否完成：
   - **未完成**：返回具体理由（如"test_login.py 还有 2 个 failure"），理由注入 Claude 下一轮上下文
   - **已完成**：目标自动清除，任务结束

## 关键约束

- 裁判模型不调用任何工具，不读文件，不跑命令
- 仅基于 Claude 在对话中产出的内容进行判断
- 完成条件必须是 Claude 在对话中能证明的东西
- 完成条件最长支持 4000 字符，可加约束（如"不修改其他测试文件""20 轮内完成否则停止"）

## 设计哲学

解决了 AI Agent 自我评估的根本缺陷：如果让执行者自己判断是否完成，存在天然的利益冲突。独立裁判模型引入了"分权制衡"的思路。
