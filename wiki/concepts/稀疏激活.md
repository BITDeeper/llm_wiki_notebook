# 稀疏激活

**稀疏激活**（Sparse Activation）是 [[mixture-of-experts|MoE]] 架构的核心机制。与稠密模型中每个 token 激活所有参数不同，稀疏激活使得每个 token 只调用少量专家（即模型参数的一个子集），从而在控制计算成本的同时大幅扩大模型总参数量。

这一机制是 MoE 能够实现"参数量大但计算量可控"的关键，但也带来了路由决策的挑战——如何为每个 token 选择最合适的专家子集。[[mp-moe|MP-MoE]] 正是针对这一路由决策问题提出了改进方案。
