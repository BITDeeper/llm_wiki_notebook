# 审查瓶颈

审查瓶颈（Review Bottleneck）是指开源项目中核心审查者数量有限，提交的 pull request 数量超过审查者处理能力的问题。在 AI 编程工具普及后，这一问题进一步恶化。

## 在 Zig 项目中的表现

- 项目有 200 个未处理的 pull request
- 代码审查主要由少数核心团队成员负责
- AI 生成的低质量 PR 挤占了审查资源
- 耐心等待的其他贡献者的代码得不到及时审核

## 与 AI 代码禁令的因果关系

[[审查瓶颈]] 是 [[ai代码禁令]] 最直接的现实动因。[[andrew-kelley]] 将 AI 辅助贡献称为"负价值"，正是因为它们不仅没有带来有效贡献，反而消耗了稀缺的审查资源，拖慢了整个项目的节奏。
