# 经验自蒸馏

经验自蒸馏是指 Agent 在冻结参数的状态下，回看自身成功与失败轨迹，自动总结出简洁、可复用经验策略的过程。这一概念由 [[evolver-agent|EvolveR]] 框架（ICML 2026）系统化提出。

## 核心机制

1. Agent 完成任务后生成完整执行轨迹（包含成功和失败案例）。
2. 冻结模型参数，对轨迹进行反思和总结。
3. 提炼出简洁的经验原则（如"遇到比较类问题，先分别收集两个对象的信息再下结论"）。
4. 经验进入经验库，经过[[经验库动态维护]]后供后续任务检索使用。

## 与传统蒸馏的区别

传统知识蒸馏是从大模型（教师）向小模型（学生）转移知识。经验自蒸馏则是 Agent 从自身轨迹中提取经验，教师和学生是同一个模型。这带来了[[认知对齐]]效应——自我蒸馏的经验比外部强教师总结的经验更符合自身能力边界和推理习惯。

## 与相关概念的关系

- **[[自进化架构]]：** 经验自蒸馏是自进化在"经验层面"的具体实现，与 [[evolver]]（代码级自进化）形成互补。
- **[[递归式自我改进]]：** 经验自蒸馏的闭环（从经验中学习→改进策略→生成更好经验）是递归式自我改进的一种具体实现形式。
- **[[办公技能框架]]：** 经验自蒸馏挑战了"Skill 必须由人类编写"的前提，提出 Skill 可由 Agent 自身经验蒸馏生成。
