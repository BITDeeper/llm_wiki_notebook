# Checkpoints

Checkpoints 是 [[entire]] 提出的一种技术，旨在解决 AI 编程中的上下文丢失问题。它将 AI 编程时的上下文和推理过程作为版本数据的一部分存入 Git。

## 痛点
当前的 AI 编程会话是短暂的：
- 提示词存活于终端中
- 推理过程存于上下文窗口内
- 一旦关闭会话，产生代码的决策、约束和迭代便消失无踪
- Git 保存了变更内容，但关于“为何如此变更”的信息却无一保留

## 解决方案
Checkpoints 在提交由智能体生成的代码时，自动捕获完整会话记录，包括：
- 对话记录
- 提示词
- 涉及文件
- Token 使用量
- 工具调用

这些上下文数据成为语义推理层的一部分，实现了代码的 [[数字谱系]]。

## 价值
1. **可追溯性**：代码评审时能关注大模型推理时的意图和约束，而不仅仅是修改的代码行。
2. **无缝交接**：接手代码时无需重放提示或会话即可继续工作。
3. **减少错误**：编程智能体可以访问历史上下文，停止重复过去会话中已纠正的错误。
4. **降低成本**：减少因重复推理和上下文重放带来的 Token 消耗。
