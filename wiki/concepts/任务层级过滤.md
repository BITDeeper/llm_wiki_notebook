# 任务层级过滤

任务层级过滤是一种基于安卓 Activity 层级的视觉隔离机制，用于保护用户隐私。它将每一次 Agent 的行为抽象成一个「任务」，并仅允许 Agent 抓取当前任务相关的应用界面。

## 工作原理
系统通过物理隔离的方式，限制了 Agent 的视觉感知范围：
- **允许抓取**：当前任务对应的主应用界面。
- **隔离屏蔽**：画中画（PIP）、安全键盘、通知栏悬浮窗等非当前任务层级的内容。

## 实证案例
在 [[豆包手机]] 的测试中，当开启 B站 画中画模式并让 Agent 操作主屏时，Agent 截取的画面完全忽略了悬浮窗。这证明了 Agent 并非读取物理屏幕输出流（即简单的录屏），而是基于任务层级进行针对性的数据抓取。

## 价值
任务层级过滤提供了一种比单纯的「数据不上传」或「不监听」承诺更务实的隐私保护思路。它通过工程上的「物理隔离」，从底层机制上降低了 AI Agent 滥用权限的风险，回应了公众对 AI 全天候录屏监控的担忧。
