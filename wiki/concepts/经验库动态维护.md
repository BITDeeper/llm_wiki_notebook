# 经验库动态维护

经验库动态维护是 [[evolver-agent|EvolveR]] 框架中确保经验库始终高效的核心机制。与传统 Agent 记忆系统直接保存原始轨迹或自然语言反思不同，EvolveR 强调对经验进行持续的质量管理。

## 核心机制

1. **使用追踪：** 每条经验记录使用次数和成功次数。
2. **动态评分：** 根据历史表现计算动态分数。
3. **剪枝：** 分值低于阈值的经验被自动移除。
4. **语义去重：** 语义重复的原则被合并。
5. **合并：** 相似经验被整合为更精炼的原则。

## 解决的核心问题

当 Agent 积累了大量经验后，关键问题不再是"有没有经验"，而是：

- 哪些经验真的有效？
- 哪些经验过时了？
- 哪些经验彼此重复？
- 哪些经验会误导模型？

经验库动态维护确保 Agent 的"大脑"始终轻盈且高效。

## 与相关概念的关系

- **[[vlm质检闭环]]：** 两者都是质量保障机制——VLM 质检闭环关注生成内容的质量，经验库动态维护关注经验本身的质量。
- **[[办公技能框架]]：** 技能框架中的 Skill 由人类维护，经验库动态维护则提出了一种自动化的"Skill 质量管理"范式。
