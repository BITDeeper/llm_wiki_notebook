# 阶梯式思维链解码

阶梯式思维链解码（Staircase Layer-Relay CoT Decoding）是 [[wall-wm|WALL-WM]] 中提出的一种推理加速技术，旨在解决传统思维链（CoT）在机器人实时控制中延迟过高的问题。

## 问题背景

CoT 能提升复杂任务的决策质量，但传统逐 token 串行生成对聊天模型尚可接受，对机器人动作控制来说延迟不可接受。

## 核心思路

将串行逐 token 生成改为「低层只跑一次，高层阶梯式并行展开」：

- **底层**：负责抽取共用的推理状态，只执行一次
- **高层**：多个思维 token 在高层并行完成

## 特性

- 生成的仍是连续 CoT latent，可通过冻结 LLM 还原为文本推理轨迹
- 保留了一定的可解释性
- 显著减少逐 token 解码带来的延迟
- 实现了可解释性与实时性的兼顾
