# 长程推理

**长程推理**（Long-Horizon Reasoning）是指 AI 系统在跨越多个步骤、阶段或较长时间跨度的任务中，保持上下文连贯性、记忆一致性以及逻辑目标导向的能力。具体而言，智能体需要在多轮交互和持续调查中保持状态一致，并逐步收敛到最终答案。这是当前智能体研究中的关键挑战之一。

## 核心特征

- **多轮交互**：推理不是一次性完成，而是需要持续调查和信息获取
- **状态一致性**：在整个推理过程中维护一致的信念状态
- **渐进收敛**：通过逐步排除和细化，最终收敛到答案
- **动态修正**：能够根据新信息修正之前的判断

## 核心难点

长程推理要求 Agent 不仅具备单步解决问题的能力，还需要具备：

1. **目标管理**：在多步骤过程中始终不忘最终目标
2. **状态追踪**：准确记忆和更新系统的当前状态
3. **错误恢复**：在中间步骤失败时能够调整策略而非直接崩溃

目前的 Agent 架构大多基于短期的上下文窗口，缺乏针对长链路任务的专门记忆和规划机制。

## 与现有范式的关系

长程推理是[[任务执行范式]]在推理领域的具体化。传统的单次问答模式无法满足真实世界中医疗诊断、故障排查等任务的需求，这些任务本质上需要智能体在不确定的动态环境中持续协作推理。

## 在 DevOps 中的挑战

在 [[devops-gym]] 的评测中，长程推理被证明是当前 AI Agent 的主要短板。具体表现为：

- **全链路失败**：在需要连续完成 Build → Monitor → Fix → Test 的串行任务中，所有顶级模型的成功率均为 0%
- **注意力涣散**：在长周期的监控任务中，Agent 往往难以在持续的日志流中保持注意力，容易忽略渐进式的异常（如内存缓慢泄漏），或者过度关注早期的观测结果而忽略后续的关键信号
- **上下文丢失**：Agent 难以将构建阶段获取的信息（如环境配置）有效地传递和利用到后续的监控或修复阶段

## GoS 的解决方案

[[graph-of-states|Graph of States（GoS）]] 通过[[共享信念状态]]和[[回溯与下钻]]机制，为长程推理提供了显式的状态管理框架，使智能体能够在多轮交互中稳定维护推理状态，避免[[四类推理失败模式]]。
