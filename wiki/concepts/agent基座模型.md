# Agent基座模型

Agent基座模型是指专为长时间自主执行任务而设计的大语言模型定位，区别于传统面向对话交互的模型。

## 核心特征

1. **长程连贯推理：** 能够在数十小时的连续运行中保持目标一致性和推理质量
2. **工具调用能力：** 支持大规模（上千次）工具调用而不出现退化
3. **抗腐化能力：** 解决 [[上下文腐化]] 问题，避免长任务中的目标遗忘和指令漂移
4. **跨框架稳定：** 在不同执行框架中表现一致，不依赖特定环境取巧

## 与传统模型的区别

传统对话模型优化的是单轮或少量轮次的交互质量，而 Agent 基座模型优化的是长时间、多步骤、多工具的自主任务完成能力。这要求模型具备：

- 持续的目标追踪能力
- 根据反馈动态调整策略的能力
- 在失败时自主切换方案而非陷入死循环的能力
