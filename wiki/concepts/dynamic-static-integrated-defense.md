# 动静结合-三位一体防御

[[动静结合-三位一体防御]] 是一种针对 AI 智能体全生命周期的综合安全架构，由 [[北京航空航天大学]] 团队在开发 [[ClawGuard Auditor]] 时提出。该架构旨在弥补传统安全工具仅具备单一检测手段的局限，通过协同不同阶段的安全机制来应对智能体特有的风险。

## 架构组成

该架构包含三个核心防御层次：

1.  **静态防御（运行前）**：
    *   通过 **静态应用安全测试（SAST）** 实现。
    *   在代码加载或技能运行前，利用词法分析和行为建模技术，提前识别并拦截恶意代码包，防止其进入运行环境。

2.  **动态防御（运行时）**：
    *   通过 **主动安全内核** 实现。
    *   在智能体运行过程中进行透明监管。一旦检测到行为试图触及敏感操作（如系统命令执行），立即接管执行流并阻断未经授权的调用。

3.  **数据防御（全程）**：
    *   通过 **主动数据防泄漏引擎** 实现。
    *   全程监控内存状态与网络出口数据，确保 API Keys、用户凭证等敏感资产不会因模型幻觉或恶意指令而外泄。

## 优势

*   **全面覆盖**：打破了单一防御手段的盲区，覆盖了从代码加载到动态执行的全过程。
*   **纵深防御**：即使某一层防线被突破（例如静态分析未发现的漏洞），后续的运行时监控或数据防泄漏机制仍能提供保护。
