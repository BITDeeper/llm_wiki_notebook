# 多分支群体记忆架构

**多分支群体记忆架构**（Multi-Branch Population Memory Architecture）是一种受软件工程中 Git 版本管理思想启发的 AI 智能体记忆管理系统。它旨在解决科研场景中多路径并行探索、非共识观点保留及失败经验沉淀的问题。

## 背景与痛点
传统的单线程智能体记忆在科研任务中存在显著缺陷：
1.  **记忆覆盖**：迭代过程中的新信息容易覆盖旧信息，导致研究源头无法追溯。
2.  **非共识观点丢失**：少数派或探索性的观点容易被主流观点覆盖。
3.  **失败经验浪费**：失败的实验路径往往被直接丢弃，未能转化为知识资产。

## 架构设计
[[多分支群体记忆架构]] 通过以下机制解决上述问题：
-   **主干认知**：基于海量文献和已验证知识构建的主体认知库。
-   **独立分支**：当智能体启动多个分身并行探索不同科研路径时，每个分身拥有独立的记忆分支与专属数据存储，实现信息隔离。
-   **合并机制**：无论是成功的经验还是失败的教训，经过专业审核后，都会回流至主体认知，并通过广播总线同步至整个记忆网络。

## 优势
-   **双向保护**：既守住了主体认知的安全底线，也为非共识的少数派记忆分支提供了自由探索的安全环境。
-   **知识沉淀**：确保每一次探索（无论成败）都成为系统的“成长养分”。
-   **可追溯性**：保留了科研过程的完整历史记录，便于回溯和审计。

## 应用
该架构已应用于 [[大圣]] 智能体系统，并在上海市科学智能百团百项超宽禁带半导体研发项目中落地，成功支撑起十余个专业智能体的有序协同。
