# 解耦门控 LoRA（Decoupled Gated LoRA）

解耦门控 LoRA 是 [[unividx]] 框架中的关键参数适配机制。该技术为不同模态分配独立的参数空间，并在对应模态作为生成目标时动态激活，从而在统一框架中有效避免不同模态之间的参数干扰。

## 设计动机

在统一多模态生成框架中，不同模态（如 RGB、法线、反照率、光照、Alpha 通道）共享同一基础模型。如果所有模态共享完全相同的参数，模态间会产生相互干扰，降低各任务的生成质量。

## 核心机制

- **解耦**：为每个模态维护独立的 LoRA 参数空间
- **门控**：仅在对应模态作为生成目标时激活相应的 LoRA 参数
- **保留先验**：基础模型参数保持不变，保留预训练扩散模型的原始生成能力

## 与 LoRA 的关系

解耦门控 LoRA 是对标准 LoRA（Low-Rank Adaptation）技术的扩展，在参数高效微调的基础上增加了模态级别的解耦与动态激活机制，使其适用于 [[多模态条件生成统一建模]] 场景。
