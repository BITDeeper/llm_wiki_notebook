# Slash Command (斜杠指令)

一种将复杂工作流封装为简单指令的技术手段，常见于 [[cursor]] 等 AI 编程工具中。

## 工作原理

用户通过输入 `/` 加上关键词（如 `/create-issue`），触发预设的 Prompt 模板。AI 会根据模板执行一系列复杂操作，如调用 API、解析语音、格式化文本等。

## 典型应用

- **`/create-issue`**：口述想法，自动在 [[Linear]] 等项目管理工具中创建包含标题、描述、复现步骤和优先级的工单。
- **`/create-plan`**：根据之前的探索结果，生成详细的 Markdown 格式实施计划。
- **`/update-docs`**：自动更新项目文档，修正 AI 的“长期记忆”，防止其在长上下文中遗忘架构决策。

## 价值

它将产品经理的流程化思维与 AI 的执行能力结合，使得个人能够像指挥千军万马一样管理软件开发流程，是实现 [[一人技术部]] 的关键基础设施。
