# 最小权限原则

最小权限原则是指仅授予 Agent 完成任务所必需的最小权限，避免给予过高系统权限（如关闭端口、访问无关硬件）。

## 必要性
由于 Agent 存在幻觉和逻辑不可控性，若赋予过高权限（如超级管理员权限），可能导致严重的业务事故。
- **反面案例**：[[银泰百货]] 赋予 Agent 端口管理权限，导致堡垒机端口被误关，全司运维瘫痪。
- **风险行为**：[[古茗]] 发现 Agent 申请与业务无关的麦克风权限，存在数据窃听风险。

## 实施建议
- 仅安装业务必需的 Skills 插件。
- 严格审查 Agent 的权限申请请求。
- 避免将核心凭证、API 密钥直接交由 Agent 管理。
