# Token 工厂经济学

Token 工厂经济学是 [[黄仁勋]] 在 GTC 2026 上提出的一套用于评估 AI 商业价值和计算效率的模型。它将 AI 推理视为一种制造业，通过坐标系来定义成本与智能的关系。

## 核心坐标系

该模型在一个二维坐标系中定义 AI 服务：

- **纵轴：Token 吞吐量**
    - 代表工厂的产能。
    - 衡量指标：每瓦能产出多少 Token。
    - 物理约束：数据中心的功率（如 1GW）是固定的上限，因此**每瓦性能决定了一切**。

- **横轴：Token 速率**
    - 代表 AI 的“聪明程度”。
    - 衡量指标：每秒生成多少 Token。
    - 权衡逻辑：模型越大、上下文越长、思考越深（Chain-of-Thought），速率通常越低，但每个 Token 的价值越高。

## 分层定价策略

基于上述模型，英伟达提出了明确的分层定价策略：

1.  **免费层**
    - **特征**：高吞吐、低速率。
    - **目的**：用于获客，覆盖大众消费级应用。

2.  **中间层**
    - **价格**：$3 - $6 / 百万 Token。
    - **服务**：普通用户和一般商业任务。

3.  **高级层**
    - **价格**：$45 / 百万 Token。
    - **服务**：大模型深度推理，需要更复杂的逻辑处理。

4.  **顶级层**
    - **价格**：$150 / 百万 Token。
    - **服务**：超长研究任务、关键路径实时响应（如金融交易、紧急医疗诊断）。

## 商业逻辑

### 功率即货币
黄仁勋强调，一座 1GW 的 AI 工厂永远不会变成 2GW。在功率封顶的前提下，提升每瓦 Token 吞吐量直接等同于降低成本。这解释了为何英伟达不惜代价追求 [[vera-rubin]] 的能效比（比上一代高出 50 倍）。

### 解决订阅制危机
这一模型直接回应了 [[ai-subscription-crisis]]。随着 Agent 任务的高消耗，传统的月费订阅模式失效。Token 工厂经济学提供了一种按“执行结果”和“思考深度”付费的量化标准，使“年度 Token 预算”成为企业招聘和运营的新指标。
