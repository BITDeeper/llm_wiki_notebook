# 文件依赖图

**文件依赖图**是描述工作空间中文件之间血缘、语义依赖和任务支撑关系的图结构。

## 定义与构成

文件依赖图包含以下几类关系：

- **血缘关系**：哪个文件是从哪个文件派生出来的（如某个图表来自三个月前的Excel）
- **语义依赖**：某个结论依赖哪个数据源（如某个策略建议来自一次未归档的会议纪要）
- **任务支撑**：完成某个任务需要哪些文件的协同（如生成全球产品策略报告需要订单CSV、物流PDF、产品信息Excel等多源材料）

## 在Workspace-Bench中的角色

[[workspace-bench]] 围绕388个带有文件依赖图的任务进行评测，平均每个任务需要解析5.1条依赖边、跨越4.7个不同文件。评测不只看最终答案是否像样，还看Agent是否：

- 找对了源文件
- 理解了文件之间的关系
- 使用了正确版本
- 遵循了任务所需的依赖结构

## Node F1 与 Edge F1

文件依赖图的评测揭示了关键发现：

- **Node F1**（节点识别）：Agent能找到相关文件
- **Edge F1**（边识别）：Agent难以判断文件间关系

Node F1 > Edge F1 的发现表明，当前Agent的核心短板不在于"找到材料"，而在于"理解材料之间的关系"。

## 与真实办公的对应

现实工作中，一个报告写得漂亮但数据源错了，比报告写得朴素更危险；一个策略建议语言流畅但证据链断了，反而会放大组织风险。文件依赖图正是将这种真实办公中的隐性知识显性化、可评测化。
