# 零成本监控

[[零成本监控]]（Zero-Cost Monitoring）是一种在长期运行的自动化任务（特别是深度学习模型训练）中，通过避免调用昂贵的 LLM API 来降低运行成本和资源消耗的策略。

## 核心原理

在深度学习实验的循环中，模型训练通常占据绝大部分时间（如 90% 以上）。传统的 AI Agent 可能会在训练期间持续调用 LLM API 来分析中间状态或生成报告，导致成本高昂。

零成本监控策略主张在训练期间**完全切断 LLM API 调用**，转而依赖轻量级的系统级命令来检查任务状态。典型的实现方式包括：

-   **进程检查**：使用 `kill -0 $PID` 检查进程是否存活。
-   **资源监控**：使用 `nvidia-smi` 检查 GPU 利用率和显存状态。
-   **日志追踪**：使用 `tail` 命令查看日志文件的最后几行，确认训练是否正常输出。

## 优势

-   **极低成本**：将长时间运行任务的主要成本（API 调用费）降至零。
-   **稳定性**：避免了因 API 限流、网络波动或 LLM 幻觉导致的监控中断。
-   **效率**：系统命令的响应延迟远低于 LLM API 请求。

## 局限性

该策略假设训练过程中的异常（如代码逻辑错误导致的死循环或数据加载器卡死）会表现为进程崩溃或 GPU 空闲。对于需要复杂逻辑判断才能识别的“软故障”，零成本监控可能无法及时干预，通常需要等待任务超时或依赖人类介入。

## 实际应用

[[Deep Researcher Agent]] 框架是这一概念的典型实践者，通过该策略将每日运行成本控制在约 0.5 元人民币。
