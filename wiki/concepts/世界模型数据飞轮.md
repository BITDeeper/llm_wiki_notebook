# 世界模型数据飞轮

**世界模型数据飞轮** 是指由多智能体世界模型驱动的自我加速循环：更好的世界模型生成更高质量的训练数据，更高质量的训练数据训练出更好的策略，更好的策略产出更多样的交互轨迹，又反哺世界模型的下一轮训练。

## 飞轮循环

```
更好的世界模型 → 更高质量训练数据 → 更好的策略（Policy）
       ↑                                        ↓
  反哺下一轮训练 ← 更多样的交互轨迹 ← 更多 Agent 探索
```

## 与单智能体时代的区别

这个循环在单智能体时代已经有人尝试，但[[多智能体世界模型]]将覆盖范围扩展到了真正有价值的场景——多主体协作、对抗、协调，这些恰恰是[[具身智能数据困境|数据最稀缺]]的领域。

## 关键前提

飞轮能否真正转起来，取决于一个根本问题：生成的多智能体交互数据，物理规律和因果逻辑能否经受真实世界的检验？虚拟环境里学到的规则如果和真实世界对不上，灌再多数据也是噪声。
