# 智能体工作流

[[智能体工作流]]（Agentic Workflow）是指由大语言模型（如 [[GPT-5.4]] 或 [[Gemini 3 Pro]]）驱动的、能够模拟人类专家认知行为并自主执行复杂任务序列的应用模式。它通过将复杂的任务拆解为多个步骤，并结合规划、执行、推理与反馈机制，来实现超越单一模型能力的智能表现。

## 工作流阶段
一个典型的智能体工作流包含以下四个闭环阶段：

1.  **规划**：
    -   利用模型的推理能力，将模糊的宏观指令（如「分析2030年量子传感器的商业化路径」）拆解为具体的子维度研究路径。
    -   使用「后退一步提示」等技术生成动态规划树。
2.  **执行**：
    -   根据规划调用工具（如搜索引擎、数据库）进行信息收集。
    -   处理海量上下文，提取关键信息。
3.  **推理**：
    -   分析收集到的信息，识别逻辑链条。
    -   发现知识缺口，判断是否需要进一步搜索。
4.  **报告**：
    -   综合所有步骤的发现，生成结构化的最终输出。
    -   提供引用来源，确保信息的可验证性。

## 核心特点
- **多步骤推理**：模型作为“Agent 的母体”，能够处理包含多个逻辑步骤的任务，区别于传统的线性对话。
- **高使用率**：在 GPT-5.4 的推动下，OpenAI 的智能体工作流使用率创下新高。
- **长时程任务**：处理长时程、非即时性的复杂任务，维护完整的历史状态和上下文，支持迭代优化。

## 与传统 Chatbot 的区别
| 特性 | 传统 Chatbot | 智能体工作流 |
| :--- | :--- | :--- |
| **结构** | 线性对话 | 动态、可扩展的树状结构 |
| **响应模式** | 追求即时响应 | 处理长时程、非即时性任务 |
| **状态管理** | 无状态 | 有状态（维护历史和上下文） |

## 商业价值
- **收入增长引擎**：成为 OpenAI 收入增长的新动力，区别于传统的订阅或搜索广告模式。
- **企业应用**：Codex 等工具每周服务超 200 万用户，使用量月环比增长超 70%。

## 技术支撑
智能体工作流的实现依赖于强大的基础模型（如 [[Gemini 3 Pro]]）和配套的基础设施（如 [[Interactions API]]）来管理状态和工具调用。
