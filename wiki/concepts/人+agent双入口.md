# 人+Agent双入口

这是一种产品设计哲学，指软件平台同时向人类用户和 AI Agent 开放其核心功能，并将两者视为平等的用户。

## 实现方式
- **人类入口**：提供图形用户界面（GUI），强调可视化、可控性和交互体验，适合需要精细操作和审美判断的任务。
- **Agent 入口**：提供应用程序接口（API）或 Skill 插件，强调自动化、批量处理和逻辑执行，适合重复性高或流程化的任务。

## 设计理念
这种设计承认了 AI Agent 不再仅仅是辅助工具，而是具备独立执行能力的“数字员工”。它反映了 [[任务执行范式]] 的转变：
- **人**：负责定义目标、判断价值、把控审美（即 [[审美法官]]）。
- **Agent**：负责调用工具、执行流程、处理数据。

## 案例分析
[[libtv]] 是这一概念的典型实践者。它允许人类在“无限画布”上精细剪辑视频，同时也允许 [[openclaw]] 等智能体通过 Skill 一键生成视频项目画布。两者操作的是同一套底层逻辑和资源，实现了人机协作的无缝切换。
