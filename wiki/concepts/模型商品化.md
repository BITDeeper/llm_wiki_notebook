# 模型商品化

[[模型商品化]] 描述了随着大语言模型技术差异的缩小，模型层逐渐沦为普通商品，导致 API 业务面临价格战和客户流失风险的经济现象。

## 商业风险
对于依赖 API 调用为主要收入来源的 AI 公司（如 [[Anthropic]]），模型商品化是一种“极度危险的商业模式”。客户可以轻易地切换到底层模型，一旦竞争对手提供更便宜或性能相当的 API，现有的客户基础可能会在一夜之间迁移。

## 应对策略
为了应对这一危机，AI 公司倾向于从提供“工具”转向构建“平台”或“基础设施”。通过构建 [[全栈应用构建系统]]，公司试图在模型层之上建立 [[平台锁定]]，控制用户的数据、工作流和部署环境，从而增加用户的迁移成本。
