# 视觉智能体

视觉智能体是具备视觉感知能力，并能通过工具使用（特别是代码执行）来解决复杂视觉任务的 AI 系统。

## 核心特征
1.  **感知**：能够接收并理解图像或视频输入。
2.  **行动**：能够调用外部工具（如 Python 解释器、图像处理库）对输入进行操作。
3.  **推理**：能够结合感知结果和工具反馈进行逻辑判断和决策。

## 与传统视觉模型的区别
传统视觉语言模型（VLM）通常是“端到端”的，直接输出文本答案。而视觉智能体引入了中间的**行动层**：
*   **VLM**: 图像 -> 模型 -> 答案
*   **视觉智能体**: 图像 -> 模型 -> 工具执行 -> 反馈 -> 模型 -> 答案

## 典型案例
[[swe-vision]] 是典型的视觉智能体，它利用代码执行作为行动手段，将视觉问题转化为计算问题，从而在需要高精度的任务中超越了传统模型。
