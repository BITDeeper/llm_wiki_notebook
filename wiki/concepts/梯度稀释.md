# 梯度稀释（Gradient Dilution）

梯度稀释是指在序列级奖励的强化学习训练中，极少数关键 Token 的梯度信号被大量普通文本 Token 淹没的现象。

## 问题背景

在 [[atlas-视觉推理|ATLAS]] 的视觉推理输出中，[[functional-token|Functional Token]] 只占极小比例。当使用标准的 Sequence-level Reward（如 GRPO）进行训练时，奖励信号会均匀地分配给序列中的所有 Token。这意味着大量普通文本 Token 的梯度更新"稀释"了少数关键 Functional Token 应该获得的强化信号。

## 影响

- 模型难以有效学习何时、如何使用关键的视觉操作 Token。
- 训练效率降低，关键能力提升缓慢。
- 可能导致模型无法真正掌握视觉推理的核心操作。

## 解决方案

[[la-grpo|LA-GRPO]] 算法通过 Token-level Anchor 机制直接针对 Functional Token 位置进行梯度增强，有效缓解梯度稀释问题。

## 一般性意义

梯度稀释不限于视觉推理场景。在任何需要模型在长序列中精准使用稀疏特殊 Token 的任务中（如工具调用、代码生成中的关键语法节点），都可能面临类似挑战。LA-GRPO 的 Token-level Anchor 思路具有通用参考价值。
