# Rubrics（评价量规）

## 定义

Rubrics（评价量规）是一组自然语言形式的评价标准，每个标准对应一个具体、可评估的质量维度。其核心作用是将模糊的"好答案"拆解为明确的评价项，使评审者或 [[llm-as-a-judge|Judge Model]] 能够逐项检查和打分。

一个 rubric set 由若干 rubric item 组成，每个 item 包含自然语言描述和重要性权重。对于输入任务和模型输出，judge model 逐项给出分数，再通过平均、加权求和或隐式聚合得到整体评价。

## 概念区分

| 概念 | 解决的问题 | 特点 |
|------|-----------|------|
| **Rubrics** | 按什么标准评 | 显式、结构化的评价标准 |
| [[llm-as-a-judge\|LLM-as-a-Judge]] | 谁来评 | 用大模型作为评审者 |
| Reward Model | 给多少分 | 通常输出标量分数，标准隐含在参数中 |
| RLVR | 如何验证 | 依赖自动可验证答案，适合有标准答案的任务 |

Rubrics 更适合需要多维度判断、难以完全验证的开放式任务。

## 四类构造方法

综述将 Rubrics 构造方法划分为四类，呈现从简单到复杂、从静态到动态的演化路线：

1. **直接生成**：给定任务指令、候选答案或参考证据，强大的 LLM 一次性生成评价标准
2. **对比生成**：输入偏好对（高质量vs低质量回答），让模型总结差异，提取更有判别力的标准
3. **迭代优化**：引入验证、分解、过滤流程——检测标准是否能稳定区分偏好对，递归拆分过粗标准
4. **在线与共同演化**：Rubrics 随 policy rollouts 更新，将新出现的错误行为纳入评价标准

## 训练应用

### Policy Model Training
- Judge Model 按 Rubrics 逐项打分，聚合为奖励信号用于 PPO、GRPO 等算法
- **轨迹级 Rubrics**：对 Agent 完整执行轨迹（而非仅最终答案）进行逐项评价，对工具调用 Agent、深度研究 Agent 尤为关键
- **鲁棒奖励聚合**：超越简单加权求和，引入 veto 机制（如医疗安全性违反则 reward 归零）、可学习权重、saturation 机制等
- **生成过程指导**：Rubrics 从"事后打分工具"推进为"生成过程中的指导"——模型先读取 Rubrics 再规划回答

### Reward Model Training
1. **提升可解释性**：奖励模型展示"为什么这个回答更好"
2. **细粒度训练信号**：Rubrics 作为结构化参考单元约束中间分析过程
3. **高质量训练数据**：识别影响质量的核心维度，避免模型学习长度、格式等浅层线索

## 评测应用

- **通用任务**：推理能力、深度研究、开放式生成、Agent 能力、对齐评测
- **专业领域**：医疗（医学正确性、安全风险、沟通质量）、法律（事实适用、过程可审计）、金融（风险披露、实务可操作性）

## 开放挑战

- [[reward-hacking|Reward Hacking]]：模型学会利用评价标准表面特征获取高分
- **泛化困难**：Rubrics 过拟合特定任务或领域
- **评测偏差**：Rubric 写法和 Judge Model 选取引入 bias
- **个性化与安全冲突**：过度迎合用户偏好可能削弱安全约束
- **Rubrics 作为攻击面**：恶意改写评价标准可能悄悄改变模型行为
- **信息损失**：多维 Rubrics 聚合为标量奖励时的信息损失问题

## 意义

Rubrics 是大模型训练与评测中的**显式质量接口**。随着大模型走向开放式、高风险和 Agentic 应用，系统需要的不只是更强的生成能力，还需要更清楚的质量定义。Rubrics 让"好答案"不再只是模糊直觉，而成为可以讨论、检查、修改和优化的明确标准。
