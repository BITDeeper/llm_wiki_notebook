# 上下文飞轮

上下文飞轮是[[workbuddy企业版]]团队协作能力中描述的组织资产持续积累的正反馈机制。

## 飞轮循环

```
任务启动 → 团队协作 → 过程沉淀 → 结果交付 → 资产复用 → 任务启动...
```

每转一圈，组织资产就变厚一层。

## 核心机制

1. **共享上下文**：项目空间中的成员、助理、聊天记录、中间产物、业务资料、任务进展都成为团队AI理解和分析的基础
2. **过程沉淀**：团队协作中产生的技能沉淀为团队AI资产
3. **资产复用**：一个人调用AI完成的成果成为全队可复用的能力
4. **经验积累**：下一次遇到类似任务可直接复用之前沉淀的知识、流程和Skill

## 与其他概念的关系

- 是[[办公技能框架]]在组织层面的动态化实现
- 与[[具身数据飞轮]]形成有趣的对照：后者是技术层面的数据闭环，上下文飞轮是组织层面的知识闭环
- 是[[超级个体到超级团队]]跃迁的核心机制
