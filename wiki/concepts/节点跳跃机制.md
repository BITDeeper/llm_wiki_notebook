# 节点跳跃机制

节点跳跃机制是 [[mango-多智能体流网络优化|MANGO]] 框架中用于降低计算开销的工程优化策略。其核心思想是：一旦某个节点的提示信息得到充分优化，进一步更新带来的收益微乎其微，因此可以选择性跳过这些节点。

## 工作原理

1. 在优化过程中，框架评估每个节点的优化充分程度
2. 选择性跳过已充分优化的节点，不对其进行提示词更新
3. 被跳过节点的输出使用训练工作流中的真实步骤填充（重用历史中间步骤）
4. 通过 Skip-k 参数控制每次最多跳跃 k 步（无跳跃时为 Skip-1）

## 效果

在 MANGO 框架的实验中：
- **Skip-3 设置**：训练时间缩短 41.5%，推理时间缩短 47.4%
- API 成本达到最低水平
- 在保持最高准确率的同时显著降低计算开销

## 潜在风险

- 用历史步骤填充跳过节点的输出，可能在分布外任务上引入偏差
- 跳过判断的标准和阈值需要谨慎设计
- 论文未充分讨论在高度动态或新颖任务场景下的表现

## 工程意义

节点跳跃机制体现了多智能体系统优化中的实用主义思想：并非所有组件都需要持续优化，识别并跳过已收敛的组件可以大幅提升系统效率。这种思路对大规模多智能体系统的工程化部署具有重要参考价值。
