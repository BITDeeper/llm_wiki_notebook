# 可观测性轨迹

可观测性轨迹是 [[nemoclaw]] 方案中 Agent 决策过程的完整记录机制，确保 Agent 行为"非黑盒"。

## 记录内容

Agent 每一步的决策都会以轨迹形式记录：
- 使用了哪个技能
- 调了哪个工具
- 传了什么参数
- 回了什么内容

## 查看工具

通过 NeMo Relay 和 Arize Phoenix 查看 Agent 的决策轨迹。

## 意义

出了问题有迹可查，解决了传统 Agent 系统的"黑盒"问题。这与 [[场景白盒化推理]] 的理念一致——将 AI 生成过程从不可见转变为可见、可审计。
