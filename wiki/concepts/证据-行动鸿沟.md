# 证据-行动鸿沟

**证据-行动鸿沟**（Evidence-to-Action Gap）是指在 AI Agent 执行任务过程中，虽然能够检索到有效的信息（证据），但无法将其转化为正确的决策（行动）的现象。

## 现象描述
根据 CodeTraceBench 的数据分析：
- 失败轨迹中无效步骤占比约 40%，接近成功轨迹（22%）的两倍。
- 正确的状态变更步骤从 30% 降至 21%，而探索信息获取能力下降并不明显。

这意味着 Agent 失败的主要原因往往不是“找不到关键信息”，而是“面对正确信息时做出了错误决策”。

## 核心症结
这一鸿沟揭示了当前 Agent 系统的一个核心瓶颈：单纯增加检索能力（RAG）或迭代次数（重试）并不能解决根本问题。提升 Agent 的决策转化能力（即如何利用证据）才是关键。

## 应对策略
[[CodeTracer]] 的[[反思回放]]机制正是为了解决这一问题而设计。通过提供清晰的错误根因提示，帮助 Agent 修正早期的错误假设，从而跨越证据与行动之间的鸿沟。
