# 龙虾

“龙虾”是 2026 年初 AI 行业内的一个特定术语或隐喻，指代当时爆火的 Agent 浪潮或相关的 Agent 生态/产品。

## 背景与含义
- **时间点**：2026 年开年。
- **指代对象**：可能指代某个具体的 Agent 平台（如 OpenAI 的 Agent 相关产品），或者泛指当时兴起的“养成型 AI”热潮。
- **关联**：文中提到“今天，你养虾了吗？”，暗示这与 [[OpenClaw]] 或类似的智能体养成/自动化项目有关。

## 行业影响
“龙虾”现象被视为 [[Agent]] 时代加速到来的标志，引发了关于 [[Skill]] 取代 [[APP]] 的广泛讨论。
