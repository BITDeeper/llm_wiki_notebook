# 推理强度分级

指 AI 模型可按不同档位（如 Extra-High / High / Medium）运行，档位直接决定输出质量与 Token 消耗量的机制。

## 核心特征

- **档位与质量强相关**：[[claude-opus-4-8|Opus 4.8]] 在 Extra-High 模式下高级工程师基准得分 63，降至 High 后暴跌至 42
- **档位与成本强相关**：高强度模式 Token 消耗极高，低强度下 Opus 4.8 的 Token 消耗几乎等于前代模型高强度水平
- **策略差异**：[[gpt-5.5|GPT-5.5]] 倾向于用更少 Token 拿到更高分数，Opus 4.8 则走向用海量 Token 堆砌智能的反面

## 行业影响

推理强度分级机制暴露了 [[tokenmaxxing|Token 吞吐量最大化]] 趋势的阴暗面：模型厂商通过拉高推理强度来刷榜，但用户在实际使用中因 [[ai-subscription-crisis|额度限制]] 无法持续享受最高档位的服务，导致"跑分神"与"体感差"的鸿沟。
