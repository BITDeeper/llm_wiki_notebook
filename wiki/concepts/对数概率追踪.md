# 概述

[[对数概率追踪]]（Log-Probit Tracking）是一种用于在 [[灰盒环境]] 下检测云端大语言模型是否发生隐秘变动（如 [[模型调包]] 或降级）的技术。它通过分析模型输出的对数概率分布，将其作为识别模型身份的“数字指纹”。

# 工作原理

在灰盒环境中，虽然用户无法直接访问模型权重，但可以通过API获取每个输出Token在词汇表上的对数概率分布。由于模型的权重、量化程度或架构的任何变动都会导致这一概率分布发生偏移，对数概率成为了监测后台变动的敏感指标。

为了克服硬件调度和批处理逻辑带来的随机噪声，该技术通常采用以下流程：
1. **极简探测**：向API发送极短的提示词（如单个字符“x”），并请求生成单个Token。
2. **重复采样**：对同一请求进行多次采样（N次），以建立统计基准。
3. **统计比对**：利用均值绝对距离算法计算新采样与基准分布之间的差异。
4. **显著性检验**：结合排列检验来验证观测到的差异是否具有统计学显著性，从而区分硬件层面的正常抖动与模型层面的本质变更。

# 技术优势

- **极高灵敏度**：能够捕捉到仅经过一个训练步数微调所带来的模型特征演变。在针对模型权重修剪的压力测试中，其敏感度达到了现有主流方案的512倍。
- **极低成本**：由于仅需极短的输入和单个Token的输出，其监测成本相比传统的大型基准测试方案缩减为原来的千分之一。
- **实时性**：适合作为持续监控手段，能够快速发现模型服务的一致性问题。

# 局限性

该技术依赖于API提供商开放对数概率接口，因此仅适用于灰盒环境，无法应用于完全封闭的 [[黑盒环境]]。
