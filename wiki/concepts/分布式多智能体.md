# 分布式多智能体

**分布式多智能体**（Distributed Multi-Agent）是一种将多个 AI 智能体视为一个计算集群的架构设计理念，强调通过分布式系统架构实现大规模并行协作，而非简单的角色扮演对话。

## 核心特征
- **计算集群视角**：将多个 Agent 视为可无限扩展的计算节点，而非独立的对话实体。
- **工程化确定性**：关注如何组织多个 AI 像工程师团队一样并行协作，解决工业级容错和扩展问题。
- **容错与自愈**：通过分布式架构（如 [[actor-模型]]）实现任务级的容错、重启和扩容，避免单点故障导致整个系统崩溃。

## 与传统 Agent 的区别
- **传统 Agent**：通常指单体模型或简单的“Cosplay Agent”（角色扮演对话），缺乏系统级的容错和调度能力。
- **分布式多智能体**：引入了消息总线、并发控制和状态管理，能够处理数百级智能体的任务并行。

## 应用案例
[[eigent]] 是该理念的一个典型实现，它通过分布式消息总线支持大规模 Agent 协作，并实现了对终端的直接控制。
