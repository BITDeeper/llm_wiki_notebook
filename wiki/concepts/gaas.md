# GaaS (Agentic as a Service)

**Agentic as a Service**（智能体即服务），指企业 IT 从销售软件工具转向出租具备实际执行能力的 AI 智能体的新商业模式。

## 从 SaaS 到 GaaS 的转变
在 [[openclaw]] 出现之前，企业 IT 的范式是“数据中心 + 软件工具 + 人类数字工人”。软件供应商通过 SaaS（Software as a Service）模式提供工具，但实际的操作和决策仍需人类完成。

随着 AI 智能体技术的发展，这一范式正在发生根本性转变：
- **SaaS**：卖工具（如 CRM、ERP 系统），用户自己操作。
- **GaaS**：出租能干活的 Agent（如自动销售、自动客服），Agent 自主操作。

## 核心驱动力
1.  **智能体能力提升**：[[openclaw]] 等操作系统赋予了 Agent 调用工具、读写文件、执行代码的能力，使其具备了替代人类执行数字任务的基础。
2.  **经济逻辑转变**：在 [[token经济学]] 框架下，企业的核心产出变为 Token。GaaS 模式允许企业按“执行结果”或“Token 消耗”付费，而非按“席位数”付费。

## 实施挑战与 NemoClaw 的解法
GaaS 的落地面临巨大挑战：一个能读文件、跑代码、发邮件的 Agent 放进企业内网就是一颗定时炸弹。

[[英伟达]] 推出的 [[nemoclaw]] 试图解决这一问题：
- **安全沙箱**：限制 Agent 的敏感操作权限。
- **混合推理**：日常任务本地化，敏感数据不出内网。
- **硬件绑定**：确保 Agent 运行在可控的硬件基础设施上。

## 行业影响
[[英伟达]] CEO 黄仁勋断言：“每一家公司都需要一个 OpenClaw 战略。” 这意味着未来每一家 SaaS 公司都将被迫转型为 GaaS 公司，否则将面临被具备 Agent 能力的竞争对手淘汰的风险。
