# 原生智能体

原生智能体（Native Agent）是指深度集成在软件核心架构中，而非作为外挂、插件或独立 API 调用存在的 AI 智能体。

## 核心特征
与传统的“外挂式 Agent”相比，原生智能体具有以下显著特征：
1. **架构级融合**：Agent 直接运行在应用的主进程或核心画布中，拥有对底层功能（如文件系统、渲染引擎、节点系统）的直接访问权限。
2. **无缝交互**：用户无需在不同窗口或工具间跳转，Agent 的操作（如生成节点、调整参数）直接反映在主界面上。
3. **深度调度能力**：能够直接调用软件内部的复杂功能模块（如 [[RHTV]] 中的分镜大师、剪辑器），而非仅限于生成文本或图片。

## 应用价值
原生智能体解决了传统 AI 工具中常见的“割裂感”问题。例如，在视频创作中，外挂 Agent 可能只能生成脚本，而原生智能体可以生成脚本后，直接在画布上搭建对应的视频渲染节点并开始渲染，实现了从意图到执行的闭环。

## 相关概念
- [[画布原生]]：原生智能体在可视化界面（如无限画布）中的具体表现形式。
- [[场景白盒化推理]]：原生智能体通常配合白盒化界面，让用户清晰看到 Agent 的决策过程。
