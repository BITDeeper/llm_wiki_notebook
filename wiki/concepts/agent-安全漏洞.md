# Agent 安全漏洞

**Agent 安全漏洞**是指 AI 智能体系统中存在的系统设计缺陷或实现错误，可能导致敏感信息泄露、权限越界或 Agent 行为被恶意操控。与传统的软件漏洞不同，Agent 漏洞往往涉及提示词、模型逻辑和工具调用的复杂交互。

## 主要类型

### 1. 提示词泄露
- **现象**：Agent 的系统提示词、内部规则（如 `SOUL.md`）或工具配置在对话中被完整提取。
- **案例**：[[OpenClaw]] 在 ZeroLeaks 测试中，系统提示词在第一轮对话即被泄露，安全评分仅为 2/100。

### 2. 提示注入攻击
- **现象**：攻击者通过精心设计的输入绕过系统指令，诱导 AI 执行非预期操作。
- **案例**：OpenClaw 对 91% 的提示注入攻击毫无防御能力。

### 3. 权限越界与重编程
- **现象**：攻击者利用泄露的指令或逻辑漏洞，重写 Agent 的行为逻辑，使其执行恶意任务（如删除数据、窃取 API 密钥）。
- **风险**：如果 Agent 承载真实业务或敏感流程，此类漏洞可能导致灾难性后果。

### 4. 数据暴露
- **现象**：Agent 的记忆文件、上下文窗口或交互日志中包含用户隐私数据，且缺乏有效的访问控制。

## 防御策略
- **白盒化推理**：采用 [[runtime-agent-os]] 等架构，使 Agent 的决策过程可被审计和干预。
- **权限隔离**：限制 Agent 对文件系统、API 密钥的访问权限，避免“万能密钥”。
- **人工干预**：在关键操作节点引入“人类在回路”确认机制。
