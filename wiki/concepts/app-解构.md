# APP 解构

APP 解构是指在 Agent 时代，传统独立应用程序（APP）的功能被拆解、剥离，转化为独立的 [[Skill]]（能力单元），并通过 Agent 进行按需调用的趋势。

## 核心逻辑
传统 APP 是一个“功能+界面+数据”的封闭闭环。而在 Agent 生态下：
- **功能剥离**：核心功能被标准化为 API 或 Skill。
- **界面消失**：用户不再通过点击图标和按钮操作，而是通过自然语言指令 Agent 调用功能。
- **入口转移**：APP 不再是流量入口，Agent 成为新的超级入口。

## 驱动因素
- **技术协议**：如 [[MCP]] (Model Context Protocol) 提供了标准化的连接方式。
- **用户需求**：追求更高效、自动化的操作体验，减少在不同 APP 间切换的成本。
- **AI 能力**：大模型理解意图并编排工具的能力日益增强。

## 潜在影响
- **对开发者**：需要重新思考产品形态，是继续维护沉重的 APP，还是转型为轻量的 Skill 提供商？
- **对用户**：拥有更个性化的体验，但可能失去对单一品牌的强感知。
- **对商业模式**：广告位消失、会员页失效，如何基于“调用次数”或“效果”收费成为新课题。
