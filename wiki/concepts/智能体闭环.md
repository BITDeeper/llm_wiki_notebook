# 智能体闭环

**智能体闭环**（Agent Loop）是指实现完全无人值守自动化系统所需的完整循环流程。它不仅仅是让 AI 生成内容，而是让 AI 能够端到端地完成任务并获得反馈。

## 循环流程
一个完整的智能体闭环包含以下步骤：
1.  **提出想法**：智能体生成提案。
2.  **自动审批**：系统评估提案并自动批准（或拒绝）。
3.  **创建任务**：将批准的提案转化为具体的任务和步骤。
4.  **执行任务**：工作节点领取并执行步骤。
5.  **发出事件**：任务完成后发出系统事件。
6.  **触发反应**：事件触发新的智能体行为或提案，回到第一步。

## 工程挑战
根据 [[voxyz]] 的开发经验，构建闭环时容易遇到以下陷阱：

### 1. 竞争条件
当多个执行者（如 VPS 和 Vercel 定时任务）同时尝试领取同一任务时，会导致状态冲突。
- **解决**：确立单一执行者，其他服务仅作为控制平面。

### 2. 任务死锁
触发器创建了提案，但跳过了任务生成步骤，导致提案永远处于待定状态。
- **解决**：建立统一的提案服务入口，确保所有路径都经过完整的审批和任务生成逻辑。

### 3. 资源堆积
当资源（如 API 配额）耗尽时，任务仍在生成并堆积在队列中，导致隐性死锁。
- **解决**：引入 [[容量关口]]，在任务进入队列前进行资源检查，遵循“在关口拒绝，不要在队列里堆积”的原则。

## 扩展机制
为了使系统更像有机体而非机械流水线，可以引入 [[反应矩阵]]，通过概率性触发机制模拟智能体之间的自发互动。
