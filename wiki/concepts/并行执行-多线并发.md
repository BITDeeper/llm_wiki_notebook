# 并行执行/多线并发

一句话触发多个异构任务同时执行的能力。用户发出一条自然语言指令后，系统自动拆解为多个子任务，分配给不同的 AI 能力模块并行处理，各自独立交付结果。

## 核心特征

- **单次输入，多线输出**：用户只需表达一次意图，系统自动拆解并分发
- **异构任务并行**：不同类型的任务（数据分析、内容生成、应用创建等）同时执行
- **独立交付**：每条线的输出独立完成，互不阻塞

## 典型场景

- 数据分析 + 热点研究 + 报告生成三线并行
- 表格 + 图表 + 深度研究 + 交互看板 + 调仓建议五线并发
- 公众号长文 + 小红书种草文 + 视频三格式同步输出

## 技术挑战

- 任务拆解的准确性：如何从一句话中正确识别多个独立子任务
- 资源调度与冲突管理：多线并发时的计算资源分配
- 上下文隔离：不同任务线之间的状态管理

## 开放问题

[[dumate]] 的并行执行是真正的多 Agent 协作还是简单的任务队列？真正的多 Agent 协作需要 Agent 之间能够通信和协调，而任务队列只是独立执行的并行。
