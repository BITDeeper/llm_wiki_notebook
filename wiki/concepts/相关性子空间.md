# 相关性子空间

**相关性子空间** (Relevance Subspace) 是指在大语言模型的 Key 嵌入空间中，通过数学方法提取出的一个低维子空间。该子空间捕捉了当某些 token 与当前问题“相关”时，Key 向量中最显著的变化方向。

## 发现背景

[[SEKA]] 团队通过研究发现，Transformer 模型的 Key 嵌入并非无结构的噪声，而是存在高度结构化的模式。当模型关注特定 token 时，Key 向量会沿着特定的方向发生偏移。

## 提取方法

通过 [[频谱分解]]（具体为奇异值分解 SVD），研究人员可以从对比数据（正向/负向/中性提示）中分离出这种变化方向。

1. **数据构造**：构造包含相关和不相关 token 的对比提示对。
2. **嵌入提取**：提取不同条件下的 Key 嵌入。
3. **SVD 分解**：计算 Key 嵌入差异的奇异值分解，提取主要特征向量作为相关性子空间的基。

## 应用价值

一旦提取了相关性子空间，就可以通过简单的投影操作（$P \cdot k$）来判断或增强一个 token 的相关性。这使得模型能够“听指挥”，优先关注用户指定的内容，而无需重新训练模型。

这一发现为理解 Transformer 的内部机制提供了新的视角，证明了模型内部存在可解释的、结构化的语义空间。
