# 凭证泄露防护

凭证泄露防护是指系统为防止用户认证信息（如用户名、密码、哈希）在非预期情况下被发送给外部服务器而采取的安全措施。

## Windows SMB 凭证泄露漏洞
在 [[OpenClaw]] 的早期版本中，存在一个严重的安全漏洞：
- **攻击原理**：攻击者可以构造特殊的 `file://` 或 UNC（通用命名约定）路径（例如 `\\evil-server\image.png`）。
- **触发机制**：当 OpenClaw 尝试加载这些路径作为媒体资源时，Windows 会自动向远程服务器发起 SMB 认证握手。
- **后果**：用户的 Windows 登录凭证（NTLM 哈希）会被发送给攻击者控制的服务器，导致凭证泄露。

## 防护措施
OpenClaw 3.22 版本通过以下方式修复了此漏洞：
- **路径拦截**：在核心媒体加载和沙盒附件路径处理中，全面拦截并阻止远程路径（`file://` 和 UNC）的解析。
- **白名单机制**：仅允许本地安全的文件路径被加载。

这一更新对于在公网部署 OpenClaw 或处理不可信内容的用户至关重要，是 AI 智能体平台安全化的关键一步。
