# 三层命令架构

[[飞书cli|飞书CLI]]的技术架构设计，被定位为"为Agent而生"的三层命令体系，兼顾易用性、精确控制力和无限扩展性。

## 架构层次

### 第一层：Shortcut
高度封装的命令层，供人和AI共用。一句"帮我查今天日程"即可跑通，降低使用门槛。

### 第二层：API Commands
与飞书OpenAPI一一映射的命令层。当Agent需要精确控制时走这层，确保操作的确定性和可预测性。

### 第三层：Raw API
可调用飞书全平台2500+端点的原始接口层。理论上无限扩展——即便CLI版本还没来得及封装某个新API，Agent也能通过Raw API自己找方案。遇到没见过的接口，Agent可以用schema命令当场查询参数定义和示例值，中途不需要退出工作流去翻文档。

## 设计理念

三层架构体现了"渐进式开放"的设计哲学：简单任务用Shortcut一步到位，复杂任务用API Commands精确控制，边缘场景用Raw API无限扩展。这种设计使Agent的能力边界不再受限于CLI的封装进度。
