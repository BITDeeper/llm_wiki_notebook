# MTP (Multi-Token Prediction)

多 Token 预测（Multi-Token Prediction，简称 MTP）是一种提升大模型推理效率与模型质量的技术。该技术要求模型在每个位置预测未来的多个 Token，而非仅预测下一个。该技术最早在 [[nemotron-3-super]] 中被引入，现已在 [[英伟达]] 的 [[HGX B200]] 平台等场景中得到应用。

## 工作原理

MTP 的核心在于打破传统推理中“逐 Token 生成”的限制，通过在训练和推理阶段引入多步预测机制，实现“一次思考，多步输出”。

### 训练阶段
在训练过程中，模型被强制预测后续的 $n$ 个 Token。这种机制迫使模型更好地理解多步之间的因果关系和更长远的文本结构，从而提升模型对上下文的整体把握能力。

### 推理阶段
在推理时，训练好的 MTP 层充当了内置的“草稿模型”：
1. **候选生成**：预测头会先生成后续几个 Token 的候选（草稿）。
2. **批量验证**：主模型在一次前向传播中验证这些草稿。
3. **并行处理**：这使得 GPU 能够在一次计算中覆盖更多的生成步骤，相当于在解码任务时进行批量处理。

## 优势

MTP 带来了多方面的性能提升，既包括模型质量的改进，也涵盖了推理效率的飞跃：

- **提升模型质量**：证明能显著降低验证集 Loss 并提升下游任务跑分。
- **原生投机解码**：相比于外挂一个独立的草稿模型，MTP 带来的额外算力开销（FLOPs）微乎其微，却实现了投机解码的加速效果。
- **提升吞吐量**：显著增加了单位时间内的生成量。
- **改善交互性**：在延迟要求严格（高交互性）的场景下，收益尤为明显，大幅降低了生成延迟。

## 应用

[[英伟达]] 的 [[HGX B200]] 平台利用 MTP 结合 [[NVFP4]] 技术，在保持精度的前提下实现了吞吐曲线的显著右移。
