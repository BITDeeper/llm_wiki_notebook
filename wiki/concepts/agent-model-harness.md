# Agent = Model + Harness

**Agent = Model + Harness** 是 AI 智能体领域的一个新兴范式公式，强调智能体的效能由模型能力与脚手架工程共同决定。

## 内涵
- **Model (模型)**：提供核心的智能、推理能力和知识库。
- **[[Harness]] (脚手架)**：提供将模型能力转化为实际效用的基础设施，包括提示词工程、工具调用、错误处理等。

## 行业背景
随着 GPT-5、Claude 4、Gemini 3 等前沿模型在能力上逐渐趋同，竞争的焦点正从“谁的模型更强”转向“谁的系统更优”。
- 这一范式标志着 AI 行业从单纯的模型研发转向 **[[任务执行范式]]** 的系统工程阶段。
- 它解释了为什么轻量级模型（如 [[Claude Haiku 4.5]]）可以通过优秀的 [[Harness]] 打败配置糟糕的重量级模型。

## 实践意义
对于 AI 应用开发者而言，这意味着：
1. **不再盲目追求最大参数**：通过优化 [[Harness]]，可以在成本更低的小模型上获得优异性能。
2. **重视工程迭代**：模型是商品，[[Harness]] 工程是构建差异化优势的关键。
3. **自动化优化**：利用 [[Meta-Harness]] 等工具自动发现最佳的 [[Harness]] 配置，而非依赖人工试错。
