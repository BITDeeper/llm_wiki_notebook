# System 0/1/2

**System 0/1/2** 是 [[Figure]] 公司在 [[Helix 02]] 系统中提出的一种三层认知控制架构。该架构借鉴了认知心理学中的系统1与系统2理论，并扩展了 System 0 以处理极低层的全身运动控制，旨在解决高层语义推理与底层物理执行之间的解耦与协同问题。

## 架构分层

### System 2：语义推理系统（慢系统）
- **频率**：低频。
- **功能**：负责高层认知任务，如理解场景语义、解析自然语言指令，并将复杂的宏观任务拆解为一系列子目标。
- **类比**：类似于人类的有意识思考过程。

### System 1：感知-行动系统（快系统）
- **频率**：200 Hz。
- **功能**：充当中间层，将 System 2 的目标转化为具体的全身关节动作。它直接处理所有传感器输入（视觉、触觉等），并输出全身运动指令，实现了 [[pixels-to-whole-body]] 的映射。
- **特点**：将机器人自身状态与环境视为一个强耦合的整体进行推理。

### System 0：全身运动控制系统（极快系统）
- **频率**：1 kHz。
- **功能**：负责最底层的物理执行，包括动态平衡、接触力处理和全身协调。
- **技术实现**：基于大规模人类运动数据训练的神经网络先验，结合 [[sim2real]] 技术。它替代了传统机器人中超过 10 万行手工编写的控制代码。
- **核心价值**：提供了一种通用的运动基础，不针对特定动作，而是学习人类在保持平衡前提下的自然运动模式。

## 设计理念
这种分层架构使得 Helix 02 能够同时满足**智能性**（System 2 的理解能力）、**灵活性**（System 1 的感知反应）和**物理稳定性**（System 0 的鲁棒控制）。System 0 的引入被认为是 Figure 区别于其他依赖传统控制器或单一大模型方案的关键工程突破。
