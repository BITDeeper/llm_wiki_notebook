# 命令中心模式

命令中心模式是指下一代 [[IDE]] 为了适应 [[智能体编排]] 而应采用的界面设计范式。它强调全局掌控、状态可视化和资源管理，而非单纯的代码编辑。

## 设计需求
[[Andrej Karpathy]] 指出，现有的工具（如 [[tmux]]）在管理多 Agent 时显得力不从心。命令中心模式应满足以下需求：

### 1. 全局视图与布局
- 支持全屏或跨多显示器显示。
- 将整个工作区用于展示 Agent 的宏观概览，而非局部的代码片段。

### 2. 视图控制
- **一键显示/隐藏**：快速收起或展开特定 Agent 的视图，避免界面杂乱。
- **分层展示**：能够根据需要聚焦于某个 Agent 或查看全局状态。

### 3. 实时状态监控
- 清晰标识每个 Agent 的当前状态：空闲、执行中、异常。
- 提供视觉提示（如颜色、图标）以便快速识别问题。

### 4. 详细统计信息
- **资源消耗**：显示每个 Agent 的 Token 消耗量、计算资源占用（CPU/GPU）。
- **效能指标**：记录运行时长、任务完成率等数据，辅助优化 [[组织架构即代码]]。

### 5. 快速干预工具
- 支持直接针对某个 Agent 弹出终端或调试窗口。
- 允许开发者在不打断整体流程的情况下进行微调。

## 硬件影响
这种模式对硬件提出了更高要求，也解释了为何开发者可能需要更大的显示器来容纳“指挥中心”式的界面布局。
