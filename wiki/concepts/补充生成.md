# 补充生成

补充生成（Complementary Generation）是 [[fusionroute]] 提出的核心创新机制。路由器不仅负责选择专家，还利用自身的理解能力为当前 token 提供额外的生成信号（router logits），与专家的输出共同作用形成最终结果。

## 工作原理

1. 路由器输出 router logits，与被选中专家的 expert logits 合并
2. 专家提供的 log-ratio 项作为不传梯度的"偏置项"处理
3. 当专家本身已能给出强策略时，偏置项较大，router 自身梯度自然变小
4. 当专家薄弱时，log-ratio gap 缩小，router 获得更大的修正信号

这种机制让路由器在专家失效的位置才发力，自动实现"按需补位"。

## 理论意义

补充生成从根本上解决了纯选择 token 级路由的 [[不可识别性]] 问题。加入补充 logits 后，最终策略的可表达策略类被显著扩张，能够在更弱的假设下恢复近似最优策略。

## 训练方式

通过 CDPO（互补直接偏好优化）阶段训练。关键挑战在于单独训练 router logits 的补充生成能力会导致 router 参数与输出路由权重的线性层不匹配，因此 [[fusionroute]] 设计了混合训练策略，将 SFT 与 CDPO 结合在同一训练流程中。
