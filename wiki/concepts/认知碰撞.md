# 认知碰撞

**认知碰撞**（Cognitive Collision）是 [[群体智能]] 及 [[harness-群体多智能体]] 协同中的核心工作机制，由 [[明日新程]] 在其产品“[[团子]]”中提出并应用。

它指的是多个 AI Agent 针对同一个问题，从不同的视角切入，通过辩论、挑战、反思、同行评审、投票等方式进行深度的思维交互，从而实现思辨与互补，并最终收敛出共识的过程。

## 核心目的

认知碰撞旨在打破单一 Agent 的认知盲区，避免多智能体协同中常见的“[[表演式一致]]”现象（即表面上一团和气，实则缺乏深度思考）。通过真实的观点冲突与逻辑博弈，群体智能能够输出经过权衡的最优解，实现“群体智能大于个体智能之和”。

## 作用与价值

- **提升质量**：模拟人类专家组的决策过程，通过对抗性讨论减少逻辑漏洞和幻觉。
- **控制成本**：其核心目的不是让信息发散，而是让信息在每一层先“收敛”再传递。这种机制有效解决了多智能体系统中的 [[协调税]] 问题，避免了 Token 消耗的指数级增长。

## 实现方式

在 [[团子]] 平台中，认知碰撞体现为几十个 Agent “围坐一桌”，各抒己见、互相补充、辩论交锋，甚至进行投票表决和同行评审。这种机制确保了决策过程的全面性和深度。

## 理论基础

[[明日新程]] 团队认为，人类社会是迄今所知唯一实现了大规模高级认知协同并持续产出的群体。认知碰撞正是借鉴了人类社会的协作模式，将思考过程的同步（而非仅共享结论）作为高效协同的基础。
