# Agent 成本失控

Agent 成本失控是指 Agent 在执行任务（如搜索、数据处理）时，因逻辑错误、死循环或无法自动终止，导致 API Token 持续消耗，造成不可控的成本浪费。

## 案例分析
[[古茗]] 在测试 [[openclaw]] 执行互联网内容搜索任务时，Agent 持续调用 API 超过二十分钟无法自动终止，只能手动停止。由于无法预知搜索次数，成本可能无限膨胀。

## 根本原因
- Agent 的自主执行逻辑缺乏有效的熔断机制。
- 任务拆解过程中可能陷入无效循环。

## 应对思路
- 设置单次任务的最大 Token 消耗阈值。
- 实施实时监控与强制中断机制。
- 利用 [[landing-zone]] 实现成本独立核算与监控。
