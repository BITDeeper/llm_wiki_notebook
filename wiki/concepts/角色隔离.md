# 角色隔离

[[角色隔离]] 是在 [[多智能体协作]] 系统设计中的一种关键技术手段。它通过在 Prompt 中严格限制每个 AI 智能体的职责范围和可调用工具（技能），防止 Agent 越权操作或行为混乱。

## 实施方法
在 Prompt 中明确写入：
1.  **职责定义**：明确 Agent 只能做什么（例如：“只做资料搜集的本职工作”）。
2.  **负面约束**：明确禁止做什么（例如：“禁止越权做其他角色的任务”）。
3.  **技能白名单**：列出 Agent 允许使用的特定技能（例如：“你只能使用 web-search, feishu-bitable 这 2 个技能”）。

## 重要性
- **防止幻觉**：避免 Agent 在面对模糊指令时胡乱执行不属于其能力的任务。
- **系统稳定性**：确保复杂工作流按预定顺序执行，避免并发冲突或逻辑死锁。
- **安全性**：限制 Agent 对敏感文件或高风险 API 的访问权限。

在 [[AI 编辑部]] 中，[[角色隔离]] 被严格执行，例如“总编虾”被禁止调用写作技能，只能调用表格读写技能。
