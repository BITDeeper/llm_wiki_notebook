# Agent 调教方法论

Agent 调教方法论是指用户为了使 AI Agent（如 OpenClaw）更好地适应特定任务和个人习惯而采取的系统化配置策略。它强调 Agent 的表现不佳往往不是因为模型不够强，而是因为配置文件太简陋。

## 调教三要素
[[MiniMax]] 解决方案架构师 [[林心怡]] 提出了“调教三要素”框架：

1.  **Soul（灵魂/底层人格）**
    *   **定义**：决定 Agent 的价值观、性格及思考底线。
    *   **作用**：设定 Agent 的行为基调，例如是毒舌助手还是温和管家。
2.  **User（用户档案/记忆核心）**
    *   **定义**：记录用户的语言风格、习惯和偏好。
    *   **作用**：让 Agent 真正“懂你”，实现个性化交互。
3.  **Agent（行为准则/操作手册）**
    *   **定义**：规定任务来临时第一步做什么、第二步做什么。
    *   **作用**：作为定制化的工作流，确保任务执行的逻辑性和准确性。

## Agent 矩阵
为了解决通用模型在特定任务上表现不佳的问题，方法论建议建立 **“Agent 矩阵”**（专虾专用）：
*   **策略**：不要试图让一只 Agent 干所有的活。
*   **实践**：为不同任务配置专门的 Agent。例如，让专门写文案的 Agent 深度学习 100 篇爆款文章，让做数据分析的 Agent 专注于报表逻辑。
*   **优势**：每只 Agent 的记忆库高度聚焦，能发挥出模型的最大战斗力。

## 核心原则
*   **养虾即带小孩**：靠的是“用心熬”和“精心伺候”。
*   **代码化理解**：养虾本质上是将用户对世界的理解“代码化”到配置文件（如 `soul.md`）中。
