# 机器人世界模型

机器人世界模型（World Model for Robot Learning）是指能够刻画环境状态如何随时间和动作发生变化的预测模型。与通用视频生成模型不同，机器人世界模型的核心问题不是"能不能想象未来"，而是"想象出的未来能否用于控制"。

## 定义与本质

机器人世界模型需要回答的核心问题是：**在当前状态下，如果机器人执行某个动作，未来状态会如何改变？**

这一定义严格区分了机器人世界模型与一般视频生成模型。后者可以生成视觉上合理的视频，但未必具备[[动作一致性]]。对于机器人控制来说，仅有视觉合理性而无法准确反映夹爪动作、接触关系和受力变化的预测，价值有限。

## 三大核心能力

1. **Foresight（前瞻预测）**：在执行前预测动作后果
2. **Imagination-driven Planning（想象驱动规划）**：通过想象 rollout 比较候选行为
3. **Data Amplification（数据扩增）**：通过合成轨迹或演示数据改善策略学习，为解决[[具身智能数据困境]]提供新路径

## 五大架构路线

### 1. 解耦式方法
采用"预测未来，再恢复动作"的两阶段框架。世界模型负责预测"将会发生什么"，策略模块负责把预测结果转化为动作。代表工作：UniPi、VidMan、Vidar、Gen2Act。优势在于模块清晰，但两个模块之间存在接口误差。

### 2. 单骨干紧耦合
使用单一生成骨干同时建模未来视觉状态和动作序列，将视频预测与动作生成放进同一个扩散或流匹配过程。代表工作：UVA、UWA、VideoVLA、Cosmos Policy。

### 3. MoE/MoT 专家混合
视频专家、动作专家和语言理解模块保持参数独立，通过共享注意力、交叉注意力或层间交互实现信息融合。代表工作：Motus、LingBot-VA、BagelVLA。

### 4. 统一 VLA
将预测目标内化到 [[vla-视觉-语言-动作]] 训练过程中，不一定显式调用外部视频世界模型。代表工作：GR-1、WorldVLA、DreamVLA、UniVLA、CoWVLA。

### 5. Latent-space 建模
在隐空间进行世界模型预测，避免显式视频生成的高计算成本，提升推理效率。

## World Model as Simulator

世界模型可作为机器人强化学习训练环境，从"辅助预测器"推进到"训练环境"。策略模型可以在学习到的环境中进行强化学习后训练，也可在测试阶段用世界模型评估多个候选动作。这一范式与 [[sim2real]] 直接关联。

关键挑战：用于策略训练时，模型错误会直接影响策略优化方向，长期稳定性、动作敏感性和奖励一致性是绕不开的问题。

## 评测范式转移

评测标准需要从开环视觉保真度（open-loop visual fidelity）转向[[closed-loop-task-utility|闭环任务效用]]（closed-loop task utility）。世界模型的好坏不应只由"生成得像不像"决定，而应由"是否帮助机器人做得更好"来决定。

## 未来挑战

- **[[动作一致性]]**：模型必须准确反映动作带来的状态变化，而非仅根据历史观测"脑补"未来
- **推理效率**：视频扩散模型计算成本高，需探索 latent-space prediction 等方案
- **[[物理grounding]]**：需融合本体感觉、力觉、触觉和结构化几何表示，超越纯视觉预测
- **与传统方法的结合**：神经世界模型并不必然取代传统规划和控制方法，符号表示、对象关系、因果结构和经典控制仍可能为长时序任务提供更稳定的抽象层

## 与 VLA 的关系

[[vla-视觉-语言-动作]] 策略提供了从视觉和语言到动作的接口，而世界模型补充了对未来物理变化的预测结构。二者结合后，机器人策略不再只是反应式映射，而是有机会引入更强的前瞻性和规划能力。VLA 的泛化能力提升暴露了缺少未来预判的局限，催生了世界模型与 VLA 结合的新研究方向。

## 当前状态

该领域被描述为"快速演化阶段"，尚未收敛到主导架构。不同任务下，解耦式、统一式、专家混合式和 latent-space 方法都可能表现出竞争力，最终效果取决于数据规模、控制频率、任务复杂度、推理成本等具体因素。
