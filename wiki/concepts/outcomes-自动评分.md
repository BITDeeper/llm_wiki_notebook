# Outcomes (自动评分)

**Outcomes** 是 Anthropic 推出的一种针对 AI Agent 输出质量的自动化评估机制，旨在解决 Agent 输出质量不稳定的问题。

## 工作原理

1.  **标准定义**：开发者编写一套评分标准（通常是 Markdown 文件），描述“什么算交付成功”。
2.  **独立评估**：系统分配一个**独立的评估器模型**（Evaluator），在其独立的上下文窗口中对 Agent 的输出进行打分。
3.  **反馈循环**：如果评估器发现问题，会精准指出需要修改的地方，并要求 Agent 重新打磨。
4.  **成本控制**：开发者可以设置最大迭代次数，防止无限循环消耗过多资源。

## 核心优势

### 隔离性
评估器与执行 Agent 完全隔离。这意味着评估过程不会被 Agent 自身的推理逻辑或幻觉带偏，保证了评估的客观性。

### 适用性广
该功能不仅适用于客观任务（如代码正确性），对主观质量评估同样有效，例如：
-   文案语气是否符合品牌调性。
-   设计稿是否遵循视觉规范。

## 性能提升数据

根据 Anthropic 的内部测试，相比标准的 Prompt 循环，Outcomes 将任务成功率提升了显著幅度：
-   **通用任务**：最高提升 10 个百分点。
-   **Docx 文档生成**：成功率提高 8.4%。
-   **PPT 幻灯片生成**：成功率提高 10.1%。

这表明在越难的任务上，自动评分带来的质量提升越明显。
