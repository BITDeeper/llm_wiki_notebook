# AaaS (Agentic as a Service)

**AaaS**（Agentic as a Service，智能体即服务）是一种新兴的商业模式，被视为传统 SaaS（软件即服务）的继任者。它指传统的 SaaS 公司向提供智能体服务的转型，主张按“产出”而非“席位”收费，强调 AI 智能体在后台直接完成任务，而非通过人机交互界面。

## 核心特征

### 1. 按产出计费
与 SaaS 时代按用户数量或席位收费不同，AaaS 根据实际完成的工作量或结果收费。例如，不是按使用法律软件的律师人数收费，而是按审查合同的数量或质量收费。

### 2. 零 UI 交互
AaaS 模式下，用户不再需要通过复杂的图形用户界面（GUI）进行操作。AI 智能体通过 API 直接在后台执行任务，人类仅负责设定目标和审核结果。

### 3. 开放接口
系统的价值不再取决于功能的封闭性和复杂性，而取决于接口的开放性和集成能力。能够无缝接入各种数据源和工具的 Agent 将更具竞争力。

## 驱动因素
这一转型主要由 [[智元经济学]] 驱动。随着 AI 从单纯的对话模型进化为能够执行复杂任务的智能体（如 [[OpenClaw]]），用户的需求从“获取信息”转向“代理执行”。

## 对 SaaS 的颠覆
AaaS 被认为是引发 [[saaspocalypse]] 的底层逻辑，它直接攻击了 SaaS 模式的根基：
- **成本结构**：一个 Claude 智能体能干掉 10 个初级员工的工作量，企业不再需要购买大量 SaaS 席位。
- **价值主张**：SaaS 卖的是“工具”和“流程”，而 AaaS 卖的是“结果”和“解决方案”。
- **市场格局**：传统的软件中间层变得毫无价值，价值流向了拥有最强模型和 Agent 能力的基础模型公司。

## 经济影响与挑战

### 经济循环
- **智元消耗**：智能体需要持续运行和思考，导致 [[智元]] 消耗量远超传统 SaaS 软件调用。
- **预算重构**：企业必须建立 [[智元预算]] 来应对这种持续的高额消耗。
- **产业闭环**：SaaS 转型 AaaS -> 增加推理需求 -> 推动云厂商建设 [[智元工厂]] -> 进一步降低智元成本 -> 刺激更多 AaaS 应用。

### 商业挑战
尽管 AaaS 模式在效率上具有巨大优势，但也面临经济学上的挑战：
- **算力成本**：高产出可能伴随高算力成本（如 AMD 虽营收超预期，但因数据中心成本过高导致利润率下降）。
- **利润率压力**：按产出收费可能导致服务商承担过多的执行风险和成本压力。

## 未来展望
AaaS 代表了从“人类操作软件”向“AI 代理人类工作”的范式转移。随着 [[claude-cowork]] 等产品的出现，这一模式正在迅速重塑企业软件市场，迫使传统软件巨头重新思考其商业模式。
