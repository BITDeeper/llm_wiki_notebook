# Amazon Stateful Runtime Environment

## 概述
[[amazon-stateful-runtime-environment]] 是 OpenAI 与 Amazon 合作中的一项关键技术特性。它允许在交互之间保持记忆、上下文和连续性，从而支持复杂的业务流程。

## 作用
- **从无状态到有状态**：传统的 API 调用通常是无状态的，而该运行时环境使得 AI 智能体能够跨时间段、跨步骤地保持上下文，这对于执行复杂的工作流至关重要。
- **企业级集成**：通过在 AWS 环境和现有治理模型内运行，它降低了受监管行业和安全敏感买家的采用门槛。
- **产品升级**：它将 OpenAI 的产品从单纯的“模型访问”提升为“生产级、长时运行、多步骤智能体”的运行时。

## 战略价值
这一合作弥补了 OpenAI 此前仅通过 Microsoft 合作所留下的市场空白（特别是那些使用 AWS 的企业），是 OpenAI 在 [[平台战争]] 中扩展市场触达的关键一环。
