# 虚拟内存

在 [[Spark 2.0]] 的语境下，[[虚拟内存]] (Virtual Memory) 指的是一种应用于 GPU 渲染的内存管理技术，旨在用有限的显存渲染超大规模的 3D 场景。

## 实现机制

Spark 2.0 会在 GPU 中预先分配一个固定大小的内存池（容量约为 1600 万个 splats），并构建一套页表映射机制。系统将 GPU 中的内存页（每页 64K splats）与数据文件中的数据块一一对应。

当用户在场景中移动时，系统会根据 [[细节层次技术]] 的遍历结果，动态加载高优先级的数据块到空闲内存页中。当内存池占满时，采用 LRU（最近最少使用）算法置换低优先级数据。

## 优势

这种设计允许引擎同时处理多个数据文件，并共享同一个 GPU 内存池，实现了跨对象的加载与存储优化，是突破显存瓶颈的关键。
