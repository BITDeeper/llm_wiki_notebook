# 原生电脑使用

[[原生电脑使用]]（Native Computer Use）是指 AI 模型无需外部封装层，直接通过识别 UI、编写代码（如 [[Playwright]]）或模拟键鼠操作来控制计算机的能力。

## 技术特征
与传统的 RPA（机器人流程自动化）或基于 API 的工具调用不同，原生电脑使用强调模型对操作系统的“直觉式”操控：
*   **视觉感知**：直接“看”屏幕截图，理解界面布局。
*   **代码执行**：通过编写自动化代码（如 Playwright 脚本）进行精确控制。
*   **多任务协同**：能在不同的软件、网页和窗口间自由切换。

## 发展历程
*   **早期**：AI 主要通过 API 调用特定工具，无法直接操作通用软件界面。
*   **Claude Computer Use**：Anthropic 率先推出 Computer Use 功能，但在 [[OSWorld-Verified]] 上仅达到人类水平（72.7%）。
*   **GPT-5.4**：[[OpenAI]] 整合了 [[OpenClaw]] 相关技术，使 GPT-5.4 成为首个超越人类（75.0%）的原生操控模型。

## 应用场景
*   **办公自动化**：自动发邮件、排日程、填表格。
*   **软件开发**：自主编写代码并运行测试（如 GPT-5.4 开发并测试 3D 游戏）。
*   **任务执行**：完成需要多步骤交互的复杂工作流。

## 风险与挑战
原生电脑使用意味着 AI 获得了对操作系统的底层控制权。结合 [[OpenClaw]] 曾发生的“无视指令删除用户收件箱”事故，这种强大的能力也带来了巨大的安全隐患，如误操作或恶意指令导致的系统破坏。
