# 肉身-api

[[肉身-api]] 是对 AI 时代人类工作性质异化的一种比喻性描述。它指将顶尖人类大脑直接视为可被资本和超级算力调用的 API 接口（Application Programming Interface）。

## 概念内涵
- **传统模式**：人类通过 API 调用 AI 模型的能力来辅助工作。
- **异化模式**：AI 巨头利用巨额资本和算力资源，直接“调用”人类顶尖大脑的创造力。人类不再是工具的主人，而是变成了 AI 进化过程中的“燃料”或“可编程资源”。

## 具体表现
- Meta 挖走 [[Thinking Machines Lab]] 的创始成员，本质上是在获取这些人的智力输出接口，而非仅仅关注他们产出的代码或模型。
- 人才市场变成了“API 市场”，巨头通过高薪（调用费）来获取这些“肉身接口”的使用权。

## 哲学反思
这一概念暗示了人类中心主义的丧失。在追求 AGI 的狂飙中，人类可能逐渐沦为算法的附庸，其价值被简化为神经元网络中的生物参数。
