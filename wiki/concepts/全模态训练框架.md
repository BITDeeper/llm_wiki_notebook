# 全模态训练框架

全模态训练框架是指能够统一覆盖 LLM（大语言模型）、VLM（视觉语言模型）、VLA（视觉-语言-动作模型）、Diffusion（扩散模型）等多种模型形态的训练加速框架。

## 背景与动机

传统训练框架（如 Megatron、FSDP）基于 LLM 时代的设计假设——"数据同质、结构单一、平台固定"。当模型形态从纯文本 LLM 演进到多模态、多组件协同系统时，这些假设不再成立，导致：

1. **工程复杂度拖累迭代速度**：模型定义与分布式策略深度耦合，适配新模型需深入底层代码
2. **异构结构带来隐性性能损耗**：ViT 与 LLM 参数量差异悬殊，"一刀切"并行策略无法分配最优资源
3. **跨平台迁移的沉没成本**：社区框架深度绑定特定硬件生态，国产芯片迁移需维护独立代码分支

## 核心特征

- **统一抽象**：将多模态模型拆解为标准组件（编码器、主干、调度层），通过声明式配置完成组网
- **端到端优化**：从 LLM 基座到多模态专项到底层算子的完整优化链路
- **跨平台支持**：一套代码在 GPU 与国产芯片（如 [[昆仑芯]] XPU）上稳定运行

## 代表实现

[[loongforge|LoongForge]] 是百度百舸开源的全模态训练框架代表，以 Megatron 为核心引擎进行原生重构，在主流模型上实现 15%~45% 端到端训练加速。
