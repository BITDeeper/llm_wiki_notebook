# AI智能体安全风险体系

[[AI智能体安全风险体系]] 是针对 AI 智能体（如 [[OpenClaw]]）在全生命周期中可能面临的安全威胁进行的系统性分类。该体系由 [[北京航空航天大学]] 团队在相关安全报告中提出，旨在构建一个完整、可追溯的风险图谱。

## 六大风险类别

该体系将风险划分为以下六个维度：

1.  **指令与模型安全**：
    *   关注点：[[提示词注入]]、模型幻觉、模型后门。
    *   核心威胁：通过恶意输入诱导模型执行非预期指令。

2.  **交互与输入安全**：
    *   关注点：恶意输入注入、诱导性交互。
    *   核心威胁：利用对话机制进行攻击。

3.  **执行与权限安全**：
    *   关注点：[[沙箱逃逸]]、越权操作、高危动作执行。
    *   核心威胁：突破环境隔离，获取系统控制权。

4.  **数据与通信安全**：
    *   关注点：敏感数据明文存储、传输加密、数据污染。
    *   核心威胁：用户凭证、API Keys 泄露或训练数据被投毒。

5.  **接口与服务安全**：
    *   关注点：未授权访问、接口越权、暴力破解。
    *   核心威胁：攻击者通过 API 接口非法获取服务或数据。

6.  **部署与供应链安全**：
    *   关注点：第三方依赖漏洞（CVE）、恶意插件、日志缺失。
    *   核心威胁：引入带有后门的开源组件或插件。

## 九大高危风险

基于上述体系，报告特别指出了九大高危风险，包括提示词注入、沙箱逃逸、路径遍历、无限制高危动作执行、敏感数据明文存储、未授权访问、接口越权、第三方依赖漏洞以及插件投毒。这些风险直接影响系统的完整性、保密性、可控性和可追溯性。
