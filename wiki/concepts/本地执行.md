# 本地执行

**本地执行** 是指 AI 任务的处理过程完全在用户的终端设备（如 PC、手机）上完成，无需将数据上传至云端服务器。这是 [[桌面智能体]] 领域的一个关键差异化特征。

## 优势

- **隐私安全**：财务报表、核心代码、未公开的商业计划书等敏感数据无需离开本地硬盘，从根本上消除了数据泄露风险。
- **低延迟**：不受网络波动影响，任务响应速度通常快于云端交互。
- **成本控制**：对于高频使用的 Agent 任务，本地执行可能避免高昂的云端 API 调用费用，间接回应了 [[ai-subscription-crisis]]。

## 挑战

- **硬件门槛**：运行高性能大模型通常需要较好的本地硬件支持（如大内存、独立显卡），这可能限制普及率。
- **模型更新**：本地模型的迭代和知识更新可能不如云端模型那样实时和便捷。

## 实例

[[QoderWork]] 是强调本地执行的典型代表。它将任务执行环境部署在用户终端，直接调用本地应用（如 Excel、浏览器）进行操作，而非采用传统的“上传 -> 云端处理 -> 下载”模式。
