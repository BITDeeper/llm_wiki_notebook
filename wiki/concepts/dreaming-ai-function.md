# Dreaming (AI功能)

**Dreaming**（做梦）是 Anthropic 为 Claude Managed Agents 开发的一种**异步反思机制**。它模拟人类睡眠时整理记忆的过程，在 AI 工作间隙自动清理记忆库、总结规律并进行自我优化，以解决长期运行导致的性能下降问题。

## 工作原理

Dreaming 是一段在对话间隙后台运行的异步任务，其核心操作包括：

1.  **合并重复，清理噪音**：将相似的记忆条目合并，删除冗余信息。
2.  **替换旧内容，更新知识**：识别并替换失效的流程、过期的规则和不再适用的偏好。
3.  **交叉分析，挖掘规律**：通过**跨智能体集体反思**，综合多个 Agent 的历史数据，发现单个 Agent 无法察觉的隐藏模式（如反复出现的错误、收敛的最优工作流）。

## 安全机制
- **非破坏性**：不修改原始记忆数据。
- **可回滚**：所有整理结果输出到全新的记忆库，用户不满意可直接删除，不影响原有数据。

## 与人类睡眠的类比
Anthropic 官方将其类比为人类认知过程：
- **Memory**：工作时当场记住学到的东西（即时学习）。
- **Dreaming**：工作间隙想明白这些经验意味着什么（深度反思）。

## 效果与影响
- **性能提升**：法律科技公司 Harvey 接入后，长文起草完成率提升约 6 倍。
- **源码关联**：该功能解释了此前 [[claude-code]] 源码泄露事件中出现的神秘 `Dreaming` 函数的真实用途。

## 局限性
目前该功能仍处于**研究预览阶段**。
