# AI算力成本链

AI算力成本链描述了用户支付的Token费用最终流向存储芯片制造商的完整价值传导链条。这一概念揭示了AI产业利润的最终去向——不是模型公司，不是GPU厂商，而是掌握 [[hbm高带宽内存]] 产能的韩国存储芯片制造商。

## 完整链条

```
用户付给OpenAI的Token钱 →
OpenAI付给微软的算力钱 →
微软付给英伟达的GPU钱 →
英伟达付给SK海力士的HBM钱 →
最终变成韩国工程师银行卡上的年终奖
```

## 利润率对比

| 环节 | 代表企业 | 营业利润率 |
|------|----------|-----------|
| 存储芯片 | [[sk海力士]] | **72%** |
| GPU | [[英伟达]] | 65% |
| 云服务 | 微软 | 较低 |
| AI模型 | [[openai]] | 亏损/微利 |

## 关键发现

- 存储芯片厂商的利润率已超过GPU厂商，真正的"吃肉者"在上游
- 英伟达卖GPU赚的是硬件钱，SK海力士和三星赚的是"所有想跑AI的人的入场券"
- 这张入场券已经卖到了2029年
- [[openai]] 一家公司消耗全球约40%的DRAM供应

## 对现有认知的修正

[[ai产业链价值分配]] 中"模型厂吃肉、应用厂喝汤、算力厂收过路费"的判断需要修正——存储芯片厂商的利润率已超过英伟达，产业链价值分配的真正格局是：**存储厂吃肉、GPU厂喝汤、模型厂烧钱**。
