# 凭证代理隔离

凭证代理隔离是 [[openshell]] 安全架构的核心机制之一，确保 Agent 无法接触用户的敏感凭证。

## 工作原理

- Agent 根本看不到用户的 Slack 或 Outlook 令牌（Token）
- 鉴权发生在沙箱代理的出口，Token 压根不会进入 Agent 的视野
- Agent 只管发出请求，真正的凭证由外面的代理注入
- 两者完全隔离

## 意义

即使 Agent 被攻破或行为异常，攻击者也无法通过 Agent 获取用户的原始凭证，从根本上杜绝凭证泄露风险。
