# 工作流入口

工作流入口是 AI 编程工具竞争的战略制高点。谁的 Agent 先让开发者养成"设完目标就走开"的习惯，谁就锁定工作流护城河。

## 核心逻辑

习惯一旦形成，迁移成本是指数级的。开发者不会轻易离开一个已经跑通了看板调度、断点续传、checkpoint 回滚的 Agent 基础设施。

## 三大竞争者

- **[[claude-code|Claude Code（Anthropic）]]** — 通过 [[独立裁判模型]] 验收机制建立信任
- **Codex（OpenAI）** — 通过持久化工作流对象和 [[断点续跑]] 建立可靠性
- **[[hermes-agent|Hermes Agent（Nous Research）]]** — 通过 [[多智能体看板系统]] 建立团队协作生态

## 战略意义

一个看似很小的 /goal 命令，背后卡的是整条 Agent 工作流的护城河。[[goal模式]] 的竞争本质上就是工作流入口的争夺战。
