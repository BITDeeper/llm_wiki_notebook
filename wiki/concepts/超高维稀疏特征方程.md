# 超高维稀疏特征方程

超高维稀疏特征方程是移动广告推荐系统面临的核心算法挑战，也是 [[axon|Axon]] 要解决的根本问题。

## 问题描述

在开放流量池里，每一次广告展示机会都涉及大量特征维度：
- 用户ID、设备信息、广告素材ID、App ID
- 地理位置、广告位、时间、网络环境
- 展示事件、付费事件……

这些特征从未孤立存在，而是在动态中发生复杂的高阶交叉。例如：
- "美国用户 + 顶级iPhone + 晚上10点 + 休闲游戏 + 激励视频 + 某个特定可玩素材"
- "日本用户 + Android千元机 + 通勤时间 + 电商广告 + 插屏广告"

每种组合背后对应完全不同的心理状态、消费意愿和价值判断。

## 维度灾难

一旦组合维度增多，特征空间就会迅速膨胀——这就是"维度灾难"。传统机器学习（如 [[axon|Axon]] 1使用的Boosting Tree）很难自动、全量捕捉这种深层、稀疏、不断变化的交叉关系。

## Axon 2的解决方案

Axon 2通过深度学习架构解决此问题：
1. **Embedding**：将离散、稀疏的ID与行为信号压缩进统一的稠密向量空间
2. **神经网络**：自动学习高阶特征关系，无需枚举所有组合
3. 模型不需要真的见过每一种组合，也能理解它和历史高价值用户之间的"相似性"

这一突破使系统第一次真正拥有了"泛化能力"。
