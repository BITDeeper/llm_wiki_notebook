# 上下文衰减

**上下文衰减**（Context Rot），又称“上下文漂移”，是指大语言模型在处理超长对话或文档时，随着输入 Token 数量的增加，模型性能（如信息检索准确性、推理能力）出现下降的现象。

## 现象描述

当对话历史或上下文窗口过长时，模型往往会“遗忘”早期的关键信息，或者在处理位于上下文中后部的信息时表现出注意力涣散。这导致模型在长任务中可能出现逻辑断裂或答非所问。

## 技术挑战

上下文衰减是限制长上下文模型（如 100k 或 1M Token 窗口）实际应用效果的主要瓶颈。即使模型支持更大的输入窗口，如果无法在长窗口中保持稳定的性能，其实际可用价值仍然有限。

## Claude Opus 4.6 的突破

[[claude-opus-4.6]] 在缓解上下文衰减方面取得了显著进展。根据 MRCR v2 的“大海捞针”基准测试（8-needle 1M 变体）：
- **Opus 4.6 得分**: 76%
- **Sonnet 4.5 得分**: 18.5%

这表明 Opus 4.6 在保持峰值性能的同时，实现了实际可用上下文数量的质的飞跃，使其能够更可靠地在数十万 Token 中捕捉深埋细节并进行推理。

## 解决方案方向

缓解上下文衰减的技术方向通常包括：
- 改进注意力机制（如线性注意力、稀疏注意力）。
- 上下文压缩与摘要。
- 动态上下文窗口管理。
