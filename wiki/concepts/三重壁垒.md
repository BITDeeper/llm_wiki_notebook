# 三重壁垒

“三重壁垒”是指阻碍 AI 技术普及和生态发展的三个主要层面：技术壁垒、采用壁垒和心理壁垒。这一概念常被用来分析开源 AI 项目（如 [[DeepSeek-R1]]）如何改变行业格局。

## 壁垒构成

### 1. 技术壁垒
- **定义**：指先进 AI 技术被封闭在专有 API 后面，外部无法访问其内部机制、推理路径或进行深度定制。
- **打破方式**：通过开源模型权重、分享推理路径和后训练方法，将高级推理能力转变为可下载、可蒸馏、可微调的工程资产。
- **结果**：推理能力开始像可复用的软件模块一样，在不同系统中反复应用。

### 2. 采用壁垒
- **定义**：指由于许可证限制、法律风险或部署复杂性，导致企业无法在生产环境中自由使用先进模型。
- **打破方式**：采用宽松的开源许可证（如 MIT 协议），消除使用、修改和再分发的法律障碍。
- **结果**：蒸馏、二次训练和领域适应变成常规工程工作，而非特殊项目。模型迅速扩散到云平台和工具链中。

### 3. 心理壁垒
- **定义**：指行业对开源模型的刻板印象，认为其无法匹敌闭源 SOTA，或认为“我们做不到/做不好”。
- **打破方式**：通过实际性能证明（如匹敌 OpenAI o1）和社区活跃度，改变行业认知。
- **结果**：讨论重点从“哪个模型分数更高”转向“如何部署它、降低成本并将其集成到实际系统中”。

## 生态意义
当这三重壁垒被打破时，生态系统开始获得**自我复制的能力**。这意味着社区不再依赖原始源头（如闭源 API 提供商）来获取能力，而是可以自主繁衍、进化和优化技术。对于中国 AI 社区而言，这也是从“跟随者”转向“范式定义者”的关键转折点。
