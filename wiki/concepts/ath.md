# ATH (Alibaba Token Hub)

[[ATH]]（Alibaba Token Hub）是阿里提出的一项关于 AI 模型推理成本与效率的战略思路，旨在解决大模型应用中的成本与效率问题。

## 核心理念
ATH 的核心口号是“创造高效 Token、输送低成本 Token、应用普惠化 Token”。其目标是通过优化模型架构和推理效率，降低 Token 的生产和消费成本，从而推动 AI 技术的普及。

## 实践落地
[[Qwen3.6-Plus]] 被视为 ATH 思路在编程模型上的一次代表性落地。该模型通过架构优化实现了“以小胜大”的效果，即用较小参数规模的模型达到了超越更大参数模型的性能，从而在保证效果的同时降低了推理成本。

## 行业背景
ATH 的提出与当前 AI 行业面临的 [[ai-subscription-crisis]]（AI 订阅制危机）密切相关。随着 Agent 任务的高算力消耗，传统的订阅制模式面临挑战。ATH 通过降低 Token 成本，为维持可持续的商业模式提供了一种可能的解决路径。
