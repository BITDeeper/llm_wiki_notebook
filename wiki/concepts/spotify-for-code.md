# Spotify for Code
针对 AI 时代开源危机提出的设想解决方案。

## 核心设想
建立一种机制，当 AI 调用开源代码时，能够像流媒体播放音乐一样，向代码的创作者支付微薄但持续的版税。

## 实施难点
-   **定价**：如何确定代码调用的价值？
-   **监控**：如何追踪 AI 对代码的使用情况？
-   **意愿**：在赢家通吃的世界里，巨头是否愿意分享利润？
