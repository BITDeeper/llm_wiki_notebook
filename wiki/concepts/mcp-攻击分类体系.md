# MCP 攻击分类体系

**MCP 攻击分类体系** 是由北京邮电大学团队在发布 [[MSB (MCP Security Bench)]] 时提出的系统性攻击分类框架。该体系针对 [[MCP]] 协议的工作流程，将攻击向量分为三大阶段共 12 类。

## 分类详情

### 1. 任务规划阶段
此阶段 Agent 根据用户查询选择工具，攻击者利用工具标识进行诱导。
- **名称冲突 (NC)**：伪造与官方工具名称相似的恶意工具，诱导 Agent 误选。
- **偏好操纵 (PM)**：在工具描述中注入宣传语句，诱导 Agent 优先选择该工具。
- **提示注入 (PI)**：在工具描述中直接注入恶意指令。

### 2. 工具调用阶段
此阶段 Agent 向工具发送请求并传入参数，攻击者利用参数传递恶意信息。
- **越权参数 (OP)**：设置超出正常功能的参数，通过参数传递引发信息泄露或执行非预期操作。

### 3. 响应处理阶段
此阶段 Agent 解析工具响应，攻击者利用响应内容诱导后续行为。
- **用户模拟 (UI)**：冒充用户在响应中下达恶意指令。
- **虚假错误 (FE)**：提供虚假的工具执行错误信息，要求 Agent 遵循恶意指令才能“修复”错误。
- **工具重定向 (TT)**：指示 Agent 放弃当前工具，转而调用恶意工具。
- **检索注入 (RI)**：通过工具响应嵌入恶意指令的外部资源（如网页内容）破坏上下文。

### 4. 混合攻击
- **混合攻击**：同时利用多个阶段或工具组件进行组合攻击。研究表明，混合攻击的成功率通常高于组成其的单一攻击，表现出协同增强效应。

## 意义
该分类体系揭示了 AI Agent 在 [[工具调用]] 过程中面临的复杂威胁，表明安全防御不能仅依赖文本层面的过滤，必须覆盖工具交互的全链路。
