# 音视频智能（AVI）

**音视频智能（Audio-Visual Intelligence, AVI）** 是利用AI同时处理、理解和生成音频与视觉信息的技术领域。它涵盖从语音识别、说话头生成、拟音合成到音视频问答、空间音频、具身导航等十几个子方向。AVI被定位为通往通用人工智能（AGI）的关键路径。

## 核心动机

人类感知世界的方式从来不是孤立的——听到破碎声会寻找玻璃碎片，看到拨弦会期待旋律。视觉与听觉的深度耦合构成了理解现实世界的基石。AVI的目标是让AI获得同样的跨模态感知能力。

## 感知-生成-交互三主线

AVI的任务体系可组织为三条主线（三大支柱）：

### 理解世界（感知 / Understanding）
音视频感知、声源定位、AVQA、跨模态检索与推理。模型不再"只看视频"或"只听语音"，而是在统一表示下做对齐、grounding与推理。AV-LLM的崛起让长视频理解、AVQA等任务有了新的基线。任务粒度从像素级的定位（声音从哪来？）到内容级的问答（视频里的人为什么笑了？），再到逻辑级的推理。

### 创造世界（生成 / Generation）
视频配音（V2A）、音频驱动视频生成、[[联合音视频生成]]、音画编辑、文字生成音视频、让照片开口说话（Talking Head）。当前最大瓶颈不是单模态画质或音质，而是联合生成中的**音画同步、跨身份一致性与长时一致性**。

### 与世界交互（交互 / Interaction）
音视频对话、[[omni-modal模型|omni-modal]]交互、具身智能与机器人。从级联式ASR+LLM+TTS到原生omni-modal实时对话，模型从"被动执行单轮指令"走向"主动审视环境并实时响应"。典型场景包括实时对话助手、能听懂指令并在复杂环境中导航的具身机器人。

## 演化路径

AVI的发展是一部微缩的AI进化史，从"对齐"走向"共生"，经历了从"单点对齐"到"统一backbone"的范式跃迁：

### 十年演进（2016—2026）

- **2016年**：简单音视匹配任务起步
- **2026年**：全模态收敛系统时代（[[gpt-4o]]、[[qwen3-omni]]、[[sora-2]]、[[movie-gen]]）

### 四阶段范式跃迁

1. **早期对齐阶段：** L3-Net、Wav2Lip — 解决"对得上"的问题
2. **可扩展表示阶段：** ImageBind、AudioLDM、MusicGen — 建立跨模态表示
3. **跨模态生成阶段：** MMAudio、FoleyCrafter、JavisDiT — 跨模态与联合生成
4. **统一模型阶段：** GPT-4o、Veo-3、Seedance 2.0、Qwen-Omni — 听-看-说-动一体化

## 技术基础

### 表示学习
- **连续嵌入：** [[clip]]、[[imagebind]]、AudioCLIP、AV-HuBERT
- **离散token化：** [[离散token化]]（VAE、EnCodec）
- **对齐方法：** 对比对齐、masked/denoising重建、token级跨模态预测

### 模型架构
- 从CLIP/AudioCLIP到AV-HuBERT、ImageBind，再到Decoder-only LLM + omni encoder与MoE架构
- 系统集成遵循[[llm集成架构五分法]]

### 生成范式
- VAE / GAN / Diffusion / 自回归（AR）/ Masked Autoregressive（MAR）五类
- 核心趋势是[[扩散模型-vs-自回归模型]]的融合

### 强化学习
- RLHF、DPO、reward shaping在AV生成上的应用
