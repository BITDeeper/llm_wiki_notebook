# 多智能体协作

**多智能体协作**（Multi-Agent Collaboration）是一种将复杂业务任务拆解并分配给多个具有特定角色的智能体，通过编排引擎协同完成工作的技术范式。这被视为继“单模型输出”之后的下一代 AI 交互范式，旨在通过模拟人类专家团队的协作过程，利用智能体之间的互相质疑和纠错来减少 [[幻觉]]，提高输出的准确性和鲁棒性。

## 核心逻辑
不同于单一模型处理所有任务，多智能体协作模拟人类团队的组织形式，将复杂任务拆解并分配给专门的智能体。正如俗语所言：“一个AI可能会骗你，但四个AI至少会互相拆台。”

## 工作原理
1.  **角色拆解**：将复杂流程（如医疗诊断或财税处理）拆分为分诊、检索、推理、核验、生成等子任务。
2.  **智能体分配**：为每个子任务分配专门的智能体，每个智能体专注于特定领域（如策划、执行、审核）。
3.  **协议编排**：通过协作协议定义智能体之间的信息流转与依赖关系。
4.  **Human-in-the-loop**：在关键节点引入人工复核，确保高风险决策的安全性。

## 主要实现模式
1.  **圆桌会议模式**：
    - **代表**：[[Grok 4.20]]。
    - **特点**：少数（如4个）精英智能体进行深度辩论，用户可见讨论过程，强调透明度和共识。
2.  **工厂流水线模式**：
    - **代表**：Kimi K2.5 的 Agent 集群。
    - **特点**：大规模（如100个）分身并行处理任务，强调吞吐量和规模效应。

## 行业应用案例

### 医疗领域：WiseClaw
在 [[WiseClaw]] 平台中，多智能体协作被用于病历质控、病案编目和用药审查等场景。
- **信息抽取**：一个智能体负责从病历中抽取关键信息。
- **指南核验**：另一个智能体负责依据临床指南进行核验。
- **人工确认**：最后由人工药师进行最终确认。

### 财税领域：深蓝财鲸
[[深蓝财鲸]] 是该架构在财税领域的典型应用，通过多智能体协同处理非标准化、模糊边界的真实商业场景：
- **票据智能体**：负责 OCR 识别与验真。
- **核算智能体**：负责会计准则匹配。
- **税务智能体**：负责税法政策同步。
- **风控智能体**：负责异常扫描。
- **调度智能体**：负责总控与决策。

### 自动化工作流：Lovart
[[Lovart]] 展示了多智能体协作在自动化工作流中的应用，通过协同工作实现“一句话让 AI 为你打工”的场景。

### 其他行业应用
- **谷歌**：Gemini 3 Deep Think 使用并行推理链进行验证。
- **Anthropic**：为 [[Claude Code]] 增加了 Agent Teams 功能。
- **xAI**：在 Grok 4 Heavy 中引入，并在 Grok 4.20 中将其大众化。

## 优势
- **专业化分工**：不同 Agent 专注不同领域，单个智能体的职责单一，便于调试和优化。
- **降低不可控性**：避免单体模型试图“一步到位”解决所有问题，减少幻觉和错误累积。
- **增强可靠性**：通过多角色交叉验证（如推理与核验分离）提高输出质量。
- **多维验证**：提供多维度的验证，逻辑更严密，适合复杂决策任务（如金融分析、代码调试）。
- **处理复杂场景**：能够处理非标准化、模糊边界的真实商业场景，而不仅仅是执行固定流程。
- **可扩展性**：易于增加新的功能模块。
- **容错性**：单个 Agent 的失败不一定导致整体任务失败。

## 挑战
- **计算成本高**：运行多个智能体需要消耗更多的计算资源。
- **裁决机制不成熟**：如何处理智能体间的分歧（即如何“裁决”）尚无统一标准。
- **信息过载**：多智能体的交互过程可能产生大量信息，用户难以有效筛选。
