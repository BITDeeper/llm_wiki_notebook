# 自主实验循环

[[自主实验循环]]（Autonomous Experiment Loop）是指由 AI Agent 驱动的、用于自动化执行科学实验（特别是深度学习模型训练）的闭环工作流。

## 标准流程

该循环通常包含以下四个阶段：

1.  **THINK（思考/规划）**：
    Agent 读取项目说明和历史实验数据，分析当前最优结果，并构思下一步的实验方案。这可能涉及修改超参数、调整模型架构或更换数据处理策略。

2.  **EXECUTE（执行/实施）**：
    Agent 自动修改代码或配置文件，并启动实验任务。为了提高效率，通常会在正式训练前加入快速验证步骤（如 [[Deep Researcher Agent]] 中的强制 dry-run），以尽早发现代码 Bug。

3.  **MONITOR（监控/观察）**：
    在任务运行期间，Agent 监控实验状态。为了控制成本和资源消耗，这一阶段可能采用 [[零成本监控]] 策略，即仅使用系统命令检查进程存活和资源占用，而不调用昂贵的 LLM API。

4.  **REFLECT（反思/迭代）**：
    实验结束后，Agent 解析日志和输出结果，提取关键指标，并与历史基线进行对比。基于这些反馈，Agent 决定是继续优化、回滚参数还是终止实验，随即开启下一轮循环。

## 关键特征

-   **持续性**：循环可以 7x24 小时运行，无需人工持续干预。
-   **自我迭代**：Agent 能够根据上一轮的结果自动调整下一轮的参数，实现实验的自我进化。
-   **人机协作**：虽然循环是自动的，但通常保留人类随时介入的接口（如通过指令文件或移动端 App），以确保研究方向不偏离。

## 应用价值

该循环将研究者从繁琐的“改参-跑实验-等结果”的机械劳动中解放出来，使其能专注于更高层次的科学问题，如假设提出和结果分析。
