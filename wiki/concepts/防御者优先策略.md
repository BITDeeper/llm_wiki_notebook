# 防御者优先策略

**防御者优先策略**（Defender-First Strategy）是 [[Anthropic]] 针对 [[Claude Mythos]] 等高风险模型提出的一种发布与部署策略。该策略的核心思想是在面对具有显著 [[双重用途风险]] 的技术时，优先向防御方（而非公众或潜在的攻击方）提供访问权限。

## 实施背景
由于 Mythos 等先进 AI 模型具备极强的网络攻击潜力，直接公开发布可能会导致黑客利用其能力发动无法防御的攻击。为了打破这种攻防不对称，Anthropic 决定改变传统的发布模式。

## 具体措施
1.  **受限访问**：不立即通过 API 向公众开放，而是设立“抢先体验权”。
2.  **对象筛选**：优先向网络安全机构、相关防御组织及经过审查的合作伙伴开放。
3.  **目标导向**：旨在让防御方利用模型提前发现并修补漏洞，提高代码库的稳健性，从而在“AI 驱动的漏洞利用浪潮”到来前建立防御优势。
