# 路径三性（隔离性、无偏性、可区分性）

**隔离性、无偏性、可区分性**是 [[visual-para-thinker]] 框架为并行推理路径设计的三项核心原则，构成该框架的理论基础。

## 隔离性

不同推理路径之间不能有信息泄露，每条路径独立探索各自的推理方向。

- **实现方式**：通过 [[pa-attention]]（路径感知注意力），利用特殊 token `<think_i>` 实现上下文隔离
- **必要性**：如果路径之间存在信息泄露，会导致路径趋同，丧失多样性

## 无偏性

不同推理路径不能存在先天的位置偏差，模型必须将各路径等同看待。

- **实现方式**：将不同路径的 position id 映射到同一区间（并行推理阶段不同路径起始 token 的 position id 相同）
- **解决的问题**：大语言模型存在固有偏差（如"loss in the middle"现象），如果不同路径使用不同 position id 区间，会因先后顺序产生天生的位置偏差
- **设计洞察**：作者认为不能将不同推理路径等同看待的做法，本质上依然是串行思考

## 可区分性

模型需要能够区分不同的推理路径，避免混淆。

- **实现方式**：通过 [[lprope]]（分段学习位置编码），在旋转位置编码之前加入路径专属的可学习绝对位置编码
- **设计矛盾**：无偏性设计（统一 position id）牺牲了可区分性，需要 LPRoPE 进行补偿

## 三者关系

三性之间存在内在张力：无偏性与可区分性的设计需求相互矛盾，需要通过巧妙的工程折中来同时满足。这一"拆东补西"的设计是否为最优解，尚存讨论空间。
