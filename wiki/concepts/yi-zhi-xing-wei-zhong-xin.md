# 以执行为中心

[[以执行为中心]] 是一种软件工程和系统设计哲学，强调将“能否被执行”作为验证工具可用性的唯一标准，而非仅仅关注代码是否存在或文档是否完善。

## 背景与动机
在科学计算领域，大量开源软件虽然发布了代码，但因依赖冲突、环境不兼容等问题，实际上无法运行。传统的“以代码为中心”或“以文档为中心”的维护方式无法解决这一痛点。

## 核心原则
-   **执行即真理**：只有通过实际运行验证的工具，才被视为可用。
-   **自动化验证**：通过自动化工作流（如 [[Deploy-Master]]）对工具进行最小可执行命令测试。
-   **Action Space**：为 AI Agent 提供确定的、可复现的动作空间，而非充满不确定性的 API 调用。

## 应用
这一理念是 [[Agentic Science]] 赖以生存的基础。如果缺乏以执行为中心的基础设施，Agent 的规划将无法落地，学习闭环也无法建立。
