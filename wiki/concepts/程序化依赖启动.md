# 程序化依赖启动

程序化依赖启动（Programmatic Dependency Launch，简称 PDL）是一种用于减少 GPU 内核启动延迟的软件技术。

## 作用
PDL 旨在让 GPU “时刻待命”，通过精细化的依赖管理，减少 CPU 与 GPU 之间的调度开销。

## 效果
在低交互性（高吞吐）场景下，PDL 能显著降低 GPU 的“空转”损耗。它是 [[TensorRT-LLM]] 提升 [[MoE]] 模型推理吞吐量的三大关键优化之一。
