# 异步强化学习基础设施

异步强化学习基础设施是一种用于提升大模型后训练阶段效率的系统架构。它旨在解决传统 PPO（近端策略优化）算法中因高度同步机制导致的 GPU 利用率低下（通常仅 20%-30%）的问题。

## 核心设计
该架构的核心是将**训练引擎**和**推理引擎**解耦到不同的 GPU 设备上：
1. **推理引擎**：持续生成轨迹，不受训练侧等待时间的影响。
2. **训练引擎**：当推理数据积累到预定阈值时，异步更新模型。
3. **权重同步**：推理引擎定期与训练侧同步权重，以减少策略滞后，保持训练的近似同策略性。

## 关键技术组件

### 1. Token-in-Token-out (TITO)
- **定义**：训练流程直接消费推理引擎生成的精确 tokenization 和解码 token 流。
- **作用**：消除了重新 tokenization 带来的边界不匹配问题，对于精确估计 token 采样概率至关重要。传统的 Text-in-Text-out 模式将推理引擎视为黑箱，重新处理文本可能导致细微的 token 级别误差。

### 2. 双侧重要性采样
- **问题**：在异步设置中，维护历史模型权重以计算精确行为概率极其困难。
- **方案**：将 rollout 期间生成的对数概率作为直接行为代理，通过计算重要性采样比 $r_t(\theta) = \pi_\theta / \pi_{rollout}$ 来消除旧策略推理的计算开销。同时采用双侧校准 token 级掩码策略，将信任域限制在 $[1-\epsilon_l, 1+\epsilon_h]$ 之间，屏蔽区间外的梯度计算。

### 3. DP 感知路由
- **问题**：在多轮 Agent 工作负载中，相同前缀的请求若分散在不同 GPU 上，会导致冗余的预填充计算。
- **方案**：通过一致性哈希将 rollout ID 映射到固定的数据并行（DP）Rank。这使得预填充成本仅与增量 token 成正比，无需跨 Rank 的 KV 同步。

## 应用与影响
这一架构被 [[GLM-5]] 用于支撑其在数学、科学、代码和工具集成推理（TIR）等多领域的混合强化学习训练。它显著提升了集群的吞吐量，使得在有限算力下进行大规模、高复杂度的 Agent 训练成为可能。
