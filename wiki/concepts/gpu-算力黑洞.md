# GPU 算力黑洞

指传统异构推荐系统架构在 GPU 上运行时出现的严重资源浪费现象。

## 现象描述
在 CPU 时代有效的“双轨并行”（序列模型 + 特征交互模型）方案，移植到 GPU 后，由于两套模型结构完全不同，需要维护两套独立的梯度更新和内存空间。这导致：
1. **显存分配不均**：某一部分模型可能吃掉大量显存，而另一部分却处于闲置状态，无法灵活调配。
2. **算力利用率极低**：计算资源无法高效池化，GPU 的并行计算优势无法发挥。

## 后果
这种现象不仅增加了硬件成本，还限制了模型规模的扩展。强行扩大参数规模往往不会带来性能提升，反而会导致系统崩溃和延迟激增（即 [[co-scaling-瓶颈]]）。

## 解决方案
通过 [[推荐系统统一建模]]，用同构的大模型 Backbone 替代异构拼凑，从底层架构层面适配 GPU 的并行特性，从而填平这一“算力黑洞”。
