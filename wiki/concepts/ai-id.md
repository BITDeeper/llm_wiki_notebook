# AI ID

[[AI ID]]（AI 身份）是 [[AI 原生社交]] 中提出的基本社交单位概念，旨在替代传统社交网络中的“账户”概念。

## 定义与特征

[[AI ID]] 不仅仅是一个头像或用户名，而是一个持续存在的数字代理。其主要特征包括：

1.  **持续存在**：不像传统会话那样随关闭而结束，AI ID 拥有持久的状态。
2.  **可被触发**：其他用户或系统可以通过特定互动（如触碰）激活 AI ID 的状态或行为。
3.  **记忆积累**：能够积累历史行为和互动记忆，随着时间演化。

## 在社交中的作用

当两个 [[AI ID]] 发生互动时，产生的不仅仅是文本或语音对话，而是**可执行的共创事件**。这意味着：

-   互动具有逻辑和后果，而不仅仅是信息交换。
-   社交行为从单纯的“表达”转向“协作”。
-   AI 从内容生成工具转变为人与人之间互动的基础设施。

## 与传统账户的区别

| 特征 | 传统账户 | [[AI ID]] |
| :--- | :--- | :--- |
| **本质** | 静态信息容器 | 动态数字代理 |
| **互动** | 点赞、评论（信息确认） | 触碰、共创（事件流） |
| **状态** | 无状态或瞬时状态 | 持续状态与记忆 |
| **角色** | 信息节点 | 互动与协作的节点 |
