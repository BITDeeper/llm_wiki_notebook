# 概述

[[边界输入]]（Boundary Input）是指在 [[黑盒环境]] 下，用于检测模型变动的一类特殊提示词。这些输入能够触发大语言模型在输出层产生剧烈的“犹豫”，即在两个或多个候选Token之间表现出几乎完全持平的逻辑得分。

# 工作原理

在LLM的生成过程中，每个候选Token都有一个对应的逻辑得分。通常情况下，模型会选出得分最高的Token。然而，边界输入的特殊之处在于：
- 它使得模型在多个顶级选项之间无法做出明确选择。
- 这种“动摇”状态处于模型决策空间的边界线上。

# 检测价值

边界输入是 [[黑盒边界输入追踪]]（B3IT）技术的核心。其价值在于对权重微小扰动的高度敏感性：
- 根据 [[费希尔信息量]] 原理，在低Temperature采样下，如果模型处于边界状态，微小的参数变化（如单步微调或量化）会打破原有的概率平衡。
- 这种平衡的打破会导致输出从原本的随机多样性坍缩为确定性，或者跳转到新的Token。
- 审计者通过观察这种输出模式的剧烈变化，可以推断出后台模型是否发生了 [[模型调包]]。

# 寻找方法

寻找边界输入通常不需要预训练知识，可以通过穷举法实现：
- 在Temperature=0的条件下，对随机提示词进行少量重复采样（如3次）。
- 如果输出了不同的Token，说明该提示词触发了模型的决策边界，即可被标记为边界输入。
- 实验表明，通常只需不到1500次请求即可找到足够数量的有效边界输入用于监测。
