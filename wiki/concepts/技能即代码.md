# 技能即代码

“技能即代码”是一种 AI Agent 记忆管理理念，指将 Agent 在交互过程中习得的认知和技能沉淀为结构化的文本文件（如 Markdown 文件），从而实现跨会话的持久化和复用。

## 实践案例
Machiwhale Studio 主理人 [[马多灵]] 在使用 OpenClaw 时，为了解决 AI “失忆”问题，采取了以下措施：
*   **外脑记忆库**：利用 Obsidian 建立本地可见的知识库。
*   **定时整理**：设置 Agent 每天凌晨 3:55 进行跨会话的记忆整理。
*   **文件化**：将所有认知和技能沉淀为 MD 文件。

## 效果
*   **肌肉记忆**：在繁杂的会话中建立了类似“肌肉记忆”的默契，使得 Agent 能够快速读取和复用之前的技能。
*   **高可读性**：200 行左右的记忆索引文件能被任何模型秒速读取，实现了不同模型或会话间的能力继承。
*   **文字大于大脑**：强调通过文本化手段固化智能，而非依赖不可控的模型内部状态。
