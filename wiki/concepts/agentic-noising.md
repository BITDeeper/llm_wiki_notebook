# Agentic Noising

[[Agentic Noising]] 是一种专门针对扩散大语言模型在 Agent 任务中训练的数据加噪策略。它由 [[中国人民大学]] 团队在 [[DLLM-Searcher]] 项目中提出，旨在解决扩散模型特有的“训练-推理不匹配”问题。

## 问题背景
扩散模型具有 [[块内双向注意力]] 机制，这意味着在训练时，模型在一个块内可以看到上下文的所有信息。在 Agent 搜索轨迹中，这包含两部分：
1.  **模型生成**：思考、工具调用。
2.  **外部返回**：搜索结果。

如果在训练时直接对整块数据加噪，模型可能会利用双向注意力机制“偷看”到同一块内的搜索结果（即答案）。这会导致模型在训练时依赖答案，但在推理时（答案尚未出现）性能崩溃。

## 解决方案
Agentic Noising 采用了选择性加噪策略：
-   **对“思考”和“工具调用”部分**：进行加噪处理，让模型学习如何从噪声中恢复这些内容。
-   **对“搜索结果”部分**：
    -   如果搜索结果出现在当前生成块之前（作为上下文），则保留原样。
    -   如果搜索结果与生成部分在同一个块内，则直接全部遮掉或保留原样但不参与损失计算，防止信息泄露。

## 配套机制
该策略通常与 [[Agentic ELBO]]（一种仅在需要学习的位置计算损失的变分下界目标）配合使用，确保梯度回传只集中在模型需要生成的部分，而忽略外部返回的搜索结果。

## 作用
通过 Agentic Noising，[[DLLM-Searcher]] 成功将原始成功率几乎为 0 的扩散模型训练成了能够熟练进行多跳问答的 Agent，同时保证了训练过程与推理过程的一致性。
