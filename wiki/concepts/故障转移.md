# 故障转移

故障转移是一种系统容错机制，指当主系统组件（如 API 服务、数据库或模型实例）发生故障或无法响应时，系统自动切换到备用组件继续运行的能力。

## 在 AI Agent 系统中的重要性
对于长时间运行的自动化任务，单点故障（如 API 额度耗尽、网络波动）可能导致整个任务流中断。[[openclaw]] 3.12 版本显著增强了这一机制，能够检测到如 402（欠费）错误或模型侧异常响应，并自动切换到用户配置的备用模型。

## 关键特性
- **自动检测**: 实时监控主服务的响应状态。
- **自动切换**: 无需人工干预即可切换至备用通道。
- **自动恢复**: 具备冷却时间探测功能，在主服务恢复（如充值后）后可自动切回。
