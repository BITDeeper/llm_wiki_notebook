# 同构骨干网络

[[同构骨干网络]]（Homogeneous Backbone Network）是指由结构统一、可重复堆叠的基础模块组成的深度学习网络架构。

## 在推荐系统中的定义
在 [[序列建模与特征交互统一]] 的语境下，同构骨干网络特指一种能够同时处理“序列行为数据”和“静态特征数据”的统一 Transformer 架构。

## 技术实现
- **输入统一**：将序列特征和非序列特征转化为统一的 Token 表示（如 S-token 和 NS-token）。
- **处理统一**：通过堆叠相同的 Transformer Block 或自定义 Block 对所有 Token 进行交互建模，无需区分特征类型。
- **优势**：这种架构天然适配 GPU 的并行计算能力，且便于通过增加 Block 数量来扩展模型规模。

## 重要性
同构骨干网络是实现 [[推荐系统缩放定律]] 的物理载体。它打破了传统 [[双轨并行架构]] 的算力割裂，使得推荐模型能够像 LLM 一样，通过增加算力和参数量来获得可预期的性能提升。
