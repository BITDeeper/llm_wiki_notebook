# 命题式与处方式知识

**命题式知识**（Propositional Knowledge）与**处方式知识**（Prescriptive Knowledge）是 [[PlugMem]] 架构中用于结构化 AI 智能体经验的两类核心知识单元。这种分类借鉴了认知科学，旨在区分“知道什么”和“怎么做”。

## 定义

### 命题式知识
指关于世界状态的**事实**（Facts）。
*   **内容**：描述静态的信息、属性或关系。
*   **例子**：“用户喜欢科幻电影”、“这家店周五关门”、“红色按钮用于停止”。
*   **作用**：为 Agent 提供决策所需的背景信息和环境约束。

### 处方式知识
指可复用的**技能或策略**（Skills/Strategies）。
*   **内容**：描述如何完成特定目标的步骤或规则。
*   **例子**：“如何在电商网站上使用优惠券筛选商品”、“如何通过验证码”、“如何回复用户的投诉”。
*   **作用**：赋予 Agent 跨场景迁移的能力，使其能从过去的成功经验中提取通用方法。

## 在记忆系统中的角色

在传统的日志式记忆中，这两类知识往往混杂在冗长的对话或操作记录中。通过将它们显式提取并结构化：
1.  **降低检索成本**：Agent 可以直接查询“如何做 X”，而不需要重新阅读包含 X 的长篇历史记录。
2.  **提升泛化能力**：处方式知识使得 Agent 能够将在任务 A 中学到的策略应用到任务 B 中。
3.  **优化上下文利用**：在生成回复或决策时，Agent 只需加载相关的处方和事实，而非整个上下文历史。

## 认知科学对应

*   **命题式知识**对应于**语义记忆**（Semantic Memory）。
*   **处方式知识**对应于**程序性记忆**（Procedural Memory）。

这种二元结构使得 AI Agent 的记忆系统更接近人类的学习与认知过程。
