# 变分得分蒸馏（VSD）

变分得分蒸馏（Variational Score Distillation, VSD）是一种采用双教师策略实现分布对齐的蒸馏方法，最初用于文本到 3D 生成以解决过饱和和多样性不足问题，后被扩展至 2D 文本到图像生成。

## 核心机制

VSD 的训练框架包含三个组件：

1. **真实模型**（由 θ 参数化）：预训练扩散模型作为教师
2. **虚假模型**（由 φ 参数化）：从教师初始化，近似教师分布
3. **学生模型**（单步生成器）：从教师初始化，经训练后单步合成高质量图像

训练过程交替优化学生模型和虚假模型直至收敛。

## 方法演进

| 方法 | 贡献 |
|------|------|
| SwiftBrush | 实现单步无图像生成 |
| SwiftBrushv2 | 利用模型集成进一步改善 |
| DMD | 引入回归损失提升性能 |
| DMD2 | 扩展至少步生成，支撑文本到视频加速 |
| **[[wadi-权重方向感知蒸馏\|WaDi]]** | **将 LoRaD 集成到 VSD 中，专注方向建模** |

## 在 WaDi 中的应用

WaDi 将 [[lorad-权重方向低秩旋转|LoRaD]] 模块集成到 VSD 框架中，对学生模型和虚假模型均应用 LoRaD，但使用不同的秩配置，实现方向感知的蒸馏优化。
