# 多智能体协作-Team

**多智能体协作**（Multi-Agent Collaboration）是指利用多个具有不同角色、技能和目标的 AI 智能体，通过分工合作、并行推进和自动交接来共同完成复杂任务的工作模式。

## 从“1V1”到“1V多”
传统的 AI 交互模式通常是“1V1”：一个用户面对一个通用 AI 助手，进行一问一答的线性交互。
**多智能体协作**则将模式转变为“1V多”：用户同时指挥一支由多个专家型 Agent 组成的团队。

## 工作机制
1.  **角色定义**：为每个 Agent 分配特定的角色（如产品经理、工程师、数据分析师）和技能包。
2.  **任务拆解**：系统自动或由用户辅助将复杂任务拆解为子任务。
3.  **并行与协作**：不同 Agent 处理各自擅长的子任务，并在需要时进行信息交换和自动交接。
4.  **结果汇总**：最终由一个主导 Agent 或系统自动整合所有子任务的产出。

## 应用案例
在 [[workbuddy]] 中，用户可以创建一个“Team”来完成产品规划：
-   **Agent A**：负责市场调研和竞品分析。
-   **Agent B**：负责撰写产品需求文档（PRD）。
-   **Agent C**：负责生成代码原型。
用户只需发出一条指令，整个团队即可协同工作，产出完整方案。

## 优势
-   **专业深度**：每个 Agent 可以针对特定领域进行深度优化，避免通用 AI 的平庸。
-   **效率提升**：并行处理大幅缩短了任务完成时间。
-   **可扩展性**：可以根据任务复杂度灵活增减 Agent 数量。
