# 稀疏枢纽注意力

**稀疏枢纽注意力（Sparse Hub Attention）** 是 [[gamma-world]] 的三大核心设计之一，用于解决多智能体世界模型中跨智能体通信的高效建模问题。

## 解决的问题

全连接注意力让所有玩家的 token 两两直接交互，计算成本随玩家数量**平方增长**——从2人扩展到8人，计算量从 477.8G 增至 7.6T，增长约16倍。这是算法复杂度决定的天花板，无法通过工程优化解决。

更深层的问题在于一个错误的假设：每个 token 级别的细节都需要在所有玩家之间直接传递。事实上，玩家A放下方块，玩家B需要感知的只是"世界里出现了一个方块"——这是一个紧凑的世界状态变化，而非A的全部视觉细节。

## 技术方案

引入一组可学习的 **hub token（枢纽token）**，构成轮辐式（hub-spoke）拓扑：

1. 每个智能体只与自身历史及 hub token 交互
2. Hub token 汇聚所有智能体的信息，压缩为共享状态摘要，再广播回各智能体流
3. 不同智能体之间的直接注意力被完全屏蔽
4. 信息经由两跳传递：**智能体→hub→智能体**

## 效果

- 将计算成本从**平方复杂度压至线性复杂度**
- 随玩家数量增加，与全连接注意力的 FLOPs 差距接近 8 倍
- 推理时通过独立的 KV cache 保留稀疏通信拓扑，支持流式生成

## 归纳偏置的意义

稀疏枢纽注意力不只是节省了算力，它本身也是一个更合理的归纳偏置——在架构层面**显式编码**了"跨智能体信息应经过共享世界状态瓶颈"这一先验，而非期待模型从数据中隐式学习。
