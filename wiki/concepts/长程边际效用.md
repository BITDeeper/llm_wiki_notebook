# 长程边际效用

长程边际效用（Long-horizon Marginal Utility）是 [[lu-kv|LU-KV]] 框架提出的核心评估思维，用于重构 [[kv-cache|KV Cache]] 的预算分配逻辑。

## 核心洞察

传统 KV Cache 压缩方法遵循"瞬时注意力分数高即重要"的假设。这种策略在单头内部往往有效，但在跨头预算分配时会"看走眼"——把预算分配给短期分数高、但长期贡献有限的 Token。

长程边际效用打破了这一短视假设，转向评估 Token 在**未来多步解码中的潜在贡献**，类似于金融投资中的"投资回报率（ROI）"思维。

## Oracle Importance

LU-KV 将这一思维具体化为 **Oracle Importance（真实重要性）** 指标：通过前瞻未来 K 步解码窗口，直接计算每个 Token 能产生的最大潜在贡献。该指标将重要性评估从"单步瞬时注意力"升级为"长程前瞻效用"。

通过 Oracle Importance，研究者首次严格量化了现有启发式指标与真实重要性之间的"最优性差距（Optimality Gap）"，从数学上证明了盲目按瞬时分数分配必然导致长期语义流失。
