# 本地嵌入

本地嵌入是指在本地设备（如个人电脑或服务器）上运行嵌入模型，将文本转换为向量表示，而非调用云端 API 服务。

## 优势
- **成本优化**：对于高频调用场景，本地运行可以消除 API 调用费用，实现零边际成本。
- **隐私保护**：数据无需上传至第三方服务器，适合处理敏感信息。
- **低延迟**：避免了网络传输开销，响应速度通常更快。

## 实践案例
在 [[一行代码不写，龙虾军团日夜为我打工赚钱]] 一文中，[[matthew-berman]] 在其 MacBook 上利用 [[Nomic]] 模型执行本地嵌入任务。这一策略使得他的自动化系统能够以极低的成本处理大量的知识库检索和相似度匹配任务。

## 技术要求
- 需要具备一定算力的本地硬件（如 GPU 或高性能 CPU）。
- 需要选择适合本地部署的开源模型（如 Nomic, Llama 等）。
