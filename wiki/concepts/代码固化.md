# 代码固化

**代码固化** (Code Solidification) 是 [[SkVM]] 中采用的一种 JIT (Just-in-Time) 优化技术，旨在大幅降低 LLM 的 Token 消耗和执行延迟。

## 工作原理
1.  **指纹生成**：在 AOT 阶段，系统会预生成代码模板及其指纹。
2.  **运行时匹配**：当 Skill 运行时，LLM 生成的代码会与预生成的指纹进行比对。
3.  **直接复用**：如果连续多次匹配成功，SkVM 会判定该逻辑已固化。后续执行将直接根据输入参数填充模板代码，完全跳过 LLM 的生成过程。

## 性能收益
- **速度提升**：代码执行时间从上万毫秒降至几百毫秒，实现 **19-50 倍** 的加速。
- **成本降低**：消除了重复的 LLM 推理调用，显著减少 Token 消耗。

## 适用场景
适用于包含大量重复逻辑或固定模板的 Skill，例如数据处理脚本、API 调用模板等。
