# Continuous Thought Machines

Continuous Thought Machines (CTM) 是 [[Sakana AI]] 提出的一种新型 AI 架构，由 [[Llion Jones]] 及其团队开发。该架构旨在突破传统 Transformer 的局限，通过模拟生物大脑的运作机制来实现更自然的智能。

## 核心原理
CTM 的设计灵感来源于生物学中的神经科学原理：
- **神经动态**：不同于传统神经网络中静态的权重矩阵，CTM 使用神经动态作为核心表示。
- **同步振荡**：模拟大脑神经元通过同步振荡来传递信息的过程，让模型在「内部思考维度」上逐步展开计算。

## 与 Transformer 的区别
| 特性 | Transformer | Continuous Thought Machines |
| :--- | :--- | :--- |
| 计算方式 | 静态权重矩阵 + 注意力机制 | 动态神经振荡 |
| 灵感来源 | 统计学/语言模型 | 生物大脑运作 |
| 知识表示 | 离散的 Token 嵌入 | 连续的思维状态流 |

## 研究动机
Llion Jones 认为，当前 LLM 表现出的 [[锯齿状智能]] 暗示了 Transformer 架构的根本缺陷。CTM 试图从底层重新思考「如何表示知识和思考」，而非在现有架构上修修补补。

## 现状
作为一个探索性方向，CTM 目前尚未在工业界大规模应用，但被视为跳出 [[架构彩票]] 陷阱、寻找下一代 AI 基础架构的重要尝试。
