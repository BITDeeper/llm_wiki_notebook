# 码流原生视觉建模

码流原生视觉建模（Codec-Native Vision Modeling）是一种将视频压缩码流中的运动向量与残差作为视觉模型基本输入单元的技术范式，而非传统的均匀采帧方式。

## 核心思想

视频编解码器（Codec）本质上是一个显式的预测模型：把视频写成"继承的上下文 + 增量观测"。这种分解同时给出两类信号——几何位移（运动向量 MV）与无法解释的外观变化（残差）——它们是对"世界在这一瞬间发生了什么"最直接的证据。

码流原生视觉建模将这套工程语法上升为视觉建模先验：让视觉模型以"状态 + 增量观测"的方式读取世界。

## 视频 MLLM 视觉表征五代演化

| 代际 | 时间 | 范式 | 代表工作 |
|------|------|------|---------|
| Ⅰ | 2018–2021 | 早期帧采样 | I3D / C3D / SlowFast / TSN |
| Ⅱ | 2022–2023 | 启发式压缩 | H2O / ToMe / DynamicViT / LLaVA-Pruner |
| Ⅲ | 2024–2025 | 学习式选择 | TokenLearner / Evo-ViT / PruMerge |
| Ⅳ | 2026 | 码流对齐 | [[llava-onevision-2]]（Codec-Stream Tokenization） |
| Ⅴ | 2026+ | 码流原生 | 端到端 Codec-Native LLM（下一步方向） |

## 与传统方法的本质区别

传统方法（均匀采帧、启发式压缩、学习式选择）将 Token 预算平均分配或基于学习策略分配，但本质上仍将视频视为"被采样的帧"。码流原生范式将视频视为"由比特率与运动残差共同驱动的连续证据流"，Token 密度跟随码流真实事件强度分布——事件密集处密 Token，平稳处稀 Token。

## 应用前景

- 机器人操作中的细粒度时间定位
- 体育分析中的动作识别
- 医疗复检中的关键瞬间捕捉
- 小时级超长视频建模
