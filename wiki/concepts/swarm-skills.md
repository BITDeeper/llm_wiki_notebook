# Swarm Skills

Swarm Skills 是 [[jiuwenswarm]] 框架中的团队级技能封装体系，解决多 Agent 协同中"经验沉淀、流通和持续优化"的全栈问题。

## 三层体系

### Swarm Skills — 团队级技能封装
将团队协作中跑通的最佳实践、SOP、角色搭配、调度策略标准化封装成可复用的"团队级技能"。使"一支优秀的 Agent 团队"变成"一套任何场景下都能即插即用的作战能力"。

### Swarm Skills Hub — 技能共享市场
开放的共享生态，让团队级协作经验在开发者社区中流通、复用、二次创作。用户可上传自己的团队技能至 Hub。

### Swarm Skills 自演进 — 越用越强的飞轮
演进引擎持续观察任务执行轨迹（任务拆解、角色调度、消息往来等），自动反推可复用的 Swarm Skill，提交用户审批即可入库。

自演进在两个层面进行：
- **团队层**：自动增减角色、补充约束规则、优化协作流程，提升 Leader 的规划与管控能力
- **成员层**：沉淀工具报错、接口超时、调用技巧等经验，再遇同类问题直接解决

## 与相关概念的比较

- **vs [[办公技能框架]]**：理念相似（可复用技能模块），但 Swarm Skills 从单 Agent 维度提升至团队级，涵盖角色搭配和协作流程
- **vs [[自进化架构]]**：Swarm Skills 自演进是自进化架构在多 Agent 协同层面的延伸，从单智能体自进化扩展到群体自进化

## 实战案例

短视频创作场景展示了完整的自演进闭环：
1. 首次执行 → Leader 组建临时团队完成创作
2. 演进引擎识别可复用模式 → 自动生成 Swarm Skill → 用户审批入库
3. 基于技能再次执行 → 识别角色形象不一致等信号 → 新增角色、优化技能
4. 持续迭代 → 视频效果不断提升，产出适配多平台的标题文案
