# Agentic UI (智能体用户界面)

**Agentic UI**（智能体用户界面）是一种新兴的界面设计范式。它指网页或应用不仅为人类用户提供视觉展示，同时也为 AI 智能体提供结构化的操作接口。在此范式下，AI 智能体不再局限于传统的对话式交互（LUI），而是能够动态调用、生成和操作传统图形用户界面（GUI）组件。

## 核心定义与特征

Agentic UI 的核心在于**双重服务**与**动态生成**：

1.  **双重服务对象**：
    在 Agentic UI 时代，网页开发者需要同时考虑两类“用户”的需求：
    *   **人类用户**：需要视觉美感、品牌叙事和直观的交互体验。
    *   **AI 智能体**：需要清晰定义的工具契约、结构化数据和高效的函数调用路径。

2.  **按需生成的界面**：
    界面不再是预先设计好的静态页面，而是由 AI 智能体根据任务上下文和用户意图，**按需自动生成和调用**的。用户与 AI 的交互从单纯的「问答」变成了「协作」，AI 可以直接在对话流中「甩出」一个交互界面（如数据图表、配置表单、文档预览），用户可以直接操作这些界面，操作结果会实时反馈给 AI。

## 交互范式的演变

Agentic UI 代表了人机交互的下一个阶段：

1.  **GUI (图形用户界面)**：传统的点击、拖拽交互，用户适应工具。
2.  **LUI (语言用户界面)**：以 ChatGPT 为代表的纯文本对话交互，AI 理解自然语言指令。
3.  **Agentic UI**：AI 结合了 LUI 的灵活性和 GUI 的直观性，界面融入工作流，需要时自动出现。

## 技术实现与意义

*   **[[webmcp]] 与 [[MCP Apps]]**：
    [[webmcp]] 的出现加速了 Agentic UI 的落地。它允许开发者在构建人类 UI 的同时，为 Agent 暴露一套专用的工具集。[[MCP Apps]] 是目前实现 Agentic UI 的典型技术方案之一，它通过沙箱化 iframe 渲染和 JSON-RPC 通信，允许 AI 模型在宿主客户端中安全地嵌入和操作第三方 UI 组件。
*   **协作体验**：
    这种设计不仅简化了身份验证和状态同步，还让用户和智能体可以在同一个界面里并肩工作。

## 行业观点与愿景

Amplitude 创始人曾直言：「传统 UI 已死，没有人再去登录 100 个 SaaS 去折腾。未来的 UI，直接融入每个人工作流，需要的时候自动出现。」这反映了 Agentic UI 的核心愿景：消除应用之间的边界，实现 [[Chat as an App]]（对话即应用）。

## 潜在风险

虽然 Agentic UI 提升了效率，但允许 AI 自动调用并操作涉及核心数据的敏感应用（如 Slack、Asana），依然存在巨大的企业数据泄露风险。如何平衡开放性与安全性是该范式面临的主要挑战。
