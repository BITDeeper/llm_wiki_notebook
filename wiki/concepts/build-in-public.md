# Build in Public（公开构建）

将产品开发过程公开化，在社区互动中迭代完善产品的理念。开发者不再闭门造车，而是将想法起源、Demo测试、翻车经历、用户反馈驱动的改进等全过程公开展示。

## 核心要素

- **过程即产品** — 开发过程本身具有观赏和传播价值
- **用户即共创者** — 社区反馈直接驱动产品迭代方向
- **高频MVP测试** — 每一次公开展示都是一次 [[mvp|最小可行性产品]] 验证

## 在AI产品开发中的应用

[[b站]] 主办的 [[build-in-bilibili-ai创造公开赛]] 是该理念在AI领域的典型实践。参赛者将AI产品创造过程以视频形式在B站连载更新，弹幕提需求、评论区挑bug，产品在社区关注和互动中逐步完善。

## 与传统模式的区别

传统产品链路中，研发、测试、发布、宣发完全割裂；公开构建模式下，这些环节在社区中同步进行，产品从一个"闭门造车的结果"变成"在众人关注中长出来的成果"。这种在社区里生长的AI应用，天然具备对抗"自嗨和伪需求"的免疫力。
