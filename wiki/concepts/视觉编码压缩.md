# 视觉编码压缩

[[视觉编码压缩]]（Visual Encoding Compression）是一种用于降低大模型训练和推理成本的技术手段，在 [[SKILL0]] 框架中被用于处理技能文档。

## 原理

将文本形式的技能文档（如 Markdown 文件）渲染成一张图片，然后利用视觉编码器（Vision Encoder）将图片压缩成高维特征向量。

## 优势

-   **降低 Token 开销**：相比于直接将长文本切分为 Token 输入语言模型，视觉编码器通常具有极高的信息压缩率，一张图片即可包含大量文本的语义信息。
-   **保留结构信息**：通过颜色编码等方式，可以在图像中保留原文档的标题、层级等结构特征，有助于模型理解技能的逻辑关系。

## 应用场景

该技术特别适用于需要向模型注入大量参考文档或知识库的场景，例如 [[上下文强化学习]] 中的技能脚手架构建。
