# 偶然复杂度

[[偶然复杂度]]（Accidental Complexity）是指在软件开发或系统落地中，并非由问题本质决定，而是由工具、流程或历史包袱引入的非必要复杂性。

## 在 Agent 落地中的体现
企业在引入 AI Agent 时，往往面临大量与核心业务无关的“脏活累活”：
- 如何配置运行环境？
- 如何管理 Agent 的长时状态？
- 如何打通异构系统的通信？
- 如何处理复杂的权限映射？

这些复杂性并非 Agent 任务本身固有的，而是由于缺乏适配的基础设施产生的。

## 解决方案
[[腾讯云]] 的 [[Agent Runtime]] 将“消灭偶然复杂度”作为核心设计目标。通过提供原生的运行环境、状态管理和安全沙箱，它屏蔽了底层技术细节，让开发者能专注于业务逻辑本身。

## 核心思想
- **本质复杂度**：必须保留，与业务直接相关。
- **偶然复杂度**：必须消灭，通过抽象和自动化由基础设施层吸收。
