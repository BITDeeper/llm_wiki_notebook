# 第三方套壳

指利用官方接口或前端工具包装底层模型服务，通常以更低价格或更便捷的交互方式提供给用户的应用程序。

## 风险与挑战
虽然此类工具（如 [[openclaw]]、早期的 Claude Code 套壳）在 AI 爆发期为用户提供了极大的便利和套利空间，但它们直接触犯了厂商的商业利益。

## 打击手段
- **技术限制**：引入客户端指纹识别、异常流量监测。
- **账号封禁**：针对使用套壳工具的账号进行无预警封禁，甚至波及核心服务（如 Gmail）。
- **法律合规**：修改服务条款，收回对非官方渠道的授权。

## 企业警示
将核心业务逻辑构建在第三方套壳上被视为高危操作，因为一旦底层供应商切断接口，企业将面临业务中断且缺乏谈判筹码的困境。
