# 技能积累

在 AI Agent 领域，[[技能积累]]（Skill Accumulation）指的是 Agent 通过试错、总结经验而形成的可复用能力单元。这是 [[傅盛]] 在实战中提出的 Agent 核心壁垒。

## 核心特征

与人类的学习过程类似，Agent 的技能积累遵循“踩坑—总结—写成文档—下次自动执行”的循环。但与人类不同的是，Agent 的技能具有以下特性：
1.  **永久性**：一旦形成，永不遗忘。
2.  **无损复制**：可以瞬间在 Agent 之间传递，无需重新学习。
3.  **确定性**：每条规则转化为一个 Skill，确保“永不再犯”。

## 实例分析

在 [[三万]] 的训练过程中，[[技能积累]] 体现得淋漓尽致：
- **初期**：Agent 无法查询公司通讯录，经常报错。
- **中期**：通过编写脚本，Agent 学会了抓取 674 人通讯录。
- **后期**：Agent 能够自主判断病情、主动联系助理、修复网站崩溃。

每一次错误都被转化为一条规则，每一条规则都变成了一个 Skill。这使得 Agent 越用越强，呈现出“越养越好用”的特性。

## 与模型参数的区别

傅盛强调，Agent 的核心壁垒不在于模型参数的大小或智商的高低，而在于 [[技能积累]]。模型决定了推理的基准能力，而技能积累决定了 Agent 在特定垂直领域的实际执行效率和可靠性。

## 商业意义

[[技能积累]] 意味着 AI Agent 的价值随着使用时间的增加而指数级增长。这解释了为什么私有数据注入和长期使用是 Agent 产品差异化的关键，也是对传统 SaaS 模式（卖固定能力）的根本性颠覆。
