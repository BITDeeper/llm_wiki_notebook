# 边缘 AI 终端

边缘 AI 终端是指在算力、内存、屏幕等资源极度受限的硬件设备上部署 AI 能力的技术范式。与在数据中心运行大模型不同，边缘终端需要在设备能力与 AI 服务之间找到可行的集成路径。

## 两种技术路线

### 路线一：本地推理

在终端设备上直接运行模型（通常经过 [[量化]] 压缩），无需网络连接。典型案例如在笔记本电脑上运行 Llama 70B。参见 [[本地推理]]。

### 路线二：超薄客户端 + 云端 API

终端设备仅充当输入/输出界面，所有推理计算在云端完成，通过 Wi-Fi 或蜂窝网络调用远程 API。[[cardputer]] 运行 [[claude-code]] 即为此路线的极端案例——ESP32-S3 芯片仅负责键盘输入、屏幕显示和 API 通信，大模型推理完全依赖 Anthropic 云端。

## 关键区别

| 维度 | 本地推理 | 超薄客户端 |
|------|---------|-----------|
| 网络依赖 | 无 | 强依赖 |
| 延迟 | 低（本地计算） | 受网络影响 |
| 隐私 | 数据不出设备 | 数据上传云端 |
| 硬件要求 | 高（需运行模型） | 极低（仅需网络通信） |
| 典型设备 | 笔记本、工作站 | IoT 开发板、嵌入式设备 |

## 意义

边缘 AI 终端的探索拓宽了 AI 工具的部署边界。[[cardputer]] 案例表明，即使是卡片大小的开发板，只要具备网络连接能力，就能接入最先进的 AI 编程代理，将"AI 握在手心"从比喻变为现实。
