# 视觉对齐的动作 Tokenizer

视觉对齐的残差向量量化 Tokenizer 是[[wall-oss-0.5]]的关键技术组件，解决了传统动作 Tokenizer 只做数值压缩、缺乏物理语义的问题。

## 核心思想

在量化动作的同时，强制 Token 的表征与对应时刻的视觉特征对齐，并要求其预测下一帧的视觉变化。每个动作 Token 同时承载两层信息：

1. **「电机怎么转」**：动作的物理执行参数
2. **「画面怎么变」**：动作对应的视觉变化

## 与 FAST Tokenizer 的对比

业界广泛使用的 FAST Tokenizer 能还原动作，但不知道动作「对应画面里发生了什么」——它只做数值压缩，不传递语义。视觉对齐 Tokenizer 使动作 Token 进入与视觉、语言相同的语义空间，主干网络在预测下一个动作时，实际上是在进行高维度的时空推演。

## 在梯度桥接中的角色

在[[梯度桥接协同训练]]框架中，视觉对齐 Tokenizer 确保通过「梯度桥」传进主干大脑的不是没有物理意义的编号，而是有真实物理含义的信号。
