# Coding作为Agent核心能力

Coding能力使Agent从调用现成工具进化为自主创建工具、写脚本、改流程，成为通用问题解决能力。

## 质变节点

2026年1-2月，Coding能力的突破被认为是Agent从概念验证进入产品爆发期的核心驱动力。

## 关键论述

- **从工具调用到自主构建**：[[openclaw|OpenClaw]]之所以能火，是因为它不只是调用现成工具，而是可以自己创建闹钟、写声音读取控件，把散落的工具和功能重新组织成可执行的任务流程
- **Coding即水电煤**：[[冯雷]]提出大模型是未来的水电煤，Coding也是未来的水电煤，会渗透到生活的方方面面
- **边界模糊**：在ToB和ToD领域，Coding Agent和通用Agent之间的边界已越来越模糊，真正的价值在于生产东西、交付可用且有ROI的结果
- **自我进化基础**：Agent自我进化本质上基于Coding能力——Agent可以根据任务需要自己补工具、写脚本、改流程

## 技术演进时间线

- 2023年：Function Calling方式做Agent tools
- 2024年：MCP出现，Agent工作围绕MCP展开
- 2025年底：Agent Skill成为大趋势
- 2026年初：Coding能力突破，Agent质变

## 与现有概念的关系

- 延伸了[[任务执行范式]]，Coding使Agent从执行者变为构建者
- 与[[vibe-coding]]相关但侧重不同：Vibe Coding强调零代码用户体验，本概念强调Coding作为Agent自身的核心能力
