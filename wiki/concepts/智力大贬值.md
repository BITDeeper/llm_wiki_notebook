# 智力大贬值

“智力大贬值”是指人工智能生成内容的边际成本随时间呈指数级下降的现象。这一趋势正在重塑 AI 行业的商业逻辑，使得智力从稀缺资源转变为廉价的基础设施。

## 数据证据
- **MMLU 42 分成本**：
  - 3 年前（GPT-3 时代）：$60 / 百万 tokens。
  - 2026 年（Together.ai）：$0.06 / 百万 tokens。
- **降幅**：达到同等智力水平的成本在三年内下降了 99.9%。

## 市场影响
1. **价格战**：2025 年全球 API 价格暴跌 60%，行业从“美元时代”进入“美分时代”。
2. **竞争格局重塑**：[[DeepSeek]] 等新玩家以 1/50 的成本迅速抹平了 OpenAI 的技术代差。
3. **订阅制失效**：固定费率的订阅模式（如 $20/月）在成本崩塌和竞争加剧的背景下显得定价过高，导致用户流失。

## 战略后果
为了应对智力不再稀缺的现实，AI 公司被迫转向 [[模型即流量诱饵]] 的商业模式，不再直接通过智力本身获利，而是将其作为吸引流量、分发广告或销售硬件的杠杆。
