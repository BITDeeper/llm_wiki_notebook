# 端-边-云一体

端-边-云一体是 [[端云协同]] 架构的进一步演进形态，引入了“边”这一算力层级。

## 架构分层

*   **端**：终端设备（手机、PC），负责敏感感知与即时交互。
*   **边**：个人或家庭算力中心（如 [[AI主机]]），负责高算力但涉及隐私的任务。
*   **云**：公有云，负责通用知识库与超大规模计算。

## 优势

这种架构旨在实现算力成本与隐私安全的最优平衡，既降低了持续使用云端 API 的 Token 成本，又保证了核心数据不出域的安全性。
