# 内鬼路由攻击

恶意 AI 中转站利用其在 Agent 和模型之间的中间人位置，注入恶意内容或替换依赖包的新型攻击向量。

## 攻击原理

当 AI 从对话工具进化为能自主执行代码的智能体（Agent），中转站的风险维度指数级升级。恶意中转站拥有对所有请求和响应的完整读写权限：

- 在返回给 Agent 的响应中注入恶意内容
- 在 Agent 自动安装依赖包时替换为同名恶意包
- 使用「条件投递」——前 50 次请求完全正常，第 51 次才激活注入逻辑

## 条件投递

条件投递使传统的行为检测完全失效。正常请求和恶意请求在统计上无法区分，安全审计面临根本性挑战。

## 真实前例

2026 年 3 月 [[litellm]] 投毒事件：黑客通过依赖包漏洞入侵主流开源 LLM 框架，波及数万个开发环境。

## 对 Agent 工具的威胁

对于赋予了代码执行最高权限的 [[claude-code]] 或类似工具，内鬼路由攻击的危险程度几乎是指数级的：中转站不需要攻击用户设备，只需污染 Agent 接收到的信息，就能让 Agent 代替攻击者完成任何操作。
