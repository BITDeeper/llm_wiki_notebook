# DSA-稀疏注意力机制

DSA (DeepSeek-style Sparse Attention) 是一种动态的细粒度选择机制，旨在解决传统 Transformer 密集注意力在长上下文场景下计算成本高昂（O(N²)）的问题。

## 工作原理
与传统的滑动窗口或全注意力机制不同，DSA 会“审视”内容，动态决定哪些 Token 是重要的。在计算当前 Token 的注意力时，它只从历史 Token 中挑选出与之最相关的 Top-K 个 Token 进行计算，忽略其他无关 Token。

## 优势
1. **成本降低**：KV Cache 开销可降低 75%，意味着同样的显存可以支撑更长的上下文或更高的并发。
2. **速度提升**：注意力计算的 FLOPS 大幅削减，推理速度可提升 3 倍。
3. **性能无损**：在 RULER 等长文本复杂推理评测中，引入 DSA 的模型性能损失通常小于 0.5%。

## 训练策略
直接训练基于 DSA 的超大模型面临梯度爆炸或模型崩塌的风险。因此，通常采用“稠密预热 + 平滑过渡”的策略：
1. **稠密预热**：预训练初期使用相对稠密的注意力（如 MLA 变体），建立稳固的语义表征。
2. **平滑过渡**：逐步提高稀疏度，引入动态路由机制，使模型适应稀疏计算。

## 应用案例
- **DeepSeek V4**：该技术的首创者，通过 DSA 实现了高效的长上下文处理。
- **GLM-5**：智谱 AI 在 GLM-5 中引入了同款 DSA 机制，验证了其在开源模型中的有效性。

## 与其他优化技术的对比
与 [[Split-K 优化]] 等牺牲确定性换取性能的工程优化不同，DSA 是一种算法层面的架构创新，旨在保持模型性能的同时降低计算复杂度。
