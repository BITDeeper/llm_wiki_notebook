# SVG 生成

[[svg-生成]] 是指利用大语言模型生成可缩放矢量图形（SVG）代码的技术。

## 优势
与传统的图像或视频生成相比，AI 生成的 SVG 具有以下显著优势：
1. **无限缩放**：基于数学公式描述的图形，在任何分辨率下都绝对清晰。
2. **体积极小**：纯代码文本文件，相比视频文件体积小得多，便于传输和嵌入网页。
3. **可交互性**：生成的代码可以直接嵌入 Web 应用，支持 CSS 动画和 JavaScript 交互。

## 应用场景
- **数据可视化**：生成实时更新的图表和看板。
- **创意动画**：根据文本描述生成复杂的动画效果（如鸟群飞舞、植物生长）。
- **UI 原型设计**：快速生成可编辑的界面元素。

## 技术体现
[[gemini-3-1-pro]] 在这一领域表现出了卓越的能力，能够理解复杂的视觉逻辑并生成对应的 SVG 代码，被视为模型代码生成与视觉理解能力结合的典范。
