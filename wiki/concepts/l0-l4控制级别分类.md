# L0-L4控制级别分类

[[agentic-visual-generation综述|Agentic视觉生成综述]]提出的核心学术贡献：按照控制器（通常为LLM/VLM）能够影响的**最远决策**，将视觉生成系统划分为五级，类比自动驾驶L0-L5分级。

## 分级定义

| 级别 | 名称 | 控制范围 |
|---|---|---|
| L0 | 固定支撑 | 生成器、编辑器、评估器按预设路径运行，无控制器决策（与画质无关） |
| L1 | 条件控制 | 准备输入条件：改写提示词、规划布局、选择参考图、检索知识、设计分镜 |
| L2 | 执行控制 | 选择并编排实际操作：生成、局部编辑、模型切换、节点编排 |
| L3 | 结果自适应控制 | 查看生成结果后局部编辑、重生成、调整条件或停止 |
| L4 | 经验自适应控制 | 将经验沉淀为长期记忆、能力档案、工作流、技能库，用于未来独立任务 |

控制范围沿L1→L4依次从输入条件扩展到执行操作、任务内反馈、跨任务长期经验。

## 数量分布与领域张力

截至2026年8月24日：L1=49、L2=33、L3=202、L4=25。2025年后增长集中于L3；L4稀少是领域结构性失衡。

## 评估要求

对齐比较条件（固定生成器/工具/预算/评估器），逐次增加一类决策能力；记录修正代价（破坏已确认内容、违反硬性约束、停止时机）。L4评估需检查负迁移与遗忘。
