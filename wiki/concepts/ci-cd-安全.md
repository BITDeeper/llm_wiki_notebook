# CI/CD 安全

CI/CD (Continuous Integration / Continuous Deployment) 安全是指保护软件自动化构建、测试和部署流程的实践。随着开发流程的自动化，CI/CD 系统往往拥有访问代码库、凭证和生产环境的极高权限，使其成为攻击者的重点目标。

## 核心风险

- **凭证泄露**：CI/CD 脚本通常包含写入数据库、部署服务器或上传包（如 PyPI）的密钥。一旦流水线被入侵，这些凭证极易泄露。
- **工具污染**：正如 [[LiteLLM]] 事件所示，即使是用于安全扫描的工具（如 [[Trivy]]），如果被篡改，也会成为攻击的跳板。
- **供应链注入**：攻击者在构建过程中自动注入恶意代码，使得官方发布的软件包自带后门。

## 防御措施
- **隔离构建环境**：使用临时或隔离的容器进行构建，避免构建环境访问敏感凭证。
- **签名验证**：对构建工具和依赖项进行加密签名验证，确保未被篡改。
- **最小权限原则**：限制 CI/CD 系统的权限范围，避免使用具有全局写入权限的令牌。
