# 操作系统Agent (OS Agent)

操作系统Agent（OS Agent）是指跳过应用层，直接在操作系统底层运行的AI智能体。与传统对话式AI助手不同，OS Agent能够接管文件管理、系统设置、应用联动等全局任务，实现从"回答问题"到"替你干活"的能力跃迁。

## 核心特征

1. **系统层运作**：不局限于单个应用内，而是扎根操作系统底层，具备全局操作权限
2. **跨应用协同**：能够联动多个应用程序完成复合任务，打破应用间的壁垒
3. **自主执行**：用户只需下达指令，Agent自行拆解、分发并执行任务
4. **设备级感知**：能够检测硬件状态、系统资源等底层信息

## 代表产品

- **[[马维斯]]**：[[腾讯]]应用宝团队推出的OS Agent，采用[[多agent协作架构]]，支持隐私/效率双模式和跨设备协同

## 与相关概念的关系

- OS Agent是[[任务执行范式]]从"对话助手"向"智能体工程化系统"演进的具体体现
- OS Agent的自主系统操作能力是[[系统智能]]从单点工具走向整合系统的关键一步
- 多Agent架构的OS Agent（如马维斯）是[[1-n-agent调度]]范式在产品层面的典型实现

## 竞争格局

OS Agent赛道目前处于早期阶段，主要参与者包括：
- 微软 Windows Copilot
- [[腾讯]] [[马维斯]]
- 其他正在探索中的系统级AI智能体产品

## 关键挑战

- **隐私安全**：AI深度进驻系统层引发用户对数据安全的顾虑
- **权限管理**：系统级操作需要精细的权限控制机制
- **任务调度效率**：多Agent并行执行中的资源分配和闲置优化
- **跨平台兼容**：不同操作系统的适配和统一体验
