# Agent 工作流

Agent 工作流是指利用多个具有特定角色和功能的 AI 智能体协同工作，以完成复杂任务的系统设计模式。它代表了从单一 Prompt 交互向结构化多 Agent 系统的演进。

## 典型特征

### 角色分工
系统中的每个 Agent 被赋予特定的职业身份和专业领域，如 [[claude-code-game-studios]] 中的“创意总监”、“技术总监”或“关卡设计师”。这种分工模拟了人类团队的组织结构。

### 层级协作
Agent 之间通常存在层级关系或协作流程。高层 Agent 负责决策和拆解任务，低层 Agent 负责具体执行和技术实现。

### 人类在环
尽管 Agent 承担了大量执行工作，但成熟的 Agent 工作流通常保留人类对关键节点的最终决策权，以确保产出符合预期且可控。

## 应用价值

### 复杂任务拆解
对于软件开发、游戏制作等复杂任务，单一模型往往难以兼顾全局战略和细节实现。多 Agent 系统通过分工合作，能有效解决上下文限制和专注度问题。

### 规模化个人生产力
通过 Agent 工作流，个人可以调动相当于数十人团队的算力和智力，实现“一人公司”或“超级个体”的运作模式。
