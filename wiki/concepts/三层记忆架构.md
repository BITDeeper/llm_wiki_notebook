# 三层记忆架构

三层记忆架构是为了解决 AI Agent 在长期运行中出现的“失忆”和核心信息丢失问题而提出的一种技术方案。由清昴智能技术专家 [[杨泽乾]] 在 OpenClaw 沙龙上提出。

## 背景与动机
AI 系统在处理大量日常对话时，往往会进行摘要或压缩，这可能导致关键信息（如 API 路径、核心决策依据）被误删或覆盖。Meta 曾因 AI 记忆压缩错误，把测试环境的背景丢失，导致差点发出灾难性的删除指令。

## 架构分层
该架构将 Agent 的记忆系统划分为三个层次：

1.  **感知**
    *   处理原始输入和即时信息。
2.  **认知**
    *   处理日常对话、上下文和短期记忆。
3.  **逻辑**
    *   **核心层**。永久固化关键的 API 路径、决策依据和核心知识。
    *   **特性**：这一层的信息不会被日常废话“摘要”掉，确保了系统的确定性和安全性。

## 价值
*   **守护技术尊严**：防止因记忆混乱导致的操作失误。
*   **降本增效**：通过这种分层机制，即便是性价比更高的边端小模型，也能跑出顶配模型的执行效果。
*   **知识沉淀**：实现了“会话会断，但知识沉淀和记忆不该断”的目标。
