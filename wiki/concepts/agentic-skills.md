# Agentic Skills

[[Agentic Skills]]（代理式技能）是指 AI 智能体在 [[行动智能]] 框架下所需的具体能力组合。在 [[Claude Mythos]] 的语境中，这些技能被明确划分为三个维度：

1.  **Agentic Coding（代理式编程）**：不仅是生成代码片段，而是能够理解整个代码库、运行测试、修复 bug 并进行版本控制的完整工程能力。
2.  **Reasoning（推理）**：支持复杂的长链路逻辑思考，能够处理多步骤问题并在执行过程中调整策略。
3.  **Agentic Search and Computer Use（代理式搜索与计算机使用）**：能够像人类一样使用计算机工具，包括浏览网页、操作终端、调用 API 以及利用软件界面。

这些技能共同构成了 AI 从“聊天工具”转变为“数字行动者”的技术基础。
