# 数据价值密度（Data Value Density, DVD）

## 定义

数据价值密度（DVD）是上海交通大学与上海人工智能实验室研究团队在首篇系统性综述中首次提出的核心概念，其数学定义为：

**f(D∣C) = V(D∣C) / μ(D)**

其中：
- **D** 表示 LLM 训练所使用的数据集
- **C** 表示评估数据价值所必须的上下文信息（如当前 LLM 能力分布、目标任务特征等）
- **V(D∣C)** 衡量数据集 D 在训练上下文 C 下对模型性能提升的总贡献价值
- **μ(D)** 衡量数据集 D 的规模

该领域的研究目标，就是构建一个新数据集，使其价值密度大于原数据集（Δf > 0）。

## 五大增强类别

基于 DVD 定义中分子 V(D∣C) 与分母 μ(D) 的动态变化关系，现有方法被划分为五大类别：

| 类别 | V(D∣C) 变化 | μ(D) 变化 | 代表方法 |
|------|------------|----------|---------|
| 第一类 | 提升 | 不变 | 数据调度、数据混合、增强式生成 |
| 第二类 | 不变 | 下降 | 重复数据去除、数据蒸馏 |
| 第三类 | 提升 | 下降 | 负价值数据去除 |
| 第四类 | 略降 | 暴降 | 高价值数据筛选 |
| 第五类 | 暴增 | 略增 | 数据进化 |

## 与相关研究范式的关系

DVD 增强与以下研究范式存在底层逻辑关联：
- **上下文学习（In-Context Learning）**
- **能力密度（Capacity Density）**
- **样本效率（Sample Efficiency）**
- **主动学习（Active Learning）**

## 四大挑战

1. **"黑盒"可解释性差**：现有方法高度依赖人类经验，数据对模型能力分布的影响、数据点之间的交互模式等仍缺乏严谨的理论框架支撑
2. **实施成本昂贵**：减少训练数据量的方法本身可能产生巨大额外成本（如调用 LLM 大规模采样、训练打分模型等）
3. **人工与自动化的两难**：专家标注质量可控但成本极高，模型自动化效率高但易引入幻觉
4. **垂直领域研究空白**：垂直领域数据稀缺且具有独特特征，通用方法在垂直领域性能往往较差

## 与 Scaling Law 的关系

当 [[scaling-law]] 在数据维度遇到瓶颈——互联网高质量数据年增长率不足10%，无法满足 LLM 训练数据规模扩张需求——DVD 提供了从"量扩展"转向"质提升"的理论路径。这代表了从粗放式数据消耗向精准化知识萃取的范式转型。

## 代表性数据集

综述梳理了 DVD 增强研究中高频使用的数据集，分为三大板块：
- **文本理解**：从万亿 Token 无标签预训练语料到少而精的有标签后训练数据
- **复杂推理**：MATH、GPQA、OpenThoughts、AIME 等主流推理数据集
- **垂直领域**：医疗、法律、金融等多个领域的相关数据集
