# NPU 训练

NPU 训练是指在专为推理设计的神经网络处理单元（NPU）上执行反向传播和权重更新。长期以来，NPU 被认为仅适合推理，但 [[manjeet-singh]] 对 [[ane-apple-neural-engine|Apple Neural Engine]] 的逆向工程证明了其在特定条件下完全具备训练能力。

## 技术挑战

### 1. 逐元素运算回退
NPU 是针对矩阵乘法和卷积等高度并行运算优化的固定功能加速器。训练过程中的许多逐元素运算（如激活函数、损失计算）在 NPU 上不支持，通常会回退到 CPU 执行，导致严重的性能瓶颈。

### 2. 内存带宽限制
训练不仅需要前向传播，还需要存储梯度以进行反向传播。这通常需要两倍的内存带宽。对于受限于 SRAM 容量的 NPU（如 ANE 的 32MB），这极大地限制了可训练模型的规模。

### 3. 软件栈限制
主流 NPU 厂商（如 Apple）通常通过软件栈（如 CoreML）禁用训练功能，仅暴露推理接口。这需要通过逆向工程私有 API 来解锁。

## 解决方案与优化

### 深度图优化
为了最大化 NPU 的吞吐量，必须构建“深度图”而非“广度图”。
- **原理**：将多个运算链接成一个长链条，使 NPU 的流水线始终处于忙碌状态。
- **效果**：在 ANE 上，这可将硬件利用率从 30% 提升至 94%。

### 卷积重塑
将标准的矩阵乘法运算重塑为 1x1 卷积运算。
- **原理**：利用 NPU 为卷积优化的快速数据通路。
- **效果**：在 ANE 上，这可带来 3 倍的性能提升。

### 混合精度训练
虽然 NPU 内部可能使用 FP16 进行计算，但利用 INT8 存储权重可以节省内存带宽。然而，需注意某些 NPU（如 ANE）在计算前会将 INT8 反量化为 FP16，因此计算速度并不会提升。

## 应用前景

### 本地微调
NPU 训练使得在个人设备（如 MacBook）上进行小规模模型的微调成为可能。
- **成本**：仅需消耗极少的电力（<1W），远低于云端 GPU 租用费用。
- **隐私**：数据无需上传至云端，适合处理敏感信息。

### 能效优势
NPU 在能效比上远超 GPU。例如，ANE 的能效比达到 6.6 TFLOPS/W，是 A100 的 80 倍。这使得 NPU 成为电池供电设备上进行 AI 训练的理想选择。

## 局限性
- **模型规模**：受限于片上 SRAM，目前仅适合训练小型模型（如 100M 参数）或对大模型进行 LoRA 微调。
- **通用性**：并非所有 NPU 都支持训练，且不同厂商的架构差异巨大，优化策略难以通用化。
