# Agent场景化模型

Agent场景化模型是指专门针对智能体任务特性进行优化的大语言模型，而非通用的对话模型。

## 核心差异

### 通用模型的局限
通用大语言模型（LLM）通常在单轮对话或简单的问答任务上表现优异，但在面对 Agent 场景时往往存在短板：
- **长链路规划**：在需要跨越多个步骤、保持长期目标的任务中容易迷失方向。
- **工具调用稳定性**：在需要反复调用 API 或操作工具时，容易出现格式错误或逻辑断裂（即“掉链子”）。

### 场景化模型的优化
像 [[pony-alpha-2]] 这样的 Agent 场景化模型，通过针对性的架构调整或训练数据优化，专注于解决以下问题：
- **多步执行**：确保在连续的工具调用和状态更新中保持逻辑连贯。
- **复杂规划**：能够将模糊的指令拆解为可执行的子任务序列。
- **容错能力**：在工具执行失败时具备更强的重试或修正能力。

## 发展趋势
随着 [[任务执行范式]] 的普及，模型研发正从单纯追求“参数规模”转向追求“特定工作流下的效能”，Agent 场景化模型正是这一趋势的体现。
