# Project Glasswing

Project Glasswing是[[anthropic|Anthropic]]旗下的项目，旨在将无护栏版本的[[mythos-5|Mythos 5]]模型提供给特定组织用于国家级网络攻防研究。

## 已知信息

- 已覆盖约**15个国家**的约**150个组织**
- 提供的是无安全护栏版本的Mythos 5——该模型因网络安全能力过强而无法全面公开
- 面向公众的[[fable-5|Fable 5]]是Mythos 5的"安全版"，涉及网络安全、生物和化学的请求会自动回退到前代模型Opus 4.8

## 战略含义

Project Glasswing揭示了AI模型能力与安全约束之间的深层张力。Mythos 5级别的模型在网络安全领域的能力已强到需要特殊管控的程度，这既是[[递归式自我改进|RSI]]进展的标志，也引发了关于AI能力扩散风险的深层担忧。
