# 内部与消费者模型差异

同一 AI 模型在内部工程场景和面向消费者场景中表现截然不同的现象，因配置、安全对齐、资源限制等差异导致。

## 核心表现

### Anthropic 内部的 Claude
- 代码库超 80% 由 Claude 编写
- 工程师人均产出翻 8 倍
- AI 独立任务时长每 4 个月翻一番
- [[claude-mythos-preview|Claude Mythos Preview]] 达到 [[metr|METR]] 评测上限
- 可连续工作 12 小时，独立完成人类需要半天才能完成的软件任务

### 面向消费者的 Claude
- 频繁使用"结束对话"工具终止交互
- 过度激进的"反驳用户"机制
- 拒绝执行简单任务（如格式化 Markdown 文档）
- 用户投诉"完全不能用了"

## 差异原因分析

1. **模型配置差异**：内部工程场景下，Claude 被精心设置为长时间、高强度运行的工作模式。
2. **安全对齐差异**：面向消费者的版本可能在安全对齐上施加了更多限制，导致矫枉过正。
3. **资源分配差异**：消费者版本在对话轮次管理、token 分配上可能有更严格的限制。
4. **提示词策略差异**：内部使用的提示词策略与消费者通过 API 或 Claude.ai 接触到的产品之间存在巨大差异。

## 行业普遍性

文章指出，这一现象似乎在其他 AI 工具中也存在类似的模式，但许多用户表示并未遇到类似问题，说明差异可能因使用场景和配置而异。
