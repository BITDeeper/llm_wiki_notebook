# 技能文档自我进化

技能文档自我进化是指将指导 AI 智能体行为的自然语言文档（如 system prompt、skill 文件、CLAUDE.md 等）视为「外部权重」，通过类似训练神经网络的系统化循环机制进行自动化迭代优化，而非依赖人工试错编写。

## 范式转移

传统方式下，开发者需要手工编写技能文档，通过「写一版→跑任务→发现问题→修改→再跑」的试错循环来迭代。这种方式本质上是手工劳动，且高度依赖开发者的经验和直觉。

技能文档自我进化将这一过程系统化、自动化：

| 维度 | 传统方式 | 自我进化 |
|------|---------|---------|
| 编写方式 | 人工试错 | 自动化训练循环 |
| 优化信号 | 主观判断 | 执行轨迹 + 验证得分 |
| 迭代节奏 | 随机、不规律 | 结构化 epoch/step |
| 质量保障 | 人工审查 | [[验证门控]] |
| 稳定性控制 | 无 | [[文本学习率]] |

## 核心类比

- **技能文档 = 外部权重**：不修改模型内部参数，而是优化外部的自然语言「参数」
- **执行轨迹 = 前向传播**：模型使用当前技能执行任务，产出「证据」
- **反思分析 = 反向传播**：分析成功/失败轨迹，计算「文本梯度」
- **结构化编辑 = 参数更新**：add/delete/replace 操作更新技能文档
- **验证门控 = 早停/正则化**：防止过拟合，确保真实改进

## 代表性实现

- **[[skillopt]]**（微软，2026年5月）：最完整的技能文档自我进化框架，包含训练循环、文本学习率、验证门控、负反馈缓冲区、元技能等全套机制。在 52 个评测组合中全面领先。
- **[[evolver]]**（EvoMap 团队）：开源自进化引擎，侧重模型层面的自进化，与 SkillOpt 的文本层面自进化形成互补。

## 关键发现

1. **小模型受益更大**：好的技能文档对能力较弱模型的帮助显著强于强模型（类比：好的操作手册对新手的帮助大于对专家的帮助）。
2. **强迁移能力**：一次训练的技能可跨模型、跨执行环境迁移使用。
3. **自优化可行**：即使优化器不比目标模型更强，系统化的训练循环仍能发现有效改进方向。
4. **部署零开销**：最终产物仅为一个 `.md` 文件，推理时无额外成本。
