# 潜意识循环（Subconscious Loop）

[[openhuman]] 提出的一种 Agent 运行机制，指智能体在用户不主动交互时，仍能自主加载待办、读取近期记忆、自主决定下一步行动。

## 核心特征

- **被动转主动**：Agent 从"你动它才动"的被动响应模式，转向持续自主思考
- **记忆驱动**：基于 [[记忆树]] 中的近期记忆做决策，而非从零开始
- **后台运行**：即使用户离开电脑，Agent 仍在后台执行待办任务

## 与现有概念的关系

- **[[系统智能]]**：潜意识循环是系统智能中"可行动"能力的具体实现
- **[[1-n-agent调度]]**：Agent 自主决策机制与多 Agent 调度趋势一致，用户角色从对话者变为监督者
- **[[认知投降]]** 风险：Agent 自主行动可能加剧用户对其输出的过度依赖

## 开放问题

- 自主决策的边界在哪里？如何防止 Agent 执行不可逆操作？
- 自主行动的可靠性和误操作风险如何评估？
