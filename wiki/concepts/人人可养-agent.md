# 人人可养 Agent

指一种极低技术门槛的 AI 智能体（Agent）使用理念。在这种模式下，普通用户无需具备编程知识或进行复杂的系统部署，就能像养电子宠物一样创建、定制和使用 AI 助理。

## 核心特征

### 1. 零部署
用户不需要配置服务器、安装环境或编写代码。Agent 通常直接集成在用户日常使用的软件平台（如 [[飞书]]）中，开箱即用。

### 2. 拟人化交互
Agent 以“联系人”、“同事”或“助理”的形式存在，用户可以通过自然语言进行对话和指令下达，降低了认知负荷。

### 3. 高度可定制
用户可以根据个人喜好设定 Agent 的“人设”（如性格、语气）和“技能”（如能调用哪些工具），使其更符合个人使用习惯。

## 意义
“人人可养”理念旨在推动 AI 技术从极客工具向大众生产力的普及。通过降低使用门槛，让更多非技术用户也能享受到 [[任务执行范式]] 转变带来的效率提升。
