# 查表式记忆

**查表式记忆** (Lookup-based Memory) 是一种模型架构设计范式，指通过直接查找预定义的静态 Embedding 表来获取记忆，而非通过输入动态计算地址向量。

## 核心思想

在传统的 Transformer（如 SwiGLU）中，FFN 层通过输入 $x$ 进行动态矩阵乘法来生成“地址向量”。而查表式记忆认为，既然核心目的是“按 token 访问记忆”，可以直接根据 token ID 查表，省去昂贵的动态计算过程。

## 代表性实现

-   **[[STEM 架构]]**：ICLR 入选论文，最早系统探索该方向的工作之一。它移除了 FFN 的 up-projection，改为静态查表。
-   **[[DeepSeek Engram]]**：工业界后续引发关注的类似机制，由 DeepSeek 提出。

## 优势

1.  **解耦记忆与计算**：模型的知识容量不再受限于单 token 的计算量（FLOPs）。
2.  **工程效率**：省去了大规模矩阵乘法，且 Embedding 表可灵活存储于 CPU 内存。
3.  **可解释性与可编辑性**：Token 与向量一一对应，便于进行知识编辑和安全性干预。

## 对比

与 [[MoE]] (混合专家模型) 相比，查表式记忆通常属于**静态稀疏架构**，不依赖运行时的动态路由决策，因此避免了负载均衡问题和通信开销。
