# 开源模型策略

## 定义
[[开源模型策略]] 指 AI 公司将大语言模型（LLM）的权重公开，允许开发者免费下载、使用和修改，而非仅通过 API 提供付费服务的商业模式。

## 阿里巴巴的立场
在 [[Qwen (通义千问)]] 技术负责人 [[林俊旸]] 离职引发外界对业务收缩的猜测时，阿里巴巴 CEO [[吴泳铭]] 明确表示，阿里将继续坚持开源模型策略，不会效仿 Meta Llama 走向闭源（注：此处指不改变现有的开源开放路径）。

## 战略价值
1. **对抗订阅制壁垒**：通过提供可本地部署的高性能模型（如 Qwen 2B/32B），吸引无法承担高昂 API 成本或对数据隐私敏感的开发者。
2. **生态建设**：开源策略有助于快速建立开发者生态，使模型成为行业标准或基础设施。
3. **差异化竞争**：在面对闭源巨头（如 OpenAI、Anthropic）时，开源是阿里、DeepSeek 等公司的重要差异化手段。

## 行业背景
这一策略与 [[DeepSeek V4]] 的路径相似，两者均试图通过开源和工程优化打破闭源模型的垄断。同时，这也被视为对 [[ai-subscription-crisis]] 的一种回应，即通过降低使用门槛来避免用户被锁定在昂贵的订阅制中。
