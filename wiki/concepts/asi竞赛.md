# ASI竞赛

ASI（Artificial Superintelligence，通用超级智能）竞赛指全球顶级AI公司在模型能力、基础设施和开发者生态三个维度上的终极角逐。当前决赛圈选手已基本锁定，形成两大阵营对峙格局。

## 阵营划分

- **OpenAI阵营**：[[openai|OpenAI]] + 微软 + Stargate（甲骨文 + 软银）
- **Anthropic阵营**：[[anthropic|Anthropic]] + 谷歌（400亿美元投资）+ 亚马逊（250亿美元容量协议）+ SpaceX（22万块GPU租赁）

## 核心论点

模型能力正在趋同，真正的护城河在于：
1. **基础设施强度**：谁拥有更多算力、更低的单位成本
2. **开发者生态规模**：谁的工具生态更丰富，吸引更多开发者
3. **企业客户粘性**：谁的客户迁移成本更高

## 关键节点

- 2026年5月中旬：马斯克诉OpenAI判决
- 2026年6月：[[anthropic|Anthropic]] IPO定价
- 2026年7月14日：[[claude-code|Claude Code]] 临时限额到期后的永久政策

## 与定价战的关联

2026年5月的 Agent SDK 额度分离事件被视为ASI决赛圈的"第一枪"。[[anthropic|Anthropic]] 修补定价漏洞的决策直接被 [[openai|OpenAI]] 转化为 Codex 迁移的卖点，开发者生态的天平可能因此倾斜。
