# 评估→训练因果链

由 [[lun-wang|Lun Wang]] 提出的分析框架，揭示评估在AI训练全链路中处于最上游位置。

## 因果链结构

**Scaling decision ← Safety metric ← RLHF ← Training signal ← Evaluation**

| 环节 | 含义 |
|------|------|
| Scaling decision | 要不要烧10亿训下一代 |
| Safety metric | 它安全吗 |
| RLHF | 它学到想学的吗 |
| Training signal | 它在学什么 |
| Evaluation | 我们到底在测什么 |

## 核心洞察

- 所有人盯着最右边（Scaling decision），但问题在最左边（Evaluation）。
- 如果评估是错的，整条链都建在错的地基上。
- 最致命的是不会立刻发现——所有内部数据都是对的，只是那些对的全部是用错的尺量出来的。
- 这与 [[古德哈特定律]] 形成共振：当一个衡量标准变成目标，它就不再是一个好的衡量标准。

## 推论

"如果你能正确地评估，你就能正确地训练。" 评估错了 = 损失函数错了 = 训练目标错了 = 训出来的模型在解错的题。
