# 长上下文RL

[[长上下文rl]] 指在极大上下文窗口（如 128K token）下进行的强化学习训练。这在需要处理大量历史信息或多轮复杂交互的任务（如 [[cuda-agent]] 编写内核）中至关重要，但也面临着训练不稳定和计算成本高昂的挑战。

## 主要挑战

-   **训练不稳定性**：随着上下文长度和交互轮数的增加，强化学习容易出现奖励波动、策略崩溃或梯度消失/爆炸。
-   **内存与计算压力**：处理长序列需要巨大的显存和计算资源。

## 解决方案

CUDA Agent 采用了分阶段训练策略来应对这些挑战：

1.  **单轮 PPO 热身**：
    -   在非交互式设置下，先让模型学习基础的代码生成能力。
    -   为后续的多轮交互打下稳定的基础。

2.  **模型初始化**：
    -   **Actor 初始化**：使用 [[拒绝微调]]（RFT），从大量采样轨迹中筛选出取得正向结果的样本进行训练，降低策略崩溃风险。
    -   **Critic 初始化**：通过价值预训练，使优势估计在训练早期就保持可靠。

3.  **环境约束**：
    -   设置防作弊机制和明确的里程碑奖励，确保奖励信号的清晰和稳定。

## 成果

通过上述方法，CUDA Agent 成功支撑了 128K token 的上下文窗口和单条轨迹最多 150 轮的交互，且在整个训练过程中奖励信号持续增长，未出现崩溃。
