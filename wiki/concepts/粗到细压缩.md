# 粗到细压缩

**粗到细压缩**（Coarse-to-fine Compression）是一种分阶段进行数据压缩的策略，旨在提高压缩效率和质量。该策略模仿了人类编辑处理长文稿的过程：“先谋篇布局，再精雕细琢”。

## 策略步骤

在 [[comi]] 框架中，粗到细压缩分为两个明确的阶段：

### 第一阶段：粗粒度组重分配
这一阶段关注全局结构。
1.  **切片**：将长文本切分为多个等长的片段。
2.  **评估**：计算每个片段的总体价值（例如基于 [[边际信息增益]] 的总分）。
3.  **预算分配**：根据片段价值动态调整压缩率。高价值片段（如包含核心论据的段落）被分配更多的保留额度，而低价值片段（如背景铺垫或重复陈述）则被大幅压缩或丢弃。

这一步确保了有限的压缩预算被精准投向“高价值信息区”，避免了“一刀切”导致的重点信息丢失。

### 第二阶段：细粒度 Token 融合
这一阶段关注局部细节。
1.  **加权**：在片段内部，不再进行简单的截断或平均池化，而是根据每个 Token 的价值（如 MIG 分数）进行加权。
2.  **融合**：将高权重的关键 Token 与低权重的冗余 Token 进行融合。关键信息在融合后的表示中占据主导地位，而冗余信息则被自然稀释。

这一步解决了传统压缩方法中常见的“信息稀释”问题，即关键细节在平均化处理中消失。

## 优势

- **结构感知**：先看全局再看细节，使得压缩过程符合文档的逻辑结构。
- **细节保留**：通过加权融合而非硬性截断，最大程度地保留了关键信息的语义完整性。
- **鲁棒性**：即使在极端压缩率（如 32 倍）下，也能通过动态调整预算来保住最核心的内容。
