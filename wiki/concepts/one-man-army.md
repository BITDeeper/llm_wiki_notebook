# 一人成军

[[一人成军]]（One-Man Army）是指在 AI 工具（如 [[claude-code]]、[[Cursor]]）的辅助下，单个开发者即可完成过去需要团队协作（如前端、后端、算法、运维）才能完成的复杂任务链路。

## 形成背景
随着 AI 编程能力的提升，特别是 [[vibe-coding]] 范式的兴起，技术壁垒被打破。开发者不再需要精通所有技术栈，只需具备清晰的需求描述能力和逻辑判断能力，即可指挥 AI 完成具体实现。

## 典型案例
1. **SBTI 复刻**：开发者 [[平凡]] 在一个周末内，利用 Claude Code 完成了 [[SBTI]] 的逆向、复刻、优化和部署，这在过去至少需要三人小组两周时间。
2. **Shopify CEO**：Tobi Lütke 使用 Claude Code 处理医疗影像数据并生成查看器，独立解决了跨平台软件兼容问题。
3. **独立开发 Mayz**：一人利用 AI 平台在几天内构建并运营了营收破万美元的情人节贺卡网站。

## 能力边界变化
- **过去**：瓶颈在于“想法到能跑的代码”之间的技术实现距离。
- **现在**：瓶颈转向“想法的质量”和“对 AI 输出的审美与逻辑判断”。

## 潜在问题
虽然效率极大提升，但也带来了原创性保护困难（如 SBTI 被快速解构）和产品同质化的风险。
