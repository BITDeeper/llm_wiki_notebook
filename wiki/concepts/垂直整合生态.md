# 垂直整合生态

指厂商试图将用户锁定在自家软硬件和服务闭环内的策略，涵盖从底层模型、中间件到应用终端的全链条控制。

## 战略意图
大模型厂商（如谷歌、Anthropic）不再满足于仅通过 API 出售算力，而是希望：
1. **把控数据**：捕获每一次用户交互数据以优化模型。
2. **锁定用户**：通过软硬件协同体验提高用户迁移成本。
3. **最大化收益**：将每一次运算转化为订阅收入，杜绝第三方“套利”。

## 行业表现
谷歌推出 [[antigravity]] 并封杀 [[openclaw]]，Anthropic 推出 Claude Code 并限制第三方调用，都是构建垂直整合生态的体现。这标志着 AI 行业从开放协作走向封闭割据。
