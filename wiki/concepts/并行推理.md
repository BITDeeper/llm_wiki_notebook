# 并行推理

[[并行推理]]（Parallel Reasoning）是指在 AI Agent 执行过程中，模型在等待外部工具（如搜索引擎、数据库查询）返回结果的延迟时间内，继续进行下一步思考或内容生成的能力。这种技术旨在解决传统 Agent 串行执行模式带来的效率瓶颈。

## 核心问题
在传统的 [[ReAct]] 框架中，Agent 的执行流程是线性的：`思考 -> 调用工具 -> (等待) -> 思考`。在等待工具返回期间，计算资源（GPU/CPU）和模型处于闲置状态，导致端到端延迟显著增加。

## 实现条件
实现真正的并行推理通常需要满足以下条件：
1.  **非因果生成机制**：模型必须能够不依赖于严格的从左到右生成顺序。[[扩散大语言模型]] 的 [[块内双向注意力]] 机制提供了这种可能性，使得模型可以在生成工具调用时，已经“预见”了后续的思考内容。
2.  **灵活的解码控制**：需要能够控制模型不同部分的生成顺序。例如 [[P-ReAct]] 策略通过置信度偏置，强制模型优先解码工具调用部分。

## 优势
-   **降低延迟**：显著减少了用户感知的响应时间（[[DLLM-Searcher]] 实现了约 15-22% 的加速）。
-   **提升吞吐**：在等待 I/O 的同时进行计算，提高了硬件资源的利用率。
-   **更接近人类行为**：符合人类“一边行动一边思考”的认知习惯。

## 技术挑战
-   **架构限制**：主流的自回归模型（如 GPT、Claude）由于因果注意力的限制，难以在不损失性能的前提下实现“先行动后思考”。
-   **训练难度**：需要特定的训练策略（如 [[Agentic SFT]]）来教会模型在并行模式下保持逻辑一致性。
