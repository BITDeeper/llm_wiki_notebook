# 记忆树（Memory Tree）

[[openhuman]] 的核心数据架构，将用户的多源数据按主题、时间线、关联对象做评分和层级摘要，折叠成树状知识结构。

## 技术实现

1. **数据清洗与压缩**：抓取的原始数据经清洗后，切成不超过 3000 个 Token 的 Markdown 片段
2. **多维度组织**：按主题、时间线、关联对象进行评分和层级摘要
3. **树状折叠**：最终折叠成一棵结构化的记忆树
4. **本地存储**：底层为 SQLite 数据库，同时同步生成兼容 [[obsidian]] 的 .md 文件

## 设计理念

记忆树是 [[卡帕西式知识库]] 理念的工程化实现——将 Karpathy 手工维护的结构化知识库变成自动生成的活数据结构。它使得 Agent 能够在本地拥有对用户工作生活的全面"记忆"，支撑 [[潜意识循环]] 中的自主决策。

## 与系统智能的关系

记忆树是 [[系统智能]] 中"可记忆"能力的具体实现案例，使 AI 从无状态的工具转变为拥有持久记忆的系统。
