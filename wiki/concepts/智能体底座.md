# 智能体底座

智能体底座（Agent Foundation Model）是指将大语言模型定位为支撑各类智能体框架运行的底层基础设施，而非单纯的对话工具或文本生成器。

## 核心特征

1. **系统级编程能力**：不仅生成代码片段，还能下沉到硬件层进行内核优化、系统配置等底层工程任务
2. **[[跨智能体框架泛化]]**：无需专门训练即可适配多种智能体框架（如 [[claude-code]]、[[openclaw]]、[[hermes-agent]]），类似操作系统提供统一标准接口
3. **超长程自主执行**：能够在无人工干预下连续数十小时完成复杂工程任务（参见[[超长程自主编程]]）
4. **工具调用与规划**：具备自主规划、工具调用与长程任务执行的闭环能力

## 行业背景

智能体底座概念呼应了 [[任务执行范式]] 的转变——AI 行业从单纯模型开发转向智能体工程化系统。[[qwen3.7-max|Qwen3.7-Max]] 是这一概念的代表性实践，阿里将其定位为 Agent 时代的"标准接口"，类比 PC 时代的 Windows 和移动时代的 Android。

## 路线分歧

当前行业存在两条路线：
- **产品驱动路线**：[[anthropic]] 和 [[openai]] 通过 Claude Code、Codex 等产品直接赢得用户
- **全栈基础设施路线**：阿里通过 [[ath-alibaba-token-hub|ATH]] 从技术到生态再到话语权全面布局
