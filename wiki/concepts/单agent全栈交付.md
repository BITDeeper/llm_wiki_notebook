# 单Agent全栈交付

指一个 AI 独立完成从数据研究、数学建模、前端架构到文案撰写的全流程产品交付模式。这是 [[任务执行范式]] 从"AI作为工具"向"AI作为独立交付者"演进的标志性跃迁。

## 四重角色

传统上需要一支多角色团队协作数周的产品，单 Agent 可独立扮演：

1. **数据研究员**：清洗数据、交叉引用多个权威来源、合成数据矩阵
2. **数学建模专家**：识别数据缺口、自主选择统计方法（如 [[蒙特卡洛模拟]]）、处理不确定性
3. **前端架构师**：设计现代审美的交互结构、解决数据可视化渲染和动态响应问题
4. **文案与情绪导演**：构建叙事节奏、调动人类情感共鸣

## 标志性案例

[[the-veil-of-history]] 是目前最典型的单 Agent 全栈交付案例。[[ethan-mollick]] 仅用一条自然语言 Prompt，[[opus-4-8]] 独立完成了整个网站的从零到上线。

## 与相关概念的关系

- 区别于 [[agentic-engineering]]：Agentic Engineering 强调 AI 深度参与研发上游工作，单 Agent 全栈交付更强调 AI 独立完成面向终端用户的产品级交付
- 是 [[任务执行范式]] 的极致体现：AI 从"辅助工具"进化为"独立交付者"
- 与 [[1-n-agent调度]] 形成互补：前者是多 Agent 并行调度，本概念强调单 Agent 的全能性
