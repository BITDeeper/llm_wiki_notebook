# ScaleRL 最佳实践方案

ScaleRL 是文献 [1]（Khatri 等，2025）提出的大规模 RL 训练最佳实践整合方案，在超过 40 万 GPU 小时的实验中验证，成功 Scaling 至 10 万 GPU 小时的单次 RL 训练运行。

## 方案组成

ScaleRL 整合了以下经实验验证的组件：

### 损失函数
- 采用 [[cispo]] 损失（在渐近性能和算力效率上均优于基准 GRPO 和 [[gspo]]）
- [[dapo]] 风格的损失聚合（直接对批次中所有 token 取平均）

### 工程优化
- **全精度 LM 头**：在训练和推理引擎中均使用 float32 语言模型头，显著改善渐近性能和算力效率
- **PipelineRL 异步训练**：相比异步 PPO，最小化 GPU 空闲时间，算力效率显著更高
- **异步程度限制**：策略更新不超过 K=8 步先于生成的轨迹

### 数据策略
- **零方差过滤**：从批次中过滤掉组内奖励方差为零的提示（与 DAPO 动态采样不同，不重新填充批次）
- **不正样本重采样**：将通过率超过 90% 的提示永久移除，避免在已解决的提示上浪费算力
- **批次奖励标准差**归一化优势

### 推理控制
- 上下文长度 16K token（12K 推理 + 2K 输入 + 2K 输出）
- 推理强制中断机制：达到 12K token 时注入终止短语

## 验证方法

通过在规模逐渐扩大的多个阶段（4K → 8K → 16K → 100K GPU 小时）拟合 sigmoid Scaling 曲线，外推结果准确预测了实际性能。逐一消融分析确认了各组件的协同效果。

## 核心发现

- 小规模实验中表现更优的方法未必能推广到大算力场景
- 许多常见 RL 干预措施更多影响算力效率 B 而非渐近性能 A
- 更长上下文窗口初期拖慢训练但长期获得更高渐近性能
- 增大批次规模能改善渐近性能并防止停滞
