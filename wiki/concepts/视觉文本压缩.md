# 视觉文本压缩

**视觉文本压缩**（Vision-Text Compression, VTC）是一种旨在降低大模型处理长文本成本的新型技术范式。其核心思路是将长文本渲染为高密度图像，再交给多模态大模型通过视觉通道（OCR）处理。

## 工作原理

VTC 改变了传统 LLM 逐字读取文本 Token 的方式，转而采用“图像化”的处理流程：

1.  **渲染**：将长文档（如 PDF、网页）渲染为一张高密度的 2D 图像。
2.  **编码**：利用视觉编码器将图像转化为少量的视觉 Token 输入给模型。

## 核心优势

- **极高的压缩率**：相比纯文本 Token，VTC 可实现 **2 倍至 10 倍** 的压缩率，用更少的视觉 Token 承载更多的上下文信息。
- **成本与效率**：大幅减少了长文本处理所需的计算资源和显存占用，使得在消费级硬件或有限 API 配额下处理超长文档成为可能。

## 认知挑战与安全风险

虽然 VTC 解决了“看得见”和“存得下”的问题，但在“看得懂”层面仍面临多重挑战：

### 理解力缺陷

[[VTCBench]] 的测试指出，VTC 在认知层面存在明显瓶颈：
- **[[空间注意力偏见]]**：模型在处理长图像时，容易丢失中间部分的信息，呈现 U 型理解曲线。
- **推理能力差距**：目前基于 VTC 的 VLM 在复杂推理任务上普遍弱于纯文本 LLM。

### 安全隐患

[[西湖大学-agi-lab]] 的研究表明，VTC 路线还引发了新的安全问题：当文本被压缩进图像并伴随视觉退化时，模型极易进入[[攻击舒适区]]（ACZ）。这提醒行业：提升压缩率和降低 Token 成本虽然有价值，但如果压缩后的图像让模型识别费力，效率收益就会伴随额外的安全成本。

## 行业地位

VTC 被视为长文本处理的一种极具潜力的“摄影式记忆”路径。[[DeepSeek-OCR]]、Glyph 等工作是该技术的代表案例，而 [[Gemini-3-Pro]] 的优异表现则证明了通过架构优化克服上述认知瓶颈的可行性。
