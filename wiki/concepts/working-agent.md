# Working Agent

区别于Coding Agent，指在日常工作场景中辅助员工执行任务的智能化Agent。被视为继Coding Agent成熟之后的下一个爆发方向。

## 核心矛盾

员工希望Agent什么事都帮自己做、了解自己的日常；企业则希望员工安全地使用Agent、有管控、不能让Agent什么事都做。Working Agent需要同时满足两者。

## 关键能力

- **深度个性化**：了解用户日常工作习惯和信息
- **主动行动**：不只是被动响应，而是主动提醒和建议
- **跨系统集成**：打通CRM、邮件、聊天工具等多个工作平台
- **个人知识图谱**：随使用不断沉淀，决策越来越像用户本人

## 产业判断

亚马逊云科技CEO Matt Garman认为，过去30年个人生产力从未被真正大规模颠覆，直到Working Agent出现。这一判断与 [[任务执行范式]] 和 [[系统智能]] 的发展方向一致。
