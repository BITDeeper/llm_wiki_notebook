# 少招人多发Token

## 核心建议
[[boris-chemy|Boris Cherny]] 给所有创业者的反直觉建议：每个项目故意少放人、多给 Token，迫使团队自动化，产生复利效应。

## 具体策略

### 两条原则
1. **尽量多给 Token**：让大家疯狂实验
2. **故意少放人**：如果觉得一个项目需要四个工程师，就只放两个人，然后给他们大量 Token

### 复利效应
因为人少，团队会把能自动化的东西全部自动化。自动化之后，下次再做会更快、更便宜。这是一个复利效应——就像 pre-compiling 一样，一次性把脏活累活做完，后面每一次重复执行都几乎免费。

### 成本结构转变
用更少的人，把预算从人的工资转移到 Token 上。这会抬高前期成本（upfront cost），但会大幅降低持续成本（ongoing cost）。

## 与其他概念的关系

### 与 [[tokenmaxxing]] 的对照
- Tokenmaxxing 是行业现象：将 Token 消耗量视为生产力和竞争力的衡量标准
- "少招人多发Token"是组织策略：主动将人力资源预算转化为 Token 预算
- 两者方向一致但视角不同：前者是描述性的，后者是规范性的

### 与 [[ai-subscription-crisis]] 的张力
AI 订阅制因 Agent 任务高消耗而失效，但 Boris 的建议恰恰是大幅增加 Token 消耗。这暗示未来的成本结构可能从"人头费"全面转向"Token费"，订阅制危机的本质是定价模式尚未适应这一转变。

### 与 [[1-n-agent调度]] 的呼应
少人多样本策略天然需要 1:N 调度能力——少量人类管理大量 Agent 实例。

## 适用性边界
- Boris 的建议基于 [[anthropic|Anthropic]] 这种前沿 AI 公司的实践
- Anthropic 员工本身就是全球顶尖人才，"少招人"的前提是招到的人足够强
- 对普通企业的适用性需要谨慎评估
