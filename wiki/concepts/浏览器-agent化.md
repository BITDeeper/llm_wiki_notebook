# 浏览器 Agent 化

**浏览器 Agent 化**是指网页浏览器从单纯的“信息展示工具”向“任务执行助手”转型的技术趋势。在这一范式下，浏览器不再仅仅呈现网页内容，而是通过内置的 AI 模型理解用户意图，自动执行跨页面的复杂任务。

## 核心特征

### 从“看”到“做”
传统浏览器的核心是导航和渲染，而 Agent 化的浏览器具备感知、决策和行动能力。例如，用户不再需要手动对比两个网页的参数，而是告诉浏览器“对比这两个产品”，浏览器自动读取内容并生成结果。

### 技能复用
为了降低使用门槛，Agent 化浏览器普遍引入了“技能”或“卡片”概念。用户将特定的 Prompt（如“总结视频要点”）保存为技能，未来可通过斜杠指令一键复用。这标志着交互模式从“对话式”转向了“指令式”。

### 多标签页上下文
这是浏览器 Agent 的杀手级能力。不同于局限于单次对话的 Chatbot，浏览器 Agent 能够同时读取和管理多个标签页的状态，从而执行涉及多个信息源的综合任务。

## 行业动态

### 主流厂商布局
- **Google Chrome**：推出 [[chrome-skills]]，内置 Gemini 模型，支持技能保存和多标签页读取。
- **Opera**：在 Neon 版中推出 **Cards** 功能，允许用户保存和复用 Prompt。
- **Microsoft Edge**：深度集成 Copilot，甚至被指推出的独立 Copilot App 本质上是 Edge 浏览器的套壳。

### AI 原生挑战者
除了传统浏览器厂商，新兴的 AI 原生浏览器也在抢占市场，包括 **Perplexity (Comet)**、**ChatGPT Atlas** 以及美团（光年之外）推出的 **Tabbit**。

## 历史类比
业界普遍将当前的浏览器 Agent 化比作 **90 年代的浏览器大战**。上一次竞争决定了谁掌握互联网的入口，而这一次竞争将决定人类与互联网交互的根本方式——从点击链接转向指令代理。

## 挑战与矛盾
- **隐私与安全**：Agent 需要读取网页内容甚至执行操作（如发邮件），这对隐私保护和权限管理提出了极高要求。
- **技术门槛转移**：虽然使用门槛降低，但编写高质量 Prompt（技能）仍需一定的逻辑思维和工程能力。
