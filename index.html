Wiki Index §

实体 §

  • 得物技术 — 得物 App 的技术研发部门，积极探索 AI 工程化落地。
  • qwen — 阿里云推出的大语言模型，涵盖文本与视觉（VL）版本，支持长上下文与 MoE 架构。
  • qwen3guard — Qwen 团队推出的多语言安全护栏模型，侧重于利用安全强化学习（RL）优化策略，平衡安全性与可用性。
  • yufeng-xguard — 阿里巴巴团队推出的推理为中心的安全护栏模型，侧重于利用合成数据与知识蒸馏实现高效推理与动态策略。
  • unsloth-studio — 提供本地 LLM 推理服务及 OpenAI/Anthropic 兼容 API 的工具，也是高效的微调框架。
  • gguf — 一种优化的模型文件格式，支持高效量化推理。
  • transformers — Hugging Face 的主流模型库与格式标准。
  • mcp2cli — 将 MCP 协议工具转换为 CLI 命令的转换工具，用于降低 Token 消耗。
  • s-eval — 用于安全护栏模型的数据集分类法或评估基准，是 YuFeng-XGuard 数据构建的核心骨架。

概念 §

  • 越权漏洞 — 分为越权读取（关注数据敏感性）和越权操作（关注利益流向）。
  • token优化策略 — 包括 MCP→CLI 转换、精准代码提取和 Early-Exit 模式。
  • 通用-agent与业务-skill分离 — 将通用模型能力与具体业务逻辑解耦的架构设计模式。
  • openai兼容api — 遵循 OpenAI 接口规范的 API 设计，便于生态集成。
  • anthropic格式兼容 — 遵循 Anthropic 接口规范的 API 设计。
  • 视觉微调 — 针对 VLM 模型进行特定领域数据训练的技术，支持选择性微调视觉或语言层。
  • grpo与gspo — 用于提升模型推理能力的强化学习算法，无需价值网络且显存高效。
  • mcp协议 — AI Agent 与工具交互的标准化协议，上下文开销较大。
  • cli封装模式 — 将协议交互封装为命令行接口的优化模式，显著降低 Token 消耗。
  • 三档严重性分类 — 将内容安全分为“安全”、“有争议”和“不安全”三类，以适应不同策略。
  • 流式安全监测 — 在 LLM 生成过程中逐 Token 进行实时安全评估的技术。
  • 安全强化学习 — 利用 Guard 模型作为奖励信号，通过 RL 训练提升模型安全性与可用性。
  • 动态策略 — 在推理时通过指令动态添加新风险类别或调整标准，无需重新训练模型。
  • 思维链审核 — 专门针对推理模型内部生成的“思考内容”进行安全审核的技术。
  • 分层推理 — 首个 Token 做即时决策，按需生成详细解释的推理机制。
  • 推理为中心 — 不仅输出判定，还生成自然语言解释的安全模型设计范式。
  • 合成数据 — 利用强模型自动生成的响应或样本，用于扩充训练集、增强模型特定能力或提升数据多样性。
  • 知识蒸馏 — 将大型模型的知识迁移到小型模型中的技术，YuFeng-XGuard 利用前向与反向 KL 散度实现 8B 到 0.6B 的压缩。
