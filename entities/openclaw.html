OpenClaw

开源 AI 智能体网关框架，全球最大的 Agent 开源项目，由”龙虾之父”Peter Steinberger 主导开发。社区用户自称”龙虾党”。2025年底发布后迅速跻身 GitHub 历史上增星速度最快的项目之一。定位正在从”多渠道消息网关”向”AI 桌面操作系统”演进。它不仅是 AI 编程工具，更催生了 OpenClaw Research 这一全新研究领域。

核心定位

OpenClaw 打破了传统智能体研究的四个”沙盒假设”，使智能体能够：

  • 自主演化策略（而非仅由开发者更新）
  • 从不受信任的社区获取工具（而非仅使用预定义工具）
  • 与数百万其他智能体共存互动（而非独立运行）
  • 在持久运行时基础设施上长期运行（而非执行短暂任务）

核心功能

  • 多渠道消息接入：支持从 Telegram、Slack、iMessage、WhatsApp 等 50+ 消息平台入口发起任务
  • Agent 调度：处理消息路由、Agent 分配、结果返回
  • 本地运行：支持在用户本机环境部署运行
  • 桌面操作（通过 peekaboo）：截图、UI 元素识别、窗口操作、点击输入等
  • 跨平台节点网络：macOS 与 Windows 设备均可作为一等公民加入分布式节点网络

生态规模

指标数据
支持消息平台50+
社区贡献技能模块（clawhub）5700+（截至2026年6月已积累超1.3万个技能）
注册智能体（moltbook）280万
OpenClaw 平台智能体16.7万

架构：智能体操作系统

OpenClaw 的架构突破是从”提示词链条”升级为智能体操作系统，包含四层：

  1. 智能体内核：持续解析意图，协调并发任务
  2. 技能模块：通过 ClawHub 分发的轻量化能力单元
  3. 模型上下文协议-mcp：类比 POSIX 系统调用的标准化双向 API
  4. 分层记忆：从会话上下文到长期语义检索的四级体系

从功能视角，架构可分为两个层次：

  • 连接层：消息入口、网关、Agent 调度——解决”谁来找我、要做什么、交给谁”
  • 执行层（Peekaboo）：屏幕理解、UI 操作、流程执行——解决”屏幕上有什么、按钮在哪里、怎么操作”

两个层次合一后，OpenClaw 从”会聊天”进化为”会干活”，有机会成为 AI 操作个人电脑和个人工作流的本地控制层。

6.1 里程碑更新（2026-06-04）

包含三大核心更新：

  1. Windows 原生节点接入：Windows 设备作为”一等公民”加入分布式节点网络，无需 Docker/WSL 中间层，覆盖16亿台设备存量市场
  2. 技能工坊：Agent 可自主发现能力缺口、发起技能提议、经人类审批后自动生成技能，实现 7×24h 自我迭代
  3. 工作板：多智能体协调看板，支持任务拆解、分发、追踪、汇总

其他更新包括 MiniMax M3 接入、GitHub Copilot Claude 1M 长上下文打通、底层 SQLite 替代文件系统扫描、178个 commit 砸进主线。

  • codexbar — macOS 菜单栏工具，追踪 AI 编程工具使用量和成本
  • agent-view — 多会话调度界面，支持同时管理多个并行 AI 会话
