TRAE SOLO

trae-solo 是由 trae 推出的 AI 原生 IDE 与智能体工作台，提供 PC 端、Web 端和移动端。它不仅具备代码编写能力，还通过 mtc模式（More Than Coding）扩展到了产品、运营、数据分析等非研发领域，旨在实现从 AI Coding 到 ai-development 的转型。同时，它集成了高级语音交互功能，主打“Voice Working”（语音办公）理念，试图通过语音作为主要交互入口，替代传统的键盘打字操作。

核心特性

三端打通

trae-solo 最大的特点是实现了移动端、桌面端和网页端的彻底打通（三端打通）。三端共享同一个 Agent、同一套文件系统和同一段对话上下文。这意味着用户可以在不同设备间无缝切换工作流，设备变了，但心流不会断。

全量功能共享

移动端版本并非桌面端的“缩水版”，而是全量功能共享，支持完整的工作流跟随：

  • MTC (思维链)：支持复杂的项目规划和提示词设计。
  • Code：支持代码编写、执行与调试。
  • 文件操作：完整的文件系统管理能力。

核心功能与模式

1. MTC 模式

  • 目标用户：产品经理、运营、数据分析师等非研发角色。
  • 主要能力：
    • 文档理解与生成：读取多格式文件（Word, Excel, PDF, 图片），生成 PRD、策划案、复盘报告等。
    • 数据清洗与可视化：自动编写脚本（如 Python Pandas）处理脏数据，生成图表和分析报告。
    • 演示文稿制作：根据文档内容自动生成 PPT，包括配图和排版。

2. Code 模式

  • 目标用户：专业研发人员。
  • 主要能力：
    • 应用开发：根据 PRD 直接生成可执行应用、架构设计和 API 定义。
    • 多任务并行：支持本地与云端项目并行处理。
    • 代码重构：在语音指令中包含技术细节（如 async await、aiohttp、参数化查询）和逻辑修正，模型能准确生成代码。

3. 智能语音交互

不同于传统的“听写式”语音转文字工具，trae-solo 强调对语音输入的深度理解与清洗：

  • 口语清洗：自动过滤语气词、重复、自我修正和无效断句，将非结构化的口语转化为结构清晰的可执行文本。
  • 语义理解与自动修正：能够识别用户的“改口”行为（例如先说“拆成三个”，后说“不对，拆成四个”），并智能保留最终结论，忽略被推翻的中间状态。
  • 功能语音直调：用户可以通过模糊的语音指令直接操作软件内部功能，无需手动点击菜单。例如：“用 Plan 模式帮我规划一下”、“调用那个批量处理的 Skill”、“切换模型”。

4. 移动端工作流

trae-solo 强调“工作流跟随人”，支持以下移动端场景（vibe-working）：

  • 语音交互：通过语音与 AI 进行实时讨论，AI 可主导节奏并生成纪要。
  • 企业集成：通过 飞书-cli-接入 直接处理企业文档。
  • 定时任务：设定自动化任务进行信息收集与汇报。

产品形态

  • 独立端：脱离了传统 IDE 架构，提供轻量级客户端，主打“随用随走”和降低学习曲线。
  • 本地文件管理：允许用户直接上传文件夹，自动识别并处理其中的多模态文件。

硬件生态

为了解决公共场合或移动办公中的拾音问题，trae-solo 与 insta360 推出了联名套装，搭配 insta360-mic-air 无线麦克风使用。该硬件具备 48kHz 采样率和全向拾音能力，配合一键 AI 降噪，旨在保障语音输入的质量。

实测案例

  • 产品经理：7分钟内完成300条用户反馈聚类、历史数据分析及 PRD 输出。
  • 运营：生成包含预算和排期的活动策划案及 18 页 PPT，并自动完成数据复盘。
  • 数据分析师：自动处理多源异构数据（清洗、合并），生成可视化分析报告。
  • 研发：基于 PRD 文档直接生成应用代码及架构设计；通过语音调用脚本（如 FFmpeg）进行批量视频处理、重命名或压缩。

行业定位与对比

行业定位

trae-solo 试图打破 AI 工具的岗位壁垒，将服务对象从程序员扩展到整个互联网产研链条。它被视为在 AI Coding 领域率先将“语音交互”做到产品级应用的玩家。其背后的逻辑是，随着 AI 承担了更多的执行工作，人类回归到“决策者”角色，而语音是决策者最高效的输出方式。

竞品对比

  • 对比 openclaw：OpenClaw 仅能通过 IM 远程控制桌面端的 claude-code，缺乏实时查看和精细控制能力；trae-solo 则提供了原生的移动端体验和完整的功能支持。
  • 对比 cursor / github-copilot：竞品主要深耕桌面 IDE 生态，而 trae-solo 率先实现了跨设备（特别是移动端）的智能体工作流协同。

发展历程

  • 2026年3月：上线独立端，推出 MTC 模式。
  • 2026年4月：正式上线语音输入功能，并推出与 Insta360 的联名硬件套装。
  • 2026年4月底：上线“实时问答互动”功能，支持双向语音对话。
  • 2026年5月：上线移动端，实现三端打通。
