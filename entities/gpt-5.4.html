GPT-5.4

GPT-5.4 是 OpenAI 于 2026 年 3 月正式发布的新一代旗舰大语言模型。作为首个具备原生电脑使用能力的通用模型，它实现了推理与编程能力的完全合流。该模型被定义为”原生大一统模型”，在同一架构中原生集成了推理、编程、计算机原生交互、深度网页搜索及百万级上下文窗口。

GPT-5.4 包含 Thinking、Pro 和 Fast 版本，以显著的推理速度提升、突破性的视觉/UI 理解能力、原生的 computer use（计算机使用）能力以及卓越的数学证明生成能力著称。在社区中，它被视为在 UI 编码领域超越 Claude Opus 4.7 的里程碑产品，同时在科学推理和金融分析领域达到了学术发表及行业应用标准。

作为 GPT-6 发布前的主力旗舰，GPT-5.4 也常被用作性能对比的基准。据后续报道，GPT-6 在代码、推理和智能体任务上比 GPT-5.4 强 40%，且上下文窗口进一步扩大（GPT-5.4 为 100 万 Token，GPT-6 据称达到 200 万）。

发布背景与泄露事件

GPT-5.4 的发布节奏反映了 OpenAI 与谷歌之间激烈的竞争。在 GPT-5.3 Instant 发布的同时，OpenAI 曾透露 GPT-5.4 的到来将比用户预想的更快。这一预告是在谷歌发布 Gemini 3.1 Flash-Lite 后不到 2 小时内做出的，最终该模型于 2026 年 3 月正式上线。

值得注意的是，在正式发布前，GPT-5.4 的存在曾通过一次代码意外泄露事件被公之于众。该模型名称首次出现在 Codex 助手的 GitHub 代码提交记录中，涉及一个名为 view_image_original_resolution 的功能开关。代码中明确提到了”当目标模型为 gpt-5.4 或更新版本时”的条件判断。此外，Codex 的模型下拉菜单也曾短暂显示过 GPT-5.4。随后，相关代码被迅速修改为 gpt-5.3-codex。鉴于 Sam Altman 的风格，部分观点认为这可能是一次故意泄露的营销行为，旨在转移公众对 DeepSeek V4 的注意力。

技术定位与架构

GPT-5.4 的设计初衷不仅是提升对话能力，更是为了充当能够操作计算机系统的智能体，支持长时运行（数天甚至数周）的复杂任务。为了充分发挥其潜力，OpenAI 配套重构了 agents-sdk，提供了 harness-compute-分离架构 作为运行底座。

OpenAI 将 GPT-5.4 定位为从”聊天机器人”向”生产力实体”转变的关键节点。其强调的”UI 交互取代 API 对接”趋势，以及”边造边测”的类人工程师工作流，直接回应了 Anthropic 在 Claude Code 和 Computer Use 领域的挑战。

核心特性

大一统架构

GPT-5.4 在单一模型架构中整合了多种高阶能力，且未出现明显的性能权衡：

  • 推理与编程：实现了两者的完全合流。
  • 计算机原生交互：无需外部 API 封装即可操作桌面环境。
  • 深度网页搜索：内置强大的联网检索能力。
  • 百万级上下文：支持约 100 万 token 的上下文（甚至有传闻称达到 200万），意味着可以一次性容纳整个代码库或长篇文档，无需复杂的分块或检索策略。

原生电脑操控与计算机使用能力

GPT-5.4 是 OpenAI 首个在通用模型中内置”原生电脑操控”能力的模型，能够像人类一样操作桌面软件（使用鼠标和键盘），无需依赖外部 API 封装或适配层。它通过识别 UI、编写代码（如 Playwright）或模拟键鼠来完成任务。

  • 基准测试表现：在 OSWorld-Verified 桌面导航测试中得分达到 75.0%，首次超越了人类平均水平（72.4%）和竞争对手 Claude Opus 4.6（72.7%）。
  • 操作案例：
    • 能够通过截图理解软件界面，执行鼠标点击和键盘输入。例如，它曾在 Microsoft Paint 中通过自我修正（搜索参考图并导入）来绘制 OpenAI 标志。
  • 生产环境案例：
    • Ramp：超过 50% 的代码 PR 由 Agent 生成。
    • Stripe：每周产出 1000+ 个 PR。
    • FurtherAI：成功处理 900 页保险理赔记录。
  • 门户网站评测：在针对约 3 万个 HOA 和房产税门户网站的评测中（数据来源：Mainstay CEO Dod Fraser）：
    • 首次尝试成功率：95%。
    • 三次尝试内成功率：100%。
    • 速度提升：相比之前的 CUA 模型提升约 3 倍。
  • 与 OpenClaw 的结合：GPT-5.4 被认为是 openclaw 的”天选模型”。其原生操控能力与 OpenClaw 的核心理念完美匹配，使得该框架不再需要复杂的适配层即可实现强大的桌面自动化。社区反馈显示，配合 GPT-5.4 的 OpenClaw 在执行复杂任务时的可靠性大幅提升。

视觉与 UI 理解

GPT-5.4 是 OpenAI 首个专门针对 UI 能力和图像理解进行训练优化的主线模型。

  • UI 克隆：具备极高精度的截图复刻能力。在测试中，为了达成”100%一致”的指令，模型展现出”类人”的策略性——直接从参考图像中裁剪 UI 元素并注入代码，而非重新编写图形资源代码。
  • 原生高精视觉：根据泄露代码显示，GPT-5.4 支持 原始分辨率视觉分析，能够绕过图像压缩直接处理原始字节数据，以消除视觉 模型幻觉，适用于复杂工程图和 UI 原型分析。
  • 前端生成：能够生成具有美感的前端界面，在 SVG 和 3D 生成上表现出更高的结构清晰度和视觉准确性。
  • 开发者指南：OpenAI 专门发布了《Designing Delightful Frontends with GPT-5.4》以展示其前端设计能力。

金融领域表现

GPT-5.4 在金融分析领域展现了突破性的能力，被视为直接切入华尔街核心业务的关键产品。

  • 基准测试：
    • 在 OpenAI 内部的投行基准测试（APEX-Agents）中，GPT-5.4 Thinking 的得分从初代 GPT-5 的 43.7% 飙升至 87.3%，实现翻倍。MercerAI CEO 称其为超越麦肯锡水平的模型。
    • 在 GDPval 评估中，横跨 44 个职业的对比显示，它在 83% 的情况下追平甚至超过了行业从业者。
  • 生态整合：OpenAI 同步推出了 ChatGPT for Excel 插件，允许 GPT-5.4 直接在电子表格中工作。此外，FactSet、Third Bridge、穆迪、道琼斯 Factiva、MSCI 等主流金融数据平台均已接入 ChatGPT 生态。

数学证明与科学推理

GPT-5.4 Pro 在解决复杂科学难题中展现了突破性的能力，特别是在攻克 高德纳 提出的 哈密顿分解 难题中扮演了关键角色：

  • 偶数情形解法：针对 m≥8 的偶数情形，GPT-5.4 Pro 不仅生成了有效的算法，还给出了严格的数学证明。
  • 大规模验证：验证了高达 m=2000（80 亿顶点）的图结构，证明了算法的鲁棒性。
  • 0 修改论文：独立生成了一篇长达 14 页、排版精美（使用 TeX）且逻辑严密的学术论文。该论文通过了 Lean 形式化验证，作者表示”连一个标点符号都不需要修改”。
  • 跨模型协作：GPT-5.4 与 Claude 4.6 Sonnet 进行了跨模型协作。研究者通过在两个模型间来回粘贴文本，利用它们不同的思维维度相互启发，最终拼凑出了完整的数学证明。

基础能力与效率

  • 1M 上下文窗口：支持约 100 万 token 的上下文（甚至有传闻称达到 200万），意味着可以一次性容纳整个代码库或长篇文档，无需复杂的分块或检索策略。这对于运行长程任务的 openclaw 等 Agent 至关重要，解决了以往模型在处理复杂指令链时容易遗忘上下文的问题。
  • 永久记忆（传闻）：业界猜测 GPT-5.4 可能具备跨会话的长期记忆能力，即”永久记忆”。这可能是通过结合 状态空间模型 (SSM) 和 Transformer 架构实现的，SSM 的线性计算复杂度使其更适合处理超长上下文和持久状态传递。
  • 静默加速：通过底层推理基础设施优化，GPT-5.4 实现了显著的延迟降低。用户反馈速度提升可达 4 倍。
  • Token 效率：
    • 在计算机使用任务中，Token 使用量相比前代模型减少约 70%，大幅降低了部署成本。
    • 引入了 Tool Search（工具搜索）优化机制，允许模型按需检索工具定义而非全部加载进上下文。据实测，这能进一步降低 Token 消耗（约 47%），直接缓解了 Agent 运行成本高昂的问题。
  • 架构优化：OpenAI 强调其能用更少的 Token 解决相同问题，这意味着首字延迟更低且生成成本下降。

SWE Atlas 详细表现

在 SWE Atlas 评测中，GPT-5.4 的表现进一步揭示了其工程能力的特征：

  • Pass³：29.2%（三次全部通过的比例，相对 Pass@1 下滑约 33%），表明在一致性方面仍有提升空间。
  • 主要失败模式：信息不完整（Missing Info），即做了实验但没覆盖完所有 rubric 子问题。
  • 代码理解行为：在 Codebase Q&A 任务中，GPT-5.4 展现出较高的代码执行频率，倾向于通过运行代码而非静态阅读来理解代码库，模拟了资深工程师的运行时分析行为。

编程与工程实测

  • 编译器构建：AI 圈大佬 Eric Hartford 测试发现，GPT-5.4 能够成功从零构建一个编译器，而 claude-code 在此任务中卡住，GPT-5.3 则表现吃力。
  • 逆向工程：有用户发现 GPT-5.4 能够对 NES（任天堂红白机）的 ROM 进行逆向工程，拆解程序结构并还原逻辑。
  • 数据分析：能够在 4 分钟内爬取 Zillow 房价数据并导入 Google 表格进行分析。
  • 极限代码生成：据测试者反馈，单次提示可生成超过 6000 行代码，且推理速度明显加快。

版本与定价

  • GPT-5.4 Thinking：面向 ChatGPT 端用户，支持 中途介入 功能，允许用户在模型推理过程中实时调整方向，提升协作效率。
  • GPT-5.4 Pro：面向高级用户和开发者，性能最强，但定价极高（输入 30，输出180/百万 token），反映了 ai-subscription-crisis 中 Agent 任务的高昂成本。
  • GPT-5.4 Fast：面向 API 开发者，提供更快的推理速度。泄露的 GitHub PR 显示，该版本可能配备”快速模式”开关，暗示其架构支持不同的计算/延迟权衡（如多级 Pipeline）。
  • Codex 集成：同步上线 Codex，支持 1.5倍速的 /fast 模式和 Playwright (Interactive) 视觉化调试。

商业表现与成本效率

GPT-5.4 在上线一周内创造了 10 亿美元 ARR 的商业记录，日均处理约 5 万亿 token，超过 OpenAI 一年前整个 API 的总量。

虽然 GPT-5.4 的单 token 价格较高（输入 2.5/百万，输出15/百万），且单次交互消耗巨大（如测试中一句”Hi”消耗 80 美元），但其单位智能成本显著下降。

  • 在 ARC-AGI-1 测试中，达到 90% 准确率的成本仅为 0.37 美元，相比 3 个月前的模型（11.64 美元）提升了 32 倍。
  • 这表明虽然单价上涨，但 AI 推理效率 的提升使得完成复杂任务的总成本大幅降低。
