GPT-5.4

GPT-5.4 是 OpenAI 在 2026 年发布的前沿大语言模型系列，包含 mini 和 nano 等不同规格的版本。该模型被官方定义为“Agent 的母体”及“最适合专业工作”的模型，旨在作为驱动智能体工作流和生产力工具的核心引擎。

💡 发布背景：在正式发布前，GPT-5.4 曾因代码泄露（GitHub 误提交 gpt-5.4 标识）和 alpha-gpt-5.4 端点截图流出而引发网络热议，传闻其具备 200 万上下文窗口和状态化能力。

评测表现

GPT-5.4 在多项基准测试中展现了强大的性能，特别是在代码生成和智能体任务中表现突出。

Claw-Eval-Live 评测

在 claw-eval-live 的动态评测中，GPT-5.4 综合排名第二，仅次于 claude-opus-4-6。

  • 通过率：与 Claude Opus 4.6 的差距仅为 2.9 个百分点。
  • 成本效益：估算 API 成本约为 $6.3，远低于 Claude Opus 4.6，被认为具有较高的性价比。

ProgramBench 代码评测

在 ProgramBench 测试中，GPT-5.4 展现了独特的“极简主义”开发风格。

  • 平均通过率：38.3%，位列第二。
  • 开发模式：平均仅使用 16 次 API 调用，成本仅 0.33 美元。
  • 生成特点：100% 的代码在一次编辑中生成，之后几乎不回头修改（39.5% 的轨迹在创建文件后零修改）。
  • 代码质量争议：生成的代码结构最差，平均每个任务只创建 5 个文件，函数数量仅为人类代码的 10%，是典型的“单文件怪兽”生成者。

版本变体

GPT-5.4 系列包含针对不同应用场景优化的多个版本，主打快速响应和经济性，特别针对编程、计算机操作及 子代理（Subagent）任务进行了优化。

GPT-5.4 mini

  • 定位：兼顾性能与速度的轻量级版本。
  • 优化方向：编程、推理、多模态理解和工具使用。
  • 性能表现：在 SWE-Bench Pro 和 OSWorld-Verified 等评测中表现接近满血版 GPT-5.4。
  • 价格：每百万输入 tokens 0.75，每百万输出tokens4.5。
  • 争议：相比旧版 GPT-5 mini，价格实际上涨了约三倍，且在 Vals 排行榜上排名不如 Kimi 2.5。

GPT-5.4 nano

  • 定位：系列中最小、最经济的版本。
  • 适用场景：分类、数据提取、排序及简单的辅助编程任务。
  • 价格：每百万输入 tokens 0.2，每百万输出tokens1.25。
  • 实测表现：在分类任务中准确率达 70%，成本比满血版降低约 92%。

核心特性

智能体与工作流

  • Agent 母体：专为驱动智能体工作流而设计，显著提升了 Agent 的使用率和效能，在复杂任务处理和多步骤推理上有显著提升。
  • 状态化能力：引入 状态化-ai（Stateful AI），具备跨会话持久记忆能力，能够保留用户的开发环境、工作流及工具调用状态，改变了传统的无状态对话模式。
  • 专业导向：主打专业工作、编码、计算机使用和工具检索。
  • 技术平衡：在推理能力、响应速度或成本效益上达到了较好的平衡。

上下文与视觉

  • 超长上下文：支持最长 100 万 token 的上下文窗口（传闻版本曾提及高达 200万上下文窗口 的潜力）。
  • 全分辨率视觉：支持 全分辨率视觉直读，能够绕过传统的图像压缩机制，直接读取原始像素数据，提升处理精细图表和 UI 设计图时的准确性。

应用与生态

OpenClaw 集成

GPT-5.4 已被深度集成至 OpenClaw 生态系统中，作为其后端模型支持长上下文任务：

  • 版本演进：
    • 在 v2026.3.7 更新中，GPT-5.4 被列为新接入的官方支持模型之一。
    • 在 v2026.3.22-beta.1 更新中，GPT-5.4 被确立为默认的 OpenAI 模型。
  • 功能支持：
    • 配合 OpenClaw 新增的 可插拔上下文引擎，能够处理长上下文任务而无需担心信息丢失。
    • 通过共享模块集中管理聊天、图像、语音和嵌入的默认值，使得未来的模型升级可以“无感”进行，无需用户手动干预。
  • 兼容性：系统增加了对 gpt-5.4-mini 和 gpt-5.4-nano 的原生前向兼容支持，使得新模型上线后能被 OpenClaw 生态系统无缝接入。

产品整合

  • 深度整合：被直接接入 ChatGPT、API 与 Codex。
  • 工作流变革：推动了 OpenAI 智能体工作流使用率创下新高。
  • 商业价值：作为 OpenAI 构建统一 AI超级应用 的核心引擎，支撑起 ChatGPT、搜索及 Agent 能力的整合。

市场反响与评价

尽管 OpenAI 官方强调 GPT-5.4 系列相比满血版的成本优势，但市场反馈呈现两极化：

  • 排名争议：其综合性能排名（第 13 名）不及一月底发布的国产模型 Kimi 2.5（第 12 名）。
  • 用户情绪：用户社区中出现了“Keep 4o”的声音，表达了对旧版模型体验的怀念以及对价格上涨的不满。

战略意义

GPT-5.4 的发布是 OpenAI 战略调整的重要信号。它不再仅仅强调模型“更聪明”，而是强调模型能否直接进入工作流、接管工具、完成任务。这标志着 OpenAI 试图通过强化生产力属性，夺回被 Anthropic 和 Claude Code 占据的企业级市场高地。

其战略重心已从单纯的“推理跑分”转向构建具备持久记忆和自主执行能力的“全自动代理”，这也可能引发新一轮的硬件“内存之战”，对底层算力架构提出更高要求。

背景与基础设施

GPT-5.4 的发布伴随着 OpenAI 巨额算力投入（1220 亿美元融资），其训练和推理依赖于庞大的多供应商基础设施组合。
