智谱

智谱（Zhipu AI / 智谱AI）是中国领先的人工智能独角兽企业，源自清华大学计算机系知识工程实验室，专注于大语言模型的研发与应用，也是 GLM 系列大语言模型的开发者。

概述

智谱致力于打造新一代认知智能大模型，提供从模型训练到应用落地的全栈解决方案。公司在学术界和工业界均有深厚积累，不仅关注模型能力的 Scaling，同样重视支撑大规模应用的系统工程稳定性。2026年上市后首份财报显示，智谱以7.24亿元年收入成为国内收入最高的大模型公司。

技术产品与迭代

智谱目前处于极快的模型迭代周期中，例如 GLM-5.1 距离上一代 GLM-5 的发布仅间隔一个多月。

GLM 系列

  • 架构：采用双向编码+自回归融合架构。
  • GLM-5：最新一代模型，编程能力逼近 Claude Opus 4.5，在 Artificial Analysis 榜单排名全球第四、开源第一。
  • GLM-5.1：在编程等核心能力上积极对标国际顶尖模型（如 Claude Opus 系列），上线后表现强劲。
  • 历史版本：包括 ChatGLM 等早期版本。

生态与工具

  • 接口标准：采用 OpenAI Compatible 接口标准，并支持 Claude Code、OpenClaw 等第三方工具接入，降低开发者迁移门槛。
  • 订阅服务：通过 GLM Coding Plan 提供订阅服务，近期因 GLM-5.1 的上线出现了因算力资源紧张导致的“售罄”现象。

商业模式与行业落地

智谱的商业模式与 anthropic 高度相似，核心为 maas（Model as a Service）。

商业表现

  • 定价策略：逆势涨价。2026年3月，glm-5-Turbo 涨价83%，调用量不降反升，吸引了9家中国前十大互联网公司作为客户。
  • 盈利能力：全年综合毛利率41%，远超行业平均的负毛利。
  • 核心逻辑：张鹏 提出的公式 商业价值 = 智能上界 × Token消耗规模。

行业应用

智谱通过 MaaS 平台、API 及私有化部署等方式，为泛互联网、金融、政务等行业提供 AI 能力。

  • MaaS平台：吴玮杰（智谱高级副总裁）负责公司的 MaaS 平台商业化。
  • 行业活动：智谱高管吴玮杰将出席中国aigc产业峰会，探讨 AI 商业化的路径与挑战。

技术实战与工程能力

除了模型研发，智谱在推理基础设施的工程优化方面展现了深厚的技术积累。针对 GLM-5 在大规模 Coding Agent 应用中出现的 Scaling Pain，智谱团队公开了详细的排查与优化过程。

关键技术贡献

  • LayerSplit：一种创新的 KV Cache 分层存储优化方案，显著降低了长上下文推理的内存压力，提升了系统吞吐量。
  • HiCache 优化：重构了缓存读取流程，引入显式同步机制，解决了高并发下的数据竞态问题。
  • 显式同步机制：在 PD 分离架构中建立了严格的时序约束，消除了跨请求的 KV Cache 损坏。

战略理论

提出了 token架构力（TAC）概念，强调从参数竞赛转向“智能架构竞争”，关注智能转化为经济价值的效率。

社区与生态活动

智谱积极参与开发者社区与新兴硬件生态的建设。

  • 龙虾 硬件生态：在2026年3月的“养虾沙龙”活动中，智谱作为合作伙伴，派遣员工（如李子玄）参与分享，并提供现场技术支持（如“替你装虾”服务）。这表明智谱可能参与了该硬件的软件适配、Agent 开发或底层技术支持。
