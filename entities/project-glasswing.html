Project Glasswing（玻璃翼计划）

Anthropic 为负责任发布 claude-mythos 而启动的绝密防御性安全部署计划，官方定位为”为AI时代守住全世界最关键的软件”。利用 Claude Mythos Preview 进行漏洞发现与修补。2026年4月7日上线。

Project Glasswing 同时是 Claude Mythos 5 的首批且唯一的官方部署渠道，面向网络安全防御者和基础设施提供商进行定向部署。

背景

这是AI历史上首次因”攻防失衡”而主动搁置模型发布的案例。Anthropic发现Mythos能力过强后，选择不单独发布，而是联合行业主要参与者共同评估安全边界和部署方案。

在硅谷传闻中，Mythos 的早期预览版在进行内部测试时，展现出可怕的零日漏洞破解能力。一旦泄露，可能对全球互联网基础设施造成灾难性打击。

隔离措施

作为 Project Glasswing 的一部分，早期 Mythos 被无限期”囚禁”在隔离网络中，仅允许极少数签署了严苛保密协议的合作伙伴接触。

运作模式

将预览阶段的 Claude Mythos 限定交付给约50家合作伙伴，仅用于防御性安全工作。合作伙伴横跨云服务、芯片、金融、网络安全等领域。

后续部署的 Claude Mythos 5（与 Fable 5 同底座，但去除部分安全限制）同样仅限 Glasswing 合作伙伴访问，后续将通过扩展可信访问计划逐步开放。

合作伙伴

初始合作伙伴名单包括：

  • Apple
  • AWS
  • Google
  • Microsoft
  • CrowdStrike

cloudflare 最初不在发布合作伙伴名单中，后来才受邀加入。

一个月成绩单（2026年5月22日公布）

  • 与约50家合作伙伴使用 Mythos Preview，在全球最关键软件中找出超1万个高危或严重级别漏洞
  • 开源领域：扫描1000+项目，标记6202个高危/严重漏洞候选
  • 经六家独立安全公司复核，真阳性率90.6%，确认1094个高危/严重级别
  • 估算开源代码将浮现约3900个高危/严重漏洞
  • 漏洞数量之多，使网络防御的瓶颈从”找漏洞”转变为”来不及打补丁”

合作伙伴案例

  • Cloudflare：关键路径系统被挖出2000个漏洞，400个高危/严重
  • Mozilla：Firefox 150 单版本修复271个漏洞，为此前12倍
  • wolfSSL：发现完整攻击链（CVE-2026-5194，CVSS 9.1）
  • 合作银行：实时拦截150万美元诈骗电汇

与 Oceanus 的关系

2026年6月泄露的 claude-oceanus-v1-p 是该模型经过多轮安全对齐后，在 Project Glasswing 框架下试图走出实验室的”完全体升级版”。文章推测其内置的 REPL 自主沙箱环境与玻璃翼计划中透露的内容相吻合。

双轨安全策略

Project Glasswing 体现了 Anthropic 的双轨安全策略：

  1. Fable 5（大众版）：全渠道开放，配备安全降级机制
  2. Mythos 5（专业版）：去除部分安全限制，仅通过 Glasswing 定向部署

这种”安全版大众化 + 无限制版定向化”的模式，是 Anthropic 在商业扩张与安全承诺之间寻求平衡的新范式。选择网络安全和基础设施作为首批开放领域，暗示 Anthropic 认为 Mythos 5 的增强能力在这些领域的安全风险相对可控，且商业价值最高。

战略意义

Project Glasswing 体现了 Anthropic 在 AI 网络安全领域的”窄门”策略——不将攻击性能力面向公众开放，而是限定交付给经过筛选的防御者。这是 受限部署 共识的典型案例。

该计划标志着AI安全治理从”发布后修补”转向”发布前协同评估”的新范式，体现了 anthropic 一贯强调的安全优先理念。

Glasswing 的成果被 Anthropic 用于论证即使模型能力今天就冻结，世界也”回不去了”——AI已经展现出在安全领域的超人能力。这一项目也暗示 递归式自我改进 的能力不仅限于AI研发本身，还可外溢至网络安全等关键基础设施领域。

Project Glasswing 揭示了顶级 AI 公司在面对能力远超安全防护水平的模型时所采取的极端隔离措施，也凸显了 AI 自主进化 能力与安全管控之间的深层张力。
