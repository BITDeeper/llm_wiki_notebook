MinerU §

MinerU 是一个开源的文档解析工具，旨在将 PDF、图片及 Office 文档（DOCX, PPTX, XLSX）转换为 Markdown、JSON 等机器可读格式，以支持下游的检索、提取和处理任务。

核心特性 §

  • 多格式支持：支持 PDF、图片、DOCX、PPTX、XLSX 等多种输入格式。
  • 多种输出格式：可输出 Markdown、JSON（包括 middle.json 和 content_list.json）。
  • 灵活的部署方式：支持命令行、Gradio WebUI 和 Docker Compose 部署。
  • 原生解析：针对 Office 文档采用原生解析，相比“转 PDF 再解析”的传统方式，速度提升数十倍。

处理架构 §

MinerU 针对不同类型的文件采用差异化的处理流程：

Office 文档处理 §

  • 流程：通过 _process_office_doc 函数处理。
  • 引擎：使用专门的原生解析器（如 office_docx_analyze）。
  • 优势：无需转换为 PDF，处理速度快，无转换产生的幻觉。
  • 限制：不支持 Layout 和 Span 的可视化调试。

PDF 与图片处理 §

  • 流程：通过 _process_pipeline 或 _process_vlm 函数处理。
  • 输入：图片会先在内部转换为 pdf字节流。
  • 后端模式：
    • Pipeline：传统的布局检测 -> OCR 流水线。
    • VLM：基于视觉语言模型（VLM）的端到端理解。
    • Hybrid：结合 VLM 的布局理解能力和 Pipeline 的 OCR 精度。

API 与部署 §

启动方式 §

  • FastAPI 服务：提供标准的 RESTful API 接口。
  • Gradio WebUI：提供交互式网页界面，可同时启动 API 服务（端口动态分配）。
  • Docker Compose：适合生产环境的容器化部署。

API 端点 §

  • /health：健康检查。
  • /tasks：异步任务提交。
  • /file_parse：同步解析接口。
  • /tasks/{task_id}：查询任务状态。

数据流 §

  1. 输入：文件或字节流。
  2. 预处理：Office 文档分流，图片转 PDF 字节流。
  3. 核心处理：版面分析、OCR、模型推理。
  4. 中间表示：生成包含详细坐标和结构的 middle-json。
  5. 最终输出：生成用户友好的 Markdown 或简化的 content-list-json。

参见 §

  • pdf字节流：PDF 处理的基础数据格式。
  • middle-json：包含详细布局信息的中间数据格式。
  • 处理后端：Pipeline、VLM 和 Hybrid 模式的详解。
