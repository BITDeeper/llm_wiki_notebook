Deep Researcher Agent §

Deep Researcher Agent 是一个开源的自动化深度学习实验框架，旨在 7x24 小时代替研究者执行重复性实验任务。该项目由 Xiangyue-Zhang 在 GitHub 上发布（项目名：auto-deep-researcher-24x7），专注于解决深度学习研究中“改超参、跑训练、等结果”这一机械循环的痛点。

核心功能与架构 §

自主实验循环 §

框架的运行基于一个四步闭环逻辑：

  1. THINK：读取项目说明和历史记忆，分析当前最优结果，决定下一步实验方案（不仅限于超参，还包括模型代码、Loss 函数和数据增强策略的修改）。
  2. EXECUTE：自动修改代码或配置文件，并在提交 GPU 任务前强制执行 dry-run（2步前向/反向传播）以快速检测代码 Bug。
  3. MONITOR：在漫长的模型训练过程中，完全不调用 LLM API，仅使用系统命令（如 kill -0, nvidia-smi, tail）检查进程状态。这是其实现极低成本运行的关键。
  4. REFLECT：训练结束后，解析日志、提取指标、对比历史最优并记录里程碑，随即开启下一轮循环。

恒定记忆系统 §

为了解决长期运行导致的上下文膨胀问题，框架采用两层记忆管理机制：

  • 第一层（冻结层）：人类编写的项目说明，最大约 3000 字符，定义研究目标和约束。
  • 第二层（滚动层）：Agent 维护的滚动日志，将关键成果压缩至 1200 字符以内，仅保留最近 15 条决策。 总记忆量恒定在约 5000 字符，确保 Agent 在运行半年后依然保持高效和低成本。

性能与成本 §

  • 成本控制：由于 90% 以上的训练时间不调用 LLM API，每日运行成本可低至 0.5 元人民币。
  • 实测表现：据项目方数据，已在真实项目中连续运行 30 多天，完成 500+ 轮循环，使项目指标提升 52%，期间人类仅介入 5-6 次。

兼容性与集成 §

  • 模型支持：支持 Anthropic 系（Claude Sonnet 4.6 / Opus 4.6）和 OpenAI 系（Codex 5.3 / GPT 5.4）后端，配置一行即可切换。
  • 移动端监控：配合 Happy Coder App（iOS/Android），用户可在手机上实时查看进度、接收推送并远程下达指令。
  • CLI 集成：提供类似 Claude Code 的斜杠命令集成，安装简便。

伦理与边界 §

作者在项目 README 中明确声明，严禁将工具用于学术造假。框架的设计初衷是替代机械劳动，让研究者专注于 Idea 的构思和结果的解读。作者强调“Agent 可以替你跑实验，但 idea、判断与责任必须由人来承担”。
