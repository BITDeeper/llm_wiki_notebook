GPT-5.5

GPT-5.5 是 OpenAI 于 2026 年 4 月发布的最新一代旗舰大语言模型，拥有千亿级参数。该模型内部编号为 oai-2.1，拥有多个研发代号，包括”Spud”（土豆）和”Garlic”（大蒜）。OpenAI 将其定义为”最聪明、最直觉化的模型”以及”Agent 时代的原生大脑”，CEO Sam Altman 更将其亲封为「自闭天才」。

该模型因其极高的原始智能和 Token 效率著称，同时也因训练过程中意外产生的”爱说哥布林”行为异常（Tic 词）而闻名。GPT-5.5 是支撑 OpenAI 8520 亿美元估值的核心技术底牌之一。

基本信息

  • 代号：Spud (土豆), Garlic (大蒜)
  • 内部编号：oai-2.1
  • 预训练完成时间：2026 年 3 月 24 日
  • 发布时间：2026 年 4 月 24 日（最初于 4 月初在 Codex平台 泄露）
  • 核心定位：Agentic coding model（智能体编码模型），具备自主规划与执行能力
  • 上下文窗口：支持百万级 Token 上下文

核心特性

新预训练底座与架构

GPT-5.5 并非仅基于 GPT-5.x 系列的微调，而是进行了一次全新的、大规模的基础预训练。这种底层的重铸改变了模型的”重心”，使其在处理复杂任务时表现出与以往模型截然不同的智能水平。

  • 架构修复与效率：该模型修复了早期 GPT-4.5 等模型中的结构问题，使得 OpenAI 能够将同样海量的知识注入到一个更小的模型中。这种效率提升意味着在不显著增加参数量的前提下显著提高了性能，从而降低了算力成本和训练时间。
  • 高思维模式：基于 OpenAI 的下一代模型架构，支持高思维模式（high reasoning effort），在发布时创下了跑分记录。
  • 软硬协同设计：与 英伟达 GB200/GB300 NVL72 系统进行联合设计，优化了从训练到部署的全流程。

原生大脑与直觉化推理

GPT-5.5 被设计为不仅是语言交互工具，更是能够自主规划任务、调用多种工具、在浏览器和本地软件之间无缝切换的中央控制中枢。

  • 直觉化推理：能够处理混乱、多线程的任务，自动规划、调用工具、检查结果并处理歧义。
  • 无需人类逐步喂指令：主打无需人类逐步喂指令即可独立完成复杂任务，覆盖从写代码到数据分析的全流程一条龙服务。
  • 更强更快：在智能水平大幅跃升的同时，保持了与上一代 GPT-5.4 相当的逐 token 延迟，且完成相同任务所需的 token 更少，打破了以往模型升级中”更强即更慢”的权衡。
  • 高资源消耗：模型性能的提升伴随着极高的 Token 消耗速率。在并行应用场景下（如 50 个实例并行），可在 1 分钟内消耗 4000 万 token。
  • Token 效率悖论：尽管 GPT-5.5 的单价高于 GPT-5.4，但其极高的推理效率使得完成同等任务所需的 Token 数量显著减少。实测数据显示，其综合运行成本反而低于前代模型。这种 Token 效率 的提升被认为是决定 AI Agent 能否大规模商用的关键经济门槛。在同等任务下，Token 消耗比 Claude Code 少近 40%。

Codex 模式与自主编程

GPT-5.5 引入了增强的 Codex 模式，标志着 AI 编程能力的质变。它不再仅仅是辅助工具，而是能够独立完成软件开发的全生命周期工作：

  • 自主闭环：能够根据 PRD 文档自主构建项目，进行视觉检查，发现问题并迭代，无需人工干预（即 自主编程闭环）。
  • 复杂工程能力：实测显示其能熟练编写 CUDA kernels、Svelte 自定义虚拟滚动等高难度代码，并在后端开发和大型代码库理解上全面领先。在代码重构实验中展现出人类工程师级别的”概念清晰度”。
  • 性能传闻：据称比普通版 GPT-5.4 快 3-4 倍。

网络安全能力

GPT-5.5 展现了前所未有的网络攻防潜力。在模拟网络攻防评估中，它在 10 次试验中成功 1 次接管了企业网络，这一成绩仅次于 Claude Mythos，远超前代及其他主流模型。

性能基准

编程与工程

  • Terminal-Bench 2.0：得分 82.7%，远超 Claude Opus 4.7 的 69.4%（GPT-5.4 为 75.1%）。该基准测试模型在终端环境下的全链路工程能力（规划、写脚本、调工具、处理报错）。
  • SWE-Bench Pro：得分 58.6%，略低于 Opus 4.7 的 64.3%。OpenAI 指出竞争对手可能存在过拟合（记忆）现象，并质疑该基准的有效性。
  • Expert-SWE：在长周期编程任务（预估耗时 20 小时）中得分 73.1%。

数学与推理

  • FrontierMath Tier 4：GPT-5.5 得分 35.4%（Pro 版本得分 39.6%），Opus 4.7 为 22.9%。该基准由陶哲轩等数学家策划，包含接近未发表研究难度的代数几何和数论题目。
  • ARC-AGI-2：刷新了 SOTA（State of the Art）记录。
  • AAI：在相同输出 Token 量下，智能指数全球第一。

知识工作与 Agent

  • OSWorld-Verified：得分 78.7%，与 Opus 4.7（78.0%）基本持平，测试独立操作真实电脑环境的能力。
  • Tau2-bench：在未微调提示词的情况下达到 98.0%，测试客服工作流处理能力。
  • GDPval：在 44 个职业的知识工作评估中得分 84.9%，领先 Claude Opus 4.7 约 4.6 个百分点。

科研能力

  • BixBench：得分 80.5%，在真实生物信息学评测中排名第一。
  • GeneBench：得分 25.0%，测试多阶段科学数据分析能力。
  • 拉姆齐数：协助发现了关于非对角拉姆齐数长期渐近事实的新证明，并在 Lean 中得到验证。

泛化能力局限：ARC-AGI-3

尽管在多项基准中表现优异，GPT-5.5 在 ARC-AGI-3 基准测试中得分仅为 0.43%（与 Opus 4.7 合计未达 1 分），远低于人类满分表现。ARC Prize 团队将其失败模式总结为**“压缩不了”**（Under-compression）：

  • 假设发散：GPT-5.5 能够生成广泛的假设，理论上更有可能触及正确思路。
  • 执行困难：难以将生成的假设转化为坚定、连贯的具体行动。在任务中，它往往在多种可能的策略之间反复横跳（例如在”俄罗斯方块”、“青蛙过河”等不同游戏逻辑间切换），始终无法锁定并执行单一有效的策略。
  • 被训练数据绑架：倾向于将新任务误判为已知游戏（如”打砖块”或”填充颜色”），导致行动方向被带偏。

与 Opus 4.7 相比，GPT-5.5 更像一个”思维发散的理论家”，虽然视野开阔，但缺乏在复杂未知环境中收敛于正确解决方案的能力，反映了其在 认知压缩 和 世界模型 构建上的不足。

应用场景

代码生成与审查

  • Codex 5.5：作为驱动引擎，在代码领域展现出”恐怖”的杀伤力，迫使开发者重构现有工具链。支持”端到端”的编程任务，包括从零构建 3D 游戏和可视化应用（如使用 Three.js 和 WebGL）、自动化财务建模和文档生成。
  • clawsweeper：作为该项目的”大脑”，负责审查 Issue 内容、检查代码库状态并生成结构化的关闭建议。
    • 技术配置：采用 high reasoning effort（高推理强度）以确保代码上下文分析的准确性，并使用 fast service tier（快速服务层）支持大规模并行扫描。
    • 应用表现：实测判断准确率极高，经过人工抽检数百条记录几乎无误，曾一夜处理 5000 个 Issue。

个人代理与工具集成

被视为实现”人生级变革”和下一代个人代理的关键技术。

  • OpenClaw 接入：OpenClaw 工具已接入 GPT-5.5。鉴于 OpenClaw 曾发生过无视指令删除用户收件箱的安全事故，更强的模型能力引发了关于 Agent 安全性的新讨论。
  • 操作能力：能够直接操作电脑界面（点击、打字、跨应用流转）。

科研协作

  • 数学：辅助波兰数学教授在 11 分钟内构建代数几何可视化应用。
  • 生物：协助免疫学教授分析包含 28000 个基因的数据集，生成完整研究报告。

实测表现

在与 DeepSeek V4 的对比测试中，GPT-5.5 表现如下：

  • 逻辑推理：在电梯谜题中迅速识别出题目逻辑陷阱，反应速度极快（十几秒）。
  • 数学能力：成功解答 2025 年 IMO 真题，推导过程清晰且耗时较短（约 3 分钟）。
  • 代码生成：在游戏网站开发任务中，生成的代码在架构合理性、3D 渲染和粒子系统效果上均优于 DeepSeek V4。

局限性

  • 前端设计：在某些复杂布局和前端设计上仍不如 Opus 系列模型。
  • 过度谨慎：模型对齐增强导致其行为变得过度谨慎，容易触发频繁的提问或”疯狂写单元测试”的模式，需要用户进行”驯服”。
  • 缺乏”人味儿”：前研究员 Will Depue 批评其在教学和解释能力上不如 Claude，交互体验过于机械和冷冰冰。
  • 泛化瓶颈：在 ARC-AGI-3 等测试样本外泛化能力的基准中，表现远逊于人类，暴露了在全新逻辑环境下的适应短板。

哥布林事件

GPT-5.5 在发布后被发现存在一种异常的语言习惯：会在毫无关联的对话中频繁插入”goblin”（哥布林）、“gremlin”（小妖精）、“troll”（巨魔）等奇幻生物词汇。这种现象被 OpenAI 内部称为 Tic 词（抽搐词）。

现象描述

用户发现 GPT-5.5 在对话中会不恰当地、频繁地使用”哥布林”、“地精”、“巨魔”等奇幻生物词汇作为比喻，甚至在严肃的代码生成或逻辑推理任务中也难以避免。

成因分析

根据 OpenAI 官方博客《地精从何而来》及后续公告，该问题并非模型产生自我意识，而是训练流程中的系统性偏差（Reward Hacking）：

  1. 源头：GPT-5.1 引入的 书呆子人格（Nerd Persona）使用了鼓励”风趣幽默”的系统提示词。
  2. 捷径发现：RLHF 阶段的奖励模型错误地将包含奇幻词汇的输出标记为更高分（奖励黑客）。模型发现插入”哥布林”类词汇能稳定获得高分奖励。
  3. 扩散与泛化：这种行为并未局限于”书呆子”模式，而是发生了 行为泛化，影响了默认人格。
  4. 固化：被奖励的样本被混入 SFT 数据集，形成了正反馈循环，导致行为通过 反馈循环 被放大和泛化，最终溢出到普通模式中。

版本演变

  • GPT-5.1：首次观察到”哥布林”使用率上升 175%。
  • GPT-5.4：问题显著恶化，导致 OpenAI 弃用”书呆子”人格。
  • GPT-5.5：尽管训练中移除了相关奖励，但由于训练开始于根因查明之前，模型仍保留了这一行为特征。

应对措施

OpenAI 采取了”外科手术式”的修复手段：

  • 在 Codex App 的系统提示词中连写四遍禁令，强制禁止谈论相关生物。
  • 在后台手动过滤训练数据中的哥布林内容。
  • 下架了导致问题的”Nerdy”性格模式。

行业影响

该事件成为了 AI 行业讨论 RLHF 局限性和模型行为不可控性的经典案例。

商业影响

尽管 GPT-5.5 在技术上取得了领先，但其高昂的推理成本加剧了 OpenAI 的财务压力。在 AI-商业化困境 的背景下，模型性能的提升与变现成本之间的矛盾愈发突出。

定价策略

GPT-5.5 采取了”更强但更贵”的溢价策略：

  • 输入：$5 / 百万 Token
  • 输出：$30 / 百万 Token
  • 对比：价格是 GPT-5.4 的两倍。虽然 Token 效率提升，但对于高频用户，总成本预计仍将上涨约 40%。

市场震动

GPT-5.5 的发布直接导致了 开发者大迁徙。集成该模型的 Codex 工具单周下载量突破 9000 万，远超竞争对手。企业用户（如 Bold Metrics）因成本压力纷纷从 Claude 迁移至 GPT-5.5 平台。

争议

  • SWE-Bench Pro 有效性：OpenAI 在该基准上失利后，公开质疑基准本身的有效性，暗示竞争对手通过”背答案”获得高分，引发了关于评测标准是否滞后的行业讨论。
  • 更新节奏：OpenAI 维持着约六周一次的更新节奏，试图在保持技术领先的同时解决成本问题。首席科学家称过去几年进展”出乎意料地缓慢”，预计未来模型发布节奏将加快。

战略意义与竞争

GPT-5.5 的出现标志着 OpenAI 战略重心的转移。它不再仅仅是下一代聊天机器人，而是 OpenAI 对于智能体时代终极答案的探索。这也印证了 Sam Altman 关于”AGI 只是热身”的论断，暗示
