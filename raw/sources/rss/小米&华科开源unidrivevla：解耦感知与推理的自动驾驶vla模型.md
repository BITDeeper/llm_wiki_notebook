在自动驾驶领域，视觉-语言-动作（Vision-Language-Action, VLA）模型正逐渐成为研究的热点。这类模型试图将大语言模型（LLM）丰富的世界知识引入驾驶系统，赋予车辆更强的认知和推理能力。然而，现有的 VLA 模型面临着一个尴尬的“两难境地”：直接使用 2D 多模态大模型（VLM）虽然推理能力强，但空间感知能力薄弱；而一旦引入 3D 空间表征来增强感知，又往往会损害 VLM 原生的语义推理能力。
为了打破这一僵局，来自小米汽车、华中科技大学和澳门大学的研究团队提出了
UniDriveVLA
。其核心思想是采用
混合 Transformer（Mixture-of-Transformers, MoT）
架构，将理解、感知和规划任务交由专门的“专家”模块处理，从而在提升空间感知时，尽力保留了语义推理的能力。

为什么需要“专家解耦”？
在传统的单体 VLA 模型中，空间感知和语义推理往往在共享的参数空间中进行优化。研究团队发现，这种“大杂烩”式的训练会导致严重的
表征干扰（Representation Interference）
。
如下图所示，在共享权重的解码器中，LLM 的 Token 和感知 Token 的余弦相似度随着层数加深迅速趋近于 1。这意味着两类完全不同的特征在模型内部发生了“坍缩”，变得难以区分。这种干扰直接导致了性能的此消彼长：感知强了，推理却乱了。
图 2 分析了表征干扰与模型性能的关系。在共享权重解码器中，相似度随层数增加而上升，导致特征坍缩；而 MoT 架构保持了较低的相似度，实现了任务解耦，性能全面领先。
UniDriveVLA 的出发点非常直观：既然放在一起会打架，那就让它们“分家”。通过引入混合 Transformer 架构，模型为不同的任务分配了专属的参数路径。
图 1 对比了不同的自动驾驶 VLA 范式。(a) 原生 2D VLA 语义强但感知弱；(b) 3D 增强 VLA 提升了感知但损害了推理；(c) UniDriveVLA 通过 MoT 架构实现了两者的兼顾。
UniDriveVLA 方法详解
UniDriveVLA 的核心架构由三个专门的专家组成：
理解专家（Understanding Expert）
、
感知专家（Perception Expert）
和
动作专家（Action Expert）
。
三位专家的分工与协作
理解专家
：基于强大的预训练 VLM（如 Qwen3-VL），负责处理驾驶指令、场景描述和常识推理。输入包括多视图图像和驾驶指令，输出为语义 Token。
感知专家
：采用
稀疏感知（Sparse Perception）
范式，从视觉特征中提取关键的空间先验，如 3D 检测框、在线地图和占用栅格（Occupancy）。输入为 2D 视觉特征，输出为结构化的空间查询。
动作专家
：负责最终的轨迹规划，利用
流匹配（Flow-matching）
生成平滑且安全的驾驶路径。输入为加噪的动作查询、语义 Token 和感知 Token，输出为去噪后的未来轨迹。
图 3 展示了 UniDriveVLA 的架构全景。模型通过三个专家处理异构 Token，并利用掩码联合注意力（Masked Joint Attention）协调它们，在单一框架内统一了理解、感知和规划。
掩码联合注意力（Masked Joint Attention）
为了让这三位专家既能各司其职，又能高效沟通，研究者设计了一种巧妙的注意力机制。其核心逻辑如下：
理解 Token
采用因果掩码，它们看不见后面的感知和动作 Token。这保证了 VLM 的原生推理能力不被后续任务“带偏”。
感知 Token
可以观察到前面的理解 Token，从而获得语义上下文。
动作 Token
则可以观察到前面所有的信息，确保规划决策是建立在充分的理解和感知基础之上的。

稀疏感知与三阶段训练
UniDriveVLA 并不一味追求复杂的 3D 表征，而是通过稀疏感知模块直接从 2D 特征中提取空间先验。这些查询通过
实例库（Instance Banks）
初始化，并利用 K-Means 聚类获得数据集层面的先验分布。
为了让模型平稳地掌握这些能力，团队制定了
三阶段渐进式训练策略
：
大规模预训练
：锚定模型的语义推理基础。
受控联合优化
：引入感知和规划监督，使用
低秩自适应（Low-Rank Adaptation, LoRA）
技术微调 VLM，同时降低其学习率以防“遗忘”常识。
专家特化微调
：冻结 VLM，专门强化感知和动作专家的性能。

实验结果：全面领先的性能
研究团队在 nuScenes（开环）和 Bench2Drive（闭环）两个主流榜单上对 UniDriveVLA 进行了严苛的测试。
闭环评估：Bench2Drive 夺冠
在 Bench2Drive 的闭环驾驶测试中，UniDriveVLA 表现出色。在不使用 PDM-Lite（一种高质量专家演示数据）的方法中，它以
78.37
的驾驶得分（Driving Score）位居第一，同时在效率（Efficiency）指标上也达到了
198.86
，大幅领先。

并道（Merging）
和
超车（Overtaking）
等复杂场景下的成功率分别达到了
38.75%
和
80.00%
，展现了极强的实战能力。

开环评估：nuScenes 精度标杆
在 nuScenes 数据集上，UniDriveVLA-Large 在无自身状态（without ego status）的设置下，取得了
0.51m

语义推理：不忘初心
最令人欣慰的是，经过驾驶任务的“特训”，UniDriveVLA 依然保留了优秀的通用多模态理解能力。在 RealWorldQA 和 ChartQA 等通用测试中，它依然能给出高质量的回答，并未发生严重的“灾难性遗忘”。

写在最后
UniDriveVLA 通过 Mixture-of-Transformers 架构，试图解决 VLA 模型中感知与推理的冲突问题。笔者认为，这种解耦思路不仅提升了性能，更重要的是为自动驾驶系统提供了一种可解释的“中间层”——感知专家的输出可以直观地告诉人类，系统到底看到了什么，而理解专家则负责解释为什么要这么开。
目前，该项目已在 GitHub 开源。代码基于 Python 开发，模型底座采用了最新的 Qwen3-VL。对于想要复现或在此基础上进行二次开发的开发者来说，作者提供的三阶段训练策略和专家解耦逻辑可直接参考。
