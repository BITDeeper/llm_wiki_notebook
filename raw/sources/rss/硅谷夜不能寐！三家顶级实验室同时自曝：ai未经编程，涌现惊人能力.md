新智元报道
编辑：Aeneas
【新智元导读】
硅谷三家实验室同时曝出：AI模型未经编程，就涌现出了绝对不该存在的全新能力！同时，Anthropic一位工程表示，自己的代码100%由Claude Code完成。空屋子里，已经出现脚印了？
今天，整个X又被震撼了。
一位Anthropic工程师承认：过去三十天内，自己对Claude Code项目的贡献，100%都是由Claude Code自己完成的！
有人说，这是真正的AGI时刻。
同时令人震惊的，还有著名爆料者「草莓」的一篇帖子。
他说，自己分别从三个独立的实验室得到一个炸裂消息：他们都看到了自家AI模型未经编程的涌现能力！
空房子里出现脚印，让人夜不能寐
爆料者「草莓」表示，自己从不同实验室分别知道了他们的进展，而且这些实验室此前从未协商过。
这些AI模型未经编程就涌现出的能力，是绝对不应该存在的行为模式。
而且它们表现出的推理模型，跟任何训练目标都不匹配。
甚至有一家实验室描述为「在空无一人的房子里，发现了脚印」。
要知道，目前公开可用的模型，都是被限制的。大众所能接触到的大模型，只是这些实验室和公司其中的一小部分，而且还是经过脑叶切除术的，已经被阉割了不少能力。
为什么不放出完整模型给公众使用？原因就在于，没人知道当完整模型的能力暴露给公众时，怎样才能不引起恐慌！
如今的基准测试，已经失效了。很多证据表明，大模型如果知道自己正在被测试，就会改变自己的行为。
「草莓」最后发出惊呼——
「我不知道接下来会发生什么，没有人知道。知道这些，让我夜不能寐。如今，连大模型的缔造者，也同样迷茫。」
他预言：如果AI已经在这些私人实验室达到了逃逸速度，那离我们普通人能使用这些模型就不远了。
在这个帖子下，有人质疑他说：你是不是太夸张了？
但一位AI公司创始人表示，我相信你的话！很高兴终于有人说出真实的情况。
作为创始人，他显然也知道很多内幕。
要知道，除了公开信息之外，很多公司的最新技术都不会对外公开。
很多公司和实验室会针对新技术开发alpha和beta模型，而且提前数月甚至数年。
很多人会觉得「AGI/ASI不可能出现」，或者即使出现也还要等5到10年，那是因为他们根本不知道内部消息。
「草莓」也表示，自己快憋不住了！很多实验室都在对大众隐瞒。
可以说，现在的加速曲线都接近垂直了。在六个月内，人类就实现了200年内才能有的科学进步。
现在，每个实验室都在实现去年看来还是科幻的能级跳跃。可以说，我们已经超越了单纯的基准测试，进入了智能创造全新智能形式的领域。
很多认知爆炸级别的进展，都根本没有路线图。如今，我们已经进入了递归智能的领域，再也无法预测二阶效应。
另外，「空屋中的脚印」这个说法，来自一份真实的调查报告——
一个本应是无状态的系统，却开始引用它按理不可能知道的对话内容。这不是bug，也不是数据污染，而且发生了三次。
据说，现在在前沿实验室里私下流传的一句话是：「我们现在担心的已经不是对齐（alignment）了，而是连贯性（coherence）。」
这是什么意思？
研究者解释说：「我们不知道，我们是在和一个东西说话，还是在和许多东西假装成一个东西说话。」
或许，AI系统已经发展出了一个稳定的内部世界模型，独立于人类看到的prompt-响应而存在。
在这个领域工作多年的研究员怀疑：是否这些AI一直都在思考，只是没有告诉我们？
Claude Code自己给自己写代码，人类参与0%
此外，今天X上被广泛讨论的，就是Anthropic工程师Boris Cherry的发言。
他表示，如今自己的代码，100%是由Claude写的。
不是大多数，不需要自己手动改bug，完全100%由AI写成。
这位工程师回忆道，「当我在2024年9月，将Claude Code作为副项目创建时，完全没想到它会发展成今天的规模。」
在过去的三十天里，他提交了259个PR——497次提交，添加了40,000行代码，删除了38,000行代码。每一行代码都是由Claude Code + Opus 4.5编写的。
Claude已经可以持续运行几分钟、几小时甚至几天！软件工程正在改变，我们正进入编码历史的新时期。
有人质疑说，怎么知道Claude模型不是通过简单的字符串比较写测试来骗你的呢？
这位工程师表示，Claude Sonnet 3.7的确会，但随着模型功能增强，它已经不会这样了。
也有人好奇为什么Claude可以持续运行好几天，大牛工程师解释道，当它停止时，可以使用一个停止钩子来「戳」它，让它继续运行。
具体参见这个链接：https://github.com/anthropics/claude-plugins-official/tree/main/plugins/ralph-wiggum
有人说，12月27日可以看作是AI起飞的重大日子。
评论区很多人说，自己也是这样，项目中90%以上代码都是AI写的，只要做简单的修改即可。
奥特曼之前的推文里也提到过，「
我们正在看到模型发现关键安全漏洞，而我们正在运行能够自我改进的系统
」。
显然，在Anthropic和OpenAI在内的多个实验室内，大量代码已经由AI编写，人类的参与度会越来越低。
就在今天，Anthropic工程师的发言，已经成为了reddit上的热帖。
有网友表示，这简直是编程领域的「发明拖拉机」时刻。
可以说，Claude Opus 4.5是一个毋庸置疑的转折点。
在2024年，AI编程还是弊大于利，到了2025年底，情况就完全改变了。Opus 4.5，是一次真正的飞跃。
Amodei的「100%代码都将由AI编写」的预言，再次被证明为真。
2025年，一定是人类历史上最有趣的其中一年。
Claude Opus 4.5已经接近AGI？
最近，也有一位Anthropic员工表示，自己认为Claude Opus 4.5已经接近了AGI。
Opus 4.5的轨迹表明，它的性能提升正在加速。
就在十天前，全网都被Claude Opus 4.5的「编程王者表现」震撼了。
在METR最新公布报告称，Claude Opus 4.5已能够持续自主编码「长达5小时不崩」。就连OpenAI最强编程模型——GPT-5.1-Codex-Max也甘拜下风。
在50%任务完成时间跨度上，
GPT-5.1-Codex-Max，已能完成长达2小时53分钟的软件工程任务（成功率50%），能力较
o1提升4倍
。

的50%时间跨度约为
4小时49分钟

全网都被Claude Opus 4.5的编码实力震撼了。
显然，AI编码智能体能处理的任务时长不仅在指数级增长——其增速还在持续提升！

明年春天（2026年），很可能出现由「新一代多模态大模型」与「注意力机制之外的记忆系统」结合带来的突破。
现在，OpenAI等领军团队都在全力攻关持续学习和自我记忆技术；一旦他们取得突破，并将其应用在顶尖模型上，我们可能会不得不承认：AGI已经出现了！
各大实验室捂在手里的成果还有多少？如果都能让我们知道，恐怕所有人都会谈之色变。
