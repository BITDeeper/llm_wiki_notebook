近年来，视频生成技术发展迅速，但想要生成时间更长、画面更稳定、动作更连贯的视频，依然是一项挑战。尤其是在长视频场景中，模型往往会出现主体漂移、背景变化、动作不自然、画质下降等问题。
针对这一难题，论文
《Stream-T1: Test-Time Scaling for Streaming Video Generation》
提出了一种即插即用的面向流式视频生成的测试时扩展框架
Stream-T1
，该框架可无缝集成至现有任意流式视频生成模型，能够从语义一致性、时序稳定性及画面观感等多个维度，显著提升流式视频的生成质量。

为什么需要 Stream-T1？
传统的视频生成方法通常需要在训练阶段投入大量数据和算力，通过扩大模型规模来提升生成效果。但这种方式成本高、周期长，并不总是可行。
测试时扩展则提供了另一条路径：不重新训练模型，而是在推理生成阶段投入更多计算，通过候选探索、质量评估和动态筛选，提升最终视频质量。
现有测试时扩展方法基于扩散模型，直接对整段视频同时进行去噪和搜索，搜索空间大、计算成本高，而且难以对视频时间轴进行精细化的动态修正。
Stream-T1 的核心思路是：
将测试时扩展与流式视频生成结合起来，让模型一段一段地生成视频，并在每一段生成过程中主动优化。
方法亮点：三步提升长视频生成质量
现有的自回归视频生成（实时视频生成）方案，尚未充分探索在推理阶段如何通过加强“当前要生成的 chunk”与“已生成的历史 chunk”之间的关联，来主动提升视频质量。Stream-T1 围绕流式视频生成的特点，设计了三个关键模块。
其中，Stream-Scaled Noise Propagation和Stream-Scaled Reward Pruning作为“即插即用”的轻量化设计，几乎不增加额外的推理时间成本。
Stream-T1逐chunk scaling框架图
1. Stream-Scaled Noise Propagation
把当前chunk的噪声与历史chunk的噪声主动关联，让生成探索空间锚定在已经验证为高质量的轨迹上，确保时序的平滑过渡。
在生成新的视频片段前，Stream-T1 不再完全随机初始化，而是参考前面已经生成且质量较高的视频片段信息，为当前片段提供更稳定的起点。这样可以帮助相邻片段之间保持更自然的衔接，减少画面突变和运动断裂，让视频整体更加连贯。
2. Stream-Scaled Reward Pruning
结合即时短期评估与基于滑动窗口的长期评估，在局部画面美感与全局时序一致性之间取得平衡。
每生成一个视频片段，系统会同时产生多个候选结果，并对它们进行综合评估。评估不仅关注单帧画面的清晰度和美观度，也关注一段时间内的视频连贯性、动作合理性和文本匹配度。随后，系统会保留表现更好的候选，舍弃质量较差的分支。这使得生成过程不再是“盲目往前走”，而是在每一步都进行质量把关。
3. Stream-Scaled Memory Sinking
根据语义边界检测，把已生成视频中重要且独特的内容沉淀为长期记忆，重复内容融合进已有记忆，不重要内容直接丢弃，让历史信息真正参与到后续生成中。
长视频生成需要记住前面发生过什么，但如果简单保留所有历史信息，会带来巨大的计算负担；如果粗暴丢弃历史，又容易导致主体变化和场景漂移。Stream-T1 通过奖励反馈动态决定哪些历史信息应该丢弃、压缩保存，或者作为新的长期记忆锚点保留下来。这种方式既能维持短期动作连续性，也能保持长期语义一致性。
性能评估：短视频和长视频均表现突出
论文在 5 秒和 30 秒视频生成任务上进行了系统评估，并与 CausVid、Self-forcing、LongLive 等代表性方法进行了比较。实验结果显示，Stream-T1 在多个关键指标上取得领先。

消融实验：各组件缺一不可
消融实验数据表明：
去掉 Stream-Scaled Memory Sinking 后，视频的背景稳定性明显退化，虽然局部图像质量略有提高，但主体一致性和背景一致性大幅受损。
去掉 Stream-Scaled Noise Propagation 后，生成过程会引入局部结构伪影（如动物肢体的畸变），各项指标呈现整体性下滑。
去掉 Stream-Scaled Reward Pruning 则极易造成语义偏离或动作僵硬。
总结
Stream-T1 将测试时扩展引入流式视频生成，通过三个模块，让视频生成过程更加可控、稳定和高效。
它有效提升了长视频中的时间一致性、动作流畅性和画面质量，为高质量长视频生成探索了一条值得关注的新路径。
