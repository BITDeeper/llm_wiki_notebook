在计算机视觉领域，从单张图片中恢复出精确的人体3D网格（Human Mesh Recovery, HMR）一直是个极具挑战的课题。虽然我们已经有了像 SMPL 这样经典的参数化模型，但在面对“野外”环境下的极端姿态、严重遮挡或者罕见视角时，现有的模型往往显得有些力不从心。
近日，Meta超级智能实验室（Meta Superintelligence Labs）的研究团队发布了一项重磅研究：
SAM 3D Body
（简称
3DB
）。该模型被命名为“SAM 3D Body”，显然是借鉴了 Meta 著名的“Segment Anything”家族的交互思想，它不仅能自动完成人体恢复，还支持通过 2D 关键点或掩码（Mask）等视觉提示来引导推理。同时，作者还引入了一种名为“
Momentum Human Rig
”（简称
MHR
）的新型人体网格表征，意在强调其在处理人体运动和形态时的灵活性与控制力，通过解耦骨骼和形状，让 3D 人体恢复变得像“分割万物”一样精准且可控。

为什么我们需要 SAM 3D Body？
在人体网格恢复（Human Mesh Recovery, HMR）领域，过去的研究大多面临两个瓶颈。首先是
数据问题
：高质量的 3D 标注非常昂贵，现有的数据集要么是在实验室环境下采集的，多样性不足；要么是利用单目拟合生成的“伪标签”，质量参差不齐。
其次是
架构问题
：现有的模型很难在统一的框架下同时兼顾身体的大轮廓和手部、脚部的精细动作。通常，全身模型在手部精度上会被“手部专用模型”甩开一大截。为了解决这些痛点，SAM 3D Body 从模型架构、表征模型和数据引擎三个维度进行了全方位的革新。

核心架构：像 SAM 一样可提示
3DB 采用了类似 SAM 的可提示编码器-解码器架构。它的核心逻辑非常清晰：输入一张人体裁剪图，通过视觉骨干网络提取特征，然后由解码器输出 3D 参数。
图2展示了SAM 3D Body的模型架构，包含共享的编码器和独立的身体/手部解码器
输入与输出流程
输入（Input）
：模型接收人体裁剪图像
。此外，它支持可选的“提示词”输入。这些提示词可以是 2D 关键点
（由用户点击或检测器生成），也可以是分割掩码
。如果是为了增强手部细节，还可以输入手部裁剪图
。
特征编码
：图像通过 Image Encoder 提取特征图
。提示词则通过 Prompt Encoder 转换为 Token。
解码推理
：模型设计了四个查询 Token（Query Tokens）：MHR+Camera Token、2D 关键点 Prompt Token、辅助 2D/3D 关键点 Token 以及手部位置 Token。这些 Token 与图像特征进行 Cross-Attention，最终由 Body Decoder 和 Hand Decoder 分别输出。
输出（Output）
：模型最终回归出 MHR 参数
，分别代表姿态（Pose）、形状（Shape）、相机位姿（Camera）和骨架结构（Skeleton）。
这种“双解码器”设计巧妙地避开了身体和手部在输入分辨率、相机估计上的冲突。在推理时，模型可以利用手部解码器的高精度预测作为“提示”，反过来引导身体解码器生成更加严丝合缝的全身网格。
Momentum Human Rig：解耦的力量
长期以来，SMPL 模型是 HMR 领域的标准。但 SMPL 有一个局限：它将骨架结构和软组织形状耦合在形状空间中，这导致参数的解释性较差，比如你很难通过调整参数来精准改变某个骨骼的长度而不影响体型。
Meta 提出的
MHR
表征解决了这个问题。它显式地将
骨架姿态
和
身体形状
解耦。这种设计不仅让模型更容易学习解剖学约束，还赋予了它更强的控制力。在标注阶段，这种解耦特性也让多视角拟合变得更加精准，能够捕捉到更细腻的肌肉形变和骨骼动作。

700万数据的“数据引擎”
性能的飞跃离不开海量数据的支撑。研究团队构建了一个包含
700万
张图像的大规模数据集，这在 HMR 领域是前所未有的规模。
多样性挖掘与 VLM 驱动
他们并没有盲目堆砌数据，而是利用视觉语言模型（Vision-Language Model, VLM）设计了一个智能数据引擎。这个引擎专门去挖掘那些“难啃”的样本，比如：
极端姿态
：杂技、舞蹈、瑜伽等罕见动作。
严重遮挡
：人体被物体或其他人员部分遮挡。
特殊视角
：俯拍、仰拍等非水平视角。
多阶段标注流水线
为了保证 700 万数据的质量，标注流程也要硬核：结合了人工 2D 关键点修正、595 个密集关键点检测以及多视角几何约束。在多视角视频中，通过时空平滑损失
确保了 3D 拟合的一致性。

强悍的泛化能力
更令人印象深刻的是它的泛化表现。在“留一法”（Leave-one-out）实验中，即模型从未见过某个特定领域的数据（如 Ego-Exo4D 或 Goliath），3DB 依然能大幅领先于之前的
SOTA
模型（如 CameraHMR 和 PromptHMR）。这说明 3DB 学到的是真正的人体物理结构，而非简单的背景过拟合。

一点思考
SAM 3D Body 的出现，标志着人体网格恢复从“纯自动推理”向“交互式引导”迈出了重要一步。通过引入解耦的 MHR 表征和强大的数据引擎，Meta 成功地将 HMR 的鲁棒性提升到了一个新的高度。
目前，该项目已经完全开源，包含了推理代码和预训练权重。Meta 这次不仅开源了模型，还开放了高效的标注思路。这种“模型+数据+表征”全方位创新的路径，或许正是未来视觉大模型发展的标准范式。对于开发者来说，这意味着我们可以更方便地在机器人导航、生物力学分析或者虚拟现实应用中集成高质量的人体 3D 理解能力。
