随着多模态大模型（MLLMs）在图文理解、数学解题、几何推理等任务上取得长足进步，可验证奖励的强化学习（RLVR）已成为提升其视觉推理能力的主流范式。然而，现有 RLVR 方法主要围绕最终答案的对错进行优化，忽视了视觉推理过程中“看图—思考—再看图—再推理”所必需的细粒度跨模态协调，导致模型在生成思维链时频繁出现视觉幻觉与逻辑断裂。
为此，来自 北京智源研究院、特伦托大学、新加坡管理大学等机构的研究者们联合提出
DyCo-RL
（Dynamic Cross-Modal Coordination Reinforcement Learning）——一个
面向视觉推理的动态跨模态协调强化学习框架
。DyCo-RL 在推理过程重新刻画了注意力的“模态内重构”，在 token 级别为每个生成步骤分配“视觉型”或“文本型”功能角色，再以角色—注意力对齐分数对优势函数进行精细化重加权，使得模型在生成过程中能够
动态地在“看图”与“思考”之间灵活切换
。
实验结果表明，DyCo-RL能够稳定提升GRPO、DAPO、SAPO和GSPO等主流RLVR算法，在7个视觉推理与数学推理基准上均取得一致增益。未来，DyCo-RL 有望在几何推理、文档问答、科学图表理解、低空遥感推理等需要多步视觉—文本协同的应用场景中展现出广泛的价值。

背景介绍
图一 模型在视觉推理过程中无法动态地关注不同模态
视觉推理是动态的“看/想”交替过程
视觉推理要求模型在生成思维链的过程中不断在“从图像中提取证据”与“依托已有文本上下文进行推理”之间切换。如图一，当这种token级别的跨模态关注切换失败时，模型会在该关注图片的token上出现幻觉（把图中∠ADE 误读为 80°），同时也在该进行逻辑推导的token上犯下与上文推理相矛盾的错误（无端断言 ∠CED = ∠ADE），最终导致答案出错。
现有 RLVR 方法忽略了 token 级跨模态协调
GRPO、DAPO、GSPO、SAPO 等主流 RLVR 算法将一个序列级优势均匀广播到每个 token，对“需要看图”的视觉型 token 与“需要回看文本”的文本型 token 给出相同的学习信号；另一些工作虽然加强了视觉感知，却将视觉与文本视为静态偏置，无法刻画思维链中动态变化的功能角色，从而留下了关键的优化盲区。
原因诊断
图二 视觉推理失效来源于token无法正确地动态切换视觉文本模态关注
研究者在 MathVerse 与 MathVision 的 200 个错误样本上，对每个 token 标注“视觉型 / 文本型”和“获取正确/错误的模态信息”。
通过token级注意力追踪，研究者正确的视觉型 token 对图像的注意力显著高于错误样本，正确的文本型token 对前文上下文的注意力同样显著更高。同时，进一步的因果干预实验表明：对错误的视觉型与文本型 token，按其功能角色放大对应模态的注意力权重，可以“纠正”原本错误的样本。从相关性到因果性验证了跨模态注意力的错配是推理失败的重要诱因。
方法介绍
图三 DyCo-RL 方法流程
1. 基于 Fisher–Rao 距离的 Token 角色分配（Token Role Assignment）
为此，DyCo-RL首先设计了基于注意力动态变化的 Token 角色分配机制。其核心思想是：当模型真正从某一模态中获取新信息时，该模态内部的注意力分布往往会发生明显重构；反之，如果模型只是沿着已有思路继续推导，则对应模态的注意力结构变化较小。
具体而言，研究者首先对视觉模态和文本模态内部的注意力分布进行归一化处理，并利用 Fisher–Rao 测地距离衡量相邻生成步骤之间注意力结构的变化程度。随后，模型比较视觉模态与文本模态对应的结构变化强度。当视觉模态变化更显著时，该 token 被判定为视觉型 Token；反之则被判定为文本型 Token。

通过这种方式，模型能够自动识别当前token角色，以及他们究竟是应该看图还是应该思考。这一过程为后续的跨模态协调优化提供了重要基础。
2. 对齐引导的优势重加权（Alignment-Guided Advantage Reweighting）
得到不同token的不同角色后，对于每个 token，模型首先计算其当前实际注意力分配与角色需求之间的匹配程度：对于视觉型 Token，其理想状态应更多关注图像区域；对于文本型 Token，其理想状态应更多关注历史推理上下文。 为此，DyCo-RL计算了相对归一化的模态注意力得分，用于量化 token 对目标模态的关注程度。
式三 对齐得分计算
随后，该对齐得分被用于动态调整强化学习中的优势项。当 token 的实际关注模态与其功能角色高度一致时，其对应优势值将被放大，从而强化正确的跨模态行为；反之，如果 token 出现“该看图时不看图”、“该推理时不推理”等失配现象，其学习信号则会被抑制。重加权后的优势被无缝集成到标准策略梯度目标之中
式四 优势重加权
值得一提的是，DyCo-RL 仅替换 RLVR 目标函数中的优势项，不引入额外可训练参数，可作为即插即用插件直接接入 GRPO、DAPO、GSPO、SAPO 等多种主流算法。
实验结果与分析
实验设置：覆盖两类场景、四种算法、两种规模
训练数据与模型：以 ThinkLite-hard-11K 为训练集，将 DyCo-RL 分别应用于 Qwen2.5-VL-3B 与 Qwen2.5-VL-7B 两种规模的多模态模型基座。
评测基准：覆盖 7 个公开 benchmark，包含 数学推理（WeMath、MathVision、MathVerse）与 视觉中心推理（LogicVista、HallusionBench、MME、MMBench）两大类任务。
对比对象：在 GRPO、DAPO、GSPO、SAPO 四种代表性 RLVR 算法之上分别应用 DyCo-RL。
实验结果
表一 DyCo-RL 在四种 RLVR 算法、两种模型规模上的主要结果
研究者们在七个公开评测基准上对 DyCo-RL 进行了全面评估，主要得出了以下发现：
1. DyCo-RL 在 GRPO、DAPO、GSPO、SAPO 之上均带来一致且相对稳定的提升；
2. 模型在视觉中心任务（如 HallusionBench、MMBench）上加强视觉感知能力的同时，在数学推理任务（如 MathVision、MathVerse）上保持并强化思维链的逻辑连贯性；
3. 在更强的 7B 基座上依旧带来明显增益，表明更大的模型同样存在跨模态协调失效问题，同时DyCo-RL具有可拓展性 。
消融实验进一步表明：将 Fisher–Rao 距离换成 Random / Reverse / Entropy / KL 等替代方案均会带来明显损失，印证了方法设计的可靠性；若把对齐分数固定为单一模态（仅视觉或仅文本），则会出现明显的此消彼长，说明真正起作用的不是“固定偏向某个模态”，而是“动态切换模态关注”。
