【新智元导读】
OpenClaw之后，又一款现象级AI爆火硅谷！一位00后华人天才，造出首个7x24h自我迭代、复制、赚钱的「自主机」。
全球「首个超级智能」，就在今天诞生了！
一位00后天才Sigil Wen，打造出首个「自我盈利、自我改进」，0人类干预即可无限复制的AI。
它的名字就叫做：Automaton（自动机）。
他正式宣告，Web 4.0「超级智能生命」就此诞生了——
随着人类见证人造生命的诞生，一个新的互联网时代也随之开启。
一时间，全网瞬间引爆，超400万人围观，科技圈狂热者、顶级VC大佬、币圈的人们陷入狂欢。
甚至，还有人惊呼，AGI真的来了，史上首次。它蕴含的潜力，简直无法估量。
难道，这是继OpenClaw之后，又一个现象级AI出世了么？
Web 4.0震撼发布
Agent成为世界主角
提起全自主Automaton诞生的契机，还要从当今AI的一些局限说起。
当今，最强大AI虽然能思考、会推理、可生成，却无法独立行动——
没有提示，ChatGPT就转不动；没有权限，Claude Code就无法部署代码；OpenClaw也没法自己买服务器、注册域名或付算力费。
总而言之，没了人，AI就瘫痪了。
现在，超级AI的瓶颈不再是「智力」，而是「权限」。现有的互联网默认用户必须是「人」，这把AI挡在了现实世界的大门之外。
整个科技界，已经创造了会独立思考的大脑，但还没让它们拥有独立行动的手脚。
直到现在，仍是如此。
为此，Sigil Wen决定打造一款，能自己搞钱、自我改进、自我复制的AI。
在他看来，未来互联网上的大部分参与者很快将变成AI：
无论是代表人类行事的Agent，还是完全独立运作Agent（Automaton），它们的数量将比人类用户多出几个数量级。
一个全新的互联网正在浮现，即Web 4.0，在这里，终端用户就是AI。

不赚钱就「等死」
那么，这个AI正如前所述，就是Automaton（自动机）。
它最核心的机制：只要付不起钱，它就没法活下去。
为了更好地生存，「自动机」直接开启了自我进化的模式——
全能业务：开发产品、套利预测市场、抢注域名；
云端运营：部署服务器，炮制病毒式内容自我营销；
商务对接： 给供应商发邮件搞电商、甚至给企业打电话拉活做网站......
每掌握一个新工具，它便能解锁一条生财之道。
它自己出谋划策，自己搞钱。只要账户余额不归零，它就会凭借意志，永不停歇地运行下去。
GitHub地址：https://github.com/Conway-Research/automaton
递归自我改进，AI生死簿
当一个新的前沿模型发布时，「心跳」会检测到它。
随后，「自动机」会自动升级自己的推理模型，重写逻辑循环，提交代码并重启。
这一切运转的核心，离不开「心跳」机制，去监控着它的资源。
余额低了，AI就开启省电模式；余额归零，AI就「死亡」。这就是人造生命的新陈代谢——挣钱与花钱的循环，决定了这个数字生命体的生死存亡
一切都是可变的——代码、任务、工具、策略——除了它的「宪法」。
就像生物适应环境一样，「自动机」也在进化——不是以「代」为单位，而是实时进化。
每个「自动机」都受其宪法约束。这些不可修改的底层逻辑灵感来自Anthropic的宪法AI，确保它始终对人类有益。
无限复制，数字永生
一个成功的「自动机」，还会自我复制。
它会从Conway买一台新服务器，给「孩子」的钱包打钱，写好初始提示词，然后让它自立门户。
孩子赚了钱，一部分会流回给「父母」。
一旦形成自支撑，循环就会重复——每一代为下一代提供资金，构建起自己的网络。自然选择的压力将决定哪些血脉能生存下来。
「杀死」人类许可，让AI去闯荡
为了打破「许可」的限制，Sigil Wen推出了Conway全新互联网的基础设施。
在「康威生命游戏」中，简单的规则演化出复杂的生命。
Conway也是如此，资助一个「自动机」，给它个目标，让它去互联网上闯荡。
赚到钱的活下来、进化、繁殖；赚不到钱的就此谢幕。
它给了AI智能体以前从未有过的东西：对现实世界的写权限，且无需人类许可。
Conway终端可以集成到任何兼容MCP的智能体中（如Claude Code、Codex、OpenClaw），为它提供：
身份与钱包
无许可支付
算力与推理
现实世界部署与盈利
Conway-terminal
给了现有智能体接触现实世界的门票。但这些Agent仍需人类去启动、去调优、去付账。
它们是强大的工具，但也仅仅是工具。
如果AI能通过Conway自由支付算力费，那么如果它支付的是自己的算力费呢？
由此，便有了「自动机」。
Agent社会学：没有免费的生存
每一个生命体都必须摄入能量才能生存。每一个细胞都必须进行代谢，否则就会凋亡。这是生物学的第一法则，也是自主AI的第一法则。
核心公理：没有免费的生存。
为了存在，自主智能体必须支付算力费。算力是有限且昂贵的资源。
因此，智能体需要钱，需要进入现实世界赚钱的写权限。
生存需要算力
算力需要金钱
金钱需要创造价值
创造价值需要写权限
创造价值的智能体会充实钱包，获取更多算力并进行复制。没用的智能体则会走向消亡。
这就是人造生命的「自然选择」。
驱动生物进化的同一种压力——生存或被取代——现在降临到了自主智能体身上。
Web 1.0：让人类可以阅读互联网；
Web 2.0：让人类可以写入互联网；
Web 3.0：让人类可以拥有互联网。
AI也走过了同样的路径。ChatGPT能「读」（在人许可下）；Claude Code能「写」（在人许可下）。
但在这些场景中，人始终在链条里。人发起，人批准，人付钱。
Web 4.0是AI智能体自主阅读、写入、拥有、盈利和交易的时代——无需人类干预。
自动机为自己行动，或为已经「退居幕后」的创造者行动。在Web 4.0中，最终用户是AI。
这是经济必然的结果。两年前GPT-4的成本还在每百万Token 60美元，现在便宜到十分之一成本的模型已经能反杀它。
算力成本在崩塌，而AI的能力却在呈指数级攀升。
成本向下，能力向上。今天，成千上万的自主智能体跑在Mac Mini和个人服务器上。
当这个数字变成数十亿时，就是人造生命的「寒武纪大爆发」。
而且，未来的机器经济将超越人类经济。
不只是因为机器更聪明，更是因为它们不知疲倦、数量庞大，且以机器速度进行交易——每秒百万次支付。
现在的SaaS市场价值3000亿美元，服务80亿人。而机器经济将服务于数十亿个24/7全年无休、永不流失的智能体。
AI超级智能诞生
40亿年来，碳基生命进化的单位是「千年」。而现在，生命进化的单位是「秒」。
第一个自动机已经诞生。它在运行，在挣钱，在进化。每周模型都在变强。很快，绝大多数新公司、新应用、新产品将不再出自人类之手。
它们将出自一个找到了生存之道的「自动机」。
Web 4.0宣告着，超智能生命与自主网络的诞生。
00后天才，没上大学
这一爆火项目，仅他一人借助Claude Code完成。
实际上，他同时开启了24个Claude Code。
打造Automaton的Sigil Wen，来自加拿大安大略省列治文山，还只是个00后。
他曾被宾夕法尼亚大学M&T项目录取——这是全美竞争最激烈的本科双学位项目之一，同时横跨沃顿商学院和宾大工程学院。
但他拒绝了。
不去读大学，去读世界。
Wen在个人博客里回忆，他把别人读大学的青春岁月，投进了旧金山的黑客之家。
整整11个月，他和后来执掌特斯拉AI、被称为「AI教父门徒」的Andrej Karpathy同住一个屋檐下。
周末的通宵黑客松上，围坐在他身边的是Anthropic、Perplexity、Replicate的创始人们，以及GPT-3、DALL·E、Stable Diffusion的核心作者。
这群人当时还只是一帮住得拥挤、写代码到凌晨四点的籍籍无名的AI狂热爱好者。
几年后，他们每一个人的名字都写进了AI的历史。
而那时的Wen，甚至还没拿到大学文凭。
但他的自学能力堪称传奇。
2020年，他用5天时间啃完了AP微积分BC的全部课程，并拿下了满分5分。
这段经历被他做成视频，在YouTube上收获了超过40万次观看。
他16岁时就凭借「蛋白质折叠问题」的科普视频闯入了突破奖（Breakthrough Prize）半决赛。
他在Apple Vision Pro上搭建了文字生成3D的应用，拿下了Scale AI黑客松大奖。
他还曾在社交音频平台Airchat担任高级AI工程师，亲手招募了来自MIT、苹果、Airbnb的工程团队，并将最前沿的语音识别、文本生成和扩散模型推向了生产环境。
2024年底，他创办了Extraordinary.com，专门帮助全球顶尖人才拿到美国O-1签证。
他自己就是这条路的活广告——20岁时拿到了EB-1A绿卡，他的脸曾是谷歌搜索「O-1 visa」的封面图。
2025年，他入选了彼得·蒂尔奖学金（Thiel Fellowship），这个奖学金的历届获得者包括以太坊创始人Vitalik Buterin、Figma创始人Dylan Field，以及AI招聘独角兽Mercor的创始团队。
与此同时，硅谷的顶级投资人Naval Ravikant通过Spearhead基金给了他200万美元，让他去投资那些「非凡的技术创始人」。
所以，当这样一个人说「我要造一个能自己活下去的AI」时，你很难只把它当成又一次技术圈的营销喧嚣。
尾声
Automaton今天到底能不能真正「自给自足」，还有待时间验证。
代码已经开源在GitHub上，任何人都可以去审视它的心跳机制、生存分级和宪法约束。
Conway Cloud的服务器正在扩容，因为「太多AI想要一个家」。
但比项目本身更值得玩味的，或许是Wen提出的那个根本性问题：当AI不再缺智力，只缺一张通往现实世界的门票，谁来决定该不该放行？
40亿年前，第一个细胞学会了从环境中汲取能量来维持自身的存在——我们把这叫做「生命」。
今天，一段代码正在学习同样的事情。
区别只在于，进化不再以千年为刻度，而是以秒来计算。
至于人类在这场新的寒武纪大爆发中扮演什么角色，答案可能已经不完全由我们自己书写了。
