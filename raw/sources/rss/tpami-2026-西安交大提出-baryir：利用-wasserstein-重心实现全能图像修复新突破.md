在计算机视觉领域，图像修复（Image Restoration）一直是个基石话题。无论是去噪、去雨还是去雾，我们通常希望一个模型就能搞定所有问题，这就是所谓的“全能型”（All-in-One）图像修复。然而，现有的模型往往在训练过的退化类型上表现神勇，一旦遇到没见过的退化（比如从未训练过的水下模糊或特殊的 JPEG 压缩），效果往往大打折扣。
最近，来自西安交通大学的研究团队在顶级期刊 IEEE TPAMI 2026 上发表了一项非常有启发性的研究。他们提出了一个名为
BaryIR
的框架。这个名字的由来非常直观：
Bary
取自
Barycenter
（重心），意指在概率分布空间寻找几何中心；而
IR
则是
Image Restoration
（图像修复）的缩写。作者的核心直觉：虽然雨、雾、噪声看起来千差万别，但它们其实都是在同一张清晰图像的基础上，叠加了不同的“退化偏移”。如果能找到这些不同退化特征的“几何重心”，不就能抓到那个与退化无关的、最本质的图像特征了吗？

背景与动机：寻找退化中的“不变量”
在全能图像修复（All-in-One Image Restoration, AIR）任务中，最难的不是处理已知的退化，而是如何让模型具备泛化能力。很多现有的方法通过加入“提示词”（Prompts）或者特定的专家模块来区分不同的退化，但这往往会导致模型过拟合在训练集的那几种退化里，缺乏对分布外（Out-of-Distribution, OOD）退化的处理能力。
西安交通大学的研究者们换了个思路。他们认为，多源退化图像的特征分布，其实可以看作是从一个底层的“退化无关分布”出发，经过不同的特定偏移诱导出来的。因此，修复的关键就在于恢复这个共享的分布。
为了实现这一点，BaryIR 引入了数学中的
Wasserstein 重心（Wasserstein Barycenter, WB）
概念。简单来说，WB 就是在一组概率分布中，寻找一个到所有分布的平均最优传输（Optimal Transport, OT）距离最小的“中心分布”。在 BaryIR 中，这个重心空间负责捕获那些跨越不同退化的不变内容，而剩下的差异则交给“残差子空间”来处理。
BaryIR 的核心理念：将潜在空间解耦为重心空间和残差空间，增强对未见数据的泛化能力。

实验结果：强悍的泛化性能
研究团队在多个基准数据集上进行了详尽的测试，包括 SOTS（去雾）、Rain100L（去雨）、BSD68（去噪）、GoPro（去模糊）和 LOL（低光增强）。
1. 全能修复的 SOTA 表现
在涵盖 5 种退化的全能修复任务中，BaryIR 展现了统治级的性能。以 PromptIR 作为主干网络时，BaryIR 在平均 PSNR 上达到了
31.05 dB
，相较于原始 PromptIR 提升了
1.33 dB
。即使与最近的强力对手如 MoCE-IR（30.25 dB）和 DA-RCOT（30.40 dB）相比，优势依然非常明显。

深度洞察：重心空间里藏着什么？
为了探究模型到底学到了什么，作者使用了 t-SNE 对特征进行了可视化。结果非常有说服力：无论输入是哪种退化，经过映射后的 WB 嵌入（WB embeddings）在特征空间中都高度重合，表现出极强的退化无关性；而残差嵌入则根据退化类型（雨、雾、噪）形成了清晰的簇。
t-SNE 可视化：左侧 WB 嵌入紧密聚集，右侧残差嵌入按退化类型分离。即便对于未见的退化（如模糊和低光），这种解耦特性依然稳健。
在推理阶段，通过特征消融实验可以发现：WB 嵌入主要负责恢复图像的全局结构和内容（如物体的轮廓、大面积的色块），而残差嵌入则精准地定位受退化影响严重的局部区域，负责修补高频纹理和边缘细节。
推理阶段 WB 与残差嵌入的贡献可视化：WB 负责结构，残差负责退化相关的细节修复。
写在最后
BaryIR 的成功，很大程度上归功于它从几何角度对多源数据分布的深刻洞察。通过引入 Wasserstein 重心，它不仅在性能上刷写了榜单，更重要的是，它为解决底层视觉任务中的泛化难题提供了一个极具启发性的数学框架。
目前，作者已经将代码在 GitHub 开源。根据论文描述，模型在单张 NVIDIA 4090 GPU 上即可高效训练，推理速度也非常快（256x256 图像仅需约 0.16s）。对于想要在实际业务中部署全能图像修复模型的开发者来说，BaryIR 是一个非常扎实且高效的基准方案。
当然，研究也并非完美。作者在文中诚实地指出，在面对极端的真实世界混合退化（如特大暴雨叠加浓雾）时，模型偶尔会因为残差空间对局部异常值不够敏感而产生细微残留。所以这一框架值得继续研究优化。
