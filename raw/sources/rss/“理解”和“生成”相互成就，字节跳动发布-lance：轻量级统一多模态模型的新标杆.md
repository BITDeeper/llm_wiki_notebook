在多模态 AI 的演进路线上，我们正目睹从“拼接式”向“原生统一”的范式转移。过去，理解模型（如 LLaVA）和生成模型（如 Stable Diffusion）往往各行其道，前者追求语义抽象，后者痴迷于纹理细节。如何在一个模型里既能“读懂”复杂的视频逻辑，又能“画出”高保真的动态画面，一直是业界的难点。
近日，来自字节跳动智能创作实验室的研究团队推出了一个名为
Lance
的原生统一多模态模型。Lance 仅凭 30 亿（3B）激活参数，就在视频理解与生成两项核心榜单上双双登顶，展现了极高的资源效率。

背景与动机：鱼和熊掌如何兼得？
在统一多模态建模中，开发者常面临一个尴尬的“表征冲突”：理解任务需要高度对齐语言的语义特征，而生成任务则依赖能够保留几何、纹理和时空动态的连续潜空间表征。
现有的方案要么强行统一表征，导致理解和生成互相“打架”；要么采用解耦表征，却增加了架构的复杂度。此外，很多模型仅局限于图文领域，在视频这种对时空一致性要求极高的模态上表现乏力。Lance 的出现，正是为了探索一种既能保留统一上下文学习，又能实现能力路径解耦的实用范式。

1. 双专家混合架构 (Dual-expert MoE)
Lance 的整体架构如下图所示。它并没有让所有参数处理所有任务，而是设计了一个“双专家”结构：
理解专家 (
)
：主要处理文本和来自 ViT 的语义视觉 Token，负责语义推理和文本生成。
生成专家 (
)
：处理来自 VAE 的连续潜变量 Token，负责视觉合成和编辑。
这两个专家共享同一个交错的多模态上下文序列，但在执行具体任务时，通过不同的路径进行计算。理解任务采用标准的
自回归（Autoregressive）
预测，而生成任务则采用高效的
流匹配（Flow Matching）
技术。

2. 模态感知旋转位置编码 (MaPE)
在统一序列中，同时存在着语义 Token、干净的 VAE 条件 Token 和加噪的 VAE 目标 Token。如果只用传统的 3D-RoPE，模型很难分清这些功能各异的 Token 组。

3. 四阶段进阶训练
Lance 设计了四阶段训练策略：
预训练 (PT)
：在 1.5T tokens 的大规模图文/视频对上建立基础。
持续训练 (CT)
：引入交错数据，扩展至编辑、主体驱动生成等复杂任务。
有监督微调 (SFT)
：通过高质量数据精炼指令遵循能力。
强化学习 (RL)
：利用 GRPO 算法，专门优化图像生成的文本渲染准确度。

统一多模态模型希望产生一种“双赢”效应：
多任务协同并不是简单的能力叠加，而是一种相互促进的机制
。Lance的消融实验也证明，引入理解数据能反哺生成任务的语义对齐，而多任务生成的训练也能提升模型对视频的理解深度。
特别是，作为一个仅有 3B 激活参数的模型，在 128 张 GPU 的预算内就完成了训练。目前，该项目已经在 GitHub 上开源，推荐感兴趣的开发者尝试复现或基于此进行二次开发。
