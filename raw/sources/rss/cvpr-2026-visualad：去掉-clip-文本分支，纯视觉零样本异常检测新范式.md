在计算机视觉的落地应用中，异常检测（Anomaly Detection）一直是个“硬骨头”。无论是工业流水线上的微小划痕，还是医学影像中的早期病变，通常都面临着样本极度不平衡的问题：正常的图像好找，但各种各样的异常样本却千奇百怪，难以收集。
为了解决这个问题，零样本异常检测（Zero-Shot Anomaly Detection, ZSAD）应运而生。近两年的主流做法是抱紧 CLIP 这类视觉-语言大模型（VLM）的大腿，通过“正常”和“异常”的文本提示词（Prompts）来引导模型识别。但你有没有想过，检测视觉上的缺陷，真的必须依赖文字描述吗？
来自安徽大学和国防科技大学的研究团队最近给出了否定的答案。他们提出了一种名为

背景与动机：文本分支真的是必须的吗？
目前的零样本异常检测方法，如经典的 AnomalyCLIP，核心逻辑是利用 CLIP 的文本编码器生成“正常”和“异常”的特征向量（Prototypes），然后将其与图像特征进行对比。
但研究团队在复现时发现了一个有趣的现象：如果我们直接扔掉文本编码器，转而直接学习两个代表“正常”和“异常”的视觉向量，效果竟然不降反升！
图 1 展示了初步研究的动机。对比 AnomalyCLIP，纯视觉变体性能更稳且精度更高。
如上图所示，纯视觉方案的评估曲线（Evaluation Curves）明显比带文本分支的方案更加平滑。这意味着，异常的本质属性——即纹理、形状或颜色的统计偏差，完全可以被纯视觉特征捕获。基于这一洞察，作者提出了
VisualAD
，旨在证明在视觉任务中，“去语言化”不仅能精简模型，还能提升泛化性能。

为了让这两个 Token 真正理解什么是“异常”，研究团队设计了两个关键模块：
空间感知交叉注意力（Spatial-Aware Cross-Attention, SCA）
：全局 Token 虽然能通过多层自注意力学到高层语义，但缺乏对具体空间位置的敏感度。SCA 模块通过引入
个可学习的锚点查询（Anchor Queries），将图像中局部的空间证据聚合到 Token 中。配合 Token 引导的门控机制（Gating Mechanism），Token 能够动态地根据当前图像内容调整其对异常特征的敏感度。
自对齐函数（Self-Alignment Function, SAF）
：由于 ViT 不同层的特征分布存在差异，SAF 作为一个轻量级的 MLP，用于在计算相似度之前重新校准每一层的 Patch 特征。它能确保 Patch 特征与不断演化的 Token 处在同一个对比空间里，从而实现稳定的跨层对齐。

通过 PCA 特征可视化（图 5），我们可以直观地看到

此外，SCA 模块的注意力图（图 6）也揭示了其跨层级协作机制：中间层（如 Layer 12）关注细粒度的缺陷边界，而深层（如 Layer 24）则关注整体的正常背景上下文。这种互补性保证了模型既能发现微小裂纹，又能准确排除复杂的背景干扰。

一点思考
VisualAD
反映了深度学习中一个朴素的真理：
Less is More
。在很多特定视觉任务中，我们可能并不需要复杂的跨模态对齐，过度依赖文本描述反而可能引入语言歧义或计算冗余。
通过将“异常”这个抽象概念直接具象化为视觉空间中的两个可学习 Token，
VisualAD
不仅简化了系统架构，还提升了鲁棒性。这种“纯视觉插件”式的设计为未来的零样本任务提供了一个新思路。
