陶哲轩+AI
再上大分！
科研人论文投稿的痛，被陶哲轩用
Claude Code
一招解决。
这事还得从几周前陶哲轩合作提交的一篇论文说起，谁能想到，即使是业界大神，也会被审稿人反复“折磨”……
但这一次，陶哲轩决定玩点不一样的。
他把审稿报告反手喂给了Claude Code，结果
15分钟
全搞定，甚至还捉虫了审稿人的错。
消息一出，网友纷纷神评论：
合理怀疑审稿人也在使用Claude Code。
（doge）
真·AI逻辑闭环了。
15分钟CC全搞定
回到这篇论文本身，其实在
第一次
收到审稿人反馈时，陶哲轩还在老老实实人工肝。
审稿人先是给了一份极为详细的审稿报告，其中包含大大小小各种建议，并零散分布在不同章节中。
于是陶哲轩拉上论文合作者，根据章节分布，各自负责一部分的论文修改，然后再借助GitHub合并所有修改项。
好在团队分工明确，几天时间就修改完成。
结果昨天，审稿人又
“死亡催更”第二轮回复
：基本满意，但……还有十几个小毛病。
而这些大多都还是错别字或LaTeX标签问题，问题倒不大，但不改不让发。
隔以前，陶哲轩可能就一个个对照着自己改了，但这次，他试着将反馈报告、LaTeX源文件和论文PDF一并喂给
Claude Code
，结果让人眼前一亮：
CC迅速识别出了审稿人提及的十二个问题，并对其中11个直接给出了终版修改方案，至于剩下的第12个，Claude也贴心地给予了两种可行建议。
有趣的是，CC在过程中还反将一军，
发现了审稿人自己写错的一个单词
。
全程陶哲轩只做了一件事，就是扫描审核AI的修改情况，以及二选一No.12的修改方案。
全程下来，只用了不到
15分钟
。
从好几天到15分钟，这效率蹭蹭涨，所以陶哲轩也不禁感叹：
重来一次，第一轮修改我就会用AI。
具体来说，他会
先用Agent通读一遍审稿意见
，然后找出所有可修正的细微问题，比如错别字，审查并实施修改。
再将那些真正需要研究员参与的实质性问题筛选出来，人为分工合作。简而言之，就是将例如语法上的脏活累活交给AI，而
人类专心解决难题
。
这也是陶哲轩一直所强调的，AI最合理的角色是成为数学家的“副驾驶”或助理，而不是取代人类在创造性、直觉性、策略性上的工作。
One More Thing
事实上，这已经不是陶哲轩第一次用AI提升效率了。
从2022年ChatGPT刚发布起，他就开始积极探索
AI辅助数学工作
的可能。
只不过彼时的ChatGPT还不能完全理解数学问题的本质，但随着时间的推移，现在的AI已初步具备数学家潜质。
在AI的帮助下，陶哲轩等数学家已陆续解决了多道困扰学界多年的难题，比如48小时通力合作Erdős
#1026
、GPT-5.2 Pro独立证明45年数论猜想。
Erdős官网也积极鼓励用户借助AI等工具辅助解题。
显然，
AI+人
正在逐渐成为数学界的新趋势。
而在这种趋势之下，陶哲轩也在努力探索AI的应用边界，从解决数学问题、形式化证明再到如今的修改论文，AI让发表数学成果变得更轻松。
