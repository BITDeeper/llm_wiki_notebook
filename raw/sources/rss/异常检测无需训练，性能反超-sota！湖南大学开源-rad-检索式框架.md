在工业质检、安全监控等领域，
多类别无监督异常检测（Multi-class Unsupervised Anomaly Detection, MUAD）
一直是个极具挑战的课题。传统的做法通常是训练一个复杂的编码器-解码器模型，试图重建正常样本的特征。但你有没有想过，这种费时费力的“训练”过程，真的是必须的吗？
最近，来自
湖南大学
和
英国格拉斯哥大学
的研究团队在一篇论文中发出了灵魂拷问：
Is Training Necessary for Anomaly Detection?
。他们提出了一种名为
RAD（Retrieval-based Anomaly Detection，基于检索的异常检测）
的框架。令人惊讶的是，这个
完全无需训练
的方法，在 MVTec-AD、VisA 等四大主流数据集上的表现，竟然全面超越了那些经过复杂训练的 SOTA 模型。
论文题目
：Is Training Necessary for Anomaly Detection?
作者机构
：湖南大学（第一作者本科生张行吾，通讯作者龙子俊），英国格拉斯哥大学
论文地址
：https://arxiv.org/abs/2601.22763
代码仓库
：https://github.com/longkukuhi/RAD（已开源）
为什么我们要放弃“训练”？
在聊 RAD 之前，我们得先看看传统方法的“苦衷”。目前主流的 MUAD 方法大多依赖于重建残差：冻结一个预训练编码器，训练一个轻量级解码器来重建特征，最后通过计算原始特征与重建特征的差异来识别异常。
但研究团队首次指出，这种模式存在一个根源性的
忠实度-稳定性困境（Fidelity-Stability Dilemma）
。
理论推导：解码器的“放大器”效应
为了防止模型学会简单的“恒等映射”（即直接复制输入），研究者通常会在架构中加入“信息瓶颈”。论文通过数学推导证明，如果要求解码器在高忠实度下重建正常特征，那么解码器的局部增益（雅可比矩阵的范数）必须非常大。
具体来说，若
是重建映射（
为解码器，
为瓶颈），论文证明了：
这意味着，当瓶颈
压缩信息越狠（
越小），解码器
就必须变成一个“高增益放大器”才能维持重建精度。这种放大效应会导致模型对细微的正常波动（如光照、位置偏移）极其敏感，从而产生大量误报。
RAD 的思路非常巧妙：既然训练难以平衡这个困境，那干脆
不训练了
，直接用预训练好的强大模型提取特征，存进“记忆库”里，用的时候直接“查表”。
RAD 框架详解：全局锁定，局部对比
RAD 的核心逻辑可以概括为：
“全局锁定，局部对比”
。它不需要学习任何参数，所有的“知识”都存储在一个多层特征存储库中。
1. 构建多层记忆库
RAD 利用冻结的编码器（如 DINOv3），提取正常样本在不同层级的特征。浅层特征关注细节（如划痕），深层特征关注语义（如结构缺失）。这些特征被存入
多层异常特征存储库（Multi-layer Anomaly-free Feature Memory Bank）
。
2. 全局上下文检索（粗筛）
输入待检测图像
后，RAD 首先提取其全局特征（
[CLS]
token），在存储库中检索出最相似的
张正常图片。这一步确保了后续对比是在“同类”之间进行，避免了语义误匹配。
3. 空间约束的块级检索（精查）
这是 RAD 最精妙的设计。在选定的
张参考图中，RAD 对测试图的每个小块（Patch）进行检索：
空间先验
：它限制检索范围在参考图相同位置的邻域
内。
异常评分
：计算测试块与检索到的最近邻特征之间的余弦不相似度。
最后，融合多个层级的评分，上采样生成最终的异常图。
性能表现：降维打击般的强大
RAD 的实验结果刷新了我们对“免训练”方法的认知。
1. 标准 MUAD 榜单
在最经典的
MVTec-AD
榜单上，RAD 在像素级指标上表现亮眼，在严苛的 Pixel AP 指标上达到了
75.6%
，显著超过了之前的强力模型 Dinomaly（69.3%）。在更复杂的
Real-IAD
数据集上，RAD 的 Pixel AP 领先优势更是扩大到了惊人的
10.9%
。
2. 少样本（Few-shot）场景
在每类仅提供 1/2/4 个正常样本的极度受限场景下，RAD 展现了恐怖的鲁棒性。在 1-shot 设置下，其 Pixel AUPRO 达到
91.9%
，远超专门针对少样本设计的 IIPAD（89.8%）。
3. 数据缩放实验（Data Scaling）
论文还探讨了在“冷启动”情况下，随着正常样本增加，性能的变化趋势。
单类缩放
：即使只有 5% 的数据，RAD 的图像级 AUROC 也能达到 97.1%。
增量类缩放
：当引入一个全新的类别（如 Transistor）时，RAD 仅需 2 个正常样本就能恢复 95.4% 的定位性能。
编码器质量的影响
作为一个完全依赖检索的方法，RAD 的性能上限取决于底层编码器的表征能力。研究人员对比了多种视觉基础模型：
对比学习类（DINOv3, DINOv2）
：表现最强，能够提供极具辨别力的特征。
掩码建模类（MAE, BEiT）
：虽然在分类任务上很强，但在异常定位上表现较弱。
分辨率提升
：将图像从 224 提升到 448 分辨率，RAD 的定位精度会有显著的统一提升。
写在最后
RAD 的出现让我们重新审视了“学习”与“记忆”的关系。在视觉基础模型已经足够强大的今天，或许我们不再需要让模型去费力地“学习”什么是正常，而只需要给它一个足够丰富的“记忆库”，并教会它如何精准地“查阅”。
这种从“模型参数化”向“数据非参数化”的转变，不仅解决了重建模型的理论困境，更为工业界提供了一种
免训练、易部署、可实时更新
的高效方案。
这种“以检索代训练”的范式，会不会成为未来工业视觉任务的新趋势呢？
