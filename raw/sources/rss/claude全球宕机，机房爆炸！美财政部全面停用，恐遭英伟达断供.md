【新智元导读】
Claude深夜宕机，全网哀嚎一片。就在今天，美财政部官宣：全面停用Claude。硅谷数百名CEO和大佬联名，掀起Anthropic保卫战。
心态彻底崩了！
就在刚刚，Claude全球宕机，瞬间引爆全网。
抵制ChatGPT转投Claude的运动迅速席卷全球，这波泼天富贵，让Anthropic因流量过载，陷入了「幸福的烦恼」。
如今，全球用户集体陷入了「断粮」危机。一大批网友纷纷表示，感觉大脑被强行关机。
此时此刻，全网一片哀嚎，离了Claude，瞬间退回了原始人的时代。
活儿干一半突然失去Claude的编辑，用ChatGPT搓了一波梗图
Claude全面宕机，这班儿上不下去了
报告显示，这场风暴最初从北京时间3月2日晚19点49分（UTC 11:49）开始酝酿。
当时，Claude.ai网页端、开发者控制台以及Claude Code工具率先亮起红灯，错误率急剧飙升。
一开始，工程师们以为这只是一次普通的服务器故障，排查重点仅限于用户的登录和登出路径。
然而没过多久，情况急转直下，部分API宣告沦陷。
「Claude宕机」瞬间刷屏全网。
紧接着，灾难蔓延到了大语言模型本身。
22点35分，核心模型Claude Opus 4.6突发大面积报错，团队被迫再次开启紧急修复。
期间系统状态几经反复，直到23点55分才彻底稳住阵脚。
还没等工程师们喘口气，另一款模型Claude Haiku 4.5紧接着在23点56分「无缝接棒」。
直到北京时间第二天凌晨5点16分，这场持续了近10个小时、波及平台与多款模型的「全线大罢工」才算真正画上句号。
算力老家被偷？AWS遭「不明物体」天降打击
究竟是什么导致了如此罕见的长时间、大规模崩溃？
路透社的一则突发报道，直接把整件事的画风从「技术故障」变成了「战争悬疑片」。
由于Anthropic的算力极度依赖亚马逊AWS，敏锐的网友很快将时间线对齐。
就在Claude开始大面积报错的40多分钟后（北京时间20:30左右），亚马逊AWS位于阿联酋的一处核心数据中心，突然被「不明物体」击中！
现场瞬间火花四溅、燃起大火，逼得消防部门直接拉闸断电。
根据AWS发布的战损通报：
太平洋标准时间凌晨4点30分左右，我们的一处可用区（代号mec1-az2）惨遭击中数据中心的物体波及，引发了火花和火情。
虽然AWS表示阿联酋的其他可用区还在坚挺，但这片重灾区想要重新「上线」恢复连接，至少需要好几个小时。
然而对于具体原因，AWS却打起了太极，既不承认也不否认，给整起事件蒙上了一层浓厚的悬疑色彩。
由于事发地位于中东，且当前该地区的地缘冲突正在持续加剧，AWS这种含糊其辞的公关话术，瞬间点燃了网友们的脑洞。
第一时间，推特上猜测四起：这分明就是因为
此前Claude参与了打击行动
，而进行的报复吧！
中东的基础设施挨了一发「不明物体」导致机房起火断电 → AWS算力池受到冲击 → 依赖这些算力节点的Claude模型失去支撑 → 导致了全球千万打工人无工可打的赛博大宕机。
不仅Claude，包括Gemini在内，许多网站和服务都受到了冲击
不得不说，这场极具戏剧性的意外，留下了一个黑色幽默般的隐喻：
平时在赛博空间里无所不能、算力通天的大模型，在真刀真枪的「物理打击」面前，竟然显得如此脆弱。
联邦政府全面停用Claude
「封禁Claude」按钮落下之后，第一块多米诺骨牌倒在了美国财政部。
一早，财政部长Scott Bessent正式官宣：全面关停Anthropic旗下所有的AI工具。
紧接着，美国联邦住房金融局（FHFA）、房利美和房地美，正全面停用Claude。
这一举动的火药味极浓。
就在上周，Anthropic和五角大楼「翻脸」，直接激怒了特朗普，随后封杀大锤落下。
也就意味着，Claude被列入了所有联邦政府的「黑名单」，禁止参与任何与政府相关的工作。
Bessent强硬表态，「美国人民应当确信，政府使用的每一项工具都在为公众利益服务」。
去年，通过总务管理局（GSA）的OneGov协议，Claude曾获准在联邦政府的「三大分支机构」中广泛使用。
尽管公开用例清单中没直接点名 Claude，但财政部内部不少员工深度依赖Claude Code跑项目。
硅谷CEO联名反击，逼宫五角大楼
如今，整个硅谷掀起了「保卫Anthropic」的运动。
上一周，OpenAI、谷歌两大巨头的600多名员工，并肩而立喊出：「我们绝不会被分裂」！
而现在，不仅仅是OpenAI、谷歌，整个硅谷的科技从业者联名，硬刚美国国防部，直接要求——
撤回对Anthropic「供应链风险」的定性。
这封信的签署者，来自多家主流科技公司，以及风险投资机构。
其中包括，OpenAI、Slack、IBM、Cursor、Salesforce Ventures等。
59位业界大牛和CEO们纷纷落笔，还有一大批科学家和研究员集体联名声援。
信中，他们还呼吁国会介入，并审查针对一家美国科技公司动用此类特殊权力是否妥当。
在Anthropic拒向五角大楼妥协后，禁令直接砸下，这场「未审先判」的封杀被业界视为赤裸裸的报复。
公开信中写道，目前的局面开创了一个危险的先例。
仅仅因为一家美国公司拒绝接受合同变更就对其进行惩罚，这向全美的科技公司传递了一个明确信号：
要么对政府的要求言听计从，要么就等着被报复。
更耐人寻味的是，就在Anthropic被打压的同时，竞对OpenAI却火速官宣与军方达成协议。
吃相太难看的奥特曼，还在宣称也有同样红线，让硅谷的技术天才们感到了深深不安。
ChatGPT日卸载量，飙涨295%
正因此，全网掀起了「退订」ChatGPT的热潮。
Sensor Tower数据显示，与DOD签署协议后，ChatGPT在美国「日卸载量」瞬间飙涨295%。
而平时这一数字仅为9%左右，用户正用脚投票，表达对AI介入军事领域的强烈不安。
这种情绪也直接反映在评分区，ChatGPT 的「一星评价」在消息公布当天狂拉775%。
另一家Appfigures数据显示，Claude日下载量已首次超越ChatGPT，并在全球六个国家APP Store领跑榜单。
QuitGPT的运动，已从昨天70万人，飙破150万人。
防不胜防，Anthropic就在昨天宣发了Claude新版「记忆功能」。
继Claude面向订阅用户开启「60秒一键搬家」后，今天，免费用户也能用了。
Anthropic坚守两条红线，虽为其带来了一大波流量红利，但也面临着下一步困境。
硬刚白宫，600亿刀融资命悬一线？
外媒Axios称，在短短数月，Anthropic已从200多家风投机构，筹集了超600亿美元。
其中一半的资金，还是上个月刚刚到账的。
然而，这笔天文数字的投资，正面临灭顶之灾，原因就是与美国国防部之间合同纠纷。
2月13日，Anthropic曾宣布了新一轮300亿美元的融资
这场纠纷现在的性质，已经不仅仅是AI技术之争，更像是一场意气之争。
风暴背后，国防部官员认为Amodei坚定的表态，是在「立牌坊」给两拨人看——
对军事合作不满的Anthropic员工；对其他科技巨头有类似顾虑的AI工程师。
在他们看来，如果Amodei真的不想玩了，大可以悄悄退出，而不是闹得满城风雨。
而这种「供应链风险」的定性，极具杀伤力。
如果严格执行，像英伟达这样既与美军做生意，又向Anthropic供应芯片的巨头，这种关系就得被迫切断。
Anthropic正面临被「围猎」的生存危机，这不仅是公司的生死时刻，更可能让AI产业及投资圈陷入前所未有的动荡。
