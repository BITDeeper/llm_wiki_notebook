最近，文本生成 3D 人体运动已经能做出不少自然动作：输入一句 “a person walks forward”，模型就能生成一段走路动画。
但真正做内容创作时，问题很快就来了：如果我想让角色先向前走、再绕一个弯、在某个位置抬手、最后停在指定区域，该怎么用文字说清楚？
仅靠文本描述，往往会陷入两个困境：
描述越细，提示词越长，用户成本越高；
描述得再细，也很难精确控制人物的空间轨迹和关键姿态。
针对这个问题，
北京邮电大学和 EVOL 创新团队
提出了 DrawMotion：一个面向手绘条件的 3D 人体运动生成框架。用户不再需要把脑海里的运动拆成冗长文字，而是可以直接画出轨迹、标出关键 stickman 姿态，再让模型生成自然的人体动作。

为什么“画出来”比“说出来”更适合运动控制？
对人体运动来说，文本更擅长表达语义，例如“走路”“挥手”“跳跃”；但空间控制本身是几何问题，例如“沿着这条曲线走”“在这里转身”“这一段慢一点”。
如果把运动生成比作导演拍戏，文本像是在描述剧情，而手绘轨迹更像是在给演员画走位图。
DrawMotion 的输入因此被设计成多条件形式：
文本：提供动作语义；
2D 轨迹：控制人物骨盆的整体移动路径和速度节奏；
手绘 stickman：在任意时间位置约束关键姿态；
任意组合：用户可以只给文本、只给手绘，也可以同时给多种条件。
手绘轨迹输入
图 1：在 DrawMotion Studio 中手绘 2D 轨迹，系统会将其转换为 3D 人体运动生成的空间控制条件。
这带来了更直观的交互：用户只需要画出路线，模型就能把 2D 手绘输入转成 3D 人体运动条件。
但多条件控制也带来了新麻烦
文本、轨迹、stickman 三类条件并不总是完全一致。
例如，文本写的是 “a person walks forward”，但用户画出的轨迹可能包含急转弯、折返、绕圈。文本模型倾向于生成自然的向前行走，而轨迹条件希望角色严格贴着线走。模型最后会在语义、空间和自然度之间找到一个折中，但这个折中结果未必足够贴近用户画出的线。
这就是 DrawMotion 重点解决的难题：
如何让生成运动更符合手绘意图，同时不牺牲动作自然度？
为此，DrawMotion 包含三部分核心设计。
DrawMotion 框架：扩散过程、MCM 与多条件融合
图 2：DrawMotion 整体框架。模型在扩散生成过程中融合文本、轨迹与 stickman 条件，并通过 MCM 统一处理多种条件组合。
一、Freehand Drawing Condition：把草图变成模型能读懂的条件
DrawMotion 不要求用户手动标注复杂 3D 骨架，而是使用手绘轨迹和 stickman 作为控制信号。
轨迹控制全局移动，stickman 控制局部姿态。对于用户来说，这更接近动画制作里的草图和关键帧；对于模型来说，这些手绘输入会被编码成可参与扩散生成的条件特征。

二、MCM：让文本、轨迹、姿态在扩散模型里融合
多条件输入的另一个问题是计算效率。
如果直接为每种条件组合单独设计通路，模型很容易变得复杂。DrawMotion 提出 Multi-Condition Module（MCM），在扩散模型训练过程中统一处理多种条件组合，例如：
文本 + 手绘；
只有文本；
只有手绘；
无条件生成。
MCM 会把不同条件映射成对运动特征的偏移，再通过 latent encoder 重新融合。这样，模型既能利用多条件信息，又能避免传统 masked attention 带来的额外计算开销。
更关键的是，MCM 还为后面的 IFG 提供了一个非常合适的“可操作位置”。
三、IFG：不重新训练模型，也能让轨迹更贴线
最值得强调的是 DrawMotion 的训练无关引导方法：
Intermediate Feature Guidance，IFG
。
DrawMotion 推理流程：IFG 在采样中更新中间特征
图 4：IFG 推理流程。训练无关引导不直接修改最终动作，而是在采样过程中更新 MCM 的中间特征。
传统的空间对齐方法通常有两种做法：
重新训练额外控制网络，把空间约束注入模型；
在采样过程中直接修改噪声或生成结果。
前者成本高，且不容易对齐；后者容易把运动从真实分布里拉出去，导致动作僵硬、抖动或不自然。
IFG 的思路不同：
它不直接拽最终动作，也不重新训练模型，而是在 DDIM 采样过程中优化 MCM 的中间特征。
这就像不去强行移动演员的身体，而是在导演分镜还没定稿时，调整模型内部对“下一步应该怎么动”的理解。
IFG 为什么可行？
关键发现是：MCM 的中间特征空间相对连续、稠密。
普通模型的中间特征往往像一个个离散簇，稍微扰动就可能跑出有效分布；而 DrawMotion 的 MCM 在融合文本与手绘条件后，中间特征具有更高的连续性。这意味着我们可以在这个空间里做适度梯度更新，而不容易破坏最终运动质量。
MCM 中间特征空间比普通模型更连续
图 5：中间特征空间示意。相比普通模型的离散簇，MCM 的中间特征更连续，因此更适合接受梯度引导。
论文中进一步用 PCA 可视化了这一点：相比 ReMoDiffuse 的不规则特征分布，DrawMotion 的 MCM 中间特征呈现更连续、更稠密的结构。
PCA 可视化：DrawMotion 的 MCM 中间特征呈现更连续的分布
图 6：PCA 可视化结果。DrawMotion 的 MCM 中间特征呈现更稠密的分布，为 IFG 提供了可优化空间。
IFG 具体怎么做？
在每一步 DDIM 反向采样中，IFG 会执行一个很直接的流程：
从指定 MCM 层取出中间特征
F
；
基于当前预测运动与用户轨迹计算空间对齐损失；
用 SGD 更新中间特征，让预测运动更贴近手绘轨迹；
用 Mahalanobis Distance Clipping 限制更新幅度，避免特征越界。
这里的重点是第 4 步。
如果只追求轨迹对齐，梯度更新可能会让中间特征偏离训练分布，结果就是“贴线但不自然”。DrawMotion 用 Mahalanobis Distance（马氏距离）估计特征距离训练分布有多远，一旦超出边界，就把更新裁回可信区域。
简单说，IFG 不是无脑把动作拉到线条上，而是在“轨迹更准”和“运动更自然”之间加了一把统计学标尺。

写在最后
DrawMotion 的核心价值，不只是把手绘草图变成 3D 人体运动生成中的一等条件，更重要的是展示了一条可迁移的控制思路：
用 MCM 找到适合融合多条件的中间表示，再用 IFG 在推理阶段对这个中间表示进行训练无关优化。
换句话说，当一个模型已经训练完成，但用户还希望在推理时施加更精细的控制，我们不一定只能重新训练 ControlNet 式的额外模块，也不一定要硬改最终结果。找到合适的中间特征，并在分布边界内优化它，可能是一种更轻量、更通用的选择。
我们也希望这套思想能被更多研究者尝试到其他生成领域中，例如视频生成、图像编辑、3D 内容生成、机器人轨迹生成和物理仿真控制。DrawMotion 只是一个开始：MCM + IFG 真正想推动的，是让“训练好的生成模型”在不重训的情况下，仍然具备更强、更细粒度的交互式控制能力。
