在AI图像以假乱真的今天，我们还需要什么能力
当前主流图像生成模型已经能够“生成好看的图”，图像的整体生成质量甚至可以达到照片级以假乱真的程度。但是，这些模型输出的只是单一的整体图片，虽然结果看起来精致美观，但是对于后续编辑和素材复用来说，单一的整体图片缺乏足够的结构信息：
哪部分是前景对象A?
哪部分是前景对象B?
哪部分属于图片背景？
哪些内容被遮挡，遮挡的内容是什么？
这些对于进一步编辑所需要的重要信息在单一的整体图片输出中是天然缺失的。这意味着：AI虽然能画，但并不真正理解图像结构。真实世界中的遮挡、透明、反射与前后景关系，本质上并不是单一 RGB 图像能够直接表达的。
将AI生成好的整体图片，精准分解为只包含指定对象的多个可编辑图层
，这就是360人工智能研究院多模态生成团队在ICML2026上发表的工作 RevealLayer 带来的解决方案。RevealLayer 的核心目标，一方面是将一张现有的RGB图片拆解为多个可独立编辑的携带alpha通道的RGBA图层，以支持后续的移动、替换、重组、细节修改和素材复用；另一方面是提供图层分解的高可控性，用户可以通过简单的框选引导，实现对指定对象/细节的精准分解，赋予用户与开发者“指哪分哪”的绝对控制力。

多图层分解
深层上，RevealLayer 做的不再只是“生成图像”，而是在尝试建立图像的结构化表示。过去的生成模型，更像是在“一次性输出最终 RGB 结果”；而 RevealLayer 则让图像变成“可拆解、可编辑、可重组”的结构世界。

核心方法概述
RevealLayer 针对当前图像生成模型“只能生成结果、难以精确编辑结构”的问题，提出了一种面向真实场景的通用图层分解框架。它无需依赖复杂的多阶段分割与修复流程，而是通过遮挡感知的端到端生成方式，将单张RGB图像直接拆解为多个可独立编辑的RGBA图层，并自动恢复被遮挡区域。
为提升复杂场景下的图层分离与遮挡补全能力，RevealLayer 引入 Region-Aware Attention，让不同图层在生成过程中尽可能“互不干扰”；并通过 Occlusion-Guided Adapter 更自然地推理被挡住区域原本应该出现的内容。同时，在训练目标设计上，模型进一步针对“边界模糊”与“跨层残影”问题提出组合损失函数，其中 Hard-Constraint Alpha Loss 重点优化透明边界区域，使前景轮廓更加锐利准确，而 Soft-Constraint Orthogonality Loss 则通过约束不同图层间的特征正交性，显著抑制背景中的目标残留与层间信息泄漏。
相比传统仅关注生成质量的目标函数，RevealLayer 更强调图层独立性、结构一致性与可编辑性，实现了从“生成图像”到“生成结构化可编辑表示”的关键跨越。
数据pipeline构建
过去的多图层数据集大多面向海报、UI或设计素材，而 RevealLayer-100K 首次将多图层分解扩展到复杂真实世界场景，数据中包含大量真实遮挡、透明物体、阴影与反射关系。该数据集结合 Qwen3-VL、Florence-2、SAM、VitMatte 与 Qwen-Image-Edit 等模型，自动完成目标检测、前景提取、背景恢复与遮挡增强，并通过人工审核与一致性过滤生成包含背景层、多前景 RGBA 图层及 bbox 标注的高质量训练数据，为复杂自然场景下的通用图层分解提供了重要的数据基础。

量化实验结果
图层分解可控性
在图层分解任务中，RevealLayer 展现出了显著的可控性优势。相比现有方法难以明确控制图层语义与层级关系的问题，RevealLayer 能够仅通过简单 bbox 条件，实现对指定目标的稳定分解，输出背景层与多个独立前景 RGBA 图层，并准确恢复复杂遮挡区域。同时，模型在图层独立性、结构一致性与可编辑性等方面表现突出，使前景、背景与透明区域能够真正实现“可拆解、可重组、可编辑”的结构化表示。
综合生成与恢复性能
除了图层可控性之外，RevealLayer 在背景恢复与前景 Matting 等核心任务上同样展现出优秀的综合性能。在背景恢复方面，模型能够有效去除目标残影与结构伪影，并保持复杂自然场景中的纹理一致性与空间合理性；而在前景 Matting 方面，RevealLayer 能够更准确地恢复复杂边缘、透明区域与细粒度结构，实现更高质量的 Alpha 边界与透明度建模。实验结果表明，RevealLayer 不仅能够完成高质量图层分解，还进一步提升了遮挡恢复、结构理解与可编辑表示能力。
目标框扰动鲁棒性
在异常 bbox 输入的鲁棒性实验中，RevealLayer 展现出较好的容错能力。实验结果表明，当 bbox 存在轻微放大、偏移或不完整时，模型性能仅出现小幅下降，仍能保持较稳定的背景恢复、前景分解与透明边界质量；只有在 bbox 偏移或缺失较为严重时，图层分离与遮挡补全才会受到明显影响。这说明 RevealLayer 并不依赖完全精确的框标注，在实际交互编辑场景中能够适应一定程度的用户框选误差，具备较强的实用性与鲁棒性。
结语
RevealLayer 不仅实现了复杂自然场景下高质量、可控的多图层分解与遮挡恢复，还构建了涵盖数据、模型与训练目标的完整解决方案，相关模型、数据和代码均已在Github和Huggingface开源。
在当前 AIGC 更关注“生成效果”的背景下，RevealLayer 将研究重点重新拉回“结构理解”与“可编辑性”，使图像不仅能生成，更能被精确拆解、控制与重组。例如在电商场景中，商品、阴影与背景第一次可以被真正独立拆解与重组，而不再只是简单抠图；在广告与内容创作中，前景目标、透明元素与遮挡区域也能够实现更加自然、可控的编辑与组合。
当前图层分解研究仍面临诸多挑战，例如复杂透明材质、视频级图层一致性以及极端遮挡场景下的稳定恢复等方向仍值得进一步探索，相关进展欢迎关注研究院主页：research.360.cn。
