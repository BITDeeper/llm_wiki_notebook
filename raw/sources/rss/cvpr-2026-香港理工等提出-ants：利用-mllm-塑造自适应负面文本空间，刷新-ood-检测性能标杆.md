在开放世界中，深度学习模型经常会遇到一些“没见过”的类别，也就是我们常说的分布外（Out-of-Distribution, OOD）样本。模型自信地对分布外样本误判，在自动驾驶或医疗诊断等应用中可能是致命的。为了解决这个问题，研究者们尝试引入“负标签（Negative Labels）”来划定边界。但传统的负标签往往是静态的、脱离实际图像内容的。

为什么现有的“负标签”不够聪明？
在基于视觉语言模型（如 CLIP）的 OOD 检测中，引入负标签（Negative Labels, NLs）是一个很有效的思路。简单来说，就是给模型准备一堆“不是 ID 类”的标签，如果测试图和这些负标签更像，就判定它是 OOD。
但作者敏锐地发现了现有方法的三个痛点：
缺乏对图像的理解
：以前的方法（如 NegLabel）是从语料库里找一些语义上离 ID 类很远的词。但这些词可能和实际出现的 OOD 图像完全没关系。如图 1 所示，由于不理解图像，这些负标签在特征空间里离真正的 OOD 样本其实很远。
难以应对“近邻”挑战
：最难的是那些长得和 ID 类很像的 OOD 样本（Near-OOD）。比如 ID 类里有“贝果”，OOD 里出现了“甜甜圈”，如果负标签不够精准，模型很容易搞混。
依赖先验假设
：很多方法需要提前知道任务是远端 OOD（Far-OOD）还是近端 OOD（Near-OOD），这在多变的现实环境中显然不现实。
T-SNE 可视化显示 ANTS 生成的句子（ENS）比传统负标签更贴近 OOD 分布
ANTS：让模型在测试时“边看边想”
为了打破这些限制，ANTS 引入了
“测试时理解与推理（Test-Time Understanding and Reasoning）”
的概念。它不再死记硬背一套负标签，而是根据测试流中实际看到的疑似 OOD 图像，动态地调整自己的负面文本空间。这种思路受到了大模型思维链（Chain-of-Thought, CoT）的启发，将感知、理解与推理有机结合。

写在最后
ANTS 的成功给我们提供了一个非常有价值的视角：在视觉语言模型时代，OOD 检测不应该只是简单的特征比对，而可以引入更高层级的语义理解。通过让模型在测试阶段具备“自省”和“推理”的能力，我们能够构建出更加鲁棒、更能适应复杂开放环境的 AI 系统。
目前，该项目的代码已经开源，对于想要在实际业务中落地 OOD 检测的同学来说，这套免训练、自适应的方案非常值得一试。
