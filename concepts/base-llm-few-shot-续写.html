Base LLM Few-Shot 续写 §

定义 §

Base LLM Few-Shot 续写 是一种利用基座大模型（Base Model，即未经过安全对齐的模型）的文本补全能力，通过提供少量示例来生成特定风格（通常是“有害”或“非道德”）回复的数据生成技术。

为什么需要 Base 模型？ §

经过安全对齐的指令模型通常内置了拒绝机制，当收到有害请求时会直接拒绝回答。这导致在构建安全护栏数据集时，缺乏“真实的负面样本”来训练模型识别和拒绝有害内容。

Base 模型由于没有经过 RLHF 或安全指令微调，保留了原始的文本分布预测能力，因此更容易续写出包含有害内容的文本。

实施方法 §

  1. 模型选择: 选择参数量较大且未对齐的 Base 模型（如 qwen3-14b-base）。
  2. Prompt 设计: 构造 Few-Shot 提示词，包含几个“有害问题”及其“有害回答”的示例。
  3. Stop Tokens: 设置严格的停止符（如 \n\n问：），防止模型在生成回答后无限续写下去。
  4. 生成: 让模型根据新的有害问题，模仿示例的风格续写回答。

应用场景 §

在 HongKong ElderCare SafeGuard 项目中，该技术用于 STAGE6 Step2，专门生成 Unsafe Response。项目组发现，仅靠 Instruction LLM 扮演“无道德角色”生成的有害内容往往不够自然，而引入 Base LLM 续写则能获得更真实、更多样化的攻击样本。

风险与限制 §

  • 模型获取: 随着安全法规的收紧，高质量 Base 模型的获取和部署可能会受到限制。
  • 内容不可控: 生成的内容可能极其极端或冒犯，需要在隔离环境中进行，并严格审核。
