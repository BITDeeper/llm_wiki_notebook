记忆-技能-训练闭环 §

“记忆-技能-训练闭环”是 hermes-agent 提出并实现的一种 Agent 自我进化机制。它旨在解决传统 Agent 容易失忆、无法积累经验的问题，通过三层架构将 Agent 的使用过程转化为可复用的资产和训练数据。

三层架构 §

1. 记忆层 §

  • 功能：负责存储和检索上下文信息。
  • 实现：
    • 使用 MEMORY.md 记录环境信息、历史教训和长期知识。
    • 使用 USER.md 记录用户偏好、工作习惯和个性化设置。
    • 支持基于 FTS5（全文搜索）的跨会话检索，允许 Agent 搜索几周前的对话内容。
  • 作用：确保 Agent 在每次会话开始时都能加载必要的背景信息，避免“失忆”。

2. 技能层 §

  • 功能：将复杂任务的经验固化为可复用的程序。
  • 实现：
    • 当 Agent 完成复杂任务（通常涉及 5 次以上工具调用）后，自动生成结构化的 Skill 文件。
    • Skill 文件包含操作步骤、常见陷阱和验证方法。
    • 自我迭代：如果在使用 Skill 的过程中发现更优解，Agent 会自动更新该 Skill。
  • 作用：实现“越用越快”。对于重复性任务，Agent 可以直接调用 Skill 而非从头推理，显著提升效率。

3. 训练数据层 §

  • 功能：回收行为数据用于模型优化。
  • 实现：
    • 内置批量轨迹生成器，记录 Agent 的所有工具调用和决策过程。
    • 集成 Atropos 强化学习环境，利用产生的轨迹数据训练下一代模型。
  • 作用：实现“越用越强”（指模型层面）。这是 nous-research 战略的核心，即通过 Agent 收集高质量数据反哺模型训练。

价值与局限 §

  • 价值：构建了一个完整的数据飞轮。用户的使用不仅解决了当前问题，还为 Agent 提供了长期记忆和短期优化，最终服务于底层模型的进化。
  • 局限：在当前的 Hermes Agent 实现中，模型参数本身并未在本地实时微调。所谓的“进化”主要体现在技能库的丰富和记忆的完善上，模型能力的提升需要依赖离线训练和版本更新。

与“自进化”的区别 §

这一概念与 自进化架构 密切相关，但更侧重于工程实现路径。它强调的是通过非参数化（记忆/Skill）和参数化（模型训练）两种方式的结合，实现系统的持续演进。
