MaaS §

MaaS（Model as a Service，模型即服务）是一种将大模型能力封装成标准化 API 接口，通过公有云调用，按调用量（Token）付费的商业模式。它是 AI 云战争的核心战场，也被视为 SaaS（软件即服务）在 AI 时代的演进。

核心特征与逻辑 §

MaaS 模式具备以下核心特征：

  • 标准化交付：无需客户自行部署或运维模型，通过 API 直接获取能力。
  • 按需调用（按量付费）：企业无需自建昂贵的 GPU 集群，而是像用电一样，按 Token 使用量灵活付费。
  • 边际成本递减：模型训练一次后，调用量越大，单 Token 成本越低，规模效应极强。
  • 高粘性：一旦业务集成，客户迁移成本较高，容易形成经常性收入。

商业飞轮 §

MaaS 模式具有显著的飞轮效应：模型效果越好 -> 吸引高价值客户 -> 带来规模收入与利润 -> 投入研发提升模型效果。这种模式打破了传统 AI 项目“增收不增利”的困局。

迭代优势 §

大模型里程碑更新极快（约每半个月一个），MaaS 平台能第一时间接入新模型，避免了企业重复部署和运维的痛苦。

与传统模式的对比 §

MaaS 相比于传统的定制化项目制，在收入模式、利润率和扩展性上具有显著优势。

维度传统项目制MaaS (模型即服务)
收入模式一次性交付，验收付费经常性收入，按量/按时付费
利润率受限于人力外包成本边际成本低，利润率更高
扩展性依赖人力堆叠依赖技术复用，扩展性强

市场格局与代表企业 §

MaaS 模式在全球范围内已被验证具备极高的商业价值。

  • anthropic：80%以上收入来自 API，2025年营收45亿美元，毛利率40%。
  • 智谱：MaaS API 平台 ARR 约17亿元，毛利率41%，验证了该模式在中国的可行性。
  • 云厂商视角：AWS 管理层表示，长远来看 MaaS 的收入贡献将与 EC2（传统计算服务）不相上下。中国头部云厂商正加码 MaaS，有的定下了“拿下 AI 云市场 80% 增量”的目标。

行业趋势 §

随着大模型技术的成熟，越来越多的 AI 公司（如 云知声）正计划从传统的“定制化项目制”向 MaaS 模式转型。云知声在财报中明确提出，将推进 API 调用、Token 计费等模式，并探索 C 端订阅制产品，以提升收入的稳定性和可预测性。

优势 §

相比于自建 GPU 部署，MaaS 具有以下优势：

  1. 灵活性：用多少买多少，无需承担硬件折旧风险。
  2. 透明度：公有云上的真实调用数据（Token 调用量）能真实反映 AI 落地情况，而自建往往是一个“黑箱”。
  3. 生态支持：通常附带完善的工具链和安全方案（如 火山引擎 的 Agent 安全方案）。

挑战 §

虽然 MaaS 模式具有高利润率和扩展性的优势，但也面临挑战，例如 ai-subscription-crisis（AI 订阅制危机）。在 Agent 时代，高算力消耗可能导致传统的固定订阅模式失效，行业可能需要探索分层定价或按效果付费的新模式。

相关概念 §

  • Token 经济：MaaS 的计费基础。
  • SaaS：软件即服务，MaaS 是其在 AI 时代的演进。
